# tokyo_subway_3d — 東京の地下鉄を「実際の深さ」で3D化する

地下鉄を地図の上に描くのではなく、**実測の軌条面標高（T.P. 基準）で地下に描く**ための
データパイプラインとビューア。対象は **都心の交差ハブを通る10路線・88駅**
（東京メトロ 銀座・丸ノ内・東西・日比谷・千代田・有楽町・半蔵門・南北、都営 三田・大江戸）。

大手町では5路線が 丸ノ内 −7.2 / 三田 −8.8 / 千代田 −9.7 / 東西 −15.6 / 半蔵門 −23.6 m (T.P.) と
積み重なり、東京メトロ最深の**国会議事堂前（公表 地下37.9m）**は千代田線で 40.9 m、都内最深の
**六本木（大江戸線、公表 42.3m）**は約 40 m と出る。成果物の正しさをこうした公表値で検証できる区間を選んでいる。

## なぜ可能なのか（データの出どころ）

地下鉄の連続的な深さは公開されていない、と思われがちだが、
**中央防災会議の浸水シミュレーション資料に路線別の縦断図がある**。

| 要素 | 出典 | 形式 |
|---|---|---|
| 軌条面標高（深さの本体） | 中央防災会議 大規模水害対策に関する専門調査会 第13回(2009-01-23) 資料8「地下鉄等の浸水シミュレーション（縦断図）」 | 150dpi の JPEG ラスタ（**画素トレースで数値化**） |
| 平面線形・駅位置 | OpenStreetMap（ODbL、`railway=subway` の way と `stop_position` ノード、出典 基盤地図情報2500） | Overpass API |
| 地表標高 | 国土地理院 標高API（DEM 1m/5m レーザ） | JSON（ローカルキャッシュ） |

資料8は37ページあるが、**同じ約17本の縦断図を6つの洪水シナリオで繰り返しているだけ**で、
ユニークな情報は pp.3–7 の17チャート（銀座・丸ノ内・東西・日比谷 / 千代田・有楽町・半蔵門・南北 /
大江戸・浅草・三田・新宿 / 埼玉高速・TX / JR横須賀総武・京葉・新幹線）。**副都心線は非収録**。

## 構成

```
src/subway3d/lines.py      路線の設定表: ページ・チャート番号・軸の値・駅名と図上距離（目視値）
src/subway3d/chart.py      縦断図の画素トレース（枠の自動検出・軌条面カーブ・駅マーカー▼・校正チェック）
src/subway3d/alignment.py  OSM way のノードグラフを駅から駅へ最短路で辿り、片側1線の中心線と駅アンカーを得る
src/subway3d/elevation.py  国土地理院 標高API（キャッシュ付き）
src/subway3d/build.py      駅をアンカーにした距離軸のラバーシート → model.json / lines.geojson
viewer/index.html          「地上から」= MapLibre + deck.gl / 「地下から」= deck.gl FirstPersonView
```

## 精度と、その根拠

| 項目 | 実測した誤差 | 検証方法 |
|---|---|---|
| 縦（標高）軸の校正 | **±0.15m**（10チャート全部） | 印字された5m刻みグリッド線と突き合わせ（`test_y_axis_calibration_matches_printed_gridlines`） |
| 横（距離）軸 | 区間全体で **0〜6%**（図が短め） | 図上の駅間距離 対 OSM線形の駅間距離 |
| 深さの絶対値 | **+3.0m**（国会議事堂前 40.9m 対 公表37.9m） | 公表値との比較 |
| 交差駅の地表標高 | 路線間の差 ≤ 6m | 同じDEMを別ノード（≤300m離れ）で引いた差 |

深さの残差3mの内訳は、①本パイプラインは**ホーム面でなく軌条面**までを測る（約1.1m）、
②公表値の地表基準点が不明で、当地は100m四方で標高が数m変わる、③画素トレース±0.3m。
**縦断の形（相対的な起伏）は±0.3mで信頼できるが、深さの絶対値は±3m程度**と理解して使う。

横軸は図の方が局所的に大きく歪む（南北線の溜池山王〜永田町は図上 620m 対 実測 900m）。
駅をアンカーにしたラバーシートで吸収しているので、駅間の**形**は正しいが、駅間の**どこ**で
起伏が起きるかは図の歪みぶんだけずれうる。

## 落とし穴（実際に踏んだもの）

- **駅の代表点で地表標高を引いてはいけない。** 国会議事堂前の駅代表座標は国会議事堂側の
  高台（標高25.5m）に乗っており、深さが44mになる。地表標高は**トンネル線形に沿って**引く。
- **駅名ラベルが軌条面の黒線と混ざる。** 「◯◯線から流入」の青い箱が黒線の上に描かれて線が
  消える（有楽町線 永田町、南北線 溜池山王）、浅い区間では縦書きの駅名が線の下まで垂れる
  （半蔵門線 青山一丁目、日比谷線 六本木）。「列の最下の黒画素」をそのまま使うと 10〜27m の
  スパイクになる。**ラベル中心の ±20px だけ**、両脇の値を結ぶ弦から 3m 以上外れていれば弦で
  置き換える（`chart.rail_profile`）。列全体を見る連続性トラッカーは、駅名の行という「もう一本の
  連続した黒線」に乗り移って破綻した。「細い1本の線だけ読む」方式は急勾配（線が太る）と駅
  （▼で汚れる）で実在の起伏を切り落とした。どちらも試して捨てた。
- **枠内上端の「20:25」形式の時刻ラベル**は黒線が隠れた列で最下の黒画素になる。上端45pxは読まない。
- **駅マーカー▼は黒とは限らない。** 赤▼（最初に浸水する駅）・青▼（他路線から流入）は検出されない。
  丸ノ内線/半蔵門線の大手町・東西線の茅場町・有楽町線の飯田橋・大江戸線の青山一丁目/新御徒町は
  目視の図上距離のまま使っている。
- **OSM の stop_position は上下線に1つずつ**ある。片側の線形に投影して 0m で乗る方を採る。
  `railway=station` ノードは複数路線の中間に置かれていて 100〜300m ずれる。
- **way の head-to-tail 連結は 5/9 路線で失敗した。** ホーム内の線路は `東京メトロ有楽町線;有楽町;1番線`
  のような名前を持ち、無名の連結 way もある。路線名を部分一致させた way ＋無名 way でノードグラフを
  作り Dijkstra で辿る。上下線は別のノード列なので、渡り線が近道にならない限り片側に留まる。
  **環状の大江戸線は始点→終点の最短路だと西側の弧を通る**ので、設定表の駅順に駅から駅へ辿る。
- **銀座線の図は最初の130mが模式的**（12m 落ちる）。青山一丁目は外し、赤坂見附から始めている。
- 図の黄色い地盤高線は駅名の黄色ハイライト箱と混ざる。地盤高は図から読まず国土地理院DEMを使う。
- リポジトリ名とパッケージ名を同じにすると pytest 9 が名前空間パッケージ化して import が壊れる
  （ワークスペース既知の罠）。ディレクトリ `tokyo_subway_3d` に対しパッケージは `subway3d`。

## ビューア

`viewer/index.html` は1ページで2つの見方を切り替える。

- **地上から**: MapLibre（地理院タイル）＋ deck.gl オーバーレイ。負のzは画面上では手前へのずれにしか
  見えないので、地表→線路に半透明のカーテンを垂らして「地下にぶら下がる」ように見せる。
- **地下から**: deck.gl 単体の `FirstPersonView`。**MapLibre のカメラは地図面より下に置けない**ので
  別レンダラになっている。地表は航空写真タイルを半透明の天井として描く（淡色地図は真下から
  見ると巨大な鏡文字になる）。駅へジャンプ・路線の表示切替・深さの誇張・天井の濃さ。
  操作は**地上（MapLibre）と同じ流儀**に揃えてある：左ドラッグ＝移動（地図をつかむ）、右ドラッグ／
  Ctrl+ドラッグ＝見回す、ホイール＝前進/後退（ズーム相当）、矢印/WASD＝移動、Shift+矢印＝回転と
  上下向き、Q/E＝上昇/下降、R＝水平に戻す。符号は MapLibre を実測して合わせた（右ドラッグ右→方位＋、
  上→ピッチ＋、左ドラッグ下→前進、右→カメラは左へ）。モード切替でカメラの位置と方位を引き継ぐ。
  deck の `FirstPersonController` は矢印で回転し慣性が付くので使っていない。マウスだけでも動かせる
  よう右下に十字パッド。左上のパネルは「−」でたためる。

z は T.P. でなく「地表からの深さ」。地図タイルは海抜0mの平面なので、T.P. をそのまま z にすると
地表 +22m の国会議事堂前で地表線が地図の上空に浮く。

描画確認は Playwright の chromium（`~/.cache/ms-playwright/chromium-1234`）で行う:

```bash
python3 -m http.server 8137 &
node viewer/shot.mjs /tmp        # → /tmp/viewer_surface.png, /tmp/viewer_underground.png
```

deck.gl の `TextLayer` は既定の `characterSet` が ASCII のみで日本語が化ける（`'auto'` が要る）。
**`TextLayer` は `FirstPersonView` では何も描かない**（`CollisionFilterExtension` の有無に関係なく）ので、
地下モードの駅名は `viewport.project()` で位置を出した DOM 要素として重ねている。
半透明カーテンは `depthWriteEnabled:false` にしないと背後のラベルを隠す。
