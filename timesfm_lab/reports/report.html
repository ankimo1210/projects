絶対に見ていないデータ同じモデル・同じ手続きで、学習コーパスとの関係だけを変えて TimesFM 3.0 を測り直す

初版で「学習データ汚染の仮説は棄却された」と書いた。これは誤りだったので訂正する。当時の検定は、汚染が効くとしたら効くはずの経路に対して構造的に盲目だった。汚染を切り分けるために、絶対に学習され得ないデータを2種類用意して測り直した — 既知の生成過程から作った合成系列と、2026年の市場データである。

結果ははっきり勾配になった。実装可能な古典手法の選択器を相手にしたとき、TimesFM の優位は学習済みと確認できたデータで +36.3%、構造的に未学習のデータで +7〜9%。優位そのものは本物だが、公開ベンチだけを見て得られる数字の 4分の1 である。

合成データはもう一つ別のことを教える。真の生成過程が分かっているので到達可能な誤差の下限が計算できる。下限が正の値を取る7過程のうち6つで、TimesFM はその +0.7〜3.4% まで届く。届かない2つ — 水準ジャンプと決定論的カオス — の外し方が、それぞれ別のことを教える。

01

4つの層に分けて測る

データセットを、「TimesFM がこれを学習していない」という主張の強さで4層に並べた。層のあいだで結果が食い違うなら、その食い違いの大きさこそが知りたかったものである。

  • 層A — 学習済みと実証したもの。コーパスから実データを落として値を突き合わせ、一致を確認した2系統。
  • 層B — コーパスの一覧に無いもの。弱い主張で、ファイル一覧が完全でモデルカードが正確であることに依存する。
  • 層C（合成） — 存在し得ないもの。乱数種から今回生成した8過程。どのクローラも到達しようがない。
  • 層C（金融） — カットオフ後のもの。予測対象が全て 2026年3月〜9月の市場データ。カードが挙げる最も遅いカットオフ（2023年11月）より後である。

ベースラインは7手法。初版の5つ（ナイーブ・季節ナイーブ・Theta・減衰 Holt-Winters・フーリエ回帰）に、金融のために HAR（Corsi の実現ボラティリティ標準手法）と EWMA を足した。全手法が点予測と分位点の両方を出す。

02

訂正：汚染について、前回は言い過ぎた

確認できている事実は変わらない。TimesFM 3.0 のモデルカードが学習源に挙げる GiftEvalPretrain の中身を落として突き合わせると、Monash の traffic_hourly と weather がバイト単位で同一に入っている。traffic は862系列、weather は3,010系列が一致し、コーパス側は末尾のテスト区間（それぞれ168点＝7日、30点）だけを削った完全なコピーである。

初版はここから、窓を「予測対象がコーパスに入っている／入っていない」で二分して比べ、差が出なかったこと（p = 1.00 / 0.54）をもって汚染仮説を棄却した。この推論が誤りだった。いま文脈側の被覆を測ると、こうなっている。

どちらの群も、条件付けに使う窓はほぼ丸ごと学習済みだった。あの検定が検出できるのは「答えそのものを覚えていたか」だけで、「このセンサーの週次プロファイルを事前学習で知っているか」には効かない。効くとしたら後者なので、否定的結果は棄却の根拠にならない。

そこで層をまたいで比べる。相手を4通り取り替えても、層Aが最上位である点は変わらない（層B と層C のあいだの順序は相手によって入れ替わるので、勾配として読めるのは A とそれ以外の差である）。

初版からの変更

初版の結論表にあった「勝ちは学習データの記憶か → 説明できない（棄却）」は撤回する。正しくは「予測対象そのものの記憶は否定できたが、系列に対する馴染みは否定できていない。層をまたぐ比較はむしろ汚染が効いていることを示唆する」である。数値そのもの（p = 1.00 / 0.54）は再計算しても変わらない。誤っていたのは、その数値から引き出した結論の範囲である。

03

合成データ：到達可能な精度と、そこからの距離

既知の関数から系列を作ると、二つのことが同時に手に入る。ひとつは汚染が原理的に不可能なこと。もうひとつは、真の生成過程が分かっているので予測誤差の下限が計算できることである。ある時点までの情報を与えられたとき、未来の条件付き分布は既知だから、そのシミュレーションから最適な点予測（絶対誤差を最小化するので条件付き中央値）と最適な分位点が出る。この下限に対する距離が、「ベースラインより何%良い」よりずっと意味のある量になる。

8過程を用意した。安定した周期、周期＋トレンド、AR(1)、ランダムウォーク、水準ジャンプ、決定論的カオス、周期的な分散、間欠需要。下限が正の値を取る7過程のうち6つで TimesFM は理論限界の +0.7〜3.4% に入る。残る2つの外し方が対照的である。

決定論的カオスは誰も学習できない

ロジスティック写像 z ← 3.9 z (1−z) はノイズを一切含まないので、理論限界は誤差ちょうど 0 である。512点の観測からこの再帰を復元できれば完全に予測できる。TimesFM の MASE は 0.565、最良の古典手法は 0.569 — 両者の差は 0.7% で、要するに誰も写像を学習していない。基盤モデルは滑らかな周期や平均回帰には強いが、短い決定論的再帰の同定はしていない。到達可能な精度が 100% ある場所で、誰も 1% も取れていない。

04

金融：カレンダーが保証する未学習データ

市場データを使う理由は、金融が得意分野だからではなく、未学習であることを日付が保証するからである。評価窓の予測対象はすべて 2026年3月13日〜9月7日にあり、文脈の開始でさえ最も古くて 2024年2月で、カードが挙げるどのカットオフよりも後になる。

対象は予測可能性の異なる3系列。出来高（対数）は曜日周期があり素直に予測できる。レンジボラ（Parkinson 推定量）はクラスタリングし、これは HAR が作られた目的そのものである。対数収益率は対照群で、ここで大きく勝つ手法があったら手法より先に実装を疑うべき系列である。

結果は控えめな勝ちだった。TimesFM は3系列すべてで CRPS 1位だが、点予測で HAR を有意に上回るのは出来高だけである。

05

「最良の古典手法」は、いまも実在しない

初版の中心的な指摘はそのまま残る。単体のベースラインを相手にすると TimesFM は全勝するが、窓ごとに全手法の最小値を取る「オラクル」には負ける。しかしオラクルは手法ではなく、ばらつく推定値を後知恵で選んだノイズの下界である。

今回、ベースラインを5手法から7手法に増やしたことで、この主張を直接検証できた。足した2つは平凡である — 公開ベンチ7系統での平均 MASE は HAR が 1.889、EWMA が 2.070 で、既存の5手法より悪い。もしオラクルが「良い手法を選ぶこと」を意味するなら、悪い候補を足しても改善しないはずである。ノイズの下界なら、候補が増えるだけで下がる。

06

不確実性は、点予測ほどには良くない

確率予測としては CRPS で TimesFM が 0.950、最良のベースライン 1.335 を大きく引き離す。だが区間の当たり方は依然として狭い側に外れる。名目 80% 区間の実測被覆は 0.792 で、層別に見ると公開ベンチで 0.770〜0.787、合成と金融では 0.803〜0.807 と名目に近い。未学習データの方が較正が良いのは、初版で書いた「一律に狭すぎる」より穏やかな像である。

それでも PIT 曲線の形は変わらない。10% 分位点の下に実測の 14.5% が落ち、90% 分位点の下には 89.1% しか落ちない。両裾が実際より薄い。経験残差ブートストラップを付けた季節ナイーブの方が、全分位点で対角線に近い。

07

この結果が言えないこと

  • 層は領域とも交絡している。層Aの2系統はセンサーネットワークで、層Cは合成と金融である。汚染の効果と「領域ごとの伸びしろ」を完全には分離できていない。最も近い対照は traffic（862センサー・時間足・学習済み・+34%）と electricity（321センサー・時間足・一覧に無い・−8%）だが、これも一対の観察に過ぎない。
  • 学習コーパスの完全な目録は公開されていない。層Bは「一覧に無い」以上のことを言えない。Wikipedia 閲覧数・Google Trends・合成／拡張データの寄与も測れていない。
  • 合成過程は現実より易しく、推定のばらつきも小さくない。8つとも定常か、単純な非定常で、実データの持つ構造変化・欠測・外れ値・複数季節性は入っていない。加えて、種の与え方を直した際に系列が張り直され、水準ジャンプでの限界超過が +4.1% から +12.0% に動いた — 1過程あたり120窓では、この程度の変動が残る。
  • 金融は日次バーだけ。レンジボラは Parkinson 推定量で、日中データによる実現ボラティリティではない。銘柄は18で、窓は各6本しかない。
  • 単変量ゼロショットのみ。TimesFM 3.0 の目玉である多変量・共変量サポートも、ファインチューニングも使っていない。
  • seed は1本。系列サンプリングと合成生成のばらつきは測っていない。窓ごとのペア検定は系列選択の分散を吸収しないので、p 値は「この系列集合において」と読む。
  • 重みは非商用ライセンス。TimesFM のソースコードは Apache-2.0 だが、3.0 の学習済み重みは timesfm-non-commercial-license-v1.0 で商用・本番利用は許諾されていない。商用の目を残すなら Apache-2.0 のままの 2.5 系を使うことになる。
