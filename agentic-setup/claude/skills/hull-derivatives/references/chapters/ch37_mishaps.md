# Ch.37 Derivatives Mishaps and What We Can Learn from Them

> **Source**: Hull 11e, Chapter 37 (pp. 815-826). Paraphrased summary for personal use.

## 1. 要点

- デリバティブ市場は数兆ドル規模で概ね機能しているが、1980年代半ば以降に発生した大規模損失事例は、内部統制の欠如・役割分担の不備・モデル依存・流動性リスクの軽視という共通パターンを持つ。
- リスク限度額はボードレベルで設定し、個人レベルまで分解して厳格に適用すること。利益が出ているときも違反は同等に罰しなければならない。市場を継続的に出し抜けると仮定してはならない。
- フロント・ミドル・バックオフィスの分離は必須。Barings（Leeson）・Société Générale（Kerviel）の崩壊はいずれも同一人物が取引記録と執行の両方を支配できた構造的欠陥に起因する。
- モデルリスクと流動性リスクは密接に絡む。「フライト・トゥ・クオリティ」発生時には非流動的証券が理論価格を大幅に下回る水準で売られる。LTCMはこの状況に高レバレッジで直面した。
- 非金融企業は自社のエクスポージャーに直接由来しない取引戦略を排除し、財務部門をプロフィットセンター化することを避けるべき。ヘッジの目的はリスク低減であり、期待収益の向上ではない。

## 2. キー用語

- **rogue trader（不正トレーダー）**: 会社の承認なく投機的ポジションを積み上げ損失を隠蔽する従業員。Leeson（Barings）・Kerviel（SocGen）・Jett（Kidder Peabody）が典型例。
- **front office / middle office / back office**: 取引執行部門 / リスク監視部門 / 記録・決済部門。三者の分離が内部統制の基本。
- **model risk（モデルリスク）**: 価格付けや損益計算に使うモデルが誤っているリスク。Kidder Peabodyはシステムの利益計算バグによって架空利益を生んだ。
- **inception profit（初期利益）**: エキゾチック商品を販売した際に市場価値を超えて認識される利益。モデル依存度が高く、即時認識は危険。
- **liquidity black hole（流動性ブラックホール）**: 多数の市場参加者が同一戦略を採っているため、売りが更なる売りを誘発して流動性が消失する状況。
- **convergence arbitrage（収束裁定）**: 理論上同一価格になるべき二証券の価格差を取る戦略。LTCMが採用。ただし価格差が短期的に拡大するリスクを内包する。
- **marking to model**: 流通市場がなく観察可能な市場価格が存在しないためモデル値で時価評価すること。
- **flight to quality（安全資産選好）**: 市場ストレス時に投資家が高品質・高流動性資産へ一斉に移動する現象。非流動資産の価格を急落させる。
- **wrong-way risk（逆方向リスク）**: カウンターパーティの信用悪化とエクスポージャーの増大が同時に起きるリスク（→ Ch.9）。
- **stress test / scenario analysis**: 極端な市場変動を想定したリスク量の推計。VaR単独では捉えられないテールリスクを補完する。
- **clawback（クローバック）**: 後に業績が悪化した場合にすでに支払ったボーナスを回収する仕組み。短期業績偏重のインセンティブを是正する。

## 4. アルゴリズム / 手順

### リスク管理ガバナンス・チェックリスト（Hull Ch.37 の教訓を手順化）

1. **リスク限度額をボードレベルで設定する** — 全社リスク許容量を取締役会が承認し、文書化する。
2. **限度額を個人レベルに分解する** — 各トレーダー・部門に対応するポジション限度・損失限度（日次 P&L、VaR 等）を割り当てる。
3. **限度額超過に利益・損失で対称的なペナルティを課す** — 利益時の超過を黙認すると「限度額は守らなくてよい」という文化が生まれる。
4. **フロント・ミドル・バックオフィスを厳格に分離する** — 同一人物が取引執行と記録・決済を兼務させない。バックオフィス経験者が同ポジションに移るケースも要注意。
5. **高利益トレーダーを特別扱いしない** — スター・トレーダーのポジションも通常のデューデリジェンスと説明責任の対象とする。
6. **日次報告書をモデル価格と実現損益の両方で照合する** — バリュエーション・プロシージャの正確性を確認する。
7. **モデルを盲信しない** — 簡単な取引戦略で常に大きな利益が報告される場合はモデルを疑う。競合より著しく有利な価格提示も同様。
8. **inception profit は保守的に認識する** — 商品の存続期間にわたって段階認識し、モデル仮定を複数シナリオで検証する。
9. **VaR とシナリオ分析・ストレステストを組み合わせる** — 「最悪の世界」における流動性スプレッド拡大・フライト・トゥ・クオリティを明示的に試験する。
10. **「皆が同じ戦略を取っている」かを常に問う** — 流動性ブラックホールとなり得る環境を早期検知する。
11. **短期資金による長期ポジション調達を最小化する** — ロールオーバーリスクを限定し、Basel 流動性比率基準を遵守する。
12. **インセンティブ構造を長期業績に連動させる** — ボーナスの繰延・クローバック条項を導入し、短期利益偏重を抑制する。

## 5. Python reference

参考: 日次リスク限度額違反のシンプルな検知例（教示目的）。

```python
import numpy as np

def check_risk_limits(daily_pnl: np.ndarray, var_limit: float) -> list[int]:
    """
    Return indices of days where |P&L| exceeds the VaR-based daily limit.

    Parameters
    ----------
    daily_pnl  : array of daily P&L values (positive = profit)
    var_limit  : absolute loss limit (positive number, e.g. 1_000_000)

    Returns
    -------
    List of day indices with limit breaches (both profit and loss sides).
    """
    breaches = np.where(np.abs(daily_pnl) > var_limit)[0]
    return breaches.tolist()


# Example — symmetric penalty: profit breaches flagged just like loss breaches
rng = np.random.default_rng(42)
pnl = rng.normal(loc=0, scale=500_000, size=252)       # ~1yr of daily P&L
limit = 1_200_000                                       # e.g. 1-day 99% VaR
breach_days = check_risk_limits(pnl, limit)
print(f"Breach days: {breach_days}")
print(f"Total breaches: {len(breach_days)} out of {len(pnl)} trading days")
```

## 6. 注意点 / 典型的なミス

### 金融機関のケース

| 事例 | 損失規模 | 根本原因 |
|------|---------|---------|
| **Barings（Nick Leeson, 1995）** | ~$1B | シンガポール拠点でフロント・バックを兼務。日経225先物の方向性ベットを隠蔽し続けた。200年の歴史を持つ英国銀行が消滅。 |
| **Kidder Peabody（Joseph Jett, 1994）** | $350M | 社内システムがゼロクーポン債のストリップ＆再構成を誤って利益計上。モデル・システムバグに依拠した架空利益。 |
| **Société Générale（Jérôme Kerviel, 2008）** | >$7B | バックオフィス経験を持つトレーダーがシステム上の抜け穴を利用して株式指数先物の巨大ポジションを隠蔽。 |
| **LTCM（1998）** | ~$4B | 収束裁定にロシアのデフォルトが直撃。高レバレッジ＋非流動資産ロング/流動資産ショートの構造がフライト・トゥ・クオリティ時に致命的。同戦略の競合他社が同時清算を試み流動性ブラックホール化。 |
| **Allied Irish Bank（John Rusnak, 2002）** | ~$700M | 外為トレーダーが架空オプション取引を作成して損失を隠蔽。数年間発覚せず。 |
| **Amaranth（Brian Hunter, 2006）** | $6B | 天然ガス先物の方向性ベット。単一商品への過度な集中リスク。 |
| **UBS（Kweku Adoboli, 2011）** | $2.3B | 株式指数ポジションの無断投機。フロントとバックの監督体制の脆弱性。 |
| **Midland Bank（1990s初）** | $500M | 金利方向ベットの失敗。後に HSBC に買収。 |
| **サブプライム関連（2007-08）** | 数兆ドル規模 | ABS CDO のAAA格上位トランシェへの過信。市場透明性の欠如・信用格付け依存・短期調達依存（Lehman, Northern Rock）。→ Ch.8 参照。 |

### 非金融企業のケース

| 事例 | 損失規模 | 根本原因 |
|------|---------|---------|
| **Metallgesellschaft（1993-94）** | $1.3B | 長期石油供給契約を短期先物のスタック・アンド・ロールでヘッジ。ヘッジ打ち切りを迫られた際に損失確定。→ Ch.3 参照。 |
| **Orange County（Robert Citron, 1994）** | ~$2B | 金利上昇リスクを無視したレバレッジ付きデュレーション・ベット。過去の利益が過信を生み、リスク限度違反を黙認させた。 |
| **Procter & Gamble（1994）** | ~$90M | Bankers Trust から購入した高度にエキゾチックな金利デリバティブの仕組みを十分理解していなかった。金利上昇で急激な損失。 |
| **Gibson Greetings（1994）** | ~$20M | 同様に Bankers Trust のエキゾチック金利デリバティブで損失。後に提訴・和解。 |
| **Hammersmith & Fulham（1988）** | ~$600M | 英国地方自治体がスターリング金利スワップ・オプションを大量締結。英国裁判所が契約を無効と判断、銀行側が損失を負担。 |
| **Allied Lyons（1991）** | $150M | 食品・飲料会社の財務部門がドル/スターリング為替レートのコールオプションを売却して損失。 |
| **Sumitomo（Hamanaka, 1990s）** | ~$2B | 単一トレーダーが銅の現物・先物・オプション市場を長期にわたりコーナリング。不正取引の典型例。 |
| **Shell（日本子会社）** | $1B | 通貨先物の無断投機。単一従業員による不正取引。 |

### 構造的・ガバナンス的ミス

- **利益超過時にリスク限度違反を黙認する**: Orange County の Citron が典型。過去の利益が賭けを大きくすることを許してしまった。
- **「市場を読める」と過信する**: 4四半期連続利益の確率は 1/16 — 16 人中 1 人は純粋な偶然でも達成する。スキルとラックを混同しない。
- **分散効果を過小評価する**: 特定市場変数に特化した賭けは、分散によって達成できるリスク調整後リターンを大幅に下回る可能性がある。
- **inception profit の即時全額計上**: モデル依存の初期利益を即時認識すると、トレーダーがボーナスを得て退職した後にモデルが誤りと判明するリスクがある。
- **簡単な戦略が常に大きな利益を生む**: モデルが誤っているサインとして扱うべき。
- **財務部門のプロフィットセンター化**: ヘッジ担当者に利益動機を持たせると投機へのドリフトが生じる。P&Gや Gibson Greetings のケースはこの構造的問題の表れ。
- **短期資金で長期ニーズを賄う**: ロールオーバーに問題が生じると流動性危機に直結（Lehman, Northern Rock）。
