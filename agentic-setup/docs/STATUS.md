# 非公開APIキーの共有

更新: 2026-11-01

## 目的・完了条件

実キーを公開レポに入れず、Google Driveを保存元としてWindows・WSL・Macで
毎回入力せずに使用する。起動時に選んだサービスのキーだけを渡す。

## 完了

- レポ外のDrive保存先とWindowsローカルコピー、端末別の非秘密なパス設定を作成。
- OpenAI・Anthropicをユーザー入力で登録。Driveとコピーの一致、クラウドの非共有状態を確認。
- Windows・WSLの起動補助を設置し、両OSで実キーの存在だけを確認する子プロセスを実行。
  選択外のキーは渡されないことを確認。キー値の表示・実API通信は行っていない。
- 不動産情報ライブラリのノートブックはenv読込へ変更。旧キーはprivateのretiredへ退避し、
  現在の追跡ファイルに同じ値が残らないことを確認。運用値への再登録を拒否。
- outputs再包含後のenv除外と、値を表示しないpre-commit検査を追加。WSLのフックも設置。
- Macの初回設定と利用手順を [共有手順](../../docs/knowledge/private-data-storage.md) に記載。

## 未完了・次の作業

  [資産側の状態](../../portfolio-analyzer/docs/STATUS.md)を参照。
  住宅資料の対象指定は運用利回りの誤認だったため撤回し、住宅は変更していない。
- 公開側はユーザー指示の通常のcommit/pushで反映する。Git履歴書換えとAPIによるキーの有効性・残高の検証は未実施。
