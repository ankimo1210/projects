# §27.7 Options on Two Correlated Assets：受入記録

**判定：accepted。** Hull 11e Global Edition pp.658–661 の相関のある二資産の三次元ツリー、Tables 27.2–27.3 を、要求 TA01–TA06 の説明・実装・独立検証・図・実画面で照合した。日付：2026-09-28。要求の対応は[レビュー](SECTION_27_7_REVIEW_2026-09-28.md)、機械可読の統合結果は[M16記録](validation/section-27-7/m16-check.json)を参照。

- 原典に数値例・印刷値がないため、欧州型は Stulz の max コール（15.926819ドル、条件付き積分との差 $10^{-14}$ドル未満）と Margrabe の交換オプション（8.306642ドル）、米国型は1次元に帰着した交換オプション（CRR と Crank–Nicolson の外挿値の平均8.763683ドル、両者の差1.4e-5ドル）を基準にした。
- 原典の係数からノードを組み、確率の質量を前向きに進めた `hullkit` を使わない価格と、公開API `hullkit.two_asset_tree` の差は、密な段数181通り×3構成（欧州・米国）、倍々の6段数、相関41点×2段数、追加30ケース、米国型 max コール9本で3.4e-13ドル以下。米国型の後退帰納は同じ手順なので、6段の小例をノードごとの再帰で解いて照合した（3.1e-14ドル、深い ITM は初回ノードで行使）。
- 三構成とも1段の対数収益率の平均と共分散が目標に一致（1.8e-18以下）。Rubinstein と確率の調整は $\rho=0,\pm1$ で一致（3.6e-15ドル以下）、$\rho=0.5$ で7.3e-4ドル違う。この例の欧州型 max コールの誤差は変数変換が倍々で毎回ほぼ半分（100–800段の傾き0.957）、他の二つは段数で振れ、800段ではどれも0.0012ドル未満。米国型交換オプションの早期行使の価値は0.457ドル、200段の誤差は +0.0035・+0.0044・−0.0046ドル。
- 相関の掃引は100段と101段で行い、変数変換の $\rho=\pm0.6$ の小さな誤差は偶数段だけに現れること、$\rho=-1$ の誤差の符号が段数の偶奇で変わることを本文と図に示した。1次元に帰着できない米国型 max コールは、800段の三構成が0.0006ドル、欧州型の誤差で補正すると0.0003ドルの幅に揃う。
- vol06 に §13.1–13.6 と共有4図を追加。§13以外の107セルはM15基点`42076f10`から後続2見出しの番号変更のみ。4改変を拒否した。Chromium 145.0.7632.6 で Book/portal×1440/1000px の16状態・16画像を確認し、軸タイトルと目盛りの重なり（4px の余白）も検査した。Book の数式346個のエラーは0。本文の数値23か所はテストが保存値と照合する。
- 独立レビューの P1 1件・P2 3件・P3 8件をすべて修正した。行使判定を0段目・1段目・0–2段目で外す変異は、ユニットテストと数値検証の両方が拒否した。
- §26.9–§26.17、§27.1–§27.6 の15節を [D1 方針](EVIDENCE_POLICY.md)で再検査した（個別テスト計1,413件）。14節は M15 の記録を基点に reused（新規保存0バイト）。§27.6 は初めての D1 記録なので redrawn（成果物ストアへ651,535バイト）。
