## 4. 実装計画

### 原則

1. **主線は本編。** 研究は本編の完了条件ではない。研究のために本編の順序（P1→P2→P3…）を飛ばさない。
2. **拡張は受入の後。** Hull の先の内容は、対象章の節を受け入れた後に別セルで足す。台帳の要求に入れない。
3. **研究は book・portal の外で始める。**
   - 置き場は `johnhull/research/<RB-ID>/`（新設。§8-2 の承認が必要）。設計メモ、出典記録、研究 notebook、小さな JSON+NPZ を置く。
   - 計算は hullkit の非公開モジュール（`_<name>.py`）に置き、テストは `hullkit/tests` に置く。
   - release manifest・book・portal には、教材採用を決めてから入れる。
4. **公開 API の追加・torch 依存・新しい production 依存は、着手時に個別に承認を取る。** hullkit は torch-free を維持する。
5. **同時に進めるのは、本編と研究トラック1本まで。** 実装は Sol、独立レビューは Claude という体制を続ける（提案書 §10.1）。
6. **大きな成果物は ADR 0004 の保管庫へ置く。** Git に置くのは小さな参照値と manifest だけ。

### 6.2 RB-F07 の実装計画（着手時の最小仕様案）

**問い：** モデルのパラメータ感応度と、実際に取引する市場クオートの感応度はどう違うか。

**範囲 v1：**
- 単一通貨・単一曲線。預金または FRA と par スワップを 4〜6 本。
- 未知数は柱の zero rate。補間は固定する。
- 正方の連立方程式として厳密に bootstrap する。
- 対象ポートフォリオは柱の間の満期のスワップと債券。
- 感応度の単位は通貨/クオート 1bp。

**式：** 較正残差 $F(\theta,q)=0$ が柱で局所的に可逆のとき、

$$
\frac{d\theta}{dq}=-F_\theta^{-1}F_q,\qquad
\frac{dV}{dq}=\frac{\partial V}{\partial q}+\frac{\partial V}{\partial\theta}\frac{d\theta}{dq}.
$$

$F_\theta$ と $F_q$ は、預金・FRA・スワップの残差を解析的に微分して作る。
有限差分は検証だけに使い、実装側と検証側で同じ近似を共有しない。

**先に作る fixture とテスト：**

| # | テスト | 期待すること |
|---|---|---|
| 1 | 2 本の手計算例 | Jacobian とクオート感応度が手計算と機械精度で一致 |
| 2 | 中央差分の再較正（bump 幅を数桁にわたって変える） | 誤差が V 字（打切り誤差と丸め誤差）を描き、最適な幅で解析値と一致 |
| 3 | パラメータ化の不変性（zero rate と log DF） | クオート感応度は一致し、パラメータ感応度は異なる（教材の中心） |
| 4 | 全クオートの平行シフト | クオート感応度の合計が、全クオートを同時に動かして再較正した差分と一致 |
| 5 | 補間の変更 | クオート感応度が変わる。これはバグではなく、そう読むべき結果として記録する |
| 6 | 条件の悪い商品の組合せ | 条件数の警告を出す。特異なら止まる |

許容差は、実験の前に設計メモで商品と単位ごとに決める（提案書 §9.4）。
