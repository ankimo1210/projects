# RB-F04：同じバニラ面と経路依存価格の違い（軽い設計メモ）

- 日付：2026-09-27。状態：設計案。順序はRB-F05の採否記録後、実装前にD1-preflight。
- 問い：バニラへの適合誤差を揃えた後にも、二時点分布・Asian価格の差を識別できるか。
- 置き場：`research/RB-F04/`、計算はhullkit非公開モジュール。CPU・合成データ。

## 1. 進め方

| 案 | 特徴 | 扱い |
|---|---|---|
| M12の解析混合面を延長 | 面の導関数と二時点差の既存参照がある | 最初の動作確認 |
| Heston→Dupire local vol→離散Asian | M11/M12を接続し、経路依存の問いを直接検証できる | 本実験の最小版 |
| バリアとヘッジを同時追加 | 境界・監視・P&L規約の誤差が増える | Asianで識別後の拡張 |

M12の既存例は解析混合面であり、Heston由来の面の高精度微分が実装済みとは扱わない。
最初は固定Hestonパラメータ、固定金利・配当、無裁定な価格面の生成と数値微分を検査する。
「同じ面」は理論上の構成を指す。有限quoteへの残差が小さいだけでは全面の一致を確認したことにならない。

## 3. 最小契約と誤差の分離

対象は満期1年、月次12観測、満期支払の算術平均call、初期spotを平均に含めない。
両モデルで同じ利率、配当、spot、strike、日付、cashflowを使う。監視格子を細かくするときも観測日は固定する。

1. Heston COSと独立積分で面の価格を確認する。
2. strike/time微分幅・外側領域・補間を変え、Dupire分母の符号と安定領域を調べる。clipで不適切な面を隠さない。
3. local vol PDEとMCで同じvanilla群を再価格付けし、Heston側MCも同じ面に収束することを確認する。
4. 上記誤差を通過した領域だけで二時点分布とAsianを比較する。共通乱数による差のSEを計算し、各モデルの時間離散化biasを別に見積もる。
5. 価格差が面・PDE・MC離散化の残差と同程度なら「モデル差を識別できず」と結論する。

価格は通貨、確率はpercentage point、時間は年。MC CIはsampling誤差だけを表し、面構成・離散化biasを含まない。
独立seed反復と格子倍増による収束表を保存し、許容差はpilot後・本比較前に固定する。
