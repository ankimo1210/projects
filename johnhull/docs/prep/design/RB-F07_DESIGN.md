## 1. 問いと、試作で見えた答え

**問い：** モデルのパラメータ感応度と、実際に取引する市場クオートの感応度はどう違うか。

試作（§5）で次の3点が機械精度で確かめられた。これが教材の中心になる。

1. **柱にリスクが無くても、クオートにはリスクがある。** v1 の曲線で、ポートフォリオは 6か月の柱に感応度 0 を持つが、6か月預金のクオートには +106.30/bp を持つ（FRA の forward を通って 1年の柱に効くため）。
2. **クオート感応度は座標と残差の書き方に依存しない。パラメータ感応度は依存する。** zero rate と log DF の座標でクオート感応度の差は 2.3e-13/bp、パラメータ感応度は符号も大きさも変わる。
3. **この試作では、補間を変えると配分が大きく変わり、合計の変化は小さかった。** zero 線形と log DF 線形で 5年スワップのクオート感応度は −1,844 と −2,295/bp、合計は −3,233.04 と −3,231.58/bp。合計の近さはこの fixture の観測で、補間に対する不変性ではない。

## 3. 式

較正残差 $F(\theta,q)=0$ が解で局所的に可逆のとき、

$$
\frac{d\theta}{dq}=-F_\theta^{-1}F_q,\qquad
\frac{dV}{dq}=\frac{\partial V}{\partial q}+\frac{\partial V}{\partial\theta}\,\frac{d\theta}{dq}.
$$

v1 は $\partial V/\partial q=0$、$F_q=-I$ なので $dV/dq=\nabla_\theta V^\top J^{-1}$。
クオートが多くポートフォリオが少ないので、実装は随伴形 $J^\top\lambda=\nabla_\theta V$ を1回解いて $dV/dq=\lambda^\top$ とする。

$J$ の行は解析的に作る。$y(t)=-\ln P(t)$、zero 線形補間の重みを $w_j(t)$ とすると $\partial P(t)/\partial z_j=-P(t)\,t\,w_j(t)$。

| 商品 | モデルのクオート $m$ | $\partial m/\partial z_j$ |
|---|---|---|
| 預金（期間 $\tau$） | $(1/P(\tau)-1)/\tau$ | $-\dfrac{\partial P(\tau)/\partial z_j}{\tau P(\tau)^2}$ |
| FRA（$t_1\to t_2$、$\tau=t_2-t_1$） | $(P_1/P_2-1)/\tau$ | $\dfrac{1}{\tau}\left(\dfrac{\partial_j P_1}{P_2}-\dfrac{P_1\,\partial_j P_2}{P_2^2}\right)$ |
| par スワップ（年金 $A=\sum\tau_iP_i$） | $(1-P_n)/A$ | $\dfrac{-\partial_jP_n\,A-(1-P_n)\,\partial_jA}{A^2}$ |
| 債券価格（半年利払、額面 100） | $\sum c_iP_i$ | $\sum c_i\,\partial_jP_i$ |

**v2（最小二乗）への注意：** 目的関数 $\tfrac12\lVert W^{1/2}(m(\theta)-q)\rVert^2$ の最適性条件 $J^\top W(m-q)=0$ を微分すると
$\left(J^\top WJ+\sum_i r_i\,W_{ii}\nabla^2m_i\right)d\theta/dq=J^\top W$（$W$ 対角、$r=m-q$）。
残差が 0 でないとき、Gauss–Newton 近似 $(J^\top WJ)^{-1}J^\top W$ は正確でない。v1 の式をそのまま流用しない（提案書 F07 の不採用条件）。

## 4. 既存コードとの関係

新しいモジュールは、モデルのクオートと解析微分を自前で計算する。既存の関数は微分を返さないので、**テストの価格オラクルとしてだけ使う**。

`hullkit.rates:bootstrap_zero_curve` は債券価格・半年利払だけを受け付け、預金・FRA・スワップは受け付けない。v1 の曲線の参照解法は試作と同じく柱ごとの brentq で作る。

| 対象 | 観測値 | 提案 |
|---|---|---|
| 手計算例、座標・残差の不変性、価格オラクル、複素ステップ | ≤ 2e-16（相対） | 相対 1e-12（BLAS と OS の差を吸収する分だけ緩める） |

| 平行シフト（h=1e-6） | 差 < 1e-6/bp | 相対 1e-9 |
| 警告 | 増幅率 1.03（正常）〜 20.7 以上（情報が薄い） | zero rate の bp / quote の bp に換算した増幅率 > 10 で警告。ゼロ列、数値的rank欠落、線形solveの失敗・非有限値で停止。生の条件数だけでは停止しない |

警告の閾値 10 bp/bp は本メモの設計値で、外部の基準ではない。v1 の商品で確かめた範囲に基づく。
数値rankは、クオート残差・zero座標に戻して単位を固定した $J$ の特異値で判定する（案：$s_{\min}\le n\epsilon s_{\max}$）。
log DF 座標や PV 残差の生の条件数をこの判定と混ぜない。solve の相対残差も保存する。
ゼロ近傍の比較は絶対許容差も必要で、実装時に量ごと（zero、PV、通貨/bp）に固定する。
複素ステップは、この滑らかな残差関数の検証に限定し、max・abs・行使判定を含む任意の価格関数へ一般化しない。

## 7. モジュールの形（案。名前は仮）

非公開モジュール `hullkit/_quote_risk.py`。公開 API への昇格は別承認。

- `Quote`：商品の種類（deposit / fra / swap / bond）、日程、クオート値の frozen dataclass
- `calibrate(quotes, *, interpolation="zero_linear")`：柱の時刻・zero・$J$・診断（条件数、増幅率）を返す
- `quote_sensitivity(calibration, grad_theta)`：随伴形で $dV/dq$ を返す
- ポートフォリオの $\nabla_\theta V$ は、v1 の割引債・スワップ・債券について解析的に書く。任意の価格関数には有限差分の勾配も受けるが、近似であることを結果に記録する

依存は NumPy と SciPy だけ。torch・外部データ・新しい依存はない。CPU で数秒。
