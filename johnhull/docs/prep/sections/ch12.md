## §12.1 Principal-Protected Notes（pp.268–270）

- **種別：** 数値（例題あり）。
- **原典の内容：** 割引債で元本を確保し、残額でoptionを買う。金利・vol・配当利回り・期間が購入可能額を左右し、発行銀行の信用riskと投資家の機会費用は残る。額面保護とリスクがないことは同義でない。

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D12.1-01 | Ex12.1の3年元本1000（269） | bond835.27+option予算164.73、満期1000+max(S−1000,0) |
| D12.1-02 | 金利/vol/期間変更（269–270） | 3%時予算、25%vol時価格、3/10/20年費用 |
| D12.1-03 | q=0では満額ATM参加が採算化しない（270） | call下限≥S−Ke^(−rT)、保護額=S=K |
| D12.1-04 | 信用risk、bid/ask、cap/Asian/barrier（269–270） | 発行者利益と投資家の調達条件、商品変更は支払変更 |

- **印刷値：** S=K=1000、q1.5%。r6%/T3で債券835.27・予算164.73、vol閾値「約15%」（数値求解14.937164%）、vol25%でcall約221（221.153880）。r3%/vol15%でT3予算86.07・call約119（119.106199）、T10予算259.18・call約217（217.357173）、T20予算451.19・call約281（281.283327）。10関係 ✓再計算一致。概数価格は±0.5USD、セント値は±.005USD。15%ちょうどで採算が合うという意味ではない。
- **既存の実装：** `hullkit.bsm:call_price`、`hullkit.volatility:implied_vol`（存在は `test_hull_pins_options.py` の呼出でも確認）。vol02「元本保護ノート（§12.1）」はS100/元本1000/vol20%で参加率を調整した合成例。`test_hull_pins_options.py:test_example_12_1_principal_protected_note`が上記の値と閾値14.94%を固定、OP-11は対応済み。
- **足りないもの：** 原典の満額ATM参加と合成の参加率調整を区別した表示、信用risk/機会費用、満期比較。
- **独立参照の案：** BSM閉形式に対し対数正規payoffの数値積分（今回実行）。q=0は無裁定下限の代数で示す。**図の案：** 債券+option予算、金利/vol/期間の採算図、元本保護payoff。
- **依存・注意：** 元本保護は発行銀行の支払能力に依存。提示15%上昇後から参加する案はstrike入力例で計算価格なし。2008年Lehmanは記述統計（ピン不要、年次に注意）。
- **規模：** S（既存pinを説明へ接続）。**関連：** OP-11（対応済み）、§11.3、§17.3、Ch26。

## §12.2 Trading an Option and the Underlying Asset（pp.270–272）

- **種別：** 数値（例題なし）。
- **原典の内容：** covered callとprotective put、各逆ポジションの損益を示す。parityにより、stock+optionは別のoptionと現金の組合せに置き換えられる。章の損益は満期受取−初期費用で、資金コストを加算しない慣用表示。

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D12.2-01 | Figure12.1の4ポジション（270–271） | stock−call、−stock+call、stock+put、−stock−put |
| D12.2-02 | 式12.1と現金の差（271–272） | p+S=c+Ke^(−rT)+D、形が同じでも初期費用/現金を省略しない |
| D12.2-03 | profitの表示規約（270） | payoffとpremium差、金利未加算を注記 |

- **印刷値：** 数値例なし。Figure12.1のKは記号、各個別損益は破線、合成は実線。
- **既存の実装：** `hullkit.payoffs:leg_payoff`、`strategy_payoff`、`STRATEGIES`のcovered_call/protective_put。`test_payoffs.py:test_covered_call_equals_short_put_plus_bond`、`test_protective_put_equals_call_plus_bond`は満期恒等式を検査。vol02の戦略builderはpremiumをBSMで控除する。
- **足りないもの：** 逆2戦略の明示、cash/bondと配当を含むparity説明。株式を含む配当例は満期株価だけのAPIでは中間配当CFが消えるので別台帳が必要。
- **独立参照の案：** leg合計に対してcovered call=min(S,K)、protective put=max(S,K)という区分式で確認。**図の案：** Figure12.1の4パネル、各legと合成。
- **依存・注意：** 無配当のprofit図とD付き現在価値恒等式を区別。**規模：** S。**関連：** §11.4/11.7、RB-H12（ETF実データ/rollは受入後）。

## §12.3 Spreads（pp.272–280）

- **種別：** 数値（例題あり）。
- **原典の内容：** 同種optionでbull/bear、box、butterflyを作る。同満期のpayoffは区分線形だがcalendar/diagonalは短期満期時点でも長期側が残るため再評価が必要。American boxは早期行使の影響でEuropean boxの割引固定額と同じにならない。

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D12.3-01 | Tables12.1/12.2、Ex12.2/12.3、Figures12.2–12.5（272–275） | call/put各bull/bear、premiumと最大損益 |
| D12.3-02 | Table12.3/BS12.1のbox（276–277） | K2−K1固定payoffはEuropean前提、American早期割当 |
| D12.3-03 | Table12.4・Figures12.6/12.7のbutterfly（276–279） | K2中点、call/put等価、reverse、strikeで折れる |
| D12.3-04 | Figures12.8/12.9 calendar/diagonal（279–280） | T1で短期をpayoff化し長期を残存T2−T1で評価 |

- **印刷値：**
  - Ex12.2、K30 callを3で買い/K35を1で売る：payoff上限5/下限0、cost2、損益−2・S−32・3（32は損益分岐）。6関係 ✓一致。
  - Ex12.3、K35 putを3で買い/K30を1で売る：payoff下限0/上限5、cost2、損益3・33−S・−2。6関係 ✓一致。
  - BS12.1、S50/r8%/vol30%/T2か月、K55/60、提示売却額5.10。理論European box=4.93（4.933775809）。
    - (call60,call55,put60,put55)の欧州=(.26,.96,9.46,5.23)、米国=(.26,.96,10.00,5.44)：8値 ✓一致（米国CRR4000step）。
    - bull call .70、bear put欧州4.23/米国4.56、組合せ欧州4.93/米国5.26：5関係 ✓一致。**5.26は丸めた構成価格から合算**。無丸め4000stepの米国boxは5.267070→5.27。これは印刷の丸め順序の差で、価格誤植としない。
  - p.278 butterfly：K55/60/65、premium10/7/5、S0=61、6か月。cost1、外側損失−1、分岐56/64、最大利益4：5関係 ✓一致。計31件。Tables12.1–12.4の他の欄は記号式。
- **既存の実装：** `hullkit.payoffs:strategy_payoff`、`box_spread_value`、registryのbull_call_spread/bear_put_spread/butterfly。`hullkit.bsm:call_price`、`hullkit.bsm:put_price`、`hullkit.trees:crr_price`が価格部品。
  - vol02「スプレッド（§12.3）」は4種類の同満期図。calendar/diagonalは未実装と正確に明記。
  - `test_payoffs.py:test_bull_call_spread_is_clip`、`test_bear_put_spread_is_clip`、`test_butterfly_spike`、`test_box_spread_value`は合成入力。`test_hull_pins_options.py:test_business_snapshot_12_1_american_box_spread`はBS12.1を固定し、丸め順序も既に区別している。Ex12.2/12.3とbutterflyの1/56/64/4は専用pinなし。
- **足りないもの：** OP-10のbull put/bear call、put butterfly、calendar/diagonalのT1時点評価。満期を持たないpayoffs APIにcalendarを押し込まない。registry追加時はノートの`_N_STRIKES`も対応が必要。
- **独立参照の案：** leg合計に対してclip/三角形の区分式、European boxはparityと割引固定CF、AmericanはCRRに対してPDE（今回は自前CRR再計算まで）。calendarは長期側の残存payoff積分とBSMを照合。
- **図の案：** bull/bear4種、call/put butterfly、European/American box、T1時点calendar/diagonal。
- **依存・注意：** p.279の高株価calendar長期call≈S−Kは定性的近似。厳密な残存価値はS−Ke^(−rΔT)（q=0）なので、両端損益が必ず同じとは要求しない。満期単調性も「通常」であって無条件でない。
- **規模：** M（同満期部品は揃うが多満期評価が不足）。**関連：** OP-10、OP-11（pin済）、§11.4–11.6、RB-H11。

## §12.4 Combinations（pp.280–283）

- **種別：** 数値（例題あり）。BS12.2の投資判断説明はD3候補。
- **原典の内容：** 同じ満期のcall/putを混ぜて方向中立または非対称な大変動への損益を作る。イベントが起こるという予想だけでは利益は保証されず、premiumに織り込まれた動きとの違いが必要になる。

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D12.4-01 | Figure12.10/Table12.5のstraddle（281） | payoff=abs(S−K)、long/shortの最大損失方向 |
| D12.4-02 | Figure12.11 strip/strap（282） | call1+put2 / call2+put1の傾き |
| D12.4-03 | Figure12.12/Table12.6のstrangle（283） | Kput<Kcall、中央ゼロpayoff、strike間隔と必要変動 |
| D12.4-04 | BS12.2イベントの織込み（282） | 高いpremiumは損益図全体を下へ動かす |

- **印刷値：** S0=69、K70、3か月、call4/put3。cost7、S69時put1/損失6、S70損失7、S90利益13、S55利益8：6関係 ✓再計算一致。Tables12.5/12.6は記号式、strip/strap数量1/2は戦略定義。
- **既存の実装：** `hullkit.payoffs:STRATEGIES`のstraddle/strangle/strip/strap、`strategy_payoff`。vol02「コンビネーション（§12.4）」は4図とイベント注意。`test_payoffs.py:test_straddle_abs`、`test_strangle_piecewise`、`test_strip_strap_weights`が合成入力を検査。69/70/90/55の原典損益pinなし。
- **足りないもの：** 原典premiumをそのまま使う例、top/bottom、数量による傾きの確認。
- **独立参照の案：** strike前後の区分式/傾きと総premiumで照合。**図の案：** 4戦略の損益、イベント前後のpremium変化。
- **依存・注意：** 本章は資金金利を損益に入れない。short straddle/strangleの無限損失は非負株価下では上昇側、下落側損失には有限上限がある。
- **規模：** S。**関連：** §10.1、§19、D3。

## §12.5 Other Payoffs（pp.283–284）

- **種別：** 数値（例題なし）。
- **原典の内容：** 狭いbutterflyのspikeを重ね、同満期の任意payoffを近似する。全strikeが取引できるという理想化と、有限格子で近似する実装を区別する。

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D12.5-01 | Figure12.13のspike（284） | 幅hなら高さh、数量1/hで高さ1 |
| D12.5-02 | 多数のspikeで近似（284） | 格子上の補間一致と格子間の誤差を分ける、端点/範囲外 |

- **印刷値：** 図は記号K1/K2/K3、等間隔条件のみ。具体的なtarget・誤差・枚数の印刷値なし。
- **既存の実装：** `hullkit.payoffs:strategy_payoff`とregistry butterfly。vol02「バタフライ＝ペイオフの『建築ブロック』（§12.5の含意）」は局所`target_payoff`（Gaussian bump）、h5、strike70〜130で重ねる。格子点誤差をノートで確認するが格子間の収束はない。`test_payoffs.py:test_butterfly_spike`は単一spikeのみ。
- **足りないもの：** h/2での近似誤差、境界と範囲外の扱い、原典の「理論上」の限定。有限個の有界spikeだけで全実数域の線形tailや不連続点を一様に任意精度へ近似できるとは書かない。
- **独立参照の案：** option legで組むspikeの和を、節点値の区分線形補間（独立の補間計算）と比較。滑らかなtargetの格子間誤差を測る。**図の案：** 原典spike、target/近似、hと最大誤差。
- **依存・注意：** vol02が触れるBreeden–Litzenbergerはoption価格のstrike微分と密度の話で、payoffのhat basis補間と同じ操作ではない。関連は説明できるが同一の「離散版」とだけ記すと混同を招く。
- **規模：** S。**関連：** §12.3、§20付録、§26.17。
