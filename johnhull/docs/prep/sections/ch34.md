## §34.1 Variations on the Vanilla Deal

- **ロジック計画／2026-10-05：** private dated legで元本列・脚別frequency/ACT basis・Following(all dates)・coupon/principal交換・projection/OIS分離・known fixing/daily RFRを実装。BS34.1のraw10/20期間・100M/120M・2%・ACT365/360を再現、独立cashflow/FRA telescope/日次積で検証。U.S.の具体holiday集合は未確定なのでcaller指定、adjusted source pinとはしない。教材・受入は章末。

**種別:** 混在。商品分類・term sheetの説明部分はD3候補。schedule評価は数値経路。

**原典の内容:** 想定元本が予定通り変わる、両脚の元本や支払頻度が異なる、basis swapになる、といったvanillaの変形を整理する。決まったcashflowにはforwardを使い、同一通貨のOISで割り引く。Reference rate移行は原典執筆時点の制度説明として扱う。

### 要求の下書き

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D34.1-01 | step-up/amortizing元本、支払頻度、accrual day countを脚ごとに指定（773–774）。 | 各couponを独立手計算したcashflow表と照合。元本交換の有無を別条件とする。 |
| D34.1-02 | BS34.1の両脚をterm sheetからschedule化（774）。 | 固定100M対変動120M、半年対四半期、ACT365対ACT360の違いを保持。 |
| D34.1-03 | forward projectionとOIS discountを分け、basis swapを説明（774–775）。 | 等しい元本/頻度に戻せば標準IRSと一致。異なるreference rateのcurveを同一視しない。 |

**印刷値（ピン候補）:** BS34.1 p774：trade 2021-01-04、effective 2021-01-11、maturity 2026-01-11、Following/米国営業日。Microsoft固定USD100M・2%・ACT365、Jan/Jul11日（初回Jul11）。Goldman変動USD120M・3か月compounded SOFR・ACT360、Jan/Apr/Jul/Oct11日（初回Apr11）。これは入力条件で価格はない。休日調整済みscheduleは **未再計算**（holiday calendar未指定の細部は要確認）。LIBOR移行等は **記述統計（ピン不要、年次に注意）**。

**既存の実装:** hullkit.swaps:irs_value_bonds / irs_value_fras / swap_rate / discount。vol07 build_swaps_notebook.py §5「非標準スワップの動物園」。test_swaps.py は標準/seasoned IRS、bond-FRA一致、currency swapを検証。両脚別の元本・scheduleを表す一般term sheet APIはない。

**足りないもの:** 脚ごとのschedule、day count、元本列、変動rate projection、date adjustmentの説明と例。既存first_accrual対応を完全schedule engineと呼ばない。

**独立参照の案:** 手作成したcoupon表のPVと、FRA分解の合計を比較。

**図の案:** 両脚の支払日と元本を重ねた時系列図。

**依存・注意:** FR09/FR10、RB-H34、§7・§4.5のOIS、§29。BS34.2は同じp775にあるが次節の例として扱う。

**規模:** M。date/scheduleの仕様が支配的。

**関連:** D34.2、D34.3、D34.4。

## §34.2 Compounding Swaps

**種別:** 数値（例題あり）。

**原典の内容:** 各期間に発生したcouponを直ちに払わず、別に指定された率で複利累積して後で支払う。coupon rateとcompounding rateを区別する。将来forwardを実現値として置く評価は一般に近似だが、spreadがない場合やspreadの付け方によって厳密となる条件を説明する。

### 要求の下書き

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D34.2-01 | coupon発生と未払残高への利息付与を別ステップで記述（775–776）。 | Ex34.1の毎年残高を再帰と幾何級数で独立計算。 |
| D34.2-02 | additive spread Q[1+(R+s)τ] とmultiplicative Q(1+Rτ)(1+sτ)を区別しforward実現法の条件を明記（776）。 | s=0で一致、非zero spreadでは交差項の差を確認。 |
| D34.2-03 | BS34.2をschedule付きで解釈し、最後の一括支払を割引（775）。 | 標準逐次払と支払日が異なることをcashflow表で確認。 |

**印刷値（ピン候補）:**

- BS34.2 p775：§34.1と同じtrade/effective/maturity、双方元本100M、四半期計算・2026-01-11一括払。固定coupon2%を2.3%で複利、ACT365。変動SOFR+20bpをSOFRで複利、ACT360。契約入力であり価格ピンなし。
- Ex34.1 p776：年1回、3年、元本100M、固定coupon4%/compounding3.9%、forward変動coupon5%/compounding4.8%、OIS年複利4%。固定残高4→8.156→12.474M、変動5→10.24→15.731M、価格2.895M（receive floating）。
- 独立計算：固定12.474084M、変動15.731520M、PV2.895848743M。固定終値は表示丸め内、変動終値を普通に丸めると15.732、PVは2.896となり **✗通常丸めでは最終桁不一致**。印刷の途中値15.731/12.474を使えば2.895461140→2.895で **✓本文の途中切捨て経路を再現**。厳密計算を印刷2.895へ強制しない。標準IRSテストはあるが本例の専用pinはない。

**既存の実装:** vol07 build_swaps_notebook.py §5のcompounding例は別パラメータの例示。hullkit.swaps:discount は最終額PVの部品。累積残高のpublic APIなし、test_swaps.py にEx34.1なし。

**足りないもの:** rateとspreadの定義、残高更新、forward実現近似の適用条件、印刷の途中切捨てを区別したpin。

**独立参照の案:** 毎期残高更新と各couponの残存複利積の和を比較。確率rateの検証には小規模rate treeを別計算とする。

**図の案:** coupon発生・複利残高・一括支払の図、spread付加方式の差。

**依存・注意:** FR09、RB-H34、§34.1・§28.4。元本単位M、年複利と連続複利を混同しない。

**規模:** M。算術はSだが一般scheduleと確率近似の境界の説明が必要。

**関連:** D34.1、D34.5。

## §34.3 Currency and Nonstandard Swaps

**種別:** 数値（例題なし）。

**原典の内容:** Currency swapはfixed/fixedに限らずfloating/floatingやfixed/floatingも可能で、各通貨の脚を評価してspotで換算する。取引価格と無裁定の曲線を整合させる条件が必要となる。CMSや異なる通貨での支払いでは、単純にforwardを代入するだけでは足りずconvexity、timing、quantoの調整が必要になる。

### 要求の下書き

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D34.3-01 | 各通貨のcashflowを評価しdomestic−spot×foreignの符号で集約（776–777）。 | 通貨とreceive/payを反転するとFX換算後の価値が符号反転。元本交換も確認。 |
| D34.3-02 | curve/basisを整合させ、market mid-priceで初期価値0になる条件を明記（777）。 | 曲線・spreadを一つずつ変え、何を校正してzeroを作ったかを残す。 |
| D34.3-03 | CMS/非標準resetのconvexity、支払日のtiming、cross-currency quantoを区別（777）。 | 各correlation/vol=0の極限で標準forward評価へ戻る。 |

**印刷値（ピン候補）:** 新規数値価格・表なし。再計算対象なし。

**既存の実装:** hullkit.swaps:currency_swap_value、test_swaps.py:test_currency_swap_hull_example_7_3。vol07 §4「通貨スワップ」、§6「LIBOR-in-arrears」。hullkit.ir_options:convexity_adjustment / bond_yield_convexity は補正の一部、vol11 §7–9がconvexity/timing/quanto。一般multi-curve/collateral/currency-basis対応を持つわけではない。

**足りないもの:** 脚仕様とFX quote方向の統一、mid-market curve整合の説明、各補正を適用する条件の明示。Ch30の関数があることをCMS全商品対応の証拠にしない。

**独立参照の案:** 各脚のゼロクーポン分解を手計算し、FX forwardを用いる分解と比較。補正は明示したjoint rate/FXの簡易MCで比較。

**図の案:** 2通貨のcashflowと換算図、補正の有無によるPV差。

**依存・注意:** FR10/FR12、EX09、RB-H34、§7・§30.1–3。本文の単純取引と担保/複数curveの研究拡張を分離。

**規模:** M。既存vanilla部品を使えるが商品条件と補正の組合せが増える。

**関連:** D30.1、D30.2、D30.3、D34.1。

## §34.4 Equity Swaps

**種別:** 混在。商品説明とresetの複製議論はD3候補。途中評価は数値経路。

**原典の内容:** 配当を再投資するtotal return indexと固定または変動金利を交換する。元本を借り指数に投資する複製により、frictionlessなequity-for-floating swapは開始時と各支払直後に価値0となる。支払日の間では既知のovernight実績と残り期間forward、および指数の累積変化を扱う。

### 要求の下書き

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D34.4-01 | total return index、resetごとの株式単位、元本Lを定義（777–778）。 | price indexのみの場合に配当を別途加える条件を説明。開始/支払直後のnet PV0を複製で確認。 |
| D34.4-02 | BS34.3のequity return L(I1/I0−1)とSOFR脚の同日決済（778）。 | 同一Lと同一期間でborrowing＋index investmentのcashflowが再現されること。 |
| D34.4-03 | 中途時点のleg PVとnet MTM、既知利息と未確定利息を分離（778–779）。 | 原典L(E−E0)/E0をそのまま単独legの一般PVとせず、Technical Note19の導出条件を確認。 |

**印刷値（ピン候補）:** BS34.3 p778は2021-01-04取引、2021-01-11開始、2026-01-11終了、Following/U.S.、双方100M、quarterly Jan/Apr/Jul/Oct11日、Microsoftがtotal return S&P500、Goldmanが3か月compounded SOFR ACT360。指数観測値・価格例はない。再計算対象なし。制度・市場慣行は **記述統計（ピン不要、年次に注意）**。

**既存の実装:** vol07 §7「エクイティスワップとキャンセラブル」は説明。専用equity-reset swap API/テストなし。hullkit.rfr:compounded_rfr / rfr_coupon / daily_accrual_schedule は既知RFRの部品、hullkit.swaps:discount はPV部品。BS34.3を一括評価する関数ではない。

**足りないもの:** reset履歴と指数単位、既知coupon、途中MTMの式と符号。原典p778の「次回equity cash flowの価値」L(E−E0)/E0は要確認：frictionlessなtotal-return指数の単独次回支払PVを直接分解すると L[E/E0−P(t,T)] となる。本文の式をnet-financing調整との関係を確認せず汎用leg PVへ採用しない。Technical Note19は今回未取得。

**独立参照の案:** 現物指数＋借入の複製と、各legのdiscounted期待cashflowを別々に計算して一致を確認。

**図の案:** reset前後の指数保有単位と借入残高。

**依存・注意:** FR10、RB-H34、§7・§34.1。契約の中途価格を0と誤解しない。SOFRの観測/支払ラグがあれば上記単純複製の条件を調整。

**規模:** M。式は短いがreset状態と過去実績の扱いが要点。

**関連:** D34.1、D34.3。

## §34.5 Swaps with Embedded Options

**種別:** 数値（例題なし）。

**原典の内容:** 条件を満たす日のみ固定利息が発生するaccrual swapは、通常swapと日次binary option列に分解できる。解約権は一回なら反対方向のEuropean swaption、複数回ならBermudanになる。複利swapの解約では、未払複利残高とspreadの扱いがexercise価値を変える。

### 要求の下書き

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D34.5-01 | accrual coupon QL n1/n2と通常couponから除く日次binary列（779）。 | 一日当たり額QL/n2、観測日/支払日、休日の参照fixingを一致させる。 |
| D34.5-02 | Black binaryのQL/n2×P(0,si)N(d2*)とtiming補正（779–780）。 | natural payment ti+τと実際siの違い。全日条件成立/不成立の極限。 |
| D34.5-03 | 解約者・receive/pay・残存期間からswaption向きを決める（780）。 | 自分が受固定10年6% swapを6年時点で解約可能→long 6×4 payer。相手に解約権を与える場合はshort option。 |
| D34.5-04 | 複数解約日はBermudan、compoundingでは残高もexercise状態に含める（780–781）。 | 支払後にfloatingをparにする条件、receive/payでmax/minの向き、spreadの4段階近似を明示。 |

**印刷値（ピン候補）:** p779 accrual trigger SOFR2%、p780 10年receive6%を6年で解約する例、および5年半年払いreceive6%に2–5年の相手解約権を付ける例。いずれもcontract入力で価格なし。価格再計算対象なし。単なるvanilla swaptionの数値を本節印刷値の代用にしない。

**既存の実装:** vol07 §7でcancelableを説明。hullkit.ir_options:swaption_black と hullkit.hull_white:hw_jamshidian_swaption / HullWhiteSwaption はEuropeanの部品。test_ir_options.py:test_swaption_payer_receiver_parity_and_atm、test_hull_white.py が既存の基準。accrual swap、Bermudan、cancelable compoundingの専用API/テストなし。

**足りないもの:** 日次観測schedule、binaryとpaymentの測度、解約側の符号、exercise schedule、累積残高。一般stock LSMをそのまま金利swapへ転用しない。

**独立参照の案:** European解約権はswap＋解析swaption分解とrate tree。多日解約は小木の全経路列挙/後退計算、LSMを作るなら独立評価pathで下界を測る。

**図の案:** accrual対象日とcoupon、long/short解約権のcashflow分解、Bermudan exercise境界。

**依存・注意:** FR11、RB-H34、RB-F03、§29.3・§30.2・§32.5–6・§33.2。spreadを固定脚へ移す近似はexerciseと無関係な厳密分解とは限らない。

**規模:** L。European説明はSだがBermudan/複利残高は状態と校正を共有する工程が必要。

**関連:** D27.8、D29.3、D32.5、D33.2、D34.2。

## §34.6 Other Swaps

**種別:** 混在。商品分類・事例の説明はD3候補。

**原典の内容:** 金利に応じ元本が変わるindex-amortizing swap、commodity swap、asset/total-return/credit/variance swapを整理する。複雑な条件を持つswapは利用者がpayoffを読み解ける必要がある。P&Gの事例は二つの金利関連指標から作るspreadが支払率を大きく変える構造を示す。

### 要求の下書き

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D34.6-01 | index-amortizingをMBS型のrate依存元本として、commodity swapをfixed-for-floating数量契約として説明（781）。 | 元本が予定済みのamortizingと区別。数量×単価の単位を確認。 |
| D34.6-02 | 他章のasset/TRS/CDS/variance swapへ参照を張る（781–782）。 | 原資産、受払対象、元本/時価、credit eventを比較表にする。 |
| D34.6-03 | BS34.4のspread構造と利率増幅を説明し、不透明な商品設計/理解不足の教訓を示す（782）。 | CMTは%表示、債券価格はpar100表示として同じ式へ入れる。 |

**印刷値（ピン候補）:** 商品例100,000 bbl/年に年5Mを10年支払う契約→fixed price50 USD/bbl **✓再計算一致**。BS34.4：1993-11-02、5年半年、元本200M、BT5.30%払い、P&Gは平均30日CP−75bp＋spread、初回spread0、残9回にspread=max(0,[98.5×(5y CMT/5.78%)−30y Treasury price]/100)。対象Treasuryは6.25%・2023年8月満期。spread10%、CP6%なら支払15.25% **✓再計算一致**。当時の指標実績・取引価格はなくvaluation再計算なし。時系列・市場規模は **記述統計（ピン不要、年次に注意）**。

**既存の実装:** vol07 §5/§7、vol12の事例説明が関連。hullkit.variance_swaps:variance_swap_value と test_variance_swaps.py は別章のvariance swap。index-amortizing/P&G構造の専用API・本節ピンなし。

**依存・注意:** RB-H34、§24・§26.16・§33.3・§37.3。現代の取引慣行へ一般化する場合は別途出典が必要。

**規模:** S。原典の説明と小算術まで。

**関連:** D33.3、D34.1、D37.3。
