## §3.1 Basic Principles（pp.70–72）

- **ロジック計画／2026-10-06：** 原油/銅の全11数値を単位付きcash表にし、現物と契約CFの独立線形replicationで確認。

- **種別：** 数値（例題あり）。
- **原典の内容：** 将来売る資産をshort、将来買う資産をlong futuresでヘッジする。受渡期に現物と先物が一致する近似で、事業と先物の損益が相殺する。

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D3.1-01 | 原油100万barrel、先物49、1,000枚売り（70–71） | 現物45/55の両ケースで受取49M |
| D3.1-02 | 銅100,000lb、4枚買い、320cents（72） | 現物325/305centsでも費用320,000 |
| D3.1-03 | 日次決済と受渡費用を省く近似（72） | 最終価格固定と資金繰りを区別 |

- **印刷値：** ✓再計算一致11項目：1,000枚、原油4/barrel・4M利益・49M合計・6/barrel損失（p.71）、銅4枚・5,000利益・325,000購入・320,000純費用・15,000損失・305,000購入（p.72）。原油現物45M/55Mは各45/55×100万の入力換算。
- **既存の実装：** vol04 `build_futures_rates_notebook.py`「2. 先物によるヘッジとベーシスリスク」の説明。専用 hullkit・原典例のpytestなし。
- **足りないもの：** 2例の単位付き受払表。**独立参照の案：** 現物額＋先物損益を別建てで加算。**図の案：** ヘッジ有無の受取/支払直線。
- **依存・注意：** cents→dollars変換、longの利益は購入費用から引く。**規模：** S。**関連：** §2.11、§3.3。

## §3.2 Arguments for and Against Hedging（pp.72–75）

- **ロジック計画／2026-10-06：** 10M先物損失を事業利益から分け、売価転嫁の合成2ケースを独立cash表で確認。

- **種別：** 混在（監査qual）。議論部分は**D3 候補**、算術例は残す。
- **原典の内容：** 株主の分散、情報・取引費用、競争相手の価格転嫁、担当者への評価がヘッジ判断を左右する。原材料価格だけを固定すると利益率リスクが増える場合がある。

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D3.2-01 | 株主と企業の分散・費用、Table3.1の宝飾企業（73–74） | 金価格変動の売価転嫁も含めた利益率 |
| D3.2-02 | 原油49→59の先物損失と事業利益、方針の共有（74–75） | $10/barrel×1M=$10M$ |
| D3.2-03 | 金鉱のヘッジとlease rate（75） | 金借入→現物売り→運用→生産金で返済 |

- **印刷値：** $10M ✓再計算一致。Table3.1は増減/不変の符号表で数値なし。18か月等は説明条件。
- **既存の実装：** vol04のヘッジ概要のみ、専用 hullkit・テストなし。
- **足りないもの：** 全社利益と先物単体の評価を分けた説明。**独立参照の案：** 原材料価格転嫁を含む2ケースの損益表。**図の案：** 任意の金価格と利益率図。
- **依存・注意：** 事後的な利益最大化と事前のリスク削減を混ぜない。**規模：** S。**関連：** §1.7、§5.11、D3。

## §3.3 Basis Risk（pp.75–79）

- **ロジック計画／2026-10-06：** S−Fのbasis、一般例とJPY/原油の全13値を再現。2種類のbasisとcash受払の独立分解を確認。

- **種別：** 数値（例題あり）。
- **原典の内容：** $b=S-F$ と定義し、売り/買いの有効価格はいずれも $F_1+b_2$ になる。満期のずれと銘柄差を分解し、流動性を考えた限月選択を説明する。

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D3.3-01 | basis strengthening/weakening、$F_1+(S_2^*-F_2)+(S_2-S_2^*)$（76–78） | short売却者とlong購入者でbasis上昇の利害が逆 |
| D3.3-02 | 円受取Ex3.1（78–79） | cents/JPY、4枚short、537,500USD |
| D3.3-03 | 原油購入Ex3.2（79） | 20枚long、978,000USD |

- **印刷値：** ✓再計算一致13項目：0.30/0.10/2.30（p.77）；Ex3.1の4枚、先物益0.0550・basis−0.0050・有効1.0750cents/JPY、$537,500；Ex3.2の20枚、1.10/0.90/48.90 per barrel、$978,000。
- **既存の実装：** vol04「2. 先物によるヘッジとベーシスリスク」は式のみ。専用 hullkit・該当ピンなし。
- **足りないもの：** 基差の2要因分解とGEの2例、限月選択の説明。
- **独立参照の案：** $S_2+F_1-F_2$ と $F_1+b_2$ の手計算。**図の案：** 2価格とbasis、ヘッジ終了日と限月の関係。
- **依存・注意：** 他文献の $F-S$ 規約を持ち込まない。**規模：** S。**関連：** §3.4、§3.6。

- **原典の内容：** 価格差分の回帰から $h^*=\rho\sigma_S/\sigma_F$、$N^*=h^*Q_A/Q_F$ を得る。日次の変化率を使う場合は $\hat hV_A/V_F$、資金運用を考える場合はtailingに進む。

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|

| D3.4-02 | Table3.2の15組→Ex3.3（82） | 標本SDはddof=1、h=0.78、37枚 |
| D3.4-03 | 変化率回帰と日次枚数、tailing（83） | 32.23枚、$1.05$で除す |

  - ✓再計算一致9項目：σF=.0313（.031343413）、σS=.0263（.026254795）、ρ=.928（.928372346）、h=.78（.777650674）、37枚、VA=2,200,000、VF=54,600、32.23（32.234432）、32枚。
