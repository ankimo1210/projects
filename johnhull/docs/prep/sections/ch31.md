## §31.1 Background（pp.719–721）

- **ロジック計画／2026-10-04：** privateの経路割引・zero yield・PDE残差・constant Gaussian bondで式31.1–5をつなぐ。印刷例なし。独立GaussianパスMCと有限差分PDE、全満期flat曲線のpolynomial矛盾を検証。教材・受入は章末。

- **種別：** 数値（例題なし、評価式と PDE）。
- **原典の内容：** Q測度の short rate 過程から割引期待値、債券価格、zero curve を決める。Markov な1因子では $f_t+m f_r+\frac12s^2f_{rr}=rf$。常に flat で確率変動する zero curve を単純に仮定することはこの PDE と両立しない。
- **要求の下書き：**

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D31.1-01 | 式31.1–31.4、経路割引からzero rate（720） | 定数rの極限と MC 債券価格 |
| D31.1-02 | 式31.5、$P=e^{-r(t)(T-t)}$ の矛盾（720–721） | 全満期で PDE を満たすには drift / diffusion がゼロ |

- **印刷値：** なし。
- **既存の実装：** interest_rate_models/ir_models.ipynb「なぜ金利モデルが必要か」「モデル分類図」。hullkit.hull_white:hw_discount_bond は後章モデルの参考。test_hull_white.py はこの節の一般 PDE を検証するものではない。
- **足りないもの：** 経路割引・PDE・flat curve反例をつなぐ導出。
- **独立参照の案：** Gaussian short-rate の解析積分と MC、PDE への代入残差。

- **依存・注意：** Ch28、rは瞬間金利、Rは期間zero rate。D3 は背景説明だけ候補、PDE残差検証は数値側に残す。

## §31.2 One-Factor Models（pp.721–726）

- **ロジック計画／2026-10-04：** privateにVasicek/CIR bond・CIR厳密時点分布（df0 zero atom）・RB GBM endpoint・short-rate riskを実装。本文3.30/0.33%/0.05をGaussian/Riccati/χ²求積・MC・RB別PDEで検証。厳密endpointと経路積分を区別し、教材・受入は章末。

- **種別：** 数値（例題あり）。
- **原典の内容：** RB は short rate の GBM、Vasicek は加法 OU、CIR は square-root diffusion。後2者の $P=Ae^{-Br}$、境界条件、債券の short-rate duration $\hat D=B$、債券価格過程を導く。1因子でも curve の形は変わりうる。
- **要求の下書き：**

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D31.2-01 | 3 SDE、平均回帰、Vasicek/CIRのA・B（721–724） | $P(T,T)=1$、PDE残差、MC割引 |
| D31.2-02 | CIRのFeller条件とVasicekの負金利（724） | 非中心χ²の遷移とEulerの境界bias |
| D31.2-03 | Ex31.1、$\hat D=B$、式31.11–12のbond diffusion（725） | finite difference のshort-rate感度 |
| D31.2-04 | 同じ局所標準偏差でVasicek/CIRを比較（726） | $\sigma_{\rm Vas}=\sigma_{\rm CIR}\sqrt r$ |

- **印刷値：** Ex31.1 $D=4$、10bpで約0.4%、$a=.1,T=4$ → $\hat D=3.30$（3.29679954）、10bpで約0.33%（0.32967995%）。p.726 $r=.04,\sigma_{\rm Vas}=.01$ → CIR $\sigma=.05$。3つの計算出力 **✓再計算一致**、専用ピンなし。Figure31.1–2は概念図で数値入力なし。
- **既存の実装：** 旧 ir_models builder の simulate_vasicek / vasicek_zero_curve（§1.1）、simulate_cir（§1.2）、simulate_rb（§1.3）、cir_zero_curve / rb_zero_curve（§4）。hullkit の金利Vasicek/CIR/RB専用 API・単体テストなし。信用損失の一因子Gaussianモデルを金利Vasicek実装の代用に数えない。

## §31.3 Real-World vs. Risk-Neutral Processes（pp.726–727）

- **ロジック計画／2026-10-04：** privateのc−a*r係数でP/Qを往復しa=0の割算を避け、signed bond diffusionからP収益を計算。印刷例なし。Gaussian raw密度求積/MC・CIR局所tilt・有限差分PDEで独立検証。教材・受入は章末。

- **種別：** 数値（例題なし）。
- **原典の内容：** 本文では bond の正のリスクプレミアムに対応し short-rate risk price を負とする。Q の drift に $\lambda s$ を足すとPの drift。Vasicek は $b^*=b+\lambda\sigma/a$、CIR で $\lambda=k\sqrt r$ なら $a^*=a-k\sigma,b^*=ab/a^*$。

| D31.3-02 | CIRの $a^*,b^*$、bond excess drift（726–727） | drift展開一致、$a^*b^*=ab$ |
