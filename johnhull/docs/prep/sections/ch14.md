## §14.1 The Markov Property（pp.316–317）

- **種別：** 定性。
- **原典の内容：** Markov 過程では、将来の予測に効くのは現在値だけで、過去の経路は無関係。株価は通常 Markov と仮定し、これは弱度の市場効率性（過去の価格情報は現在の価格に織り込まれている）と整合する。仮に「あるパターンの後は 65% の確率で急騰する」と分かれば、買いが殺到してその効果は消える、という競争の議論で説明する。脚注 1：過去の統計的性質（ボラティリティなど）の推定に履歴を使うのは構わない。

  1. §14.1＋§14.4：定性の 2 節。D3 の軽い経路（説明＋実画面のみ）の候補。§14.4 は §15.4 と重なる。
  2. §14.2＋§14.3：例題と Table 14.1、Figure 14.1・14.2。1 マイルストーン。
  3. §14.5＋§14.6＋§14.7＋付録：Itô の補題の系統。数値例がなく、恒等式と MC で受け入れる。§15.1（対数正規の例題）と同時にすると重複が減る。
  4. §14.8：単独。§27.2（受入済み）の rough volatility と R1 へつなぐ。
- **一度だけ作る共有部品：**
  - 与えた乱数列で経路を再生する関数（Table 14.1。OP-06 の Table 19.2・19.3 にも使える）
  - 相関正規乱数と Cholesky の小さなヘルパー（§14.5、§14.8、§21.6、§27.7）
  - fBM の共分散（式 14.20）と経路生成（§14.8。vol 25 の fGn と共通化できるかを設計時に決める）
