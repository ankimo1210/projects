## §27.6 Barrier Options（pp.656–658）

- **種別：** 数値（例題なし）。式と Figure 27.4・27.5 がある。
- **原典の内容：** 解析解のないバリア型の数値法。ツリーでノードがバリアを越えたら値を 0 にする素朴な方法は収束が遅い。ツリーは暗黙に「外側のバリア」を真のバリアとして扱い、その誤差はノード間隔（$\sqrt{\Delta t}$ の次数）で残る。対策は3つ：内側と外側のバリアで価格を出して補間する、ノードがバリアの上に乗るよう $u$ を選ぶ、初期価格がバリアに近いときは adaptive mesh（§21.4、Figlewski–Gao）を使う。
- **要求の下書き：**

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D27.6-01 | 素朴な方法（up-and-out ならバリアを越えたノードで 0）。三項は二項よりよいが、それでも収束が遅い（p.656） | 解析バリア（§26.9、受入済み）と比べた N ごとの誤差。のこぎり状の振動 |
| D27.6-02 | 内側・外側のバリア。ツリーは外側を暗黙に真のバリアとみなす。誤差はノード間隔の次数。2 価格を補間する方法（p.656、Figure 27.4） | 内側・外側・補間の 3 価格と解析値。補間で誤差の次数が変わるかを測る |
| D27.6-03 | ノードをバリアに乗せる：$\ln u=(\ln H-\ln S_0)/N$、$N=\mathrm{int}\big[(\ln H-\ln S_0)/(\sigma\sqrt{3\Delta t})+0.5\big]$。三項確率は2次までのモーメントを合わせる：$p_u,p_d=\pm\frac{(r-q-\sigma^2/2)\Delta t}{2\ln u}+\frac{\sigma^2\Delta t}{2(\ln u)^2}$、$p_m=1-\frac{\sigma^2\Delta t}{(\ln u)^2}$（pp.657–658、Figure 27.5） | 1 ステップの平均・分散が目標と一致すること。収束の速さを D27.6-01 と比べる |
| D27.6-04 | 初期価格がバリアに近いと上の方法は効かず、adaptive mesh を使う（p.658） | 下の「注意」の負の確率・$N=0$ の例で、なぜ効かないかを数値で示す |

- **印刷値（ピン候補）：** なし。式（$N$、$\ln u$、$p_u,p_m,p_d$）を手計算の小例でピンにする。
- **既存の実装：**
  - `hullkit.exotics:barrier_call` と `hullkit.exotics:barrier_put`：連続監視の解析解。`n_observations` を渡すと BGK 補正を使う。
  - `hullkit.exotics:bgk_adjusted_barrier`
  - 三項ツリー：vol06 §2 のノート内関数 `trinomial_price` だけ（hullkit にはない）。
- **足りないもの：**
  - バリア付きの三項ツリー（素朴・内側・外側・補間・ノードをバリアに乗せる方法）
  - 収束の比較図
  - 近すぎるバリアで壊れる例
  - adaptive mesh（原典は1段落の紹介だけ。実装は任意）
- **独立参照の案：**
  - 連続監視の解析解（§26.9、M1 で受入済み）。
  - 方式の違う参照として、バリアを境界条件にした Crank–Nicolson PDE を置く。
  - ツリーは「各時点で監視」するので、解析値との差には監視の離散性と格子位置の両方が含まれる。この2つを分けて測る：離散監視の MC（Brownian bridge なし）と BGK 補正の値を並べる。
- **図の案：**
  1. 価格と N（素朴な二項／素朴な三項／補間／バリア上ノード）
  2. log-log の誤差
  3. 内側・外側・真のバリアのノード配置（Figure 27.4 の再現）
  4. バリアに近づけたときの確率 $p_m$ と価格の破綻
- **依存・注意：**
  - $x=(\ln H-\ln S_0)/(\sigma\sqrt{3\Delta t})$ とおくと、$N=1$ のとき $p_m=1-1/(3x^2)$ になる。$0.5\le x<1/\sqrt3\approx0.577$ で $p_m<0$、$x<0.5$ で $N=0$（ゼロ除算）。原典の「初期価格がバリアに近いと効かない」の具体的な中身なので、拒否か Δt の調整を仕様で決める（2026-09-27 に式から導出。数値での確認は受入時）。
  - ドリフトが大きいと $p_u$ や $p_d$ が負になりうる。
- **規模：** M（新しいツリー実装＋収束実験＋図 4 枚）。
- **関連：** RB-F02、監査 EX-02（バリアプット・BGK は対応済み）。

## §27.7 Options on Two Correlated Assets（pp.658–661）

- **種別：** 数値（例題なし）。3つの構成法と Table 27.2・27.3 がある。
- **原典の内容：** 相関する 2 資産に依存する米国型を 3 次元ツリーで評価する 3 つの方法。
  1. 変数変換：$x_1=\sigma_2\ln S_1+\sigma_1\ln S_2$、$x_2=\sigma_2\ln S_1-\sigma_1\ln S_2$ は無相関。ボラは $\sigma_1\sigma_2\sqrt{2(1\pm\rho)}$。2 本の二項ツリーを組み合わせ、$S_1=\exp[(x_1+x_2)/(2\sigma_2)]$、$S_2=\exp[(x_1-x_2)/(2\sigma_1)]$ で戻す。
  2. Rubinstein の非矩形ツリー：4 枝とも確率 0.25。$u_1,d_1$ と $A,B,C,D=\exp[(r-q_2-\sigma_2^2/2)\Delta t\pm\sigma_2\sqrt{\Delta t}(\rho\pm\sqrt{1-\rho^2})]$。
  3. 確率の調整：確率 0.5 の代替二項（§21.4）を無相関で組み合わせる（Table 27.2、各 0.25）。そこから、同方向の 2 枝を $0.25(1+\rho)$、逆方向の 2 枝を $0.25(1-\rho)$ にする（Table 27.3）。
- **要求の下書き：**

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D27.7-01 | 無相関の 2 変数なら 2 次元ツリーの積で 3 次元ツリーを作れる。4 枝の確率は積（p.659） | 確率の和が 1、周辺分布が元のツリーと一致 |
| D27.7-02 | 変数変換の式・ドリフト・ボラ・逆変換（pp.659–660） | $x_1,x_2$ の共分散が 0。逆変換で $\ln S_1,\ln S_2$ の平均・分散・共分散（$\rho\sigma_1\sigma_2\Delta t$）が合う |
| D27.7-03 | Rubinstein の非矩形ツリー。$\rho=0$ なら §21.4 の代替二項を 2 本並べたものと同じ（p.660） | 1 ステップの平均・分散・共分散。$\rho=0$ の一致 |

- **印刷値（ピン候補）：** Table 27.2・27.3 の確率（記号式）。数値例はないので、構成ごとの 1 ステップのモーメントを手計算の小例でピンにする。
- **既存の実装：**
  - `hullkit.exotics:exchange_option`（Margrabe）
  - `hullkit.exotics:exchange_option_american`（M6、1 次元化した格子）
  - `hullkit.exotics:better_of_two_assets`、`hullkit.exotics:worse_of_two_assets`
  - `hullkit.exotics:basket_option_price`（M7、モーメント整合）
  - 3 次元ツリーはない。
- **足りないもの：** 3 構成の 3 次元ツリー、米国型 2 資産オプションの評価、構成ごとの収束の比較、確率が負になる条件の扱い。
- **独立参照の案：**
  - 欧州 exchange は Margrabe（§26.14、受入済み）。
  - 米国 exchange は M6 の 1 次元化格子（方式が違う）。
  - 欧州 max/min は Stulz の解析式（二変量正規。hullkit に未実装なので、独立参照として SciPy で書く）。
  - 相関のある正規乱数の MC（欧州のみ）。
- **図の案：**
  1. 3 構成のノード配置（1 ステップ）
  2. 米国 exchange（または max）の価格と N を 3 構成で比較
  3. $\rho\to\pm1$ での挙動（変数変換で一方のボラが 0 になる）
- **依存・注意：**
  - 変数変換は $\rho=\pm1$ で退化する。
  - Rubinstein の方法は $|\rho|\le1$ で定義される。
  - 確率調整は代替二項（全確率 0.5）を前提にしている。CRR に当てはめると一致しない。
- **規模：** M–L（3 構成×米国型、参照 2 種）。

## §27.8 Monte Carlo Simulation and American Options（pp.660–665）
