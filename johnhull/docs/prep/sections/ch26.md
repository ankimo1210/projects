## §26.1 Packages（pp.614–615）

- **種別：** 混在。商品の構成説明と繰延プレミアムの算式。数値例なし。
- **原典の内容：** 欧州 call/put・forward・現金・原資産を組み合わせる。range forward は異なる strike の call と put の価格を等しくして初期費用をゼロにする。プレミアムを満期払いにした商品にも将来の支払義務は残る。
- **要求の下書き：**

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D26.1-01 | package と Ch12 の各戦略、zero-cost collar の構成（614–615） | 各脚の価格と給付の和 |
| D26.1-02 | 繰延プレミアム $A=ce^{rT}$、給付 $\max(S_T-K,0)-A$（615） | 初期 PV がゼロ、満期最大損失 $A$ |

- **印刷値（ピン候補）：** なし。式の恒等性を合成入力で検証する。
- **既存の実装：** hullkit.payoffs:leg_payoff / strategy_payoff、hullkit.bsm:call_price / put_price。vol10 build_exotics_notebook.py「1. エキゾチックの分類」の商品表。test_payoffs.py は部品の検証で、この節の繰延契約専用ピンではない。
- **足りないもの：** 将来支払を含む cashflow 表と range-forward の strike 選択例。
- **独立参照の案：** 各脚を手計算した満期 cashflow と割引 PV。根探索で決めた collar を MC で照合する。
- **図の案：** collar / deferred call の給付と支払を重ねる1図。
- **依存・注意：** Ch12、§17.2。初期費用ゼロをリスクゼロと表現しない。D3 は商品分類の説明部分だけ候補、算式の検証は残す。
- **規模：** S（部品再利用と説明）。**関連：** RB-H26（term sheet 分解は P2 後のコラム）。

- **要求の下書き：**

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D26.2-01 | $w=r-q-\sigma^2/2$、$a_1=(-w+\sqrt{w^2+2\sigma^2r})/\sigma^2$、$a_2=(w+\sqrt{w^2+2\sigma^2r})/\sigma^2$（615–616） | characteristic 方程式への代入残差 |
| D26.2-02 | $H_1=Ka_1/(a_1-1)$、$H_2=Ka_2/(a_2+1)$。継続価値 $(H_1-K)(S/H_1)^{a_1}$ / $(K-H_2)(S/H_2)^{-a_2}$（615–616） | value matching、smooth pasting、行使域では intrinsic |

## §26.4 Gap Options（p.617）

- **種別：** 数値（例題あり）。
- **原典の内容：** 行使トリガー $K_2$ と決済額に使う strike $K_1$ を分ける。call は $(S_T-K_1)1_{S_T>K_2}$、put は $(K_1-S_T)1_{S_T<K_2}$。BSM の $d_1,d_2$ は $K_2$、支払係数は $K_1$ を用いる。
- **要求の下書き：**

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D26.4-01 | 式26.1–26.2、vanilla＋binary の分解（617） | $K_1=K_2$ の vanilla 極限、call-put parity |
| D26.4-02 | Example26.1 の移転費用と insurer の支払（617） | 通常 put / gap put、保険料減少率 |

- **印刷値（ピン候補）：** $S=500,000,\sigma=20\%,r=5\%,T=1,q=0$。通常 put $K=400,000$：印刷3,436、独立計算3,435.9470199 **✓再計算一致**。移転費用50,000 → $K_1=400,000,K_2=350,000$：印刷1,896、計算1,895.6889444 **✓再計算一致**。約45%減：44.8277598% **✓再計算一致**。整数通貨単位の丸め。test_exotics_puts.py:test_gap_put_hull_example_26_1 が両価格を固定済み。

- **足りないもの：** 給付の跳び、policyholder の手取りと insurer の支出の違いを説明する教材。
- **独立参照の案：** 対数正規密度に対する区分求積（trigger で積分区間を分ける）。
- **図の案：** 二つの strike を動かす給付、移転費用と保険料。
- **依存・注意：** gap の給付は strike の順序によって負になる領域がある。勝手に max(·,0) を追加しない。GE値は既存ピンとも一致。
- **規模：** S（実装・ピンは既存、説明と独立求積）。**関連：** EX-02 は対応済み、RB-H26。

| D26.5-02 | ESO の将来付与との関係（618） | 契約開始・strike 決定・満期を区別 |

## §26.6 Cliquet Options（p.618）

- **種別：** 混在。単純型の分解は数値、複雑型の分類は定性。
- **原典の内容：** 各 reset 時点の spot を次期 strike にする call / put の列。単純型は最初の vanilla と後続 forward-start の和で評価する。期間合計の上下限や条件付き早期終了を持つと分解は使えず MC が候補となる。
- **要求の下書き：**

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D26.6-01 | $t_1,\ldots,t_n$ ごとに支払う単純 cliquet（618） | 各支払を各日付で割引、$n=1$ で vanilla |
| D26.6-02 | global cap/floor・早期終了により生じる経路依存（618） | 単純和が使えなくなる反例を説明 |

- **印刷値（ピン候補）：** なし。
- **既存の実装：** 専用 API / テストなし。vol10 商品表の説明のみ（監査 absent→md）。hullkit.bsm:call_price / put_price が単純型の部品。
- **足りないもの：** 単純型の支払時点を含む契約と検証。複雑型の全実装は本文の要求に自動追加しない。
- **独立参照の案：** reset を含む GBM 経路から各給付を直接集計し、forward-start の和と MC の誤差帯を比較。
- **図の案：** 経路上の strike reset と期間別 cashflow。
- **依存・注意：** §26.5。単純型の給付と return cliquet は別契約。D3 は複雑型を紹介する説明部分だけ候補。
- **規模：** M（reset / 支払の契約定義と参照 MC）。**関連：** EX-03、RB-H26。

## §26.7 Compound Options（pp.618–619）

- **種別：** 数値（例題なし）。
- **原典の内容：** call-on-call / put-on-call / call-on-put / put-on-put の4種。第1行使日 $T_1$ と第2行使日 $T_2$、それぞれ strike $K_1,K_2$ がある。Geske の式は二変量正規と、第1時点の vanilla 価格が $K_1$ になる臨界 spot $S^*$ を用いる。
- **要求の下書き：**

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D26.7-01 | 4給付と $S^*$、$0<T_1<T_2$（618–619） | vanilla$(S^*,T_2-T_1)=K_1$ の残差 |
| D26.7-02 | $M(a,b;\pm\sqrt{T_1/T_2})$ の4公式（619） | underlying option ごとの compound put-call parity |
| D26.7-03 | $a_i$ は $S^*$、$b_i$ は $K_2$ を用いる（619） | 二つの strike を取り違える変異を検出 |

- **印刷値（ピン候補）：** なし。式の記号は PDF を再確認して実装に転記する。
- **既存の実装：** 専用 API / テストなし。vol10 商品表に名称と方法のみ（監査 absent→md）。hullkit.bsm:call_price / put_price は内側オプションの部品。
- **足りないもの：** 臨界価格探索、4種の公式、根が存在しない契約領域と端点。
- **独立参照の案：** $T_1$ の対数正規密度について vanilla 価値の正部を1次元積分（二変量 CDF を使わない）。Geske (1979) は導出の原典候補。
- **図の案：** 第1行使の閾値、4種の価格と $K_1$、求積との差。
- **依存・注意：** put の最大価値より $K_1$ が大きい場合等は有限 $S^*$ がない。根探索の失敗をそのまま価格の失敗にしない。
- **規模：** M（4契約・臨界点・独立求積）。**関連：** EX-03、§26.8、RB-H26。

## §26.8 Chooser Options（pp.619–620）

- **種別：** 数値（例題なし）。
- **原典の内容：** $T_1$ に call / put のどちらを持つか選び、選択価値は $\max(c,p)$。両者の strike と満期が同じなら put-call parity によって静的 package に分解できる。異なる strike / 満期の複雑型は compound に近い。
- **要求の下書き：**

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D26.8-01 | $T_2$ call 1個＋$T_1$ put $e^{-q(T_2-T_1)}$ 個、後者 strike は $Ke^{-(r-q)(T_2-T_1)}$（620） | $T_1$ での package 価値と $\max(c,p)$ が一致 |
| D26.8-02 | $T_1=0$ と $T_1=T_2$ の極限（式からの検証要求） | 今日の max(call,put)、満期 straddle |

- **印刷値（ピン候補）：** なし。
- **既存の実装：** hullkit.bsm:call_price / put_price が全部品。専用 API / テストなし。vol10 商品表のみ（監査 absent→md）。
- **足りないもの：** 複製比率と変更 strike の導出、選択時点の感度。複雑 chooser は本文に公式がなく拡張扱い。
- **独立参照の案：** $S_{T_1}$ を積分し $\max(c(S_{T_1}),p(S_{T_1}))$ を割引。公式の package と別経路にする。
- **図の案：** 選択境界と package の価値、選択猶予による価格増分。
- **依存・注意：** 配当による個数調整を落とさない。§26.1 / Ch11 parity。
- **規模：** S（BSM 部品・1次元求積）。**関連：** EX-03、RB-H26。
