## §33.1 The Heath, Jarrow, and Morton Model

- **ロジック計画／2026-10-05：** privateでsigned bond loading/finite forward/瞬間forwardの多因子ドリフト、Euler step、deterministic-vol HJM pathを実装。印刷価格なし。独立Gaussian short-rate解析とのbond/option MC・時間刻み収束・同じrで異なる履歴driftを検証。一般履歴依存HJMのscalar Markov性は保証しない。教材・受入は章末。

**種別:** 数値（例題なし）。

**原典の内容:** 満期別債券ボラティリティから瞬間フォワードのドリフトを無裁定で決める。多因子では各因子の寄与を足し合わせる。一般の履歴依存モデルは非Markovであり、少数の状態だけで木を再結合できるとは限らない。Ho–LeeとHull–Whiteはボラ構造を制限した特殊例になる。

### 要求の下書き

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D33.1-01 | 債券 dP/P=r dt+v(t,T)dW から有限期間forwardと瞬間forwardの式を導く。v(t,t)=0、F=-∂T log P（755–757）。 | Itôの交差項と満期微分の符号を確認。債券拡散をvと置くとforward拡散は−∂Tv。 |
| D33.1-02 | 独立因子のforward拡散をσkと書けば μ(t,T)=Σk σk(t,T)∫t^Tσk(t,u)du（757）。 | 債券を数値積分して構成し、割引価格の平均ドリフトが0になることをMCで比較。 |
| D33.1-03 | σ一定→Ho–Lee、σ exp[−a(T−t)]→HW。一般HJMの非Markov性と計算量を説明（757–758）。 | 同じ初期曲線・ボラで解析ZCB/optionと比較し、有限因子数とMarkov性を同一視しない。 |

**印刷値（ピン候補）:** 数値価格の例題・校正表はない。30段の二分岐木がおよそ10億状態になる説明は計算量の例（2^30）、価格ピン不要。Figure33.1はforward定義の図。

**既存の実装:** interest_rate_models/build_ir_models_notebook.py §3.1「HJM」の hjm_curves、§3まとめの hjm_normal_vol / hjm_black_equivalent_vol はノート内関数。hullkit.hull_white:hw_discount_bond / hw_zcb_option は特殊例の解析基準。一般HJM公開API/専用テストはない。

**足りないもの:** 債券からforwardへの導出、離散満期間隔・時間刻みに対する整合性、多因子拡散の内積、ドリフトの独立検証。見栄えの曲線生成だけでHJM実装済みと判定しない。

**独立参照の案:** 一定または指数減衰ボラのHJM離散化を、Ho–Lee/HWの解析債券価格・分散と比較する。ドリフトを同じコードから呼び出す比較は避ける。

**図の案:** 初期forwardとシミュレーション曲線、満期別ボラ構造、刻みと割引債価格誤差。

**依存・注意:** EX16、EX17、RB-H33。§28.4–8のnumeraire、§32.1–3。HJMと「複数short rate因子」を同一視しない。原典の研究発表年と脚注の出版年は別物。

**規模:** M。導出と特殊例の検証は限定でき、一般任意ボラの製品ライブラリは後続研究。

**関連:** D28.8、D32.1、D32.3、D33.2。

## §33.2 The BGM Model

- **ロジック保留／2026-10-05：** 本人指示に従い、flexicapのstrike/対象reset・payment日、sticky初期K0が原典から確定できないため、この節を飛ばして§33.3へ進む。ユーザーも追加資料を持たないと回答済み。Ex33.1/Table33.1・多因子LMM/CEV/行使基盤を含む既存の下調べは保持し、印刷価格から契約を逆推定しない。

**種別:** 数値（例題あり）。

**原典の内容:** 期間ごとに実際に観測する単利forwardを状態とし、対応する支払日のforward測度でlognormalにする。共通測度ではforward間の共分散からドリフトが決まる。Capletの周辺分布が同じでも因子数・相関を変えるとratchet、sticky、flexicapやswaption価格は変わる。本文はLIBORだけでなくOISのforwardにも適用すると説明する。

## §33.3 Agency Mortgage-Backed Securities

- **ロジック計画／2026-10-05：** privateでhomogeneous poolの月次償却・履歴適応SMM・IO/PO・sequential CMO・固定cashflow OAS逆算を実装。本文の400/300/100と100/200/500（計800）を再現。独立償却閉形式/PV等比級数/Gaussian割引MCで検証。pool/prepay/市場価格は本文にないため合成例、実証的返済モデル/保証制度の検証とは別。教材・受入は章末。

**種別:** 混在。構造・リスク説明はD3（説明＋renderedのみ）候補。価格手順を受入対象にする場合は別途数値検証が必要。

**原典の内容:** Agency保証があっても住宅ローンの繰上返済オプションが残る。金利の履歴と借り手の行動に依存する返済を、金利モデルだけで決定できるとは限らない。Pass-through、優先順位を持つCMO、IO/POを区別し、OASは仮定した返済モデルの下で市場価格を一致させるspreadとして求める。

### 要求の下書き

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D33.3-01 | 信用保証と繰上返済リスク、pass-through/CMO/IO/POのcashflowを説明（768–769）。 | 繰上返済増加に対するIOとPOの方向性、tranche間のprincipal保存。 |
| D33.3-02 | 月次金利path→履歴依存prepayment→cashflow→Treasury曲線＋spreadで割引する評価手順（769–770）。 | σ=0かつprepaymentなしの極限を通常の償却表と比較。 |
| D33.3-03 | OASを市場価格への逆算とし、返済モデル・担保pool特性・rate modelに依存すると明記（770）。 | 固定cashflowではspreadと価格が単調逆向き。異なるprepayment仮定の価格/OAS感応度。 |

**印刷値（ピン候補）:** 30年住宅ローンと、CMOのA/B/Cを400/300/100対100/200/500に配分する例（p768–769）は構造説明。どちらも合計800だが価格ピンはない。市場・制度の説明は **記述統計（ピン不要、年次に注意）**。prepayment関数・poolデータ・価格は指定されないためOAS数値は再計算対象なし。

**既存の実装:** MBS/prepayment/OASの専用hullkit API・本節ピンはない。vol12の証券化説明はcredit trancheの文脈でありagency MBSの期限前返済モデルとは別。hullkit.hull_white:simulate_hw_paths は金利pathの部品候補にとどまる。

**足りないもの:** Agency保証と借り手の行使の説明、月次cashflow仕様、返済仮定とOASの解釈。本文が与えない借り手モデルを必須製品仕様として発明しない。

**独立参照の案:** deterministic償却表とprincipal/interest保存、固定cashflowの手計算PV・spread逆算。将来の確率prepaymentモデルには別の公開pool観測値が必要。

**図の案:** 金利path→返済→tranche配分→OASのフロー図1点。

**依存・注意:** EX16、RB-H33、§32.1・§33.1–2・Ch8の証券化。prepayment riskとdefault riskを分離。制度名・guaranteeの範囲は原典時点の説明として扱う。

**規模:** M（cashflow/OASまで）、S（説明のD3に限定する場合）。

**関連:** D33.1、D33.2、D34.6。
