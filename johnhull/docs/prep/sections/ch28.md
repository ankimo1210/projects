## §28.1 The Market Price of Risk（pp.671–674）

- **種別：** 数値（例題あり）。
- **原典の内容：** 同一リスク源を持つ無配当証券2本の拡散を相殺し、$(\mu-r)/s=\lambda$ を導く。$s$ は signed loading、通常の volatility は $|s|$。測度変更は drift を変え、拡散を保つ。
- **要求の下書き：**

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D28.1-01 | 式28.2–28.9 の portfolio と共通 $\lambda$（671–672） | 拡散ゼロと利回り $r$ |
| D28.1-02 | Examples28.1–2、消費財 spot に式を機械適用しない（673） | 3出力と資産の分類 |
| D28.1-03 | $\mu=r+\lambda s$、Girsanov（673–674） | 再重み付けと変更 drift の直接標本 |

- **印刷値：** $(.12-.08)/.2=.2$、$(.03-.06)/.2=-.15$、$.06-.15(.3)=.015$（1.5%）：3値 **✓再計算一致**。専用印刷ピンは確認できず。
- **既存の実装：** hullkit.sde:girsanov_weights / brownian_paths、test_sde.py。vol13 の Girsanov、vol10「6. 市場リスクの価格 λ」「8. ギルサノフの定理」。
- **足りないもの：** 負の loading、負の $\lambda$ の例と消費財の注意。
- **独立参照の案：** lognormal の解析期待値と変更 drift からの MC。
- **図の案：** 密度の傾斜と期待値。
- **依存・注意：** §14、§36.3。$\lambda$ の単位は年$^{-1/2}$。
- **規模：** S（部品・算術例）。**関連：** EX-06、RB-H28。

## §28.3 Martingales（pp.675–676）

- **種別：** 混在（定義と Itô による導出）。

- **要求の下書き：**

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D28.3-01 | 脚注の条件付き定義と式28.14（675–676） | Itô drift の相殺 |
| D28.3-02 | 正値 numeraire と式28.15（676） | 同じ給付の価格不変性 |

- **印刷値：** なし。
- **既存の実装：** vol10「5. マルチンゲールとニュメレール」「7. ニュメレールの選択」のインライン MC。関連部品 hullkit.sde:girsanov_weights、test_sde.py。専用 API / テストなし。
- **足りないもの：** 条件付き期待値の検査。標本平均の一致だけでは定義全体を確認しない。
- **独立参照の案：** 2時点の条件付き解析期待値と区間別 MC。
- **図の案：** 比 $f/g$ の平均と SE 帯。
- **依存・注意：** zero drift は一般には局所 martingale の条件で、可積分性を省略しない。本文の GBM 等の条件内で説明。D3 は定義・証明部分だけ候補。

| ID | 原典上の要点（頁） | 検証の手がかり |

| D28.8-03 | 相対 drift と絶対 drift（684） | 単位と係数 |

- **印刷値：** なし。
