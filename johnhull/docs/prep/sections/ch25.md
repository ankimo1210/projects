## §25.1 Credit Default Swaps（pp.588–591）

- **ロジック計画／2026-10-06：** CDSの保護買い/売りの時点CF・停止/経過premiumとbasis算術をprivate化。本文7値と生存/default状態の独立cashflowを照合。日付は概算年分数で明示。

- **種別：** 混在。
- **原典の内容：** CDSは参照企業の信用事由に対する保護で、買い手はデフォルトまでプレミアムを払い、信用事由時に額面と回収価格の差を受け取る。現物決済・現金決済、最後の経過分、CTD債の選択を区別する。債券と保護買いの組合せからCDSと債券スプレッドが近くなる理由とbasisを説明する。
- **要求の下書き：**

| ID | 原典上の要点（頁） | 検証の手がかり |
|---|---|---|
| D25.1-01 | 参照企業・信用事由・元本・保護買い/売りのキャッシュフロー（pp.588–589） | Figure25.1と四半期支払・回収の例 |
| D25.1-02 | 現金/現物決済、経過プレミアム、CTD（pp.589–591） | 額面100に対し回収35なら支払65を確認 |
| D25.1-03 | 保険との相違、情報の非対称性と信用リスクの移転（pp.588,590） | BS25.1/25.2を原典の事例として説明 |
| D25.1-04 | CDS–bond basisの符号と近似裁定（p.591） | basis＝CDS spread−bond yield spread。7%−2%=5% |

- **印刷値（ピン候補）：** ✓7値再計算一致。p.588：年90bpから四半期22.5bp、元本100Mの支払225,000。p.589：回収35%なら65M、2か月分経過額は概算150,000、250/260bp＝2.5/2.6%。p.591：債券利回り7%から保護費用2%を引き5%。実際の日数を使う場合は150,000・225,000の概算から差が出ることを脚注2に従い明示する。

- **足りないもの：** 具体例のキャッシュフロー表、信用事由と取引相手のデフォルトの区別、basisの定義と近似の条件。
- **独立参照の案：** 日付を簡略化した手計算。保護付き債券の生存/デフォルト別キャッシュフローを列挙して符号を照合する。
- **図の案：** 2枚（支払方向図、デフォルト時の停止・経過分の時間軸）。
- **依存・注意：** 現在の契約標準・法的解釈の保証は対象外。割引率の参照先は原典時点のLIBOR/swapであることを示す。RB-H25のSRT契約への拡張はP5後。
