# §26.2 永久アメリカン・コールとプット：受入記録

**数式と数値。**

- 継続領域の特性方程式の正根 $a_1$ と負根 $-a_2$、上方・下方初回到達の価値、コール境界 $H_1=Ka_1/(a_1-1)$、プット境界 $H_2=Ka_2/(a_2+1)$ を導いた。独立参照の6市場で公開 API の価格差は最大 $7.2\times10^{-15}$、境界差は $5.7\times10^{-14}$、指数差は $2.3\times10^{-16}$。価値一致と滑らかな接続も照合した。
- 対称例 $S_0=K=100$、$r=q=4\%$、$\sigma=20\%$ では $a_1=2$、$a_2=1$、$H_1=200$、$H_2=50$、コール・プット価値はともに25。$q=0$ のコールは有限の最適行使境界を持たず、価値は $S$。専用例ではコール100、プット境界71.4286、プット価値12.3200。
- `hullkit` から独立した有限満期 CRR 後退帰納を20・40・80・160年、年10ステップで計算した。対称例の価格は22.6442、24.4426、24.9375、24.9800と永久値25へ近づく。保存した格子価格を独立に再計算し、価格と差の列を一緒に改変しても拒否した。有限満期と離散格子の効果を分離した厳密な誤差上界とは呼ばない。
