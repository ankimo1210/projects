# §26.3 非標準アメリカン・オプション：原典照合とレビュー

日付：2026-09-30。対象は Hull, *Options, Futures, and Other Derivatives*, 11th Global Edition, p.616, §26.3。原典PDFの再配布はしない。

## 原典との対応

原典は、特定日だけ行使できる Bermudan 型、開始後の一定期間は行使できない型、契約期間中に行使価格が変わる型を挙げ、二項木の各節点で行使可否とその時点の行使価格を評価できると説明する。7年ワラントの例は、3～7年目の特定日に行使でき、行使価格が3・4年目は30ドル、5・6年目は32ドル、7年目は33ドルという**契約条件**である。原典には市場の初期株価、金利、配当、ボラティリティ、計算価格は印刷されていない。

教材は行使可能日を整数格子点と価格の対応表で指定する。ワラントは各年末を代表日とした**合成例**で、$S_0=30$, $r=4\%$, $q=1\%$, $\sigma=25\%$, $T=7$ 年、70ステップを仮定した。8.6196956043ドルはこの仮定下の離散CRR価格であり、Hull の印刷価格ではない。

## 独立計算と結果

2ステップの小格子は終端経路を個別列挙して割引し、50・70ステップは `hullkit` を使わない単純な後退帰納で参照を作った。別実装の公開 API との差は11例で最大 $5.87\times10^{-14}$。小格子では欧州型プット22.3140495868、途中行使日を許す型27.2727272727、途中の行使価格を120へ上げる型38.1818181818となる。

1年・50ステップの同一合成市場で、欧州型8.178596、四半期Bermudan型8.452106、半年ロックアウト型8.510789、毎格子点行使可能型8.539077。行使日を増やしたときの価格順序と、行使不可日の節点が行使判定を持たないことを検査した。保存した価格、行使日、ワラントの行使価格、説明ラベルの4種類の改変を拒否した。

## 範囲と留保

日付は格子番号で厳密に指定し、暦日を格子へ暗黙に丸めない。満期格子点の行使価格を必須とする。CRRの無裁定確率と正の有限な入力を検査する。図の頻度比較は離散格子内の比較であり、連続行使の厳密誤差評価ではない。ワラントの希薄化、発行体信用、離散配当、確率的金利・配当・変動率、市場データでの性能は受入範囲外。
