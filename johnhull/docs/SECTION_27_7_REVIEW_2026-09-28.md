# §27.7 Options on Two Correlated Assets：原典照合と受入範囲

日付：2026-09-28。対象は Hull 11e Global Edition pp.658–661、Tables 27.2–27.3。
§27.6 と同じ5軸（説明、実装、独立検証、可視化、実画面）で TA01–TA06 を確認する。
原典に数値例・印刷価格はないため、欧州型は Stulz と Margrabe の式、米国型は1次元に帰着できる交換オプションを基準にし、
各構成の式は1段の枝と手計算の小例で固定する。

| TA02 変数変換 | vol06 §13.2。$x_1=\sigma_2\ln S_1+\sigma_1\ln S_2$、$x_2=\sigma_2\ln S_1-\sigma_1\ln S_2$、ボラティリティ $\sigma_1\sigma_2\sqrt{2(1\pm\rho)}$、逆変換 $S_1=\exp[(x_1+x_2)/(2\sigma_2)]$、$S_2=\exp[(x_1-x_2)/(2\sigma_1)]$（pp.659–660）。原典は各ツリーを最初の二つのモーメントに合わせるよう求める。$\pm h_i$ の二項で1段の平均 $m_i$ と分散 $v_i$ をともに正確に合わせると $h_i=\sqrt{v_i+m_i^2}$、$p_i=\tfrac12+m_i/(2h_i)$ に決まる（よく使う近似 $h_i=\sqrt{v_i}$ は分散を $\Delta t$ の一次までしか合わせない）。100段で $h_1=0.01039$、$h_2=0.00600$、$p_1=0.4942$、$p_2=0.4950$。 |

**独立参照。** `scripts/build_two_asset_reference.py` は `hullkit` を使わない。(1) Stulz の max コールの式を、第1資産で条件付けた1次元積分と照合（差 $10^{-14}$ドル未満）。(2) Margrabe の式（`hullkit.exotics.exchange_option` との差0）。(3) 米国型の交換オプションを1次元に帰着して CRR（20000・40000段の偶奇平均と外挿）と Crank–Nicolson（Rannacher 開始と射影、4000・8000格子の外挿）で解き、差 $1.4\times10^{-5}$ドル。(4) 原典の係数（$x_1,x_2$ の逆変換、$A,B,C,D$ の積、代替二項）からノードの株価を組み、欧州型は確率の質量を前向きに進める。米国型の後退帰納はベクトル化の手順が `hullkit` と同じなので、独立性は株価と確率の組み方にある。手順そのものは6段の小例（深い ITM と ATM、$q_1=25\%$）をノードごとの再帰で解いて照合した（差 $3.1\times10^{-14}$ドル、深い ITM は初回ノードで行使して本源的価値20ドル）。`numerical-check.json` では、公開関数との差が密な段数181通り×3構成（欧州・米国）、倍々の6段数、相関41点、追加30ケース、米国型 max コール9本で $3.4\times10^{-13}$ドル以下。

**可視化と検査。** 1段の枝（$\sigma_i\sqrt{\Delta t}$ で割った座標と相関の楕円）、米国型交換オプションの20–200段の収束、欧州型 max コールの誤差の倍々、相関と誤差の4図を Book と portal で共用する。Browser 検査は4図×2画面×2幅（1440/1000px）、数値、ラベルのはみ出しと軸タイトル・目盛りの重なり（4px の余白）、意図的な数値改変の拒否を確認する。相関の図は100段（実線）と101段（点線）を重ね、偶奇による振れを見せる。本文の数値は `report/tests/test_two_asset_notebook.py` が保存値と照合する。ノートブック検査は M15 基点の §13 以外107セルを後続2見出しの番号変更を除いて保持し、保存出力を新規4図と既存24図に照合する。

**独立レビュー。** 実装の外から本文・図・検査を読み直したレビューで、P1 1件、P2 3件、P3 8件の指摘があり、すべて修正した。`two_asset_tree.py` に誤りは見つからなかった。P1 は相関の図の本文で、100段だけを見て「各 $\rho$ で誤差は段数に反比例し、変わるのは係数」と書いていた。実際には $\rho=\pm0.6$ の落ち込みは偶数段だけに現れる。101段の点線を加え、99・100・101段の値（`parity`）で本文を書き直し、検証スクリプトが主張を照合する。P2 は、例の結果を方法の性質として書いていたこと（「この例（$\rho=0.5$）では」と限定）、米国型の初回ノードでの行使が未検査だったこと（深い ITM の6段で本源的価値に一致するテストを追加）、本文の数値と保存値をつなぐ検査がなかったこと（上記のテストを追加）。P3 は、所要時間、積分差の書き方、$\rho=\pm1$ で「動かない」という表現（ボラティリティが0で確定的に動く）、モーメント合わせの説明、符号の欠落、米国型交換オプションの許容誤差（400・401段で3e-3）、図の軸タイトルと目盛りの重なり、参照の独立性の書き過ぎ。変異テストでは、行使判定を0段目・1段目・0–2段目で外す変異を単体テストと検証スクリプトの両方が拒否した。

**適用範囲。** 定数の連続金利・配当利回り・ボラティリティ・相関の二資産で、ペイオフは関数として渡す。三資産以上、確率ボラティリティ、時間で変わる相関、市場での相関の推定、Hull–White 1994 の金利ツリーへの応用、1次元に帰着できない米国型の独立基準（2次元 PDE など）は対象外。
