# §26.2 永久アメリカン・コールとプット：原典照合と受入範囲

日付：2026-09-29。対象は Hull 11e Global Edition pp.615–616。原典に数値例はなく、以下の数値は独立参照が作った合成市場の値である。説明、実装、独立検証、可視化、実画面の5軸で PA01–PA06 を照合する。**受入判定は、最終 Book/portal と既受入18節の D1 再検査まで保留する。**

| 要求 | 原典・実装・検証の位置 |
|---|---|
| PA01 特性方程式 | 継続領域の $\tfrac12\sigma^2S^2f_{SS}+(r-q)Sf_S-rf=0$ に $f=S^a$ を代入。正根 $a_1$ と負根 $-a_2$ を vol10 §4.9.1、`perpetual_option`、独立参照の特性方程式残差で照合。 |
| PA02 到達と最適境界 | $S<H$ の上方初回到達は $(S/H)^{a_1}$、$S>H$ の下方初回到達は $(S/H)^{-a_2}$。最適境界 $H_1=Ka_1/(a_1-1)$、$H_2=Ka_2/(a_2+1)$ における価値一致と滑らかな接続を §4.9.2–4.9.3、公開 API、独立参照で照合。対称例は $S_0=K=100$、$r=q=4\%$、$\sigma=20\%$、$H_1=200$、$H_2=50$、コール・プットとも25。 |

**独立数式レビュー。** pp.615–616 の特性方程式、根、初回到達価値、境界最適化、価値一致、滑らかな接続は通常のモデル領域で一致した。原典の印刷値を再現したという主張はしない。合成市場6件の価格・境界、特性方程式と境界の残差、無配当の極限を独立参照と照合した。

**指摘と対応。**

- P2：極端に小さい正の $q$ と行使価格で、$a_1-1$ の桁落ちと境界の桁あふれを避ける計算へ修正した。継続価値の比が浮動小数点の範囲外になる場合も対数比から計算し、正の値を保持する。行使境界が行使価格から浮動小数点精度で分離できない場合や $\sigma^2$ がアンダーフローする場合は、誤った行使判定を返さず `ValueError` とする。極端入力の回帰テストを追加した。
- P2：保存参照の有限満期 CRR 価格だけを改変し、差の列も整合させれば旧数値ゲートが通る余地があった。ゲートで独立 CRR 後退帰納を再計算して保存値を照合し、改変が拒否されるテストを追加した。
- P3：年10ステップの有限満期 CRR と永久解析値の差には、有限満期の効果と格子の離散化誤差が両方含まれる。参照 JSON と §4.9.5 でその区別を明記した。差を連続行使解への厳密な誤差上界とは呼ばない。

**最終確認待ち。** 図の右軸目盛りを調整した後の Book/portal 16状態の再実行、数値改変の拒否、既受入18節の D1 再検査、統合記録 `m19-check.json` の生成と再検査を受入条件とする。
