# §27.5 Path-Dependent Derivatives：原典照合と受入範囲

日付：2026-09-27。対象は Hull 11e Global Edition pp.653–656、Example 26.3 と Figure 27.3。
§27.4 と同じ5軸（説明、実装、独立検証、可視化、実画面）で PD01–PD06 を確認する。

| 要求 | 原典・実装・検証の位置 |
|---|---|
| PD01 経路状態 | vol06 §11.1。将来の経路関数が現在の値と次の株価から更新できる条件、初期値を含む離散算術平均を明示。 |
| PD02 平均の上下限 | vol06 §11.2。各株価節点の到達可能平均の最小・最大を前向きに伝播する。 |
| PD03 代表値と補間 | vol06 §11.3。Figure 27.3 の X・Y・Z の4平均格子、線形補間と X の後退値を照合。 |
| PD04 欧州型価格 | vol06 §11.4。20段×4平均で7.17ドル、60段×100平均で5.58ドルの印刷値を再現。 |
| PD05 米国型価格 | vol06 §11.5。各株価・平均節点で行使を選択し、同条件で7.77ドル・6.17ドルを再現。 |
| PD06 独立検証と限界 | vol06 §11.6。4–12段の全経路列挙10価格と平均期待値恒等式、Book/portal共有4図。 |

**独立参照。** `scripts/build_path_dependent_reference.py` は `hullkit` を使わず、原著の印刷値と、再結合させない全経路の小格子価格を生成する。公開実装 `hullkit.path_dependent_tree` は CRR 株価格子の各節点へ代表平均を置き、子節点の値を線形補間して後退帰納する。`numerical-check.json` の印刷値との最大差は0.0032ドル、Figure 27.3 の平均格子差は0.00394ドル以下、全経路基準との差は0.00048ドル以下、線形ペイオフの平均期待値恒等式差は2.2e-14ドル以下。

**可視化と検査。** 平均グリッド、X・Y・Z の補間、粗密格子の価格、全経路基準の4図を Book と portal で共用する。Browser 検査は4図×2画面×2幅（1440/1000px）、数値とラベルのはみ出し、意図的な数値改変拒否を確認する。ノートブック検査は M13 基点の §11 以外82セルを後続2見出しの番号変更を除いて保持し、保存出力を新規4図と既存16図に照合する。

**適用範囲。** 一定の連続金利・配当利回り・ボラティリティ、離散時点の等間隔観測、単一の更新可能な算術平均状態を扱う。線形補間と有限格子には近似誤差がある。原著の連続平均の解析近似5.62ドルは観測規約が違うため、60段の5.58ドルへの厳密な検証値にはしない。2状態以上を要する契約、一般のバリア、実市場での較正やヘッジは対象外。
