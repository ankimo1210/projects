# §27.6 Barrier Options：原典照合と受入範囲

日付：2026-09-28。対象は Hull 11e Global Edition pp.656–658、Figures 27.4–27.5。
§27.5 と同じ5軸（説明、実装、独立検証、可視化、実画面）で BT01–BT06 を確認する。
原典に例題・印刷値はないため、§26.9 の連続監視の解析値を基準にし、式は手計算の小例で固定する。

| 要求 | 原典・実装・検証の位置 |
|---|---|
| BT01 素朴な方法 | vol06 §12.1。バリア以上のノードで価値を0にする。CRR 二項と §21.4 の三項を同じ20–300段で比較し、のこぎり状の振れを示す。原典は三項のほうがよいとするが、この例では平均絶対誤差が三項0.205ドル・二項0.121ドルで、同じ段数では素朴な三項のほうが悪い。 |
| BT02 外側バリア | vol06 §12.2。内側・外側バリアの定義（Figure 27.4）。素朴な三項の価格は外側バリアを真とした価格と一致する。位置の差は0から1間隔の間にあり、縮むのは上限だけ。25・100・400段では外側バリアが123.10ドルに留まり、1600段で121.51ドル、3200段で120.17ドルになる。 |
| BT03 補間 | vol06 §12.3。内側・外側を真とした二価格を、バリアの株価で線形に補間する（原典は補間の変数を指定しない）。 |
| BT04 バリア上のノード | vol06 §12.4。$\ln u=(\ln H-\ln S_0)/N$、$N=\operatorname{int}[(\ln H-\ln S_0)/(\sigma\sqrt{3\Delta t})+0.5]$ と三本の確率。100段で $N=4$、$\ln u=0.04558$。平均は正確に一致する。二次のモーメントは $\sigma^2\Delta t$ に置かれ、真の値 $\sigma^2\Delta t+(\mu\Delta t)^2$ とは $\Delta t$ の一次まで一致する（分散も同じ）。$N$ は Hull の規則で最も近い整数に丸める。 |
| BT05 誤差の分解 | vol06 §12.4。素朴な三項の誤差を外側バリアの位置の差と格子の誤差に分ける。バリア上のノードの誤差は $N$ が変わる所で段差を持ち、倍々に取った400–3200段の包絡線の次数は1.005。 |
| BT06 近いバリアと限界 | vol06 §12.5–12.6。$x<0.5$ で段がなく、$N=1$ かつ $H<S_0e^{\sigma\sqrt{\Delta t}}$ で $p_m<0$。公開関数はどちらも拒否する。adaptive mesh は説明のみ。 |

**独立参照。** `scripts/build_barrier_tree_reference.py` は `hullkit` を使わず、(1) §26.9 の up-and-out コールの式、(2) バリアを吸収境界にした Crank–Nicolson PDE（Rannacher 開始）、(3) 同じ格子で生き残る確率質量を前向きに進める価格を計算する。(3) は主例に加え、down-and-out コール、up-and-out プット、down-and-out プット（いずれも q=3%）を50・100・200段で持つ。公開実装 `hullkit.barrier_tree` は価値を後ろ向きに戻す。`numerical-check.json` では、解析値0.432155ドルと PDE の差が1.9e-6ドル、`hullkit.exotics` の式との差は0、289通りの段数と追加9ケースでの前向き・後ろ向きの差は9.4e-14ドル以下、3200段の誤差はバリア上−0.00106ドル・補間−0.00051ドル。

**監視の扱い。** 三項・二項の株価は1段で1レベルしか動かないので、外側のレベルを飛び越えられない。各段でノードを判定すれば、格子の上では連続監視と同じになる。したがって離散監視の行き過ぎ（BGK 補正の $0.5826\sigma\sqrt{\Delta t}$）は起きない。100・400・1600段で、バリア上のツリーと連続監視の差は−0.028・−0.009・−0.002ドル、同じ回数の離散監視（BGK 近似）と連続監視の差は+0.167・+0.079・+0.038ドルで、符号も縮み方も違う。BGK はこのツリーの誤差の分解には使わない。下調べの時点では離散監視の MC と BGK で監視の誤差を分ける案だったが、この性質により外側バリアでの解析値を使う分解に替えた。

**独立レビュー（2026-09-28）。** 別エージェントが原典・実装・検証・図を点検した。P1 1件（§12.1 の「三項のほうがよい」がこの例のデータと逆）、P2 2件（検証が up-and-out コール・q=0 の1ケースだけで、プット・down 方向・配当の変異4種を見逃した。16倍で縮まないという記述が偶然の一致に依存）、P3 7件（モーメント一致の書き方、包絡線、N の丸め規則、down 方向でバリア＝初期価格を受け付ける、近接図の縦線の説明、練習問題2、BGK の理由と数値）。すべて修正し、変異7種がユニットテストと数値検証の両方で検出されることを確かめた。

**可視化と検査。** ノード配置（Figure 27.4・27.5）、20–300段の価格、誤差の分解、近いバリアでの中央の確率の4図を Book と portal で共用する。Browser 検査は4図×2画面×2幅（1440/1000px）、数値とラベルのはみ出し、意図的な数値改変の拒否を確認する。ノートブック検査は M14 基点の §12 以外94セルを後続2見出しの番号変更を除いて保持し、保存出力を新規4図と既存20図に照合する。

**適用範囲。** 定数の連続金利・配当利回り・ボラティリティ、水平な単一バリア、欧州型ノックアウトのコール・プットを扱う。ノックインは in+out=バニラで求められるがツリーは実装しない。米国型、二重バリア、時間で動くバリア、adaptive mesh、補間の変数の比較、市場での較正やヘッジは対象外。
