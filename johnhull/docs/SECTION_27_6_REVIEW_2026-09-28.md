# §27.6 Barrier Options：原典照合と受入範囲

日付：2026-09-28。対象は Hull 11e Global Edition pp.656–658、Figures 27.4–27.5。
§27.5 と同じ5軸（説明、実装、独立検証、可視化、実画面）で BT01–BT06 を確認する。
原典に例題・印刷値はないため、§26.9 の連続監視の解析値を基準にし、式は手計算の小例で固定する。

| 要求 | 原典・実装・検証の位置 |
|---|---|
| BT01 素朴な方法 | vol06 §12.1。バリア以上のノードで価値を0にする。CRR 二項と §21.4 の三項を20–300段で比較し、のこぎり状の振れを示す。 |
| BT02 外側バリア | vol06 §12.2。内側・外側バリアの定義（Figure 27.4）。素朴な三項の価格は外側バリアを真とした価格と一致し、25・100・400段で外側バリアが123.10ドルに留まる例を示す。 |
| BT03 補間 | vol06 §12.3。内側・外側を真とした二価格を、バリアの株価で線形に補間する（原典は補間の変数を指定しない）。 |
| BT04 バリア上のノード | vol06 §12.4。$\ln u=(\ln H-\ln S_0)/N$、$N=\operatorname{int}[(\ln H-\ln S_0)/(\sigma\sqrt{3\Delta t})+0.5]$ と三本の確率。100段で $N=4$、$\ln u=0.04558$。平均と二次の素のモーメントは正確に一致し、分散は $\Delta t$ の一次まで一致する。 |
| BT05 誤差の分解 | vol06 §12.4。素朴な三項の誤差を外側バリアの位置の差と格子の誤差に分ける。バリア上のノードの誤差は400–3200段で次数1.005。 |
| BT06 近いバリアと限界 | vol06 §12.5–12.6。$x<0.5$ で段がなく、$N=1$ かつ $H<S_0e^{\sigma\sqrt{\Delta t}}$ で $p_m<0$。公開関数はどちらも拒否する。adaptive mesh は説明のみ。 |

**独立参照。** `scripts/build_barrier_tree_reference.py` は `hullkit` を使わず、(1) §26.9 の up-and-out コールの式、(2) バリアを吸収境界にした Crank–Nicolson PDE（Rannacher 開始）、(3) 同じ格子で生き残る確率質量を前向きに進める価格を計算する。公開実装 `hullkit.barrier_tree` は価値を後ろ向きに戻す。`numerical-check.json` では、解析値0.432155ドルと PDE の差が1.9e-6ドル、`hullkit.exotics` の式との差は0、289通りの段数での前向き・後ろ向きの差は6.6e-14ドル以下、3200段の誤差はバリア上−0.00106ドル・補間−0.00051ドル。

**監視の扱い。** 三項・二項の株価は1段で1レベルしか動かないので、外側のレベルを飛び越えられない。各段でノードを判定すれば、格子の上では連続監視と同じになる。したがって週次などの離散監視の補正（BGK）は、このツリーの誤差の分解には使わない。下調べの時点では離散監視の MC と BGK で監視の誤差を分ける案だったが、この性質により外側バリアでの解析値を使う分解に替えた。

**可視化と検査。** ノード配置（Figure 27.4・27.5）、20–300段の価格、誤差の分解、近いバリアでの中央の確率の4図を Book と portal で共用する。Browser 検査は4図×2画面×2幅（1440/1000px）、数値とラベルのはみ出し、意図的な数値改変の拒否を確認する。ノートブック検査は M14 基点の §12 以外94セルを後続2見出しの番号変更を除いて保持し、保存出力を新規4図と既存20図に照合する。

**適用範囲。** 定数の連続金利・配当利回り・ボラティリティ、水平な単一バリア、欧州型ノックアウトのコール・プットを扱う。ノックインは in+out=バニラで求められるがツリーは実装しない。米国型、二重バリア、時間で動くバリア、adaptive mesh、補間の変数の比較、市場での較正やヘッジは対象外。
