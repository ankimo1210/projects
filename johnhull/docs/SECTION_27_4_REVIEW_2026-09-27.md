# §27.4 Convertible Bonds：原典照合と受入範囲

日付：2026-09-27。対象は Hull 11e Global Edition pp.650–653、Example 27.1・Figure 27.2。
§27.3 と同じ5軸（説明、実装、独立検証、可視化、実画面）で CB01–CB06 を確認する。

| 要求 | 原典・実装・検証の位置 |
|---|---|
| CB01 契約と権利の順序 | vol06 §10.1。転換価値、継続価値、発行体コール、コール後の再転換を明示。 |
| CB02 デフォルト付き株価3枝 | vol06 §10.2。$p_u+p_d=e^{-\lambda\Delta t}$、$p_uu+p_dd=e^{(r-q)\Delta t}$。負の枝確率を拒否。 |
| CB03 満期と後退帰納 | vol06 §10.3。原典10節点と初期価格107.44ドルを固定。回収40ドル、利払いの生存条件を明示。 |
| CB04 コール後の再転換 | vol06 §10.4。B の継続119.54→転換116.18、D の135.08→134.99、E は継続106.78。 |
| CB05 信用・回収・利払い | vol06 §10.5。ハザード率、回収額の20シナリオの一部、利付債の独立キャッシュフロー恒等式。 |
| CB06 収束と限界 | vol06 §10.6。3–96段の値、状態独立・一定ハザード仮定、Book/portal共有4図。 |

**独立参照。** `scripts/build_convertible_bond_reference.py` は `hullkit` を使わず、
節点をメモ化再帰で評価する。原典の印刷値10個と B・D・E の継続価値を照合する。
公開実装 `hullkit.convertible_bond` は配列の後退帰納を使う。
`numerical-check.json` では10節点・20シナリオの最大差 1.3e-11 ドル、
利付債の閉形式キャッシュフロー差 1.5e-14 ドル、無信用・無コールの
BSM分解との400段差 0.0065 ドルを上限内で確認した。3段の初期値は
107.4418504343806ドルで、原典の107.44ドルへ丸められる。

**可視化と検査。** 保存した参照値から3段ツリー、B・D・E の判断、
ハザード率と回収額の感応度、格子収束の4図を生成し、Bookとportalで共用する。
ツリー図の縦配置は価格軸ではなく枝位置とし、各節点に株価・社債価値を表示する。
Browser検査は4図×2画面×2幅（1440/1000px）、数値とラベルのはみ出し、
意図的な数値改変拒否を確認する。ノートブック検査は基点M12の節外セルを
後続2見出しの番号変更を除いて保持し、保存出力を新規4図と既存12図に照合する。

**適用範囲。** 一定の連続金利・配当、一定の生存条件付きボラティリティ・
危険中立ハザード率・固定回収額、一定の転換株数とコール価格、常時転換可能な
契約を扱う。期末利息は生存していればその期末の権利判断前に支払う仮定。
原典が触れる時変条件、株価依存ハザード、条件付きコール、市場較正、
実際の転換社債の清算条項はこの例では評価しない。
