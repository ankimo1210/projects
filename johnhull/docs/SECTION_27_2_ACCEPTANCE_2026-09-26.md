# §27.2 Stochastic Volatility Models：受入記録

**判定：accepted。** Hull 11e Global Edition pp.646–649の時間依存ボラ、Hull–Whiteの混合公式、相関とHeston、
SABRを、要求SV01–SV06の説明・実装・独立検証・図・実画面で照合した。日付：2026-09-26。
要求と実測の詳細は[レビュー](SECTION_27_2_REVIEW_2026-09-26.md)、実行記録は[検証ディレクトリ](validation/section-27-2/)と
[M11統合記録](validation/section-27-2/m11-check.json)にある。

- 式27.1の例（20%→30%）の平均分散率0.065・BSMボラ25.5%を再現。平均分散のBSMは独立PDEと最大1.58e-4通貨で一致し、
  単純平均25%はATMで0.187通貨ずれる。
- Hull–Whiteの混合公式（厳密CIR遷移の条件付きMC）は独立Gil-Pelaez積分の26価格と最大0.31 SEで一致。
  同じ期待分散のBSMはK=88–128を過大評価し、両裾を過小評価する。ρ=0のスマイルは対数フォワード・マネネスで対称（1.8e-15）。
- 公開HestonのCOS価格は独立Gil-Pelaezの78価格と最大1.6e-13通貨で一致。ρ<0で右下がり、ρ>0で右上がりのスキュー。
- `hullkit.sabr.sabr_implied_vol`は原典のSABR式の独立転記と216値で3.1e-16以内。Euler MCとの差は7行使価格で最大6.5e-4（1.49 SE）。
  ρが傾き、νが曲がりを決めることを数値で確認した。
- vol06に§8.1–8.6と共有4図を追加。§8以外の46セルは基点と一致（見出し番号の変更2件のみ）、4種類の改変を拒否。
  ChromiumでBook/portal×1440/1000pxの20状態・20画像を照合し、Book MathJaxエラー0、portal外部要求0。
- 共有ファイルの変更を受け、§26.9–§26.17と§27.1の10節の個別テストと両画面をM11の再検証記録として保存した。過去の記録は変更していない。

受入は教材と数値例の整合・再現性を示す。SABRの近似誤差の上界、rough volatilityとGARCHの数値検証、市場較正、
ヘッジ成績は承認対象に含まれない。
