## §25.1 Credit Default Swaps

出典: Hull 11e Global Edition pp.588–591。

CDSは参照企業の信用事由に対する保護で、買い手はデフォルトまでプレミアムを払い、信用事由時に額面と回収価格の差を受け取る。現物決済・現金決済、最後の経過分、CTD債の選択を区別する。債券と保護買いの組合せからCDSと債券スプレッドが近くなる理由とbasisを説明する。

### 要点の読み方

CDS buyerは定期premiumを払い、reference entityのcredit eventで保護支払を受ける。年90bp・元本1億なら四半期22.5bp=225000。回収35%の損失支払は6500万、defaultまで2か月の経過premiumは概算150000。250/260bpは年率2.5/2.6%である。

出典: Hull 11e Global Edition pp.596–596。

## §25.7 Total Return Swaps

出典: Hull 11e Global Edition pp.597–598。

債券のクーポンと値上がり/値下がりを含む総収益を、変動金利＋スプレッドと交換する。原資産を保有するpayerは信用リスクをreceiverへ移せ、receiverは資金を借りて原資産を保有した形に近い経済効果を得る。所有権を保つpayerにも、原資産が下落した時のreceiver破綻リスクが残る。

### 要点の読み方

TRSは原資産のcouponと価格変化を渡し、floatingとspreadを受け取る。本文の元本1億・5年・floating+25bpなら価格が10%上がるとtotal return payerからreceiverへ1000万、15%下がるとreceiverからpayerへ1500万となる。couponは金額、financingは元本と年分数から計算する。

保有権を残すownerと、経済的な収益・信用riskを受け取るreceiverを区別する。借入で原資産を購入するCFとの照合は固定initial notionalの例であり、periodic resetやcalendar規約は別条件。fair spreadや信用調整に必要な市場入力は原典にない。

## §25.11 Alternatives to the Standard Market Model

出典: Hull 11e Global Edition pp.608–610。

同質性・Gaussian・固定回収率/負荷・静的な環境という仮定を順に緩める。不均質では件数分布を二項式で計算できず数値再帰が必要。double-t、因子依存回収率/相関、市場から逆算するimplied copula、資産・強度・総損失を動かす3種の動的モデルを比較する。

### 要点の読み方

異質poolのASBは因子条件付きのPoisson-binomial再帰で件数分布を作る。同質ならbinomialへ戻り、確率和1と平均件数ΣPDを保つ。double-tは因子と個別成分に自由度4の独立tを使い、各varianceを1へ合わせる。共通scaleを持つ一般的な多変量t-copulaと同じではない。

factorに依存する回収とloadingを変えたら、目標PDへ再較正する。implied copulaは固定hazard gridの非負weights、和1を静的legへfitする例で、quoteが不足するとweightsは一意でない。本文に結果の印刷priceはないため、独立状態列挙・潜在tのMC・既知weights回復による合成検証である。全copula、著者の市場parameter、CR-11の動的研究は今回の数値受入に含めない。
