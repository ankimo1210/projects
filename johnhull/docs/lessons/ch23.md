## §23.2 The Exponentially Weighted Moving Average Model

出典: Hull 11e Global Edition pp.544–546。

数値（例題あり）。pp544–546。EWMAは前の分散と最新の二乗returnの加重平均で、過去への展開には初期分散λ^m項が残る。λが小さいほど新しいショックへの反応が速い。

### 要点の読み方

EWMAは $v_n=\lambda v_{n-1}+(1-\lambda)u_{n-1}^2$。展開すると過去の二乗returnへの指数重みと $\lambda^m v_{n-m}$ の初期項が残る。initial varianceを指定し、観測m点に対して最初の予測と翌日予測を含むm+1値を返す。当日returnを同日の予測に入れない。

λ=.9、昨日のSD1%、return2%ならvariance.00013、翌日SD1.140175%である。1994年RiskMetricsのλ=.94は歴史上の設定であり、すべての系列の最適値ではない。λは記憶の長さと反応の速さを変える。

## §23.3 The Garch

出典: Hull 11e Global Edition pp.546–547。

数値（例題あり）。pp546–547。ω+αu²+βvに長期分散VL=ω/(1−α−β)を対応させる。観測二乗returnの過去重みはαβ^(i−1)、予測の平均回帰を決めるのはα+βであり、この2つを分ける。

### 要点の読み方

GARCH(1,1)は $v_n=\omega+\alpha u_{n-1}^2+\beta v_{n-1}$。定常条件では $\gamma=1-\alpha-\beta,V_L=\omega/\gamma$。ω=.000002/α=.13/β=.86ならγ=.01、長期variance.0002、日次SD1.414214%。昨日SD1.6%、return−1%なら翌日variance.00023516、SD1.5335%。

過去観測の重みを減衰させるβと、将来予測の平均回帰を決めるα+βを区別する。α+βが1以上なら有限の定常長期varianceを仮定しない。本文の連続時間対応a=1−α−β、ξ=α√2は近似であり、厳密な時間単位換算ではない。

## §23.4 Choosing between the Models

出典: Hull 11e Global Edition pp.547–548。

定性。pp547–548。GARCHの長期分散への回帰とEWMAの追随性を比較する。原典は不適切な負のωが推定される場合のEWMAへの切替を述べるが、既存推定器は最初から正値制約を置いている。

### 要点の読み方

EWMAでは長期varianceへの平均回帰を入れず、GARCHでは定常な場合に長期値へ近づく。どちらが適切かは、系列、推定期間、予測目的による。係数の解釈と実際の予測性能を分けて読む。

原典の負ω等の不適切解は、制約を課さずにfitした場合の議論である。最初から非負係数と定常条件を課したfitにも同じ解が現れるという意味ではない。この節はモデル選択の説明を確認し、市場性能の承認とはしない。

## §23.6 Using Garch

出典: Hull 11e Global Edition pp.553–556。

数値（例題あり）。pp553–556。将来分散の期待値をVL+(α+β)^t(v0−VL)で予測し、期間平均分散を積分してoption maturity別の年率volへ換算する。spot varianceの変化が長い満期のIVへ及ぼす影響は弱まる。

### 要点の読み方

p=α+βなら $E[v_{n+t}]=V_L+p^t(v_n-V_L)$。連続補間は $a=-\log p$、期間平均varianceは $\bar v(T)=V_L+(v_n-V_L)(1-e^{-aT})/(aT)$。年率volは $\sqrt{252\bar v(T)}$ であり、平均SD $E[\sqrt v]$ とは別である。α=β=0では当日が初期値、正のhorizonはωという有効な定数予測となる。
