# §27.6 Barrier Options：受入記録

**判定：accepted。** Hull 11e Global Edition pp.656–658 のツリーによるバリア・オプション評価、Figures 27.4–27.5 を、要求 BT01–BT06 の説明・実装・独立検証・図・実画面で照合した。日付：2026-09-28。要求の対応は[レビュー](SECTION_27_6_REVIEW_2026-09-28.md)、機械可読の統合結果は[M15記録](validation/section-27-6/m15-check.json)を参照。

- 原典に印刷値がないため、§26.9 の up-and-out コールの解析値0.432155ドルを基準にした。`hullkit` を使わない Crank–Nicolson PDE との差は1.9e-6ドル。同じ格子で生存確率を前向きに進める独立価格と `hullkit.barrier_tree` の後ろ向き価格の差は、主例289通りの段数と down/put・配当3%の追加9ケースで9.4e-14ドル以下。
- 素朴な三項は外側バリアを真とした価格に一致し、20–300段の平均絶対誤差は三項0.205ドル・二項0.121ドル（同じ段数では三項のほうが悪い）。バリア上のノードの包絡線の次数は1.005、3200段の誤差はバリア上−0.00106ドル・補間−0.00051ドル。近いバリアは段がない場合と $p_m<0$ の場合を拒否する。
- vol06 に §12.1–12.6 と共有4図を追加。§12以外の94セルはM14基点から後続2見出しの番号変更のみ。4改変を拒否した。Chromium 145 で Book/portal×1440/1000px の16状態・16画像を確認し、Book の数式250個のエラーは0。
- 独立レビューの P1 1件・P2 2件・P3 7件をすべて修正し、レビューの変異7種がユニットテストと数値検証の両方で検出されることを確かめた。
- §26.9–§26.17、§27.1–§27.5 の14節を [D1 方針](EVIDENCE_POLICY.md)の本運用として再検査した（個別テスト計1,377件）。vol10 の9節は M15 途中の再描画を基点に reused（新規保存0バイト）、vol06 の5節は §12 の追加で redrawn（成果物ストアへ2,338,282バイト）。§27.3 は Playwright 1.62.1→1.56.0 の実行環境差で redrawn になり、16画像はすべて基点とバイト一致した。
