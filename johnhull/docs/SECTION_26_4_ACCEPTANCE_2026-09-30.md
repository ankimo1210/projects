# §26.4 ギャップ・オプション：受入記録

**判定：accepted。** 日付：2026-09-30。Hull 11e Global Edition p.617 の §26.4（式26.1・26.2、例題26.1）について、GP01–GP06 の説明・実装・独立検証・図・実画面を照合した。要求の対応は[レビュー](SECTION_26_4_REVIEW_2026-09-30.md)、機械可読の統合結果は[M21統合記録](validation/section-26-4/m21-check.json)を参照。

公開 API `hullkit.gap_options.gap_option` を追加した。入力を検証し、価格を「行使価格 $K_2$ の通常のオプション＋符号付きのキャッシュ・オア・ナッシング」に分けて返す。価格そのものは既存の `hullkit.exotics.gap_call`/`gap_put`（式26.1・26.2）で出す。

**原典の数値（例題26.1）**

- $S_0=500{,}000$、$\sigma=20\%$、$r=5\%$、$q=0$、$T=1$。行使価格400,000の通常のプットは 3,435.95（印刷 3,436）、$K_1=400{,}000$・$K_2=350{,}000$ のギャップ・プットは 1,895.69（印刷 1,896）、減少は 44.83%（印刷「約45%」）。
- 契約者の価値（行使価格350,000の通常のプット）630.79 と、移転費用の現在価値 1,264.90 への分解は原典にない補足である。和は保険会社の費用に $10^{-9}$ 以内で一致する。

**独立参照（`hullkit` を使わない）**

- 式26.1・26.2 を `math.erfc` で自前実装し、対数正規密度の Gauss–Legendre 求積（トリガーを区間の端点に置く）と38ケースで照合した。差は絶対 $5\times10^{-12}$ 以内。
- 10ケースは、ケースごとに別シードの反対変量モンテカルロ（$2^{19}$ 組）でも確かめた。$\lvert z\rvert$ は最大1.58。
- 公開 API と保存参照の相対差は $4.2\times10^{-15}$ 以下。価値ゼロの $K_1$（トリガー条件付きの $S_T$ の平均）は求積と一致した。
- 保存データの改変5件に加え、公開 API 側の改変3件（$d$ を $K_1$ で計算、プットの $K_1$・$K_2$ の入れ替え、相対 $10^{-9}$ のずれ）も拒否した。
