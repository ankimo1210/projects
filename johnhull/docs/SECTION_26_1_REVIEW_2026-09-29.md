# §26.1 Packages：原典照合と受入範囲

日付：2026-09-29。対象は Hull 11e Global Edition pp.614–615 と §17.2（zero-cost collar）。
§27.8 と同じ5軸（説明、実装、独立検証、可視化、実画面）で PK01–PK06 を確認する。
原典が数値を挙げるのは §17.2 の例（$S_0=1.32$、$r=r_f=2\%$、$\sigma=14\%$、$T=0.25$、$K_1=1.3000$ に対して $K_2=1.3414$、費用ゼロ、$p(1.30)=0.0273$）だけである。

**独立参照。** `scripts/build_packages_reference.py` は `hullkit` を使わない。

1. Black–Scholes は `math.erfc` で自前実装し（`hullkit.bsm` との差 $1.4\times10^{-14}$）、$K_2$ は二分法で求める（公開関数との相対差 $5\times10^{-15}$）。
2. 現在価値・損失確率は、対数正規分布の求積（折れ点で区間を分け、$\pm16\sigma$）で求める。36本のレンジ先渡しの正味現在価値は $2.5\times10^{-14}$ 以内で0。
3. 局所傾きの極限は $N(\sigma\sqrt T/2)/N(-\sigma\sqrt T/2)$ を独立に導いて突き合わせる。
4. モンテカルロはシード20260926、$2^{19}$ 組の反対変量、許容は4標準誤差。

**可視化と検査。** Book と portal で次の4図を共用する。

- レンジ先渡しの満期損益
- $K_1$ と $K_2$ の関係（原典の点と $K_1=F$ の点つき）
- 後払いコール（ブレークフォワード）
- 期待損失PV・損失確率・最大損失（買う側、最大損失は対数目盛）

Browser 検査は4図×2画面×2幅（1440/1000px）で16状態・16スクリーンショット、数値の改変が拒否されることを確認する。ノートブックは136セル（§4.8 の11セルと、それ以外の125セル）で、負の対照6件を拒否する。

**独立レビュー。** 実装の外から原典・コード・本文・図・検査を読み直したレビューで、P1 は1件、P2 は4件、P3 は5件の指摘があった。原典の数値（§17.2）は独自に再現され、`packages.py` の計算に誤りはなかった。指摘はすべて対応した。

P1 の1件：

- **不等号の向き。** §4.8.2 の「$c(K_2)=p(K_1)>p(F)=c(F)$」は向きが逆だった（$c$ は行使価格の減少関数なので、この式だと $K_2<F$ になる）。$<$ に直し、正しい式があり逆向きの式がないことを本文の検査に加えた。

P2 の4件：

- **入力検証。** 入力の検査が $S_0$・$\sigma$・$T$ だけで、$r$・$q$ は明示的に検査していなかった。$r=800$（$e^{rT}$ が桁あふれ）は3関数とも `OverflowError`、$r=\infty$ は `deferred_option` が検査なしに価格を返した。$r$・$q$ が NaN や $q=-\infty$ の入力が `ValueError` になっていたのは、下流の計算が偶然拒否していたためである。`deferred_amount` は $r$・$T$ を検証していなかった。$r$・$q$・$T$ の有限性と、指数関数の桁あふれを、入口で `ValueError` にした。
- **下限の説明。** $K_1$ が $F$ より極端に低いと、プットの価値が0に丸められ、探索失敗を意味する `ArithmeticError`（200回の倍化後）になっていた。§17.2 の市場で $K_1=0.01$ が該当する。丸めを名指しする `ValueError` にした（$K_1=0.3F$ は従来どおり解ける）。検証器の拒否件数は5から10に増えた。
- **リスク表の所在。** MODEL_INDEX と本文が、リスク表をライブラリが計算するかのように読めた。表は保存した独立参照にだけあり、hullkit の関数にはないと明記した。ライブラリの API は増やしていない。
- **買う側の明示。** 4.8.5 の数値と図が、どちらの側の数値か書いていなかった。本文と図のタイトル・注記に「買う側（ロング）」を入れ、売る側は損益の符号が反転して損失確率と最大損失が別の値になると書いた。

P3 の5件：

- 損失確率と最大損失の図：最大損失の対数目盛はパネルの題に書いてあるので維持した。
- $K_1=F$ の白抜き丸が原典の点に隠れていたので、マーカーを大きくした。
- 図の注記の $A$ は 0.03686 と書いていた。値は 0.0368547 なので 0.03685 に直した。
- 検査の中に、常に真になる主張（ブレークフォワードの期待損失が中間）があった。レンジ先渡し < ブレークフォワード < 先渡しの実際の比較に直した。
- 「最も知られた例」は原典に根拠がないので「代表的な例」に和らげた。

**適用範囲。** BSM の欧州オプションの組み合わせで、$r,q,\sigma$ は定数。損失確率はリスク中立の値で、現実の確率ではない。取引コスト、ビッドアスク、後払いの信用リスク、離散の行使価格、任意の市場での $K_2$ の水準や損失確率の大小関係は対象外。リスク比較は $\sigma=14\%$・$T=0.25$ の1市場の例である。
