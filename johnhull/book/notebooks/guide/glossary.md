(guide-glossary)=
# 用語と記号：同じ言葉で章をつなぐ

この用語集は、式を読むときに戻ってくる場所です。まず短い意味を確認し、理由や計算は各章のガイドと [モデル地図](models.md) で読みます。{ref}`章どうしのつながり <chapter-connections>` も、同じ言葉を受け渡す順序で並べています。

訳語は既存の Book とユーザーの選択に合わせました。二項ツリー、ノード、ポートフォリオ、無リスク金利、デフォルト、インセンティブ、グリークスを使います。「無次元」は単位を持たないという意味です。記号は全章共通の辞書として固定せず、同じ文字を別の意味に使う箇所を下の表で区別します。

(terms-contracts)=
## 契約と市場：誰が、いつ、何を払うか

| 用語（English・略語） | このガイドでの意味と読み分け | 主に読む章 |
|---|---|---|
| デリバティブ（derivative） | 原資産などの状態によって受払いが決まる契約。現物そのものと契約の価値を分ける | Ch1 |
| 原資産（underlying asset） | 契約の支払いの基準になる株式、商品、金利など | Ch1・10 |
| 先渡（forward）／先物（futures） | 将来の売買価格を決める契約。先物には日々の値洗いがあり、先渡と資金の受払時点が異なる | Ch2・5・6 |
| ロング（long）／ショート（short） | 契約の買い手側／売り手側。現物を保有するか借りて売るかとは、契約ごとに分けて読む | Ch1・2 |
| 証拠金（margin）／値洗い（marking to market） | 損失への備えとして差し入れる担保／評価の変化に応じた精算 | Ch2 |
| 中央清算機関（central counterparty、CCP） | 取引当事者の間に入り、清算と破綻時の負担を取り決める機関 | Ch2・8・9 |
| ベーシス（basis）／ベーシス・リスク（basis risk） | 現物と先物などの価格差／両者の変化がそろわずヘッジに残るリスク | Ch3 |
| ヘッジ（hedge） | 別の取引を組み合わせ、特定のリスクを減らすこと。すべてのリスクの消滅とは限らない | Ch3・13・19 |
| ポートフォリオ（portfolio） | 複数の資産・契約を合わせて持つもの | Ch3・13・22 |
| スワップ（swap） | 契約期間中の受払列を交換する契約。想定元本を必ず交換するとは限らない | Ch7・34 |
| コール（call）／プット（put） | 決めた条件で原資産を買う権利／売る権利 | Ch10–13 |
| 権利行使（exercise）／権利行使価格（strike price） | 契約の権利を使うこと／その売買に用いる価格 | Ch10・11 |
| ヨーロピアン（European）／アメリカン（American） | 満期だけ行使できる契約／満期までの途中にも行使できる契約。地域名ではない | Ch10・13 |
| ペイオフ（payoff）／損益（profit and loss、P&L） | 契約から生じる受払額／購入代金や資金調達なども含めた損益。両者は同じではない | Ch10–12 |
| スプレッド（spread） | 二つの金利や価格の差。または異なる行使価格等のオプションを組み合わせる戦略。文脈を確かめる | Ch8・12 |
| 従業員ストック・オプション（employee stock option、ESO） | 従業員への報酬として付与する権利。譲渡や行使の制約が市場のオプションと異なる | Ch16 |

(terms-pricing)=
## 評価と確率：予測と価格を分ける

| 用語（English・略語） | このガイドでの意味と読み分け | 主に読む章 |
|---|---|---|
| 裁定（arbitrage）／無裁定（no arbitrage） | 元手や損失リスクなしに利益を得る取引／その機会がないという価格間の条件 | Ch5・11・13 |
| 複製（replication） | 対象の契約と同じ受払いを別の取引で作ること | Ch11・13・15 |
| 無リスク金利（risk-free rate） | 評価上、確実な受払いを借入れ・運用する金利。どの曲線・通貨かも指定する | Ch4・13・29 |
| 連続複利（continuous compounding） | 利息を組み入れる間隔を限りなく短くした複利。年率と期間の単位を合わせる | Ch4・13 |
| 割引因子（discount factor） | 将来の金額を現在価値へ換算する係数 | Ch4・28–34 |
| リスク中立世界（risk-neutral world）／リスク中立確率 | 複製や無裁定と整合するように重みを付けた評価の世界と、その重み。実際の発生頻度の予測とは分ける | Ch13・15・28 |
| ニュメレール（numeraire） | 価格の比を測る基準の資産。その選び方に対応して評価の確率も変わる | Ch28・29 |
| 二項ツリー（binomial tree）／ノード（node） | 各期間の状態を上下に分ける格子／その時点と状態を表す点 | [Ch13](ch13.md)・21 |
| 後退帰納（backward induction） | 終点の支払いから現在へ戻り、各ノードの価値を決める手順 | Ch13・21 |
| 継続価値（continuation value） | 今すぐ行使せず、次の時点から先の選択を続ける価値 | Ch13・27 |
| 幾何ブラウン運動（geometric Brownian motion、GBM） | 価格に比例したドリフトとランダムな変動を持つ、連続時間の価格過程 | Ch14・15 |
| ウィーナー過程（Wiener process） | 独立な正規増分を持ち、増分の分散が経過時間に比例する過程 | Ch14 |
| 伊藤の補題（Itô's lemma） | ランダムな変動を持つ変数の関数が、どのように変わるかを求める規則 | Ch14・28 |
| マルチンゲール（martingale） | 現在の情報で見た将来値の条件付き平均が現在値になる過程。確率の世界と基準資産の指定が必要 | Ch28 |
| ギルサノフの定理（Girsanov's theorem） | 条件のもとで確率の重みを変え、ブラウン運動のドリフトを移す定理 | Ch13・28 |

(terms-volatility)=
## 変動と計算：何を近似しているか

| 用語（English・略語） | このガイドでの意味と読み分け | 主に読む章 |
|---|---|---|
| ボラティリティ（volatility） | 収益率等のばらつきの尺度。日次か年率か、正規型か対数正規型かを添える | Ch15・20・23 |
| インプライド・ボラティリティ（implied volatility、IV） | 市場価格を所定の価格式へ入れて逆算するボラティリティ | Ch20 |
| スマイル／サーフェス（smile／surface） | 行使価格による IV の形／満期も合わせた面 | Ch20・27 |
| 局所ボラティリティ（local volatility） | 現在の価格と時刻の関数として与えるボラティリティ | Ch27 |
| 確率ボラティリティ（stochastic volatility） | ボラティリティや分散自体もランダムに変動するモデル | Ch27 |
| グリークス（Greeks） | 価格を株価・ボラティリティ・金利などで動かしたときの感応度の総称 | Ch19 |
| デルタ（delta）／ガンマ（gamma） | 原資産価格に対する価格の一階／二階の感応度 | Ch13・19 |
| ベガ（vega）／セータ（theta）／ロー（rho） | ボラティリティ／時間／金利に対する感応度。単位と符号の慣行を確認する | Ch19 |
| モンテカルロ法（Monte Carlo、MC） | ランダムな標本で期待値などを推定する方法。離散化誤差と標本誤差を分ける | Ch21・27 |
| 有限差分法（finite difference、FD）／偏微分方程式（partial differential equation、PDE） | 価格等の格子上で微分を差に置き換える方法／時間と状態に対する価格の関係式 | Ch21 |
| 最小二乗モンテカルロ法（least-squares Monte Carlo、LSM） | 回帰で継続価値を推定し、行使を判断する方法 | Ch27 |
| コントロール・バリアット（control variate） | 平均が分かる別の量との差を使い、推定のばらつきを減らす方法 | Ch21 |
| 重要度サンプリング（importance sampling）／準モンテカルロ法（quasi-Monte Carlo、QMC） | 標本の取り方を変えて重みを補正する方法／低食い違い点列で積分する方法 | Ch21 |
| 較正（calibration）／推定（estimation） | 価格等へモデルを合わせること／観測データからパラメーター等を求めること。どの入力・目的かを明示する | Ch23・27・32 |

(terms-credit)=
## リスクと信用：損失額・確率・資金を分ける

| 用語（English・略語） | このガイドでの意味と読み分け | 主に読む章 |
|---|---|---|
| デフォルト（債務不履行、default） | 契約上必要な支払いを果たせない状態 | Ch8・24・25 |
| 証券化（securitization）／トランシェ（tranche） | 資産の受払いを証券へ組み替えること／受払順位で区切った層 | [Ch8](ch08.md) |
| 資産担保証券（asset-backed security、ABS）／住宅ローン担保証券（mortgage-backed security、MBS） | 資産からの支払いを裏付けとする証券／そのうち住宅ローンを裏付けとするもの | Ch8 |
| 債務担保証券（collateralized debt obligation、CDO） | 債務を裏付けとして層を設けた商品。ABS の層を集めた ABS CDO と元の ABS を区別する | Ch8・25 |
| 特別目的事業体（special purpose vehicle、SPV） | 証券化の資産保有等のために設ける事業体 | Ch8 |
| シニア／メザニン／エクイティ（senior／mezzanine／equity） | 優先／中間／最劣後の層。この文脈のエクイティは企業の普通株式ではない | Ch8・25 |
| ウォーターフォール（waterfall） | 契約で決めた受払い・損失配分の順序 | Ch8 |
| 超過担保（overcollateralization）／超過スプレッド（excess spread） | 証券の元本を超える担保／資産収入から証券への利払い等を引いた余剰 | Ch8 |
| 組成・販売型（originate-to-distribute、OTD） | ローンを組成し、保有を続けず販売する仕組み | Ch8 |
| インセンティブ（incentive）／エージェンシー・コスト（agency costs） | 行動を促す動機／依頼する側と行動する側の利害のずれから生じる問題 | Ch8・37 |
| ネガティブ・エクイティ（negative equity） | 住宅等の資産価値が残債を下回る状態 | Ch8 |
| バリュー・アット・リスク（value at risk、VaR）／期待ショートフォール（expected shortfall、ES） | 指定した期間と確率水準での損失の分位点／その裾側の平均。標本の定義にも注意する | Ch22 |
| 指数加重移動平均（exponentially weighted moving average、EWMA）／一般化自己回帰条件付き不均一分散（generalized autoregressive conditional heteroskedasticity、GARCH） | 過去ほど小さな重みで分散を更新する方法／過去の変動と条件付き分散を用いるモデル | Ch23 |
| デフォルト確率（probability of default、PD）／デフォルト時損失率（loss given default、LGD） | 指定期間のデフォルトの確率／そのとき回収できない元本等の割合 | Ch24 |
| ハザード率（hazard rate）／回収率（recovery rate） | 生存を条件にした瞬間的なデフォルト率／デフォルト時の回収割合 | Ch24・25 |
| コピュラ（copula） | 個々の分布を保ったまま、変数間の依存を表す道具。相関だけで裾の依存が決まるとは限らない | Ch24・25 |
| クレジット・デフォルト・スワップ（credit default swap、CDS） | 保険料に相当する支払いと、信用事由発生時の支払いを交換する契約 | Ch25 |
| エクスポージャ（exposure）／期待エクスポージャ（expected exposure、EE） | 相手の不払いで損失になりうる正の価値／その時点の平均 | Ch9・24 |
| 信用評価調整（credit valuation adjustment、CVA）／債務評価調整（debit valuation adjustment、DVA） | 相手の信用／自分の信用に対応する価格調整。符号は評価の立場で定める | Ch9 |
| 資金調達評価調整（funding valuation adjustment、FVA）／XVA | 資金調達に対応する価格調整／各種調整の総称。合算時の二重計上に注意する | Ch9 |

## 金利と先の話：曲線からモデルへ

| 用語（English・略語） | このガイドでの意味と読み分け | 主に読む章・巻 |
|---|---|---|

(guide-symbols)=
## 記号と単位：同じ文字でも意味を決め直す

価格は通貨を省略せず、率は百分率を小数へ直して式に入れます。時間を年で測るか日で測るかで、係数の単位も変わります。以下の年を基準とする単位は、このガイドの標準的な読み方です。

| 記号 | 意味 | 単位・注意 |
|---|---|---|
| $t,T,\Delta t$ | 現在の時刻、満期、時間刻み | 年。Ch13 の1期間の式は $T$、多段では $\Delta t$ |
| $S_t,K$ | 原資産価格、権利行使価格 | 例：米ドル／株。指数なら指数ポイント |
| $f,c,p$（価格の式） | 一般のデリバティブ、コール、プットの価格 | 契約1単位あたりの通貨。確率の $p$ と区別する |
| $F_t$ | 先渡価格または先物価格 | 対象資産の建値単位。金利商品等では文脈を確認する |
| $r,q,r_f,\mu$ | 無リスク金利、配当利回り、外国金利、現実の期待成長率 | 連続複利の年率（年の逆数） |
| $\sigma$（収益率モデル） | ランダムな収益率の変動係数 | 年の平方根の逆数。正規金利モデルの絶対ボラとは単位が異なる |
| $W_t,dW_t$ | ウィーナー過程、その増分 | 年の平方根。増分の分散は経過時間 |
| $v_t$ | 年率換算した瞬間分散 | 年の逆数。累積分散と区別する |
| $u,d$ | 二項ツリーの上下倍率 | 無次元。収益率は $u-1,d-1$ |
| $p$（Ch13） | リスク中立の上昇確率 | 無次元。プット価格の記号ではない |
| $p^*$（Ch13本文／付録） | 現実の上昇確率／株価で重みを付け直した上昇確率 | どちらも無次元だが別の量。付録は本文の予測確率を再利用していない |
| $a$（Ch13）／$a$（短期金利） | 評価上の平均成長倍率／平均回帰の速さ | 前者は無次元、後者は年の逆数 |
| $\alpha$（Ch13付録） | 行使を分ける上昇回数の境界 | 無次元。成長倍率 $a$ と異なる記号 |
| $n,j$ | 段数、上昇回数 | 無次元の整数 |
| $P,Q$ | 現実の確率測度、リスク中立確率測度 | 数値や通貨ではなく、確率を付ける規則 |
| $N(x)$ | 標準正規分布の累積分布関数 | 入力と出力は無次元 |
| $\Delta,\Gamma$ | デルタ、ガンマ | 価格／原資産価格、価格／原資産価格の二乗。ヘッジ株数の表現にも注意 |
| $\nu$（ベガ） | ボラティリティに対する感応度 | 価格／ボラティリティの単位。1ポイント変化あたりの表示と区別する |
| $\rho$ | 相関、または金利感応度のロー | 相関は無次元。感応度なら価格／金利の単位 |
| $\theta$ | セータ、モデルの長期水準、または短期金利のドリフト係数 | セータは価格／時間、長期水準は状態変数と同じ単位。Hull–White で平均回帰項と別に加わる $\theta(t)$ は金利／時間 |
| $L,m(L)$（Ch8） | 原資産損失率、メザニン層自体の損失率 | 無次元。分母となる元本が異なる |
| $\lambda$（信用） | ハザード率 | 年の逆数。市場リスクの価格の同名記号とは分ける |
| PD、LGD、回収率 | デフォルト確率、損失割合、回収割合 | 無次元。PD の対象期間と、回収額の基準を明記する |
| EE、PFE、CVA等 | エクスポージャの平均・分位点、価格調整額 | 通貨。PFE は potential future exposure |
| $P(t,T)$ | 時点 $t$ での満期 $T$ の割引債価格 | 満期1通貨単位の支払いに対する比率。確率測度 $P$ と区別する |
| $r_t,f(t,T),L_i(t)$ | 短期金利、瞬間フォワード金利、有限期間フォワード金利 | 年率。$f$ がオプション価値を表す節とも区別する |
| $\delta_i$ | 金利商品の利息計算期間 | 年分数。株価感応度デルタ $\Delta$ ではない |
