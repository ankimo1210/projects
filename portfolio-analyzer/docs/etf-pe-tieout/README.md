# ETF PER の再構成 — 2020〜2026 年のヒストリカル tie-out

保有ポジションの ETF（QQQ / SMH / 1329 / 1475 / XLE）について、「構成銘柄の株価 ÷ EPS の
加重調和平均」で提供会社の公表 PER を過去 5〜6 年ぶん再現できるかを検証した記録（2026-09-11）。
現在時点の再現（4 本とも ±2.6% 以内）は `data/analysis_reference.private.json` の各 ETF の
`method` / `note` と、メモリ `etf_per_reconstruction` に記録済み。ここはその**過去分**。

## 結論

| ETF | アンカー（公表値） | 時点数 | 再現の規約 | 誤差（MAE / 平均） | 判定 |
|---|---|---:|---|---|---|
| **SMH** | VanEck ファクトシート（US 版・欧州 UCITS 版、Wayback） | 8（2021-09〜2026-06） | 実績 GAAP・赤字除外・調和平均 | **4.9% / +2.5%** | 再現できる |
| **1475 / 1329**（JPX 定義） | JPX「規模別・業種別 PER」加重 PER（プライム／旧一部 総合、月次） | 75（2020-06〜2026-08） | 実績・全上場株ベース・赤字含む Σ時価総額 ÷ Σ純利益 | **3.1% / −1.1%** | 再現できる |
| **1475 / 1329**（BlackRock 定義） | BlackRock 7/31 のみ（過去のファクトシートは Wayback に無い） | 1 | 実績・浮動株ウェイト・赤字除外・調和平均 | 7/31 EPS で +2.8% / +1.0%、8 月発表分まで入れると **±0%** | 再現できる（EPS は作成日基準） |
| **QQQ** | Invesco QQQM ファクトシート（Wayback） | 9（2021-03〜2026-06） | 実績 GAAP・調和平均 | **15.4% / −14.9%**（赤字除外）、13.7% / −11.7%（赤字は重み残し） | **再現できない**（後述） |
| **XLE** | SSGA ファクトシート（Wayback） | 7（2019-12〜2026-06） | — | — | **検証不能**：公表値が FY1 予想 PER のみで、過去の予想コンセンサスは無料で取れない |

- SMH・日本株・（現在時点の）BlackRock は、「全構成銘柄 × 時点整合した EPS × 正しい規約」で
  **数% 以内**に収まる。前回のメモリの結論（外れるのはこちらの定義・時点・データ品質のミス）は
  過去 5 年でも成り立つ。
- **QQQ は例外**。Invesco の脚注は「Weighted Harmonic Average … 12-month trailing」だが、
  GAAP 実績の調和平均は 9 時点中 7 時点で −13〜−29% 低い。一致するのは 2023-09（−6 / +1%）と
  2026-06（+2 / +8%）だけ。**PER を 60〜70 で頭打ちにした加重「算術」平均なら 9 時点とも ±9%
  （MAE 6%、平均 −0.5%）**に入るが、脚注と矛盾するので採用しない。2026-06 の +1.4%（前回）は
  たまたま合った点だったと見るべき。ダッシュボードの QQQ 保存値は再構成の実績値のまま
  （Invesco の数字を目標にしない）。

## データソース

| データ | 取り方 | 備考 |
|---|---|---|
| 米国 ETF の保有（全銘柄・株数・評価額） | SEC N-PORT `primary_doc.xml`（`data.sec.gov/submissions/CIK…json` → `Archives/edgar/data/<cik>/<acc>/primary_doc.xml`） | QQQ は四半期 26 本（2020-03〜2026-06）。VanEck は多シリーズなので `<seriesName>` を先頭 4KB で判定して SMH を特定（`data/smh_nport_acc.json`、55 時点）。**時点の株価 = valUSD ÷ balance** なので株価データ不要（上場廃止銘柄も扱える） |
| 識別子 → ティッカー | OpenFIGI `v3/mapping`（CUSIP / ISIN、無キー 10 件/req） | 上場廃止銘柄は欧州上場の別ティッカー（`ATVIEUR` 等）が返るので手で直す。外国籍（G/N/M で始まる CUSIP）は 0 件なので手で補完 |
| 米国銘柄の EPS（時点整合） | SEC XBRL `companyconcept/…/EarningsPerShareDiluted`（`filed` 日付付き） | **`companyconcept` が空・古い年で止まる銘柄がある**（PYPL/MDLZ/CDNS/NXPI/ABNB 等）→ `companyfacts` で置換（`sec_facts_fix.py`）。BIDU/TCOM/MNST/VRSN は それでも古いまま（中央値補完） |
| 分割 | yfinance `Ticker.splits` | XBRL の過去四半期は**申告時点の株数ベース**なので、四半期ごとに「その申告日より後の分割」で割り戻す（NFLX 10:1、NVDA 10:1、GOOG/AMZN 20:1、AVGO 10:1、BKNG） |
| ADR / 外貨 | 手動比率（TSM 5、PDD 4、JD 2、BIDU 8、NTES 5、AZN 0.5）＋ yfinance FX | 20-F 銘柄は年次しか無い（半期 6-K は XBRL 外）。TSM の 20-F は USD と TWD の両方で申告されるので**通貨で ADR 換算の要否を判定してはいけない** |
| 提供会社の公表値（アンカー） | Wayback CDX（`web.archive.org/cdx/search/cdx?url=…`）→ `web/<ts>id_/<url>` | 429 を避けるため 6〜12 秒間隔。VanEck は US 版 PDF（`us/en/investments/semiconductor-etf-smh-fact-sheet.pdf`）と欧州版 `*/library/fact-sheets/smh-fact-sheet.pdf`、Invesco は QQQM の `us-rest/contentdetail?contentId=5b4d8e58e0737710VgnVCM1000006e36b50aRCRD&dnsName=us`（QQQ 本体の contentId は国選択ページしか残っていない）。**BlackRock JP のファクトシートは 1 時点しか無く、その版には PER が載っていない**。日経公式 PER は Cloudflare で取れない |
| 日本株の保有 | iShares JP の保有 CSV（現在のみ） | 過去のウェイトは「現在の ETF 株数 × 当時の株価」で近似（浮動株比率・株数の変化は無視） |
| 日本株の EPS（時点整合） | yfinance `Ticker.get_earnings_dates(limit=60)` の `Reported EPS` | **四半期（3 か月）EPS・分割調整済み・発表日付き**で 2014 年まで遡れる。ただし約 1,000/1,635 銘柄にしか無く、うち約 500 は 2020 年以前で途切れている → 有効は約 400 銘柄（プライム時価総額の約 9 割） |
| 日本株の株数 | yfinance `get_shares_full`（四半期）＋ `splits` | `get_shares_full` は**分割前の株数**のまま返るので、分割で割り戻さないと 2023〜24 年（NTT 25 分割等）で時価総額が 1/5〜1/25 になる |
| 日本のアンカー | JPX 規模別・業種別 PER・PBR（連結）`jpx.co.jp/markets/statistics-equities/misc/04.html` の `perpbrYYYYMM.xlsx` | 2020-01 から月次。2022-03 以前は「市場一部」、以後「プライム市場」。**2022-03 以前のブックは数値が `=2155` のような定数式で入っていて `data_only=True` だと None になる**。定義＝上場株式数ベースの時価総額合計 ÷ 確定年次純利益合計（赤字含む） |

## 方法

1. **ウェイト**: 米国は N-PORT の評価額そのもの。日本は現在の株数 × 月末株価。
2. **EPS の時点**: 米国は「as-of までに `filed` された四半期」の直近 4 本（10-K しか無い Q4 は
   FY − Q1〜Q3、ただし 3 本を 10-K の株数ベースに揃えてから引く）。20-F 銘柄は直近年次（500 日以内）。
   日本は「as-of までに発表された四半期」の直近 4 本（TTM）。JPX 定義の比較では「直近の確定
   決算期（FYE ≤ as-of − 45 日、15 か月以内）」の年次。
3. **規約**: 赤字は除外して再規格化（SMH / BlackRock）または重みだけ分子に残す（Invesco の
   2026-06 に合った規約）。PER < 1〜2 は EPS 単位エラーとして欠測扱い（西日本 FH の TTM EPS
   288,017 円が 1475 の分母の 36% を占めた事故の再発防止）。欠測は中央値で補完。
4. **比較**: アンカー日の公表値との誤差（%）。

## 再現手順

`scripts/` は作業時のスクリプトをそのまま置いたもの（作業ディレクトリは環境変数
`ETF_PE_WORKDIR`）。順序は 日本: `jp_fetch.py` → `jp_fetch2.py` → `jp_fetch3.py` →
`jp_fetch4.py` → `jp_hist2.py`（現在時点だけなら `jp_calc.py`）。米国: N-PORT を取得して
`nport_parse.py <dir>` → OpenFIGI で `figi_map.json` → `sec_eps.py` → `sec_facts_fix.py` →
`us_splits.py` → `us_hist.py <nport_dir> figi_map.json sec_eps.json splits.json out.csv anchors.json`。
JPX・Wayback・iShares CSV の取得 URL は上の表のとおり。yfinance は 1,635 銘柄 × 4 パスで
約 40 分、SEC は 170 社で数分、Wayback は 1 件 7〜12 秒。

## 落とし穴（次にやる人へ）

- 調和平均は EPS の単位エラー 1 件で壊れる。PER < 1〜2 は欠測扱いにする。
- XBRL の四半期 EPS は申告時点の株数ベース。分割は**四半期ごとに**割り戻す。Q4 を FY − 3Q で
  出すときも 3 本を 10-K の株数ベースに揃える（NFLX で TTM が −8.65 になった）。
- `companyconcept` は古い年で止まる銘柄がある。`companyfacts` で置き換える。
- 20-F 銘柄は USD 申告でも 1 株ベース。ADR 比率は通貨に関係なく掛ける（TSM の PER が 223 になった）。
- yfinance `get_shares_full` は分割前の株数。`get_earnings_dates` の Reported EPS は分割調整済み。
- 提供会社の月末 PER は月末時点の EPS ではなく作成日（翌月中旬）の EPS。日本株は Q1 決算が 8 月に
  集中するので 7 月末値を 7 月末 EPS で再現すると +3〜7% 上振れする。
- Wayback は 6〜12 秒間隔でも稀に空ファイルを返す。`file -b` で PDF か確認し、gzip なら解凍する。
