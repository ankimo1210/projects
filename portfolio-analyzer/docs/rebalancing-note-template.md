## 実行前チェック

- [ ] 価格、数量、売買単位を更新した
- [ ] 売却銘柄の取得価額、取得時為替、税区分を確認した
- [ ] 税金、手数料、スプレッドを確認した
- [ ] 口座間の資金移動と受渡日を確認した
- [ ] 決算・分配金・権利確定日の直前でないか確認した
- [ ] 一括か分割かを決めた
- [ ] 入れ替え後のダッシュボードを再生成した

## 注意

PERと感応度は推定値です。実績・予想・提供会社基準PERを混ぜず、ファクター係数の算定メモと
カバー率を確認します。利益予想の下方修正、相関上昇、流動性、税金、手数料、約定価格は
完全には反映できません。実行判断では最新の価格と公式資料を再確認します。
