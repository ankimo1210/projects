## 完了した変更

- timeseries.py / ibkr.py / daily_pl_report.py: 外貨現金 FX の期間集計を特定日の日次利益として扱わない。欠損価格・為替・口座履歴を未定義のまま伝播し、指定期間を短縮しない。DD は期末入金を仮定した収益指数から算出。XIRR の無効なキャッシュフローを拒否し、終端 NAV が推定の場合に表示で区別する。日次率の分母は日次損益控除前の総資産。
- jpbroker.py / mtm.py: NISA と課税区分の数量・原価・売却損益を分離。課税部分に税を計算し、課税原価が不明の場合は税額と税引後値を未計算にする。
- core.py / risk.py / estimate_factors.py: 銘柄を口座横断で集計した集中度、過去局面の総資産分母、価格対象内と総資産のカバー率を修正。実測ショック・共分散・逆ストレスには同じ円建て超過ファクターの共同回帰係数を要求し、不完全な係数をゼロで補わない。仮定の線形ストレスは別の近似として表示する。非現金商品の価格履歴が不足する場合は全体のボラ・VaR 等を未計算にする。
- dashboard.py / mailer.py / manifest_html.py: 制約を冒頭に表示し、未計算の損失をゼロと描かない。未計算の方針チェックを「超過なし」と表示しない。基準日・推定値・分母の表示を計算と一致させる。CLI の未計算損益もゼロ表示を避ける。
- 対応テストと README: 手計算の回帰例、欠損時の振る舞い、定義と入力制約を追加。
