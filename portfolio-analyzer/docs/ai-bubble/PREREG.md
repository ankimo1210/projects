| 銘柄 | 層ごとの候補集合から基準日の時価総額で上位を取る（買い手5・設計3・製造メモリ3・装置テスト6・DC等3）。Oracle と CoreWeave は必ず含める | 評価倍率・上昇率・保有で選ばない。資金面の脆さが集まる層を外さない |

| 項目 | 規則 | 理由 |
|---|---|---|
| 観測EV | 終値×株数（分割の基準をそろえた発行体の株数）＋有利子負債＋ファイナンス・リース負債−現金−短期投資−長期の市場性債券−長期投資。米国基準のオペレーティング・リース負債は入れない。IFRS 16 のリース負債は負債に入れる。基準日にファイナンス・リースのタグが無ければ0とし、それ以前の最新値を注記する | 米国基準ではオペレーティング・リース費用が営業利益の中にあるので、負債にも数えると二重になる。非支配持分は調整しない（小さい） |
| 長期投資 | 営業利益の外で稼ぐ投資（株式・持分法投資）はEVから差し引き、投下資本からも除く。合計タグ（LongTermInvestments、無ければ OtherLongTermInvestments）、無ければ公正価値の株式＋公正価値が容易に算定できない株式（またはその合算タグ）＋持分法投資。差し引かない場合のEVを感応度に出す | 営業利益で割り引く価値と比べるので、営業の外の資産は外す（仕様§5「EVとCFで非営業資産の扱いをそろえる」）。最初の登録は「小さい」として調整しなかったが、V を計算する前に Amazon 1,227億・Alphabet 1,315億・NVIDIA 907億・Meta 337億ドルと分かったので改めた |
| 負債 | 基準日の負債タグを決めた順に試し、最初にそろった組（LongTermDebt、流動＋固定、Notes and loans、債務の帳簿価額など）＋短期借入・CP | 会社ごとにタグが違う（Oracle は Notes and loans、CoreWeave は債務の帳簿価額だけ） |
| 営業利益 | 直近4四半期の営業利益。タグが無い会社は売上−売上原価−研究開発費−販管費 | KLA は 2015 年以降営業利益をタグ付けしていない |
| 税率 | 1年目は直近4四半期の実効税率（0〜35%、IFRS の決算短信は税引前利益−純利益、税引前利益をタグ付けしない会社は純利益＋法人税）、T年目に法定税率へ直線で移し、終端は法定税率（米国25%＝連邦21%＋州税の概算、日本30.64%＝2026年4月以後の事業年度の標準税率で防衛特別法人税を含む） | 一時的に低い実効税率を永久に置くと価値が膨らむ |
| 売上が減る年の再投資 | 0（資本は戻らない） | 設備は売上が減っても現金に戻らない |
| ストレス | 自社の履歴に2年続く減収が無ければ1〜2年目は横ばい | 上場の浅い企業では「最悪の2年」が増収になり、ストレスにならない |
