## 時点の扱い

| 入力 | `available_at`（この時刻以降に使える） | 理由 |
|---|---|---|
| SEC 10-K/10-Q/20-F の XBRL | `filed` の翌営業日 00:00（ニューヨーク） | submissions の `acceptanceDateTime` は「Z」付きだが、実際は東部時間を UTC と書いたもので数時間先にずれる（NVIDIA の決算 8-K は 16:20 ET の提出が 00:21Z、EDGAR の閉まっている 03–08Z に 246 件）。監査用に `sec_acceptance_raw` として残すだけにした |
| 決算短信 | 表紙の公表日の翌営業日 00:00（東京） | ページに時刻が無い。TDnet の開示は多くが 15:00 |
| 終値 | その市場の引け後（東京 15:30、ニューヨーク 16:00）。為替は翌 UTC 日 | 日次レポートと同じ `mtm.bar_is_final`。取引中の足は終値ではない |

同じ期間の訂正・遡及修正は別の行として残り、`select_as_of` は基準時刻に使えた最新版を選ぶ。同時刻に値が食い違えば止まる。
SEC で同じ日に提出された年次と四半期の報告が食い違う場合だけ年次を採り、他方を `same_day_conflict` に残す（19社・約7万行で Arista の 2012 年末現金の1件）。

株価は yfinance の `auto_adjust=False` の終値で、配当調整はしないが、取得時点までの株式分割で過去にさかのぼって割り戻されている。
開示の株数は計数日のものなので、計数日より後の分割を掛けて同じ基準にそろえる（`universe.shares_at`）。価格×株数は基準日の時価総額になる。
東京エレクトロン（1:5、2026-09-29 権利落ち）は同社の 2026-05-29 開示で確かめた。yfinance の株数と時価総額は分割前のままだった（東京エレクトロンで 1/5、キオクシアは 1/3 の可能性）ので、照合にも代用にも使えない。

## 決算短信の読み方

要約ページ（1ページ目、表紙があれば2ページ目）の経営成績・財政状態・キャッシュ・フローと、その後2ページまでの発行済株式数を読む。

- 全角は NFKC で直す。`△` は負、`―`・`-` は空欄（理由付きの欠損でゼロにしない）。
- 会計基準は表題の〔IFRS〕〔米国会計基準〕〔日本基準〕（丸括弧・角括弧も）。2010 年以前の様式は米国基準の会社だけが基準を書いたので、表記が無ければ日本基準とし `basis_printed = False` を付ける。
- 2024 年4月以降の第2四半期は「中間期」と書かれる。2010 年以前は1株当たりの円と銭が別の列。
- 列の並びは会計基準・親会社持分の列の有無で変わるので、列の見出しで決める。
- キオクシアの要約は Non-GAAP の列が入り、文書ごとに並びも違う。そこで TDnet の iXBRL（JPX の www2.jpx.co.jp に PDF と並んで置かれる）を読む（`jp.parse_summary_ixbrl`）。タグが会計基準を名乗り（`SalesIFRS` など）、期間は各コンテキストの日付から取るので、列の位置に左右されない。予想・個別（単体）・増減率は読まない。

## 逆算DCF（Task 2）

### 作り方

- 観測EV = 終値×株数 ＋ 有利子負債 ＋ ファイナンス・リース負債 − 現金 − 短期投資 − 長期の市場性債券 − 長期投資。細目は [PREREG](PREREG.md) の「評価の細目」で、V を計算する前に登録した。
- 株数は発行体の開示（表紙、決算短信の発行済−自己株式、クラス別の会社は希薄化後の加重平均）に、計数日より後の分割を掛けたもの。キオクシアの 1:3（2026-10-01 効力発生）は 2026-07-31 の決算短信の注記で確かめた。
- 割引率 `r_j` は米国 9.32%（10年国債 5.12%、2026-10-20）、日本 7.127%（2.927%）に、Damodaran の ERP 4.20%（2026-10 月）を足したもの。β は推定しない。
- 終端価値: T=10 年の後、`NOPAT×(1−g∞/RONIC)` を `r_j−g∞` で割る。中央の EV のうち 50〜73% が終端価値（AMD は予測期間の FCFF が負なので 129%）。
- 再投資: 売上の増加 ÷ 直近4四半期の売上/投下資本。投下資本 = 自己資本＋有利子負債＋ファイナンス・リース−現金−投資。売上が減る年は0。終端では g∞/RONIC を再投資に回す（中央の RONIC は `r_j`+5pt）。
- リース: 米国基準のオペレーティング・リースは負債にも投下資本にも入れない（費用が営業利益の中にある）。ファイナンス・リースと IFRS 16 のリース負債は負債（償却が営業利益の中、利息がその下）。基準日にタグが無い会社は0とし、以前の値と EV に対する比率を注記した（最大 Meta の 0.07%）。
- 株式報酬と希薄化: GAAP の営業利益は株式報酬を費用として引いた後なので、NOPAT はそれを1回負担する。株数は直近の発行済で、将来の付与をもう一度引くことはしない。未確定の付与は株数に入れていないので、株式報酬の大きい会社（Meta は純利益の 37%）では時価総額をわずかに小さく見ている。
- 長期投資（Amazon 1,227億・Alphabet 1,315億・NVIDIA 907億ドル、アドバンテスト 3,577億・東京エレクトロン 3,433億・キオクシア 5,308億円など）は EV からも投下資本からも外した。外さない場合の V も計算し、どの会社でも V は変わらない。

- V の「支持」は「登録した経路（成長は φ=0.6 で速く減衰、利益率は自社の5年平均へ）と `r_j` では、今の価格を説明するのに中央・楽観のどちらも1割以上足りない」という意味で、割高の断定ではない。12社が支持、4社が混在、2社が弱める。

- `r_j` は 10年国債 5.12% のもとで高く、β を推定しないので、β が1未満の大型株では支持の側に寄る（仕様は β>1 の偏りだけを書いていた）。

- 層の整合: 中央では、買い手5社の投資（売上の増加÷売上/投下資本）が毎年減る（−21%〜−12%）のに、設計・製造・装置の売上は増え続ける（+63%〜+16%）。5年すべてが警告。楽観は5年目だけ、ストレスは4・5年目が警告。TSMC と ASML は入っていない。
- 実績: Amazon と Alphabet の直近4四半期の純利益は約6割が営業外（Anthropic・保有株の評価益など）なので、PER（20.9、17.2）より EV/EBIT（29.2、26.5）で比べる。Oracle の設備投資後 CF 利回りは −7.2%、CoreWeave は −39.9%。
- 1年の株価変化の分解: 買い手と NVIDIA・Broadcom・Micron は EPS の伸びが株価を上回り PER は下がった（例: NVIDIA は Δlog EPS +0.81、Δlog PER −0.64）。装置の Lam・Applied・KLA・東京エレクトロンは PER が上がった（+0.16〜+0.29）。

## 資金の持続性（Task 3）

### 作り方

- 8四半期、新規調達なし。配当と自社株買い（任意の支出）、未使用の融資枠は入れない。細目は [PREREG](PREREG.md) の「資金の細目」で、F を計算する前に登録した。
- 起点の現金 = 現金＋短期投資（長期の市場性証券と長期投資は除く）。KLA は保有債券の合計しかタグが無く、流動資産に載っているので短期として数えた。Alphabet の短期投資 1,866億ドルには保有株が入る（債券は 995億ドル）が、外しても F は変わらない。
- 営業CF = 直近4四半期の営業CF÷4 を、Task 2 の中央・ストレス経路の NOPAT の変化分だけ動かす。ストレスは1〜2年目に、自社の履歴で最悪の連続2年の売上変化と最低の利益率を当てる。減収で売掛金と在庫が減って戻る現金は入れていない（不足を大きめに見る）。
- 設備投資 = 直近4四半期÷4 を毎四半期（投資を続ける前提）。購入義務は設備投資か営業の支払で払うので、足さずに表示だけする。
- 元本: 直近の会計年度末以降の満期表で、今年度の残りと12か月以内を1〜4四半期、2年目を5〜8四半期に均等割り。CP と短期借入は1四半期目（借り換えなし）。満期表が無い NVIDIA・Applied Materials・KLA・アドバンテスト・キオクシアは、流動部分を1〜4四半期、残りを5四半期目に置く（窓の中で最悪の置き方）。KLA は流動・固定の区分も無いので全額を1四半期目に置く。最悪の置き方のときだけ不足が出る経路は未評価。
- リース: ファイナンス・リース（IFRS 16 のリース）の1・2年目の支払。支払には利息が含まれるので少し多めに見ている。
- F: 中央の8四半期で途中の最大不足が正なら支持、中央・ストレスとも0なら弱める、ストレスだけ不足なら混在、未評価の経路があればデータ不足。
- 満期表の新しさの条件は、F の最初の結果を見た後に PREREG を改めて足した。Applied Materials の満期表のタグは 2010年、KLA は 2021年が最後で、今の債務とは関係がない。原文どおりなら Applied は弱める・KLA は混在で、他の16社は同じ。

## 急騰と崩落の基底率（Task 4、記述版 S）

### 作り方

- Kenneth French の49業種（時価加重・配当込み・月次、1926-07〜2026-08、CRSP 202608 版）から "Other" を除いた48業種。構成企業10社以上の月だけを使う。市場は Mkt-RF＋RF。
- 急騰（GSY の主定義）: 24か月の生リターンと対市場リターン（累積リターンの差）がともに100%以上、かつ60か月の生リターンが50%以上。崩落: 起点から24か月以内に、どの時点からでも40%以上下がること。エピソードは業種ごとに最初の月を起点とし、起点から24か月は数え直さない。

- 取得した版（202608）を固定した疑似時点順の検証で、当時配信された版や分類の改訂は復元していない。

## 既知の欠落と取れない理由

- 決算短信 4件（アドバンテスト）と9件（東京エレクトロン）は要約ページが画像か、文字の対応表が無いフォントで読めない。その期間の値は翌年の決算短信の前年比較から取れるが、使える時刻は1年遅れる。東京エレクトロンの 2015年3月期の通期損益は、翌年の決算短信も画像なので欠ける。
- 東京エレクトロンの「訂正」15件（2016年の受注高・受注残、2020年の説明文の CF）は要約ページの値に影響しない。
- TSMC と ASML は 20-F（年次）しか XBRL が無く、四半期は 6-K の PDF だけ。自国（台湾・オランダ）の10年国債の取得元も PREREG に無いので、Task 2 では未評価にした。評価するには、利回りの取得元を登録し、四半期の財務諸表を書き写す必要がある。
- Alphabet・Meta・CoreWeave の表紙株数はクラス別で companyfacts に無い。
- キオクシアの IR サイトは JavaScript で一覧を出すので、JPX（www2.jpx.co.jp）の TDnet 文書を直接取った（決算短信4本）。上場が 2024年12月なので年度の履歴は3年しか無く、ストレスに使う「最悪の連続2年の減収」が無い（ストレスの1〜2年目は横ばいになる）。ディスコは採用外で未取得。
- www.sec.gov（提出書類の本文）は連絡先の無い User-Agent を 403 で拒む。利用者のメールアドレスは送らない方針なので、本文との照合は会社のリリースで代えた。
- 満期表を最近の報告書でタグ付けしていない会社（NVIDIA は一度も無し、Applied Materials は 2010年、KLA は 2021年が最後）は、F で満期を最悪の置き方にする。KLA は流動部分のタグも 2025年が最後。
- 顧客の集中（顧客別の売上比率）は companyfacts に無く、提出書類の本文を読まないと取れない。
- FRED はこの環境から接続できない。米国財務省・財務省・FRB H.10 の原表で代える。Stooq はブラウザ検証を求めるので使わない。J-Quants のキーは環境変数に無い。
