# V10 — 170㎡・24人の縮小比較モデル

更新: 2026-11-16。ユーザーが貼り付けた1億円案を「元案と比較する候補」と指定し、続けて「fableとチェックして画像と3Dを更新して」と依頼した。元案V8/V9を採用解除せず、新しい比較モデルV10を作る。既存の画像/会話/ZIPを保存する。

## 目的と採用する比較条件

- 男性専用1系統。原型170㎡、在館24人は運営目標で許可定員ではない。
- 主室22㎡目安、通常12席を基本。少し奥へ寄せたストーブを三方から囲む。人数を詰めず、演者の床と出入口を分離。イベント8〜10人の目標。14席は必須にしない。
- セルフロウリュ約10㎡・4〜6席。今回の比較版にはTV付きドライ室を設けない。
- 冷水1槽・16℃仮、水面2.4×1.8m・水深0.70mを出発点。炭酸1槽・37℃仮、水面2.4×1.8m・水深0.55m。階段を人数に数えず、出入りできる床を空ける。
- 正式休憩16席（室内の椅子12・寝椅子2＋浴室造り付け2）。視線が正面衝突しにくい向き、適度な袖壁、清掃/監視/救助への見通し。4シャワー、30ロッカー、受付・洗面WC・機械室・リネン等を実装する。
- 暗い暖色間接光、木/石、控えめな曲線と斜め、V8と同程度の素材/メッシュ/実レンダリング品質。全体照度やメーカー・法令の成立は未確認。
- 面積表を均等縮小しない。主22、セルフ10、2槽区画13、休憩28、洗い8、浴室通路待機12、更衣27、受付6、洗面WC6、機械17、スタッフ/リネン5、壁/追加共通動線16＝170㎡を目安に、重複しない座標へ落とす。壁/通路は一度だけ計上。必要な変更は量と理由を記録。

## 技術上の必須照合

1. 70cmでも掘削ゼロとしない。元断面仮定（FL0、水面−0.06、スラブ上−0.20、底下包絡0.25）なら冷槽の支持下端−1.01m、スラブから0.81m。炭酸は−0.86/床下0.66m。主表示は条件付き床下型、断面で必要空間を見せる。実物件のスラブを切断可能とはしない。
2. 主室のベンチ・人・ガード・扉・演者の空間を同じメッシュ/座標で検査。演者の円を名目だけで描かず、実際の床/物体に当たるかを測る。既存の仮タオルR1.30mを基準比較し、満たせなければ未成立と正直に記録する。
3. 休憩16/24で全員集中8不足、水風呂4位置仮/イベント10人・60秒仮なら6人待ち/最大120秒。通路外の一時待機/満席時の戻り動線を描く。入浴時間の推奨ではない。
4. 2槽8.64㎡の水面＋槽壁/階段/周囲、設備17㎡の機器包絡/点検/交換、ロッカーの開扉/更衣、受付から客と裏方の移動が成立するかを明示。物件未定なので柱梁や外部設置権を創作しない。
5. LIXIL床/METOSは元案の比較段階を維持。ヒーター能力/機種/離隔は再選定が必要。金額1億円は低位仮定目標、貼付本文の基準単価総額1.4056億円も84明細Excel本体が未添付で再監査未了。3Dで費用成立を認定しない。
