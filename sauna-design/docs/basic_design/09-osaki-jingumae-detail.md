# 大崎・神宮前の詳細比較 — 予算上限を外した再判定

更新: 2026-11-15。対象はCIRCLES∞大崎1階と、いちご神宮前ビルB1-102。2億円は今回の足切り条件から外した。40人・3サ室・水風呂2槽＋炭酸泉・20×14m原型は承認なく縮小していない。

## 結論

**今回の2件は、費用を増やせば今の間取りをそのまま実現できる候補とは扱えない。** 大崎は貸主側の現ページが掲載終了で、事務所仕様の床荷重・設備容量にも大きな課題がある。神宮前は募集307.93㎡の中に共用部按分があり、それを控除した区画は約210.5㎡。現280㎡案のままは入らない。前回08の「募集面積が280㎡以上」という抽出から、評価を修正する。[大崎公式仕様](https://mec-circlesribbon.com/osaki/floor/first-floor.php)、[神宮前の按分明記](https://search.sunfrt.co.jp/floor/2967/54060/)。

実賃料と浴場用途の承諾は2件とも取得できていない。以下の資金比較は、280㎡の同じ計画を維持する場合に仮賃料と追加工事枠を動かしたもの。2物件の成約額、施工可能な計画の見積、神宮前を210㎡へ縮めた別案の見積ではない。

## サウナ利用可否の回答範囲

2件とも、貸主から浴場用途や必要工事の承諾を得ていない。「不可」の回答を受けたわけでもないため、私の判定は「未承諾・現計画未成立」。賃料の非公開も、営業可否の回答不足も公開検索だけでは確定できない。

[渋谷区の案内](https://www.city.shibuya.tokyo.jp/jigyosha/jigyo-eisei/kankyo-eisei/yokujo.html)はサウナを含むその他の公衆浴場の営業許可・構造設備/維持管理基準を説明し、[東京都の案内](https://www.hokeniryo.metro.tokyo.lg.jp/kankyo/eisei/yokujyou/yokujyou_faq)も所在地管轄への照会を案内している。貸主の用途承諾と、建築/消防・衛生上の適用や営業許可は別に確認する。この調査では行政への事前相談や申請、法適合の認定はしていない。
