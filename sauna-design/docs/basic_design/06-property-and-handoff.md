## 2億円と物件条件をつなぐ

⑥の基準は運転3か月込み2億2625.2万円。前回の目標例1億9824.4万円は、家賃120万円/月・保証金6か月だけでなく、直接工事1200万円減が必要。

- ピット200万円減：P01/P02の適合再利用を確認して純減額を出す。修理/使用料/構造補強を差し引く。
- 別の既存設備500万円減：E03/G05/G08/V01等。能力・劣化・所有権・整備費を確認し、同じ工事を再度減らさない。
- 他工種の調達/仕様整理500万円減：未交渉で工種配賦前。物件が良いだけでは自動的に得られない。

元請10%・予備15%・消費税10%・運転3か月・工事賃料5か月・礼金1か月・仲介1か月・保証会社0.7か月・全額返還保証金を固定した**探索用の簡略式**は、金額を万円として

\[
F = 19370.1982 + R(d+11.7) - 1.3915S
\]

\(R\)は税抜月額固定費、\(d\)は保証金月数、\(S\)は税抜直接工事減額。11.7には工事中・非返還初期費・運転3か月の賃料分が入る。同じ費目をさらに足さない。共益費を礼金/仲介の算定基礎に含めない契約などは、候補フォームへ**実額**を入力する。

| 家賃/月・保証金 | 1200万円減が得られた総額 | 2億以内に必要な直接工事減額（切上） |
|---|---:|---:|
| 100万円・6か月 | 1億9470.4万円 | 820万円 |
| 110万円・6か月 | 1億9647.4万円 | 947万円 |
| 120万円・6か月 | 1億9824.4万円 | 1074万円 |
| 130万円・6か月 | 2億1.4万円 | 1202万円 |
| 120万円・8か月 | 2億64.4万円 | 1247万円 |

物件由来700万円減しか確認できず残り500万円減が得られない場合、保証金6か月での家賃上限は**税抜約90.6万円/月**。合計1200万円減が得られれば同条件の理論家賃上限は約129.9万円/月だが、追加費用余白をほぼ使い切るため探索目標を100〜110万円とした。これは市場でその家賃の物件が見つかる保証ではない。

120万円・6か月・1200万円減の目標例の余白は**175.6万円を追加費用全体で共有**。工期+1か月だけで家賃が132万円増え、現場経費等を除いて残り43.6万円。別途の営業権代/受変電等があると簡単に超える。1億9000万円で契約前査定する比較なら、同条件で直接工事減額約1792.5万円が必要（1800万円減なら約1億8989.5万円）。1億9000万円は余裕を持つための参考比較で、ユーザーの2億円上限の変更ではない。

## 建築・設備で確認すること

深槽/座槽/炭酸泉の仮質量は約8.87t/4.82t/9.94t。水・仮RC外殻・仕上・人の在庫質量で、階段/支持脚/基礎等は含まない。水圧や募集の一律床荷重だけで支持可能と判断しない。構造図/床伏/配筋/補強履歴と支持位置から基礎まで照合する。

床上げBは梁下約3.76m、併用Cは約3.06mなら、仮頭上2.10m＋設備帯0.35mと比較できる。ただしCは床下0.70mも必要で、現平面ではB/Cの階段が干渉。これらを価格の安い代替として採用せず、階段用面積と動線を再設計してから予算化する。

新規給水の基準約23.04m³/日。シャワー6組の混合48L/minに他用途/充填ピークを重ね、給水動水圧・受水/加圧を確認する。50mmは料金用の仮定で能力保証ではない。3槽全水量10.2384m³を30分で同時に排水する比較値は5.69L/sだが、必要なら分散/貯留等を計算し同時排水を必須化しない。

機械室21㎡・主ダクト600×250mm/縦包絡0.35m・CO2/薬品局所排気・外機保守を図面と実測で照合。径1m×高2.1mの仮貯湯槽は框内0.8m扉を通らず、分割又は開口変更が必要。外入口だけでなく全経路と将来の交換まで確認する。

用途変更/確認等の適用は所在地・現況用途・対象部分・既存履歴で判定する。[国交省の改修資料](https://www.mlit.go.jp/jutakukentiku/content/001911322.pdf)。衛生基準と許可/変更は[管轄保健所での照合](https://www.hokeniryo.metro.tokyo.lg.jp/kankyo/eisei/yokujyou/yokujyou_faq)が必要で、元浴場の許可を無条件に引き継がない。港区の[2026年サウナ基準](https://www.city.minato.tokyo.jp/kankyoueiseishidou/documents/202610jyoureikaisei.html)は港区の例。他区の基準を確認したことにはならない。

## 入力と判定

Excelは4シート（物件条件/候補判定/予算境界/根拠）。物件名・所在地、全10費用値と根拠、9主要成立条件の状態・証拠・実日付を入力する。候補を特定していなくても概算金額だけは計算できるが、総合判定は資料不足。配布時は物件/費用値/証拠が全て未入力で、状態0（未確認）。

数値の0は確認した追加なし等、空欄は不明。保証金は返還予定実額、礼金/仲介/保証会社/償却は非返還初期費へ。償却を両方へ足さない。追加直接工事は基準からの**純増額**に元請/予備/税を掛け、別途の税込支払額はその他追加現金へ入れ重複させない。家賃以外の月次費用増減も入力できる。実額初期費は家賃変更時に契約に合わせ再入力する。

主要条件は、用途承諾、収まり、支持、断面、供給設備、外部経路/搬入、避難/消防/アクセス、手続き、減額/追加費の非重複の9件。状態0未確認/1根拠照合/2変更案/3成立困難の確認は点数ではない。

| 予備判定 | 条件 |
|---|---|
| 資料不足 | 物件特定、費用値/根拠、主要条件の証拠/実日付が不足。空白や「未確認」等では通さない |
| 成立困難 | 物件が特定され用途禁止等を証拠/実日付付きで確認。根拠のない否定は資料不足 |
| 予算超過・変更案未確認 | 2億を超え解消する具体策が未入力。対応可能と推定しない |
| 変更で対応 | 根拠付き変更案あり。予算超過の場合は具体的な解消案も別欄へ記録。承諾/金額/配置は再照合 |
| 成立見込み（予備判定） | 全主要条件の根拠・入力が揃い2億以下。次の調査へ進む候補で、契約判断・構造安全・許可取得の確定ではない |

Excelの確認日は実際のExcel日付（表示yyyy-mm-dd）として入力し、文字列は未確認。Pythonは実在するISO日付を照合。証拠本文の真偽や許認可の有効性を自動検証するツールではない。
