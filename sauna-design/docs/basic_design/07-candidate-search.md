## 費用式・検証・成果物

税抜万円で家賃本体をB、家賃＋共益費をR、保証金月数をd、税抜直接純減額をSとする。前工程の家賃関連を除いた定数K=19370.198204305。礼金・仲介を各税込本体家賃1か月、初回保証を税込固定費1か月とする比較用の式は、F=K+9.9R+(d+2.2)B−1.3915S。係数1.3915は元請1.1×予備費1.15×税1.1。⑦探索表の保証料0.7か月とは仮定が異なるため、前回の目標例を上書きしない。

共益費未記載は「試算外」で、存在しないと確認した0円ではない。税抜共益費が月1万円増えると、共通条件の参考総額は9.9万円増える。減額1200万円の場合、予算余白はC01約851.6万、C02約819.9万、C03約1644.6万、C04約390.6万円で、**全ての未算入費と共有する余白**。建物固有追加直接工事は同じ1.3915倍率で影響する。
