# 物件照会シート（未送信の文案）

東京で男性専用のサウナ・浴場を検討しています。館内同時40人、サウナ3室、水風呂2槽（深さ1.2m/0.6m）と炭酸泉1槽、浴室内休憩を中心とした約280㎡の計画です。物件に合わせた調整前の条件で、用途可否や施工可否は確認中です。

希望する探索条件：

- 地上階の元浴場・温浴施設を優先。計画が柱・シャフト・必要通路と両立して収まる区画。募集面積は300〜330㎡程度も対象ですが、使用可能面積と形を確認したいです。
- 家賃・共益費等の月額固定費合計は税抜100〜110万円を目標、120万円は設備再利用等の条件次第。全額返還保証金6か月以下、礼金・償却・譲渡代・その他初期費を明示してください。
- 梁下3m程度以上を比較目標とし、既存ピット・浴槽の支持・給排水・電源・ガス・換気/屋外機経路を再利用できる物件を希望します。これらの数値は法定基準や適合確認済みの最低値ではありません。

候補があれば、以下をご提示ください。

1. 所在地・階・建物用途・直下用途、募集面積の壁芯/内法/共用区分、寸法入り区画図、柱梁/PS、実梁下の断面。
2. 既存浴場等の許可/変更/廃止/承継資料と、建築確認・検査・増改築履歴の資料。
3. ピットの位置/内寸/底レベル、構造図/床伏/基礎、漏水/防水/補強履歴。掘削・支持・貫通等の許容範囲。
4. 当該区画へ割当可能な電力、単線結線図・三相電源、給水口径/動水圧・排水径/接続高さ/許容流量、ガス供給と給湯排気の条件。
5. 冷水機/空調等の屋外設置・保守区画、排気/給気経路、屋上/外壁の使用権、騒音/振動と運転時間制限、搬入・将来交換の経路。
6. 公衆浴場/湿式サウナ/ロウリュ/定期イベント・営業時間の貸主承諾、建物全体の避難/消防設備、共用部改修・バリアフリーの条件。
7. 貸主/借主の工事区分、指定業者の工事範囲/見積、工事時間・引渡/賃料発生日・免賃、契約期間/更新/建替予定・原状回復・残置設備の所有責任。

サウナ用途可という回答のみでなく、浴槽・床下・外機/排気・給排水等の工事が書面上認められるかを併せて確認したいです。不明な項目は未確認としてご案内ください。
