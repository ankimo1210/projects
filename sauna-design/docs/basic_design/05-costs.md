# ⑥ 費用試算 — 賃貸での開業総資金

更新：2026-11-15。280㎡・男性専用40人・3サ室・10/16℃の2冷槽・37℃仮定の炭酸泉1槽。成約見積りは未取得。これは工種別の**計画予算**で、工事費の市場価格を確定したものではない。物件未定のため主要な工種単価・工数・調達条件は作成者の仮定。公開定価は一部材料・機器の参考値として区別する。

低位は条件の良い物件・低い調達価格・低めの家賃等が同時に揃う場合。統計的な信頼区間でも、上振れの絶対上限でもない。賃貸案なので土地建物購入・新築費は未算入・価格未定。購入する場合の総額をゼロ追加と解釈しない。

1億/1.5億/2億は同じ見積への予算枠。基準の3か月込み総額との差は、それぞれ**1億2625.2万/7625.2万/2625.2万円の不足**。1億円は現計画の新設には厳しく、2億円は物件・既存設備・調達の条件改善を前提に目指す水準。

返還保証金は費用ではないが開業時の現金需要に含める。全額返還を仮定しており、償却があれば返還なし部分を費用へ移して税区分も再確認する。事業用賃料等と返還保証金の税の区別は[国税庁6225](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6225.htm)。消費税還付・仕入控除による後日の回収は開業現金から差し引かない。

設備が高い理由は、3つの浴槽を別の循環・薬注系統で扱い、10℃と16℃の冷却を分け、炭酸の加熱・ガス管理と6シャワーを加えるため。水面を小さくしても、系統数による固定費は比例して減らない。機器本体・配管・設置・電源を分け、メーカーのパッケージ合計と重ねない。

84項目は `plan/basic_design/cost_items.csv`。低/基準/高単価は万円で保持し、計算時に円へ換算。数量・工事範囲・根拠ID・未確認事項が各行にある。見積りがない項目を0円で埋めず、予算枠と明記した。

## 数量と単価の扱い

- 浴室/炭酸/洗い場78.60㎡から槽開口13.682㎡を一度だけ控除：水平床64.918㎡。椅子下・笠石等を含む暫定上限寄り。発注用の割付ではない。
- LIXILタイルは床に限る。床64.918㎡×ロス10%を83ケースに切上げ、概算72.21㎡（1ケース約0.87㎡換算）。槽内・サ室床・腰掛けへ流用しない。
- 槽内は底＋水深までの側壁33.314㎡、階段・水面上/端部等15%仮加算で38.3111㎡。踏面の投影を底面と二重に足さない。
- サ室床47.412528㎡、壁天井158.561328㎡。ベンチは部材表未作成で延べ22mの予算単位。一般内装とサ室皮膜を分ける。
- 独立レビューで休憩床45.45㎡と一般扉4枚の拾い漏れを修正。一般扉12・サ室扉3・入口扉1（入口一式に含む）。

メーカー/販売者公開値と採用品は異なる。[NORITZ](https://for-biz.noritz.co.jp/products/roka/roka1.html)のRAF42N230.14万・RAF112N460.24万円は税別本体の参考。今回の低温/炭酸水適合は未確認で、計上した調達価格は仮定。NC型を採るなら別薬注の重複分を控除する。温泉用上位RAOを無条件に標準にしない。

[ORION](https://www.orionkikai.co.jp/product/chiller/selection/)の能力は水温/外気/流量で確認が必要。公開20.5kW機229万円、6.1kW機116万円は比較価格で、10℃/19.70kWと16℃/6.27kWに適合した選定結果ではない。清水側と浴槽水を二次熱交換器で分離する枠を含む。[METOS](https://metos.co.jp/products/ziel)と業務用炭酸装置は公開価格なしで、見積取得済みとは扱わない。

LIXIL27,900円/㎡（税別施工別）は2026年8月改定の公式検索索引の参考値。元URLが新サイトへ転送するため、現行原表は再確認待ち。安い方の単価は値引き率が確認されたものではない。全出典と確からしさは `cost_sources.json`。

## 物件・開業準備・運転資金

基準家賃/共益費150万円/月税抜、全額返還保証金10か月、工事中賃料5か月、礼金1・仲介1・保証会社0.7か月を仮定。工事中賃料825万＋礼金165万＋仲介165万＋保証会社105万＝1260万円。保証会社費用は保険型非課税の仮定で契約時確認。アットホームの市況は5〜50坪の対象であり、84.7坪のサウナ可能物件へ当てはめない。居抜き営業権代は金額未定で別。

設計/調査/申請は税抜1060万円、便宜上10%税込枠1166万円。開業備品/広報等は税込308万、営業前の採用研修給与150万円。保険/公的手数料の一部も便宜的に税を加算した保守的予算枠で、実税計算は発注内訳確定後に置換する。現段階で外部へ依頼していない。

基準運転費は**月908.5万円**。30日・200人/日、営業時間16h＋清掃等込み18h。現場3人相当×18h×30日×雇用側負担込み2000円/h＝324万円、管理50万を別計上。外部出演/応援等は月8開催×4万円＝32万。実際の採用・休暇・シフトは未作成。

電気は[TEPCO2026年11月表](https://www.tepco.co.jp/ep/corporate/plan_h/pdf/202611minaoshisiryou.pdf)の関東高圧基本2651.50円/kW月を110kWに使用。電力量23MWh/月×調整等込み仮28円＋基本で約93.6万円。公表電力量17.47円とは区別。高圧契約可否/力率/季節/燃料市場調整は未確定。3ヒーターを営業中100%稼働のまま足す計算はしない。ガス1800m³×170円＝30.6万円は実契約でなく冬季・損失等を含む感度仮定。

新規給水は、既計算20.0384m³/日＋便所/清掃等3m³/日＝691.152m³/月。[水道一般用50mm](https://www.waterworks.metro.tokyo.lg.jp/tetsuduki/ryokin/keisan_23?area=23ku)と[下水一般汚水](https://www.gesui.metro.tokyo.lg.jp/living/fee/keisan/ryokinhyo)で約50.4万円/月。普通浴場の優遇は自動適用しない。循環量を給水量へ加えない。口径・給水能力・実際の換水/逆洗運用は未確定。

3/6か月の資金は売上相殺なしのバッファ。来客150/200/300人は予測ではない。借入元利返済・利益への税・売上連動の決済歩率を含めた損益/資金繰り計画は別。月次の金額を利益と取り違えない。

## 2億円へ寄せる具体例と残るリスク

直接工事を1200万円下げる（適合ピット再利用200万、別の既存MEP再利用500万、残工種の仕様/調達整理500万）。家賃を150→120万円/月、保証金10→6か月へ。3サ室/3槽/休憩・予備15%・運転3か月を維持した計算結果は**1億9824.4万円**、2億との差175.6万円。減額は工事1669.8万、物件費252万、返還保証金780万、開業後3か月賃料99万の合計2800.8万円。交渉済みでも、値引き可能と確認したものでもない。

調達整理500万円は各行への配賦前。再利用工事の節約と実際に重複しないことを見積段階で確認する。既存ピット利用料/修理費/営業権代が出れば差し引く。

深槽は床下1.31mが必要。基準ピット枠500万円に、主要梁/柱/基礎・建物全体補強/地下水・有害物除去・新設キュービクル・道路本管大改修・共用避難/消防/バリアフリー・長大排気/屋上補強を含めない。これらは**未算入、ゼロ円ではない**。工事の許可がなければ予備費を増やしても成立しない。

断面B/Cは現平面で階段が干渉し、Bの頭上1.34m、Cの2.04m（梁下3m仮定）。安い代替として総額比較に混ぜず、平面・階高を再設計してから差額を出す。ガス→HPは重複計上せず純差額150〜450万円の直接工事枠を示したが、屋外機/受電と冬季能力次第。運転費差は実COP/契約確認後。

## 成果物・検証・再生成

canonical data root の `cost-v1/` に計算JSON・CSV・A3 PDF14ページ・Excel5シート・検証・再生成用ソースを集約。architecture-v1/とV3〜V8を変更しない。データ規模見込み20MB未満・CPUのみ。⑦と最終内装3D統合は別、GPU保留。

- 24テスト（既存20＋費用4）成功。税・返還保証金・欠測/重複範囲・上下水道/数量を確認。
- Excelは単一明細から数量×単価を計算し集計。Python独立計算と低/基準/高/目標を照合。家賃変更、数量空欄/ゼロ、復元後の再計算と式エラー0を確認。Excelデスクトップ本体での再計算は未実施。
- PDF全14ページをCPUで描画し全ページの改ページ/重なりを目視。表のはみ出しは生成時にも検査。
- 独立レビューで床・扉の拾い漏れを修正し、総額/保証金/減額の集計を再照合。
- 凍結済V3〜V8の463ファイルと建築資料マニフェスト91ファイルのハッシュ不変、同じFable会話の原本/控え一致、配布コピー/ZIP整合を確認。cost-v1/実測約9.03MB、配布ZIP約0.55MB。

再生成は専用worktreeの `scripts/` から `python -B -m basic_design.costs`、`python -B -m basic_design.cost_report`（CPU）。Excelは同梱のartifact-tool環境で `cost_workbook.mjs 入力JSON 出力フォルダ`。成果物は再計算後に保存し、配布コピーのハッシュとZIPを照合する。
