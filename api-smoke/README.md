# OpenAI と Anthropic API のスモークテスト

架空の円建て債券ポートフォリオを同じ課題として与え、構造化 JSON、Python の
Tool Calling、日本語説明と計算結果の整合性を確認する。網羅的な性能評価ではない。

## 仕様と実行計画

- [x] 手計算の正解値と、不正なスキーマ・引数・説明を検出するローカルテストを作成する。
- [x] 共通課題とネイティブ JSON Schema 出力を使う HTTP クライアントを実装する。
- [x] 各社で自動のツール選択を実測する。OpenAI は Python 実行から最終回答まで成功、Anthropic はツール未使用で FAIL。
- [x] レスポンス・レイテンシー・トークン数・PASS/FAIL を保存し、ローカル検証を完了する。

Python 3.12 以上と `jsonschema` を使用する。HTTP は標準ライブラリで実行し、SDK は不要。
このワークスペースではルートの共有 `.venv` を使用し、新しい仮想環境は作らない。
`requirements-dev.txt` はテスト用依存の宣言であり、今回の作業では追加インストールしない。

## 架空データと照合範囲

| 銘柄 ID | 時価（円） | 金利 DV01（円/bp） | スプレッド DV01（円/bp） |
|---|---:|---:|---:|
| JGB_2Y | 60,000,000 | 12,000 | 0 |
| JGB_10Y | 100,000,000 | 85,000 | 0 |
| CORP_5Y | 80,000,000 | 36,000 | 32,000 |

金利 +25 bp、信用スプレッド +40 bp を与え、各リスク要因の損益を
`-DV01 × shock_bp` で計算する。DV01 は架空の固定値で、凸性・キャリー・為替は扱わない。
正解は金利 -3,325,000 円、スプレッド -1,280,000 円、合計 -4,605,000 円。
最大損失銘柄は `CORP_5Y`（-2,180,000 円）、最大リスク要因は金利。

最終出力は共通 JSON Schema で検証する。配列件数と本文の非空は、スキーマ適合とは
別の整合性チェックで評価するため、JSON の PASS は内容の正確性を意味しない。
数値・銘柄・リスク方向を照合し、日本語の説明と総括は正解値を埋め込んだ限定的な句形で
厳密照合する。例えば「合計損益は-4605000円の損失です。」は合格するが、その数値を
含む否定文は合格しない。照合対象外の言い回しも手動確認が必要な FAIL とする。
一般的な文章力や自由文全体の意味、投資判断の妥当性を保証する検証ではない。

## 実行

リポジトリのルート `/home/kazumasa/projects` から実行する。
キーは実行プロセスの `OPENAI_API_KEY`、`ANTHROPIC_API_KEY` に安全に設定しておく。
キー本体をコマンドラインに書かない。`.env` の自動読込みは行わない。

```bash
uv run --no-sync python -m unittest discover -s api-smoke -p 'test_*.py' -v
uv run --no-sync python api-smoke/smoke.py
```

通常経路は各社 2 回の生成リクエスト。最初は `tool_choice=auto`、Python 実行後は追加の
ツール呼出しを禁止して最終回答を得る。自動再試行はなく、HTTP エラーやツール未使用も
そのまま FAIL として記録する。既定モデルは `gpt-6-luna` と `claude-haiku-5-5`。
`--openai-model`、`--anthropic-model`、`--output-dir` で変更できる。

出力は既定で `_data/api-smoke/<UTC時刻>/` の `results.json` と `summary.md`。
API リクエスト本文・レスポンス、Python の実行結果、各 HTTP 呼出しのレイテンシーと
入出力トークン数を記録する。認証ヘッダーは記録せず、保存時にキー文字列も除去する。
料金は今回、公式単価を確認しないため算出しない。Web 検索、ブラウザー操作、
コンピューターユーズ、残高照会は実装しない。

## 実測結果

2026-11-01 15:49 JST に実行。両社で同一の初回プロンプトと JSON Schema を使用した。
結果はこの 1 課題・1 試行での観測であり、API 機能の一般的な非対応を示さない。

| API / model | JSON | Tool Calling | 計算と日本語説明 | HTTP回数 | HTTP合計秒 | 入力 / 出力token |
|---|---|---|---|---:|---:|---:|
| OpenAI / gpt-6-luna | PASS | PASS | PASS | 2 | 5.457 | 2087 / 385 |
| Anthropic / claude-haiku-5-5 | PASS | FAIL | FAIL | 1 | 2.829 | 2218 / 148 |

- OpenAI は自動で `calculate_pnl` を呼び、Python の結果を返送後、合計 -4,605,000 円と整合する日本語説明を返した。
- Anthropic はツールを使わず、`total_pnl_jpy=-6`、空の銘柄配列・リスク配列・説明文を返した。HTTP エラーや打切りではなく、スキーマには適合するがタスク内容には適合しない回答だった。
- 修正案は、計算精度の責務とツールの用途をプロンプトで明確化し、両社に同じ修正版を与えて別の比較を行うこと。今回の未使用だけで Anthropic の Tool Calling が非対応とは判定しない。強制呼出しを自動選択の成功として代用しない。
- 実 API は合計 3 リクエスト、再試行なし。思考は両社とも無効。料金は未算出。
- レビューで、否定文による説明の矛盾、初回応答の打切り、不正な応答・usage の形による記録喪失を検出し、失敗する回帰テストを追加して修正した。ローカルテストは 15 件すべて成功。
