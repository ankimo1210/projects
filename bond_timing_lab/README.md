# bond_timing_lab：債券タイミングの売買シグナル（候補9）

**結論：判定は `no_usable_signal`（本番 B の1回目、記録値）。** 2000〜2018年の本番 A で、ずっと保有に有意に勝つ戦略はなかった。最もよかったのは利回りの主成分の OLS（P2、CER +1.7%/年）と NN（P4、+1.5%/年）で、本番 B でも保有に勝ったが、Holm 補正後の p 値は 0.83 と 0.49。ただし、この検定は年数%の改善を検出できない（G1 の検出力の表）ので、「シグナルがない」ことを示したわけではない。マクロの上乗せ（10年ゼロでの P4−P2、+0.9%/年）は、マクロが効かない世界と区別できなかった（G3 の p=0.15）。原論文に近い設定（V0）でも NN の R²oos は負で（−14〜−18%）、原論文の値は再現しなかった。

## 何を調べたか

- 出発点は Bianchi, Büchner, Tamoni, "Bond Risk Premiums with Machine Learning"（RFS 34(2) 1046–1089, 2021）と、その訂正論文（Bianchi, Büchner, Hoogteijling, Tamoni, RFS 34(2) 1090–1103）。訂正論文は「予測の時点で入手できない情報を使っていた」ことを直したもので、訂正後の数値と直した中身は確認できていない。
- 問い：月末ごとに米国債（TLT 型の合成ゼロクーポン債）を「持つか、現金か」で切り替えるシグナルが、時点の規則を守り、費用を引いたあとでも、ずっと保有と単純なルールに勝つか。ML は、単純なルールと線形モデルに費用込みで勝つときだけ採用する。
- 設計書：`/home/kazumasa/projects/docs/superpowers/specs/2026-10-19-bond-timing-ml-design.md`。事前登録：[PREREG.md](PREREG.md)。

## 手順

- 時点の規則：R1（判断 t には t までに観測できたデータだけ。マクロはビンテージ t−1 で、系列ごとに公表の遅れを持たせる）、R2（学習には目的変数が確定した組だけ）、R3（候補の値の選択は後ろ15%で、h か月の空白を置く）、R4（標準化・主成分・欠損の処理は学習の窓の中だけで作る）、R5（感度として、翌月の5営業日目に執行）。
- 階段：L0（ずっと保有・ずっと現金）、L1（傾き・trend・CP の単純ルール）、L2（利回りの主成分の OLS、マクロ因子つき）、L3（Elastic Net・Extra Trees・勾配ブースティング・NN）。毎年1月に推定し直す。
- 主な戦略5本：P1（開発期間で選んだ単純ルール）、P2（主成分3つの OLS）、P3（P2＋実時間のマクロ因子8つ）、P4（NN、フォワード＋マクロ、初期値20通り）、P5（Extra Trees、フォワード＋マクロ）。
- 検定：同じ月の差の系列に定常ブートストラップ（平均ブロック12か月、1万回）。H_A は P1〜P5 対ずっと保有（Holm 5本）、H_B は P4・P5 対 P1（Holm 2本）、片側5%。費用は切り替え1回 2bp（感度 4bp）。
- 道具の確認：G0（データ）、G1（シグナルのない世界 W0 と、マクロのシグナルを埋め込んだ世界 W2）、G2（漏れの検査、単体テスト）、G3（Bauer–Hamilton 型：マクロが効かない世界との比較）。
- 事前登録：`PREREG.md` を commit 1c7fac58 で固定してから、G1 と本番 A を初めて回した（結果の JSON の `meta.prereg_commit`）。
- PREREG の前の変更（ユーザーの決定、2026-10-19）：G1 の W2（埋め込んだシグナルの検出）は、合成データで確かめた検出力が足りず、道具が正しくても設計の「20回中18回」に届かないため、合否から外して検出率の報告にした（PREREG §4）。合否は W0（偽陽性）だけで判定する。本番 A の判定の検定は変えていない。

## 限界

- 判定は合成の TLT 型（17年ゼロ）で出した。実際の TLT とは、クーポン・凸性・経費で違う（月次の相関 0.979、年率の差の平均 1.4%）。
- 2000〜2018年は債券の上昇相場で、ずっと保有に勝つのが難しい期間。本番 B は92か月と短い。
- 検定の検出力が低い（G1）。判定が `no_usable_signal` でも、年数%の改善がないとは言えない。
- 再推定は毎年1月（設計書 §6.3）。V0 の「s ≤ t−1」は1月の判断にしか効かず、毎月推定し直す原論文より、目的変数の重なりによる先読みが小さい。原論文が再現しない理由の候補の一つで、毎月推定し直す V0 で確かめていない。
- 訂正論文の中身と訂正後の数値は確認できていないので、論文の訂正後の値とは比べていない。
- FRED-MD の公開日が分からないので、判断 t にはビンテージ t−1 を使うと仮定した。
