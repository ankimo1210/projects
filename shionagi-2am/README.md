# 汐凪市 午前2時（shionagi-2am）

肩越し三人称視点の短編 3D サバイバルホラー。豪雨で停電した架空の港町・汐凪市で、渡船ターミナルの夜勤設備員が
避難先の汐凪警察署をめざす。弾は数発しかなく、撃つか、やり過ごすかを毎回選ぶ。

- PC ブラウザ向け（Three.js / TypeScript / Vite）。画像・音声ファイルは 1 つも持たず、
  街並み・看板・人物・効果音・環境音はすべてコードで生成している（本作独自）。
- 進捗と検証結果は [docs/STATUS.md](docs/STATUS.md)。

## 起動

```bash
cd shionagi-2am
pnpm install          # pnpm が PATH に無い環境では npx --yes pnpm@11.1.0 install
pnpm dev              # http://localhost:5183/ を Chrome で開く
```

| コマンド | 内容 |
|---|---|
| `pnpm dev` | 開発サーバー（ポート 5183） |
| `pnpm build` / `pnpm preview` | 型チェック＋本番ビルド（`dist/`）／ビルドの確認（ポート 5184） |
| `pnpm test` | 単体テスト＋自動プレイによる全ルート通しテスト（Vitest、ブラウザ不要） |
| `pnpm lint` / `pnpm typecheck` | ESLint ／ `tsc --noEmit` |
| `pnpm e2e:smoke` | 実ブラウザ・実入力イベントでの操作確認（要 `pnpm dev` 起動中、Google Chrome） |
| `pnpm e2e:normal` / `pnpm e2e:pacifist` | 実ブラウザで各ルートを等速で通す（スクリーンショット付き） |
| `pnpm e2e:audio` | 全効果音を録音してスペクトログラムと WAV を出力 |

e2e の出力はリポジトリ外扱いの `../_data/shionagi-2am/` に置く。

## 操作

| 入力 | 動作 |
|---|---|
| `W` `A` `S` `D` | 移動 |
| マウス | 視点（画面クリックでポインターを捕捉） |
| `Shift` | 走る（速いが足音が遠くまで届き、見つかりやすい） |
| `E` | 調べる・拾う・扉や操作盤を動かす／死亡後のやり直し |
| 右クリック（押している間） | 拳銃を構える |
| 左クリック | 撃つ（構えている間だけ） |
| `Esc` / `P` | 一時停止 |

画面表示は体力（左下・4 目盛り）、残弾（右下・拳銃を持ってから）、必要な場面の操作案内だけ。

## 進行（最短で約 210 m、4 場面）

1. **渡船ターミナル** — 曇ったガラスの外を人影が引きずるように歩いていく。非常口の灯りをたどり、
   職員通路の扉 → 裏口の順に `E` で開けて搬入路へ出る。
2. **商店街「なぎさ通り」** — 大通りは街灯とパトカーの回転灯で見通しがよいが敵が多い。
   東側の裏路地は暗く狭いが、眠っている 1 体のほかは誰もいない。2 本の横道（南・北）でつながっている。
   拳銃（5 発）は南の横道の出口、パトカーのボンネットの上。救急箱（体力 +50）は大通りと裏路地に 1 つずつ。
3. **水門管理所** — 岸壁の操作盤で歩道橋を下ろす（12 秒）。巻上機の音で構内の敵が集まる。
   小屋の陰で待つ／わざと見つかって小屋を回り込む／撃って道を開ける、のどれでも渡れる。
   門の詰所に予備の弾（3 発）。
4. **警察署前庭** — 橋の先に玄関の誘導灯だけが見える。暗がりから声がして、落雷で 3 体が動き出す。
   玄関まで走り、`E` で扉に手をかけた瞬間に暗転してクリア。

敵は前方の視界（約 13 m）と物音に反応する。歩く足音は約 2.4 m、走ると約 10 m、銃声は約 46 m 届く。
敵の追跡は走れば振り切れる速さ。体力は 4 回の被弾で尽き、直前のチェックポイント
（開始／搬入路／交差点／前庭）から体力 60 以上でやり直せる。

## 構成

```
src/
  sim/      ゲーム本体。DOM も three.js も使わない固定 60Hz の決定的シミュレーション
    level.ts   マップ定義（当たり判定・見た目・照明・敵配置を 1 か所で記述）
    sim.ts     プレイヤー、敵 AI（視界・聴覚・追跡）、射撃、橋、チェックポイント、調整値 TUNE
    camera.ts  肩越しカメラ（壁際で寄る・反対の肩へ回る）
    nav.ts     0.25 m グリッドの A* 経路探索
  view/     描画（three.js）。sim を読むだけで、sim には書き込まない
  audio/    Web Audio による音の合成（雨、足音、声、軋み、橋、防災無線 など）
  ui/       HUD とタイトル・一時停止・死亡・クリア画面
  input.ts  キーボードとマウス
  dev/      検証用の自動プレイヤー（bot.ts）と、それを実 DOM イベント経由で動かす橋渡し
tests/      Vitest（sim / level / ルート通し）
e2e/        実ブラウザ検証スクリプト（Playwright で手元の Chrome を操作）
```

キーボード・マウスも自動プレイヤーも、同じ `sim.step(入力)` と `sim.applyLook()` だけで
ゲームを動かす。そのためブラウザを使わないテストでルート全体を再現できる。

## テストと検証

- `tests/sim.test.ts` — 移動、扉、カメラ、敵の視界・聴覚、被弾・死亡・リトライ、射撃、橋、
  クリア、「姿より先に音が届く」場面のタイミング。
- `tests/level.test.ts` — 扉と橋による進行の区切り、両ルートの連結、配置物が歩行可能な床にあること。
- `tests/routes.test.ts` — 自動プレイヤーで全行程を通す。通常ルート（大通り・拳銃使用）、
  弾を使わないルート（裏路地・発砲 0）、橋の 3 通りの切り抜け方、乱数シード 24 通りの頑健性。
- `e2e/smoke.mjs` — 本物のキー・マウスイベントで開始、移動、扉、拳銃、一時停止、被弾、死亡、
  リトライ、クリア、もう一度、を確認。
- `e2e/playthrough.mjs <normal|pacifist> <出力先> [direct|dom]` — 実ブラウザで等速の通しプレイ。
  `dom` を付けると自動プレイヤーの操作を実際の DOM キー／マウスイベントとして流す。
- `e2e/audiolab.mjs` — 全効果音を鳴らして録音し、スペクトログラム（PNG）と WAV、音量表を出力。
- そのほかの補助: `perf.mjs`（高解像度での fps）、`tts.mjs`（防災無線の読み上げ）、
  `glass.mjs`（冒頭のガラスの人影）、`tour.mjs` / `shot.mjs` / `sheet.mjs`（各所のスクリーンショットと一覧化）、
  `botrun.mjs`（倍速の通し）。

e2e はどれも開発サーバー（`pnpm dev`）に接続し、手元の Google Chrome を消音・ヘッドレスで動かす。
本番ビルドを対象にするときは `SHIO_URL=http://localhost:5184`（`pnpm preview`）を付ける。

自動プレイヤーは人と同じ入力（キーのオン／オフと、回転速度に上限を付けた視点操作）だけを使い、
敵については「見えているか、聞こえる距離にいるもの」しか参照しない。道順は知っている。

### 開発用 URL パラメータ

| パラメータ | 効果 |
|---|---|
| `?bot=normal` / `?bot=pacifist` | 自動プレイヤーに操作させる |
| `&via=dom` | 自動プレイヤーの操作を実 DOM イベント経由にする |
| `&aim=head` | 自動プレイヤーが頭を狙う（既定は胴体） |
| `&bridge=lure` / `&bridge=shoot` | 橋の場面の切り抜け方（既定は物陰で待つ） |
| `&autostart` `&nolock` `&speed=4` `&dev` | 即開始／ポインター捕捉なし／倍速／デバッグ表示 |
| `&tts=0` | 防災無線の読み上げ（OS の音声合成）を止める |

## 調整するとき

- 手触りと難度は `src/sim/sim.ts` の `TUNE`（移動速度、音の届く距離、敵の視界・速度、弾数など）。
- 配置は `src/sim/level.ts`。変更したら `pnpm test` で両ルートが通ることを確認する。
- 音量バランスは `src/audio/audio.ts`。耳で確かめられない環境では `pnpm e2e:audio` の表と画像で見る。

## 既知の制限

- 人物は関節人形に近い簡素なモデルで、アニメーションも手続き的。
- 防災無線の言葉は OS の日本語音声（macOS なら Kyoko など）に依存する。無い環境では
  チャイムと、言葉の聞き取れない拡声器の声になる。
- PC のキーボード＋マウス専用。ゲームパッド、タッチ操作、設定画面（感度・音量）は無い。
