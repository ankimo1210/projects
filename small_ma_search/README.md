## 調査済みの要点

再調査せずに使える、構造的に安定した事実。

- **沖縄では日本政策金融公庫を使わない。** 沖縄振興開発金融公庫が同等業務を一元的に担う。
  同庫の「事業承継コネクト」は無料のマッチング支援（買い手個人の登録可否は未確認）
- **チャネルで売り手の質が偏る**（2021年版中小企業白書）。事業引継ぎ支援センター経由は
  赤字傾向 56.3%、M&A仲介経由は黒字傾向 47.9%。「公的機関だから優良」ではない
- **価格は最優先ではない。** 中小企業の経営者は雇用維持のためなら価格引下げに応じることがある。
  個人買い手が事業会社に競り勝てる唯一の経路（現場に入る／雇用を変えない／屋号を残す）
- **BATONZ からの自動データ取得は不可。** 利用規約 第19条第10号がクローリング・スクレイピング・
  生成AIへの利用を明示的に禁止。robots.txt でも ClaudeBot に `Crawl-delay: 60` を指定。
  TRANBI は明示の禁止条項が見当たらないが、案件詳細はログイン必須

## 陳腐化に注意

後継者不在率・補助金の枠と上限・プラットフォームの料金体系は**毎年変わります**。
`roadmap.html` の数値は 2026年8月時点の確認値で、出典リンクをページ末尾に置いてあります。

既に一度更新が入った例：沖縄の後継者不在率 67.7%（古い記事）→ **61.0%**（帝国データバンク2025年）。
全国平均 50.1% / 東京 47.9% / 神奈川 55.8%（いずれも2025年）。
