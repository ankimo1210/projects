# 改定記録 2026-08-17 — 指標の実データ化と、株価による事後検証

前版（`226cb936`）からの改定と、その結果として**結論が2つ反転した**ことの記録。
指標の定義そのものは [METHODOLOGY.md](METHODOLOGY.md) が正本で、ここには
「何を変えたか」「なぜ順位が動いたか」「株価で測ったら何が起きていたか」だけを書く。

## 要旨

1. **情報・通信業は右上象限の筆頭ではない。** 脱出ポテンシャル 74.8 → 54.4（1位 → 7位）。
   1位は不動産業 67.0。動かしたのは重み配分ではなく、**analyst が置いていたセルを
   公表統計に差し替えたこと**（下の「なぜ順位が動いたか」で分解した）。
2. **右上象限（AI解放）は、AIラリー開始以降ユニバースを下回っている。**
   2022年11月末を100として2026年8月末で AI解放 189.6 に対しユニバース全体 220.2。
   勝ったのは AI増益象限 251.9 で、中身は銀行・証券・保険＝金利であって
   AIによる人件費削減ではない。**この枠組みが指す先は、まだ株価では報われていない。**

## 1. 何を変えたか

| 項目 | 前版 | 今版 | 理由 |
|---|---|---|---|
| X軸の指標 | 6本（TDB 正社員不足割合 0.25 を含む） | 6本（**短観 雇用人員判断DI 0.30** に置換） | TDB は51業種のうち上位10業種しか公表されず、残りは analyst 内挿になる。短観は41業種分が公表され東証33業種にほぼ1対1で当たる |
| 有効求人倍率の重み | 0.25 | **0.20** | ハローワーク経由しか映さない。建設・保安で過大、情報処理・ホワイトカラーで過小という経路バイアスがある |
| 欠員率 | 手置き（全産業アンカー 2.9%） | 雇用動向調査 令和7年上半期（**2.6% / 2025年6月末**） | 前版のアンカーが古かった。e-Stat 側の該当テーブルは2021年で止まっているため、厚労省公表の `zuhyo.xlsx` を直読みする |
| Y軸 | `llm_potential` と `phys_potential` の2本立て | **ILO WP140 の単一 `ai_potential`** | ILO の index は生成AI exposure の1本で、物理的自動化はほぼ考慮されていない。2本に割るのは出典に無い区別を足すことになる |
| 職業構成比 | 手置き | **労働力調査 表2-5-1**（e-Stat `0003024266`、産業×職業） | 職業別の ILO スコアを業種に写すための唯一の公式な橋 |
| 感応度シナリオ | `robotics_weight` の振り | **6指標の leave-one-out** | Y軸が ILO 公表値で固定された結果、振るパラメータが AI軸側から消えた |
| 生成の経路 | reference TOML を直接編集 | **`tools/build_reference.py` が3つの TOML を再生成** | 手置きセルの全廃。差分を見れば出典と時点が追える |

数値の入っていない判断値は**規制ドラッグだけ**残した（0.03〜0.18、法令上の人的要件が
根拠、[METHODOLOGY.md §3](METHODOLOGY.md) に一覧）。効果は代替割合を最大18%下げる程度で、
順位を入れ替えない（例：銀行業 51.8% → 44.0%）。

## 2. なぜ順位が動いたか（情報・通信業の分解）

「短観DIを入れたから落ちた」は**誤り**。実測すると、今版から DI を外して5指標に
再正規化しても 7位 → 6位しか戻らない。有効求人倍率を 0.25 に戻しても 7位 → 6位。
落としたのは重み配分ではない。

| | 前版 | 今版 |
|---|---|---|
| 人手不足スコア | 55.9 | **34.4（16位/33）** |
| AI代替スコア | **100.0（上限）** | 86.1（6位/33） |
| 脱出ポテンシャル | 74.8（**1位**） | 54.4（**7位**） |

X軸を指標ごとに見ると、原因は2つに絞れる。

| 指標 | 前版の値と順位 | 今版の値と順位 |
|---|---|---|
| TDB 正社員不足割合 | 68.0% — **1位/33**（重み0.25） | 廃止 |
| 短観 雇用人員判断DI（符号反転） | — | +32 — 14位/33（**中位**） |
| 欠員率 | 2.60% — 9位/33（手置き） | **1.80% — 27位/33**（公表統計） |
| 55歳以上就業者比率 | 18.0% — 33位 | 16.9% — **33位（最下位）** |

- **前版は TDB の1位で持っていた。** 前版のまま TDB だけ外すと 74.8 → 58.6（1位 → 3位）。
  他の5指標はどれを外しても1位のままなので、順位はこの1本に依存していた。
  TDB は51業種の分類で「情報サービス」が全業種中1位に出る調査であり、
  33業種に写した時点で情報・通信業がX軸の最上位になることが決まっていた。
- **欠員率を実データにすると9位 → 27位。** 手置きの 2.60% に対し、雇用動向調査の
  情報通信業は 1.80%（全産業 2.6%、陸運 4.1%、建設 3.5%）。IT は
  「募集して埋まっていない実数」では不足産業の上位ではない。
- 55歳以上比率が最下位というのは前版でも同じで、若い産業なので将来圧力が最小。

Y軸も 100.0 → 86.1 に下がった。前版は手置きで情報・通信を上限に置いていたが、
ILO の職業別スコアを表2-5-1 で写すと、事務職比率の高い金融（その他金融100.0、
銀行・保険・証券94.8）が上に来て、情報・通信は卸売業（86.2）とほぼ同値になる。

## 3. 株価による事後検証

象限は供給制約への感応度の地図であって株価の予測ではない。だが「市場はもう
織り込んだのか」は別に測れる。`tools/quadrant_performance.py` が、ChatGPT公開
（2022年11月末）を100とする象限別の等ウェイト指数を作る。

| 象限 | 銘柄数 | 等ウェイト指数 | 中央値リターン |
|---|---:|---:|---:|
| AI増益 | 458 | **+151.9%** | +81.5% |
| 低感応 | 472 | +118.1% | **+89.1%** |
| 人手依存 | 366 | +109.7% | +56.7% |
| **AI解放（右上）** | 315 | **+89.6%** | +69.5% |
| ユニバース全体 | 1,611 | +120.2% | +76.5% |

**右上象限は、等ウェイトでも中央値でもユニバースを下回る。**
最下位は指標により変わる（等ウェイトでは AI解放、中央値では人手依存）が、
「右上が勝っていない」という向きは両方で一致する。

業種別の中央値で見ると、勝者と敗者がはっきりしている。

| 上位 | | 下位 | |
|---|---:|---|---:|
| 銀行業 | +399.9% | サービス業 | +8.6% |
| 証券、商品先物取引業 | +207.8% | 陸運業 | +14.6% |
| 鉱業 | +186.0% | 空運業 | +17.0% |
| 倉庫・運輸関連業 | +173.8% | 医薬品 | +23.7% |
| 保険業 | +172.3% | 水産・農林業 | +25.4% |

- 勝ったのは**金利（銀行・証券・保険）と半導体**で、AIによる人件費削減ではない。
  これらが AI増益象限に入っているのは事務職比率の高さ（ILOスコア94.8）による偶然の一致で、
  株価を説明しているのは象限ではなく金利局面である。
- **前版が推していた2業種が最下位近辺**（情報・通信業 +30.4%、サービス業 +8.6%）。
  これは前版から書いていた「受託型の削減は値下げとして顧客に流出する」という
  留保（[METHODOLOGY.md §6](METHODOLOGY.md)「この計算が言っていないこと」）が、
  そのまま株価に出た形と読める。

### この検証が言っていないこと

- **象限は look-ahead で当てている。** 2025-26年のデータで付けた区分を2022年11月に
  遡って適用しており、当時それが分かっていたわけではない。リバランスもしていない。
- **生存バイアスがある。** ユニバースは現行TOPIX構成銘柄なので、期間中に上場廃止に
  なった銘柄が最初から居ない。全象限が一様に上振れする。
- **起点に株価が無い銘柄（期間中の新規上場）は除外**しているので、1,642社 → 1,611社。
- 「右上が負けた」は「右上の仮説が間違い」を意味しない。3年で織り込まれる話ではない
  可能性と、そもそもこの区分に株価の説明力が無い可能性の両方が残る。

### 配信データの異常値

**8303 SBI新生銀行の Yahoo Finance 配信が壊れている**（負の調整後終値と 5.4e10 の
スパイク）。1銘柄で AI増益象限の等ウェイト指数に月次▲40%の穴が空いていた。
`sanitize()` で月次変化率が4倍を超える／0.25倍を下回る／負値を含む銘柄を落とす。
除外後、指数の月次最大変化は 14.7% に収まっている。**等ウェイト指数を作るときは、
1銘柄の配信バグが数百銘柄の平均を壊せることを前提に検算する。**

## 4. 再現手順

`_data/` は gitignore なので、リポジトリには入っていない。

```bash
# 1. 公表統計のスナップショットを _data/sources/ に置く（一覧は build_reference.py の冒頭）
# 2. reference TOML を3つ再生成（ネットワーク不要）
uv run python labor_ai_quadrant/tools/build_reference.py

# 3. 既存の銘柄リストと財務で再スコア（ネットワーク不要・象限の移動も表示）
uv run python labor_ai_quadrant/tools/rescore_topix.py

# 4. 株価の事後検証（Yahoo Finance、_data/prices_monthly.json にキャッシュ）
uv run python labor_ai_quadrant/tools/quadrant_performance.py
```

`rescore_topix.py` は `_data/topix_scored.csv` を**上書きしながら**旧版と比較する。
比較したい版を残す場合は先に退避すること（この改定では旧版の象限を
`git archive HEAD` で取り出した旧コードから再構成して確認した）。

## 5. データ側の落とし穴（次に触る人向け）

- **e-Stat の欠員率テーブルは2021年で止まっている。** 厚労省の公表 Excel を直読みする。
- **短観のコード説明ページは信用できない。** 項目位置がずれている。公表DI値
  （2026年6月調査：全産業▲37、製造業▲27、非製造業▲43）で項目608を指紋照合してから、
  shift_jis の `tankan_code.html` を読む。
- **労働力調査の年齢階級コードは `15` と `16`+`17` で揺れる。** 加えて万人単位の丸めで
  小さい業種の分母が消える。素直に足すと建設業16.7%・鉱業/空運0.0% という嘘が出る。
  `older_share()` で親分類にフォールバックする。
- **表2-5-1 の細分類の内訳合計は産業合計に届かない**（丸めと秘匿）。残差を親の大分類の
  職業構成で按分している。**鉱業と石油・石炭製品は約50%が按分由来**なので、
  この2業種の職業構成は弱い。
- **有効求人倍率は倍率を平均してはいけない。** Σ有効求人 ÷ Σ有効求職 で組み替える。
- worktree の `.venv` には他ワークスペースメンバーが入っていないため、ルートの
  `conftest.py` が import に失敗する。`--noconftest` を付けて回す。

## 6. 残っている限界

- 規制ドラッグは公表統計ではなく判断値。順位は動かないが、絶対水準の根拠は弱い。
- 鉱業・石油石炭の職業構成は按分依存（上記）。
- 象限の区分は company-level の傾き（`labor_intensity` / `knowledge_tilt`）を
  持つが、J-Quants からは企業属性が取れないため全社 "mid"。実質は業種スコアの転写。
- `verify-universe` のキュレーション211銘柄のうち5件が現行上場リストに無い
  （3141 / 7205 / 9613 / 9719 / 9787）。銘柄選定の判断が要るので未着手。
