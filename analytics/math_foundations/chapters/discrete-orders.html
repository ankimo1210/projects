半順序と比較不能

資料を集める作業 A と、図を作る作業 B は、どちらを先に進めてもよいとします。ただし両方が済むまで本文 C は完成できず、本文 C の後に点検 D を行います。A、B の間には先後がなくても、全体には守るべき順序があります。

大小の順序に慣れると、比較できない二つがあることを欠陥に感じるかもしれません。この章では、必要な比較だけを持つ半順序を定義し、矢印で表した先行条件を一本の実行順へ並べられる条件を証明します。後のグラフの知識は前提にしません。

学習の目安は演習込み110–160分です。半順序と被覆関係、実行順を作る手順、一意性と条件の設計の三回に分けられます。演習1–3は基本、4–7は定義と手順の診断、8–10は設計・証明・逆算です。作業例は本章のための自作モデルです。

半順序と全順序

集合 X 上の関係 ≼ が次の三条件を満たすとき、半順序と呼びます。記号 ≼ は、問題に応じて「以下」「含まれる」「先行してよい」などと読みます。

整数の ≤ も半順序です。集合 {a, b} の部分集合全体での ⊆ も半順序ですが、{a} と {b} の間にはどちら向きの包含もありません。この二つは比較不能です。任意の x、y に x ≼ y または y ≼ x が成り立つ半順序は全順序です。半順序は比較不能を許し、全順序は許しません。

反対称は「対称でない」の言い換えではありません。対称律は xRy ⇒ yRx、反対称律は両方向が成り立つなら x = y という条件です。等号 = は両方を満たします。前章の「差が 3 の倍数」は対称ですが、0 と 3 のような異なる二つでも両方向が成り立つため、整数上で反対称ではありません。

x ≼ y かつ x ≠ y を x ≺ y と書きます。また、x より真に小さい要素がないとき x を極小元、すべての y に x ≼ y となるとき x を最小元といいます。集合族 {{a}, {b}, {a, b}} では {a} と {b} が極小元で、最小元はありません。最小元があれば反対称律により一つだけですが、極小元は複数ありえます。

整除による半順序

最小元と極小元の区別を、次節の図の読み方へつなげます。ここで順序を逆向きに読んだ用語も定めます。xより真に大きい要素がないときxを極大元、すべてのyについてy≼xならxを最大元といいます。最小元・最大元は存在すればそれぞれ一つですが、存在しないこともあります。

例題1：数の大小と割り切れる順序を区別する

X={1,2,3,4,6,12} で、x≼yを「xがyを割り切る」とします。xは自分を割り切り、y=kxとz=ℓyならz=ℓkxなので推移律があります。両方向に割り切れるならx=ℓkxとなり、x>0からkℓ=1。正整数k,ℓはともに1となるので反対称律も成り立ちます。ここで正の整数という条件を使いました。

最小元は1、最大元は12です。すべてのxが1の倍数であり、12はすべてのxの倍数だからです。しかし3と4はどちらも他方を割り切らず、比較不能です。普通の数の大小3<4を、ここで選んだ順序と混同してはいけません。

同じ順序を部分集合Y={2,3,4,6}だけに制限すると、極小元は2と3、極大元は4と6です。2は3を割り切らず、3は2を割り切らないので最小元はありません。4と6も比較不能なので最大元はありません。有限なら数として一番小さい値はあっても、その要素がこの順序の最小元とは限りません。

次節では「割り切れる組を全部描く」代わりに、その比較を復元するために必要な線だけを残します。例題1のXでは、1から12への比較が、どの中間点を経由して分かるか考えてください。

被覆関係とハッセ図

有限の半順序を図にするとき、x ≺ y のうち、間に x ≺ z ≺ y となる z がない組だけを線で結びます。y を x より上に置き、自己関係と推移律で分かる線を省いた図がHasse 図です。線の上向きを「小さい方から大きい方」と読む約束なので、矢印の先端も省きます。

この「xとyの間に、別の要素を挟めない」という組を被覆関係と呼びます。省くのは比較そのものではなく、途中の要素を経由すれば復元できる線です。

有限であれば、比較 x ≺ y の間に中間点があるたび線を分ける操作は、点の数に限りがあるので終わります。従って省いた比較も上向きの線の連鎖から復元できます。ただし図に直接線がないことだけでは、比較不能とは限りません。下から上へたどる連鎖があるかを調べます。

被覆関係を計算して比較を復元する

例題1のX={1,2,3,4,6,12}に戻ります。x≺yとなる組を見付けたら、間に別の約数zがXの中にあるか調べます。間の数は全整数からでなく、今扱っているXから選ぶのが重要です。たとえばX={1,12}だけなら、1と12の間の点は存在せず、1–12は被覆になります。

例題1の続き：残す線を一つずつ選ぶ

1より上の要素2,3,4,6,12のうち、4は2を、6は2か3を、12も2を間に挟めるので、1から直接残すのは2と3だけです。2の上の4,6,12では、12の間に4や6が入るので2–4、2–6だけを残します。3の上では3–6を残し、3–12は6を経由して省きます。最後に4–12と6–12を残します。

合計7本、すなわち1–2、1–3、2–4、2–6、3–6、4–12、6–12です。1と12に直接線はなくても1–2–4–12と上向きにたどれます。一方3と4、4と6の間にはどちら向きの連鎖もなく、比較不能です。2と3も比較不能なので、比較不能な二点の組はこの三組です。

集合をY={2,3,4,6}に制限すれば残る線は2–4、2–6、3–6の3本です。最小・最大がなくても被覆関係を作れます。図の形だけから、全員をつなぐ最小元があると想定する必要はありません。

有向非巡回グラフとトポロジカル順序

先ほどの作業図を、点が作業、矢印が厳密な先行条件という形で一般化します。作業を一列に並べる妨げは、矢印をたどって元の点へ戻る輪です。その輪と、輪がないときに選べる先頭を、次の言葉で区別します。

有限個の点 V と、点から点への矢印の集合 E ⊆ V×V を指定します。u → v は「u を v より先に置く」という厳密な先行条件です。矢印を順にたどり、点を繰り返さない列を有向道と呼びます。一点だけの道も許します。同じ点へ戻る長さ 1 以上の矢印の列で、始点と終点以外に点の重なりがないものを有向閉路といいます。u → u も長さ 1 の閉路です。閉路のない有限の矢印の系を、有限 DAG（有向非巡回グラフ）とも呼びます。

各点へ入ってくる矢印の本数が入次数です。すべての点を一度ずつ並べ、どの矢印も左の点から右の点へ向くようにした並びがトポロジカル順序です。すべての点どうしを比較する元の規則はなくても、選んだ一本の列の中では先後が決まります。

有限で閉路がなければ、実行順を作れる

空でない有限 DAG には入次数 0 の点があります。それを先頭にして除く操作を繰り返せば、トポロジカル順序が得られます。

最長の有向道の先頭を見る

空でない有限の点集合では、点を繰り返さない有向道は有限通りしかないので、最も長いものを一つ選べます。それを v₀ → v₁ → … → vₖ とします。先頭へ入る矢印 u → v₀ があると、u が道の途中の点なら有向閉路ができ、u が道にない点なら道を前へ延ばせます。u = v₀ でも長さ 1 の閉路です。いずれも条件に反するので、v₀ の入次数は 0 です。

次に点の数について帰納法を使います。0 点なら空の列でよいとします。入次数 0 の点 v を除いた系にも閉路はないので、帰納法で残りを並べられます。v をその先頭に置けば、v に入る矢印はなく、v から出る矢印はすべて後ろへ進みます。残りの矢印も帰納法で守られるので、列全体が条件を満たします。

逆に有向閉路があれば、その閉路の点を一周する間ずっと「先」を要求するため、一列には並べられません。よって有限の系で並べられる条件は、ちょうど閉路がないことです。点が無限だと証明の有限性は失われます。整数に n → n + 1 をすべて置いた系は閉路がありませんが、どの点にも一つ前からの矢印があり、先頭として取り除ける点はありません。

入次数を更新しながら実行順を作る

存在の証明は、そのまま具体的な計算法になります。残っている点どうしの矢印だけを数え、入次数0の点を一つ選び、点とそこから出る矢印を取り除きます。元の入次数を最後まで固定したまま使うのではありません。先行作業を済ませるたび、次の作業を選べるようになるからです。

例題2：選択を変えながら六作業を並べる

作業A,B,C,D,E,Fに、A→C、A→D、B→D、B→F、C→E、D→Eという六つの条件を課します。最初の入次数はA,Bが0、C,Fが1、D,Eが2です。最初にAを選ぶと、Cの入次数は0、Dは1になり、次はBまたはCを選べます。

ここでCを選んでも先行条件は破れません。CからEへの矢印を除くとEの入次数は1ですが、Bが未実行なのでDはまだ選べません。Bを選んだ後はD,Fの両方が選べます。Fを先に選ぶ方針で続けると、表の実行順になります。

各行で「選べる点」は、どの作業を終えた結果なのか確認してください。たとえば3行目でEを選べない理由は、Eへ入るDからの矢印がまだ残っていることです。

半順序とDAGの接続

有限半順序の x ≺ y を矢印にすれば閉路はありません。もし閉路があれば、最初の一辺 x ≺ y に対し、残りの矢印を推移律でつないで y ≼ x です。反対称律から x = y となり、最初の辺の x ≠ y に反します。自分への矢印も定義からありません。従って有限半順序は、比較可能だった二点の向きを保ったまま全体を一列に並べられます。これは比較不能な二点のどちらを先にするかを選ぶ操作で、元の比較が増えていたと主張するものではありません。

逆に DAG から、x ≼ y を「x = y、または矢印を何本かたどって x から y へ行ける」と定めると、反射律は等号、推移律は列の連結から従います。異なる二点の間で両方向に行けるなら、その往復の列の中で同じ点へ戻る最短の非空区間を選びます。その内部に重複はないので有向閉路になり、DAG の条件に反します。従って反対称律も成り立ちます。直接の先行条件を、推移的な順序関係へ広げられるわけです。

順序の一意性と先行条件の設計

実行順が少なくとも一つ存在することと、ただ一つに決まることは別の条件です。有限DAGについて、点を除く各段階で選べる入次数0の点が一つだけなら、その列は一意です。どの実行順でも、先頭の点へ入る矢印があればその矢印は右から左へ向くので、先頭は入次数0の点です。先頭を除いた残りは残った系の実行順なので、各段階で候補が一つなら、どの実行順も同じ点を順に選ぶことになります。逆に、ある段階で二点u,vを選べるなら、そこでuを先に選んで残りを並べることも、vを先に選んで残りを並べることもできます。残りはどちらもDAGなので、この二つの異なる列を最後まで完成できます。

一意なトポロジカル順序の条件

有限DAGの実行順が一意であるための必要十分条件は、入次数0の点を除く手順の各段階で、残っている点がある限り選べる点がちょうど一つであることです。

一つの望ましい列を指定して条件を増やす場合は、その列の隣り合う点をつなぐ方針が役立ちます。列のすべての点がその順に鎖でつながれば、どの実行順も鎖を守る必要があるため、その列に固定されます。

例題3：望む列を一意にする最少の追加条件

例題2の六矢印を保ち、A,B,C,D,E,Fの順だけを許したいとします。隣り合う二点の組A–B、B–C、C–D、D–E、E–Fを調べると、D→Eだけが既にあります。そこでA→B、B→C、C→D、E→Fの4本を追加します。A→B→C→D→E→Fという鎖ができ、元の六矢印もすべてこの順に前進するので、閉路を作らず一意に並びます。

4本より少なくできるでしょうか。この望む列を許したまま、隣接した二点u,vの順を強制したいとします。uからvへの道に別の点wがあれば、どんな実行順でもu,w,vの順でなければならず、u,vが隣接していることに反します。従って隣接二点の順を道で強制するなら、直接の矢印u→vが必要です。

直接の矢印も道もなければ、逆向きv→uを加えても閉路は生じず、逆順を含む実行順が作れます。したがって、既にあるD→E以外の隣接4組の矢印はすべて必要で、4本は最少です。単に4本で動いたという実験だけでなく、これ未満が不可能な理由まで確かめました。

追加する矢印は条件を厳しくする判断です。元の比較不能を、「最初から先後が決まっていた」と読み替えてはいません。また、閉路のある系では、矢印を足すだけで閉路を消すことはできません。条件を削るか変更する必要があります。

寄り道［自作モデル］：同じ条件でも、実行順は一つとは限らない

冒頭の四作業では、最初に選べる点は A と B の二つです。A を除いた後は B が残り、両方を終えると C、最後に D が選べます。先頭の選択を逆にした二通りがあり、C と D の位置は動かせません。

入次数 0 の点が複数あることは、条件だけからは一つの次の作業に決まらないという情報です。同時に作業できる人数、作業時間、期限などを決めた最適な日程は、さらに別の問題です。トポロジカル順序は、ここで指定した先行条件を守る列の存在を保証します。

演習：半順序と実行順序

1．割り切れる関係は半順序か

X = {1, 2, 3, 6} で、x ≼ y を「x が y を割り切る」とします。半順序の三条件を確認し、比較不能な二点と Hasse 図に残る組を挙げてください。

ヒント1：両方向に割り切れる正の整数

y = kx、x = ℓy で k、ℓ は正の整数です。

ヒント2：1 と 6 の間には何があるか

1 から 6 の直接線は、2 または 3 を経由して復元できるか考えます。

解答

x は自分を割り切ります。両方向に割り切れると kℓ = 1 なので k = ℓ = 1、従って x = y です。y = kx、z = ℓy なら z = ℓkx なので推移的です。2 と 3 は比較不能。Hasse 図に残る組は 1–2、1–3、2–6、3–6 で、1–6 は省略します。

2．並べられるか、閉路を探す

矢印 P → Q、P → R、Q → S、R → S のトポロジカル順序を二つ示してください。さらに S → P を加えると何が起こりますか。

ヒント1：最初に入次数が 0 の点

最初は P だけです。P を除いた後を考えます。

ヒント2：S から P に戻ると、一周できるか

P → Q → S をつなげます。

解答

P, Q, R, S と P, R, Q, S が条件を満たします。S → P を加えると P → Q → S → P という有向閉路ができるので、すべての先行条件を守る列は存在しません。

3．極小元は最小元か

集合族 X = {{a}, {b}, {a, b}} を包含で順序づけます。極小元と最小元を求め、∅ を X に追加するとどう変わるか説明してください。

ヒント1：下に何もない、全員の下にある

この二つの条件は同じでしょうか。

ヒント2：空集合はどの集合に含まれるか

追加前は、空集合が X の要素でないことにも注意します。

解答

追加前の極小元は {a} と {b} です。どちらももう一方の部分集合でないため、最小元はありません。∅ を追加すると、∅ がすべての要素の部分集合なので最小元になります。また他の三要素には真に小さい ∅ があるため、極小元も ∅ だけになります。

4．割り切れる関係の定義域を変える

整数全体でx≼yを「xがyを割り切る」とすると半順序でしょうか。一方、X={0,1,2,3,6}ではどうでしょう。後者の最小元と最大元も求めてください。

ヒント1

整数では1と−1を両方向に調べます。

ヒント2

0はすべての整数の倍数です。0が割り切るのは0だけです。

解答

整数全体では1が−1を、−1が1を割り切るのに1≠−1なので反対称律が破れます。Xでは反射律・推移律は成立。両方向に割り切れるとき、一方が0なら他方も0、両方正なら正整数の証明で等しくなるため半順序です。1はすべてを割り切るので最小元、すべてが0を割り切るので0が最大元です。数として最大の6と混同しないことが検算になります。

5．直接線の欠落を診断する

例題1のX={1,2,3,4,6,12}のHasse図に1–12の線がないことから、ある人は1と12は比較不能だと言いました。誤りを説明し、本当に比較不能な全組を求めてください。

ヒント1

直接線でなく上向きの連鎖を探します。

ヒント2

各二点について、どちらか一方が他方を割り切るかを調べます。

解答

1–2–4–12などの連鎖があり、1は12を割り切ります。直接線を省いたのは被覆でないからです。比較不能な組は{2,3},{3,4},{4,6}の三つだけ。他の12組は一方向に割り切れます。六点から選ぶ異なる二点は15組なので、12+3=15と全組を点検できます。

6．出ていく矢印がない点を選ぶ手順

例題2で「入次数の代わりに、出ていく矢印の本数が0の点を先頭から並べよう」という案を診断してください。その基準を生かした正しい並べ方に直してください。

ヒント1

最初にEを置いてよいか調べます。

ヒント2

その点は先頭と末尾のどちらに置けるでしょうか。

解答

最初にEやFを選べますが、Eを先頭にするとC→EやD→Eに反します。出ていく矢印がない点は、残っている系の末尾へ置けばよいのです。すべての矢印を逆向きにしたDAGで入次数0を除く手順に相当するので、末尾から順に決める方法は正しく働きます。例としてE,F,D,C,B,Aの順で取り除き、逆順A,B,C,D,F,Eを得ると元の六条件をすべて守ります。

7．手順が止まったときの閉路を示す

点P,Q,R,S,TにP→Q、Q→R、R→P、R→Sを置きます。入次数0を除く手順で最初に何が選べ、どこで止まりますか。一本だけ条件を削って並べられるようにし、実行順を示してください。

ヒント1

孤立した点Tの入次数を調べます。

ヒント2

残ったP,Q,Rの間をたどります。

解答

最初に選べるのはTだけです。Tを除いてもP,Q,R,Sにはそれぞれ入る矢印があり、止まります。P→Q→R→Pが閉路です。R→Pを削ればP,Q,R,Sの順で進められ、たとえばT,P,Q,R,Sが全条件を守ります。R→Sだけを削っても三点の閉路が残るので不十分です。

8．別の目標列を最少条件で指定する

例題2の六矢印を保ち、B,F,A,C,D,Eだけを唯一の実行順にしたいとします。追加する矢印の最少本数を求め、その本数が必要な理由も示してください。

ヒント1

目標列で隣り合う五組を調べます。

ヒント2

既にあるのはB→F、A→C、D→Eです。

解答

不足するF→A、C→Dの2本を加えるとB→F→A→C→D→Eの鎖になり、元の条件もすべて守るので実現します。目標列の隣接二点の順を強制する道には他の点を挟めないため、直接の矢印が必要です。不足する二組は別々なので少なくとも2本必要で、これが最少です。元の比較不能を選んだ先後で解消する設計です。

9．極小元が一つなら最小元か

空でない有限半順序集合では、極小元がちょうど一つならその点は最小元になることを証明してください。有限を外すとどうでしょう。反例を自分で構成してください。

ヒント1

任意の点yから、真に小さい点へ降り続けます。

ヒント2

無限の場合は、整数の通常の順序と、整数すべてと比較不能な一点aを合わせてみます。

解答

有限の場合、同じ点へ戻る下降は反対称律に反し、異なる点を無限に選べないので、y以下の極小元へ必ず着きます。極小元が一つmだけならm≼yで、任意のyについて成り立つためmは最小元です。反例はX=ℤ∪{a}（aは整数でない記号）で、整数どうしは通常の≤、aは自分自身だけと関係する順序です。整数には必ず一つ小さい整数があり極小元でなく、aだけが極小元ですが、aは0以下でないので最小元ではありません。

10．許される列から元の比較を逆算する

四点A,B,C,Dの半順序について、許されるトポロジカル順序がA,B,C,DとB,A,C,Dの二つだけです。元の厳密な比較と被覆関係をすべて復元してください。直接矢印の集合も一意でしょうか。

ヒント1

AとBの前後が入れ替わることから比較不能だと分かります。

ヒント2

Cより前の二点、Dより前の三点に注目し、推移的な比較と被覆を分けます。

解答

厳密な比較はA≺C、B≺C、C≺D、A≺D、B≺Dの五組、被覆はA–C、B–C、C–Dの三組です。必要性も確認します。両列でuがvより前なのにu≺vがないとすると、逆向きのv≺uも許される列に反するので、二点は比較不能です。v→uを追加しても閉路はできず、逆順を含む列を作れるため「二列だけ」に反します。この議論をAとC、BとC、CとDへ使えば三つの被覆が強制され、残る二比較は推移律から従います。これらの比較なら最初はA,Bだけ、次は残った一方、続いてC,Dとなり、ちょうど二列です。直接矢印は被覆三本だけでも、推移的なA→DやB→Dを足しても同じ列を許すため一意ではありません。
