不変量と到達不能性

並べ方が何通りもあるとき、全部を試す前に「どの操作でも変わらないものはないか」と考えてみましょう。目的の状態ではその量が別の値になるなら、どんな順番で操作しても到達できません。操作のたびに保存される量や性質を不変量と呼びます。動くものを眺めながら、変わらないものを選ぶのが、この章の考え方です。

不変量は、最初から問題文に数値として書かれているとは限りません。色を付ける、余りを取る、共通する約数を見る、といった見方をこちらで加えます。ただし、見つけた量が本当にすべての許された操作で保存されることを証明しなければ、到達できないという結論には使えません。

最初の盤では、面積は合うのに敷き詰められない理由を探します。次の整数計算では、約数を全部列挙せずに最大公約数を求めます。さらに操作の条件を変え、同じ不変量がいつ使えなくなるかを確かめます。答えを探す前に、何を状態とし、何を一回の操作とするかを固定して読み進めてください。

学習の目安は演習を含めて110–160分です。盤と操作の変更、互除法の選び方と検算、到達可能性と演習の三回に分けられます。演習1–3は基本、4–7は保存と終了の診断、8–10は操作列の構成や条件の逆算です。

市松模様の不変量とドミノ敷き詰め

縦 8 升、横 8 升の正方形の盤を考えます。上から数えた行を r、左から数えた列を c とし、(r, c) で升を表します。ここから左上の (1, 1) と右下の (8, 8) を取り除きます。残りは 62 升なので、2 升を覆うドミノ 31 枚と面積は合います。ドミノは辺を共有する二つの升を、横向きまたは縦向きに覆い、重ねたり盤からはみ出したりしないものとします。

面積の条件は必要ですが、それだけでは足りません。盤を市松模様に塗り、r + c が偶数の升を黒、奇数の升を白とします。隣の升へ横または縦に一歩動くと r + c の偶奇が変わるので、どのドミノも黒と白を一升ずつ覆います。

なぜ市松模様を持ち込むのでしょう。升の位置のまま全配置を追うのは複雑ですが、ドミノ一枚が必ず「隣り合う二升」を覆うという局所的な条件は共通です。隣へ一歩進むたびに切り替わる二種類を用意すれば、縦向きでも横向きでも同じ数え方にできます。升の総数は一枚で2減るため保存されませんが、二種類の差なら一枚で(−1)−(−1)=0だけ変わります。操作の共通点から、保つ量を選んでいます。

この盤はドミノでは敷き詰められない

8 × 8 の盤から (1, 1) と (8, 8) を取り除いた領域は、上で指定したドミノだけでは完全に覆えません。

色の差を見る短い証明

元の盤には黒と白が 32 升ずつあります。取り除いた二つの升は r + c がそれぞれ 2 と 16 なので、どちらも黒です。残りは黒 30 升、白 32 升です。ドミノを一枚置いて残りの升から取り除くと、黒も白も一つずつ減り、差「黒の数 − 白の数」は −2 のまま変わりません。しかし全部を覆った状態では残りは黒も白も 0 で、差は 0 になるはずです。この値には到達できないため、敷き詰めは不可能です。

不可能という結論は、どの順番で置くかに依存しません。一枚の操作で保存されることが、帰納法によって何枚置いた後にも続くからです。試行回数を増やす代わりに、すべての操作列に共通する制約を取り出しました。

ただし、黒と白の数が等しければ必ず敷き詰められる、とはまだ言えません。たとえば (1, 1) と (1, 4) の二升だけからなる領域は黒白一升ずつですが、升が離れているため一枚のドミノでは覆えません。不変量は不可能性の理由を与えますが、その障害がないことだけで可能性まで証明したことにはならないのです。

敷き詰めの条件変更と不変量の限界

例題：対角の隅から隣の二升へ変える

取り除く升を(1,1),(1,2)へ変えます。前者は黒、後者は白なので残りは31升ずつです。色の差は0となり、先ほどの不可能性の証明は使えません。しかし、まだ「可能」と結論する段階ではありません。実際の配置を一つ作ります。

第1行は列3から8までを(3,4),(5,6),(7,8)の三組にします。残りの7行は各行で(1,2),(3,4),(5,6),(7,8)の四組です。各組に横向きのドミノを置けば、3+7·4=31枚。重なりも空きもなく、残りの62升をすべて覆います。色の一致は必要条件、ここでの具体的な配置が十分性の証明です。

「ドミノが黒白一升ずつを覆う」という条件を変えたらどうでしょう。斜めに接する二升を一枚で覆ってよいとすると、r+cは変わらないか、2増えるか2減り、偶奇が変わらないため同色の二升を覆えます。黒二升を覆えば黒−白は2減り、白二升なら2増えるので、差そのものは不変でなくなります。盤の色を変えなくても、許す操作を変えれば保存の証明をやり直す必要があります。元の結論を、そのまま別の道具へ持ち越してはいけません。

逆に、ドミノを置くほかに既に置いたドミノを取り除くことを許しても、差は保たれます。取り除く一回では黒白が一つずつ増え、その差の変化は1−1=0だからです。前進だけでなく、許された逆向きの操作も一回ずつ点検すれば、置き直しを何度行っても元の不可能性は変わりません。

ユークリッドの互除法：不変量と停止性

長さ252cmと105cmの二本の棒を、余りを出さずに同じ長さの部品へ分けるとします。部品の長さは正の整数cmに限定し、できるだけ長くしたい。この自作模型で許される長さdは252と105をともに割り切るので、求めるのは最大公約数です。「どんな長さで分けられるか」という問題を、小さい数へ置き換えたいのです。

不変量は、できないことの証明だけでなく、答えを求める手順の正しさにも使えます。二つの正の整数 a、b の最大公約数を考えましょう。最大公約数は、両方を割り切る正の整数のうち最大のものです。大きな数の約数を全部並べる代わりに、数の組を小さくしても共通の約数が変わらない操作を探します。

例えば 252=2·105+42 です。252を105で割ったときの商が2、余りが42で、余りは0以上105未満です。この計算を a=qb+r と書くと、qが商、rが余りに当たります。組 (252,105) を (105,42) に替えても最大公約数が変わらないなら、小さい数で続きを計算できます。

この置き換えを選ぶ理由を、引き算から作ってみます。aとbをともに割り切る長さなら、a−bも割り切ります。252から105を一回引けば147、もう一回引けば42です。毎回一本分を除いても共通の割り方は保たれます。割り算252=2·105+42は、この二回の引き算を一度にまとめたものです。さらに小さくするには、42より大きい105を次に42で割ります。

ただ小さくするだけなら、両方から1を引く方法もあります。しかしそれでは同じ長さで切れるかという情報を失います。反対に二つの数を交換するだけなら共通の約数は保ちますが、二回で元へ戻ってしまいます。答えを保つことと、計算を進めることを同時に満たすため、余りを選びます。

余りへ置き換えても最大公約数は同じ

a ≥ b > 0 を整数とし、整数の割り算で a = qb + r、0 ≤ r < b と書くと、a と b の最大公約数は b と r の最大公約数に等しくなります。r = 0 の場合は、b と 0 の最大公約数を b とします。

共通の約数を両方向に追う

正の整数 d が a、b の両方を割り切るなら、r = a − qb も割り切ります。逆に d が b、r を割り切るなら、a = qb + r も割り切ります。したがって二つの組の共通の正の約数はまったく同じです。その中で最大のものも同じなので、主張が成り立ちます。

この置き換えを繰り返す方法がユークリッドの互除法です。表では 252 と 105 から始め、最後の 0 でない数 21 が最大公約数になります。数そのものは変化しますが、共通の約数の集合という情報が残ります。

正しい値を保つだけでは、計算が終わるとは限りません。ここでは次の余りが、前の正の割る数より必ず小さくなります。正の整数を無限に減らし続けることはできないため、いつか余りが 0 になります。「何を保つか」が答えの正しさを、「何が減るか」が終了を支えます。二つの役割を分けて確認することが重要です。

一般の互除法では第二成分bが正の間だけ割り算を行い、次の第二成分rは0≤r<bです。0になったら割り算を続けず終了します。最後の組(d,0)では、dと0の共通の正の約数はdの正の約数そのものなので、最大のものはdです。これが「最後の非零数を答えにする」理由です。もし始めから(a,0)、a>0なら、そのままaが答えです。

両方が0の組は別です。どの正の整数も0を割り切るので、共通の正の約数に最大のものがありません。従って本章の「最大の正の公約数」という定義では(0,0)には値を定めません。文脈によってgcd(0,0)=0と約束することがありますが、それはこの最大性の定義から出た結論ではありません。

例題：互除法を逆にたどって答えを検証する

252と105の計算をもう一度見ます。21は252=12·21、105=5·21から、確かに共通の約数です。しかし「割れる」だけでは最大とは言えません。直前の式を逆に使うと、21=105−2·42、42=252−2·105なので、

21=105−2(252−2·105)=5·105−2·252。

252と105の共通の正の約数dは、右辺のどの整数倍の和も割り切るので、21も割り切ります。従ってd≤21。一方21自身は共通の約数だったので、最大公約数は21と二方向から確かめられます。検算は5·105−2·252=525−504=21です。途中の計算を全部信じなくても、この一行と二つの割り算を調べれば答えの最大性を検証できます。

棒の問題に戻すと、21cmの部品をそれぞれ12個と5個作れます。もし21cmより長い正の整数cmで両方を切れたなら、その長さdは21を割り切ることになり矛盾します。数の答えを、元の条件と単位へ戻しました。

余りの不変量と到達可能な状態の構成

二つの箱に球があり、一回にちょうど3個を片方からもう片方へ移す自作のゲームを考えます。球の個数は0以上の整数で、移す側に3個未満しかなければ、その向きの操作はできません。最初を左9個、右3個とします。合計12は保存されますが、合計が12ならどの状態へも行けるでしょうか。

例題：合計だけでは見えない障害を追加する

左の個数をxと書けば、右は12−xです。一回の操作でxは3だけ増えるか減ります。9から始めて3ずつ動くので、xを3で割った余りは常に0です。(6,6)へは一回で到達しますが、(5,7)は合計が12でも、左5の余りが2なので到達できません。合計という不変量が目的を区別しなかったため、余りという別の不変量を探しました。

このゲームでは、可能性も最後まで決められます。左の個数が0以上12以下で、3の倍数なら候補は0,3,6,9,12。隣り合う候補どうしは3個移せば結ばれ、0←3←6←9→12と、すべて実際に到達できます。従って到達できる状態は(0,12),(3,9),(6,6),(9,3),(12,0)の五つです。

合計を任意の0以上の整数T、最初の左の数をx0へ変えても同じ理由が使えます。目標xが0≤x≤Tを満たし、x−x0が3の倍数なら、差の向きに3ずつ移せばよい。途中の値は二つの端点の間にあり0からTを出ないため、すべての操作が合法です。この条件は必要なだけでなく十分です。盤の場合に一般の十分条件を言えなかったのとは、構成を与えられた点が違います。

3個ずつを「1個ずつ、または3個ずつ」に変更すると、余りは保存されなくなり、0からTまでのすべての左の個数へ1個ずつ動かせます。一方、合計は引き続き保存されます。一つの操作変更が、不変量の全部を壊すとは限りません。条件ごとに何が残るかを確認します。

寄り道［背景］：15パズルには、動かし続けても解けない配置がある

4 × 4 の枠に15枚の札と空所を置く15パズルは、1879年の Johnson と Story の論文でも扱われています。完成形の14と15だけを入れ替えた配置は解けません。ここでは、その障害を偶奇で見てみましょう。

札を上の行から読み、空所を除いて「大きい数が小さい数より先にある組」を数え、逆転数と呼びます。横移動では札の読み順は変わりません。縦移動では一枚がほかの三枚をまたぐため、逆転数の偶奇が反転します。同時に、空所の行番号の偶奇も反転します。したがって二つの和の偶奇は不変です。14と15だけを交換すると逆転数だけが反転し、この不変量が変わるので到達できません。手数を増やす努力が、そもそも届かない配置を変えることはないのです。

出典：Johnson・Story：Notes on the “15” Puzzle（1879）。

演習：不変量と到達可能性

1．盤の大きさを変える

6 × 6 の盤から (1, 1) と (6, 6) を取り除きます。本文と同じドミノで敷き詰められるでしょうか。

ヒント1：取り除く升の色を見る

黒を r + c が偶数の升とします。二つの隅は何色ですか。

ヒント2：残りの数を比較する

元は黒白が 18 升ずつです。取り除いた後の差を求めます。

解答

取り除く二升はともに黒なので、黒 16 升、白 18 升です。各ドミノは黒白を一つずつ覆うため、差 −2 は残り続けます。全部を覆った差 0 にはできず、敷き詰めは不可能です。

2．色の障害がないとき、実際に作る

8 × 8 の盤から、今度は (1, 1) と (1, 2) を取り除きます。色の数を確認し、実際の敷き詰め方を説明してください。

ヒント1：同じ行の隣り合う二升である

取り除くのは黒白一升ずつです。第1行には何升残りますか。

ヒント2：行ごとに横向きに置く

第1行の列 3、4 を一組にし、その後も二升ずつ組にします。

解答

黒白は 31 升ずつです。第1行は列 (3, 4)、(5, 6)、(7, 8) の三組を横向きに覆います。第2行から第8行では、各行の列 (1, 2)、(3, 4)、(5, 6)、(7, 8) を覆います。計 3 + 7·4 = 31 枚で完成です。色の一致だけでなく、具体的な構成で可能性を示しました。

3．互除法の途中で何を保ったか

414 と 162 の最大公約数を互除法で求め、途中で共通の約数が変わらない理由も一文で述べてください。

ヒント1：余りを次の割る数にする

414 = 2·162 + 90 から始めます。

ヒント2：0 まで続ける

162 = 90 + 72、90 = 72 + 18 です。次の余りを求めます。

解答

72 = 4·18 + 0 なので最大公約数は 18 です。a = qb + r の各段階で、a、b を割り切る数と b、r を割り切る数が一致するため、最大公約数は保存されます。余りが小さくなることは、別に計算の終了を保証します。

4．操作を増やしたときの誤った証明

元の8×8の隅二升を除いた盤で、通常のドミノのほかに「斜めに接する二升」を覆う道具も許します。ある人は「黒−白は−2のままだから不可能」と言いました。差が変わる合法な一回を挙げ、この指摘だけで敷き詰め可能と結論できるかも説明してください。

ヒント1

(1,2)と(2,3)は盤に残っており、斜めに接しています。

ヒント2

この二升のr+cは3と5です。何色を何升覆いますか。

解答

両方白なので、この二升を覆う一回で残りは黒30、白30となり、差は−2から0へ変わります。従って元の保存の主張は偽です。ただし不可能性を示すこの理由が使えなくなっただけで、盤全体を覆う配置はまだ作っていません。可能と結論するには配置など別の証明が必要です。

5．計算結果の最大性まで検証する

1071と462の最大公約数を互除法で求め、最後の非零数を1071と462の整数倍の和として表してください。その等式と割り切れることを使って、最大性を説明してください。

ヒント1

1071=2·462+147、462=3·147+21です。

ヒント2

21=462−3·147へ、147=1071−2·462を入れます。

解答

147=7·21+0で終了し、最大公約数は21。逆に21=462−3(1071−2·462)=7·462−3·1071で、3234−3213=21と検算できます。21は1071=51·21、462=22·21を割り切ります。またどの共通の正の約数も等式の右辺、従って21を割り切るため21以下です。この二点から最大性が分かります。

6．引き算だけの互除法を設計する

正の整数の組から始め、両方が正なら「大きい方から小さい方を引く」、等しいときはどちらか一方からもう一方を引く、とします。どちらかが0になったら終了します。最大公約数を保つ理由と、必ず終了する理由をそれぞれ示し、(18,12)で実行してください。

ヒント1

a≥b>0なら、共通の約数は(a,b)と(a−b,b)で同じです。

ヒント2

成分を固定せず、二成分の和を見ると毎回正の整数だけ減ります。

解答

dがa,bを割り切ることと、a−b,bを割り切ることは同値です。よって最大公約数は保存されます。両方が正の一回で和は小さい方の値だけ減り、0以上の整数の和を無限に減らせないので終了します。(18,12)→(6,12)→(6,6)→(0,6)で、答えは6。最後は6が両成分を割り切り、停止した組の最大公約数でもあります。通常の互除法の第二成分ではなく、この規則に合う減少量を選びました。

7．減るだけでは停止を言えない

「正の量が毎回小さくなるから、いつか0になる」という説明はいつでも正しいでしょうか。実数xから始めxを毎回x/2へ替える規則をx=1で調べ、互除法の停止証明に必要だった条件を説明してください。

ヒント1

n回後の値を式で書いてみます。

ヒント2

1/2nは有限のnで0になりますか。互除法の第二成分は何の集合に入っていましたか。

解答

n回後は2−nで、どの有限のnでも正です。厳密に減っても0には達しません。互除法では減る量が0以上の整数であることが必要でした。初めの第二成分がbなら、正の間は少なくとも1ずつ減るため、無限回の減少はできません。0へ近付くことと、有限回で0になって止まることを区別します。

8．余りから全到達状態を決める

二箱の球を(8,5)から始め、今度は一回にちょうど4個を移します。球の個数は非負です。到達できる状態をすべて挙げ、(0,13)までの最小手数と、(5,8)に到達できるかを説明してください。

ヒント1

合計は13、左の数を4で割った余りは0です。

ヒント2

0≤x≤13にある4の倍数を並べます。隣り合う候補は一回で結べます。

解答

左は0,4,8,12だけなので、状態は(0,13),(4,9),(8,5),(12,1)です。どれも8から4ずつ動かせるため実際に到達します。(0,13)へは(8,5)→(4,9)→(0,13)の二回。一回で左は4しか変わらないので8減らすには少なくとも二回必要で、最小です。(5,8)は合計が同じでも左の余りが1となり到達できません。

9．到達させる移動単位を選ぶ

二箱の状態(14,6)から(5,15)へ、一回にちょうどs個を移す規則を設計します。sは正の整数で、移す側に十分な球があるときだけ操作できます。到達できるsをすべて求め、その中で最小の手数を与えるものを選んでください。

ヒント1

左の個数の差は−9です。何回か±sを加えた結果になるには何が必要ですか。

ヒント2

sは9の正の約数でなければなりません。それぞれ左から右へ移す列が作れるか確かめます。

解答

左の差−9はsの整数倍なので、必要な候補はs=1,3,9です。いずれも左から右へ9/s回移せば14から5へ下がり、途中は5以上14以下で球不足になりません。従って三つとも十分です。各回で左が変わる絶対値はsなので、手数は少なくとも9/s。単方向の列がその値を実現します。最速はs=9の一回で、(14−9,6+9)=(5,15)と検算できます。

10．最大公約数を指定して長さを逆算する

長さ90cmの棒と、長さL cmの棒を、できるだけ長い共通の部品へ余りなく切ると、その長さが18cmだったとします。Lは100以上150以下の整数です。可能なLをすべて求め、候補を共通の約数であることだけで判断しないようにしてください。

ヒント1

18がLを割り切ることは必要です。区間内の18の倍数を列挙します。

ヒント2

90=18·5です。L=18kとして、5とkにさらに共通因数がないか確かめます。

解答

候補は108=18·6、126=18·7、144=18·8です。5と6、5と7、5と8の最大公約数はいずれも1なので、90と各候補の最大公約数は18です。直接には108=90+18、126=90+36と90=2·36+18、144=90+54と90=54+36と54=36+18で確認できます。区間内の18の倍数はこの三つだけなので、漏れはありません。単位をcmへ戻すと、90cm側では5個の18cm部品を作ります。
