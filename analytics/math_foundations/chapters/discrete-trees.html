木と全域木

六つの拠点を、互いに連絡できるように結ぶとします。辺を増やせば別の経路もできますが、「つながる」だけが目的なら余分な辺もあるはずです。どこまで減らせるでしょうか。グラフの形から、必要な辺の本数を説明します。

この章のグラフは有限・単純・無向で、木については頂点が一つ以上あるとします。「余分がない」を、まず閉路がないという条件で表し、唯一の道や n − 1 本という別の姿へつなぎます。さらに、一辺を追加して別の一本を外す設計、枝分かれから葉を逆算する計算、待ち行列を使う実行へ進めます。

演習を含む学習の目安は120–180分です。木の特徴と証明、辺を選ぶ設計、BFSの記録と演習の三回に分けても読めます。辺の長さや費用を最小にする問題とは区別し、本章では辺の本数と最短の辺数を扱います。

木の定義と道の一意性

木は、連結で閉路を持たないグラフです。閉路を持たないが、連結とは限らないグラフを森と呼びます。木では、辺を一本除くとつながりが切れます。もし除いた辺 uv の両端を別の道で結べたら、その道と uv が閉路を作り、木の条件に反するからです。

木では、二頂点間の道がただ一つ

有限非空グラフが木であることと、異なる任意の二頂点の間にちょうど一つの道があることは同値です。一頂点の木では、異なる二頂点についての条件は自動的に満たされます。

二つの道があれば、行きと帰りで輪ができる

木は連結なので、二頂点を結ぶ道が少なくとも一つあります。異なる二本の道があったとします。始点からたどって初めて分かれる頂点を x とし、その先で再びもう一方の道と出会う最初の頂点を y とします。終点では必ず出会うので y は存在します。x から y までの二つの部分は内部の頂点を共有せず、合わせると閉路です。これは木の条件に反します。

逆にどの二点もただ一つの道で結ばれれば、まず連結です。閉路があれば、その上の二頂点を輪の両側から結ぶ異なる二本の道を作れるので、唯一性に反します。従って閉路はなく、木です。

一頂点・辺なしのグラフも木です。その頂点から自分への道は長さ 0 とします。一方、空のグラフをここでは木とは呼びません。後の n − 1 の公式でも、n ≥ 1 という条件を保ちます。

例題：一辺を足し、一辺を外して木を作り替える

六頂点の木で、DからFへの道を確認します。Dの隣はBだけなのでD–B、BからA、AからC、CからFと進み、D–B–A–C–Fの四辺です。「唯一」とは、これと異なる頂点列の道がないことです。B–Eへ寄り道して戻る歩道は作れますが、Bを再訪するので別の道には数えません。

新しい辺EFを追加すると何が変わるでしょう。木の中に既にあるEからFへの唯一の道 E–B–A–C–F に、新辺FEを合わせて一つの閉路ができます。頂点は六つ、辺は六本となり、もはや木ではありません。しかし、増えた閉路上から別の一本を外せば、つながりを保って五本へ戻せそうです。

ABを外すと、残る辺はAC、BD、BE、CF、EFです。B側とA側はB–E–F–C–Aという迂回路でつながり、DもBにつながっています。従って連結です。辺を全部たどると一本の道D–B–E–F–C–Aになっており、閉路もありません。DからFへの道はD–B–E–Fの三辺へ変わりました。

どの辺を外してもよいわけではありません。BDは追加で生じた閉路の外にあり、外すとDが孤立します。EFを追加した後の表で、「閉路上」という条件の働きを比べてください。

この交換が一般の木でも使える理由

木へ非隣接な二頂点u、vを結ぶ一辺を足すと、元の唯一のu–v道と新辺で閉路ができます。新しい閉路は必ず新辺を含みます。もし含まなければ元の木にも閉路があったことになるからです。元のu–v道は唯一なので、生じる閉路もこれ一つです。その閉路上の一辺を取り除いても、両端は残った輪でつながり、全体の連結性を保ちます。唯一の閉路が壊れるので、再び木になります。

この設計で小さくしたのは特定の二点間の辺数です。全ての二点間の距離が短くなるわけではありません。AからBはA–C–F–E–Bとなり、元の一本から四本に伸びています。何を改善したいのかを決めてから辺を交換する必要があります。

木の葉と辺数

次数が 1 の頂点を葉と呼びます。六頂点の木の図の葉は D、E、F です。一頂点だけの木の次数は 0 なので、この定義では葉ではありません。

二頂点以上の有限の木には、少なくとも二枚の葉がある

これ以上延ばせない道の両端を見る

有限なので、長さが最大の道を一つ選べます。二頂点以上で連結だから、その長さは少なくとも 1。端点 x の隣接点が道の外にあれば、その点を足して道を延ばせてしまいます。道の中の、直前以外の点と隣接していれば、その辺と道の一部で閉路ができます。従って x の隣接点は直前の一点だけで、次数 1 です。反対側の端点にも同じ議論が使え、異なる二枚の葉を得ます。

n 頂点の木の辺は n − 1 本

|E|=|V|−1(|V|≥1)

葉を一枚取り、帰納法を使う

n = 1 なら単純グラフに辺はなく、0 = 1 − 1 です。n ≥ 2 では葉を一枚と、その葉に接する辺を一本取り除きます。残るグラフに閉路は増えません。また残った二頂点を結ぶ元の道は、次数 1 の葉を内部に通れないので、そのまま残ります。従って残りは n − 1 頂点の木です。帰納法で辺は n − 2 本、取り除いた一本を戻して n − 1 本となります。

木の同値条件と全域木の存在

n − 1 本だから木、とはまだ言えません。三角形と孤立点一つを並べると、四頂点・三辺ですが、連結でなく閉路もあります。数が一致することと、必要な場所につながっていることは違います。

頂点を一つ以上持つ有限連結グラフから、全頂点を保ったまま辺の一部を選んで作る木を全域木と呼びます。全域は「全ての頂点を含む」という意味です。次の構成で、全域木が必ず作れることを確かめます。

一つの頂点から、外へ一本ずつ伸ばす

一頂点だけを選び、選んだ頂点の集まり S とします。まだ外に頂点があるなら、元のグラフの連結性から、S と外を結ぶ辺が一本はあります。S から外の頂点への道をたどり、初めて S を出る辺を取ればよいのです。その辺と外側の一頂点だけを追加します。新しい点は一本だけで付くので閉路はできず、選んだ部分の連結性も保たれます。

一回に頂点が一つ増えるため、n − 1 回で全 n 頂点を含む木になります。従って連結グラフの辺数は少なくとも n − 1。もともと辺が n − 1 本なら、構成で選んだ辺が全ての辺なので、元のグラフ自体が木です。

「連結で n − 1 本」なら木。本数だけでは足りない
グラフ連結閉路なし辺数
六頂点の木はいはい5 = n − 1
三角形と孤立点いいえいいえ3 = n − 1

また、閉路なしで n − 1 本なら連結です。連結成分が c 個なら、各成分は木なので、頂点数を n₁、…、nc として辺数は (n₁ − 1) + … + (nc − 1) = n − c。本数 n − 1 との比較で c = 1 になります。木の特徴は、「連結」「閉路なし」「n − 1 本」のうち二つから残りを得る形にもまとめられます。

例題：成分数と葉の数を逆算する

全ての点を結ばなくてよい森では、何本の辺を選べるでしょう。連結成分の数をc、全頂点数をnとすれば、各成分は木なので辺数m=n−cです。孤立点も一頂点・辺なしの木として数えます。例えば九頂点・六辺の森なら、6=9−cからc=3。図の配置を知らなくても、成分数が確定します。

「九頂点・六辺」という数だけで森と判定してよいでしょうか。そうはできません。三角形一つ、離れた一本の辺、さらに三頂点の道、孤立点一つを並べると、頂点数3+2+3+1=9、辺数3+1+2+0=6ですが、閉路があり成分数は4です。c=n−mを使う前に、閉路がないという条件を確かめます。

枝分かれを増やすと、葉は何枚必要か

二頂点以上の木で、葉の数をLとします。葉以外の頂点は次数2以上です。握手補題と辺数n−1から全次数の和は2(n−1)。各頂点に次数2を仮に割り当てた合計2nから比べると、全体は2だけ少なくなります。一枚の葉は2より1少なく、次数3以上の点はその分を増やします。

L = 2 + ∑deg(v)≥3(deg(v)−2)

式の意味を確かめるため、葉以外の点が次数3の二点B、Cと次数4の一点Qだけだとします。L=2+(3−2)+(3−2)+(4−2)=6です。次数2の点を追加しても右辺は変わりません。辺の途中に中継点を挟むだけでは、端は増えないことに対応します。

実際に作るなら、QをB、C、D、Eへ結び、BをF、Gへ、CをH、Iへ結びます。辺はQB、QC、QD、QE、BF、BG、CH、CIの八本。頂点は九つで、葉はD、E、F、G、H、Iの六つ。次数和は4+3+3+6=16=2×8です。逆算と構成の両方で確かめました。

この葉の式には「二頂点以上の木」が必要です。一頂点の木の次数は0で、葉は0枚。そこへL=2を当てはめることはできません。また、森全体では成分ごとに計算し、一頂点の成分を別に扱います。

幅優先探索と無重み最短路

全域木を作るとき、出発点から何本の辺で行けるかも同時に記録したいとします。探索の出発点を根と呼び、初めて見つけた点へ進んできた直前の点を、その点の親として記録します。各点に付ける辺数の記録d(v)がラベルです。以下の手順では、このラベルが最短の辺数になることまで証明します。

全域木の作り方は一つではありません。根 r から、辺を一本で行ける点、二本で初めて行ける点、という順に広げる方法を幅優先探索（BFS）と呼びます。ここでいう距離は、通る辺の最少本数です。通路ごとの所要時間は、まだ扱いません。

手順を正確にすると、r のラベルを d(r) = 0 として発見済みにし、待ち行列へ入れます。待ち行列は先に入れた点を先に取り出す仕組みです。先頭の u を取り出し、未発見の隣接点 v を全て d(v) = d(u) + 1 として発見済みにし、親を u と記録して末尾へ入れます。空になるまで繰り返します。発見した時点で印を付けるので、同じ点を重ねて追加しません。

例題：待ち行列と親を、一手ずつ区別する

七辺のBFS図で、隣接点はアルファベット順に調べます。角括弧の左端が次に取り出す点です。「取り出した」と「初めて発見した」は同時ではありません。Bを処理してEを発見すると、その時点で親をBとし、Dを処理する前に印を付けます。次の表で、Dを取り出した時にEを再登録しない理由を確かめてください。

親はB←A、D←A、C←B、E←B、F←Cです。Fから逆向きにF、C、B、Aとたどり、反転するとA–B–C–F。三辺で到達できます。各辺が一層だけ進むことも確認できます。Aから二辺で着くには、BまたはDとFの間に辺が必要ですが、どちらもないので三辺が最少です。

Aの隣をD、Bの順にすれば、DがEを先に発見し、EがFを先に発見します。Fへの記録はA–D–E–Fとなりますが、やはり三辺です。隣を見る順で親は変わっても層は変わらないという予想を、ここから一般の証明へ進めます。

待ち行列の層が逆転しないことから、最短性へ

待ち行列のラベルは小さい順に並び、先頭が k なら、中には k と k + 1 の層だけがあります。初めは 0 だけなので成立します。k の点を取り出すと、新しく入る点は全て k + 1 で末尾に並びます。k がなくなって初めて k + 1 が先頭になるので、この性質が保たれます。

親をたどるとラベルが一つずつ減って根へ至ります。従って、発見した v には長さ d(v) の道があります。また辺 uv について、u を処理する時点で v が未発見なら d(v) = d(u) + 1。発見済みなら、既に処理された点のラベルは d(u) 以下、待ち行列の点は d(u) + 1 以下なので、やはり d(v) ≤ d(u) + 1 です。

根から v への任意の道 r = v₀、v₁、…、vₖ = v にこの不等式を順に使うと、d(v) ≤ k。つまりどの道も d(v) 本より短くできません。親の道はちょうど d(v) 本なので最短です。根から行ける点が未発見のまま残ることもありません。そうなら根からそこへの道上に、処理済みの点から未発見の点へ出る最初の辺があり、処理時に発見していたはずだからです。

親の辺だけを残すと、根以外の各点が一本ずつ親を持ち、根までつながります。ラベルが下がる親の列で構成され、各点を新しく一つずつ付け足した形なので閉路はありません。従って根の連結成分の全域木です。元のグラフが非連結なら、他成分の点は未発見のまま。未発見点を根にして繰り返せば全域の森を作れます。

同じ層の内部の順番や、複数ある最短の道のどれを親で記録するかは変えられます。一方、辺の本数の最小値は変わりません。辺に異なる時間を付けたときの最短路は、次章で別の確定規則を使います。

寄り道［自作モデル］：配線を減らすと、代わりの道も消える

架空の六拠点ネットワークで、全拠点を結ぶためのケーブル本数だけを減らすなら、五本の全域木が達成できます。しかしどの一本が切れても、木は二つの部分に分かれます。閉路の辺なら残りの輪で迂回できますが、木にはその輪がありません。

「本数が最少」と「一本切れても通信できる」は異なる設計目標です。また本数が同じ五本でも、一本ごとの長さが違えば総延長は違います。本章は辺数と連結性の話で、総延長を最少にする全域木の選択までは解いていません。何を節約するかによって、次に必要な数学も変わります。

演習：木とBFS

1．二種類の「余分がない」

連結な七頂点のグラフに辺が六本あります。これは木ですか。また、七頂点・六辺という情報だけならどうですか。

ヒント1：全域木に必要な辺数

連結なら六本の辺を選んで全域木を作れます。

ヒント2：連結性を外した反例

六頂点の閉路と孤立点一つを並べてください。

解答

連結で六辺なら木です。全域木も六辺で、余分な辺が残らないからです。本数だけでは不十分。六頂点を輪につないだ六辺の閉路と孤立点一つは、七頂点・六辺ですが、連結でなく木ではありません。

2．葉を消してもよい理由

最初の六頂点の木から葉 E を除きます。残る辺と葉を挙げ、連結性が失われない理由を説明してください。一頂点の木にも葉が二枚あると言えますか。

ヒント1：葉に接する一本だけが消える

消える辺は BE です。残った各頂点の次数を数えます。

ヒント2：道の内部には二本の辺が必要

次数 1 の頂点を、他の二点を結ぶ道の途中には使えません。

解答

残る辺は AB、AC、BD、CF、葉は D と F です。残る二点間の元の道は E を内部に含まないので、そのまま使えます。一頂点の木は次数 0 で葉はありません。二枚の葉の定理には「二頂点以上」という条件が必要です。

3．親が違っても、距離は同じ

BFS の図の七辺のグラフで、F の親を E にした全域木の辺を書き、A–F の最短の辺数を答えてください。A から二本の辺で F へ行けない理由も示してください。

ヒント1：各点に、ひとつ前の層の親を置く

B、D の親は A、C、E の親は B としてかまいません。

ヒント2：二本で着くなら、最初の隣の点から F へ辺がある

A の隣は B と D ですが、BF も DF もありません。

解答

辺 AB、AD、BC、BE、EF が一例で、A–B–E–F は三本です。一本なら AF が必要ですがありません。二本なら A の隣の B または D から F への辺が必要ですが、どちらもありません。従って最小は 3。親を C から E に変えても最短の辺数は同じです。

4．閉路なしの条件から成分数を戻す

十二頂点・八辺の森があります。連結成分数を求めてください。さらに「森」という条件を外して同じ式を使う誤りを、四頂点三辺の反例で説明してください。

ヒント1：方針を決める

各成分の辺数は、その成分の頂点数より一つ少なくなります。

ヒント2：計算を進める

三角形と孤立点は何成分でしょう。

解答

m=n−cから8=12−c、従ってc=4です。森でなければ各成分が木とは限りません。三角形と孤立点はn=4、m=3ですがc=2であり、n−m=1とは一致しません。閉路のない条件を確かめてから式を使います。

5．辺の交換を設計する

六頂点の木E={AB,AC,BD,BE,CF}へEFを足しました。CFを外した場合とBDを外した場合を比べ、木になる方ではDからFへの道も書いてください。

ヒント1：方針を決める

新しく生じた閉路E–B–A–C–F–Eに注目します。

ヒント2：計算を進める

CFを外してもFはEを経て結ばれています。BDの先のDには他の辺がありますか。

解答

CFは閉路上なので、外すと木になります。残る辺AB、AC、BD、BE、EFは六頂点を結び、D–B–E–Fが三辺の道です。BDは閉路外なので、外すとDが孤立し、閉路は残ります。辺数が五本に戻っただけでは木を保証できません。

6．枝分かれから葉を設計する

二頂点以上の木で、次数3の頂点が四つ、他の頂点は全て次数1または2です。葉は何枚必要ですか。次数2の点を一本の辺の途中へ三つ挿入したら、葉数・頂点数・辺数はどう変わりますか。

ヒント1：方針を決める

葉の式で次数3の点の寄与を足します。

ヒント2：計算を進める

一辺を四辺の鎖へ取り替えると、辺は何本増えますか。

解答

L=2+4(3−2)=6です。次数2の中継点を三つ挿入しても枝分かれは増えず、葉は六枚のまま。頂点数は3、辺数も3増えます。一辺が四辺になるためで、m=n−1の差も保ちます。

7．発見時に印を付ける理由

BFSの七辺の例で、Bを処理した後の待ち行列は[D,C,E]です。Dを処理するとき、Eの印を「取り出す時まで付けない」規則に変えると何が起きますか。本章の規則の利点を説明してください。

ヒント1：方針を決める

Eは待ち行列にはありますが、まだ取り出していません。

ヒント2：計算を進める

未発見と誤認すると末尾に同じEを追加します。

解答

誤った規則ではEを未発見と見て再追加し、例えば[C,E,E]となります。親をDに書き換えるかどうかも曖昧になります。本章は発見して末尾へ入れた時に印と親を確定するので、各頂点は一度だけ待ち行列に入り、最初に見つけた層と親を保ちます。

8．親だけから最短性を判断しない

七辺のBFS例で、親の辺としてAB、BC、CF、FE、EDを選ぶと木になります。この木でのA–Dの辺数を求め、AからのBFS木と言えない理由を説明してください。

ヒント1：方針を決める

選んだ辺だけではA–B–C–F–E–Dと進みます。

ヒント2：計算を進める

元のグラフにあるADと比較します。

解答

選んだ木でのA–Dは五辺です。しかし元のグラフではAD一本で着き、最短距離は1。従ってこれは全域木ですが、Aを根としたBFS木ではありません。全頂点を結ぶことと、根からの最短辺数を保存することは別の条件です。

9．一辺を足して、一故障への弱さを変える

六頂点の道A–B–C–D–E–Fに新辺一本を足し、どの一本の辺が切れても残りが連結になるようにしたいとします。どこを結べばよいですか。それ以外の結び方が失敗する理由も示してください。

ヒント1：方針を決める

葉AとFに、別の接続を用意する必要があります。

ヒント2：計算を進める

AかFの次数が1のままなら、その一本を切ると孤立します。

解答

AFを足せば六頂点の閉路になります。どの一本を切っても残りは六頂点を結ぶ道です。新辺がAに接しなければAの唯一の辺ABが弱点のまま、Fに接しなければEFが弱点のままです。一本で両方を解消するにはAFしかありません。

10．条件を最小限選んで証明する

n≥1の有限単純無向グラフで、「連結」「閉路なし」「辺数n−1」のうち二条件ずつを与えたとき、残りを導く方針を三通り述べてください。n=1も確認してください。

ヒント1：方針を決める

連結なら全域木を作れます。閉路なしなら各成分が木です。

ヒント2：計算を進める

連結＋閉路なしは定義、閉路なし＋辺数にはm=n−cを使います。

解答

連結かつ閉路なしなら木なのでm=n−1。連結かつm=n−1なら、全域木もn−1辺を持つため元の辺が全て選ばれ、閉路なし。閉路なしでm=n−1ならm=n−cよりc=1で連結です。n=1ではm=0、一頂点は連結で閉路もなく、三通りとも成立します。

自分の言葉で

  1. 閉路がないことと、二頂点間の道がただ一つであることを、どう結びましたか。
  2. n − 1 本という本数に、どの条件を足せば木だと言えますか。孤立点がある反例も説明できますか。
  3. BFS の親と層は何を記録しますか。異なる重みがあるとき、辺数の最短性だけでは足りないのはなぜですか。
