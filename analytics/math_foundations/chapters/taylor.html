Taylor多項式と関数の近似

一次近似では、一点での値と傾きを合わせた直線を使いました。さらに曲がり方も合わせれば、もっとよい近似になるでしょうか。多項式は値も微分も計算しやすいので、複雑な関数を近くで扱う道具になります。ただし項数を増やした見た目だけで正確さを判断せず、残った誤差を式で管理します。

前提は高階の微分、Rolleの定理、級数です。高階導関数 f⁽ᵏ⁾ は k 回微分した関数、階乗 n! は 1 から n までの積で 0! = 1 とします。この章ではまず有限の近似を証明し、その後で無限の展開へ進める条件を調べます。

具体的な目標を「√1.04 を誤差10⁻⁵以下で求める」としてみましょう。何次まで計算するかを先に決めず、使いやすい中心、区間での導関数の上界、許す誤差の順に選びます。学習の目安は演習込み110–160分です。前半で有限の誤差保証を作り、後半で中心と範囲を変えた場合を比べます。

Taylor多項式の定義

中心 a において f と n 次までの導関数が一致するよう、多項式 Pₙ を作ります。定数項は f(a)、一次の係数は f′(a)。二次の項を2回微分すると係数の2倍になるので、二次の係数は f″(a)/2 です。同じ考えを続けると、階乗で割る理由が分かります。

Pn(x)=∑k=0nf(k)(a)k!(x−a)k

これが a を中心とするTaylor多項式です。定義だけでは、離れた x で f に近いことはまだ保証しません。「a で n 回まで微分が同じ」という局所の情報と、「指定した x で誤差が小さい」という評価を結ぶのが、次の剰余項です。

Taylorの定理とLagrange剰余

Lagrangeの剰余項を持つTaylorの定理

n ≥ 0 とし、a と x を含む区間で f が n + 1 回連続微分可能であるとします。x ≠ a なら、a と x の間のある ξ で次が成り立ちます。

f(x)−Pn(x)=f(n+1)(ξ)(n+1)!(x−a)n+1

Rolleの定理を繰り返す

x を固定し、K = (f(x) − Pₙ(x))/(x − a)ⁿ⁺¹ と置きます。g(t) = f(t) − Pₙ(t) − K(t − a)ⁿ⁺¹ は g(x) = 0 で、a では g(a) = g′(a) = … = g⁽ⁿ⁾(a) = 0 です。

g の a と x における零点から、Rolleの定理で間に g′ の零点があります。その零点と g′(a) = 0 から、さらに g″ の零点が得られます。これを n + 1 回続けると、間のある ξ で g⁽ⁿ⁺¹⁾(ξ) = 0。したがって K = f⁽ⁿ⁺¹⁾(ξ)/(n + 1)! です。x < a でも区間の向きを入れ替えれば同じ議論です。

ξ の位置が分からなくても、a と x の間で |f⁽ⁿ⁺¹⁾(t)| ≤ M と分かれば、誤差は M|x − a|ⁿ⁺¹/(n + 1)! 以下です。M はその区間全体で使える上界でなくてはなりません。中心での導関数の値だけでは、途中の増加を抑えられません。

n = 0 なら、この式は f(x) − f(a) = f′(ξ)(x − a) という平均値の定理そのものです。n = 1 なら接線との差を二階導関数で評価します。高次の近似は、突然別の仕組みを持ち込んだのではなく、すでに使った定理を繰り返して得られました。近似の次数を上げるときは、それだけ高い階の微分の存在と上界が新たに必要になります。

平方根の近似と次数の選択

√1.04を求めるのに、中心を1.04自身に取ると定数項に求めたい値が現れてしまいます。そこで値と導関数を正確に計算できる a=1 を選び、h=x−1=0.04 を小さい量として扱います。中心は「目標に近い」だけでなく「必要な情報を知っている」点である必要があります。

例題1：要求精度から二次近似を選ぶ

f(x)=√x とすると、f′(x)=1/(2√x)、f″(x)=−1/(4x3/2)、f‴(x)=3/(8x5/2)。従って P₁(1+h)=1+h/2、P₂(1+h)=1+h/2−h²/8 です。二階導関数そのものが二次の係数ではなく、さらに2!で割る点を確認してください。

まず一次で足りるか見ます。区間[1,1.04]で |f″|≤1/4 なので、|f(1.04)−P₁(1.04)|≤(1/4)(0.04)²/2=0.0002。これは目標10⁻⁵より大きく、この上界では保証できません。ただし、上界が大きいだけで実際の失敗と決めることはできません。

二次なら同じ区間で |f‴|≤3/8。よって誤差は (3/8)(0.04)³/6=0.000004=4×10⁻⁶ 以下です。これで目標を満たすので、P₂(1.04)=1+0.02−0.0002=1.0198を採用できます。単に「二次の方がよさそう」ではなく、要求した精度が選択の理由です。

別解で検算しましょう。q=1.0198とすると q²=1.03999204<1.04。平方根は正なのでq<√1.04であり、差は (1.04−q²)/(√1.04+q)=0.00000796/(√1.04+q) です。分母は2より大きいので差は0.00000398未満。Taylor剰余の保証と一致し、誤差の符号も分かりました。

一次の値1.02についても、差1.02−√1.04=0.0004/(1.02+√1.04)です。√1.04<1.02なので分母は2.04未満、差>0.0004/2.04>10⁻⁵。今度は実際の誤差に下界を与えたので、一次では足りないことまで確かめられます。

目標を x=0.96 に変えると、区間は[0.96,1]です。|f‴(t)|=3/(8t5/2)は t が小さいほど大きいので、先ほどの M=3/8を流用できません。中心が同じでも、目標までの区間が変われば上界を選び直します。√x は0の近くで導関数が大きくなるため、この点検は特に重要です。

指数関数のTaylor展開と収束

例として eˣ を使います。ここでは e⁰ = 1、(eˣ)′ = eˣ、正で増加し e < 3 であるという性質を借用します。次章では級数から指数関数を構成してこれらを示し、その構成にこの章の展開を使いません。したがって以下は、性質が与えられた関数を近似する議論です。

0 でのすべての導関数が 1 なので Pₙ(x) = 1 + x + x²/2! + … + xⁿ/n!。例えば x = 1/2 で4次まで使うと P₄(1/2) = 211/128 = 1.6484375 です。0 から 1/2 の間で5階導関数 eᵗ は e より小さいため、誤差は 3(1/2)⁵/5! = 1/1280 未満と保証できます。

さらに固定した R > 0 に対し |x| ≤ R で考えると、剰余の絶対値は eᴿRⁿ⁺¹/(n + 1)! 以下。この上界の隣り合う項の比は R/(n + 2) となり、十分後では 1/2 以下です。その先は定数倍の (1/2)ⁿ で抑えられるので、幾何べきの極限により上界は 0 へ近づきます。したがって任意の固定した有限区間で Pₙ(x) → eˣ と分かります。単に微分が何回でもできるからでなく、剰余が消えることを示したのです。

区間全体での誤差保証と次数の比較

一つの値だけでなく、|x|≤1/2の全てで eˣ を誤差10⁻⁶以下にしたいとします。入力ごとに次数を選び直す代わりに、区間共通の多項式を作る問題です。指数関数の性質は前節と同じ借用の下で使います。

例題2：計算する前に保証できる次数を決める

0からxまでの全てのtに対し eᵗ<3です。したがって、n次多項式の区間共通の誤差上界として Bₙ=3(1/2)n+1/(n+1)! を使えます。xが負でも |x|≤1/2 と同じ上界が使えるので、正負を別々に計算する必要はありません。

Bn+1/Bₙ=(1/2)/(n+2)。各次数についてべきと階乗を初めから計算する代わりに、この比で次の上界を更新できます。n≥0では比が1/4以下なので、この上界は単調に減ります。

次の表で10⁻⁶と比べ、最初に条件を満たす行を選んでください。「不十分」の意味は、実際の近似の失敗でしょうか、それともこの上界での保証の失敗でしょうか。小数列は最初の0でない数字から4桁に切り上げ、分数の上界を保っています。

同じ中心0、同じ区間|x|≤1/2、同じ上界M=3で比較。誤差は無単位。有限の4行は全次数の証明ではなく、単調性は本文の比によります。

上界の選択まで含めて結論を読む

7次なら全入力で条件を保証できます。Bₙが単調に減りB₆>10⁻⁶なので、この上界を使って選ぶ最小次数は7です。eᵗ≤3という評価は粗く、実際の誤差がBₙと等しいわけではありません。より小さいMや別の剰余評価で、より低い次数を保証できる可能性は残ります。

例えばx=0ではどの次数でも誤差0ですが、共通の上界Bₙは正です。上界を実際の誤差と同一視できない、最も簡単な検算です。一方、区間を広げると |x|n+1 だけでなく導関数の上界も変わり得ます。次数だけを増やすのでなく、区間を小さくして同じ多項式を使う考え方もあります。

べき級数の収束半径と端点

係数 cₙ を持つ ∑ₙ₌₀∞ cₙ(x − a)ⁿ を、a を中心とするべき級数と呼びます。|x − a| < R で絶対収束し、|x − a| > R で発散する境目 R が存在するとき、それを収束半径といいます。R = 0（中心以外で発散）や R = ∞（すべての実数で絶対収束）も認めます。R が正の有限値なら、境界 |x − a| = R は別に判定します。以下の例では、この性質を直接確かめます。

f(x) = 1/(1 − x) は、0 での k 階導関数が k! なので、Taylor多項式は 1 + x + … + xⁿ です。この例では幾何級数の有限和から、誤差を直接正確に書けます。

11−x−∑k=0nxk=xn+11−x(x≠1)

|x| < 1 なら|x|ⁿ⁺¹ → 0 なので誤差は 0 へ近づき、級数は関数を表します。絶対値の級数も比 |x| の幾何級数なので収束します。|x| > 1 では項自体が 0 に近づかず発散。境界 x = −1 では部分和が振動し、x = 1 では部分和が増大し元の関数も定義されません。この級数の収束半径は 1 です。f(2) = −1 は計算できますが、その値をこの0中心の級数で得ることはできません。

Taylorの定理は各 n の有限の等式です。無限級数として f と等しいという主張には、剰余が 0 に近づく追加の証明が必要です。導関数の上界 M が n に応じて大きくなる場合、分母の階乗だけを見て誤差が消えるとは言えません。

展開の中心を変える効果と剰余評価の限界

0を中心とする級数が届かない点でも、元の関数が定義されていれば、別の中心が使えることがあります。必要なのは同じ係数の式を無理に延ばすことではなく、中心の値と導関数から多項式を作り直すことです。

例題3：同じ関数を別の中心から近似する

f(x)=1/(1−x)で x=−2 の値を考えます。もちろん直接計算ならf(−2)=1/3で、以下は中心の役割を確かめる自作の練習です。0中心の級数の項は(−2)kとなって0へ行かず、この級数では近似できません。

a=−1を選び、h=x+1と書きます。分母は2−hなので、f(−1+h)=(1/2)/(1−h/2)。有限の幾何和を使うと、n次Taylor多項式は Qₙ(x)=(1/2)∑k=0n(h/2)kで、差は (1/2)(h/2)n+1/(1−h/2)です。hのk乗の係数1/2k+1は、f⁽ᵏ⁾(−1)/k!とも一致します。

x=−2ではh=−1なので、誤差の絶対値は1/[3·2n+1]。n=4で1/96>1/100、n=5で1/192<1/100。従って5次を選べます。Q₅(−2)=21/64、1/3−21/64=1/192と検算できます。0中心では失敗しても、中心−1なら収束半径2、距離1の点はその内部です。

どの中心でもよいわけではありません。a=1では関数が定義されず、導関数の値からTaylor多項式を作れません。また中心から目標までの区間に特異な点x=1を挟めば、本章のTaylor定理の連続微分可能性の仮定を満たしません。

最後に、剰余の上界が消えないときの読み方を点検します。同じfを中心0、x=1/2で扱い、Lagrange剰余に区間[0,1/2]の最大値をそのまま入れると、f⁽ⁿ⁺¹⁾(t)=(n+1)!/(1−t)n+2なので Mₙ=(n+1)!2n+2。上界は Mₙ(1/2)n+1/(n+1)!=2 となり、次数を上げても0になりません。

それでも正確な差は (1/2)n+1/(1−1/2)=2−n→0です。従って「この上界では収束を示せない」と「収束しない」は別です。逆に、Mₙの変化を無視して「階乗があるから必ず0」と言うこともできません。有限の定理、選んだ上界、その上界の極限を一段ずつ区別します。

寄り道［応用］：sin ボタンの中には、小さな多項式がいる

数値計算ライブラリ fdlibm の sin の内部関数は、入力をおおむね −π/4 から π/4 の範囲に限り、13次の多項式で近似します。公開ソースには x + S₁x³ + ⋯ + S₆x¹³ という形と、目標の誤差評価が記されています。三角関数の値を得る仕事の一部が、足し算と掛け算へ置き換えられているのです。

係数は Taylor 係数をそのまま有限個並べたものとは限りません。限られた区間での近似誤差や、機械での丸めを考えて選ばれています。また大きい角度には、先に小さい範囲へ読み替える処理が要ります。本文の Taylor 定理は、こうした数値用多項式を自動的に保証するものではありません。それでも「近い点で関数を多項式に置き換え、残りを評価する」という発想が、実際の関数計算の設計へつながることは分かります。

出典：Netlib fdlibm：k_sin.c の多項式近似。

Taylor係数・剰余・収束範囲の演習

1．中心を移す

f(x) = x³ の a = 1 を中心とする2次Taylor多項式を求め、正確な差も求めてください。

ヒント1：中心での値

f(1) = 1、f′(1) = 3、f″(1) = 6 です。

ヒント2：x = 1 + (x − 1)

三乗を展開すると、残る三次の項が見えます。

解答

P₂(x) = 1 + 3(x − 1) + 3(x − 1)²。x³ − P₂(x) = (x − 1)³ です。f‴ = 6 なので、剰余の式も 6(x − 1)³/3! = (x − 1)³ と一致します。

2．指数関数の二次近似

|x| ≤ 0.1 で eˣ を 1 + x + x²/2 で近似します。e < 3 を使って、区間全体の誤差上限を示してください。

ヒント1：次は3階導関数

中心0と x の間では eᵗ < 3 を使えます。

ヒント2：最大の距離

3|x|³/3! を |x| ≤ 0.1 で評価します。

解答

|eˣ − (1 + x + x²/2)| ≤ 3(0.1)³/6 = 0.0005。この上界は正負両方の x に使えます。実際の誤差と上界が等しいという主張ではなく、指定した範囲でそれ以下に収まるという保証です。

3．関数の定義域と収束域

1/(1 − x) の0中心のTaylor級数について、x = 1/2、−1、2 の各点で関数が定義されるか、級数がその値へ収束するかを判定してください。

ヒント1：分母を見る

関数が定義されないのは x = 1 です。

ヒント2：級数は幾何級数

収束には |x| < 1 が必要です。

解答

三点とも関数は定義され、値は順に 2、1/2、−1。級数が収束するのは x = 1/2 だけで、和は 2。x = −1 では部分和が振動し、x = 2 では項が増大します。関数を計算できる範囲と、その級数が表せる範囲は一致するとは限りません。

4．中心の情報から多項式を作る

f(2)=3、f′(2)=−1、f″(2)=4と分かっています。中心2の二次Taylor多項式とx=2.1での近似値を求めてください。[2,2.1]で|f‴|≤6なら、誤差をどこまで保証できますか。

ヒント1：方針

h=x−2と置き、二次係数を2!で割ります。

ヒント2：計算の足場

P₂=3−h+2h²。剰余には6|h|³/3!を使います。

解答

P₂(x)=3−(x−2)+2(x−2)²、P₂(2.1)=3−0.1+0.02=2.92。誤差は6(0.1)³/6=0.001以下です。中心2では値3、傾き−1、二階導関数4となるので、与えられた三つの情報とも一致します。

5．上界の不足と実際の失敗を区別する

√1.04の一次近似1.02について、Lagrange上界0.0002>10⁻⁵だけから「誤差は10⁻⁵より大きい」と結論できますか。正確な差の変形を使って実際に失敗することを示してください。

ヒント1：方針

大きい上界の下に、小さい誤差がある可能性は残ります。下界が必要です。

ヒント2：計算の足場

1.02−√1.04=(1.02²−1.04)/(1.02+√1.04)を使います。

解答

上界だけから失敗とはいえません。今回は1.02²=1.0404なので正確な差は0.0004/(1.02+√1.04)。√1.04<1.02より分母<2.04なので、差>0.0004/2.04>10⁻⁵。こちらは下界を示したので、実際に目標を満たさないと分かります。

6．区間全体を保証する次数を決める

|x|≤1/2でeˣの0中心Taylor近似を誤差10⁻⁶以下にしたいとします。M=3を使う上界Bₙで選ぶ最小次数を求め、それが実際の誤差に関する最小次数と同じとは限らない理由も説明してください。

ヒント1：方針

Bₙ=3(1/2)ⁿ⁺¹/(n+1)!です。

ヒント2：計算の足場

B₆=1/215040、B₇=1/3440640で、Bₙは減少します。

解答

B₆>10⁻⁶、B₇<10⁻⁶なので、この上界による最小次数は7です。Bₙ₊₁/Bₙ=1/[2(n+2)]<1なので、それより低い次数の上界はさらに大きくなります。ただしM=3は粗い上界で、実際の誤差はもっと小さくなり得ます。従ってこれだけで実際に6次が失敗すると結論できません。

7．中心での微分値だけを使う誤り

f(x)=x³を中心0で一次近似するとP₁=0です。「f″(0)=0なので剰余も0」とする議論を直してください。0≤x≤h、h>0で使えるMを選び、正確な差とも比べてください。

ヒント1：方針

剰余の導関数は0でなく、0とxの間の点で評価されます。

ヒント2：計算の足場

f″(t)=6tなので区間[0,h]ではM=6hです。

解答

中心の値だけでは区間を抑えられません。|f(x)−P₁(x)|≤(6h)x²/2=3hx²≤3h³と保証できます。正確な差はx³で、x=hではh³。上界3h³は粗いですが正しく、誤差0という結論は誤りです。

8．関数の計算可能性と中心を選ぶ

f(x)=1/(1−x)のx=2での値を近似します。中心0が使えない理由を述べ、中心3でh=x−3と置いてTaylor多項式を作ってください。正確な尾部から誤差1/100以下になる最小次数も求めてください。

ヒント1：方針

f(3+h)=−(1/2)/(1+h/2)と書きます。

ヒント2：計算の足場

x=2ではh=−1なので級数の比は1/2です。次数nなら項数はn+1です。

解答

0中心では項2ᵏが0へ行かず発散します。中心3ならQₙ(x)=−(1/2)∑ₖ₌₀ⁿ(−h/2)ᵏ。x=2でQₙ=−1+2⁻⁽ⁿ⁺¹⁾、正確な値−1との差は−2⁻⁽ⁿ⁺¹⁾。n=5の誤差1/64は大きく、n=6の1/128は十分なので最小6次です。[2,3]は特異点1を含まず、中心の選択も定理の仮定と整合します。

9．消えない上界から何が分かるか

f(x)=1/(1−x)を中心0、x=1/2で近似すると、区間での導関数の最大値を使うLagrange上界は全次数で2になります。これを理由にTaylor級数が発散するといえますか。正確な剰余を使って判定してください。

ヒント1：方針

誤差≤2は、誤差が0へ行かないという下界ではありません。

ヒント2：計算の足場

幾何和による正確な差はxⁿ⁺¹/(1−x)です。

解答

いえません。正確な剰余は(1/2)ⁿ⁺¹/(1/2)=2⁻ⁿなので0へ行き、級数はf(1/2)=2へ収束します。上界2は全ての次数に正しいものの、収束を証明するには粗すぎます。上界の失敗と対象の失敗を区別する例です。

10．同じ次数で使える区間を選ぶ

f(x)=1/(1−x)のP₃(x)=1+x+x²+x³を区間全体で誤差1/100以下にしたいとします。|x|≤1/4と|x|≤1/3のどちらが使えますか。区間全体の上界と、使えない方の反例を示してください。

ヒント1：方針

|剰余|=|x|⁴/|1−x|≤ρ⁴/(1−ρ)を使います。

ヒント2：計算の足場

ρ=1/4では1/192、ρ=1/3では1/54です。後者はx=1/3で等号になります。

解答

|x|≤1/4なら誤差≤(1/4)⁴/(3/4)=1/192<1/100なので使えます。|x|≤1/3の上界1/54だけでは直ちに失敗といえませんが、x=1/3で正確な誤差も1/54>1/100となります。従ってその区間全体への保証は不可能です。次数を固定し、使う区間を精度から設計しました。
