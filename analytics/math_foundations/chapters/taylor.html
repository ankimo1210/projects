Taylor多項式と関数の近似

一次近似では、一点での値と傾きを合わせた直線を使いました。さらに曲がり方も合わせれば、もっとよい近似になるでしょうか。多項式は値も微分も計算しやすいので、複雑な関数を近くで扱う道具になります。ただし項数を増やした見た目だけで正確さを判断せず、残った誤差を式で管理します。

前提は高階の微分、Rolleの定理、級数です。高階導関数 f⁽ᵏ⁾ は k 回微分した関数、階乗 n! は 1 から n までの積で 0! = 1 とします。この章ではまず有限の近似を証明し、その後で無限の展開へ進める条件を調べます。

Taylor多項式の定義

中心 a において f と n 次までの導関数が一致するよう、多項式 Pₙ を作ります。定数項は f(a)、一次の係数は f′(a)。二次の項を2回微分すると係数の2倍になるので、二次の係数は f″(a)/2 です。同じ考えを続けると、階乗で割る理由が分かります。

Pn(x)=∑k=0nf(k)(a)k!(x−a)k

これが a を中心とするTaylor多項式です。定義だけでは、離れた x で f に近いことはまだ保証しません。「a で n 回まで微分が同じ」という局所の情報と、「指定した x で誤差が小さい」という評価を結ぶのが、次の剰余項です。

Taylorの定理とLagrange剰余

Lagrangeの剰余項を持つTaylorの定理

n ≥ 0 とし、a と x を含む区間で f が n + 1 回連続微分可能であるとします。x ≠ a なら、a と x の間のある ξ で次が成り立ちます。

f(x)−Pn(x)=f(n+1)(ξ)(n+1)!(x−a)n+1

Rolleの定理を繰り返す

x を固定し、K = (f(x) − Pₙ(x))/(x − a)ⁿ⁺¹ と置きます。g(t) = f(t) − Pₙ(t) − K(t − a)ⁿ⁺¹ は g(x) = 0 で、a では g(a) = g′(a) = … = g⁽ⁿ⁾(a) = 0 です。

g の a と x における零点から、Rolleの定理で間に g′ の零点があります。その零点と g′(a) = 0 から、さらに g″ の零点が得られます。これを n + 1 回続けると、間のある ξ で g⁽ⁿ⁺¹⁾(ξ) = 0。したがって K = f⁽ⁿ⁺¹⁾(ξ)/(n + 1)! です。x < a でも区間の向きを入れ替えれば同じ議論です。

ξ の位置が分からなくても、a と x の間で |f⁽ⁿ⁺¹⁾(t)| ≤ M と分かれば、誤差は M|x − a|ⁿ⁺¹/(n + 1)! 以下です。M はその区間全体で使える上界でなくてはなりません。中心での導関数の値だけでは、途中の増加を抑えられません。

n = 0 なら、この式は f(x) − f(a) = f′(ξ)(x − a) という平均値の定理そのものです。n = 1 なら接線との差を二階導関数で評価します。高次の近似は、突然別の仕組みを持ち込んだのではなく、すでに使った定理を繰り返して得られました。近似の次数を上げるときは、それだけ高い階の微分の存在と上界が新たに必要になります。

指数関数のTaylor展開と収束

例として eˣ を使います。ここでは e⁰ = 1、(eˣ)′ = eˣ、正で増加し e < 3 であるという性質を借用します。次章では級数から指数関数を構成してこれらを示し、その構成にこの章の展開を使いません。したがって以下は、性質が与えられた関数を近似する議論です。

0 でのすべての導関数が 1 なので Pₙ(x) = 1 + x + x²/2! + … + xⁿ/n!。例えば x = 1/2 で4次まで使うと P₄(1/2) = 211/128 = 1.6484375 です。0 から 1/2 の間で5階導関数 eᵗ は e より小さいため、誤差は 3(1/2)⁵/5! = 1/1280 未満と保証できます。

さらに固定した R > 0 に対し |x| ≤ R で考えると、剰余の絶対値は eᴿRⁿ⁺¹/(n + 1)! 以下。この上界の隣り合う項の比は R/(n + 2) となり、十分後では 1/2 以下です。その先は定数倍の (1/2)ⁿ で抑えられるので、幾何べきの極限により上界は 0 へ近づきます。したがって任意の固定した有限区間で Pₙ(x) → eˣ と分かります。単に微分が何回でもできるからでなく、剰余が消えることを示したのです。

べき級数の収束半径と端点

係数 cₙ を持つ ∑ₙ₌₀∞ cₙ(x − a)ⁿ を、a を中心とするべき級数と呼びます。|x − a| < R で絶対収束し、|x − a| > R で発散する境目 R が存在するとき、それを収束半径といいます。R = 0（中心以外で発散）や R = ∞（すべての実数で絶対収束）も認めます。R が正の有限値なら、境界 |x − a| = R は別に判定します。以下の例では、この性質を直接確かめます。

f(x) = 1/(1 − x) は、0 での k 階導関数が k! なので、Taylor多項式は 1 + x + … + xⁿ です。この例では幾何級数の有限和から、誤差を直接正確に書けます。

11−x−∑k=0nxk=xn+11−x(x≠1)

|x| < 1 なら|x|ⁿ⁺¹ → 0 なので誤差は 0 へ近づき、級数は関数を表します。絶対値の級数も比 |x| の幾何級数なので収束します。|x| > 1 では項自体が 0 に近づかず発散。境界 x = −1 では部分和が振動し、x = 1 では部分和が増大し元の関数も定義されません。この級数の収束半径は 1 です。f(2) = −1 は計算できますが、その値をこの0中心の級数で得ることはできません。

Taylorの定理は各 n の有限の等式です。無限級数として f と等しいという主張には、剰余が 0 に近づく追加の証明が必要です。導関数の上界 M が n に応じて大きくなる場合、分母の階乗だけを見て誤差が消えるとは言えません。

寄り道［応用］：sin ボタンの中には、小さな多項式がいる

数値計算ライブラリ fdlibm の sin の内部関数は、入力をおおむね −π/4 から π/4 の範囲に限り、13次の多項式で近似します。公開ソースには x + S₁x³ + ⋯ + S₆x¹³ という形と、目標の誤差評価が記されています。三角関数の値を得る仕事の一部が、足し算と掛け算へ置き換えられているのです。

係数は Taylor 係数をそのまま有限個並べたものとは限りません。限られた区間での近似誤差や、機械での丸めを考えて選ばれています。また大きい角度には、先に小さい範囲へ読み替える処理が要ります。本文の Taylor 定理は、こうした数値用多項式を自動的に保証するものではありません。それでも「近い点で関数を多項式に置き換え、残りを評価する」という発想が、実際の関数計算の設計へつながることは分かります。

Taylor係数・剰余・収束範囲の演習

1．中心を移す

f(x) = x³ の a = 1 を中心とする2次Taylor多項式を求め、正確な差も求めてください。

ヒント1：中心での値

f(1) = 1、f′(1) = 3、f″(1) = 6 です。

ヒント2：x = 1 + (x − 1)

三乗を展開すると、残る三次の項が見えます。

解答

P₂(x) = 1 + 3(x − 1) + 3(x − 1)²。x³ − P₂(x) = (x − 1)³ です。f‴ = 6 なので、剰余の式も 6(x − 1)³/3! = (x − 1)³ と一致します。

2．指数関数の二次近似

|x| ≤ 0.1 で eˣ を 1 + x + x²/2 で近似します。e < 3 を使って、区間全体の誤差上限を示してください。

ヒント1：次は3階導関数

中心0と x の間では eᵗ < 3 を使えます。

ヒント2：最大の距離

3|x|³/3! を |x| ≤ 0.1 で評価します。

解答

|eˣ − (1 + x + x²/2)| ≤ 3(0.1)³/6 = 0.0005。この上界は正負両方の x に使えます。実際の誤差と上界が等しいという主張ではなく、指定した範囲でそれ以下に収まるという保証です。

3．関数の定義域と収束域

1/(1 − x) の0中心のTaylor級数について、x = 1/2、−1、2 の各点で関数が定義されるか、級数がその値へ収束するかを判定してください。

ヒント1：分母を見る

関数が定義されないのは x = 1 です。

ヒント2：級数は幾何級数

収束には |x| < 1 が必要です。

解答

三点とも関数は定義され、値は順に 2、1/2、−1。級数が収束するのは x = 1/2 だけで、和は 2。x = −1 では部分和が振動し、x = 2 では項が増大します。関数を計算できる範囲と、その級数が表せる範囲は一致するとは限りません。
