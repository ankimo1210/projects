複素微分と方向の独立性

実数の微分では、右からでも左からでも同じ差商へ近づくことを求めました。複素数では、調べる点 a を固定しても、そこからの増分 h は横、縦、斜め、さらに曲がった道から0へ近づけます。それでも一つの数が変化率を表せるなら、平面の変換はどれほど制限されるのでしょう。

前提は複素極限と開集合、二成分の実全微分です。偏微分の存在と、全微分可能性を区別して使います。

学習の目安は演習を含めて120–170分です。差商と逆数の例題、実行列とCRの条件、未知の関数の設計と演習に分けて進められます。演習1–3は基本、4–6は評価と条件の診断、7–9は設計・近似・定義域の点検です。

複素導関数の定義

開集合 U ⊂ ℂ、a ∈ U、関数 f : U → ℂ を考えます。次の極限が複素数として存在するとき、f は a で複素微分可能といい、極限を f′(a) と書きます。h は実数に限らず、十分小さいすべての非零複素数を動きます。

f′(a)=limh→0,h≠0f(a+h)−f(a)h

c = f′(a) とすると、これは f(a + h) = f(a) + ch + R(h)、|R(h)|/|h| → 0 と同じ条件です。実際、差商から c を引いたものが R(h)/h で、その絶対値は |R(h)|/|h| です。複素微分は、一次近似が一つの複素数を掛ける操作になるという条件なのです。この余りの式から連続性も従います。

この先の比較で使う正則は、ある開集合のすべての点で複素微分できることです。「点 a で正則」というときも、その点を含む小さな開集合全体で成り立つことを求めます。一点の差商が収束する条件と分けて観察します。

二乗では、方向によらない誤差が残る

f(z) = z² なら、h ≠ 0 で ((a + h)² − a²)/h = 2a + h。どの方向から h → 0 としても、2a との距離はちょうど |h| なので0へ行き、f′(a) = 2a です。有限の差商は 2a と同じではありません。誤差を評価できたことで、全方向の極限が保証されました。

θだけを変え、選んだ方向の差商を示す丸の値を比べます。四角は実方向、三角は虚方向の差商の基準値で、θに依りません。縮尺は表示する値に応じて変わるので、画面上の位置だけでなく数値欄でも確かめてください。z² なら微分の輪との距離は h、共役なら h を減らしても方向差が残ります。図は有限の刻みの比較であり、全方向の極限の証明は差商の式で行います。一点で微分できることと、その近傍で正則なことも表の条件で分けてください。

差商を評価して全方向の極限を示す

二本の方向で差商が違えば微分不可能と分かります。逆に、何本かの方向で同じ値になっただけでは微分可能とは言えません。存在を示すときには、増分の向きを含まない |h| の評価へ持ち込むのが有効です。

例題1：逆数の差商では、分母を先に守る

f(z)=1/z の定義域は U=ℂ∖{0} です。a≠0 を固定して微分します。商の微分公式をまだ使わず、定義から導きます。増分 h が −a なら f(a+h) が未定義になるため、まず 0<|h|<|a|/2 に制限します。逆三角不等式から |a+h|≥|a|−|h|>|a|/2 で、分母が0から離れます。

差を通分して h を約分すると、[1/(a+h)−1/a]/h=−1/[a(a+h)]。極限の候補は −1/a² です。候補との差は h/[a²(a+h)] なので、その絶対値は 2|h|/|a|³ 未満です。この上界は向きによらず0へ近づき、f′(a)=−1/a² と分かります。

例えば a=1+i なら a²=2i、f′(a)=−1/(2i)=i/2 です。微分値を掛け戻すと (i/2)(2i)=−1 となり符号を検算できます。a=0へ同じ式を代入することはできません。関数そのものが未定義であり、微分の問題を始められないためです。

ε>0 に対し δ=min(|a|/2, ε|a|³/2) を選べば、0<|h|<δ から差商の誤差は ε 未満です。「分母は近くでも0でない」という説明を、どれくらい近ければよいかまで具体化しています。

複素微分と実線形写像

複素数を実二成分として見るとき、実線形な写像 T は、任意の実数 s,t と複素数 z,w に対し T(sz+tw)=sT(z)+tT(w) を満たします。複素線形では、係数 s,t に複素数も許します。例えば T(x+iy)=2x+iy は実線形ですが、T(i)=i と iT(1)=2i が違うので複素線形ではありません。一つの複素数を掛ける形は、この追加の条件も満たします。

c=α+iβ（α,βは実数）とし、この段と直下の行列表示では増分を h+ik（h,kは実数）と書きます。この h は増分の実部で、前後の差商で複素増分全体を表す h とは役割が異なります。c を掛けると c(h+ik)=(αh−βk)+i(βh+αk) です。実二成分での行列は次の特別な形になります。一般の実行列の四つの成分が、二つの実数 α,β で決まります。

h+ik↦c(h+ik)↔[α−ββα]

c ≠ 0 なら、一次近似は全方向を同じ倍率 |c| で拡大し、同じ角度だけ回します。c = 0 では一次の項は全部0となり、この一次近似に回転角や角度保存を割り当てられません。二乗も a = 0 ではこの場合です。

f(x+iy)=u(x,y)+iv(x,y) と書き、u を実部、v を虚部を返す実関数とします。uₓ は y を固定して x で微分した偏導関数、uᵧ は x を固定して y で微分したものです。vₓ,vᵧ も同じ記法です。実全微分 Du,Dv は、それぞれの関数の一次近似を表す線形写像で、二つをまとめた実微分行列の上段は (uₓ,uᵧ)、下段は (vₓ,vᵧ) になります。

実全微分可能とは、この行列による一次近似の余りを、入力の増分の長さで割ると0へ近づくことでした。複素微分可能なら、先ほどの余りの式がそのまま実全微分を与えます。その行列は上の特別な形なので、次のCauchy–Riemannの関係式（CR）が必要です。

ux=vy,uy=−vx,f′=ux+ivx

二本の軸だけで必要性を確認することもできます。実の h では差商は uₓ + ivₓ へ、h = it では vᵧ − iuᵧ へ近づきます。同じ数になるには上の二式が必要です。ただし、この確認だけでは全方向の極限の存在を示していません。

コーシー・リーマン方程式と実全微分

C¹ とは、近傍で偏微分が存在し、連続であるという便利な十分条件です。複素微分の定義に、導関数の連続性を最初から要求しているわけではありません。偏導関数の連続性から全微分を得る議論を使っています。

CRが十分になる条件

u、v が a で実全微分可能であるとします。このとき f = u + iv が a で複素微分可能であることと、a でCRを満たすことは同値です。特に、u、v が a の開近傍で C¹ なら実全微分可能性が保証されるので、CRを確かめれば十分です。

行列の形を、余りの式へ戻す

必要性は複素微分と実線形写像の節で示しました。逆向きでは、実全微分可能性から f(a + h) − f(a) = Ah + R(h)、|R(h)|/|h| → 0 と書けます。ここで h を実二成分のベクトルと同一視しています。CRにより A は複素数の乗算を表す行列なので、Ah は c h、c = uₓ(a) + ivₓ(a) です。h ≠ 0 で割れば差商は c + R(h)/h。後者の絶対値は0へ近づくので、複素微分が存在します。

点での偏微分とCRだけでは不十分です。原点以外で G(x, y) = x²y/(x² + y²)、G(0, 0) = 0 とし、f = G + 0i を考えます。二軸上では G = 0 なので、原点の四つの偏微分はすべて0でCRを満たします。しかし h = t(1 + i) なら f(h)/h = (t/2)/(t(1 + i)) = (1 − i)/4。実軸では0です。極限は存在しません。|G(x, y)| ≤ |y| なので連続ではありますが、原点で実全微分できないことが抜けていたのです。

CRから関数を設計し、成立する点を分類する

CRは与えられた関数を検査するだけでなく、まだ分からない成分や係数を決める条件にもなります。実部と虚部の候補を作った後、実全微分可能性と、条件が成り立つ場所の両方を確認します。

例題2：実部から虚部を作る

実部が u(x,y)=x²−y²+x である、全平面で正則な f=u+iv を作り、f(0)=0 も満たすようにします。未知なのは実関数 v です。CRから vₓ=−uᵧ=2y、vᵧ=uₓ=2x+1 という二つの条件が必要になります。

まず vₓ=2y を x で積分します。y は固定しているので v=2xy+g(y)。積分の「定数」は y に依存してよく、ここを実定数だけにすると候補を失います。次に y で微分すると vᵧ=2x+g′(y)。もう一方の条件と比べて g′(y)=1、したがって g(y)=y+C です。

候補 v=2xy+y+C は多項式なので C¹ で、CRを全平面で満たします。よって十分条件も使えて f(z)=z²+z+iC は正則です。f(0)=iC=0 から C=0 と決まり、答えは f(z)=z²+z。導関数2z+1の実部は2x+1、虚部は2yで、uₓ+ivₓと一致します。

定義域を二つの離れた開円板へ制限すれば、それぞれで違う定数 C を選んでも局所のCRは変わりません。この例で一つの C を使ったのは、全平面上の一つの式として v を構成したためです。

例題3：係数によって「一点だけ」と「全体」が入れ替わる

実数 λ を固定し、fλ(x+iy)=x²−y²+iλxy を全平面で定めます。どの λ で正則になるか、正則でない場合にも微分できる点があるかを調べます。成分はどの λ でも C¹ なので、この例ではCRを解けば必要十分です。

uₓ=2x、uᵧ=−2y、vₓ=λy、vᵧ=λx。CRは (2−λ)x=0 と (λ−2)y=0 です。λ=2 ならどの x,y でも成立して f₂(z)=z²、導関数は2z。λ≠2 なら x=y=0 に限られます。

原点の微分は差商からも確認できます。r=|h| とすれば |x²−y²|≤r²、|xy|≤r²/2 より、|fλ(h)/h|≤(1+|λ|/2)r→0。従ってすべての λ で fλ′(0)=0 です。λ≠2 の場合は、原点を含むどんな開円板にも x≠0 の実数があり、そこでCRが破れるので、原点で正則とは言えません。

次の表で、λを少し変えることが「微分値の小さな変化」だけで済むか確かめてください。どの行も原点での導関数は同じ0です。

原点の導関数が同じでも、近傍での成立範囲は異なる
λ関数の式微分できる点原点で正則か
2z²全平面はい
0x²−y²原点だけいいえ
−2z̄²原点だけいいえ

λ=0、−2は分類の具体例です。任意の λ≠2 について原点だけになることは、例題3の二つの一次条件が保証しています。「正則か」を一つの点への代入だけで判定できない理由が、成立範囲の列に表れています。

一点の複素微分可能性と正則性

開集合 U のすべての点で複素微分可能なとき、f は U で正則といいます。「a で正則」という場合も、a を含むある開近傍で正則という意味で使います。一点だけで微分できるという主張より強い条件です。

共役 f(z) = z̄ では、どの a でも差商は h̄/h。実の h では1、純虚数の h では−1なので、どこでも複素微分できません。鏡映という実の線形変換は存在しますが、その行列は対角成分が1、−1で、複素数を掛ける形ではありません。

一方、f(z) = |z|² = x² + y² は、uₓ = 2x、uᵧ = 2y、vₓ = vᵧ = 0。成分は C¹ なのでCRが成り立つ原点だけで微分可能です。実際、a = 0 の差商は |h|²/h = h̄ → 0 です。しかし原点を含むどんな開円板にも非零の点があるため、原点のどの近傍でも正則ではありません。

「実全微分＋CR」が一点での複素微分を保証します。表の G は本文で定義した x²y/(x²+y²) の反例です。正則性を言うには、その点だけでなく開集合内の全ての点で複素微分できることが必要です。式を一つ代入する検査と、成立する点の範囲の検査を分けてください。

和・積の微分則も、実微分と同じ差商の分解から得られます。積では f、g の微分可能性による連続性を使って (fg)′ = f′g + fg′、g(a) ≠ 0 では (f/g)′ = (f′g − fg′)/g² です。合成では実全微分の連鎖律を使うと二つの複素乗算が合成され、(g ∘ f)′(a) = g′(f(a))f′(a)。合成先の開集合に f(a) が入り、その近くで合成が定義できることが必要です。

これで多項式は全平面、有理関数は分母が0でない開集合で正則と分かります。次章では同じ基準で、指数関数と対数を作ります。局所でできる逆操作が平面全体でできるか、という定義域の問題も現れます。

寄り道［自作モデル］：円を楕円にする拡大は、複素数一つで書けるか

T(x, y) = (2x, y) という横だけ2倍のモデルを考えます。実線形であり、余りは0です。しかし複素微分できるなら、入力1の出力2から掛ける数は2と決まります。その数をiへ掛けると2iになるはずなのに、Tの出力はiです。一つの掛け算では二つの方向を同時に説明できません。

実微分は一般の行列を許し、複素微分は回転と一様な拡大の形を要求します。複素微分の条件が強いことは、この小さな矛盾からも見えます。後の境界から内部を取り出す公式は、この強い条件が生む性質です。

出典：本章で定めた線形モデルの直接計算です。実在する物体の変形則を仮定したものではありません。

演習：複素微分と正則性

1．三乗の全方向の微分

f(z) = z³ の導関数を、差商と誤差の評価から求めてください。

ヒント1：差を展開する

(a + h)³ − a³ = 3a²h + 3ah² + h³ です。

ヒント2：方向を使わずに上限を取る

差商と 3a² の差の絶対値を、|h| だけで抑えます。

解答

差商は 3a² + 3ah + h²。誤差は |3ah + h²| ≤ 3|a||h| + |h|² → 0 なので、どの方向でも f′(a) = 3a² です。全平面で複素微分可能なため正則です。

2．CRと行列が一致するか

f(x + iy) = (x² − y²) + i(2xy) についてCRを確かめ、a = 1 + i での実微分行列と複素導関数を求めてください。

ヒント1：四つの偏微分

uₓ = 2x、uᵧ = −2y、vₓ = 2y、vᵧ = 2x です。

ヒント2：実全微分の根拠

四つの偏導関数は連続です。a では x = y = 1 を代入します。

解答

全平面で成分は C¹、uₓ = vᵧ、uᵧ = −vₓ なので正則です。a で行列の第一行は (2, −2)、第二行は (2, 2)。これは 2 + 2i を掛ける行列であり、f′(a) = 2 + 2i = 2a と一致します。

3．一点で微分できれば十分か

f(z) = |z|² の原点での導関数を直接求め、原点で正則といえない理由を説明してください。

ヒント1：非零の増分で割る

|h|² = h h̄ を使えば、差商は簡単になります。

ヒント2：近傍内の非零の点

原点のどんな開円板にも、x ≠ 0 の実数の点が入ります。その点でCRを調べます。

解答

原点では差商が h̄ なので f′(0) = 0。一方、非零実数 x では uₓ = 2x ≠ 0 = vᵧ でCRに反し、微分できません。原点のどの開近傍にもこのような点があるため、原点を含む開集合で正則にはなりません。

4．逆数の誤差を先に指定する

f(z)=1/z、a=2i とします。f′(a)を求め、差商と f′(a) の距離を ε 未満にする δ を一つ選んでください。

ヒント1：方針を選ぶ

例題1の上界2|h|/|a|³を使えます。

ヒント2：条件を絞る

|a|=2なので、まず|h|<1なら|a+h|>1です。

解答

a²=−4なのでf′(a)=1/4。0<|h|<1では差商の誤差は2|h|/8=|h|/4未満です。δ=min(1,4ε) とすれば誤差はε未満になります。δを小さくすることは許され、全方向に一つのδが使えるのが要点です。

5．未知の一次項を設計する

実数α,βに対し f(x+iy)=x²−y²+i(2xy+αx+βy) とします。複素微分できる点が一つでも存在するためのα,βの条件と、そのときの正則性を調べてください。

ヒント1：方針を選ぶ

成分はC¹です。四つの偏微分をCRへ入れます。

ヒント2：条件を絞る

2x=2x+β、−2y=−(2y+α) は、点の座標を変えると解決する条件でしょうか。

解答

CRからβ=0、α=0が必要です。この二条件が成立すればf=z²なので全平面で正則。どちらかが非零ならCRはどの点でも成立せず、複素微分できる点はありません。例題3のλ≠2とは違い、原点でさえ一次のずれが消えないためです。

6．二軸の差商が同じという誤診

原点以外で f(x+iy)=(x³+iy³)/(x²+y²)、f(0)=0 とします。「実軸と虚軸の差商がともに1だから f′(0)=1」という論証を診断してください。原点のCRも調べます。

ヒント1：方針を選ぶ

軸上の値から偏微分を求めた後、h=t(1+i)も代入します。

ヒント2：条件を絞る

対角線ではf(h)=t(1+i)/2です。

解答

実軸ではf(t)=t、虚軸ではf(it)=itなので二軸の差商は1。原点の偏微分はuₓ=vᵧ=1、uᵧ=vₓ=0でCRも成立します。しかし対角線の差商は1/2なので複素微分できません。|f(z)|≤(|x|³+|y|³)/|z|²≤2|z|より連続ではあります。二軸と点でのCRだけでは実全微分可能性を保証せず、それが不足しています。

7．一次近似の第二列を決める

ある点での実微分行列の第一列が (3,−1) です。複素微分可能にする第二列を選び、導関数と長さの倍率を求めてください。第二列が (−1,3) ならどうですか。

ヒント1：方針を選ぶ

第一列は複素数cを1へ掛けた出力です。

ヒント2：条件を絞る

第二列はcをiへ掛けた出力、すなわち第一列を反時計回り90°回したものです。

解答

c=3−iなのでci=1+3i、第二列は(1,3)。導関数は3−i、倍率は√10です。ただしこの行列が実全微分であることが前提です。第二列(−1,3)ではuᵧ=−1に対し−vₓ=1となってCRに反し、複素微分できません。

8．一次近似を実際の値で検算する

f(z)=z²、a=1+i、h=0.01(1−i) とします。f(a)+f′(a)h と f(a+h) を計算し、近似誤差の絶対値を求めてください。a=0で同じ近似を使うと何が変わりますか。

ヒント1：方針を選ぶ

展開の余りは正確にh²です。

ヒント2：条件を絞る

2(1+i)h=0.04、h²=−0.0002iです。

解答

f(a)=2i、f′(a)h=0.04なので一次近似は0.04+2i。正確な値は0.04+1.9998iで、誤差は0.0002=|h|²です。a=0では導関数が0、一次近似は0ですが、正確な値はh²。微分可能性は保たれても、一次の写像が0になるのでその一次近似へ角度保存や非零の拡大率を割り当てられません。

9．約分で定義域を忘れない

f(z)=(z²−1)/(z−1) の正則な範囲を答えてください。「約分して z+1 だから f′(1)=1」としてよいですか。必要なら点1での値を追加して延長してください。

ヒント1：方針を選ぶ

式を約分できるのは元の分母が0でない点です。

ヒント2：条件を絞る

延長した新しい関数をFと書き、F(1)を周囲と一致させます。

解答

元のfの定義域はℂ∖{1}で、そこでf=z+1、f′=1です。f(1)は未定義なのでf′(1)も語れません。F(z)=f(z)（z≠1）、F(1)=2と定めれば全平面でF=z+1になり、正則かつF′(1)=1です。式が同じ値を返す範囲と、関数の定義域を区別します。
