曲面積と投影面積

曲線では一つのパラメータ方向の伸びを測りました。曲面には二つの方向があり、小さな座標の長方形は空間内の平行四辺形へ変わります。その面積は、横から見れば短く見えるという投影の都合に左右されない量であるはずです。

復習は外積と面積、全微分と連鎖律、二重積分、変数変換定理です。

曲面のパラメータ表示と正則性

座標領域 D ⊂ ℝ² から空間への写像 r(u, v) = (x(u, v), y(u, v), z(u, v)) をパラメータ表示と呼びます。本章で積分する正則な曲面片では、D は閉かつ有界な Jordan 可測領域で、境界は有限個の区分 C¹ 曲線からなるとします。r は D を含む開近傍で C¹、D 上で rᵤ × rᵥ ≠ 0 とし、D の内部では単射とします。境界の継ぎ目での重複は有限本の曲線に限り、重複度も有限とします。

rᵤ、rᵥ は二つの接方向です。外積が非零という条件は、その二方向が一次独立で、局所的に面を張ることを保証します。r(u, v) = (u, 0, 0) は空間への C¹ 写像ですが、二方向目が潰れているので、この意味の曲面片ではありません。

複数の曲面片を合わせるときは、各片の内部の像が面積を持つ部分で重ならず、重複が有限本の境界曲線に限られる有限分割を使い、各片の積分を足します。面積0の曲線の重複は値を変えません。一般の滑らかな曲面上の区分 C¹ 曲線が面積0であるという事実は、正則座標上で曲線を細い帯で覆う標準的な性質として使います。

外積による曲面積・スカラー面積分

小さな座標変化の像は、全微分により rᵤΔu と rᵥΔv を辺とする平行四辺形に近づきます。その面積は ‖rᵤ × rᵥ‖ΔuΔv です。これをもとに、曲面積と連続なスカラー関数 f の面積分を次で定めます。曲がった面の幾何的な面積がこの式に一致する一般定理の完全証明は、本章の範囲外です。

Area(S):=∬D‖ru×rv‖dudv,∬SfdS:=∬Df(r)‖ru×rv‖dudv

例えば r(u, v) = (u, v, u)、0 ≤ u, v ≤ 1 では、rᵤ = (1, 0, 1)、rᵥ = (0, 1, 0)、rᵤ × rᵥ = (−1, 0, 1)。曲面積は √2 です。一方、xy 平面への投影は単位正方形で面積1。同じ「面積」という名前でも、測る面が違います。

一般のグラフ r(u, v) = (u, v, g(u, v)) なら rᵤ × rᵥ = (−gᵤ, −gᵥ, 1) なので、dS = √(1 + gᵤ² + gᵥ²)du dv。傾きが大きいほど、同じ投影面積に対する曲面積は大きくなります。

曲面の座標変換と面積の不変性

T(s, t) = (u(s, t), v(s, t)) が、座標領域 E を D へ一対一に移す C¹ 座標変換で、近傍でも逆写像を持ち det DT ≠ 0 とします。η = r ∘ T と置きます。二重積分の変数変換定理を使える Jordan 可測領域と連続な被積分関数を考えます。

二方向の連鎖律を、外積へ入れる

ηₛ = rᵤuₛ + rᵥvₛ、ηₜ = rᵤuₜ + rᵥvₜ。外積の双線形性、同じベクトル同士の外積0、順序交換の負号を使うと次になります。

ηs×ηt=(usvt−vsut)(ru×rv)=detDT·(ru×rv)

右辺の r の偏微分は T(s, t) で評価します。長さを取ると |det DT| が出ます。従って ∫∫E f(η)‖ηₛ × ηₜ‖ds dt に変数変換定理を使えば、∫∫D f(r)‖rᵤ × rᵥ‖du dv と一致します。座標の刻み方や向きを替えても、同じ面を同じ回数覆えばスカラー面積分は変わりません。

r(u, v) = (cos u, sin u, v)、0 ≤ u ≤ 4π、0 ≤ v ≤ 1 は外積の長さが常に1ですが、円柱の側面を二度覆います。積分は4πとなり、一度だけ覆うときの2πの二倍です。正則性だけで単射性を置き換えることはできません。

球面座標の極と継ぎ目

半径 R > 0 の球で r(θ, φ) = (R sin θ cos φ, R sin θ sin φ, R cos θ) とすると、‖rθ × rφ‖ = R² sin θ です。0 < θ < π、0 < φ < 2π の内部では正則かつ単射ですが、θ = 0、π では外積が0、φ = 0 と 2π は同じ継ぎ目です。閉じた座標矩形全体を、前の正則な一片の定義にそのまま入れることはできません。

球全体は、例えば立方体の六面の方向を球へ正規化する六つの正則片で扱えます。x が正で最も大きい部分には r(u, v) = R(1, u, v)/√(1 + u² + v²)、−1 ≤ u, v ≤ 1 を使い、他の五面も同様にします。各片は近傍で C¹、接方向は独立で、内部は一度だけ覆い、境界の重なりだけを共有します。

球面座標で計算するときは、まず ε ≤ θ ≤ π − ε、δ ≤ φ ≤ 2π − δ に制限し、正則片として積分します。欠けた極の帽子は、グラフ z = ±√(R² − x² − y²) を使うと、各面積が πR²sin²ε/cos ε 以下（0 < ε < π/2）。継ぎ目の細帯は、角度を −δ ≤ φ ≤ δ とずらした正則表示で極を除いて覆え、面積は 2πR²δ 以下です。これらは0へ縮むので、極と継ぎ目を除いた積分の極限が球全体の面積になります。積分は 2R²(2π − 2δ)cos ε で、極限は 4πR² です。

寄り道［数学の見方］：地図の不具合と、面そのものの不具合

球の北極でも、球面そのものに角や穴はありません。球面座標で全方位角が一つの点へ集まるため、選んだ地図の一方向が潰れただけです。北極付近で z を x、y の関数にすれば、外積の消えない別の地図を使えます。

一つの座標が使えないことを対象そのものの特異性と混同しないために、曲面を複数の正則片で扱います。ただし重なった片の面積をそのまま足すと二重計数になります。

演習：曲面の正則性と重複

1．平面の面積と投影

r(u, v) = (u, v, 2u − v)、0 ≤ u, v ≤ 1 の曲面積と xy 投影面積を求めてください。

ヒント1：二方向を微分する

rᵤ = (1, 0, 2)、rᵥ = (0, 1, −1)。

ヒント2：外積の長さ

rᵤ × rᵥ = (−2, 1, 1) です。

解答

外積の長さは √6 で一定、座標領域の面積は1なので曲面積は √6。xy 投影面積は1です。r は第一・第二成分から座標が決まり単射で、外積はどこでも非零です。

2．座標の単位を替える

前問と同じ面を η(s, t) = (2s, t, 4s − t)、0 ≤ s ≤ 1/2、0 ≤ t ≤ 1 と表します。面積が一致することを直接確かめてください。

ヒント1：外積を計算する

ηₛ = (2, 0, 4)、ηₜ = (0, 1, −1)。

ヒント2：座標領域の幅も替わる

外積の長さは前問の二倍ですが、s の幅は半分です。

解答

ηₛ × ηₜ = (−4, 2, 2)、長さ2√6。領域の面積1/2を掛けて √6 です。変換 T(s, t) = (2s, t) の行列式2が外積に掛かり、座標領域の縮小と対応します。

3．正則なら一度だけ覆うか

r(u, v) = (cos u, sin u, v)、0 ≤ u ≤ 4π、0 ≤ v ≤ 1 の外積の長さと面積積分を求め、一枚の円柱側面の面積と違う理由を説明してください。

ヒント1：接方向

rᵤ = (−sin u, cos u, 0)、rᵥ = (0, 0, 1)。

ヒント2：u と u + 2π

両者は同じ空間の点へ写ります。

解答

外積は (cos u, sin u, 0)、長さ1なので積分は4πです。一度だけ覆う円柱側面は2π。内部で r(u, v) = r(u + 2π, v) となるため単射性を欠き、同じ面を二重に数えています。外積が非零という局所条件だけでは防げません。
