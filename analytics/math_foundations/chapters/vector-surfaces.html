曲面積と投影面積

曲線では一つのパラメータ方向の伸びを測りました。曲面には二つの方向があり、小さな座標の長方形は空間内の平行四辺形へ変わります。その面積は、横から見れば短く見えるという投影の都合に左右されない量であるはずです。

復習は外積と面積、全微分と連鎖律、二重積分、変数変換定理です。

学習時間の目安は演習を含みます。本文と例題、条件を変える考察、演習の三回に分けて読み進めても構いません。

曲面のパラメータ表示と正則性

まず二つの実数 u,v を入力して、空間の点 r(u,v)=(u,v,u) を出す例を見ます。(0,0) は (0,0,0)、(1,0) は (1,0,1)、(0,1) は (0,1,0) へ移ります。u だけを増やす方向と、v だけを増やす方向が、面上の二つの接方向です。これから使う rᵤ,rᵥ は、それぞれ片方の変数だけで微分したベクトルを表します。

曲面片（patch）は、このような一組の座標で表す面の一部分です。正則という条件で二つの接方向が潰れないことを、内部の単射という条件で同じ面を重ねて数えないことを指定します。単射とは、異なる入力を同じ出力へ送らないことです。Jordan可測は二重積分で使った条件です。有界な集合 D を囲む長方形上で、D に入る点では1、その外では0となる指示関数を Riemann積分できることをいいます。格子を細かくしたとき、内側から数える面積と境界を含めて外側から数える面積の差が0へ近づくという、これまでの面積の条件です。

座標領域 D ⊂ ℝ² から空間への写像 r(u, v) = (x(u, v), y(u, v), z(u, v)) をパラメータ表示と呼びます。本章で積分する正則な曲面片では、D は閉かつ有界な Jordan 可測領域で、境界は有限個の区分 C¹ 曲線からなるとします。r は D を含む開近傍で C¹、D 上で rᵤ × rᵥ ≠ 0 とし、D の内部では単射とします。境界の継ぎ目での重複は有限本の曲線に限り、重複度も有限とします。

rᵤ、rᵥ は二つの接方向です。外積が非零という条件は、その二方向が一次独立で、局所的に面を張ることを保証します。r(u, v) = (u, 0, 0) は空間への C¹ 写像ですが、二方向目が潰れているので、この意味の曲面片ではありません。

複数の曲面片を合わせるときは、各片の内部の像が面積を持つ部分で重ならず、重複が有限本の境界曲線に限られる有限分割を使い、各片の積分を足します。面積0の曲線の重複は値を変えません。一般の滑らかな曲面上の区分 C¹ 曲線が面積0であるという事実は、正則座標上で曲線を細い帯で覆う標準的な性質として使います。

外積による曲面積・スカラー面積分

小さな座標変化の像は、全微分により rᵤΔu と rᵥΔv を辺とする平行四辺形に近づきます。その面積は ‖rᵤ × rᵥ‖ΔuΔv です。これをもとに、曲面積と連続なスカラー関数 f の面積分を次で定めます。曲がった面の幾何的な面積がこの式に一致する一般定理の完全証明は、本章の範囲外です。

Area(S):=∬D‖ru×rv‖dudv,∬SfdS:=∬Df(r)‖ru×rv‖dudv

例えば r(u, v) = (u, v, u)、0 ≤ u, v ≤ 1 では、rᵤ = (1, 0, 1)、rᵥ = (0, 1, 0)、rᵤ × rᵥ = (−1, 0, 1)。曲面積は √2 です。一方、xy 平面への投影は単位正方形で面積1。同じ「面積」という名前でも、測る面が違います。

一般のグラフ r(u, v) = (u, v, g(u, v)) なら rᵤ × rᵥ = (−gᵤ, −gᵥ, 1) なので、dS = √(1 + gᵤ² + gᵥ²)du dv。傾きが大きいほど、同じ投影面積に対する曲面積は大きくなります。

面積分の方針を、面と領域から決める

面積を求める前に、何を一度ずつ数えるかを決めます。z=g(x,y) と書けるなら (x,y,g(x,y)) が出発点です。円すいのように回転で作る面なら、半径と角度を座標にした方が境界を短く書けます。どちらでも、座標領域を決めずに外積だけ計算しては積分は完成しません。

  1. 求める量が面積か、密度 f を掛けた量かを確認し、f が空間のどの点で評価されるかを書きます。
  2. 座標領域 D と写像 r を同時に選び、外積の非零と内部の単射性を確かめます。
  3. 二接方向の外積の長さを作り、f(r) と掛けます。面積では法線の正負を選びません。
  4. 積分後、投影面積との大小、単位、重複の有無で検算します。

例えば f が単位実面積あたりの質量なら、f dS は質量です。投影面積 dxdy に f をそのまま掛けると、同じ密度でも斜面の材料を少なく数えます。以下の密度と面は、計算法を考えるための自作モデルです。

例題1：三角形の斜面に、位置で変わる密度を載せる

投影領域を D={(x,y):0≤x≤2, 0≤y≤2−x}、面を z=x+2y とし、密度を f(x,y,z)=1+x とします。長さと密度の単位は固定した模型の単位です。面積と総質量を求めます。境界は x=0、y=0、x+y=2 の三辺で、積分の上端が一定の長方形ではありません。

面の伸びと、密度の増加を分ける

r(x,y)=(x,y,x+2y) なら rₓ=(1,0,1)、rᵧ=(0,1,2)。外積は (−1,−2,1)、長さは √6 です。第一・第二成分を見れば座標は一意に戻り、外積は境界でも非零なので正則片の条件を満たします。

D の面積は ∫₀²(2−x)dx=2 だから、曲面積は A=2√6。密度は面上でも f(r)=1+x なので、総質量は M=√6∫₀²∫₀²⁻ˣ(1+x)dy dx=√6∫₀²(2+x−x²)dx です。

積分すると M=√6[2x+x²/2−x³/3]₀²=√6(4+2−8/3)=10√6/3。平均密度 M/A=5/3 は最小1と最大3の間にあります。x が大きいほど密度は高くなりますが、y 方向の幅2−xは狭くなるので、端の密度3を面全体へ掛けることはできません。

別の検算では、D 上の x の平均は (∫₀²x(2−x)dx)/2=(4/3)/2=2/3。伸び率 √6 が一定なので、面上でも平均密度は 1+2/3 です。傾きが位置により変わる面では、投影領域での単純な平均をそのまま使えません。

例題2：円すいの一部では、半径と角度を選ぶ

z=√(x²+y²) のうち、1≤√(x²+y²)≤2、y≥0 の部分を考えます。頂点を含まない半円すいの帯です。xy グラフとして微分することもできますが、境界が半径一定・角度一定なので、r(u,v)=(u cos v,u sin v,u)、1≤u≤2、0≤v≤π を選びます。

伸び率が一定でない面積要素

rᵤ=(cos v,sin v,1)、rᵥ=(−u sin v,u cos v,0)。外積は (−u cos v,−u sin v,u) で、長さは √2u。u≥1 なので外積は消えず、半径と半周の角度は内部で一意です。

A=∫₀^π∫₁²√2u du dv=3π√2/2。高さ z を重みにした積分は ∫∫S z dS=√2∫₀^π∫₁²u² du dv=7π√2/3 です。したがって面積で重み付けした平均高さは (7π√2/3)/(3π√2/2)=14/9 となり、1と2の間に入ります。

グラフで検算すると、gₓ=x/√(x²+y²)、gᵧ=y/√(x²+y²) だから gₓ²+gᵧ²=1。dS=√2dxdy に極座標の dxdy=u du dv を入れると同じ √2u になります。外積に u が入っているのに、さらに「極座標だから」と u を掛けると、同じ伸びを二度数えてしまいます。

頂点 u=0 まで広げると外積が消えます。その表示は正則片の定義を閉領域全体では満たしません。u≥ε へ切り、欠けた部分の面積が π√2ε²/2 で0へ近づくことを確かめるなら、この半円すいの面積を極限として扱えます。単に「一点だから」と公式の仮定を省くのとは区別します。

例題3：面積から傾きを逆算し、設計の自由度を調べる

単位正方形0≤x,y≤1の上に z=ax+by の板を作り、実面積を3にしたいとします。dS=√(1+a²+b²)dxdy だから、条件は a²+b²=8 です。面積だけでは a と b は一意に決まりません。これは計算不足ではなく、一つの条件で二つの未知数を決めようとしたためです。

さらに「対角線 x=y の上では高さ0」を指定すると、z=(a+b)x=0 がすべての0≤x≤1で必要なので a+b=0。連立して2a²=8、(a,b)=(2,−2) または (−2,2) です。「xを増やすと上る」も加えると a>0 から (2,−2) に決まります。どちらの板も投影面積は1で、実面積は3です。

曲面の座標変換と面積の不変性

T(s, t) = (u(s, t), v(s, t)) が、座標領域 E を D へ一対一に移す C¹ 座標変換で、近傍でも逆写像を持ち det DT ≠ 0 とします。η = r ∘ T と置きます。二重積分の変数変換定理を使える Jordan 可測領域と連続な被積分関数を考えます。

二方向の連鎖律を、外積へ入れる

ηₛ = rᵤuₛ + rᵥvₛ、ηₜ = rᵤuₜ + rᵥvₜ。外積の双線形性、同じベクトル同士の外積0、順序交換の負号を使うと次になります。

ηs×ηt=(usvt−vsut)(ru×rv)=detDT·(ru×rv)

右辺の r の偏微分は T(s, t) で評価します。長さを取ると |det DT| が出ます。従って ∫∫E f(η)‖ηₛ × ηₜ‖ds dt に変数変換定理を使えば、∫∫D f(r)‖rᵤ × rᵥ‖du dv と一致します。座標の刻み方や向きを替えても、同じ面を同じ回数覆えばスカラー面積分は変わりません。

面積を正しく数えるための三つの区別
条件・量保証すること保証しないこと
rᵤ × rᵥ ≠ 0二方向が局所的に面を張ります。離れた座標点の重複は防ぎません。
内部の単射性同じ面の内部を一度数えます。複数片を無条件に重ねて足せるわけではありません。
曲面積空間内の長さで面積を測ります。固定平面への投影面積とは限りません。
スカラー面積分座標の向きの反転でも不変です。法線の向きは次章で別に選びます。

r(u, v) = (cos u, sin u, v)、0 ≤ u ≤ 4π、0 ≤ v ≤ 1 は外積の長さが常に1ですが、円柱の側面を二度覆います。積分は4πとなり、一度だけ覆うときの2πの二倍です。正則性だけで単射性を置き換えることはできません。

球面座標の極と継ぎ目

球面座標では、θ を正の z 軸から測る角度、φ を xy 平面での方位角として使います。θ を0からπへ動かすと北極から南極へ進み、φ を動かすと軸のまわりを回ります。この二つの角度を座標に選ぶと、極と継ぎ目で何が起こるでしょうか。

半径 R > 0 の球で r(θ, φ) = (R sin θ cos φ, R sin θ sin φ, R cos θ) とすると、‖rθ × rφ‖ = R² sin θ です。0 < θ < π、0 < φ < 2π の内部では正則かつ単射ですが、θ = 0、π では外積が0、φ = 0 と 2π は同じ継ぎ目です。閉じた座標矩形全体を、正則な一片の定義にそのまま入れることはできません。

球全体は、例えば立方体の六面の方向を球へ正規化する六つの正則片で扱えます。x が正で、|x| が三成分の絶対値の中で最大となる部分には r(u, v) = R(1, u, v)/√(1 + u² + v²)、−1 ≤ u, v ≤ 1 を使い、他の五面も同様にします。各片は近傍で C¹、接方向は独立で、内部は一度だけ覆い、境界の重なりだけを共有します。

球面座標で計算するときは、まず ε ≤ θ ≤ π − ε、δ ≤ φ ≤ 2π − δ に制限し、正則片として積分します。欠けた極の帽子は、グラフ z = ±√(R² − x² − y²) を使うと、各面積が πR²sin²ε/cos ε 以下（0 < ε < π/2）。継ぎ目の細帯は、角度を −δ ≤ φ ≤ δ とずらした正則表示で極を除いて覆え、面積は 2πR²δ 以下です。これらは0へ縮むので、極と継ぎ目を除いた積分の極限が球全体の面積になります。積分は 2R²(2π − 2δ)cos ε で、極限は 4πR² です。

寄り道［数学の見方］：地図の不具合と、面そのものの不具合

球の北極でも、球面そのものに角や穴はありません。球面座標で全方位角が一つの点へ集まるため、選んだ地図の一方向が潰れただけです。北極付近で z を x、y の関数にすれば、外積の消えない別の地図を使えます。

一つの座標が使えないことを対象そのものの特異性と混同しないために、曲面を複数の正則片で扱います。ただし重なった片の面積をそのまま足すと二重計数になります。

演習：曲面の正則性と重複

1．平面の面積と投影

r(u, v) = (u, v, 2u − v)、0 ≤ u, v ≤ 1 の曲面積と xy 投影面積を求めてください。

ヒント1：二方向を微分する

rᵤ = (1, 0, 2)、rᵥ = (0, 1, −1)。

ヒント2：外積の長さ

rᵤ × rᵥ = (−2, 1, 1) です。

解答

外積の長さは √6 で一定、座標領域の面積は1なので曲面積は √6。xy 投影面積は1です。r は第一・第二成分から座標が決まり単射で、外積はどこでも非零です。

2．座標の単位を替える

前問と同じ面を η(s, t) = (2s, t, 4s − t)、0 ≤ s ≤ 1/2、0 ≤ t ≤ 1 と表します。面積が一致することを直接確かめてください。

ヒント1：外積を計算する

ηₛ = (2, 0, 4)、ηₜ = (0, 1, −1)。

ヒント2：座標領域の幅も替わる

外積の長さは前問の二倍ですが、s の幅は半分です。

解答

ηₛ × ηₜ = (−4, 2, 2)、長さ2√6。領域の面積1/2を掛けて √6 です。変換 T(s, t) = (2s, t) の行列式2が外積に掛かり、座標領域の縮小と対応します。

3．正則なら一度だけ覆うか

r(u, v) = (cos u, sin u, v)、0 ≤ u ≤ 4π、0 ≤ v ≤ 1 の外積の長さと面積積分を求め、一枚の円柱側面の面積と違う理由を説明してください。

ヒント1：接方向

rᵤ = (−sin u, cos u, 0)、rᵥ = (0, 0, 1)。

ヒント2：u と u + 2π

両者は同じ空間の点へ写ります。

解答

外積は (cos u, sin u, 0)、長さ1なので積分は4πです。一度だけ覆う円柱側面は2π。内部で r(u, v) = r(u + 2π, v) となるため単射性を欠き、同じ面を二重に数えています。外積が非零という局所条件だけでは防げません。

4．三角形領域と面上の重み

z=x+y、x≥0、y≥0、x+y≤1 の面積と ∫∫S(x+y)dS を求め、平均値が0と1の間か確かめてください。

ヒント1

グラフの面積要素は √3dxdy。yの上端は1−xです。

ヒント2

∫₀¹∫₀¹⁻ˣ(x+y)dy dx=1/3 です。

解答

面積は √3/2。内側の積分は x(1−x)+(1−x)²/2=(1−x²)/2 なので、重み付き積分は √3[(x−x³/3)/2]₀¹=√3/3。平均は2/3で、重みの範囲内です。投影面積1/2と実面積を区別します。

5．面積と端の高さから設計する

z=ax+by の単位正方形の板で、面積が √6、(1,0) の高さが2です。可能な (a,b) をすべて求めてください。

ヒント1

高さから a=2 が決まります。

ヒント2

面積から1+a²+b²=6です。

解答

a=2、b²=1なので (2,1)、(2,−1)。両方とも外積の長さ √6 ですが、y方向の上り下りが逆です。面積と一点の高さだけでは、この符号を決められません。

6．潰れと二重計数を診断する

r(u,v)=(u²,v,0)、−1≤u≤1、0≤v≤1 の外積積分は2です。像は単位正方形なのに面積2としてよいでしょうか。二つの問題点と、一度だけ数える別表示を挙げてください。

ヒント1

rᵤ×rᵥ=(0,0,2u)。u=0を調べます。

ヒント2

uと−uは同じ点へ移ります。

解答

u=0で外積0となり正則性を欠き、u≠0でも内部の二点が同じ点へ移るため単射性も欠きます。∫₋₁¹2|u|du=2 は重複して数えた値です。η(s,t)=(s,t,0)、0≤s,t≤1 なら外積 e_z、内部単射で面積1。元の式の絶対値を外すと0になりますが、それは面積の修正にはなりません。

7．総質量から密度を逆算する

z=x、0≤x,y≤1 の板で、密度を f=c(1+x)、c≥0 とします。総質量が3√2ならcと平均密度を求めてください。

ヒント1

dS=√2dxdy です。

ヒント2

∫₀¹(1+x)dx=3/2。

解答

M=(3/2)c√2=3√2 より c=2。面積 √2 で割った平均密度は3です。密度の最小2、最大4の間に入り、中央の値とも一致します。密度の単位は質量/実面積です。

8．二つの表示で計算量を比べる

1≤√(x²+y²)≤3、0≤arg(x+iy)≤π/2 にある z=√(x²+y²) の面積を求めてください。グラフから極座標へ移る方法と直接のパラメータ表示の面積要素を比較してください。

ヒント1

グラフでは dS=√2dxdy。

ヒント2

直接表示では r(u,v)=(u cos v,u sin v,u)、1≤u≤3、0≤v≤π/2。

解答

どちらも √2u du dv になり、A=√2(π/2)[u²/2]₁³=2π√2。グラフの平方根微分を計算する方法より、円弧の境界を座標領域へ直接移す方法が短くなります。直接表示の外積へ追加のuを掛けないことが一致の要点です。

9．向きを替える座標変換

r(u,v)=(u,v,u+v)、0≤u,v≤1 に対し η(s,t)=r(t,s) とします。外積と面積を求め、行列式の負号が消える場所を説明してください。

ヒント1

ηₛ=(0,1,1)、ηₜ=(1,0,1)。

ヒント2

ηₛ×ηₜ=(1,1,−1)。

解答

元の外積 (−1,−1,1) の反対ですが、長さはどちらも √3。座標変換T(s,t)=(t,s)の行列式は−1、その絶対値が長さに現れるので面積は √3 のままです。法線向きを指定する流束の計算とは、ここが異なります。

10．極を除く計算の誤差を評価する

半径Rの球面座標で ε≤θ≤π−ε、0≤φ≤2π と制限した面積を計算し、球全体との差を求めてください。0<ε<π/2 とします。

ヒント1

面積要素はR²sinθ dθdφ。継ぎ目の重複は境界曲線です。

ヒント2

∫ε^(π−ε)sinθ dθ=2cosε。

解答

制限部分は4πR²cosε、全体4πR²との差は4πR²(1−cosε)。1−cosε=2sin²(ε/2)≤ε²/2 だから差は2πR²ε²以下で0へ近づきます。極を含む表示は正則ではありませんが、極を除いた正則帯と欠けた面積の評価で極限を正当化できます。
