事象の独立

二台の装置が別々の場所にあっても、同じ電源に頼っていれば、一台の故障を知ることがもう一台の故障の見込みを変えるかもしれません。逆に、一個のさいころから作った二つの事象が独立になる場合もあります。独立は、物理的に離れているか、言葉の上で違う出来事かでは決まりません。

「B が起きたと分かっても A の確率が変わらない」を、条件付き確率で書けば P(A | B) = P(A) です。ただし P(B) = 0 では左辺を定義できません。そこで、分母を使わず、両者を対称に扱える形を定義に選びます。

学習の目安は演習込み120–180分です。二事象の等式と重なりの設計、三事象と条件付け、装置モデルと演習の三回に分けられます。演習1–3は基本、4–7は独立性の逆算と誤診断、8–10は証明・条件の選択・設計です。

二事象の独立と条件付き確率

二事象の独立の定義

二つの事象 A、B が独立であるとは、次の等式が成り立つことです。

P(A∩B)=P(A)P(B)

確率が変わらないという読み方との同値

P(B) > 0 のときは、上の等式を P(B) で割れば P(A | B) = P(A) です。逆にこの条件付き確率の等式に P(B) を掛ければ積の定義に戻ります。従って P(B) > 0 の下では二つの言い方は同値です。P(A) > 0 なら、同様に P(B | A) = P(B) とも同値になります。

例えば二回のコイン投げで、表表、表裏、裏表、裏裏の四結果を等確率とするモデルを置きます。A を「一回目が表」、B を「二回目が表」とすると P(A) = P(B) = 1/2、P(A ∩ B) = 1/4 なので独立です。最初に四結果を等確率と置いたことが、独立性を導くモデルの情報になっています。

確率 0 の事象 A も、積の定義では任意の B と独立です。A ∩ B ⊆ A より P(A ∩ B) = 0 = P(A)P(B) だからです。P(A) = 1 の場合も、P(Aᶜ ∩ B) ≤ P(Aᶜ) = 0 なので、P(A ∩ B) = P(B) − P(Aᶜ ∩ B) = P(B) = P(A)P(B)。従って任意の B と独立です。これは「A を条件にした割合を必ず計算できる」という意味ではありません。定義に分母を使わない利点と、条件付けの制限を分けて読みます。

排反と独立の違い

公平なさいころで A を「偶数」、D を「奇数」とします。二つは排反ですが、P(A ∩ D) = 0 に対し P(A)P(D) = 1/4 で、独立ではありません。奇数が出たと分かれば偶数の可能性が消えるので、情報としては強く結び付いています。

一般に、P(A) > 0、P(B) > 0 の二事象が排反なら、同時確率は 0、積は正なので独立ではあり得ません。排反と独立が両立するのは、少なくとも一方の確率が 0 の場合です。排反事象では和を足せる、独立事象では同時確率を掛けられる、という二つの条件を混同しないようにします。

一方、同じさいころで A を「偶数」、B を「3 の倍数」とすると、P(A) = 1/2、P(B) = 1/3、A ∩ B = {6} で P(A ∩ B) = 1/6。従って独立です。一つの試行から作った事象でも、等式を満たすことはあります。独立性は、選んだ事象と確率モデルに対する性質です。

排反では共通部分が空かを、独立では共通部分の重みが積と等しいかを確かめます。「別々に見える」という印象で判定するものではありません。

独立と補事象

補集合との独立

A と B が独立なら、A と Bᶜ、Aᶜ と B、Aᶜ と Bᶜ もそれぞれ独立です。

A を二つに分けて引き算する

A = (A ∩ B) ∪ (A ∩ Bᶜ) は排反な分割です。従って P(A ∩ Bᶜ) = P(A) − P(A ∩ B) = P(A) − P(A)P(B) = P(A)(1 − P(B)) = P(A)P(Bᶜ)。これが A と Bᶜ の独立です。A と B を入れ替えれば Aᶜ と B の独立も得られます。最後に、すでに独立と分かった A と Bᶜ に同じ結果を使い、A の側を補集合にすれば Aᶜ と Bᶜ も独立です。

例えば二台の装置がある期間を故障せずに動く事象が独立なら、その期間に両方が故障する確率も、各故障確率の積です。ただし、「各装置の故障しにくさ」を知っただけでは、独立という関係までは決まりません。関係を調べずに積を使わないことが大切です。

例題：個別の確率を保って、独立な重なりを設計する

二つの通知が出る事象をA、Bとし、P(A)=3/5、P(B)=2/5とする自作モデルを作ります。この二つの数だけでは、両方出る確率は決まりません。独立にしたいなら、重なりを積(3/5)(2/5)=6/25へ設定する必要があります。本当に他の部分の重みも整合するか、四部分まで作って確かめます。

一つの重なりから、四部分を復元する

両方は6/25、Aだけは3/5−6/25=9/25、Bだけは2/5−6/25=4/25、どちらもないのは1−3/5−2/5+6/25=6/25です。全て非負で、合計は25/25=1。従ってこの四つを結果とする有限モデルを実際に作れます。条件付き確率でもP(A|B)=(6/25)/(2/5)=3/5で、元と変わりません。

独立な行には、もう一つの作り方があります。結果を(i,j)、1≤i,j≤5の25個の組とし、各組を1/25とします。Aをi≤3、Bをj≤2とすれば、Aは3×5=15個、Bは5×2=10個、両方は3×2=6個です。Aの条件が一方の座標だけ、Bの条件がもう一方の座標だけを選ぶので、積の個数が現れます。25個を等確率としたモデルの情報から独立性を導いています。

一般の0≤a,b≤1でも、独立な四部分ab、a(1−b)、(1−a)b、(1−a)(1−b)は全て非負で、和は[a+(1−a)][b+(1−b)]=1です。従ってどんな二つの周辺確率にも独立なモデルを少なくとも一つ作れます。一方、そのモデルを採用する根拠は、個別確率とは別に必要です。

周辺確率と実現可能な同時確率

事象Aが起きる確率P(A)、事象Bが起きる確率P(B)を、それぞれの周辺確率と呼びます。ここでP(A)には、Bも同時に起きる場合を含めます。これに対し、両方が同時に起きるP(A∩B)が同時確率です。周辺確率を同じに保っても、同時確率を変えられるかを調べます。以下のmaxは二数の大きい方、minは小さい方を選ぶ記号です。

a = P(A)、b = P(B)、c = P(A ∩ B) とします。全体は「両方」「A だけ」「B だけ」「どちらもない」の四部分に分かれ、その重みは順に c、a − c、b − c、1 − a − b + c です。すべて非負である条件から、重なりの動ける範囲は max(0, a + b − 1) ≤ c ≤ min(a, b) になります。

a、b を固定し、c だけ動かしてみます。独立になるのは c = ab の位置です。例えば a = b = 1/2 なら、c = 0 は排反、c = 1/4 は独立、c = 1/2 は二つが同じ側に重なるモデルになります。個別の確率だけでは、この三つを区別できません。

独立の定義は正確な等式です。画面上で丸めた数が同じに見えることと、数学的に等しいことは区別します。また b = 0 では P(A | B) の比は定義しませんが、積の定義では独立かどうかを判定できます。

対独立と相互独立

A₁, …, Aₙ が相互に独立とは、どの二個以上の部分集団を選んでも、そのすべてが同時に起きる確率が個別の確率の積になることです。三事象なら、三通りの二事象の等式と、P(A ∩ B ∩ C) = P(A)P(B)P(C) の両方が必要です。二つずつの条件だけを満たす場合は対独立と呼びます。

反例を四結果で作れます。Ω = {00, 01, 10, 11} を等確率とし、A を「一文字目が 1」、B を「二文字目が 1」、C を「二文字が異なる」とします。A = {10, 11}、B = {01, 11}、C = {01, 10} なので、それぞれの確率は 1/2 です。

A ∩ B = {11}、A ∩ C = {10}、B ∩ C = {01} はいずれも確率 1/4。従って、どの二つも独立です。しかし A ∩ B ∩ C = ∅ で確率 0 なのに、三つの確率の積は 1/8 です。二文字とも 1 と分かれば「異なる」は不可能になります。二つずつでは見えない関係が三つの間に残りました。

相互独立な事象は、一部を補集合に替えてもよい

相互独立な A₁, …, Aₙ の任意の一部を、それぞれの補集合に替えた事象族も相互独立です。成功する位置だけでなく、失敗する位置も指定した並びの確率を積で書ける理由です。

一つ替えて、同じ議論を繰り返す

まず Aᵢ だけを補集合に替えます。Aᵢ を含まない部分集団の積の等式は変わりません。Aᵢ を含む部分集団では、残りの任意の共通部分を C とすると、相互独立の定義から P(Aᵢ ∩ C) = P(Aᵢ)P(C)、かつ P(C) は残りの確率の積です。従って P(Aᵢᶜ ∩ C) = P(C) − P(Aᵢ ∩ C) = (1 − P(Aᵢ))P(C)。残りがない場合は C = Ω、空の積は 1 と読みます。どの部分集団でも新しい積の等式が成立するので、替えた族も相互独立です。この操作を一つずつ繰り返せば、任意の一部を補集合に替えられます。

n 個について「全部の同時確率が積になる」という一個の等式だけを調べるのも、相互独立の定義には足りません。途中の部分集団すべてが対象です。後で多数の試行の成功回数や平均を扱うときに使う「独立」は、この相互独立の意味で使います。

例題：三つ全部の等式だけを調べても足りない

前節の四結果モデルは「二つずつは独立でも三つ全体では崩れる」という反例でした。逆に、三つ全部の積だけが合っていれば、二つずつも合うでしょうか。答えも否です。この見落としを、八つの結果の自作モデルで診断します。

Ω={1,2,3,4,5,6,7,8}を等確率とし、A=B={1,2,3,4}、C={1,5,6,7}とします。三事象の確率は全て1/2。三つ全部の共通部分は{1}なので、P(A∩B∩C)=1/8=(1/2)³です。しかしAとBは全く同じ集合です。

必要な等式を一つずつ検査する

A∩B={1,2,3,4}なのでP(A∩B)=1/2であり、P(A)P(B)=1/4とは違います。さらにA∩C=B∩C={1}で、その確率1/8も積1/4とは違います。従って三つ全部の等式は成り立っても、三組の二事象条件は全て失敗しています。全体の等式一つに、途中の条件が隠れているとは限りません。

三事象の相互独立を判定するときは、(A,B)、(A,C)、(B,C)と(A,B,C)という四つの等式を検査します。二つずつだけを検査する方法と、三つ全部だけを検査する方法は、違う方向に条件を落としています。前節の反例とこの反例を並べると、両方の検査が必要な理由が見えます。

相互独立が確かめられたら、一部を補集合に替える前節の定理が使えます。例えばAだけ起き、B,Cは起きない確率はP(A)(1−P(B))(1−P(C))。この積は「AとBが独立だから」という一つの条件では出ません。三つが同時にどう結び付くかまで調べたことが必要です。

条件付けによる独立性の変化

改めて、二回のコイン投げの四結果を等確率とし、A を「一回目が表」、B を「二回目が表」とします。元のモデルで A と B は独立です。ここで D =「少なくとも一回は表だった」という情報だけを受け取ると、残る表表、表裏、裏表はそれぞれ条件付き確率 1/3 になります。

この新しい確率の下では P(A | D) = P(B | D) = 2/3 に対し、P(A ∩ B | D) = 1/3。1/3 ≠ (2/3)² なので独立ではありません。少なくとも一回は表と分かった上で、一回目が裏だと追加で知れば、二回目は必ず表です。選ばれた集まりの中で、二つの結果が結び付いたのです。

逆に、ある条件の下で独立だからといって、条件を外しても独立だとは限りません。どの集まりで、何を条件にした確率を計算しているかを明記します。条件付き確率は原因を直接操作した結果ではなく、情報を使って重みを付け直したものでした。

例題：二台の装置の設計と、共通の停止原因

同じ時点まで装置Aが動く確率を9/10、Bを4/5とする理想化モデルです。「両方が必要」な仕組みと、「少なくとも一方が動けばよい」仕組みを比較します。これらは本章の自作モデルであり、実際の製品の性能や故障機構を述べる数値ではありません。

生存が独立なモデルで計算する

両方必要なら、動作事象はA∩Bで確率(9/10)(4/5)=18/25=0.72。少なくとも一方ならA∪Bで、補集合はAᶜ∩Bᶜです。補事象も独立なので停止確率は(1/10)(1/5)=1/50。動作確率は49/50=0.98です。加法公式で9/10+4/5−18/25=49/50としても一致します。

独立を置かなかった場合の限界を調べる

周辺確率だけなら、重なりcの範囲は7/10≤c≤4/5。両方必要な動作確率はこの範囲を動き、少なくとも一方の動作確率は17/10−cなので9/10から1まで動きます。独立の0.72、0.98は、それぞれ範囲内の一つの値です。装置を二台にしただけで0.98という結論までは出ません。

次に共通の電源を加えます。電源が動く事象をNとしP(N)=19/20、電源が止まれば両台も止まるとします。Nの下ではA、Bの動作が独立で、条件付きの動作確率は先ほどと同じ9/10、4/5です。つまり、電源が動く集まりの内部でのみ、積の規則を置くモデルです。

条件を外すと、独立は変わる

全確率からP(A)=(19/20)(9/10)=171/200=0.855、P(B)=(19/20)(4/5)=19/25=0.76です。同時に動く確率は(19/20)(9/10)(4/5)=171/250=0.684。ところが周辺確率の積は0.855×0.76=0.6498。差は0.0342で、同じではありません。電源が正常という条件の下の独立が、条件を外した確率で保たれるとは限らない具体例です。

少なくとも一方が動く確率は、Nの下で49/50、電源停止の下で0なので、(19/20)(49/50)=931/1000=0.931です。停止は1−0.931=0.069。周辺の停止確率を独立と思って掛けた0.145×0.24=0.0348より大きくなります。共通停止が二つの停止に同時に入り、単なる掛け算では表せなくなったのです。

条件をどこに置いたかを明記すれば、二つのモデルは矛盾しません。「正常な電源の下で独立」と「全体で独立」は別の等式です。条件付きの割合を集めた後に全体の積を使うときは、もう一度等式を検査します。

寄り道［応用］：部品の信頼性を掛けてよい条件

NIST の直列システムのモデルは、どれか一つの部品が故障すると全体が停止し、部品の故障・生存が独立である場合に、各部品の信頼性を掛けて全体の信頼性を計算します。ここで信頼性は、指定した時点まで動く確率です。

本章の仮想例で、同じ時点まで部品 A が動く確率を 0.99、B を 0.98 とします。両方必要で、生存が独立と仮定すれば、全体が動く確率は 0.99×0.98 = 0.9702、停止する確率は 1 − 0.9702 = 0.0298 です。後者は二つの故障率を単純に足した 0.03 から、両方故障する確率 0.01×0.02 = 0.0002 を引いたものにも一致します。

共通の電源や環境があれば、生存の独立性は自動的には言えません。二つの周辺の確率だけを同じに保ちながら、同時確率を変えられることは実験でも見ました。掛け算は便利ですが、その便利さを支えているのは独立というモデルの仮定です。

出典：NIST/SEMATECH：8.1.8.2 Series model。部品の数値と計算は本章の仮想設定です。

演習：独立性と条件付け

1．一個のさいころから作る独立

公平なさいころで A を「偶数」、B を「4 以下」とします。A と B が独立かを判定し、Aᶜ と Bᶜ の独立も、確率を直接計算して確かめてください。

ヒント1：同時に満たす出目を数える

A ∩ B = {2, 4} です。

ヒント2：両方の補集合の重なりも書く

Aᶜ = {1, 3, 5}、Bᶜ = {5, 6} です。

解答

P(A) = 1/2、P(B) = 4/6 = 2/3、P(A ∩ B) = 2/6 = 1/3 = (1/2)(2/3) なので独立です。補集合は P(Aᶜ) = 1/2、P(Bᶜ) = 1/3、Aᶜ ∩ Bᶜ = {5} で確率 1/6 = (1/2)(1/3)。従って補集合どうしも独立です。一つの試行かどうかではなく、選んだ事象の重なりを計算しました。

2．重なりを動かして独立にする

P(A) = 0.6、P(B) = 0.5、P(A ∩ B) = 0.2 とします。四部分の確率と P(A | B) を求め、独立か判定してください。個別の確率を保ったまま独立にするには、重なりをいくつにすればよいですか。

ヒント1：両方、A だけ、B だけ、どちらもない

順に c、a − c、b − c、1 − a − b + c です。

ヒント2：独立のときの重なりは積

0.6×0.5 と今の 0.2 を比べます。

解答

四部分は 0.2、0.4、0.3、0.1 で、すべて非負、総和 1 です。P(A | B) = 0.2/0.5 = 0.4 で元の 0.6 と違い、0.2 ≠ 0.6×0.5 なので独立ではありません。独立にするには c = 0.3 とすればよく、四部分は 0.3、0.3、0.2、0.2 になります。許される重なりの範囲は 0.1 ≤ c ≤ 0.5 なので、新しい設定も実現できます。

3．「同じだった」と知った後の独立

二回のコイン投げの四結果を等確率とします。A を「一回目が表」、B を「二回目が表」、E を「二回の結果が同じ」として、P(A | E)、P(B | E)、P(A ∩ B | E) を求め、E を条件にした新しい確率の下で独立か判定してください。

ヒント1：条件に合う結果は二つ

E = {表表, 裏裏} です。

ヒント2：新しい周辺確率の積と比べる

独立であるためには P(A ∩ B | E) = P(A | E)P(B | E) が必要です。

解答

P(E) = 1/2。E の中で A、B、A ∩ B を満たす結果はいずれも表表だけなので、三つの条件付き確率はすべて (1/4)/(1/2) = 1/2 です。同時確率 1/2 は周辺確率の積 1/4 と違うので、E を条件にした確率では独立ではありません。元のモデルでは独立でしたが、同じ結果だけに絞る情報が二つを結び付けました。

4．自分自身と独立な事象

事象AがA自身と独立であるための必要十分条件を求めてください。P(A)=0のとき、空集合と限らないことにも注意してください。

ヒント1：方針を選ぶ

A∩A=Aなので、独立の等式はP(A)=P(A)²です。

ヒント2：計算をつなぐ

0≤P(A)≤1の数pについてp(1−p)=0を解きます。

解答

必要十分条件はP(A)=0またはP(A)=1です。p=p²からp(1−p)=0で必要性が出ます。逆にp=0,1ならp=p²なので十分です。一般のモデルでは確率0の非空事象も許されるため、条件をA=∅またはA=Ωに言い換えることまではできません。

5．個数表の空欄を独立になるように埋める

等確率な結果の個数を四部分で記録します。A∩Bが12個、A∩Bᶜが18個、Aᶜ∩Bが8個、Aᶜ∩Bᶜがx個です。xを非負整数から選び、AとBが独立となるようにしてください。

ヒント1：方針を選ぶ

全体の個数38+xを分母にします。Aの個数は30、Bは20です。

ヒント2：計算をつなぐ

12/(38+x)=[30/(38+x)][20/(38+x)]を解きます。

解答

12(38+x)=600よりx=12です。全体50でP(A)=30/50=3/5、P(B)=20/50=2/5、P(A∩B)=12/50=6/25となり、積と一致します。xは分子だけでなく全体の分母も変えるので、先に分母を固定してはいけません。

6．同時確率が不明な二台を比較する

装置Aが動く確率0.9、Bが動く確率0.8だけを知っています。両方必要な仕組みと少なくとも一方必要な仕組みの動作確率の範囲を求め、それぞれ最悪側の端点を四部分の重みで作ってください。

ヒント1：方針を選ぶ

同時確率cの範囲0.7≤c≤0.8から始めます。

ヒント2：計算をつなぐ

四部分はc、0.9−c、0.8−c、c−0.7です。

解答

両方必要は[0.7,0.8]で最悪はc=0.7、四部分(0.7,0.2,0.1,0)。少なくとも一方必要は[0.9,1]で最悪はc=0.8、四部分(0.8,0.1,0,0.1)です。両者の最悪を作る同時確率は違います。両方とも非負で和1なので、単なる上限下限ではなく実現する端点です。

7．二つずつの独立で三つの補集合を掛けてよいか

Ω={00,01,10,11}の等確率モデルでAを一文字目が1、Bを二文字目が1、Cを二文字が異なる事象とします。P(A∪B∪C)を求め、1−(1/2)³=7/8という解答を診断してください。

ヒント1：方針を選ぶ

三つとも起きない結果を書き出します。

ヒント2：計算をつなぐ

三つとも起きないのは00だけです。対独立と相互独立を区別します。

解答

合併は{01,10,11}なので3/4。補集合の同時確率はP({00})=1/4で、三つの補集合の確率の積1/8とは違います。このモデルは二つずつ独立でも相互独立ではないため、三つをまとめた積の使用が誤りです。個別の補事象が各1/2であることだけでは不足します。

8．共通原因の効果を文字で証明する

P(N)=s、0<s<1とし、Nが起きないとA,Bは共に起きないモデルです。Nの下ではA,Bが独立で、P(A|N)=u、P(B|N)=vとします。P(A∩B)−P(A)P(B)を求め、どんなu,vで正になるか示してください。

ヒント1：方針を選ぶ

全確率でP(A)=su、P(B)=sv、同時確率=suvです。

ヒント2：計算をつなぐ

suv−s²uvを因数分解します。

解答

差はs(1−s)uvです。0<s<1なので、u>0かつv>0なら正となり全体では独立でありません。u=0またはv=0なら差0で、片方が確率0なので独立です。端のs=1なら条件を外しても同じモデル、s=0ならNによる条件付き確率を定義できないので、問題の仮定からは外します。

9．独立性が残る条件付けを証明する

A,B,Cが相互独立でP(A)>0とします。Aを条件にした確率の下で、BとCが独立であることを証明してください。対独立だけで同じ証明が通るかも説明してください。

ヒント1：方針を選ぶ

条件付きの二つの周辺確率と同時確率を、それぞれ定義で計算します。

ヒント2：計算をつなぐ

相互独立ならP(A∩B∩C)=P(A)P(B)P(C)です。

解答

P(B|A)=P(B)、P(C|A)=P(C)。同時確率はP(B∩C|A)=P(A∩B∩C)/P(A)=P(B)P(C)なので、条件付きの周辺確率の積と一致し独立です。対独立では二つの周辺の等式は出ますが三つの同時確率は決まらず、最後の等式を導けません。演習7の四結果モデルでAを条件にするとBとCは同時には起きず、反例にもなります。

10．必要な台数を設計する

各装置が動く確率を4/5とし、全装置の動作事象が相互独立なモデルを選びます。少なくとも一台が動く確率を0.999以上にする最小台数nを求め、独立性について必要な仮定を述べてください。

ヒント1：方針を選ぶ

全て停止する確率は(1/5)ⁿです。

ヒント2：計算をつなぐ

n=4,5を厳密な小数で比較します。台数を増やすと停止確率は減ります。

解答

n=4では停止確率1/625=0.0016、動作0.9984で不足。n=5では停止1/3125=0.00032、動作0.99968で達成します。(1/5)ⁿはnとともに減るので最小は5です。相互独立を仮定すれば全台の停止確率を積で計算でき、二つずつの独立だけでは一般にはこの保証を導けません。共通原因がある別モデルなら再計算が必要です。
