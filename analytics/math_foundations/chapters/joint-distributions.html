同時分布と周辺分布

X と Y がそれぞれ 0、1 を半々で取るとします。いつも Y = X なら和は 0 または 2。いつも Y = 1 − X なら和は必ず 1。X と Y それぞれの分布は同じなのに、和の分布は違います。

必要なのは、二つの値が同時に起きる確率です。この章では有限の同時確率の表を使い、条件付きの平均、独立性、和の分散を一つの表から導きます。

同時確率分布と周辺化

X の取り得る値を xᵢ、Y の取り得る値を yⱼ とし、pᵢⱼ = P(X = xᵢ, Y = yⱼ) と書きます。これが同時分布の表です。全てのセルが非負で、全てを足すと 1 になります。以下は自作のモデルです。

もう一方の値で、事象を分割する

{X = xᵢ} は、異なる yⱼ についての {X = xᵢ, Y = yⱼ} の排反な和です。従って確率を足せば行の和になります。列も同様です。また任意の関数 h について、値の組を一つの結果としてまとめれば、E[h(X, Y)] = ∑ᵢ∑ⱼ h(xᵢ, yⱼ)pᵢⱼ。期待値を値ごとにまとめる証明と同じ考え方です。

この表では E[X] = E[Y] = 1/2。積 XY は (1, 1) だけで 1 になるので E[XY] = 3/8 です。一変数の周辺分布だけでは、この 3/8 という同時の重みを知ることはできません。

条件付き分布と条件付き期待値

qⱼ = P(Y = yⱼ) > 0 のとき、Y = yⱼ を条件とする X の条件付き分布は、P(X = xᵢ | Y = yⱼ) = pᵢⱼ/qⱼ です。選んだ列を、その列の確率で割って合計 1 にします。これは条件付き確率の定義そのものです。

上の表で Y = 1 の列を使うと、P(X = 0 | Y = 1) = 1/4、P(X = 1 | Y = 1) = 3/4。従って条件付き期待値 E[X | Y = 1] は 3/4 です。一方、Y = 0 なら E[X | Y = 0] = 1/4。条件で重みを変えた後に、普通の期待値を計算しています。

有限の場合の全期待値の法則

m(yⱼ) = E[X | Y = yⱼ] とします。qⱼ = 0 の値では、m(yⱼ) を便宜上 0 などの任意の値に置きます。このとき m(Y) も確率変数になり、その期待値は E[X] です。

E[m(Y)]=∑j:qj>0E[X|Y=yj]qj=E[X]

条件で割った重みを、外側で戻す

qⱼ > 0 の列では m(yⱼ) = ∑ᵢxᵢpᵢⱼ/qⱼ です。これに qⱼ を掛けて j で足すと ∑ⱼ∑ᵢxᵢpᵢⱼ = ∑ᵢxᵢrᵢ = E[X]。qⱼ = 0 の列は、非負のセルの和が 0 なので全セルが 0 であり、合計に影響しません。未定義の条件付き分布を計算したのではなく、その列を除いて計算しています。

例では (1/4)(1/2) + (3/4)(1/2) = 1/2。条件付き平均を、条件が起こる確率でもう一度平均すると、元の平均に戻ります。E[E[X | Y]] = E[X] という書き方も、この m(Y) の意味で読みます。

独立な確率変数と積分布

有限値の X、Y が独立であるとは、全ての値の組について pᵢⱼ = rᵢqⱼ が成り立つことです。このとき任意の値の集合 A、B に対して、P(X ∈ A, Y ∈ B) = P(X ∈ A)P(Y ∈ B) です。実際、該当するセルを足すと、∑ᵢ∈A∑ⱼ∈B rᵢqⱼ が二つの和の積へ分かれます。逆に任意の集合で成立するなら、一点の集合を取ってセルの式を得ます。

独立な有限変数の積の平均

独立な有限値の X、Y について、E[XY] = E[X]E[Y] です。

二重の有限和を因数分解する

E[XY] = ∑ᵢ∑ⱼ xᵢyⱼpᵢⱼ = ∑ᵢ∑ⱼ(xᵢrᵢ)(yⱼqⱼ) = (∑ᵢxᵢrᵢ)(∑ⱼyⱼqⱼ)。これが E[X]E[Y] です。ここでは、期待値の和の線形性とは違って、同時確率を積へ変える箇所で独立性を使いました。

最初の表は (1, 1) のセルが 3/8 ですが、周辺の積は (1/2)(1/2) = 1/4 なので独立ではありません。独立なら、正の確率を持つ条件 Y = yⱼ で割った後も、X の分布は rᵢ のままです。

有限値の変数 X₁、…、Xₙ が相互に独立であるとは、どの値の組に対しても、同時確率 P(X₁ = x₁, …, Xₙ = xₙ) が P(X₁ = x₁) · … · P(Xₙ = xₙ) へ分かれることです。任意の二つについては、残りの値を全て足せば二変数の独立性が従います。逆に二変数ずつの独立性だけから相互独立は言えないことは、独立性の章で見た通りです。

一般の実数値の変数では、任意の範囲に入る事象どうしの独立を定義に使います。独立な可積分変数についての積の期待値の因数分解も成立しますが、その積分による一般化は本冊では未証明で使う標準的な性質です。ここでの有限表の主張は、上で全て証明しました。

共分散と和の分散

平均 μₓ、μᵧ を持つ変数の共分散を Cov(X, Y) = E[(X − μₓ)(Y − μᵧ)] と定義します。有限表では必ず有限です。一般の場合は E[X²]、E[Y²] が有限と仮定すれば、2|XY| ≤ X² + Y² により積も可積分となり、以下の式を使えます。

Cov(X,Y)=E[XY]−E[X]E[Y]

和の分散

二乗の期待値が有限なら、次の式が成立します。特に独立なら共分散が 0 なので、和の分散は分散の和になります。

Var(X+Y)=Var(X)+Var(Y)+2Cov(X,Y)

二乗の交差項を残す

まず共分散の定義を展開し、期待値の線形性を使うと E[XY] − μₓE[Y] − μᵧE[X] + μₓμᵧ = E[XY] − μₓμᵧ です。次に、和の平均からの差は (X − μₓ) + (Y − μᵧ)。二乗して平均すると二つの分散と、交差項 2E[(X − μₓ)(Y − μᵧ)] が現れます。独立なら E[XY] が平均の積に分かれるので、共分散は 0 です。

最初の表では Cov(X, Y) = 3/8 − 1/4 = 1/8 です。各分散は 1/4 なので Var(X + Y) = 1/4 + 1/4 + 2 · (1/8) = 3/4。二つの値が同じ側になりやすい重みが、和の散らばりに現れました。逆に Y = 1 − X の場合は共分散が負となり、和の分散は 0 です。

交差項は各組 i < j に一つずつ対応します。各組が独立なら全て消えます。従って独立な Bernoulli 変数 n 個の成功数の分散は np(1 − p)。実は、和の分散の加法性だけには、各組の共分散が 0 であれば十分です。

無相関と独立の違い

共分散が 0 であることを無相関と呼びます。独立なら無相関ですが、逆向きは一般に誤りです。X が −1、0、1 をそれぞれ確率 1/3 で取り、Y = X² としましょう。X が決まれば Y も決まります。

E[X] = 0、E[Y] = E[X²] = 2/3、E[XY] = E[X³] = (−1 + 0 + 1)/3 = 0。従って Cov(X, Y) = 0 です。しかし P(X = 0, Y = 0) = 1/3 に対し、P(X = 0)P(Y = 0) = (1/3)(1/3) = 1/9 で、独立の条件を満たしません。

正と負の X による交差の寄与が相殺したことが、共分散 0 の理由です。二次的な結び付きまで消えたわけではありません。平均と分散だけでなく、依存関係の要約にも、落ちる情報があります。

寄り道［応用］：別々に見える集計にも、同じデータが混ざる

MIT の共分散の教材は、三回のコイン投げから、最初の二回の表の数と、最後の二回の表の数を作る例を扱っています。元の投げ方が独立でも、二つの集計は真ん中の一回を共有します。

本章でも公平で独立な 0、1 の変数 A、B、C から U = A + B、V = B + C を作ると、E[U] = E[V] = 1。積を展開して E[UV] = E[AB] + E[AC] + E[B²] + E[BC] = 1/4 + 1/4 + 1/2 + 1/4 = 5/4 です。従って共分散は 1/4。別の名前の集計でも、入力を共有すれば独立とは限らないことが、表を作る前にも見えてきます。

演習：同時分布と共分散

1．列を選び、平均を戻す

本文の表について E[X | Y = 0]、E[X | Y = 1] を求め、全期待値の法則で E[X] を確かめてください。

ヒント1：列の和はどちらも 1/2

各セルを 1/2 で割って、条件付き確率を作ります。

ヒント2：0、1 の平均は 1 の確率

条件付き平均を、Y の二つの周辺確率で重み付けします。

解答

E[X | Y = 0] = (1/8)/(1/2) = 1/4、E[X | Y = 1] = (3/8)/(1/2) = 3/4。外側で平均すると (1/4)(1/2) + (3/4)(1/2) = 1/2 で、周辺分布から得る E[X] と一致します。

2．同じ周辺分布で独立にする

X、Y がそれぞれ 0、1 を半々で取り、さらに独立とします。同時表の四つのセルと、Var(X + Y) を求め、本文の表と比較してください。

ヒント1：セルは周辺確率の積

全ての組で (1/2)(1/2) です。

ヒント2：独立なら交差項は 0

各分散は Bernoulli の公式により 1/4 です。

解答

四つのセルは全て 1/4。E[XY] = 1/4 で共分散は 1/4 − (1/2)(1/2) = 0 です。従って Var(X + Y) = 1/4 + 1/4 = 1/2。本文の表では周辺分布が同じでも共分散が 1/8 なので、和の分散は 3/4 でした。

3．無相関でも依存する二変数

本文の X = −1、0、1 が等確率で Y = X² の例について、Var(X)、Var(Y)、Var(X + Y) を求めてください。独立性を仮定してよいですか。

ヒント1：Y² = Y

E[Y] = 2/3 なので、Var(Y) = 2/3 − (2/3)² です。

ヒント2：共分散は既に 0

和の分散の公式は、独立でなくても使えます。

解答

Var(X) = 2/3 − 0² = 2/3、Var(Y) = 2/3 − 4/9 = 2/9。共分散 0 なので Var(X + Y) = 2/3 + 2/9 = 8/9 です。直接にも X + Y は 0 を確率 2/3、2 を確率 1/3 で取り、分散は 4/3 − (2/3)² = 8/9。二変数は独立ではなく、ここでは無相関だけで加法性が成立しています。
