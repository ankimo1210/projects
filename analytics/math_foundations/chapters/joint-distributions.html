同時分布と周辺分布

X と Y がそれぞれ 0、1 を半々で取るとします。いつも Y = X なら和は 0 または 2。いつも Y = 1 − X なら和は必ず 1。X と Y それぞれの分布は同じなのに、和の分布は違います。

必要なのは、二つの値が同時に起きる確率です。この章では有限の同時確率の表を使い、条件付きの平均、独立性、和の分散を一つの表から導きます。

学習の目安は演習込み110–160分です。表の復元と条件付き分布、独立性と分散、設計と演習の三回に分けられます。演習1–3は基本、4–7は復元と診断、8–10は証明と境界条件です。扱う表はすべて有限で、追加の数値モデルも自作です。

同時確率分布と周辺化

X の取り得る値を xᵢ、Y の取り得る値を yⱼ とし、pᵢⱼ = P(X = xᵢ, Y = yⱼ) と書きます。これが同時分布の表です。全てのセルが非負で、全てを足すと 1 になります。以下は自作のモデルです。

行の和 rᵢ = ∑ⱼpᵢⱼ は P(X = xᵢ)、列の和 qⱼ = ∑ᵢpᵢⱼ は P(Y = yⱼ) です。このように一方の変数だけを残した分布を周辺分布と呼びます。

もう一方の値で、事象を分割する

{X = xᵢ} は、異なる yⱼ についての {X = xᵢ, Y = yⱼ} の排反な和です。従って確率を足せば行の和になります。列も同様です。また任意の関数 h について、値の組を一つの結果としてまとめれば、E[h(X, Y)] = ∑ᵢ∑ⱼ h(xᵢ, yⱼ)pᵢⱼ。期待値を値ごとにまとめる証明と同じ考え方です。

この表では E[X] = E[Y] = 1/2。積 XY は (1, 1) だけで 1 になるので E[XY] = 3/8 です。一変数の周辺分布だけでは、この 3/8 という同時の重みを知ることはできません。

周辺分布から同時表を復元する

周辺分布が分かっても表が一つに決まらないことを、未知のセルを残して確かめます。X、Y は0か1を取り、P(X=1)=p、P(Y=1)=q とします。自由に動かせそうな量として t=P(X=1,Y=1) を選びます。残り三セルを別々の未知数にするより、行と列の和で順に消去する方が、残る自由度を見通せるからです。

P(1,1)=t、P(1,0)=p−t、P(0,1)=q−t、P(0,0)=1−p−q+t。

ここでは P(i,j) を P(X=i,Y=j) の略記としました。四セルの和は自動的に1になりますが、非負性は別に確認しなければなりません。t≥0、t≤p、t≤q、t≥p+q−1 を同時に要求して、

max(0,p+q−1) ≤ t ≤ min(p,q)

を得ます。逆にこの範囲の t なら全セルが非負で合計1なので、四つの結果 (0,0)、(0,1)、(1,0)、(1,1) にその確率を与えるモデルを作れます。従って必要条件であるだけでなく十分条件です。

条件付き分布と条件付き期待値

qⱼ = P(Y = yⱼ) > 0 のとき、Y = yⱼ を条件とする X の条件付き分布は、P(X = xᵢ | Y = yⱼ) = pᵢⱼ/qⱼ です。選んだ列を、その列の確率で割って合計 1 にします。これは条件付き確率の定義そのものです。

最初の対称表（3/8, 1/8; 1/8, 3/8）で Y = 1 の列を使うと、P(X = 0 | Y = 1) = 1/4、P(X = 1 | Y = 1) = 3/4。従って条件付き期待値 E[X | Y = 1] は 3/4 です。一方、Y = 0 なら E[X | Y = 0] = 1/4。条件で重みを変えた後に、普通の期待値を計算しています。

有限の場合の全期待値の法則

m(yⱼ) = E[X | Y = yⱼ] とします。qⱼ = 0 の値では、m(yⱼ) を便宜上 0 などの任意の値に置きます。このとき m(Y) も確率変数になり、その期待値は E[X] です。

E[m(Y)]=∑j:qj>0E[X|Y=yj]qj=E[X]

条件で割った重みを、外側で戻す

qⱼ > 0 の列では m(yⱼ) = ∑ᵢxᵢpᵢⱼ/qⱼ です。これに qⱼ を掛けて j で足すと ∑ⱼ∑ᵢxᵢpᵢⱼ = ∑ᵢxᵢrᵢ = E[X]。qⱼ = 0 の列は、非負のセルの和が 0 なので全セルが 0 であり、合計に影響しません。未定義の条件付き分布を計算したのではなく、その列を除いて計算しています。

例では (1/4)(1/2) + (3/4)(1/2) = 1/2。条件付き平均を、条件が起こる確率でもう一度平均すると、元の平均に戻ります。E[E[X | Y]] = E[X] という書き方も、この m(Y) の意味で読みます。

条件付き平均を重み付きで戻す

例題2：条件が等確率でない場合

例題1の t=3/10 の表に戻ります。Y=0 の列は (3/10,1/10)、列の和は2/5です。X=1の条件付き確率は (1/10)/(2/5)=1/4。Y=1 の列は (3/10,3/10)、列の和は3/5なので、X=1の条件付き確率は1/2です。Xは0,1だけを取るため、この二つがそれぞれの条件付き平均になります。

元の平均を求めたいなら、二つの条件を一回ずつ数えるのではなく、その起こる確率で重み付けします。従って E[X]=(2/5)(1/4)+(3/5)(1/2)=1/10+3/10=2/5。周辺から求めた値と一致します。二つの平均を単純に平均した (1/4+1/2)/2=3/8 は、Y=0とY=1を半々に選ぶ別のモデルの平均です。

逆向きにも計算できます。P(Y=1)=3/5、E[X|Y=0]=1/4、E[X|Y=1]=1/2 が分かれば、Xが0,1という条件の下で、各列に列の和を掛けて (3/10,1/10) と (3/10,3/10) を復元できます。条件付きの平均だけで列の確率まで分かるのは、値が二つで、平均が「1の確率」だからです。三値以上なら一般には平均だけで分布は決まりません。

列の和が0なら、その列を正規化する割り算はできません。確率0の条件での平均を便宜上どう置いても、全期待値の和では重み0が掛かります。「条件付き分布を0と定義した」とは言っていません。

独立な確率変数と積分布

有限値の X、Y が独立であるとは、全ての値の組について pᵢⱼ = rᵢqⱼ が成り立つことです。このとき任意の値の集合 A、B に対して、P(X ∈ A, Y ∈ B) = P(X ∈ A)P(Y ∈ B) です。実際、xᵢ ∈ A を満たす添字 i と yⱼ ∈ B を満たす添字 j のセルを足すと、∑i:xᵢ∈A∑j:yⱼ∈B rᵢqⱼ が二つの和の積へ分かれます。逆に任意の集合で成立するなら、一点の集合を取ってセルの式を得ます。

独立な有限変数の積の平均

独立な有限値の X、Y について、E[XY] = E[X]E[Y] です。

二重の有限和を因数分解する

E[XY] = ∑ᵢ∑ⱼ xᵢyⱼpᵢⱼ = ∑ᵢ∑ⱼ(xᵢrᵢ)(yⱼqⱼ) = (∑ᵢxᵢrᵢ)(∑ⱼyⱼqⱼ)。これが E[X]E[Y] です。ここでは、期待値の和の線形性とは違って、同時確率を積へ変える箇所で独立性を使いました。

最初の表は (1, 1) のセルが 3/8 ですが、周辺の積は (1/2)(1/2) = 1/4 なので独立ではありません。独立なら、正の確率を持つ条件 Y = yⱼ で割った後も、X の分布は rᵢ のままです。

有限値の変数 X₁、…、Xₙ が相互に独立であるとは、どの値の組に対しても、同時確率 P(X₁ = x₁, …, Xₙ = xₙ) が P(X₁ = x₁) · … · P(Xₙ = xₙ) へ分かれることです。任意の二つについては、残りの値を全て足せば二変数の独立性が従います。逆に二変数ずつの独立性だけから相互独立は言えないことは、独立性の章で見た通りです。

一般の実数値の変数では、任意の範囲に入る事象どうしの独立を定義に使います。独立な可積分変数についての積の期待値の因数分解も成立しますが、その積分による一般化は本冊では未証明で使う標準的な性質です。ここでの有限表の主張は、上で全て証明しました。

共分散と和の分散

平均 μₓ、μᵧ を持つ変数の共分散を Cov(X, Y) = E[(X − μₓ)(Y − μᵧ)] と定義します。有限表では必ず有限です。一般の場合は E[X²]、E[Y²] が有限と仮定すれば、2|XY| ≤ X² + Y² により積も可積分となり、以下の式を使えます。

Cov(X,Y)=E[XY]−E[X]E[Y]

和の分散

二乗の期待値が有限なら、次の式が成立します。特に独立なら共分散が 0 なので、和の分散は分散の和になります。

Var(X+Y)=Var(X)+Var(Y)+2Cov(X,Y)

二乗の交差項を残す

まず共分散の定義を展開し、期待値の線形性を使うと E[XY] − μₓE[Y] − μᵧE[X] + μₓμᵧ = E[XY] − μₓμᵧ です。次に、和の平均からの差は (X − μₓ) + (Y − μᵧ)。二乗して平均すると二つの分散と、交差項 2E[(X − μₓ)(Y − μᵧ)] が現れます。独立なら E[XY] が平均の積に分かれるので、共分散は 0 です。

最初の表では Cov(X, Y) = 3/8 − 1/4 = 1/8 です。各分散は 1/4 なので Var(X + Y) = 1/4 + 1/4 + 2 · (1/8) = 3/4。二つの値が同じ側になりやすい重みが、和の散らばりに現れました。逆に Y = 1 − X の場合は共分散が負となり、和の分散は 0 です。

有限個の和にも、同じ二乗の展開が使えます。

Var(∑i=1nXi)=∑i=1nVar(Xi)+2∑i<jCov(Xi,Xj)

交差項は各組 i < j に一つずつ対応します。各組が独立なら全て消えます。従って独立な Bernoulli 変数 n 個の成功数の分散は np(1 − p)。実は、和の分散の加法性だけには、各組の共分散が 0 であれば十分です。

和の分散から依存の強さを設計する

平均と分散を別々に指定するだけでは、二変数を同時にどう動かすかは決まりません。例題1と同じ周辺 P(X=1)=2/5、P(Y=1)=3/5 を固定し、和 S=X+Y の分散を3/5にするには、どの表を選べばよいでしょう。ここでは「分散を計算する」向きを逆にします。

例題3：目標から同時確率を逆算する

まず E[XY]=t、E[X]E[Y]=6/25 なので Cov(X,Y)=t−6/25。各分散は (2/5)(3/5)=6/25 です。従って Var(S)=6/25+6/25+2(t−6/25)=2t。目標 2t=3/5 を解くと t=3/10 です。

無相関と独立の違い

共分散が 0 であることを無相関と呼びます。独立なら無相関ですが、逆向きは一般に誤りです。X が −1、0、1 をそれぞれ確率 1/3 で取り、Y = X² としましょう。X が決まれば Y も決まります。

E[X] = 0、E[Y] = E[X²] = 2/3、E[XY] = E[X³] = (−1 + 0 + 1)/3 = 0。従って Cov(X, Y) = 0 です。しかし P(X = 0, Y = 0) = 1/3 に対し、P(X = 0)P(Y = 0) = (1/3)(1/3) = 1/9 で、独立の条件を満たしません。

正と負の X による交差の寄与が相殺したことが、共分散 0 の理由です。二次的な結び付きまで消えたわけではありません。平均と分散だけでなく、依存関係の要約にも、落ちる情報があります。

寄り道［応用］：別々に見える集計にも、同じデータが混ざる

MIT の共分散の教材は、三回のコイン投げから、最初の二回の表の数と、最後の二回の表の数を作る例を扱っています。元の投げ方が独立でも、二つの集計は真ん中の一回を共有します。

本章でも公平で独立な 0、1 の変数 A、B、C から U = A + B、V = B + C を作ると、E[U] = E[V] = 1。積を展開して E[UV] = E[AB] + E[AC] + E[B²] + E[BC] = 1/4 + 1/4 + 1/2 + 1/4 = 5/4 です。従って共分散は 1/4。別の名前の集計でも、入力を共有すれば独立とは限らないことが、表を作る前にも見えてきます。

演習：同時分布と共分散

1．列を選び、平均を戻す

最初の対称表（3/8, 1/8; 1/8, 3/8）について E[X | Y = 0]、E[X | Y = 1] を求め、全期待値の法則で E[X] を確かめてください。

ヒント1：列の和はどちらも 1/2

各セルを 1/2 で割って、条件付き確率を作ります。

ヒント2：0、1 の平均は 1 の確率

条件付き平均を、Y の二つの周辺確率で重み付けします。

解答

E[X | Y = 0] = (1/8)/(1/2) = 1/4、E[X | Y = 1] = (3/8)/(1/2) = 3/4。外側で平均すると (1/4)(1/2) + (3/4)(1/2) = 1/2 で、周辺分布から得る E[X] と一致します。

2．同じ周辺分布で独立にする

X、Y がそれぞれ 0、1 を半々で取り、さらに独立とします。同時表の四つのセルと、Var(X + Y) を求め、最初の対称表（3/8, 1/8; 1/8, 3/8）と比較してください。

ヒント1：セルは周辺確率の積

全ての組で (1/2)(1/2) です。

ヒント2：独立なら交差項は 0

各分散は Bernoulli の公式により 1/4 です。

解答

四つのセルは全て 1/4。E[XY] = 1/4 で共分散は 1/4 − (1/2)(1/2) = 0 です。従って Var(X + Y) = 1/4 + 1/4 = 1/2。最初の対称表（3/8, 1/8; 1/8, 3/8）では周辺分布が同じでも共分散が 1/8 なので、和の分散は 3/4 でした。

3．無相関でも依存する二変数

本文の X = −1、0、1 が等確率で Y = X² の例について、Var(X)、Var(Y)、Var(X + Y) を求めてください。独立性を仮定してよいですか。

ヒント1：Y² = Y

E[Y] = 2/3 なので、Var(Y) = 2/3 − (2/3)² です。

ヒント2：共分散は既に 0

和の分散の公式は、独立でなくても使えます。

解答

Var(X) = 2/3 − 0² = 2/3、Var(Y) = 2/3 − 4/9 = 2/9。共分散 0 なので Var(X + Y) = 2/3 + 2/9 = 8/9 です。直接にも X + Y は 0 を確率 2/3、2 を確率 1/3 で取り、分散は 4/3 − (2/3)² = 8/9。二変数は独立ではなく、ここでは無相関だけで加法性が成立しています。

ヒント1

全セルの和を1にします。

ヒント2

XYが1なのは(1,1)だけです。

解答

a=1−1/5−1/10−2/5=3/10。Xの周辺は(1/2,1/2)、Yの周辺は(2/5,3/5)。条件付き確率は (2/5)/(3/5)=2/3。共分散は2/5−(1/2)(3/5)=1/10です。全セル非負、行・列の総和1を確認できます。

5．条件付き平均の単純平均を診断する

例題2で、ある人は E[X]=(1/4+1/2)/2=3/8 と答えました。何を暗に変えたのか説明し、元の表を復元して正しい平均を示してください。

ヒント1

条件Yの確率は半々でしょうか。

ヒント2

各条件付き確率に列の和を掛けます。

解答

Yの分布を(1/2,1/2)へ変えています。元の列の和は2/5と3/5なので、列は(3/10,1/10)と(3/10,3/10)。X=1の行の和は1/10+3/10=2/5であり、全期待値でも (2/5)(1/4)+(3/5)(1/2)=2/5。単純平均3/8との差は1/40です。

6．実現できない共分散を見抜く

P(X=1)=2/5、P(Y=1)=3/5 の0,1変数で、共分散を1/5にしたいとします。実現可能性を調べ、可能な共分散の範囲を求めてください。

ヒント1

共分散をt−6/25と書きます。

ヒント2

四セル非負の範囲は0≤t≤2/5です。

解答

目標にはt=1/5+6/25=11/25が必要ですが、2/5=10/25を超え、P(1,0)=−1/25になります。可能な範囲は−6/25≤Cov≤4/25。両端はt=0と2/5の確率表で実現するため、単なる上界・下界でなく正確な範囲です。

7．和と差の分散を同時に指定する

例題3と同じ周辺で Var(X+Y)=3/5、Var(X−Y)=2/5 を同時に指定できますか。できなければ前者を保って後者を修正してください。

ヒント1

二つの分散の和を先に見ます。

ヒント2

共分散の交差項は和と差で相殺します。

解答

二つの分散の和は2Var(X)+2Var(Y)=24/25。指定値の和は1=25/25なので両立しません。前者を保つとt=3/10、後者は24/25−3/5=9/25です。表(3/10,3/10;1/10,3/10)で実現します。差Dは−1を3/10、0を3/5、1を1/10で取り、E[D]=−1/5、E[D²]=2/5より分散2/5−1/25=9/25と検算できます。

8．二値変数での逆向きを証明する

X,Yが0,1だけを取るとき、無相関なら独立であることを証明してください。p=0やq=1という境界も含めてください。

ヒント1

E[XY]=t、E[X]=p、E[Y]=qです。

ヒント2

t=pqを残り三セルへ代入します。

解答

共分散0はt=pqです。四セルは (1−p−q+pq,q−pq;p−pq,pq)=((1−p)(1−q),(1−p)q;p(1−q),pq)。すべて周辺確率の積なので独立です。割り算をしない証明なのでp=0やq=1でも有効です。一般の無相関から独立が従わない反例と矛盾しません。ここでは0,1の二値に限定しています。

9．無相関で依存する例を設計する

Xが−1,0,1を確率a,1−2a,aで取り、Y=X²とします。確率表が作れるaの範囲を求め、無相関だが独立ではない範囲を決めてください。

ヒント1

E[X]とE[X³]は対称性で0です。

ヒント2

事象X=0とY=0を使い、a=0とa=1/2も別に調べます。

解答

非負性から0≤a≤1/2。E[X]=E[X³]=0なので共分散は全範囲で0です。0<a<1/2ではP(X=0,Y=0)=1−2aと周辺の積(1−2a)²が異なるため独立ではありません。a=0ではX=Y=0が確実、a=1/2ではY=1が確実で、どちらも独立です。従って求める範囲は開区間(0,1/2)で、端点を含めると誤りです。

10．確率0の条件を区別する

X,Yが0,1を取り、表が(3/4,0;1/4,0)です。Y=0でのXの分布、E[X]を求めてください。「Y=1ではXの平均は0」と条件付き分布から計算できるでしょうか。全期待値ではその列をどう扱いますか。

ヒント1

Yの列の和は1と0です。

ヒント2

0/0という比は条件付き確率を定めません。

解答

Y=0でXの分布は(3/4,1/4)で平均1/4です。周辺からもE[X]=1/4。Y=1の条件付き確率は0/0で未定義です。m(1)を便宜上0あるいは他の有限値に置けますが、条件付き分布を計算したことにはなりません。E[m(Y)]=m(0)·1+m(1)·0=1/4で、正の確率を持つ列だけで全期待値が求まります。
