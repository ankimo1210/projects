指数関数の周期性と対数

実数の指数関数は単調なので、正の数から対数を一つに決められました。複素数の指数は回転も表します。一周分の角度を加えても同じ点へ戻るなら、指数を逆にたどるとき、その一周をどこへ記録すればよいでしょう。

前提は極形式と偏角、CRと実全微分の十分条件、実の指数関数と実の対数です。複素冪級数の項別微分は、まだ使いません。

学習の目安は演習を含めて130–180分です。指数とその方程式、主値Logの構成、枝の選び方と一周の障害に分けて読み進められます。演習1–3は定義の確認、4–7は範囲と枝の点検、8–9は平方根と三角関数への応用です。

複素指数関数の定義と性質

z = x + iy に対し、複素指数関数を次で定義します。右辺の指数、cos、sin は既に知っている実関数です。記号 eᶻ も同じ意味で使います。

exp(x+iy)=ex(cosy+isiny)

実部 x が長さ eˣ、虚部 y が角度を決めます。|exp z| = eˣ > 0 なので指数関数の値は0になりません。実指数の加法性と三角関数の加法定理から exp(z + w) = exp z exp w。特に exp(−z) は exp z の逆数です。

定義から正則性を確かめる

u = eˣ cos y、v = eˣ sin y とすると、uₓ = eˣ cos y = vᵧ、uᵧ = −eˣ sin y = −vₓ です。四つの偏導関数は連続なので、CRの十分条件を全平面で使えます。したがって exp は全平面で正則で、(exp z)′ = uₓ + ivₓ = exp z。複素指数の微分を、未証明の級数操作から導いていません。

exp z = exp w となる条件は、exp(z − w) = 1 です。絶対値から Re(z − w) = 0、単位円の座標から Im(z − w) = 2πk（k は整数）と分かります。つまり z − w = 2πik。指数関数の周期は、逆関数を平面全体で一つにできない原因です。

指数方程式を長さと偏角へ分ける

指数関数は一対一ではありませんが、入力の実部と虚部が担う仕事は分かれています。方程式 exp w=ζ を解くときは、未知の複素数を w=p+iq（p,qは実数）と置き、まず長さで p を決め、それから角度で q の候補をすべて残します。

例題1：出力から指数の入力をすべて求める

exp w=−√3+i を解きます。右辺の長さは √(3+1)=2 なので eᵖ=2、従って p=ln2。残る条件は cos q=−√3/2、sin q=1/2 です。実部が負、虚部が正なので角度は第2象限にあり、q=5π/6+2πk、kは任意の整数です。

答えは w=ln2+i(5π/6+2πk)。定義へ代入すると e^(ln2)=2 で、三角関数の周期性によりすべての k が −√3+i を返します。逆に、長さから p はこれ以外に選べず、同じ単位円上の点を表す角度は2πの整数倍だけ違うので、これですべてです。

入力を −π<q<π に制限するなら k=0 の一つだけ残ります。入力を π<q<3π に制限するなら k=1、q=17π/6 が残ります。どちらも同じ出力に対応します。範囲を指定することは、存在する入力を消してしまう計算ではなく、逆向きの対応から一つを選ぶ操作です。

出力0ならどうでしょう。|exp w|=eᵖ>0 なので解はありません。「対数の値がたくさんある」という話を、0にも広げてはいけません。

複素三角関数

指数関数を作ると、実の三角関数も同じ材料で複素数へ広げられます。ここでその対応を確認したあと、「指数の逆をどこで一つに選べるか」という対数の問いへ戻ります。

複素数を角度に入れた cos、sin は、実の単位円だけでは定義できません。そこで、実数では成り立つ指数の組合せを、そのまま複素数での定義にします。

cosz=eiz+e−iz2,sinz=eiz−e−iz2i

実数への一致と微分を確認する

実数 t では exp(it) = cos t + i sin t、exp(−it) = cos t − i sin t なので、和と差は従来の実三角関数を返します。複素数でも指数関数の合成・和・定数倍は正則です。連鎖律で (exp(iz))′ = i exp(iz)、(exp(−iz))′ = −i exp(−iz)。定義を微分すれば (cos z)′ = −sin z、(sin z)′ = cos z です。

公式が似ていても、実数での値域まで同じではありません。t > 0 に対し sin(it) = i(eᵗ − e⁻ᵗ)/2 なので、その絶対値は t とともに限りなく増えます。「sinの絶対値は1以下」は実数の入力での性質です。定義を拡張したとき、どの性質が残るかは改めて確かめます。

主値対数と分枝切断

同じ点に対数の候補がいくつもあるとき、その中から連続につながる値を一つずつ選ぶと、通常の関数として扱えます。これが分枝（枝）を選ぶという意味です。一つの入力に一つの出力が決まることを一価といい、値を連続に選べるよう定義域から除く線などを分枝切断と呼びます。

z ≠ 0 を r(cos θ + i sin θ) と書くと、exp w = z の解は w = ln r + i(θ + 2πk) です。ここで ln は正の実数の自然対数です。この解たちから、点 z ごとに連続につながる一つを選んだ関数を対数の枝と呼びます。

この本の主値対数の約束

D = ℂ ∖ (−∞, 0]、すなわち0を含む負の実軸を除いた開集合で、Arg z を (−π, π) にある唯一の偏角とします。主値対数を Log z = ln|z| + i Arg z と定めます。切断上の0と負の実数では、Arg も Log もこの定義では未定義です。±π のどちらかを切断上だけ付け足す約束は使いません。

選んだ Log が正則かを確かめるには、偏角 Arg を実二変数の関数として微分したいところです。そこで次の二つの証明では、まず実の角度を取り出す arctan の微分を準備し、それを使って Arg の偏微分とCRを確かめます。

この定義で exp(Log z) = z が成立します。逆に Log(exp w) = w は常に成り立つわけではありません。例えば w = 2πi なら exp w = 1、Log 1 = 0 です。−π < Im w < π の帯に制限すれば、指数と主値対数は互いの逆になります。

角度を取り出す実関数を準備する

実の区間 (−π/2, π/2) で tan θ = sin θ/cos θ と定めます。この区間では cos θ > 0。商の微分則から tan′ θ = (cos² θ + sin² θ)/cos² θ = 1 + tan² θ > 0 なので、平均値の定理により厳密に増加します。端へ近づくと sin θ はそれぞれ −1、1へ、cos θ は正の側から0へ近づくため、tan θ の極限はそれぞれ −∞、+∞。連続性と中間値の定理により、この tan は区間から ℝ への全単射です。その逆関数を arctan : ℝ → (−π/2, π/2) と定めます。

逆関数の連続性も確認します。t₀ = tan θ₀ とし、θ₀ ± ε が区間内にあるほど小さい ε > 0 を取ります。tan(θ₀ − ε) < t₀ < tan(θ₀ + ε) なので、t を t₀ に十分近づけるとこの二つの値の間に入ります。単調性より θ₀ − ε < arctan t < θ₀ + ε。したがって t → t₀ なら θ = arctan t → θ₀ です。

t ≠ t₀ なら単射性から θ ≠ θ₀ なので、逆関数の差商を次のように書けます。分母側の差商は既に微分可能な tan のものです。θ → θ₀ を使うと、その極限は 1 + tan² θ₀ = 1 + t₀² > 0 となり、逆数の極限も取れます。

arctant−arctant0t−t0=1tanθ−tanθ0θ−θ0→11+t02

これで arctan の微分可能性と (arctan t)′ = 1/(1 + t²) が示せました。この導関数は連続なので、arctan は実 C¹ です。逆関数が微分できることを先に仮定してはいません。

局所的な角度から、Logの微分を導く

D の各点では角度 θ を連続に選べます。具体的には x ≠ 0 の近くなら arctan(y/x) に一定の π の整数倍を足し、x = 0、y ≠ 0 の近くなら arctan(−x/y) に一定の ±π/2 を足せます。切断を避けた小近傍で、これが Arg と一致します。上で導いた arctan の微分式から、θₓ = −y/(x² + y²)、θᵧ = x/(x² + y²) です。

u = ln r = (1/2)ln(x² + y²) とすると uₓ = x/(x² + y²)、uᵧ = y/(x² + y²)。これらも角度の偏導関数も小近傍で連続です。CRの十分条件が成立するので、Log は D で正則です。導関数は次になります。

Log′z=xx2+y2−iyx2+y2=1z

ここで必要なのは小近傍での実 C¹ の角度です。切断を避けた各小近傍で arctan を使うことで得られ、平面全体で一つの角度を選べると仮定したわけではありません。

積の公式の条件と、別の枝の設計

ここからは、主値の定義域 D=ℂ∖(−∞,0] を使います。Log z という記号を含む式は、まず z が D に入るかを確かめてから計算します。指数を取った後に等しいことだけでは、選んだ対数の値の等しさまでは言えません。

例題2：Log(zw)=Log z+Log w を使える条件を決める

z,w∈D とし、θ=Arg z、φ=Arg w、s=θ+φ と置きます。|zw|=|z||w| なので、実の対数の公式から ln|zw|=ln|z|+ln|w|。問題は虚部だけです。s は (−2π,2π) に入り、積の偏角を (−π,π) へ戻す必要があります。

−π<s<π なら Arg(zw)=s で、積も切断外にあるため Log(zw)=Log z+Log w です。π<s<2π なら Arg(zw)=s−2π で、左辺は右辺より2πi小さくなります。−2π<s<−π なら Arg(zw)=s+2π で、左辺は右辺より2πi大きくなります。s=±π では積は負の実数なので、左辺は未定義です。

例えば z=w=i では個々の主値はπi/2ですが、zw=−1は切断上なので Log(zw) を書けません。一方 z=w=exp(2πi/3) なら個々の主値の和は4πi/3、積の主値は−2πi/3で、両方定義されるのに一致しません。指数を取るとどちらも同じ積になることが検算です。

例題3：負の実数でも使える枝を作る

負の実数の近くを通る計算では、主値Logの切断が邪魔になります。代わりに E=ℂ∖[0,∞)、つまり0を含む正の実軸を除き、角度を (0,2π) に選ぶ枝を設計します。主値をすでに作ったので、回転してから使う方針が簡単です。

z∈E なら −z∈D なので、L(z)=Log(−z)+πi と定められます。指数を取ると exp L(z)=exp(Log(−z))exp(πi)=(−z)(−1)=z。虚部は Arg(−z)+π∈(0,2π) で、望んだ角度範囲です。合成の微分則から L′(z)=[1/(−z)](−1)=1/z です。

L(−1)=πi、L(i)=πi/2、L(−i)=3πi/2。主値では Log(i)=πi/2、Log(−i)=−πi/2 なので、上半平面では差0、下半平面では差2πiです。一方、Log(−1)とL(1)はそれぞれの切断上で未定義です。枝を変えることは、同じ式へ都合のよい値を付け足すことでなく、定義域と角度の約束をそろえて変えることです。

重なる定義域 D∩E は上半平面と下半平面に分かれています。二つの枝の導関数がともに1/zでも、差の定数が二つの部分で異なれるのはこのためです。原点を除く平面 ℂ∖{0} 全体で一つの枝を作れたことにはなりません。

経路に沿う偏角と対数の多価性

原点だけを除いた複素平面 ℂ∖{0} を、穿孔平面とも呼びます。切断を入れた主値の定義域と違い、ここでは原点を一周する道が残っています。点だけから値を選ぶことと、進んだ道も記録することを比較します。

円に沿って z(t) = r exp(it) と動くなら、ln r + it は t とともに連続で、指数を取ると z(t) です。これは道に沿って持ち上げた角度を使う値です。t = 0 と t = 2π は同じ点 z = r ですが、この値は 2πi 違います。したがって、円上の点だけで値が決まる一つの関数とは区別します。

円上の同じ点と、下の二つの虚部の高さを対応づけます。±180°では主値は切断上で未定義、±360°では点は出発点へ戻っても追跡値の虚部だけが±2π残ります。経路の履歴を持つ値は、穿孔平面全体の各点へ一価で連続な対数を定めたものではありません。

原点を除く平面全体では、連続な対数も作れない

連続な L : ℂ ∖ {0} → ℂ があり、exp(L(z)) = z を満たすと仮定します。単位円上で指数の逆像の形を使うと、L(exp(it)) = i(t + 2πk(t))、k(t) は整数です。左辺と t が連続なので k(t) も [0, 2π] で連続。連続な実関数が異なる整数を取れば中間値の定理で非整数も取るため、k は一定です。

すると t = 2π と t = 0 の値の差は2πi。しかし exp(2πi) = exp(0) = 1 だから、同じ関数 L の値は等しいはずです。矛盾により、この L は存在しません。特に、平面全体から原点だけを除いた集合で正則な対数はありません。

主値でも Log(zw) = Log z + Log w を無条件に使えません。z = w = exp(3πi/4) なら、右辺は 3πi/2、積は −i なので左辺は −πi/2 です。どれも切断外ですが、差は2πi。指数を取ると一致することと、選んだ枝の値が一致することは別です。次章ではこの一周分の違いを、積分で測ります。

寄り道［自作モデル］：平方根も、切れ目の選択を受け継ぐ

主値対数の定義域 D で S(z) = exp((1/2)Log z) と置きます。指数の加法性から S(z)² = z、連鎖律から S′(z) = S(z)/(2z) = 1/(2S(z)) です。0を除いているため分母は0になりません。これが一つの正則な平方根の枝です。

円を一周する道で角度を連続に追うと、半分の角度は π だけ変わり、平方根の符号が逆になります。同じ点へ戻ったときの値を一つに定めるには、対数と同じく定義域を選ぶ必要があります。実数の正の平方根を複素数へ延長すると、単なる符号の選択が道の問題になります。

演習：指数・対数と定義域

1．主値と逆像を分ける

Log(−i) を求め、exp w = −i を満たす w をすべて挙げてください。Log(−1) はこの章で定義されていますか。

ヒント1：主値の角度

−i の偏角で (−π, π) に入るものは −π/2 です。

ヒント2：周期と切断

指数の逆像には2πiの整数倍を足せます。負の実軸は主値の定義域から除いています。

解答

Log(−i) = −πi/2、逆像は w = i(−π/2 + 2πk)、k はすべての整数です。−1は切断上なので Log(−1) は未定義です。ただし exp w = −1 の解は i(π + 2πk) として存在します。

2．複素三角関数の値域

cos(it) を実指数で表し、t > 0 のとき1より大きいことを示してください。

ヒント1：iを二回掛ける

i(it) = −t、−i(it) = t です。

ヒント2：1との差の符号

eᵗ + e⁻ᵗ − 2 = (exp(t/2) − exp(−t/2))² を使います。

解答

cos(it) = (eᵗ + e⁻ᵗ)/2。1との差は (exp(t/2) − exp(−t/2))²/2 で、t > 0 なら正です。複素入力でのcosは、実入力での値域 [−1, 1] に制限されません。

3．同じ点と、一周の記録

z(t) = 2exp(it)、0 ≤ t ≤ 2π とします。道に沿う値 ln 2 + it と主値 Log z(t) を、t = 0、π、2π で比較してください。

ヒント1：道の値は連続

t をそのまま虚部に使います。

ヒント2：主値の入力を確認する

t = π で点は −2、端点ではどちらも2です。

解答

道に沿う値は順に ln 2、ln 2 + πi、ln 2 + 2πi。主値は順に ln 2、未定義、ln 2 です。道の端点の値は2πi違いますが、主値は同じ点2で同じ値を返します。切断点を主値の連続な通過点とみなすことはできません。

4．指定された帯から逆像を選ぶ

exp w=−3i を満たし、π≤Im w<3π である w をすべて求めてください。この値は主値Log(−3i)と同じですか。

ヒント1：方針を選ぶ

長さからRe wを、偏角からIm wを決めます。

ヒント2：範囲を点検する

−π/2+2πk が指定区間に入る整数kを探します。

解答

全解はln3+i(−π/2+2πk)。π≤−π/2+2πk<3πから3/4≤k<7/4なのでk=1だけ、答えはln3+3πi/2です。主値はln3−πi/2で、差は2πi。指数を取ると両方とも−3iになるので、選んだ帯が違っても矛盾しません。

5．積の公式の前に式が定義できるか

(A) z=1+i,w=1−i と (B) z=1+i,w=−1+i について、Log z+Log w と Log(zw) を比較してください。

ヒント1：方針を選ぶ

個々の偏角と、積の位置を先に調べます。

ヒント2：範囲を点検する

Aの積は2、Bの積は−2です。

解答

Aは両方の長さが√2、偏角が±π/4なので主値の和はln2。積2の主値もln2で一致します。Bは偏角の和がπ/4+3π/4=π、主値の和はln2+πiですが、積−2は切断上なのでLog(zw)は未定義です。「差が2πi」とすら比較できない場合があるため、まず各式の定義域を調べます。

6．導関数が同じ枝を比較する

例題3の L(z)=Log(−z)+πi について、L(−1)とL′(−1)を求めてください。またL(−i)−Log(−i)とL(i)−Log(i)が違ってよい理由を説明してください。

ヒント1：方針を選ぶ

Lの定義域は正の実軸と0を除いたEです。

ヒント2：範囲を点検する

共通定義域D∩Eは上半平面と下半平面に分かれます。

解答

−1はEに入るのでL(−1)=Log1+πi=πi、L′(−1)=1/(−1)=−1。下側の−iで差は2πi、上側のiで差は0です。共通定義域が二つの部分に分かれるため、導関数が同じでも差の定数を平面全体で一つとする理由はありません。主値Log(−1)は依然未定義です。

7．合成した対数の定義域を設計する

F(z)=Log(z²) の定義域を座標で求めてください。Re z>0 ではF(z)=2Log zが成り立つことを示し、z=−1では右辺がどうなるか答えてください。

ヒント1：方針を選ぶ

z²=(x²−y²)+2ixy が0を含む負の実軸へ入る条件を求めます。

ヒント2：範囲を点検する

2xy=0 と x²−y²≤0 を同時に解きます。

解答

除く条件はx=0、すなわち虚軸全体です。したがって定義域は{x+iy:x≠0}。Re z>0ならArg z∈(−π/2,π/2)なので2Arg z∈(−π,π)、長さも|z²|=|z|²よりF(z)=2Log zです。z=−1ではF(−1)=Log1=0ですがLog(−1)は未定義で、右辺は書けません。合成の定義域を外側の関数だけから決めてはいけません。

8．平方根の枝と一周の障害

D上のS(z)=exp(Log z/2) とE上のS_E(z)=exp(L(z)/2) をz=−iで比較してください。さらに、穿孔平面全体で連続な平方根があると仮定すると、単位円の一周でなぜ矛盾しますか。

ヒント1：方針を選ぶ

Log(−i)=−πi/2、L(−i)=3πi/2を半分にします。

ヒント2：範囲を点検する

連続な平方根Rがあるとき、q(t)=R(exp(it))/exp(it/2) は連続でq(t)²=1です。

解答

S(−i)=(1−i)/√2、S_E(−i)=(−1+i)/√2で互いに逆符号、二乗はともに−iです。全体の連続なRを仮定するとqは値±1だけを取る連続関数なので区間[0,2π]で一定です。従ってR(exp(2πi))=−R(exp0)となりますが、両入力は1で同じ。R(1)²=1よりR(1)≠0なので矛盾します。連続な整数値が一定という本章の議論と同じ理由です。

9．複素三角方程式を指数へ戻す

複素数zに対する sin z=0 の解をすべて求めてください。複素入力でsinの絶対値が増えうることと矛盾しますか。

ヒント1：方針を選ぶ

定義式を使い、exp(iz)=exp(−iz) を指数の加法性でまとめます。

ヒント2：範囲を点検する

指数関数は0にならないのでexp(2iz)=1と同値です。

解答

exp(2iz)=1より2iz=2πik、kは整数。従ってz=πkが全解で、実数に限られます。逆にz=πkを代入するとsin z=0です。零になる場所が実軸上にあることは、他の複素入力で大きな値を取ることを妨げません。値域の大きさと零点の位置を別々に調べています。

  2. 主値Logが切断上で未定義であることと、指数の逆像が存在することは、なぜ両立しますか。
  3. 円に沿って連続に追った対数の値が、円上の点だけの関数にならないのはなぜですか。
