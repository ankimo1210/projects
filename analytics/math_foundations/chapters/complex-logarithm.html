指数関数の周期性と対数

実数の指数関数は単調なので、正の数から対数を一つに決められました。複素数の指数は回転も表します。一周分の角度を加えても同じ点へ戻るなら、指数を逆にたどるとき、その一周をどこへ記録すればよいでしょう。

前提は極形式と偏角、CRと実全微分の十分条件、実の指数関数と実の対数です。複素冪級数の項別微分は、まだ使いません。

複素指数関数の定義と性質

z = x + iy に対し、複素指数関数を次で定義します。右辺の指数、cos、sin は既に知っている実関数です。記号 eᶻ も同じ意味で使います。

exp(x+iy)=ex(cosy+isiny)

実部 x が長さ eˣ、虚部 y が角度を決めます。|exp z| = eˣ > 0 なので指数関数の値は0になりません。実指数の加法性と三角関数の加法定理から exp(z + w) = exp z exp w。特に exp(−z) は exp z の逆数です。

定義から正則性を確かめる

u = eˣ cos y、v = eˣ sin y とすると、uₓ = eˣ cos y = vᵧ、uᵧ = −eˣ sin y = −vₓ です。四つの偏導関数は連続なので、CRの十分条件を全平面で使えます。したがって exp は全平面で正則で、(exp z)′ = uₓ + ivₓ = exp z。複素指数の微分を、未証明の級数操作から導いていません。

exp z = exp w となる条件は、exp(z − w) = 1 です。絶対値から Re(z − w) = 0、単位円の座標から Im(z − w) = 2πk（k は整数）と分かります。つまり z − w = 2πik。指数関数の周期は、逆関数を平面全体で一つにできない原因です。

複素三角関数

複素数を角度に入れた cos、sin は、実の単位円だけでは定義できません。そこで、実数では成り立つ指数の組合せを、そのまま複素数での定義にします。

cosz=eiz+e−iz2,sinz=eiz−e−iz2i

実数への一致と微分を確認する

実数 t では exp(it) = cos t + i sin t、exp(−it) = cos t − i sin t なので、和と差は従来の実三角関数を返します。複素数でも指数関数の合成・和・定数倍は正則です。連鎖律で (exp(iz))′ = i exp(iz)、(exp(−iz))′ = −i exp(−iz)。定義を微分すれば (cos z)′ = −sin z、(sin z)′ = cos z です。

公式が似ていても、実数での値域まで同じではありません。t > 0 に対し sin(it) = i(eᵗ − e⁻ᵗ)/2 なので、その絶対値は t とともに限りなく増えます。「sinの絶対値は1以下」は実数の入力での性質です。定義を拡張したとき、どの性質が残るかは改めて確かめます。

主値対数と分枝切断

z ≠ 0 を r(cos θ + i sin θ) と書くと、exp w = z の解は w = ln r + i(θ + 2πk) です。ここで ln は正の実数の自然対数です。この解たちから、点 z ごとに連続につながる一つを選んだ関数を対数の枝と呼びます。

この本の主値対数の約束

D = ℂ ∖ (−∞, 0]、すなわち0を含む負の実軸を除いた開集合で、Arg z を (−π, π) にある唯一の偏角とします。主値対数を Log z = ln|z| + i Arg z と定めます。切断上の0と負の実数では、Arg も Log もこの定義では未定義です。±π のどちらかを切断上だけ付け足す約束は使いません。

この定義で exp(Log z) = z が成立します。逆に Log(exp w) = w は常に成り立つわけではありません。例えば w = 2πi なら exp w = 1、Log 1 = 0 です。−π < Im w < π の帯に制限すれば、指数と主値対数は互いの逆になります。

角度を取り出す実関数を準備する

実の区間 (−π/2, π/2) で tan θ = sin θ/cos θ と定めます。この区間では cos θ > 0。商の微分則から tan′ θ = (cos² θ + sin² θ)/cos² θ = 1 + tan² θ > 0 なので、平均値の定理により厳密に増加します。端へ近づくと sin θ はそれぞれ −1、1へ、cos θ は正の側から0へ近づくため、tan θ の極限はそれぞれ −∞、+∞。連続性と中間値の定理により、この tan は区間から ℝ への全単射です。その逆関数を arctan : ℝ → (−π/2, π/2) と定めます。

逆関数の連続性も確認します。t₀ = tan θ₀ とし、θ₀ ± ε が区間内にあるほど小さい ε > 0 を取ります。tan(θ₀ − ε) < t₀ < tan(θ₀ + ε) なので、t を t₀ に十分近づけるとこの二つの値の間に入ります。単調性より θ₀ − ε < arctan t < θ₀ + ε。したがって t → t₀ なら θ = arctan t → θ₀ です。

t ≠ t₀ なら単射性から θ ≠ θ₀ なので、逆関数の差商を次のように書けます。分母側の差商は既に微分可能な tan のものです。θ → θ₀ を使うと、その極限は 1 + tan² θ₀ = 1 + t₀² > 0 となり、逆数の極限も取れます。

arctant−arctant0t−t0=1tanθ−tanθ0θ−θ0→11+t02

これで arctan の微分可能性と (arctan t)′ = 1/(1 + t²) が示せました。この導関数は連続なので、arctan は実 C¹ です。逆関数が微分できることを先に仮定してはいません。

局所的な角度から、Logの微分を導く

D の各点では角度 θ を連続に選べます。具体的には x ≠ 0 の近くなら arctan(y/x) に一定の π の整数倍を足し、x = 0、y ≠ 0 の近くなら arctan(−x/y) に一定の ±π/2 を足せます。切断を避けた小近傍で、これが Arg と一致します。上で導いた arctan の微分式から、θₓ = −y/(x² + y²)、θᵧ = x/(x² + y²) です。

u = ln r = (1/2)ln(x² + y²) とすると uₓ = x/(x² + y²)、uᵧ = y/(x² + y²)。これらも角度の偏導関数も小近傍で連続です。CRの十分条件が成立するので、Log は D で正則です。導関数は次になります。

Log′z=xx2+y2−iyx2+y2=1z

ここで必要なのは小近傍での実 C¹ の角度です。切断を避けた各小近傍で arctan を使うことで得られ、平面全体で一つの角度を選べると仮定したわけではありません。

経路に沿う偏角と対数の多価性

円に沿って z(t) = r exp(it) と動くなら、ln r + it は t とともに連続で、指数を取ると z(t) です。これは道に沿って持ち上げた角度を使う値です。t = 0 と t = 2π は同じ点 z = r ですが、この値は 2πi 違います。したがって、円上の点だけで値が決まる一つの関数とは区別します。

円上の同じ点と、下の二つの虚部の高さを対応づけます。±180°では主値は切断上で未定義、±360°では点は出発点へ戻っても追跡値の虚部だけが±2π残ります。経路の履歴を持つ値は、穿孔平面全体の各点へ一価で連続な対数を定めたものではありません。

原点を除く平面全体では、連続な対数も作れない

連続な L : ℂ ∖ {0} → ℂ があり、exp(L(z)) = z を満たすと仮定します。単位円上で指数の逆像の形を使うと、L(exp(it)) = i(t + 2πk(t))、k(t) は整数です。左辺と t が連続なので k(t) も [0, 2π] で連続。連続な実関数が異なる整数を取れば中間値の定理で非整数も取るため、k は一定です。

すると t = 2π と t = 0 の値の差は2πi。しかし exp(2πi) = exp(0) = 1 だから、同じ関数 L の値は等しいはずです。矛盾により、この L は存在しません。特に、平面全体から原点だけを除いた集合で正則な対数はありません。

主値でも Log(zw) = Log z + Log w を無条件に使えません。z = w = exp(3πi/4) なら、右辺は 3πi/2、積は −i なので左辺は −πi/2 です。どれも切断外ですが、差は2πi。指数を取ると一致することと、選んだ枝の値が一致することは別です。次章ではこの一周分の違いを、積分で測ります。

寄り道［自作モデル］：平方根も、切れ目の選択を受け継ぐ

主値対数の定義域 D で S(z) = exp((1/2)Log z) と置きます。指数の加法性から S(z)² = z、連鎖律から S′(z) = S(z)/(2z) = 1/(2S(z)) です。0を除いているため分母は0になりません。これが一つの正則な平方根の枝です。

円を一周する道で角度を連続に追うと、半分の角度は π だけ変わり、平方根の符号が逆になります。同じ点へ戻ったときの値を一つに定めるには、対数と同じく定義域を選ぶ必要があります。実数の正の平方根を複素数へ延長すると、単なる符号の選択が道の問題になります。

出典：本章の主値対数と指数関数から作った数学的構成です。一般の多価関数の理論は前提にしていません。

演習：指数・対数と定義域

1．主値と逆像を分ける

Log(−i) を求め、exp w = −i を満たす w をすべて挙げてください。Log(−1) はこの章で定義されていますか。

ヒント1：主値の角度

−i の偏角で (−π, π) に入るものは −π/2 です。

ヒント2：周期と切断

指数の逆像には2πiの整数倍を足せます。負の実軸は主値の定義域から除いています。

解答

Log(−i) = −πi/2、逆像は w = i(−π/2 + 2πk)、k はすべての整数です。−1は切断上なので Log(−1) は未定義です。ただし exp w = −1 の解は i(π + 2πk) として存在します。

2．複素三角関数の値域

cos(it) を実指数で表し、t > 0 のとき1より大きいことを示してください。

ヒント1：iを二回掛ける

i(it) = −t、−i(it) = t です。

ヒント2：1との差の符号

eᵗ + e⁻ᵗ − 2 = (exp(t/2) − exp(−t/2))² を使います。

解答

cos(it) = (eᵗ + e⁻ᵗ)/2。1との差は (exp(t/2) − exp(−t/2))²/2 で、t > 0 なら正です。複素入力でのcosは、実入力での値域 [−1, 1] に制限されません。

3．同じ点と、一周の記録

z(t) = 2exp(it)、0 ≤ t ≤ 2π とします。道に沿う値 ln 2 + it と主値 Log z(t) を、t = 0、π、2π で比較してください。

ヒント1：道の値は連続

t をそのまま虚部に使います。

ヒント2：主値の入力を確認する

t = π で点は −2、端点ではどちらも2です。

解答

道に沿う値は順に ln 2、ln 2 + πi、ln 2 + 2πi。主値は順に ln 2、未定義、ln 2 です。道の端点の値は2πi違いますが、主値は同じ点2で同じ値を返します。切断点を主値の連続な通過点とみなすことはできません。
