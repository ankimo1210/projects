偏微分と座標方向の変化

高さ f(x, y) の地形を考えると、x だけを動かす道と、y だけを動かす道には、それぞれ一変数の傾きがあります。この二つを求めれば、地形の近くの様子を言い尽くせるでしょうか。前章の F は、軸上ではいつも 0 なのに、原点で不連続でした。切り口で分かることの範囲を確かめる必要があります。

まず片方を固定して、一変数の微分を行います。この偏微分は大切な部品ですが、二つの入力を同時に動かす近似は次章で別に定義します。

偏微分係数・偏導関数の定義

開集合 U ⊂ ℝ² 上の関数 f と、点 p = (a, b) ∈ U を考えます。開集合なので、十分小さい正負の h、k に対して (a + h, b)、(a, b + k) は U に入ります。

偏微分係数の定義

次の有限の極限が存在するとき、それぞれ x、y に関する偏微分係数と呼びます。

fx(a,b)=limh→0f(a+h,b)−f(a,b)h
fy(a,b)=limk→0f(a,b+k)−f(a,b)k

最初の商では b を固定し、二つ目では a を固定しています。商自体は h = 0、k = 0 で未定義です。一変数の微分と同じく、0 を代入せず、0 以外で計算して極限を取ります。

各点の偏微分係数を対応させた関数が偏導関数 fₓ、fᵧ です。∂f/∂x、∂f/∂y とも書きます。ある点に一つの係数が存在することと、その係数を並べた関数が近くで連続なことは、別の主張です。

多項式の偏微分と座標断面

P(x, y) = x² + xy + y² を定義から計算します。x 側では、b を一つの定数として扱います。

差の商を展開する

P(a+h,b)−P(a,b)h=2ah+h2+bhh=2a+b+h

h ≠ 0 での式です。h → 0 により Pₓ(a, b) = 2a + b。同様に k ≠ 0 で縦の差の商は a + 2b + k なので、Pᵧ(a, b) = a + 2b です。

従って Pₓ(x, y) = 2x + y、Pᵧ(x, y) = x + 2y。(1, 2) ではそれぞれ 4 と 5 で、横と縦の傾きは一致する必要がありません。既知の和・積の微分規則で照合しても、y を固定した xy の x 微分は y、y を固定すれば y² は定数なので、その x 微分は 0 となり、同じ式が出ます。

この二つの偏導関数は連続です。実際、入力の増分を (h, k)、距離を r とすれば、Pₓ の変化の絶対値は |2h + k| ≤ 3r、Pᵧ でも |h + 2k| ≤ 3r。どの点でも δ = ε/3 で連続性を示せます。この性質が、次章の十分条件を支えます。

偏微分の存在と連続性の反例

前章の F(x, y) = xy/(x² + y²)（原点以外）、F(0, 0) = 0 に戻ります。横軸と縦軸の関数値が 0 なのだから、そこでの傾きも計算できそうです。

存在する二つの極限と、存在しない全体の極限

h ≠ 0 で {F(h, 0) − F(0, 0)}/h = 0。よって Fₓ(0, 0) = 0 です。k ≠ 0 でも {F(0, k) − F(0, 0)}/k = 0 なので Fᵧ(0, 0) = 0。一方、t ≠ 0 で F(t, t) = 1/2 であり、原点の値 0 へ近づきません。従って F は原点で不連続です。

偏微分の存在が教えるのは、各座標軸に平行な二つの切り口に制限した関数が、その点で微分できることです。一変数では微分可能なら連続でしたが、ここで得られるのもまず切り口上の連続性です。円板内の全点の連続性へ、そのまま拡張することはできません。

「x と y について偏微分可能」という言い方を、「二つの偏微分係数が存在する」の意味で使う場合があります。次章の全微分可能とは区別してください。F は二つの偏微分があっても連続でない、という反例です。

関数の連続性と偏導関数の連続性

では、関数も連続なら十分でしょうか。G(x, y) = x²y/(x² + y²)（原点以外）、G(0, 0) = 0 は、|G(x, y)| ≤ ‖(x, y)‖ により原点で連続でした。軸上の値も 0 なので、原点の偏微分は両方 0 です。しかし、Gᵧ の値の分布を調べると違う様子が見えます。

原点の定義と、原点以外の計算を分ける

原点では差の商が 0 なので Gₓ(0, 0) = Gᵧ(0, 0) = 0。原点以外では、一方を固定した商を微分して次を得ます。

Gx(x,y)=2xy3(x2+y2)2,Gy(x,y)=x2(x2−y2)(x2+y2)2

商の法則も、ここでは既知の規則から確かめられます。分母 v が非零の点で、1/v の差の商は −{v(t + h) − v(t)}/[hv(t + h)v(t)] なので極限は −v′(t)/v(t)²。これと積の法則から (u/v)′ = (u′v − uv′)/v² です。分母 x² + y² は原点以外では正で、切り口の十分近くでも非零です。

上式の x 側の分子は 2xy(x² + y²) − 2x³y = 2xy³。y 側は x²(x² + y²) − 2x²y² = x²(x² − y²) となります。x ≠ 0、y = 0 を代入すると Gᵧ(x, 0) = 1。原点での 0 に近づかないため、Gᵧ は原点で連続ではありません。

G の連続性は高さの値が近づくこと、Gᵧ の連続性は縦の傾きの値が近づくことです。対象とする関数が違います。原点近くで G が小さくても、その近くの縦の傾きまで小さくなるとは限らないのです。

次の全微分の十分条件では、偏導関数の連続性を使います。二つの切り口の情報を、同時に動かした入力の近似へ結び付けるためです。

原点で比較する三つの性質
関数関数は連続か二つの偏微分偏導関数は連続か
F=xy/(x²+y²)×両方0×
G=x²y/(x²+y²)○両方0×（x≠0ではGᵧ(x,0)=1）
P=x²+xy+y²○両方0○

FとGの原点の値は0とします。高さの連続性と、近くの傾きの連続性は別の列です。全微分の保証へは次章で進みます。

寄り道［応用］：写真の横の変化と、縦の変化

OpenCV の公式チュートリアルは、Sobel 演算子を画像のエッジ検出に使う離散的な微分近似として説明しています。3 × 3 の係数を、横用には行ごとに (−1, 0, 1)、(−2, 0, 2)、(−1, 0, 1)、縦用には (−1, −2, −1)、(0, 0, 0)、(1, 2, 1) と並べます。

ここでは列が右へ x の正方向、行が下へ y の正方向とし、対応する係数と画素値を掛けて足します。小さい濃淡の格子が、上から (0, 1, 2)、(0, 1, 2)、(0, 1, 2) なら、中心で横用の和は 2 + 4 + 2 = 8、縦用は −4 + 4 = 0 です。明るさは右へ変わりますが、下へは変わりません。格子の行と列を入れ替える（転置する）と出力も 0 と 8 に入れ替わります。ここでは尺度の正規化をしていません。

これは有限個の画素の差分処理です。画素間隔を 0 へ近づけた極限を計算したわけではなく、画像そのものを連続な関数と同一視することもできません。それでも「一方の座標を動かした変化を、もう一方と分けて測る」という偏微分の見方は、二つの出力を読み解く助けになります。

偏微分と連続性の演習

1．定義から二つの傾きを出す

P(x, y) = x² + xy + y² の二つの偏微分を定義から求め、(1, 2) で評価してください。

ヒント1：一方は定数

x 側では y = b、y 側では x = a を固定します。

ヒント2：二次の増分を約分する

横の差は 2ah + h² + bh、縦の差は ak + 2bk + k² です。

解答

h ≠ 0 で横の差の商は 2a + b + h、従って極限は Pₓ(a, b) = 2a + b。k ≠ 0 で縦の差の商は a + 2b + k、従って Pᵧ(a, b) = a + 2b です。(1, 2) では Pₓ = 4、Pᵧ = 5。固定した変数を微分するのではありません。

2．偏微分可能なら連続か

F(x, y) = xy/(x² + y²)（原点以外）、F(0, 0) = 0 の原点での二つの偏微分と連続性を、それぞれ判定してください。

ヒント1：軸上で商を作る

F(h, 0)、F(0, k)、F(0, 0) はすべて 0 です。

ヒント2：連続性には別の経路を使う

t ≠ 0 で F(t, t) を計算します。

解答

二つの差の商は、非零の増分について常に 0。よって Fₓ(0, 0) = Fᵧ(0, 0) = 0 です。一方、F(t, t) = 1/2 であり、(t, t) → (0, 0) でも原点の値 0 へ近づかないので不連続です。二つの偏微分の存在は、二変数の連続性の十分条件ではありません。

3．高さは連続でも、傾きは飛ぶ

G(x, y) = x²y/(x² + y²)（原点以外）、G(0, 0) = 0 について、G は原点で連続でも Gᵧ はそこで連続でないことを示してください。

ヒント1：原点では定義へ戻る

Gᵧ(0, 0) は、G(0, k) = 0 を使えば求まります。

ヒント2：傾きの関数を軸上で見る

原点以外で Gᵧ = x²(x² − y²)/(x² + y²)² です。y = 0 としてください。

解答

|G(x, y)| ≤ |y| ≤ ‖(x, y)‖ により、δ = ε で G の原点での連続性が示せます。原点の縦の差の商は常に 0 なので Gᵧ(0, 0) = 0。一方、原点以外で商の法則を使うと Gᵧ = {x²(x² + y²) − 2x²y²}/(x² + y²)²。x ≠ 0 なら Gᵧ(x, 0) = 1 となり、原点へ近づいても Gᵧ(0, 0) = 0 に近づきません。従って Gᵧ は不連続です。
