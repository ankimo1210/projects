偏微分と座標方向の変化

高さ f(x, y) の地形を考えると、x だけを動かす道と、y だけを動かす道には、それぞれ一変数の傾きがあります。この二つを求めれば、地形の近くの様子を言い尽くせるでしょうか。前章の F は、軸上ではいつも 0 なのに、原点で不連続でした。切り口で分かることの範囲を確かめる必要があります。

まず片方を固定して、一変数の微分を行います。この偏微分は大切な部品ですが、二つの入力を同時に動かす近似は次章で別に定義します。

演習込みの目安は110–160分です。二つの切り口の計算から始め、同時に入力を動かす場合との差、関数値と傾きの連続性の差へ進みます。演習1–3は基本、4–7は条件と誤読の点検、8–10は情報の逆算と保証です。

偏微分係数・偏導関数の定義

開集合 U ⊂ ℝ² 上の関数 f と、点 p = (a, b) ∈ U を考えます。開集合なので、十分小さい正負の h、k に対して (a + h, b)、(a, b + k) は U に入ります。

偏微分係数の定義

次の有限の極限が存在するとき、それぞれ x、y に関する偏微分係数と呼びます。

fx(a,b)=limh→0f(a+h,b)−f(a,b)h
fy(a,b)=limk→0f(a,b+k)−f(a,b)k

最初の商では b を固定し、二つ目では a を固定しています。商自体は h = 0、k = 0 で未定義です。一変数の微分と同じく、0 を代入せず、0 以外で計算して極限を取ります。

各点の偏微分係数を対応させた関数が偏導関数 fₓ、fᵧ です。∂f/∂x、∂f/∂y とも書きます。ある点に一つの係数が存在することと、その係数を並べた関数が近くで連続なことは、別の主張です。

ここでの両側極限には、基準点の左右の入力が必要です。半径d>0の円板がUに入るなら、|h|<dで(a+h,b)、|k|<dで(a,b+k)が入ります。境界にあって片側しか使えない場合は、ここでの偏微分とは別に条件を定めます。「hを小さくする」ときにbまでhの関数に変えると、別の切り口を測ってしまいます。

例題：積の相手は、どの計算で定数になるか

W(x,y)=x²y+sin y を考えます。xについては y=b と固定するので、W(x,b)=bx²+sin b。よって Wₓ(a,b)=2ab です。yについては x=a と固定し、W(a,y)=a²y+sin y。今度は Wᵧ(a,b)=a²+cos b となります。「yだから定数」ではなく、「今どの変数で微分するか」が判断の基準です。

(a,b)=(2,0)なら、横の切り口は W(x,0)=0 で横の傾き0。縦の切り口は W(2,y)=4y+sin y で、基準点(2,0)、すなわちy=0での傾き5です。直接、非零のkで {W(2,k)−W(2,0)}/k=4+sin k/k→5 と照合できます。横の差の商は非零hで常に0です。両方の商に増分0を代入して答えを出すのではありません。

多項式の偏微分と座標断面

P(x, y) = x² + xy + y² を定義から計算します。x 側では、b を一つの定数として扱います。

差の商を展開する

P(a+h,b)−P(a,b)h=2ah+h2+bhh=2a+b+h

h ≠ 0 での式です。h → 0 により Pₓ(a, b) = 2a + b。同様に k ≠ 0 で縦の差の商は a + 2b + k なので、Pᵧ(a, b) = a + 2b です。

従って Pₓ(x, y) = 2x + y、Pᵧ(x, y) = x + 2y。(1, 2) ではそれぞれ 4 と 5 で、横と縦の傾きは一致する必要がありません。既知の和・積の微分規則で照合しても、y を固定した xy の x 微分は y、y を固定すれば y² は定数なので、その x 微分は 0 となり、同じ式が出ます。

この二つの偏導関数は連続です。実際、入力の増分を (h, k)、距離を r とすれば、Pₓ の変化の絶対値は |2h + k| ≤ 3r、Pᵧ でも |h + 2k| ≤ 3r。どの点でも δ = ε/3 で連続性を示せます。この性質が、次章の十分条件を支えます。

例題：接線の傾きと、有限幅の平均変化率

p=(1,2)でP=7でした。横の増分hに対して P(1+h,2)−7=4h+h²、縦の増分kに対して P(1,2+k)−7=5k+k²。非零の増分で割った商はそれぞれ4+h、5+kです。偏微分は、この商を0へ近づけた極限4、5であり、有限幅の変化そのものではありません。

例えばh=0.1なら P(1.1,2)=7.41なので差0.41、商4.1。h=−0.1ならP(0.9,2)=6.61なので差−0.39、商3.9。負の増分では差も分母も負になるので、商が負になるとは限りません。極限4は左右から同じ値になります。

表では増分の符号も含めて、左右から4と5へ近づく様子を比べてください。0の行には差の商を書かず、その極限値を区別しています。

非零増分hまたはk横の差の商4+h縦の差の商5+k読む際の区別

入力・出力とも本章では無単位です。横用と縦用で同じ数値の増分を使い、それぞれ別の切り口を計算しています。有限3例の並びだけで極限を証明したのではなく、本文の差の商4+h、5+kが両側の極限を与えます。

座標を同時に動かす変化と、固定する条件

二つの偏微分を求めた後に、「横と縦を一緒に動かせばどうなるか」という元の問いへ戻ります。ここではまだ一般の近似公式を仮定せず、Pを正確に展開して比較します。

例題：二つの切り口の傾きは、二次の混ざり方まで決めない

p=(1,2)から増分(h,k)だけ動かすと、P(1+h,2+k)−7=4h+5k+h²+hk+k² です。4hと5kは、基準点での二つの傾きからの予測。h²とk²は各切り口でも現れましたが、hkは二つを同時に変えたことで現れる項です。h=0またはk=0では、この項が見えません。

(h,k)=(0.1,−0.1)なら一次の予測は0.4−0.5=−0.1。残りは0.01−0.01+0.01=0.01なので、正確な変化は−0.09です。直接P(1.1,1.9)=1.21+2.09+3.61=6.91と計算しても、7との差は−0.09になります。

横を先に動かす別解では、最初の変化は0.41。次はx=1.1を固定するので、縦の傾きは基準点の5でなく、Pᵧ(1.1,2)=5.1です。縦の変化は5.1(−0.1)+(−0.1)²=−0.50。合計0.41−0.50=−0.09です。固定する座標の値は、どの切り口にいるかによって更新されます。

条件を変える：曲線上で二つの入力が連動する場合

f(x,y)=xy をp=(1,2)で考えます。y=2を固定すればf(x,2)=2xなので fₓ(1,2)=2。一方、y=2xという条件を課して動くとf(x,2x)=2x²で、そのx=1での一変数の微分は4です。同じ点を通っても、通る線が違うため答えは違います。

差の商でも、固定した切り口は {(1+h)2−2}/h=2、連動する切り口は {2(1+h)²−2}/h=4+2h→4 です。後者をfₓと呼ぶのは、yも動いていることを見落としています。一般に連動をどう扱うかは、次章の全微分と連鎖律で整理します。

偏微分の存在と連続性の反例

前章の F(x, y) = xy/(x² + y²)（原点以外）、F(0, 0) = 0 に戻ります。横軸と縦軸の関数値が 0 なのだから、そこでの傾きも計算できそうです。

存在する二つの極限と、存在しない全体の極限

h ≠ 0 で {F(h, 0) − F(0, 0)}/h = 0。よって Fₓ(0, 0) = 0 です。k ≠ 0 でも {F(0, k) − F(0, 0)}/k = 0 なので Fᵧ(0, 0) = 0。一方、t ≠ 0 で F(t, t) = 1/2 であり、原点の値 0 へ近づきません。従って F は原点で不連続です。

偏微分の存在が教えるのは、各座標軸に平行な二つの切り口に制限した関数が、その点で微分できることです。一変数では微分可能なら連続でしたが、ここで得られるのもまず切り口上の連続性です。円板内の全点の連続性へ、そのまま拡張することはできません。

「x と y について偏微分可能」という言い方を、「二つの偏微分係数が存在する」の意味で使う場合があります。次章の全微分可能とは区別してください。F は二つの偏微分があっても連続でない、という反例です。

関数の連続性と偏導関数の連続性

では、関数も連続なら十分でしょうか。G(x, y) = x²y/(x² + y²)（原点以外）、G(0, 0) = 0 は、|G(x, y)| ≤ ‖(x, y)‖ により原点で連続でした。軸上の値も 0 なので、原点の偏微分は両方 0 です。しかし、Gᵧ の値の分布を調べると違う様子が見えます。

原点の定義と、原点以外の計算を分ける

原点では差の商が 0 なので Gₓ(0, 0) = Gᵧ(0, 0) = 0。原点以外では、一方を固定した商を微分して次を得ます。

Gx(x,y)=2xy3(x2+y2)2,Gy(x,y)=x2(x2−y2)(x2+y2)2

商の法則も、ここでは既知の規則から確かめられます。分母 v が非零の点で、1/v の差の商は −{v(t + h) − v(t)}/[hv(t + h)v(t)] なので極限は −v′(t)/v(t)²。これと積の法則から (u/v)′ = (u′v − uv′)/v² です。分母 x² + y² は原点以外では正で、切り口の十分近くでも非零です。

上式の x 側の分子は 2xy(x² + y²) − 2x³y = 2xy³。y 側は x²(x² + y²) − 2x²y² = x²(x² − y²) となります。x ≠ 0、y = 0 を代入すると Gᵧ(x, 0) = 1。原点での 0 に近づかないため、Gᵧ は原点で連続ではありません。

G の連続性は高さの値が近づくこと、Gᵧ の連続性は縦の傾きの値が近づくことです。対象とする関数が違います。原点近くで G が小さくても、その近くの縦の傾きまで小さくなるとは限らないのです。

次の全微分の十分条件では、偏導関数の連続性を使います。二つの切り口の情報を、同時に動かした入力の近似へ結び付けるためです。

原点で比較する三つの性質
関数関数は連続か二つの偏微分偏導関数は連続か
F=xy/(x²+y²)×両方0×
G=x²y/(x²+y²)○両方0×（x≠0ではGᵧ(x,0)=1）
P=x²+xy+y²○両方0○

FとGの原点の値は0とします。高さの連続性と、近くの傾きの連続性は別の列です。全微分の保証へは次章で進みます。

例題：高さが縮んでも、近くの縦の傾きが縮まらない

Gの横軸上の基準点を (a,0)、a≠0 とします。縦の切り口は G(a,y)=a²y/(a²+y²)。y=k≠0で作る差の商は a²/(a²+k²) で、k→0なら1です。例えばa=0.01と小さくしても、この点での縦の傾きは1のままです。

対してa=0の縦の切り口は最初からG(0,y)=0で、原点の縦の傾きは0。先に基準点aを固定してkを0へ近づける計算と、基準点a自体を0へ近づける計算を取り違えないでください。高さの値が小さいことから、商で割った後の傾きまで小さいとは結論できません。

寄り道［応用］：写真の横の変化と、縦の変化

OpenCV の公式チュートリアルは、Sobel 演算子を画像のエッジ検出に使う離散的な微分近似として説明しています。3 × 3 の係数を、横用には行ごとに (−1, 0, 1)、(−2, 0, 2)、(−1, 0, 1)、縦用には (−1, −2, −1)、(0, 0, 0)、(1, 2, 1) と並べます。

ここでは列が右へ x の正方向、行が下へ y の正方向とし、対応する係数と画素値を掛けて足します。小さい濃淡の格子が、上から (0, 1, 2)、(0, 1, 2)、(0, 1, 2) なら、中心で横用の和は 2 + 4 + 2 = 8、縦用は −4 + 4 = 0 です。明るさは右へ変わりますが、下へは変わりません。格子の行と列を入れ替える（転置する）と出力も 0 と 8 に入れ替わります。ここでは尺度の正規化をしていません。

これは有限個の画素の差分処理です。画素間隔を 0 へ近づけた極限を計算したわけではなく、画像そのものを連続な関数と同一視することもできません。それでも「一方の座標を動かした変化を、もう一方と分けて測る」という偏微分の見方は、二つの出力を読み解く助けになります。

偏微分と連続性の演習

1．定義から二つの傾きを出す

P(x, y) = x² + xy + y² の二つの偏微分を定義から求め、(1, 2) で評価してください。

ヒント1：一方は定数

x 側では y = b、y 側では x = a を固定します。

ヒント2：二次の増分を約分する

横の差は 2ah + h² + bh、縦の差は ak + 2bk + k² です。

解答

h ≠ 0 で横の差の商は 2a + b + h、従って極限は Pₓ(a, b) = 2a + b。k ≠ 0 で縦の差の商は a + 2b + k、従って Pᵧ(a, b) = a + 2b です。(1, 2) では Pₓ = 4、Pᵧ = 5。固定した変数を微分するのではありません。

2．偏微分可能なら連続か

F(x, y) = xy/(x² + y²)（原点以外）、F(0, 0) = 0 の原点での二つの偏微分と連続性を、それぞれ判定してください。

ヒント1：軸上で商を作る

F(h, 0)、F(0, k)、F(0, 0) はすべて 0 です。

ヒント2：連続性には別の経路を使う

t ≠ 0 で F(t, t) を計算します。

解答

二つの差の商は、非零の増分について常に 0。よって Fₓ(0, 0) = Fᵧ(0, 0) = 0 です。一方、F(t, t) = 1/2 であり、(t, t) → (0, 0) でも原点の値 0 へ近づかないので不連続です。二つの偏微分の存在は、二変数の連続性の十分条件ではありません。

3．高さは連続でも、傾きは飛ぶ

G(x, y) = x²y/(x² + y²)（原点以外）、G(0, 0) = 0 について、G は原点で連続でも Gᵧ はそこで連続でないことを示してください。

ヒント1：原点では定義へ戻る

Gᵧ(0, 0) は、G(0, k) = 0 を使えば求まります。

ヒント2：傾きの関数を軸上で見る

原点以外で Gᵧ = x²(x² − y²)/(x² + y²)² です。y = 0 としてください。

解答

|G(x, y)| ≤ |y| ≤ ‖(x, y)‖ により、δ = ε で G の原点での連続性が示せます。原点の縦の差の商は常に 0 なので Gᵧ(0, 0) = 0。一方、原点以外で商の法則を使うと Gᵧ = {x²(x² + y²) − 2x²y²}/(x² + y²)²。x ≠ 0 なら Gᵧ(x, 0) = 1 となり、原点へ近づいても Gᵧ(0, 0) = 0 に近づきません。従って Gᵧ は不連続です。

演習4以降では、固定する座標、増分、微分した後の関数の三つを区別して式を書いてください。

4．同じ点を通る二つの切り口

f(x,y)=xy のp=(2,3)でfₓとfᵧを求めてください。y=3x/2を満たしながらxを動かしたときの一変数の微分も求め、fₓと違う理由を差の商で説明してください。

ヒント1

偏微分では他方の値を3または2に固定します。

ヒント2

条件付きの関数は(3/2)x²。x=2+hと置いて差を取ります。

解答

fₓ(2,3)=3、fᵧ(2,3)=2。条件付きでは f(x,3x/2)=(3/2)x²なので微分は3x、x=2で6です。差の商は {(3/2)(2+h)²−6}/h=6+(3/2)h→6。固定した切り口なら {(2+h)3−6}/h=3です。通る点が同じでも、yの固定と連動という条件が違います。h=0で商を評価してはいません。

5．偏微分0から一定といえるか

U(x,y)=(x−1)²+3(y−2) のp=(1,2)で二つの偏微分を求めてください。Uₓ(p)=0ならy=2の切り口はpの近くで一定、という説明を点検してください。

ヒント1

横の差の商はhです。

ヒント2

有限の横増分hで、値の差はh²です。

解答

Uₓ=2(x−1)、Uᵧ=3なのでpで0と3です。y=2ではU(1+h,2)−U(1,2)=h²。h=0.1なら0.01増えるため、切り口は一定ではありません。差の商hが0へ近づくことは、差がすべて0であることとは違います。例えばh=−0.1でも値は0.01増えますが、商は−0.1です。

6．一方だけ偏微分が存在する例

R(x,y)=|x|+y² のp=(0,1)で、二つの偏微分係数の存在を判定してください。

ヒント1

横の差の商には|h|/hが現れます。

ヒント2

縦の差の商は{(1+k)²−1}/kです。

解答

横の商はh>0で1、h<0で−1となり、両側極限が一致しないのでRₓ(0,1)は存在しません。縦の商はk≠0で2+kなのでRᵧ(0,1)=2です。一つの偏微分が存在しても、他方は別に検査が必要です。R自体は |R(h,1+k)−R(0,1)|≤|h|+2|k|+k²≤3r+r² によりpで連続です。

7．傾きを変えずに不連続にできるか

Fは本文の原点値0の関数とし、V_c(x,y)=2x−3y+cF(x,y) とします。原点の二つの偏微分が2と−3になる実数cをすべて求め、その中で原点に連続となるcも求めてください。

ヒント1

軸上ではF=0です。

ヒント2

対角線ではV_c(t,t)=−t+c/2です。

解答

軸上の差の商はx方向で2、y方向で−3なので、すべての実数cで指定の偏微分になります。c≠0なら対角線の値はc/2へ近づき、原点値0と一致しないため不連続。c=0なら |2x−3y|≤5r により連続です。したがって連続にする選択はc=0だけ。例えばc=2では二つの偏微分は同じままですが、対角線の値は1へ近づきます。

8．測った傾きから係数を復元する

Q(x,y)=ax²+bxy+cy²+d とします。Qₓ(1,0)=4、Qᵧ(1,0)=1、Qᵧ(0,1)=6、Q(0,0)=5 を満たす係数を求めてください。最後の高さの情報がない場合に何が決まらないかも説明してください。

ヒント1

まず二つの偏導関数を係数で表します。

ヒント2

Qₓ=2ax+by、Qᵧ=bx+2cy。定数dは微分で消えます。

解答

2a=4、b=1、2c=6よりa=2、b=1、c=3。原点値はdなのでd=5です。Q=2x²+xy+3y²+5と復元できます。検算するとQₓ(1,0)=4、Qᵧ(1,0)=1、Qᵧ(0,1)=6です。高さの条件がなければdは任意で、どれも同じ偏導関数を持ちます。傾きだけでは全体を上下へ移した違いを区別できません。

9．原点の傾きと近くの傾きを分ける

K(x,y)=x³/(x²+y²)（原点以外）、K(0,0)=0 とします。原点で連続であること、Kₓ(0,0)=1、Kᵧ(0,0)=0 を示してください。さらにb≠0でのKₓ(0,b)を定義で求め、Kₓが原点で連続か判定してください。

ヒント1

|K|≤|x|です。軸上ではK(x,0)=x、K(0,y)=0になります。

ヒント2

b≠0を固定した横の差の商はh²/(h²+b²)です。

解答

原点以外で |K|=|x|x²/(x²+y²)≤|x|≤r なので、δ=εで連続。原点の横の差の商はh/h=1、縦は0なので偏微分は1と0です。b≠0ではK(0,b)=0で、横の商はh²/(h²+b²)→0。従ってKₓ(0,b)=0です。(0,b)→(0,0)でも値は0のままで、原点値1に近づかずKₓは不連続。例えばb=0.01を固定してからh→0にした結果も0です。

10．二つの傾きに共通する精度を選ぶ

V(x,y)=x²y+y² のp=(1,2)で、VₓとVᵧの連続性を同じδで保証してください。すなわち、任意のε>0に対してr=√(h²+k²)<δなら、二つの偏導関数のpからの変化がともにε未満となるδを一つ選んでください。

ヒント1

Vₓ=2xy、Vᵧ=x²+2yです。基準値は4と5。

ヒント2

積の差を展開するとVₓの差は4h+2k+2hk、Vᵧの差は2h+h²+2kです。

解答

Vₓの差の絶対値は4|h|+2|k|+2|hk|≤6r+2r²、Vᵧの差は2|h|+h²+2|k|≤4r+r²です。r<1ならそれぞれ8r、5r以下。δ=min(1,ε/8) とすれば両方がε未満となります。零増分ではどちらの差も0。例えばε=0.1ならδ=0.0125で、h=0.003、k=−0.004ならr=0.005<δ。Vₓ(1.003,1.996)=4.003976、Vᵧ(1.003,1.996)=4.998009で、基準からの差は0.003976と−0.001991です。関数値Vそのものの変化とは別に、傾きの安定性を保証しました。
