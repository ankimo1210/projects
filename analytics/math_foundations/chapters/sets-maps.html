集合と写像の導入

x を二乗する操作を考えます。実数をすべて入れてよいなら、2 と −2 は同じ 4 へ移ります。入力を 0 以上に限れば、この重なりはなくなります。また、出力として負の数まで期待するかどうかで、「すべての出力を作れるか」という問いの答えも変わります。計算式だけでは、関数の性質は決まりません。

学習の目安は演習込み110–160分です。集合の所属を追う前半と、写像の性質・合成・逆写像を計算する後半に分けて読めます。演習1–3は基本、4–7は定義と操作の点検、8–10は条件の設計と証明です。

この章では、対象の集まりを集合として指定し、その間の対応を写像として扱います。微積分で関数を調べる前に、何を入力でき、どこに出力されるかを明確にするためです。量化記号と合わせると、「一つに決まる」「すべて届く」といった言葉も正確に読めるようになります。

集合・所属・包含と集合演算

集合は、どの対象が入っているかを区別して考える集まりです。x が A の要素であることを x ∈ A と書きます。{1, 2, 3} と {3, 2, 1, 1} は同じ集合です。順番と重複回数は記録しません。要素が一つもない集合が空集合 ∅ です。集合が等しいとは、入っている要素がまったく同じという意味です。

要素を列挙する代わりに、条件で集合を指定することもできます。実数全体を ℝ と書くと、{x ∈ ℝ：x ≥ 0} は「実数 x のうち、x ≥ 0 を満たすものを全て集める」という意味です。区切りの「：」の右側が集める条件です。この集合は区間の記号で [0, ∞) とも書き、0を含む全ての非負の実数を表します。∞はここでは実数の要素でなく、上へ限りなく続くという印です。

A のどの要素も B に入るとき、A は B の部分集合で、A ⊆ B と書きます。A 自身も A の部分集合です。「要素である」∈ と「部分集合である」⊆ は役割が異なり、1 ∈ {1, 2} と {1} ⊆ {1, 2} を区別します。前者は一つの対象、後者は集まりどうしの関係です。

A ∪ B は A または B に入る要素の集合、A ∩ B は両方に入る要素の集合です。全体の範囲 U を固定したとき、A の補集合は U に入るが A に入らない要素の集合です。補集合は U に依存します。たとえば A = {1, 2} の補集合は、U = {1, 2, 3} なら {3} ですが、U を整数全体に変えれば別の集合になります。

要素による集合の等式の証明

図の囲みを重ねると、いくつかの集合演算の等式を予想できます。しかし囲みの描き方に依存しない理由が必要です。集合が等しいとは要素が同じことなので、任意の一つの要素xを取り、その所属条件を言い換える方針を使います。AとBを同じ全体Uの部分集合とし、Uで取る補集合をAc、Bcと書きます。集合の差A∖Bは、Aに入るがBには入らない要素の集合です。

例題：和集合の補集合を言葉に戻す

(A∪B)c=Ac∩Bcを示します。任意のx∈Uについて、xが左辺に入る条件は「xはAまたはBに入る、ということがない」です。これは「xはAに入らず、かつBにも入らない」と同じです。補集合の定義に戻すと「x∈Acかつx∈Bc」、つまり右辺への所属です。

どの言い換えも逆向きにたどれるので、左辺の要素は右辺へ入り、右辺の要素も左辺へ入ります。二つの包含を一度に示しました。片方だけを示して集合の等式とするのは不十分です。この等式はド・モルガンの法則の一つで、前章の「または」の否定を集合で書いたものです。

同じ観点から∅⊆Aも確認できます。「∅に入るのにAに入らないx」は存在しないので、包含を崩す反例はありません。一方、∅∈AはAの要素に空集合そのものがあるかという別の話です。例えばA={∅}は要素が一つある集合であり、∅とは等しくありません。

写像の定義・単射・全射

写像 f：A → B は、A の各要素 x に対し、B の要素 f(x) をちょうど一つ定める対応です。A が定義域、B が終域です。実際に出力される値の集合 f(A) = {f(x)：x ∈ A} を像と呼びます。終域の要素がすべて出力されるとは限らないので、終域と像は分けて考えます。この本では実数値の写像を特に関数とも呼びます。

像の記号 {f(x)：x ∈ A} では、「Aに入る入力 x を全て動かし、その出力 f(x) を集める」と読みます。例えば A={−1,0,1}、f(x)=x² なら、出力は1,0,1ですが、集合として重複を除いた像は {0,1} です。

f：実数 → 実数、f(x) = x² なら、像は 0 以上の実数全体です。終域には −1 も入りますが、像には入りません。一方、f：実数 → 0 以上の実数、f(x) = x² と指定すれば、終域と像は一致します。「x に ±√x を対応させる」は x > 0 で出力が二つあるため、そのままでは写像の定義を満たしません。

異なる入力が異なる出力へ移る写像を単射といいます。同じことを「f(x₁) = f(x₂) なら x₁ = x₂」と書けます。終域のどの y に対しても、f(x) = y となる入力 x が少なくとも一つある写像を全射といいます。両方を満たせば全単射です。単射は重なりのなさ、全射は終域への届き方を述べています。

二乗の関数の四つの指定を、節末の表で比べます。入力の重なりをなくす変更と、終域へすべて届くようにする変更は、別の役割を持ちます。ここでは非負の実数に一意な非負の平方根があるという、実数の性質を使っています。

表の「逆写像」は、出力 y から元の入力 x をただ一つ選び直す対応を意味します。二つの入力が同じ出力へ重なると選び直せず、終域に届かない出力があるとそこから戻れません。単射と全射の両方が必要になる理由です。次節では、全単射から逆写像を作り、行って戻る合成が元に戻ることを確かめます。

定義域の制限と逆写像の構成

二乗の表では、定義域を制限すると重なりを取り除けました。今度は式から逆写像を作るところまで自分で進めます。f(x)=(x−2)²とし、定義域A=[2,∞)、終域B=[0,∞)とします。Aは2以上の実数全体です。まず、どのx∈Aでもf(x)≥0なので、指定した終域へ値を返す写像になっています。

例題：方程式を解くだけで逆写像と呼べるか

全射を示すには、任意のy∈Bを渡されたとして、(x−2)²=yを解きます。形式的にはx=2±√yですが、x≥2という条件があるのでx=2+√yを選びます。これならAに入り、代入してf(2+√y)=(√y)²=y。従ってどのyにも届きます。

単射は、f(x₁)=f(x₂)から示します。x₁−2、x₂−2はともに非負なので、平方が等しければx₁−2=x₂−2、従ってx₁=x₂です。したがってfは全単射で、逆写像はf⁻¹(y)=2+√y、B→Aとなります。「±」のままでは一つの出力を返さず、逆写像にはできません。

実数tの絶対値|t|を、t≥0ならt、t<0なら−tとします。行って戻る計算も二方向で確認します。f(f⁻¹(y))=(2+√y−2)²=y。逆のf⁻¹(f(x))=2+√((x−2)²)=2+|x−2|=xです。ここではx≥2だから|x−2|=x−2です。平方根と二乗を条件なしに消したのではありません。x=3ならf(3)=1、逆で2+√1=3へ戻ります。

定義域を2以下の実数全体へ変えると、同じ終域Bへの全単射になりますが、今度の逆写像は2−√yです。すべての実数を入れる元の式では、1と3がともに1へ移るので逆写像を作れません。逆の式の符号は好みで選ぶのでなく、元の定義域が決めます。また、f⁻¹と逆数1/fは操作が異なります。例えば同じ入力3に対してf⁻¹(3)=2+√3ですが、1/f(3)=1です。記号の−1乗が、ここでは対応を逆にすることを意味している点に注意しましょう。

写像の合成と逆写像

f：A → B と g：B → C を順に使う写像を合成と呼び、g ∘ f：A → C、(g ∘ f)(x) = g(f(x)) と定めます。右の f を先に使います。f の出力を g が受け取れることが必要です。式だけをつなぎ、入力の範囲を忘れると、途中で定義されない計算を作ってしまいます。

単射どうしの合成は単射

f：A → B、g：B → C がともに単射なら、g ∘ f も単射です。

短い証明

x₁、x₂ ∈ A について g(f(x₁)) = g(f(x₂)) とします。g が単射なので f(x₁) = f(x₂)。さらに f が単射なので x₁ = x₂ です。合成の出力が等しいときに入力も等しいことが示せたので、合成は単射です。

全射どうしの合成も全射です。任意の z ∈ C に対し、g の全射性で g(y) = z となる y ∈ B を取り、次に f の全射性で f(x) = y となる x ∈ A を取ればよいからです。二段階で届く先を、順にたどっています。

全単射なら、各 y ∈ B からそれを生む唯一の x ∈ A へ戻る逆写像 f⁻¹：B → A が作れます。存在を保証するのが全射、ただ一つを保証するのが単射です。f⁻¹(f(x)) = x、f(f⁻¹(y)) = y が成り立ちます。ここで f⁻¹ は逆数 1/f ではありません。二乗の逆を平方根とするにも、まず非負の範囲へ制限する必要があります。

合成の順序と逆写像の順序

合成の記号を覚えるには、各段階の入力と出力を実際に書くのが確実です。f：ℝ→ℝをf(x)=x+1、g：ℝ→ℝをg(x)=3xとします。どちらも全実数で定義され、出力も実数なので、どちらの順番でも途中で定義されなくなることはありません。

例題：二つの操作を順に使い、順に戻す

fを先に使うならx→x+1→3(x+1)で、(g∘f)(x)=3x+3。gを先に使うならx→3x→3x+1で、(f∘g)(x)=3x+1です。例えばx=0でも前者は3、後者は1。従って一般にg∘fとf∘gは同じではありません。矢印を読む順序と、記号を右から作用させる順序が対応しています。

h=g∘fを戻すには、最後に掛けた3を先に戻し、それから足した1を引きます。h(x)=yを直接解けば3x+3=y、3x=y−3、x=y/3−1です。一方f⁻¹(y)=y−1、g⁻¹(y)=y/3なので、h⁻¹=f⁻¹∘g⁻¹となり、順番が逆になります。

二方向の検算はh(y/3−1)=3(y/3−1)+3=yと、h⁻¹(3x+3)=(3x+3)/3−1=xです。もし誤ってg⁻¹∘f⁻¹とすると(y−1)/3で、hに戻すとy+2となり、元に戻りません。式の見た目ではなく、操作をどの順で取り消したかで判断します。

この順序の理由は一般の全単射でも同じです。fの出力をgが受け取るなら、結果から最初に戻す先はgの入力で、その後にfの入力へ戻ります。逆写像を作る前には各写像の全単射性と、合成の途中の範囲を確認します。本文の定理は単射の合成を保証しますが、逆方向の主張で何が言えるかは演習9で考えます。

寄り道［つながり］：どんなファイルも小さくする圧縮は作れない

圧縮したファイルを必ず元に戻したいなら、異なる入力が同じ圧縮結果になることは許されません。圧縮は単射でなければならないのです。DEFLATE 形式を記述する RFC 1951 も、すべての入力を圧縮できる方式はないと、数え上げを理由に述べています。

理由を自分で数えてみましょう。n 桁の 0、1 の列は 2ⁿ 通り。一方、n 桁未満の列は、空の列も入れて 1 + 2 + ⋯ + 2ⁿ⁻¹ = 2ⁿ − 1 通りしかありません。全部を短くしようとすると、少なくとも二つが同じ出力へ重なり、元に戻せなくなります。よく縮むデータがある一方、縮まないデータも必要になる。これは開発者の工夫不足ではなく、対応の個数から分かる限界です。

出典：RFC 1951：DEFLATE、1.1 Purpose。

演習：集合演算と写像の性質

1．要素を一つずつ追う

U = {1, 2, 3, 4, 5}、A = {1, 2, 4}、B = {2, 3} とします。A ∪ B、A ∩ B、U における A の補集合を求めてください。

ヒント1：「または」と「かつ」を分ける

和集合はどちらかにある要素、共通部分は両方にある要素です。

ヒント2：補集合は U の中で探す

U の五つの要素のうち、A にないものだけを残します。

解答

A ∪ B = {1, 2, 3, 4}、A ∩ B = {2}、A の補集合は {3, 5} です。5 は和集合には入らず、補集合には入ります。

2．二乗の三つの指定

f(x) = x² の定義域・終域を、①実数・実数、②実数・非負実数、③非負実数・非負実数とした場合に、単射か全射かを判定してください。

ヒント1：単射を崩す二入力を探す

1 と −1 が同時に定義域に入るか確認します。

ヒント2：全射では任意の出力から戻る

y ≥ 0 なら √y が入力の候補です。負の y には候補がありますか。

解答

①は単射でも全射でもありません。②は全射ですが単射ではありません。③は全単射です。③の単射性は x₁² = x₂² より (x₁ − x₂)(x₁ + x₂) = 0、非負であることから x₁ = x₂ と分かります。全射性は y ≥ 0 に入力 √y を選べば示せます。

3．合成が全単射なら、途中も全単射か

A = {a}、B = {b, c}、C = {d} とし、f(a) = b、g(b) = g(c) = d とします。f、g、g ∘ f の単射性と全射性を調べてください。

ヒント1：使われない要素を見る

f の出力として c は現れますか。g では入力の重なりがありますか。

ヒント2：合成は一要素どうし

合成の入力は a だけ、終域の要素は d だけです。

解答

f は単射ですが c に届かないため全射ではありません。g は全射ですが b、c が同じ d に移るため単射ではありません。合成は a を d に移す全単射です。したがって合成が全単射でも、途中の写像がそれぞれ全単射とは限りません。

4．要素と部分集合を分けて判定する

A={∅,{1}}とします。①∅∈A、②∅⊆A、③{1}∈A、④{1}⊆Aの真偽を判定し、Aの要素数も答えてください。

ヒント1

Aの要素として列挙されている対象は、空集合と集合{1}の二つです。

ヒント2

{1}⊆Aなら、数1そのものがAの要素でなければなりません。

解答

①真、②真、③真、④偽。①と③は列挙された対象そのものです。②は空集合には包含を崩す要素がないため真。④は1∉Aなので偽です。Aの要素は二つで、∅と{1}は別の集合です。中括弧を外して数1を要素と数えたり、空集合を無視して一要素にしたりしません。

5．もう一つのド・モルガンの法則

A、B⊆Uとします。(A∩B)c=Ac∪Bcを、任意のx∈Uの所属条件から証明してください。有限集合の一例だけの確認で終えないようにします。

ヒント1

xが左辺に入るとは「Aに入り、かつBに入る」の否定です。

ヒント2

「かつ」の否定は「少なくとも一方が成り立たない」です。

解答

任意のx∈Uについて、x∈(A∩B)cであることは、xがAとBの両方に入るわけではないこと、すなわちx∉Aまたはx∉Bと同値です。これはx∈Acまたはx∈Bc、従ってx∈Ac∪Bcと同値です。どの段階も逆向きにたどれるため、両辺は同じ要素を持ちます。補集合はすべて同じUで取っています。

6．式が書けても写像とは限らない

①f：ℝ→ℝ、f(x)=1/x、②g：ℝ→[0,∞)、g(x)=x−1、③h：[0,∞)→ℝ、h(x)=√xのうち、指定された写像として定義できるものを選んでください。定義できないものは、式を変えずに定義域または終域を変更して修正してください。

ヒント1

各入力に一つの値が定まり、すべて終域に入る必要があります。

ヒント2

①はx=0、②はx=0を点検します。③では非負の平方根を取ります。

解答

③だけがそのままで写像です。①は0で割るため値が定まらず、定義域をℝ∖{0}へ変えればℝへの写像になります。②はg(0)=−1が終域に入らないので不適切です。終域をℝへ変えるか、定義域を[1,∞)へ制限すれば修正できます。修正は一意ではありません。終域を変える操作は未定義の割り算を直せず、①では定義域の変更が必要です。

7．整数から整数への一次式

整数全体をℤと書きます。f：ℤ→ℤ、f(n)=2n+1について、像、単射性、全射性を調べてください。式を変えずに全単射にする終域も指定してください。

ヒント1

出力はすべて奇数です。逆にどの奇数もこの形で書けますか。

ヒント2

単射では2n₁+1=2n₂+1を解きます。終域に0を残すと全射になれません。

解答

像は奇数全体{2k+1：k∈ℤ}です。任意の奇数2k+1は入力kで作れるので、含まれるだけでなく一致します。2n₁+1=2n₂+1なら2n₁=2n₂、n₁=n₂で単射。一方0へ届かず、ℤへの全射ではありません。終域を奇数全体へ変えれば全単射で、逆写像はy→(y−1)/2です。yが奇数なのでこの値は整数になり、二方向の合成も元に戻ります。

8．二乗の逆を別の枝で作る

f(x)=(x−2)²で、定義域を2以下の実数全体、終域を[0,∞)とします。全単射性と逆写像を示し、x=−1とy=9を用いて二方向の合成を検算してください。

ヒント1

yから戻る候補2±√yのうち、定義域に入るものを選びます。

ヒント2

x≤2なら√((x−2)²)=2−xです。

解答

任意のy≥0へx=2−√y≤2を選ぶとf(x)=yなので全射です。x₁,x₂≤2で平方が等しければ、非負の2−x₁と2−x₂が等しく、x₁=x₂なので単射。逆写像はf⁻¹(y)=2−√yです。f(−1)=9、f⁻¹(9)=−1で戻ります。一般にもf(f⁻¹(y))=(−√y)²=y、f⁻¹(f(x))=2−(2−x)=x。平方根をx−2と取り違えるとこの枝では戻れません。

9．合成から必ず分かる性質

f：A→B、g：B→Cとします。①g∘fが単射ならfは単射、②g∘fが全射ならgは全射を証明してください。gが単射、fが全射まで言えるかは、演習3の例で点検してください。

ヒント1

①はf(x₁)=f(x₂)から始めます。②は任意のz∈Cに対する合成の入力を使います。

ヒント2

①では両辺へgを作用させられます。②ではz=g(f(x))の中のf(x)がBに入ります。

解答

①f(x₁)=f(x₂)ならg(f(x₁))=g(f(x₂))。合成が単射なのでx₁=x₂、従ってfは単射です。②任意のz∈Cに対し、合成の全射性からg(f(x))=zとなるx∈Aがあります。y=f(x)∈Bを取ればg(y)=zなのでgは全射です。演習3では合成は全単射ですが、gは単射でなく、fは全射でありません。合成が使わないBの要素に起きる重なりや未到達は、合成の性質だけでは取り除けません。

10．逆算から定義域と終域を設計する

f(x)=(2x+1)/(x−1)とします。定義域をℝ∖{1}とし、終域を実数から一つだけ除いて全単射にしたいとします。除くべき値と逆写像を求め、分母が0にならないこと、二方向に戻ることを確認してください。

ヒント1

y=(2x+1)/(x−1)からxを解きます。y=2の場合は元の等式が成立しますか。

ヒント2

(y−2)x=y+1なのでx=(y+1)/(y−2)。このxについてx−1=3/(y−2)です。

解答

f(x)=2なら2x+1=2(x−1)から1=−2となり不可能なので、2を除きます。任意のy≠2に対しx=(y+1)/(y−2)は実数で、x−1=3/(y−2)≠0、従って定義域に入ります。代入すると2x+1=3y/(y−2)なのでf(x)=yです。この逆算はyごとに唯一のxを定めるため全単射で、f⁻¹(y)=(y+1)/(y−2)です。またf(x)−2=3/(x−1)≠0、f(x)+1=3x/(x−1)なのでf⁻¹(f(x))=x。y=0なら逆は−1/2、f(−1/2)=0となり、具体的にも検算できます。
