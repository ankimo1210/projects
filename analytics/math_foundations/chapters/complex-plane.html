複素数と複素平面

平面上の点 (3, 4) は、「横へ3、縦へ4」という二つの数で位置を表しています。この点を原点 (0, 0) のまわりに回すと、横と縦の値はどちらも変わります。二つの座標の変化を、まとめて扱う方法はないでしょうか。

ここで使う数を、定義から確認します。虚数単位と呼ぶ数 i を用意し、実数と同じ交換・結合・分配法則に、i² = −1 という規則を加えて計算します。実数を二乗しても負にはならないので、i は実数にはない新しい数です。実数 a、b を使って a + bi と表す数が複素数です。実数も a + 0i として含まれます。複素数全体を表す記号が ℂ です。二つの複素数 a + bi と c + di が等しいのは、a = c、b = d の両方が成り立つときです。

複素数 a + bi を、平面上の点 (a, b) と一対一に対応させます。この対応で数を表した平面を複素平面と呼びます。横の軸が実軸、縦の軸が虚軸です。例えば 3 + 4i は点 (3, 4)、i = 0 + 1i は点 (0, 1)、0 は原点を表します。

では、3 + 4i に i を掛けてみます。分配法則で展開し、i² を −1 に置き換えます。

(3+4i)i=3i+4i2=−4+3i

結果の −4 + 3i は点 (−4, 3) です。一般の a + bi でも i(a + bi) = −b + ai となり、点 (a, b) は (−b, a) へ移ります。これは回転行列 R(π/2)と同じ座標の変化です。なぜ反時計回り90度の回転なのかは、この後の極形式の節で、長さと角度の計算からも確かめます。

この章では、この数と点の対応から出発し、点どうしの距離、掛け算による向きと長さの変化、平面上で「近づく」ことの意味を順に調べます。次章の複素微分で必要になる、どの方向から近づいても同じ結果になるという条件を準備します。

複素数の四則演算、複素数の絶対値と距離、回転と複素数の積を復習したいときは、既習の章に戻れます。実数の極限を距離で述べた考え方も、平面へ広げて使います。

学習の目安は演習を含めて110–160分です。距離の条件を式にするところまで、極形式と変換の逆算、開集合・極限と演習の三回に分けても構いません。演習1–3は基礎、4–6は計算と設計、7–9は定義域と極限の方針を扱います。

複素絶対値とユークリッド距離

点の位置を数で書けたので、次は「どれだけ離れているか」を数にします。一般の複素数を z = x + iy と書くとき、x、y は実数です。これは先ほどの a + bi で文字を変え、yi と iy の順序を入れ替えた同じ表し方です。横の座標 x を実部、縦の座標 y を虚部といい、それぞれ Re z、Im z と書きます。虚部は実数 y であり、iy 全体ではありません。

原点から点 (x, y) までの直線距離は、三平方の定理で √(x² + y²) です。この長さを複素数 z の絶対値と呼び、|z| と書きます。例えば |3 + 4i| = √(3² + 4²) = 5 です。実数 x なら |x + 0i| = √(x²) = |x| となり、従来の絶対値と一致します。

もう一つの点 w = u + iv までの距離は |z − w| と書けます。差が (x − u) + i(y − v) なので、|z − w| = √((x − u)² + (y − v)²)。これは平面の二点を直線で結んだ長さ、すなわちユークリッド距離です。

長さを計算するときに役立つ操作が共役です。z = x + iy に対して、虚部の符号を変えた x − iy を z̄ と書き、z の共役と呼びます。複素平面では実軸に関する反射です。共役との積を使うと、長さと演算を結び付けられます。

これからの証明で使う共役の性質を確かめます。z = x + iy、w = u + iv なら、zw = (xu − yv) + i(xv + yu)。その共役は (xu − yv) − i(xv + yu) で、z̄w̄ を展開した結果と一致します。つまり、積の共役は、各共役の積です。

また、w = u + iv では w + w̄ = 2u = 2 Re w、Re w = u ≤ |u| ≤ √(u² + v²) = |w| です。どの複素数にも成り立つので、z w̄ にも当てはめられます。和の長さの二乗を展開すると現れる z w̄ と w z̄ は互いの共役なので、足すと 2 Re(z w̄) にまとまります。基礎の章で成分から調べた絶対値の性質を、ここでは共役を使って示し直し、後で使う z z̄ = |z|² と結び付けます。

zz¯=|z|2,|zw|=|z||w|,|z+w|≤|z|+|w|

掛け算と足し算を、長さで読む

共役の積は z z̄ = (x + iy)(x − iy) = x² + y²。また、共役は積を保つので |zw|² = zw z̄w̄ = |z|²|w|² です。非負の平方根を取れば積の式になります。和については |z + w|² = |z|² + 2 Re(z w̄) + |w|²。Re(z w̄) ≤ |z w̄| = |z||w| より、右辺は (|z| + |w|)² 以下です。これが三角不等式です。

線形代数との接続：係数と次元

実数の組全体を ℝ² と書きます。複素数の集合 ℂ と ℝ² は、a + bi と (a, b) の対応で一対一に結べます。複素数には、この対応に加えて複素数どうしの積の規則があります。

選んだ基本の数に係数を掛けて足すことで、どの数も一通りに表せるとき、その基本の数の組を基底と呼びます。基底の個数が次元です。

数を組み立てるとき、実数だけを掛けて足すなら z = x·1 + y·i で、基底は 1 と i の二つです。この意味で ℂ は実数上で二次元です。複素数を係数として使ってよいなら z = z·1 で、基底は 1 一つになり、複素数上では一次元です。「何を係数として使うか」をそろえて次元を比べます。次章で複素数の掛け算を実2×2行列で読むときにも、この二つの見方を使います。

一方、ℂ² は複素数の組 (z₁, z₂) 全体です。各成分に二つずつ、計四つの実数の座標が必要になります。例えば (1 + i, 2 − 3i) には、(1, 1, 2, −3) という四つの実数の座標が対応します。基底の意味は基底・次元と次元定理で確認できます。

距離の条件から点の集合を求める

絶対値は長さを出すだけでなく、「同じ距離にある」「こちらに近い」という条件を式へ移す道具になります。条件を満たすすべての点の集合を軌跡と呼びます。ここでは入力を z=x+iy、定義域を複素平面全体として調べます。

例題1：1と i から等距離の点はどこか

|z−1|=|z−i| を満たす z をすべて求めます。図の見た目から直線を予想しても、すべての点で成り立つことはまだ分かりません。両辺は非負なので、二乗しても条件は同値です。平方根を外し、座標の式にする方針を選びます。

|z−1|²=(x−1)²+y²、|z−i|²=x²+(y−1)² です。等しいと置いて展開すると、x²−2x+1+y²=x²+y²−2y+1。共通の項を消して −2x=−2y、つまり y=x となります。逆に y=x なら両辺の平方は等しく、距離も等しいので、答えは直線 {x+ix : xは実数} 全体です。

さらに「1の方に近い」なら |z−1|<|z−i|。平方の差は −2x+2y なので y<x です。等距離の直線は境界となり、不等号が厳密ならその直線を含みません。点1では y=0<1=x なので、どちら側かの検算もできます。

極形式と複素数の積

掛け算で長さと向きがどう変わるかを見るため、同じ点を「原点からの長さ」と「向き」で指定してみます。z ≠ 0 の長さを r = |z| > 0、正の実軸から点 z の方向まで、反時計回りを正として測った角度を θ とすると、横の座標は r cos θ、縦の座標は r sin θ です。したがって z = r(cos θ + i sin θ) と書けます。これを極形式、角度 θ を z の偏角と呼びます。

角度には、円弧の長さを半径で割って測るラジアンを使います。一周は 2π、反時計回りの90度は π/2 です。同じ方向に一周加えても点は変わらないので、θ + 2πk（k は整数）も偏角になります。偏角は、角度の取り方を指定しなければ一つには決まりません。原点 z = 0 には、向きを決める偏角はありません。

もう一つの0でない複素数 w も、長さ s = |w| > 0 と偏角 φ を使って表します。この書き方で二つの数を掛けると、長さと角度は次のように変わります。

z=r(cosθ+isinθ),w=s(cosφ+isinφ)⇒zw=rs(cos(θ+φ)+isin(θ+φ))

積を展開すると、実部は rs(cos θ cos φ − sin θ sin φ)、虚部は rs(sin θ cos φ + cos θ sin φ) です。実の三角関数の加法定理で、それぞれ rs cos(θ + φ)、rs sin(θ + φ) になります。固定した w ≠ 0 を掛ける操作は、長さを s 倍し、角度を φ だけ回します。w = 0 のときは全点が原点へつぶれ、回転角という説明は使えません。

冒頭の i は、i = cos(π/2) + i sin(π/2) と表せる、長さ1・偏角 π/2 の複素数です。したがって i を掛けると長さは変わらず、角度だけが π/2 増えます。(3, 4) から (−4, 3) への移動が反時計回り90度の回転になる理由が、これで角度からも確かめられました。

数 w を固定した掛け算も、入力 z から出力 wz を定める一つの規則でした。このように、許された複素数の入力ごとに複素数の出力を一つ定める規則を複素関数と呼びます。ほかにも、入力 z を二乗する関数は z ↦ z²、逆数を返す関数は z ↦ 1/z と書きます。「↦」は、その入力がどの出力へ移るかを表します。逆数では入力0を除く必要があり、こうした入力を許す範囲が定義域です。定義域を E とすれば f : E → ℂ と書きます。違う入力が同じ出力を持つことはあります。

逆数と二乗の幾何

z ≠ 0 で 1/z = z̄/|z|²。長さは 1/r、偏角は −θ です。二乗 z² の長さは r²、偏角は 2θ です。二乗は各点に同じ数を掛ける線形変換とは異なり、掛ける数 z 自体が入力とともに変わります。

逆数が定義できる条件を確かめる

z·z̄/|z|² = 1 なので逆数の式が成立します。分母が正であるために z ≠ 0 が必要です。極形式で共役を取ると sin の符号だけが変わり、長さの r を r² で割れば 1/r となります。二乗の式は上の積で w = z とすれば得られます。

複素数の積から変換を逆算する

極形式は、計算の後に角度を説明するだけでなく、実現したい変換を決めるためにも使えます。固定した数 q を掛ける関数 T(z)=qz と、入力ごとに掛ける数が変わる z² を区別して使います。

例題2：1+i を −2+2i へ移す倍率と角度を決める

T(z)=qz が T(1+i)=−2+2i を満たすように q を選びます。未知なのは出発点でも終点でもなく、掛ける数です。1+i≠0 なので割り算で一意に求められます。

q=(−2+2i)/(1+i)=(−2+2i)(1−i)/2。分子を展開すると −2+2i+2i−2i²=4i なので q=2i です。これは長さ2、偏角 π/2 の数です。したがって、平面全体を2倍し反時計回り90°回す変換になります。検算すると 2i(1+i)=−2+2i、別の点 −i では T(−i)=2 です。

別の求め方では、長さの比が |−2+2i|/|1+i|=(2√2)/√2=2、偏角の差が 3π/4−π/4=π/2 です。代数と幾何が同じ q を返します。ただし出発点が0で終点が非零なら q·0=0 に反し、設計できません。0を0へ送る条件だけなら、q は一つに決まりません。

例題3：二乗の出力から入力をすべて復元する

z²=3+4i を解きます。偏角の半分を取る方法もありますが、3+4i の角度は簡単な π の倍数ではありません。今回は成分と長さを併用する方が短く、角度を小数で近似せずに済みます。

z=x+iy とすると x²−y²=3、2xy=4。さらに |z²|=|z|² であり |3+4i|=5 なので x²+y²=5 です。和と差から 2x²=8、2y²=2、よって x=±2、y=±1。条件 xy=2 に戻すと符号は同じで、z=2+i または −2−i だけが残ります。

(2+i)²=4+4i−1=3+4i、(−2−i)²=(2+i)² と検算できます。平方の条件だけで符号を四通り残すと、2−i と −2+i が混ざります。これらの二乗は3−4iで、元の虚部の符号を満たしません。極形式で見ると、二つの正しい入力は長さ√5で向きが π 違い、二乗すると同じ点へ重なります。

例題2は非零の入力を一つ指定すると q が一意になる問題、例題3は非零の出力に二つの入力が対応する問題でした。関数が入力ごとに一つの出力を持つことと、出力から入力を一つに戻せることは別の条件です。

開集合・領域と複素極限

関数の変化を調べるには、入力をある点に近づけることを考えます。数直線と違い、平面では左右だけでなく、どの方向からも近づけます。そこで、点 a の周りにある点を、距離の節で定めた |z − a| でまとめて表します。

a を中心とする半径 r > 0 の開円板を D(a, r) = {z : |z − a| < r} と書きます。中括弧の中は、「a からの距離が r 未満である点 z をすべて集める」という意味です。境界 |z − a| = r は含めません。

集合 U のどの点 a を選んでも、ある半径 r > 0 の開円板 D(a, r) が U の中に収まるとき、U を開集合と呼びます。円板の半径は、点ごとに変えて構いません。また、a を中心とする開円板を一つでも含む集合を、a の近傍と呼びます。近傍そのものが円板である必要はありません。次章で「その近傍で正則」と述べるときも、一点だけでなく周囲の範囲を含むという意味で使います。

複素関数 f : E → ℂ の入力 z を、点 a へ近づけます。a 自体は定義域 E に入っていなくてもよく、a のどれほど近くにも、a とは異なる E の点があるとします。このような a を E の集積点といいます。多変数の極限と同じ条件です。出力の行き先の候補を複素数 L として、距離 |f(z) − L| を小さくできるか調べます。

どんな許容誤差 ε > 0 に対しても、ε に応じてある δ > 0 を選ぶことができ、E 内のすべての zについて 0 < |z − a| < δ なら |f(z) − L| < ε となるとき、limz→a f(z) = L と書き、L を f の a における極限と呼びます。一つ選んだ δ は、その範囲内のすべての z に同時に使います。

条件の 0 < |z − a| は、a 自体を除いて周囲の点を調べるという意味です。f が a で定義されていなくても、この極限は考えられます。

これに対して、連続性では a ∈ E として、a 自身の値 f(a) と比べます。どんな ε > 0 に対しても、ある δ > 0 を選べて、E 内のすべての z について |z − a| < δ なら |f(z) − f(a)| < ε となるとき、f は a で連続です。この条件では z = a も含めます。

a が E の集積点でもあるときは、連続性は limz→a f(z) = f(a) と同値です。一方、E = {a} のように近づく他の入力がない場合も、連続性の条件は使えます。唯一の入力 z = a では出力の差が0なので、どんな ε にも条件を満たします。

E が開集合で a ∈ E の場合は、δ を十分小さく取れば a の周りの円板全体が E に入り、あらゆる方向からの近づき方が条件に含まれます。開集合では各点が集積点なので、連続性は極限との一致で調べられます。一般の E では、E の中から可能なすべての近づき方を調べます。例えば原点を除く平面なら、f が原点で未定義でも、0以外の点を原点へ近づけられます。後の z̄/z の例と、次章の h ≠ 0 で定義する差商は、この形です。

例えば z² の連続性は |z² − a²| = |z − a||z + a| から分かります。|z − a| < 1 に制限すれば |z + a| ≤ 2|a| + 1 なので、ε に対し δ = min(1, ε/(2|a| + 1)) と取れます。こうして、全方向で同じ評価を与えることで連続性を示せました。

この極限は、出力の実部と虚部をそれぞれ近づけることとも同値です。その理由は、差 f(z) − L を一つの複素数としてみると、各成分の絶対値は差全体の絶対値以下であり、差全体の絶対値は二つの成分の絶対値の和以下だからです。二つの成分がともに0へ近づけば、差全体も0へ近づき、逆向きも成り立ちます。

ただし、入力の近づき方については全方向を調べる必要があります。実軸上だけで極限が存在しても不十分です。例えば z̄/z（z ≠ 0）は、実軸では z̄ = z なので1、虚軸では z̄ = −z なので−1となります。同じ原点に近づくのに出力が食い違うため、原点で極限を持ちません。

ここまでは一点への近づき方を調べました。これから積分を扱うときには、二点の間を許された集合の中で移れるかも考えます。後の複素対数や複素線積分では切断した領域、Cauchyの積分定理では開いた凸領域を使います。こうした条件を読むために、まず集合全体のつながりを表す連結と、領域の意味を定めます。

集合 S の部分集合 A が相対開集合であるとは、周囲の空間の開集合 V を使って A = S ∩ V と書けることです。例えば数直線上の区間 S = [0, 1] では、[0, 1/2) = S ∩ (−1, 1/2) は相対開集合です。数直線全体で見ると0の左側を含まないので開集合ではありませんが、S の内側を基準にすると0の周囲にある点も含んでいます。後の証明でも S = [0, 1] の形を使います。平面の集合を扱うときは、V に平面の開集合を使います。これは、A の各点 p について、ある r > 0 で S ∩ D(p, r) が A に入ると言い換えられます。

集合が連結であるとは、空でない二つの相対開集合で、互いに交わらず、合わせると全体になるようには分けられないことです。空でない連結な開集合を領域と呼びます。定義域 E も、この三つの条件を満たすときには領域になります。平面の開集合では、どの二点も集合内の連続な曲線で結べることと同値ですが、この同値の証明はここでは使いません。

例えば U = D(2, 1) ∪ D(−2, 1) は、離れた二つの開円板です。A = D(2, 1)、B = D(−2, 1) とすると、両者は交わらず、合わせると U になります。A = U ∩ D(2, 1)、B = U ∩ D(−2, 1) と書けるため、A、B は U の相対開集合です。定義どおり二つに分けられるので、U は連結ではありません。開集合であることだけでは、つながりは保証されないのです。

円板が領域になる理由を、次の証明で確かめます。二点 a、b の間を γ(t) = (1 − t)a + tb（0 ≤ t ≤ 1）で動くと、t = 0 で a、t = 1 で b になります。どの二点を選んでもこの線分全体が集合内に入る性質が凸です。証明中の γ⁻¹(A) は逆関数ではなく、「γ(t) が A に入る t をすべて集めた集合」を表す逆像の記号です。線形代数での点の逆像では出力を一点に固定しましたが、ここでは出力が集合 A に入る入力を集めています。

次の証明では、凸な開集合 U が相対開集合 A、B に分かれたと仮定し、P = γ⁻¹(A)、Q = γ⁻¹(B) と置きます。γ(t) が A に入るなら、その点の周りの小円板を U の中に限った部分も A に入ります。|γ(s) − γ(t)| = |b − a||s − t| なので、s を [0, 1] 内で t に十分近づければ γ(s) もその部分に入ります。U は凸なので、γ(s) は U の中にあります。したがって P は [0, 1] の相対開集合であり、Q も同じです。これが、証明で連続性から逆像の開性へ進む理由です。

また、sup P は P の上限、すなわち最小の上界です。P の要素であるとは限りません。実数の完備性と上限を使い、二つに分けた境目で矛盾を作ります。

凸な開集合は、連結である

任意の二点 a、b を結ぶ線分 γ(t) = (1 − t)a + tb（0 ≤ t ≤ 1）が集合内に入ることを凸といいます。空でない凸な開集合 U が、空でない相対開集合 A、B に分離できたと仮定し、a ∈ A、b ∈ B を取ります。|γ(t) − γ(s)| = |b − a||t − s| より γ は連続なので、その逆像 P = γ⁻¹(A)、Q = γ⁻¹(B) は [0, 1] の相対開集合です。両者は交わらず区間全体を覆い、0 ∈ P、1 ∈ Q です。

c = sup P と置きます。0でのPの開性と1でのQの開性から 0 < c < 1。c ∈ P なら開性により c より少し大きい点もPに入り、上限に反します。c ∈ Q なら開性により c の少し手前までQに入りますが、上限の定義により c へ任意に近いPの点が存在し、やはり矛盾します。区間がPとQで覆われる以上どちらかの場合なので、この分離は不可能です。したがってUは連結です。

開円板、平面全体、右半平面 {z : Re z > 0} は空でない凸な開集合なので領域です。開円板の凸性は三角不等式、右半平面の凸性は実部の一次性から確かめられます。原点を除く平面も領域ですが、その連結性は本章では証明しない標準事実として借ります。離れた二つの円板の和集合は開集合ですが、領域ではありません。穴があることと、連結でないことは別です。

次章では、この全方向の極限を差商へ適用します。

寄り道［自作モデル］：回転と拡大を、何度も繰り返す

毎回同じ倍率 ρ > 0、同じ角度 θ で矢印を動かすモデルを考えます。q = ρ(cos θ + i sin θ) と置けば、n回後は zₙ = qⁿz₀。積の規則から |zₙ| = ρⁿ|z₀| で、偏角は初期角に nθ を足したものです。ρ < 1 なら原点へ縮み、ρ = 1 なら同じ円上、ρ > 1 なら z₀ ≠ 0 のとき長さが増えます。

θ = π/2、ρ = 1/2、z₀ = 1 なら、1、i/2、−1/4、−i/8、1/16 と進みます。四回で向きは戻りますが、点そのものは戻りません。向きと大きさを別に読むことが、反復の見通しを作ります。行列ならρR(θ)の反復と同じです。

出典：本章の積の規則から作った数学モデルです。実際の装置や観測データを表すものではありません。

演習：複素平面と複素関数

1．逆数の向きと長さ

z = 3 + 4i の逆数を求め、絶対値の積が1になることを確かめてください。

ヒント1：共役を使う

分子と分母に 3 − 4i を掛けます。

ヒント2：長さの平方

|3 + 4i|² = 25 です。

解答

1/z = (3 − 4i)/25 = 3/25 − (4/25)i。元の絶対値は5、逆数の絶対値は √(9 + 16)/25 = 1/5 なので積は1です。共役により偏角の符号が反転し、長さは逆数へ変わります。

2．二乗で見分けられない二点

z² = −4 の解をすべて求め、極形式で二点の向きの違いを説明してください。

ヒント1：長さを先に決める

|z|² = 4 なので |z| = 2 です。

ヒント2：角度は2倍になる

2θ = π + 2πk から、θ を 2π の違いまで区別します。

解答

θ = π/2 + πk なので、異なる点は 2i と −2i の二つです。両者の向きは π 違いますが、2倍すると差が 2π となり同じ向きになります。代数でも z² + 4 = (z − 2i)(z + 2i) = 0 より、この二つで尽くされています。

3．軸だけ調べてよいか

原点以外で F(x + iy) = xy/(x² + y²) とします。原点へ向かう二軸と直線 y = x で値を比べ、極限の有無を判断してください。

ヒント1：二軸の分子

x = 0 または y = 0 なら分子は0です。

ヒント2：対角線で約分する

x = y = t ≠ 0 を代入します。

解答

二軸では0、対角線では t²/(2t²) = 1/2 です。原点へいくら近づけても値が異なるので極限は存在しません。二軸の極限の一致は、全方向の極限が存在するための十分条件ではありません。

4．虚部と共役を取り違えない

z=(2+i)/(1−2i) を計算し、Re z、Im z、z̄、|z| を求めてください。「虚部は i である」という答案の誤りも説明してください。

ヒント1：方針を選ぶ

分母の共役1+2iを掛けます。

ヒント2：条件へ戻す

(2+i)(1+2i)=5i、(1−2i)(1+2i)=5です。

解答

z=i=0+1i。Re z=0、Im z=1、z̄=−i、|z|=1です。虚部は i の係数である実数1で、i全体ではありません。i(1−2i)=2+i と掛け戻すと割り算も検算できます。

5．距離の二条件を同時に満たす

|z−1|=|z−i| かつ |z|=√2 を満たす z をすべて求めてください。

ヒント1：方針を選ぶ

例題1の等距離条件を座標に直します。

ヒント2：条件へ戻す

y=x を x²+y²=2 に代入し、両方の符号を残します。

解答

y=x なので2x²=2、x=±1です。答えは1+iと−1−i。どちらも絶対値√2で、1とiからの距離はそれぞれ1と√5です。二点の間で距離が同じという条件ではなく、各点から1とiへの二距離が等しいという条件です。

6．二つの指定を同時に実現できるか

T(z)=qz が T(1+i)=−2+2i と T(2)=4i を同時に満たせるか調べてください。二つ目が T(2)=4 ならどうなりますか。

ヒント1：方針を選ぶ

最初の指定だけで q を決めます。

ヒント2：条件へ戻す

同じ q を二つ目へ代入し、指定ごとに別の q を選ばないようにします。

解答

最初の指定から例題2と同じく q=2i。T(2)=4i なので元の二指定は実現できます。二つ目を4へ変えると2q=4からq=2が必要になり、q=2iと両立しません。一つの固定乗算で実現できるかは、全指定に同じ q が使えるかで判定します。

7．定義域の中に円板を設計する

U=ℂ∖{2}、a=1+i とします。D(a,r) が U に含まれる半径 r>0 の条件を求めてください。r=√2 は使えますか。

ヒント1：方針を選ぶ

除いた点2と中心aの距離を求めます。

ヒント2：条件へ戻す

円板の境界は含めません。rが距離より大きい場合も調べます。

解答

|a−2|=|−1+i|=√2。0<r≤√2 なら点2は円板に入らないのでD(a,r)⊂Uです。r>√2 なら2が入るため不可能です。r=√2では2は境界上であり、開円板には含まれません。中心が2自身なら、どのr>0も使えません。

8．極限の誤差から半径を逆算する

f(z)=z²、a=1+i とします。0<ε≤1 に対し、|z−a|<δ なら |z²−a²|<ε を保証する δ を一つ具体的に選んでください。

ヒント1：方針を選ぶ

|z²−a²|=|z−a||z+a| とし、まず|z−a|<1で残りを抑えます。

ヒント2：条件へ戻す

|a|=√2、|z+a|≤|z−a|+2|a| を使います。

解答

δ=ε/(2√2+1) と取れます。0<ε≤1よりδ<1なので、|z+a|<1+2√2。したがって |z²−a²|<δ(1+2√2)=ε です。これは一つの十分な選び方で、最大のδを求めたわけではありません。a²=2iへの全方向の極限を同時に保証します。

9．二軸の検査から全方向の評価へ

原点以外で H(x+iy)=xy²/(x²+y²) とします。二軸で0だから極限も0、という論証の不足を述べたうえで、本当に極限が0になることを示してください。

ヒント1：方針を選ぶ

演習3のFと同じく、二軸の一致だけでは十分でありません。全点に使える絶対値の上界を探します。

ヒント2：条件へ戻す

0≤y²/(x²+y²)≤1、|x|≤|z| です。

解答

二軸以外の経路が未検査なので、提示された論証だけでは結論は出ません。しかし |H(z)|≤|x|≤|z|。任意のε>0にδ=εとすれば0<|z|<δから|H(z)|<εで、極限は0です。演習3のFは対角線で1/2でしたが、Hは対角線でもt/2→0です。経路の列挙でなく、全方向共通の評価が証明を完結させます。
