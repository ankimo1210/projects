複素数と複素平面

点 (3, 4) を原点のまわりに回すとき、二つの座標を別々に計算する方法があります。ところが、3 + 4i という一つの数へ i を掛ければ、結果は −4 + 3i。90度の回転が、一回の掛け算になりました。座標を数として扱うと、図形の変換や変化率にどんな見通しが生まれるのでしょう。

前提は複素数と四則演算、絶対値、回転と複素数の積です。実数の極限と同様に、近づくことを距離で定め直します。

複素絶対値とユークリッド距離

複素数 z = x + iy の実部を Re z = x、虚部を Im z = y と書きます。虚部は実数 y であり、iy 全体ではありません。共役は z̄ = x − iy、絶対値は |z| = √(x² + y²) です。点 z と w の距離を |z − w| とすると、いつもの平面の距離と一致します。

zz¯=|z|2,|zw|=|z||w|,|z+w|≤|z|+|w|

掛け算と足し算を、長さで読む

共役の積は z z̄ = (x + iy)(x − iy) = x² + y²。また、共役は積を保つので |zw|² = zw z̄w̄ = |z|²|w|² です。非負の平方根を取れば積の式になります。和については |z + w|² = |z|² + 2 Re(z w̄) + |w|²。Re(z w̄) ≤ |z w̄| = |z||w| より、右辺は (|z| + |w|)² 以下です。これが三角不等式です。

集合として ℂ と ℝ² は同じ座標で対応します。しかし、複素数の積という追加の規則があります。ℂ は実数上では二次元、複素数上では一次元です。ℂ² と書くと複素数の組 (z₁, z₂) なので、実数では四つの座標が必要です。ℂ と ℝ² の対応を、ℂ² と ℝ² が同じ次元という意味に取り違えないでください。

極形式と複素数の積

z ≠ 0 なら r = |z| > 0 とし、z = r(cos θ + i sin θ) と表せます。これを極形式、θ を偏角と呼びます。角度はラジアンで測ります。同じ点に θ + 2πk（k は整数）も対応するため、偏角は指定なしには一つに決まりません。z = 0 では長さは0ですが、方向を決める偏角はありません。

z=r(cosθ+isinθ),w=s(cosφ+isinφ)⇒zw=rs(cos(θ+φ)+isin(θ+φ))

証明は積を展開し、実の三角関数の加法定理を使うだけです。固定した w ≠ 0 を掛ける操作は、長さを s 倍し、角度を φ だけ回します。w = 0 のときは全点が原点へつぶれ、回転角という説明は使えません。

逆数と二乗の幾何

z ≠ 0 で 1/z = z̄/|z|²。長さは 1/r、偏角は −θ です。二乗 z² の長さは r²、偏角は 2θ です。二乗は各点に同じ数を掛ける線形変換とは異なり、掛ける数 z 自体が入力とともに変わります。

逆数が定義できる条件を確かめる

z·z̄/|z|² = 1 なので逆数の式が成立します。分母が正であるために z ≠ 0 が必要です。極形式で共役を取ると sin の符号だけが変わり、長さの r を r² で割れば 1/r となります。二乗の式は上の積で w = z とすれば得られます。

開集合・領域と複素極限

a を中心とする半径 r > 0 の開円板を D(a, r) = {z : |z − a| < r} と書きます。集合 U の各点 a に対して、ある D(a, r) が U に含まれるとき、U は開集合です。a の近傍とは、このような開円板を含む集合です。円板の境界 |z − a| = r は開円板に含めません。

開集合 U 上の関数 f について、a ∈ U で limz→a f(z) = L とは、任意の ε > 0 に対し、ある δ > 0 があり、0 < |z − a| < δ なら |f(z) − L| < ε となることです。十分小さい円板を U 内に取ります。a 自体での値は極限に使いません。極限が f(a) と一致するとき、f は a で連続です。ℝ² と同じ距離なので、実部と虚部の極限を別々に確かめることとも同値です。

二つの成分が0へ行けば複素絶対値も |Re z| + |Im z| 以下なので0へ行きます。逆に各成分の絶対値は |z| 以下です。この二つの不等式が同値性の根拠です。全方向の条件なので、実軸上だけで極限が存在しても不十分です。例えば z̄/z（z ≠ 0）は実軸で1、虚軸で−1となり、原点で極限を持ちません。

領域とは、空でない連結な開集合です。連結とは、二つの空でない、互いに交わらない相対開集合に分けられないことです。平面の開集合では道でつながることとも同値ですが、この同値の証明はここでは使いません。

凸な開集合は、連結である

任意の二点 a、b を結ぶ線分 γ(t) = (1 − t)a + tb（0 ≤ t ≤ 1）が集合内に入ることを凸といいます。空でない凸な開集合 U が、空でない相対開集合 A、B に分離できたと仮定し、a ∈ A、b ∈ B を取ります。|γ(t) − γ(s)| = |b − a||t − s| より γ は連続なので、その逆像 P = γ⁻¹(A)、Q = γ⁻¹(B) は [0, 1] の相対開集合です。両者は交わらず区間全体を覆い、0 ∈ P、1 ∈ Q です。

c = sup P と置きます。0でのPの開性と1でのQの開性から 0 < c < 1。c ∈ P なら開性により c より少し大きい点もPに入り、上限に反します。c ∈ Q なら開性により c の少し手前までQに入りますが、上限の定義により c へ任意に近いPの点が存在し、やはり矛盾します。区間がPとQで覆われる以上どちらかの場合なので、この分離は不可能です。したがってUは連結です。

開円板、平面全体、右半平面 {z : Re z > 0} は空でない凸な開集合なので領域です。開円板の凸性は三角不等式、右半平面の凸性は実部の一次性から確かめられます。原点を除く平面も領域ですが、その連結性は本章では証明しない標準事実として借ります。離れた二つの円板の和集合は開集合ですが、領域ではありません。穴があることと、連結でないことは別です。

半径 r>0 の開円板は |z−a|<r です。開集合とは各点の周囲に小円板が入り、領域とは空でない連結な開集合をいいます。同じ図に点が二つあることと、集合がつながっていることは別です。極限を調べるときも、定義域内の全ての近づき方を相手にし、二本の軸だけの一致では全方向の極限を保証できません。

例えば z² の連続性は |z² − a²| = |z − a||z + a| から分かります。|z − a| < 1 に制限すれば |z + a| ≤ 2|a| + 1 なので、ε に対し δ = min(1, ε/(2|a| + 1)) と取れます。図で滑らかに見えることを、全方向で同じ評価へ置き換えました。次章では、この全方向の極限を差商へ適用します。

寄り道［自作モデル］：回転と拡大を、何度も繰り返す

毎回同じ倍率 ρ > 0、同じ角度 θ で矢印を動かすモデルを考えます。q = ρ(cos θ + i sin θ) と置けば、n回後は zₙ = qⁿz₀。積の規則から |zₙ| = ρⁿ|z₀| で、偏角は初期角に nθ を足したものです。ρ < 1 なら原点へ縮み、ρ = 1 なら同じ円上、ρ > 1 なら z₀ ≠ 0 のとき長さが増えます。

θ = π/2、ρ = 1/2、z₀ = 1 なら、1、i/2、−1/4、−i/8、1/16 と進みます。四回で向きは戻りますが、点そのものは戻りません。向きと大きさを別に読むことが、反復の見通しを作ります。行列ならρR(θ)の反復と同じです。

出典：本章の積の規則から作った数学モデルです。実際の装置や観測データを表すものではありません。

演習：複素平面と複素関数

1．逆数の向きと長さ

z = 3 + 4i の逆数を求め、絶対値の積が1になることを確かめてください。

ヒント1：共役を使う

分子と分母に 3 − 4i を掛けます。

ヒント2：長さの平方

|3 + 4i|² = 25 です。

解答

1/z = (3 − 4i)/25 = 3/25 − (4/25)i。元の絶対値は5、逆数の絶対値は √(9 + 16)/25 = 1/5 なので積は1です。共役により偏角の符号が反転し、長さは逆数へ変わります。

2．二乗で見分けられない二点

z² = −4 の解をすべて求め、極形式で二点の向きの違いを説明してください。

ヒント1：長さを先に決める

|z|² = 4 なので |z| = 2 です。

ヒント2：角度は2倍になる

2θ = π + 2πk から、θ を 2π の違いまで区別します。

解答

θ = π/2 + πk なので、異なる点は 2i と −2i の二つです。両者の向きは π 違いますが、2倍すると差が 2π となり同じ向きになります。代数でも z² + 4 = (z − 2i)(z + 2i) = 0 より、この二つで尽くされています。

3．軸だけ調べてよいか

原点以外で F(x + iy) = xy/(x² + y²) とします。原点へ向かう二軸と直線 y = x で値を比べ、極限の有無を判断してください。

ヒント1：二軸の分子

x = 0 または y = 0 なら分子は0です。

ヒント2：対角線で約分する

x = y = t ≠ 0 を代入します。

解答

二軸では0、対角線では t²/(2t²) = 1/2 です。原点へいくら近づけても値が異なるので極限は存在しません。二軸の極限の一致は、全方向の極限が存在するための十分条件ではありません。
