等式制約下の極値問題

単位円 x²+y²=1 の円周だけを動きながら f(x,y)=x+2y を大きくしたいとします。平面全体なら勾配 (1,2) に沿って増やせますが、その方向へ進むと円周から外れるかもしれません。動ける接線方向に、増やす余地がなくなるのはどこでしょうか。

大きく、または小さくしたい量 f を目的関数と呼びます。ここでは g(x,y)=x²+y² と置き、g=1を満たす点だけを比較します。このように、動ける点を等式 g(x,y)=c で限定する条件が等式制約です。cは指定した一定の値です。円から外れて増える方向は、制約上の比較には入りません。

接線と勾配の直交から Lagrange の乗数方程式を導きます。方程式が与えるのは極値の候補です。最大・最小の存在や、候補が実際に最適であることは、別に確かめます。

例題：円周から外れない動きを、実際に作る

出発点p=(1,0)で目的関数は1です。勾配(1,2)へ直線的にεだけ動いた(1+ε,2ε)は、ε>0ならx²+y²=1+2ε+5ε²>1で、比較を許された点ではありません。制約付きの問いでは「値が増える」前に「そこへ動ける」を確かめます。

接線は、曲線の最初の動きを表す

円周に残る道としてγ(s)=(√(1−s²),s)、−1<s<1を取ります。二つの平方の和は正確に1で、γ(0)=p、γ′(0)=(0,1)。目的関数をこの道へ代入すると F(s)=√(1−s²)+2s となり、F′(0)=2です。従って正の小さいsでは目的関数を増やせます。

「接線方向へ動く」とは、円の外側の直線(1,s)をそのまま進んでよいという意味ではありません。この道では横成分が √(1−s²)−1=−s²/(1+√(1−s²)) だけ内側へずれます。この二次の補正によって円周を保ち、一次の変化率は縦成分の2が決めています。

数値でもs=3/5を代入するとγ=(4/5,3/5)、F=4/5+6/5=2です。制約も16/25+9/25=1。これはpでまだ増やせる具体例です。一方、増加率2という局所の情報だけから、s=3/5が最適点だとは言えません。円周上ではこの点より高い値√5も得られます。

円周の任意の点p=(x,y)では、単位接線T=(−y,x)に沿う一次の変化率は(1,2)·T=−y+2xです。これが正ならT向きに、負なら−T向きに増やす余地があります。0で初めて候補になります。下の乗数方程式は、この「残る接線の増加率が0」を、制約の勾配を使って書く道具です。

演習を含む学習の目安は110–160分です。明示曲線から必要条件を導く部分、候補を別の方法で保証する例、正則性・端点・存在の診断の三回に分けて読めます。

正則な曲線による制約の表示

開区間 I 上の C¹ 曲線 γ : I → ℝ² を考えます。γ の二成分がともに C¹ で、t₀ ∈ I、γ(t₀) = p、γ′(t₀) ≠ 0 のとき、その点で正則なパラメータ曲線と呼びます。速度が非零なので、進む接線方向が定まります。

例えば円周は γ(t) = (cos t, sin t)、t ∈ ℝ と書けます。γ′(t) = (−sin t, cos t) の長さは常に 1 なので、全ての点で正則です。t₀ は開区間の内点とし、道の始点・終点だけの片側の極値は、以下の必要条件には含めません。

曲線上の極値と接線方向の必要条件

明示された曲線に沿う必要条件

γ が t₀ で正則、γ(t₀) = p、f が p の開近傍で定義され p で全微分可能とします。f ∘ γ が t₀ で局所最大または局所最小なら、∇f(p) · γ′(t₀) = 0 です。曲線の像の上での局所極値なら、この仮定を満たします。

一変数の極値に戻す

f ∘ γ は一変数の関数です。極値の左右の差商の符号から、その両側微分は 0 です。曲線に沿う連鎖律により、その微分は ∇f(p) · γ′(t₀)。従って接線方向の変化率が消えます。曲線の像の局所極値から合成の局所極値が従うのは、γ の連続性によって t が t₀ に近ければ γ(t) も p に近いからです。

ラグランジュの未定乗数法

与えた正則曲線上の Lagrange の必要条件

前節の仮定に加え、g が p で全微分可能、曲線上で g(γ(t)) = c、n = ∇g(p) ≠ 0 とします。このとき、ある実数 λ が存在して次を満たします。

∇f(p)=λ∇g(p),g(p)=c

二成分の代数で平行を示す

g ∘ γ が一定なので、連鎖律から n · γ′(t₀) = 0。一方 f の極値から ∇f(p) · γ′(t₀) = 0 です。n = (n₁, n₂) ≠ 0 に直交する非零のベクトルは、γ′(t₀) = α(−n₂, n₁)、α ≠ 0 と書けます。例えば n₁ ≠ 0 なら直交式から第一成分を第二成分で表せます。n₁ = 0 なら n₂ ≠ 0 なので第二成分が 0 となり、同じ表現です。

q = ∇f(p) とすれば、q · (−n₂, n₁) = 0、すなわち q₂n₁ − q₁n₂ = 0。従って q は n の実数倍で、λ = (q · n)/‖n‖² と取れます。q = 0 でも λ = 0 とすれば成立します。q では割りません。ここまでで証明したのは、与えられた正則曲線に沿う必要条件です。

λ をLagrange の乗数と呼びます。制約を書き換えると値も変わります。例えば g を 2g にすれば同じ制約集合でも乗数は半分です。最適点の座標や目的関数値とは別の量です。

陰関数定理と正則なレベル集合

g(x,y)=c を満たす点全体をレベル集合と呼びます。勾配の章で f(x,y)=c と書いた等高線と同じ考え方です。ここではgの勾配が0でない部分を曲線としてたどるために使います。

ここだけ未証明で借りる：陰関数定理

g が p = (a, b) の近傍で C¹、g(p) = c、gᵧ(p) ≠ 0 なら、ある p 周りの小矩形内のレベル集合 g = c は、一意な C¹ 関数 y = ψ(x) のグラフとして表せます。gₓ(p) ≠ 0 なら x、y を交換します。これは陰関数定理の二変数・一方程式の場合です。グラフの存在・一意性・C¹ 性の完全証明は本章では行いません。

この借用によって γ(x) = (x, ψ(x)) を取れます。γ′ = (1, ψ′) ≠ 0 なので正則です。「勾配が非零だから曲線がある」という部分は、前節の内積の証明だけでは出てこず、この定理に依存します。

借用を含む、一般の正則レベル集合への拡張

f、g が p の近傍で C¹、p が制約集合 g = c 上の局所極値、∇g(p) ≠ 0 なら、∇f(p) = λ∇g(p) を満たす実数 λ が存在します。

借りた曲線へ、証明済みの必要条件を適用する

非零の ∇g の少なくとも一成分は非零なので、陰関数定理で上記の正則なグラフ曲線を得ます。C¹ から f、g は全微分可能です。制約上の局所極値はこの曲線上でも局所極値なので、前節で証明した必要条件を使えます。

以下の円周の主例と演習は、円周の明示曲線や直接の不等式で検算でき、この借用を使わなくても読めます。

乗数方程式と大域的な極値の保証

f = x + 2y、g = x² + y²、制約 g = 1 を考えます。円周上では ∇g = (2x, 2y) ≠ 0。明示した円周は正則なので必要条件を適用できます。

まず乗数方程式を解く

(1, 2) = λ(2x, 2y) と x² + y² = 1 を連立します。λ = 0 は最初の式に矛盾するため、x = 1/(2λ)、y = 1/λ。制約へ戻すと 5/(4λ²) = 1 なので λ = ±√5/2、候補は p = ±(1, 2)/√5。値はそれぞれ ±√5 です。これだけでは、一般に候補が極値であるとも、全体の最大・最小とも結論できません。

別の不等式で全体を保証する

Cauchy–Schwarz 不等式により、円周全体で |x + 2y| ≤ √5√(x² + y²) = √5。候補で両端を実際に達成するので、最大値 √5 は (1, 2)/√5 で、最小値 −√5 は −(1, 2)/√5 で取ります。値の存在は達成点を示して確認したので、一般の最大最小定理を新たに借りる必要もありません。

円周では n=∇g が接線に直交します。このように接線に直交する方向を法線方向と呼びます。下では、目的の勾配 q=∇f から法線方向の成分を取り除き、円周に沿ってまだ増やせる成分を残します。その残りが0かを見るのであり、一般の点で係数を計算しただけで最適点を得たわけではありません。

任意の円周上の点で q = ∇f、n = ∇g とし、λproj = (q · n)/‖n‖² と置けば、q の法線への射影係数を計算できます。これは常に定義できる係数で、最適点の乗数方程式が解けたことを意味しません。残差 q − λprojn は、単位接線 T = (−y, x) と接線変化率 −y + 2x の積です。残差が厳密に 0 の解析的な候補は本文で求め、浮動小数点の「約 0」だけで極値と判定しません。

例題：楕円上の最適点を、座標の変更でも確かめる

x²+4y²=4の楕円上で f=x+2y の最大・最小を求めます。円周の答えをそのまま拡大すると、xとyの尺度の違いを落とします。まずg=x²+4y²と置けば、∇g=(2x,8y)はこの楕円上で非零です。

乗数方程式と制約を、最後まで連立する

(1,2)=λ(2x,8y)より、λ=0は不可能で、x=1/(2λ)、y=1/(4λ)。制約に代入すると 1/(4λ²)+4/(16λ²)=1/(2λ²)=4。従って λ=±1/(2√2)、候補は ±(√2,1/√2)です。目的値は±2√2になります。

候補を作っただけでは結論しません。u=x/2、v=yと置くと制約はu²+v²=1、目的は2(u+v)。Cauchy–Schwarzから |f|≤2√2で、u=v=±1/√2のとき等号を達成します。よって候補が本当に全体の最大・最小です。楕円はγ(t)=(2cos t,sin t)と明示でき、γ′=(-2sin t,cos t)は0にならないため、必要条件の正則曲線の仮定も直接確認できます。

最大点を元の制約へ戻すと (√2)²+4(1/√2)²=2+2=4。勾配も λ∇g=(1/(2√2))(2√2,4√2)=(1,2)で一致します。制約のy²の係数4が、勾配では8yになることに注意してください。

この例では座標を変える別解が短くなりました。乗数法は座標変換を思い付かなくても候補を探せる一方、最適性の保証には不等式や一変数化が役立ちます。同じ問題で異なる方法を照合すると、方程式の解き漏れと「候補だから最適」という飛躍の両方を点検できます。

例題：制約の値と、乗数の大きさを区別する

f=(x−2)²+(y+1)²を、直線x+y=c上で最小にします。fは点(2,−1)からの距離の二乗です。cは任意の実数で、まず固定したcごとに問題を解き、その後にcを変えたときの最小値を比べます。

乗数0を除外せず、平方完成で保証する

g=x+yでは∇g=(1,1)≠0。乗数方程式は 2(x−2)=λ、2(y+1)=λ です。x=2+λ/2、y=−1+λ/2を足すと1+λ=cなので、λ=c−1。候補は ((c+3)/2,(c−3)/2)、値は(c−1)²/2です。ここではλで割る必要がなく、c=1のλ=0も正しく残ります。

全体の最小性は、a=x−2、b=y+1と置くとa+b=c−1であることから示せます。f=a²+b²={(a+b)²+(a−b)²}/2≥(c−1)²/2、等号はa=bで、求めた点に一致します。直線は無限に続きますが、この下界と達成点によって最小の存在を直接保証できました。

c=3なら点(3,0)、λ=2、最小値2。代入すると(3−2)²+(0+1)²=2です。c=1なら元の点(2,−1)が制約を満たし、最小値0、目的の勾配も0です。乗数0だから異常なのではありません。非零であるべきなのは、定理では制約の勾配でした。

最小値をV(c)=(c−1)²/2と書くと、V(c+δ)−V(c)=(c−1)δ+δ²/2です。この自作例では乗数λ=c−1が制約値を少し動かしたときの一次の変化率を表します。c=3、δ=1/10なら差は41/200=0.205で、λδ=0.2との差はδ²/2=0.005です。

ただし同じ直線をG=2x+2y=2cと書けば∇G=2∇gなので、新しい乗数はμ=λ/2です。右辺の変化も2δになるためμ·2δ=λδで一致します。乗数の数値だけを、制約の書き方と単位から切り離して比べてはいけません。一般の制約で常にこの微分公式が使えるという定理は、ここでは主張していません。

候補へ近付いたことと、候補であることを区別する

最初の円周の問題へ戻ります。表の「接線変化率」を見て、どの点ではまだ円周に沿って増やせるか答えてください。λproj=(q·n)/‖n‖²=(x+2y)/2はどの円周上でも計算できるので、その値が出ただけでは乗数方程式を解いたことになりません。

乗数法の適用条件と反例

正則性を落とすと、極値でも方程式を満たさない

g = x² + y² = 0 の制約集合は原点だけです。f = x の制約上の最大値も最小値も 0。しかし ∇f(0) = (1, 0)、∇g(0) = 0 なので (1, 0) = λ(0, 0) を満たす λ はありません。∇g ≠ 0 の仮定を欠いており、定理への反例ではありません。一点だけの集合には非零の速度の曲線を置けません。

方程式を満たしても、極値とは限らない

円周上の f = x³ では、p = (0, 1)、(0, −1) の両方で ∇f = (0, 0)。λ = 0 で乗数方程式を満たします。しかし各 p の近くに (s, ±√(1 − s²)) があり、正負の小さい s に対して f = s³ は正負を取ります。従ってどちらも極値ではありません。円周の正則性を満たしていても、必要条件は十分条件にはなりません。

正則な制約でも、最適点が存在するとは限らない

g = y = 0 は正則な無限直線ですが、f = x は上にも下にも無界で、最大値も最小値もありません。必要条件が最適点の存在まで保証するわけではありません。不等式制約、端点や角のある制約も別の検査を要し、本章の定理だけでは扱いません。

乗数方程式の前後で分ける、三つの確認
本文の例乗数方程式との関係極値の結論
g = x² + y² = 0、f = x∇g(0) = 0。必要な正則性を欠き、方程式の解λはない制約は原点だけなので、そこで最大かつ最小
円周 x² + y² = 1、f = x³、p = (0, ±1)正則な制約。∇f(p) = 0 なので λ = 0 で方程式を満たす近くで正負の値を取るため、pは極値でない
直線 g = y = 0、f = x制約は正則だが、∇f = λ∇g を満たす点はない上にも下にも無界で、最大も最小もない

同じ制約集合でも、方程式の書き方で正則性が変わる

直線y=0を、g(x,y)=y=0と書く場合と、G(x,y)=y²=0と書く場合を比べます。どちらも動ける点は同じですが、前者の勾配は(0,1)、後者は直線上で(0,0)です。制約が見た目に滑らかでも、使う関数の勾配が非零とは限りません。

目的f=x²+yは、この直線上ではx²です。原点が唯一の大域最小で、値は0。gを使えば原点で∇f=(0,1)=1∇gとなります。Gを使えば∇f=(0,1)をλ(0,0)とは書けません。極値の有無が変わったのではなく、二番目の表現が必要条件の仮定を満たさなくなったのです。

したがって計算の順序は、①実行可能な集合を把握する、②制約の勾配が消える点を別に拾う、③正則な部分では乗数方程式を解く、④候補・特異点・端点を元の目的関数で比べる、です。勾配の消える点を黙って捨てることも、すべてを乗数方程式で処理できると思うことも、解き漏れを生みます。

寄り道［応用］：発電量の配分で、限界費用がそろう

電力シミュレータ PowerWorld の公式資料は、発電費用 C(P) の出力 P に対する微分を incremental cost（限界費用）として扱います。一定の総出力を複数の発電機へ配分する問題は、微分を使って費用を考える具体的な出番です。以下では自作のモデルから、限界費用と乗数の関係を確かめます。

ここからは現実の設備データではなく、本章の仮想モデルです。出力 p₁、p₂ を MW、費用を通貨単位/時として、C₁(p₁) = p₁²、C₂(p₂) = 2p₂²（係数は対応する単位を持つ）、p₁ + p₂ = 3 MW と置きます。目的 C₁ + C₂ の勾配は (2p₁, 4p₂)、制約の勾配は (1, 1)。内部最適点の必要条件は 2p₁ = λ = 4p₂ で、配分は (2, 1)、総費用は 6 です。

最小であることは別に、C₁(3 − p₂) + C₂(p₂) = 6 + 3(p₂ − 1)² ≥ 6 で保証できます。片方から他方へ少し出力を移せるとき、その交換による一次の費用差が 0 になるのが「限界費用がそろう」の意味です。現実の容量上下限、送電損失、起動費、運転制約はこのモデルに含めていません。上限に達した発電機まで無条件に同じ微分値になる、という主張ではありません。

ラグランジュ乗数と極値の演習

1–3で基本の連立と正則性、4–6で別解・条件変更・逆設計を練習します。7–10は候補、特異な表現、端点、存在を自分で選んで検査してください。

1．円周上の線形関数

x² + y² = 1 上で f = x + 2y の乗数方程式を解き、全体の最大・最小を別に保証してください。

ヒント1：正則性から確認する

円周では ∇g = (2x, 2y) は非零です。方程式は (1, 2) = λ(2x, 2y)。

ヒント2：不等式の等号も調べる

|(1, 2) · (x, y)| ≤ √5 を使います。

解答

円周は明示された正則曲線で、f、g は C¹ です。λ = 0 は不可能なので x = 1/(2λ)、y = 1/λ。制約から λ² = 5/4、λ = ±√5/2。候補は ±(1, 2)/√5 で値は ±√5。円周全体で Cauchy–Schwarz により |f| ≤ √5、両候補がその上下端を達成するので、最大は √5、最小は −√5 です。方程式の必要条件と不等式による全体保証を分けました。

2．積の四つの候補

同じ円周上で f = xy の全候補と λ を求め、最大・最小を保証してください。

ヒント1：軸上も落とさず調べる

(y, x) = 2λ(x, y)。x = 0 または y = 0 は成立しますか。

ヒント2：積の大きさを抑える

2|xy| ≤ x² + y² = 1 です。

解答

方程式は y = 2λx、x = 2λy。x = 0 なら最初の式から y = 0 となり制約に矛盾し、y = 0 も同様。両方非零なので代入して 4λ² = 1。λ = 1/2 なら x = y、候補は (1, 1)/√2 と (−1, −1)/√2、値は 1/2。λ = −1/2 なら x = −y、候補は (1, −1)/√2 と (−1, 1)/√2、値は −1/2。全円周で |xy| ≤ 1/2、これらの点で達成するので、最大値 1/2、最小値 −1/2 が保証されます。

3．一点だけの制約

制約 x² + y² = 0、目的 f = x に乗数法の必要条件を使えますか。実際の最大・最小も説明してください。

ヒント1：制約集合を先に決める

実数の二つの平方の和が 0 になるのはいつですか。

ヒント2：二つの勾配を比べる

原点で ∇f = (1, 0)、∇g = (0, 0) です。

解答

x²、y² はともに非負なので、実行可能点は原点のみ。従って最大値も最小値も 0 です。一方 ∇g(0) = 0 で定理の正則性を欠き、(1, 0) = λ(0, 0) はどんな λ でも成立しません。乗数方程式に解がないことから極値の不存在を結論してはいけません。先に適用条件を確かめる必要があります。

4．楕円で座標の尺度を確かめる

x²+4y²=4上でx+2yの極値を乗数法で求め、u=x/2、v=yへの変更でも保証してください。

ヒント1

∇g=(2x,8y)は楕円上で非零です。

ヒント2

方程式からx=1/(2λ)、y=1/(4λ)と置けます。

解答

λ=0は不可能。制約は1/(2λ²)=4なのでλ=±1/(2√2)、候補は±(√2,1/√2)、値±2√2です。u²+v²=1、f=2(u+v)なので|f|≤2√2で、これらの候補が等号を達成します。最大2√2、最小−2√2です。

最大点でx²+4y²=2+2=4、λ(2x,8y)=(1,2)とも検算できます。yの尺度をxと同じに扱うと候補を誤ります。

5．乗数0を含む直線上の最小

f=(x−2)²+(y+1)²をx+y=c上で最小にしてください。c=1とc=3の乗数も求め、制約を2x+2y=2cと書く場合の乗数と比べてください。

ヒント1

二つの偏導関数を同じλと置き、足します。

ヒント2

a=x−2、b=y+1ならa+b=c−1です。

解答

2(x−2)=λ=2(y+1)よりλ=c−1、点は((c+3)/2,(c−3)/2)。a²+b²=((c−1)²+(a−b)²)/2なので最小値(c−1)²/2を達成します。c=1は点(2,−1)、λ=0、値0。c=3は(3,0)、λ=2、値2です。

2gを使う乗数μはλ/2で、順に0、1です。最適点も最小値も変わりません。λ=0を先に除くとc=1の正しい解を失います。

6．望む最大点と値から目的関数を設計する

単位円周上の線形目的f=ax+byについて、最大点を(3/5,4/5)、最大値を10にしたいとします。a,bと、その点でのg=x²+y²に対する乗数を求め、全体の最大も保証してください。

ヒント1

最大点で(a,b)=2λ(3/5,4/5)です。

ヒント2

その点の目的値を代入すると10=2λになります。

解答

乗数方程式と値からλ=5、a=6、b=8です。全円周で6x+8y≤√(36+64)√(x²+y²)=10で、指定点では18/5+32/5=10。等号の正方向は一つなので、最大点も指定どおりです。

制約は9/25+16/25=1、勾配は(6,8)=5(6/5,8/5)と検算できます。最大点だけの指定なら(a,b)の正の倍率が未定でしたが、最大値10の指定で大きさも決まりました。

7．必要条件を満たす全候補を比較する

単位円周上でf=x³の乗数方程式を、x=0の場合も含めて解いてください。全候補を極値とそれ以外に分けてください。

ヒント1

方程式は3x²=2λx、0=2λyです。xで割る前に場合分けします。

ヒント2

x=0ではy=±1、x≠0ならλ≠0なのでy=0です。

解答

x=0ならy=±1、二式目からλ=0。x≠0ならλ=3x/2≠0、二式目からy=0でx=±1、λ=±3/2。候補は四点です。

−1≤x≤1なので−1≤x³≤1、最大は(1,0)で1、最小は(−1,0)で−1。一方(0,±1)の近くには(s,±√(1−s²))があり、値s³は正負を取るので極値ではありません。例えばs=±1/10では±1/1000。必要条件だけで四点すべてを極値と判定してはいけません。

8．同じ直線を特異な式で書く

f=x²+y、制約y²=0で最小を求め、『乗数方程式に解がないから最小もない』を診断してください。制約をy=0と書いた場合も比べてください。

ヒント1

実行可能集合を先に求めると、どちらもy=0です。

ヒント2

y²の勾配は制約上で0ですが、yの勾配は(0,1)です。

解答

制約上でf=x²なので最小値0を原点で達成し、最大はありません。y²を使うと原点で∇g=0、∇f=(0,1)で乗数方程式を満たせません。しかし正則性を欠くため、定理を使えないというだけです。

g=yなら(2x,1)=λ(0,1)よりx=0、λ=1で正しい候補を得ます。例えば(1,0)では値1、原点では0。幾何的に同じ直線でも、方程式の表現の仮定は別に検査します。

9．半円には端点もある

上半円周x²+y²=1、y≥0上でf=x+2yの最大・最小を求めてください。円周全体の乗数候補だけでは何を落としますか。

ヒント1

y>0の部分では円周の乗数条件を使い、端点(±1,0)を別に比較します。

ヒント2

負の候補−(1,2)/√5は上半円に入りません。

解答

内部の候補は(1,2)/√5だけで値√5。端点の値は(1,0)で1、(−1,0)で−1です。最大はCauchy–Schwarzの上界√5を達成します。最小はx≥−1、y≥0よりx+2y≥−1で、(−1,0)が達成します。

最小点では接線方向の両側へ動けるわけではありません。円周全体での乗数方程式だけを課すとこの端点を落とします。不等式制約を本章の等式制約の必要条件に無断で含めないことが必要です。

10．無限に続く制約でも最小はあるか

xy=1上でf=x²+y²の乗数候補をすべて求め、最小と最大の有無をそれぞれ保証してください。

ヒント1

∇g=(y,x)は制約上で非零です。x,yも0になりません。

ヒント2

2x=λy、2y=λxからx²=y²。全体の下界には(x−y)²を使えます。

解答

二式からx²=y²、xy=1なのでx=y=±1で、λ=2です。全制約でx²+y²=(x−y)²+2xy=(x−y)²+2≥2となり、両候補で最小値2を達成します。

一方(t,1/t)（t>0）は常に制約を満たし、f=t²+t⁻²→∞なので最大はありません。t=2なら4+1/4=17/4>2。制約が有界でないことだけから最小まで否定せず、下界と達成を別々に調べます。
