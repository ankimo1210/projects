分散と標準偏差

必ず 0 を取る変数と、−10、10 を半々で取る変数は、どちらも期待値が 0 です。しかし平均からの離れ方は大きく違います。期待値に加えて、散らばりを数にする必要があります。

単に平均からの差を平均すると、E[X − E[X]] = 0 になって左右が打ち消し合います。差を二乗してから平均すれば、符号による相殺を防げます。その数から、大きく外れる確率の上限も引き出します。

この「平均との差を二乗した数の重み付き平均」を分散と呼び、Var(X)と書きます。その平方根が標準偏差です。まず下の二例で、二乗する距離が0か100かという違いを見てから、一般の計算公式へ進みましょう。

どちらも中心は 0 ですが、右では二乗距離 100 に合計 1 の重みがあります。平均だけでは、この違いが消えてしまいます。

学習の目安は演習込み120–180分です。まず分散を二通りで計算し、尺度変換と「中心に何を選ぶか」を確かめ、最後に平均や分散だけから得られる確率の保証を設計します。演習1–3は基本、4–7は計算・証明・誤診断、8–10は境界と保証の逆算です。

分散の定義と計算公式

E[X²] < ∞ を仮定します。この条件なら |x| ≤ 1 + x² と期待値の単調性から E[|X|] ≤ 1 + E[X²] < ∞ であり、平均 μ = E[X] も有限です。分散を Var(X) = E[(X − μ)²]、標準偏差を σ = √Var(X) と定義します。有限離散では全ての値が有限なので、この条件を自動的に満たします。

Var(X)=E[(X−μ)2]=E[X2]−(E[X])2

二乗を展開し、線形性を使う

(X − μ)² = X² − 2μX + μ² の期待値を取ります。μ は定数なので E[(X − μ)²] = E[X²] − 2μE[X] + μ² = E[X²] − μ²。各項の期待値は有限で、∞ − ∞ を計算していません。また (X − μ)² ≤ 2X² + 2μ² から、分散自体も有限です。非負な量の期待値なので Var(X) ≥ 0 です。

例えば Bernoulli 変数 X では X² = X なので E[X²] = p。従って Var(X) = p − p² = p(1 − p) です。p = 0、1 なら必ず同じ値を取って分散は 0、p = 1/2 なら分散は 1/4 になります。密度 f を持つ場合は、絶対可積分性を確認して Var(X) = ∫(x − μ)²f(x) dx と計算します。

単位にも違いがあります。X が秒なら、分散は秒²、標準偏差は秒です。標準偏差は元の値と同じ尺度で散らばりを読めますが、「必ずその幅に収まる」という意味ではありません。

分散の平行移動と尺度変換

尺度変換の公式

有限な二乗の期待値を持つ X と実数 a、b に対して、Var(aX + b) = a²Var(X) です。従って標準偏差は |a| 倍です。

新しい平均からの差を取る

E[aX + b] = aμ + b なので、(aX + b) − (aμ + b) = a(X − μ)。二乗して期待値を取れば a²Var(X) です。定数 b は差の中で消え、a が負でも二乗で非負になります。

例えば計測値を秒からミリ秒へ変えると a = 1000 なので分散は 100 万倍、標準偏差は 1000 倍です。単位を変えただけで散らばり方の意味が変わったわけではありません。なお Var(X + Y) をいつでも Var(X) + Var(Y) とすることはできません。和に現れる追加の項は、共分散で扱います。

負の倍率と、中心を動かす操作

例題2：表示の向きが逆になっても散らばりは非負

例題1のXをY=−2X+3で記録し直します。平均はE[Y]=−2(7/4)+3=−1/2、分散はVar(Y)=4(67/16)=67/4です。標準偏差は√67/2≈4.0927。倍率−2の符号は値の左右を反転させますが、距離は2倍、二乗距離は4倍です。

実際の値で検算するとYは3、−1、−7を元と同じ確率で取ります。新しい平均−1/2からの差は7/2、−1/2、−13/2。元の差−7/4、1/4、13/4をそれぞれ−2倍したものと一致します。二乗距離の重み付き和も49/8+1/16+169/16=67/4となります。

a=0ならaX+bは必ずbで、分散0・標準偏差0です。bだけを変えても散らばりは動きません。平均を目的の位置へ合わせる操作と、散らばりの大きさを変える操作を、二つの係数で分けて設計できます。

なぜ平均との差を使うのか

二乗距離を測る基準を、平均ではなく任意の実数cにしたらどうなるでしょう。E[(X−c)²]は、毎回の値と基準cのずれを二乗して平均した量です。基準を動かすと最も小さくなるのはどこか、式で調べます。

例題3：二乗距離の平均を最小にする中心

μ=E[X]としてX−c=(X−μ)+(μ−c)と分けます。二乗を展開すると、(X−c)²=(X−μ)²+2(μ−c)(X−μ)+(μ−c)²です。E[X−μ]=0なので、中央の項を平均すると0になります。従ってE[(X−c)²]=Var(X)+(μ−c)²。有限な二乗の期待値を仮定しているので、どの項も有限で、∞から∞を引いていません。

右辺の最初の項はcによらず、二つ目は非負でc=μのときだけ0です。従って二乗距離の平均を最小にする基準は一意にc=μ、最小値はVar(X)です。この意味で平均を中心に選ぶ理由が得られました。絶対値の距離など、別のずれの測り方でも同じ中心になると主張しているわけではありません。

例題1で基準c=2にすると、Var(X)+(7/4−2)²=67/16+1/16=17/4。直接でも、(0−2)²(1/2)+(2−2)²(1/4)+(5−2)²(1/4)=2+9/4=17/4です。2は実際に取る値ですが、二乗距離を最小にするのは実際には取らない7/4の方です。

Markovの不等式

Markov の不等式

Y ≥ 0 で E[Y] < ∞ とし、a > 0 とします。このとき P(Y ≥ a) ≤ E[Y]/a です。右辺が 1 を超える場合は、確率の上限 1 と合わせて小さい方を使えます。

P(Y≥a)≤E[Y]a(Y≥0,a>0)

しきい値以上の部分だけを残す

A = {Y ≥ a} とします。A 上では Y ≥ a、外では Y ≥ 0 なので、全ての結果で Y ≥ aIₐ です。期待値の単調性と指示変数の公式から、E[Y] ≥ aE[Iₐ] = aP(A)。a > 0 で割れば結論です。分布の形や独立性は使っていません。

Y の非負性は証明の外側の部分で必要です。反例として、Y が −1 を確率 9/10、9 を確率 1/10 で取ると E[Y] = 0 ですが、P(Y ≥ 1) = 1/10。非負性を外して E[Y]/1 = 0 を上限とすることはできません。また a = 0 では割り算自体が定義されません。

上界がちょうど実現する分布を作る

例題4：平均3分から分かること、分からないこと

非負な待ち時間Yの平均が3分なら、MarkovからP(Y≥12)≤3/12=1/4です。この数を実際の確率だと言ってよいでしょうか。異なる二つの分布を作って確かめます。

必ず3分のモデルなら平均は3分で、12分以上の確率は0です。一方、0分を確率3/4、12分を確率1/4で取る自作モデルなら、平均は0(3/4)+12(1/4)=3分で、P(Y≥12)=1/4。平均が同じでも、実際の尾確率は異なります。

後のモデルでは、事象A={Y≥12}の指示変数IAを使った不等式Y≥12IAが全ての結果で等号です。しきい値以上ではちょうど12、外ではちょうど0なので、平均を取っても余分な量がありません。これが上界へ達する理由です。「平均3分」という情報だけで、1/4より小さい一律の上限に置き換えることはできません。

端点を外してP(Y>12)とすると、同じ二点モデルの確率は0になります。Markovの≥という境界を、数値例でも保つ必要があります。また平均が非負でもY自体が負を取れるなら、元の証明の外側Y≥0が失われ、同じ上界は使えません。

Chebyshevの不等式

Chebyshev の不等式

有限な二乗の期待値を持ち、平均 μ、分散 σ² の変数 X について、任意の t > 0 に対し、平均から t 以上離れる確率は σ²/t² 以下です。

P(|X−μ|≥t)≤σ2t2(t>0)

二乗した差に Markov を使う

Y = (X − μ)² と置きます。Y ≥ 0、E[Y] = σ² で、|X − μ| ≥ t と Y ≥ t² は同じ事象です。従って Markov の不等式をしきい値 a = t² > 0 で使えば結論を得ます。これが、二乗による散らばりと、確率の上限を結ぶ理由です。

σ > 0 のとき、例えば t = 2σ なら外れる確率は高々 1/4。これは分布の形を知らずに使える上限です。実際の確率がちょうど 1/4 だという意味でも、観測値が必ず 2σ 以内だという意味でもありません。

標準偏差σが正なら、平均からの距離を「標準偏差の何倍か」で表せます。その倍率をk>0としてt=kσを代入すると、上界はσ²/(kσ)²=1/k²です。次の図ではσ=1、k=2として、実際の尾の確率とこの上界を比べます。

σ² = 0 なら全ての正の t で P(|X − μ| ≥ t) = 0 です。X ≠ μ なら、ある正の整数 m で |X − μ| ≥ 1/m となるため、{X ≠ μ} はこれらの事象の可算和です。可算個の和事象の上界から P(X ≠ μ) = 0。つまり X は確率 1 で μ に等しくなります。確率 0 の結果を含む一般モデルでは、全ての結果で等しいという主張とは区別します。

有限離散ではこの証明は全て有限和の期待値の性質に基づきます。一般のモデルでは前章で明示した積分の単調性と、確率の可算加法性の枠組みを使っています。次章で和の分散を求めれば、最後に繰り返しの平均へこの不等式を適用できます。

同じ平均と分散でも、尾の確率は決まらない

例題5：Chebyshev上界を二つの分布で比較する

X₁は−2、2を確率1/2ずつ、X₂は−4、0、4を確率1/8、3/4、1/8で取る自作モデルです。両方とも対称なので平均0。分散はX₁で4、X₂で16(1/8+1/8)=4です。従ってどちらもP(|X|≥4)≤4/16=1/4という同じ保証を受けます。

実際にはX₁の尾確率は0、X₂は1/8+1/8=1/4です。平均と分散だけでは二つを見分けられません。X₂では二乗距離が、内側の0と、境界の4²=16だけなので、Markovを使った証明が等号になります。元の図のσ=1、しきい値2という例を、値を2倍にして読み直すこともできます。

このX₂でP(|X|>4)なら確率0です。図と式を読むときは、境界を尾へ入れたかを確認します。一般の上界は厳密な不等号の事象にも使えますが、この三点分布がその場合にも等号を実現するとは言えません。

逆向きに、平均から3点以上外れる確率を1/100以下とChebyshevで保証したいなら、σ²/3²≤1/100、すなわちσ²≤9/100点²を要求すれば十分です。標準偏差ではσ≤3/10点。分散と標準偏差のどちらが与えられたかで、二乗の置き方が違います。

ただしこれは、その上界を通じた保証の条件です。条件を満たさない分布の実際の尾確率が1/100を超える、とは結論できません。平均と分散以外の情報が分かれば、もっと強い評価が得られる場合があります。演習では「十分な条件」と「実際の確率に必要な条件」を見分けます。

寄り道［見方］：平均が同じ分布を、どこまで見分けられるか

MIT の分散の教材は、同じ平均を持っていても散らばりが違う分布を比べるところから始まります。本章の言葉なら、中心の情報だけでは、中心からの距離の情報が欠けています。

自作の例で、X は −1、1 を半々、Y は −2、2 を半々で取るとします。両方とも平均 0 ですが、分散はそれぞれ 1、4 です。Y は X の尺度を 2 倍にした分布なので、分散は 4 倍。標準偏差に戻せば 1 と 2 になり、元の距離の倍率を読めます。平均と標準偏差の二つが分かっても分布全体が決まるわけではなく、目的に応じて情報の残し方を選んでいるのです。

出典：MIT OpenCourseWare 18.05：Variance of Discrete Random Variables、2–3。X、Y の分布は本章の自作例です。

演習：分散と確率不等式

1．成否を別の尺度で記録する

X は成功確率 1/5 の Bernoulli 変数です。E[X]、Var(X)、Z = 5X + 3 の平均と分散を求めてください。

ヒント1：X² = X を使う

Var(X) = p − p² です。

ヒント2：平均は一次、分散は倍率の二乗

E[Z] = 5E[X] + 3、Var(Z) = 25Var(X) です。

解答

E[X] = 1/5、Var(X) = (1/5)(4/5) = 4/25。従って E[Z] = 1 + 3 = 4、Var(Z) = 25 · (4/25) = 4 です。定数 3 は平均を移動させますが、分散には影響しません。

2．非負な待ち時間

Y ≥ 0 で E[Y] = 3 分と分かっています。12 分以上待つ確率の上限を求めてください。独立性や密度の形の仮定は必要ですか。

ヒント1：平均しか分からない

非負性と平均を使う Markov の不等式を選びます。

ヒント2：単位をそろえる

しきい値 a = 12 分で、E[Y]/a を計算します。

解答

P(Y ≥ 12) ≤ 3/12 = 1/4 です。比の単位は消えます。非負性と有限な期待値で十分であり、独立性も特定の密度も不要です。これは上限であって、待ち時間の確率を正確に決めたものではありません。

3．区間の外と内を対応させる

X の平均が 50、分散が 9 のとき、P(|X − 50| ≥ 6) の上限と、P(44 < X < 56) の下限を求めてください。

ヒント1：分散は既に二乗の量

Chebyshev の右辺は 9/6² であり、9²/6² ではありません。

ヒント2：端点の含め方を確認する

|X − 50| ≥ 6 の補集合は |X − 50| < 6 です。

解答

P(|X − 50| ≥ 6) ≤ 9/36 = 1/4。補集合を取ると P(44 < X < 56) ≥ 3/4 です。端点 44、56 は外側の事象に含めたので、内側の区間は厳密な不等号になります。

4．負の尺度変換の誤り

E[X]=4、Var(X)=9とし、Y=−2X+5とします。平均・分散・標準偏差を求め、「分散は−2倍で−18になる」という計算を診断してください。

ヒント1

平均からの差は−2(X−4)です。

ヒント2

標準偏差は分散の非負の平方根です。

解答

E[Y]=−8+5=−3、Var(Y)=(−2)²9=36、標準偏差6です。分散は非負な二乗距離の平均なので−18にはなりません。定数5は平均を動かし、倍率の絶対値2が標準偏差を3から6へ変えます。

5．二通りの分散計算

Xは−1、1、3を確率1/4、1/2、1/4で取ります。平均・分散を求め、定義とE[X²]−(E[X])²の両方で検算してください。

ヒント1

平均は中央の1になるかを重み付きで確かめます。

ヒント2

平均との差は−2、0、2です。

解答

μ=−1/4+1/2+3/4=1です。定義からVar(X)=4(1/4)+0(1/2)+4(1/4)=2。一方E[X²]=1/4+1/2+9/4=3なので、3−1²=2です。E[X²]=3をそのまま分散とする誤りを、二通りの一致で避けられます。

6．実際に取る値を中心にすべきか

Xは0を確率3/4、4を確率1/4で取ります。E[(X−c)²]を最小にする実数cと最小値を求め、c=2の場合と比べてください。

ヒント1

平均は1です。中心の分解公式を使えます。

ヒント2

分散はE[X²]−1=4−1です。

解答

μ=1、Var(X)=3なのでE[(X−c)²]=3+(1−c)²です。最小はc=1で3、c=2では4です。直接でもc=1のとき(3/4)1+(1/4)9=3、c=2のとき両結果の二乗距離が4で平均4。中心は実際の値0、4のどちらでもなくて構いません。

7．平均非負ならMarkovを使えるか

Yは−2を確率2/3、4を確率1/3で取ります。E[Y]とP(Y≥1)を求め、Markovで確率0以下とする誤りを説明してください。さらにZ=Y+2で非負に直した場合の上界も求めてください。

ヒント1

Yの平均と、Y自体の非負性は別の条件です。

ヒント2

{Y≥1}={Z≥3}で、E[Z]=2です。

解答

E[Y]=−4/3+4/3=0ですがP(Y≥1)=1/3です。Y≥0ではないのでE[Y]/1を上界にはできません。Zは0、6を確率2/3、1/3で取り非負、平均2なのでP(Y≥1)=P(Z≥3)≤2/3です。実際の1/3はこの上界以下で、矛盾しません。

8．等号と境界を設計する

平均5、分散4で、P(|X−5|≥4)=1/4となる有限分布を一つ作ってください。同じ分布でP(|X−5|>4)はいくつですか。

ヒント1

平均の位置と、そこから左右4離れた位置を使います。

ヒント2

左右の質量をそれぞれ1/8にすると、二乗距離16への合計質量は1/4です。

解答

1、5、9を確率1/8、3/4、1/8で取ればよいです。平均は1/8+15/4+9/8=5、分散は16(1/8+1/8)=4、境界を含む尾確率は1/4でChebyshev上界4/16に達します。一方厳密に4より離れた値はないのでP(|X−5|>4)=0。左右等確率は今回平均を作るための選択で、一般分布の条件ではありません。

9．保証の条件は必要条件か

平均10のXについてP(|X−10|≥2)≤1/100をChebyshevで保証する標準偏差の条件を求めてください。標準偏差が1なら実際の尾確率は1/100より大きいと言えますか。

ヒント1

分散σ²に対してσ²/4≤1/100を解きます。

ヒント2

平均からの距離が必ず1の分布を反例にできます。

解答

σ²≤1/25、すなわち0≤σ≤1/5なら保証できます。σ=1のとき上界1/4は目標を保証しませんが、実際の確率が大きいとは言えません。例えば9、11を半々で取るなら平均10、分散1、標準偏差1でも、距離2以上の尾確率は0です。十分条件を満たさないことと、目標そのものを満たさないことは違います。

10．平均と確率の保証を同時に設計する

自作の記録値Xは平均20、分散9です。Y=aX+bでa≥0とし、平均を100へ合わせ、Chebyshevを使ってP(|Y−100|≥2)≤1/100を保証したいとします。全候補のa,bを求め、aを最も大きくする設定を選んでください。

ヒント1

平均条件でbをaの式にします。

ヒント2

分散は9a²なので、9a²/4≤1/100です。

解答

平均条件は20a+b=100、従ってb=100−20a。保証には9a²≤1/25が十分で、a≥0より0≤a≤1/15です。この全範囲とbの式が、指定のChebyshev保証を満たす候補です。最大はa=1/15、b=296/3。このとき平均100、分散1/25、標準偏差1/5、上界は(1/25)/4=1/100です。a=0なら必ず100となり分散0ですが、aを最大にする目的には選ばれません。分布の形を知らないため、上界の保証を超えて実際の尾確率を決めてはいません。
