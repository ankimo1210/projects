仕事と力の接線成分

同じ強さの力でも、進む方向に押す場合と、真横へ押す場合とでは移動への寄与が違います。道に沿って集めたいのは力の大きさそのものではなく、移動に平行な成分です。前章の正の長さ要素 ds を、向きを持つ移動 dr に替えると何が起きるでしょう。

復習は内積、区分 C¹ 曲線、微積分の基本定理です。ここでの「仕事」は、力と変位の内積を足す数学モデルとして使います。

演習込み100–150分が目安です。定義と向き、経路を替える例、勾配場と演習、の三回に分けて読めます。曲線の入力区間・始終点・進む向きを、計算より先に確認します。

線積分の入力と計算方針

計算の入力は、場Fだけでは足りません。どこをどちらへ通る曲線かと、その全体でFが連続かを確認します。例えば「単位円」は図形の名前だけで、時計回りか反時計回りか、一周か二周かを指定していません。仕事を一つの値にするには、その情報が必要です。

方針は次の順で選べます。まず、位置r(t)・場F(r(t))・速度r′(t)の三つを別々に書きます。次に内積を取って一変数の積分へ戻します。一定場なら全変位へまとめられます。場がある関数の勾配なら、線積分の基本定理で端点へまとめられます。最後の方法は後で証明するので、それまでは直接計算で確かめます。

ベクトル場の線積分の定義

区分 C¹ 曲線 r : [a, b] → U ⊂ ℝ³ と、その像で連続な場 F を考えます。ベクトル場の線積分を次で定めます。角がある場合は有限個の C¹ 部分で積分して足します。

dr は道の向き付きの微小な移動を表し、パラメータ表示では dr=r′(t)dt と読みます。場所 r(t) での力 F(r(t)) と、同じ時刻の移動の内積を足すため、次の式には両方が入ります。

∫CF·dr:=∫abF(r(t))·r′(t)dt

F = (P, Q, R)、r = (x, y, z) なら、被積分関数は P(r)x′ + Q(r)y′ + R(r)z′。この意味で ∫CF·dr = ∫CP dx + Q dy + R dz とも書きます。場が力、座標が長さの単位なら、積分は「力 × 長さ」の単位です。速度が非零の点では r′ = T‖r′‖ なので、F·dr = (F·T)ds。仕事は、進む方向への符号付き成分を長さに沿って集めます。

線積分の再パラメータ化と向きの反転

η(s) = r(ψ(s)) とします。ψ は新しい閉区間から [a, b] への増加全単射で、有限分割の各部分で C¹、ψ′ > 0、片側導関数が端まで連続に延長できるとします。r の分割点の逆像でも区切れば、連鎖律と一変数の置換で次が分かります。ここではこの条件を満たす向きを保つ正則な再パラメータ化を扱います。

速さの係数を、積分の幅へ戻す

各部分で η′ = r′(ψ)ψ′。従って F(η)·η′ = {F(r(ψ))·r′(ψ)}ψ′ です。t = ψ(s) と置換すると元の積分になり、部分を足せば ∫ηF·dr = ∫rF·dr を得ます。ψ′ が正なので始点と終点の順序は保たれます。

逆向き −r(t) = r(a + b − t) では、微分に負号が現れます。置換後に ∫−CF·dr = −∫CF·dr。道の連結では各積分が足され、同じ周回を二回行えば二倍です。

パラメータ表示から仕事を求める

例題1：曲がる道に沿って、変化する力を足す

F(x,y)=(2x,y)、r(t)=(t,t²)、0≤t≤1とします。道は(0,0)から(1,1)への放物線です。Fは変化するので、終点の場F(1,1)=(2,1)と変位(1,1)の内積3を取っても仕事にはなりません。各点の力を使う必要があります。

F(r(t))=(2t,t²)、r′(t)=(1,2t)。したがってF(r(t))·r′(t)=2t+2t³で、仕事は∫₀¹(2t+2t³)dt=[t²+t⁴/2]₀¹=3/2です。最初に場の中へy=t²を代入し、速度側のy′=2tも掛けたことが重要です。

別の道r₁(t)=(t,t)なら内積は3tで、積分はやはり3/2。二本の一致だけで「すべての道で同じ」とは証明できませんが、Fが一つの関数の勾配になっていないかを調べる動機になります。実際、φ=x²+y²/2を微分すればFに戻ります。基本定理の証明後には、すべての許された道で一致することが分かります。

逆向きでは−3/2です。曲線が曲がっていること自体が経路依存の理由なのではありません。場の性質も調べます。

例題2：長さは正でも、仕事は相殺する

F=(0,1)の下で、上半円r(t)=(cos t,sin t)、0≤t≤πを(1,0)から(−1,0)へたどります。速度は(−sin t,cos t)なので、内積はcos t。仕事は[sin t]₀^π=0です。上りの0≤t≤π/2では仕事1、下りのπ/2≤t≤πでは仕事−1となり、足すと0です。

一方、‖r′(t)‖=1だから道の長さはπ。さらに‖F‖=1なので∫‖F‖dsもπです。後者を仕事とすると、下りで力が移動に逆らう負の寄与を失います。一定場なのでF·(B−A)=(0,1)·(−2,0)=0でも検算できます。仕事0は「どこでも力が0」でも「道が短い」でもありません。

線積分の経路依存性

平面の場 F(x, y) = (−y, x) で、A = (0, 0) から B = (1, 1) へ進みます。直線 r(t) = (t, t)、0 ≤ t ≤ 1 では、F(r)·r′ = (−t, t)·(1, 1) = 0 で仕事は0。一方、x 軸を (1, 0) へ進んでから縦に上がる道では、第一部分の寄与は0、第二部分 r₂(t) = (1, t) の寄与は (−t, 1)·(0, 1) = 1 なので仕事は1です。

経路を選ぶ問題と仕事の範囲

二本の道で値が違うことを見たので、今度は同じ端点のまま道の形を連続的に選びます。これは自作の経路比較で、座標と場の数値は共通の無次元尺度とします。

例題3：経路の形を変えて、望む仕事へ近づける

F=(−y,x)とし、rₚ(t)=(t,tᵖ)、0≤t≤1、実数p≥1を選びます。速度は(1,ptᵖ⁻¹)、場は(−tᵖ,t)だから、内積は(p−1)tᵖ。したがって仕事はW(p)=(p−1)/(p+1)です。p=1では道と場が直交して0、p=2では1/3、p=3では1/2になります。

Wを増やすには何を変えるべきでしょう。W(p)=1−2/(p+1)だから、pを大きくすると仕事は増え、1へ近付きます。ただし有限のpでは1になりません。右へ進んでから上がる折れ線の仕事1は、個々の滑らかな曲線の仕事と区別します。曲線の極限と積分の極限の一般定理を、この式だけで証明したことにもなりません。

仕事をちょうど1/3にするpは、3(p−1)=p+1を解いてp=2。負の仕事をこの族で作れないのは、p≥1では被積分関数が非負だからです。欲しい値が出ないときには、計算の失敗を疑うだけでなく、選んだ経路の範囲を見直します。

次の表では、端点と場を固定したとき何が変わったかを読んでください。二本の道の差は、片方を往路、もう片方の逆向きを復路にした閉曲線の仕事です。

勾配場の線積分と基本定理

線積分の基本定理

開集合 U 上で φ が C¹、F = ∇φ とします。C は U に含まれる区分 C¹ 曲線で、始点 A、終点 B を持つとします。このとき ∫CF·dr = φ(B) − φ(A) です。

一変数の基本定理へ戻す

各 C¹ 部分で連鎖律により (φ(r(t)))′ = ∇φ(r(t))·r′(t)。一変数の微積分の基本定理を使えば、その部分の積分は両端での φ の差です。有限個の部分を足すと、隣り合う端点の値は打ち消し合い、最初と最後の値だけが残ります。

例えば φ = (x² + y² + z²)/2 なら F = (x, y, z)。原点から (1, 1, 0) までの仕事はどんな許された道でも1です。閉曲線なら始点と終点が同じなので0。反対に、直線と折れ線の比較での (−y, x) の二つの仕事は異なるので、この平面全体でその場を勾配とする C¹ 関数は存在しません。次章では、どんな場が勾配になるかを定義域の形も含めて調べます。

F=∇φ と表せるとき、この φ を場 F のポテンシャルと呼びます。端点の φ の差が仕事を表すので、場の各成分を別々に積分する代わりに、一つの関数へまとめられます。次章は、そのような φ を作れる条件を調べます。

例題4：端点法を選び、微分で検算する

F=(2xy,x²,2z)でA=(1,0,1)からB=(2,1,0)へ進むとします。最初の二成分の形から、x²yを微分すると2xyとx²を同時に作れると気付きます。残る2zはz²の微分です。候補φ=x²y+z²を全成分で微分して、確かに∇φ=Fと確認します。

φはℝ³でC¹なので、どんな区分C¹の道でも仕事はφ(B)−φ(A)=4−1=3。道が指定されていないため困る問題ではなく、指定されなくても計算できる場を見分ける問題です。検算としてA→(2,0,1)→(2,1,1)→Bの折れ線を使うと、x区間はy=0なので0、y区間は∫₀¹4dy=4、z区間は∫₁⁰2zdz=−1となり、合計3です。

寄り道［数学の見方］：消えるのは道か、途中の値か

勾配場の線積分でも、道は計算の中から最初から消えているわけではありません。各小部分では場も速度も道に依存します。連鎖律により「一つの関数の変化率」になったため、基本定理を適用したあとで中間の値が消えます。

端点だけで決まる性質を見つけたいときには、被積分関数を「何かの微分」に戻せるかが手がかりです。これは実一変数の積分と同じ発想ですが、多変数では定義域に穴がある場合の注意が加わります。

出典：本章の連鎖律と基本定理の証明を言い換えたものです。

演習：線積分・向き・端点

1．定数場の折れ線の仕事

F = (2, −1, 3) の下で、A = (0, 0, 0) から任意の区分 C¹ 曲線で B = (1, 2, −1) へ進む仕事と、戻る仕事を求めてください。

ヒント1：成分の基本定理

定数場では ∫F·r′dt = F·∫r′dt です。

ヒント2：変位全体

B − A = (1, 2, −1)。このベクトルとの内積を取ります。

解答

仕事は 2·1 − 1·2 + 3·(−1) = −3。戻る道では向きが逆なので3です。φ = 2x − y + 3z を使っても同じ結果です。

2．円を逆にたどる

F(x, y) = (−y, x)、r(t) = (cos t, sin t)、0 ≤ t ≤ 2π の線積分と、その逆向きの値を求めてください。

ヒント1：場と速度

どちらも (−sin t, cos t) になります。

ヒント2：内積の値

sin²t + cos²t = 1 です。

解答

F(r)·r′ = 1 なので積分は2π。逆向きは−2πです。弧長は両方2πですが、仕事には向きが残ります。閉曲線の積分が非零なので、この場は平面全体で勾配ではありません。

3．空間の道を計算せずに積分する

φ(x, y, z) = xy + z²、F = ∇φ とします。A = (1, 0, 1) から B = (2, 3, −1) へ進む任意の区分 C¹ 曲線の仕事を求め、必要な仮定を述べてください。

ヒント1：ポテンシャルの値

φ(A) = 1、φ(B) = 6 + 1 です。

ヒント2：適用する定理

φ は ℝ³ 全体で C¹、曲線はその領域内にあります。

解答

F = (y, x, 2z)、仕事は φ(B) − φ(A) = 7 − 1 = 6。φ の C¹ 性と曲線の区分 C¹ 性から連鎖律と基本定理を各部分で使えます。曲線の具体的な形や速さを決める必要はありません。

4．速さを変えた計算の診断

例題1の道をη(s)=(2s,4s²)、0≤s≤1/2と表した人が、元の被積分関数へt=2sだけを代入してs=0から1/2までの∫(4s+16s³)dsを仕事としました。誤りを特定して正しい仕事を求めてください。

ヒント1

η(s)=r(2s)です。場と速度を別々に求めます。

ヒント2

F(η)=(4s,4s²)、η′=(2,8s)です。

解答

内積は8s+32s³で、積分は4(1/2)²+8(1/2)⁴=1+1/2=3/2。誤った式は元の被積分関数2t+2t³へt=2sだけを代入し、dt=2dsを落としています。新旧の曲線は同じ向きに同じ道を一回通るので、結果が例題1と一致することも検算です。

5．仕事と力の大きさを区別する

F=(−y,x)と単位円の反時計回り一周で、仕事と∫‖F‖dsが一致します。「この二つはいつでも等しい」という主張を、Fを変えず向きだけ変えて診断してください。

ヒント1

時計回りの仕事と長さをそれぞれ計算します。

ヒント2

単位円上の‖F‖は1で、dsは向きを反転しても変わりません。

解答

反時計回りはどちらも2πですが、時計回りの仕事は−2π、∫‖F‖dsは2πです。元の一致は場と正向き接線が平行で同じ向きだったためです。逆向きでは反対になるので、非負の大きさを足す積分で仕事を表せません。

6．観測した仕事から経路を逆算する

F=(−y,x)、rₚ(t)=(t,tᵖ)、0≤t≤1、p≥1で仕事が3/5でした。pを求めて代入検算し、この族で仕事−1/2を作れるか説明してください。

ヒント1

例題3の式を、pについての方程式にします。

ヒント2

(p−1)/(p+1)=3/5、またこの式の分母は正です。

解答

5p−5=3p+3よりp=4。実際、内積は3t⁴で∫₀¹3t⁴dt=3/5です。p≥1では分子が非負なので−1/2は作れません。p≥1という条件を忘れて形式的に解くことは、許されない道を選ぶことになります。

7．ポテンシャルがあるときの二通りの計算

F=(y,x)、A=(0,0)、B=(1,1)とします。φ=xyを使う方法と、r(t)=(t,t²)、0≤t≤1を使う方法で仕事を求めてください。F=(−y,x)の場合との違いも述べてください。

ヒント1

∇(xy)を計算し、別にF(r)·r′を計算します。

ヒント2

直接法では(t²,t)·(1,2t)=3t²です。

解答

∇φ=(y,x)なので端点法はφ(B)−φ(A)=1。直接法も∫₀¹3t²dt=1です。ℝ²でφはC¹なので、この場では全経路で同じです。F=(−y,x)では同じ放物線の仕事は1/3、直線では0で、先頭成分の負号が経路独立性を変えます。

8．一周と往復を見分ける

F=(−y,x)の下で、原点から(1,1)へ右→上の折れ線で進み、直線で原点へ戻り、同じ周回をもう一度します。総仕事はいくらですか。同じ折れ線をそのまま逆に戻る場合と比較してください。

ヒント1

道の連結では積分を足せます。帰路の向きを確認します。

ヒント2

折れ線は1、直線はどちら向きでも0。折れ線の逆向きは−1です。

解答

一周は1+0=1なので二周で2です。同じ折れ線を逆に戻るなら1−1=0で、一往復を二回しても0。どちらも始終点は原点ですが、一般の場では「閉曲線だから0」とは言えません。勾配場であるという追加情報が必要です。

9．望む仕事を折れ線で設計する

F=(−y,x)、0≤a≤1とし、(0,0)→(a,0)→(a,1)→(1,1)の三線分をこの順に進みます。仕事W(a)を求め、W=3/5となるaを選び、実現できる仕事の範囲も求めてください。

ヒント1

水平線分ではdy=0、垂直線分ではdx=0です。

ヒント2

最初は0、中央はa、最後は−(1−a)です。

解答

W(a)=0+a−(1−a)=2a−1。W=3/5にはa=4/5が必要で、0≤a≤1も満たします。実際、中央4/5、最後−1/5で合計3/5。a=0で−1、a=1で1、Wは連続な一次式なので全範囲は[−1,1]です。経路族を選ぶことで、例題3では出せなかった負の仕事も設計できます。
