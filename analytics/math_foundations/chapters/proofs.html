命題の証明と証明方法の選択

計算してみると正しそうなのに、どう説明すればよいか分からない。証明で最初に困るのは、式を知らないことより、どこから出発し、どこへ着けばよいかが見えないことです。前提を P、結論を Q とすると、P ⇒ Q を示す方法は一つではありません。ここでは直接示す方法、対偶を使う方法、矛盾を導く方法を比べます。

学習の目安は演習込み110–170分です。直接証明と式変形、対偶、背理法の三段階に分けても読めます。演習1–3は基本、4–7は証明の構成と誤りの診断、8–10は仮定の変更と条件の設計です。

どの方法でも、前提と結論の間に、読者が確認できる橋を架けます。証明は心の中でひらめいた順番をそのまま記録するものではありません。考えるときは結論から逆算してもかまいませんが、完成した文章では、まだ示していない結論を理由として使わないように整理します。

直接証明と定義の展開

直接証明では前提を仮定し、そこから結論へ進みます。「偶数二つの和は偶数」を示すなら、偶数という言葉を 2 の倍数という定義に戻すと、計算の出発点ができます。

偶数の和の直接証明

a、b を偶数の整数とします。ある整数 r、s があって a = 2r、b = 2s と書けます。すると a + b = 2(r + s)。整数の和 r + s も整数なので、a + b は 2 の倍数、つまり偶数です。

「整数の和は整数」という一見小さな一文にも役割があります。偶数であるためには、単に 2 を掛けた形にするだけでなく、その相手が整数である必要があるからです。前提の範囲や、定義の各条件を最後まで確認すると、式の見た目だけに頼った説明を避けられます。

平方の非負性と不等式の直接証明

定義を開いても、そのまま計算できるとは限りません。実数a、bについてa²+b²≥2abを示すには、結論の左右を見比べ、非負だと分かる一つの式にまとめることを考えます。実数tの平方t²は0以上で、0になるのはt=0の場合だけです。この既知の事実へ結び付けたいのです。

例題：結論から探し、既知の事実から書く

考える途中では、目標をa²+b²−2ab≥0と書き直し、左辺が(a−b)²だと気付けます。これは証明の発見であり、目標を正しいと仮定したことにはしません。完成した証明は、任意の実数a、bに対して(a−b)²≥0から始めます。展開してa²−2ab+b²≥0、両辺に2abを加えるとa²+b²≥2abです。

等号がいつ起きるかも、出発点へ戻れば分かります。(a−b)²=0とa=bは同じなので、等号条件はa=bです。a=−3、b=−3でも18=18、a=1、b=−1なら2>−2。aとbが正だという仮定は使っていないので、全実数で成り立ちます。

右辺の係数2を3へ強められるでしょうか。a=b=1なら2≥3となって失敗します。2を選んだのは単なる慣習ではなく、等しい入力で境界に達するからです。ただし、係数を小さくすれば全実数で必ず成立する、とは言えません。abが負なら右辺の大小も逆向きに変わるためです。この条件の違いは演習10で調べます。

結論を見て使えそうな形を探すことと、結論を根拠にして結論を出すことは異なります。最後に「既知の事実→展開→目標」の向きで読み直せるなら、探索を逆向きにしても循環論法にはなりません。

含意と同値変形の区別

式を変形するとき、元の条件から新しい条件へ進めるだけなのか、逆にも戻れるのかを分けます。前者が含意、両方向へ進める場合が同値です。両辺へ同じ数を足す操作は逆に引けますが、二乗する操作は符号の情報を失うので、条件なしには元へ戻れません。−1と1は異なるのに、平方は同じ1になるからです。

例題：平方根を含む方程式を解く

実数xについて√(x+2)=xを解きます。√uはu≥0で定義される非負の平方根です。まずx+2≥0が必要で、さらに左辺が非負なので解ならx≥0です。根号を消す方針を選び、解が満たす必要条件として両辺を二乗すると、x+2=x²、x²−x−2=0、(x−2)(x+1)=0となります。従って候補はx=2、−1です。

候補を元の式へ戻すと、x=2は√4=2で解、x=−1は√1=1≠−1で解ではありません。ゆえに解はx=2だけです。二乗後の候補をすべて拾い、そのうち元の条件を満たすものだけを残したので、漏れも余計な解もありません。

初めからx≥0を保てば、「√(x+2)=x」と「x≥0かつx+2=x²」は同値と書けます。後者から前者へは、平方根を取って√(x+2)=√(x²)=xと戻れます。ここで√(x²)=xにx≥0を使っています。条件を外して√(x²)=xと書くと、x=−1で誤りになります。

対偶による証明と逆命題との違い

P ⇒ Q と同じ真偽を持つ主張が「Q でない ⇒ P でない」で、これを対偶と呼びます。どちらも、P が真で Q が偽という場合だけを排除しているため、同じ意味になります。論理で見た逆 Q ⇒ P は、これとは別の主張です。

平方が偶数なら、元の整数も偶数

整数 n に対し、n² が偶数なら n も偶数です。

対偶による短い証明

対偶「n が偶数でないなら、n² も偶数でない」を示します。整数が偶数でなければ奇数なので、n = 2k + 1 と書けます。n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1 で、括弧内は整数です。よって n² は奇数です。対偶が示せたので、元の主張も成り立ちます。

この証明の前提を実数へ広げてはいけません。たとえば n = √2 の平方は整数の偶数 2 ですが、n 自身を整数の偶数と呼ぶことはできません。どの世界で「偶数でないなら奇数」と言えたのかが重要です。証明の途中で使った事実をたどると、必要な前提が見えてきます。

背理法と素数の無限性

背理法では、示したい主張が偽だと仮定し、認めた事実と両立しない結論を導きます。P ⇒ Q を示す場合なら、P と「Q でない」を一緒に仮定して矛盾を導きます。矛盾が出るまでは、仮定した反対の主張を一時的に使ってよいのです。最後に、その仮定を捨てることを明示します。

素数は、1 より大きい正の整数で、正の約数が 1 と自分自身だけのものです。次に「素数は無限にある」を示します。その前に、どんな整数 N > 1 にも素数の約数があることを確認しましょう。N の 1 より大きい約数の中で最小のものを d とします。もし d が素数でなければ d = ab、1 < a < d と分解でき、a も N の約数となって最小性に反します。したがって d は素数です。ここでは正の整数の空でない集合には最小要素があるという性質を使いました。

素数が無限にあることの証明

素数が有限個しかないと仮定し、そのすべてを p₁、p₂、…、pₖ と並べます。2 が素数なので、このリストは空ではありません。N = p₁p₂⋯pₖ + 1 と置くと N > 1 です。上で示した事実により N は素数の約数 q を持ちます。しかし各 pᵢ で N を割ると余りが 1 なので、q はリストのどの pᵢ とも等しくありません。すべて並べたはずなのに別の素数が見つかり、矛盾します。よって素数は有限個ではなく、無限にあります。

この証明は N 自身が素数だとは主張していません。必要なのは、N の素数の約数がリストの外にあることです。ここを強く言い過ぎると、正しい証明が別の誤った予想へ変わります。結論に必要な分だけを確実に示すことも、証明を短く保つ技術です。

背理法で「おかしい気がする」と書くだけでは不十分です。何と何が両立しないのかを指定します。この証明では「すべての素数はリストにある」と「リストの外に素数 q がある」の衝突です。また、式を割るときには割る数が 0 でないか確認してください。正しそうな式変形でも、許される条件を外すと矛盾らしいものを人工的に作れてしまいます。

背理法と平方根の無理性

背理法を選ぶ理由がはっきりする、もう一つの問題を考えます。有理数とは、整数p、qを用いてp/q（q≠0）と表せる実数、無理数とは有理数でない実数です。√2が無理数であることを直接示そうとすると、「どんな整数の比にも等しくない」という無数の候補を一度に相手にする必要があります。反対に有理数だと仮定すれば、等式を一つ手に入れられます。

整数の比は分母を正にし、共通する1より大きい整数で割って、それ以上約分できない形にできます。この形を既約分数といいます。約分するたびに正の整数の分母が小さくなるので、いつまでも約分し続けることはありません。既約なら分子と分母が両方偶数ということはない、という条件を使います。

例題：仮定した分数表示から何と矛盾するか

√2が有理数だと仮定し、√2=p/qを既約分数で表します。qは正の整数です。両辺を二乗して2=p²/q²、q²を掛けてp²=2q²。従ってp²は偶数です。対偶の節で示した「平方が偶数なら元も偶数」を使うと、p=2kと書けます（kは整数）。

代入すると4k²=2q²、2で割ってq²=2k²。今度はq²が偶数なのでqも偶数です。pとqの両方が2で割れることになり、既約という条件に矛盾します。従って有理数だという仮定が誤りで、√2は無理数です。

「分子と分母が両方偶数だからおかしい」というだけでは十分ではありません。例えば2/4は正当な分数で、両方偶数です。矛盾するのは既約として選んだ表示なのに両方偶数になったという二つの条件です。反対の仮定だけでなく、最初に何を選んだかも証明に必要でした。

同じ書き方を√4へ使おうとすると失敗します。p²=4q²からpが偶数とは分かりますが、p=2kを代入するとk²=q²になり、qが偶数とは言えません。実際√4=2/1です。背理法は反対の仮定を置けば自動的に矛盾する手順ではなく、命題が正しい理由を計算で突き止める方法です。

寄り道［背景］：ユークリッドは「積に1を足せば素数」とは言っていない

ユークリッド『原論』第9巻命題20には、与えられた有限個の素数より多くの素数がある、という議論が載っています。既知の素数すべてで割れる数に 1 を足し、それ自身が素数の場合と、素数でない場合を分けます。後者でも、その素因数が元の一覧にないと示せば十分なのです。

例えば 2·3·5·7·11·13 + 1 = 30031 は、59·509 に分解でき、素数ではありません。それでも 59 も 509 も、元の六つのどれでもありません。「新しい素数を含む」と「その数自身が素数」は別の主張です。古い証明を読む面白さは、結論だけでなく、必要なことだけを正確に言い切る設計にもあります。

出典：『原論』IX.20、Clark University 公開本文。

演習：直接証明・対偶・背理法

1．同値には二つの向きがある

整数 n について、「n が偶数であること」と「n² が偶数であること」が同値であると証明してください。

ヒント1：二本の矢印に分ける

n が偶数 ⇒ n² が偶数、と、その逆を別々に示します。

ヒント2：片方は本文で示した

逆向きには対偶の証明が使えます。順向きは n = 2k と置きます。

解答

n = 2k なら n² = 4k² = 2(2k²) で偶数です。逆に n² が偶数なら、本文の対偶による証明から n は偶数です。両方向が成り立つので同値です。一方向だけでは同値の証明になりません。

2．有理数を足しても隠れない

有理数は整数どうしの比（分母は 0 以外）で表せる実数、無理数はそうでない実数です。r を有理数、α を無理数とします。r + α は無理数であることを示してください。有理数どうしの差は有理数である事実を使ってかまいません。

ヒント1：反対を仮定する

r + α が有理数 q だと仮定してみます。

ヒント2：α を一方に残す

α = q − r と書けたら、右辺はどの種類の数ですか。

解答

r + α = q が有理数だと仮定すると、α = q − r です。q、r は有理数なので右辺も有理数ですが、これは α が無理数であるという前提に矛盾します。したがって r + α は有理数ではなく、無理数です。

3．どこで条件を失ったか

a = b = 1 とします。「a² = ab なので a² − b² = ab − b²。因数分解し、a − b を消すと a + b = b。よって 2 = 1」という議論の誤りを指摘してください。

ヒント1：消したものの値を調べる

a − b はこの設定でいくつですか。

ヒント2：約分は割り算である

(a − b)(a + b) = b(a − b) の両辺を何で割りましたか。

解答

a − b = 0 です。a − b を消した箇所で 0 による割り算をしており、許されません。そこまでの式は 0 = 0 を述べているだけで、a + b = b は導けません。矛盾が出ても、途中の操作が正当でなければ背理法にはなりません。

4．同じ文字を使ってよいか

「奇数a、bはa=2k+1、b=2k+1と書けるので、a+b=4k+2は偶数」という証明案を診断し、任意の二つの奇数について正しい証明に直してください。

ヒント1

同じkで二つの数を表すと、aとbにどんな関係を課しますか。

ヒント2

a=2r+1、b=2s+1と別々の整数を使います。

解答

同じkを使うとa=bの場合しか扱えず、例えばa=1、b=3を表せません。任意の奇数a、bについて整数r、sを用いてa=2r+1、b=2s+1と置きます。するとa+b=2(r+s+1)。r+s+1は整数なので偶数です。誤った案でも結論自体は正しいですが、すべての対象を覆った証明にはなっていません。

5．等号条件まで運ぶ

実数x、yについてx²+4y²≥4xyを証明し、等号条件を求めてください。x、yが非負である必要があるかも説明してください。

ヒント1

左辺から右辺を引き、平方へまとめます。

ヒント2

x²−4xy+4y²=(x−2y)²です。

解答

実数x−2yの平方は非負なので、(x−2y)²=x²−4xy+4y²≥0。両辺に4xyを加えれば目標です。等号はx−2y=0、すなわちx=2yの場合に限ります。非負の仮定は使っていません。例えばx=−2、y=−1でも等号となります。平方が0となる条件まで保持することで、不等式だけより詳しい結論が得られます。

6．二乗した後の候補を検査する

実数xについて√(x+6)=xを解いてください。二乗による候補と元の方程式の解を区別し、条件付きの同値としても書いてください。

ヒント1

解なら右辺xも非負です。その条件を残して二乗します。

ヒント2

x²−x−6=(x−3)(x+2)です。

解答

解ならx≥0で、二乗するとx+6=x²、従ってx=3または−2です。x=3は√9=3で解ですが、−2は√4=2≠−2で解ではありません。よって解は3だけ。「√(x+6)=x」は「x≥0かつx²=x+6」と同値です。逆向きにはx²=x+6≥0から平方根を取り、x≥0なので√(x²)=xとできます。因数分解だけで二つとも解とすると余分な候補を残します。

7．誤った結論を最小限修正する

整数a、bについて「abが偶数ならaが偶数」は偽です。反例を示した上で、結論を「aまたはbの少なくとも一方が偶数」へ修正し、対偶で証明してください。

ヒント1

aが奇数でもbが偶数なら、積は偶数になります。

ヒント2

修正した結論の否定は、aとbがともに奇数であることです。

解答

a=1、b=2なら積2は偶数でもaは奇数なので、元の文の反例です。修正した文の対偶は「a、bがともに奇数ならabは奇数」。a=2r+1、b=2s+1と置けばab=4rs+2r+2s+1=2(2rs+r+s)+1。括弧内は整数なので積は奇数です。対偶が成り立つため修正後の主張は真です。「少なくとも一方」の否定を「少なくとも一方が奇数」としないことが要点です。

8．非零という仮定は何を守るか

rは0でない有理数とします。r√2が無理数であることを示してください。r=0を許すとどうなるかも説明してください。有理数どうしの商は、割る数が0でなければ有理数であることを使えます。

ヒント1

r√2が有理数qだと仮定し、√2を一方へ残します。

ヒント2

√2=q/rです。本文で示した無理性と比べます。

解答

r√2=qが有理数と仮定すると、r≠0より√2=q/r。有理数の非零有理数による商は有理数なので、√2の無理性に矛盾します。よってr√2は無理数です。r=0なら積は0という有理数で、結論は失敗します。さらにq/rという操作自体もできなくなります。非零条件は計算の正当性と主張の真偽の両方に必要です。

9．与えられた数より大きい素数

Mを正の整数とし、M!=1·2⋯Mと定義します。N=M!+1の素数の約数qを取り、q>Mを証明してください。N自体が素数である必要があるか、M=5とM=1で検算してください。

ヒント1

N>1なので素数の約数があることは本文で示しました。q≤Mだと仮定します。

ヒント2

q≤MならqはM!の因子です。NとM!の両方を割るなら、その差1も割ることになります。

解答

もし素数q≤Mなら、積1·2⋯Mに因子qが含まれるのでqはM!を割ります。qはNも割るため、N−M!=1を割ることになります。しかしq>1で1は割れず、矛盾。従ってq>Mです。Nが素数である必要はなく、その素数の約数を使うだけです。M=5ではN=121=11²で、素因数11は確かに5より大きいものの、N自体は合成数です。M=1ではN=2で、q=2>1となり境界でも成り立ちます。

10．成立する係数をすべて設計する

実数cについて、すべての実数x、yでx²+y²≥cxyが成り立つ条件を求めてください。次にx、yを非負実数だけへ制限すると、cの範囲がどう変わるか調べてください。必要条件だけで止めず、十分性も示してください。

ヒント1

x=y=1とx=1、y=−1を代入し、cの上下の条件を調べます。

ヒント2

実数全体ではxy≥0とxy<0に場合分けし、(x−y)²≥0と(x+y)²≥0を使えます。非負範囲では後者の符号の場合がなくなります。

解答

全実数の場合、x=y=1からc≤2、x=1、y=−1からc≥−2が必要です。逆に−2≤c≤2とします。xy≥0ならcxy≤2xy≤x²+y²で、最後は(x−y)²≥0によります。xy<0ならc≥−2に負のxyを掛けてcxy≤−2xy、さらに(x+y)²≥0から−2xy≤x²+y²。両場合を覆うので十分です。全解は−2≤c≤2です。

非負のx、yだけならxy≥0しかないので、c≤2で同じ最初の議論が使えます。x=y=1からc≤2が必要でもあるため、全解はc≤2です。下限はありません。例えばc=−3は非負範囲で成立しますが、全実数ではx=1、y=−1に対して2≥3となり失敗します。範囲の変更が証明でどの分岐を消すかを見ています。

  2. 素数の証明で、N 自身が素数である必要がないのはなぜですか。
  3. 背理法で矛盾を見つけたとき、どの仮定を捨てるのかをどう確認しますか。
