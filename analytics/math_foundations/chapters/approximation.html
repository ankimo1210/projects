近似値と誤差評価

f(x) = x² を x = 1 の近くで計算するなら、接線 y = 1 + 2(x − 1) が使えます。x = 1.1 では 1.2 と見積もれますが、本当の値は 1.21。誤差は 0.01 でした。近くで使えばよさそう、という感覚を、計算する前の保証へ変えられるでしょうか。

微分可能性は、誤差が入力の変化より速く小さくなると述べますが、それだけでは「0.1 動かしたら何桁合うか」は分かりません。そこで、区間内の高い階数の導関数を抑えます。近似式を作ることと、近似の誤差を保証することを、分けて考えましょう。

計算したい値が1.21だと分かっていない場面では、近似値だけを返されても、どこまで信用できるか判断できません。この章では「誤差を0.001以下にしたい」という注文から、一次か二次か、中心をどこに置くか、何回反復するかを選びます。近似値・保証幅・その幅が成り立つ条件を一組として扱います。

学習の目安は演習を含めて120–170分です。有限Taylor近似と評価、精度からの方法選択、Newton法の検証と演習の三回に分けられます。演習1–3は基本、4–7は誤差と条件の診断、8–10は停止の保証・逆算・方法比較です。無限Taylor級数の収束や一般のNewton法の収束定理を前提にはしません。

線形近似・二次近似と剰余の評価

f′ をもう一度微分したものが二階導関数 f″、さらに微分したものが三階導関数 f‴ です。点 a から x = a + h までの閉区間を S とします。h が負のときは S = [x, a] です。以下では、必要な導関数が S を含む開区間で存在すると仮定します。

冒頭の平方を x=1+h と書けば、(1+h)²=1+2h+h² です。1+2hで止めた一次式を P₁、二次の項まで残す式を P₂ と呼びます。元の値から近似式を引いた残りが剰余です。この例の一次の剰余はh²、二次では0。次の定理は、同じ区別を一般の関数で行い、残りを導関数で上から押さえます。

以下の一次式は、変数 t に対して P₁(t)=f(a)+f′(a)(t−a) と書きます。t=x=a+h を入れると、P₁(x)=f(a)+f′(a)h です。

有限の Taylor 近似の誤差評価

f が二回微分可能で、S 全体で |f″(t)| ≤ M₂ なら、一次式 P₁(x) = f(a) + f′(a)h の誤差は M₂|h|²/2 以下です。さらに f が三回微分可能で、S 全体で |f‴(t)| ≤ M₃ なら、二次式 P₂(x) = f(a) + f′(a)h + f″(a)h²/2 の誤差は M₃|h|³/6 以下です。

|f(x)−P1(x)|≤M22|h|2,|f(x)−P2(x)|≤M36|h|3

Rolle の定理を繰り返す短い証明

h = 0 なら両方の誤差は 0 です。h ≠ 0 とし、まず一次式との差 R = f(x) − P₁(x) に対して C = R/h² と置きます。F(t) = f(t) − P₁(t) − C(t − a)² は F(a) = F(x) = 0、かつ F′(a) = 0 を満たします。Rolle の定理で F′ に a と x の間の零点ができ、それと a の間でもう一度使えば F″(ξ) = 0 となる点 ξ が得られます。よって C = f″(ξ)/2、R = f″(ξ)h²/2 で、主張の上限が従います。

二次式でも C = {f(x) − P₂(x)}/h³ と置き、F(t) = f(t) − P₂(t) − C(t − a)³ を考えます。今度は F(a)、F′(a)、F″(a) がすべて 0、さらに F(x) = 0 です。Rolle を三回使うと F‴(ξ) = 0、つまり C = f‴(ξ)/6。これで二次の評価も得られます。必要な連続性は、仮定した微分可能性から従います。

f(x) = x² では f″ = 2、f‴ = 0 です。一次近似の誤差は |h|² 以下で、冒頭の h = 0.1 なら 0.01 以下と事前に保証できます。二次近似は元の多項式そのものなので誤差 0 です。一般の関数では、二次式が厳密な値になるとは限りません。

導関数の上限は点 a だけでなく、a から x までの区間全体で必要です。例えば f(t) = Kt³ の a = 0 では、どんな K でも f″(0) = 0 ですが、f(h) と一次式 0 の差は K h³ です。一点の二階導関数だけでは、一定の幅での誤差を共通に抑えられません。また有限の近似の定理だけから、無限に項を足せば必ず元の関数に戻るとは言えません。それはTaylor 級数で別に調べます。

多項式の剰余から近似の次数を選ぶ

誤差の上限を使うには、まず中心aと計算したいxを決め、両者を含む区間で導関数を押さえます。中心でのf(a),f′(a),f″(a)は近似式を作る情報、区間全体のM2,M3はその誤差を保証する情報です。両者を混ぜると、よい式が書けても保証が抜け落ちます。

例題：立方の近似に必要な項数を決める

f(x)=x³をa=1の周りで近似します。f(1)=1、f′(1)=3、f″(1)=6なのでP1(1+h)=1+3h、P2(1+h)=1+3h+3h²です。展開から真の値は1+3h+3h²+h³。従って一次の剰余は3h²+h³=h²(3+h)、二次はh³と、正確に分かります。

|h|≤0.1という入力範囲なら0.9≤t≤1.1で|f″(t)|=6t≤6.6、|f‴(t)|=6です。定理による保証は一次で3.3|h|²以下、二次で|h|³以下。x=1.1ではP1=1.3、P2=1.33、真の値1.331なので誤差は0.031と0.001です。二次なら注文「0.001以下」を満たしますが、一次の保証0.033だけでは満たせるとは言えません。この例では実際の一次誤差も注文を超えています。

x=0.9でも同じ区間上の保証が使えます。P1=0.7、P2=0.73、真の値0.729。一次の誤差は0.029、二次は0.001です。hが負だと二次の剰余h³も負ですが、絶対誤差の上限は|h|³なので変わりません。符号を捨てる前の式は、過大評価か過小評価かも教えます。

逆算すると、同じ中心で二次式の誤差を0.000001以下にしたいなら、|h|³≤0.000001から|h|≤0.01で十分です。一次式なら3.3|h|²≤0.000001を満たす必要があり、たとえば|h|≤0.0005なら上限0.000000825です。計算項数を減らす代わりに使える入力範囲が狭くなる、という選択が見えます。

分母を保つ近似と代数的な誤差評価

高い階数の導関数を使う方法だけが評価の道ではありません。関数の形が分かるなら、差を直接整理して、より鋭い保証を得られることがあります。f(x)=1/xをa=1で考えます。ここではx=0を定義域から除き、|h|≤0.1に限るので1+h≥0.9>0を確保します。

例題：逆数の近似を二通りに保証する

f′(x)=−1/x²、f″(x)=2/x³、f‴(x)=−6/x⁴から、P1=1−h、P2=1−h+h²です。区間[0.9,1.1]で|f″|≤3、|f‴|≤10と押さえられるので、Taylorの評価は一次で(3/2)h²以下、二次で(5/3)|h|³以下です。たとえば2/0.9³<3、6/0.9⁴<10から上限を検算できます。

一方、差を通分すると1/(1+h)−(1−h)=h²/(1+h)、1/(1+h)−(1−h+h²)=−h³/(1+h)です。分母1+h≥0.9から、一次誤差は(10/9)h²以下、二次は(10/9)|h|³以下。導関数で選んだ上限より狭い保証を得ました。両方とも正しいのですが、直接の式は分母という情報をより詳しく使っています。

x=1.1なら一次値0.9、二次値0.91。正確な値10/11との差はそれぞれ1/110、−1/1100で、絶対誤差は約0.00909と0.000909です。誤差0.001以下という注文なら、二次値と直接評価の上限1/900（約0.00111）だけでは、まだ保証できません。しかしこの点で分母を正確に1.1と使えば上限は1/1100で、注文を満たすと分かります。全区間共通の保証と、一点だけの保証の違いです。

式を高次まで作る前に、差を簡単に整理できるか、分母が0からどれだけ離れているかを確認します。|h|が1へ近付く側ではこの共通の分母の評価を失うので、小さいhでよかった近似を定義域全体へ広げることはできません。

方程式に対するNewton法

近似の別の使い方が、f(x) = 0 の根を探すことです。現在の推定値 xₙ の近くで、f(x) を f(xₙ) + f′(xₙ)(x − xₙ) に置き換えます。この直線が 0 になる点を次の推定値にすると、Newton 法を得ます。ただし f′(xₙ) ≠ 0 が必要です。

次の点 xₙ₊₁ を得るには、この一次式で0を目指して 0=f(xₙ)+f′(xₙ)(xₙ₊₁−xₙ) と置きます。f(xₙ)を移項し、0でない f′(xₙ) で割れば、次の更新式になります。元の曲線の零点でなく、接線の零点をまず解いているのです。

xn+1=xn−f(xn)f′(xn)

f(x) = x² − 2 なら f′(x) = 2x なので、xₙ₊₁ = (xₙ + 2/xₙ)/2 です。x₀ = 1 から始めると x₁ = 3/2、x₂ = 17/12 となります。連続性の章で存在を確認した正の根 r = √2 に、少ない更新で近づきます。

更新式から r を引くと、分母は 2xₙ、分子は xₙ²−2rxₙ+2 です。r²=2 より分子は (xₙ−r)² となります。

従って、xₙ₊₁ − r = (xₙ − r)²/(2xₙ)。x₀ > 0 なら全項が正で、最初の更新後は xₙ ≥ r です。また xₙ ≥ r のとき次の項は xₙ 以下。よって以後は単調減少で下に有界であり、極限 L が存在します。更新式の極限を取ると L² = 2、L > 0 なので L = r です。

誤差の式は、根の近くでは次の誤差が今の誤差の二乗に比例することも示します。ただしこれは、この関数・正の初期値・正確な計算という条件の下の結論です。繰り返し式を書けたことだけでは、一般の収束は保証されません。

残差と根の誤差を区別して反復を止める

方程式f(x)=0の近似値qに対し、|f(q)|を残差と呼びます。これは式がどれだけ0から外れたかであり、根rとの距離|q−r|そのものではありません。たとえばf(x)=0.000001(x−10)なら、q=0で残差は0.00001でも根までの距離は10です。関数全体を小さく掛けただけで残差も小さくなるため、距離の保証には追加情報が要ります。

例題：√2のNewton法に精度保証を付ける

f(x)=x²−2の正の根rが[1,2]にあることを、端の符号と連続性から確かめておきます。近似値qも[1,2]なら、平均値の定理でf(q)−f(r)=f′(ξ)(q−r)となるξが間にあります。f′(ξ)=2ξ≥2なので、|q−r|≤|q²−2|/2です。これで計算できる残差を、根の距離の上限へ変えられます。

x0=1からの更新はx1=3/2、x2=17/12、x3=(17/12+24/17)/2=577/408です。x2の残差は(289−288)/144=1/144、従って誤差上限は1/288。一方、x3の残差は(577²−2·408²)/408²=1/166464で、誤差上限は1/332928<0.00001です。整数の二乗と割り算だけで、この精度を保証できました。

二回目が本当に注文を満たさないことも確認できます。x2>rなのでx2−r=(x2²−2)/(x2+r)。r≤2から分母はx2+2以下であり、誤差は少なくとも(1/144)/(41/12)=1/492>0.00001です。上限で証明できなかっただけなのか、実際に不十分なのかを、この下限で分けられます。

一般に、qとrの間で|f′|≥m>0が分かれば、同じ平均値の議論で|q−r|≤|f(q)|/mです。根の存在、qとrが同じ評価区間にあること、導関数が0から離れていることを確かめて使います。mが小さければ、同じ残差でも距離の保証は広くなります。

二分法なら、根を挟む区間[1,2]をn回半分にした幅は2−nです。その中点を返せば誤差は2−n−1以下。n=16なら1/131072<0.00001なので十分です。この問題のNewton法は少ない更新で済みますが、二分法は区間の符号と連続性から幅の保証を持ち続けます。速さと、どの情報で保証できるかを両方見て選びます。

Newton法の非収束例

f(x) = x³ − 2x + 2 では f′(x) = 3x² − 2 です。x₀ = 0 から始めると、次は 0 − 2/(−2) = 1。そこからは 1 − 1/1 = 0 に戻ります。したがって 0、1、0、1、… と循環し、根へ収束しません。通過する二点では導関数が 0 でなく、関数も実数全体で滑らかです。

Newton 法の接線は、区間の外や、根から遠い場所を指すことがあります。一方、二分法は、閉区間での連続性と両端の符号の違いを保てば、その中に根を残し、区間幅から誤差を保証できます。Newton 法を選ぶなら、初期値、導関数、更新が定義域に残るか、停止の基準を別に検討します。|f(xₙ)| が小さいことと、根との距離が小さいことも、一般には同じ保証ではありません。

寄り道［背景］：粘土板に残る、√2 の六桁に迫る近似

Yale Babylonian Collection 所蔵の粘土板 YBC 7289 には、対角線のある正方形と、60進法の数 1;24,51,10 が記されています。CDLI の資料では、これは √2 の近似値として読まれています。現代の表記で計算すると、a = 1 + 24/60 + 51/60² + 10/60³ = 30547/21600 ≈ 1.41421296 です。

この板の数だけから、書き手がどの算法を使ったかまでは決まりません。一方、近似のよさは自分で検査できます。2 − a² = 791/466560000 で、|a − √2| = |a² − 2|/(a + √2)。a も √2 も 1 より大きいので、誤差はその差の半分より小さく、10⁻⁶ 未満だと保証できます。昔の計算を眺めるだけでなく、本文の不等式で精度を確かめられるのです。

近似値と誤差保証の演習

1．一次と二次を比べる

f(x) = x³、a = 1、x = 1.1 とします。二つの近似値を求め、[1, 1.1] 上の導関数から誤差上限を保証してください。

ヒント1：必要な導関数をそろえる

f′ = 3x²、f″ = 6x、f‴ = 6 です。

ヒント2：区間全体の上限を選ぶ

M₂ = 6.6、M₃ = 6 が使えます。

解答

h = 0.1 より P₁ = 1 + 3 · 0.1 = 1.3、P₂ = 1.3 + 6 · 0.1²/2 = 1.33。一次誤差は 6.6 · 0.1²/2 = 0.033 以下、二次誤差は 6 · 0.1³/6 = 0.001 以下です。実際の値 1.331 との差は 0.031 と 0.001 で、いずれも保証内に入ります。

2．Newton 法の更新を確かめる

x² − 2 の Newton 法で x₀ = 1 から二回更新し、各更新で 0 による割り算が起きないことを確認してください。

ヒント1：専用の更新式を使う

次の値は (x + 2/x)/2 です。

ヒント2：分数のまま進める

二回目には 2/(3/2) = 4/3 を使います。

解答

x₁ = (1 + 2)/2 = 3/2、x₂ = (3/2 + 4/3)/2 = 17/12。使った点 1、3/2 はともに正で、導関数 2x は 0 でありません。二回で根そのものを得たわけではなく、根に近い有理数を得ています。

3．循環を停止と取り違えない

x³ − 2x + 2 の Newton 法を x₀ = 0 から使うとき、三回更新し、根が得られていない理由を述べてください。

ヒント1：二点の値と傾きを調べる

f(0) = 2、f′(0) = −2、f(1) = 1、f′(1) = 1 です。

ヒント2：反復する値を見る

一回目と三回目が同じ値になります。

解答

x₁ = 1、x₂ = 0、x₃ = 1 です。同じ二点を永久に往復し、数列は収束しません。また f(0) = 2、f(1) = 1 で、どちらも根ではありません。関数が微分可能で更新式が毎回計算できても、収束の保証にはなりません。

4．要求精度から使える範囲を決める

f(x)=x²をa=2の一次式で近似します。式を作り、すべての|x−2|≤δで絶対誤差0.0001以下を保証する最大のδ>0を求めてください。過大評価か過小評価かも説明してください。

ヒント1

x=2+hと置けば(2+h)²=4+4h+h²です。

ヒント2

剰余は正確にh²です。範囲の端h=δでも条件を満たす必要があります。

解答

一次式はP1(x)=4+4(x−2)で、f(x)−P1(x)=(x−2)²≥0なので過小評価です。全範囲で誤差≤δ²となり、δ=0.01ならδ²=0.0001で保証できます。これより大きいδではx=2+δが範囲内で誤差δ²>0.0001となるので不可。最大は0.01です。二次式なら元の平方そのもので誤差は0です。

5．一点の条件を使って評価を鋭くする

1/0.95を中心1の一次・二次式で近似し、差を通分して誤差を正確に求めてください。絶対誤差0.0002以下を満たすのはどちらですか。

ヒント1

h=−0.05=−1/20で、一次は1−h、二次は1−h+h²です。

ヒント2

剰余は一次h²/(1+h)、二次−h³/(1+h)。分母は19/20です。

解答

一次値は21/20=1.05、二次値は421/400=1.0525です。正確な値20/19との差は一次で1/380、二次で1/7600。ともに正なので過小評価です。1/380>1/5000=0.0002ですが、1/7600<0.0002なので二次だけが条件を満たします。分母19/20が正であることも確認し、区間全体の粗い上限でなくこの点の分母を使いました。

6．中心の導関数だけで保証できるか

Kを任意の正の実数としてfK(x)=Kx³を中心0で一次近似します。「どのKでもf″K(0)=0なので、x=0.01で誤差は0.001以下」という説明を診断してください。反例と、正しい保証に必要な情報を示してください。

ヒント1

中心でfとf′はともに0です。x=0.01での真の値をKで書きます。

ヒント2

誤差はK·0.000001です。K=2000を試します。

解答

一次式は0で、誤差はK·10−6です。K=2000なら0.002となり主張に反します。中心での二階導関数は0でも、区間[0,0.01]ではf″K(t)=6Ktで上限は0.06Kです。Taylorの保証は(0.06K)(0.01)²/2=0.000003K。正しい保証にはKまたは区間全体の導関数の上限の制約が必要です。各Kを固定した保証と、全Kに共通の保証は異なります。

7．Newton法の初期値の符号を変える

x²−9=0のNewton法をx0=−1から二回実行し、近付くと考えられる根を述べてください。負の初期値から全項が負になることと、正の根へは近付けないことも説明してください。x0=0の場合はどうなりますか。

ヒント1

更新は(x+9/x)/2です。負のxの逆数も負です。

ヒント2

yn=−xnと置くと、yの更新は正の初期値の同じ式になります。

解答

x1=−5、x2=(−5−9/5)/2=−17/5です。負の入力なら二項とも負で、次も負です。yn=−xnは正で、yn+1=(yn+9/yn)/2。本文と同じくyn+1−3=(yn−3)²/(2yn)≥0、更新後は3以上で単調減少し、極限は3です。従ってxは−3へ収束し、正の根3へは近付きません。x0=0は導関数2xが0なので、最初の更新から定義できません。

8．式の尺度を変えた停止基準

f(x)=x−3、g(x)=100(x−3)は同じ根を持ちます。q=3.0001で両残差を求め、「残差0.001以下」という同じ停止条件が異なる判定をすることを確認してください。導関数の下限で割った誤差保証はどうなりますか。

ヒント1

根はどちらも3です。残差は100倍になります。

ヒント2

|f′|=1、|g′|=100なので、残差を割る下限も100倍になります。

解答

|f(q)|=0.0001なので条件を満たしますが、|g(q)|=0.01なので満たしません。真の根との距離は同じ0.0001です。導関数の下限で割ると、前者は0.0001/1、後者は0.01/100で、ともに0.0001以下という同じ保証になります。式全体の尺度に左右される残差の数値だけで、根の距離を判断しないことが要点です。

9．区間幅で保証する反復回数

連続関数の根を[0,2]に挟み、各回で符号を保つ半区間へ二分するとします。n回の後に区間の中点を返すとき、区間幅だけから誤差0.001以下を保証できる最小のnを求めてください。根の正確な位置は分からないものとします。

ヒント1

n回後の幅は2/2nです。中点から端までの距離はその半分です。

ヒント2

中点の誤差上限2−nを0.001と比べます。2⁹=512、2¹⁰=1024です。

解答

誤差上限は2−nなので、n=10なら1/1024<0.001です。n=9では1/512>0.001で、幅の情報だけでは端に近い根を排除できず保証できません。従って必要な保証を得る最小回数は10回です。個別の関数ではもっと早く精度に達することがありますが、それは区間幅以外の情報を用いた判断です。

10．多項式近似と計算時の丸めを合わせる

f(x)=x³を中心1の二次式P2で近似し、最後に表示する値qには|q−P2(x)|≤0.0002の丸め誤差があるとします。全体を|q−f(x)|≤0.0012へ保証するため、|x−1|≤δとするδを一つ選んでください。またδ=0.1の場合、残りの丸め誤差に最大どれだけ割り当てられますか。

ヒント1

三角不等式で全体の誤差を、近似そのものと丸めの二つへ分けます。

ヒント2

近似の誤差は|x−1|³です。δ³+0.0002≤0.0012を満たします。

解答

|q−f(x)|≤|q−P2(x)|+|P2(x)−f(x)|≤0.0002+δ³です。δ=0.1ならδ³=0.001なので全体は0.0012以下。逆にδ=0.1を固定すれば、丸めへ残る幅は0.0012−0.001=0.0002です。二つの誤差が打ち消す保証はないので、絶対値の上限を加えました。多項式の評価だけ正確でも、実際に返す値の保証には丸め分も含めます。
