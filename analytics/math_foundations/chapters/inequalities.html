不等式による評価と誤差の上限

二つの測定値にそれぞれ誤差があるとき、足した値の誤差はどこまで大きくなり得るでしょうか。個々の誤差が正か負か分からなくても、上限は知りたいものです。不等式は、答えをぴったり求める代わりに、答えが入る範囲を保証します。後の極限や近似では、この「保証できる範囲」が中心になります。

以下では通常の大小関係を持つ実数を扱います。不等式の両辺には同じ数を足せますが、掛ける場合は符号の確認が必要です。正の数なら向きは同じ、負の数なら向きは逆になります。また −3 < 2 から 9 < 4 は導けません。両辺の二乗が大小を保つのは、両辺が非負であるなど、適切な条件があるときです。

まず、符号が未知の誤差を足しても保証できる幅を作ります。次に、長方形の辺の長さを選んで面積を最大にする問題へ進みます。最後は「出力をこの幅へ入れたい」という注文から、入力の幅を逆に選びます。どの場合も、不等式を使う前に何を知っていて、どちら側から押さえたいかを決めることが出発点です。

学習の目安は演習を含めて120–170分です。絶対値と誤差、平均の不等式と等号、繰返しと入力範囲の三回に分けても構いません。演習1–3は基本、4–7は評価の選択と条件の診断、8–10は精度の逆算と制約のある設計です。

絶対値と三角不等式

実数 x の絶対値 |x| は、x ≥ 0 なら x、x < 0 なら −x です。数直線では 0 からの距離、|x − a| は a と x の間の距離を表します。常に −|x| ≤ x ≤ |x| です。したがって |x| ≤ M と言うことは、M ≥ 0 のもとで −M ≤ x ≤ M と言うことと同じです。

三角不等式

どんな実数 a、b に対しても、|a + b| ≤ |a| + |b| が成り立ちます。

短い証明

−|a| ≤ a ≤ |a| と −|b| ≤ b ≤ |b| を辺々足すと、−(|a| + |b|) ≤ a + b ≤ |a| + |b| です。|a| + |b| は非負なので、絶対値の意味から |a + b| ≤ |a| + |b| が従います。

等号になるとは限りません。a = 2、b = −2 なら、左辺は 0、右辺は 4 です。向きの違う誤差が打ち消し合うこともあるので、右辺は最悪の場合まで含めた上限です。実数の場合、a、b が同じ符号か、少なくとも一方が 0 のときには等号になります。

この不等式を a = (a − b) + b に使うと、|a| ≤ |a − b| + |b|、つまり |a| − |b| ≤ |a − b| が得られます。a と b を入れ替えれば逆向きの差も同様に評価でき、||a| − |b|| ≤ |a − b| です。絶対値を取った後の差は、取る前の差より大きくならないことが分かります。

一次結合の誤差上限と精度の配分

三角不等式を使う理由は、未知の符号を場合分けせずに済むことです。ただし、係数は誤差の大きさも拡大するので、そのまま足すだけにはしません。以下は測定の性質を説明する自作模型で、誤差は指定した範囲を動けるものとし、確率分布や追加の関係は仮定しません。

例題：差を取る計算でも誤差が増えることがある

長さX,Yを1.20cm、0.50cmと記録し、真の値との差をe1,e2としてX=1.20+e1、Y=0.50+e2と書きます。|e1|≤0.02cm、|e2|≤0.01cmだけが分かるとします。求めたい長さの一次結合D=2X−3Yは、記録値では2·1.20−3·0.50=0.90cmです。

真の値との差はD−0.90=2e1−3e2。符号が不明なので、差のまま打消しを期待せず、|D−0.90|≤|2e1|+|−3e2|=2|e1|+3|e2|≤0.04+0.03=0.07cmと評価します。従って0.83cm≤D≤0.97cmです。

上限0.07は実現できるでしょうか。e1=0.02、e2=−0.01なら2e1−3e2=0.07です。下端も符号を逆にすれば実現します。追加の情報なしで0.07より小さい幅を必ず保証することはできません。これを、この条件の下で鋭い上限と呼びます。

表でe2の符号を変えた二行を比べてください。元の誤差が同符号のときでなく、係数を掛けた後の二項が同符号のとき、三角不等式が等号になります。

逆向きに、Dの誤差を0.06cm以下にしたいとします。X,Yの誤差上限をr,sと設計するなら、2r+3s≤0.06が保証の条件です。同じ精度r=s=tなら5t≤0.06、つまりt≤0.012cm。Xをr=0.015cmまで測れるなら、残りは3s≤0.03からs≤0.01cmです。2r+3s≤0.06の範囲で、一方の誤差を小さくすれば他方の許容幅を広げられます。ただしrとsをそのまま交換してよいわけではありません。係数が大きいY側では同じ誤差の許容が、Dへより大きく響きます。

相加平均・相乗平均の不等式と等号条件

誤差を上から押さえるだけでなく、これ以上小さくできない値を下から押さえたいこともあります。非負の二数 a、b の足し算の平均 (a+b)/2 を算術平均（相加平均）、積から作る平均 √(ab) を幾何平均（相乗平均）と呼びます。例えば1と4なら、算術平均は5/2、幾何平均は2です。次の不等式は、積を固定したとき、和をどこまで小さくできるかを教えます。

二数の相加平均・相乗平均の不等式

a、b が正の実数なら、(a + b)/2 ≥ √(ab) です。等号が成り立つのは、a = b のとき、そしてそのときに限ります。

平方の非負性から示す

(√a − √b)² ≥ 0 を展開すると a + b − 2√(ab) ≥ 0 です。両辺を整理し、正の数 2 で割れば不等式が得られます。平方が 0 になるのは √a = √b のときだけなので、等号条件は a = b です。

たとえば x > 0 に対し、x と 1/x の積は 1 なので、x + 1/x ≥ 2 です。最小値 2 は x = 1 のときに実現します。下限を示しただけでは、その値を取れるかは未確定です。等号条件まで確認して初めて、最小値と言えます。前提 x > 0 を落とすと、x = −1 では和は −2 となり、この評価は成り立ちません。

固定した和から積を評価し、等号を実現する

相加平均・相乗平均の不等式は、積が分かれば和の下限を、和が分かれば積の上限を与えます。どちらの量を固定するかで、使う向きが変わります。a,bが非負なら証明の平方はそのまま使え、((a+b)/2)²≥abです。二乗する前に両辺が非負であることを確かめました。

例題：同じ周の長さで最大の面積を作る

周の長さ20cmの長方形を作ります。辺をa,b cmとし、a,b>0です。周の条件は2a+2b=20、従ってa+b=10。面積はA=ab cm²なので、5²=((a+b)/2)²≥ab、すなわちA≤25cm²です。等号条件a=bと和の条件からa=b=5。実際に一辺5cmの正方形を作れば周20cm、面積25cm²となり、上限を実現できます。

別の計算でも確かめられます。b=10−aを代入するとA=a(10−a)=25−(a−5)²。平方が非負だからA≤25で、平方が0となるa=5で等号です。「二辺が違う分」を表す平方が、面積の損失を測っています。たとえばa=3,b=7ならA=21で、最大からの差4は(3−5)²と一致します。

辺aに2≤a≤4という制限を追加したら、a=b=5は許されません。2≤a≤4では1≤5−a≤3なので、(a−5)²≥1。従ってA≤24で、a=4,b=6なら実現します。元の上限25は依然正しいですが、新しい制約下の最大値は24です。等号条件が許容範囲へ入るかまで調べる必要があります。

反対に最小面積はあるでしょうか。a,b>0ならA>0なので0は取りません。一方、任意の小さい正の数ηに対して0<a<1かつa<η/10とすれば、b=10−a>0で、A<10a<ηです。従って面積をいくらでも0に近くできても0にできず、最小値は存在しません。「A≥0という下からの保証」と「最小値0を取る」は異なります。辺0の退化した図形まで許せば、その別の条件では0を取れます。

ベルヌーイの不等式と帰納法

毎回同じ倍率 1+x を掛ける変化を、n回繰り返したらどうなるでしょうか。実際の倍率は (1+x)ⁿ です。変化 x を単純にn回足した 1+nx と比べると、繰り返す掛け算の大きさに、扱いやすい下限を与えられます。

ベルヌーイの不等式

x ≥ −1 を実数、n ≥ 1 を整数とすると、(1 + x)ⁿ ≥ 1 + nx が成り立ちます。

帰納法による証明

n = 1 では等号です。k ≥ 1 で (1 + x)ᵏ ≥ 1 + kx を仮定します。1 + x ≥ 0 なので、両辺に 1 + x を掛けても不等号の向きは変わりません。よって (1 + x)ᵏ⁺¹ ≥ (1 + kx)(1 + x) = 1 + (k + 1)x + kx² ≥ 1 + (k + 1)x です。最後は kx² ≥ 0 を使いました。したがって帰納法からすべての整数 n ≥ 1 で成立します。

この証明で x ≥ −1 は、掛ける数の符号を保証しています。範囲外へそのまま広げると、たとえば x = −3、n = 3 では左辺は −8、右辺は −8 で等号ですが、x = −4、n = 3 では −27 ≥ −11 となり誤りです。一つの範囲外の例がうまくいっても、前提を外してよい証明にはなりません。

反復倍率の評価と、下限の有効な範囲

例題：増減の繰返しを一次の式で保証する

量を一回ごとに2%増やす自作模型では、初めを1とした10回後の倍率は1.0210です。ベルヌーイの不等式でx=0.02、n=10を選べば1.0210≥1+10·0.02=1.20。従って増加は少なくとも20%です。「倍率は正確に1.20」でも「1.20以下」でもありません。二回の時点でも1.02²=1.0404>1.04で、差はx²=0.0004から生じています。

一回ごとにtの割合を失う場合は0≤t≤1とし、x=−tを代入します。(1−t)n≥1−ntなので、失った割合1−(1−t)nはnt以下です。t=0.1、n=3なら残る倍率は0.9³=0.729≥0.7、失った割合は0.271≤0.3です。単純に毎回初期量の10%を引く計算より、実際の減少は小さくなります。

n=20,t=0.1では下限1−nt=−1になります。残る倍率は非負なので、−1以上という保証自体は正しくても粗く、0以上という当然の情報より弱いものです。この場合は二つを合わせて(1−t)n≥max(0,1−nt)と書けます。maxは二つのうち大きい方です。評価式が使えることと、欲しい精度に役立つことは別です。

誤差評価とε–δによる入力範囲の選択

x² を 4 に近づけたいとします。差を因数分解すると |x² − 4| = |x − 2||x + 2| です。|x − 2| が小さくても、もう一つの因子を放置しては評価が終わりません。まず |x − 2| < 1 とすれば 1 < x < 3 となり、|x + 2| < 5 が得られます。したがって |x² − 4| ≤ 5|x − 2| です。

例えば出力の誤差を0.1未満にしたいなら、入力を2から0.02未満の範囲に入れれば、5·0.02=0.1という評価を使えます。この例では0.02 < 1なので、先に求めた係数5の条件も保たれます。一般には、先に指定される出力の許容誤差を ε、こちらが選ぶ入力の許容幅を δ と名付けます。

ほしい誤差を任意の正の実数 ε とします。δ = min(1, ε/5)、つまり 1 と ε/5 の小さい方を選び、|x − 2| < δ とすれば、|x − 2| < 1 と 5|x − 2| < ε が同時に成り立ちます。よって |x² − 4| < ε です。先に因子を一定値で押さえ、次に誤差の要求へ合わせる。この二段階が、極限の議論の基本になります。

入力の許容幅：十分な選択と最大の選択

前節でδ=min(1,ε/5)を選んだのは、なるべく広いδを探すためではなく、二つの要求を同時に満たす分かりやすい選択を作るためです。ここでminは小さい方の値です。ε>0なのでδ>0で、どれほど小さい注文にも正の幅を返せます。δは先に与えられたεから選び、その後にその範囲のすべてのxで保証します。xごとにδを変えるのではありません。

例題：二乗の誤差をもう少し鋭く押さえる

h=x−2と書きます。するとx²−4=(2+h)²−4=4h+h²=h(4+h)です。|h|<δなら、|4+h|≤4+|h|から|x²−4|≤|h|(4+|h|)<δ(4+δ)。従ってδ(4+δ)=εを満たす正のδを選べば保証できます。

δ²+4δ−ε=0を解くと、正の解はδ*=√(4+ε)−2です。ε>0だから√(4+ε)>2で、確かに正です。ε=0.1ならδ*は約0.02485で、前節の0.02より広い幅を使えます。これは丸めた0.02485を保証幅として選ぶという意味ではなく、正確な根号の式で選びます。

これより大きい幅δを選ぶと、x=2+δ*が|x−2|<δを満たしてしまいます。その点ではx²−4=εなので、厳密な目標|x²−4|<εに反します。従ってこの二乗の問題ではδ*が最大の対称な許容幅です。境界の点を含まない|x−2|<δ*なら問題なく、境界で等号になることと矛盾しません。

どの問題でも最大幅を求める必要はありません。目的が「要求を満たす幅を一つ示すこと」なら、minを使った幅の方が計算も検証も簡単です。目的が「測定の手間を減らすため、可能な限り広い幅を知ること」なら、鋭さを調べる価値があります。最初に必要な結論を決めてから、評価の精密さを選びます。

寄り道［応用］：答えを一個にせず、入っている区間を計算する

数値計算には、答えを小数一個で表示する代わりに、真の値が入る区間を計算する「区間演算」があります。NIST の数理関数の資料も、丸め誤差を含めた計算結果の囲い込みに、この方法を位置づけています。近そうな値を出すだけでなく、どこまで外れないかを返す発想です。

例えば a ≤ x ≤ b、c ≤ y ≤ d なら、足し算の順序の性質から a + c ≤ x + y ≤ b + d。入力の上下限だけで、出力の上下限が求まります。実際のコンピュータでは、丸めで区間を内側へ縮めないよう、端を適切な方向へ丸めます。ただし同じ x が二度出る式を別々の値として扱うと、区間が広がりすぎることもあります。不等式による保証の確かさと、評価の鋭さは、別に考える必要があります。

出典：NIST DLMF：3.1(ii) Interval Arithmetic。

演習：不等式の条件と等号の達成

1．三つの誤差をまとめる

実数 a、b、c について |a + b + c| ≤ |a| + |b| + |c| を示してください。

ヒント1：二つずつまとめる

a + b + c を (a + b) + c と見ます。

ヒント2：同じ不等式を二回使う

まず |(a + b) + c| を評価し、その後 |a + b| を評価します。

解答

三角不等式から |(a + b) + c| ≤ |a + b| + |c| ≤ |a| + |b| + |c| です。最初から三つの数の定理を仮定せず、二数の場合を繰り返せば示せます。

2．下限と最小値を区別する

x > 0 のとき、x + 9/x の最小値と、その値を取る x を求めてください。

ヒント1：積が一定の二数を選ぶ

x と 9/x はともに正で、積が 9 です。

ヒント2：等号条件も解く

和は 2√9 以上です。等号は x = 9/x のときです。

解答

相加平均・相乗平均の不等式より x + 9/x ≥ 6 です。等号条件は x² = 9。x > 0 なので x = 3 で、実際に 3 + 9/3 = 6 となります。したがって最小値は 6、そのとき x = 3 です。

3．指定された誤差に応じて選ぶ

ε > 0 が与えられたとき、|x − 1| < δ なら |x² − 1| < ε となる δ > 0 を一つ選び、理由を示してください。

ヒント1：因数分解して局所的に押さえる

|x² − 1| = |x − 1||x + 1| です。|x − 1| < 1 なら 0 < x < 2 です。

ヒント2：二つの要求を同時に満たす

|x + 1| < 3 を使えます。δ は 1 以下、かつ ε/3 以下にします。

解答

δ = min(1, ε/3) とします。ε > 0 より δ > 0 です。|x − 1| < δ なら |x + 1| < 3 なので、|x² − 1| ≤ 3|x − 1| < 3δ ≤ ε です。入力の範囲を、任意に指定された正の誤差に合わせて選べました。

4．誤差の上限を求め、その鋭さを確かめる

|e1|≤0.03、|e2|≤0.02という情報だけから、|e1+2e2|の最も小さい共通の上限を求めてください。その上限を実現する誤差も挙げてください。さらにe1=−2e2と分かったら、評価はどう変わりますか。

ヒント1

三角不等式では係数2も絶対値の外に出します。

ヒント2

二項が同符号になる端点を選ぶと上限を実現できます。追加条件がある場合は、先に式をまとめます。

解答

|e1+2e2|≤|e1|+2|e2|≤0.03+0.04=0.07です。e1=0.03、e2=0.02で等号になるので、全許容誤差に共通の上限をこれより小さくはできません。追加条件の下ではe1+2e2=0で、鋭い上限は0です。元の上限0.07も偽ではありませんが、既知の関係を使うと改善します。

5．端点を二乗する方針を点検する

|x−1|≤2から「−1≤x≤3だから1≤x²≤9」とした解答を診断し、x²が取り得る範囲を正しく求めてください。どこで大小を保つ条件を失いましたか。

ヒント1

区間−1≤x≤3の中にx=0は含まれていますか。

ヒント2

区間が0をまたぐので、二乗の最小は端点とは限りません。最大の絶対値も考えます。

解答

x=0でx²=0なので1≤x²は偽です。二乗が大小を保つのは非負の範囲であり、−1≤xの両辺へそのまま使えません。全区間で|x|≤3なので0≤x²≤9。0はx=0、9はx=3で取れます。さらに任意の0≤y≤9にはx=√y∈[0,3]を選べるので、取り得る範囲はちょうど[0,9]です。

6．等号点を除いたときの最小値

範囲を0<x<3に限ったとき、x+9/xには最小値がありますか。6という下からの保証は正しいか、6を取るか、それより大きい別の最小値があり得るかを分けて説明してください。

ヒント1

x+9/x=6+(x−3)²/xです。等号点x=3は許されません。

ヒント2

任意の許されたxに対し、y=(x+3)/2を選ぶとx<y<3です。二つの値の差を因数分解してください。

解答

相加平均・相乗平均から常に6以上ですが、x≠3なので実際は6より大きく、6は取りません。さらにy=(x+3)/2なら、(x+9/x)−(y+9/y)=(y−x)(9/(xy)−1)>0です。x,y>0かつxy<9を使いました。従ってどのxからも、許容範囲内でもっと小さい値を作れるので、別の最小値もありません。たとえばx=2なら6.5ですが、y=2.5なら6.1と小さくなります。下から押さえられることだけで最小値の存在は言えません。

7．反復する減少を評価する

初めの量を1として毎回2%ずつ減らす自作模型で、8回後の量と失った割合を、ベルヌーイの不等式で評価してください。「8回で正確に16%を失う」という説明は正しいでしょうか。2回の場合を計算して点検してください。

ヒント1

残る倍率は(1−0.02)⁸です。x=−0.02を選びます。

ヒント2

残りの下限から1を引くのではなく、1から残りを引いて損失の上限へ直します。

解答

0.98⁸≥1−8·0.02=0.84で、残る割合は少なくとも84%、失った割合は1−0.98⁸≤0.16、すなわち高々16%です。正確に16%ではありません。2回なら残り0.98²=0.9604、損失0.0396で、単純に2·0.02=0.04とした値より小さくなります。毎回の2%はその時点の残量に対する割合だからです。不等式の向きと、どの量に対する割合かを確認します。

8．分母も押さえて入力幅を選ぶ

ε>0が与えられたとき、|x−2|<δならx≠0かつ|1/x−1/2|<εとなるδ>0を一つ選んでください。分母が0へ近付かないことを先に保証してください。

ヒント1

|x−2|<1なら1<x<3です。差は|x−2|/(2|x|)になります。

ヒント2

分母2|x|を2より大きくできるので、|x−2|/2で押さえられます。

解答

δ=min(1,2ε)とします。正の二数の小さい方なのでδ>0。|x−2|<δ≤1ならx>1で、x≠0です。また|1/x−1/2|=|x−2|/(2|x|)≤|x−2|/2<δ/2≤ε。先にδ≤1で分母を押さえ、その後δ≤2εで誤差を制御しました。入力を小さくするという説明だけで分母の条件を省かないことが要点です。

9．誤差を二つの測定へ配分する

D=3X−2Yを計算し、X,Yの誤差をそれぞれ|e1|≤r、|e2|≤sとします。誤差の間に追加の関係はありません。Dの誤差を0.04以下へ保証したいとき、(a) r=s=tの場合の最大t、(b) r=2sの場合の最大sと対応するrを求めてください。

ヒント1

最悪の誤差は3r+2sです。引き算の符号は、誤差が打ち消すことを保証しません。

ヒント2

(a)は5t≤0.04、(b)は3·2s+2s≤0.04を解きます。大きくできない理由には端点の誤差を使います。

解答

|3e1−2e2|≤3r+2sで、e1=r、e2=−sにより等号になります。従って保証の必要十分条件は3r+2s≤0.04です。(a) t≤0.04/5=0.008なので最大t=0.008。(b) 8s≤0.04なので最大s=0.005、そのときr=0.01です。検算は3·0.01+2·0.005=0.04。どちらも等号の誤差が可能なので、それぞれの制約内でこれ以上は緩められません。

10．長方形の制約と指定面積を同時に満たす

周24cmの長方形の辺をa,b cmとし、2≤a≤5とします。面積の最大値・最小値と、それを取る辺を求めてください。さらに面積32cm²を作る許容された辺をすべて求めてください。

ヒント1

b=12−a、面積はa(12−a)=36−(a−6)²です。

ヒント2

2≤a≤5では1≤6−a≤4です。面積32には(a−6)²=4が必要です。

解答

1≤(a−6)²≤16なので20≤A≤35です。最大35cm²はa=5,b=7、最小20cm²はa=2,b=10で実現します。32cm²には(a−6)²=4よりa=4または8ですが、8は条件外。従ってa=4,b=8だけです。周は2(4+8)=24、面積は4·8=32と検算できます。正方形a=b=6は元の周の条件では最大でも、この許容範囲には入っていません。
