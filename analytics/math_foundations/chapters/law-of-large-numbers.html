弱大数の法則と確率収束

公平なコインの表の確率を 1/2 と定めても、10 回投げて表がちょうど 5 回になるとは限りません。それでも回数を増やすと、表の比率が 1/2 の近くにある確率は高くなるでしょうか。

ここまでの確率は、整合的なモデルの規則として扱ってきました。この章では、独立で同じ分布という条件を置き、繰り返しの平均が分布の期待値へ近づくことを証明します。頻度との結び付きは、条件を持つ定理として得られます。

演習込みの学習時間は150–210分を目安に、証明と精度設計、依存と偏り、演習へ分けて読めます。演習1–3は基本、4–7は境界と保証の診断、8–10は条件を変えた設計です。

独立同分布と標本平均

一回目、二回目、…の観測で記録する値を、確率変数X1、X2、…で表します。実際に得られた一組の観測記録が標本で、その最初のn個の平均が標本平均です。観測前の標本平均は、結果によって値が変わる確率変数で、観測記録が決まると一つの数になります。一つの変数の分布から、繰り返しを一緒に扱うモデルへ進むために、変数どうしの関係も指定します。

同じ確率モデル上の変数列 X₁、X₂、…を考えます。まず、全ての変数が共通の有限個の実数値を取る場合を扱います。任意の有限個について、どの値の組の同時確率も各変数の確率の積に分かれるという相互独立性を持ち、全ての Xᵢ が同じ分布なら、独立同分布（iid）と言います。共通の平均を μ、分散を σ² とします。有限値なので二乗の期待値も有限です。

最初の n 個の標本平均を、X̄ₙ = (X₁ + … + Xₙ)/n とします。X̄ₙ も結果によって値が変わる確率変数です。平均と分散は、期待値の線形性、独立な和の分散、尺度変換の公式から求まります。

E[X¯n]=μ,Var(X¯n)=1n2nσ2=σ2n

分子の和の分散が nσ²、平均にする倍率 1/n の二乗が 1/n² なので、分散は σ²/n です。平均の式には独立性が要りませんが、ここで交差する共分散を消すためには独立性を使っています。

無限列の確率モデルの構成は、前章までに明示した未証明の枠組みです。そのモデルを与えられれば、有限値の iid について以下の各 n の計算は有限の同時表で証明した性質だけで確認できます。一般の実数値の変数についても、有限な二乗の期待値を仮定し、未証明で借用した積分の線形性・独立な積の期待値の因数分解を使えば、同じ平均・分散の式が成り立ちます。この一般化の積分の基礎まで証明したわけではありません。

Chebyshevの不等式による弱大数の証明

平均にどれだけ近ければよいかを決めるため、正の許容幅εを一つ固定します。調べるのは「平均の誤差そのもの」ではなく、「その幅以上に外れるという事象の確率」です。

有限値の iid に対する弱大数の法則

上の有限値の iid の条件の下で、任意の ε > 0 について、標本平均が μ から ε 以上外れる確率は 0 へ収束します。一般の実数値の iid に対しても、有限な二乗の期待値と、直前で明示した積分の性質を前提とすれば同じ結論になります。

0≤P(|X¯n−μ|≥ε)≤σ2nε2→n→∞0

標本平均を、一つの変数として扱う

標本平均の平均は μ、分散は σ²/n です。この X̄ₙ にChebyshev の不等式をしきい値 ε > 0 で適用すると、P(|X̄ₙ − μ| ≥ ε) ≤ σ²/(nε²)。ε と σ² は n によらない有限な値なので、右辺は 0 へ行きます。確率は非負だから、挟み撃ちで結論です。実験のグラフを見て収束と判定したのではなく、全ての n に使える上限を作りました。

任意の ε > 0 に対してこの外れる確率が 0 へ行くことを、X̄ₙ が μ に確率収束すると言います。さらに「外れる確率を δ 以下にしたい」なら、δ > 0 に対し n ≥ σ²/(δε²) を選べば十分です。これは十分な回数の保証で、最小の必要回数だとは限りません。

σ² = 0 の場合も、割っているのは n と ε² だけなので式は成立します。逆に分散が有限でなければ、この証明の有限な上限は使えません。それだけで大数の法則自体が必ず不成立になるとは言えません。本章は、証明できた条件付きの範囲を述べています。

確率収束の量化と許容幅の変化

極限の主張を、実際に選べる回数へ戻してみましょう。二つの精度を区別します。εは値の許容幅、δはその幅から外れる確率の許容上限です。確率収束とは、どんなε>0とδ>0を先に指定されても、ある整数Nを選び、n≥NのすべてのnでP(|X̄ₙ−μ|≥ε)≤δとできることです。δがどんなに小さくてもこの形で答えられることが、確率の極限0に当たります。δを1個だけ固定できても、まだ確率収束の証明ではありません。

例題：誤差幅を狭くしながら観測する

公平なiid Bernoulli変数で、許容幅をεₙ=n⁻¹ᐟ⁴とします。固定幅の定理をそのまま当てはめるのでなく、各nに成立する不等式へ代入すると、P(|X̄ₙ−1/2|≥n⁻¹ᐟ⁴)≤(1/4)/(n·n⁻¹ᐟ²)=1/(4√n)→0です。幅を狭めても、分散が減る速さに余裕があれば、外れる確率を抑えられます。

一方、εₙ=n⁻¹ᐟ²では右辺は1/4のままです。この上界からは外れる確率が0へ行くとも、行かないとも決まりません。上界が消えないことと、確率自身が消えないことは別です。本章で証明する定理のεはnに依存しないため、縮む帯の話にはこのような追加計算が要ります。

標本数の設計と最悪条件

標本数は、平均を計算する前にも設計できます。重要なのは「回数を増やす」という方針を、εとδを満たす不等式にすることです。Bernoulli試行なら未知のpも分散に入るため、どのpに対して保証したいのかを先に定めます。

例題：成功確率の範囲を使って、十分な回数を選ぶ

自作の試行モデルで、p∈[0,1/5]と分かっているとします。比率の誤差が0.04以上となる確率を0.05以下に保証するには、何回あればよいでしょう。p(1−p)はこの区間で最大4/25です。実際、q≥pかつq≤1/5ならq(1−q)−p(1−p)=(q−p)(1−q−p)≥0なので、右端が最悪です。

従って(4/25)/(n·(1/25)²)≤1/20を満たせばよく、左辺は100/nです。答えはn≥2000。n=2000の上限を再代入すると100/2000=0.05になります。pの範囲を使わず1/4で抑えると、必要な保証回数は3125です。追加情報は、どの分布を最悪とするかを変えました。

ここで2000は、この上界から得た最小の整数です。実際の尾確率を使って求めた最小回数ではありません。n=1999で100/nが0.05を超えても、現実の尾確率まで0.05を超えると結論してはいけません。また、幅を半分にして同じ上限を求めるならnは四倍、許容する逸脱確率を半分にするならnは二倍です。式のε²とδの位置から、精度の費用が読めます。

Bernoulli標本平均と成功比率

Xᵢ が成功確率 p の iid Bernoulli 変数なら、X̄ₙ は成功数を n で割った比率です。μ = p、σ² = p(1 − p) なので、外れる確率は p(1 − p)/(nε²) 以下となります。成功確率 p を先に持つモデルから、観測比率が p に近い確率を導けました。

例えば p = 1/2、n = 100、ε = 0.1 なら Chebyshev の上限は 0.25 です。同じ事象の正確な確率は二項分布から計算でき、約 0.0568879 です。ここで「0.1 以上」には成功数 40 と 60 も含むので、足すのは 40 以下または 60 以上の質量です。上限と実際の確率は同じとは限りません。

一度の繰り返しで得られた結果列と、その途中の平均の推移を、一つの標本経路と呼びます。補助図はこの一経路です。主図の「理論の逸脱確率」は、同じ n の成否列のうち比率が p から ε 以上外れるものに限って、モデルの重みを足した値です。二つは答えている問いが違います。

「Chebyshev上界」は不等式が保証する値です。上界を 1 で打ち切って表示します。二項分布の k/n という格子が n とともに変わるため、理論の逸脱確率は単調に減らないことがあります。補助図は一回分の経路です。固定 seed の有限な疑似乱数列が、数学上の無限 iid 列を構成したわけではありません。

逸脱確率と標本平均の標本経路

確率収束の主張は、各 n で平均の分布を見たとき、固定幅 ε の外側の確率が小さくなるというものです。一つの経路が毎回 μ に近づく、誤差が単調に減る、ある回数以降は必ず帯の中にいる、という主張ではありません。Chebyshev の上限も、その一経路の誤差の上下を囲う帯の保証ではありません。

公平なコインで、最初の三つが 1、0、1 なら、比率は 1、1/2、2/3 です。二回目で中心に着いた後、三回目では離れます。この並びの確率は 1/8 で、普通に起こり得ます。また無限列を全て含むモデルでは、全て表という経路も存在し、その経路の比率は 1 のままです。ただしその経路の確率は、最初の n 回が全て表である確率 2⁻ⁿ 以下なので 0 です。

「確率 1 で経路が収束する」という、さらに強い型の大数の法則もありますが、それは別の定理で、本冊では証明しません。ここで確かめた確率収束の内容だけを、まず正確に読めるようにします。経路の誤差や、理論の逸脱確率の列が単調減少するとも、この定理からは言えません。

依存する標本の平均と分散

Y を公平な Bernoulli 変数とし、全ての i で Xᵢ = Y とします。全ての変数は同じ分布で、平均 1/2、分散 1/4 です。しかし独立ではありません。何個平均しても X̄ₙ = Y のままです。

ε = 1/4 とすれば、|Y − 1/2| は必ず 1/2 なので、P(|X̄ₙ − 1/2| ≥ 1/4) = 1。いくら n を増やしても 0 へ近づきません。和の分散には全ての組の共分散 1/4 が残るため、平均の分散も 1/4 のままです。「同じ分布」と「観測回数が多い」だけでは、この結論は保証できません。

独立性はこの証明に使った十分条件です。依存する列の全てで平均が失敗する、とまでは言っていません。例えば前章の和の分散の式からは、二変数ずつの共分散が全て 0 で、平均と分散が共通なら同じ上限を導けます。条件の役割を追うと、どこまで一般化できるかも分かります。

比べているのは、有限回 n = 4 の平均が取り得る値の分布です。一本の実現経路を描いた図ではなく、この有限例だけを弱大数の証明としているわけでもありません。

ブロック依存と平均の分散

同じ情報を何度も記録する場合、記録数をそのまま独立な試行回数とは数えられません。自作モデルとして、独立で同じ分布のY₁,…,Yₘをそれぞれb回ずつコピーし、n=mb個の記録を作ります。同じYⱼのb個を一つのブロックと呼びます。平均はμ、各Yⱼの分散はσ²とします。

例題：四百個の記録は、何回分の情報か

記録の総和はb(Y₁+…+Yₘ)なので、平均はb(Y₁+…+Yₘ)/(mb)=(Y₁+…+Yₘ)/mです。独立なのはYどうしですから、その分散はσ²/m=bσ²/n。nだけ見てσ²/nとすると、同じブロック内の共分散を落としています。

Yⱼを公平なBernoulli変数にすると、四百個の記録を一回ずつ別に測る場合と、百個を四回ずつコピーする場合は、平均の分散が四倍違います。すべてを同じ一回からコピーするならm=1で、nをいくら増やしても分散は1/4のままです。依存があれば一律に失敗するのではなく、独立なブロック数mが増えるかを確かめます。bを固定してm→∞なら、先ほどの不等式で確率収束を証明できます。

0/1の公平な独立測定をb回ずつコピー。総記録数n=400を固定し、ε=0.1で比較します。上界が1に達した行では、この不等式から有用な確率保証は得られません。

推定対象からの偏りと平均二乗誤差

大数の法則が近づける相手はモデルの平均μです。測りたい値θとμが違う場合、平均を取るだけでは解消できません。この違いb=μ−θを、ここでは偏りと呼びます。ずれの二乗の期待値E[(X̄ₙ−θ)²]が平均二乗誤差です。

例題：長さの校正と、反復回数の役割を分ける

真の長さをθ=100、記録の平均をμ=102、各記録の分散を4とする仮想のiidモデルを考えます。X̄ₙ−100=(X̄ₙ−102)+2と分けて二乗すると、交差項の期待値は4E[X̄ₙ−102]=0です。従って平均二乗誤差は4/n+4。回数で減る部分と、残り続ける部分が分かれます。一般にもσ²/n+b²です。

幅3以上の誤差を確率0.01以下にしたいなら、三角不等式から|X̄ₙ−100|≥3は|X̄ₙ−102|≥1を意味します。従って確率は4/n以下、n≥400で十分です。一方、幅1未満に入れたいという注文は逆です。|X̄ₙ−102|<1なら必ず|X̄ₙ−100|>1なので、P(|X̄ₙ−100|≥1)≥1−4/n。n=400では少なくとも0.99で外れます。回数を増やすほど、誤った中心の近くへ集中してしまいます。

このモデルで記録から既知の校正値2を引けば、修正後の平均は100、分散は同じ4/nになり、誤差保証の中心も変わります。実際の校正値をどう知るかは別の測定の課題です。本章の定理が、未知のずれを自動的に見つけてくれるわけではありません。

寄り道［応用］：たくさん測っても、ずれた物差しは直らない

MIT の大数の法則の教材は、偶然の誤差と、系統的な誤差や標本の偏りを区別しています。大数の法則が近づける相手は、そのモデルの期待値です。測りたかった対象と、その期待値が一致するかは別に確認します。

例えば真の長さを 100 とした仮想の計測で、各記録が 102 に平均 0 の独立同分布の誤差を足したものなら、誤差の分散が有限の下で記録の平均は 102 に確率収束します。回数を増やせば散らばりは抑えられても、校正のずれ 2 は消えません。繰り返しの条件と、何を測る分布なのかを併せて考える必要があります。

大数の法則と統計的推測への接続

この冊子では、確率モデルから確率変数、期待値、散らばりへ進み、最後に繰り返しの平均とモデルの平均を結びました。次には、有限回の観測から未知の値をどう推測するかが問題になります。

標本平均の揺れの形を調べる中心極限定理は、その先の道具です。本章の弱大数の法則から、揺れが正規分布であると結論することはできません。ここでは式や証明へ進まず、入口の「その先の数学」にある「確率・統計へ」から、既存の統計教材へつなぎます。モデルの仮定と推測に必要な追加の条件を、引き続き区別してください。

演習：確率収束と標本数

1．成功確率が未知でも上限を出す

iid Bernoulli 試行で、成功比率が p から 0.05 以上外れる確率を 0.01 以下と保証したいとします。p が未知でも、Chebyshev による十分な n を求めてください。

ヒント1：分散を一様に抑える

p(1 − p) = 1/4 − (p − 1/2)² ≤ 1/4 です。

ヒント2：確率の上限を 0.01 以下にする

(1/4)/(n · 0.05²) ≤ 0.01 を解きます。

解答

外れる確率は (1/4)/(0.0025n) = 100/n 以下です。100/n ≤ 0.01 ならよいので n ≥ 10000。これは全ての p に共通する十分な回数です。特定の p における正確な二項確率を調べた最小回数ではありません。

2．回数を四倍にする効果

iid な記録の平均が μ、分散が 4 とします。ε = 0.2 に対する Chebyshev の上限を n = 400 と n = 1600 で計算してください。実際の尾確率も必ず四分の一になりますか。

ヒント1：標本平均の分散を使う

上限は 4/(n · 0.2²) です。

ヒント2：上限と正確な確率を分ける

不等式は、分布の全ての形を指定してはいません。

解答

n = 400 では 4/(400 · 0.04) = 1/4、n = 1600 では 4/(1600 · 0.04) = 1/16 です。上限は四分の一になります。実際の尾確率の比まで、この不等式だけで決まるわけではありません。

3．コピーの回数を増やす

Y が 0、1 を半々で取り、全ての Xᵢ が Y のコピーである例について、E[X̄ₙ]、Var(X̄ₙ)、P(|X̄ₙ − 1/2| ≥ 1/4) を求め、弱大数の証明で使えない箇所を示してください。

ヒント1：平均しても同じ変数

X̄ₙ = (nY)/n = Y です。

ヒント2：和の交差項を見直す

異なる i、j でも共分散は Var(Y) = 1/4 であり、0 ではありません。

解答

E[X̄ₙ] = 1/2、Var(X̄ₙ) = 1/4、求める外れる確率は 1 です。独立な和の分散として n · (1/4) と置く箇所が使えません。実際には Var(∑Xᵢ) = Var(nY) = n²/4 なので、平均の分散は n で減らず、外れる確率が 0 へ行く上限を得られません。

4．格子の違いと尾確率の増加

公平なiid Bernoulli変数でε=1/4とします。n=2とn=4についてP(|X̄ₙ−1/2|≥1/4)を厳密に求めてください。nを増やすたび尾確率が減ると言えますか。

ヒント1：等号の格子点も含める

n=4で成功数1、3は、中心との差がちょうど1/4です。

ヒント2：成否列を数える

n=4の各成功数の重みは1,4,6,4,1を16で割ったものです。

解答

n=2は成功数0、2の2列なので2/4=1/2。n=4は0、1、3、4を含み、(1+4+4+1)/16=5/8です。確率は増えました。これはn→∞で0へ行くという定理と両立します。極限の存在は単調減少を要求しません。

5．未知の成功確率と整数回数

p∈[0.1,0.3]のiid Bernoulli試行で、誤差0.03以上の確率を0.02以下に保証します。Chebyshev上界から得る最小の整数nを選び、最小性の意味を説明してください。

ヒント1：区間の最悪分散を探す

区間は1/2より左なのでp(1−p)の最大は0.3·0.7です。

ヒント2：最後に整数へ切り上げる

n≥0.21/(0.02·0.03²)を計算します。

解答

分散上界は21/100。n≥35000/3=11666と2/3なので11667です。11666ではこの上界が0.02より大きく、11667では以下になります。これは選んだ分散上界を使う保証の最小整数です。実際の二項尾確率での最小回数は求めていません。

6．縮む許容幅を診断する

公平なiid Bernoulli変数で、許容幅をn⁻¹ᐟ³とした場合とn⁻¹とした場合のChebyshev上界を求めてください。それぞれから何が結論できますか。

ヒント1：不等式は各nで使える

1/(4nεₙ²)に代入します。

ヒント2：上界が増えても確率は1以下

上界が0へ行かないことだけで、不収束を証明したことにはなりません。

解答

n⁻¹ᐟ³では1/(4n¹ᐟ³)→0なので、縮む幅の外側の確率も0へ行きます。n⁻¹ではn/4で、確率の自明な上界1と合わせるだけです。この評価からは0へ行くとも行かないとも決まりません。固定したεについての弱大数の法則は、どちらの設定でも別に成立しています。

7．分散0を除外する必要はあるか

有限値のiid変数でσ²=0とします。任意の正のn、εについて逸脱確率はいくつですか。標本数を求める式でn=0を選んでもよいですか。

ヒント1：割るものを確かめる

0≤P(|X̄ₙ−μ|≥ε)≤0/(nε²)です。

ヒント2：標本平均の定義へ戻る

nは正の整数で、n=0の平均は定義していません。

解答

各n≥1で逸脱確率は0です。σ²で割る必要がないため、定理から除外しません。n≥σ²/(δε²)=0だけではnの定義域を言い落としており、実際には正の整数nを選びます。n=1で既に十分です。

8．コピー数から測定計画を選ぶ

公平な独立Bernoulli測定を各5回コピーして600記録を作ります。全記録の平均の分散と、ε=0.1の逸脱確率の上界を求めてください。同じ600記録を全て別測定にできればどう変わりますか。

ヒント1：独立な測定数を数える

最初の計画はm=600/5=120です。

ヒント2：コピーは平均で打ち消される

平均はm個のYの平均と一致します。

解答

最初は分散(1/4)/120=1/480、逸脱確率は(1/480)/(1/100)=5/24以下です。全て別なら分散1/2400、上界1/24以下。独立測定数を五倍にすると保証上界は五分の一です。最初の計画で1/24と答えるのは、コピーを独立と扱った誤りです。

9．残る偏りを逆算する

iid記録の分散が9で、真値θとの差の平均二乗誤差がn=9で5、n=36で17/4でした。この二つは、nによらない偏りbを持つモデルと整合しますか。bの符号まで決まりますか。

ヒント1：平均二乗誤差は分散と偏りの二乗

9/n+b²を二つのnへ代入します。

ヒント2：二つの観測から同じ値が出るか

5−1と17/4−1/4を比べます。

解答

いずれもb²=4となり、モデルと整合します。b=2または−2で、符号は二乗誤差だけでは決まりません。nを増やした極限も4です。真値と平均の位置関係を知る追加情報なしには、どちらへ校正すべきかは判断できません。

10．同分布を外して証明を作る

独立な0/1変数で、奇数番目の成功確率を0.3、偶数番目を0.7とします。n個の平均は1/2へ確率収束しますか。ε=0.1で外れる確率を0.05以下にする、全ての大きいnに使える十分な回数も一つ示してください。

ヒント1：期待値と分散を別々に計算する

偶数nの平均の期待値は1/2、奇数nは1/2−0.2/nです。各分散は0.21です。

ヒント2：偏りの分だけ幅を減らす

n≥4なら期待値と1/2の差は0.05以下。中心から0.1以上離れれば、自分の期待値から0.05以上離れます。

解答

平均の分散は0.21/n、期待値と1/2の差は0.2/n以下です。任意の固定ε>0に対し、nを十分大きくしてこの差をε/2以下にすれば、P(|X̄ₙ−1/2|≥ε)≤0.21/(n(ε/2)²)→0。従って確率収束します。ε=0.1ではn≥4で上界84/nを使え、n≥1680なら0.05以下です。同分布の定理をそのまま引用したのでなく、分散計算と中心のずれの評価から証明し直しました。
