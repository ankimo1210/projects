二項関係と同値関係

0、1、2、3、4、5 の札を、3 で割った余りごとにまとめます。0 と 3 は別の整数ですが、余りだけを見る問題では同じ役割を持ちます。「同じ」とみなす基準を選ぶと、六枚の札を三つの箱で扱えます。ただし、気分で似たものを寄せ集めると、箱の境界が重なるかもしれません。

この章の問いは、どんな関係なら、すべての対象を重ならない組へ分けられるかです。集合と写像の言葉を使い、対象の等しさと、目的に応じた同一視を区別します。この見方は、余りの計算や、数え上げで順序を忘れる操作にもつながります。

二項関係と同値関係の定義

二つの対象を一番目、二番目という順番を保って組にしたものを順序対 (x, y) といいます。(x, y) = (u, v) とは x = u かつ y = v であることです。X の要素どうしの順序対をすべて集めた集合 X×X = {(x, y)：x, y ∈ X} を、X と X の直積と呼びます。

集合 X の二項関係 R は X×X の部分集合です。(x, y) ∈ R を xRy と書き、「x と y の間で R が成り立つ」と読みます。二つ組には順序があり、xRy と yRx は別の条件です。たとえば整数で xRy を「x ≤ y」とすれば、2R5 は成り立ち、5R2 は成り立ちません。

関係は写像と違い、相手を一つに決める必要がありません。0 ≤ y となる整数 y は多数あります。「x と y の差が 3 の倍数」という関係なら、0 は 0、3、−3 などと関係します。何を同じとみなしたいかを、まず二つの対象についての条件にするわけです。

三条件を整数の余りで確かめ、一つずつ欠く関係と比べる。条件はすべてのx,y,z∈Xについて。
性質必要な条件余りが等しい関係（整数全体）この性質を欠く反例
反射律xRx1∼1。自分自身の余りは同じ。X={0,1}上の空の関係R=∅。対称律と推移律は破れないが、0R0が偽。自分を入れる箱がない。
対称律xRy ⇒ yRx1∼4なら4∼1。先後を逆にしても余りは同じ。X={0,1}上の≤。反射律と推移律は成立するが、0≤1から1≤0は言えない。
推移律xRy、yRzからxRz0∼3、3∼6から0∼6。同じ余りのままつながる。X={0,1,2}で|x−y|≤1。反射的・対称的でも、0と1、1と2が近いことから0と2が近いとは言えない。

この三つを満たす関係が同値関係です。以後は x ∼ y と書きます。整数の「差が 3 の倍数」なら、x − x = 0、差の符号を変えても 3 の倍数、二つの差を足しても 3 の倍数なので、三条件を満たします。

「差の絶対値が 1 以下」は反射的かつ対称的ですが、整数全体では推移的でありません。0 は 1 と、1 は 2 と関係しても、0 は 2 と関係しません。「近い」というだけでは、重ならない箱を作れるとは限りません。

同値類と商集合

x と同値な対象をすべて集めた集合を、x の同値類 [x] といいます。x は箱の名札になる代表元です。代表は変わっても、同じ箱を指すことがあります。

[x]={y∈X：y∼x}

同値類は、等しいか、まったく交わらない

[x] と [y] が一つでも共通要素を持てば、[x] = [y] です。また、すべての同値類を合わせると X になります。

一つの共通要素から、箱全体を比べる

z ∈ [x] ∩ [y] とします。z ∼ x と z ∼ y から、対称律と推移律により x ∼ y です。任意の w ∈ [x] について、w ∼ x ∼ y なので w ∈ [y]。逆も同じなので二つの集合は等しくなります。さらに反射律から x ∈ [x] であり、どの x も少なくとも一つの類に入ります。これで、漏れも、別の箱どうしの重なりもないことが分かりました。

同値関係と集合の分割

X の分割は、空でない部分集合を箱として、異なる箱どうしは交わらず、すべての箱の和集合が X になるようにしたものです。箱に空集合を許すと、「実際には対象のない箱」を余分に足せるため、ここでは除きます。X = ∅ の場合は、箱も一つもない分割を認めます。

分割と同値関係は、同じ構造の二つの表現

分割があれば、x ∼ y を「x と y が同じ箱に入る」と定義します。x はどれか一つの箱に入るので反射律、同じ箱という条件の向きを変えても同じなので対称律が成り立ちます。x と y が同じ箱、y と z が同じ箱なら、その二箱は y を共有するので同じ箱です。従って x と z も同じ箱で、推移律が成り立ちます。

この関係の [x] は、元の分割で x が入っていた箱そのものです。逆に、同値関係から類の分割を作り、同じ箱という関係へ戻しても、x ∼ y ⇔ [x] = [y] により元の関係が得られます。対象を比較する規則と、できあがった箱分けは互いに復元できます。

「同じ」の基準を変えれば分割も変わります。六つの整数を偶奇で分ければ二箱、数そのものの等しさで分ければ六箱です。何を捨て、何を残すかは問題次第。次章の半順序では、「同じ箱にいる」ではなく「こちらが先、こちらが含まれる」といった非対称な比較を調べます。

寄り道［自作モデル］：回した並びを同じ模様とみなす

三つの位置に A、B、C を一つずつ置き、向きを一周ずらした配置を同じとみなします。ABC、BCA、CAB は一つの類、ACB、CBA、BAC はもう一つの類です。何もしない回転、逆向きの回転、二つの回転の合成があるので、回転で移り合えるという関係は反射的・対称的・推移的です。

この例では、六つの配置が三つずつ二類に分かれます。ただし同じ文字を許すと AAA の類は一要素です。「回転で三つずつ重なるから、いつでも 3 で割る」は成り立ちません。類の大きさがそろう条件は、数え上げで改めて確認します。

出典：本章のために作成した有限配置モデル。外部の実測値や歴史的事実は用いていません。

演習：同値関係と分割

1．似ているだけでは足りない

整数上の xRy を |x − y| ≤ 2 で定めます。反射律・対称律・推移律を一つずつ判定してください。

ヒント1：同じ数と、向きを逆にした差

|x − x| と |x − y| = |y − x| を使います。

ヒント2：二歩進むと、距離はどうなるか

0、2、4 の三数を比べてください。

解答

反射律は |x − x| = 0 ≤ 2、対称律は差の絶対値が向きを変えても同じなので成り立ちます。0R2、2R4 は成り立つ一方、|0 − 4| = 4 > 2 なので 0R4 は成り立ちません。推移律がなく、同値関係ではありません。

2．余りの箱を全部書く

X = {0, 1, 2, 3, 4, 5, 6, 7} で、差が 4 の倍数なら同値とします。同値類をすべて書き、[1] と [5] を比べてください。

ヒント1：四で割った余りを名札にする

余りは 0、1、2、3 のいずれかです。

ヒント2：代表元が違っても、箱は同じか

1 と 5 の差を調べてから、それぞれと同値な要素を集めます。

解答

類は {0, 4}、{1, 5}、{2, 6}、{3, 7} の四つです。[1] = [5] = {1, 5} です。1 と 5 自体は異なりますが、類を出力とする写像では同じ値へ送られます。

3．箱の重なりが起こす矛盾

X = {a, b, c} の「箱」を {a, b} と {b, c} の二つにし、どれか一つの箱に一緒に入れば xRy と定めます。分割にも同値関係にもならない理由を説明してください。

ヒント1：分割の箱は交わってよいか

二つの箱の共通要素を調べます。

ヒント2：a から b、b から c とたどる

a と c が一緒に入る箱はあるでしょうか。

解答

二箱は b を共有し、異なる箱どうしが交わらないという分割の条件を満たしません。関係は aRb、bRc を満たしても aRc を満たさず、推移律がありません。重なる箱を作ってから「同じ箱」と呼ぶだけでは、整合的な同一視は得られません。

自分の言葉で

  1. 対象が等しいことと、選んだ関係で同値になることは、どう違いますか。
  2. 同値類が一つの要素を共有したとき、三つの性質のどれを使って全体の一致を導きましたか。
  3. 分割を先に指定する方法と、同値関係を先に指定する方法を、同じ具体例で説明できますか。
