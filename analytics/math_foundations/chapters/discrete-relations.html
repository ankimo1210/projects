二項関係と同値関係

0、1、2、3、4、5 の札を、3 で割った余りごとにまとめます。0 と 3 は別の整数ですが、余りだけを見る問題では同じ役割を持ちます。「同じ」とみなす基準を選ぶと、六枚の札を三つの箱で扱えます。ただし、気分で似たものを寄せ集めると、箱の境界が重なるかもしれません。

この章の問いは、どんな関係なら、すべての対象を重ならない組へ分けられるかです。集合と写像の言葉を使い、対象の等しさと、目的に応じた同一視を区別します。この見方は、余りの計算や、数え上げで順序を忘れる操作にもつながります。

学習の目安は演習込み100–150分です。三条件と同値類、写像と分割、関係の補完と代表元の三回に分けて読めます。演習1–3は基本の反例、4–7は条件の復元と証明、8–10は設計と境界です。

二項関係と同値関係の定義

二つの対象を一番目、二番目という順番を保って組にしたものを順序対 (x, y) といいます。(x, y) = (u, v) とは x = u かつ y = v であることです。X の要素どうしの順序対をすべて集めた集合 X×X = {(x, y)：x, y ∈ X} を、X と X の直積と呼びます。

集合 X の二項関係 R は X×X の部分集合です。(x, y) ∈ R を xRy と書き、「x と y の間で R が成り立つ」と読みます。二つ組には順序があり、xRy と yRx は別の条件です。たとえば整数で xRy を「x ≤ y」とすれば、2R5 は成り立ち、5R2 は成り立ちません。

関係は写像と違い、相手を一つに決める必要がありません。0 ≤ y となる整数 y は多数あります。「x と y の差が 3 の倍数」という関係なら、0 は 0、3、−3 などと関係します。何を同じとみなしたいかを、まず二つの対象についての条件にするわけです。

「同じとみなす」という関係を考えるときは、xRyの代わりにx∼yとも書きます。次の表は、どんな関係なら箱分けに使えるかを調べる三つの検査です。どれも一つの例だけでなく、集合内のすべての対象について要求します。

三条件を整数の余りで確かめ、一つずつ欠く関係と比べる。条件はすべてのx,y,z∈Xについて。
性質必要な条件余りが等しい関係（整数全体）この性質を欠く反例
反射律xRx1∼1。自分自身の余りは同じ。X={0,1}上の空の関係R=∅。対称律と推移律は破れないが、0R0が偽。自分を入れる箱がない。
対称律xRy ⇒ yRx1∼4なら4∼1。先後を逆にしても余りは同じ。X={0,1}上の≤。反射律と推移律は成立するが、0≤1から1≤0は言えない。
推移律xRy、yRzからxRz0∼3、3∼6から0∼6。同じ余りのままつながる。X={0,1,2}で|x−y|≤1。反射的・対称的でも、0と1、1と2が近いことから0と2が近いとは言えない。

この三つを満たす関係が同値関係です。以後は x ∼ y と書きます。整数の「差が 3 の倍数」なら、x − x = 0、差の符号を変えても 3 の倍数、二つの差を足しても 3 の倍数なので、三条件を満たします。

「差の絶対値が 1 以下」は反射的かつ対称的ですが、整数全体では推移的でありません。0 は 1 と、1 は 2 と関係しても、0 は 2 と関係しません。「近い」というだけでは、重ならない箱を作れるとは限りません。

同値類と商集合

x と同値な対象をすべて集めた集合を、x の同値類 [x] といいます。x は箱の名札になる代表元です。代表は変わっても、同じ箱を指すことがあります。

同じ同値類を一度だけ集め、その類を一個の新しい対象として扱った集合を商集合と呼び、X/∼と書きます。元の要素を忘れるのではなく、「どの類に入るか」という情報だけを残す操作です。次の図では六つの入力が三つの類へ移ります。

[x]={y∈X：y∼x}

同値類は、等しいか、まったく交わらない

[x] と [y] が一つでも共通要素を持てば、[x] = [y] です。また、すべての同値類を合わせると X になります。

一つの共通要素から、箱全体を比べる

z ∈ [x] ∩ [y] とします。z ∼ x と z ∼ y から、対称律と推移律により x ∼ y です。任意の w ∈ [x] について、w ∼ x ∼ y なので w ∈ [y]。逆も同じなので二つの集合は等しくなります。さらに反射律から x ∈ [x] であり、どの x も少なくとも一つの類に入ります。これで、漏れも、別の箱どうしの重なりもないことが分かりました。

写像の値が等しいという同値関係

「同じ」という基準を一から考えると、推移律を見落とすことがあります。そこで、各対象に一つの値を与える写像 f:X→Y を先に作り、x∼y を f(x)=f(y) と定める方法を考えます。同じ値を持つ対象だけをまとめるので、基準が明示できます。

値の等しさから三条件を導く

f(x)=f(x)だから反射律、f(x)=f(y)ならf(y)=f(x)だから対称律が成り立ちます。f(x)=f(y)、f(y)=f(z)なら等号の推移律からf(x)=f(z)です。従ってどんな写像でもこの規則は同値関係を作ります。[x]は、fの値がf(x)に等しい入力すべての集合です。

例題1：二乗の値だけを残す

X={−2,−1,0,1,2} で f(x)=x² とします。類を求めるときは、各代表元を順番に調べて同じ類を重複して書くより、出力ごとに入力を集めます。出力0に対して{0}、出力1に対して{−1,1}、出力4に対して{−2,2}です。

従って X/∼={{0},{−1,1},{−2,2}} は三要素。[−2]=[2]でも−2=2とは言っていません。また商集合は{0,1,4}そのものではありません。前者の要素は集合で、後者の要素は数です。ただし各類に二乗の値を対応させれば、一対一に対応します。

関係Rを順序対として数える別の検算もできます。一つの類にm個の要素があれば、その中の任意の順序対m²個がRに入ります。ここでは1²+2²+2²=9個。たとえば(−1,1)と(1,−1)は別々の二組として数えます。対角の5組も含むので、3個の類を3組の関係と混同してはいけません。

数値そのものを復元したい問題では、この二乗による分類は情報を捨て過ぎます。一方、二乗だけで決まる量を扱うなら符号を区別する必要はありません。何を計算したいかに応じて、残す値fを選びます。

同値関係と集合の分割

X の分割は、空でない部分集合を箱として、異なる箱どうしは交わらず、すべての箱の和集合が X になるようにしたものです。箱に空集合を許すと、「実際には対象のない箱」を余分に足せるため、ここでは除きます。X = ∅ の場合は、箱も一つもない分割を認めます。

分割と同値関係は、同じ構造の二つの表現

分割があれば、x ∼ y を「x と y が同じ箱に入る」と定義します。x はどれか一つの箱に入るので反射律、同じ箱という条件の向きを変えても同じなので対称律が成り立ちます。x と y が同じ箱、y と z が同じ箱なら、その二箱は y を共有するので同じ箱です。従って x と z も同じ箱で、推移律が成り立ちます。

この関係の [x] は、元の分割で x が入っていた箱そのものです。逆に、同値関係から類の分割を作り、同じ箱という関係へ戻しても、x ∼ y ⇔ [x] = [y] により元の関係が得られます。対象を比較する規則と、できあがった箱分けは互いに復元できます。

「同じ」の基準を変えれば分割も変わります。六つの整数を偶奇で分ければ二箱、数そのものの等しさで分ければ六箱です。何を捨て、何を残すかは問題次第。次章の半順序では、「同じ箱にいる」ではなく「こちらが先、こちらが含まれる」といった非対称な比較を調べます。

同値関係を満たすように関係を補う

「aとbは同じ」「bとcは同じ」とだけ指定したなら、どこまで同一視を増やす必要があるでしょう。ここでいう最小の同値関係は、指定された順序対をすべて含む同値関係のうち、含める順序対が集合の包含で最も少ないものです。単に対の個数が少なそうだ、という予想ではなく、他のどの候補にも含まれることを確かめます。

例題2：不足している比較を逆算する

X={a,b,c,d,e} で、自分自身との5組に、(a,b)、(b,a)、(b,c)、(c,b)、(d,e)、(e,d)を加えた11組をRとします。反射律と対称律は既にあります。しかしaRb、bRcから必要なaRcがありません。逆向きのcRaも必要です。

この2組を追加すれば、箱{a,b,c}の中の9組と、箱{d,e}の中の4組、計13組になります。これは分割から作る同値関係なので三条件を満たします。これ以上の追加は不要です。しかもRを含むどんな同値関係でも推移律によって(a,c)、(c,a)が強制されるので、この13組すべてを含まなければなりません。従って最小です。

「全部を同じとすればよい」という別案では、X×Xの25組になります。確かに同値関係ですが、aとdまで同一視する追加の決定が入ります。指定から必然な追加と、目的に応じた追加を区別すると、過剰に情報を捨てずに済みます。

次の三行について、増えた順序対がどの条件から必要になったのか考えてください。個数はこの五要素モデルだけの値ですが、「類の中の全順序対を含む」という数え方は任意の有限分割で使えます。

同じX={a,b,c,d,e}上で比較する。最小の補完は、不足した(a,c)、(c,a)の2組だけを加えます。
関係組の数三条件同一視の範囲
指定したR11推移律を欠くa,b,cの間の指定が未完
最小の補完13すべて成立{a,b,c}と{d,e}を分ける
X×X25すべて成立全要素を一つにする

二つの分類R、Sを同時に守りたい場合は、xRyかつxSyという関係R∩Sを使えます。反射律は両方で成立し、対称律・推移律もそれぞれ両方の関係で適用できるので、R∩Sは同値関係です。類は両方の箱の空でない共通部分になります。

「どちらか一方で同じ」というR∪Sは一般には同値関係でありません。X={a,b,c}上で、Rの箱を{a,b},{c}、Sの箱を{a},{b,c}とすると、aとb、bとcはR∪Sで関係しても、aとcは関係しません。この和集合を含む最小の同値関係に補うと、三要素すべてが一つの箱へ入ります。

代表元によらない計算の条件

同値類を一つの対象として扱うなら、代表元を変えても計算結果が同じでなければ困ります。類[x]に値f(x)を対応させる規則がよく定義されるとは、同じ入力の類に対し、どの代表元を選んでも一つの同じ出力になることです。

類の上に値を定められる条件

f:X→Yに対して、F([x])=f(x)という写像F:X/∼→Yを定められるための必要十分条件は、すべてのx,yについて x∼yならf(x)=f(y) となることです。

必要性と十分性を分ける

Fが写像なら、x∼yのとき[x]=[y]なのでF([x])=F([y])、従ってf(x)=f(y)です。逆にこの条件があれば、同じ類からどの代表元を取ってもfの値が同じです。各類は空でないので代表元は存在し、出力は一つに定まります。これで写像を作れます。

例題3：余りの類から計算してよい量を選ぶ

X={0,1,2,3,4,5}を、差が3の倍数という関係で分けます。f(x)をx²を3で割った余りとしましょう。xとyが同じ類なら、x−y=3kを満たす整数kがあり、x²−y²=(x−y)(x+y)=3k(x+y)も3の倍数です。従って二乗の余りは一致し、この計算は類の上でよく定義されます。

実際、[0]={0,3}では0、[1]={1,4}では1、[2]={2,5}でも1を出力します。商集合の三要素に対し出力は二種類であり、よく定義されることは単射であることと別です。

一方「代表元そのものを返す」規則G([x])=xは、[0]=[3]なのに0と3を返してしまいます。「各類から小さい方を選んで返す」と決めればこの有限の例では別の写像を定義できますが、任意の代表元xを返す規則と同じではありません。条件を足して選び方を固定したことを明記する必要があります。

同値関係が許す情報の捨て方と、その後で行いたい計算が両立するか。この条件を先に調べると、箱の名札の取り方に依存する誤りを防げます。

寄り道［自作モデル］：回した並びを同じ模様とみなす

三つの位置に A、B、C を一つずつ置き、向きを一周ずらした配置を同じとみなします。ABC、BCA、CAB は一つの類、ACB、CBA、BAC はもう一つの類です。何もしない回転、逆向きの回転、二つの回転の合成があるので、回転で移り合えるという関係は反射的・対称的・推移的です。

この例では、六つの配置が三つずつ二類に分かれます。ただし同じ文字を許すと AAA の類は一要素です。「回転で三つずつ重なるから、いつでも 3 で割る」は成り立ちません。類の大きさがそろう条件は、数え上げで改めて確認します。

出典：本章のために作成した有限配置モデル。外部の実測値や歴史的事実は用いていません。

演習：同値関係と分割

1．似ているだけでは足りない

整数上の xRy を |x − y| ≤ 2 で定めます。反射律・対称律・推移律を一つずつ判定してください。

ヒント1：同じ数と、向きを逆にした差

|x − x| と |x − y| = |y − x| を使います。

ヒント2：二歩進むと、距離はどうなるか

0、2、4 の三数を比べてください。

解答

反射律は |x − x| = 0 ≤ 2、対称律は差の絶対値が向きを変えても同じなので成り立ちます。0R2、2R4 は成り立つ一方、|0 − 4| = 4 > 2 なので 0R4 は成り立ちません。推移律がなく、同値関係ではありません。

2．余りの箱を全部書く

X = {0, 1, 2, 3, 4, 5, 6, 7} で、差が 4 の倍数なら同値とします。同値類をすべて書き、[1] と [5] を比べてください。

ヒント1：四で割った余りを名札にする

余りは 0、1、2、3 のいずれかです。

ヒント2：代表元が違っても、箱は同じか

1 と 5 の差を調べてから、それぞれと同値な要素を集めます。

解答

類は {0, 4}、{1, 5}、{2, 6}、{3, 7} の四つです。[1] = [5] = {1, 5} です。1 と 5 自体は異なりますが、類を出力とする写像では同じ値へ送られます。

3．箱の重なりが起こす矛盾

X = {a, b, c} の「箱」を {a, b} と {b, c} の二つにし、どれか一つの箱に一緒に入れば xRy と定めます。分割にも同値関係にもならない理由を説明してください。

ヒント1：分割の箱は交わってよいか

二つの箱の共通要素を調べます。

ヒント2：a から b、b から c とたどる

a と c が一緒に入る箱はあるでしょうか。

解答

二箱は b を共有し、異なる箱どうしが交わらないという分割の条件を満たしません。関係は aRb、bRc を満たしても aRc を満たさず、推移律がありません。重なる箱を作ってから「同じ箱」と呼ぶだけでは、整合的な同一視は得られません。

4．分割を順序対へ戻す

X={a,b,c}の分割{{a,b},{c}}が定める関係Rを、順序対を省略せずに書いてください。三つの自己関係だけを残した場合、類はどう変わりますか。

ヒント1

同じ箱に入る順序対を全部書きます。

ヒント2

大きさ2の箱は2²=4組を作ります。

解答

R={(a,a),(a,b),(b,a),(b,b),(c,c)}の5組です。自己関係だけなら等号関係で、類は{a},{b},{c}の三つになります。元の分割ではaとbを同一視したため両方向の2組が必要です。どちらも同値関係ですが分割は違います。

5．指定から同値関係を設計する

X={a,b,c,d}で、a∼b、c∼d、aとcは同値でない、を満たす同値関係をすべて求めてください。さらにa∼dを加えられるでしょうか。

ヒント1

二つの強制された箱を考えます。

ヒント2

もし二つの箱が一要素でも共有・結合すると何が起こるでしょうか。

解答

a,bは同じ箱、c,dも同じ箱です。この二箱を合わせるとa∼cになるため、分割は{{a,b},{c,d}}に一意に決まります。関係は各箱内の4組ずつ、計8組です。a∼dを追加するとd∼cと推移律からa∼cが必要になり、指定に反します。三条件は、好きな組を独立に選んでよいという規則ではありません。

6．代表元を変えて計算を点検する

整数全体を差が4の倍数で同一視します。F([x])をx²を4で割った余り、G([x])をxを3で割った余りとします。それぞれよく定義されるか調べてください。

ヒント1

x²−y²を因数分解します。

ヒント2

Gでは0と4を代表元にした結果を比較します。

解答

x−y=4kならx²−y²=4k(x+y)で、Fはよく定義されます。類[0],[1],[2],[3]の出力は0,1,0,1です。一方[0]=[4]でも、3で割った余りは0と1なのでGはよく定義されません。一組の反例で不成立を示せますが、Fの成立はすべての代表元についての式で証明する必要があります。

7．二つの分類を同時に守る

X={1,2,3,4}で、Rの箱は{1,2},{3,4}、Sの箱は{1,3},{2,4}です。R∩Sの類を求め、R∪Sが推移的でないことを具体的に示してください。

ヒント1

R∩Sの箱は二つの分割の共通部分です。

ヒント2

和集合では2と1、1と3をつないでみます。

解答

共通部分は{1},{2},{3},{4}なので、R∩Sは等号関係です。R∪Sには2R1と1S3から(2,1),(1,3)が入りますが、2と3はどちらの箱でも一緒でなく(2,3)は入りません。よって推移律がありません。両方の条件を満たす分類は細かくなりますが、どちらか一方を満たすという操作は推移律を保ちません。

8．類の個数と関係の組数から逆算する

六要素集合を三つの類に分け、同値関係に含まれる順序対をちょうど14組にしたいとします。類の大きさを決め、具体的に設計してください。同じ三類で10組にできますか。

ヒント1

類の大きさn₁,n₂,n₃は正整数で、和6、二乗和14です。

ヒント2

最大の大きさを4以上、3、2以下に分けます。

解答

最大が4以上なら他の二類が非空なので二乗和は少なくとも4²+1²+1²=18。最大が2以下なら(2,2,2)で12組です。最大が3なら残りの和3から(2,1)となり、(3,2,1)で14組。たとえば{a,b,c},{d,e},{f}で実現します。また∑(nᵢ−2)²=∑nᵢ²−12≥0なので、三類なら最低12組。10組は不可能です。

9．商集合と出力集合の対応を証明する

写像f:X→Yから x∼y⇔f(x)=f(y) と定めます。f(X)={f(x):x∈X}に対して、H:X/∼→f(X)、H([x])=f(x)が全単射になることを証明してください。

ヒント1

まず代表元を変えても同じ値になることを確かめます。

ヒント2

同じ出力なら同じ類になるか、どの出力にも入力があるかを分けます。

解答

x∼yならf(x)=f(y)なのでHはよく定義されます。H([x])=H([y])ならf(x)=f(y)、従ってx∼yで[x]=[y]だから単射です。任意のz∈f(X)にはf(x)=zというxが存在し、H([x])=zだから全射です。商集合と出力集合は要素の種類が違っても、この写像で一対一に対応します。

10．空集合の境界を区別する

X=∅のとき、R=∅は同値関係ですか。類、商集合、分割はどうなりますか。Xが空でない場合のR=∅とも比較してください。

ヒント1

三条件に反例となるx,y,zは存在しますか。

ヒント2

同値類はXの要素xごとに作ります。

解答

X=∅では条件を破る要素が存在しないため三条件すべてが成立します。代表元x自体がないので類は一つもなく、商集合も∅、分割も箱を一つも持たない空の集合族です。{∅}という一箱ではありません。空箱は分割の定義から除かれています。一方X≠∅でR=∅なら、任意のx∈XについてxRxが偽となり反射律が破れます。
