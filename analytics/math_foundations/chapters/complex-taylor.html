正則関数とテイラー展開

有限個の微分から作るTaylor多項式は、近似の道具でした。複素関数では、開集合で微分できるという条件だけから、関数そのものが近くで無限のべき級数になります。なぜそんな強い結論が出るのでしょう。鍵はCauchyの積分公式の分母を、有限の幾何和で分解することです。

この章では「無限和へ直せそうだ」という観察と、残りが本当に0になる証明を分けます。前提は正則性、ML評価、前章でTaylor展開を使わずに示した高階微分の積分公式です。

演習を含めて120–180分が目安です。有限の核と剰余、中心・次数の選択、零点と一致定理の三回に分けても読めます。

中心 a のまわりのべき級数は、複素数の係数 c₀,c₁,… を使う無限和 c₀+c₁(z−a)+c₂(z−a)²+… です。0以上の整数Nについて、0次からN次まで足した有限の多項式を部分和 PN と書き、ここでは N を打ち切る次数、n を和の中の番号に使います。無限和の値とは、この部分和を N→∞ とした極限です。例えば 1+z+z²+… は中心0、係数がすべて1のべき級数で、最初の三項の部分和は P₂(z)=1+z+z² です。

コーシー核の有限幾何級数展開

f が閉円板 |ζ − a| ≤ R を含む開近傍で正則であるとします。境界の円 C は反時計回りです。|z − a| < R なら、前章の公式は f(z) = (1/2πi)∮C f(ζ)/(ζ − z) dζ でした。q = (z − a)/(ζ − a) と置き、1/(1 − q) の有限恒等式を使います。

1ζ−z=∑n=0N(z−a)n(ζ−a)n+1+(z−a)N+1(ζ−a)N+1(ζ−z)

有限和なら積分を項へ分けてよく、各係数は高階Cauchy公式から cₙ = f⁽ⁿ⁾(a)/n! です。そこで PN(z) = ∑ₙ₌₀ᴺ cₙ(z − a)ⁿ とすると、f − PN は上の最後の項を f(ζ) 倍して積分したものです。これが誤差を調べるための正確な式になります。

図では、ある内側の円板全体で誤差をそろえて抑えます。どんな正の誤差幅を指定しても、一つの N を選べば、その次数以降の部分和の誤差が円板内のすべての点で同時にその幅より小さくなることを、一様収束といいます。次節の sup は、指定した全点での誤差の上限を表す記号です。

テイラー展開の剰余評価と一様収束

M = max|ζ−a|=R|f(ζ)| とし、0 < r < R を固定します。境界で |ζ − a| = R、小円板で |z − a| ≤ r、したがって |ζ − z| ≥ R − r。円の長さ 2πR と ML評価を使うと、次が得られます。

sup|z−a|≤r|f(z)−PN(z)|≤MRR−r(rR)N+1→0

正則関数は局所的にTaylor級数になる

上の仮定で、|z − a| < R において f(z) = ∑ₙ₌₀∞ [f⁽ⁿ⁾(a)/n!](z − a)ⁿ。任意の r < R について閉小円板 |z − a| ≤ r で一様収束します。一様とは、一つの N でその円板内の全点の誤差を同時に小さくできることです。

f(z)=∑n=0∞f(n)(a)n!(z−a)n,|z−a|<R

証明は直前の評価そのものです。r/R < 1 なので幾何べきが0へ行きます。任意の内点 z に対して |z − a| < r < R を選べるので、その点でも和は f(z) になります。円周 |z − a| = R までの収束は主張していません。

表の「極」は、ある正の整数 m について (z−a)ᵐf(z) を点 a まで正則に延ばせ、そこでの値が0でないような点 a を指します。例えば 1/(1+z²) では、(z−i)f(z)=1/(z+i) が i で非零なので i は1位の極です。−i も同様です。こうした正則に扱えない点を特異点として、次章で詳しく分類します。

例題1：中心を移すと、同じ点へ届くとは限らない

f(z)=1/(2−z)を中心0と中心1で展開します。まず中心0なら、分母から2をくくり、f(z)=(1/2)/(1−z/2)=∑ₙ₌₀∞ zⁿ/2ⁿ⁺¹、|z|<2です。すべての項で使う比はz/2なので、比の絶対値が1未満になる範囲を必ず添えます。

変数を中心からのずれに変える

中心1ではw=z−1と置くと2−z=1−w。従ってf(z)=∑ₙ₌₀∞(z−1)ⁿ、|z−1|<1です。係数はすべて1へ変わります。微分でもf⁽ⁿ⁾(z)=n!/(2−z)ⁿ⁺¹なので、f⁽ⁿ⁾(1)/n!=1となって一致します。

例えばz=3/2では中心0の比は3/4、中心1の比は1/2で、どちらの和もf(3/2)=2です。しかしz=0では、中心0の級数は最初の1/2だけが残るのに、中心1の級数は1−1+1−1+…となり収束しません。関数はz=0で定義され正則でも、その中心から作った級数が境界で収束するとは限らないのです。

表では中心と係数の違いに加えて、点0がどこに来るかを確認してください。二つの円板が重なるところでは同じ関数を表しますが、一つの級数を収束範囲の外へそのまま代入してはいけません。

例題2：要求誤差から、次数と外円を選ぶ

exp(z)を中心0の多項式PN(z)=∑ₙ₌₀ᴺ zⁿ/n!で近似し、|z|≤1/2のすべての点で誤差を1/100以下にしたいとします。Cauchyの剰余評価には、近似する半径r=1/2のほかに、積分する外円の半径Rを選ぶ余地があります。

|exp(ζ)|=exp(Re ζ)≤exp(R)です。また既に得た指数関数の級数よりe=2+∑ₙ₌₂∞1/n!<3です。実際n!≥2ⁿ⁻¹で、n≥3では不等号が厳しいため、後半は∑ₙ₌₂∞2⁻ⁿ⁺¹=1より小さくなります。従ってR=1ならM=3、R=2ならM=9を安全な上界に使えます。

係数が分かるときの別解

N=3の後の絶対値の和は、最初の項が(1/2)⁴/4!=1/384。その後の項の比は(1/2)/(n+1)≤1/10（n≥4）なので、尾部全体は(1/384)/(1−1/10)=5/1728<1/100です。一方N=2では、実数z=1/2で最初の省略項だけでも(1/2)³/3!=1/48>1/100。従ってこのPNの族で実際に必要な最小次数は3です。任意の別の近似多項式まで比較して最適性を主張したわけではありません。

べき級数の正則性

この先では、級数で作った関数にも微分を使いたくなります。実変数での項別微分を、そのまま複素変数へ移して済ませずに確かめます。∑cₙ(z − a)ⁿ が |z − a| < R で収束するとし、0 < r < ρ < R を選びます。距離ρの一点で級数が収束するので、その項の絶対値 |cₙ|ρⁿ はある C で抑えられます。

係数の上界から、線分上の積分へ

|z − a| ≤ r で元の項は C(r/ρ)ⁿ 以下、微分した項は (C/ρ)n(r/ρ)ⁿ⁻¹ 以下です。後者の数値級数は収束します。実際、隣り合う正の項の比は ((n + 1)/n)(r/ρ) で、十分後では固定した q < 1 以下になり、残りを幾何級数で抑えられます。よって多項式の部分和 PN とその導関数は、小円板でそれぞれ一様収束します。導関数の和を g とすると、一様極限の連続性により g は連続です。

点 z と z + h を結ぶ線分が小円板内にあるとき、有限多項式について PN(z + h) − PN(z) = h∫₀¹ PN′(z + th)dt。これは t を実変数とした基本定理を実部・虚部へ使った式です。一様収束により積分の誤差は sup|PN′ − g| 以下なので、N → ∞ として f(z + h) − f(z) = h∫₀¹ g(z + th)dt。h ≠ 0 で割り、h → 0 とすると g の連続性から f′(z) = g(z) です。したがって和は正則です。

k 回微分した項の上界も、定数倍の nᵏ(r/ρ)ⁿ で抑えられ、同じ比の議論で収束します。同じ補題を繰り返せば高階でも項別微分でき、f⁽ⁿ⁾(a) = n!cₙ。係数は和の関数から一意に決まります。

正則から級数を得る証明には境界積分を使い、級数から正則を得る証明には線分上の基本定理を使いました。二つの向きを独立に支えたので、次章で新しい級数を扱う際にも循環がありません。

零点の孤立性と一致の定理

f(b)=0 となる点 b を零点と呼びます。その点を除く十分小さい近傍にほかの零点がなければ、零点は孤立しているといいます。異なる零点が限りなく近づく先の点は、零点の集積点です。一つの零点の近くに何が起こるかを、最初の非零係数から読みます。

f(b) = 0 とします。b を中心とするTaylor級数に初めて現れる非零係数が cm なら、f(z) = (z − b)ᵐg(z)、g(b) = cm ≠ 0 と書けます。残りのべき級数はべき級数の正則性の補題から正則で、g は連続です。b の十分近くでは g ≠ 0 なので、そこでは b 以外に零点はありません。この m を零点の位数と呼びます。初めの非零係数がなければ、f は b の近くで恒等的に0です。

一致定理

連結な開集合 D 上で f、g が正則であり、異なる点からなる一致点の列 zₙ が D 内の点 b に収束するなら、D 全体で f = g です。「連結な開集合」を領域と呼んだことを思い出してください。

近くで0になる範囲に、端がない

F = f − g とします。連続性から F(b) = 0 です。b に零点が集まるので、直前の有限位数の場合は不可能です。従って F の全Taylor係数が0で、b の近くでは F = 0。E を「近傍全体で F が0になる点」の集合とすると、E は非空で開です。

E の D 内での極限点 c を考えます。c が E に入らないなら、E の異なる点の列を c に近づけられ、それらはすべて F の零点で、連続性から F(c) = 0 です。有限位数の孤立性に反するので c の近くでも F = 0、結局 c は E に入ります。よって E は D 内で閉でもあります。連結とは非空の開閉集合で二つに分かれないことなので、E = D。これで全体に広がります。

条件は省けません。右半平面 Re z > 0 上の sin(π/z) は 1/n で0ですが、集積点0は領域外なので恒等的には0になりません。また、離れた二円板で片方は0、他方は1とする関数はそれぞれで正則でも、連結でないため一方の一致は他方へ届きません。有限個の点での一致だけでも足りません。

例題3：値がそろっていても、整関数は作れるか

すべての正整数nについて f(1/n)=n/(n+1) を満たす整関数fはあるでしょうか。与えられた値は1/2、2/3、3/4、…と穏やかに1へ近づきます。値が有界だからといって、整関数で実現できるとは限りません。ここでの整関数は、全平面で正則な関数のことです。

右辺を点z=1/nの式で書くと1/(1+z)です。しかしこの候補はz=−1で定義されません。候補とfの差をそのまま全平面で扱う代わりに、分母を掛けて、全平面で正則な関数を作る方針を選びます。

一致定理を使える形へ設計する

存在すると仮定し、H(z)=(1+z)f(z)−1と置きます。Hは整関数で、H(1/n)=(1+1/n)n/(n+1)−1=0。異なる零点1/nの集積点0は、連結な開集合である全平面の内部です。一致定理からH≡0となります。

ところがz=−1を代入するとH(−1)=0·f(−1)−1=−1。これは矛盾です。従って求める整関数は存在しません。1/(1+z)という式が局所的に値を実現することと、その値を保ったまま全平面で正則にできることは、別の問題です。

有限個の値では、集積点を使うこの議論はできません。一致定理は単なる「多数のデータが一致した」という統計的な判断ではなく、無限列・内部の集積点・正則性・連結性がそろったときの厳密な結論です。

寄り道［数学の見方］：無限の指紋と、有限の測定の違い

一点 a でのすべての微分値が同じなら、二つの正則関数は近くで同じTaylor級数を持ち、一致定理で同じ領域全体に一致します。ところが N 階までの微分しか知らないなら、f(z) に ε(z − a)ᴺ⁺¹ を足しても、その情報は変わりません。有限のデータは無限の指紋と同じではないのです。

例えば定数1と 1 + (z − a)⁴ は3階までの微分が一致し、4階で初めて違います。これは解析接続の一意性を直感する自作例ですが、近似データから安定に遠方を復元できるとは主張していません。誤差の制御には、別に円の上の M と半径の情報が必要です。

1．幾何級数の打切りを保証する

f(z) = 1/(1 − z) を中心0で N 次まで足します。|z| ≤ 1/2 の全点で誤差 ≤ 1/16 にする最小の N を、幾何級数の正確な剰余から求めてください。

ヒント1：最後の項は zᴺ

残りは zᴺ⁺¹/(1 − z) です。

ヒント2：小円板全体の上限

|1 − z| ≥ 1/2 なので、誤差は 2⁻ᴺ 以下。z = 1/2 で等号です。

解答

2⁻ᴺ ≤ 2⁻⁴ より最小は N = 4、つまり5項です。z = 1/2 で誤差がちょうど1/16なので、N = 3 では円板全体の保証ができません。一般のCauchy評価より鋭い式が、この例では幾何級数から直接得られます。

2．零点の位数を読む

f(z) = eᶻ − 1 − z の0における零点の位数を求め、0の十分近くで他の零点がない理由を説明してください。

ヒント1：指数関数の係数

f(z) = z²/2! + z³/3! + … です。

ヒント2：z² を外へ出す

残る正則関数 g の0での値を調べます。

解答

f = z²g、g(0) = 1/2 ≠ 0 なので位数は2です。g はべき級数の補題から正則で連続、従って十分小さい円板では |g(z) − 1/2| < 1/4、特に g(z) ≠ 0。そこで f が0になるのは z = 0 だけです。

3．集積点はどこにあるか

領域 D 上の正則関数 f が f(1/n) = 0 をすべての正整数 n で満たすとします。D が複素平面全体の場合と右半平面の場合で、恒等的に0と結論できるか比較してください。

ヒント1：列の極限

1/n → 0 です。0 が D に入っているか確認します。

ヒント2：結論できない場合の候補

sin(π/z) を考え、全域で0ではない点も挙げます。

解答

複素平面全体では集積点0が内部なので一致定理から f ≡ 0。右半平面では結論できず、f(z) = sin(π/z) が反例です。z = 1/n では sin(nπ) = 0 ですが、z = 2 では1です。0が境界にあることが違いです。

4．二つの幾何級数を合わせる

f(z)=1/[(2−z)(1+z)]を中心0で展開し、一般の係数cₙと収束半径を求めてください。境界でも項の条件を点検してください。

ヒント1

部分分数は(1/3)[1/(2−z)+1/(1+z)]です。

ヒント2

二つの比はz/2と−z。係数は(1/3)[2⁻ⁿ⁻¹+(−1)ⁿ]です。

解答

cₙ=(1/3)[2⁻ⁿ⁻¹+(−1)ⁿ]で、|z|<1なら両級数が収束してfを表します。|z|=1では|cₙzⁿ|=|cₙ|→1/3で0にならず、外側ではさらに項が0へ行かないので収束半径は1、境界全点で発散です。c₀=1/2はf(0)=1/2と一致し、c₁=−1/4も直接微分で確認できます。

5．次数を固定して近似範囲を設計する

f(z)=1/(1−z)をP₂(z)=1+z+z²で近似します。0≤r<1として、|z|≤rの全点で誤差≤1/4となる最大のrを求めてください。

ヒント1

正確な剰余はz³/(1−z)で、z=rのとき絶対値の上界に等しくなります。

ヒント2

r³/(1−r)はrとともに増えます。r=1/2を試してください。

解答

誤差の最大値はr³/(1−r)。r=1/2では(1/8)/(1/2)=1/4で条件を満たします。rが増えると分子は増え、正の分母は減るので、この比は厳密に増えます。従って最大はr=1/2です。一般の上界の十分条件だけでなく、実点z=rで等号となるため必要性も示せています。

6．項別微分で別の和を作る

幾何級数から∑ₙ₌₁∞ n zⁿ⁻¹の和と収束円板を求め、z=i/2での値を計算してください。項別微分できる根拠も述べてください。

ヒント1

元の和1/(1−z)を微分します。

ヒント2

(1−i/2)²=3/4−iです。逆数を実部・虚部へ分けます。

解答

|z|<1でべき級数の正則性の補題を使うと、和は1/(1−z)²です。z=i/2では1/(3/4−i)=(3/4+i)/(25/16)=(12+16i)/25。境界での項の絶対値はnなので0へ近づかず、収束円板は|z|<1です。項別微分は有限項の形式操作だけでなく、少し大きいρ<1を使った一様収束で支えられています。

7．指定した位数の零点を設計する

F(z)=exp(z)−A−Bz−Cz²−Dz³が0でちょうど4位の零点を持つように、A,B,C,Dを選んでください。最初の非零係数とF⁽⁴⁾(0)も求めてください。

ヒント1

0次から3次のTaylor係数を消し、4次は残します。

ヒント2

指数関数の係数は1/n!です。

解答

A=B=1、C=1/2、D=1/6。するとF(z)=z⁴/24+z⁵/120+…で、最初の非零係数は1/24、F⁽⁴⁾(0)=4!·(1/24)=1です。F=z⁴g、g(0)=1/24≠0なのでちょうど4位。gは連続なので十分近くで非零となり、零点は孤立します。

8．連結性を落とす反例を作る

U={|z|<1}∪{|z−3|<1}上で正則なfを作り、f(1/n)=1/n（n≥2）なのにU全体でf(z)=zとはならないようにしてください。一致定理のどの条件が欠けていますか。

ヒント1

二つの円板は交わりません。一方ごとに別の多項式を定められます。

ヒント2

原点側ではf=z、3側ではf=z+1とします。

解答

提案の関数は各点の近傍で多項式なのでU上で正則です。原点側ではすべてのn≥2で値が一致し、集積点0もUの内部ですが、f(3)=4≠3です。Uは二つの離れた非空な開集合に分かれ、連結ではありません。一致は原点を含む円板には広がりますが、もう一方まで強制されません。

9．各点での収束と一様収束を診断する

Pₙ(z)=1+z+…+zⁿが|z|<1の各点で1/(1−z)へ収束することから、「開単位円板全体でも一様収束する」と結論してよいでしょうか。N次の部分和に対し、実点z=1−1/[2(N+1)]を選んで診断してください。

ヒント1

この点ではf(z)=2(N+1)です。P_Nの項はすべて0以上1以下です。

ヒント2

P_N(z)≤N+1なので、差を下から評価できます。

解答

指定したzは0<z<1で、f(z)−P_N(z)≥2(N+1)−(N+1)=N+1≥1です。どのNでも円板内に誤差1以上の点があるため、一様収束しません。各点を固定した収束とは矛盾しません。反例の点をNとともに境界へ近づけているためです。任意の固定r<1の閉小円板では、本章の剰余評価により一様収束します。

10．無限の値と有限の値を分ける

整関数fがすべての正整数nでf(1/n)=1/n+1/n²を満たすときfを決め、f(i)を求めてください。条件をn=1,…,10の10点だけにした場合、同じ結論を強制できないことも、別の整関数を一つ作って示してください。

ヒント1

候補p(z)=z+z²との差に一致定理を使います。

ヒント2

有限の場合にはp(z)へ∏ₖ₌₁¹⁰(z−1/k)を加えられます。

解答

無限の条件ではf−pが整関数で、零点列1/nが内部点0に集まるため恒等的に0です。従ってf=z+z²、f(i)=−1+i。有限条件ではq(z)=z+z²+∏ₖ₌₁¹⁰(z−1/k)も10点で同じ値ですが、q(0)=(−1)¹⁰/10!=1/10!≠0=p(0)です。二つは異なる整関数で、10点の一致だけでは一意に決まりません。
