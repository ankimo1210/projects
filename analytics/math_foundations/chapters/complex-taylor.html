正則関数とテイラー展開

有限個の微分から作るTaylor多項式は、近似の道具でした。複素関数では、開集合で微分できるという条件だけから、関数そのものが近くで無限のべき級数になります。なぜそんな強い結論が出るのでしょう。鍵はCauchyの積分公式の分母を、有限の幾何和で分解することです。

この章では「無限和へ直せそうだ」という観察と、残りが本当に0になる証明を分けます。前提は正則性、ML評価、前章でTaylor展開を使わずに示した高階微分の積分公式です。

コーシー核の有限幾何級数展開

f が閉円板 |ζ − a| ≤ R を含む開近傍で正則であるとします。境界の円 C は反時計回りです。|z − a| < R なら、前章の公式は f(z) = (1/2πi)∮C f(ζ)/(ζ − z) dζ でした。q = (z − a)/(ζ − a) と置き、1/(1 − q) の有限恒等式を使います。

1ζ−z=∑n=0N(z−a)n(ζ−a)n+1+(z−a)N+1(ζ−a)N+1(ζ−z)

有限和なら積分を項へ分けてよく、各係数は高階Cauchy公式から cₙ = f⁽ⁿ⁾(a)/n! です。そこで PN(z) = ∑ₙ₌₀ᴺ cₙ(z − a)ⁿ とすると、f − PN は上の最後の項を f(ζ) 倍して積分したものです。これが誤差を調べるための正確な式になります。

テイラー展開の剰余評価と一様収束

M = max|ζ−a|=R|f(ζ)| とし、0 < r < R を固定します。境界で |ζ − a| = R、小円板で |z − a| ≤ r、したがって |ζ − z| ≥ R − r。円の長さ 2πR と ML評価を使うと、次が得られます。

sup|z−a|≤r|f(z)−PN(z)|≤MRR−r(rR)N+1→0

正則関数は局所的にTaylor級数になる

上の仮定で、|z − a| < R において f(z) = ∑ₙ₌₀∞ [f⁽ⁿ⁾(a)/n!](z − a)ⁿ。任意の r < R について閉小円板 |z − a| ≤ r で一様収束します。一様とは、一つの N でその円板内の全点の誤差を同時に小さくできることです。

f(z)=∑n=0∞f(n)(a)n!(z−a)n,|z−a|<R

証明は直前の評価そのものです。r/R < 1 なので幾何べきが0へ行きます。任意の内点 z に対して |z − a| < r < R を選べるので、その点でも和は f(z) になります。円周 |z − a| = R までの収束は主張していません。

1/(1+z²) は実軸上ではどこでも滑らかでも、中心0から距離1の ±i で定義されません。同じ中心の級数へ代入すると、|z|=1 では項の絶対値が1で0へ近づかないことも確認できます。特異点の位置と級数の項の条件を組み合わせ、実軸の図だけから収束半径を決めないでください。

三つ目も比 −z² の幾何級数で範囲を確かめられます。指数関数は実指数と三角関数から作った正則関数で、すべての高階微分が eᶻ、中心0での値は1です。ここでは未証明の「最も近い特異点までが収束半径」という一般論を使わず、各例を個別に支えています。

べき級数の正則性

この先では、級数で作った関数にも微分を使いたくなります。実変数での項別微分を、そのまま複素変数へ移して済ませずに確かめます。∑cₙ(z − a)ⁿ が |z − a| < R で収束するとし、0 < r < ρ < R を選びます。距離ρの一点で級数が収束するので、その項の絶対値 |cₙ|ρⁿ はある C で抑えられます。

係数の上界から、線分上の積分へ

|z − a| ≤ r で元の項は C(r/ρ)ⁿ 以下、微分した項は (C/ρ)n(r/ρ)ⁿ⁻¹ 以下です。後者の数値級数は収束します。実際、隣り合う正の項の比は ((n + 1)/n)(r/ρ) で、十分後では固定した q < 1 以下になり、残りを幾何級数で抑えられます。よって多項式の部分和 PN とその導関数は、小円板でそれぞれ一様収束します。導関数の和を g とすると、一様極限の連続性により g は連続です。

点 z と z + h を結ぶ線分が小円板内にあるとき、有限多項式について PN(z + h) − PN(z) = h∫₀¹ PN′(z + th)dt。これは t を実変数とした基本定理を実部・虚部へ使った式です。一様収束により積分の誤差は sup|PN′ − g| 以下なので、N → ∞ として f(z + h) − f(z) = h∫₀¹ g(z + th)dt。h ≠ 0 で割り、h → 0 とすると g の連続性から f′(z) = g(z) です。したがって和は正則です。

k 回微分した項の上界も、定数倍の nᵏ(r/ρ)ⁿ で抑えられ、同じ比の議論で収束します。同じ補題を繰り返せば高階でも項別微分でき、f⁽ⁿ⁾(a) = n!cₙ。係数は和の関数から一意に決まります。

正則から級数を得る証明には境界積分を使い、級数から正則を得る証明には線分上の基本定理を使いました。二つの向きを独立に支えたので、次章で新しい級数を扱う際にも循環がありません。

零点の孤立性と一致の定理

f(b) = 0 とします。b を中心とするTaylor級数に初めて現れる非零係数が cm なら、f(z) = (z − b)ᵐg(z)、g(b) = cm ≠ 0 と書けます。残りのべき級数は直前の補題から正則で、g は連続です。b の十分近くでは g ≠ 0 なので、そこでは b 以外に零点はありません。この m を零点の位数と呼びます。初めの非零係数がなければ、f は b の近くで恒等的に0です。

一致定理

連結な開集合 D 上で f、g が正則であり、異なる点からなる一致点の列 zₙ が D 内の点 b に収束するなら、D 全体で f = g です。「連結な開集合」を領域と呼んだことを思い出してください。

近くで0になる範囲に、端がない

F = f − g とします。連続性から F(b) = 0 です。b に零点が集まるので、直前の有限位数の場合は不可能です。従って F の全Taylor係数が0で、b の近くでは F = 0。E を「近傍全体で F が0になる点」の集合とすると、E は非空で開です。

E の D 内での極限点 c を考えます。c が E に入らないなら、E の異なる点の列を c に近づけられ、それらはすべて F の零点で、連続性から F(c) = 0 です。有限位数の孤立性に反するので c の近くでも F = 0、結局 c は E に入ります。よって E は D 内で閉でもあります。連結とは非空の開閉集合で二つに分かれないことなので、E = D。これで全体に広がります。

条件は省けません。右半平面 Re z > 0 上の sin(π/z) は 1/n で0ですが、集積点0は領域外なので恒等的には0になりません。また、離れた二円板で片方は0、他方は1とする関数はそれぞれで正則でも、連結でないため一方の一致は他方へ届きません。有限個の点での一致だけでも足りません。

寄り道［数学の見方］：無限の指紋と、有限の測定の違い

一点 a でのすべての微分値が同じなら、二つの正則関数は近くで同じTaylor級数を持ち、一致定理で同じ領域全体に一致します。ところが N 階までの微分しか知らないなら、f(z) に ε(z − a)ᴺ⁺¹ を足しても、その情報は変わりません。有限のデータは無限の指紋と同じではないのです。

例えば定数1と 1 + (z − a)⁴ は3階までの微分が一致し、4階で初めて違います。これは解析接続の一意性を直感する自作例ですが、近似データから安定に遠方を復元できるとは主張していません。誤差の制御には、別に円の上の M と半径の情報が必要です。

演習：テイラー展開と剰余評価

1．幾何級数の打切りを保証する

f(z) = 1/(1 − z) を中心0で N 次まで足します。|z| ≤ 1/2 の全点で誤差 ≤ 1/16 にする最小の N を、幾何級数の正確な剰余から求めてください。

ヒント1：最後の項は zᴺ

残りは zᴺ⁺¹/(1 − z) です。

ヒント2：小円板全体の上限

|1 − z| ≥ 1/2 なので、誤差は 2⁻ᴺ 以下。z = 1/2 で等号です。

解答

2⁻ᴺ ≤ 2⁻⁴ より最小は N = 4、つまり5項です。z = 1/2 で誤差がちょうど1/16なので、N = 3 では円板全体の保証ができません。一般のCauchy評価より鋭い式が、この例では幾何級数から直接得られます。

2．零点の位数を読む

f(z) = eᶻ − 1 − z の0における零点の位数を求め、0の十分近くで他の零点がない理由を説明してください。

ヒント1：指数関数の係数

f(z) = z²/2! + z³/3! + … です。

ヒント2：z² を外へ出す

残る正則関数 g の0での値を調べます。

解答

f = z²g、g(0) = 1/2 ≠ 0 なので位数は2です。g はべき級数の補題から正則で連続、従って十分小さい円板では |g(z) − 1/2| < 1/4、特に g(z) ≠ 0。そこで f が0になるのは z = 0 だけです。

3．集積点はどこにあるか

領域 D 上の正則関数 f が f(1/n) = 0 をすべての正整数 n で満たすとします。D が複素平面全体の場合と右半平面の場合で、恒等的に0と結論できるか比較してください。

ヒント1：列の極限

1/n → 0 です。0 が D に入っているか確認します。

ヒント2：結論できない場合の候補

sin(π/z) を考え、全域で0ではない点も挙げます。

解答

複素平面全体では集積点0が内部なので一致定理から f ≡ 0。右半平面では結論できず、f(z) = sin(π/z) が反例です。z = 1/n では sin(nπ) = 0 ですが、z = 2 では1です。0が境界にあることが違いです。
