導入：局所最小と大域最小

小さく歩いても下り道がない場所は、谷底かもしれません。しかし、離れた場所にもっと深い谷があるかもしれません。最適化では「近くで負けない」という局所の情報から「どこへ行っても負けない」という大域の結論へ進みたい。その橋になるのが凸性です。

凸性は見た目の丸さを表すだけではありません。二点を結ぶ線分が使えることと、線分上の値を両端の値で抑えられることを、別々に定義します。

凸集合の定義

凸集合

C⊂ℝ² が凸とは、任意の x,y∈C と 0≤t≤1 に対し、(1−t)x+ty∈C となることです。二点を結ぶ線分全体が C の中にあります。以下の問題では C は空でないとします。

円板や長方形は凸です。円周だけの集合や、中心に穴を開けた円板は凸ではありません。「連結である」より強く、迂回できることだけでは足りません。凸集合は開いていても、閉じていても、非有界でもかまいません。

例題1：配分の条件を混ぜても守れるか

二用途への配分を、無次元の点(u,v)で表す自作モデルを使います。C={(u,v):u≥0,v≥0,u+v≤1}では、量を負にせず、合計1以下にすることを求めます。頂点の図を眺めるだけでなく、任意の二案を混ぜても条件が残るかを式で確かめます。

二案x=(u₁,v₁)、y=(u₂,v₂)がCにあるとします。z=(1−t)x+tyの第一成分は(1−t)u₁+tu₂≥0、第二成分も同様です。成分の和は(1−t)(u₁+v₁)+t(u₂+v₂)≤(1−t)+t=1。すべての0≤t≤1で三条件が残るため、Cは凸です。

条件を「二用途を同時に使えない」と変更し、さらにuv=0を課したSを考えます。(1,0)と(0,1)はSに入りますが、中点(1/2,1/2)の積は1/4でSに入りません。一組の反例で、Sは凸でないと判定できます。凸性を証明するには任意の二点、否定するには条件を破る一組が必要です。

制約を追加して候補を減らすことが、凸性を保つとは限りません。三角形から二軸の部分だけを残す変更は、その具体例です。次に、この混ぜる操作が目的関数の値をどう変えるかを調べます。

凸関数の定義とJensenの不等式

凸関数

凸集合 C 上の f:C→ℝ が凸とは、すべての x,y∈C、0≤t≤1 について次の不等式が成立することです。

f((1−t)x+ty)≤(1−t)f(x)+tf(y)

右辺は両端の高さを直線で補間した値です。入力を混ぜたときの値が、出力を混ぜた値以下になる、と読みます。定義域 C の凸性を確認せず、関数の式だけでこの定義を使うことはできません。

この二点と混ぜる割合についての不等式は、Jensenの不等式の二点版でもあります。二変数で使う‖x‖は、ユークリッドノルムによる長さです。x=(x1,x2)なら‖x‖²=x1²+x2²で、成分ごとの平方を足します。次の確認では、この二乗和を使います。

平方の凸性は、差を平方にする

f(x)=x² なら、右辺から左辺を引いた差は t(1−t)(x−y)²≥0。従って ℝ 上で凸です。二変数の f(x)=‖x‖² でも、成分ごとに足せば差は t(1−t)‖x−y‖²。微分を使わずに確かめられます。

微分可能な凸関数の一次条件

微分を使う前に、偏微分と全微分を短く振り返ります。∇fは、二つの座標についての偏微分を並べた勾配です。C¹は、一階の偏導関数が連続であるという条件を表します。 例えば座標を(a,b)とすれば、f(a,b)=a²+b²の勾配は(2a,2b)で、偏導関数は全平面で連続です。

二つのベクトルの内積は対応する成分の積の和で、u·v=u1v1+u2v2です。従って∇f(x)·(y−x)は、点xからyへ動いたときの一次近似による値の変化を表します。凸なら、その接線・接平面の予測が元の値を下から支えるかを調べます。

微分可能な凸関数の一次条件

C は空でない凸集合、f は C を含む開集合上で C¹ とします。このとき f の C 上の凸性は、すべての x,y∈C に対し次が成立することと同値です。境界でも開近傍で定義された勾配を用います。

f(y)≥f(x)+∇f(x)·(y−x)

線分の端で微分し、逆向きには二つ足す

凸性から 0<t≤1 で f(x+t(y−x))−f(x)≤t(f(y)−f(x))。tで割って t→0+ とすると、連鎖律で ∇f(x)·(y−x)≤f(y)−f(x) です。

逆に一次条件がすべての二点で成り立つとします。0<t<1 と z=(1−t)x+ty∈C に対し、f(x)≥f(z)+∇f(z)·(x−z)、f(y)≥f(z)+∇f(z)·(y−z)。前者に1−t、後者にtを掛けて足すと、内積の項は0になり、凸性の不等式が得られます。t=0,1 は等号です。

従って凸な f で ∇f(x*)=0 なら、すべての y∈C に対し f(y)≥f(x*)。これは大域最小の十分条件です。境界では勾配0が必要とは限りません。例えば f(x)=x、C=[0,1] の最小点0で f′=1 です。

例題2：非零の勾配でも、制約の下では最小になる

例題1の三角形Cで、費用f(u,v)=(u−1)²+2(v−1)²を最小化します。二点x,yの成分の差をΔu,Δvとすれば、Jensenの右辺から左辺を引いた差はt(1−t){(Δu)²+2(Δv)²}≥0です。従ってfは全平面で凸で、C上でも凸です。

まず合計を使い切る辺v=1−u上で候補を探すと、f(u,1−u)=(u−1)²+2u²=3(u−1/3)²+2/3。候補はx*=(1/3,2/3)、費用2/3です。ただし辺上で最良と分かっただけでは、三角形全体で最良かはまだ分かりません。そこで凸関数の一次条件で、すべての実行可能点と比較します。

勾配は∇f=(2(u−1),4(v−1))、候補では(−4/3,−4/3)です。0ではありませんが、任意のy=(u,v)∈Cに対して、∇f(x*)·(y−x*)=(4/3)(1−u−v)≥0です。一次条件よりf(y)≥f(x*)+∇f(x*)·(y−x*)≥f(x*)。これで全体に対する最小性を保証できました。

さらに次の恒等式で直接検算できます。

f(u,v)−2/3=(u−1/3)²+2(v−2/3)²+(4/3)(1−u−v)

C内では右辺の三項がすべて非負で、等号には二つの平方が0であることが必要です。よって最小点はx*だけです。勾配0は制約なしの内点で使う条件であり、境界で許されない方向へ下れることは、実行可能な改善点の存在を意味しません。

凸最適化における局所最小と大域最小

x*∈C の局所最小とは、ある r>0 があり、y∈C かつ ‖y−x*‖<r なら f(x*)≤f(y) となることです。比較は C の中だけで行います。

凸なら、局所最小は大域最小

C が凸で f が C 上凸なら、局所最小点は大域最小点です。微分可能性は要りません。

遠い改善点があれば、近くにも改善点ができる

もし f(y)<f(x*) となる y∈C があれば、十分小さい 0<t<1 で z=x*+t(y−x*) は局所の半径内に入ります。凸性より f(z)≤(1−t)f(x*)+tf(y)<f(x*)。これは局所最小に反します。従って、遠い改善点もありません。

集合の凸性も必要です。f(x)=x は凸な式ですが C={0,2} では2も C 内で孤立しているため局所最小で、0より値が大きく大域最小ではありません。線分が C 内にないため、証明の z を使えません。

狭義凸性と最小点の一意性

x≠y、0<t<1 のとき、凸性の不等号が常に厳しい f を狭義凸といいます。

二つの最小点があると、中点はさらに低くなる

異なる最小点 x,y があり、共通の最小値を m とすると、狭義凸性から f((x+y)/2)<(f(x)+f(y))/2=m。最小値の定義に矛盾します。よって最小点は高々一つです。存在するときに限り、一意な最小点があると言えます。

例えば f(x)=x²、C=(0,1) は狭義凸ですが、下限0を達成しません。狭義凸性だけでは存在を補えません。また f(x,y)=x² は ℝ² 上凸でも狭義凸ではなく、y 軸全体が最小点です。

次章では、凸性がないときにも使える必要条件と、局所最小を保証する十分条件を区別します。

寄り道［数学の見方］：混ぜる操作を、証明の道にする

凸性の定義に出る (1−t)x+ty は、二つの案を割合で混ぜる操作です。遠い二点を一度に比べられなくても、tを小さくすると一方の点のすぐ近くへ移れます。局所と大域を結ぶ証明で、この同じ操作を使いました。

「図で谷に見える」よりも、任意の二点と任意の割合について使える不等式の方が強い。その強さが、未知の場所にも深い谷がないという保証へ変わります。

出典：本章で証明した線分上の不等式の読み直しです。

例題3：係数を動かして凸性と一意性を設計する

qₐ(u,v)=u²+2auv+v²を全平面で考えます。実数aをどう選べば凸になり、原点が唯一の最小点になるでしょうか。二階微分の判定に進む前に、平方完成と凸性の定義で解けます。

qₐ(u,v)=(u+av)²+(1−a²)v²です。|a|≤1なら二項は非負。また二点x,yに対するJensenの差はt(1−t)qₐ(x−y)ですから、0以上になり凸です。|a|<1ならx−y≠0に対してqₐ(x−y)>0となり、0<t<1で差も厳密に正です。従って狭義凸で、qₐ=0を満たす点も原点だけです。

a=1ではq₁=(u+v)²、a=−1ではq₋₁=(u−v)²となり、それぞれ直線u+v=0、u−v=0の全点が最小点です。凸性は残りますが一意性は失われます。

a>1ならz=(1,−1)でqₐ(z)=2−2a<0。−zでも同じ値なのに、中点0での値は0なので、qₐ(0)≤{qₐ(z)+qₐ(−z)}/2という凸性の不等式を破ります。a<−1ではz=(1,1)を選ぶと同様です。さらにqₐ(sz)=s²qₐ(z)→−∞となるため、最小点もありません。

同じ二次式でも、係数の境界で保証が変わる
aの範囲凸性最小点
|a|<1狭義凸原点の一つ
a=1凸、狭義凸ではない直線u+v=0
a=−1凸、狭義凸ではない直線u−v=0
|a|>1非凸なし、下に有界でない

表の境界は、有限個の係数を試した結果ではなく、すべてのaに対する平方完成と反例方向から得たものです。原点を唯一の最小点にするという要求への答えは−1<a<1。凸であるだけなら閉区間−1≤a≤1まで許せるため、何を保証したいかで係数の範囲が変わります。

例題4：折れ目のある凸関数を、微分なしで解く

目標位置0,2,5からの距離の合計F(x)=|x|+|x−2|+|x−5|を小さくする自作モデルを考えます。任意の実数cについて、|(1−t)(x−c)+t(y−c)|≤(1−t)|x−c|+t|y−c|は三角不等式です。三つを足せばFは凸と分かります。位置と距離はこのモデルの同じ無次元尺度で比べます。

折れ目0,2,5で区間を分け、絶対値を外します。微分が定義できない点を除いてしまうと、答えそのものを取り逃がすので、区間の境界も含めて比較します。

距離の合計を、折れ目ごとの一次式で読む
xの範囲F(x)最小へ向かう方向
x≤07−3x右へ進むと下がる
0≤x≤27−x右へ進むと下がる
2≤x≤5x+3左へ進むと下がる
x≥53x−7左へ進むと下がる

各境界で両側の式は同じ値を返し、全体の唯一の最小点はx=2、最小値は5です。Fは(0,2)などで一次関数なので狭義凸ではありません。それでも最小点は一意です。狭義凸性は一意性の十分条件であり、必要条件ではないと分かります。

目標5の項を外してG(x)=|x|+|x−2|に変えると、0≤x≤2でG=2となり、この区間の全点が最小点です。同じ凸性があっても、目標の選び方で一点へ決まる場合と、同じ値の候補が残る場合が変わります。凸性による大域性の保証と、最小点の一意性を区別します。

演習：凸性と最適性の保証

1．円板が凸である理由

C={x∈ℝ²:‖x‖≤1} が凸であることを、三角不等式から示してください。

ヒント1

‖(1−t)x+ty‖ を二項の和として抑えます。

ヒント2

0≤t≤1 なので係数は非負です。

解答

‖(1−t)x+ty‖≤(1−t)‖x‖+t‖y‖≤(1−t)+t=1。よって線分の全点が C 内です。ここでユークリッドノルムの三角不等式を使いました。

2．平方の一次条件

f(x)=x² について、f(y)−f(x)−f′(x)(y−x) を計算し、一次条件を確かめてください。

ヒント1

f′(x)=2xです。

ヒント2

展開した差を一つの平方に戻します。

解答

y²−x²−2x(y−x)=(y−x)²≥0。従って接線は全域でグラフ以下です。x=0なら f′=0 なので大域最小が分かります。

3．狭義凸なら存在するか

f(x)=x² を (0,1) 上で考えます。狭義凸であることと、最小点がないことをそれぞれ示してください。

ヒント1

異なる二点と 0<t<1 では t(1−t)(x−y)²>0 です。

ヒント2

任意の許された x に対し、x/2 も許されます。

解答

凸性の差は厳しく正なので狭義凸です。しかし x/2∈(0,1)、f(x/2)=f(x)/4<f(x) なので、どの点も最小点ではありません。高々一つと、ちょうど一つは違います。

4．制約を追加しても凸とは限らない

C={(u,v):u≥0,v≥0,u+v≤1}が凸であることを任意の二点から示し、uv=0も課した集合が凸でないことを一組の反例で示してください。

ヒント1

非負の重みを掛けて、三つの不等式を足します。

ヒント2

二軸上の点(1,0),(0,1)を混ぜます。

解答

混合点の両成分は非負で、和は(1−t)(u₁+v₁)+t(u₂+v₂)≤1なのでC内です。uv=0を課すと二点は許されても中点(1/2,1/2)は積1/4で許されません。全点での条件と、一組の反例の役割を分けます。

5．混ぜる割合を逆算する

f(x)=x²で、入力−1と3を混ぜて1/2にしたいとします。割合tを求め、入力を混ぜてから計算した値と、出力を混ぜた値、その差を求めてください。

ヒント1

−1+4t=1/2を解きます。

ヒント2

Jensenの右辺は(1−t)·1+t·9です。

解答

t=3/8。左辺f(1/2)=1/4、右辺(5/8)·1+(3/8)·9=4、差は15/4です。恒等式t(1−t)(−1−3)²=(3/8)(5/8)·16=15/4でも検算できます。

6．保証したい性質から係数を選ぶ

qₐ=u²+2auv+v²で、凸性だけを要求する範囲と、原点を唯一の最小点にする範囲を求めてください。a=−1とa=−2は具体的に調べてください。

ヒント1

平方完成とJensenの差を使います。

ヒント2

a=−2では点(1,1)を試します。

解答

凸性は−1≤a≤1、原点のみが最小点となるのは−1<a<1です。a=−1は(u−v)²で直線u=v全体が最小点。a=−2ではq(1,1)=−2で、反対点も−2、中点0の値0が平均−2より大きいので非凸です。この方向に拡大すると値は−∞へ下がります。

7．勾配0という誤った必要条件

f(x)=(x−2)²をC=[0,1]で最小化するとき、「最小点ならf′=0なので解なし」という報告を直してください。一次条件を使う検算も示してください。

ヒント1

許された点で2に最も近いのは1です。

ヒント2

x*=1の導関数は−2、許されたyにはy−1≤0です。

解答

最小点は1、最小値1です。f′(1)=−2でも、f′(1)(y−1)=2(1−y)≥0。凸性の一次条件からf(y)≥f(1)です。境界では許されない方向の下降は比較に使えず、勾配0を必要条件としてはいけません。

8．望む一点を距離の重みで選べるか

G_w(x)=|x|+w|x−2|をℝ上で最小化します。w>0について最小点を分類し、x=1を唯一の最小点とする重みを選べるか考えてください。

ヒント1

[0,2]ではG_w=2w+(1−w)xです。

ヒント2

この区間の外では、内側へ動くと値が下がります。

解答

0<w<1では唯一の最小点0、w>1では唯一の最小点2、w=1では[0,2]の全点が最小点です。x=1を最小点の一つにはできますが、それにはw=1が必要で、一意にはできません。凸な距離の和でも、望む一点を選ぶという設計が必ず可能とは限りません。

9．凸な式でも、集合が非凸なら

f(x)=x、C=[−2,−1]∪[1,2]とします。x=1がC内で局所最小であることと、大域最小でないことを示し、凸最適化の定理を使えない理由を述べてください。

ヒント1

半径1より近い実行可能点は正の区間側だけです。

ヒント2

C全体の最小点は−2です。

解答

x=1の半径1の近傍で実行可能なyは1≤y<2なのでf(y)≥1、局所最小です。しかしf(−2)=−2<1で大域最小ではありません。−1と1はCに入りますが、その中点0はCに入りません。従ってCは非凸で、定理の線分上の証明を使えません。式が全実数上凸でも、実行可能集合の条件を省けません。

10．一意性の逆は成り立つか

f(x)=|x|がℝ上凸で最小点0だけを持つことを示し、狭義凸でない一組の二点と割合も示してください。「狭義凸なら最小点は（存在すれば）一意」の逆、つまり「最小点が一意なら狭義凸」は正しいでしょうか。

ヒント1

凸性は三角不等式、最小性は絶対値の非負性です。

ヒント2

x=1,y=3,t=1/2を試します。

解答

絶対値の三角不等式で凸です。|x|=0はx=0だけなので最小点は一意。一方f(2)=2=(f(1)+f(3))/2で、異なる二点と内側の割合でも厳密な不等号になりません。従って狭義凸ではなく、逆向きは成り立ちません。最小点では微分できませんが、凸性と一意性の議論に支障はありません。
