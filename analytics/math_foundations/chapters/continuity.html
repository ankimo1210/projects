連続性と方程式の解の存在

正方形の面積を 2 にする辺の長さを知りたいとします。長さ 1 なら面積は小さすぎ、長さ 2 なら大きすぎる。途中にちょうどよい長さがありそうです。では、「ありそう」を「必ずある」に変えるには何が必要でしょうか。

関数 f(x) = x² − 2 を使えば、問いは「f(x) = 0 となる実数 x があるか」です。区間 [0, 2] の端では f(0) = −2、f(2) = 2。まずこの符号の違いを手がかりに、答えのありかを絞りましょう。ここで [a, b] は、両端を含む a 以上 b 以下の実数の集まりを表します。

二分法と区間の縮小

区間の中点を調べ、値が 0 なら終了します。負なら中点を左端に、正なら右端にして、両端の符号が違う半分を残します。これを二分法と呼びます。最初の中点 1 では値が −1 なので、次の区間は [1, 2]。その中点 1.5 では値が 0.25 なので、[1, 1.5] が残ります。

下の実験では、同じ手順を三つの関数に使います。二つ目は 1.3 を境に −1 から +1 へ飛ぶ関数、三つ目は 1/(x − 1.3) です。反復回数を増やし、区間の幅と、その中に本当に 0 になる点があるかを分けて見てください。

区間を狭くする手順自体は、連続でない関数にも実行できてしまいます。飛び移りの関数では境目へ迫っても値は ±1 のまま。三つ目の関数では、両端の符号が違っていても 1.3 で関数が定義されず、ほかのどこでも値は 0 になりません。区間が狭まるという観察だけでは、根の存在は証明できないのです。

連続関数のε–δ定義

グラフを「ひと筆で描ける」という感覚を、議論で使える言葉に直しましょう。点 c で連続とは、出力のずれをどんな小さい許容幅 ε に収めたいと指定しても、入力のずれを十分小さい幅 δ に制限すれば、その要求を満たせることです。ε、δ はともに正の数です。

|x−c|<δ⇒|f(x)−f(c)|<ε

この条件は、定義域にあるすべての該当する x について満たす必要があります。区間の端では、その区間の内側からの近づき方を考えます。区間全体で連続とは、各点でこの条件が成り立つことです。「少し変えれば少し変わる」を、相手が要求する精度に応じて入力の精度を選べる、という約束にしたのです。

x² − 2 なら、x と c が [0, 2] にあるとき、出力の差は |x² − c²| = |x − c||x + c| ≤ 4|x − c|。したがって δ = ε/4 と選べば要求を満たせます。一方、飛び移りの関数の c = 1.3 では、いくら近い左側の点でも出力の差は 2。例えば ε = 1 という要求に応えられません。この境目では連続でない、と判定できます。

合成関数と点列による連続性

連続関数と極限

g(h) → c で f が c で連続なら、合成が定義される範囲で f(g(h)) → f(c) です。また f が c で連続であることは、定義域内のどの数列 xₙ → c に対しても f(xₙ) → f(c) となることと同値です。

許容幅を順につなぐ

最初の主張では、出力の要求 ε に対し、f の連続性で入力の幅 η を選び、次に g(h) が c から η 未満になる入力の幅を選びます。点列の場合も、十分先で |xₙ − c| < η とすれば同じです。逆に連続でなければ、ある ε₀ > 0 に対し、各 n で |xₙ − c| < 1/n なのに |f(xₙ) − f(c)| ≥ ε₀ となる点を選べます。これは xₙ → c なのに f(xₙ) が f(c) へ収束しない列なので、点列による条件と矛盾します。

ここでは外側の関数が c で定義され、連続であることを使いました。c を除いた極限だけが分かっている場合、内側がちょうど c を取る入力で合成が未定義になる可能性があり、同じ形を無条件には使えません。

区間縮小法と実数の完備性

二分法で得た閉区間は、前の区間の中に次の区間が入る「入れ子」です。幅はどこまでも小さくなります。しかし、手順を有限回実行しても、一般には答えそのものは出ません。「永久に絞り続けた先に、数がひとつ存在する」という部分を支えるのが実数の完備性です。

最小上界性から導く入れ子区間の定理

空でない実数の閉区間 [aₙ, bₙ] が入れ子になり、その幅が 0 に近づくなら、すべての区間に共通する実数がただひとつ存在します。

左端の上限を取る

左端の集合は空でなく、b₁ 以下なので、最小上界性により c = sup{aₙ} が存在します。任意の固定した n について、すべての左端は bₙ 以下です。後の左端は入れ子の条件から、前の左端は aₙ 以下であることから分かります。よって aₙ ≤ c ≤ bₙ で、c は全区間に入ります。別の共通点 d があれば |c − d| ≤ bₙ − aₙ → 0 となるため d = c です。二分法で幅が 0 へ近づくことは、r = 1/2 の補題で保証されます。

なぜ「実数」とわざわざ書くのでしょう。定義域を [0, 2] 内の有理数だけに限り、同じ x² − 2 を考えてみます。中点を取る操作は分数のまま続けられ、関数も有理数の範囲で連続です。それでも、数の世界の章で証明したように x² = 2 を満たす有理数はありません。実数の世界で区間を埋め合わせる √2 が、有理数の世界にはないからです。計算の規則だけでなく、数の世界の性質も結論に関わります。

中間値の定理

中間値の定理の、根を見つける形

実数の閉区間 [a, b]（a < b）全体で f が定義され連続であり、f(a) < 0 < f(b) なら、a < c < b を満たす実数 c で f(c) = 0 となるものが存在します。符号が逆の場合も同様です。端の値が 0 なら、その端がすでに根です。

二分法からの短い証明

中点で 0 が出れば、それが求める点です。出なければ、左端で負、右端で正という条件を保って区間を半分にし続けます。いま証明した入れ子区間の定理により、すべての区間に入る一点 c が存在します。幅が 0 に近づくので、左右の端はともに c に近づきます。

もし f(c) > 0 なら、連続性で出力のずれを f(c)/2 より小さく抑えられるため、c に十分近い点の値も正です。しかし左端は c に近づくのに、値はずっと負。これは矛盾です。f(c) < 0 と仮定しても右端の正の値と矛盾するので、残るのは f(c) = 0 です。端 a、b の値は 0 でないため、c はその内側にあります。

ここで二つの条件が別々に働きました。完備性は区間の先に入力 c があることを保証し、連続性はその点の出力が 0 であることを保証します。定理は、ただ図を信じるための名前ではありません。どの橋を渡って結論へ届いたかを示しています。

この定理が保証するのは根の存在で、個数ではありません。例えば f(x) = x³ − x は [−2, 2] の両端で符号が違いますが、根は −1、0、1 の三つです。唯一の根を求めたいなら、区間内で厳密に増加するなど、別の条件が要ります。

二分法の誤差評価

最初の [0, 2] から n 回半分にした区間を [aₙ, bₙ]、その中点を mₙ とします。幅は毎回半分なので、根 c に対する中点の誤差には次の保証があります。

bn−an=22n,|mn−c|≤12n

根が区間に入っているので、中点から根までの距離は幅の半分以下です。この誤差は x の誤差であり、|f(mₙ)| という出力の誤差とは区別します。√2 は無理数なので、有理数である有限回の中点と完全には一致しません。それでも、必要な精度を決めれば、何回計算すればよいかを先に決められます。

寄り道［応用］：実用の根探しにも「連続であること」と書いてある

科学計算ライブラリ SciPy の brentq は、符号が違う両端の間から方程式の根を探す関数です。公式文書は入力の条件として、区間で関数が連続であることと、端の値が異符号であることを明記しています。内部では二分法をほかの近似手順と組み合わせていますが、速く探す工夫の下にも、この章の存在保証があります。

コンピュータに渡せるのは、有限個の点で値を計算する手順です。それだけで区間の全点における連続性を検査したことにはなりません。飛びや極を含む式を入れて区間が狭まっても、根の存在は別問題です。定理の仮定は、実装の説明に添える飾りではなく、計算結果を根として受け取るために、使う側も確認すべき契約なのです。

中間値の定理と二分法の演習

1．何回で十分か

[0, 2] からの二分法で、中点の誤差を 0.001 以下と保証したいとき、何回半分にすれば十分ですか。

ヒント1：幅と誤差を区別する

中点の誤差の上限は 2/2ⁿ ではなく 1/2ⁿ です。

ヒント2：近い二つのべき乗

2⁹ = 512、2¹⁰ = 1024 を使います。

解答

10 回で 1/1024 = 0.0009765625 ≤ 0.001 なので十分です。9 回では上限が 1/512 > 0.001 のため、この評価だけでは保証できません。

2．仮定のどこが欠けるか

「x < 1.3 で −1、それ以外で +1」と「1/(x − 1.3)」に、[0, 2] 上の中間値の定理を使えない理由を、それぞれ述べてください。

ヒント1：定理の条件へ戻る

両端の符号以外に、「全体で定義される」と「連続」が必要です。

ヒント2：境目の値を見る

前者は 1.3 で値を持ちます。後者はどうでしょう。

解答

前者は全体で定義されますが、1.3 で連続でありません。後者は 1.3 で分母が 0 になり、区間全体では定義されません。どちらも両端の符号は違いますが、0 になる点はありません。

3．根は一つだけか

x² − 2 の根が [0, 2] にただ一つしかないことを、中間値の定理にもう一つの議論を加えて説明してください。

ヒント1：二点を比べる

0 ≤ x < y ≤ 2 としたときの y² − x² を調べます。

ヒント2：因数分解する

y² − x² = (y − x)(y + x)。二つの因子の符号はどうなりますか。

解答

y − x > 0、y + x > 0 なので y² − x² > 0。関数は厳密に増加し、異なる二点で同じ値 0 を取れません。中間値の定理が少なくとも一つの存在を保証し、この比較が高々一つであることを保証するので、ただ一つです。
