連続性と方程式の解の存在

正方形の面積を 2 にする辺の長さを知りたいとします。長さ 1 なら面積は小さすぎ、長さ 2 なら大きすぎる。途中にちょうどよい長さがありそうです。では、「ありそう」を「必ずある」に変えるには何が必要でしょうか。

関数 f(x) = x² − 2 を使えば、問いは「f(x) = 0 となる実数 x があるか」です。区間 [0, 2] の端では f(0) = −2、f(2) = 2。まずこの符号の違いを手がかりに、答えのありかを絞りましょう。ここで [a, b] は、両端を含む a 以上 b 以下の実数の集まりを表します。

f(x)=0を満たす入力 x を、f の零点と呼びます。方程式の解という意味で根ともいいます。ここで探しているのは出力の0そのものではなく、出力が0になる辺の長さです。

学習の目安は演習込み120–180分です。二分法の問い、連続性の定義、中間値の定理の証明と誤差評価の順に読みます。演習1–3は基本、4–7は点の値・端点・定義域、8–10は精度保証と共通する入力幅を扱います。

二分法と区間の縮小

区間の中点を調べ、値が 0 なら終了します。負なら中点を左端に、正なら右端にして、両端の符号が違う半分を残します。これを二分法と呼びます。最初の中点 1 では値が −1 なので、次の区間は [1, 2]。その中点 1.5 では値が 0.25 なので、[1, 1.5] が残ります。

下の実験では、同じ手順を三つの関数に使います。二つ目は 1.3 を境に −1 から +1 へ飛ぶ関数、三つ目は 1/(x − 1.3) です。反復回数を増やし、区間の幅と、その中に本当に 0 になる点があるかを分けて見てください。

区間を狭くする手順自体は、連続でない関数にも実行できてしまいます。飛び移りの関数では境目へ迫っても値は ±1 のまま。三つ目の関数では、両端の符号が違っていても 1.3 で関数が定義されず、ほかのどこでも値は 0 になりません。区間が狭まるという観察だけでは、根の存在は証明できないのです。

連続関数のε–δ定義

グラフを「ひと筆で描ける」という感覚を、議論で使える言葉に直しましょう。点 c で連続とは、出力のずれをどんな小さい許容幅 ε に収めたいと指定しても、入力のずれを十分小さい幅 δ に制限すれば、その要求を満たせることです。ε、δ はともに正の数です。

|x−c|<δ⇒|f(x)−f(c)|<ε

この条件は、定義域にあるすべての該当する x について満たす必要があります。区間の端では、その区間の内側からの近づき方を考えます。区間全体で連続とは、各点でこの条件が成り立つことです。「少し変えれば少し変わる」を、相手が要求する精度に応じて入力の精度を選べる、という約束にしたのです。

x² − 2 なら、x と c が [0, 2] にあるとき、出力の差は |x² − c²| = |x − c||x + c| ≤ 4|x − c|。したがって δ = ε/4 と選べば要求を満たせます。一方、飛び移りの関数の c = 1.3 では、いくら近い左側の点でも出力の差は 2。例えば ε = 1 という要求に応えられません。この境目では連続でない、と判定できます。

一点での極限と連続になる値

前章の極限は、その点を除いた周囲での挙動でした。連続性では、その点の値f(c)が比較相手になります。周囲からの極限があっても、点の値がないか別の値なら連続とはいえません。点cに周囲の入力がある場合、①f(c)が定義される、②x→cでの極限が存在する、③その極限がf(c)に等しい、という三つを分けると状態を整理できます。

例題：穴を埋める値は何でもよいか

x≠1でf(x)=(x²−1)/(x−1)とします。因数分解するとf(x)=x+1なので、x→1での極限は2です。実際、ε>0に対しδ=εとすれば、0<|x−1|<δで|f(x)−2|=|x−1|<εです。x=1では元の式は定義されません。

ここへf(1)=Kという実数値を付け足します。K=2なら、x=1でも出力差は0、x≠1では差|x−1|なので、同じδ=εで連続の条件を満たします。K=5なら連続ではありません。ε=1を指定し、どんなδ>0にもh=min(δ/2,1/2)とx=1+hを取ります。hは正でh<δですが、|f(1+h)−f(1)|=|2+h−5|=3−h≥5/2>1です。

従ってK=2だけが連続に埋める値です。Kが2以外の一般の場合も、もし連続ならその点の極限はf(1)=Kでなければならず、極限の一意性によりK=2へ戻ります。点の値を変えるだけでは周囲の極限を動かせず、むしろ極限が、連続にする点の値を決めています。

端点でも比較相手は点の値です。f(x)=√xを[0,1]で考えるとf(0)=0があり、任意のε>0に対しδ=ε²で、定義域内の0≤x<δなら|f(x)−f(0)|=√x<εです。したがって0で連続です。左側の実数にも値を作る必要はなく、指定された定義域の中で全該当入力を扱います。区間の端を内側から読むという定義がここで働きます。

合成関数と点列による連続性

定義域の点を順に並べた x₁,x₂,… を点列と呼びます。ここでは各入力が実数なので、点列は実数の数列です。

連続関数と極限

g(h) → c で f が c で連続なら、合成が定義される範囲で f(g(h)) → f(c) です。また f が c で連続であることは、定義域内のどの数列 xₙ → c に対しても f(xₙ) → f(c) となることと同値です。

許容幅を順につなぐ

最初の主張では、出力の要求 ε に対し、f の連続性で入力の幅 η を選び、次に g(h) が c から η 未満になる入力の幅を選びます。点列の場合も、十分先で |xₙ − c| < η とすれば同じです。逆に連続でなければ、ある ε₀ > 0 に対し、各 n で |xₙ − c| < 1/n なのに |f(xₙ) − f(c)| ≥ ε₀ となる点を選べます。これは xₙ → c なのに f(xₙ) が f(c) へ収束しない列なので、点列による条件と矛盾します。

ここでは外側の関数が c で定義され、連続であることを使いました。c を除いた極限だけが分かっている場合、内側がちょうど c を取る入力で合成が未定義になる可能性があり、同じ形を無条件には使えません。

合成の連続性と許容幅の受け渡し

外側と内側の関数の連続性を、式の名前だけで適用せず、要求する精度をどう渡すか見てみましょう。F(x)=√(1+x²)を点0で考えます。内側u(x)=1+x²は0へ近づくと1へ近づき、外側v(y)=√yはy=1で連続です。内側の出力は常に1以上なので、外側の定義域にも必ず入ります。

例題：外側の要求を先に決める

外側ではy≥0に対し|√y−1|=|y−1|/(√y+1)≤|y−1|です。従って最終誤差εを満たすには、外側への入力を|y−1|<εに収めれば足ります。そこで内側を見ると|u(x)−1|=x²なので、|x|<√εとすればその要求へ届きます。δ=√εは正で、|x|<δなら|F(x)−F(0)|<εです。

F全体を直接評価すると、さらに|√(1+x²)−1|=x²/(√(1+x²)+1)≤x²/2となり、δ=√(2ε)でも足ります。合成の定理から得る選択は十分なもので、最大の入力幅とは限りません。外側への入力が1以上という、今回の式に固有の情報を使うと、保証を少し広げられました。

例えばε=0.01なら最初の選択はδ=0.1、直接評価の選択はδ=√0.02です。どちらも正しく、前者が誤りということではありません。極限や連続性を示す場面では簡単な十分条件が便利で、許される入力幅を大きくしたい場面では、より丁寧な評価に意味があります。

証明の順番は「最終出力のε→外側の入力幅→内側の入力幅」です。関数を実際に計算する順番「内側→外側」と逆になります。定理にある二段階の幅の選択は、この精度の受け渡しを一般の関数で行ったものです。

区間縮小法と実数の完備性

二分法で得た閉区間は、前の区間の中に次の区間が入る「入れ子」です。幅はどこまでも小さくなります。しかし、手順を有限回実行しても、一般には答えそのものは出ません。「永久に絞り続けた先に、数がひとつ存在する」という部分を支えるのが実数の完備性です。

最小上界性から導く入れ子区間の定理

空でない実数の閉区間 [aₙ, bₙ] が入れ子になり、その幅が 0 に近づくなら、すべての区間に共通する実数がただひとつ存在します。

左端の上限を取る

左端の集合は空でなく、b₁ 以下なので、最小上界性により c = sup{aₙ} が存在します。任意の固定した n について、すべての左端は bₙ 以下です。後の左端は入れ子の条件から、前の左端は aₙ 以下であることから分かります。よって aₙ ≤ c ≤ bₙ で、c は全区間に入ります。別の共通点 d があれば |c − d| ≤ bₙ − aₙ → 0 となるため d = c です。二分法で幅が 0 へ近づくことは、r = 1/2 の補題で保証されます。

なぜ「実数」とわざわざ書くのでしょう。定義域を [0, 2] 内の有理数だけに限り、同じ x² − 2 を考えてみます。中点を取る操作は分数のまま続けられ、関数も有理数の範囲で連続です。それでも、数の世界の章で証明したように x² = 2 を満たす有理数はありません。実数の世界で区間を埋め合わせる √2 が、有理数の世界にはないからです。計算の規則だけでなく、数の世界の性質も結論に関わります。

中間値の定理

中間値の定理の、根を見つける形

実数の閉区間 [a, b]（a < b）全体で f が定義され連続であり、f(a) < 0 < f(b) なら、a < c < b を満たす実数 c で f(c) = 0 となるものが存在します。符号が逆の場合も同様です。端の値が 0 なら、その端がすでに根です。

二分法からの短い証明

中点で 0 が出れば、それが求める点です。出なければ、左端で負、右端で正という条件を保って区間を半分にし続けます。いま証明した入れ子区間の定理により、すべての区間に入る一点 c が存在します。幅が 0 に近づくので、左右の端はともに c に近づきます。

もし f(c) > 0 なら、連続性で出力のずれを f(c)/2 より小さく抑えられるため、c に十分近い点の値も正です。しかし左端は c に近づくのに、値はずっと負。これは矛盾です。f(c) < 0 と仮定しても右端の正の値と矛盾するので、残るのは f(c) = 0 です。端 a、b の値は 0 でないため、c はその内側にあります。

ここで二つの条件が別々に働きました。完備性は区間の先に入力 c があることを保証し、連続性はその点の出力が 0 であることを保証します。定理は、ただ図を信じるための名前ではありません。どの橋を渡って結論へ届いたかを示しています。

名前の「中間値」は、0に限らず両端の高さの間の値を全て取ることから来ています。例えば f(a) < y₀ < f(b) という目標の高さ y₀ を選んだら、g(x)=f(x)−y₀ と高さをずらします。gの両端の符号が違うので、いまの定理から g(c)=0、つまり f(c)=y₀ となる点が得られます。

この定理が保証するのは根の存在で、個数ではありません。例えば f(x) = x³ − x は [−2, 2] の両端で符号が違いますが、根は −1、0、1 の三つです。唯一の根を求めたいなら、区間内で厳密に増加するなど、別の条件が要ります。

中間値の定理と根の一意性の併用

定理を使い、簡単な式で解けない方程式の根を囲んでみましょう。f(x)=x³+x−1を[0,1]で考えます。立方はxを三回掛けたもので、和と積の極限法則から連続です。この区間なら直接にも、|f(x)−f(c)|=|x−c||x²+xc+c²+1|≤4|x−c|となり、δ=ε/4で連続性を確かめられます。

例題：存在、個数、位置を別々に保証する

両端はf(0)=−1、f(1)=1で異符号です。[0,1]全体で定義され連続なので、中間値の定理から0<c<1でf(c)=0となる点が少なくとも一つあります。次に0≤x<y≤1なら、f(y)−f(x)=(y−x)(y²+xy+x²+1)>0です。どの因子も非負で、最初の因子と括弧内は正なので、厳密に増加します。従って同じ値0を異なる二点では取れず、根はただ一つです。

ここまでで存在と個数が決まりましたが、まだ小数の値は計算していません。位置を絞るため二分法を使います。中点0.5ではf(0.5)=0.125+0.5−1=−0.375なので[0.5,1]、次の0.75では0.421875+0.75−1=0.171875なので[0.5,0.75]が残ります。各回、両端が異符号という条件を保つので、同じ唯一の根を失いません。

表では「調べた中点」と「その後残す区間」を区別してください。中点を区間の端へ移した後、次の中点は別の数になります。数値はこの自作の多項式の正確な有限小数で、他の関数で浮動小数点誤差が消えるという意味ではありません。

二分法の誤差評価

最初の [0, 2] から n 回半分にした区間を [aₙ, bₙ]、その中点を mₙ とします。幅は毎回半分なので、根 c に対する中点の誤差には次の保証があります。

bn−an=22n,|mn−c|≤12n

根が区間に入っているので、中点から根までの距離は幅の半分以下です。この誤差は x の誤差であり、|f(mₙ)| という出力の誤差とは区別します。√2 は無理数なので、有理数である有限回の中点と完全には一致しません。それでも、必要な精度を決めれば、何回計算すればよいかを先に決められます。

寄り道［応用］：実用の根探しにも「連続であること」と書いてある

科学計算ライブラリ SciPy の brentq は、符号が違う両端の間から方程式の根を探す関数です。公式文書は入力の条件として、区間で関数が連続であることと、端の値が異符号であることを明記しています。内部では二分法をほかの近似手順と組み合わせていますが、速く探す工夫の下にも、この章の存在保証があります。

コンピュータに渡せるのは、有限個の点で値を計算する手順です。それだけで区間の全点における連続性を検査したことにはなりません。飛びや極を含む式を入れて区間が狭まっても、根の存在は別問題です。定理の仮定は、実装の説明に添える飾りではなく、計算結果を根として受け取るために、使う側も確認すべき契約なのです。

中間値の定理と二分法の演習

1．何回で十分か

[0, 2] からの二分法で、中点の誤差を 0.001 以下と保証したいとき、何回半分にすれば十分ですか。

ヒント1：幅と誤差を区別する

中点の誤差の上限は 2/2ⁿ ではなく 1/2ⁿ です。

ヒント2：近い二つのべき乗

2⁹ = 512、2¹⁰ = 1024 を使います。

解答

10 回で 1/1024 = 0.0009765625 ≤ 0.001 なので十分です。9 回では上限が 1/512 > 0.001 のため、この評価だけでは保証できません。

2．仮定のどこが欠けるか

「x < 1.3 で −1、それ以外で +1」と「1/(x − 1.3)」に、[0, 2] 上の中間値の定理を使えない理由を、それぞれ述べてください。

ヒント1：定理の条件へ戻る

両端の符号以外に、「全体で定義される」と「連続」が必要です。

ヒント2：境目の値を見る

前者は 1.3 で値を持ちます。後者はどうでしょう。

解答

前者は全体で定義されますが、1.3 で連続でありません。後者は 1.3 で分母が 0 になり、区間全体では定義されません。どちらも両端の符号は違いますが、0 になる点はありません。

3．根は一つだけか

x² − 2 の根が [0, 2] にただ一つしかないことを、中間値の定理にもう一つの議論を加えて説明してください。

ヒント1：二点を比べる

0 ≤ x < y ≤ 2 としたときの y² − x² を調べます。

ヒント2：因数分解する

y² − x² = (y − x)(y + x)。二つの因子の符号はどうなりますか。

解答

y − x > 0、y + x > 0 なので y² − x² > 0。関数は厳密に増加し、異なる二点で同じ値 0 を取れません。中間値の定理が少なくとも一つの存在を保証し、この比較が高々一つであることを保証するので、ただ一つです。

4．穴を埋める値を逆算する

x≠2でf(x)=(x³−8)/(x−2)、x=2でf(2)=Kとします。2で連続になるKを求め、εに応じたδの一つを示してください。「元の分子が0だからK=0」とする案も診断してください。

ヒント1

x³−8=(x−2)(x²+2x+4)です。約分はx≠2で行います。

ヒント2

K=12が候補です。|x²+2x+4−12|=|x−2||x+4|で、|x−2|<1なら|x+4|<7です。

解答

周囲でf(x)=x²+2x+4なので、x→2での極限は12。連続ならK=12が必要です。この値を付けると全xでf(x)=x²+2x+4と読めます。ε>0に対しδ=min(1,ε/7)なら、|x−2|<δで|f(x)−12|=|x−2||x+4|<7|x−2|<ε（x=2では差0）。従って十分です。元の式はx=2で0/0という未定義の形なので、分子の値だけから商の値0を決められません。

5．端点での連続性を定義域から読む

f(x)=√xを[0,4]で考えます。点0での連続性をε–δで示し、負のxを調べなくてよい理由を述べてください。g(x)=1/xを(0,4]で定義した場合、g(0)を何か実数で付けて0で連続にできるでしょうか。

ヒント1

fの条件で調べる入力は0≤x≤4の範囲だけです。gではxₙ=1/nを考えます。

ヒント2

δ=ε²とすると√x<εです。一方g(1/n)=nになります。

解答

f(0)=0で、ε>0に対しδ=ε²を選ぶと、定義域内の|x|<δから0≤x<ε²、従って|√x−0|<εです。負のxは定義域にないので要求の対象ではありません。gではどんな実数Kをg(0)に置いても、1/n→0なのにg(1/n)=nはKへ収束しません。点列による連続性の条件に反するため、有限値で連続には埋められません。端点だから値を自由に決めてよいわけではありません。

6．端の符号が同じなら根はないか

連続関数の[−2,2]での両端の値がともに正であるとき、「根がない」と言えるでしょうか。「根がある」場合と「根がない」場合の多項式を一つずつ作り、異符号条件の役割を説明してください。

ヒント1

中間値の定理の条件が使えないことと、根がないことは別です。

ヒント2

x²−1とx²+1を比べます。

解答

f(x)=x²−1は両端で3>0ですが、根−1、1を持ちます。g(x)=x²+1は両端で5>0で、全実数xで1以上なので根がありません。従って同符号という情報だけでは判定できません。連続性の下で異符号なら根の存在に十分ですが、根が存在するための必要条件ではありません。定理の仮定を満たさないことから、結論の否定は導けません。

7．定義域の間に穴がある場合

D=[−2,−1]∪[1,2]上でf(x)=1/xとします。fはDの各点で連続で、f(−1)<0<f(1)です。それでも根がない理由と、中間値の定理の欠けた条件を説明してください。

ヒント1

端点−1と1の間の閉区間全体が、定義域へ入っているでしょうか。

ヒント2

0はDに入らず、−1と1の間の点もほとんどDに入りません。

解答

1/xは定義されたどの点でも0にならないので、根はありません。定理には[−1,1]全体で関数が定義され連続であることが必要ですが、今回Dは二つに分かれ、間の点を欠いています。Dの各点での連続性だけでは、その間の値をつなぐ保証はありません。端点の符号だけを抜き出して、定理が要求する区間を別の集合へ置き換えてはいけません。

8．どの近似値へ誤差を付けるか

根cを含む[1.25,1.5]が得られたとします。①中点1.375、②右端1.5を近似値にする場合、区間の情報だけで保証できる誤差をそれぞれ求めてください。端点の符号が異なることだけから、右端にも中点と同じ保証を付けられますか。

ヒント1

区間内で近似値から最も遠い点までの距離を調べます。

ヒント2

幅は0.25です。中点から両端へは同じ距離です。

解答

①は|1.375−c|≤0.125、②は|1.5−c|≤0.25です。異符号なら根は厳密に内部にありますが、左端へいくらでも近い可能性を排除できず、右端の誤差を一律に0.125以下とは保証できません。例えば[1.25,1.5]でf(x)=x−1.26なら端点は異符号でも、右端の誤差は0.24です。返す点を明示してから誤差の式を適用します。

9．小さい関数値は小さい位置誤差か

自作の一次関数f(x)=10⁻⁶(x−1)を考えます。近似値m=2での|f(m)|と、真の根cからの距離|m−c|を求めてください。『|f(m)|が0.001未満だから根の位置も0.001以内』という停止判定を診断し、この関数で位置誤差を0.001以下にする関数値の条件を求めてください。

ヒント1

根は1です。関数値の差は位置の差を10⁻⁶倍したものです。

ヒント2

|m−1|=10⁶|f(m)|を使います。

解答

c=1なので|f(2)|=10⁻⁶ですが、|2−1|=1です。関数値だけの小ささを同じ数の位置誤差へ移す判定は無効です。この関数では|m−c|=10⁶|f(m)|なので、位置誤差0.001以下は|f(m)|≤10⁻⁹と同値です。関数の尺度を変えると関数値の誤差は変わっても根の位置は変わりません。二分法の区間幅による保証は、この尺度に依存しない点が利点です。

10．同じδを全点で使えるか

f(x)=1/xについて、①[1,2]では任意のcとxに共通するδ=εが連続性の保証に使えることを示してください。②(0,∞)全体で、ε=1に対し一つのδ>0を全cに共通で使うことはできないと示してください。各点で連続であることとは区別します。

ヒント1

①は|1/x−1/c|=|x−c|/(xc)でxc≥1です。②は0に近いcとx=2cを考えます。

ヒント2

任意のδ>0に対しc=min(δ/2,1/4)、x=2cとすると、|x−c|=c<δ、出力差は1/(2c)です。

解答

①x,c∈[1,2]では|f(x)−f(c)|≤|x−c|なので、δ=εで全cに同じ保証が使えます。②任意のδ>0に対し、ヒントのcを選ぶとc>0、c<δで、x=2cも正です。しかし|1/x−1/c|=1/(2c)≥2>1。従って一つのδを全点に共通にはできません。一方、固定したc>0ではδ=min(c/2,εc²/2)とすれば、|x−c|<δからx>c/2、誤差|x−c|/(xc)<2δ/c²≤εとなり連続です。点ごとにδを選ぶ要求と、点を選ぶ前に共通δを決める要求の順序が違います。

  2. 完備性と連続性は、証明のどの段階で必要でしたか。
  3. 区間が狭まる図を見たとき、根があると言う前に何を確認しますか。
