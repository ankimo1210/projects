流束と法線成分

流れと平行に板を置くと、板の面積が大きくても流れは板を横切りません。面を通り抜ける寄与を数えるには、場のうち面に垂直な成分だけが必要です。線に沿う仕事では接方向を使いましたが、今度は面の法線方向を使います。

復習は内積と外積、曲面と面積要素です。「流れ」は数学の場のモデルとして用い、物理的な保存則をここで仮定しません。

ベクトル場の面積分と流束の定義

正則な曲面片 r(u, v) の法線には二つの向きがあります。一方を n = (rᵤ × rᵥ)/‖rᵤ × rᵥ‖ と選べば、n は連続な単位法線です。逆は −n。複数の片で滑らかに続く面では、重なる座標でも同じ法線を選びます。こうして全体で整合する連続な単位法線を選べる曲面を向き付け可能と呼び、本章ではそのような面を扱います。角を持つ面では滑らかな各片に法線を選び、境界曲線は面積に寄与しないものとして積分します。

曲面 S 上で連続な場 F に対し、選んだ向きでの流束を次で定めます。n を選んだことがデータの一部であり、流束は正にも負にもなります。

Flux(F,S,n):=∬SF·ndS=∬DF(r)·(ru×rv)dudv

最後の等式は n を外積の向きに選んだ場合です。ベクトル面積要素 dS⃗ = n dS と書くと、dS⃗ = (rᵤ × rᵥ)du dv。単位化で割った長さと面積要素の長さが打ち消し合います。反対の向きなら全体に負号を付けます。例えば F·n = 0 なら接方向の流れで寄与は0、F·n > 0 なら選んだ正方向、F·n < 0 なら逆方向へ横切る寄与です。

グラフ曲面の上向き面積ベクトル

z = g(x, y) を D 上の C¹ グラフとし、r(u, v) = (u, v, g(u, v)) とします。外積は (−gᵤ, −gᵥ, 1) で第三成分が正なので、上向きの法線を与えます。F = (P, Q, R) とすると、流束は次になります。P、Q、R はすべて (u, v, g(u, v)) で評価します。

∬SF·ndS=∬D(−Pgu−Qgv+R)dudv

具体的に F = (0, 0, c)、平面 z = au + bv、D = [−1, 1]² とします。外積は (−a, −b, 1) なので、曲面積は 4√(1 + a² + b²)。しかし上向き流束は ∬D c du dv = 4c で、傾き a、b によりません。下向きなら −4c です。面積の増加と法線への射影の減少が、正確に相殺します。

曲面の座標変換と向き

行列式の符号は、法線の反転を記録する

前章の座標変換 η = r ∘ T では、ηₛ × ηₜ = det DT·(rᵤ × rᵥ) でした。det DT > 0 なら同じ法線向きです。流束の式へ代入し、変数変換定理を使うと値が一致します。

det DT < 0 なら η の外積は逆向きになります。そのまま外積を使って積分すれば符号が反転します。同じ向き付き曲面の流束を計算したいなら、η の外積に負号を付け、もとの選択 n に合わせます。座標の交換だけで、あらかじめ指定した面の正方向まで勝手に変えてはいけません。

z=x、−1≤x,y≤1の同じ面で、符号だけを替えて検算する

上向き、F=(0,0,1)4√24√2 × 1/√2 = 4
法線だけ反転4√2−4

閉曲面の外向き法線

立体 Ω の境界 S = ∂Ω が有限個の滑らかな面でできるときは、通常は外向きを正とします。これは各点でΩから外へ出る方向です。球の上部では上向き、下部では下向きであり、「外向き」は「いつでも上向き」ではありません。稜線や角で法線が一つに決まらなくても、各面の積分を足します。

定数場 F = (0, 0, c) で直方体の外向き流束を考えると、上面の寄与は c × 上面積、下面は −c × 下面積、側面は0なので合計0です。一方、F(x, y, z) = (x, y, z) を半径 R の球で考えると、外向き単位法線 n = (x, y, z)/R との内積は R。前章の球面積から流束は R·4πR² = 4πR³ です。これらは各面の定義からの直接計算です。

第9章のGaussの定理は、閉曲面の外向き流束を内部の積分と結びます。ここでは、閉じたという理由だけで流束0とは結論しません。内部にどんな場があるかが関わります。

寄り道［自作モデル］：窓の量を二つの方法で数える

一定の上向きの場 (0, 0, 1) と、投影が同じ正方形になる傾いた平面片のモデルでは、面の実面積は変わっても上向き流束は4のままです。面積を大きくするために傾けると、場の法線成分がちょうど小さくなります。

この相殺は、本章の平面・一定場の仮定から出た正確な結果です。場が場所により変わる場合、同じ投影だから同じ流束と即断できません。まず面上での場の値を評価する必要があります。

出典：F = (0, 0, 1)、z = au + bv の自作モデルを直接積分したものです。

演習：面積・法線・流束

1．傾きが増えたら流束も増えるか

F = (0, 0, 2)、S は z = 2u − v、−1 ≤ u, v ≤ 1 です。面積と上向き・下向きの流束を求めてください。

ヒント1：外積

rᵤ × rᵥ = (−2, 1, 1) で長さは √6。

ヒント2：内積を先に取る

(0, 0, 2)·(−2, 1, 1) = 2、座標面積は4です。

解答

面積は4√6、上向き流束は8、下向き流束は−8です。単位法線を使えば F·n = 2/√6 となり、面積要素の √6 と相殺します。

2．場を面上で評価する

F(x, y, z) = (x, 0, z)、S は z = 1 + x、0 ≤ x, y ≤ 1 の上向きグラフです。流束を求めてください。

ヒント1：ベクトル面積要素

r(x, y) = (x, y, 1 + x) なので外積は (−1, 0, 1)。

ヒント2：第三成分も代入する

F(r) = (x, 0, 1 + x) です。

解答

F(r)·(−1, 0, 1) = −x + 1 + x = 1。単位正方形で積分して流束は1です。場の第三成分を z のまま残して平面への代入を忘れると、正しい被積分関数になりません。

3．閉じた面でも0とは限らない

Ω = [−1, 1]³、F(x, y, z) = (x, y, z) とします。六面の外向き流束を直接足してください。

ヒント1：x の二面

x = 1 では n = (1, 0, 0)、x = −1 では n = (−1, 0, 0)。どちらも F·n = 1。

ヒント2：各面の面積

一面の面積は4です。y、z の面も同様です。

解答

六面のいずれでも F·n = 1 なので一面あたり4、合計24です。反対側の面では場も法線も反転するため、内積は同じ正の値です。閉曲面であることだけから合計0とはいえません。

  2. 座標を交換したとき、同じ向き付き曲面の流束を保つには何を確認しますか。
  3. 閉じた境界の「外向き」は「上向き」とどう違い、流束0を何も仮定せず結論できないのはなぜですか。
