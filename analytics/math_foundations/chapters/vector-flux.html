流束と法線成分

流れと平行に板を置くと、板の面積が大きくても流れは板を横切りません。面を通り抜ける寄与を数えるには、場のうち面に垂直な成分だけが必要です。線に沿う仕事では接方向を使いましたが、今度は面の法線方向を使います。

復習は内積と外積、曲面と面積要素です。「流れ」は数学の場のモデルとして用い、物理的な保存則をここで仮定しません。

学習時間の目安は演習を含みます。本文と例題、条件を変える考察、演習の三回に分けて読み進めても構いません。

ベクトル場の面積分と流束の定義

面に接する二つの独立な方向の両方に垂直な、0でないベクトルを法線ベクトルと呼びます。その長さを1にしたものが単位法線です。例えば xy 平面では (0,0,1) と (0,0,−1) が、二つの向きの単位法線です。前章の二接方向 rᵤ,rᵥ の外積を使えば、向きを付けた法線を一つ作れます。

正則な曲面片 r(u, v) の法線には二つの向きがあります。一方を n = (rᵤ × rᵥ)/‖rᵤ × rᵥ‖ と選べば、n は連続な単位法線です。逆は −n。複数の片で滑らかに続く面では、重なる座標でも同じ法線を選びます。こうして全体で整合する連続な単位法線を選べる曲面を向き付け可能と呼び、本章ではそのような面を扱います。角を持つ面では滑らかな各片に法線を選び、境界曲線は面積に寄与しないものとして積分します。

曲面 S 上で連続な場 F に対し、選んだ向きでの流束を次で定めます。n を選んだことがデータの一部であり、流束は正にも負にもなります。

Flux(F,S,n):=∬SF·ndS=∬DF(r)·(ru×rv)dudv

最後の等式は n を外積の向きに選んだ場合です。ベクトル面積要素 dS⃗ = n dS と書くと、dS⃗ = (rᵤ × rᵥ)du dv。単位化で割った長さと面積要素の長さが打ち消し合います。反対の向きなら全体に負号を付けます。例えば F·n = 0 なら接方向の流れで寄与は0、F·n > 0 なら選んだ正方向、F·n < 0 なら逆方向へ横切る寄与です。

グラフ曲面の上向き面積ベクトル

z = g(x, y) を D 上の C¹ グラフとし、r(u, v) = (u, v, g(u, v)) とします。外積は (−gᵤ, −gᵥ, 1) で第三成分が正なので、上向きの法線を与えます。F = (P, Q, R) とすると、流束は次になります。P、Q、R はすべて (u, v, g(u, v)) で評価します。

∬SF·ndS=∬D(−Pgu−Qgv+R)dudv

具体的に F = (0, 0, c)、平面 z = au + bv、D = [−1, 1]² とします。外積は (−a, −b, 1) なので、曲面積は 4√(1 + a² + b²)。しかし上向き流束は ∬D c du dv = 4c で、傾き a、b によりません。下向きなら −4c です。面積の増加と法線への射影の減少が、正確に相殺します。

面上の値・面積・向きを、一つずつ決める

流束の計算では、式を長く展開するより先に三つのデータをそろえます。第一にどの面か、第二にどちら向きか、第三に面上で場がいくつかです。「上向き」は法線のz成分が正という条件であって、場が上を向くという意味ではありません。

  1. 面の座標領域を決め、正則かつ一度ずつ覆う表示 r を選びます。
  2. rᵤ×rᵥ の向きが指定に合うかを、成分または領域の内外で確かめます。逆なら負号を付けます。
  3. F のすべての成分へ r を代入し、F(r)·(rᵤ×rᵥ) を積分します。
  4. 向きを逆にすると符号が逆か、接方向の場なら0かを検算します。

ベクトル面積要素を使うと、単位法線と dS の平方根を別々に計算する手間を省けます。ただし、外積を単位化した後に投影面積だけを掛けると、面の伸びを落とします。単位法線 n と実面積 dS、または外積と座標面積 du dv を一組で使います。

例題1：傾いた板で、場の代入による相殺を見る

S を z=1+x+2y、0≤x,y≤1 の板、F(x,y,z)=(x,y,z) とし、上向き流束を求めます。一定の鉛直場の例とは異なり、三成分すべてが場所で変わります。座標は r(x,y)=(x,y,1+x+2y)、ベクトル面積要素は (−1,−2,1)dxdy です。

第三成分の高さを代入してから内積を取る

F(r)=(x,y,1+x+2y) だから、F(r)·(−1,−2,1)=−x−2y+(1+x+2y)=1。よって上向き流束は ∫₀¹∫₀¹1dy dx=1、下向きは−1です。

別の検算では n=(−1,−2,1)/√6、dS=√6dxdy。F·n=1/√6 は面上で一定なので、実面積 √6 と掛けて1です。面が原点を通る z=x+2y なら同じ場との内積は0になります。原点から面上の点へ向かうベクトルが、その平面に沿うためです。

さらに z=c+x+2y とすれば上向き流束は c。傾きは同じで面積も同じでも、高さを変えると非一定場の面上での値が変わります。「投影が同じなら同じ流束」は、場と面の条件を確かめた上で使う結論です。

例題2：流束0は、どこでも横切らないことか

単位円板 D={x²+y²≤1} の上の放物面 z=x²+y² を上向きに取り、F=(x,y,1) の流束を計算します。r=(x,y,x²+y²) は第一・第二成分から単射、外積 (−2x,−2y,1) は常に非零です。

局所の正負を残してから、全体を足す

内積は F(r)·(−2x,−2y,1)=1−2x²−2y²。円対称なので、投影面で x=ρ cosθ、y=ρ sinθ とし、dxdy=ρ dρdθ を使います。ここで ρ は投影面の半径で、曲面写像 r とは別の記号です。

流束は ∫₀²π∫₀¹(1−2ρ²)ρ dρdθ=2π[ρ²/2−ρ⁴/2]₀¹=0 です。しかし中心では内積1、円周では−1。中心側から選んだ法線方向へ通る寄与と、外周側で逆に通る寄与が相殺したのであって、どこでも接しているわけではありません。

符号が変わる円は ρ=1/√2。内側の寄与は 2π[ρ²/2−ρ⁴/2]₀^(1/√2)=π/4、外側は−π/4 です。下向きへ反転すれば両部分の符号が交換し、全体はやはり0になります。

全体の0を、接方向の0と正負の相殺に分けて読みます

ρ=1/√20この円周は面積0

表の内積は単位法線との内積ではなく、投影面積に掛ける面積ベクトルとの内積です。流束の列は各部分を実際に積分した値です。全体の0だけを見て「場が面の接方向」と診断できないことが読み取れます。

例題3：面積を保ち、流束を0にする板を設計する

自作の板モデルとして、0≤x,y≤1 上の平面 z=ax+by、一定場 F=(1,0,2) を考えます。実面積を3、上向き流束を0にする傾きを探します。面積条件は √(1+a²+b²)=3、流束条件は ∫₀¹∫₀¹(−a+2)dy dx=0 です。

流束条件から a=2、面積条件へ戻して b²=4。したがって候補は (a,b)=(2,2)、(2,−2) です。y方向へ上る条件を加えれば前者に決まります。外積 (−2,−b,1) と場 (1,0,2) の内積は全点で0なので、この例の0は例題2の相殺とは違い、各点で場が接方向になった結果です。

設計できる流束にも限界があります。同じ面積3の条件から |a|≤√8 なので、上向き流束2−aは 2−√8 以上 2+√8 以下。例えば流束6を指定すると a=−4 が必要ですが、a²>8となり面積条件と両立しません。逆算では方程式の解だけでなく、残った条件に実数解があるかも確認します。

曲面の座標変換と向き

行列式の符号は、法線の反転を記録する

前章の座標変換 η = r ∘ T では、ηₛ × ηₜ = det DT·(rᵤ × rᵥ) でした。det DT > 0 なら同じ法線向きです。流束の式へ代入し、変数変換定理を使うと値が一致します。

det DT < 0 なら η の外積は逆向きになります。そのまま外積を使って積分すれば符号が反転します。同じ向き付き曲面の流束を計算したいなら、η の外積に負号を付け、もとの選択 n に合わせます。座標の交換だけで、あらかじめ指定した面の正方向まで勝手に変えてはいけません。

z=x、−1≤x,y≤1の同じ面で、符号だけを替えて検算する

閉曲面の外向き法線

以下の Ω は積分する立体、∂Ω はその境界全体です。ここで扱う閉曲面は、球面や直方体の全六面のように、縁を残さず立体を囲む全境界です。面の一部分だけを選ぶ場合と、全部を足す場合を分けます。

立体 Ω の境界 S = ∂Ω が有限個の滑らかな面でできるときは、通常は外向きを正とします。これは各点でΩから外へ出る方向です。球の上部では上向き、下部では下向きであり、「外向き」は「いつでも上向き」ではありません。稜線や角で法線が一つに決まらなくても、各面の積分を足します。

定数場 F = (0, 0, c) で直方体の外向き流束を考えると、上面の寄与は c × 上面積、下面は −c × 下面積、側面は0なので合計0です。一方、F(x, y, z) = (x, y, z) を半径 R の球で考えると、外向き単位法線 n = (x, y, z)/R との内積は R。前章の球面積から流束は R·4πR² = 4πR³ です。これらは各面の定義からの直接計算です。

第9章のGaussの定理は、閉曲面の外向き流束を内部の積分と結びます。ここでは、閉じたという理由だけで流束0とは結論しません。内部にどんな場があるかが関わります。

寄り道［自作モデル］：窓の量を二つの方法で数える

一定の上向きの場 (0, 0, 1) と、投影が同じ正方形になる傾いた平面片のモデルでは、面の実面積は変わっても上向き流束は4のままです。面積を大きくするために傾けると、場の法線成分がちょうど小さくなります。

この相殺は、本章の平面・一定場の仮定から出た正確な結果です。場が場所により変わる場合、同じ投影だから同じ流束と即断できません。まず面上での場の値を評価する必要があります。

出典：F = (0, 0, 1)、z = au + bv の自作モデルを直接積分したものです。

演習：面積・法線・流束

1．傾きが増えたら流束も増えるか

F = (0, 0, 2)、S は z = 2u − v、−1 ≤ u, v ≤ 1 です。面積と上向き・下向きの流束を求めてください。

ヒント1：外積

rᵤ × rᵥ = (−2, 1, 1) で長さは √6。

ヒント2：内積を先に取る

(0, 0, 2)·(−2, 1, 1) = 2、座標面積は4です。

解答

面積は4√6、上向き流束は8、下向き流束は−8です。単位法線を使えば F·n = 2/√6 となり、面積要素の √6 と相殺します。

2．場を面上で評価する

F(x, y, z) = (x, 0, z)、S は z = 1 + x、0 ≤ x, y ≤ 1 の上向きグラフです。流束を求めてください。

ヒント1：ベクトル面積要素

r(x, y) = (x, y, 1 + x) なので外積は (−1, 0, 1)。

ヒント2：第三成分も代入する

F(r) = (x, 0, 1 + x) です。

解答

F(r)·(−1, 0, 1) = −x + 1 + x = 1。単位正方形で積分して流束は1です。場の第三成分を z のまま残して平面への代入を忘れると、正しい被積分関数になりません。

3．閉じた面でも0とは限らない

Ω = [−1, 1]³、F(x, y, z) = (x, y, z) とします。六面の外向き流束を直接足してください。

ヒント1：x の二面

x = 1 では n = (1, 0, 0)、x = −1 では n = (−1, 0, 0)。どちらも F·n = 1。

ヒント2：各面の面積

一面の面積は4です。y、z の面も同様です。

解答

六面のいずれでも F·n = 1 なので一面あたり4、合計24です。反対側の面では場も法線も反転するため、内積は同じ正の値です。閉曲面であることだけから合計0とはいえません。

4．座標交換と指定向き

η(s,t)=(t,s,t)、0≤s,t≤1 で表す z=x の板で、F=(0,0,1) の上向き流束を求めてください。外積をそのまま使った値との違いも説明してください。

ヒント1

ηₛ=(0,1,0)、ηₜ=(1,0,1)。

ヒント2

外積は (1,0,−1) なので下向きです。

解答

外積をそのまま使う値は−1ですが、指定は上向きなので面積ベクトルを (−1,0,1)dsdt とし、流束は1です。場も面も変えていません。座標の順番による向きの反転を、指定法線に合わせて補正しました。

5．相殺する場の強さを逆算する

上向きの放物面 z=x²+y²、x²+y²≤1 に対し F=(x,y,c) とします。流束をcで表し、全体が0になるcを求めてください。そのとき各点で0になりますか。

ヒント1

内積は c−2ρ²。

ヒント2

単位円板で ∫∫ρ²dxdy=π/2 です。

解答

流束は cπ−2(π/2)=π(c−1)。したがって c=1。中心では内積1、円周では−1なので各点で0ではありません。c=0なら全体−π、c=2ならπとなり、cを増やした分だけ鉛直成分の寄与が増えます。

6．同じ投影なら同じ流束か

F=(0,0,z) とし、単位正方形の上の水平板 z=0 と z=1 をどちらも上向きに取ります。流束を比較し、「同じ投影なら同じ」という説明の不足を指摘してください。

ヒント1

どちらの面積ベクトルも (0,0,1)dxdy です。

ヒント2

場を面へ代入すると第三成分はそれぞれ0と1です。

解答

z=0の板は0、z=1の板は1です。投影も実面積も同じですが、面上での場の値が変わります。一定の鉛直場について示した相殺を、場所で変わる場へ無条件に広げたのが誤りです。

7．流束と端の高さから板を決める

F=(1,2,3)、z=ax+by、0≤x,y≤1 の上向き流束を1、点(1,0)の高さを1と指定します。a,bと板の実面積を求めてください。

ヒント1

高さ条件から a=1。流束は3−a−2bです。

ヒント2

3−1−2b=1 を解きます。

解答

a=1、b=1/2。面積は √(1+1+1/4)=3/2 です。単位法線 n=(−2/3,−1/3,2/3) に対して F·n=−2/3−2/3+2=2/3。実面積3/2と掛けると1になり、逆算を検算できます。

8．円柱の側面と全境界を区別する

半径2、高さ3の円柱0≤z≤3で F=(x,y,z) を考えます。外向き側面、上面、下面の流束を直接求めてください。

ヒント1

側面は r(θ,t)=(2cosθ,2sinθ,t)。外積 rθ×rt=(2cosθ,2sinθ,0)。

ヒント2

側面の内積は4、上面はF·n=3、下面は0。

解答

側面は ∫₀³∫₀²π4dθdt=24π。上面は3×π·2²=12π、下面は0、全境界は36πです。側面だけは閉曲面ではありません。側面表示の角度の継ぎ目は境界の有限重複として扱い、内部では一度だけ覆っています。

9．定数場の外向き流束

Ω=[−1,1]³、F=(1,0,0) とします。六面の寄与を求め、「向かい合う二面だから必ず相殺する」という説明が F=(x,y,z) にも通じるか比べてください。

ヒント1

x=1では4、x=−1では−4です。

ヒント2

F=(x,y,z)では反対面で場の成分も反転します。

解答

定数場ではxの二面が4と−4、残る四面は0なので合計0。放射場 F=(x,y,z) では六面とも F·n=1、各4で合計24です。法線が逆でも場が同じとは限らず、各面で両方を評価する必要があります。

10．面積条件の下で実現できる流束

例題3の F=(1,0,2)、単位正方形上の z=ax+by、実面積3で、上向き流束5は実現できますか。可能な最大流束と、そのときの傾きも求めてください。

ヒント1

a²+b²=8、流束2−a です。

ヒント2

最大にはaを最小にします。

解答

流束5にはa=−3が必要で、a²=9>8となるため不可能。最大は2+√8で、そのときa=−√8、b=0です。下限は2−√8。境界値でb²=0になることも確認でき、向きはすべて上向きのままです。
