密度の積分と二重積分

雨の深さは場所によって違います。地面を小さい長方形に分け、それぞれの雨量に面積を掛けて足せば、全体に降った水の量を見積もれそうです。分け方や代表点を変えても、合計は同じ値へ落ち着くでしょうか。

一変数の上下の和を、二つの軸で作る格子へ広げます。最初は閉矩形、次に三角形のような曲がった境界を持つ領域を扱い、積分の順序を替えてよい条件まで確かめます。

例題：小片の水量から、総量と平均を分ける

横2m、縦1mの長方形Q=[0,2]×[0,1]に、深さh(x,y)=(1+x+2y)mmの雨が降るという自作モデルを考えます。この式のx,yはmを単位に測った座標の数値で、xと2yの係数はそれぞれ1mm/m、2mm/mに対応します。式を作った段階で、座標と深さの単位を区別しておきます。

列ごとの積分にも、まだ幅を掛ける段階が残る

xを固定した細い縦の列で、y方向の深さを集めると ∫₀¹(1+x+2y)dy=[(1+x)y+y²]₀¹=2+x です。この段階の単位はmm·mで、水量そのものではありません。次に横幅dxを掛けて集めると ∫₀²(2+x)dx=[2x+x²/2]₀²=6、単位はmm·m²です。

1mm=1/1000mなので、総水量は6/1000m³=0.006m³=6L。面積2m²で割ると、面積平均の深さは3mmです。総量6と平均3を、単位を省いて同じ量として扱わないでください。

逆順では ∫₀²(1+x+2y)dx=[x+x²/2+2yx]₀²=4+4y、それを∫₀¹(4+4y)dy=6と積分して一致します。深さの最小は1mm、最大は5mmなので、全量は2L以上10L以下、平均3mmもその間にあり、桁と単位の検算ができます。

この例のhは一次式なので、矩形の中心(1,1/2)での深さ3mmに面積2m²を掛けても正確に6Lです。しかし曲がった分布では一般に近似になります。例えばh=x²ならQでの積分は∫₀²x²dx=8/3ですが、中心値×面積は1²·2=2です。代表点を一つ選ぶことと、分割を細かくした極限を定めることは区別します。

演習を含む学習の目安は120–170分です。矩形での定義と存在、領域と積分順序、符号・単位・積分可能性を問う演習の三回に分けて読めます。

矩形分割と二重積分の定義

[a,b]×[c,d] は、a≤x≤b と c≤y≤d を同時に満たす点 (x,y) の集まりで、長方形を表します。例えば単位正方形を縦横に二等分すると、左下の小片は [0,1/2]×[0,1/2]。横幅1/2、縦幅1/2なので面積は1/4です。関数 f(x,y) の値が雨の深さなら、長さの単位をそろえて深さにこの面積を掛けると、小片の水の体積になります。場所の値に掛けるものが一方向の幅から小片の面積へ変わることが、二重積分の出発点です。

a < b、c < d とし、Q = [a, b] × [c, d] 上の有界な f を考えます。x 軸の分割 a = x₀ < … < xₙ = b と、y 軸の分割 c = y₀ < … < yₘ = d を合わせた格子を P とします。セル Qᵢⱼ = [xᵢ₋₁, xᵢ] × [yⱼ₋₁, yⱼ] の面積は ΔAᵢⱼ = ΔxᵢΔyⱼ。その上の値の下限を mᵢⱼ、上限を Mᵢⱼ とします。実際に達成される最小値・最大値とは限りません。

上限と下限の差 Mᵢⱼ−mᵢⱼ を、その小片での振動と呼びます。値が変わり得る幅であり、後で境界を表す関数でも、短い区間での上限と下限の差を同じように使います。

添字 i は横に何番目か、j は縦に何番目かを表し、二つの番号で小片を一つ選びます。Δxᵢ=xᵢ−xᵢ₋₁、Δyⱼ=yⱼ−yⱼ₋₁ が二辺の幅です。Σi,j は全ての小片の寄与を一度ずつ足す記号で、mᵢⱼ,Mᵢⱼはそれぞれの小片の全ての値を下・上から押さえる高さです。ξᵢⱼは、その小片の中から選んだ代表の一点を表します。

L(P)=∑i,jmijΔAij,U(P)=∑i,jMijΔAij

各セルの代表点 ξᵢⱼ を選ぶ Riemann 和 S(P) = ∑f(ξᵢⱼ)ΔAᵢⱼ は、必ず L(P) ≤ S(P) ≤ U(P) を満たします。

二重積分の定義と ε 基準

すべての格子の下和の上限 α = sup L(P) と、上和の下限 β = inf U(P) が一致するとき、f は Q 上で Riemann 積分可能といい、共通の値を ∬Qf(x, y)dA と書きます。同じ条件は「任意の ε > 0 に対して U(P) − L(P) < ε となる格子 P がある」です。

二軸でも、共通細分で挟める

分割点を追加すると、セル内の下限は下がらず上限は上がらないので、下和は増え上和は減ります。二つの格子の x 分割・y 分割をそれぞれ合併すれば共通細分ができ、任意の下和は任意の上和以下です。従って α ≤ β。隙間を ε 未満にできれば 0 ≤ β − α < ε なので一致します。逆に共通値 I があれば、下和が I − ε/2 より大きい格子と、上和が I + ε/2 より小さい格子を選び、共通細分を取れば隙間は ε 未満です。

二重積分の線形性・面積・平均値

定数・線形性・単調性

定数 C の積分は C(b − a)(d − c)。積分可能な f、g と実数 α、β に対し αf + βg も積分可能で、積分は α∬f + β∬g です。f ≤ g なら ∬f ≤ ∬g。特に |f| ≤ M なら |∬Qf| ≤ M·面積(Q) です。

有限和の規則から、隙間を縮める

定数の上下和は同じ C·面積(Q) です。αf + βg の各セルでの振動は |α| と f の振動の積、|β| と g の振動の積の和以下。共通細分で両方の上下和差を小さくすれば、和も積分可能です。同じ代表点を使う有限和は線形性を満たすので、その和と積分値の差を上下和差で抑えて 0 へ縮めれば積分の線形性が出ます。f ≤ g では各セルの下限も同じ順序なので、下和の上限を取れば単調性です。最後の評価は定数 −M、M との比較です。

密度 f の積分は総量、面積で割った値は面積平均です。高さ f なら体積に、面積当たりの質量なら総質量になります。符号のある f では正負が相殺されるので、常に幾何学的体積になるわけではありません。

閉矩形上の連続関数の可積分性

連続な閉矩形上の関数は積分可能

f が閉矩形 Q 全体で連続なら、有界かつ一様連続で、二重積分可能です。境界での連続性は Q 内からの近づき方で考えます。

一変数のコンパクト性を、二成分へ使う

Q 内の点列 (xₙ, yₙ) を取ります。既証明の Bolzano–Weierstrass の定理で x 成分が [a, b] 内に収束する部分列を取り、さらにその部分列の y 成分が [c, d] 内に収束する部分列を取ります。後の選び直しで x の収束は保たれるので、点列は Q 内の点へ収束する部分列を持ちます。

f が有界でなければ |f(pₙ)| > n となる点を選べますが、収束部分列と連続性から f(pₙₖ) は有限値へ収束して矛盾します。一様連続でなければ、ある η₀ > 0 に対し ‖pₙ − qₙ‖ < 1/n なのに |f(pₙ) − f(qₙ)| ≥ η₀ となる二点列を選べます。p の収束部分列では q も同じ点へ収束し、連続性と矛盾します。

従って任意の η > 0 に対して、全 Q で使える δ > 0 があり、距離 δ 未満の二点の値の差は η 未満です。各セルの対角線長が δ 未満となる格子なら、Mᵢⱼ − mᵢⱼ ≤ η。よって U(P) − L(P) ≤ η·面積(Q)。η = ε/{2面積(Q)} を取れば ε 基準を満たします。各点ごとに異なる δ を取るだけではなく、全セルで共通にしたのが要点です。

累次積分とFubiniの定理

全ての小片を一度に足す代わりに、縦の列ごとに集められるでしょうか。xを一つ固定してy方向に積分すると、その列についての一変数の量 F(x) ができます。それを今度はx方向に積分して全体を集めるのが累次積分です。入れ子の式では、内側のdyを先に計算し、その間xは定数として扱います。

連続関数に限定した反復積分の交換

f が閉矩形 Q で連続なら、二つの反復積分が存在し、次の等式が成立します。

∬QfdA=∫ab(∫cdf(x,y)dy)dx=∫cd(∫abf(x,y)dx)dy

内側も外側も、同じ上下和で挟む

固定した x の切り口は連続なので、一変数の積分 F(x) = ∫cdf(x, y)dy が存在します。一様連続性により |x − x′| < δ なら全 y で |f(x, y) − f(x′, y)| < η。一変数積分の上界から |F(x) − F(x′)| ≤ η(d − c) なので F は連続、外側の積分も存在します。

ある x セル内の全 x について、各 y セルでは mᵢⱼ ≤ f(x, y) ≤ Mᵢⱼ。y で積分して足すと ∑ⱼmᵢⱼΔyⱼ ≤ F(x) ≤ ∑ⱼMᵢⱼΔyⱼ。さらに x セルで積分して足せば L(P) ≤ ∫abF(x)dx ≤ U(P) です。二重積分の値も同じ間にあり、隙間を任意に小さくできるので等しくなります。x、y を交換した議論で逆順も得ます。

これは有界な閉矩形上の連続関数の証明です。無限区間、特異点で発散する広義積分、一般の不連続関数へ、条件を確認せず交換の公式を持ち出してはいけません。

例えば Q = [0, 1] × [0, 2]、f = x + 2y なら、縦を先に積分すると ∫₀¹(2x + 4)dx = 5。横を先にすると ∫₀²(1/2 + 2y)dy = 5。同じ総量を二つの切り方で集めています。

例題：積分が表すのは、正負を相殺した合計か

Q=[0,2]×[0,1]上でf=x−yを積分します。雨の深さには負の値は使いませんが、基準面からの符号付きの高さや、増減量の密度なら負の値も意味を持ちます。dAは非負の面積で、負の寄与はfの側から来ます。

全体の積分と、絶対値の積分を比べる

まず全体を縦に集めると ∫₀²∫₀¹(x−y)dy dx=∫₀²(x−1/2)dx=[x²/2−x/2]₀²=1です。負の部分があるから積分が負になる、とも限りません。

負の領域は0≤x<y≤1です。固定したyに対しxは0からyまでなので、その寄与は N=∫₀¹∫₀ʸ(x−y)dx dy=∫₀¹(−y²/2)dy=−1/6。残る正の領域の寄与PはP+N=1からP=7/6です。従って∬|x−y|dA=P−N=4/3となり、符号付き合計1とは違います。

例えばy=1/2の断面では、x<1/2で負、x>1/2で正です。x=0で−1/2、x=2で3/2という値を見れば、正負の領域の位置と符号を検算できます。二重積分1を、グラフと平面の間の幾何的な体積と呼ぶには注意が要ります。その体積に対応するのは絶対値を付けた4/3です。

線形性や積分順序の交換は、負の値があるだけで壊れません。このfは閉矩形で連続で、前節の定理の条件を満たしています。一方、雨量のように非負を仮定するモデルへ使うときは、積分公式より前にfの意味を確かめる必要があります。

単純領域の積分と境界セルの誤差評価

φ、ψ が [a, b] で連続、φ ≤ ψ とし、D = {(x, y) : a ≤ x ≤ b, φ(x) ≤ y ≤ ψ(x)} とします。D を含む矩形 Q 上へ、D 内では f、外では 0 とする関数 f̃ を作り、f̃ が積分可能なら ∬Df = ∬Qf̃ と定義します。f ≡ 1 の積分が D の面積です。外側の矩形を大きくしても、追加部分は 0 なので値は変わりません。

領域Dの内側で1、外側で0となる関数を、Dの指示関数と呼びます。この指示関数を、囲む長方形上でRiemann積分できる有界な領域を、後の証明ではJordan可測と呼びます。例えば囲む長方形Q自身を領域にすれば、指示関数はQ上で常に1なので積分でき、面積は (b−a)(d−c) です。Jordan可測は新しい計算公式ではなく、この面積を積分として定められるという性質を表します。

証明はまず、Dのどんな点列からもD内の一点に収束する部分列を取れることを使います。この性質を逐次コンパクトと呼び、閉矩形上の可積分性の節でも確かめました。その後、境界に触れる小片の総面積を小さくして、外側を0にした関数の跳びの影響を抑えます。境界で不連続になることを無視して、連続関数の定理を使うわけではありません。

連続な境界に挟まれた領域の積分

f がこの閉領域 D で連続なら、0 拡張 f̃ は積分可能で、次の可変端点の公式が成立します。

∬DfdA=∫ab(∫φ(x)ψ(x)f(x,y)dy)dx

境界セルの総面積を評価する

D は有界で、D の点列が Q 内で収束すれば、φ、ψ の連続性から極限も D に入ります。従って閉矩形上の可積分性の節と同じ部分列の議論で D も逐次コンパクト、f は有界かつ一様連続です。|f| ≤ M とします。

横の最大幅を s、縦の最大幅を t とする格子を取り、a、b は x 分割点に入れます。一つの x 列内で φ の値の振動を ωφ(s)、ψ の振動を ωψ(s) 以下とできます。一様連続性により両方とも s → 0 で 0 へ近づきます。φ のグラフと接する全セルの縦の合計幅は、その列内の最大値と最小値の差に上下の余裕 2t を足したもの以下。従って二つのグラフに接するセルの総面積は (b − a){ωφ(s) + ωψ(s) + 4t} 以下です。両端の縦辺に接する列も含めるなら、Q の高さを H として 4sH 以下を加えれば足ります。

この境界セルの面積 B(P) は 0 へ近づきます。境界と接しないセルは全体が D 内か外で、外なら振動 0、内なら一様連続性で振動 η 以下。境界セルの振動は 2M 以下なので、U(P) − L(P) ≤ η·面積(Q) + 2M B(P)。先に η、次に s、t を小さくすれば任意に小さくでき、f̃ は積分可能です。境界だけで値を有界に変更しても、同じ評価で積分は変わりません。特に D の境界の面積は 0 です。このように有界集合の指示関数が積分可能なことをJordan 可測と呼びます。

各固定 x の f̃ の y 切り口は、連続な区間 [φ(x), ψ(x)] の外で 0 です。不連続になり得るのはその二端点だけで、幅の小さい区間で囲めば上下和差を小さくできるため、一変数でも積分可能です。φ = ψ の一点だけの場合も値の寄与は 0。従って内側の積分は F(x) = ∫φ(x)ψ(x)f(x, y)dy です。

F の連続性も確認します。x、x′ の縦区間の共通部分では一様連続性により二つの f の差は η 以下で、共通部分の長さは H 以下。共通でない部分の長さの合計は |φ(x) − φ(x′)| + |ψ(x) − ψ(x′)| 以下です。よって |F(x) − F(x′)| ≤ Hη + M{|φ(x) − φ(x′)| + |ψ(x) − ψ(x′)|} → 0。最後に各セルの f̃ の下限・上限で内側と外側の積分を挟む、累次積分の節と同じ議論を使えば公式が得られます。連続矩形の定理を、不連続な 0 拡張に無断で適用したのではありません。

x と y の役割を入れ替え、連続な φ、ψ（φ ≤ ψ）により c ≤ y ≤ d、φ(y) ≤ x ≤ ψ(y) と書ける領域でも、同じ証明が通ります。その積分は ∫cd(∫φ(y)ψ(y)f(x, y)dx)dy です。この二つの形の少なくとも一方で書ける領域を、この章では単純領域と呼びます。順序を替えるときは、もう一方の形でも同じ領域を表せるか確かめます。

次の二図では、三角形 D = {0 ≤ y ≤ x ≤ 1} の境界に接するセルを覆います。斜線の帯の総面積が小さくなることが、境界での跳びの影響を抑える鍵です。有限の二例から収束を結論せず、本文の B(P) の評価を使います。

積分順序の交換と積分範囲

D = {0 ≤ y ≤ x ≤ 1} は、縦に見ると 0 ≤ x ≤ 1、0 ≤ y ≤ x、横に見ると 0 ≤ y ≤ 1、y ≤ x ≤ 1 です。単に dx と dy を入れ替えるのでなく、端点も描き直します。

図の縦の切り口は下辺から斜辺へ、横の切り口は斜辺から右辺へ走ります。例えば f = x + y なら、縦からは ∫₀¹∫₀ˣ(x + y)dy dx = ∫₀¹3x²/2 dx = 1/2。横からは ∫₀¹∫ᵧ¹(x + y)dx dy = ∫₀¹(1/2 + y − 3y²/2)dy = 1/2 です。

例題：放物線と直線に挟まれた領域を、両方から切る

D={0≤x≤1、x²≤y≤x}を考えます。下の境界は放物線、上は直線です。横に切る範囲を求めるときは、元の不等式をそのままyで解きます。x≥0なのでx²≤yはx≤√y、y≤xはx≥y。従って同じ領域は0≤y≤1、y≤x≤√yと書けます。

まずf=1で範囲を確かめ、次に密度を入れる

縦から面積を計算すると ∫₀¹(x−x²)dx=1/2−1/3=1/6。横からは ∫₀¹(√y−y)dy=2/3−1/2=1/6です。yと√yを逆にすると内側の幅が負になり、領域の面積を表しません。例えばy=1/4では、動けるxは1/4から1/2までで、(1/3,1/4)はD内、(3/4,1/4)はD外です。

次にf=xを入れます。縦からは ∫₀¹x(x−x²)dx=1/3−1/4=1/12。横からは ∫₀¹[x²/2]ᵧ^√ʸdy=∫₀¹(y−y²)/2dy=1/4−1/6=1/12です。面積平均のx座標は(1/12)/(1/6)=1/2。0≤x≤1という範囲にも収まっています。

例題：積分しやすい順序を、領域から選ぶ

三角形D={0≤y≤x≤1}上でf=e^(x²)を積分します。yを固定してxから積分しようとすると、内側は∫ᵧ¹e^(x²)dxで、この章までの置換だけでは扱いにくい式が残ります。そこで関数を眺めるだけでなく、yから積分できる領域表示を使います。

内側の幅が、置換に必要な係数を作る

xを固定したとき0≤y≤xなので、fはyに依存せず、∫₀ˣe^(x²)dy=xe^(x²)。次にu=x²と置くとdu=2x dxで、∫₀¹xe^(x²)dx=(1/2)∫₀¹eᵘdu=(e−1)/2です。端点はx=0でu=0、x=1でu=1です。

1≤e^(x²)≤e、三角形の面積は1/2なので、答えは1/2以上e/2以下であるはずです。実際(e−1)/2はその間にあります。内側の幅xを落とすと∫₀¹e^(x²)dxとなり、別の領域の量を集めてしまいます。また、置換u=x²でdu=2x dxの係数1/2を落とすとe−1となります。これはe>2よりe/2を超えるため、先の見積もりでも誤りに気づけます。

順序の選択は、積分が存在するかという問いと、手元の方法で簡単に計算できるかという問いを分けます。このfはD上で連続なので積分可能です。一方の順序で原始関数をすぐ書けないことは、二重積分の不存在を意味しません。

二重積分の下和・上和・中点和の実験

単位正方形の f = x² + y² は二つの座標で増加するため、各セルの左下が下限、右上が上限です。n 等分した上下和と中点和は次の式になります。平方和の公式とその帰納法による確認を使って計算できます。

Lₙ = (n − 1)(2n − 1)/(3n²)、Uₙ = (n + 1)(2n + 1)/(3n²)、Mₙ = 2/3 − 1/(6n²)。上下の差は 2/n、両端の極限は 2/3 なので二重積分は 2/3 です。中点和も近づきますが、一般の関数について常に下側になる規則ではありません。

密度の色とセル一個の寄与 f(ξ)ΔA は別の量です。画面の有限格子は公式と照合する観察で、全ての細かさについての収束を保証するのは上の式です。

有界関数の可積分性と反例

単位正方形で x が有理数なら 1、無理数なら 0 とする関数は有界ですが、正の幅のどのセルでも下限 0、上限 1。下和は常に 0、上和は常に 1 で積分できません。これは一変数の Dirichlet 関数を縦に延ばした反例です。

一方、直線や上で扱った連続グラフの境界で有限の跳びがあっても、その周りのセルの総面積を小さくできれば積分できます。連続性は便利な十分条件ですが、必要条件ではありません。「点や線を除けばよい」も無条件の合言葉ではなく、ここでは被覆面積と有界性によって影響を抑えました。

寄り道［応用］：雨量の平均は、観測点の個数の平均とは違う

米陸軍工兵隊 HEC-HMS の技術資料は、雨量計から流域の平均雨量を推定する際に、観測された深さの重み付き平均を用いる考えを説明しています。観測点が十分な密度で分布し、適切に稼働しているかも推定の質に関わります。面積全体の平均と、数個の雨量計の単純平均は同じとは限りません。

ここからは本章の仮想計算です。流域 2 km² を、面積 0.5 km²、雨の深さ 10 mm の部分と、面積 1.5 km²、深さ 30 mm の部分に分けます。総水量は 0.010 m × 500,000 m² + 0.030 m × 1,500,000 m² = 50,000 m³。面積平均の深さは 50,000/2,000,000 m = 25 mm です。二つの深さの単純平均 20 mm は、面積の違いを無視しています。

連続モデルで深さを h(x, y) とすれば、総量は ∬h dA、平均はそれを流域面積で割った値です。ただし未知の降雨分布を数点から正確に再現できるとは限らず、観測からの推定と、与えられた関数の積分計算は分けて考えます。

二重積分の領域・単位・誤差の演習

1–3で両順の計算と誤差、4–7で単位・符号・曲がった領域・順序の選択、8–10で積分可能性・密度の逆算・領域分割を練習します。範囲を先に書き、端点を代入してから計算してください。

1．二つの順序と面積平均

f = x + 2y を [0, 1] × [0, 2] で両方の順序により積分し、面積と面積平均も求めてください。

ヒント1：先に積分しない変数は定数

y を先にすると内側は 2x + 4 です。

ヒント2：総量を面積で割る

矩形の面積は二辺の長さの積です。

解答

f は閉矩形で連続なので反復積分を使えます。∫₀¹∫₀²(x + 2y)dy dx = ∫₀¹(2x + 4)dx = [x² + 4x]₀¹ = 5。逆順は ∫₀²∫₀¹(x + 2y)dx dy = ∫₀²(1/2 + 2y)dy = [y/2 + y²]₀² = 5。面積は 1×2 = 2、面積平均は 5/2 です。総量 5 と平均 5/2 は異なります。

2．同じ三角形を横から見る

0 ≤ y ≤ x ≤ 1 上の x + y の積分を両順で計算し、逆順の上下端を説明してください。

ヒント1：固定した y で動ける x

y ≤ x ≤ 1、y 全体は 0 ≤ y ≤ 1 です。

ヒント2：内側の原始関数

y なら xy + y²/2、x なら x²/2 + yx です。

解答

縦先は ∫₀¹[xy + y²/2]ᵧ₌₀ᵧ₌ₓ dx = ∫₀¹3x²/2 dx = 1/2。横先では同じ三角形を 0 ≤ y ≤ 1、y ≤ x ≤ 1 と表すので、∫₀¹[x²/2 + yx]ₓ₌ᵧₓ₌₁ dy = ∫₀¹(1/2 + y − 3y²/2)dy = 1/2 + 1/2 − 1/2 = 1/2。上下端を変えずに積分記号だけ入れ替えると別の領域になります。

3．n 等分の保証を作る

単位正方形の x² + y² について n 等分の下和・上和・中点和・真値を求め、n = 2 の値と、上下和差を 0.1 以下にする等分数を示してください。

ヒント1：二つの平方の和を分ける

下和は (2/n³)∑ᵢ₌₀ⁿ⁻¹i²、上和は (2/n³)∑ᵢ₌₁ⁿi² です。

ヒント2：中点も平方和へ展開

Mₙ = (2/n³)∑ᵢ₌₀ⁿ⁻¹(i + 1/2)²。上下和を引くと 2/n です。

解答

平方和から Lₙ = (n − 1)(2n − 1)/(3n²)、Uₙ = (n + 1)(2n + 1)/(3n²)。中点では ∑(i + 1/2)² = ∑i² + ∑i + n/4 = n(4n² − 1)/12 なので、Mₙ = 2/3 − 1/(6n²)。上下和の極限が 2/3 で一致するため真値は 2/3。n = 2 では L₂ = 1/4、U₂ = 5/4、M₂ = 5/8。Uₙ − Lₙ = 2/n ≤ 0.1 は n ≥ 20 と同値です。これは真値を挟む区間の幅の保証です。

4．深さを水量へ直す

3m×2mの矩形で、x方向をmで測り雨の深さをh=(2+x)mmとする自作モデルです。総水量をm³とLで、平均の深さをmmで求めてください。xの係数の単位も答えてください。

ヒント1

最初の積分値の単位はmm·m²です。

ヒント2

yの幅は2m。1mm=0.001m、1m³=1000Lです。

解答

∫₀³∫₀²(2+x)dy dx=∫₀³(4+2x)dx=[4x+x²]₀³=21mm·m²。総量は0.021m³=21L、面積6m²で割った平均の深さは3.5mmです。xの係数は1mm/mに対応します。

深さは2mmから5mmなので平均3.5mmはその間にあります。中心x=1.5での深さも3.5mmで、この一次式では平均と一致します。

5．符号付き合計と幾何的な体積

Q=[0,2]×[0,1]上でf=x−yについて、∬f、負の部分の寄与、∬|f|を求めてください。

ヒント1

負の部分は0≤x<y≤1です。

ヒント2

全体の合計が分かれば、正の寄与は引き算で出せます。

解答

全体は∫₀²(x−1/2)dx=1。負の寄与N=∫₀¹∫₀ʸ(x−y)dx dy=−1/6です。正の寄与PはP+N=1より7/6、絶対値の積分はP−N=4/3です。

∬f=1は相殺した値で、グラフと平面の間の幾何的な体積に対応するのは4/3です。|∬f|=1≤4/3=∬|f|という不等式とも整合します。

6．曲がった領域の面積と平均座標

D={0≤x≤1、x²≤y≤x}を横に切る範囲を書き、面積と∬x dAを両順で求め、面積平均のx座標を答えてください。

ヒント1

固定したyでx²≤yとy≤xを同時に解きます。

ヒント2

xは非負なのでx²≤yからx≤√yです。

解答

横の表示は0≤y≤1、y≤x≤√y。面積は縦で∫₀¹(x−x²)dx=1/6、横で∫₀¹(√y−y)dy=1/6です。∬xは縦で∫₀¹(x²−x³)dx=1/12、横で∫₀¹(y−y²)/2dy=1/12。

平均座標は(1/12)/(1/6)=1/2です。y=1/4なら1/4≤x≤1/2となることでも、上下端の向きを検算できます。

7．順序を変えて計算を閉じる

I=∫₀¹∫ᵧ¹e^(x²)dx dyを、先に積分する変数を選び直して計算してください。領域の三つの頂点も答えてください。

ヒント1

0≤y≤1、y≤x≤1を、xを固定する形へ書きます。

ヒント2

内側をyで積分すると、残るxがu=x²の置換に役立ちます。

解答

領域は0≤y≤x≤1で、頂点は(0,0)、(1,0)、(1,1)。従ってI=∫₀¹∫₀ˣe^(x²)dy dx=∫₀¹xe^(x²)dx=(1/2)[eᵘ]₀¹=(e−1)/2です。

fはこの閉単純領域で連続なので、両表示で同じ積分を表せます。1≤f≤eと面積1/2から1/2≤I≤e/2になり、答えもこの範囲です。

8．境界の跳びと、どのセルにも残る振動

単位正方形でh=1（y≤x）、h=3（y>x）とします。hを積分し、対角線上だけ任意の有界な値へ変更しても同じ理由を説明してください。xが有理数のとき1、無理数のとき0という関数と何が違いますか。

ヒント1

三角形二つの面積は各1/2です。

ヒント2

対角線の周りの細い帯と、正の幅の全セルでの振動を比較します。

解答

∬h=1·1/2+3·1/2=2です。対角線上の変更幅がC以下なら、そこを覆う境界セルの総面積B(P)を0へ縮めると積分差の絶対値もCB(P)以下で0になります。変更が有界であることを使いました。

有理/無理の関数では、正の幅のどのセルにも両方のxがあり、振動1が全面積1に残ります。常に下和0、上和1で、狭い境界帯へ振動を閉じ込められません。

9．総量と重心から密度を逆算する

単位正方形上の密度ρ=a+bxを考えます。総量∬ρ=2、密度で重み付けした平均x座標(∬xρ)/(∬ρ)=7/12となるa,bを求め、密度の非負性も確認してください。

ヒント1

平均の式から∬xρ=7/6です。

ヒント2

総量a+b/2=2、xの重み付き総量a/2+b/3=7/6を連立します。

解答

a+b/2=2、a/2+b/3=7/6。前者の半分を後者から引くとb/12=1/6よりb=2、a=1です。従ってρ=1+2x≥1で非負です。

総量は1+2/2=2、重み付き量は1/2+2/3=7/6、割ると7/12です。密度は右ほど大きいため、平均座標が一様密度の1/2より右へ寄ることとも一致します。

10．一つの表示で書きにくい領域を分ける

D=([0,1]×[0,2])∪([1,2]×[0,1])でf=x+yを積分し、面積平均も求めてください。Dを[0,2]²と取り違えた値と比較してください。

ヒント1

二つの矩形は境界の線分しか重ならないので、それぞれ積分して足せます。

ヒント2

全正方形から[1,2]×[1,2]を引く方法でも確かめられます。

解答

左の矩形では∫₀¹∫₀²(x+y)dy dx=∫₀¹(2x+2)dx=3。右下では∫₁²∫₀¹(x+y)dy dx=∫₁²(x+1/2)dx=2。合計5、面積は2+1=3なので平均5/3です。境界線の重なりの面積は0です。

全正方形なら積分8で、除く右上の単位正方形の積分は3。8−3=5と一致します。積分順序の変更では、領域の形によって区間分けが必要になることもあります。
