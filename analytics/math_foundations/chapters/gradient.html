方向微分と勾配の関係

地形の高さを f(x, y) とすると、偏微分は東西・南北という二つの切り口の傾きでした。では斜めに歩いたら、どれだけ上るのでしょうか。最も急に上る向きも選べるでしょうか。全微分の一次近似が、この問いを一つの内積へまとめます。

ただし、斜めの切り口ごとの微分が全部存在することと、全方向に共通する線形近似があることは別です。この章では、その差も確かめます。

単位方向による方向微分の定義

開集合 U ⊂ ℝ² の点 p と、長さ ‖u‖ = 1 のベクトル u = (u₁, u₂) を取ります。開性により、小さい正負の t で p + tu は U に入ります。

方向微分の定義

次の有限の両側極限が存在するとき、u 方向の方向微分と呼びます。

Duf(p)=limt→0f(p+tu)−f(p)t

t は向きの符号を含む距離で、商は t ≠ 0 で考えます。非単位の v に対して同じ商を定義することもできますが、それはパラメータ t 当たりの変化率です。例えば 2u は同じ向きでも移動速度が二倍なので、存在する微分も二倍になります。方向同士の急さを比べるには長さを 1 にそろえます。境界の片側微分は、ここでの両側の定義には含めません。

二つの偏微分が存在すれば、その値を並べた勾配 ∇f(p) = (fₓ(p), fᵧ(p)) を定義できます。勾配というベクトルの存在だけで、任意方向の微分との公式まで保証されるわけではありません。

全微分可能性と勾配の内積表示

a · b = a₁b₁ + a₂b₂ を二成分の内積と書きます。

全微分可能性から方向微分へ

f が開集合の点 p で全微分可能なら、すべての単位方向 u の方向微分が存在し、Dᵤf(p) = ∇f(p) · u です。

全微分の余りに、直線を代入する

全微分の係数から、f(p + v) = f(p) + ∇f(p) · v + R(v)、|R(v)|/‖v‖ → 0 です。v = tu を代入し、t ≠ 0 で割ると、差の商は ∇f(p) · u + R(tu)/t。‖tu‖ = |t| なので、後項の絶対値は |R(tu)|/‖tu‖ → 0 です。従って公式が成立します。

例えば P(x, y) = x² + xy + y² は全微分可能と確認済みで、∇P(a, b) = (2a + b, a + 2b) です。(1, 0) から u = (3/5, 4/5) へ進む方向微分は (2, 1) · u = 2。有限距離 t の変化が必ず 2t ちょうど、という意味ではありません。

Cauchy–Schwarz不等式と最急方向

二成分の Cauchy–Schwarz 不等式

|a · b| ≤ ‖a‖‖b‖。両ベクトルが非零なら等号は平行な場合に限り、同じ向きなら内積は正、反対向きなら負です。

差を一つの平方にする

距離の章の恒等式 ‖a‖²‖b‖² − (a · b)² = (a₁b₂ − a₂b₁)² ≥ 0 から、非負の平方根を取れば不等式です。等号は a₁b₂ = a₂b₁ のとき。a₁ ≠ 0 なら b = (b₁/a₁)a、a₁ = 0 なら a₂ ≠ 0 なので b₁ = 0 となり、やはり b は a の実数倍です。内積の符号はその倍率の符号で決まります。零ベクトルの場合は両辺 0 です。

勾配による最急方向

f が p で全微分可能で、q = ∇f(p) ≠ 0 なら、単位方向の最大変化率は ‖q‖、その方向は q/‖q‖。最小変化率は −‖q‖、その方向は −q/‖q‖ です。q = 0 なら全方向の一次変化率は 0 で、最急方向は一つに決まりません。

上限と、それを達成する方向を分けて確かめる

‖u‖ = 1 に対し −‖q‖ ≤ q · u ≤ ‖q‖。実際に u = ±q/‖q‖ を入れれば両端の値を達成します。等号条件から、非零の q では最大・最小の単位方向もそれぞれ一つです。q = 0 の場合は割り算せず、q · u = 0 を使います。

方位盤は基準点 p での方向ベクトルの図です。角度は数学の慣習どおり x の正方向から反時計回りに測ります。角度ごとの曲線を有限個描くことと、すべての方向に対する不等式の証明は区別してください。

曲線に沿う微分と等高線の接線

曲線に沿う連鎖律

開区間上の曲線 γ が t₀ で微分可能、γ(t₀) = p、f が p の開近傍で定義され p で全微分可能なら、(f ∘ γ)′(t₀) = ∇f(p) · γ′(t₀) です。曲線の微分は二つの成分をそれぞれ微分したベクトルです。

速度が 0 の場合も、余りの評価で含める

s → 0 で γ(t₀ + s) = p + sγ′(t₀) + e(s)、‖e(s)‖/|s| → 0 です。w = γ(t₀ + s) − p と置けば、十分小さい s で ‖w‖ ≤ K|s|（K = ‖γ′(t₀)‖ + 1）。曲線の連続性と定義域の開性により合成も近くで定義できます。

全微分の式に代入すると、差は s∇f(p) · γ′(t₀) + ∇f(p) · e(s) + R(w) です。内積の不等式から第二項を |s| で割った絶対値は 0 へ近づきます。任意の η > 0 に対し小さい w で |R(w)| ≤ η‖w‖、w = 0 でも R(0) = 0 なので、第三項は |s| で割って ηK 以下。η を小さくできるから極限は 0 です。γ′ や w で割らないので、速度が 0 でも成立します。

γ 上で f が一定なら、左辺は 0、従って ∇f(p) · γ′(t₀) = 0。速度も勾配も非零なら、接線と勾配は直交します。例えば f = x² + y²、γ(t) = (cos t, sin t) では (2cos t, 2sin t) · (−sin t, cos t) = 0 です。ここで証明したのは与えられた曲線に関する主張で、一般の等高線が滑らかな曲線になる存在定理はまだ使っていません。

方向微分と全微分可能性の反例

全微分できない例 G をもう一度使います。G(x, y) = x²y/(x² + y²)（原点以外）、G(0, 0) = 0 です。v = (a, b) ≠ 0 なら t ≠ 0 で G(ta, tb)/t = a²b/(a² + b²)。従ってすべての方向で両側極限が存在します。単位 u なら DᵤG(0) = u₁²u₂ です。

軸方向の二つの偏微分は 0 なので、勾配は (0, 0) と定義できます。しかし u = (1, 1)/√2 では方向微分は 1/(2√2) ≠ 0。勾配との内積には一致しません。全微分があれば先の定理に矛盾するため、全微分はありません。「各方向で別々に極限を取れる」と「一つの線形写像で全方向を近似できる」の差です。

全微分可能な関数でも、方向微分が 0 なら値一定、とはいえません。P の p = (1, 1)、u = (1, −1)/√2 では ∇P · u = 0 ですが、P(p + tu) = 3 + t²/2 です。消えたのは一次の変化だけで、二次の変化は残ります。次章でその先を調べます。

寄り道［応用］：地図の斜面は、上りと下りで向きが逆

GIS の slope は斜面の急さ、aspect は下り斜面の向きを表します。Esri の公式資料は、標高の近隣セルとの差から求めるため解像度の影響を受けること、aspect は格子の北を 0°、東を 90° とする時計回りの角度であることを説明しています。地形の条件を組み合わせた場所選びに使われます。

ここからは本章の仮想モデルです。東を x、北を y とし、水平距離も標高も m で測って z = 0.02x + 0.01y と置きます。最も上る単位方向は (2, 1)/√5、下る方向は (−2, −1)/√5。水平 1 m 当たりの最大上昇量は √5/100 m、傾斜角は arctan(√5/100) です。下りの aspect は南西寄りで、北から時計回りに約 243.4°。数学の角度と始点・回転方向が違います。

単位をそろえず標高だけを cm にすれば数値の傾きが変わります。また離散データからの推定値を、未知の地形の厳密な微分と同一視はできません。勾配 0 の平地には、この一次モデルでは一つの下り方位を選べません。

出典：Esri：Slope and aspect（定義・単位・格子方位・解像度）。平面モデルと数値は本章で設定・計算しました。

方向微分・勾配・適用条件の演習

1．最も増減する方向を探す

P = x² + xy + y² の p = (1, 0) で、u = (3/5, 4/5) の方向微分、最も増加・減少する単位方向と変化率を求めてください。

ヒント1：まず二つの偏微分

∇P = (2x + y, x + 2y) です。

ヒント2：長さを 1 にそろえる

方向微分は勾配との内積、最大・最小は勾配の長さとその負です。

解答

P は多項式で C¹、従って全微分可能です。p では ∇P = (2, 1)、‖u‖ = 1。DᵤP = 2·3/5 + 1·4/5 = 2 です。勾配の長さは √5 なので、最大変化率 √5 は (2, 1)/√5 方向で、最小変化率 −√5 は −(2, 1)/√5 方向で達成します。元の u は最急方向ではありません。

2．方向微分が全部ある G

上の G の原点で、非零 v = (a, b) に沿う方向微分を計算し、全微分可能か判定してください。

ヒント1：t ≠ 0 で約分する

G(ta, tb) の分子は t³a²b、分母は t²(a² + b²) です。

ヒント2：軸と斜めを比べる

全微分があれば、軸方向の値が線形写像の二つの係数を決めます。

解答

差の商は a²b/(a² + b²) で t によらないため、全ての非零 v で存在します。単位 u なら u₁²u₂。軸では両方 0 なので、もし全微分があれば D G(0) は零写像です。しかし u = (1, 1)/√2 では 1/(2√2) となり、全微分から得られる内積の公式と矛盾します。従って全微分できません。非単位 v の値はパラメータ当たりの変化率です。

3．一次の変化が 0 なら値は一定か

P の p = (1, 1)、u = (1, −1)/√2 で方向微分を求め、直線 p + tu 上で P が一定か調べてください。

ヒント1：勾配との内積

∇P(p) = (3, 3) です。

ヒント2：近似でなく、展開する

x = 1 + t/√2、y = 1 − t/√2 を P に代入します。

解答

DᵤP = (3, 3) · (1, −1)/√2 = 0。一方、x² + y² = 2 + t²、xy = 1 − t²/2 なので P(p + tu) = 3 + t²/2 です。t ≠ 0 では基準値 3 より大きく、一定ではありません。差を t で割った t/2 は 0 に近づくため、方向微分 0 とも矛盾しません。

自分の言葉で

  1. 方向の長さを 1 にそろえるのはなぜですか。非単位ベクトルなら何を測っていますか。
  2. 勾配はいつ定義でき、方向微分を内積で表すには何を追加で仮定しましたか。
  3. 勾配 0、または接線との内積 0 から、有限距離の変化や極値についてどこまで結論できますか。
