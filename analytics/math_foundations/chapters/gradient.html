方向微分と勾配の関係

地形の高さを f(x, y) とすると、偏微分は東西・南北という二つの切り口の傾きでした。では斜めに歩いたら、どれだけ上るのでしょうか。最も急に上る向きも選べるでしょうか。全微分の一次近似が、この問いを一つの内積へまとめます。

ただし、斜めの切り口ごとの微分が全部存在することと、全方向に共通する線形近似があることは別です。この章では、その差も確かめます。

演習込みの目安は120–180分です。まず歩く距離と速さを分けて方向微分を定め、次に全微分からの内積表示と最急方向、最後に等高線・零勾配・適用条件を調べます。演習4–10では測定値からの逆算、向きの設計、有限歩幅の点検も行います。

単位方向による方向微分の定義

開集合 U ⊂ ℝ² の点 p と、長さ ‖u‖ = 1 のベクトル u = (u₁, u₂) を取ります。開性により、小さい正負の t で p + tu は U に入ります。

方向微分の定義

次の有限の両側極限が存在するとき、u 方向の方向微分と呼びます。

Duf(p)=limt→0f(p+tu)−f(p)t

t は向きの符号を含む距離で、商は t ≠ 0 で考えます。非単位の v に対して同じ商を定義することもできますが、それはパラメータ t 当たりの変化率です。例えば 2u は同じ向きでも移動速度が二倍なので、存在する微分も二倍になります。方向同士の急さを比べるには長さを 1 にそろえます。境界の片側微分は、ここでの両側の定義には含めません。

二つの偏微分が存在すれば、その値を並べた勾配 ∇f(p) = (fₓ(p), fᵧ(p)) を定義できます。勾配というベクトルの存在だけで、任意方向の微分との公式まで保証されるわけではありません。

例題：同じ道を速く歩くと、何が増えるか

p=(1,0)から v=(3,4) に沿う点 p+sv=(1+3s,4s) は、パラメータsが0から少し動く間に距離5|s|だけ移動します。単位方向u=v/5=(3/5,4/5)で書けば同じ点はp+tu、t=5sです。前者の微分はs当たり、後者の微分は符号を付けた距離t当たりになります。

P=x²+xy+y²をこの道へ代入すると P(1+3s,4s)=1+10s+37s²。非零sでの差の商は10+37s→10です。単位方向では P(p+tu)=1+2t+(37/25)t²なので、方向微分は2。数値10が大きいのは速さ5が含まれたためで、同じ向きの急さが変わったのではありません。

例えばs=0.02とt=0.1は同じ移動で、どちらでも値は1.2148です。v=0なら道は一定でパラメータ当たりの微分は0ですが、長さが0なのでv/‖v‖という単位方向は定められません。最急方向を比べる候補から零ベクトルを除く理由です。

全微分可能性と勾配の内積表示

a · b = a₁b₁ + a₂b₂ を二成分の内積と書きます。

全微分可能性から方向微分へ

f が開集合の点 p で全微分可能なら、すべての単位方向 u の方向微分が存在し、Dᵤf(p) = ∇f(p) · u です。

全微分の余りに、直線を代入する

全微分の係数から、f(p + v) = f(p) + ∇f(p) · v + R(v)、|R(v)|/‖v‖ → 0 です。v = tu を代入し、t ≠ 0 で割ると、差の商は ∇f(p) · u + R(tu)/t。‖tu‖ = |t| なので、後項の絶対値は |R(tu)|/‖tu‖ → 0 です。従って公式が成立します。

例えば P(x, y) = x² + xy + y² は全微分可能と確認済みで、∇P(a, b) = (2a + b, a + 2b) です。(1, 0) から u = (3/5, 4/5) へ進む方向微分は (2, 1) · u = 2。有限距離 t の変化が必ず 2t ちょうど、という意味ではありません。

例題：内積が予測する一次変化を、正確な展開と比べる

同じP、p=(1,0)、u=(3/5,4/5)で、勾配は(2,1)。内積2を求めた後に、先ほどの正確な展開 1+2t+(37/25)t² と照合します。正の距離t=0.1なら変化は0.2148、一次予測0.2との差0.0148。t=−0.1なら変化は−0.1852、一次予測−0.2との差はやはり0.0148です。

差の商は2+(37/25)tなので、正側からは2より上、負側からは2より下を通って同じ2へ近づきます。有限の平均変化率は2.148または1.852であり、方向微分そのものではありません。微小な歩幅で直線近似が使えることと、有限距離でも一次式が正確なことを区別します。

Cauchy–Schwarz不等式と最急方向

二成分の Cauchy–Schwarz 不等式

|a · b| ≤ ‖a‖‖b‖。両ベクトルが非零なら等号は平行な場合に限り、同じ向きなら内積は正、反対向きなら負です。

差を一つの平方にする

距離の章の恒等式 ‖a‖²‖b‖² − (a · b)² = (a₁b₂ − a₂b₁)² ≥ 0 から、非負の平方根を取れば不等式です。等号は a₁b₂ = a₂b₁ のとき。a₁ ≠ 0 なら b = (b₁/a₁)a、a₁ = 0 なら a₂ ≠ 0 なので b₁ = 0 となり、やはり b は a の実数倍です。内積の符号はその倍率の符号で決まります。零ベクトルの場合は両辺 0 です。

勾配による最急方向

f が p で全微分可能で、q = ∇f(p) ≠ 0 なら、単位方向の最大変化率は ‖q‖、その方向は q/‖q‖。最小変化率は −‖q‖、その方向は −q/‖q‖ です。q = 0 なら全方向の一次変化率は 0 で、最急方向は一つに決まりません。

上限と、それを達成する方向を分けて確かめる

‖u‖ = 1 に対し −‖q‖ ≤ q · u ≤ ‖q‖。実際に u = ±q/‖q‖ を入れれば両端の値を達成します。等号条件から、非零の q では最大・最小の単位方向もそれぞれ一つです。q = 0 の場合は割り算せず、q · u = 0 を使います。

方位盤は基準点 p での方向ベクトルの図です。角度は数学の慣習どおり x の正方向から反時計回りに測ります。角度ごとの曲線を有限個描くことと、すべての方向に対する不等式の証明は区別してください。

例題：横か縦かだけでは、最大の上りを選べない

水平座標x,yと標高zをすべてmで測る、自作の理想化した平面 z=100+0.03x+0.04y を考えます。横へ1m進むと0.03m、縦へ1m進むと0.04m上がります。偏微分の大きい方だけを選んで縦へ進むと、最大の上りになるでしょうか。

単位方向(3/5,4/5)なら上昇率は 0.03(3/5)+0.04(4/5)=0.018+0.032=0.05。縦の0.04より大きくなりました。勾配の長さは√(0.03²+0.04²)=0.05で、勾配をこの長さで割ると(3/5,4/5)。上の不等式はほかのどの単位方向も0.05を超えないこと、代入はこの向きで実際に0.05になることを、それぞれ保証します。

これは水平1m当たり標高0.05mという比です。勾配の向きは単位方向、勾配の長さは最大変化率と、二つの役割があります。モデルが一次式なのでこの例では有限の移動にも正確ですが、曲がった地形では近似の余りを調べる必要があります。

今度はPの同じ基準点で、距離0.1の六つの歩き方を比べます。方向微分が0の行でも値が変わること、最急の上りと下りでも余りが残ることを表から読んでください。

Pは無単位の関数です。すべての行で同じ基準点・同じユークリッド距離0.1を用い、値の変化を比較します。有限六方向の表だけで最大性を証明したのではなく、全単位方向へのCauchy–Schwarz不等式と等号達成が根拠です。

条件を変える：下る向きでも、一歩が大きすぎたら

全微分可能でq=∇f(p)≠0なら、u=−q/‖q‖方向に正の小さいtだけ進むと、変化は −‖q‖t+R(tu) です。余りの比が0へ近づくので、十分小さくすれば |R(tu)|≤‖q‖t/2。したがって変化は −‖q‖t/2 以下で、確かに下がります。これが微小な最急方向を、実際の小さい一歩へ結び付ける理由です。

Pのp=(1,0)では u=−(2,1)/√5。正確な変化は −√5t+(7/5)t² なので、下がるのは 0<t<5√5/7、境界t=5√5/7で変化0です。例えばt=2では −2√5+28/5≈1.1279>0 と、むしろ上がります。方向だけを決めても、任意の歩幅で減少する保証にはなりません。

曲線に沿う微分と等高線の接線

同じ高さ c を取る点の集合 f(x,y)=c を等高線と呼びます。例えば f=x²+y²、c=1 なら単位円です。そこを曲線 γ(t) でたどれるなら、tを動かしても高さ f(γ(t)) は一定です。その微分が0になることを、勾配と歩く速度の関係へ読み替えましょう。ここでは曲線が与えられた場合を調べ、どの等高線も滑らかな曲線になるとは仮定しません。

曲線に沿う連鎖律

開区間上の曲線 γ が t₀ で微分可能、γ(t₀) = p、f が p の開近傍で定義され p で全微分可能なら、(f ∘ γ)′(t₀) = ∇f(p) · γ′(t₀) です。曲線の微分は二つの成分をそれぞれ微分したベクトルです。

速度が 0 の場合も、余りの評価で含める

s → 0 で γ(t₀ + s) = p + sγ′(t₀) + e(s)、‖e(s)‖/|s| → 0 です。w = γ(t₀ + s) − p と置けば、十分小さい s で ‖w‖ ≤ K|s|（K = ‖γ′(t₀)‖ + 1）。曲線の連続性と定義域の開性により合成も近くで定義できます。

全微分の式に代入すると、差は s∇f(p) · γ′(t₀) + ∇f(p) · e(s) + R(w) です。内積の不等式から第二項を |s| で割った絶対値は 0 へ近づきます。任意の η > 0 に対し小さい w で |R(w)| ≤ η‖w‖、w = 0 でも R(0) = 0 なので、第三項は |s| で割って ηK 以下。η を小さくできるから極限は 0 です。γ′ や w で割らないので、速度が 0 でも成立します。

γ 上で f が一定なら、左辺は 0、従って ∇f(p) · γ′(t₀) = 0。速度も勾配も非零なら、接線と勾配は直交します。例えば f = x² + y²、γ(t) = (cos t, sin t) では (2cos t, 2sin t) · (−sin t, cos t) = 0 です。ここで証明したのは与えられた曲線に関する主張で、一般の等高線が滑らかな曲線になる存在定理はまだ使っていません。

速度が0の歩き方では、接線の向きを取り出せない

f(x,y)=x、γ(t)=(t²,0)、t₀=0 とします。p=(0,0)、勾配は(1,0)ですが、γ′(0)=(0,0)。合成はf(γ(t))=t²なので、t=0での微分は0であり、内積(1,0)·(0,0)=0と一致します。

それでもγに沿って値が一定なわけではなく、t≠0ならt²>0です。また速度0は長さ1へ直せないので、この内積0から「接線の方向が勾配に垂直」とは結論しません。非零の速度と勾配という条件は、直交する二つの向きを読み取るために必要です。

方向微分と全微分可能性の反例

全微分できない例 G をもう一度使います。G(x, y) = x²y/(x² + y²)（原点以外）、G(0, 0) = 0 です。v = (a, b) ≠ 0 なら t ≠ 0 で G(ta, tb)/t = a²b/(a² + b²)。従ってすべての方向で両側極限が存在します。単位 u なら DᵤG(0) = u₁²u₂ です。

軸方向の二つの偏微分は 0 なので、勾配は (0, 0) と定義できます。しかし u = (1, 1)/√2 では方向微分は 1/(2√2) ≠ 0。勾配との内積には一致しません。全微分があれば先の定理に矛盾するため、全微分はありません。「各方向で別々に極限を取れる」と「一つの線形写像で全方向を近似できる」の差です。

全微分可能な関数でも、方向微分が 0 なら値一定、とはいえません。P の p = (1, 1)、u = (1, −1)/√2 では ∇P · u = 0 ですが、P(p + tu) = 3 + t²/2 です。消えたのは一次の変化だけで、二次の変化は残ります。次章でその先を調べます。

零勾配で分かるのは、一次の変化まで

f₁=x²+y²、f₂=−x²−y²、f₃=x²−y² はいずれも多項式で、原点の勾配は(0,0)。したがってすべての単位方向の一次変化率は0です。それでも原点以外では f₁>0、f₂<0。f₃は横軸上で正、縦軸上で負です。

例えば距離0.1の点(0.1,0)、(0,0.1)で、f₁はどちらも0.01、f₂はどちらも−0.01、f₃は0.01と−0.01になります。零勾配だけでは、近くの値が上側にあるか、下側にあるか、方向で変わるかを決められません。次章で、一次の後に残る二次の変化を整理します。

寄り道［応用］：地図の斜面は、上りと下りで向きが逆

GIS の slope は斜面の急さ、aspect は下り斜面の向きを表します。Esri の公式資料は、標高の近隣セルとの差から求めるため解像度の影響を受けること、aspect は格子の北を 0°、東を 90° とする時計回りの角度であることを説明しています。地形の条件を組み合わせた場所選びに使われます。

ここからは本章の仮想モデルです。東を x、北を y とし、水平距離も標高も m で測って z = 0.02x + 0.01y と置きます。最も上る単位方向は (2, 1)/√5、下る方向は (−2, −1)/√5。水平 1 m 当たりの最大上昇量は √5/100 m、傾斜角は arctan(√5/100) です。下りの aspect は南西寄りで、北から時計回りに約 243.4°。数学の角度と始点・回転方向が違います。

単位をそろえず標高だけを cm にすれば数値の傾きが変わります。また離散データからの推定値を、未知の地形の厳密な微分と同一視はできません。勾配 0 の平地には、この一次モデルでは一つの下り方位を選べません。

出典：Esri：Slope and aspect（定義・単位・格子方位・解像度）。平面モデルと数値は本章で設定・計算しました。

方向微分・勾配・適用条件の演習

1．最も増減する方向を探す

P = x² + xy + y² の p = (1, 0) で、u = (3/5, 4/5) の方向微分、最も増加・減少する単位方向と変化率を求めてください。

ヒント1：まず二つの偏微分

∇P = (2x + y, x + 2y) です。

ヒント2：長さを 1 にそろえる

方向微分は勾配との内積、最大・最小は勾配の長さとその負です。

解答

P は多項式で C¹、従って全微分可能です。p では ∇P = (2, 1)、‖u‖ = 1。DᵤP = 2·3/5 + 1·4/5 = 2 です。勾配の長さは √5 なので、最大変化率 √5 は (2, 1)/√5 方向で、最小変化率 −√5 は −(2, 1)/√5 方向で達成します。元の u は最急方向ではありません。

2．方向微分が全部ある G

上の G の原点で、非零 v = (a, b) に沿う方向微分を計算し、全微分可能か判定してください。

ヒント1：t ≠ 0 で約分する

G(ta, tb) の分子は t³a²b、分母は t²(a² + b²) です。

ヒント2：軸と斜めを比べる

全微分があれば、軸方向の値が線形写像の二つの係数を決めます。

解答

差の商は a²b/(a² + b²) で t によらないため、全ての非零 v で存在します。単位 u なら u₁²u₂。軸では両方 0 なので、もし全微分があれば D G(0) は零写像です。しかし u = (1, 1)/√2 では 1/(2√2) となり、全微分から得られる内積の公式と矛盾します。従って全微分できません。非単位 v の値はパラメータ当たりの変化率です。

3．一次の変化が 0 なら値は一定か

P の p = (1, 1)、u = (1, −1)/√2 で方向微分を求め、直線 p + tu 上で P が一定か調べてください。

ヒント1：勾配との内積

∇P(p) = (3, 3) です。

ヒント2：近似でなく、展開する

x = 1 + t/√2、y = 1 − t/√2 を P に代入します。

解答

DᵤP = (3, 3) · (1, −1)/√2 = 0。一方、x² + y² = 2 + t²、xy = 1 − t²/2 なので P(p + tu) = 3 + t²/2 です。t ≠ 0 では基準値 3 より大きく、一定ではありません。差を t で割った t/2 は 0 に近づくため、方向微分 0 とも矛盾しません。

4–10では長さ1への正規化、全微分可能性、有限歩幅という三つの条件を、計算を始める前に点検してください。

4．速さの違う二つの歩き方を公平に比べる

f(x,y)=3x+4y の同じ基準点から、v₁=(0,10)、v₂=(3,4) に沿ってパラメータtで進みます。それぞれのt当たりの変化率と距離当たりの変化率を求め、どちらが急か判定してください。

ヒント1

fは一次式なので、代入で正確に計算できます。

ヒント2

長さは10と5。単位方向は(0,1)と(3/5,4/5)です。

解答

t当たりの変化率はv₁で40、v₂で25。一方、距離当たりでは40/10=4、25/5=5です。したがって急なのはv₂の向きで、実際に勾配(3,4)の単位方向に一致します。例えばt=0.1なら前者は距離1で変化4、後者は距離0.5で変化2.5。移動距離をそろえずに出力だけ比べると、結論を逆にしてしまいます。

5．測った二方向の変化率から勾配を復元する

fはpで全微分可能とします。D_(1,0)f(p)=2、D_(3/5,4/5)f(p)=−2 と分かっているとき、勾配、最大変化率、最も増える単位方向を求めてください。

ヒント1

勾配を(A,B)とし、内積の式を二つ作ります。

ヒント2

A=2、(3A+4B)/5=−2です。

解答

A=2を代入すると6+4B=−10、B=−4。したがって∇f(p)=(2,−4)、最大変化率は√20=2√5、方向は(1,−2)/√5です。検算すると(2,−4)·(3/5,4/5)=6/5−16/5=−2。二つの測定だけで任意の関数の全微分可能性を証明したのではなく、その仮定の下で二つの係数を復元しました。

6．指定した上り率になる向きを設計する

全微分可能なfのpでの勾配が(3,−4)です。方向微分が3になる単位方向u=(a,b)をすべて求めてください。また方向微分が6になる単位方向はあるでしょうか。

ヒント1

条件は3a−4b=3とa²+b²=1です。

ヒント2

b=(3a−3)/4を代入すると25a²−18a−7=0になります。

解答

方程式は(a−1)(25a+7)=0と因数分解でき、a=1または−7/25。対応するbは0または−24/25です。従ってu=(1,0)、u=(−7/25,−24/25)の二つ。後者の長さは√(49+576)/25=1、内積は−21/25+96/25=3で検算できます。最大変化率は‖(3,−4)‖=5なので6を与える単位方向はありません。方程式を解く前にも、この上限で不可能と判定できます。

7．最急降下の方向と歩幅を分けて点検する

Pのp=(1,0)からu=−(2,1)/√5へ、距離t>0だけ進みます。値が小さくなるtの範囲を求め、t=1と2を比較してください。

ヒント1

正確な増分は−√5t+(7/5)t²です。

ヒント2

t>0でくくり、残った一次式の符号を調べます。

解答

増分はt((7/5)t−√5)なので、下がるのは0<t<5√5/7。境界では同じ値で、それより大きければ上がります。t=1の増分は7/5−√5≈−0.8361、移動後の値は約0.1639。t=2の増分は28/5−2√5≈1.1279、値は約2.1279です。最小の方向微分−√5は基準点における一次の変化率で、任意の有限歩幅で値を下げるという主張ではありません。

8．同じ零勾配から違う近傍の様子を作る

原点の勾配が0となる三つの多項式を自分で作ってください。第一は原点以外の近い点ですべて正、第二はすべて負、第三は原点のどんな近くにも正と負の点があるものとします。方向微分も確認してください。

ヒント1

二次の項なら原点の一次係数は0になります。

ヒント2

平方の和、負の和、差を使えます。

解答

例えばf₁=x²+2y²、f₂=−x²−2y²、f₃=x²−y²です。原点の勾配はすべて0で、全微分可能なので全単位方向の方向微分も0。f₁は非零点で正、f₂は負、f₃は(t,0)でt²>0、(0,t)で−t²<0です。どんなδ>0でも0<|t|<δを選べるので、第三には原点の任意の近くで両方の符号があります。例えばt=0.01なら±0.0001。この違いは、零勾配という情報だけでは決まりません。

9．楕円の等高線と、曲線をたどる速度

f(x,y)=x²+4y²、γ(t)=(2cos t,sin t) とします。曲線上の高さが一定であることを示し、勾配と速度の内積を求めてください。t=π/2で両者の向きと長さも確認してください。

ヒント1

f(γ(t))を直接計算し、次に二つの成分を微分します。

ヒント2

∇f(γ(t))=(4cos t,8sin t)、γ′(t)=(−2sin t,cos t)です。

解答

f(γ(t))=4cos²t+4sin²t=4で一定。内積は−8cos t sin t+8sin t cos t=0です。t=π/2ではp=(0,1)、勾配(0,8)は縦で長さ8、速度(−2,0)は横で長さ2。非零の二つの向きは直交します。速度の長さは1ではないので、γに沿うt当たりの微分は速度との内積として計算しました。曲線γは明示的に与えられており、任意の等高線の存在を仮定してはいません。

10．勾配0でも、最も増える方向がある反例

本文のGの原点では∇G=0ですが、単位u=(a,b)に対しDᵤG=a²bです。この方向微分を最大・最小にする単位方向と値を求め、勾配の最急方向の定理を使えない理由を説明してください。

ヒント1

a²+b²=1よりa²b=b−b³、−1≤b≤1です。

ヒント2

一変数関数b−b³の導関数は1−3b²。端点の値も比べます。

解答

候補はb=±1/√3と端点±1です。端点の値は0、b=1/√3で2/(3√3)、b=−1/√3で−2/(3√3)。従って最大方向は(±√(2/3),1/√3)、最小方向は(±√(2/3),−1/√3)で、いずれも長さ1です。最大値は約0.3849で、勾配の長さ0とは一致しません。Gは原点で全微分可能でないため内積表示と最急方向の定理の仮定を満たしません。各方向の微分が存在するだけでは、その値が一つの線形写像から生じるとは限らないことを、最大値でも確認しました。
