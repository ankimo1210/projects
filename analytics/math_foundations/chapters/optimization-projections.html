導入：制約と最近点

変数を一定の範囲に保ちたいとき、勾配法で外へ出た点を、その範囲の中へ戻す操作を考えます。元の点から一番近い実行可能点を選ぶのが射影です。「一番近い点はあるか」「二つに分かれないか」「点のずれを増やさないか」を、距離の二乗と内積だけで確かめます。

ユークリッド射影の存在と一意性

C を ℝ² の非空な閉凸集合とします。p∈ℝ² に対して ‖p−z‖² が最小になる z∈C を PC(p) と書きます。距離は Euclid 距離です。閉とは集合内の収束列の極限も含むこと、凸とは二点を結ぶ線分全体を含むことです。

射影の存在

任意の p に対し、距離を最小にする点が少なくとも一つ存在します。この存在だけには凸性は不要です。

無限に遠い部分を切り落とす

非空なので c₀∈C を一つ選び、R=‖p−c₀‖ とします。K=C∩{z:‖p−z‖≤R} は非空、閉、有界です。ここで、ℝ² の閉有界集合は compact であり、その上の連続関数は最小値を取るという極値の事実を未証明で借ります。連続関数 ‖p−z‖² は K 上の q で最小です。C のうち K の外の点は距離が R より大きく、q の距離は R 以下なので、全 C でも q が最小です。R=0 なら c₀=p で、同じ結論を直接得ます。C 自体が有界である必要はありません。

閉でない C=(0,1)×{0} に p=(0,0) を射影しようとすると、距離の下限0を取る点がありません。凸でない C={(−1,0),(1,0)} に p=(0,0) を射影すれば、最近点が二つです。以下の一意性には凸性が働きます。

射影の変分不等式と非拡大性

射影を特徴づける内積不等式

q∈C が p の射影であるための必要十分条件は、全ての z∈C について次の式が成り立つことです。これを変分不等式（VI）と呼びます。

(p−q)·(z−q)≤0

凸な線分に沿って、二乗距離を展開する

q が最近点なら、凸性から q+t(z−q)∈C（0≤t≤1）。q の最小性により 0≤−2t(p−q)·(z−q)+t²‖z−q‖²。t>0 で割り、t→0⁺ とすれば VI を得ます。逆に VI があれば、任意の z∈C で ‖p−z‖²=‖p−q‖²−2(p−q)·(z−q)+‖z−q‖²≥‖p−q‖²。従って q は最近点です。

直線や部分空間への射影と違い、一般の凸集合では内積が0とは限りません。円板の図では −1 です。片側にしか進めない境界では、等号より不等号が自然です。

次は入力を二点動かしたとき、射影先がどれだけ動くかを比べます。入力二点の距離より、出力二点の距離を大きくしない性質を非拡大性と呼びます。同じ入力ならその距離は0なので、この性質は一意性の確認にも使えます。

一意性と非拡大性を同時に得る

p₁、p₂ の射影を q₁、q₂ とします。VI でそれぞれ z=q₂ と z=q₁ を選ぶと、(p₁−q₁)·(q₂−q₁)≤0、(p₂−q₂)·(q₁−q₂)≤0。足して整理すると ‖q₁−q₂‖²≤(p₁−p₂)·(q₁−q₂)。Cauchy–Schwarz より右辺は ‖p₁−p₂‖‖q₁−q₂‖ 以下です。q₁≠q₂ なら長さで割れて、‖q₁−q₂‖≤‖p₁−p₂‖。q₁=q₂ でも成立します。特に同じ入力 p₁=p₂ なら q₁=q₂ で、一意性も従います。

円板・箱への射影

原点中心の円板 C={z:‖z‖≤r}（r>0）では、‖p‖≤r なら q=p。外側なら q=rp/‖p‖ です。外側の場合、全ての z∈C で ‖p−z‖≥‖p‖−‖z‖≥‖p‖−r、そしてこの q が等号を達成するので、式を確認できます。

箱 C=[−r,r]² では、r は半辺長です。距離の二乗は各成分の二乗の和なので、それぞれを区間 [−r,r] の最近点へ戻せば全体も最小です。clip(t)=min(r,max(−r,t)) と書けば q=(clip(p₁),clip(p₂))。角でもこの式で一意に定まります。

表でいう外向きの法線方向は、境界点qから集合内のどの点zへ動くときも、n·(z−q)≤0となる非零のベクトルnが示す向きです。射影の残差p−qは、非零ならVIによってこの向きになります。残差が0の場合は、この残差を割って方向にする操作と、境界の形から法線を考えることを分けます。

例題1：集合に戻ることと、最も近く戻ることを区別する

無次元の配分集合C={(u,v):u≥0,v≥0,u+v≤1}へ、p=(2,1)を戻す自作問題です。Cは非空の閉凸集合なので、射影は存在して一意です。成分を[0,1]へ個別にクリップすると(1,1)になりますが、合計2でCに入りません。箱への公式を、結び付きのある制約へそのまま使えない例です。

まず直線u+v=1へ、直線に垂直な(1,1)方向に戻す候補を作ります。q=p−τ(1,1)と置くと成分の和は3−2τなので、τ=1でq=(1,0)です。これは非負条件も満たします。任意のz=(u,v)∈Cに対し、(p−q)·(z−q)=(1,1)·(u−1,v)=u+v−1≤0。変分不等式から、qがCへの射影だと保証できました。

別の戻し方として、クリップした(1,1)を合計1へ縮めたw=(1/2,1/2)もCに入ります。しかし最短ではありません。z=qを使うと、(p−w)·(q−w)=(3/2,1/2)·(1/2,−1/2)=1/2>0で、wはVIを破ります。

例題2：射影先を指定し、元の点の範囲を逆算する

同じ三角形Cについて、q=(1,0)へ射影される入力p=(p₁,p₂)をすべて求めます。n=p−q=(p₁−1,p₂)と置けば、VIはn·(z−q)≤0です。頂点z=(0,0)とz=(0,1)を代入すると、それぞれ−n₁≤0、−n₁+n₂≤0。従って必要条件はn₁≥0、n₂≤n₁です。

二頂点の検査だけで十分かも確かめます。任意のz=(u,v)∈Cでは、z−q=(1−u−v)(−1,0)+v(−1,1)。係数はどちらも非負なので、先ほどの二つの内積が非正なら、その和も非正です。従って条件は十分でもあり、答えはp₁≥1、p₂≤p₁−1です。

p=(2,1)もp=(2,−3)もこの範囲に入り、同じqへ射影されます。後者の残差(1,−3)は前者の(1,1)と異なる方向です。角の射影は一意でも、そこへ戻る元の点や残差の方向が一つとは限りません。p=qも含まれ、その場合だけ残差0で単位方向を作れないことは、既存の円板・箱の例と同じです。

射影勾配法と最適性条件

射影勾配法は x⁺=PC(x−α∇f(x))（α>0）と更新します。各更新後の点は C に入ります。ただし、射影の一意性だけから任意の歩幅での下降や収束までは結論できません。

更新しても同じ点のままになる点を不動点と呼びます。次は「動かなくなった」という計算の状態を、許された方向へ動いても、一次の変化では値を下げられないという条件へ翻訳します。

止まる条件を、制約付きの一次条件へ翻訳する

x∈C が更新の不動点であることは、VI に p=x−α∇f(x)、q=x を代入して、全 z∈C で ∇f(x)·(z−x)≥0 と同値です。α>0 なので符号を反転して割れます。f が C を含む開凸集合で C¹ で凸なら、一次の凸不等式 f(z)≥f(x)+∇f(x)·(z−x) から大域最小性が従います。逆に制約付き最小点なら、線分 x+t(z−x) に沿う右微分は非負で、この一次条件を得ます。凸でない f では、不動点でも大域最小の保証にはなりません。

この境界での一次条件を、次の等式乗数と KKT 条件へつなげます。

寄り道［自作モデル］：「クリップ」はいつ最近点か

二つの値をそれぞれ許容区間へ戻すとき、Euclid 距離と箱の組合せなら成分クリップが最近点になります。しかし x+y=1 という結び付きのある制約では、各成分を個別に切るだけでは和が1になる保証がありません。距離に成分間の項を加えた場合も同じ公式を流用できません。集合と距離の両方を指定してから「一番近い」を決めます。

出典：本章の二乗距離の分離に基づく自作例です。

例題3：射影の不等式から、下降する歩幅を導く

x∈C、α>0とし、更新点をq=PC(x−α∇f(x))、変位をd=q−xと書きます。VIで比較点z=xを選ぶと、(−α∇f(x)−d)·(−d)≤0。整理して次の不等式を得ます。

∇f(x)·d≤−‖d‖²/α

これは射影後の移動も一次近似を下げる方向である、という定量的な情報です。実際の関数値を評価するため、勾配がL-Lipschitz、すなわち‖∇f(y)−∇f(x)‖≤L‖y−x‖（L>0）を、Cを含む開凸領域上で仮定します。勾配法の下降補題から、線分の両端x,qに対して次が従います。

f(q)≤f(x)+∇f(x)·d+(L/2)‖d‖²≤f(x)−(1/α−L/2)‖d‖²

従って0<α<2/Lなら、d≠0で厳密に下降します。α=2/Lでは係数が0で、非増加までしかこの式から言えません。また各歩で下がることだけから、点列そのものの収束までは主張していません。

具体例f(x)=(x−2)²/2、C=[0,1]ではL=1です。x₀=0、α=1/2なら、射影前は0−(1/2)(−2)=1で、x₁=1。費用は2から1/2へ下がり、d=1に対する上界の減少量(2−1/2)·1=3/2と一致します。次は射影前が1−(1/2)(−1)=3/2、射影後は1のままです。勾配−1が非零でも、制約下での最小点では動きません。

歩幅の条件を外した反例も作れます。f(x)=x²/2、C=[−1,1]、x₀=1でα=2なら、1→−1→1と周期になります。α=3でも射影前が−2、2となって両端へ戻るので同じ周期です。費用は常に1/2。射影の一意性と実行可能性が保たれても、下降や収束は別の条件を必要とします。

演習：射影と変分不等式

1．二つの射影

r=1、p=(2,1) を円板と箱へ射影し、それぞれの距離を求めてください。

ヒント1

‖p‖=√5。円板の外側です。

ヒント2

箱では2だけが上限を超えています。

解答

円板は q=(2/√5,1/√5)、距離 √5−1。箱は q=(1,1)、距離1。円板と箱では集合が異なるため、射影も距離も異なります。

2．直交等号を確かめる

単位円板で p=(2,0)、q=(1,0) とします。z=(0,1) と z=q の二つで VI の左辺を求めてください。

ヒント1

p−q=(1,0) です。

ヒント2

z−q はそれぞれ (−1,1) と (0,0) です。

解答

内積はそれぞれ −1、0。両方とも ≤0 ですが、全ての z で等号になるわけではありません。部分空間での直交の絵を一般の凸集合へそのまま広げることはできません。

3．閉凸の役割

C={(−1,0),(1,0)}、p=(0,0) の最近点を求め、射影の一意性の定理を使えない理由を説明してください。

ヒント1

二点への距離は同じです。

ヒント2

二点の中点が C に入るかを確認します。

解答

両点とも距離1で最近点です。C は非空で閉ですが、中点 (0,0) を含まず凸ではありません。存在は保たれても、一意性の証明に必要な線分を使えません。

4．最近点という誤った報告を診断する

例題1の三角形へp=(2,1)を戻す計算がw=(1/2,1/2)を返しました。実行可能性を確認した上で、VIを破る比較点を選び、距離でも検算してください。

ヒント1

比較点z=(1,0)を使えます。

ヒント2

残差p−w=(3/2,1/2)です。

解答

wは非負で合計1なので実行可能。しかし(p−w)·(z−w)=1/2>0で射影ではありません。距離の二乗はwで5/2、zで2。実行可能なだけで最近点と宣言したのが誤りです。

5．指定の射影先から入力を設計する

三角形Cへ射影した結果をq=(1,0)にしたいとします。p₂=2を固定したとき、許されるp₁の全範囲を求めてください。p=(1/2,−1)がqへ射影されないこともVIで示してください。

ヒント1

例題2ではp₁≥1、p₂≤p₁−1です。

ヒント2

後半は比較点z=(0,0)を使います。

解答

p₂=2ならp₁≥3が必要十分です。p=(1/2,−1)ではp−q=(−1/2,−1)、z−q=(−1,0)で内積1/2>0。従ってqは射影ではありません。実際の射影は(1/2,0)です。

6．半平面と三角形を取り違えない

p=(3,−1)をH={(u,v):u+v≤1}と例題1の三角形Cへ射影してください。Hへの候補はp−τ(1,1)で求め、CではVIを使って検算してください。

ヒント1

pの成分和は2なので、Hの境界へ戻すτは1/2です。

ヒント2

Cへの候補は(1,0)。残差(2,−1)を調べます。

解答

Hへの射影は(5/2,−3/2)、距離1/√2です。任意のH内のzで残差(1/2,1/2)との内積は(u+v−1)/2≤0なので確定します。この点は負の成分を持ちCには入りません。Cへの射影は(1,0)で距離√5。残差(2,−1)はn₁≥0,n₂≤n₁を満たすためVIが成立します。

7．下降の係数から歩幅を逆算する

勾配Lipschitz定数L=4の問題で、例題3の下降上界をf(q)≤f(x)−‖q−x‖²という形にしたいとします。十分な歩幅α>0の全範囲を求めてください。

ヒント1

1/α−L/2≥1を要求します。

ヒント2

1/α−2≥1を解きます。

解答

0<α≤1/3です。この範囲なら1/α−2≥1となり要求を保証します。これはこの下降評価から選ぶ十分条件であり、範囲外の歩幅がどの関数でも必ず失敗するという必要条件ではありません。

8．不動点でも最小でない例

f(x)=−x²、C=[−1,1]で、x=0から射影勾配を行うとどうなりますか。α>0は任意です。大域最小の結論を使えない理由も述べてください。

ヒント1

f′(0)=0です。

ヒント2

端点の関数値と比べます。

解答

射影前も後も0なので不動点です。しかしf(±1)=−1<f(0)=0で、最小点ではありません。目的関数が凸でないため、不動点の一次条件を大域最小の十分条件へつなげられません。

9．一回で戻す方法と小さく進む方法を比べる

f(x)=‖x−c‖²/2、c=(2,1)、Cは例題1の三角形とします。x₀=(0,0)からα=1とα=1/2を比較し、後者の二更新と各費用を求めてください。

ヒント1

勾配はx−cです。α=1では射影前が常にcです。

ヒント2

α=1/2の射影前は一回目(1,1/2)、二回目(11/8,5/8)です。

解答

α=1なら一回で(1,0)となり、費用は1です。α=1/2では一回目の成分和3/2を均等に1/4ずつ減らし(3/4,1/4)、費用17/16。二回目は成分和2を1/2ずつ減らし(7/8,1/8)、費用65/64です。各候補の非負性とVIを確認できます。小さい歩幅ほど一回で最適点へ行ける、とは限りません。

10．非拡大性と逆の一意性

三角形Cへのp₁=(2,1)、p₂=(2,−1)の射影を求め、入力間と出力間の距離を比較してください。射影が一意という定理から、元の入力も一意に復元できるでしょうか。

ヒント1

どちらも例題2の入力条件を満たします。

ヒント2

入力間距離は2です。

解答

両方の射影は(1,0)なので出力間距離0≤2です。非拡大性は距離を増やさないことであり、距離を保つことではありません。各入力の射影先は一意でも、多数の入力が同じ点へ射影されるので逆の復元は一意ではありません。
