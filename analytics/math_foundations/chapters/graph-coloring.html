頂点彩色と彩色数

架空の発表会で、同じ参加者が聞きたい二つの発表を、同じ時間帯に置かないようにしたいとします。発表を頂点、同時に置けない二つの発表を辺にすれば、各頂点に時間帯の番号を付ける問題になります。隣接する二点だけは、異なる番号にしなければなりません。

全てに違う番号を付ければ条件を守れますが、時間帯が多すぎます。二つで足りる条件は何か。必ず使える個数の上限を、近所の情報だけで保証できるか。この二つの問いを考えます。

適正彩色と彩色数

この章も有限単純無向グラフを扱います。頂点へ 1、…、k の番号を割り当て、各辺 uv で c(u) ≠ c(v) となるものを適正な頂点彩色、または短く彩色と呼びます。実際の色の代わりに番号でもかまいません。同じ番号の頂点どうしには辺がなく、それぞれ一つの組として扱えます。

彩色できる最小の色数を彩色数 χ(G) とします。非空のグラフでは少なくとも 1、孤立点だけなら 1 です。空のグラフには 0 色で足りるとします。辺が一本でもあれば、両端を分けるため 2 色以上が必要です。どれか一つの彩色を見つけることと、色数が最小だと証明することは、別の作業です。

二部グラフと奇閉路

頂点全体を、内部には辺のない二つの集合 L、R に分けられるグラフを二部グラフと呼びます。片方が空でもかまいません。L を 1、R を 2 とすれば二色で彩色でき、逆に二色の各組を L、R にすれば二部グラフです。「二部」とは、連結成分が二つあるという意味ではありません。

二部グラフであることと、奇数長の閉路がないことは同値

閉路を一つも持たない木や森も含みます。グラフ全体が連結である必要はありません。

必要性：辺を渡るたびに、左右を入れ替える

二部グラフの辺は全て L と R の間にあります。L から一歩なら R、二歩なら L と交互に移ります。出発点へ戻る閉路の長さは偶数でなければなりません。従って奇数長の閉路はありません。

十分性：BFS の距離の偶奇で分ける

各連結成分で根を一つ選び、BFSで辺数の最短距離 d(v) と親の木を作ります。d が偶数の点を L、奇数の点を R に入れます。根だけの成分でも問題ありません。

辺 uv があれば、根から u までの最短の道に uv を足して v へ行けるので d(v) ≤ d(u) + 1。逆も同じだから、二つの距離の差は高々 1 です。もし u、v の距離の偶奇が同じなら、この二つの整数は等しくなります。

親の木で、根から u と v への二つの道が最後に共通する頂点を z とします。z の先の二つの枝は内部で交わりません。その枝二つと辺 uv を合わせると、頂点の繰り返しがない閉路になります。長さは次の通り奇数です。

(d(u)−d(z))+(d(v)−d(z))+1=2(d(u)−d(z))+1

u、v は異なる同じ層の点なので z は両方より前にあり、閉路の長さは少なくとも 3 です。奇閉路がないという仮定に反します。従って全ての辺は偶数層と奇数層を結び、L、R で二部に分けられます。成分ごとに作った二つの組を、それぞれまとめれば全体でも成立します。

「奇数長の閉路がない」は「閉路がない」より弱い条件です。四角形の閉路は二部グラフですが木ではありません。一方、「三角形がない」だけでは足りません。五角形の閉路は三角形を含まなくても奇閉路なので、二色で彩色できません。

貪欲彩色と最大次数による上界

二色で足りない場合にも、使える色数の簡単な保証があります。頂点が一つ以上あるとし、最大次数を Δ = max deg(v) とします。頂点を好きな順番に並べ、既に彩色した隣接点が使っていない最小の正の番号を付けていく方法を貪欲彩色（greedy coloring）と呼びます。

貪欲彩色は、どんな順番でも Δ + 1 色以下でできる

χ(G)≤Δ+1

禁止される色は、隣の点の個数以下

今彩色する頂点 v の隣は高々 Δ 個です。既に彩色された隣が使う異なる色の数も高々 Δ。候補を 1、…、Δ + 1 の Δ + 1 個用意すれば、一つは残ります。その色を選べば、既に彩色した隣との衝突はありません。後から彩色する隣も同じ規則で今の v の色を避けるので、最後まで各辺の条件が守られます。これで適正な彩色が一つ作れるため、最小値 χ もその使用色数以下です。

この定理は上限であって、必ず Δ + 1 色必要という意味ではありません。また貪欲法がいつも最小色数を見つけるという保証でもありません。次の道グラフでは、最大次数は 2、最小色数は 2 ですが、順番によって貪欲法は三色を使います。

必要な最小値と、必ず足りる上限を分けて読む
グラフχ(G)Δ + 1最小値の理由
四頂点の道23二部で、辺がある。
四角形の閉路23交互の二色で足り、辺があるので一色では足りない。
三角形33三頂点が互いに隣接するので、三つとも違う色が必要。
全ての二点間に辺がある四頂点44四頂点を全て異なる色にする必要がある。

下限は「これより少なくはできない」理由、上限は「これだけあれば作れる」理由です。二つが一致したときに、最小色数が確定します。三角形なら下限 3 と上限 3 が一致しますが、四頂点の道の上限 3 だけから最小値を 3 とすることはできません。

寄り道［自作モデル］：衝突の輪は、三つ組だけでは見えない

架空の五つの発表 A、B、C、D、E に、AB、BC、CD、DE、EA だけの衝突があるとします。三つの発表が全て互いに衝突する組はありません。それでも五本の閉路が奇数長なので、二時間帯では配置できません。A、B、C、D、E を 1、2、1、2、3 とすれば三時間帯で配置でき、最少は 3 です。

ここでは発表の長さは同じで、時間帯は互いに重ならず、衝突は二発表ごとの関係だけで決まると仮定しています。発表者の空き時間、部屋の容量、発表ごとの長さは入れていません。彩色で得た番号が現実の時間割になるには、どの条件をモデルへ入れたかを確認する必要があります。

出典：本章のために作成した発表会の衝突モデル。実際のイベントのデータではありません。

演習：彩色数の下界と上界

1．三角形がなくても、二色では足りない

五頂点の閉路 A–B–C–D–E–A の彩色数を求めてください。三色の例と、二色ではできない理由を両方示してください。

ヒント1：輪に沿って交互に置く

A を 1 にすると、B、C、D、E は二色では順にどうなりますか。

ヒント2：最後の頂点だけ三色目にする

1、2、1、2、3 と付けたとき、最後の辺 EA も確認します。

解答

奇数長の閉路なので二部グラフでなく、二色では不可能です。直接には A から 1、2、1、2、1 と付けると EA が同色になります。一方 1、2、1、2、3 は五本全ての両端を分ける適正彩色です。下限 3 と上限 3 が一致し、彩色数は 3 です。

2．同じ道に、二つの順番

四頂点の道 v₁–v₂–v₃–v₄ を、最小の使用可能色を選ぶ貪欲法で彩色します。順番 v₁、v₂、v₃、v₄ と、順番 v₁、v₄、v₂、v₃ を比較してください。Δ + 1 の上限に反しますか。

ヒント1：まだ色のない隣は、今は色を禁止しない

二つ目の順番では両端がどちらも最初の色を使えます。

ヒント2：最後の頂点の、二つの隣の色を見る

二つ目の最後は v₃ で、隣は v₂ と v₄ です。

解答

最初の順番では、左から 1、2、1、2 となり二色です。二つ目では、左から 1、2、3、1 となり三色。最大次数は 2 なので Δ + 1 = 3、どちらも上限内です。貪欲法は常に適正彩色を作りますが、最小色数を達成するかは順番によることが、この例で分かります。

3．同じ層の辺から、奇閉路を取り出す

自作の別例で、辺は RA、RB、AC、BD、CD とします。根 R からの BFS の層を求め、同じ偶奇の層を結ぶ辺と、そこからできる奇閉路を挙げてください。

ヒント1：R から近い順に並べる

R が 0、A と B が 1、C と D が 2 です。

ヒント2：C と D の親を根までたどる

C–A–R と D–B–R の最後の共通点は R です。

解答

層は R=0、A=B=1、C=D=2。同じ層を結ぶ辺は CD です。親の枝 C–A–R–B–D に CD を足すと R–A–C–D–B–R という長さ 5 の閉路になります。従ってこのグラフは二部グラフではありません。

自分の言葉で

  1. 二部グラフの二つの組と、BFS の距離の偶奇をどう結びましたか。奇閉路があると何が衝突しますか。
  2. Δ + 1 は何の上限ですか。貪欲法の使用色数と最小の彩色数は、いつ違いましたか。
  3. 時間割を彩色で表すとき、頂点・辺・色は何を意味し、どんな条件はまだ表されていませんか。
