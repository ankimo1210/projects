数学的観察と予想の導入

1、4、9、16 と並んでいたら、次は 25 と答えたくなります。順に 1²、2²、3²、4² だからです。規則を見つける力は数学の大切な入口です。しかし、この四つの数だけから、次が必ず 25 だと言えるでしょうか。「自然に思える答え」と「条件から必ず従う答え」を区別することから、この本を始めます。

観察では、具体的な数や図を調べ、共通する特徴を探します。そこから立てる、まだ証明していない主張が予想です。証明は、その予想が指定した範囲のすべての対象で成り立つ理由を、定義やすでに認めた事実から説明します。観察が弱く、証明が強いという順位づけではありません。問いを発見する仕事と、その答えの届く範囲を確定する仕事が違うのです。

有限データと規則の非一意性

正の整数 n に対して、a(n) = n² と b(n) = n² + (n − 1)(n − 2)(n − 3)(n − 4) を考えます。最初の四項では追加した積の因子に 0 があるので、二つの式の値は表のように一致します。どちらも一つの式で定めた規則ですが、第5項から値が分かれます。

P(n)=(n−1)(n−2)(n−3)(n−4) です。まず同じ値ではなく、追加した積が消える理由を各行で見ます。この表は二つの規則の5項の比較です。任意個の観測で同じ仕掛けが使えることは、続く証明で確かめます。

有限個の一致だけでは、規則は一つに決まらない

m を正の整数とします。数式 f(n) の最初の m 個の値を知っても、数式で表せるという条件だけでは、その先の値は決まりません。

短い証明

f(n) に c(n − 1)(n − 2)⋯(n − m) を足した式を g(n) とします。c は 0 でない定数です。1 ≤ n ≤ m では積が 0 なので g(n) = f(n)。しかし n = m + 1 では積は 1·2⋯m であり 0 でないため、g(m + 1) ≠ f(m + 1) です。同じ観測結果に合う別の規則が作れました。

ここから「どの予想も同じ程度によい」とは言えません。単純な式を優先する、変化が滑らかだと仮定する、といった方針には用途があります。ただし、それは観測値とは別に加えた条件です。「二次式で表される」と初めから指定されていれば、先ほどの別の式は候補から外れます。何を知り、何を仮定したのかを分けて書くと、推測を有用なまま誠実に使えます。

全称命題の証明と反例

「正の整数 n について、n と n + 1 の積は偶数だ」という予想を考えます。1·2、2·3、3·4 を計算すれば確かに偶数です。百個調べても、そのままでは百一個目を説明していません。そこで数を代入する手を止め、連続する整数の構造に注目します。

偶数になる理由

整数は偶数か奇数のどちらかです。n が偶数なら n = 2k と書けるので、n(n + 1) = 2k(n + 1) は 2 の倍数です。n が奇数なら n = 2k + 1 と書け、n + 1 = 2(k + 1) なので、やはり積は 2 の倍数です。二つの場合ですべての整数 n を覆ったので、主張は正の整数だけでなく整数全体で成り立ちます。

これに対し、「整数 n ≥ 0 なら n² + n + 41 は必ず素数だ」は誤りです。n = 0、1、2 では 41、43、47 と素数が続きますが、n = 41 では 41² + 41 + 41 = 41·43 です。条件を満たすのに結論を満たさない対象を反例といいます。全称的な主張を否定するには一つで十分です。その一つを除いても、ほかのすべてが正しいと証明されたわけではありません。

もちろん、対象が有限で、漏れなく全部を調べたなら、その確認は証明になります。「1 以上 10 以下の整数」という範囲なら十個の調査で足ります。問題は計算した個数ではなく、主張の範囲をすべて覆ったかどうかです。後の数学的帰納法は、一段ずつ確かめる発想を、無限個の整数を覆う論証へ変える方法です。

寄り道［背景］：40回続く素数も、次には崩れる

オイラーのベルヌーイ宛書簡として残る資料 E461 には、x² − x + 41 が x = 0 から 40 の整数で素数を生むという観察が記されています。本文の n² + n + 41 は x = n + 1 と置いた同じ式です。小さな値だけでなく、かなり長い間、素数が続くのです。

ところが x = 41 では 41²、本文の添字なら n = 40 で 1681 になり、41 で割れます。元の書簡も、成り立つ範囲を限って述べています。大数学者の名前がつく式でも、問うべきことは「何例当たったか」から「どの範囲を主張したか」へ進みます。ここでは有限の範囲での見事な規則そのものが、新しい問いの入口になっています。

出典：Euler Archive：書簡 E461。

演習：規則の非一意性と反例

1．次の値を好きに変える

最初の四項が 1、4、9、16 で、第5項が 1 になる式を、本文の作り方で一つ示してください。

ヒント1：定数を残しておく

n² + c(n − 1)(n − 2)(n − 3)(n − 4) と置きます。

ヒント2：第5項だけで c を決める

n = 5 で値は 25 + 24c です。これが 1 になる条件を解きます。

解答

c = −1 です。したがって n² − (n − 1)(n − 2)(n − 3)(n − 4) が一例です。n = 1、2、3、4 では積が消え、n = 5 では 25 − 24 = 1 となります。

2．例の列を、理由に置き換える

どんな整数 n に対しても、連続する二整数 n、n + 1 の和は奇数であることを証明してください。

ヒント1：奇数の定義を目標にする

ある整数 k を用いて 2k + 1 と書ければ十分です。

ヒント2：まず和を整理する

n + (n + 1) の括弧を外します。係数が 2 の部分は何ですか。

解答

n + (n + 1) = 2n + 1 です。n は整数なので、これは奇数の定義そのものです。特定の値に依存しない計算により、負の整数や 0 も含めて示せました。

3．反例の効き方を説明する

「すべての整数 n ≥ 0 で n² + n + 41 は素数」を否定してください。また、その否定から「すべて合成数だ」と結論してよいでしょうか。

ヒント1：定数と同じ値を入れる

n = 41 として、41 を共通因数にします。

ヒント2：否定後の主張も例で調べる

n = 0 の値は素数でした。一つの失敗と、全面的な失敗を区別します。

解答

n = 41 で 41·43 となり、両因子が 1 より大きいので素数ではありません。これで元の主張は否定できます。しかし n = 0 では素数 41 なので、「すべて合成数」も誤りです。正しい否定は「素数でない値を与える整数 n ≥ 0 が存在する」です。

自分の言葉で

  1. 観察、予想、証明は、同じ問題に対してそれぞれ何をしますか。
  2. 有限個の確認が証明になる場合と、ならない場合を一つずつ挙げてください。
  3. 好ましい予測を選ぶことと、唯一の答えを証明することは、どう違いますか。
