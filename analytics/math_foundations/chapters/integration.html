リーマン積分と長方形による近似

高さが場所によって変わる図形の面積を、細い長方形に分けて求めたいとします。例えば y = x² と横軸に挟まれた、0 ≤ x ≤ 1 の部分です。左端の高さを使えば控えめに、右端の高さを使えば多めに見積もれます。分割を細かくすると、二つの見積もりは同じ数へ近づくでしょうか。

細かく分ければ必ず一つの値に落ち着くでしょうか。「小片の合計が定まる」を定義して調べます。この章では、実数の有限な閉区間上のRiemann 積分を扱います。

欲しいのは、長方形の和を一つ計算することだけではありません。代表点を変えても、計算を細かくしても、同じ量を測っていると言える保証です。まず上下から挟む幅を計算し、どこを細分すると幅が縮むかを調べます。次に符号のある量や、連続でない例を通して、何を積分できるのかを確かめます。

学習の目安は演習を含めて130–180分です。分割と可積分性、連続性からの保証と平方和、符号・反例・演習の三回に分けられます。演習1–3は基本、4–7は分割の選択と精度、8–10は符号・条件の診断と設計です。原始関数や基本定理による計算は、次章で結び付けます。

分割・下和・上和

まず f(x)=x² を0から1まで、二つの幅1/2の区間に分けて考えます。左の区間で高さは0から1/4、右では1/4から1です。小さい高さで作る二つの長方形の合計は (0+1/4)·1/2=1/8、大きい高さなら (1/4+1)·1/2=5/8。曲線の下の面積はこの間にあります。この計算を、等分でない分け方や一般の関数でも書ける記号に直します。

a < b とし、f は [a, b] 全体で定義された有界な実数値関数とします。分割 P は a = x₀ < x₁ < … < xₙ = b という点の並びです。第 i 小区間 [xᵢ₋₁, xᵢ] の幅を Δxᵢ、その区間の値の最大の下界を mᵢ、最小の上界を Mᵢ とします。これらは最小値・最大値として達成されなくても構いません。有界性と実数の完備性により存在します。

Δ はここでは「幅」を表し、Δxᵢ=xᵢ−xᵢ₋₁ です。添字 i は左から数えた小区間の番号で、mᵢ,Mᵢもその区間に対応します。上の二等分では x₀=0,x₁=1/2,x₂=1、幅は二つとも1/2です。次の Σ は、小区間の番号を一つずつ動かして全ての寄与を足す記号です。

幅に mᵢ を掛けたものを合計した下和を L(P)、幅に Mᵢ を掛けたものを合計した上和を U(P) と呼びます。また各小区間の代表点 ξᵢ を一つずつ選び、f(ξᵢ)Δxᵢ を足すものが Riemann 和です。

L(P)=∑i=1nmiΔxi≤∑i=1nf(ξi)Δxi≤U(P)

f が非負なら図形の面積に対応し、負の値は横軸より下を負に数える合計になります。

この和が細かい分割で一つの値に定まるとき、後の定義の節のように ∫ₐᵇf(x)dx と書きます。a,bは集める範囲の両端、f(x)はその場所の値で、dxはx方向の細かい幅を使って集めることを示します。この記号だけで原始関数が与えられるわけではありません。

上下和の隙間と細分する場所の選択

一つの代表点で作った和がたまたま真の値に近くても、そのことだけでは誤差は分かりません。上下和なら、区間ごとの値の幅をすべて含められます。第i小区間が作る隙間は(Mi−mi)Δxi。値の振れだけでなく、その場所の幅も掛けて判断します。

例題：同じ一個の分割点を、左右のどちらへ加えるか

f(x)=x²、区間[0,1]を0,1/2,1で分けたとき、L=1/8、U=5/8でした。左の小区間の隙間は(1/4−0)(1/2)=1/8、右は(1−1/4)(1/2)=3/8です。右の方が全体の不確かさへ大きく寄与しています。

右へ3/4を追加すると、幅は1/2,1/4,1/4です。下和は0·(1/2)+(1/4)(1/4)+(9/16)(1/4)=13/64。上和は(1/4)(1/2)+(9/16)(1/4)+1·(1/4)=33/64。隙間は20/64=5/16へ縮みます。

左へ1/4を追加した場合は、下和0·(1/4)+(1/16)(1/4)+(1/4)(1/2)=9/64、上和(1/16)(1/4)+(1/4)(1/4)+1·(1/2)=37/64で、隙間は28/64=7/16です。同じ三分割でも、今回は右を細かくする方が狭い保証を得られます。「分割数が同じ」だけでは精度は決まりません。

元の分割に点を加えた場合には、小区間が分かれても、その中の値は元の最大の下界以上、最小の上界以下です。従って下和は下がらず、上和は上がりません。分割点をただ移動した二つの分割の間には、この単調な関係を必ずしも言えません。ここで役に立つのは、元の点を残した細分です。

リーマン可積分性の定義

積分可能性の定義

有界な f について、すべての下和の最小の上界と、すべての上和の最大の下界が一致するとき、f は Riemann 積分可能といいます。その共通の実数 I を積分値とし、∫ₐᵇ f(x) dx と書きます。x は合計する位置を表す変数です。

同じ条件は「どんな ε > 0 に対しても、U(P) − L(P) < ε となる分割 P がある」と言い換えられます。各 ε で分割を選び直して構いません。

言い換えが成り立つ理由

分割へ点を追加すると下和は下がらず、上和は上がりません。二つの分割の点をすべて集めた共通の細分を考えると、どの下和もどの上和以下です。したがって下積分 α = sup L(P)、上積分 β = inf U(P) には α ≤ β が成り立ちます。

隙間を任意に小さくできれば 0 ≤ β − α ≤ U(P) − L(P) < ε なので α = β です。逆に α = β = I なら、L(P₁) > I − ε/2 となる分割と U(P₂) < I + ε/2 となる分割を選べます。共通の細分 P では U(P) − L(P) < ε。これで二つの定義が一致します。

積分値はどの分割でも L(P) ≤ I ≤ U(P) を満たします。上下の隙間が小さければ、代表点の選び方による揺れも小さくなります。

積分の線形性・単調性・区間加法性

各小区間での関数の上限と下限の差を、その区間での値の振れ（振動）と呼びます。f の場合は Mᵢ−mᵢ です。値の幅なので、最大値や最小値が達成される必要はありません。

区間加法性・線形性・単調性

積分可能な関数について、a < c < b なら、全区間の積分は二つの部分区間の積分の和です。実数 α、β と積分可能な f、g に対し αf + βg も積分可能で、∫(αf + βg) = α∫f + β∫g。同じ区間で f ≤ g なら ∫f ≤ ∫g です。上下端を省略した積分は、すべて同じ [a, b] を表します。

∫abf(x)dx=∫acf(x)dx+∫cbf(x)dx

共通の細分で比べる

まず区間加法性です。分割に c を追加すると、上下の和は左右それぞれの和を足したものになります。全体の隙間が ε 未満なら、各部分の隙間も ε 未満なので、部分区間でも積分可能です。逆に左右で隙間の小さい分割を選び、合わせれば全体でも隙間が小さくなります。全体の積分値と左右の積分値の和は、ともに同じ上下の和の間に入るので、その隙間を 0 へ縮めると等しくなります。

次に線形性です。小区間の値の振れについて、αf + βg の振れは |α| と f の振れの積、|β| と g の振れの積の和以下です。f、g の上下和差を共通の細分で任意に小さくできるため、αf + βg も積分可能です。同じ代表点を使う Riemann 和は有限和の線形性を満たします。各和と積分値の差は対応する上下和の隙間以下なので、三つの隙間を 0 へ近づければ積分の線形性が従います。最後に f ≤ g なら、各小区間の下限もこの順序を満たすので Lf(P) ≤ Lg(P)。両側で上限を取れば積分の単調性です。

定数 C の上下和はどちらも C(b − a) なので、その積分も同じ値です。特に |f| ≤ M なら定数 −M、M と比較して |∫ₐᵇ f| ≤ M(b − a) を得ます。

等しい端の積分は 0、b から a までの積分は a から b までの積分に負号を付けたものと定義します。三点を昇順に並べた加法式を移項すれば、区間加法性は端点の並びによらず成立します。従って |f| ≤ M なら、任意の二点 x、y について |∫ₓʸ f| ≤ M|y − x| です。これらは原始関数や微積分の基本定理を用いず、上下和から得た規則です。

符号付きの量と単位：一定の区間ごとの計算

面積の図から積分を導入しましたが、積分で集める量は非負とは限りません。流入を正、流出を負とする正味の流量を、時間幅と掛けて合計する自作模型を考えます。この例の流量は区間ごとに一定なので、基本定理を使わず長方形の和で計算できます。

例題：正味の増減と、通った量を分ける

時刻tは分、流量f(t)はL/分とし、0≤t<1では2、1≤t≤3では−1とします。最初の1分には2·1=2L入り、次の2分には(−1)·2=−2Lの増減です。正味の変化は0Lですが、入った量2Lと出た量2Lを合わせた通過量は4Lです。

積分の線形性と区間加法性では、∫03f(t)dt=2·(1−0)+(−1)·(3−1)=0。絶対値を先に取った関数|f|なら2·1+1·2=4です。単位はどちらも(L/分)×分=Lですが、集めている意味が違います。また端を3から0へ逆にすれば、符号の定義により∫30f=−0=0です。最初の1分だけを逆向きに集めれば∫10f=−2Lとなります。

時刻1の値を2へ変えても結果は同じです。変わった一点の周囲だけを幅の合計ηの小区間で囲めば、上下和の追加の隙間は高々3η。ηをいくらでも小さくできるため積分値は変わりません。一点の値が長方形の大きな幅全体を表すことは、極限では要求していないのです。

一般の連続な符号付き関数でも、定数−MとMで挟めば積分の大きさはM(b−a)以下です。これは打消しを無視した安全な上限で、積分が0なら関数も0という意味ではありません。区間全体で正と負の寄与が釣り合う場合があります。

連続関数の可積分性

各点で連続でも、点ごとに別々の幅しか選べないままでは、分割全体の長方形を一度に制御できません。どんな ε > 0 に対しても、全区間で共通の δ > 0 を選べて、区間のどの二点も距離が δ 未満なら値の差が ε 未満になる性質が一様連続性です。δはεに応じて選べますが、二点の場所には依存しません。閉区間上の連続関数がこの性質を持つことを、次の証明で確かめます。

閉区間で連続なら積分可能

f が [a, b] 全体で連続なら、f はそこで有界であり、Riemann 積分可能です。

一つの幅で、全区間をまとめて制御する

有界性は最大値・最小値定理から従います。また閉区間で連続な関数は一様連続です。これは、出力の許容幅 η > 0 に対して、全区間で共通に使える δ > 0 があり、|s − t| < δ なら |f(s) − f(t)| < η となる性質です。

この性質も証明しましょう。もし成立しなければ、ある η₀ > 0 に対し、各 n で |sₙ − tₙ| < 1/n かつ |f(sₙ) − f(tₙ)| ≥ η₀ となる二点を選べます。平均値の章で証明したコンパクト性から sₙ の収束部分列を取ると、対応する tₙ も同じ点へ収束します。連続性により二つの出力の差は 0 へ近づくので矛盾です。

そこで η = ε/{2(b − a)} とし、各幅が δ 未満の分割を選びます。小区間ごとの値の振れ Mᵢ − mᵢ は η 以下なので、U(P) − L(P) ≤ η(b − a) = ε/2 < ε。積分可能性の条件を満たしました。一様連続性は最小上界性から導いた定理で、独立に借りた仮定ではありません。

閉区間という条件から、各点の連続性を全区間共通の制御へ変えたことが要点です。

二次関数の積分と平方和

[0, 1] を n 等分します。x² はこの区間で増加するので、左端の値を使う和が下和 Lₙ、右端の値を使う和が上和 Uₙ です。幅は 1/n、高さはそれぞれ (k/n)² で、左端では k = 0, …, n − 1、右端では k = 1, …, n を使います。

平方和の公式 1² + … + m² = m(m + 1)(2m + 1)/6 を使うと、Lₙ = 1/3 − 1/(2n) + 1/(6n²)、Uₙ = 1/3 + 1/(2n) + 1/(6n²)。差は 1/n なので積分可能で、両方の和が 1/3 へ収束するため積分値も決まります。

Ln≤∫01x2dx≤Un,∫01x2dx=13

平方和の公式は数学的帰納法で確かめられます。m = 1 で成立し、右辺を m + 1 の式へ変えた差は (m + 1)² です。したがって和に次の平方を足す操作と一致します。ここでの面積値は、分割の合計とその極限から得ました。微分との結び付きは微積分の基本定理で確立します。

上下和から誤差と必要な分割数を決める

x²の積分値が1/3と決まるのは、LnとUnの差が0へ縮むからです。同じ式から、有限のnで返す値の精度も計算できます。ここでは「区間で挟むこと」と「近似値一つの誤差」を区別します。

例題：保証幅から分割数を逆算する

積分値を幅0.001以下の区間へ入れたいなら、Un−Ln=1/n≤0.001からn≥1000です。代表点を任意に選んだ和Snもこの区間内なので、|Sn−I|≤1/nが保証できます。

数値一つを返すなら、上下和の中点Qn=(Ln+Un)/2を選ぶ方法があります。Iも同じ区間内なので誤差は隙間の半分1/(2n)以下。誤差0.001以下だけが目標なら、この保証からはn≥500で十分です。たとえばn=4ではL=14/64、U=30/64、Q=22/64で、保証誤差は1/8です。幅の保証と中点の誤差保証では必要なnが違います。

さらにこの関数の正確な式を使えばQn=1/3+1/(6n²)なので、実際の誤差は1/(6n²)です。n=13なら1/1014<0.001ですが、n=12では1/864>0.001。従ってこのQの正確な式から選ぶ最小は13です。500は間違いではなく、上下の隙間だけを使う、情報の少ない保証でした。

「小区間の中点を代表点にする」方法は、上下和の平均とは別です。その和をMnとすれば、x²の場合はMn=(1/n³)∑k=1n(k−1/2)²。平方を展開し、平方和と自然数和を使うとMn=1/3−1/(12n²)です。n=4なら21/64となり、Q4=22/64とは一致しません。この関数では中心の高さがよい近似になりますが、別の関数でも同じ誤差式が使えるという意味ではありません。

一様連続性の証明は、具体的な分割数の公式がなくても、どの要求精度にも届く分割が存在することを保証しました。今の計算は、その一般の存在に対して、特定の関数では必要なnまで設計できる、という一段詳しい情報です。

不連続関数の可積分性と反例

[0, 1] で、x < 1/2 なら 0、x ≥ 1/2 なら 1 となる関数を考えます。境目で連続でありませんが、境目の直前に幅 η の小区間を作れば、上下の和が違うのはその幅の部分だけです。例えば分割 0、1/2 − η、1/2、1（0 < η < 1/2）では下和 1/2、上和 1/2 + η。差をいくらでも小さくできるので積分可能で、値は 1/2 です。

一方、有理数で 1、無理数で 0 となる関数を同じ [0, 1] で考えます。どんな正の幅の実数区間にも有理数と無理数があるという性質を使うと、すべての小区間で mᵢ = 0、Mᵢ = 1。どんな分割でも下和は 0、上和は 1 で、隙間が縮みません。この Dirichlet 関数は有界でも Riemann 積分可能でありません。連続性は十分な条件ですが必要な条件ではなく、有界性だけでは十分でないのです。

アルキメデス『放物線の求積』命題24は、放物線と弦で囲まれた領域の面積が、領域と同じ底辺と高さを持つ内接三角形の面積の 4/3 になることを示します。曲がった境界なのに、答えが三角形との簡単な比になるのは意外ではないでしょうか。

可積分性と上下和の演習

1．幅 0.01 の保証

x² の [0, 1] 上の等分による上下の和の差を 0.01 以下にしたいとき、何等分以上にすればよいですか。

ヒント1：二つの公式を引く

共通の 1/3 と 1/(6n²) が消えます。

ヒント2：必要な不等式を書く

1/n ≤ 0.01 を満たす正の整数 n を求めます。

解答

Uₙ − Lₙ = 1/n なので n ≥ 100、つまり 100 等分以上です。積分値はその二つの数の間にあるため、幅 0.01 以下の区間で値を挟めます。実験の最大 64 等分から先の保証も、式を使えば求められます。

2．飛びの位置を変える

[0, 1] で、x < 3/4 なら 0、それ以外なら 1 とする関数の積分値を、上下の和で示してください。

ヒント1：境目の直前を狭く囲う

0、3/4 − η、3/4、1 を分割点にします。

ヒント2：高さ 1 が確定する幅を数える

[3/4, 1] の幅は 1/4 です。

解答

0 < η < 3/4 として示された分割を使うと、下和は 1/4、上和は 1/4 + η。任意の ε > 0 に対して η < ε とできるので積分可能です。積分値はすべての η で 1/4 と 1/4 + η の間に入り、したがって 1/4 です。

3．代表点によって違う合計

Dirichlet 関数の Riemann 和で、代表点をすべて有理数にする場合と、すべて無理数にする場合の値を比べ、積分できない理由を説明してください。

ヒント1：各長方形の高さを見る

二つの選び方で、高さはすべて 1、またはすべて 0 になります。

ヒント2：幅の合計は変わらない

どんな分割でも幅を足すと 1 です。

解答

有理数の代表点だけなら和は 1 · (幅の合計) = 1、無理数だけなら 0 です。分割をいくら細かくしてもこの二つの選び方ができ、合計は共通の値に定まりません。上下の和でも、差が常に 1 となるため定義の条件を満たしません。

4．等分でない幅を忘れない

x²を[0,1]の分割0,1/4,1で調べ、下和と上和を求めてください。「左端の値0,1/16を足して2で割る」という方法が正しくない理由も説明してください。

ヒント1

二つの幅は1/4と3/4です。x²は増加するので左端が下、右端が上です。

ヒント2

下和は0·(1/4)+(1/16)·(3/4)です。

解答

L=3/64、U=(1/16)(1/4)+1·(3/4)=49/64で、隙間は46/64=23/32です。値を足して2で割る方法は、幅をどちらも1/2として扱うので、下和1/32という別の値を出します。高さは対応する幅を掛けて集めます。実際の値1/3も3/64と49/64の間にあり、上下からの保証と矛盾しません。

5．左端が下とは限らない

f(x)=1−xを[0,1]でn等分します。下和・上和を求め、その差と積分値を決めてください。x²の例と比べ、代表点のどちらが下和になりますか。

ヒント1

今度は減少関数です。右端の高さ1−k/nが小さい方になります。

ヒント2

自然数和∑k=n(n+1)/2を使うと、下和は1−(n+1)/(2n)です。

解答

Ln=(1/n)∑k=1n(1−k/n)=(n−1)/(2n)、Un=(n+1)/(2n)です。差は1/nで0へ縮み、両方とも1/2へ近付くので積分値は1/2。n=1ならL=0,U=1と確かめられます。下和は右端、上和は左端であり、位置だけでなく増減から小区間の下限・上限を選びます。

6．二種類の「中点」を比較する

x²を[0,1]で二等分し、(a)上下和の中点Q、(b)各小区間の中点を代表点とした和Mを計算してください。それぞれと積分値1/3との差も求め、同じ方法でないことを確かめてください。

ヒント1

L=1/8,U=5/8です。小区間の中点は1/4と3/4です。

ヒント2

M=((1/4)²+(3/4)²)/2です。比較は48分の表示でできます。

解答

Q=(1/8+5/8)/2=3/8、M=(1/16+9/16)/2=5/16です。Q−1/3=1/24、1/3−M=1/48なので、今回はMの方が誤差が小さく、過小評価です。Qは上下の数値の平均で、Mは中央の場所の関数値を使う和です。この一例の比較だけでは、どの関数でもMが必ず優れるとは言えません。

7．値の振れから分割数を保証する

x²を[0,2]でn等分します。0≤s,t≤2なら|s²−t²|≤4|s−t|を示し、この評価からU−L≤16/nを導いてください。さらに増加性と端点値を使って正確な差8/nを求め、それぞれで隙間0.01以下に必要なnを比べてください。

ヒント1

|s²−t²|=|s−t||s+t|で、s+t≤4です。各幅は2/nです。

ヒント2

振れ≤8/nを幅の総和2へ掛けます。正確な差では(2/n)∑[(2k/n)²−(2(k−1)/n)²]が打ち消し合います。

解答

s+t≤4から最初の評価が出ます。各区間の振れは8/n以下なので、U−L≤(8/n)·2=16/nです。一方、増加性から上端と下端の差を足すと中間項が消え、U−L=(2/n)(2²−0²)=8/nとなります。0.01以下には、前の保証ならn≥1600、正確な差ならn≥800。粗い上限も正しいですが、この関数の追加情報で半分の分割数まで保証できます。

8．一点だけ値が違う関数

[0,1]でf(1/2)=5、それ以外ではf(x)=0とします。上下和で積分可能性と積分値を示してください。一点の値が5だから積分も正になる、という説明は正しいでしょうか。

ヒント1

0<η<1として、1/2を幅ηの小区間の内部へ入れます。

ヒント2

分割0,1/2−η/2,1/2+η/2,1では、下和0、上和5ηです。

解答

示された分割では、どの小区間にも値0の点があるのでL=0です。値5を含むのは中央の幅ηだけでU=5η。任意のε>0へη<ε/5を選べば隙間をε未満にでき、積分可能です。積分値Iはすべてのηで0≤I≤5ηなのでI=0。一点の高さと、それを正の幅にわたって足すことは違います。非負の積分が0でも関数が各点で0とは限りません。

9．正味と通過量から時間を逆算する

0からT分まで、最初の1分は3L/分の流入、その後は1L/分の流出とする自作模型を考えます。T≥1とします。正味の変化を0LにするTを求め、その間の通過量を求めてください。初期の水量までこの積分から決まりますか。

ヒント1

正味の変化は3·1−1·(T−1)です。

ヒント2

通過量では流出にも正の符号を付け、3+(T−1)を計算します。

解答

3−(T−1)=0からT=4分です。最初の流入3Lと、その後3分の流出3Lが釣り合います。通過量は3+3=6Lで、正味0Lとは異なります。積分で分かったのは初期量からの変化なので、初期の水量は別に指定しなければ決まりません。水のない状態を避けるなどの現実の条件を加えるなら、その初期量も模型へ入れる必要があります。

10．細かい一列の和だけで可積分と言えるか

Dirichlet関数で各小区間の代表点を有理数にそろえ、n等分の和が毎回1だったとします。「同じ値へ落ち着いたから積分値は1」という結論を診断してください。積分可能性を判断するために、何を追加で調べますか。

ヒント1

同じ分割で代表点を無理数に選ぶこともできます。

ヒント2

分割ごとの下限と上限は、選んだ一点の高さではなく、小区間のすべての値を含めます。

解答

無理数の代表点なら同じ各和は0なので、代表点の選び方によらない値に定まっていません。上下和はどの分割でもL=0,U=1で、隙間を小さくできません。従ってRiemann積分不能です。一列の代表点を都合よく選んだ和が収束するだけでは不十分で、定義の任意の精度に対して上下の隙間を縮められるかを調べます。
