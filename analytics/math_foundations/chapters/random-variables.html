確率変数と確率分布

二回のコイン投げでは、表裏の並びが結果です。一方、知りたいものが「表の回数」なら、表裏と裏表を同じ数 1 としてまとめます。このまとめ方を明示すると、元の結果の確率から、知りたい数の確率を計算できます。

この章は、確率のある世界から実数への写像を作る章です。有限の場合から始め、成功回数と、初めて成功するまでの回数を比べます。

確率変数の定義

標本空間 Ω 上の確率変数 X は、各結果 ω に実数 X(ω) を対応させる写像です。「変数自体が勝手に変わる」というより、どの結果が実現するかによって読まれる値が変わります。有限の Ω で全ての部分集合を事象にする場合は、どんな実数値写像でも構いません。

例えば二回の独立な公平なコイン投げで、Ω = {表表, 表裏, 裏表, 裏裏} とします。X を表の回数とすれば、それぞれ 2、1、1、0 です。X = 1 という事象は、元の空間では {表裏, 裏表}。したがって P(X = 1) = 1/2 であり、三つの値 0、1、2 が等確率になるわけではありません。

一般の実数のモデルでは、{ω : X(ω) ≤ t} が全ての実数 t で事象となる条件を加えます。これは可測性と呼ばれます。その一般理論と無限列の確率モデルの構成は、本冊では証明せずに使う枠組みです。有限の集合をまとめる計算は、この章で直接確かめます。

確率質量関数と累積分布関数

X の分布とは、X がどの範囲に入るかの確率を与える規則です。有限または可算個の値を取る離散型では、確率質量関数（PMF）pₓ(x) = P(X = x) を並べれば分布が分かります。pₓ(x) ≥ 0 で、異なる取り得る値について足すと 1 です。値の添字を区別するため、ここでは関数名を pₓ と書きます。

P(X∈A)=∑x∈ApX(x),∑xpX(x)=1

同じ値になる結果をまとめる

異なる x に対して {X = x} は互いに排反です。これらを全て合わせると Ω になるので、加法性から質量の合計は 1。A に入る値だけを合わせれば、上の確率も得られます。有限個なら有限加法性、可算個なら可算加法性を使っています。

累積分布関数（CDF）は Fₓ(t) = P(X ≤ t) です。離散型では t 以下の質量を全て足します。t を増やすと事象が広がるので Fₓ は減少しません。先ほどのコインでは、t < 0 で 0、0 ≤ t < 1 で 1/4、1 ≤ t < 2 で 3/4、t ≥ 2 で 1。値 1 における飛びの大きさ 1/2 が P(X = 1) です。

同じ分布でも、同じ写像とは限りません。一回の公平なコインで、表なら X = 1、裏なら X = 0 とし、Y = 1 − X とします。X と Y の分布は同じですが、同じ結果に対する値は必ず異なります。二つの変数が一緒にどう動くかは、同時分布が記録します。

Bernoulli分布と二項分布

成功なら 1、失敗なら 0 を取る変数をBernoulli 分布と呼びます。成功確率を p とすると P(X = 1) = p、P(X = 0) = 1 − p。条件は 0 ≤ p ≤ 1 で、p = 0、1 という必ず同じ値になる場合も含みます。

二項分布の質量

n を正の整数とします。成功確率が全て p の、相互に独立な n 回の Bernoulli 試行の成功数 S は、次の二項分布に従います。まず 0 < p < 1 で式を読みます。

P(S=k)=(nk)pk(1−p)n−k,k=0,…,n

一つの並びの重みと、並びの数を掛ける

成功位置がちょうど k 個決まった並びの確率は、成功・失敗の事象を混ぜても保たれる相互独立により pᵏ(1 − p)ⁿ⁻ᵏ です。その位置の選び方は組合せにより nCk 通り。異なる並びは排反なので、同じ重みを足せば公式になります。全ての k で足すと、二項定理から {p + (1 − p)}ⁿ = 1。確かに正規化されています。

p = 0 では P(S = 0) = 1、p = 1 では P(S = n) = 1 と直接定めます。これなら 0⁰ の扱いに頼りません。各回の成功確率が違ったり、独立でなかったりすれば、成功数がこの二項分布になるとは限りません。例えば全ての回で同じ一回のコインの結果をコピーすると、S は 0 または n だけです。

棒の高さは各整数値の確率そのものです。次章の密度の高さとは、この点が違います。実験の丸め誤差があっても、数学上の質量の合計は厳密に 1 です。

幾何分布と可算分布

独立で同じ成功確率 p の試行を続け、初成功の試行番号を T とします。ここでは幾何分布を 1、2、3、…から始まる約束で使います。条件は 0 < p ≤ 1。最初の k − 1 回が失敗し、k 回目が成功するので、0 < p < 1 では P(T = k) = (1 − p)ᵏ⁻¹p です。p = 1 なら T = 1 に確率 1 を置きます。

有限までの合計を先に求める

q = 1 − p とすると、最初の m 項の合計は p(1 + q + … + qᵐ⁻¹) = 1 − qᵐ です。0 ≤ q < 1 だから m → ∞ で 1 になり、正規化が確かめられます。この有限和と極限は幾何級数と同じ計算です。また正の整数 m について P(T > m) = qᵐ、P(T ≤ m) = 1 − qᵐ です。m = 0 なら P(T > 0) = 1 と直接分かります。実数 t ≥ 1 での CDF なら、m を t 以下の最大の整数に置き換えます。t < 1 では CDF は 0 です。

無限の試行列のモデルで「いつまでも成功しない」列を考える場合、その事象の確率は P(T > m) 以下であることが全ての m で成り立ち、従って 0 です。その事象上の T には便宜上 1 などの値を割り当てれば、実数値の確率変数として同じ幾何分布を持ちます。確率 0 の事象を取り除いたモデルでも構いません。

p = 0 を上の有限値の公式に代入すると全て 0 になり、合計は 1 でなくなります。この場合は成功が起こらず、有限の待ち回数の分布にはなりません。また「初成功までの失敗数」を数える資料では値が 0 から始まります。名前が同じでも、何を数えるかを確認します。

寄り道［応用］：二項分布の「成功」は、良い結果とは限らない

NIST の統計ハンドブックは、二項分布を二種類の結果のうち一方を数えるモデルとして説明しています。「成功」は数える側の名前なので、不具合の検出を 1 としても構いません。

例えば仮想の検査で、各製品が独立に確率 0.02 で不具合となると仮定すれば、10 個中の不具合数は二項分布です。しかし同じ製造条件が全製品へ影響するなら、独立性の点検が必要です。数を数えられることと、二項モデルの条件を満たすことを分けて考えましょう。

出典：NIST/SEMATECH：Binomial Distribution。検査数と確率は本章の仮想値です。

演習：写像と確率分布

1．同じ数へまとめる

公平な六面の骰子で、出目が 1 または 2 なら X = 0、それ以外なら X = 1 とします。PMF と CDF を求めてください。

ヒント1：値ごとの元の結果を数える

X = 0 は二つの出目、X = 1 は四つの出目をまとめます。

ヒント2：実数 t の範囲を分ける

t < 0、0 ≤ t < 1、t ≥ 1 の三つです。

解答

P(X = 0) = 2/6 = 1/3、P(X = 1) = 4/6 = 2/3 で、他の値の質量は 0 です。CDF は t < 0 で 0、0 ≤ t < 1 で 1/3、t ≥ 1 で 1 となります。元の六面が等確率でも、まとめた二値は等確率ではありません。

2．成功が高々一回

独立な 4 回の試行で成功確率が毎回 1/3 のとき、成功数 S について P(S = 1) と P(S ≤ 1) を求めてください。

ヒント1：成功位置は四通り

各並びの確率は (1/3)(2/3)³ です。

ヒント2：0 回も忘れない

P(S ≤ 1) は P(S = 0) と P(S = 1) の和です。

解答

P(S = 1) = 4 · (1/3) · (2/3)³ = 32/81 です。P(S = 0) = (2/3)⁴ = 16/81 なので P(S ≤ 1) = 48/81 = 16/27。ちょうど一回と、高々一回という事象を区別しました。

3．三回目を待つ

成功確率 p = 1/4 の幾何分布で、P(T ≥ 3) と P(T ≤ 3) を求めてください。

ヒント1：三回目以降なら

最初の二回が失敗していればよく、三回目自体の成否は問いません。

ヒント2：三回以内の補集合

T ≤ 3 の補集合は T > 3 です。

解答

P(T ≥ 3) = (3/4)² = 9/16。P(T ≤ 3) = 1 − (3/4)³ = 37/64 です。前者は T > 2、後者の補集合は T > 3 なので、指数が一つ違います。
