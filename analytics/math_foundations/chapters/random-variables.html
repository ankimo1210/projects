確率変数と確率分布

二回のコイン投げでは、表裏の並びが結果です。一方、知りたいものが「表の回数」なら、表裏と裏表を同じ数 1 としてまとめます。このまとめ方を明示すると、元の結果の確率から、知りたい数の確率を計算できます。

この章は、確率のある世界から実数への写像を作る章です。有限の場合から始め、成功回数と、初めて成功するまでの回数を比べます。

学習の目安は演習込み110–160分です。「元の結果をまとめてPMFとCDFを作る」「一定回数の成功数と初成功の番号を使い分ける」「未知の確率や試行数を逆算する」の三段階で読みます。演習1–3は基本、4–6は情報の読み替え、7–10は条件の診断と設計です。

確率変数の定義

標本空間 Ω 上の確率変数 X は、各結果 ω に実数 X(ω) を対応させる写像です。「変数自体が勝手に変わる」というより、どの結果が実現するかによって読まれる値が変わります。有限の Ω で全ての部分集合を事象にする場合は、どんな実数値写像でも構いません。

例えば二回の独立な公平なコイン投げで、Ω = {表表, 表裏, 裏表, 裏裏} とします。X を表の回数とすれば、それぞれ 2、1、1、0 です。X = 1 という事象は、元の空間では {表裏, 裏表}。したがって P(X = 1) = 1/2 であり、三つの値 0、1、2 が等確率になるわけではありません。

一般の実数のモデルでは、{ω : X(ω) ≤ t} が全ての実数 t で事象となる条件を加えます。これは可測性と呼ばれます。その一般理論と無限列の確率モデルの構成は、本冊では証明せずに使う枠組みです。有限の集合をまとめる計算は、この章で直接確かめます。

記録する数を選び、元の結果へ戻る

同じ試行でも、何を記録するかで異なる変数ができます。二回のコインで、表の回数Xのほかに「二回とも同じ面なら1、違えば0」というYを作れます。X=0とX=2はY=1に、X=1はY=0にまとまります。XからYは決まりますが、Y=1だけではX=0か2かは分かりません。記録は計算を簡単にする一方、元の情報を捨てることがあります。

「Xがある値になる確率」を求めるときは、値の個数を数える前に、その値を作る元の結果の集合を探します。等確率なのが元の結果なら、その集合の個数を数えられます。元の結果が等確率でなければ、個数の代わりにそれぞれの確率を足します。どちらも同じ加法性による手順です。

例題1：支払額を記録する自作の抽選

公平な六面の骰子を一回振り、1、2なら支払額X=0、3、4、5ならX=1、6ならX=2とします。金額の単位は仮想の1点です。取り得る額が三つだから各1/3、とする前に、各額へ集まる出目を並べます。

X=0を作るのは{1,2}なので2/6=1/3。X=1は{3,4,5}なので3/6=1/2。X=2は{6}なので1/6です。各確率が非負で、1/3+1/2+1/6=1。さらに三つの集合は重ならず、六つの出目を尽くしていることでも検算できます。

「少なくとも1点を受け取る」は{X≥1}={3,4,5,6}です。出目からは4/6=2/3、額ごとには1/2+1/6=2/3。違うまとめ方で同じ答えになります。額そのものではなく、知りたい条件を満たす元の結果へ戻るのが基本です。

確率質量関数と累積分布関数

X の分布とは、X がどの範囲に入るかの確率を与える規則です。有限または可算個の値を取る離散型では、確率質量関数（PMF）pX(x) = P(X = x) を並べれば分布が分かります。pX(x) ≥ 0 で、異なる取り得る値について足すと 1 です。どの確率変数の質量関数かを示すため、添字 X を付けて pX と書きます。

P(X∈A)=∑x∈ApX(x),∑xpX(x)=1

同じ値になる結果をまとめる

異なる x に対して {X = x} は互いに排反です。これらを全て合わせると Ω になるので、加法性から質量の合計は 1。A に入る値だけを合わせれば、上の確率も得られます。有限個なら有限加法性、可算個なら可算加法性を使っています。

累積分布関数（CDF）は Fₓ(t) = P(X ≤ t) です。離散型では t 以下の質量を全て足します。t を増やすと事象が広がるので Fₓ は減少しません。先ほどのコインでは、t < 0 で 0、0 ≤ t < 1 で 1/4、1 ≤ t < 2 で 3/4、t ≥ 2 で 1。値 1 における飛びの大きさ 1/2 が P(X = 1) です。

同じ分布でも、同じ写像とは限りません。一回の公平なコインで、表なら X = 1、裏なら X = 0 とし、Y = 1 − X とします。X と Y の分布は同じですが、同じ結果に対する値は必ず異なります。二つの変数が一緒にどう動くかは、同時分布が記録します。

例題2：二つの似た区間は同じか

P(0<X≤1)は額1だけなので1/2です。CDFではF(1)−F(0)=5/6−1/3=1/2。引いたF(0)にはX=0の質量も入るため、下端0は除かれます。一方P(0≤X≤1)=1/3+1/2=5/6。下端を含むかで1/3違います。

一般にa<bに対し、{X≤b}は{X≤a}と{a<X≤b}の排反な和です。従ってP(a<X≤b)=F(b)−F(a)。下端も含めたい有限離散の場合は、aより小さい値の質量だけを引きます。端点の違いを暗記するより、何を引いたかを集合で確かめると誤りにくくなります。

表はこの三値モデルの計算を整理したもので、一般のCDFが三段になるという意味ではありません。次章の密度を持つ分布でもCDFは使いますが、そこでは一点の質量が0になる点が異なります。

Bernoulli分布と二項分布

成功なら1、失敗なら0と記録する確率変数をBernoulli変数といい、その分布をBernoulli分布と呼びます。成功確率を p とすると P(X = 1) = p、P(X = 0) = 1 − p。条件は 0 ≤ p ≤ 1 で、p = 0、1 という必ず同じ値になる場合も含みます。

次は成功数が0回、1回、…となる重みを作ります。分布として使うには、それらの確率をすべて足すと1になることも必要です。このように全体の重みを1にそろえることを正規化と呼び、下の証明ではその確認も行います。

二項分布の質量

n を正の整数とします。成功確率が全て p の、相互に独立な n 回の Bernoulli 試行の成功数 S は、次の二項分布に従います。まず 0 < p < 1 で式を読みます。

P(S=k)=(nk)pk(1−p)n−k,k=0,…,n

一つの並びの重みと、並びの数を掛ける

成功位置がちょうど k 個決まった並びの確率は、成功・失敗の事象を混ぜても保たれる相互独立により pᵏ(1 − p)ⁿ⁻ᵏ です。その位置の選び方は組合せにより nCk 通り。異なる並びは排反なので、同じ重みを足せば公式になります。全ての k で足すと、二項定理から {p + (1 − p)}ⁿ = 1。確かに正規化されています。

p = 0 では P(S = 0) = 1、p = 1 では P(S = n) = 1 と直接定めます。これなら 0⁰ の扱いに頼りません。各回の成功確率が違ったり、独立でなかったりすれば、成功数がこの二項分布になるとは限りません。例えば全ての回で同じ一回のコインの結果をコピーすると、S は 0 または n だけです。

例題3：三回中、少なくとも一回成功する確率

独立な三回の試行で毎回p=1/4とします。S≥1の各質量を足してもよいですが、「一回も成功しない」という一つの事象の補集合を使う方が短くなります。P(S≥1)=1−P(S=0)=1−(3/4)³=37/64です。

全ての質量でも検算します。k=0,1,2,3の順に、27/64、3(1/4)(3/4)²=27/64、3(1/4)²(3/4)=9/64、1/64。合計64/64で、後ろ三つの和も37/64です。P(S=1)=27/64は「一回以上」の37/64とは違います。条件が成功数の一点か範囲かを、式の前に書きます。

ここで三回とも同じ一回の成否をコピーしたら、各回の成功確率は同じ1/4でも、S=0が3/4、S=3が1/4になります。P(S≥1)も1/4です。独立性がないモデルへ二項の係数を機械的に使えないことを、同じ成功確率の二モデルで確かめられました。

棒の高さは各整数値の確率そのものです。次章の密度の高さとは、この点が違います。実験の丸め誤差があっても、数学上の質量の合計は厳密に 1 です。

幾何分布と可算分布

独立で同じ成功確率 p の試行を続けます。条件は 0 < p ≤ 1。初めて成功した試行の番号を実数値の確率変数 T として記録するには、成功しない列を含むモデルなら、その列にも形式上の値を決める必要があります。

「いつまでも成功しない」事象は、任意の正の整数 m について「最初の m 回が全て失敗する」事象に含まれます。後者の確率は (1 − p)ᵐ なので、前者の確率は全ての m について (1 − p)ᵐ 以下です。0 ≤ 1 − p < 1 より、m → ∞ でこの上界は 0 になるため、無成功事象の確率は 0 です。その事象上では便宜上 T = 1、成功する列では初成功の番号を T の値と定めます。これで実数値の確率変数となり、確率 0 上の値の決め方は分布を変えません。確率 0 の事象を取り除いたモデルでも構いません。

ここでは、この T の分布を 1、2、3、…から始まる幾何分布と呼びます。最初の k − 1 回が失敗し、k 回目が成功するので、0 < p < 1 では P(T = k) = (1 − p)ᵏ⁻¹p です。p = 1 なら T = 1 に確率 1 を置きます。

有限までの合計を先に求める

q = 1 − p とすると、最初の m 項の合計は p(1 + q + … + qᵐ⁻¹) = 1 − qᵐ です。0 ≤ q < 1 だから m → ∞ で 1 になり、正規化が確かめられます。この有限和と極限は幾何級数と同じ計算です。また正の整数 m について P(T > m) = qᵐ、P(T ≤ m) = 1 − qᵐ です。m = 0 なら P(T > 0) = 1 と直接分かります。実数 t ≥ 1 での CDF なら、m を t 以下の最大の整数に置き換えます。t < 1 では CDF は 0 です。

例題4：初成功の期限から、必要な回数を決める

成功確率p=1/3の独立な試行を、最大m回まで行う自作モデルです。「m回以内に少なくとも一度成功する確率を9/10以上にしたい」なら、最初のm回が全て失敗する確率を1/10以下にすればよいので、(2/3)ᵐ≤1/10を解きます。

対数でm≥log(1/10)/log(2/3)と候補を得られます。分母が負なので不等号の向きが変わる点に注意します。最小性は隣り合う整数で確かめるのが確実です。m=5では(2/3)⁵=32/243>1/10、m=6では64/729<1/10。失敗確率はmとともに減るので、最小は6回です。成功確率もそれぞれ211/243、665/729となり、目標の両側にあります。

「六回目に初めて成功」は(2/3)⁵(1/3)=32/729で、六回以内に成功する665/729とは別です。また既に二回失敗した後、さらに三回とも失敗する条件付き確率はP(T>5)/P(T>2)=(2/3)⁵/(2/3)²=8/27。分母が正であることと、残り三回という指数を確認します。

p = 0 を上の有限値の公式に代入すると全て 0 になり、合計は 1 でなくなります。この場合は成功が起こらず、有限の待ち回数の分布にはなりません。また「初成功までの失敗数」を数える資料では値が 0 から始まります。名前が同じでも、何を数えるかを確認します。

寄り道［応用］：二項分布の「成功」は、良い結果とは限らない

NIST の統計ハンドブックは、二項分布を二種類の結果のうち一方を数えるモデルとして説明しています。「成功」は数える側の名前なので、不具合の検出を 1 としても構いません。

例えば仮想の検査で、各製品が独立に確率 0.02 で不具合となると仮定すれば、10 個中の不具合数は二項分布です。しかし同じ製造条件が全製品へ影響するなら、独立性の点検が必要です。数を数えられることと、二項モデルの条件を満たすことを分けて考えましょう。

出典：NIST/SEMATECH：Binomial Distribution。検査数と確率は本章の仮想値です。

演習：写像と確率分布

1．同じ数へまとめる

公平な六面の骰子で、出目が 1 または 2 なら X = 0、それ以外なら X = 1 とします。PMF と CDF を求めてください。

ヒント1：値ごとの元の結果を数える

X = 0 は二つの出目、X = 1 は四つの出目をまとめます。

ヒント2：実数 t の範囲を分ける

t < 0、0 ≤ t < 1、t ≥ 1 の三つです。

解答

P(X = 0) = 2/6 = 1/3、P(X = 1) = 4/6 = 2/3 で、他の値の質量は 0 です。CDF は t < 0 で 0、0 ≤ t < 1 で 1/3、t ≥ 1 で 1 となります。元の六面が等確率でも、まとめた二値は等確率ではありません。

2．成功が高々一回

独立な 4 回の試行で成功確率が毎回 1/3 のとき、成功数 S について P(S = 1) と P(S ≤ 1) を求めてください。

ヒント1：成功位置は四通り

各並びの確率は (1/3)(2/3)³ です。

ヒント2：0 回も忘れない

P(S ≤ 1) は P(S = 0) と P(S = 1) の和です。

解答

P(S = 1) = 4 · (1/3) · (2/3)³ = 32/81 です。P(S = 0) = (2/3)⁴ = 16/81 なので P(S ≤ 1) = 48/81 = 16/27。ちょうど一回と、高々一回という事象を区別しました。

3．三回目を待つ

成功確率 p = 1/4 の幾何分布で、P(T ≥ 3) と P(T ≤ 3) を求めてください。

ヒント1：三回目以降なら

最初の二回が失敗していればよく、三回目自体の成否は問いません。

ヒント2：三回以内の補集合

T ≤ 3 の補集合は T > 3 です。

解答

P(T ≥ 3) = (3/4)² = 9/16。P(T ≤ 3) = 1 − (3/4)³ = 37/64 です。前者は T > 2、後者の補集合は T > 3 なので、指数が一つ違います。

4．等確率でない元の結果

Ω={a,b,c,d}の確率が順に1/10、2/10、3/10、4/10です。X(a)=X(d)=0、X(b)=1、X(c)=2とします。PMFとF(1)を求め、「0に写る結果は二つだから確率1/2」という説明の問題点も述べてください。

ヒント1

個数ではなく元の確率を足します。

ヒント2

P(X=0)=P({a,d})です。

解答

質量は0に5/10=1/2、1に2/10=1/5、2に3/10です。F(1)=1/2+1/5=7/10、総和は1です。0の確率は偶然1/2ですが、結果二つという個数だけでは求まりません。例えば{a,b}の二つなら3/10です。正しい数値と正しい理由を区別します。

5．累積から質量を復元する

F(t)はt<−1で0、−1≤t<0で1/5、0≤t<2で3/5、2≤tで1です。各値の質量、P(0<X≤2)、P(0≤X≤2)を求めてください。

ヒント1

各点の質量は、その点での増加量です。

ヒント2

0での増加量は3/5−1/5です。

解答

質量は−1に1/5、0に2/5、2に2/5で、合計1。P(0<X≤2)=1−3/5=2/5です。下端も含めるとP(0≤X≤2)=2/5+2/5=4/5。CDFの差は下端の質量を除くことが、復元したPMFからも確認できます。

6．二乗で失う情報

Xは−2、−1、1、2を順に確率1/8、3/8、1/4、1/4で取ります。Y=X²のPMFを求め、Yの分布だけでP(X>0)を決められるか説明してください。

ヒント1

二乗すると同じ値になる入力をまとめます。

ヒント2

Y=1はX=−1と1、Y=4はX=−2と2から来ます。

解答

P(Y=1)=3/8+1/4=5/8、P(Y=4)=1/8+1/4=3/8で正規化されています。元のP(X>0)=1/2ですが、Yの分布だけでは符号の分け方を復元できません。例えばXを正の1、2だけに置いて確率5/8、3/8としてもYは同じ分布で、P(X>0)=1になります。

7．二項モデルの誤診断

公平なコインを一回振り、表なら三つのランプを全て点灯、裏なら全て消灯します。点灯数Sに二項分布n=3、p=1/2を使ってよいですか。実際のPMFとP(S=1)を求めて診断してください。

ヒント1

各ランプの点灯確率は1/2ですが、一緒の動きも確認します。

ヒント2

Sは0か3しか取りません。

解答

実際にはP(S=0)=P(S=3)=1/2、P(S=1)=P(S=2)=0です。各ランプは同時に動くため相互独立ではありません。二項モデルならP(S=1)=3(1/2)³=3/8となり、実際の0と食い違います。同じ周辺の成功確率だけでは二項分布を保証できません。

8．ゼロ回の確率から率を逆算する

独立で同じ成功確率pの二回の試行で、P(S=0)=9/16です。pを決め、P(S=1)も求めてください。

ヒント1

(1−p)²=9/16を解きます。

ヒント2

0≤p≤1なので1−pは非負です。

解答

1−p=3/4からp=1/4です。負の平方根−3/4は確率条件を満たしません。P(S=1)=2(1/4)(3/4)=3/8。P(S=2)=1/16と合わせ、9/16+6/16+1/16=1で検算できます。

9．成功の保証と有限の期限

p=1/2の幾何分布で、P(T≤m)≥7/8となる最小の整数mを求めてください。また、有限のmでP(T≤m)=1にできるでしょうか。

ヒント1

P(T>m)=2⁻ᵐを使います。

ヒント2

目標の等号を含むのでm=3を除かないでください。

解答

1−2⁻ᵐ≥7/8は2⁻ᵐ≤1/8と同値です。m=2では3/4、m=3では7/8なので最小は3。どの有限mでも2⁻ᵐ>0だから、確率1の有限の期限はありません。一方m→∞では2⁻ᵐ→0なので、いつか成功する確率は1です。有限の期限と無限の極限は違います。

10．条件を満たす三値分布を設計する

値0、1、2を取る分布でP(X=2)=2P(X=0)、F(1)≥3/4とします。全ての候補を一つのパラメータで表し、その中でP(X≥1)を最小にする分布を選んでください。質量0の値も許します。

ヒント1

P(X=0)=aと置き、総和1を使います。

ヒント2

質量はa、1−3a、2aで、F(1)=1−2aです。

解答

非負性から0≤a≤1/3、累積の条件から1−2a≥3/4、つまりa≤1/8です。従って全候補は0≤a≤1/8で質量(a,1−3a,2a)。P(X≥1)=1−aを最小にするのはa=1/8で、質量は(1/8,5/8,1/4)、最小確率は7/8です。総和1とF(1)=3/4を満たし、比の条件も1/4=2(1/8)で確認できます。
