曲線とパラメータの役割

道を描く式には、形だけでなく進む順序や速さも入っています。長さは歩く速さによらない一方、同じ道を二周すれば二倍になるはずです。曲線の定義に何を含め、積分にどの係数を掛ければ、この二つを両立できるでしょう。

復習はベクトルの長さ、微分、置換積分です。複素解析を学んだ読者は複素平面の道と対比できますが、必修にはしません。

曲線のパラメータ表示と接ベクトル

区分 C¹ 曲線r : [a, b] → ℝ³ は連続で、a = t₀ < t₁ < … < tₙ = b という有限個の分割により、各閉部分区間で C¹ になるものとします。各部分の内部の導関数は端点まで連続に延長でき、端点ではその片側導関数と解釈します。折れ線の角では左右の導関数が違って構いません。積分は各部分の積分の和です。

r(a) は始点、r(b) は終点で、一致すれば閉曲線です。r の像は通った点の集合ですが、曲線には順序と繰り返しも含めます。r(t) = (cos t, sin t, 0) を [0, 2π] と [0, 4π] で使うと像は同じ円でも、一周と二周の違う曲線です。

C¹ の部分で r′(t) を速度、‖r′(t)‖ を速さと呼びます。単位接ベクトル T(t) = r′(t)/‖r′(t)‖ は r′(t) ≠ 0 の点でのみ定義します。曲線がその点で微分可能でも、速度0ならこの式は使えません。r(t) = (t³, 0, 0) は原点を滑らかな直線上で通りますが、t = 0 の速度は0です。単位接ベクトルの式の不成立と、像の直線の存在は別の話です。

弧長の定義と再パラメータ化

区分 C¹ 曲線の弧長を L(r) = ∫ₐᵇ‖r′(t)‖dt と定めます。小さな移動は r(t + Δt) − r(t) ≈ r′(t)Δt なので、その長さの一次近似を足す定義です。折線近似の長さの上限とこの積分が一致する定理は、ここでは未証明です。以下の計算はこの積分による定義から進めます。

速さを変えると、積分の幅も変わる

η(s) = r(ψ(s)) とし、ψ : [c, d] → [a, b] は向きを保つ増加全単射で、有限分割の各部分で C¹、ψ′ > 0、導関数が各端まで延長できるとします。分割は r の分割点の逆像でも細かくしておきます。連鎖律で ‖η′(s)‖ = ‖r′(ψ(s))‖ψ′(s)。各部分で一変数の置換積分を使い、和を取れば L(η) = L(r) です。これを本章で扱う正則な再パラメータ化の十分条件とします。

逆向きの曲線 −r は s ↦ r(a + b − s)（s ∈ [a, b]）。速度には負号が付きますが、長さを取ると消えるので L(−r) = L(r)。一方、連結した二本の曲線の長さは和で、一周を二回たどれば二倍です。

半径 R > 0 の円 r(t) = (R cos t, R sin t, 0)、0 ≤ t ≤ 2π では、速さは一定の R、弧長は 2πR です。らせん r(t) = (R cos t, R sin t, ht) では速さは √(R² + h²)、同じ範囲の弧長は 2π√(R² + h²)。円への投影が同じでも、上下の移動は弧長に含まれます。

曲線の像で連続なスカラー関数 f に対して、スカラー線積分を次で定めます。記号 ds は正の長さ要素を表し、s という特別なパラメータを既に選んだという意味ではありません。f が負でも積分は定義でき、非負の密度なら線に分布する量を集めるモデルになります。

前節の連鎖律と置換を f(r) にも適用すれば、向きを保つ正則な再パラメータ化で値は変わりません。逆向きでも速さは同じなので ∫−Cf ds = ∫Cf ds。曲線 C という記号には重複してたどる回数も含めます。同じ像だからといって二重計数が消えるわけではありません。

寄り道［自作モデル］：同じ針金を二度数えるとは

単位円上で密度を1とするモデルでは、一周のスカラー線積分は2π、二周なら4πです。一方、物体として一つの円形の線を数えるなら通常は一度だけ覆う曲線を選びます。二周の式を選んでから「同じ像だから2π」と直すのは、定義を途中で替えることになります。

パラメータ表示は、形を描く装置であると同時に、何回数えるかを決める装置でもあります。後の曲面積でも、重なりの条件が必要になる理由です。

出典：一定密度と円のパラメータ表示による自作モデルです。

演習：曲線・弧長・線密度

1．らせんの速さと長さ

r(t) = (3cos t, 3sin t, 4t)、0 ≤ t ≤ 2π の単位接ベクトルと弧長を求めてください。

ヒント1：三成分を微分する

r′ = (−3sin t, 3cos t, 4)。三角関数の二乗和を使います。

ヒント2：速さは一定

速さの二乗は 9 + 16 です。

解答

速さは5で常に非零。T(t) = (−3sin t, 3cos t, 4)/5、L = ∫₀²π5dt = 10π です。xy 平面への投影の長さ6πとは異なります。

2．非等速の線分と密度

r(t) = (t², 0, 0)、0 ≤ t ≤ 1、f(x, y, z) = x とします。∫Cf ds と ∫₀¹f(r(t))dt を比べ、逆向きの線積分も答えてください。

ヒント1：長さの要素

この範囲で ‖r′(t)‖ = 2t です。

ヒント2：密度も代入する

f(r(t)) = t²。線積分の被積分関数は 2t³ です。

解答

∫Cf ds = ∫₀¹2t³dt = 1/2。一方、時間積分は ∫₀¹t²dt = 1/3。逆向きのスカラー線積分も1/2です。始点の速度が0でも、速さの積分による定義は有効です。

3．角を持つ道

(0, 0, 0) から (1, 0, 0)、続いて (1, 1, 0) へ直線で進む道 C で、f(x, y, z) = x + y のスカラー線積分を求めてください。角で単位接ベクトルは一つに決まりますか。

ヒント1：二本に分ける

最初は r₁(t) = (t, 0, 0)、次は r₂(t) = (1, t, 0)、各0 ≤ t ≤ 1。

ヒント2：各部分の速さ

どちらも速さ1です。密度はそれぞれ t と 1 + t。

解答

第一部分は1/2、第二部分は3/2で、合計2。角では入る速度 (1, 0, 0) と出る速度 (0, 1, 0) が違い、二側の微分も一つの単位接ベクトルも定まりません。有限個の角は部分ごとに積分すればよく、積分値を妨げません。
