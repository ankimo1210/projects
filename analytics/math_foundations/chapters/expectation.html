期待値と重み付き平均

公平な骰子の出目には 1 から 6 があります。全ての値を同じ重みで平均すると 3.5 ですが、3.5 の目はありません。ここで欲しいのは「次に出る数の予言」ではなく、分布全体の中心を表す一つの数です。

値によって起こりやすさが違うなら、その確率を重みにして平均します。これを先に定義し、実際の繰り返しの平均との関係は、最後の大数の法則で条件を付けて証明します。

学習の目安は演習込み120–180分です。まず分布の重みを残して平均し、次に支払額の変換や個数の数え方を変え、最後に無限の和と積分の条件を確かめます。演習1–3は基本、4–7は逆算・診断・指示変数、8–10は収束条件と支払方法の設計です。

離散確率変数の期待値

まず有限の標本空間 Ω で、結果 ω の確率を q(ω) とします。確率変数 X の期待値を、全ての結果について X(ω)q(ω) を足した値と定義します。E[X] と書き、平均 μ と呼ぶこともあります。

E[X]=∑ω∈ΩX(ω)q(ω)=∑xxpX(x)

結果で足しても、値でまとめても同じ

X(ω) = x となる結果を一つの組にまとめます。その組の和は x ∑q(ω) = xP(X = x)。異なる x ごとにこれを足せば、右の式になります。有限和の順序を変えただけであり、どの値を取るかの確率、つまり分布から期待値が決まることが分かります。

例えば値 0、2、5 の確率が 1/2、1/4、1/4 なら、E[X] = 0 · (1/2) + 2 · (1/4) + 5 · (1/4) = 7/4 です。値だけを単純に足して 3 で割るのではありません。定数 c の期待値は c、また X の最小値と最大値の間に E[X] が入ります。これは、確率の重みが非負で合計 1 だからです。

関数 g で値を変えた変数も、同じ重みで平均できます。新しい変数 g(X) の分布を作り直す必要はありません。

E[g(X)]=∑xg(x)pX(x)

この式も、同じ値を持つ結果をまとめる証明から従います。ただし一般に E[g(X)] と g(E[X]) は等しくありません。二乗してから平均することと、平均してから二乗することは別の操作です。

平均する前に、何を支払うかを決める

上の0、2、5の例を、自作の抽選の受取額X（単位は点）と読みます。知りたいものが受取額ならxに、受取額の二乗ならx²に確率を掛けます。確率の列を変えず、記録する関数だけを変えることが、E[g(X)]の式の使いどころです。

例題1：平均額に上限を掛けてよいか

各回の受取額を最大2点にするなら、0、2、5は0、2、2へ変わります。従ってE[min(X,2)]=0(1/2)+2(1/4)+2(1/4)=1点です。先に平均してから上限を掛けたmin(E[X],2)=min(7/4,2)=7/4とは異なります。平均額の上限を決めることと、各回の上限を決めることは、別の支払規則です。

別解では、上限を超えた分を元の額から引きます。超過分はX=5のときだけ3点なので、期待される超過分は3(1/4)=3/4点。7/4−3/4=1点で一致します。さらに全ての結果で0≤min(X,2)≤Xなので、平均も0以上7/4以下になるはずです。算出した1はこの範囲に入ります。

表の各寄与は平均を作るための量で、その値を一回に受け取るとは限りません。上限後の1点も実際には取らない値です。「起こる値の候補」と「重み付き平均」を最後まで区別します。

期待値の線形性

有限の線形性と単調性

同じ有限の確率モデル上の X、Y と実数 a、b に対し、E[aX + bY] = aE[X] + bE[Y] です。独立性は仮定しません。また全ての結果で X ≤ Y なら E[X] ≤ E[Y] です。

一つの結果での計算を、重み付きで足す

定義へ代入すると、E[aX + bY] = ∑{aX(ω) + bY(ω)}q(ω) = a∑X(ω)q(ω) + b∑Y(ω)q(ω)。各結果に同じ重みを掛けて分配しただけで、X と Y の関係は使いませんでした。また X(ω)q(ω) ≤ Y(ω)q(ω) を足せば、単調性が出ます。

繰り返して使えば、有限個の和の期待値は期待値の和です。例えば Y = −X のように完全に結び付いていても、E[X + Y] = E[X] − E[X] = 0。対して、積について E[XY] = E[X]E[Y] と言うには追加の条件が必要です。その条件は同時分布の章で調べます。

参加料と平均の損益を、同じモデルで比べる

例題2：平均の損益が0になる参加料

前の抽選の受取額Xから固定参加料c点を引いた、純受取額をZ=X−cとします。参加料は毎回同じ定数なので、線形性によりE[Z]=7/4−c。平均の純受取額を0にするのはc=7/4点です。この意味で平均だけを釣り合わせる設定を、ここでは「平均上の公平」と呼びます。個々の参加者に同じ額を返すという意味ではありません。

c=7/4で、純受取額は−7/4、1/4、13/4、確率は1/2、1/4、1/4です。直接平均すると−7/8+1/16+13/16=0で、定義からも検算できます。正の純受取額を得る確率は1/2ですが、最も悪い損失や大きい利益は同じ大きさではありません。

上限2点の抽選へ規則を変えると、平均受取額は例題1より1点なので、平均上の公平な参加料も1点に変わります。元の7/4点の参加料をそのまま使えば平均純受取額は1−7/4=−3/4点。分布や支払関数が変われば、以前の平均を流用できません。

平均0という結果だけから、必ず損しないことや、各回の増減が小さいことは言えません。そうした問いには分布の別の情報が必要です。次章では平均からの離れ方を二乗で測ります。

指示変数による計数

事象 A が起きたら 1、起きなければ 0 を取る指示変数を Iₐ と書きます。定義から E[Iₐ] = 1 · P(A) + 0 · P(A の補集合) = P(A) です。「起きた個数」を指示変数の和として書けば、その平均は確率を足すだけになります。

E[∑i=1nIAi]=∑i=1nP(Ai)

独立で同じ成功確率 p の n 回の成功数 S は、Bernoulli 変数 n 個の和なので E[S] = np。これで二項分布の平均が導けました。実は平均の式だけなら独立性は不要です。各回の成功確率が p なら、どのような依存があっても平均は np。一方、成功数の分布全体が二項分布になることを証明する際には、独立性を使いました。独立でなければ二項分布になるとは限りません。

例えば一回の公平なコインの結果を 10 回コピーした成功数は、0 または 10 です。それでも平均は 5。独立な 10 回の成功数も平均は 5 ですが、分布の形は違います。平均だけで、ばらつきや依存関係を復元することはできません。

複雑な分布を作る前に、数える対象を分ける

例題3：二つの箱に何個の箱が使われるか

区別できる三つの玉を、それぞれ独立に、確率1/2ずつで二つの箱A、Bへ入れる自作モデルです。玉の個数ではなく、少なくとも一つ玉が入った箱の個数Nを平均したいとします。玉は三つでも箱は二つなので、Nを玉三つの成否の和としてはいけません。数えたい箱に一つずつ指示変数を作ります。

Aが空でないならIₐ=1、そうでなければ0。Bも同様にIBと置くとN=Iₐ+IBです。Aが空になるのは三つともBへ入る場合だけで、その確率は(1/2)³=1/8。従ってP(Aが空でない)=7/8、Bも同じです。E[N]=7/8+7/8=7/4個です。

全8通りの配置でも検算できます。三つとも同じ箱に入るAAA、BBBの2通りではN=1、それ以外の6通りではN=2。従ってE[N]=1(2/8)+2(6/8)=14/8=7/4。一つ以上二つ以下という範囲にも入ります。

IₐとIBは独立ではありません。Aが空ならBは必ず空でないからです。玉ごとの独立性は「Aが空の確率が1/8」という積を作るところで使い、箱の指示変数の期待値を足すところでは使っていません。必要な条件を計算の場所ごとに切り分けます。

一般に、分布全体を知らなくても、数える対象が有限個あり、それぞれが数えられる確率が分かれば平均の個数は求まります。一方、Nの各値の確率や散らばりを知るには、それぞれの対象が一緒に数えられる関係も調べる必要があります。

可算分布の期待値と絶対収束

可算個の値を取る X では、絶対収束する条件 ∑|x|pₓ(x) < ∞ の下で、E[X] = ∑xpₓ(x) と定めます。有限の期待値を持つ、または可積分である、と言います。絶対収束級数の並べ替え・まとめ直しで和が変わらない定理を、ここでは証明せず借用します。この定理により、値の並べ方に依存しない平均を定められます。g(X) なら ∑|g(x)|pₓ(x) < ∞ を確かめます。

非負の変数では、非負項の和が発散した場合に期待値を +∞ と呼ぶこともできます。ただし有限の実数の平均ではありません。正負両方を持つ場合、正の部分と負の部分がともに無限大なら、∞ − ∞ を数として計算することはできません。

反例として、各 k = 1、2、…に対し、X = 2ᵏ と X = −2ᵏ のそれぞれへ確率 2⁻⁽ᵏ⁺¹⁾ を置きます。正負を合わせた確率は各 k で 2⁻ᵏ なので、全確率は幾何級数の和 1 です。各 k の正の寄与も負の寄与の大きさも 1/2 なので、どちらの合計も発散します。「正負を一組にして 0」とする計算では、期待値 0 を定義できません。

級数と絶対収束の意味は級数の章で確認できます。そこで並べ替えの定理を証明済みとしているわけではありません。無限での条件は、有限和を無条件に繰り返せなくなる箇所に付いています。

密度を用いた期待値

前章の密度 f を持つ X について、∫|x|f(x) dx < ∞ のとき、期待値を次の積分で定めます。全実数上の絶対可積分性を要求し、正の側と負の側を対称に打ち消す極限で代用しません。g(X) の平均も、∫|g(x)|f(x) dx < ∞ の下で求めます。g(X) の平均を元の密度 f で計算できる変換公式は、ここでは証明せず借用します。ここで使う積分が通常または広義積分として定義できる関数を扱います。

E[X]=∫−∞∞xf(x)dx,E[g(X)]=∫−∞∞g(x)f(x)dx

[a, b] の一様分布なら E[X] = ∫ₐᵇ x/(b − a) dx = (b² − a²)/{2(b − a)} = (a + b)/2 です。0 ≤ x ≤ 1 で f(x) = 2x なら、E[X] = ∫₀¹ 2x² dx = 2/3。同じ [0, 1] の中でも、大きな x の方へ多くの重みがあるため、一様分布の平均 1/2 より大きくなります。これらは有界区間で有界な被積分関数なので、絶対可積分です。

一般の確率変数に対する積分の構成、g(X) の積分公式、一般の可積分な変数の線形性・単調性は、確率論の標準的な枠組みとして本冊では未証明で使います。有限離散については上で証明済みです。一つの密度に関する積分の計算規則は、既存の積分の性質から確かめられます。後の不等式と大数の法則も、有限離散ではその証明だけで読め、一般の場合はこの積分の枠組みを前提とします。

密度のある待ち時間と、支払いの上限

例題4：平均待ち時間と、上限付きの支払額

時間Xを、x≥0で密度f(x)=e⁻ˣ、それ以外で0の指数分布とします。時間の単位を一つ固定した理想化モデルです。まず期待値が有限かを、有限の端Rまで積分して確かめます。部分積分により∫₀ᴿxe⁻ˣdx=[−xe⁻ˣ]₀ᴿ+∫₀ᴿe⁻ˣdx=1−(R+1)e⁻ᴿです。

R→∞でRe⁻ᴿ→0、e⁻ᴿ→0なのでE[X]=1です。例えばR>0でeᴿ≥R²/2という指数関数の標準的な評価を使えば、0≤Re⁻ᴿ≤2/R→0と確認できます。Xが非負なので、同じ積分がE[|X|]にもなり、有限の平均を使う条件が満たされました。

待ち時間1単位につき1点を支払い、支払総額を1点までにするなら、受取額はg(X)=min(X,1)です。x≤1ではg(x)=x、x>1ではg(x)=1なので、式が変わる1で積分を分けます。E[g(X)]=∫₀¹xe⁻ˣdx+∫₁∞e⁻ˣdx=(1−2/e)+1/e=1−1/e≈0.6321点です。

一方g(E[X])=min(1,1)=1点。非線形な支払いを平均へ直接掛けると、ここでも違う値になります。検算として、0≤g(X)≤1、g(X)≤Xから、0≤E[g(X)]≤1のはずで、答えは範囲内です。絶対可積分性も|g(X)|≤1から確かめられます。平均が有限なことと、変換後の平均が同じになることは別です。

例題の部分積分は通常の広義積分の計算です。一般のg(X)を元の密度で平均できるという枠組み自体は前節で借用した公式です。有限離散で証明した事実と、一般の積分で借りた事実の境目を残しています。

寄り道［見方］：平均は、分布を支えるつり合いの点

MIT の確率入門は、期待値を確率の質量がつり合う位置として説明しています。この見方なら、期待値が実際には取らない値でも困らないことが分かります。

例えば自作の分布として、位置 0 に重み 0.8、位置 10 に重み 0.2 を置くと、平均は 2 です。2 から左右への距離に重みを掛ければ、左は 2 · 0.8、右は 8 · 0.2 で同じになります。位置 2 に質量がなくても、つり合いはそこで取れます。「最も起こりやすい値 0」と「平均 2」は、別の問いの答えなのです。

出典：MIT OpenCourseWare 18.05：Discrete Random Variables: Expected Value、2.1。位置と重みは本章の自作例です。

演習：期待値と線形性

1．平均と二乗の順序

X は −1、1 をそれぞれ確率 1/2 で取ります。E[X]、E[X²]、(E[X])² を求めてください。

ヒント1：値ごとに重みを掛ける

平均では −1 と 1、二乗の平均では 1 と 1 を使います。

ヒント2：先に平均したら

E[X] を計算してから、その一つの数を二乗します。

解答

E[X] = (−1)/2 + 1/2 = 0。E[X²] = 1/2 + 1/2 = 1、(E[X])² = 0² = 0 です。従って E[g(X)] = g(E[X]) は g(x) = x² ですでに成立しません。

2．戻さない抽選でも

10 枚中 2 枚が赤い札から、一様に、戻さず順に 3 枚引きます。各位置の札が赤である確率は 2/10 です。赤い札の枚数 N の期待値を求めてください。位置どうしは独立である必要がありますか。

ヒント1：三つの指示変数を作る

i 番目が赤なら Iᵢ = 1 とすると、N = I₁ + I₂ + I₃ です。

ヒント2：期待値の和を使う

各 E[Iᵢ] は、与えられた赤の確率です。

解答

E[N] = E[I₁] + E[I₂] + E[I₃] = 3 · (2/10) = 3/5 です。線形性には独立性が不要です。実際、一枚目が赤なら二枚目の赤の確率は 1/9 となり、無条件の 1/5 と違うので独立ではありません。それでも期待値の計算は成立します。

3．面積に位置を掛ける

0 ≤ x ≤ 1 で密度 f(x) = 2x を持つ X の E[X] と E[X²] を求めてください。

ヒント1：密度に掛ける関数を変える

一つ目は x、二つ目は x² を f(x) に掛けます。

ヒント2：べきの積分を使う

∫₀¹ 2x² dx と ∫₀¹ 2x³ dx を計算します。

解答

E[X] = [2x³/3]₀¹ = 2/3、E[X²] = [x⁴/2]₀¹ = 1/2 です。両方とも有界区間の有界な関数の積分なので、絶対可積分性も満たします。E[X²] = 1/2 と (E[X])² = 4/9 は異なります。

4．平均から確率を逆算する

Xは0、3、9を確率1/2、r、1/2−rで取ります。E[X]=3となるrを求め、確率の条件も確認してください。

ヒント1

重み付き平均をrの式にします。

ヒント2

3r+9(1/2−r)=3です。

解答

3r+9/2−9r=3より6r=3/2、r=1/4です。従って確率は(1/2,1/4,1/4)で全て非負、総和1です。直接の平均も3/4+9/4=3。方程式の解が出ても0≤r≤1/2を満たすかを別に確かめます。

5．非線形な利益の計算を診断する

Xは0を確率3/4、8を確率1/4で取ります。g(X)=max(X−3,0)の期待値を求め、「E[X]=2だからE[g(X)]=max(2−3,0)=0」という計算を診断してください。

ヒント1

各回のXに関数を掛けてから平均します。

ヒント2

g(0)=0、g(8)=5です。

解答

E[g(X)]=0(3/4)+5(1/4)=5/4です。g(E[X])=0とは違います。線形性が保証するのは実数a,bのaX+bという形であり、maxを平均の外へ無条件に出すことではありません。0≤g(X)≤Xなので、平均5/4が0以上2以下になることでも検算できます。

6．完全に連動する個数の平均

公平な一回のコインで、表なら四つのランプを全て点灯、裏なら全て消灯します。点灯数Nの平均を、指示変数の和と実際の分布の二通りで求め、独立性が必要か説明してください。

ヒント1

各ランプの点灯確率は1/2です。

ヒント2

Nは0か4をそれぞれ1/2で取ります。

解答

四つの点灯指示変数の期待値を足すとE[N]=4(1/2)=2です。実際の分布でも0(1/2)+4(1/2)=2。ランプは完全に連動しており独立ではありませんが、平均を足すことには影響しません。分布は独立な四試行の二項分布とは異なります。

7．三つの箱へ四つの玉

区別できる四つの玉を、独立に、それぞれ確率1/3ずつで三つの箱へ入れます。空でない箱の個数Nの期待値を求めてください。

ヒント1

箱に一つずつ指示変数を作り、空になる補集合を使います。

ヒント2

一つの箱が空の確率は(2/3)⁴です。

解答

一つの箱が空でない確率は1−16/81=65/81。三箱の指示変数を足してE[N]=3(65/81)=65/27≈2.4074個です。必ず一箱以上三箱以下なので、この平均もその間にあります。独立性は玉四つから空の確率を積で作るために使い、三箱の指示変数どうしの独立性は必要ありません。

8．平均が有限でも二乗はどうか

k=1,2,…に対しX=2ᵏに確率3/4ᵏを置きます。正規化、E[X]、E[X²]を調べてください。有限の平均を持つことから二乗の平均も有限だと言えますか。

ヒント1

三つとも幾何級数の形にします。

ヒント2

平均の各項は3/2ᵏ、二乗の各項は3です。

解答

確率の和は3∑ₖ₌₁∞(1/4)ᵏ=3(1/4)/(1−1/4)=1です。非負のXなのでE[|X|]=E[X]=3∑ₖ₌₁∞(1/2)ᵏ=3で有限。一方E[X²]は各項が3で、部分和3m→∞となります。従って二乗の期待値は+∞で、有限ではありません。mまでの平均への寄与は3(1−2⁻ᵐ)ですが、これは残りの確率を含まない部分和で、切り詰めて正規化した別分布の平均とは区別します。

9．二つの平均条件を同時に満たせるか

Xは[0,a]の一様分布でa>0です。E[X]=2になるaを求め、同時にE[X²]=5を満たせるか調べてください。

ヒント1

密度は1/aです。二つの積分を作ります。

ヒント2

E[X]=a/2、E[X²]=a²/3です。

解答

E[X]=∫₀ᵃx/a dx=a/2なのでa=4です。このときE[X²]=∫₀⁴x²/4 dx=16/3で、5とは等しくありません。平均の条件がaを一つに決めるので、同じ一様分布の族で両条件を満たすことはできません。有界区間なのでどちらも絶対可積分です。

10．上限を平均額から設計する

Xは[0,2]の一様分布です。0≤k≤2を選び、受取額をgₖ(X)=min(X,k)とします。E[gₖ(X)]=3/4となる上限kを求め、実際に上限で支払われる確率も求めてください。

ヒント1

密度1/2を使い、x=kで積分を分けます。

ヒント2

期待値は∫₀ᵏx/2 dx+∫ₖ²k/2 dx=k−k²/4です。

解答

k−k²/4=3/4からk²−4k+3=0、すなわち(k−1)(k−3)=0です。範囲0≤k≤2にあるのはk=1だけ。実際に1点を支払うのはX≥1の場合で、その確率は1/2です。連続分布なのでX=1の一点の確率は0。積分でも1/4+1/2=3/4となり、平均設計を検算できます。
