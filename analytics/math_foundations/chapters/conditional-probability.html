条件付き確率と検査モデル

ある検査装置が「不良品の 90% に警報を出す」とします。警報が出た製品は、90% の確率で不良品でしょうか。「不良品の中で警報が出る割合」と「警報が出た中で不良品である割合」は、分母が違います。さらに、元から不良品がどれくらいあるかも、警報の内訳を変えます。

この章の工場、製品、検査値はすべて計算のための仮想モデルです。目的は装置を評価することではなく、情報を得たときに確率の基準となる全体がどう変わるかを見ることです。条件付き確率は、すでに起きた情報を新しい全体として重みを付け直します。

学習の目安は演習込み120–180分です。条件付き確率の分母を作る回、経路を掛けて足す回、検査の逆算・設計と演習の回に分けられます。演習1–3は基本、4–6は重みと逆算、7–10は設計・追加情報・境界を扱います。

条件付き確率の定義

事象 B が起きたと分かったとします。A のうち残る部分は A ∩ B で、新しい全体は B です。P(B) > 0 のとき、B の下での A の条件付き確率を次で定義します。縦棒の右側が、分かっている条件です。

P(A|B)=P(A∩B)P(B),P(B)>0

公平なさいころで、B = {4, 5, 6} が分かった後に、A = {2, 4, 6} の確率を問うなら、残る偶数は {4, 6} です。従って P(A | B) = (2/6)/(3/6) = 2/3。元の P(A) = 1/2 から変わりました。出目そのものを変更したのではなく、使う情報が変わったのです。

重みを付け直しても、確率の約束を満たす

PB(A) = P(A | B) と置きます。非負性は分子と分母から従い、PB(Ω) = P(B)/P(B) = 1 です。A と C が排反なら A ∩ B と C ∩ B も排反で、P((A ∪ C) ∩ B) = P(A ∩ B) + P(C ∩ B)。両辺を同じ P(B) で割れば加法性です。従って条件付けは、その場限りの割り算ではなく、新しい確率の規則を作っています。新しい規則では B 自身も確率 1 です。

P(B) = 0 では、この比は定義しません。0/0 を 0 と置くこともできません。有限モデルなら、正の重みを持たない結果だけに絞るため、このモデルの重みから新しい割合を決められないのです。連続量の「ちょうどある値」という情報の扱いには、別の定義と条件が必要です。本章の公式の対象には入れません。

例題：残った結果の個数ではなく、重みを割り直す

条件を知ると残る結果だけを見ますが、残った結果が自動的に等確率になるわけではありません。自作モデルΩ={a,b,c,d}に、順に重み1/2、1/4、1/8、1/8を与えます。A={a,c}を知りたい事象とし、B={b,c,d}が起きたと知らされたとします。

残す操作と、全体を1にする操作を分ける

まずBの外のaを除きます。残る重みの合計は1/4+1/8+1/8=1/2。この段階では合計が1でないので、同じ数1/2で全てを割ります。新しいb,c,dの重みは1/2、1/4、1/4です。Aのうち残るのはcだけなのでP(A|B)=1/4。

定義から直接求めてもP(A∩B)/P(B)=(1/8)/(1/2)=1/4です。Aが残る三結果のうち一つだから1/3、とはできません。条件付けは元の重みの比を保って全体を1に直す操作であり、重みを均等に塗り直す操作ではないのです。

逆向きも計算すると、P(A)=1/2+1/8=5/8なのでP(B|A)=(1/8)/(5/8)=1/5。二つの条件付き確率は違いますが、(1/2)(1/4)=(5/8)(1/5)=1/8となり、同じ重なりに戻ります。次節の乗法公式は、この「重なりへ戻る計算」を一般の形にしたものです。

もう一度、追加情報C={c,d}も受け取ったとしましょう。最初からB∩C={c,d}を条件にするとc,dは各1/2で、P(A|B∩C)=1/2です。Bで付け直した重みでも、Cの重み1/2でcの1/4を割れば同じ1/2になります。情報を二段階で使うときは、二回目に既に付け直した確率を使います。二つの別々の条件付き確率を根拠なく掛けるわけではありません。

確率の乗法定理

定義の両辺に P(B) を掛ければ、P(A ∩ B) = P(B)P(A | B) です。P(A) > 0 なら、条件にする側を入れ替えた P(A ∩ B) = P(A)P(B | A) も使えます。これが乗法公式です。二つの事象が同時に起こる確率 P(A ∩ B) を、同時確率と呼びます。

例えば赤三枚・青二枚の札から、各段で等確率に二枚を戻さず引きます。一枚目が赤である確率は 3/5。一枚目が赤と分かった後は赤二枚・青二枚なので、二枚目も赤の条件付き確率は 2/4。従って両方赤は (3/5)×(2/4) = 3/10 です。二枚目が赤の無条件の確率 3/5 を、そのまま二回掛けることはできません。

三段階なら、P(A) > 0、P(A ∩ B) > 0 の下で P(A ∩ B ∩ C) = P(A)P(B | A)P(C | A ∩ B)。各段で、それまでに分かった情報を条件に入れます。独立という特別な関係があれば条件を省けますが、その条件は次章で扱います。

例題：次の色の確率と、前の色の推定を区別する

赤3枚・青2枚を戻さず二枚引く、前節のモデルを続けます。R₁を「一枚目が赤」、R₂を「二枚目が赤」とします。一枚目が分からないときのP(R₂)と、二枚目が赤だと知った後のP(R₁|R₂)を求めます。添字は札の番号ではなく、引く回を表します。

二枚目が赤となる経路は、一枚目も赤の場合と、一枚目が青の場合の二つです。前者だけで答えを作ると、一枚目が青でも二枚目に赤を引ける場合を落としてしまいます。前節の木の下段で、二枚目が赤の二つの葉を探してください。

まず経路を掛け、次に経路どうしを足す

赤→赤は(3/5)(2/4)=3/10、青→赤は(2/5)(3/4)=3/10。二経路は排反なのでP(R₂)=3/10+3/10=3/5です。「二枚目も元と同じ確率になる」のは、この足し算の結果です。R₁を知った後の確率2/4と、無条件の確率3/5は違います。

二枚目が赤だったと知ると、残すのはこの二経路で、合計3/5が新しい全体です。P(R₁|R₂)=(3/10)/(3/5)=1/2。一枚目の赤の確率は、元の3/5から1/2へ下がります。後の札を見た情報で前の札の確率を付け直しても、過去の色が物理的に変化するわけではありません。

別の検算では、区別できる五枚を使います。二枚目が赤の順序付き結果は、二枚目の赤3通り×一枚目の残り4通り=12通り。そのうち一枚目も赤なのは3×2=6通りなので6/12=1/2です。確率木の割り算と、同じ条件での数え上げが一致します。

三回まで進み、赤→青→赤の一経路だけを求めるなら、(3/5)(2/4)(2/3)=1/5です。最後の2/3は「既に赤一枚・青一枚を引いた」という履歴の下で、残る赤2枚・青1枚から作っています。二枚目の情報だけを条件にし、最初の札を忘れた比を使ってはいけません。

全確率の公式

Ω を、互いに排反な A₁, …, Aₘ に分け、合併が Ω となるとき、これを分割と呼びます。まず各 P(Aᵢ) > 0 とします。どの経路から B が起きたかを分ければ、全体の P(B) が求まります。

全確率の公式

P(B)=∑i=1mP(Ai)P(B|Ai)

分割で切ると、重複なく B を覆う

B = (B ∩ A₁) ∪ ⋯ ∪ (B ∩ Aₘ) は排反な分割です。加法性から P(B) = ∑ᵢP(B ∩ Aᵢ)。各項に乗法公式 P(B ∩ Aᵢ) = P(Aᵢ)P(B | Aᵢ) を使えば得られます。確率 0 の Aᵢ がある場合は、P(B ∩ Aᵢ) = 0 なのでその項を除いて計算します。未定義の P(B | Aᵢ) に 0 を掛けたと書く必要はありません。

全確率は、経路ごとの割合の単純平均ではありません。経路そのものが選ばれる重みを掛けて足す平均です。部署の人数を忘れて集計するなど、分母の違う割合をそのまま足す間違いを避けられます。

ベイズの定理

P(A) > 0、P(B) > 0 とします。A ∩ B の同じ重みを二通りに表すと、P(B)P(A | B) = P(A)P(B | A)。従って次のBayes（ベイズ）の公式が得られます。

P(A|B)=P(A)P(B|A)P(B)

分割の一つ Aⱼ に当てはめ、全確率を分母に使えば、P(Aⱼ | B) = P(Aⱼ)P(B | Aⱼ)/∑ᵢP(Aᵢ)P(B | Aᵢ) です。観測前の P(Aⱼ) を事前確率、B を知った後の P(Aⱼ | B) を事後確率と呼びます。この式は、観測前の重みを、B との同時確率に変え、B 全体で割り直しています。条件を逆にするというより、同じ重なりのどちら側を基準に見るかを変えた式です。

P(B | A) と P(A | B) は一般に等しくありません。また条件付けは、A が B の原因であることを示す操作でもありません。情報の関係と、外から働きかけたときの因果関係は別の問いです。本章は、与えた確率モデルの内部で計算しています。

検査モデルの事後確率

D を「製品が不良」、T を「警報が出る」とします。仮想モデルを P(D) = 0.01、P(T | D) = 0.90、P(T | Dᶜ) = 0.05 と置きます。最初の 1% が基準率です。二番目は不良品の検出率、三番目は良品に警報を出す誤警報率です。

警報は「不良品で検出」と「良品で誤警報」という排反な二経路から来ます。前者の確率は 0.01×0.90 = 0.009、後者は 0.99×0.05 = 0.0495。従って P(T) = 0.0585、求める割合は P(D | T) = 0.009/0.0585 = 2/13 ≈ 0.1538、約 15.4% です。

同じ重みを一万単位の仮想的な内訳に拡大すると、不良 100 のうち警報 90・警報なし 10、良品 9,900 のうち警報 495・警報なし 9,405 です。警報全体 585 の中に不良は 90 しかありません。この内訳はモデルの比率を読みやすくしたもので、実際の一万個の製品で必ず同じ個数が出るという予言ではありません。

基準率だけを変えると、二つの警報経路の比はどう動くでしょうか。検出率と誤警報率を同時に 0 にすれば警報全体の確率が 0 になり、警報が出たという条件付けはできません。画面の「条件付け不可」は、事後の割合が 0 という意味ではありません。

例題：事後確率の目標から、基準率と誤警報率を逆算する

前節の警報モデルを一般化します。不良率をqとし、0≤q≤1です。検出率9/10、誤警報率1/20に対応する四つの同時確率を、P(D∩T)=q(9/10)、P(D∩Tᶜ)=q(1/10)、P(Dᶜ∩T)=(1−q)(1/20)、P(Dᶜ∩Tᶜ)=(1−q)(19/20)と定めます。四セルはこの範囲で非負、和は1なので、両端を含むモデルができます。

0<q<1では、P(T|D)=[q(9/10)]/q=9/10、P(T|Dᶜ)=[(1−q)(1/20)]/(1−q)=1/20となり、元の条件付き率と一致します。q=0ではDを条件とする率、q=1ではDᶜを条件とする率は、分母が0なので比として未定義です。ここでは未定義の率に0を掛けず、上のパラメータから四セルを直接定め、端まで拡張しています。

警報の二経路は(9/10)qと(1/20)(1−q)。両者の和は(1+17q)/20で正なので、この範囲なら警報を条件にできます。事後の不良確率は18q/(1+17q)です。

次の表では、同じ検出率と誤警報率を保って基準率だけを変えています。「警報が正しい確率が半分になる境目」はどの行か、二つの警報経路の重みから読んでください。いずれも実測した個数ではなく、理想化モデルの確率です。

単位は全製品に対する確率。最後の列だけは警報全体を分母にした割合
不良率q不良かつ警報良品かつ警報警報中の不良
1/1009/100099/20002/13
1/199/1909/1901/2
1/109/1009/2002/3

半分以上となる基準率を求める

分母が正であることを確認してから、18q/(1+17q)≥1/2を解きます。36q≥1+17q、つまりq≥1/19です。同じ結論は「不良からの警報が良品からの警報以上」すなわち(9/10)q≥(1/20)(1−q)からも出ます。境界q=1/19では表の二経路が等しく、事後確率はちょうど1/2です。

今度は基準率を保ち、装置側の条件を設計する

q=1/100、検出率9/10を保ち、誤警報率だけをfへ変更して、警報中の不良を9/10以上にしたいとします。事後確率は(9/1000)/(9/1000+(99/100)f)。分母は少なくとも9/1000で正です。両辺を払って整理すると9/10000≥(891/1000)fなので、0≤f≤1/990が条件です。

境界f=1/990では、良品からの警報は(99/100)(1/990)=1/1000。全警報は10/1000で、そのうち不良は9/1000なので確かに9/10です。元の誤警報率1/20に比べ、かなり小さい率を要求しています。「検出率90%」だけで警報の90%が正しいとは言えない理由が、設計条件にも表れます。

端も点検します。上の四セルで定めたモデルではq=0なら事後0、q=1なら事後1。誤警報率を0にしてq>0・検出率>0なら、警報は不良からしか来ないため事後1です。一方、検出率と誤警報率を両方0にすると警報の確率自体が0になり、この割り算は使えません。未定義と、計算結果0は区別します。

寄り道［応用］：同じ装置でも、使う場所が変わると警報の内訳が変わる

NIST の信頼性評価の解説は、事前の情報と現在のデータを Bayes の公式で組み合わせる考え方を扱っています。本章では未知の寿命などを推定する手法には進まず、観測前の重みを忘れずに使う点に注目します。

本章の仮想装置を別の生産ラインへ移し、不良率だけが 10% になったとします。検出率 90%、誤警報率 5% はそのままと仮定します。不良からの警報は 0.10×0.90 = 0.09、良品からの警報は 0.90×0.05 = 0.045 なので、警報の中の不良は 0.09/(0.09 + 0.045) = 2/3。前の約 15.4% から大きく変わります。

装置の二つの条件付き確率を同じと仮定しても、使う集団が変われば逆向きの確率は同じになりません。さらに現実では、製品の種類が変われば検出率や誤警報率も変わり得ます。Bayes の公式そのものの正しさと、入力した三つの値がその現場に合うかは、別に確かめる必要があります。

演習：条件付き確率と全確率

1．同じ重なりを、違う側から見る

1 から 10 までの番号札を一枚、等確率で引きます。A を「3 の倍数」、B を「6 以上」として、P(A | B) と P(B | A) を求め、それぞれの分母を説明してください。

ヒント1：三つの集合を書き出す

A = {3, 6, 9}、B = {6, 7, 8, 9, 10}、A ∩ B = {6, 9} です。

ヒント2：縦棒の右が新しい全体

P(A | B) では B の五枚、P(B | A) では A の三枚を基準にします。

解答

P(A | B) = (2/10)/(5/10) = 2/5、P(B | A) = (2/10)/(3/10) = 2/3。どちらも重なる札は 6 と 9 ですが、条件に合う札が五枚か三枚かで割合が違います。P(B)P(A | B) = (5/10)(2/5) = 2/10 と P(A)P(B | A) = (3/10)(2/3) = 2/10 は、同じ同時確率に戻ります。

2．基準率を含めて警報を読む

仮想工場で不良率 0.02、検出率 0.80、誤警報率 0.04 とします。警報が出る確率と、その中で不良である確率を求めてください。検出率と誤警報率が両方 0 の場合にも、後者を計算できますか。

ヒント1：良品の確率も使う

良品は 0.98。そのうちの 0.04 が誤警報になります。

ヒント2：分子は不良からの警報、分母はすべての警報

分子は 0.02×0.80、分母には 0.98×0.04 も加えます。

解答

P(T) = 0.02×0.80 + 0.98×0.04 = 0.016 + 0.0392 = 0.0552。従って P(D | T) = 0.016/0.0552 = 20/69 ≈ 0.2899、約 29.0% です。検出率と誤警報率がともに 0 なら P(T) = 0 となり、P(D | T) はこの定義では計算できません。値を 0 と置くことは、割合が未定義であることと区別します。

3．どちらの機械から来た不良品か

製品の 60% は機械 A、40% は機械 B が作ります。それぞれの不良率は 2%、6% とします。全製品から等確率に一個を選んだときの不良率と、不良と分かった製品が機械 B 製である確率を求めてください。

ヒント1：機械別の重みを先に掛ける

不良の経路は 0.60×0.02 と 0.40×0.06 です。

ヒント2：機械 B の全体比率では割らない

条件にするのは「不良」なので、分母は全体の不良率です。

解答

全体の不良率は 0.60×0.02 + 0.40×0.06 = 0.012 + 0.024 = 0.036、つまり 3.6%。不良かつ機械 B 製の確率は 0.024 なので、求める条件付き確率は 0.024/0.036 = 2/3 です。機械 B の生産量は少なくても、不良品という集まりの中では多い側になります。機械別不良率の単純平均 4% は、生産量の違いを無視しています。

4．条件付けを二段階で行う

Ω={a,b,c,d}の重みを1/2、1/4、1/8、1/8とし、A={a,b}、B={b,c,d}、C={b,c}です。P(A|B)とP(A|B∩C)を求め、Bの下でさらにCを条件にしても同じ結果になるか確かめてください。

ヒント1：方針を選ぶ

Bの重みは1/2、B∩Cの重みは3/8です。

ヒント2：計算をつなぐ

Bの下でbの重みは1/2、Cの重みは3/4になります。

解答

P(A|B)=(1/4)/(1/2)=1/2、P(A|B∩C)=(1/4)/(3/8)=2/3です。Bで付け直した確率からも、A∩Cの重み1/2をCの重み3/4で割り2/3。元の確率と条件付き確率を混ぜず、同じ規則の分子と分母を使うことが要点です。

5．履歴を省略した枝を診断する

赤3枚・青2枚から戻さず三枚引きます。赤→青→赤の確率を(3/5)(2/4)(3/4)とした解答を診断し、正しい値を順序付き札の個数でも検算してください。

ヒント1：方針を選ぶ

最後には二枚引いた後の三枚しか残っていません。

ヒント2：計算をつなぐ

最後の残りは赤2枚・青1枚。元の札を区別して全体5×4×3と数える方法もあります。

解答

最後の3/4は「青一枚だけを引いた」状況の比で、最初の赤を忘れています。正しくは(3/5)(2/4)(2/3)=1/5。札で数えると分子3×2×2=12、分母5×4×3=60で12/60=1/5です。最後の枝はそれ以前の全履歴を条件に作ります。

6．警報全体から基準率を復元する

検出率0.90、誤警報率0.05が固定されたモデルで、全体の警報率が0.135だと分かりました。不良率qと警報中の不良の確率を求めてください。

ヒント1：方針を選ぶ

警報率は0.90q+0.05(1−q)です。

ヒント2：計算をつなぐ

0.85q+0.05=0.135を解きます。

解答

q=(0.135−0.05)/0.85=0.10です。不良からの警報0.09、良品から0.045を足して0.135に戻ります。警報中の不良は0.09/0.135=2/3です。検出率と誤警報率が同じなら警報率はqによらず一定となり、この逆算でqを一意に決めることはできません。

7．誤警報率の上限を設計する

不良率1/50、検出率4/5を保ちます。警報が出た製品の不良確率を4/5以上にするための、誤警報率fの範囲を求め、境界で検算してください。

ヒント1：方針を選ぶ

不良からの警報は(1/50)(4/5)=2/125で正です。

ヒント2：計算をつなぐ

(2/125)/(2/125+(49/50)f)≥4/5を解きます。

解答

正の分母を払うと(1/5)(2/125)≥(4/5)(49/50)f、従って0≤f≤1/245。境界では良品からの警報(49/50)(1/245)=1/250で、全警報は2/125+1/250=1/50。その中の不良は(2/125)/(1/50)=4/5です。f=0では事後1となり、求める範囲とも整合します。

8．二回の警報に必要な追加情報

不良率0.01、第一検査の検出率0.90、誤警報率0.05です。さらに「不良で第一検査が警報なら第二検査も警報となる確率0.90」「良品で第一検査が警報なら第二検査も警報となる確率0.05」という追加の仮定を置きます。二回とも警報となる確率と、その中の不良率を求めてください。

ヒント1：方針を選ぶ

二回とも警報への経路を不良と良品に分け、三つの条件付きの率を掛けます。

ヒント2：計算をつなぐ

二経路は0.01×0.90×0.90と0.99×0.05×0.05です。

解答

不良経路0.0081、良品経路0.002475、合計0.010575。事後不良率は0.0081/0.010575=36/47≈0.7660です。一回の警報中の不良率2/13を二乗してはいけません。また二番目の二つの率は最初の検査の説明だけからは出ず、問題が追加したモデルの情報です。同じ製品を再検査するという言葉だけでは決まりません。

9．確率0の条件を近づけて考える

Ω={a,b,c}の重みが(0,0,1)で、A={a}、B={a,b}とします。P(A|B)がこの定義で求まらない理由を述べてください。0<ε<1として重みを(ε,0,1−ε)に変えた場合と(0,ε,1−ε)に変えた場合も比較してください。

ヒント1：方針を選ぶ

元のBの重みは0です。変更後は両方ともP(B)=εです。

ヒント2：計算をつなぐ

二つの変更でA∩Bの重みが違います。

解答

元の比は0/0で未定義です。一つ目の変更ではε/ε=1、二つ目では0/ε=0。εを0へ近付けると両モデルの重みは元へ近付きますが、条件付き確率の値は一致しません。従って0/0に一つの値を都合よく補うことは、元の確率だけからは正当化できません。

10．両方向の条件付き確率から表を作る

P(A)=2/5、P(B|A)=1/2、P(A|B)=3/4とします。P(A∩B)、P(B)、四部分の重みを求め、この三条件が一つのモデルで実現できるか示してください。

ヒント1：方針を選ぶ

P(A∩B)を先に乗法公式で求めます。

ヒント2：計算をつなぐ

同じ重なりをP(B)で割ると3/4になるはずです。

解答

P(A∩B)=(2/5)(1/2)=1/5。P(B)=(1/5)/(3/4)=4/15です。両方、Aだけ、Bだけ、どちらもないは(1/5,1/5,1/15,8/15)。全て非負で和は3/15+3/15+1/15+8/15=1なので実現できます。表から(1/5)/(2/5)=1/2、(1/5)/(4/15)=3/4と二方向を検算できます。
