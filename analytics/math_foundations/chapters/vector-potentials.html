ポテンシャルと端点の値の差

勾配場の仕事は端点の値の差だけで決まりました。では、与えられた場 F を ∇φ と書けるか、どう判定すればよいでしょう。偏微分の一致は局所的な検査ですが、一本の φ を領域全体へ作れるかどうかには、領域の穴も関わります。

復習は線積分の基本定理、偏微分、連続な二階偏微分の交換です。本章は回転を表す演算子をまだ使いません。

ここで局所とは各点の十分小さい近くを、大域とは領域全体を指します。各点の近くでそれぞれ φ を作れることと、同じ一つの φ を領域全体へ定められることは、分けて確かめます。

演習込み100–150分が目安です。成分から関数を復元する計算、星形領域の証明、穴の反例と演習、の三回に分けられます。「微分条件」「領域の条件」「閉曲線での検算」を別々に記録します。

ポテンシャル・経路独立性・閉曲線積分

領域の言葉も確認します。開集合は、各点のまわりに十分小さい球を取れば、その全体が集合に入るものです。開集合が連結であるとは、互いに交わらない二つの空でない開集合の和に分けられないことです。例えば、離れた二つの開球の和集合は開ですが、その二球に分けられるので連結ではありません。以下では、この条件から道の存在を得る標準事実を借り、二点を結ぶ積分を定義します。

開かつ連結な U ⊂ ℝ³ 上の C¹ 場 F を考えます。φ が C¹ で ∇φ = F を満たすとき、φ を F のポテンシャルと呼びます。ここでは「開連結集合の任意の二点は、その中の区分 C¹ の道（実際は有限折れ線）で結べる」という標準事実を未証明で使います。この条件の下で、次の三つは同値です。

  1. U 上にポテンシャル φ が存在する。
  2. U 内の二点 A、B に対する ∫A→BF·dr は、道によらない。
  3. U 内のすべての閉じた区分 C¹ 曲線 C で ∮CF·dr = 0。

閉じた道を、行きと戻りへ分ける

1から2は線積分の基本定理です。2から3は、閉じた道と同じ点にとどまる定数曲線を比べれば、定数曲線の積分が0なので従います。3から2は、A から B への道 C₁ と C₂ を取り、C₁ のあとに −C₂ をつないだ閉曲線を考えます。その積分は ∫C₁F·dr − ∫C₂F·dr = 0 です。

2から1を示します。基点 a を固定し、φ(x) を a から x への積分と定めます。道は存在し、仮定2により値が一つに決まります。x の十分近くの小球が U に入るので、その中で座標方向の短い線分を足せます。経路独立性から φ(x + heⱼ) − φ(x) = ∫₀ʰFⱼ(x + seⱼ)ds。h で割って h → 0 とすると、連続性により ∂ⱼφ(x) = Fⱼ(x)。これらの偏微分は連続なので φ は C¹ で、∇φ = F です。

ポテンシャルに定数を加えても勾配は同じです。逆に二つのポテンシャルの差は、任意の二点を結ぶ道に沿う変化が0なので U 全体で定数です。領域が非連結なら、この定数は成分ごとに違って構いません。

非連結な場合の「成分」は、ベクトルの座標成分ではなく、領域を連結なまとまりに分けた各部分（連結成分）を指します。定数の違いを領域全体で一つにそろえるには、連結性が必要です。

成分からポテンシャルを復元する

場Fが与えられたら、すべての道を積分して比べるのは現実的ではありません。まず交差する偏微分を比べ、不一致ならポテンシャルはないと判断します。一致したら、領域に使える十分条件があるかを調べます。候補φを実際に作れた場合は、その全成分を微分してFへ戻ることが、最も直接的な確認です。

例題1：積分定数を、残る変数の関数として持つ

ℝ³でF=(2xy+z,x²+2y,x+2z)を考えます。第1成分からφₓ=2xy+zなので、xで積分してφ=x²y+xz+g(y,z)と置きます。xで微分すると消える項は数の定数だけではないため、gを残すのが方針です。

これをyで微分するとφᵧ=x²+gᵧ。第2成分との一致からgᵧ=2yなので、g=y²+h(z)。さらにφ_z=x+h′(z)=x+2zよりh′(z)=2z、h=z²+Cです。従ってφ=x²y+xz+y²+z²+C。最初の一成分の積分では決まらなかった項を、残りの成分で順に決めました。

検算は三成分をもう一度微分することです。∂ₓφ=2xy+z、∂ᵧφ=x²+2y、∂_zφ=x+2zで全て一致します。A=(1,0,1)からB=(2,1,0)への仕事はφ(B)−φ(A)=5−2=3。定数Cは差から消えます。ℝ³上の多項式なので、道の連続性・滑らかさの仮定も問題ありません。

「第1成分を積分して終わり」では、gを落として第2・第3成分を作り損ねます。一方、各成分の原始関数を別々に作って全部足すと、共有する項を二重三重に数えることがあります。必要なのは、一つのφが全成分の微分条件を同時に満たすことです。

星形領域でのポテンシャルの構成

任意の二点を結ぶ線分全体が領域に入るとき、その集合は凸といいます。これから使う星形では、線分の片方の端を一つの基点に固定します。どこからでも直線で行けることと、その基点から直線で行けることを区別します。

開集合 U が a ∈ U に関して星形であるとは、任意の x ∈ U に対し線分 a + t(x − a)、0 ≤ t ≤ 1 がすべて U に入ることです。凸集合なら任意の基点について星形ですが、星形集合は凸でなくても構いません。星形なら基点と各点を線分で結べるので連結です。

星形領域でのポテンシャル構成

U は a に関して星形な開集合、F = (F₁, F₂, F₃) は U 上で C¹ とします。すべての i、j について ∂ᵢFⱼ = ∂ⱼFᵢ なら、次の関数は ∇φ = F を満たします。

φ(x)=∫01F(a+t(x−a))·(x−a)dt

これは a から x への直線の仕事そのものです。経路独立性を先に仮定して式を作ったのではありません。この候補を微分して F へ戻ることを確かめます。

例えば位置ベクトル p に対し F(p)=2p とする場で、基点を0に選びます。線分上の場は F(tx)=2tx なので、公式は φ(x)=∫₀¹2t‖x‖²dt=‖x‖² となります。勾配は2xで、元の場へ戻ります。一般の F でも同じことを示すため、次節では、積分の中を x で微分してよい根拠から確かめます。

ポテンシャル構成の微分と偏微分の対称性

ここでいうコンパクトは、有限次元のユークリッド空間では、二重積分で説明した逐次コンパクトと同じ性質です。すなわち、集合内のどんな点列からも、その集合内の点へ収束する部分列を取れます。次の閉線分Kでは、点列を表すパラメータtの列が区間[0,1]にあるので、その収束部分列からK内に収束する部分列を作れます。

さらに、コンパクトなKが開集合Uに含まれるなら、ある共通の幅η>0を取れて、Kの各点から距離η以下の点をすべて集めてもUに含まれる、という標準事実をここでは未証明で使います。この共通の幅が、xを少し動かした線分もU内で比較し、積分と微分を交換するための準備になります。

小補題：連続な偏微分は、差商を一様に近づける

固定した x に対し、線分 K = {a + t(x − a) : 0 ≤ t ≤ 1} は U 内のコンパクト集合です。U が開なので、K の十分細い閉じた管状近傍も U に含められます。x を小さく動かしても対応する線分はこの近傍に入ります。被積分関数 g(x, t) = F(a + t(x − a))·(x − a) とその x に関する偏微分は、その小近傍と [0, 1] の積で連続です。

固定した x と成分 j に対し、x + seⱼ が上の小近傍に入るよう δ > 0 を選び、G(s, t) = ∂ⱼg(x + seⱼ, t) を閉矩形 [−δ, δ] × [0, 1] 上で考えます。G は連続な二変数関数なので、二重積分で用いた二次元の一様連続性を使えます。一変数の基本定理から、{g(x + heⱼ, t) − g(x, t)}/h = ∫₀¹∂ⱼg(x + θheⱼ, t)dθ。G(θh, t) と G(0, t) の差は t、θ ∈ [0, 1] について一様に0へ行くので、右辺と ∂ⱼg(x, t) の差の絶対値の上限も、t ∈ [0, 1] について一様に0へ行きます。その差を t で積分しても、区間の長さ1を掛けた上限以下。従って ∂ⱼ∫₀¹g(x, t)dt = ∫₀¹∂ⱼg(x, t)dt です。ここで連続偏微分と閉矩形上の二次元の一様連続性を使いました。

線分方向の微分を、t の微分へまとめる

d = x − a、q(t) = a + td と書きます。積と連鎖律、および前の補題から、∂ⱼφ(x) は次の式になります。

∂jφ(x)=∫01[Fj(q)+t∑i=13di∂jFi(q)]dt

仮定 ∂ⱼFᵢ = ∂ᵢFⱼ を使えば、角括弧は Fⱼ(q(t)) + t(d/dt)Fⱼ(q(t)) = (d/dt){tFⱼ(q(t))} です。基本定理により ∂ⱼφ(x) = [tFⱼ(a + td)]₀¹ = Fⱼ(x)。F は連続なので φ は C¹、実際には F が C¹ のため φ は C² です。

逆に F = ∇φ で F が C¹ なら φ は C² なので、連続な二階偏微分の交換から ∂ᵢFⱼ = ∂ⱼFᵢ は必要です。この成分の一致を、第6章で「curl F = 0」とまとめて呼びます。今の証明はその記号にも、GreenやStokesの定理にも依存していません。

線分公式を使う前後の検査

例題2：線分の仕事が、そのままポテンシャルになる条件

例題1の場へ基点0の線分公式を使うと、F(tx,ty,tz)=(2t²xy+tz,t²x²+2ty,tx+2tz)です。これと(x,y,z)の内積は3t²x²y+2txz+2ty²+2tz²。積分してx²y+xz+y²+z²を得ます。成分ごとに復元した式のC=0と一致しました。

この一致は偶然ではありません。Fの交差偏微分は、∂ᵧF₁=∂ₓF₂=2x、∂_zF₁=∂ₓF₃=1、∂_zF₂=∂ᵧF₃=0です。ℝ³は0について星形なので、構成の証明を適用できます。線分法は全成分を対等に扱える別解で、成分積分法は未知項を一段ずつ決める別解です。

では同じ線分公式にG(x,y)=(−y,x)を入れるとどうでしょう。G(tx,ty)·(x,y)=−txy+txy=0なので、候補はψ=0です。しかし∇ψ=(0,0)はGと一致しません。星形のℝ²でも、∂ᵧG₁=−1と∂ₓG₂=1が異なり、構成定理の仮定を満たさないからです。

線分の積分は、どんな連続な場でも基点からの一つの仕事を定義します。それをポテンシャルと呼べるかは別問題です。公式を計算できたことを、∇φ=Fの証明と取り違えないようにします。

穴のある領域と大域ポテンシャル

同じ議論は二次元でも成り立ちます。原点を除いた平面 U = ℝ² ∖ {(0, 0)} で、F = (P, Q) = (−y/(x² + y²), x/(x² + y²)) を考えます。この場は U で C¹ で、直接微分すると ∂ᵧP = (y² − x²)/(x² + y²)² = ∂ₓQ。局所の対称性は満たします。

しかし単位円 r(t) = (cos t, sin t)、0 ≤ t ≤ 2π 上では F(r(t)) = (−sin t, cos t) = r′(t)。従って ∮F·dr = ∫₀²π1dt = 2π ≠ 0。基本定理より、U 全体でのポテンシャルは存在しません。原点で場を定義したことにしても連続にならず、仮定の穴は埋まりません。

経路比較と領域の制限

例題3：同じ端点へ、上と下から進む

穴の場H=(−y,x)/(x²+y²)でA=(1,0)、B=(−1,0)を結びます。上半円r₊(t)=(cos t,sin t)、0≤t≤πではH(r₊)=r₊′だから仕事はπです。下半円を同じAからBへ進むr₋(t)=(cos t,−sin t)では、H(r₋)=(sin t,cos t)、r₋′=(−sin t,−cos t)。内積は−1なので仕事は−πです。

二本の差はπ−(−π)=2π。上半円のあと下半円を逆に戻れば、反時計回り一周になります。円一周の計算を、経路独立性がどこで失敗するかの比較へ読み直したものです。始点と終点に同じφの値を置こうとすれば、差がπと−πの両方でなければならず矛盾します。

例題4：領域を狭めれば一つの角度を選べる

今度は右半平面V={(x,y):x>0}だけを考えます。φ(x,y)=arctan(y/x)を選ぶと、∂ₓφ={1/(1+(y/x)²)}(−y/x²)=−y/(x²+y²)、∂ᵧφ={1/(1+(y/x)²)}(1/x)=x/(x²+y²)。従って同じHのポテンシャルです。

Vは凸な開集合で、原点を含みません。この領域ではφが一つの連続な値として定まり、A=(1,0)からD=(1,1)への仕事はπ/4−0=π/4です。縦線分x=1を直接積分しても∫₀¹1/(1+y²)dy=π/4。原点を回る円全体はVに入りません。小さい領域で成功することと、穴を囲む領域全体で成功することは矛盾しません。

寄り道［数学の見方］：局所検査を全体の結論にする追加情報

偏微分の等式は、一点のすぐ近くの変化だけを見ています。一周の仕事は離れた点を順につないだ結果です。星形領域では、すべての点へ同じ作り方で線分を引けるので、局所検査を一つの積分公式へまとめられました。

反例が教えるのは「対称性は役立たない」ではなく、「領域の情報なしには全体を決めない」という限界です。定理の仮定には、関数の滑らかさと領域の形という異なる二種類の情報があります。

出典：本章の星形構成と原点除外平面の直接計算による比較です。

演習：ポテンシャルの構成と条件

1．星形の公式を実際に使う

ℝ³ 上の F = (2xy + z, x², x + 2z) について、基点0の線分公式からポテンシャルを求め、勾配を確認してください。

ヒント1：線分上へ代入する

F(tx, ty, tz)·(x, y, z) = 3t²x²y + 2txz + 2tz² です。

ヒント2：t で積分する

∫₀¹3t²dt = 1、∫₀¹2tdt = 1。

解答

φ = x²y + xz + z²。偏微分は (2xy + z, x², x + 2z) で F に一致します。ℝ³ は0について星形で、F は C¹。成分の交差偏微分もそれぞれ 2x、1、0 で対応する相手と一致し、構成定理の仮定を満たします。

2．穴と反転

本章の原点除外平面の場を、半径 R > 0 の円 r(t) = (R cos t, R sin t)、0 ≤ t ≤ 2π で積分してください。向きを逆にするとどうなりますか。

ヒント1：分母は R²

F(r(t)) = (−sin t/R, cos t/R) です。

ヒント2：速度の R と相殺する

r′(t) = (−R sin t, R cos t)。内積を取ります。

解答

内積は1なので半径によらず2π、逆向きなら−2πです。R = 0 は曲線が場の定義域に入らないので許されません。R を小さくしても一周の積分が消えないことは、原点まで連続に場を拡張できないことと整合します。

3．星形でなければ必ず失敗するか

U = ℝ² ∖ {(0, 0)} で F = (2x, 2y) とします。ポテンシャルと閉曲線の積分を求め、「U が星形でないのでポテンシャルがない」という推論を検討してください。

ヒント1：二乗和を微分する

φ = x² + y² は U でも定義されています。

ヒント2：十分条件と必要条件

星形構成が使えないことと、別の方法で φ を作れないことは違います。

解答

∇φ = (2x, 2y) なのでポテンシャルは存在し、U 内のすべての閉曲線の積分は0です。星形性は本章の構成定理の十分条件で、必要条件ではありません。領域に穴があると対称性だけで結論は出ませんが、すべての場が失敗するわけでもありません。

4．仕事と対称性から係数を設計する

ℝ³でF=(2xy+z,x²+ay,bx+2z)とします。ポテンシャルを持ち、(0,0,0)から(0,2,0)への仕事が6になるように、実数a,bを決め、φ(0,0,0)=0となるポテンシャルも求めてください。

ヒント1

交差偏微分のうち、係数bが現れる組を比べます。aはどの対称性の式に入るでしょうか。

ヒント2

b=1ならφ=x²y+xz+(a/2)y²+z²+C。指定した二点で差を取ります。

解答

∂_zF₁=1、∂ₓF₃=bからb=1が必要です。他の二組は任意のaで一致します。φ(0)=0よりC=0、指定区間の仕事は2aなのでa=3。候補φ=x²y+xz+(3/2)y²+z²の勾配がFに一致し、端点差6を確認できます。微分条件だけではaは決まらず、仕事の条件が残る自由度を決めています。

5．各成分の原始関数を足す誤り

F=(2x+yz,2y+xz,2z+xy)に対し、各成分をそれぞれx,y,zで積分して足し、ψ=x²+y²+z²+3xyzとした人がいます。誤りを微分で特定し、正しいポテンシャルを作ってください。

ヒント1

ψの第1成分を微分し、場の第1成分と比べます。

ヒント2

三つの成分に現れるyz、xz、xyは、一つの項xyzから同時に出ます。

解答

ψₓ=2x+3yzで、必要な2x+yzと一致しません。共有するxyzを三回数えたのが誤りです。φ=x²+y²+z²+xyz+Cなら全成分が一致します。例えば(1,1,1)で∇ψ=(5,5,5)、F=(3,3,3)なので、有限の一点でも候補を棄却できます。全領域での正しさは三成分の式の一致で確認します。

6．線分の積分をポテンシャルと呼べるか

G=(−y,x)に対し、原点からの線分積分が常に0であることを示してください。その結果を「Gのポテンシャルは0」としてはいけない理由を、微分と別経路の両方で説明してください。

ヒント1

G(tx,ty)と(x,y)の内積を取ります。

ヒント2

(0,0)から(1,1)へ右→上の折れ線で進むと仕事は1です。

解答

内積−txy+txy=0なので線分積分は0。しかし0の勾配は(0,0)でGとは一致しません。線分では仕事0、折れ線では1なので、基点からの全経路の仕事が同じではありません。線分積分を定義する段階と、それをポテンシャルだと証明する段階を区別する必要があります。

7．領域を決めて角度を使う

H=(−y,x)/(x²+y²)を右半平面x>0で考え、A=(1,−1)からB=(1,1)への仕事を求めてください。全円を同じポテンシャルで計算できない理由も説明してください。

ヒント1

例題4のφ=arctan(y/x)を使えます。

ヒント2

φ(A)=−π/4、φ(B)=π/4です。

解答

仕事はπ/2。縦線分で∫₋₁¹1/(1+y²)dy=π/2とも検算できます。φは右半平面の中で一つのポテンシャルですが、全円にはx≤0の部分があるため、そのまま適用できません。原点除外平面で全円を含む一つのポテンシャルがあれば仕事0のはずですが、直接計算は2πなので存在しません。

8．有限の閉曲線検査の限界

F=(−y,x)について、任意の線分を進んで同じ線分を戻る閉曲線の仕事は0です。この検査を何本成功させても、ポテンシャルの存在を結論できないことを説明してください。

ヒント1

逆向きの積分は元の負号付きです。この相殺はどんな場でも起きます。

ヒント2

別の種類の閉曲線として、単位円を考えます。

解答

往復はI+(−I)=0で、場が勾配かどうかを問わない相殺です。一方、単位円を反時計回りに積分すると2π。ポテンシャルなら全閉曲線で0でなければならないので、この場には存在しません。「すべての閉曲線」の条件を、有限個の選んだ検査に置き換えることはできません。

9．非連結領域の積分定数

U={(x,y):x≠0}でF=(2x,2y)とします。φ(1,0)=0、φ(−1,0)=2となるポテンシャルを作ってください。「同じ場なら二つのポテンシャルの差は領域全体で一つの定数」という主張の不足も説明してください。

ヒント1

Uは右半平面と左半平面に分かれます。各側で別の積分定数を使えます。

ヒント2

x>0でx²+y²+C₊、x<0でx²+y²+C₋とします。

解答

C₊=−1、C₋=1なので、右側ではφ=x²+y²−1、左側ではφ=x²+y²+1です。各点の近くでは同じ側だけを見ればよく、U上C¹で勾配はF。基準ψ=x²+y²との差は右で−1、左で1となります。一つの定数とするには連結性が必要です。(1,0)と(−1,0)をU内で結ぶ連続な道はなく、その間の仕事をこの領域の線積分として指定できません。
