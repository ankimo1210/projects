ポテンシャルと端点の値の差

勾配場の仕事は端点の値の差だけで決まりました。では、与えられた場 F を ∇φ と書けるか、どう判定すればよいでしょう。偏微分の一致は局所的な検査ですが、一本の φ を領域全体へ作れるかどうかには、領域の穴も関わります。

復習は線積分の基本定理、偏微分、連続な二階偏微分の交換です。本章は回転を表す演算子をまだ使いません。

ポテンシャル・経路独立性・閉曲線積分

開かつ連結な U ⊂ ℝ³ 上の C¹ 場 F を考えます。φ が C¹ で ∇φ = F を満たすとき、φ を F のポテンシャルと呼びます。ここでは「開連結集合の任意の二点は、その中の区分 C¹ の道（実際は有限折れ線）で結べる」という標準事実を未証明で使います。この条件の下で、次の三つは同値です。

  1. U 上にポテンシャル φ が存在する。
  2. U 内の二点 A、B に対する ∫A→BF·dr は、道によらない。
  3. U 内のすべての閉じた区分 C¹ 曲線 C で ∮CF·dr = 0。

閉じた道を、行きと戻りへ分ける

1から2は線積分の基本定理です。2から3は、閉じた道と同じ点にとどまる定数曲線を比べれば、定数曲線の積分が0なので従います。3から2は、A から B への道 C₁ と C₂ を取り、C₁ のあとに −C₂ をつないだ閉曲線を考えます。その積分は ∫C₁F·dr − ∫C₂F·dr = 0 です。

2から1を示します。基点 a を固定し、φ(x) を a から x への積分と定めます。道は存在し、仮定2により値が一つに決まります。x の十分近くの小球が U に入るので、その中で座標方向の短い線分を足せます。経路独立性から φ(x + heⱼ) − φ(x) = ∫₀ʰFⱼ(x + seⱼ)ds。h で割って h → 0 とすると、連続性により ∂ⱼφ(x) = Fⱼ(x)。これらの偏微分は連続なので φ は C¹ で、∇φ = F です。

ポテンシャルに定数を加えても勾配は同じです。逆に二つのポテンシャルの差は、任意の二点を結ぶ道に沿う変化が0なので U 全体で定数です。領域が非連結なら、この定数は成分ごとに違って構いません。

星形領域でのポテンシャルの構成

開集合 U が a ∈ U に関して星形であるとは、任意の x ∈ U に対し線分 a + t(x − a)、0 ≤ t ≤ 1 がすべて U に入ることです。凸集合なら任意の基点について星形ですが、星形集合は凸でなくても構いません。星形なら基点と各点を線分で結べるので連結です。

星形領域でのポテンシャル構成

U は a に関して星形な開集合、F = (F₁, F₂, F₃) は U 上で C¹ とします。すべての i、j について ∂ᵢFⱼ = ∂ⱼFᵢ なら、次の関数は ∇φ = F を満たします。

φ(x)=∫01F(a+t(x−a))·(x−a)dt

これは a から x への直線の仕事そのものです。経路独立性を先に仮定して式を作ったのではありません。この候補を微分して F へ戻ることを確かめます。

ポテンシャル構成の微分と偏微分の対称性

小補題：連続な偏微分は、差商を一様に近づける

固定した x に対し、線分 K = {a + t(x − a) : 0 ≤ t ≤ 1} は U 内のコンパクト集合です。U が開なので、K の十分細い閉じた管状近傍も U に含められます。x を小さく動かしても対応する線分はこの近傍に入ります。被積分関数 g(x, t) = F(a + t(x − a))·(x − a) とその x に関する偏微分は、その小近傍と [0, 1] の積で連続です。

固定した x と成分 j に対し、x + seⱼ が上の小近傍に入るよう δ > 0 を選び、G(s, t) = ∂ⱼg(x + seⱼ, t) を閉矩形 [−δ, δ] × [0, 1] 上で考えます。G は連続な二変数関数なので、二重積分で用いた二次元の一様連続性を使えます。一変数の基本定理から、{g(x + heⱼ, t) − g(x, t)}/h = ∫₀¹∂ⱼg(x + θheⱼ, t)dθ。G(θh, t) と G(0, t) の差は t、θ ∈ [0, 1] について一様に0へ行くので、右辺と ∂ⱼg(x, t) の差の絶対値の上限も、t ∈ [0, 1] について一様に0へ行きます。その差を t で積分しても、区間の長さ1を掛けた上限以下。従って ∂ⱼ∫₀¹g(x, t)dt = ∫₀¹∂ⱼg(x, t)dt です。ここで連続偏微分と閉矩形上の二次元の一様連続性を使いました。

線分方向の微分を、t の微分へまとめる

d = x − a、q(t) = a + td と書きます。積と連鎖律、および前の補題から、∂ⱼφ(x) は次の式になります。

∂jφ(x)=∫01[Fj(q)+t∑i=13di∂jFi(q)]dt

仮定 ∂ⱼFᵢ = ∂ᵢFⱼ を使えば、角括弧は Fⱼ(q(t)) + t(d/dt)Fⱼ(q(t)) = (d/dt){tFⱼ(q(t))} です。基本定理により ∂ⱼφ(x) = [tFⱼ(a + td)]₀¹ = Fⱼ(x)。F は連続なので φ は C¹、実際には F が C¹ のため φ は C² です。

逆に F = ∇φ で F が C¹ なら φ は C² なので、連続な二階偏微分の交換から ∂ᵢFⱼ = ∂ⱼFᵢ は必要です。この成分の一致を、第6章で「curl F = 0」とまとめて呼びます。今の証明はその記号にも、GreenやStokesの定理にも依存していません。

穴のある領域と大域ポテンシャル

同じ議論は二次元でも成り立ちます。原点を除いた平面 U = ℝ² ∖ {(0, 0)} で、F = (P, Q) = (−y/(x² + y²), x/(x² + y²)) を考えます。この場は U で C¹ で、直接微分すると ∂ᵧP = (y² − x²)/(x² + y²)² = ∂ₓQ。局所の対称性は満たします。

しかし単位円 r(t) = (cos t, sin t)、0 ≤ t ≤ 2π 上では F(r(t)) = (−sin t, cos t) = r′(t)。従って ∮F·dr = ∫₀²π1dt = 2π ≠ 0。基本定理より、U 全体でのポテンシャルは存在しません。原点で場を定義したことにしても連続にならず、仮定の穴は埋まりません。

同じ局所条件でも、領域を替えると大域結論が変わる
条件と領域言える結論検算・言えない結論
F=∇φ、F∈C¹、開集合成分偏微分が対称。φはC²となり混合偏微分を交換できる。
偏微分対称、開集合の小球内各点の近くにポテンシャル。小球は星形。離れた領域まで一つのφになるとは限らない。
偏微分対称、開星形領域一つの大域ポテンシャルを構成できる。基点からの全線分を領域内に置ける。
偏微分対称、原点を除いた平面局所条件だけでは大域φを保証しない。円の仕事2πが反例。穴をまたぐ線分も使えない。
全閉曲線の仕事0、開連結領域経路独立⇔大域ポテンシャル。有限個の閉曲線を試すだけでは「全閉曲線」を確認したことにならない。

穴のない一般領域に何を仮定すればよいか、という位相の一般論はここでは証明しません。星形は検査しやすい十分条件であって、ポテンシャルが存在するための必要条件ではありません。例えば原点を除いた平面でも、定数場 (1, 0) は φ = x を持ちます。

寄り道［数学の見方］：局所検査を全体の結論にする追加情報

偏微分の等式は、一点のすぐ近くの変化だけを見ています。一周の仕事は離れた点を順につないだ結果です。星形領域では、すべての点へ同じ作り方で線分を引けるので、局所検査を一つの積分公式へまとめられました。

反例が教えるのは「対称性は役立たない」ではなく、「領域の情報なしには全体を決めない」という限界です。定理の仮定には、関数の滑らかさと領域の形という異なる二種類の情報があります。

演習：ポテンシャルの構成と条件

1．星形の公式を実際に使う

ℝ³ 上の F = (2xy + z, x², x + 2z) について、基点0の線分公式からポテンシャルを求め、勾配を確認してください。

ヒント1：線分上へ代入する

F(tx, ty, tz)·(x, y, z) = 3t²x²y + 2txz + 2tz² です。

ヒント2：t で積分する

∫₀¹3t²dt = 1、∫₀¹2tdt = 1。

解答

φ = x²y + xz + z²。偏微分は (2xy + z, x², x + 2z) で F に一致します。ℝ³ は0について星形で、F は C¹。成分の交差偏微分もそれぞれ 2x、1、0 で対応する相手と一致し、構成定理の仮定を満たします。

2．穴と反転

本章の原点除外平面の場を、半径 R > 0 の円 r(t) = (R cos t, R sin t)、0 ≤ t ≤ 2π で積分してください。向きを逆にするとどうなりますか。

ヒント1：分母は R²

F(r(t)) = (−sin t/R, cos t/R) です。

ヒント2：速度の R と相殺する

r′(t) = (−R sin t, R cos t)。内積を取ります。

解答

内積は1なので半径によらず2π、逆向きなら−2πです。R = 0 は曲線が場の定義域に入らないので許されません。R を小さくしても一周の積分が消えないことは、原点まで連続に場を拡張できないことと整合します。

3．星形でなければ必ず失敗するか

U = ℝ² ∖ {(0, 0)} で F = (2x, 2y) とします。ポテンシャルと閉曲線の積分を求め、「U が星形でないのでポテンシャルがない」という推論を検討してください。

ヒント1：二乗和を微分する

φ = x² + y² は U でも定義されています。

ヒント2：十分条件と必要条件

星形構成が使えないことと、別の方法で φ を作れないことは違います。

解答

∇φ = (2x, 2y) なのでポテンシャルは存在し、U 内のすべての閉曲線の積分は0です。星形性は本章の構成定理の十分条件で、必要条件ではありません。領域に穴があると対称性だけで結論は出ませんが、すべての場が失敗するわけでもありません。
