数学的帰納法と有限の観察

1 から n までの和を Sₙ とすると、S₁ = 1、S₂ = 3、S₃ = 6、S₄ = 10 です。Sₙ = n(n + 1)/2 という式を予想したとしましょう。いくつか代入して確かめても、有限の観察だけでは、すべての n を説明できません。しかし n の場合から n + 1 の場合へ、いつでも進めるならどうでしょうか。

数学的帰納法は、最初の一段と、次へ進む共通の仕組みによって、整数上の無限個の主張を示します。日常の「いくつかの例から一般化する」という意味の帰納とは違い、論理的な証明法です。使えるのは、自然数が最初から一段ずつ進んで尽くされるという構造を持つからです。

この章では、和の公式を証明した後で、「公式はどう見付けるのか」「一段の仮定だけで足りないときはどうするか」「開始位置や初期値を変えると何が変わるか」を調べます。P(n) は、整数 n を一つ決めると真か偽かが定まる文を表します。たとえば P(n) を「1からnまでの和がn(n+1)/2である」と読めばよく、特別な記号操作を意味しません。

学習の目安は演習を含めて110–160分です。原理と和の計算、漸化式と強い帰納法、成立範囲と演習の三回に分けても構いません。演習1–3で基本を確かめ、4–7で証明を作り、8–10で誤った議論の修正や条件の設計を行います。

数学的帰納法の原理と最小反例

数学的帰納法の原理

整数 n ≥ n₀ に対する命題 P(n) を考えます。P(n₀) が真であり、すべての整数 k ≥ n₀ に対して P(k) ⇒ P(k + 1) が成り立つなら、すべての整数 n ≥ n₀ で P(n) は真です。

最初の確認を基底、P(k) から P(k + 1) へ進む部分を帰納段階と呼びます。帰納段階では P(k) を一時的に仮定してよく、これを帰納法の仮定と呼びます。ただし k は特定の一個ではなく、範囲内の任意の整数です。仮定してよいのは P(k) であり、これから示す P(k + 1) ではありません。

なぜこの仕組みでよいのか

ここでは、空でない正の整数の集合には最小要素があるという性質を前提にします。添字を n − n₀ + 1 と読み替えれば、n ≥ n₀ の範囲でもこの最小性が使えます。もし P が偽となる n があれば、その中で最小のものを m とします。基底から m ≠ n₀ なので m > n₀ です。m − 1 は範囲内で m より小さいため P(m − 1) は真。帰納段階により P(m) も真となり、矛盾します。偽となる最初の場所が存在できないので、すべてで成り立ちます。

出発点だけでは、その先に届きません。次へ進む橋だけでは、そもそもどこから進めるかが分かりません。二つの条件は役割が異なり、片方を省くことはできません。

自然数の和の公式と帰納法

1 + 2 + ⋯ + n = n(n + 1)/2 の証明

n = 1 では左辺も右辺も 1 で、基底は成立します。次に k ≥ 1 とし、1 + 2 + ⋯ + k = k(k + 1)/2 を仮定します。次の和はこれに k + 1 を足したものなので、1 + 2 + ⋯ + k + (k + 1) = k(k + 1)/2 + (k + 1) = (k + 1)(k + 2)/2 です。これは n = k + 1 のときの公式そのものです。したがって帰納法により、すべての整数 n ≥ 1 で公式が成り立ちます。

この証明では、n = k + 1 の式がどんな形かを先に見ておくと、計算の目標が明確になります。k を k + 1 に置き換えるので、二つ目の因子も k + 1 ではなく k + 2 に変わります。文字を機械的に一つ足すのでなく、「次の場合の主張をまるごと書く」と誤りが減ります。

和の帰納段階を作る：差と因数分解

和の公式を知っていることと、帰納段階を組み立てられることは別です。Sk+1の最後の項だけを外すとSkが残るので、和の問題では「次の和−今の和」を見るのが自然です。先ほどの公式なら、右辺の候補F(n)=n(n+1)/2についても F(k+1)−F(k)=(k+1)((k+2)−k)/2=k+1。この差が、左辺で新たに加えた項と一致しています。

例題：平方の和の公式を最後まで確かめる

1²+2²+⋯+n²=n(n+1)(2n+1)/6 を、すべての整数n≥1で示します。最初に目標を丸ごと書くと、n=k+1での右辺は (k+1)(k+2)(2k+3)/6 です。2n+1を2k+2にしてしまわないようにします。

基底n=1では、1·2·3/6=1です。kの場合を仮定して最後の平方(k+1)²を足すと、次の計算になります。

k(k+1)(2k+1)6+(k+1)2=(k+1)[k(2k+1)+6(k+1)]6=(k+1)(2k2+7k+6)6=(k+1)(k+2)(2k+3)6

目標に(k+1)があるので、まず共通因子(k+1)をくくります。残った2k²+7k+6を、目標にある(k+2)(2k+3)へ因数分解する方針です。これで帰納段階が示されました。検算としてn=2なら右辺2·3·5/6=5、左辺1+4=5です。この検算は計算ミスを見つける助けであり、すべてのnの証明は基底と任意のkの計算が担います。

逆に、右辺から左辺へ変形しても構いません。ただし「示したい式が成り立つ」と仮定して両辺を同時に書き換えるときは、各変形が逆向きにも戻せるかを確認します。ここでは既知の和に一項を加えた式から出発したので、結論を先取りしていません。

漸化式と一般項の帰納法による確認

a₀ = 1、aₙ₊₁ = 2aₙ + 1 と定めた数列を考えます。このように初めの値を指定し、既に定まった値から次の値を順に作るのが再帰的な定義です。その値どうしの関係を表す式を漸化式と呼びます。添字は0から始まります。まず a₁=2·1+1=3、a₂=2·3+1=7、a₃=2·7+1=15 と、直前の値を順に入れて計算します。

1、3、7、15のままでは規則が見えにくくても、それぞれに1を足すと2、4、8、16です。実際、漸化式の両辺へ1を足せば aₙ₊₁+1=2(aₙ+1) となり、「1を足した値」は毎回二倍になります。ここから aₙ+1=2ⁿ⁺¹、つまり aₙ=2ⁿ⁺¹−1 と予想できます。次は、この発見を全ての n についての証明に直します。

漸化式から公式を確かめる

n = 0 では 2¹ − 1 = 1 = a₀ です。aₖ = 2ᵏ⁺¹ − 1 と仮定すると、定義の漸化式より aₖ₊₁ = 2(2ᵏ⁺¹ − 1) + 1 = 2ᵏ⁺² − 1 です。これは k + 1 の場合の式なので、すべての整数 n ≥ 0 で予想した公式が成り立ちます。

公式を発見する段階では、表を作ったり、aₙ + 1 に注目したりしてかまいません。証明の段階では、初期値と漸化式に合うことを確認します。発見の方法を、証明に必要な順番と無理に一致させる必要はありません。後の級数でも、まず有限の部分和についてこのような式を示してから、その極限を調べます。

初期値を変えた漸化式と補助量

an+1=2an+1では、なぜ1を足したのでしょう。漸化式の両辺へ同じ定数cを足して、an+1+c=2(an+c)という「二倍するだけ」の式を作りたいからです。左辺は2an+1+c、右辺は2an+2c。等しくするには1+c=2c、つまりc=1です。偶然に見える工夫も、ほしい式を逆に書けば選べます。

例題：同じ更新規則から異なる数列ができる

初期値だけをa0=Aに変えます。Aは固定した整数です。bn=an+1と置けばb0=A+1、bn+1=2bn。従って候補はbn=(A+1)2nで、元に戻すとan=(A+1)2n−1です。

帰納法で確認すると、n=0で(A+1)−1=A。ak=(A+1)2k−1を仮定したとき、ak+1=2[(A+1)2k−1]+1=(A+1)2k+1−1となります。A=1なら先ほどの2n+1−1、A=0なら2n−1。A=−1ならどの項も−1で、実際2(−1)+1=−1です。毎回二倍する項があるからといって、すべての初期値で数列が増えるとは限りません。

逆算もできます。a3=23にしたければ、8(A+1)−1=23よりA=2です。実際に2→5→11→23となり、初期値も整数という条件を満たします。一方a3=24ならA=17/8となり、整数の初期値からは作れません。式を解いた後に、問題の数の範囲へ戻って確かめます。

同じ漸化式だけでは数列は一つに決まりません。初期値まで一致する二つの数列は、最初の項が等しく、等しい項から同じ次の項が作られるので、帰納法で全項が等しくなります。一般項の確認が役に立つのは、この一意性、つまり条件を満たす数列が一つしかないという理由もあるからです。

強い帰納法と二つ前の項を使う漸化式

直前の一項ではなく、その前の項も使う場合があります。強い帰納法では、n0からkまでのすべての主張を仮定し、P(k+1)を示します。使える仮定は増えますが、結論を先取りするのではありません。「P(n0)かつ…かつP(k)」という一つの主張を通常の帰納法でつないでいる、と考えれば同じ原理に戻ります。

例題：二つの直前の項から上限を伝える

f0=0、f1=1、n≥0でfn+2=fn+1+fnと定めます。最初の項は0,1,1,2,3,5です。すべてのn≥0で0≤fn≤2nを示しましょう。和で次を作るので、既知の二項を同時に押さえる方針を取ります。

n=0,1では0≤0≤1、0≤1≤2で成立します。k≥1とし、0からkまで成り立つと仮定すると、使うのは特にkとk−1の場合です。0≤fk+1=fk+fk−1≤2k+2k−1=3·2k−1≤4·2k−1=2k+1。二つ前までの仮定で、次の主張を得ました。k=1でf2へ進めるよう、基底を二個確認したことが効きます。

たとえばf5=5≤32です。上限はぴったりの公式ではなく、簡単な式で必ず押さえるためのものです。f0だけを確認し、次の式にまだ定義していないf−1を持ち込む証明はできません。添字の範囲も計算の条件です。

二項ずつを一組とする通常の帰納法でも示せます。「0≤fk≤2kかつ0≤fk+1≤2k+1」を一つの主張にすれば、次は共通のfk+1と新しいfk+2を押さえます。必要な情報を組にして渡すか、それ以前をすべて仮定するかの違いです。問題に合う、書きやすい方を選べます。

帰納法の基底・帰納段階と成立範囲

「すべての n ≥ 1 で 2ⁿ ≥ n²」と言い、n = 1 を確かめた後で、「2ᵏ⁺¹ = 2·2ᵏ ≥ 2k² ≥ (k + 1)²」と続けたらどうでしょう。最後の不等式は常に真ではありません。k = 2 では 8 ≥ 9 となって失敗します。実際、元の主張も n = 3 で偽です。帰納法の形式をなぞるだけでは、その中の計算は保証されません。

この主張は範囲を n ≥ 4 に直せば証明できます。基底は 2⁴ = 4²。k ≥ 4 なら 2k² − (k + 1)² = (k − 1)² − 2 ≥ 7 > 0 なので、先ほどの帰納段階が正当になります。反例を見つけた後、どの範囲なら同じ考えが働くかを調べることも、数学の前進です。

帰納段階から開始位置と基底を決める

2n≥n²の例では、帰納段階の最後に必要だった条件は2k²≥(k+1)²、すなわちk²−2k−1≥0でした。整数k≥3なら(k−1)²−2≥2なので、この補助不等式は成り立ちます。それでもn=3から始められないのは、基底2³≥3²が偽だからです。段階を使える範囲と、最初に真になる位置は別々に調べます。n=4の基底とk≥4の段階を使う先ほどの証明は、この両方を満たしています。

また、P(k)⇒P(k+2)という橋は、奇数から奇数へ、偶数から偶数へ進みます。n≥1の全体を覆いたければP(1)とP(2)の二つが必要です。一般にd段ずつ進むなら、開始範囲に連続するd個の基底を用意すると、どの整数もそのいずれかから何回か進んだ位置になります。これは基底をただ増やす作業ではなく、どの添字へ届くかの確認です。

寄り道［応用］：巨大なべき乗を、二進法で少しずつ作る

プログラミング言語 Go の多倍長整数の実装には、指数を二進法で一桁ずつ読み、平方し、必要なら元の数を一回掛ける計算が現れます。例えば 13 は二進法で 1101。a の指数を 1 → 3 → 6 → 13 と進めれば、a¹³ を作れます。毎回 a を一個ずつ掛けるより、途中の結果を大きく再利用できます。

正しさの核は短い帰納法です。読み終えた桁の値が p、計算結果が aᵖ だとします。次の桁 b が 0 か 1 なら、新しい指数は 2p + b。平方して、b = 1 のときだけ a を掛けると、結果はちょうど a²ᵖ⁺ᵇ になります。最初の一桁も合うので、何桁進んでも意味が保たれます。帰納法は無限の公式だけでなく、繰り返す手順を信頼する理由にもなるのです。

演習：帰納法の適用と検証

1．奇数を足すと平方になる

すべての整数 n ≥ 1 について、1 + 3 + ⋯ + (2n − 1) = n² を帰納法で示してください。

ヒント1：次に足す数を指定する

n = k + 1 で最後に加える奇数は 2k + 1 です。

ヒント2：平方の展開を使う

帰納法の仮定を入れると k² + 2k + 1 が現れます。

解答

n = 1 では 1 = 1²。k の場合を仮定すると、次の和は k² + (2k + 1) = (k + 1)² です。基底と帰納段階が示せたので、すべての n ≥ 1 で成り立ちます。

2．初期値も忘れずに

b₀ = 0、bₙ₊₁ = bₙ + 2n + 1 とします。bₙ = n² がすべての整数 n ≥ 0 で成り立つことを示してください。

ヒント1：0 から始める

最初の主張は b₀ = 0² です。

ヒント2：定義と仮定を順に使う

bₖ₊₁ = bₖ + 2k + 1 に bₖ = k² を入れます。

解答

b₀ = 0 = 0² で基底が成立します。bₖ = k² と仮定すれば bₖ₊₁ = k² + 2k + 1 = (k + 1)²。よって帰納法から公式が成り立ちます。これは最初の n 個の奇数を足す関係を、漸化式で書いたものです。

3．到達できない整数を見つける

P(1) と「すべての k ≥ 1 で P(k) ⇒ P(k + 2)」だけから、すべての n ≥ 1 で P(n) と言えるでしょうか。言えないなら反例となる性質を挙げてください。

ヒント1：出発点から並べる

1 の次は 3、その次は 5 です。2 へは進めますか。

ヒント2：奇数だけで成り立つ性質を使う

P(n) を「n は奇数」とした場合に、二つの条件を調べます。

解答

言えません。P(n) を「n は奇数」とすると P(1) は真で、奇数に 2 を足せば奇数なのでP(k) ⇒ P(k + 2) も真です。しかし P(2) は偽です。すべてに届けるには、P(2) の確認も必要です。

4．最後の項と開始添字を選ぶ

すべての整数n≥0について、1+2+2²+⋯+2n=2n+1−1を示してください。和はn=0のとき一項だけです。次の和に加える項も明記してください。

ヒント1

項の個数はn+1です。n=k+1で最後に加えるのは2k+1です。

ヒント2

既知の和2k+1−1に、その最後の項を足します。

解答

n=0では1=2¹−1。kの場合を仮定すると次の和は(2k+1−1)+2k+1=2·2k+1−1=2k+2−1で、k+1の場合になります。n=1でも1+2=3と確認できます。最初の一項を空の和と取り違えないことが基底の確認です。

5．割り切れることを伝える

すべての整数n≥0で7n−1が6で割り切れることを、帰納法で示してください。「6で割り切れる」とは、ある整数mを使って6mと書けることです。

ヒント1

7k+1−1を、7(7k−1)と残りに分けます。

ヒント2

7k+1−1=7(7k−1)+6です。

解答

n=0では7⁰−1=0=6·0。7k−1=6m（mは整数）と仮定すると、7k+1−1=7·6m+6=6(7m+1)で、括弧内も整数です。よって全n≥0で成立します。n=2では48=6·8と検算できます。単に値が増えることではなく、整数倍という形を次へ残しました。

6．補助量を選んで一般項を発見する

c0=2、cn+1=3cn+2とします。cnへ定数を足して「三倍するだけ」の式にし、一般項を予想して帰納法で証明してください。

ヒント1

cn+1+t=3(cn+t)にしたければ、2+t=3tが必要です。

ヒント2

t=1です。c0+1=3から始まります。

解答

cn+1は毎回三倍なので、候補はcn=3n+1−1です。n=0では3−1=2。kの場合を仮定するとck+1=3(3k+1−1)+2=3k+2−1で、次の場合の式になります。定義から2→8→26、公式でもn=1,2で8,26と一致します。定数を選ぶ段階と、全添字で確かめる段階を分けました。

7．四つの基底が必要な構成

4点と7点の札を何枚でも使える自作の得点模型を考えます。すべての整数n≥18がn=4a+7b（a,bは0以上の整数）と表せることを示してください。また17点が作れないことも確かめ、開始位置18の意味を説明してください。

ヒント1

作れた点数に4を足せます。18,19,20,21をまず作ると、四つの系列へ進めます。

ヒント2

18=4+2·7、19=3·4+7です。17の場合には7点札は0,1,2枚しか使えません。

解答

基底は18=4+2·7、19=3·4+7、20=5·4、21=3·7です。k≥21とし18からkまで作れると仮定すると、k+1−4=k−3は18以上k以下なので作れます。それに4点札を一枚加えればk+1も作れます。強い帰納法で全n≥18を示せました。17ではb≤2ですが、17−7bは順に17,10,3で、どれも4の倍数でありません。従って17は作れず、「それ以上は全部作れる」という開始位置は18が最小です。

8．重なりを使う証明の切れ目

「どんなn個の実数も全部等しい」という誤った主張に、次の帰納法が付いています。「一個なら自明。k+1個のうち最初のk個は仮定から等しく、最後のk個も等しい。重なる数があるので全体が等しい」。どの段階が壊れていますか。具体的な数で示してください。

ヒント1

最初のk個と最後のk個の共通部分は何個ですか。

ヒント2

k=1では、二個のうち一個ずつを見ることになります。

解答

k=1から2へ進む段階で共通部分は0個です。たとえば二個の数0,1なら、最初の一個も最後の一個も「その中の数はすべて等しい」を満たしますが、0と1を結ぶ共通の数がありません。k≥2で使える重なりをk=1にも使ったのが誤りです。基底が真でも、すべてのkで帰納段階が成り立たなければ全体は示せません。

9．成立する最小の開始位置を決める

n!は1からnまでの積です。すべての整数n≥Nでn!>2nとなる最小の正の整数Nを求め、その範囲で帰納法を完成してください。

ヒント1

n=1,2,3,4を調べてから、(k+1)!=(k+1)k!を使います。

ヒント2

k!>2kを、正の数k+1で掛けます。k≥4ならk+1>2です。

解答

1<2、2<4、6<8ですが、4!=24>16=2⁴。k≥4で仮定すると(k+1)!=(k+1)k!>(k+1)2k>2·2k=2k+1です。よってn≥4で成立します。n=3が偽なのでNを3以下にはできず、最小はN=4です。基底と、段階内で掛けた数の正負をともに確認しました。

10．整数の初期値から到達できる値を逆算する

a0=A、an+1=2an+1で、Aは整数とします。固定した整数m≥0と整数Tに対し、am=TとなるAが存在する必要十分条件を述べてください。その条件でm=4、T=31とT=30を判定してください。

ヒント1

本文で証明したam=(A+1)2m−1を使い、Aについて解きます。

ヒント2

A=(T+1)/2m−1が整数であるための条件です。条件を満たせば代入でも確かめます。

解答

必要十分条件はT+1が2mで割り切れることです。必要性はT+1=(A+1)2mから、十分性はそのときの整数A=(T+1)/2m−1を選び公式へ代入することから従います。m=4、T=31ではA=32/16−1=1で、1→3→7→15→31。T=30では31は16で割り切れず、整数Aは存在しません。m=0でも2⁰=1なので任意のTが許され、A=Tと初期値の意味に一致します。
