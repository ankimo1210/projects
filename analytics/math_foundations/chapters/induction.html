数学的帰納法と有限の観察

1 から n までの和を Sₙ とすると、S₁ = 1、S₂ = 3、S₃ = 6、S₄ = 10 です。Sₙ = n(n + 1)/2 という式を予想したとしましょう。いくつか代入して確かめても、有限の観察だけでは、すべての n を説明できません。しかし n の場合から n + 1 の場合へ、いつでも進めるならどうでしょうか。

数学的帰納法は、最初の一段と、次へ進む共通の仕組みによって、整数上の無限個の主張を示します。日常の「いくつかの例から一般化する」という意味の帰納とは違い、論理的な証明法です。使えるのは、自然数が最初から一段ずつ進んで尽くされるという構造を持つからです。

数学的帰納法の原理と最小反例

数学的帰納法の原理

整数 n ≥ n₀ に対する命題 P(n) を考えます。P(n₀) が真であり、すべての整数 k ≥ n₀ に対して P(k) ⇒ P(k + 1) が成り立つなら、すべての整数 n ≥ n₀ で P(n) は真です。

最初の確認を基底、P(k) から P(k + 1) へ進む部分を帰納段階と呼びます。帰納段階では P(k) を一時的に仮定してよく、これを帰納法の仮定と呼びます。ただし k は特定の一個ではなく、範囲内の任意の整数です。仮定してよいのは P(k) であり、これから示す P(k + 1) ではありません。

なぜこの仕組みでよいのか

ここでは、空でない正の整数の集合には最小要素があるという性質を前提にします。添字を n − n₀ + 1 と読み替えれば、n ≥ n₀ の範囲でもこの最小性が使えます。もし P が偽となる n があれば、その中で最小のものを m とします。基底から m ≠ n₀ なので m > n₀ です。m − 1 は範囲内で m より小さいため P(m − 1) は真。帰納段階により P(m) も真となり、矛盾します。偽となる最初の場所が存在できないので、すべてで成り立ちます。

出発点だけでは、その先に届きません。次へ進む橋だけでは、そもそもどこから進めるかが分かりません。二つの条件は役割が異なり、片方を省くことはできません。

自然数の和の公式と帰納法

1 + 2 + ⋯ + n = n(n + 1)/2 の証明

n = 1 では左辺も右辺も 1 で、基底は成立します。次に k ≥ 1 とし、1 + 2 + ⋯ + k = k(k + 1)/2 を仮定します。次の和はこれに k + 1 を足したものなので、1 + 2 + ⋯ + k + (k + 1) = k(k + 1)/2 + (k + 1) = (k + 1)(k + 2)/2 です。これは n = k + 1 のときの公式そのものです。したがって帰納法により、すべての整数 n ≥ 1 で公式が成り立ちます。

この証明では、n = k + 1 の式がどんな形かを先に見ておくと、計算の目標が明確になります。k を k + 1 に置き換えるので、二つ目の因子も k + 1 ではなく k + 2 に変わります。文字を機械的に一つ足すのでなく、「次の場合の主張をまるごと書く」と誤りが減ります。

漸化式と一般項の帰納法による確認

a₀ = 1、aₙ₊₁ = 2aₙ + 1 と定めた数列を考えます。このように前の値を使って次の値を定める関係を漸化式と呼びます。最初から計算すると 1、3、7、15 と続き、aₙ = 2ⁿ⁺¹ − 1 が予想できます。添字が 0 から始まっていることに注意しましょう。

漸化式から公式を確かめる

n = 0 では 2¹ − 1 = 1 = a₀ です。aₖ = 2ᵏ⁺¹ − 1 と仮定すると、定義の漸化式より aₖ₊₁ = 2(2ᵏ⁺¹ − 1) + 1 = 2ᵏ⁺² − 1 です。これは k + 1 の場合の式なので、すべての整数 n ≥ 0 で予想した公式が成り立ちます。

公式を発見する段階では、表を作ったり、aₙ + 1 に注目したりしてかまいません。証明の段階では、初期値と漸化式に合うことを確認します。発見の方法を、証明に必要な順番と無理に一致させる必要はありません。後の級数でも、まず有限の部分和についてこのような式を示してから、その極限を調べます。

帰納法の基底・帰納段階と成立範囲

「すべての n ≥ 1 で 2ⁿ ≥ n²」と言い、n = 1 を確かめた後で、「2ᵏ⁺¹ = 2·2ᵏ ≥ 2k² ≥ (k + 1)²」と続けたらどうでしょう。最後の不等式は常に真ではありません。k = 2 では 8 ≥ 9 となって失敗します。実際、元の主張も n = 3 で偽です。帰納法の形式をなぞるだけでは、その中の計算は保証されません。

この主張は範囲を n ≥ 4 に直せば証明できます。基底は 2⁴ = 4²。k ≥ 4 なら 2k² − (k + 1)² = (k − 1)² − 2 ≥ 7 > 0 なので、先ほどの帰納段階が正当になります。反例を見つけた後、どの範囲なら同じ考えが働くかを調べることも、数学の前進です。

寄り道［応用］：巨大なべき乗を、二進法で少しずつ作る

プログラミング言語 Go の多倍長整数の実装には、指数を二進法で一桁ずつ読み、平方し、必要なら元の数を一回掛ける計算が現れます。例えば 13 は二進法で 1101。a の指数を 1 → 3 → 6 → 13 と進めれば、a¹³ を作れます。毎回 a を一個ずつ掛けるより、途中の結果を大きく再利用できます。

正しさの核は短い帰納法です。読み終えた桁の値が p、計算結果が aᵖ だとします。次の桁 b が 0 か 1 なら、新しい指数は 2p + b。平方して、b = 1 のときだけ a を掛けると、結果はちょうど a²ᵖ⁺ᵇ になります。最初の一桁も合うので、何桁進んでも意味が保たれます。帰納法は無限の公式だけでなく、繰り返す手順を信頼する理由にもなるのです。

演習：帰納法の適用と検証

1．奇数を足すと平方になる

すべての整数 n ≥ 1 について、1 + 3 + ⋯ + (2n − 1) = n² を帰納法で示してください。

ヒント1：次に足す数を指定する

n = k + 1 で最後に加える奇数は 2k + 1 です。

ヒント2：平方の展開を使う

帰納法の仮定を入れると k² + 2k + 1 が現れます。

解答

n = 1 では 1 = 1²。k の場合を仮定すると、次の和は k² + (2k + 1) = (k + 1)² です。基底と帰納段階が示せたので、すべての n ≥ 1 で成り立ちます。

2．初期値も忘れずに

b₀ = 0、bₙ₊₁ = bₙ + 2n + 1 とします。bₙ = n² がすべての整数 n ≥ 0 で成り立つことを示してください。

ヒント1：0 から始める

最初の主張は b₀ = 0² です。

ヒント2：定義と仮定を順に使う

bₖ₊₁ = bₖ + 2k + 1 に bₖ = k² を入れます。

解答

b₀ = 0 = 0² で基底が成立します。bₖ = k² と仮定すれば bₖ₊₁ = k² + 2k + 1 = (k + 1)²。よって帰納法から公式が成り立ちます。これは最初の n 個の奇数を足す関係を、漸化式で書いたものです。

3．到達できない整数を見つける

P(1) と「すべての k ≥ 1 で P(k) ⇒ P(k + 2)」だけから、すべての n ≥ 1 で P(n) と言えるでしょうか。言えないなら反例となる性質を挙げてください。

ヒント1：出発点から並べる

1 の次は 3、その次は 5 です。2 へは進めますか。

ヒント2：奇数だけで成り立つ性質を使う

P(n) を「n は奇数」とした場合に、二つの条件を調べます。

解答

言えません。P(n) を「n は奇数」とすると P(1) は真で、奇数に 2 を足せば奇数なので推移条件も真です。しかし P(2) は偽です。すべてに届けるには、P(2) の確認も必要です。

自分の言葉で

  2. 帰納法の仮定を使うことは、結論を先に仮定する循環論法とどう違いますか。
  3. 一つ反例があった主張を、範囲を変えて正しい定理に直すには何を調べますか。
