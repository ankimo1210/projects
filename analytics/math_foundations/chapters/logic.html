命題と条件

「どの人にも、好きな本が一冊ある」と「ある一冊の本を、どの人も好きだ」は違います。前者では人ごとに本を選び直せますが、後者では全員に共通する一冊が必要です。数学でも、使う言葉の順番が、用意すべき答えを変えます。計算を始める前に、その文章が何を要求しているかを読めるようになりましょう。

真か偽かが定まる文章を命題と呼びます。「3 は奇数だ」は命題です。一方「x は奇数だ」は、x の範囲や値を決めなければ真偽が定まりません。文字を含む条件を P(x) と書き、対象を一つ入れたときの命題だと考えます。この章では、整数と実数の通常の計算を使います。数の種類は数の拡張でも整理します。

全称量化・存在量化と量化の順序

全称の「すべての x で P(x)」を ∀x P(x)、存在の「ある x で P(x)」を ∃x P(x) と書きます。存在という言葉は、ちょうど一つという意味ではありません。一つ以上あれば十分です。また「すべて」と言うときには、すべての整数なのか、すべての正の実数なのか、必ず範囲を指定します。

選び直せる数と、固定しなければならない数

実数について「∀x ∃y：y > x」は真ですが、「∃y ∀x：y > x」は偽です。どちらも x、y は実数を動きます。

短い証明

前者では x がどの実数でも、その x に応じて y = x + 1 を選べば y > x です。後者が真だとすると、一つの実数 y がすべての実数 x より大きくなります。しかし x = y を選ぶと y > y が必要になり、これは成り立ちません。したがって後者を満たす y はありません。

記号を左から読むと、どこまで値に依存してよいかが見えます。∀x の後に ∃y があるなら、y は x を見て決められます。∃y が先なら、その後どんな x が来ても同じ y で対応しなければなりません。この依存関係は、後の極限の定義で、小さい誤差の要求に応じてどこから先を見るかを選ぶときにも現れます。

命題と量化命題の否定

P の否定とは、P が真なら偽、偽なら真になる命題です。「すべての対象が P を満たす」の否定は、「P を満たさない対象が少なくとも一つある」です。「どれも P を満たさない」ではありません。観察と反例で、一つの反例が全称命題を崩せたのは、この仕組みによります。

同様に「ある対象が P を満たす」の否定は、「どの対象も P を満たさない」です。量化記号をまたいで否定を中へ入れると、∀ と ∃ が入れ替わります。たとえば「∀x ∃y：y > x」の否定は、「∃x ∀y：y ≤ x」です。最後の不等号にも注意しましょう。y > x が成り立たない範囲には、等しい場合も含まれます。

条件を組み合わせる「P かつ Q」の否定は「P でない、または Q でない」です。「P または Q」の否定は「P でも Q でもない」です。数学での「または」は、特に断らなければ両方が真の場合も含みます。整数が「2 の倍数、または 3 の倍数」であると言うとき、6 を除外する意図はありません。

含意・必要条件・十分条件

含意 P ⇒ Q は、「P が成り立つのに Q が成り立たない場合はない」という主張です。P が偽の場合について、Q が真か偽かを指定していません。「整数 n が 4 の倍数なら n は偶数」は、n = 4k と書けば n = 2(2k) だから真です。しかし偶数すべてが 4 の倍数とは限らず、n = 2 が反例です。矢印を逆にした Q ⇒ P は逆といい、別の主張です。

P ⇒ Q が成り立つとき、P は Q の十分条件、Q は P の必要条件です。4 の倍数であることは偶数であるために十分で、偶数であることは 4 の倍数であるために必要です。「十分」はそれだけで結論まで届くこと、「必要」は欠けると前提を満たせないこと、と読むと向きが見えます。両方向が成り立つときは同値 P ⇔ Q と書き、必要十分条件と呼びます。

含意の否定は「P かつ Q でない」です。「P ならば Q でない」ではありません。たとえば「すべての実数 x で、x² = 1 なら x = 1」を否定するには、x² = 1 と x ≠ 1 を同時に満たす x を示します。x = −1 がそれです。前提を満たさない x = 0 を選んでも、反例にはなりません。

日常の「ならば」には原因や時間の順序を感じることがありますが、数学の含意が述べるのは条件の関係です。また全体が真でも、前提を満たす対象が存在するとは限りません。「x² = −1 である実数 x なら x = 0」という含意は、前提を満たす実数がないため反例を持ちません。解の存在を主張したいなら、存在は別に示す必要があります。

寄り道［応用］：データベースにも「すべて」と「ある」がある

実際のデータベース PostgreSQL には、複数の値との比較をまとめる ALL と ANY があります。数 x が一覧のすべてより大きいなら ALL、一つでも大きい相手があれば ANY が真です。例えば一覧が 10 と 20、x が 15 なら、前者は偽、後者は真になります。数式の量化が、検索条件の意味を決めているのです。

面白いのは空の一覧です。仕様では ALL は真、ANY は偽。「反例が一つもない」と「満たす相手が一つある」は、対象が空のときにはっきり分かれます。ここでは欠損値 NULL を含まない通常の数を考えました。NULL が入る SQL には「不明」という別の結果もあり、数学の二値の真偽をそのまま移す前に、対象と規則を確認する必要があります。

演習：量化と必要十分条件

1．量化記号のある文を否定する

x、M は実数とします。「すべての x に対して、x < M となる M がある」の否定を、記号を使わずに述べてください。

ヒント1：外側から否定する

「すべての x」の否定では、「ある x」が現れます。

ヒント2：等しい場合を忘れない

「ある M で x < M」の否定は「すべての M で x ≥ M」です。

解答

「ある実数 x が存在し、すべての実数 M に対して x ≥ M である」です。この否定文自体は偽です。どんな候補 x に対しても M = x + 1 を選べば成立しないからです。

2．必要条件と十分条件

実数 x について、x > 2 は x² > 4 の必要条件、十分条件のどちらですか。逆向きも成り立つか確かめてください。

ヒント1：正の数を掛ける

x > 2 なら x は正です。両辺を二乗したときの大小を考えます。

ヒント2：逆では負の数を試す

x = −3 は x² > 4 を満たしますか。

解答

x > 2 なら x² > 4 なので十分条件です。しかし x = −3 では x² = 9 > 4 でも x > 2 でないため、必要条件ではありません。範囲を x ≥ 0 に限定すれば逆も成り立ち、必要十分条件になります。

3．反例になっているか

「整数 n で、n が 6 の倍数なら n は 4 の倍数だ」に対し、n = 4、6、12 のどれが反例ですか。

ヒント1：前提を満たすか調べる

反例には、まず 6 の倍数であることが必要です。

ヒント2：結論は失敗している必要がある

6 の倍数の候補のうち、4 の倍数でないものを探します。

解答

n = 6 だけが反例です。4 は前提を満たしません。12 は前提と結論を両方満たします。一つの命題を崩すには、前提が真で結論が偽となる同じ対象を選ぶ必要があります。

  2. 「すべて正しい」の否定を、「すべて誤り」としてはいけないのはなぜですか。
  3. 十分条件と必要条件を、矢印を一本描いて説明してください。
