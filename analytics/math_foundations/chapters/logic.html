命題と条件

「どの人にも、好きな本が一冊ある」と「ある一冊の本を、どの人も好きだ」は違います。前者では人ごとに本を選び直せますが、後者では全員に共通する一冊が必要です。数学でも、使う言葉の順番が、用意すべき答えを変えます。計算を始める前に、その文章が何を要求しているかを読めるようになりましょう。

真か偽かが定まる文章を命題と呼びます。「3 は奇数だ」は命題です。一方「x は奇数だ」は、x の範囲や値を決めなければ真偽が定まりません。文字を含む条件を P(x) と書き、対象を一つ入れたときの命題だと考えます。学習の目安は演習込み100–150分です。演習1–3は記号と反例、4–7は範囲・否定・依存関係、8–10は条件の設計を扱います。この章では、整数と実数の通常の計算を使います。数の種類は数の拡張でも整理します。

有限の表における全称と存在

まず、最初の本の話を、三人と三冊だけの自作例で最後まで確かめます。○を「その人がその本を好き」、×を「好きではない」とします。好みの程度は考えず、この二通りだけを記録した理想化です。「好きな本がある」を調べるなら、一行の中に○があるかを見ます。「全員が好きな本がある」を調べるなら、一列を固定して縦に見なければなりません。

各行に○はあるが、全部が○の列はない
人本A本B本C
人1○××
人2×○×
人3○×○

例題：同じ表から二つの文を判定する

「どの人にも好きな本がある」は真です。人1にはA、人2にはB、人3にはA（またはC）を選べばよく、三人全員を覆いました。「ある一冊の本を全員が好き」は偽です。候補Aは人2が、Bは人1が、Cも人1が好きではありません。三冊すべての候補を崩したので、共通する一冊はありません。

後者を否定するのに「どの本も誰にも好かれない」まで示す必要はありません。各本について、その本を好きでない人が少なくとも一人いれば十分です。その人も本ごとに選び直せます。表の判定は有限の全調査です。人数や本の数が無限の場合は、同じ形の理由が全対象を覆うように別途説明します。

逆に、全員が好きな一冊があれば、各人にも好きな本があります。その共通の一冊を全員に選べるからです。従って二つの文は無関係なのではなく、一方から他方は従い、逆方向はこの表で失敗します。これから導入する記号は、この選び方の違いを短く書くための道具です。

全称量化・存在量化と量化の順序

全称の「すべての x で P(x)」を ∀x P(x)、存在の「ある x で P(x)」を ∃x P(x) と書きます。存在という言葉は、ちょうど一つという意味ではありません。一つ以上あれば十分です。また「すべて」と言うときには、すべての整数なのか、すべての正の実数なのか、必ず範囲を指定します。

選び直せる数と、固定しなければならない数

実数について「∀x ∃y：y > x」は真ですが、「∃y ∀x：y > x」は偽です。どちらも x、y は実数を動きます。

短い証明

前者では x がどの実数でも、その x に応じて y = x + 1 を選べば y > x です。後者が真だとすると、一つの実数 y がすべての実数 x より大きくなります。しかし x = y を選ぶと y > y が必要になり、これは成り立ちません。したがって後者を満たす y はありません。

記号を左から読むと、どこまで値に依存してよいかが見えます。∀x の後に ∃y があるなら、y は x を見て決められます。∃y が先なら、その後どんな x が来ても同じ y で対応しなければなりません。この依存関係は、後の極限の定義で、小さい誤差の要求に応じてどこから先を見るかを選ぶときにも現れます。

対象の範囲と存在の証明

量化記号の順序に加えて、動く数の範囲も真偽を決めます。「∀x ∃y：y²=x」を読んでみましょう。xもyも実数なら、どんな実数xを渡されても、それを二乗で作る実数yを用意せよ、という要求です。一つの数で確かめるのでなく、入力から答えを作る式を探します。

例題：平方根を使える条件を切り分ける

x=4ならy=2でも−2でもよく、存在は一意性を要求しません。しかしx=−1なら、実数yの平方は0以上なのでy²=−1は不可能です。従ってxが実数全体を動く主張は偽です。正の数をいくら多く試しても、この一例を埋められません。

xを非負実数へ限定し、yは実数のままとすれば真になります。任意のx≥0に対し、平方してxになる非負の数を√xと書き、y=√xを選べばy²=xです。非負実数にはこの平方根が存在するという実数の性質を使っています。x=0ならy=0、x>0なら±√xが二つの答えです。

さらにyを整数だけへ制限すると、x=2に対して答えがありません。整数yでは、−1≤y≤1ならy²≤1、y≥2またはy≤−2ならy²≥4だから、2にはなりません。「y=√xと置く」という式だけでは不十分で、それが指定した範囲の数かを確認する必要があります。

存在の証明は具体的な数を一つ出す方法だけでなく、渡されたxに応じる選び方を説明する方法でもできます。後者では、式が定義されること、選んだ値が範囲に入ること、要求された等式や不等式を満たすことの三つを点検します。

量化順序による共通値の存在条件

選び直しができるかどうかを、数値の条件として調べます。0≤x≤1の実数xと実数yを考え、距離がr以下であることを要求します。ここでrは先に指定する非負の実数です。実数tの絶対値|t|を、t≥0ならt、t<0なら−tと定義します。二点x、yの数直線上の距離は|x−y|です。

例題：人ごとの選択と共通の選択

まず「すべてのxについて、|x−y|≤rとなるyがある」なら、y=xと選べば距離0です。従ってr≥0のすべてで真です。yはxを見た後に選べるので、同じ位置に置けます。

次に「あるyがあり、すべてのxで|x−y|≤r」を考えます。先にyを固定するので、端のx=0とx=1にも同時に対応しなければなりません。|0−y|≤rは−r≤y≤r、|1−y|≤rは1−r≤y≤1+rです。両方を満たすには1−r≤r、すなわちr≥1/2が必要です。

必要というだけで止めず、実際に全xへ対応することを示します。r≥1/2ならy=1/2を選べます。0≤x≤1から−1/2≤x−1/2≤1/2、従って|x−1/2|≤1/2≤rです。よって共通のyが存在する条件は、ちょうどr≥1/2です。端の二点が下限を決め、区間全体への不等式がその選択で足りることを保証しました。

r=1/2ではy=1/2だけが可能です。r>1/2なら、端点の二条件から1−r≤y≤rとなり、この範囲の任意のyで全xとの距離がr以下になります。実際、0≤x≤1なので−r≤x−y≤rです。存在するかという問いから、どの値ならよいかという問いへ進めます。

「すべてのxで」だからといって、必ず無限個を代入する必要はありません。今回は端点を使って候補を絞り、任意のxについての不等式で全体を保証しました。有限の検算と一般の証明を役割で分けています。

命題と量化命題の否定

P の否定とは、P が真なら偽、偽なら真になる命題です。「すべての対象が P を満たす」の否定は、「P を満たさない対象が少なくとも一つある」です。「どれも P を満たさない」ではありません。観察と反例で、一つの反例が全称命題を崩せたのは、この仕組みによります。

同様に「ある対象が P を満たす」の否定は、「どの対象も P を満たさない」です。量化記号をまたいで否定を中へ入れると、∀ と ∃ が入れ替わります。たとえば「∀x ∃y：y > x」の否定は、「∃x ∀y：y ≤ x」です。最後の不等号にも注意しましょう。y > x が成り立たない範囲には、等しい場合も含まれます。

条件を組み合わせる「P かつ Q」の否定は「P でない、または Q でない」です。「P または Q」の否定は「P でも Q でもない」です。数学での「または」は、特に断らなければ両方が真の場合も含みます。整数が「2 の倍数、または 3 の倍数」であると言うとき、6 を除外する意図はありません。

含意・必要条件・十分条件

含意 P ⇒ Q は、「P が成り立つのに Q が成り立たない場合はない」という主張です。P が偽の場合について、Q が真か偽かを指定していません。「整数 n が 4 の倍数なら n は偶数」は、n = 4k と書けば n = 2(2k) だから真です。しかし偶数すべてが 4 の倍数とは限らず、n = 2 が反例です。矢印を逆にした Q ⇒ P は逆といい、別の主張です。

P ⇒ Q が成り立つとき、P は Q の十分条件、Q は P の必要条件です。4 の倍数であることは偶数であるために十分で、偶数であることは 4 の倍数であるために必要です。「十分」はそれだけで結論まで届くこと、「必要」は欠けると前提を満たせないこと、と読むと向きが見えます。両方向が成り立つときは同値 P ⇔ Q と書き、必要十分条件と呼びます。

下の図では、条件を満たす整数をひとまとめにして比べます。図中の P は4の倍数全体、Q は偶数全体を表します。P ⊆ Q は「Pに入る整数は全てQにも入る」という意味です。条件どうしの「ならば」を、条件を満たす集まりの包含として描き直しています。

含意の否定は「P かつ Q でない」です。「P ならば Q でない」ではありません。たとえば「すべての実数 x で、x² = 1 なら x = 1」を否定するには、x² = 1 と x ≠ 1 を同時に満たす x を示します。x = −1 がそれです。前提を満たさない x = 0 を選んでも、反例にはなりません。

日常の「ならば」には原因や時間の順序を感じることがありますが、数学の含意が述べるのは条件の関係です。また全体が真でも、前提を満たす対象が存在するとは限りません。「x² = −1 である実数 x なら x = 0」という含意は、前提を満たす実数がないため反例を持ちません。解の存在を主張したいなら、存在は別に示す必要があります。

寄り道［応用］：データベースにも「すべて」と「ある」がある

実際のデータベース PostgreSQL には、複数の値との比較をまとめる ALL と ANY があります。数 x が一覧のすべてより大きいなら ALL、一つでも大きい相手があれば ANY が真です。例えば一覧が 10 と 20、x が 15 なら、前者は偽、後者は真になります。数式の量化が、検索条件の意味を決めているのです。

面白いのは空の一覧です。仕様では ALL は真、ANY は偽。「反例が一つもない」と「満たす相手が一つある」は、対象が空のときにはっきり分かれます。ここでは欠損値 NULL を含まない通常の数を考えました。NULL が入る SQL には「不明」という別の結果もあり、数学の二値の真偽をそのまま移す前に、対象と規則を確認する必要があります。

演習：量化と必要十分条件

1．量化記号のある文を否定する

x、M は実数とします。「すべての x に対して、x < M となる M がある」の否定を、記号を使わずに述べてください。

ヒント1：外側から否定する

「すべての x」の否定では、「ある x」が現れます。

ヒント2：等しい場合を忘れない

「ある M で x < M」の否定は「すべての M で x ≥ M」です。

解答

「ある実数 x が存在し、すべての実数 M に対して x ≥ M である」です。この否定文自体は偽です。どんな候補 x に対しても M = x + 1 を選べば成立しないからです。

2．必要条件と十分条件

実数 x について、x > 2 は x² > 4 の必要条件、十分条件のどちらですか。逆向きも成り立つか確かめてください。

ヒント1：正の数を掛ける

x > 2 なら x は正です。両辺を二乗したときの大小を考えます。

ヒント2：逆では負の数を試す

x = −3 は x² > 4 を満たしますか。

解答

x > 2 なら x² > 4 なので十分条件です。しかし x = −3 では x² = 9 > 4 でも x > 2 でないため、必要条件ではありません。範囲を x ≥ 0 に限定すれば逆も成り立ち、必要十分条件になります。

3．反例になっているか

「整数 n で、n が 6 の倍数なら n は 4 の倍数だ」に対し、n = 4、6、12 のどれが反例ですか。

ヒント1：前提を満たすか調べる

反例には、まず 6 の倍数であることが必要です。

ヒント2：結論は失敗している必要がある

6 の倍数の候補のうち、4 の倍数でないものを探します。

解答

n = 6 だけが反例です。4 は前提を満たしません。12 は前提と結論を両方満たします。一つの命題を崩すには、前提が真で結論が偽となる同じ対象を選ぶ必要があります。

4．平方根の存在をどこで要求するか

①「すべての非負実数xに、y²=xとなる整数yがある」、②「すべての整数yに、y²=xとなる非負実数xがある」を判定し、真なら選び方、偽なら反例を示してください。

ヒント1

どちらの文字を先に渡され、どちらを選ぶのかを区別します。

ヒント2

①はx=2、②はx=y²を考えます。指定された範囲に入るかも確認します。

解答

①は偽。x=2に対して整数yの平方は、|y|≤1なら1以下、|y|≥2なら4以上なので2になりません。②は真。どんな整数yでもx=y²と置けば非負実数であり、要求された等式を満たします。文字の順序と動く範囲が違うため、同じ等式でも別の主張です。

5．二段階の選択を否定する

x、yは実数とします。「あるyが存在し、すべてのxでy>x」の否定を書き、その否定を具体的な選び方で証明してください。「すべてのyでy≤x」とだけ書くと何が不足しますか。

ヒント1

∃yの否定は∀y、∀xの否定は∃xへ変わります。

ヒント2

否定は「すべてのyに、y≤xとなるxがある」です。xはyに依存してよいので、等号になる選択をします。

解答

否定は「どんな実数yに対しても、y≤xとなる実数xが存在する」です。yを渡されたらx=yと選ぶとy≤xが成り立つので真です。「すべてのyでy≤x」だけではxの選択や範囲が量化されず、一つの固定xを想定してしまうおそれがあります。実際、一つのxが全実数y以上になるという別の主張なら、y=x+1で失敗します。

6．『かつ』と『または』の境界

実数xについて、①「x>0かつx<1」、②「x≤0またはx≥1」の否定をそれぞれ書いてください。x=0、1、1/2を使い、元の文と否定の真偽が必ず逆になることを確認してください。

ヒント1

かつを否定するとまたは、またはを否定するとかつになります。

ヒント2

>の否定は≤、<の否定は≥です。等号を落とさないようにします。

解答

①の否定は「x≤0またはx≥1」、②の否定は「x>0かつx<1」です。x=0と1では①が偽、②が真。x=1/2では①が真、②が偽です。「または」は両方が真でもよい意味ですが、この二条件は同時には成り立ちません。三例は境界の検算で、すべての実数について互いが否定となる理由は否定の規則です。

7．条件を満たさない入力で含意を崩せるか

実数xについて「x²=−1ならx=7」という全称の含意は真か偽か。また「x²=−1かつx=7を満たす実数が存在する」は真か偽か。前提の存在との違いを説明してください。

ヒント1

含意の反例は、前提が真で結論が偽となる同じxです。

ヒント2

実数の平方は0以上なので、x²=−1を満たす実数はありません。

解答

全称の含意は真です。前提x²=−1を満たす実数がないので、前提が真で結論が偽という反例は存在しません。一方、存在の主張は偽です。前提だけでも実現できないからです。含意が真であることから、x=7という解が得られたとも、前提を満たす数があるとも言えません。

8．結論から前提へ戻る誤り

「4の倍数なら偶数である。nは偶数である。従ってnは4の倍数である」という推論を診断してください。前提二つをともに満たして結論が失敗する整数を示し、前提と結論の向きをどう直せば有効な推論になるか述べてください。

ヒント1

必要条件を満たすだけで十分条件まで戻れるでしょうか。

ヒント2

n=2を試します。有効な例として、4の倍数でないことを結論にする方向もあります。

解答

n=2は偶数ですが4の倍数ではなく、推論は無効です。一般の含意P⇒QとQからPは導けません。「nは4の倍数である」を二つ目にすれば「nは偶数」と正しく進めます。また二つ目を「nは偶数でない」とすれば、結論を「nは4の倍数でない」とできます。もし4の倍数なら偶数になり、前提と両立しないからです。修正では結論も対応させる必要があります。

9．共通値を最も小さい誤差で選ぶ

0≤x≤4のすべての実数xに対し、同じ実数yで|x−y|≤rを満たしたいとします。非負実数rの最小値と、そのときのyを求めてください。xごとにyを選び直せる場合も比較してください。

ヒント1

端点x=0、4が同時に要求するyの範囲を調べます。

ヒント2

端点から−r≤y≤r、4−r≤y≤4+rとなり、4−r≤rが必要です。

解答

4−r≤rよりr≥2が必要です。r=2ならy=2を選べば、任意の0≤x≤4に対して−2≤x−2≤2、従って|x−2|≤2となり十分。最小値はr=2で、端点の条件の共通部分はy=2だけです。xごとに選び直せるならy=xで距離0なので最小はr=0。端点だけの調査は必要条件、区間全体の不等式は十分性の証明という役割です。

10．厳密不等号に変えると最小値はあるか

0≤x≤1で、①「すべてのxに、|x−y|<rとなるyがある」、②「あるyがあり、すべてのxで|x−y|<r」が真となる実数rの条件を求めてください。それぞれ最小のrは存在しますか。

ヒント1

距離は0以上なのでr≤0は不可能です。②では二つの端点を同時に調べます。

ヒント2

②の端点から1−r<y<r、従ってr>1/2が必要です。r=1/2では1−r<y<rが1/2<y<1/2となり、満たすyがありません。

解答

①はr>0ならy=xで0<rとなり真、r≤0では非負の距離がr未満になれないので偽です。②は端点から1−r<y<rが必要なのでr>1/2。逆にr>1/2ならy=1/2で|x−y|≤1/2<rとなり、全xを覆います。いずれも条件は下端を含みません。①で任意の候補r>0より小さいr/2も可能、②で任意の候補r>1/2より小さい(r+1/2)/2も可能なので、最小のrは存在しません。≤を<へ変えるだけで、境界が実現できるかが変わります。

量化・否定・含意の整理

  1. ∀x ∃y と ∃y ∀x では、y を選ぶ自由がどう違いますか。
  2. 「すべて正しい」の否定を、「すべて誤り」としてはいけないのはなぜですか。
  3. 十分条件と必要条件を、矢印を一本描いて説明してください。
