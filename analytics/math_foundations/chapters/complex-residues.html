円周積分と負一乗の係数

中心 a を反時計回りに一周すると、(z − a)⁻¹ の積分だけが 2πi になり、それ以外の整数べきの積分は0でした。Laurent展開があれば、多くの項を含む関数の積分でも、たった一つの係数を読むだけで済みそうです。その係数を留数と名づけます。

円の積分から始め、最後に有限個の特異点を囲む単純閉曲線へ進みます。前提はべきの円周積分と向き、Laurent展開、有限円孔を持つ境界のCauchyの定理です。自己交差する曲線や一般の巻き数は扱わず、境界上に特異点がある場合は公式の対象外にします。

計算の順番は、まず積分路と特異点の位置を確定し、各点で必要な係数だけを求め、最後に向きの符号を付けることです。全てのLaurent係数を計算する必要はありませんが、留数が0だから特異点が消えたとも言えません。以下の例題では「どこを囲むか」と「どの係数を求めるか」を別々に選びます。

学習時間の目安は演習を含みます。本文と例題、条件を変える考察、演習の三回に分けて読み進めても構いません。

留数の定義と円周積分

a が孤立特異点で、0 < |z − a| < R で f が正則とします。そのLaurent展開の c₋₁ を Res(f, a) と書きます。a が極か真性かによらず定義でき、可除のときは0です。関数の値 f(a) ではありません。

Res(f,a)=c−1=12πi∮|z−a|=sf(z)dz,0<s<R

一様な残りは、積分しても消える

半径 s の円上ではLaurent展開の正・負の部分がそれぞれ一様収束します。有限部分和を積分すると、整数べきの公式から c₋₁(z − a)⁻¹ だけが 2πic₋₁ を与え、他の項は0です。関数と有限和の積分差は、円の長さ 2πs と一様誤差の積以下なので0へ行きます。従って円周積分は 2πic₋₁。これは前章の係数公式の k = −1 の場合でもあります。

単純極・高位の極の留数計算

f が a で単純極、つまり1位の極を持つとき、(z − a)f(z) は正則に延長でき、その中心での値が留数です。特に f = g/h で、g、h が a の近くで正則、g(a) ≠ 0、h(a) = 0、h′(a) ≠ 0 なら、次の式が便利です。

Res(gh,a)=g(a)h′(a)

分母の単純零点を、一つの因子にする

Taylor展開から h(z) = (z − a)u(z)、u は正則で u(a) = h′(a) ≠ 0 です。十分近くで u は0でなく、正則関数の商の微分則により g/u も正則。f(z) = [g(z)/u(z)]/(z − a) の負1乗の係数は g(a)/u(a) です。g(a) ≠ 0 なので、確かに単純極になっています。

もし g(a) = 0 なら、h(a) = 0、h′(a) ≠ 0 の下では g(z) = (z − a)v(z)、h(z) = (z − a)u(z) と書け、u、v は正則で u(a) ≠ 0 です。従って g/h = v/u は a へ正則に延長でき、留数は0で、g(a)/h′(a) と一致します。例えば z/z は0の外で1なので可除です。分子・分母の打ち消しを先に確認します。また h′(a) = 0 なら、この式で割ることはできません。

m 位の極なら f(z) = φ(z)/(z − a)ᵐ、φ は中心まで正則、φ(a) ≠ 0 と書けます。φ のTaylor級数を割ると、負1乗になるのは次数 m − 1 の項なので、Res(f, a) = φ⁽ᵐ⁻¹⁾(a)/(m − 1)! です。例えば eᶻ/z³ は0で3位の極ですが、eᶻ = 1 + z + z²/2 + … から留数は1/2。単に最高の負のべきの係数を読むのではありません。

Res(f,a)=φ(m−1)(a)(m−1)!,f(z)=φ(z)(z−a)m

留数の計算法を選ぶ

極の位数を調べるのは、留数と取り違えるためではなく、正則な分子の何次までが必要かを決めるためです。中心で正則な関数の導関数が簡単なら高位の極の公式、低次数の係数がすぐ読めるなら級数を選びます。

例題1：二重極の「必要な一次」だけを求める

f(z)=eᶻ/(z−1)² を反時計回りの円 |z−1|=1/2 で積分します。eᶻ は全平面で正則、e¹≠0なので1は二重極で、他に特異点はありません。分母の零点を微分する単純極の公式は、ここでは分母の微分が1で0になるため使いません。

φ(z)=eᶻ と置けば、負1乗に必要なのは φ′(1)=e。従って Res(f,1)=e、円周積分は2πieです。別に w=z−1 と置くと eᶻ=e·eʷ=e(1+w+w²/2+…) なので、f=e w⁻²+e w⁻¹+e/2+…。負2乗の係数も負1乗の係数も今回はeですが、積分へ残る理由はあくまで指数が−1だからです。

条件を変えて f(z)=eᶻ/(z−1)³ にすると三重極になり、必要なのは二次係数e/2です。留数e/2、同じ円での積分πie。極の位数が増えても、積分が大きくなるとは限りません。円を時計回りにすれば、それぞれ−2πieと−πieになります。

留数定理と境界積分

有限個の孤立特異点に対する留数定理

Γ を単純な区分 C¹ 閉曲線で、内部を左に見る正向きとします。f は Γ とその内部の閉領域を含む開集合で、内部の有限個の点 a₁,…,aₘ を除いて正則で、各 aⱼ は孤立特異点とします。Γ 上に特異点はないものとします。このとき

∮Γf(z)dz=2πi∑j=1mRes(f,aj)

借用した境界定理の条件を確認する

各 aⱼ の周りに、互いに交わらず、Γ の内部に厳密に含まれ、他の特異点を含まない小さい閉円板を取ります。点は有限個なので、この選び方ができます。f は全境界と円板の間の閉領域を含む開近傍で正則です。

有限円孔へのCauchyの定理（そこで一般境界への拡張を借用）から、Γ の積分は各小円を反時計回りに積分したものの和。各小円の積分は留数の定義と円周積分から 2πi Res(f, aⱼ) なので、足せば上の式です。領域の境界として内周をたどる向きは時計回りですが、等号の右側へ移した小円は反時計回り。この符号を図と合わせて確認します。

f(z) = 1/[z(z − 1)] なら、0での留数は −1、1での留数は1です。正向きの円 |z| = 2 の積分は0ですが、|z| = 1/2 の積分は −2πi。どちらも積分する円そのものに極はありません。どの極を内部に含むかを先に決めてから、留数を足します。

積分路の選択と特異点の変化

例題2：同じ関数を、異なる円で積分する

F(z)=(z+2)/[z(z−1)] とします。分子を展開する前に、候補0と1で打ち消しがないことを確認します。どちらも単純極です。0で Res(F,0)=lim zF(z)=2/(−1)=−2、1で Res(F,1)=lim (z−1)F(z)=3/1=3 となります。

反時計回りの |z|=1/2 なら0だけを含み、積分は2πi·(−2)=−4πi。|z|=2 なら両方を含み、2πi(−2+3)=2πiです。同じ0中心の円でも、半径を大きくすると内部の特異点が変わるので値は変わります。半径1では1が輪郭上に来るため、両方の答えを補間するのでなく、通常の積分が定義されません。

別解として部分分数 F=−2/z+3/(z−1) も使えます。分子を戻すと −2(z−1)+3z=z+2 なので検算できます。係数−2と3がそのまま各単純極の留数になり、どの項を一周するかで同じ結果を得ます。

留数を計算し直さず、内部と向きだけを切り替える
F=(z+2)/[z(z−1)] の輪郭使う留数積分判断の要点
|z|=1/2、反時計回り−2−4πi0だけが内部。
|z|=2、反時計回り−2+3=12πi両方を一度囲む。
|z|=2、時計回り−2+3=1−2πi向きの反転は最後に負号。
|z|=1、いずれの向きも定理を適用しない未定義1が輪郭上。誤差の大小ではない。

この表で最初に見るべき列は輪郭です。留数自体は局所的な数で変わらず、有限個の特異点を含む単純閉曲線であるという条件の下で、選ぶ和と向きが積分を決めます。

例題3：極が合流すると公式の形も変わる

実数aに対し Gₐ(z)=1/[z(z−a)] を反時計回りの |z|=1 で積分します。a≠0のとき、0とaは単純極で、留数はそれぞれ−1/aと1/aです。0<|a|<1なら両方が内部なので積分0、|a|>1なら0だけが内部なので−2πi/aです。|a|=1は輪郭上の極のため除きます。

a=0では分母がz²となり、二重極です。−1/aや1/aを代入してはいけません。G₀=z⁻² の負1乗の係数は0なので積分も0。a→0の各留数は大きくなりますが、両方を含む円での和は常に0です。「それぞれの極の式を極限へ送ること」と「合流後の関数から係数を読むこと」を分けます。

例えばa=2では0の留数−1/2だけを使って−πi、a=1/2では留数−2と2を足して0です。合流後も特異点自体は消えません。z⁻²は0で有界ではなく、留数0は可除性の判定にはなりません。

極の位置・積分路の向きと数値積分

円 |z| = 1 に沿って f(z) = 1/(z − a) を積分する実験です。a は実数 −2 から2、向きは反時計回りまたは時計回り、分割数 N は16から256の16刻みです。|a| < 1 なら極が内側なので厳密値は正向きで 2πi、|a| > 1 なら内側で正則なので0です。向きを逆にすると符号が反転します。

極の内側・外側を十字の中心で判定し、向きだけを反転させて厳密値の符号を比較します。極が円周上なら通常の積分は未定義です。中点の有限サンプルが極を避けることは、積分の存在を保証しません。円周に近い極で分割数を増やす観察も、有限和の誤差の検査であり、留数定理の証明とは区別します。

表示される有限分割の中点和は近似です。固定した a が円上になければ N を増やして積分へ近づけられますが、極が円に近いと誤差が大きくなることがあります。有限の表示だけで留数定理を証明したことにはなりません。a = ±1 は誤差の問題でなく、輪郭上に極があるため、厳密値も近似積分の表示も対象外です。

輪郭上は、内側と外側の中間値ではない
極の位置反時計回り時計回り理由
|a| < 12πi−2πi内部の単純極の留数が1。
|a| > 100円と内部を含む近傍で正則。
|a| = 1未定義未定義輪郭上の極。留数定理の条件外。

境界上の極を勝手に「留数の半分」として扱うことはできません。経路を避けて通る方法や積分の主値など、別の定義と条件を導入する必要があり、この章では扱いません。

ここでいう積分の主値は、主値対数 Log のように関数の値の候補から一つを選ぶ約束ではありません。特異点の両側をどの組合せで極限へ近づけるかを別に指定する積分の定義です。本章の通常の輪郭積分へ、その値を補って扱うことはしません。

寄り道［数学の見方］：円の上の振動を、平均で選ぶ

z = a + s eⁱᵗ、0 ≤ t ≤ 2π と置くと、留数の式は Res(f, a) = (1/2π)∫₀²π f(a + s eⁱᵗ)s eⁱᵗ dt となります。Laurentの k 番の項は、定数倍の eⁱ⁽ᵏ⁺¹⁾ᵗ という振動になります。整数 k + 1 が0でなければ、その一周平均は0です。直接積分して、[eⁱ⁽ᵏ⁺¹⁾ᵗ/(i(k + 1))]₀²π = 0 と確かめられます。

k = −1 だけは振動せず定数になるので平均に残ります。無限級数でも円上の一様収束とML評価があるので、この有限和の観察を極限へ渡せます。留数は、円上の振動から特定の成分を取り出す操作とも読めます。Fourier教材への入口では、この「振動を積分で分ける」考えが別の形で現れます。

出典：円のパラメータ表示と本章のLaurent係数公式からの直接計算。

演習：留数と留数定理

1．単純極の公式を使う

反時計回りの円 |z| = 2 に沿う ∮ dz/(z² + 1) を求めてください。内部の二つの極の留数を別々に書きます。

ヒント1：分母の零点

z² + 1 = (z − i)(z + i) です。

ヒント2：h′(z) = 2z

それぞれの留数は 1/(2i) と 1/(−2i) になります。

解答

極は ±i で両方とも円の内部です。留数は i で 1/(2i)、−i で −1/(2i)、和は0。留数定理から積分は0です。内部に極があることだけで積分が非零とは限りません。

2．二重極でも負1乗を読む

f(z) = (z + 2)/(z − 1)² の1での極の位数と留数を求め、反時計回りの円 |z − 1| = 1/2 の積分を計算してください。

ヒント1：分子を中心1で書く

z + 2 = 3 + (z − 1) です。

ヒント2：二つの負のべき

f = 3(z − 1)⁻² + (z − 1)⁻¹ です。

解答

2位の極で、留数は負1乗の係数1です。積分は 2πi。負2乗の係数3を留数にしてはいけません。φ(z) = z + 2 とすれば、m = 2 の公式 φ′(1) = 1 でも確かめられます。

3．円上の極を検出する

∮|z|=1 dz/(z − 1) を、この章の留数定理で求められますか。「極は境界にあるので半分」という説明の問題点を述べてください。

ヒント1：曲線に代入する

z = eⁱᵗ と置くと t = 0、2π で分母が0です。

ヒント2：定理の仮定

f は Γ 上でも正則でなければなりません。

解答

求められません。極1が輪郭上にあり、通常の区分C¹曲線上で連続な被積分関数という前提も破れています。この章で定義した輪郭積分は未定義で、0やπiと結論できません。経路の変更や主値を使うなら、別の定義とその根拠が必要です。

4．打ち消してから極を判定する

f(z)=(z²−1)/[(z−1)(z+2)] の1と−2での特異点を分類し、反時計回りの |z|=3 の積分を求めてください。

ヒント1

z≠1で共通因子z−1を打ち消せます。

ヒント2

延長した関数は(z+1)/(z+2)。−2では分子は−1です。

解答

1は可除で留数0。−2は単純極で留数−1です。よって積分は−2πi。実際 (z+1)/(z+2)=1−1/(z+2) なので同じ係数が読めます。1で元の式が未定義でも、円上には問題がなく、留数定理では内部の孤立特異点として扱えます。

5．必要な次数を逆算する

f(z)=sin z/z⁴ の0での極の位数と留数を求め、反時計回りの |z|=1 の積分を計算してください。

ヒント1

sin z=z−z³/6+z⁵/120−… です。分子の零点も数えます。

ヒント2

z⁴で割った後、z⁻¹になる項を探します。

解答

f=z⁻³−(1/6)z⁻¹+z/120−… なので3位の極、留数−1/6、積分−πi/3です。分母の四乗だけから4位と判断するのは誤りです。sin z/z は0へ正則に延長され値1なので、f=(sin z/z)/z³ として二階導関数の公式でも係数−1/6を確認できます。

6．積分値から分子を設計する

H(z)=(αz+β)/[z(z−1)]（α,βは実数）について、反時計回りの |z|=1/2 の積分を2πi、|z|=2 の積分を6πiにするα,βを求めてください。

ヒント1

0の留数は−β、1の留数はα+βです。

ヒント2

小円は−βだけ、大円は二つの和αを選びます。

解答

−β=1、α=3よりα=3、β=−1。1での留数は2となり、実際 H=1/z+2/(z−1) です。小円は2πi、大円は2πi(1+2)=6πiに戻ります。両方の留数が非零なので、どちらも確かに単純極です。

7．零積分からの誤診を直す

「|z|=2での積分が0なら、内部に特異点はない」という主張を、極が一つの場合と二つの場合の反例で訂正してください。向きは反時計回りです。

ヒント1

一つの極でも留数が0になれます。

ヒント2

二つの単純極の留数を、互いに反対の数にします。

解答

一つなら f=1/z² で二重極があっても留数0。二つなら f=1/[z(z−1)]=−1/z+1/(z−1) で留数の和0です。どちらも積分は0。逆に内部に特異点がなく閉領域の開近傍で正則ならCauchyの定理で0ですが、その逆は一つの輪郭の積分だけから言えません。

8．中心を選んで一つだけ囲む

F(z)=(z+2)/[z(z−1)] の0だけを含み、1を含まない反時計回りの円を、中心c=−1/2を固定して選びます。許される半径r>0を全て求め、積分を答えてください。

ヒント1

中心から0と1への距離はそれぞれ1/2と3/2です。

ヒント2

内部に入れるには距離より大きく、外部に置くには距離より小さくします。

解答

1/2<r<3/2 が全てです。両端の等号は極が円上に来るため除きます。内部の留数は−2だけなので積分は−4πi。例えばr=1なら実軸との交点は−3/2と1/2で、0が内部、1が外部という位置関係も確かめられます。

9．真性特異点にも同じ係数を使う

f(z)=z e^(1/z) の0の留数と、時計回りの |z|=1/2 の積分を求めてください。「極でないから留数定理は使えない」という説明も判定してください。

ヒント1

e^(1/z)=1+z⁻¹+z⁻²/2+z⁻³/6+… です。

ヒント2

zを掛けるので、元のz⁻²の項が負1乗になります。

解答

f=z+1+(1/2)z⁻¹+(1/6)z⁻²+… なので留数1/2、時計回りの積分は−2πi·(1/2)=−πi。負のべきが無限にある真性特異点ですが、0は孤立特異点で、円と0を除く内部では正則です。有限個の孤立特異点に対する本章の定理の条件を満たします。
