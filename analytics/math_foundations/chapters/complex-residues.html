円周積分と負一乗の係数

中心 a を反時計回りに一周すると、(z − a)⁻¹ の積分だけが 2πi になり、それ以外の整数べきの積分は0でした。Laurent展開があれば、多くの項を含む関数の積分でも、たった一つの係数を読むだけで済みそうです。その係数を留数と名づけます。

円の積分から始め、最後に有限個の特異点を囲む単純閉曲線へ進みます。前提はべきの円周積分と向き、Laurent展開、有限円孔を持つ境界のCauchyの定理です。自己交差する曲線や一般の巻き数は扱わず、境界上に特異点がある場合は公式の対象外にします。

留数の定義と円周積分

a が孤立特異点で、0 < |z − a| < R で f が正則とします。そのLaurent展開の c₋₁ を Res(f, a) と書きます。a が極か真性かによらず定義でき、可除のときは0です。関数の値 f(a) ではありません。

Res(f,a)=c−1=12πi∮|z−a|=sf(z)dz,0<s<R

一様な残りは、積分しても消える

半径 s の円上ではLaurent展開の正・負の部分がそれぞれ一様収束します。有限部分和を積分すると、整数べきの公式から c₋₁(z − a)⁻¹ だけが 2πic₋₁ を与え、他の項は0です。関数と有限和の積分差は、円の長さ 2πs と一様誤差の積以下なので0へ行きます。従って円周積分は 2πic₋₁。これは前章の係数公式の k = −1 の場合でもあります。

単純極・高位の極の留数計算

f が a で単純極、つまり1位の極を持つとき、(z − a)f(z) は正則に延長でき、その中心での値が留数です。特に f = g/h で、g、h が a の近くで正則、g(a) ≠ 0、h(a) = 0、h′(a) ≠ 0 なら、次の式が便利です。

Res(gh,a)=g(a)h′(a)

分母の単純零点を、一つの因子にする

Taylor展開から h(z) = (z − a)u(z)、u は正則で u(a) = h′(a) ≠ 0 です。十分近くで u は0でなく、正則関数の商の微分則により g/u も正則。f(z) = [g(z)/u(z)]/(z − a) の負1乗の係数は g(a)/u(a) です。g(a) ≠ 0 なので、確かに単純極になっています。

もし g(a) = 0 なら、h(a) = 0、h′(a) ≠ 0 の下では g(z) = (z − a)v(z)、h(z) = (z − a)u(z) と書け、u、v は正則で u(a) ≠ 0 です。従って g/h = v/u は a へ正則に延長でき、留数は0で、g(a)/h′(a) と一致します。例えば z/z は0の外で1なので可除です。分子・分母の打ち消しを先に確認します。また h′(a) = 0 なら、この式で割ることはできません。

m 位の極なら f(z) = φ(z)/(z − a)ᵐ、φ は中心まで正則、φ(a) ≠ 0 と書けます。φ のTaylor級数を割ると、負1乗になるのは次数 m − 1 の項なので、Res(f, a) = φ⁽ᵐ⁻¹⁾(a)/(m − 1)! です。例えば eᶻ/z³ は0で3位の極ですが、eᶻ = 1 + z + z²/2 + … から留数は1/2。単に最高の負のべきの係数を読むのではありません。

Res(f,a)=φ(m−1)(a)(m−1)!,f(z)=φ(z)(z−a)m

留数定理と境界積分

有限個の孤立特異点に対する留数定理

Γ を単純な区分 C¹ 閉曲線で、内部を左に見る正向きとします。f は Γ とその内部の閉領域を含む開集合で、内部の有限個の点 a₁,…,aₘ を除いて正則で、各 aⱼ は孤立特異点とします。Γ 上に特異点はないものとします。このとき

∮Γf(z)dz=2πi∑j=1mRes(f,aj)

借用した境界定理の条件を確認する

各 aⱼ の周りに、互いに交わらず、Γ の内部に厳密に含まれ、他の特異点を含まない小さい閉円板を取ります。点は有限個なので、この選び方ができます。f は全境界と円板の間の閉領域を含む開近傍で正則です。

第5章で借用した有限円孔へのCauchyの定理から、Γ の積分は各小円を反時計回りに積分したものの和。各小円の積分は前節から 2πi Res(f, aⱼ) なので、足せば上の式です。領域の境界として内周をたどる向きは時計回りですが、等号の右側へ移した小円は反時計回り。この符号を図と合わせて確認します。

f(z) = 1/[z(z − 1)] なら、0での留数は −1、1での留数は1です。正向きの円 |z| = 2 の積分は0ですが、|z| = 1/2 の積分は −2πi。どちらも積分する円そのものに極はありません。どの極を内部に含むかを先に決めてから、留数を足します。

極の位置・積分路の向きと数値積分

円 |z| = 1 に沿って f(z) = 1/(z − a) を積分する実験です。a は実数 −2 から2、向きは反時計回りまたは時計回り、分割数 N は16から256の16刻みです。|a| < 1 なら極が内側なので厳密値は正向きで 2πi、|a| > 1 なら内側で正則なので0です。向きを逆にすると符号が反転します。

極の内側・外側を十字の中心で判定し、向きだけを反転させて厳密値の符号を比較します。極が円周上なら通常の積分は未定義です。中点の有限サンプルが極を避けることは、積分の存在を保証しません。円周に近い極で分割数を増やす観察も、有限和の誤差の検査であり、留数定理の証明とは区別します。

表示される有限分割の中点和は近似です。固定した a が円上になければ N を増やして積分へ近づけられますが、極が円に近いと誤差が大きくなることがあります。有限の表示だけで留数定理を証明したことにはなりません。a = ±1 は誤差の問題でなく、輪郭上に極があるため、厳密値も近似積分の表示も対象外です。

輪郭上は、内側と外側の中間値ではない
極の位置反時計回り時計回り理由
|a| < 12πi−2πi内部の単純極の留数が1。
|a| > 100円と内部を含む近傍で正則。
|a| = 1未定義未定義輪郭上の極。留数定理の条件外。

境界上の極を勝手に「留数の半分」として扱うことはできません。経路を避けて通る方法や主値など、別の定義と条件を導入する必要があり、この章では扱いません。

寄り道［数学の見方］：円の上の振動を、平均で選ぶ

z = a + s eⁱᵗ、0 ≤ t ≤ 2π と置くと、留数の式は Res(f, a) = (1/2π)∫₀²π f(a + s eⁱᵗ)s eⁱᵗ dt となります。Laurentの k 番の項は、定数倍の eⁱ⁽ᵏ⁺¹⁾ᵗ という振動になります。整数 k + 1 が0でなければ、その一周平均は0です。直接積分して、[eⁱ⁽ᵏ⁺¹⁾ᵗ/(i(k + 1))]₀²π = 0 と確かめられます。

k = −1 だけは振動せず定数になるので平均に残ります。無限級数でも円上の一様収束とML評価があるので、この有限和の観察を極限へ渡せます。留数は、円上の振動から特定の成分を取り出す操作とも読めます。Fourier教材への入口では、この「振動を積分で分ける」考えが別の形で現れます。

出典：円のパラメータ表示と本章のLaurent係数公式からの直接計算。

演習：留数と留数定理

1．単純極の公式を使う

反時計回りの円 |z| = 2 に沿う ∮ dz/(z² + 1) を求めてください。内部の二つの極の留数を別々に書きます。

ヒント1：分母の零点

z² + 1 = (z − i)(z + i) です。

ヒント2：h′(z) = 2z

それぞれの留数は 1/(2i) と 1/(−2i) になります。

解答

極は ±i で両方とも円の内部です。留数は i で 1/(2i)、−i で −1/(2i)、和は0。留数定理から積分は0です。内部に極があることだけで積分が非零とは限りません。

2．二重極でも負1乗を読む

f(z) = (z + 2)/(z − 1)² の1での極の位数と留数を求め、反時計回りの円 |z − 1| = 1/2 の積分を計算してください。

ヒント1：分子を中心1で書く

z + 2 = 3 + (z − 1) です。

ヒント2：二つの負のべき

f = 3(z − 1)⁻² + (z − 1)⁻¹ です。

解答

2位の極で、留数は負1乗の係数1です。積分は 2πi。負2乗の係数3を留数にしてはいけません。φ(z) = z + 2 とすれば、m = 2 の公式 φ′(1) = 1 でも確かめられます。

3．円上の極を検出する

∮|z|=1 dz/(z − 1) を、この章の留数定理で求められますか。「極は境界にあるので半分」という説明の問題点を述べてください。

ヒント1：曲線に代入する

z = eⁱᵗ と置くと t = 0、2π で分母が0です。

ヒント2：定理の仮定

f は Γ 上でも正則でなければなりません。

解答

求められません。極1が輪郭上にあり、通常の区分C¹曲線上で連続な被積分関数という前提も破れています。この章で定義した輪郭積分は未定義で、0やπiと結論できません。経路の変更や主値を使うなら、別の定義とその根拠が必要です。
