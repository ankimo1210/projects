停留点と二次の変化

原点で x² + y²、−x² − y²、x² − y² を比べると、どれも勾配は 0 です。それでも一つ目は谷、二つ目は山、三つ目は向きによって上り下りが逆の峠（鞍点）です。一次の傾きが消えた後には、どの情報が残るのでしょうか。

上は同じ座標・高さの縮尺を用いた曲面の見取り図で、灰色の菱形は水平面 z=0 です。下は原点を通る断面で、橙実線が y=0、青破線が x=0。切り口が同じ場合は線が重なります。谷と山の全方向の判定には本文の符号の議論を使います。峠では原点のどれほど近くにも上る向きと下る向きがあります。

一変数の二階微分を、二つの変数の二階偏微分を並べた行列へ広げます。ただし、二階の情報だけでは結論できない場合も、最後まで残ります。

学習の目安は演習込み120–170分です。まず二次近似と判定の証明、次に三つの計算例、最後に演習へ進みます。停留点を探す段階、二次の符号を読む段階、判定不能の後に元の関数を比べる段階を分けてください。

二階偏導関数とヘッセ行列

fₓᵧ は (fₓ)ᵧ、つまり先に x、次に y で偏微分したものとします。fᵧₓ = (fᵧ)ₓ とは、まだ等しいと仮定しません。開集合上で一階・二階の偏導関数が存在し、すべて連続な関数をC² 級と呼びます。

Hessian の定義

二階偏微分が存在するとき、次の行列をHessian 行列と呼びます。この章では C² の関数について二次近似に用います。

Hf=[fxxfxyfyxfyy]

例えば P = x² + xy + y² では Pₓ = 2x + y、Pᵧ = x + 2y、従って行列の二行は (2, 1)、(1, 2) です。多項式の偏導関数は連続なので C² です。

この行列を作る狙いは、全微分の章で残った二次の変化を読むことです。Pの余り h²+hk+k² は、(1/2)(2h²+2hk+2k²) と書け、対角の2がh²,k²の係数、二つの混合成分1の和が2hkの係数として現れます。一般の関数でも同じ形の近似ができることは、後のTaylorの定理で証明します。その前に、二つの混合偏微分を一つの係数として扱える条件を確かめます。

混合偏導関数の対称性

行列の対角線をはさんだ二つの成分が等しいとき、その行列を対称行列と呼びます。直前のPの行列では、二つの成分がともに1でした。一般には fₓᵧ と fᵧₓ の等しさに当たります。微分する順序をただ交換してよいと決めず、C²という連続性の条件から示します。

C² なら混合偏微分を交換できる

f が p の開近傍で C² なら fₓᵧ(p) = fᵧₓ(p)。従って Hessian は対称行列です。

同じ矩形の変化を、二通りに数える

p = (a, b) の周りの小さい矩形を定義域内に取り、h、k ≠ 0 に対して Δ = f(a + h, b + k) − f(a + h, b) − f(a, b + k) + f(a, b) と置きます。補助関数 A(x) = f(x, b + k) − f(x, b) を作ると Δ = A(a + h) − A(a) です。

平均値の定理をA へ一度使えば、ある 0 < θ < 1 で Δ/h = A′(a + θh) = fₓ(a + θh, b + k) − fₓ(a + θh, b)。二本の切り口へ別々に使って、異なる中間点を同じと置いたのではありません。次に固定した x = a + θh で fₓ の y 方向に使うと、ある 0 < η < 1 で Δ/(hk) = fₓᵧ(a + θh, b + ηk) です。

逆に B(y) = f(a + h, y) − f(a, y) へ使い、次に fᵧ の x 方向へ使えば、同じ Δ/(hk) = fᵧₓ(a + θ′h, b + η′k) を得ます。C² により一変数の各関数は区間で連続、内部で微分可能なので定理の条件を満たします。h、k が負でも端点を昇順にして、差の向きを戻せば同じ式です。

h、k → 0 で中間点はともに p へ近づきます。二階偏導関数の p での連続性から、同じ差商の極限は fₓᵧ(p) でも fᵧₓ(p) でもあり、両者は等しいのです。h = 0 や k = 0 は証明用の差商に入れません。

存在だけでは交換できません。K(x, y) = xy(x² − y²)/(x² + y²)（原点以外）、K(0, 0) = 0 とします。y ≠ 0 で K(h, y)/h → −y、y = 0 でも 0 なので Kₓ(0, y) = −y。同様に Kᵧ(x, 0) = x。従って Kₓᵧ(0, 0) = −1、Kᵧₓ(0, 0) = 1 です。原点以外で滑らかでも、原点を含む C² の条件を満たすことにはなりません。

多変数の二次Taylor近似

ᵀ は転置を表し、ここでは列ベクトルを行ベクトルに並べ直す記号です。v = (h, k) を列ベクトルと見たとき、vᵀHv は行ベクトル・行列・列ベクトルの積で、H の二行が (A, B)、(B, C) なら Ah² + 2Bhk + Ck² です。この二次式を二次形式と呼びます。

C² の二変数 Taylor 展開

f が p の開近傍で C² なら、v → 0 で次が成立します。o(‖v‖²) は、その絶対値を ‖v‖² で割ると全方向から 0 へ近づく余りです。

f(p+v)=f(p)+∇f(p)·v+12vTHf(p)v+o(‖v‖2)

線分で展開し、余りを全方向で抑える

p 中心の半径 d の円板を C² の開近傍内に取り、0 < ‖v‖ < d/2 とします。φ(t) = f(p + tv) は [0, 1] の少し外側まで定義されます。曲線連鎖律から φ′(t) = ∇f(p + tv) · v。一階偏導関数も C¹ なので同じ規則をもう一度使い、φ″(t) = vᵀHf(p + tv)v です。従って φ は C² です。

一変数 Taylor の定理を中心 0、評価点 1、n = 1で φ に使うと、ある 0 < θ < 1 で f(p + v) = f(p) + ∇f(p) · v + (1/2)vᵀHf(p + θv)v。n = 2 は使わないので、三階の微分は要求しません。

Hf の全成分の p での連続性により、任意の η > 0 に対し、‖q − p‖ < δ なら各成分の差を η 以下にできます。‖v‖ < δ なら θ の選び方によらず ‖θv‖ ≤ ‖v‖ なので、二次形式の差は次で抑えられます。

|vT(Hf(p+θv)−Hf(p))v|≤η(|h|+|k|)2≤2η‖v‖2

この差の半分が展開の余りなので、絶対値は η‖v‖² 以下です。η は任意であり、δ は方向によらず一つに選べました。これで全方向からの o(‖v‖²) を示せます。v = 0 では元の等式をそのまま使い、0/0 は作りません。

局所極値における停留条件

p のある近傍内の定義域の点 q すべてで f(q) ≥ f(p) なら局所最小、≤ なら局所最大です。q ≠ p で常に厳密不等号なら厳密な局所極値です。全定義域での最大・最小とは区別します。∇f(p) = 0 の点を停留点と呼びます。

内点の局所極値の必要条件

開集合の内点 p で f が全微分可能で、局所最大または局所最小なら ∇f(p) = 0。さらに近傍で C² なら、局所最小ではすべての v に対して vᵀHf(p)v ≥ 0、局所最大では ≤ 0 です。

座標方向の一次、任意方向の二次を見る

局所最小を考えます。各座標軸の切り口で、正の増分の差商は非負、負の増分では非正。両側の微分が存在すれば共通の極限は 0 で、二つの偏微分が消えます。これが一変数の Fermat の議論です。

非零の固定 v では、Taylor 展開から f(p + tv) − f(p) = (t²/2)vᵀHf(p)v + o(t²)。左辺が非負なので t² で割って極限を取れば vᵀHf(p)v ≥ 0。v = 0 では 0 です。最大は −f に同じ議論を使います。

二次形式が全 v で非負なら半正定値、非零 v で常に正なら正定値といいます。非正・負定値も符号を逆にして定義します。半正定値はここでは必要条件で、十分条件ではありません。また境界の片側の極値に、内点の必要条件をそのまま適用はできません。

二次形式と極値の二階判定

二変数の二階判定

f が内点 p の開近傍で C²、∇f(p) = 0 とします。Hf(p) の二行を (A, B)、(B, C)、D = AC − B² と置きます。D > 0 なら AC > B² ≥ 0 なので A ≠ 0 です。

  • D > 0、A > 0 なら厳密局所最小。
  • D > 0、A < 0 なら厳密局所最大。
  • D < 0 なら鞍点。つまり任意の近傍に f(p) より高い点と低い点があります。
  • D = 0 では、この判定から結論できません。

平方完成に、全方向の余りの評価を組み合わせる

A > 0、D > 0 なら Q(h, k) = Ah² + 2Bhk + Ck² = A(h + (B/A)k)² + (D/A)k² です。s = h + (B/A)k とすると、h² + k² ≤ 2s² + (1 + 2B²/A²)k²。従って次の方向によらない正の下限を持ちます。

Q(v)≥m‖v‖2,m=min(A2,D/A1+2B2/A2)>0

Taylor の余りを |R(v)| ≤ (m/4)‖v‖² とできるほど v を小さくすれば、f(p + v) − f(p) ≥ (m/2)‖v‖² − (m/4)‖v‖² > 0（v ≠ 0）。従って厳密局所最小です。A < 0、D > 0 は −f にこの証明を使えば厳密局所最大です。固有値の定理は使っていません。

D < 0、A ≠ 0 なら Q(1, 0) = A と Q(−B/A, 1) = D/A は異符号です。A = 0 なら D = −B² < 0 で B ≠ 0。Q(1, t) = 2Bt + Ct² は、十分小さい正負の t で異符号です。従ってどちらの場合も、Q が正・負になる二つの固定方向 v₊、v₋ を選べます。

その各方向へ増分 ρv₊、ρv₋ を取ると、Taylor の二次主項は非零で、余りを ρ² で割った極限は 0。十分小さい非零の ρ で実際の差も正・負になります。ρ をさらに小さくできるので、任意の近傍に上下の点があり、鞍点です。

例題：中心を移し、二次項と余りを別々に評価する

F(x,y)=(x−1)²+(x−1)(y+2)+2(y+2)²+(x−1)³ を、p=(1,−2)の近くで調べます。原点の式だけを覚えていると、Hessianをどこで評価するかを落としがちです。比較したい点を中心に h=x−1、k=y+2 と置けば、F(p)=0との差がそのまま書けます。

停留を確認してから、二次判定を使う

Fₓ=2h+k+3h²、Fᵧ=h+4k なので、pでは両方0です。二階偏導関数は Fₓₓ=2+6h、Fₓᵧ=Fᵧₓ=1、Fᵧᵧ=4。従って H(p)=[[2,1],[1,4]]、D=8−1=7>0、A=2>0です。pは厳密局所最小と判定できます。混合項hkの係数1を、Hessianの両方の非対角成分へ足して2にしてはいけません。(1/2)vᵀHvでは二つの1が合わさってhkになります。

判定の中身も具体的に確かめます。r=√(h²+k²)とすると、|hk|≤(h²+k²)/2から h²+hk+2k²≥r²/2。また |h³|≤r³。よって F(p+(h,k))≥r²(1/2−r)で、0<r<1/2なら正です。これは全方向に共通する半径1/2の保証です。r=1/2でも正かもしれませんが、この下界が0になるため、この評価から厳密不等号は結論しません。

実値でも検算します。(h,k)=(1/4,0)では F=1/16+1/64=5/64、二次近似は1/16、余りは1/64です。下界は r²(1/2−r)=1/64で、実値を確かに下から抑えています。(h,k)=(−1/4,0)なら F=3/64。同じ二次近似でも三次の余りの符号は変わりますが、どちらも正です。

これは局所の結論です。k=0、h=−2なら F=4−8=−4<F(p)なので、pは全平面での最小ではありません。二次判定が保証する範囲を「全体の最小」へ広げないことも、元の式による検算の役割です。

例題：混合項を変えると、谷から峠へどう移るか

qₐ(x,y)=x²+2axy+y²を原点で比べます。どのaでも両座標軸上ではt²で、勾配も原点で0です。軸だけを見ても、aによる違いは現れません。交差する項xyを読むには、二つの座標を同時に動かす方向を選びます。

同方向と逆方向へ動かして、平方の係数を読む

y=xなら qₐ(t,t)=2(1+a)t²、y=−xなら qₐ(t,−t)=2(1−a)t²。二つの切り口を調べた理由は、次の平方の分解が全点で成り立つためです。

qₐ(x,y)={(1+a)/2}(x+y)²+{(1−a)/2}(x−y)²。

|a|<1なら両係数が正で、非零点では二つの平方の少なくとも一つが正です。より直接には qₐ≥(1−|a|)(x²+y²)>0。従って厳密最小です。|a|>1なら上の二つの切り口が異符号になり、鞍点です。例えばa=2では q₂(1/10,1/10)=3/50、q₂(1/10,−1/10)=−1/50。この二点だけは検算で、任意に小さいtについての式が鞍点の証明です。

H=[[2,2a],[2a,2]]の固有方向も(1,1)、(1,−1)で、倍率は2(1+a)、2(1−a)です。実際H(1,−1)=2(1−a)(1,−1)と掛けて確認できます。ここで固有値の符号と二次式の符号が対応するのは、直交するこの二方向に実際に分解できたからです。一般の行列の固有値の一覧だけで、二次式を判定したのではありません。

a=1ならq₁=(x+y)²で、x=−y上はすべて0。a=−1ならq₋₁=(x−y)²で、x=y上は0です。どちらも原点は最小ですが厳密ではありません。D=4(1−a²)=0で一つの固有値が0になる境目では、高次の項を加えると結論が変わり得ます。

次の表で、a=1の「0になる方向」を見てください。この方向に何を足すかで、同じHessianの下に異なる形を作れます。表の関数はすべて自作の比較例です。

三つとも原点のHessianは[[2,2],[2,2]]で、固有値は4と0です。零固有値は、その方向で二次の変化が消えるという情報です。関数がその方向で一定になるとも、極値がないとも限りません。

退化したヘッセ行列と高次項

x⁴ + y⁴、−x⁴ − y⁴、x⁴ − y⁴ はいずれも原点で勾配 0、Hessian も零行列です。しかし最初は原点以外で正なので厳密最小、二番目は負なので厳密最大、三番目は x 軸で正、y 軸で負なので鞍点です。三つとも D = 0。「判定不能」は「極値がない」でも「値が一定」でもありません。

実験の「Hessian による判定」と「本文で確かめた実際の形」を区別してください。有限個の切り口の図は観察であり、全方向の極値を保証するのは本文の不等式です。

ヘッセ行列・選んだ断面の情報が十分かを反例で点検する
関数二次情報と見える断面実際の結論
x⁴+y⁴H=0, D=0だが非零入力では正。厳密最小。判定不能は「極値なし」ではない。
−x⁴−y⁴H=0, D=0だが非零入力では負。厳密最大。同じ零ヘッセ行列でも形は逆になる。
x⁴−y⁴H=0, D=0、x軸では正、y軸では負。鞍点。二次の情報だけでは高次の符号を失う。
対照：x²+y²−4xy両軸ではt²>0だが、斜めx=y=tでは−2t²<0。鞍点。二つの上向き断面だけから谷とは言えない。D=4−16=−12で二階判定も整合。

例題：直線の切り口だけで足りない場合

G(x,y)=(y−x²)²−x⁶の原点では、H=[[0,0],[0,2]]、D=0です。二次近似y²は非負ですが、x方向の二次項はありません。そこで最小だと結論せず、正の平方が小さくなる道を探します。平方を0にするy=x²が自然な候補です。

全直線での観察と、曲線上での比較を区別する

直線y=mxではG(x,mx)=x²{(m−x)²−x⁴}です。m≠0を一つ固定すると、十分小さい非零xで括弧は正。m=0ならG(x,0)=x⁴(1−x²)>0（0<|x|<1）です。縦の直線x=0でもG(0,y)=y²>0です。このように、原点を通るどの固定直線も、原点の十分近くで上向きになります。

しかし曲線y=x²では G(x,x²)=−x⁶<0（x≠0）。対してx=0では正です。xをどれだけ小さくしても負の点を作れるので、実際は鞍点です。例えばx=1/2では、軸上G(1/2,0)=3/64に対し、曲線上G(1/2,1/4)=−1/64となります。

各直線で使える「十分近く」の範囲は、傾きmによって変わります。直線を一つずつ調べたことを、全方向で同じ円板が使えるという保証に置き換えられません。正定値の場合に二次形式をm‖v‖²で下から押さえたのは、この全方向に共通する余裕を確保するためでした。

実際の計算では、①定義域の内点か、②勾配が0か、③二次形式が決着を付けるか、④付かないなら平方完成・符号比較・適切な曲線を探す、という順に進めます。Hessianの計算は、最後の段階を不要にする条件がそろったときに強い道具になります。

寄り道［応用］：写真の「角」を探す別の二次形式

OpenCV の公式資料は、Harris コーナー検出で小さな画像の移動に対する明るさの差の二乗和を使い、E(h, k) ≈ (h, k)M(h, k)ᵀ と近似する式を示しています。M は近隣画素の勾配から、非負の重み w を付けて二行 (Iₓ², IₓIᵧ)、(IₓIᵧ, Iᵧ²) の行列を足したものです。

これは勾配の外積を集めたstructure tensorで、画像強度 I の Hessian そのものではありません。本章との接点は行列の名前ではなく、方向ごとの変化を二次形式で比べる考え方です。一次近似 I(x + h, y + k) − I(x, y) ≈ Iₓh + Iᵧk を二乗して足せば、この形が現れます。

ここからは本章の仮想計算です。重み 1 の二つの勾配が (1, 0)、(1, 0) なら M の対角成分は 2、0 で、二次形式は 2h²。縦移動には変化が見えません。一方 (1, 0)、(0, 1) なら M は単位行列で h² + k²。どの単位方向にも同じ変化を持ちます。いずれも二乗和なので非負であり、画像の推定誤差や実際の検出性能までこの計算が保証するわけではありません。

出典：OpenCV：Harris Corner Detection（Theory）。二つの勾配を使う比較は、本章で設定・計算した例です。

ヘッセ行列と極値判定の演習

1–3は元の式での基本判定、4–6は候補探索・係数の範囲・逆算、7–10は仮定と判定不能の診断です。まず自力で比較する量を決め、必要な段階だけヒントを開いてください。

1．余りを含めて、最小を保証する

f = x² + xy + y² + x³ の原点で二次近似と正確な余りを求め、厳密局所最小を保証する円板の半径を一つ示してください。

ヒント1：原点で二階まで計算する

fₓ = 2x + y + 3x²、fᵧ = x + 2y です。

ヒント2：二次項を下から抑える

r² = h² + k² とすると |hk| ≤ r²/2、|h³| ≤ r³ です。

解答

f は C²、∇f(0) = 0。二階偏導関数は fₓₓ = 2 + 6x、fₓᵧ = fᵧₓ = 1、fᵧᵧ = 2 なので原点の Hessian の二行は (2, 1)、(1, 2)。二次近似は h² + hk + k²、正確な余りは h³ です。f(h, k) ≥ r²/2 − r³ = r²(1/2 − r) > 0（0 < r < 1/2）。従って半径 1/2 の開円板で、原点は厳密局所最小です。D = 3 > 0、A = 2 > 0 の判定とも一致します。

2．二つの道で、峠を確かめる

f = x² + 4xy + y² の原点を Hessian で判定し、二つの直線上の値でも確認してください。

ヒント1：混合項の係数に注意

Hessian の非対角成分は 4 です。

ヒント2：同じ符号と逆の符号

y = x と y = −x を代入します。

解答

原点は内点で、f は C²、勾配 (2x + 4y, 4x + 2y) は原点で 0。Hessian の二行は (2, 4)、(4, 2)、D = 4 − 16 = −12 < 0 なので鞍点です。実際 f(t, t) = 6t² > 0、f(t, −t) = −2t² < 0（t ≠ 0）。t を任意に小さく取れば、どの近傍にも原点より高い点・低い点があります。

3．同じ Hessian、違う形

x⁴ + y⁴、−x⁴ − y⁴、x⁴ − y⁴ の原点の Hessian と極値を比較してください。

ヒント1：二階でも二乗が残る

x⁴ の二階微分は 12x² です。混合偏微分は 0 です。

ヒント2：元の式の符号を見る

最後の関数は x 軸と y 軸で調べてください。

解答

いずれも C² で勾配は原点で 0、Hessian の全成分も 0、D = 0 です。x⁴ + y⁴ は原点以外で正なので厳密最小、−x⁴ − y⁴ は負なので厳密最大。x⁴ − y⁴ は (t, 0) で t⁴ > 0、(0, t) で −t⁴ < 0 なので鞍点です。二階判定の判定不能は、高次の項や直接の符号評価を調べる必要があるという意味です。

4．停留点を探してから分類する

f=x³−3x+y²の停留点をすべて求め、各点を分類してください。局所の結論と全平面での結論も区別してください。

ヒント1

二つの一階偏導関数を同時に0と置きます。

ヒント2

H=diag(6x,2)です。xが正の点と負の点で符号が変わります。

解答

fₓ=3x²−3、fᵧ=2yより停留点は(1,0)、(−1,0)です。(1,0)ではH=diag(6,2)、D=12なので厳密局所最小、値は−2。(−1,0)ではH=diag(−6,2)、D=−12なので鞍点、値は2です。

直接にもf(1+h,k)−f(1,0)=3h²+h³+k²で、|h|<1なら正です。他方f(−1+h,k)−2=−3h²+h³+k²はk=0で負、h=0で正になります。x→−∞ではf(x,0)→−∞なので、(1,0)は大域最小ではありません。

5．係数の範囲を自分で選ぶ

qₐ=x²+2axy+y²の原点について、厳密最小、厳密でない最小、鞍点になるaの範囲を求めてください。最大になるaはありますか。

ヒント1

Dだけでなく、D=0で残る平方を調べます。

ヒント2

a=1では(x+y)²、a=−1では(x−y)²です。

解答

D=4(1−a²)、A=2です。|a|<1では正定値で厳密最小、|a|>1ではD<0で鞍点。a=±1では平方一つで非負ですが、0になる直線が残るので厳密でない最小です。

どのaでもqₐ(t,0)=t²>0なので原点は局所最大になりません。境界a=1をDだけで放置せず、例えばq₁(1/10,−1/10)=0という点でも非厳密性を検算できます。

6．方向の測定値から行列を復元する

停留点pでC²のfのHessianをH=[[A,B],[B,C]]とします。二次形式Q(v)=vᵀHvについてQ(1,0)=4、Q(0,1)=2、Q((1,1)/√2)=5です。Hを復元し、pを判定してください。

ヒント1

最初の二つは対角成分を直接与えます。

ヒント2

三つ目は(A+2B+C)/2です。Taylorの二次項はQ/2です。

解答

A=4、C=2、(4+2B+2)/2=5からB=2。H=[[4,2],[2,2]]でD=8−4=4>0、A>0なのでpは厳密局所最小です。Q(h,k)=4(h+k/2)²+k²は非零点で正です。

復元後にQ((1,1)/√2)=(4+4+2)/2=5と戻して検算します。単位方向t(1,1)/√2に沿うfの変化の二次主項は5t²/2であり、5t²ではありません。

7．正定値ならいつでも最小か

『f=x+x²+y²のHessianは正定値なので原点は局所最小』という解答を診断し、原点近くで実際に上下の値を示してください。本当の最小点も求めてください。

ヒント1

二階判定の前に勾配を確認します。

ヒント2

x=tとx=−t、y=0で比較し、平方完成もします。

解答

∇f(0)=(1,0)≠0で、停留点という仮定を欠いています。0<t<1ではf(t,0)=t+t²>0、f(−t,0)=−t+t²<0。原点は局所極値ではありません。

f=(x+1/2)²+y²−1/4より、全平面の厳密最小点は(−1/2,0)、値−1/4です。ここでは勾配も0。正定値Hessianの判定と平方完成が一致します。

8．零固有値を残したまま設計する

H(0)=diag(2,0)となる多項式を三つ作り、原点が厳密最小、厳密でない最小、鞍点となるようにしてください。Hessian以外の根拠を添えてください。

ヒント1

x²を共通に残し、yだけの高次項を選べます。

ヒント2

y⁴、0、−y⁴を加えた三つを比較します。

解答

例はx²+y⁴、x²、x²−y⁴です。どれも原点で勾配0、H=diag(2,0)です。最初は非零点で少なくとも一項が正なので厳密最小。二番目は非負ですがy軸全体で0となり、最小は厳密でありません。

三番目は(t,0)でt²>0、(0,t)で−t⁴<0なので鞍点です。t=1/2なら値1/4と−1/16。二次の0を高次項がどう補うかが違いで、零固有値から結論を決めてはいけません。

9．境界の最小と勾配

定義域をD={y≥0}とし、f=x²+yを原点で調べてください。勾配が0でないことは最小の否定になりますか。

ヒント1

比較してよい点は定義域内だけです。

ヒント2

x²とyはどちらも非負で、同時に0になる点を調べます。

解答

D内でf≥0=f(0,0)、等号はx=0、y=0のときだけ。従って原点はD上の厳密大域最小です。∇f(0)=(0,1)≠0ですが、原点はDの内点ではなく、内点の必要条件は適用できません。

全平面へ拡張するとf(0,−t)=−t<0となり最小ではありません。この点はDでは禁止されます。境界の情報を落とすと別問題になることが分かります。

10．すべての直線が上向きでも

G=(y−x²)²−x⁶について、原点でのHessianと、y=0、y=x²、x=0上の値を求めて分類してください。『どの直線でも局所最小だから平面でも最小』の飛躍を説明してください。

ヒント1

二次の項はy²です。平方が消える曲線を選びます。

ヒント2

固定傾きmで得る近傍の大きさが、mに依存する点を考えます。

解答

H(0)=diag(0,2)、D=0で判定不能です。G(x,0)=x⁴(1−x²)>0（0<|x|<1）、G(x,x²)=−x⁶<0、G(0,y)=y²>0より鞍点です。x=1/2で軸上3/64、曲線上−1/64と検算できます。

固定m≠0ではG(x,mx)=x²((m−x)²−x⁴)>0が十分小さい非零xで成り立ちます。しかしその許容範囲はmに依存し、すべての方向と曲線を含む共通の円板を保証しません。正定値の場合の一様な下界が、ここにはありません。
