積分の計算法と適用条件

積分の定義を長方形の和から作り、基本定理で原始関数による計算へ結びました。では、原始関数がすぐ見つからないときはどうするでしょう。微分の合成関数・積の公式を逆向きに読むと、積分の形を変える二つの道具が得られます。公式を当てはめる前に、何をひとまとまりと見るかが大切です。

前提は微分と基本定理です。この章ではまず有限の閉区間で連続な関数を扱い、最後に無限区間や端で発散する場合へ進みます。計算規則と、積分が有限に定まるかという問題を区別しましょう。

見分ける手掛かりは、式の中に「まとまりの微分」が一緒にあるか、積の一方を微分すると簡単になるか、展開だけで済むか、そして積分区間に通常の定理を使えない端がないかです。この順に条件を点検し、正しい公式へ当てはめた後にも、得た原始関数の微分と値の符号で検算します。

学習の目安は演習を含めて140–190分です。置換と端の向き、部分積分と別解、広義積分と演習の三回に分けられます。演習1–3は基本、4–7は形と方法の選択、8–10は収束・切断誤差・条件の診断です。分数や一般の実数指数の微分公式の借用は、使う直前に明示します。

置換積分法

連続微分可能とは、微分でき、その導関数も連続であることです。微分可能なら元の関数は自動的に連続です。連続微分可能は、さらに導関数まで連続であることを求める、より強い条件です。この章で閉区間についていうときは、内点では通常の微分、両端では片側の微分を考え、導関数が端まで連続につながるものとします。

変数と端を一緒に変える

φ が [a, b] で連続微分可能で、f が φ([a, b]) を含む区間で連続なら、次の公式が成り立ちます。φ が単調である必要はありません。

∫abf(φ(x))φ′(x)dx=∫φ(a)φ(b)f(u)du

同じ原始関数を二通りに使う

f の原始関数を H とすれば、連鎖律で (H(φ(x)))′ = f(φ(x))φ′(x)。基本定理から左辺は H(φ(b)) − H(φ(a)) となり、右辺も同じ値です。「du = φ′(x)dx」という書き方はこの関係を覚える略記で、極小量を分数のように勝手に動かす根拠ではありません。

次の積分では、繰り返し現れる内側のまとまり 1+x² を、新しい入力 u として扱います。一般公式の記号に合わせると φ(x)=1+x²、外側の関数は f(u)=u³ です。内側を微分した2xも元の式にあるので、置換の公式をそのまま使えます。なお [H(u)]₁² は、上端の値 H(2) から下端の値 H(1) を引く記号です。

例えば ∫₀¹ 2x(1 + x²)³ dx では、u = 1 + x² と置きます。2x は内側の微分です。端は x = 0 で u = 1、x = 1 で u = 2。よって ∫₁² u³ du = [u⁴/4]₁² = 15/4 です。変数を変えた後も端を 0、1 のままにすると、別の積分を計算してしまいます。

この向きの公式は、φ が折り返しても符号つきで往復分が相殺します。一方、逆関数で x を u の式に解き直す方法では、一対一になる区間を選ぶ必要があります。また φ(x) = x² に x < 0 が含まれるとき、√(x²) は x でなく |x| です。

端の順序も大切です。例えば x を 0 から 1 まで動かし、u = 1 − x と置くと、u は 1 から 0 へ減ります。微分の因子の負号と、積分の向きを反転する負号が対応します。新しい端をいつも小さい順に並べると決めつけず、元の左端と右端がそれぞれどこへ写るかを書きましょう。

折り返す置換と、符号の相殺

φの始点と終点を変える公式は、途中の進み方を原始関数の差へまとめます。単調でなくてもよいのは、逆向きに通った部分が符号付きで差し引かれるからです。「同じ端だから積分は0」という結論は、元の積分にφ′という因子まで含まれる場合に使います。

例題：同じ区間でも、絶対値を付けると答えが変わる

I=∫−112x(1+x²)³dxを考えます。u=1+x²とすると、元の両端x=−1,1はともにu=2です。従ってI=∫22u³du=0。元の原始関数(1+x²)⁴/4を微分しても2x(1+x²)³へ戻り、両端の値も等しいので検算できます。

途中で何が起きたかを見ると、xが−1→0ではuは2→1へ減り、この部分は∫21u³du=−15/4。xが0→1では1→2へ増え、15/4を加えます。二つは相殺します。

J=∫−11|2x|(1+x²)³dxでは同じ置換をそのまま使えません。x<0では|2x|=−2xなので、左の寄与は−∫21u³du=15/4、右も15/4。よってJ=15/2です。被積分関数は非負なので、J>0という答えの符号も自然です。端だけを写してJ=0とするのは、微分因子の符号を落とした誤りです。

部分積分法

積の微分からの公式

u、v が [a, b] で連続微分可能なら、次の式が成り立ちます。角括弧は [uv]ₐᵇ = u(b)v(b) − u(a)v(a) を表します。

∫abuv′dx=[uv]ab−∫abu′vdx

積を微分してから集める

(uv)′ = u′v + uv′ の両辺を積分すると、基本定理で [uv]ₐᵇ = ∫ₐᵇ u′v dx + ∫ₐᵇ uv′ dx。右の一項を移すだけです。積の積分を、それぞれの積分の積にしてよいという公式ではありません。

ここからの分数の指数を使う計算と、後の一般の指数 p の例では、正の x に対する実数べき xᵖ の定義と微分公式 (xᵖ)′=pxᵖ⁻¹ を一時的に借用します。初等関数の章では xᵖ=exp(p log x) と定めて、この公式を示します。expはそこで作る指数関数、logはその逆関数の名前です。その構成は本章の広義積分を使わないので、依存は循環しません。

次の例では x を微分すると1になり、残る平方根の因子は積分できます。どちらを微分し、どちらを積分すると元より簡単な式になるかを、この組合せで試します。

例として I = ∫₀¹ x√(1 + x)dx を計算します。u = x、v′ = √(1 + x) と選べば、u′ = 1、v = (2/3)(1 + x)³ᐟ²。部分積分で I = 4√2/3 − (2/3)∫₀¹(1 + x)³ᐟ²dx。残りは原始関数 (2/5)(1 + x)⁵ᐟ² を使い、I = 4√2/3 − (4/15)(4√2 − 1) = 4(√2 + 1)/15 です。x を微分して単純にする選択が効きました。

役の選び方は一通りではありませんが、新しい積分が簡単になるかで判断します。微分した方が複雑になる関数を u に選ぶと、正しい等式でも計算が遠回りになることがあります。部分積分は答えを自動で出す命令ではなく、元の問題を別の積分へ結び付ける等式です。得た原始関数を最後に微分し直せば、符号や係数を独立に確認できます。

被積分関数の構造と計算法の比較

公式が正しく使えることと、その計算が最短に近いことは別です。部分積分では、微分する側が簡単になるだけでなく、残った積分が解けるかを見ます。置換では、内側の微分があるかに加え、残りのxを新しい変数で全部表せるかを確認します。

例題：同じ積分を置換で解き、部分積分と照合する

前節のI=∫01x√(1+x)dxでは、xを微分する部分積分が使えました。一方u=1+xと置けばx=u−1、dxに対応する因子はduで、端は1から2です。残りのxもすべてuで書けるので、I=∫12(u−1)u1/2du=∫12(u3/2−u1/2)du。

原始関数は(2/5)u5/2−(2/3)u3/2です。端を入れるとI=(2/5)(4√2−1)−(2/3)(2√2−1)=4(√2+1)/15で、部分積分の答えと一致します。微分するとu3/2−u1/2へ戻るため、係数も検算できます。

次にJ=∫01x²√(1+x)dxを考えます。部分積分でx²を微分してもまだxが残りますが、同じ置換なら一度にJ=∫12(u−1)²u1/2du。展開してu5/2−2u3/2+u1/2を積分し、

J=[(2/7)u7/2−(4/5)u5/2+(2/3)u3/2]12=(44√2−16)/105。

上端の係数は16/7−16/5+4/3=44/105、下端は2/7−4/5+2/3=16/105です。もとの区間では1≤√(1+x)≤√2なので、1/3≤J≤√2/3という比較も使えます。得た約0.4402はこの範囲にあり、答えの大きさも矛盾しません。

広義積分と端点での収束

∫₁∞ f(x)dx は、まず有限の R で ∫₁ᴿ f(x)dx を計算し、R → ∞ の有限な極限があるときに定めます。∫₀¹ f(x)dx では、0で f が未定義であったり、0の近くで有界でなかったりする場合（このような点を、ここでは特異点と呼びます）には、0 < ε < 1 の各区間 [ε,1] で通常の積分が存在すると仮定します。εを正のまま0へ近づける（ε → 0+ と書く）とき、∫ε¹ f(x)dx が有限な値へ収束すれば、その値を ∫₀¹ f(x)dx と定めます。これが広義積分です。無限大を式へ直接代入する操作ではありません。

ここで無限遠の極限を言葉にしておきます。各有限のR≥1についてF(R)=∫₁ᴿf(x)dxが存在すると仮定します。R→∞でF(R)の極限が実数Aであるとは、どんな許容誤差η>0に対しても境目R₀を選べて、R≥R₀のすべての実数Rで|F(R)−A|<ηになることです。数列の極限で使った整数Nを、実数の境目R₀へ替えた形です。有限な極限がない場合を発散と呼びます。特にF(R)→∞とは、どんな実数Mに対しても境目R₀を選べて、R≥R₀なら必ずF(R)>Mとなることです。発散には振動する場合もあり、発散すべてが→∞ではありません。

次の実数べきの例では、a>0ならR→∞でRᵃ→∞、R⁻ᵃ→0となり、ε→0+ではεᵃ→0、ε⁻ᵃ→∞となる性質も借用します。これは初等関数の章のxᵃ=exp(a log x)から確かめられます。例えばR⁻ᵃ<ηを保証するにはR>η⁻¹ᐟᵃとすればよく、どこまで進めばよいかも逆算できます。

実数 p に対する x⁻ᵖ（x > 0）を調べましょう。部分積分の節で一時借用した実数べきの微分公式により、p ≠ 1 なら原始関数は x¹⁻ᵖ/(1 − p) です。

∫1∞1xpdx が収束⇔p>1,∫011xpdx が収束⇔p<1

無限側では p > 1 のとき R¹⁻ᵖ → 0 となり、値は 1/(p − 1)。p < 1 では R¹⁻ᵖ → ∞ で発散します。0 側では p < 1 のとき ε¹⁻ᵖ → 0 で値は 1/(1 − p)、p > 1 では発散です。同じ関数でも、どちらの端を問題にするかで条件が逆になります。

無限側では減る速さが十分かを問い、零の側では発散の強さが積み重ねに耐えるかを問います。グラフが零へ近づくだけでも、グラフが端で無限に高くなるだけでも、収束の判定には足りません。有限の区間で計算してから極限を取る手順が、この二つの直感を正確な条件へ変えています。

境界の p = 1 は両側で発散します。無限側では各区間 [2ᵏ, 2ᵏ⁺¹] で 1/x ≥ 1/2ᵏ⁺¹ なので積分は少なくとも 1/2。区間を増やすたび同じ量以上が加わります。0 側も [2⁻ᵏ⁻¹, 2⁻ᵏ] の積分が少なくとも 1/2。対数の公式をまだ使わずに境界を判定できました。

内点で発散する場合は、その点の左右の広義積分を別々に定め、両方が有限な場合だけ足します。∫₋₁¹ 1/x dx を左右対称に打ち消して 0 とする操作は、通常の広義積分の収束を意味しません。

表の p=1 の行にある log は、後の初等関数の章で定義する対数です。その行の有限区間の計算式は先の内容を使う参照例ですが、発散するという結論は、上で示した区間ごとの1/2の下限だけで既に分かります。対数の公式を前提にする必要はありません。

広義積分の切断と残りの誤差

広義積分が収束すると分かっても、有限の区間だけを計算してどこまで正確かは別の問題です。無限端をRで切ったり、零端をηだけ避けたりしたとき、除いた部分の積分を切断誤差として評価します。以下の被積分関数は非負なので、除いた分はそのまま値の不足になります。

例題：無限区間で、必要な上端を逆算する

∫0∞dx/(1+x)²を考えます。有限のR>0なら原始関数−1/(1+x)で、∫0Rdx/(1+x)²=1−1/(1+R)。R→∞で1へ収束するので、広義積分値は1です。残りの∫R∞は1/(1+R)。誤差0.001以下を保証するには1/(1+R)≤0.001からR≥999で十分で、この関数では必要でもあります。

無限区間を有限へ写す置換も、まず有限のRで行います。t=1/(1+x)ならx=1/t−1、dx/dt=−1/t²、元の被積分関数はt²。端はx=0でt=1、x=Rでt=1/(1+R)です。従って有限の積分は∫11/(1+R)(−1)dt=1−1/(1+R)となります。その後R→∞を取れば、向きを直した区間[0,1]の定数1の積分へつながります。この例では特異性が相殺しましたが、どんな関数でもそうなる保証はありません。

例題：小さい幅を除いても、誤差が同じ幅とは限らない

零端で発散する1/√xでも、∫η1x−1/2dx=2−2√ηなので、η→0+で2へ収束します。除いた部分の誤差は2√η。η=0.0001なら誤差は0.02であり、除いた幅0.0001とは桁が違います。端付近の高さが大きいことが効いています。

誤差0.001以下には2√η≤0.001、従って0<η≤0.00000025と選びます。η=1/4000000なら2√η=1/1000と検算できます。無限端ではRを大きくし、零端ではηを小さくするという逆向きの操作ですが、どちらも有限区間を計算して、残りを上から押さえるという同じ目的です。

寄り道［応用］：無限に広い積分区間を、0から1へ折りたたむ

数値積分プログラム QUADPACK の公開ソースには、無限区間を (0, 1) へ変換してから積分する処理があります。式を簡単にするための置換は、手計算を楽にする技巧にとどまらず、計算機が扱う区間そのものを設計する方法でもあるのです。

例えば x = a + (1 − t)/t と置くと、t が 1 から 0 へ近づくにつれ、x は a から無限大へ進みます。dx/dt = −1/t² なので、向きを直した積分では f(a + (1 − t)/t)/t² を使います。ソースにも、この入力の読み替えと t² による割り算が現れます。無限遠は端点 t = 0 へ移ったのであり、困難が消えた保証はありません。そこでの収束と、変換後の関数の振る舞いを確かめることが、置換を使いこなす次の一歩です。

出典：Netlib QUADPACK：dqk15i.f の変数変換。

積分公式と広義積分の演習

1．端も置き換える

∫₀² 2x(1 + x²)dx を置換積分で求めてください。

ヒント1：内側を一つの文字にする

u = 1 + x² とします。

ヒント2：端を書き直す

x = 0、2 は u = 1、5 に対応します。

解答

du に対応する因子は 2x dx なので、積分は ∫₁⁵ u du = [u²/2]₁⁵ = (25 − 1)/2 = 12。元の多項式 2x + 2x³ を積分しても 4 + 8 = 12 です。

2．微分する役を選ぶ

∫₀¹ x(1 + x)²dx を、u = x とする部分積分で求めてください。

ヒント1：残りを積分する

v′ = (1 + x)² なら v = (1 + x)³/3 です。

ヒント2：境界項を先に計算する

[x(1 + x)³/3]₀¹ = 8/3 です。

解答

公式から 8/3 − (1/3)∫₀¹(1 + x)³dx = 8/3 − [(1 + x)⁴/12]₀¹ = 8/3 − 15/12 = 17/12。残りの積分の前に付く負号を保つのが要点です。

3．同じべきでも端が違う

∫₀¹ x⁻¹ᐟ²dx と ∫₁∞ x⁻¹ᐟ²dx の収束を、有限区間での計算から判定してください。

ヒント1：原始関数

2√x を微分すると x⁻¹ᐟ² です。

ヒント2：別々の極限

前者は 2 − 2√ε、後者は 2√R − 2 を調べます。

解答

ε → 0+ では 2 − 2√ε → 2 なので前者は収束し、値は 2。R → ∞ では 2√R − 2 → ∞ なので後者は発散します。p = 1/2 は 0 側の p < 1 を満たしますが、無限側の p > 1 は満たしません。

4．減る置換の負号を診断する

∫02(3−x)²dxにu=3−xを使い、∫31u²du=−26/3とした解答を修正してください。元の式の符号と、別の方法でも検算してください。

ヒント1

duに対応する微分因子は−dxなので、dxの側にも負号が必要です。

ヒント2

正しくは−∫31u²duです。展開すれば9−6x+x²です。

解答

−∫31u²du=∫13u²du=(27−1)/3=26/3です。元の被積分関数は非負なので負の答えは不自然です。展開しても[9x−3x²+x³/3]02=18−12+8/3=26/3となります。端の順序を逆にする負号と、導関数の負号を対応させます。

5．平方根の枝を間違えない

∫−20√(x²)dxを計算してください。√(x²)=xとして負の答えを得た議論はどこで条件を落としましたか。u=x²からx=√uとだけ書いてよいかも説明してください。

ヒント1

平方根は非負を選ぶので√(x²)=|x|です。

ヒント2

この区間では|x|=−xで、逆向きの式はx=−√uの枝です。

解答

∫−20(−x)dx=[−x²/2]−20=2です。√(x²)=xが使えるのはx≥0のときで、この区間には負のxがあります。u=x²を逆に解くなら負の枝x=−√uが対応し、正の枝だけを選ぶと元の区間を表していません。元の積分は非負の関数の面積なので2という符号も確認できます。

6．展開と置換を比較して選ぶ

∫01x²(1+x)²dxを、(a)先に展開、(b)u=1+xと置換、の二通りで求めてください。今回どちらを選ぶか、変形後の式の長さから説明してください。

ヒント1

(a)はx²+2x³+x⁴です。(b)ではx=u−1で端は1,2です。

ヒント2

(b)の被積分関数は(u−1)²u²=u⁴−2u³+u²です。

解答

(a)は1/3+1/2+1/5=31/30。(b)は[u⁵/5−u⁴/2+u³/3]12=16/15−1/30=31/30で一致します。今回はどちらも三項ですが、(a)は端の変更がなくそのまま計算できるため簡単です。内側が見えるという理由だけで必ず置換する必要はありません。両方とも原始関数を微分して三項へ戻ると検算できます。

7．原始関数の定数を部分積分へ入れる

∫01x(1+x)²dxでu=x、v′=(1+x)²とします。v=(1+x)³/3+Cという別の原始関数を選んでも結果が同じになることを、境界項と残りの積分のCを追って示してください。

ヒント1

v0=(1+x)³/3と書くと、[x(v0+C)]01は、C=0の場合よりCだけ増えます。

ヒント2

残りの∫01u′(v0+C)dxもCだけ増え、公式では前に負号があります。

解答

v0=(1+x)³/3と書けば、境界項は[xv0]01+C、残りの項は−∫01v0dx−Cです。追加分C−Cが消えるので、値はC=0の場合と同じ17/12です。境界項にだけCを加えて残りに加えないと、別のvを同じ公式の両方へ入れたことになりません。微分すれば定数は消えますが、部分積分中は二箇所で整合させます。

8．零端と無限端を同時に満たせるか

実数pについて、∫0∞x−pdxが通常の広義積分として収束するpをすべて求めてください。1で区間を分け、それぞれ有限区間の極限が必要なことから説明してください。

ヒント1

零端の条件と無限端の条件を別々に書きます。

ヒント2

零端はp<1、無限端はp>1です。境界p=1はどうでしたか。

解答

0から1の積分が有限なのはp<1、1から∞が有限なのはp>1で、同時には満たせません。p=1も両端で発散します。従って収束する実数pはありません。p<1なら無限側のR1−pが発散し、p>1なら零側のη1−pが発散します。一方の端だけを調べて全体へ結論を広げられない例です。

9．絶対誤差と相対誤差で上端を設計する

I=∫2∞dx/(1+x)²を、2≤Rまでの積分IRで近似します。Iと切断誤差を求め、相対誤差|I−IR|/|I|を1%以下にする最小のRを決めてください。R=99の場合の絶対誤差と相対誤差も比べてください。

ヒント1

IR=1/3−1/(1+R)なので、I=1/3です。

ヒント2

相対誤差は3/(1+R)です。1%は無単位の0.01です。

解答

I=1/3、切断誤差は1/(1+R)です。相対誤差≤0.01には3/(1+R)≤0.01、従ってR≥299で、最小は299です。R=99なら絶対誤差は0.01ですが、相対誤差は0.01/(1/3)=0.03=3%。絶対値の0.01と1%は違う注文です。有限Rの式から単調に誤差が減ることも分かり、R=299で相対誤差がちょうど1%になると検算できます。

10．対称の打消しと広義積分の違い

0<η<1でSη=∫−1−ηdx/x+∫η1dx/xを考えます。各ηでSη=0でも、∫−11dx/xが通常の広義積分として収束しない理由を説明してください。対数の公式を使わず、正側の下限で判断しても構いません。

ヒント1

左はx=−tの置換で右の負になります。しかし定義では左右を独立に収束させます。

ヒント2

[2−k−1,2−k]では1/x≥2kで、幅は2−k−1です。

解答

同じηなら二つの有限積分は符号が逆でSη=0です。一方、各正側の区間の積分は少なくとも2k·2−k−1=1/2。η=2−NまでN区間を足すと正側はN/2以上となり、有限値へ収束しません。左側も符号を逆にして発散します。通常の広義積分は左右がそれぞれ有限であることを要求するので、対称に同じ幅を除いた和の極限0とは違います。発散する二量を相殺して収束と呼ぶことはできません。
