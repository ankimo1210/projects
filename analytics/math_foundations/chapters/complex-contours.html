複素線積分と積分路

実の積分では、小さな横幅 dx に関数の値を掛けて足しました。複素平面の道では、横にも縦にも動きます。その小さな移動 dz を複素数として掛けて足すと、終点だけで決まる量と、道の回り方を覚えている量が現れます。両者をどう見分ければよいでしょう。

前提は実の定積分、微積分の基本定理、複素微分、主値対数の定義域です。この章ではCauchyの定理、GreenやStokesの定理を使いません。

曲線のパラメータ表示と線積分

区分 C¹ 曲線とは、閉区間 [α, β] から平面への連続な写像 γ で、区間を有限個に分ければ各部分で C¹ になるものです。各部分の導関数は端まで連続に延長できるとします。折れ線の角で微分がなくても構いません。γ(α) が始点、γ(β) が終点で、等しければ閉曲線です。同じ点を何度通るかも、曲線のデータに含めます。

f が曲線の像で連続なら、複素線積分を次で定めます。各 C¹ 部分で積分し、その値を足します。複素数値関数の実パラメータによる積分は、実部と虚部の実積分を別々に行うという意味です。

∫γf(z)dz=∫αβf(γ(t))γ′(t)dt

γ = x + iy、f(γ) = u + iv と書けば、掛け算から次の二成分になります。u、v も道に沿った t の関数です。fをただ時間で足す ∫f(γ(t))dt とは異なり、γ′ を掛けることで道の移動そのものを数えます。

∫γfdz=∫(ux′−vy′)dt+i∫(vx′+uy′)dt

例えば線分 γ(t) = a + t(b − a)、0 ≤ t ≤ 1 なら、dz = (b − a)dt。定数 f = c の積分は c(b − a) です。向きと長さが b − a に含まれています。道に沿っての移動量を数える定義から、実積分の線形性により ∫γ(Af + Bg)dz = A∫γf dz + B∫γg dz（A、B は複素定数）が従います。

再パラメータ化・向きの反転・連結

η(s) = γ(φ(s)) とし、φ が新しい区間から [α, β] への増加 C¹ 全単射で、φ′ > 0 とします。連鎖律で η′(s) = γ′(φ(s))φ′(s)。実積分の置換 t = φ(s) を二成分に使えば、∫η f dz = ∫γ f dz です。区分ごとにこの条件を満たす場合も同様です。ここでは、この条件を満たす向きの保存された再パラメータ化を扱います。

逆向き −γ は t ↦ γ(α + β − t)。導関数に負号が付き、置換すると ∫−γf dz = −∫γf dz になります。また、γ₁ の終点と γ₂ の始点が一致するとき、続けてたどる道 γ₁ * γ₂ の積分は二つの積分の和です。一周を二回たどるなら二倍であり、像の図形が同じというだけで同じ積分とはいえません。

同じ被積分関数 z̄ で、操作と積分値を対応づける
操作パラメータ表示・道∫ z̄ dz何が保たれたか
基準の直線γ(t)=t(1+i), 0≤t≤1。1。始点0、終点1+i。
速さだけを変更γ(s)=(s/2)(1+i), 0≤s≤2。1。同じ道・同じ向き。速度は半分、区間は二倍。
向きの反転γ(t)=(1−t)(1+i), 0≤t≤1。−1。同じ道を逆にたどり、符号が反転。
連結して別の道0→1→1+i の二線分。1/2+(1/2+i)=1+i。同じ端点でも道が違えば値は変わる。連結では二積分を足す。

速さの行は向きを保つ滑らかな再パラメータ化です。別の道の行では被積分関数は同じ共役のままです。「速さを変える」と「道を変える」を同一視しないでください。経路独立性には原始関数の存在などの別の理由が必要です。

ML評価と積分の上界

曲線の長さを L(γ) = ∫αβ|γ′(t)|dt と定めます。角のある場合は部分ごとの和です。曲線上で |f| ≤ M なら、積分の絶対値は M と長さの積以下になります。これをML評価と呼びます。

|∫γf(z)dz|≤∫αβ|f(γ(t))||γ′(t)|dt≤ML(γ)

複素積分の三角不等式を、実部へ戻す

区分連続な g(t) の積分を I とします。I = 0 なら |I| ≤ ∫|g| は明らかです。I ≠ 0 なら c = Ī/|I| と置けば |c| = 1、cI = |I|。したがって |I| = Re(cI) = ∫Re(cg(t))dt ≤ ∫|g(t)|dt です。g = f(γ)γ′ を代入し、曲線上での上限 M を使えばML評価になります。複素数を大小で比較したのでなく、その実部を比較しました。

例えば半径 R の円の長さは 2πR。円上で |f| ≤ 3 なら、積分の絶対値は 6πR 以下です。これは上界であり、積分の正確な値とは限りません。細かい打ち消し合いがあれば実際の値はもっと小さくなります。後の章では、小円を縮めるときの誤差をこの評価で消します。

原始関数と経路独立性

開集合 U 上で F が正則で、F′ = f となるとき、F を f の原始関数と呼びます。ここでは f は連続とします。曲線 γ の像が U に含まれれば、実の微積分の基本定理が、道に沿って使えます。

曲線に沿う基本定理

∫γf(z)dz=F(γ(β))−F(γ(α))

実パラメータに沿って微分する

各 C¹ 部分で、複素微分が表す実全微分と実の連鎖律から dF(γ(t))/dt = F′(γ(t))γ′(t) = f(γ(t))γ′(t)。右辺は連続です。実部と虚部へ実の基本定理を使い、部分区間の端点の差を足します。途中の端点の F の値は打ち消し合い、最初と最後だけが残ります。

したがって、同じ開集合に原始関数があれば、同じ端点を結ぶどの区分 C¹ 曲線でも積分は同じで、閉曲線の積分は0です。例えば f(z) = z² は F(z) = z³/3 を全平面に持ちます。0から1 + iへの積分は、どんな道でも (1 + i)³/3 = (−2 + 2i)/3 です。

一般の連続関数では道が重要です。f(z) = z̄ を0から1 + iへ積分すると、直線と折れ線で次の違いが出ます。

二本の道を、定義どおりに計算する

直線 γ(t) = (1 + i)t、0 ≤ t ≤ 1 では、γ̄γ′ = (1 − i)t(1 + i) = 2t なので積分は1です。折れ線の横の部分は γ₁(t) = t で積分が ∫₀¹t dt = 1/2。縦は γ₂(t) = 1 + it、γ̄₂γ′₂ = (1 − it)i = t + i なので1/2 + i。和は1 + iです。折れ線を進み直線を逆に戻る閉曲線の積分はiになり、全平面で z̄ の原始関数が存在しないことも分かります。

円周積分と負一乗の核

a を中心とする半径 R > 0 の円を、反時計回りに一周する曲線 C : γ(t) = a + Rexp(it)、0 ≤ t ≤ 2π とします。円の中心 a は曲線上にありません。f(z) = 1/(z − a) は曲線上で連続なので、積分を定義できます。

分母と接ベクトルを、直接約分する

γ′(t) = iRexp(it) なので、f(γ(t))γ′(t) = i。したがって積分は ∫₀²π i dt = 2πi です。半径 R には依存しません。時計回りなら向きの反転により −2πi、同じ向きに二周すれば4πiです。

∮Cdzz−a=2πi

この結果を、ほかの整数べきと並べます。次の C は上で定めた反時計回りの円です。

∮C(z−a)kdz={2πik=−10k∈ℤ,k≠−1

k ≠ −1 の場合は、F(z) = (z − a)ᵏ⁺¹/(k + 1) が原始関数です。負の整数べきでも、a を除いた開集合上では通常の商の微分則で確かめられます。円は閉じているので基本定理から積分は0。k = −1 だけはこの式で割れず、一周の積分が残ります。ここでは整数べきだけを使い、枝の必要な一般の複素べきは使っていません。

1/(z − a) は a を除けば正則ですが、ℂ ∖ {a} 全体で原始関数を持ちません。持てば閉曲線の積分が0となり、2πiという直接計算に反するからです。特に a = 0 では、前章の主値Logは切断した領域で原始関数になりますが、原点を一周する円全体はその領域に入りません。Log′ = 1/z を、切断をまたぐ円に適用することはできません。

さらに、ℂ ∖ {0} に正則な対数 L があると仮定すれば、exp L(z) = z を微分して exp L(z)L′(z) = 1、つまり L′(z) = 1/z になります。これは上の積分と矛盾します。前章の連続な角度の議論と、この積分の議論は、同じ一周の障害を別々に捉えています。

閉曲線で積分が0になるのは、どの条件のもとでしょうか。正則性に加え、道と定義域の形を確かめる必要があります。次のCauchyの定理で、この問いを小さな三角形から調べます。

寄り道［自作モデル］：長方形の面積が、虚部に現れる

原点、b、b + ih、ih を順に進む反時計回りの長方形を考えます。b、h は正の実数です。下辺の ∫z̄ dz は b²/2、右辺は h²/2 + ibh、上辺は −b²/2 + ibh、左辺は −h²/2 と、各線分を実パラメータで計算できます。

和は2ibh、つまり虚部は面積 bh の2倍です。実部は各辺どうしで打ち消し合います。これはこの長方形についての直接計算であり、一般の領域の面積公式を証明したわけではありません。複素積分が道の囲む量を覚えることを、四本の実積分だけで観察できます。

出典：本章の積分の定義に基づく自作の長方形モデルです。Greenの定理など一般の面積定理は用いていません。

演習：複素線積分

1．同じ線分を、違う速さで進む

γ(t) = (1 + i)t、0 ≤ t ≤ 1 と η(s) = (1 + i)(s + s²)/2、0 ≤ s ≤ 1 で、∫z dz を計算し、同じ値になることを確かめてください。

ヒント1：共通の原始関数

F(z) = z²/2 は全平面で z の原始関数です。

ヒント2：再パラメータ化

φ(s) = (s + s²)/2 は端点を保ち、φ′ = (1 + 2s)/2 > 0 です。

解答

どちらも0から1 + iへ進み、積分は ((1 + i)² − 0)/2 = i です。直接には γ で被積分関数は2it、ηで2iφ(s)φ′(s) となり、それぞれの積分もiです。向きを保つ速さの変更なので一致します。

2．ML評価と正確な値

線分0から1 + iに沿う ∫z dz の絶対値を、M = √2、L = √2 を用いて評価し、正確な値と比べてください。

ヒント1：線分上の絶対値

z = (1 + i)t、0 ≤ t ≤ 1 なので |z| = √2t ≤ √2 です。

ヒント2：積分の値と上界

前問の積分はiです。その絶対値と ML を比較します。

解答

ML評価は |∫z dz| ≤ (√2)(√2) = 2。正確な値はiで、その絶対値は1なので評価を満たします。さらに ∫₀¹|γ(t)||γ′(t)|dt = ∫₀¹2t dt = 1 まで計算すれば鋭い評価ですが、MLは最大値だけで簡単に得られる上界です。

3．一周と原始関数

|z − 2| = 3 を時計回りに一周するとき、∮dz/(z − 2) と ∮dz/(z − 2)² を求めてください。二つ目の原始関数も挙げてください。

ヒント1：反時計回りとの関係

一つ目は反時計回りなら2πiです。向きを反転します。

ヒント2：負の整数べき

−1/(z − 2) の導関数を調べます。

解答

一つ目は −2πi。二つ目は F(z) = −1/(z − 2) という原始関数が ℂ ∖ {2} にあるため0です。どちらの関数も中心2では未定義ですが、円上では連続です。中心に特異点があるだけで、すべての閉曲線積分が非零になるわけではありません。
