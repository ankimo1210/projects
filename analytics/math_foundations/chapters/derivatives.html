微分係数と局所的な線形近似

位置が f(t) = t² で変わる物体を、仮想のモデルとして考えます。例えば時刻1から1.1までなら、位置は1から1.21へ変わり、位置の差0.21を時間の差0.1で割った平均の変化率は2.1です。一般の時刻 a から a+h までなら、位置の差が f(a+h)−f(a)、時間の差が h なので、その比は {f(a+h)−f(a)}/h となります。

時間幅 h を小さくすれば、時刻 a での符号付きの速度に迫れそうです。正は位置が増す向き、負は減る向きの変化を表します。しかし h=0 を代入すると0で割ることになります。一瞬の変化率は、どのように定義すればよいでしょうか。

もう一つの見方は、曲線を一点の近くで直線に置き換えることです。直線の傾きを選んだとき、ずれが入力の変化 h よりも速く小さくなるなら、その傾きは局所的な変化をよく表しています。微分は、この近似の条件を極限で正確に述べます。

学習の目安は演習込み130–190分です。定義と線形近似、連続性との違い、積・合成・逆関数の順に分けて読めます。演習1–3は基本、4–7は残りの大きさと計算規則の診断、8–10は条件の確認と設計です。

微分係数・導関数の定義

実数の開区間 I 上で定義された関数 f と、その内側の点 a を考えます。h ≠ 0 で a + h が I に入るときの差の商が、h → 0 で有限の実数に収束すれば、f は a で微分可能といい、その極限を微分係数 f′(a) と呼びます。左右のどちらから近づいても、同じ値に収束する必要があります。

f′(a)=limh→0f(a+h)−f(a)h

各点の微分係数を対応させた関数 f′ を導関数と呼びます。区間の端で片側だけを使う定義もありますが、この章の微分可能性は内点での両側の定義です。定義域を確認せずに、端点や穴のある点へ同じ式を当てはめないようにします。

局所的な一次近似との言い換え

f が a で微分可能で f′(a) = m であることは、f(a + h) = f(a) + mh + r(h) と書けて、r(h)/h → 0 となることと同値です。r(h) は直線近似の残りです。

定義を引き算する

r(h) = f(a + h) − f(a) − mh と置くと、h ≠ 0 で r(h)/h は差の商から m を引いたものです。したがって差の商が m へ収束することと、残りの比が 0 へ収束することは同じです。単に r(h) → 0 では不十分で、入力の大きさと比べて無視できることが肝心です。

二次関数の微分と接線

f(x) = x² なら、h ≠ 0 で {(a + h)² − a²}/h = 2a + h です。よって h → 0 の極限は 2a。すべての実数 a で f′(a) = 2a となり、直線は y = a² + 2a(x − a) です。一次近似の残りは h² であり、h²/h = h → 0 とも確認できます。

差の商は二点を結ぶ割線の傾きで、接線の傾きはその極限です。h = 0 で差の商に 2 を代入して定義し直すことはできますが、それは元の割り算を実行したことではありません。この区別は、数値計算で非常に小さい h を使うときにも残ります。

微分可能なら連続です。差の商は有限の値へ収束するため、十分小さい h では有界です。f(a + h) − f(a) はその商と h の積なので 0 に近づきます。逆向きは、次の反例が否定します。

逆数関数の微分と近似誤差

公式を適用する前に、差の商がどのように有限の値へまとまるかをもう一つ確かめます。f(x)=1/xはx≠0で定義されます。点a≠0を固定し、|h|<|a|/2とすれば|a+h|≥|a|−|h|>|a|/2なので、a+hも0ではありません。まず定義域から外れない入力幅を選ぶ必要があります。

例題：差の商と線形近似の残りを両方求める

h≠0で、差の商は{1/(a+h)−1/a}/h={−h/(a(a+h))}/h=−1/(a(a+h))です。分母の極限a²は0でないので、h→0の極限は−1/a²。従ってf′(a)=−1/a²です。

直線近似はf(a+h)≈1/a−h/a²。近似記号≈はここでは一次近似を表し、等号ではありません。残りを厳密に計算すると、r(h)=1/(a+h)−1/a+h/a²=h²/(a²(a+h))です。従って|r(h)|≤2h²/|a|³、|r(h)/h|≤2|h|/|a|³→0となり、定義との言い換えも確かめられます。

a=2、h=0.01なら、近似値は1/2−0.01/4=0.4975です。実際の値は100/201で、残りは1/80400、約0.00001244。上の評価は|r(h)|≤h²/4=0.000025を保証します。誤差の上界は実誤差と同じである必要はありませんが、その値を超えない理由が式として残ります。またa+h>0ではr(h)>0なので、この範囲の直線近似は実際の値より小さいことも分かります。

連続性と微分可能性の違い

f(x) = |x| は 0 で連続です。実際、|f(h) − f(0)| = |h| なので、入力のずれを ε 未満にすれば出力も ε 未満です。ところが差の商 |h|/h は、h > 0 で 1、h < 0 で −1。両側からの極限が一致せず、0 で微分できません。

グラフの角という見た目は、この不一致を表しています。ただし判定に使ったのは図の印象ではなく、二つの近づき方で得られる値です。また 0 以外では、正の側で f′ = 1、負の側で f′ = −1 となります。ある点で失敗しても、関数全体がどこでも微分できないわけではありません。

区分的な関数の微分可能性

グラフを継ぎ合わせるとき、値がつながることと傾きがつながることを別々に調べます。実数A、Bを使い、x≤1でf(x)=x²、x>1でf(x)=Ax+Bとします。点1で微分可能になるようにA、Bを決められるでしょうか。異なる式を使う点では、どちらか片方の式を微分して終えることはできません。

例題：連続性を先に満たしてから傾きを合わせる

微分可能なら連続なので、まず右からの値A+Bがf(1)=1と一致する必要があります。従ってA+B=1です。h<0なら差の商は{(1+h)²−1}/h=2+hで、左からの極限は2。一方h>0なら{A(1+h)+B−1}/h=A+(A+B−1)/hです。

連続条件A+B=1を入れると右側の商はAとなります。左右が同じ有限値へ行くためにはA=2が必要で、従ってB=−1です。この組なら左の商2+hも右の商2も2へ収束するので、条件は十分でもあります。f′(1)=2で、右側に接いだ直線2x−1は、左側の放物線の点1での接線そのものです。

例えばA=0、B=1でも値はつながりますが、左の傾き2と右の傾き0は一致しません。A+B≠1なら、右側の商には0でない定数をhで割る項が残り、連続性すら失われます。この順番で条件を処理すると、何がどの失敗を直したかを区別できます。

積の微分と連鎖律

積の法則と連鎖律

f、g が同じ点 a の近くで定義され、a で微分可能なら、(fg)′(a) = f′(a)g(a) + f(a)g′(a) です。また f が a で微分可能、g が f(a) を含む開区間で定義され f(a) で微分可能で、a の近くの f の値がその区間に入るなら、(g ∘ f)′(a) = g′(f(a))f′(a) です。

余分な項を足し引きする

積の差を、{f(a + h) − f(a)}g(a + h) + f(a){g(a + h) − g(a)} に分解して h で割ります。二つの差の商は微分係数へ、g(a + h) は連続性により g(a) へ収束します。極限の和と積の法則から、積の公式が出ます。同じ考え方で和の法則 (f + g)′ = f′ + g′ と、定数倍の法則 (cf)′ = cf′ も得られます。

合成では k = f(a + h) − f(a) とします。外側の微分可能性から g(f(a) + k) − g(f(a)) = g′(f(a))k + kη(k) と書け、η(k) → 0 です。η(0) = 0 と決めれば k = 0 でも等式は成立します。h で割ると、k/h → f′(a)、連続性から k → 0、したがって (k/h)η(k) → 0。これが連鎖律です。k で直接割る証明では、k = 0 の場合を落としてしまうので注意します。

規則を具体的に使う前に、外側に使う三乗の微分を確かめます。積の法則と (u²)′=2u、(u)′=1 から、(u³)′=(u²u)′=2u·u+u²·1=3u² です。次の例では、uという入力自体がxとともに動きます。

例えば (x² + 1)³ は、内側 x² + 1 と外側 u³ の合成です。外側を u で微分した 3u² に、内側の微分 2x を掛けます。導関数は 6x(x² + 1)²。掛ける 2x は、内側の入力がどの速さで変わるかを換算しています。外側の式だけ微分して終わりにはできません。

連鎖律における内側の値と変化率

合成が三段になると、微分する変数と、その導関数へ代入する値を区別する必要がはっきりします。H(t)=(1+(3t−1)²)³を考えます。内側からu(t)=3t−1、v(u)=1+u²、w(v)=v³と名前を付ければ、H=w∘v∘uです。どの段階も実数全体で微分可能なので、連鎖律を二度使えます。

例題：各段階の入力をそろえて掛ける

各導関数はu′(t)=3、v′(u)=2u、w′(v)=3v²。従ってH′(t)=w′(v(u(t)))v′(u(t))u′(t)=3(1+(3t−1)²)²·2(3t−1)·3=18(3t−1)(1+(3t−1)²)²です。最後の3を落とすと、内側の入力がtの三倍の速さで動く分を忘れます。

t=0ではu=−1、v=2、H=8です。外側の変化率はw′(2)=12、中間はv′(−1)=−2、内側は3なので、H′(0)=12·(−2)·3=−72。w′をt=0へ直接代入してw′(0)=0とするのは、外側が受け取る入力v=2を取り違えています。

したがってt=0の近くではH(t)=8−72t+r(t)、r(t)/t→0と書けます。負の導関数は、この点でtを増やすと一次近似の変化が減少方向へ向くことを表します。一方t=1/3ではu=0なので導関数は0ですが、Hが全域で一定になるわけではありません。実際H(1/3)=1とH(0)=8は異なります。微分係数は指定した一点の局所的な変化率です。

連鎖律の証明で、内側の増分kによって割らなかった理由もここへ戻れます。内側の増分は0になることがあり、外の微分係数が存在しても毎回0でないとは保証されません。残りをkη(k)と書く方法なら、その入力も同じ証明で扱えます。

逆関数の微分

区間で厳密に増加するとは、どの x₁ < x₂ に対しても f(x₁) < f(x₂) となることです。例えば f(x)=2x では、入力の大小を二倍しても出力の大小が保たれます。厳密な減少では出力の大小が逆になります。どちらかを満たすことを厳密な単調性と呼びます。また値域 J=f(I) は、入力区間 I から実際に得られる出力全体、すなわち写像の言葉でいう像です。この範囲で出力から入力へ戻る関数を考えます。

逆関数の微分

f が開区間 I 上で連続かつ厳密に単調であるとします。値域 J = f(I) は開区間で、逆関数 g : J → I が存在します。a ∈ I で f が微分可能かつ f′(a) ≠ 0 なら、b = f(a) で g は微分可能で、g′(b) = 1/f′(a) です。導関数が 0 でないことだけでなく、逆関数を定められる条件も含めた主張です。

逆関数の連続性を先に確かめる

増加の場合を示します。I 内で a − η、a + η を選ぶと、f(a − η) < b < f(a + η) です。b からこの二つの値への距離の小さい方より y のずれを小さくすれば、単調性から a − η < g(y) < a + η。η は任意に小さくできるので、g は b で連続です。減少の場合は大小を逆にして同じ結論です。J が区間であることは中間値の定理から、各 f(a) が J の内点であることは前後の値で挟めることから従います。

y → b とし、h = g(y) − a と置きます。逆関数の連続性から h → 0、y ≠ b なら一対一性により h ≠ 0 です。従って差の商は {g(y) − g(b)}/(y − b) = 1/[{f(a + h) − f(a)}/h]。角括弧内の商を h = 0 では f′(a) と補えば、h = 0 で連続な関数です。合成の極限と分母の極限が 0 でない商の法則から、極限は 1/f′(a) です。

f(x) = x³ は厳密に増加し逆関数を持ちますが、f′(0) = 0 です。逆関数の 0 での差の商は、y = h³ と書けば h/h³ = 1/h² で、有限の極限を持ちません。微分の逆数という公式を、分母が 0 の点へ延長することはできません。対数関数の微分では、この定理の条件を確かめて使います。

寄り道［応用］：微分する規則が、そのまま計算の部品になる

JAX という計算ライブラリの公式入門には、関数を受け取り、その導関数を計算する関数を作る grad という操作があります。機械学習で必要になる勾配の計算も紹介されています。数学で学ぶ「式から変化率を求める」が、実際の計算を組み立てる道具になっています。

例えば f(x) = (x² + 1)³ なら、内側の変化率 2x と、外側の変化率 3(x² + 1)² を掛け、f′(x) = 6x(x² + 1)² が出ます。部品ごとの微分規則と連鎖律が分かれば、大きな計算の微分を小さな関係へ分解できます。ただし、微分できない点や、計算機での丸めは別に扱う必要があります。「h をひたすら小さくする」以外にも、微分の定義が保証した規則を再利用する道があるのです。

出典：JAX：Automatic differentiation。

微分の定義と計算の演習

1．x³ を定義から微分する

f(x) = x³ の差の商を展開し、f′(a) を求めてください。

ヒント1：三乗を展開する

(a + h)³ = a³ + 3a²h + 3ah² + h³ です。

ヒント2：h ≠ 0 で約分する

約分した後で h → 0 とします。

解答

h ≠ 0 で差の商は (3a²h + 3ah² + h³)/h = 3a² + 3ah + h² です。h → 0 で後ろの二項が 0 になるため f′(a) = 3a²。h = 0 で元の商を計算したのではありません。

2．角が移動したら

g(x) = |x − 2| が x = 2 で連続だが微分できないことを示してください。

ヒント1：入力を 2 + h と書く

g(2 + h) = |h|、g(2) = 0 です。

ヒント2：符号を分ける

|h|/h を正負の h について比べます。

解答

|g(2 + h) − g(2)| = |h| → 0 なので連続です。一方、差の商は h > 0 で 1、h < 0 で −1 となり、両側の極限が一致しません。したがって 2 で微分できません。

3．内側の変化を忘れない

F(x) = (x² + 1)² を連鎖律で微分し、展開して微分した結果と照合してください。

ヒント1：外側と内側を名付ける

外側は u²、内側は x² + 1 です。

ヒント2：x⁴ は積として扱える

x⁴ = x² · x² に積の法則を使います。

解答

連鎖律では F′(x) = 2(x² + 1) · 2x = 4x(x² + 1)。展開すると F = x⁴ + 2x² + 1。積の法則から (x⁴)′ = 2x · x² + x² · 2x = 4x³ なので、F′ = 4x³ + 4x となり一致します。いずれの関数も実数全体で微分可能なので、適用する点に制限はありません。

4．残りが0へ行くだけでは傾きが決まらない

f(x)=x²を点0で、任意の傾きmの直線mhにより近似します。残りrₘ(h)=h²−mhについて、rₘ(h)→0となるmと、rₘ(h)/h→0となるmをそれぞれ求め、定義が後者を要求する理由を説明してください。

ヒント1

hとh²は0へ行きますが、hで割った後に残る定数項は何ですか。

ヒント2

h≠0でrₘ(h)/h=h−mです。

解答

rₘ(h)=h²−mhはどの実数mでも0へ収束します。しかし比はh−m→−mなので、0へ行くのはm=0だけです。単に残りが0になる条件では、この曲線へどんな傾きの直線を当てても区別できません。入力の変化hよりも残りが小さいという比の条件が、微分係数0を一つに選びます。

5．微分可能なら二次誤差まで保証できるか

f(x)=|x|√|x|が点0で微分可能であることを示してください。さらに、ある定数C≥0とδ>0を選んで、すべての0<|h|<δで|f(h)−f(0)−f′(0)h|≤Ch²とすることはできないと示してください。

ヒント1

差の商の絶対値は√|h|です。

ヒント2

微分係数は0です。正のhで残りをh²で割ると1/√hになります。

解答

f(0)=0で、h≠0の差の商の絶対値は|h|√|h|/|h|=√|h|→0。従ってf′(0)=0です。一方、もし二次の評価があれば正の十分小さいhで1/√h≤Cが必要です。任意のCとδに対して0<h<min(δ,1/(C+1)²)を選ぶと1/√h>C+1となって矛盾します。微分の定義は残り/h→0までを保証し、一定の二次誤差を全関数へ保証するものではありません。

6．連鎖律が使えないと合成も微分できないか

F(x)=(|x|)²とG(x)=√(x²)を点0で調べてください。それぞれ内側・外側を挙げ、連鎖律の仮定が満たされるかと、合成そのものが微分可能かを分けて判定してください。

ヒント1

F(x)=x²、G(x)=|x|という恒等式を使えます。

ヒント2

Fの内側|x|は0で微分できません。Gの外側√uは0で、この章の両側微分の条件を満たしません。

解答

Fは内側|x|、外側u²ですが、内側が0で微分できず連鎖律を適用できません。それでもF(x)=x²なのでF′(0)=0です。Gは内側x²、外側√uですが、外側は0を含む開区間で定義されず、0で有限の両側微分係数を持ちません。G(x)=|x|で左右の差の商が−1、1となるので、合成も微分できません。定理の仮定が欠けた場合、結論が真か偽かは個別に調べます。

7．積と合成の規則を選び分ける

F(x)=(2x+1)³(1+x²)を微分し、F′(0)を求めてください。二つの因子をそれぞれ微分して掛ける案が、どの規則を取り違えているかも説明してください。

ヒント1

全体は積ですが、第1因子は合成です。

ヒント2

第1因子の導関数は3(2x+1)²·2、第2因子は2x。積の法則では片方ずつを微分した二項を足します。

解答

F′(x)=6(2x+1)²(1+x²)+(2x+1)³·2x、従ってF′(0)=6です。因子の微分だけを掛けると6(2x+1)²·2xとなり、0で0を返して誤ります。積では二因子がそれぞれ変わる効果を足し、合成では内側の変化率を外側へ換算して掛けます。すべて多項式なので、全実数で規則の条件を満たします。

8．逆関数の傾きはどこで評価するか

f(x)=x³+xを開区間I=(0,3)で考えます。fが連続かつ厳密に増加し、像がJ=(0,30)であることを確かめ、逆関数gのg′(2)を求めてください。1/f′(2)とする案も点検してください。

ヒント1

0<x<y<3でf(y)−f(x)を因数分解できます。gの入力2を作る元の入力aを先に求めます。

ヒント2

f(1)=2、f′(1)=4です。逆関数の公式はg′(f(a))=1/f′(a)です。

解答

多項式なので連続です。f(y)−f(x)=(y−x)(y²+xy+x²+1)>0なので厳密に増加します。0<x<3で0<f(x)<30であり、0と30の間の任意の値は、[0,3]への同じ多項式の連続な延長に中間値の定理を使えば内部の点で取れます。従って像は(0,30)。f(1)=2で、f′(x)=3x²+1よりf′(1)=4≠0。条件がそろいg′(2)=1/4です。1/f′(2)=1/13は、逆の入力2に対応する元の点1を取り違えています。

9．有限幅の対称な差はいつ厳密か

h≠0でDₕf(a)={f(a+h)−f(a−h)}/(2h)とします。f(x)=x²とf(x)=x³について計算し、微分係数との差を求めてください。対称に取ればどんな関数でも有限hで厳密な微分係数になるでしょうか。

ヒント1

二つの展開を引くと、偶数次のhの項が消えます。

ヒント2

平方では分子4ah、立方では6a²h+2h³になります。

解答

平方ではDₕf(a)=2aで、すべての非零hで微分係数と一致します。立方ではDₕf(a)=3a²+h²なので、微分係数3a²との差はh²です。従って対称化しても有限幅で常に厳密になるわけではありません。立方ではh→0で誤差が0になり、|h|≤0.01なら誤差は0.0001以下と評価できます。ここでは正確な実数計算を考え、計算機の丸め誤差は含めていません。

10．接線から関数の係数を設計する

f(x)=Ax²+Bx+Cが、点x=1で値2、微分係数3を持ち、さらにf(0)=0となるようにA、B、Cを決めてください。その点の直線近似と残りも求め、微分の定義を検算してください。

ヒント1

値の条件はA+B+C=2、C=0、傾きの条件は2A+B=3です。

ヒント2

f(1+h)を展開すると、定数・hの係数・h²の係数に分かれます。

解答

C=0、A+B=2、2A+B=3よりA=1、B=1です。f(x)=x²+xで、f(1+h)=2+3h+h²。直線近似はy=2+3(x−1)、残りはr(h)=h²です。h≠0で差の商は3+h→3、またr(h)/h=h→0となり、値と傾きの指定を満たします。f(0)=0も確認できます。三つの独立な条件から係数が一組に決まっています。
