実数と極限の考え方

数列 1、1/2、1/3、… は、どの項も正で、0そのものにはなりません。それでも「0からのずれを0.01未満にしてほしい」と言われたら、101番目以降なら応えられます。0.001未満なら1001番目以降です。要求を厳しくしても、それに応じて見る位置を後ろへ選べる。このことを、0へ近づくという言葉で表したいのです。最初の千項だけの観察と違い、その先の全項についても保証する規則が必要です。

数の世界では有理数の隙間を実数で埋めました。この章では実数が持つ完備性を出発点として借り、極限を定義します。実数そのものの構成は行いません。学習の目安は演習込み130–190分です。数列と完備性、極限法則と収束判定、関数の極限の三回に分けても読めます。演習1–3は基本、4–7は誤差から選択を作る問題、8–10は条件と量化の点検です。数列は、正の整数 n ごとに実数 aₙ を一つ対応させる写像です。添字 n は項の番号で、時刻とは限りません。

この例なら aₙ=1/n で、行き先の候補0は見えています。しかし「どう近づくか」を定めるだけでは、「近づいた先が実数の中にあるか」はまだ分かりません。増え続けながらある数を越えない列では、行き先の数が初めから分かるとは限らないからです。そこで収束の定義に先立ち、実数が隙間を残さないという性質を確認します。

実数の完備性と上限

Aを、0より大きく1より小さい実数を全て集めた集合とします。2も1も、Aのどの要素以上でもあります。このように全ての要素を上から押さえる数を上界と呼び、上界が一つでもあれば上に有界といいます。

このAでは最小の上界は1ですが、1はAに入っていないので最大の要素ではありません。「集合の最大の要素」と「集合を上から押さえる最小の数」は別です。後者を上限と呼び、sup A と書きます。実数の完備性は、空でなく上に有界な実数の集合には、この最小の上界が必ず実数として存在する、という性質です。

本書で「誤差の上限」などと呼ぶ見積もりは、示した条件の下で誤差を上から押さえる上界です。最小の上界とは限らず、安全側の値として使います。一方、sup と書くときは、いつも最小の上界を指します。

最小上界性：この教材で採る完備性の公理

空でなく上に有界な実数の集合には、最小の上界が存在します。集合のすべての数以上の数を上界といい、そのうち最も小さいものを上限、または sup と書きます。この性質を実数の完備性として採用します。実数の構成による証明は行いません。以下では通常の四則・順序の法則とこの公理から議論を進め、別の形の完備性を独立の公理にはしません。

次の確認では、自然数全体が上に有界だと仮定し、実数の完備性によって上限 L を取って矛盾を導きます。

自然数が上に有界でないことを導く

もし自然数全体に上限 L があれば、L − 1 は上界でないので、n > L − 1 となる自然数 n が存在します。すると自然数 n + 1 は L より大きく、L が上界であることに矛盾します。したがって、どんな実数よりも大きい自然数を選べます。これがアルキメデス性です。

逆に、集合の全ての要素以下である数を下界と呼び、下界があれば下に有界といいます。その中で最大の下界が下限 inf です。これは各数の符号を変えた集合の上限に、再び負号を付ければ得られます。上限・下限は集合に属するとは限りません。例えば、0と1の間の実数全体 (0, 1) の上限は1ですが、1はその集合の要素でありません。

数列の極限とε–N定義

数列 aₙ が実数 L に収束するとは、どんな正の許容誤差 ε を指定されても、ある正の整数 N を選ぶと、N 番目以降のすべての項が L から距離 ε 未満に入ることです。これを aₙ → L、または lim aₙ = L と書きます。

∀ε>0∃N∈ℕ∀n≥N:|an−L|<ε

ここでは ℕ = {1, 2, …} とします。N は ε に応じて変えてよく、最小である必要もありません。一方、N を選んだ後に現れる n に合わせて N を選び直すことはできません。この量化の順番が、「ときどき近い」と「以後ずっと近い」を分けます。最初の有限個の項がどうであっても、収束の結論は変わりません。

1/n → 0 の証明

ε > 0 を任意に与えます。先ほど導いたアルキメデス性により、N > 1/ε を満たす整数 N を選べます。n ≥ N なら |1/n − 0| = 1/n ≤ 1/N < ε。これで、すべての正の ε に対して開始位置を作れました。例えば ε = 0.001 なら N = 1001 が使えます。N = 1000 では最初の差が ε と等しく、厳密な「未満」の条件を満たしません。

計算機の整数型には上限があります。数学の自然数について証明した性質を、そのまま機械の仕様と混同してはいけません。

誤差から開始位置を逆算する

定義の証明では「近そうな値をたくさん出す」のでなく、要求されたεから、以後の全項に使えるNを作ります。そのために、極限候補との差を先に整理します。極限法則をまだ使わず、aₙ=(2n+1)/(n+3)を調べましょう。分子と分母をnで割ると行き先2を予想できますが、その計算だけで誤差保証まで済んだとはしません。

例題：差を一つの分数にする

予想した2との差は、aₙ−2=(2n+1−2(n+3))/(n+3)=−5/(n+3)。従って|aₙ−2|=5/(n+3)です。これがε未満になる条件を解くとn+3>5/ε、すなわちn>5/ε−3です。ε>0を受け取った後、N>5/εとなる正の整数を選べば、この条件を確実に満たします。

実際、n≥Nなら5/(n+3)≤5/(N+3)<5/N<εです。Nはεだけから選び、その後のどのnにも同じ評価が使えました。ここまでが収束の証明です。最小のNを選ぶ必要はありませんが、費用のかかる計算を止めたいときには、元の不等式からより小さい開始位置を探せます。

例えばε=0.01ならn>497なので、最小のNは498です。N=497では誤差が5/500=0.01で境界に載り、未満になりません。N=498では5/501<0.01、その先は分母が増えて誤差が小さくなります。一方、簡単な十分条件N>500からN=501を選んでも証明として正しく、三項だけ余分に待つことになります。

「各nに対してε=6/(n+3)とすれば誤差がε未満」という計算は、収束の要求に答えていません。要求する側が先にどんなε>0でも指定でき、その後にこちらがNを決める順序だからです。εを後から都合よく選ぶと、極限に近づかない数列にも似た説明ができてしまいます。

極限の一意性と四則演算

和と積の極限

実数列 aₙ → A、bₙ → B とすると、aₙ + bₙ → A + B、aₙbₙ → AB です。どちらも有限の実数への収束を仮定しています。

誤差を分ける

和では、二つの差をそれぞれ ε/2 未満にする開始位置を取り、大きい方を N とします。三角不等式から、和の差は二つの差の和以下なので ε 未満です。積ではまず、十分先で |aₙ − A| < 1 とし、|aₙ| ≤ |A| + 1 に抑えます。次の分解が使えます。

|anbn−AB|≤|an||bn−B|+|B||an−A|

|bₙ − B| < ε/{2(|A| + 1)}、|aₙ − A| < ε/{2(|B| + 1)} をともに満たすところまで進めば、右辺は ε 未満です。積の証明では、差だけでなく掛け算する相手の大きさも抑える必要がありました。

極限は一つに決まります。異なる二つの候補 A、B があれば、ε = |A − B|/3 を選び、十分先の同じ項から両方への距離を ε 未満にします。すると |A − B| < 2|A − B|/3 となり矛盾します。したがって「その極限」と呼んでよいのです。

商・順序・挟み撃ちも確かめる

B ≠ 0 なら、十分先では |bₙ − B| < |B|/2 より |bₙ| > |B|/2。したがって |1/bₙ − 1/B| ≤ 2|bₙ − B|/|B|² → 0 です。積の法則と合わせて aₙ/bₙ → A/B を得ます。分母の極限が 0 の場合には、この結論を使えません。

十分先で aₙ ≤ bₙ なら A ≤ B です。もし A > B なら、二つの誤差を (A − B)/3 未満にすると aₙ > bₙ となり矛盾します。特に aₙ ≤ cₙ ≤ bₙ で両端が同じ L へ収束すれば、十分先の cₙ も L ± ε の中に入り、cₙ → L。これが挟み撃ちです。

単調有界数列の収束

値が増え続け、しかもある数 M（上界）を越えない数列は、どこかへ落ち着きそうです。この「どこか」を保証する部分は、計算規則だけでは得られません。

単調有界数列の収束

実数列が単調増加、つまり aₙ ≤ aₙ₊₁ で、ある実数 M に対し全項が aₙ ≤ M を満たすなら、有限の実数に収束します。単調減少で下に有界の場合も同様です。

完備性を使う箇所

最小上界性により、項の集合の上限 L が存在します。ε > 0 に対し、L − ε は上界でないため aₙ > L − ε となる項 aₙ が存在します。単調性からその先の全項は L − ε より大きく、上界の定義から L 以下です。したがって L へ収束します。減少の場合は項の符号を変えて同じ証明を使います。

条件を一つずつ外してみます。aₙ = n は増加しますが上に有界でなく、有限の実数へ収束しません。aₙ = (−1)ⁿ は −1 と 1 の間に収まりますが、二つの値を往復するため収束しません。有界という条件だけでも、単調という条件だけでも足りないのです。

漸化式と単調有界性からの極限決定

単調有界定理は、極限を知らなくても存在を保証できます。自作の数列をa₁=1、aₙ₊₁=√(2+aₙ)で定めます。右辺に前の項を入れて次の項を決める式を漸化式といいます。数値を数項作ると1、√3、√(2+√3)、…と増えますが、どこへ進むかは式から調べます。

例題：極限の存在を示してから方程式を使う

まず1≤aₙ<2をすべてのnで示します。初項は条件を満たします。1≤aₙ<2なら3≤2+aₙ<4なので、1<√3≤aₙ₊₁<2です。数学的帰納法により範囲が保たれ、平方根も常に定義されます。

増加するかは、差を有理化して調べます。aₙ₊₁−aₙ=(2+aₙ−aₙ²)/(√(2+aₙ)+aₙ)=(2−aₙ)(aₙ+1)/(√(2+aₙ)+aₙ)>0。分子の二因子も分母も正なので、単調増加です。上界2があるため、有限の極限Lが存在します。順序の法則から1≤L≤2です。

存在を確認した今なら、漸化式を二乗したaₙ₊₁²=2+aₙで極限を取れます。aₙ→Lなら、一項ずらしたaₙ₊₁もLへ収束します。積と和の法則からL²=2+L、従って(L−2)(L+1)=0。候補は2と−1ですが、L≥1なのでL=2です。平方根の連続性をまだ使わず、既に証明した和と積の極限だけで決めました。

最初から「極限をLとしてL=√(2+L)を解く」だけでは、列が収束することを示していません。例えばaₙ₊₁=−aₙ、a₁=1なら、同じ手順はL=−Lから0を候補に出しますが、実際の列は1と−1を往復します。極限の方程式は収束するなら満たす条件であり、存在の証明の代わりにはなりません。

Cauchy列と完備性

極限の候補 L がまだ分からないとき、Lとの距離を調べることはできません。それでも、十分後ろの項どうしが互いに近いかなら調べられます。n番目以降の aₙ,aₙ₊₁,… を列の「後ろの部分」（尾部）と呼び、その中のどの二項の差も小さくできる、という条件を使います。

実数列の Cauchy 判定

数列が Cauchy 列であるとは、任意の ε > 0 に対し、ある N 以降のすべての m、n で |aₘ − aₙ| < ε となることです。実数列が有限の実数へ収束することと、Cauchy 列であることは同値です。

各尾部を上下から挟む

収束列では、各項と極限との距離を ε/2 未満にすれば、三角不等式で Cauchy 条件が得られます。逆に Cauchy 列なら、十分先の項は一つの項の前後 1 以内にあり、最初の有限個も含めて全体が有界です。尾部 {aₖ : k ≥ n} の下限を lₙ、上限を uₙ とすると、lₙ は増加、uₙ は減少する有界列です。単調有界定理により両方に極限があります。Cauchy 条件から十分先で 0 ≤ uₙ − lₙ ≤ ε なので、極限は共通の L です。lₙ ≤ aₙ ≤ uₙ と挟み撃ちから aₙ → L を得ます。これは最小上界性から導いた定理で、新しい公理ではありません。

等比数列の収束と誤差評価

幾何的な減少の補題

実数 r が |r| < 1 を満たすなら、|r|ⁿ → 0、したがって rⁿ → 0 です。

Bernoulli の不等式から

r = 0 は直ちに分かります。0 < q = |r| < 1 なら d = 1/q − 1 > 0 と置きます。入門で得た Bernoulli の不等式 (1 + d)ⁿ ≥ 1 + nd を使います。n = 1 で成立し、両辺に 1 + d を掛ければ次の n でも成立するので帰納法で得られるものでした。よって 0 ≤ qⁿ ≤ 1/(1 + nd)。任意の ε > 0 に対し N > 1/(dε) と選べば、n ≥ N で右辺は ε 未満です。挟み撃ちから結論が従います。二分法の幅や幾何級数の残りの評価は、この補題を使います。

関数の極限とε–δ定義

番号 n を大きくする数列の極限に対し、関数では実数の入力を指定した点へ近づけます。ここでは、その点からのずれを h として0へ近づけましょう。例えば g(h)=1+2h なら、1からの出力のずれは |g(h)−1|=2|h|。出力の誤差を ε 未満にしたいなら、入力のずれを ε/2 未満にすれば足ります。

一般に、関数 g の h → 0 での極限が L とは、どんな ε > 0 に対しても、それに応じて δ > 0 を選べて、定義域の全ての h について、0 < |h| < δ なら |g(h) − L| < ε となることです。δはεに応じて選び直せますが、選んだ後はその範囲の全てのhへ同じ保証を与えます。ここでは g が0の両側の、0を除く十分小さい範囲で定義されている場合を考えます。右側から近づける h → 0+ は、gが0の右側の、0を除く十分小さい範囲で定義されているとし、同じ ε–δ の条件を 0 < h < δ の全てのhに限って定めます。左側からの h → 0− では、−δ < h < 0 の全てのhに限ります。平面へ広げる場合は、後の多変数の極限の定義で扱います。後の微分でも、このように入力の刻みを0へ近づけます。

h = 0 を除くのは、極限がその点の値ではなく、その周りでのふるまいを述べるからです。例えば g(h) = h/h は h ≠ 0 で 1 なので極限は 1 ですが、式のままでは g(0) は定義されません。連続性は、こうして得られる極限と、その点で定義された関数値が一致する条件として読み直せます。

和・積・商と順序の極限法則も同じ誤差評価で成り立ちます。数列で「十分大きい番号」とした部分を、「十分小さい入力のずれ」に替えて証明します。商では、ここでも分母の極限が 0 でないことが必要です。

関数の誤差評価とδの選択

ε–δの定義でも、Nの代わりにδを選ぶだけでなく、出力の差を入力の差で押さえる計算が必要です。点x=2でのx²の極限を調べるため、h=x−2と置き、g(h)=(2+h)²をh→0で考えます。行き先の候補は4です。

例題：小さくする因子と、抑えておく因子

差を展開すると|g(h)−4|=|4h+h²|=|h||4+h|です。|h|を小さくしたい一方、相手の|4+h|もhに依存しています。そこで先に|h|<1と制限すると、三角不等式で|4+h|≤4+|h|<5です。1という幅は唯一の選択ではありませんが、計算しやすい上界5が得られます。

任意のε>0に対しδ=min(1,ε/5)と選びます。minは二数の小さい方を取る記号です。どちらも正なのでδ>0。0<|h|<δなら|h|<1と|h|<ε/5が同時に成り立ち、|g(h)−4|=|h||4+h|<5|h|<εです。従って極限は4です。

例えばε=0.1ならδ=0.02で足ります。実際h=0.01では出力のずれが0.0401です。δ=εと無条件に選ぶと、同じε=0.1でもh=0.05でずれ0.2025となり、要求を超えます。εとδは同じ単位の数を並べただけの記号ではなく、関数の変化を通して結び付く量です。

例題：その点で割れなくても極限は調べられる

次にg(h)=(√(1+h)−1)/hを考えます。定義域はh≥−1かつh≠0です。h=0を代入すると0/0となり、商の極限法則は分母の極限が0なので使えません。ここでは分子に根号の差があるため、共役な式√(1+h)+1を掛ける方針を選びます。

h≠0でg(h)=((1+h)−1)/(h(√(1+h)+1))=1/(√(1+h)+1)。この式から候補L=1/2が見えます。さらに|g(h)−1/2|=|1−√(1+h)|/(2(√(1+h)+1))=|h|/(2(√(1+h)+1)²)≤|h|/2です。

ε>0に対しδ=min(1/2,2ε)と選べば、0<|h|<δからh>−1/2となって定義域内にあり、誤差は|h|/2<ε。よって極限は1/2です。途中でhを消せたのは、極限で調べる入力から0を除いていたからです。g(0)を後で7と定義しても、この極限の値は変わりません。

左右極限と定義域の端点

左右で別の値へ近づくなら、両側の極限は作れません。例えばh>0でs(h)=1、h<0でs(h)=−1とします。右極限は1、左極限は−1です。右側ではすべての値がちょうど1なので、どんなεにもδ=1が使えます。左側も同じ理由で−1です。

もし両側の極限Lがあれば、同じδの保証は右側だけ、左側だけへ制限しても成り立ちます。極限の一意性からL=1かつL=−1となり不可能です。逆に左右極限が同じLなら、εに対する右の幅δ₊と左の幅δ₋の小さい方を取れば、両側のどの入力にも保証が行き渡ります。従って両側の極限があることと、左右極限が存在して同じ値になることは同値です。両側で定義されるというこの節の前提の下での結論です。

端点では、そもそも両側に入力があるかを先に確認します。g(h)=√hはh≥0で定義され、0の左側には実数の入力を持ちません。右からの極限は0で、ε>0に対しδ=ε²とすれば、0<h<δで|√h−0|=√h<εです。本章の「両側の穴あき近傍で定義された関数」という約束のままでは、これに左極限や両側極限を付けません。定義域の中からだけ近づくという別の一般化では、同じ挙動を端点の極限と呼べます。次章の閉区間での連続性では、この片側の読み方を明示して使います。

寄り道［背景］：半分、また半分。それでもゴールへ着けるか

アリストテレス『自然学』第6巻には、ゼノンの議論として「目的地へ着く前に、まず半分まで着かねばならない」という難問が記録されています。半分までの途中にもさらに半分があるなら、終えるべき段階は無限にある。何が本当の障害なのか、考えたくなる問いです。

ここからは現代の数列で見直しましょう。長さ1を、1/2、1/4、1/8、…と進むなら、n 段階の合計は 1 − 2⁻ⁿ、残りは 2⁻ⁿ です。段階の個数は無限でも、残りは指定したどんな正の幅より小さくできます。各段階に同じ時間が必要だとは限りません。極限は「無限だから終わらない」という言葉を、何が増え、何が小さくなり、どんなモデルで時間を数えているかという問いへ分けてくれます。

出典：アリストテレス『自然学』VI.9、MIT 公開英訳。

極限の定義と誤差評価の演習

1．開始位置を作る

aₙ = 3 + 2/n が 3 に収束することを示し、ε = 0.01 に使える N を一つ求めてください。

ヒント1：差だけを残す

|aₙ − 3| = 2/n です。

ヒント2：不等号に注意する

N > 2/ε を満たす整数を選びます。

解答

任意の ε > 0 に対して N > 2/ε を選ぶと、n ≥ N で |aₙ − 3| = 2/n ≤ 2/N < ε です。ε = 0.01 なら N = 201 が使えます。これで定義のすべての要求を満たしました。

2．ときどき近いだけでは足りない

aₙ = (−1)ⁿ が 1 に収束しないことを、ε を一つ選んで示してください。

ヒント1：定義を否定する

どんな N に対しても、要求に反する n ≥ N を見つけます。

ヒント2：奇数番目を見る

奇数番目の値は −1 です。

解答

ε = 1 とします。どの N より先にも奇数 n があり、その項では |aₙ − 1| = |−1 − 1| = 2 ≥ 1 です。「以後のすべての項」が近いとは言えず、1 に収束しません。同様に、二つの部分列の値が異なるため、ほかの実数にも収束しません。

3．単調有界定理を使う

aₙ = n/(n + 1) の単調性と上界を確かめ、収束先も求めてください。

ヒント1：1 との差を見る

aₙ = 1 − 1/(n + 1) と書けます。

ヒント2：存在と値を分ける

単調有界定理は行き先の存在を、差の評価は行き先の値を教えます。

解答

1/(n + 1) は減少するので aₙ は増加し、aₙ < 1 です。単調有界定理から収束します。また |aₙ − 1| = 1/(n + 1) → 0 なので、極限は 1 です。上界は 2 などでもよいですが、収束先は上界の任意の選び方では決まりません。

4．極限と一つの値から規則を逆算する

A、Bを実数とし、aₙ=(An+B)/(n+1)とします。極限が3、初項が2になるA、Bを求め、|aₙ−3|<0.02が以後ずっと成り立つ最小の正の整数Nも求めてください。

ヒント1

aₙ=A+(B−A)/(n+1)と書くと、極限と係数の関係が見えます。

ヒント2

A=3を初項の式(A+B)/2=2へ入れます。誤差の厳密不等号も残します。

解答

(B−A)/(n+1)→0なので極限はA、従ってA=3。初項から(3+B)/2=2、B=1です。aₙ=3−2/(n+1)で、誤差2/(n+1)<0.02はn+1>100、すなわちn>99と同値。最小のNは100です。n=99では誤差0.02で失敗、n=100では2/101<0.02で、その先はさらに小さくなります。初項も3−2/2=2へ戻ります。

5．δを入力を見てから選んでいないか

g(h)=(−1+h)²がh→0で1へ近づくことを示します。「誤差は|h||h−2|だから、δ=ε/|h−2|と選ぶ」という案を診断し、εだけから選べるδで証明を完成してください。

ヒント1

δを選んだ後に、その範囲のすべてのhに同じ保証が必要です。

ヒント2

|h|<1なら|h−2|≤|h|+2<3です。

解答

案のδは後から現れるhに依存し、定義の順序を守っていません。h=2では分母も0になります。任意のε>0に対しδ=min(1,ε/3)と取れば正です。0<|h|<δなら|h−2|<3、従って|g(h)−1|=|h||h−2|<3|h|<εです。入力に依存する因子を先に一様な数で抑え、その後にδを決めるのが修正の要点です。

6．一点の値で極限を変えられるか

h≠0でg(h)=(h²+3h)/h、h=0でg(0)=Kと定義します。実数Kをどのように選ぶとh→0での極限が5になりますか。極限をε–δで確かめ、g(0)と極限が一致するKも求めてください。

ヒント1

極限を調べる入力は0を除きます。h≠0で式を整理します。

ヒント2

g(h)=3+hなので、3との差は|h|です。

解答

どのKでも極限は3で、5にするKはありません。ε>0に対しδ=εを取れば、0<|h|<δで|g(h)−3|=|h|<εです。極限の一意性から5にはなりません。g(0)と極限が一致するのはK=3です。0での値だけを変えても、その周囲の穴あき範囲で調べる極限は変わりません。

7．左右の規則をつないで極限を設計する

h>0でg(h)=1+h、h<0でg(h)=c−2hとします。両側極限が存在する実数cを求め、そのとき同じδで両側を保証してください。g(0)を定義する必要はありますか。

ヒント1

右極限は1、左極限はcです。両側では同じ値が必要です。

ヒント2

c=1なら、右側の誤差は|h|、左側は2|h|です。

解答

両側極限があるなら右と左の極限が一致するのでc=1が必要です。c=1なら任意のε>0に対しδ=ε/2と取ります。0<|h|<δのとき、h>0なら誤差|h|<ε/2<ε、h<0なら2|h|<ε。両側極限は1で、c=1は十分でもあります。g(0)は極限の条件から除かれているため、定義しなくてもよく、どんな値を置いてもこの極限は変わりません。

8．隣り合う項が近いこととCauchy条件

aₙ=√nについて、aₙ₊₁−aₙ→0を示してください。それでもCauchy列でないことを、ε=1とm=4nを使って示してください。

ヒント1

隣どうしの差を有理化します。Cauchy条件では離れた二項も同じN以降なら調べる必要があります。

ヒント2

√(n+1)−√n=1/(√(n+1)+√n)≤1/(2√n)。一方√(4n)−√n=√nです。

解答

差は0<aₙ₊₁−aₙ≤1/(2√n)で、右辺は0へ収束します。具体的にはn>1/(4ε²)なら右辺<εです。しかし任意の正の整数Nに対しn≥Nを取り、m=4nとすればm,n≥Nで|aₘ−aₙ|=√n≥1。ε=1に対するCauchy条件が破れます。隣の一歩は小さくても、尾部のすべての二項が近いとは限りません。

9．幾何的な誤差から停止回数を決める

n段階後の誤差が厳密に2⁻ⁿ（n≥1）である自作の理想モデルを考えます。誤差を0.001未満にする最小のnを求めてください。また誤差が「2⁻ⁿ以下」とだけ分かる場合、同じ回数について何が保証でき、何が最小とは言えませんか。

ヒント1

2⁹=512、2¹⁰=1024を比較します。

ヒント2

誤差そのものと、誤差の上界を区別します。上界より実誤差が小さい場合もあります。

解答

n=9では1/512>1/1000、n=10では1/1024<1/1000です。2⁻ⁿは厳密に減るので、誤差がちょうどこの値なら最小は10です。誤差がこの値以下というだけでも、n=10で必ず要求を満たすことは保証できます。しかし実際の誤差が初めからもっと小さい可能性があるため、10が実誤差について最小とは断言できません。保証に十分な回数と実際の最小回数は異なります。

10．極限方程式だけで収束を主張できるか

a₁=0、aₙ₊₁=1−aₙとします。「極限をLとするとL=1−LだからL=1/2」という案を診断してください。奇数番目と偶数番目の項を求め、1/2に収束しないことを定義の否定で示してください。

ヒント1

最初の数項は0、1、0、1です。収束することを仮定した計算と、収束の証明を区別します。

ヒント2

どの項も1/2との距離は1/2です。ε=1/4を選べます。

解答

漸化式から奇数番目は0、偶数番目は1です。極限方程式は「収束するならL=1/2」という必要条件を出しただけで、収束を保証しません。ε=1/4とすると、どんなNでもn=Nの項について|aₙ−1/2|=1/2≥εで、収束条件は成立しません。ほかのLについても、偶数・奇数の一定な二つの列が異なるため収束できません。単調有界定理を使うにも、この列は単調ではありません。

極限の量化・誤差・定義域の整理

  2. 単調有界定理の証明で、実数の完備性はどの一文に使われましたか。
