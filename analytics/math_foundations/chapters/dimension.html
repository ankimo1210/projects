線形独立・生成と次元

回転の章では、平面の二本の基本の矢印から、すべての矢印を作りました。では三本選べば、平面に三つ目の自由な方向を増やせるでしょうか。矢印を何本並べたかと、互いに頼らず動かせる方向がいくつあるかは、区別する必要があります。

ベクトル空間と線形写像の足し算と実数倍を使い、ここでは実数を係数とする有限次元の空間を考えます。座標の選び方によらない「必要な本数」を定め、写像によって失われる自由度を数えるのが目標です。

例えば平面で「横へ一歩」「縦へ一歩」「斜めへ一歩」の三種類を使えるとしても、斜めの一歩が横と縦の和なら、三つの係数を変える余地と、動ける点の自由度は一致しません。同じ到着点を別の係数で表せてしまうからです。どこにでも届くことと、届き方が一つであることを別々に調べてから、必要な本数を数えます。

演習込み120–170分が目安です。最初は生成・独立・座標の計算、次に本数が一定になる証明、最後に核と像での自由度の配分を扱います。式の成分数、並べたベクトルの本数、独立に動かせる係数の数を混同しないことが目標です。

基底と座標の一意性

ベクトル v₁, …, vₘ の実数倍を足したものを線形結合、その全体を列の張る空間（span）と呼びます。空間 V のすべてのベクトルが作れるなら、この列は V を生成するといいます。有限本で生成できる空間を有限次元と呼びます。まだ、その本数が一つに決まるとは主張していません。

本章では一本も選ばない空の列も認め、空の和は零ベクトル 0とします。したがって空の列が張る空間は {0} です。

一方、次の等式が、すべての係数を 0 にしたときにしか成立しない列を一次独立（線形独立）と呼びます。それ以外は一次従属です。

a1v1+⋯+amvm=0⇒a1=⋯=am=0

一次独立な列に零ベクトルは含まれません。零ベクトルの係数だけを 1、ほかを 0 にすれば、全係数が 0 でないのに和が 0 になるからです。空の列は一次独立とします。

両方を満たす列が基底です。生成は「足りる」、独立は「余らない」という役割を持ちます。平面の (1, 0), (0, 1), (1, 1) は、どの二本も平行ではありません。しかし三本目は最初の二本の和なので従属です。「どの二本も平行でない」は、三本以上の独立性を保証しません。

例題1：余分な一本を除き、作れる範囲を式で確かめる

ℝ³のv₁=(1,1,0)、v₂=(2,2,0)、v₃=(0,1,1)、v₄=(1,2,1)を調べます。四本のうちv₂=2v₁、v₄=v₁+v₃なので、v₂とv₄を取り除いても作れる範囲は変わりません。残ったv₁,v₃の結合は、sv₁+tv₃=(s,s+t,t)。従って作れる点は、z=y−xを満たす点に限られます。

逆にz=y−xなら、(x,y,z)=xv₁+zv₃と表せるので、この条件を満たす点はすべて作れます。両方向を示して初めて、作れる範囲を過不足なく特定できました。sv₁+tv₃=0なら第一成分からs=0、第三成分からt=0なので、この二本は独立です。従って二本は平面U={(x,y,z):z=y−x}の基底です。ℝ³全体の基底とは言っていません。

目標(2,5,3)は条件を満たし、係数は(s,t)=(2,3)。2(1,1,0)+3(0,1,1)=(2,5,3)と検算できます。しかし(2,5,4)は4≠5−2なので作れません。列を四本から二本に減らせることと、その二本でℝ³全体を生成できることは別です。

四本のままなら、同じ(2,5,3)に係数(2,0,3,0)のほか、(0,0,1,2)も使えます。差は2v₁+2v₃−2v₄=0という関係です。出力が同じで係数が違う、という現象を0への関係へ直すのが、独立性を調べる理由です。

基底であることと、座標が一意に決まること

固定した有限列が V の基底であることと、V の任意のベクトルが、その列の線形結合としてただ一通りに表せることは同値です。

短い証明

基底なら生成性が表現の存在を保証します。二通りの表現を引くと、係数の差による線形結合が 0 になります。独立性により差はすべて 0 なので、表現は一致します。逆に、すべてのベクトルに唯一の表現があれば生成性は成立します。特に 0 の表現は、全係数が 0 のものしかないため独立です。

座標とは、この順序づけた基底に対する係数の列です。存在と一意性を別々の条件で支えるために、基底には二つの要件が必要だったのです。

例題2：同じ点でも、基底を変えると座標は変わる

平面のb₁=(1,2)、b₂=(1,−1)を順に使います。cb₁+db₂=(p,q)なら、c+d=p、2c−d=q。足して3c=p+qなのでc=(p+q)/3、続いてd=(2p−q)/3です。任意の(p,q)に係数が存在し、しかもこの二式で一つに決まるため、二本はℝ²の基底です。

例えば点(4,2)のこの基底での座標は(2,2)。2(1,2)+2(1,−1)=(4,2)と戻せます。標準基底での座標(4,2)と、b₁,b₂での座標(2,2)は同じ点を記録する別の数列です。座標が変わっても、平面の点そのものや、必要な基底の本数が変わったわけではありません。また順序をb₂,b₁に逆転すれば係数の並びも逆になります。

有限生成なら、基底が存在する

V の有限生成列を固定し、空の列から始めます。生成列を順に調べ、今の列で作れないベクトルだけを加えます。追加後に和が 0 となる関係があれば、新しいベクトルの係数が非零の場合は、そのベクトルが元の列で作れてしまい矛盾します。その係数が 0 なら元の列の一次独立性により、ほかの係数もすべて 0 です。したがって一次独立性は保たれます。調べ終わると、加えたベクトルはもちろん、見送ったベクトルも最終的な列で作れます。元の生成列の全要素が作れるので、V を生成します。よって得られた列は基底です。

交換定理と次元の不変性

斜めの二本でも平面の基底にできます。それでも必ず二本でしょうか。見た目で数える代わりに、「独立な列は、生成する列より長くできない」と証明します。

一本を交換しても作れる範囲が変わらない例を見ましょう。e₁=(1,0)、e₂=(0,1) の代わりに、e₁と u₁=e₁+e₂ を選びます。元の e₂ も u₁−e₁ として作れるので、新しい二本でも全ての平面ベクトルが作れます。次の証明では、この「元の一本を新しい組から解き直せる」という操作を繰り返します。

この操作の肝は、置き換える対象の係数が非零であることです。例えばu₁=e₁+e₂ならe₂=u₁−e₁と解き直せます。しかしu₁=2e₁なら、e₂をu₁へ置き換えると縦方向を失います。係数0のe₂を解こうとしてはいけません。以下の証明は、次の独立なベクトルを追加するたびに、解き直せる係数が必ず残ることを使います。

交換補題の本数の比較

同じ実ベクトル空間 V において、s₁, …, sₘ が V を生成し、u₁, …, uₙ が一次独立なら、n ≤ m です。

一本ずつ置き換える証明

n = 0 なら結論は成立します。m = 0 なら V = {0} なので、独立な非空の列はありません。以下では m、n ともに正とします。u₁ は生成列の線形結合です。u₁ は 0 でないので、少なくとも一つの係数が 0 ではありません。その係数の s を左辺に解き出せるため、その s を u₁ に置き換えても V を生成します。

一般に u₁, …, uₖ と残りの s で生成できたとします。次の uₖ₊₁ をその列で表すと、残りの s の係数の少なくとも一つは非零です。すべて 0 なら、uₖ₊₁ が先の u の結合になり、独立性に反するからです。非零の係数の s を解き出して置き換えます。もし n > m なら、m 回の置換後には u₁, …, uₘ だけで V を生成します。すると uₘ₊₁ もその結合になり矛盾します。よって n ≤ m。

有限生成の V には、前節で示したように基底が存在します。二つの基底の本数を p、q とします。一方を独立列、他方を生成列とすれば p ≤ q。役割を逆にすれば q ≤ p です。したがって p = q。この共通の本数を次元と呼び、dim V と書けます。名前をつける前に、選び方に依存しないことを確かめたのです。これは不変量の一例です。

基底の拡張定理

次節では、線形写像で出力の零ベクトルへ移る入力全体を核と呼んで調べます。その自由度を数える準備として、いま持っている独立な組を、空間全体の基底まで増やせるかを確かめます。

有限生成の V で独立な列を一つ選び、V の有限生成列のベクトルを順に調べます。今の列で作れないものだけを加えます。独立性は保たれます。加えたベクトルの係数が非零の従属関係があれば、それを解いて「作れない」はずのベクトルを作れてしまうからです。最後には元の生成列もすべて作れるので、基底になります。これが基底の拡張です。

前に示した基底の存在証明は、空の列から始める場合です。また、V の部分空間 U でも、今の列で作れない U のベクトルを加えていけば基底を得ます。交換補題により独立列の長さは V の有限生成列の長さ以下なので、追加は必ず有限回で止まります。後で核に基底を選べるのは、このためです。

例題3：独立な一本を、基底まで増やす

ℝ³でk=(1,−1,0)から始めます。kの倍数は第三成分が0で、第一・第二成分の和も0です。e₁=(1,0,0)は和が1なので作れず、追加できます。二本の結合はak+be₁=(a+b,−a,0)で第三成分が0のままなので、e₃=(0,0,1)も作れず、追加できます。

ak+be₁+ce₃=(x,y,z)を成分で読むと、a+b=x、−a=y、c=z。従ってa=−y、b=x+y、c=zがただ一通りです。例えば(2,3,4)=−3k+5e₁+4e₃。独立性を保って追加した三本が、今度は全入力も生成することを計算で確かめました。追加の候補は唯一ではなく、e₂など別のベクトルでも基底を作れますが、作れないものを選ぶ条件は同じです。

{0} の基底は空の列なので、次元は 0 です。本章の本数の議論と次の次元定理は、有限次元という条件のもとで述べています。

核・像と次元定理

まず T(x,y)=(x,0) を考えると、(2,1)も(2,2)も同じ (2,0) へ移ります。縦方向の違いは出力に現れません。特に (0,y) は全て零ベクトルへ移り、一方、実際の出力は (x,0) という横軸の点だけです。この「零へ消える入力の集まり」と「実際に届く出力の集まり」に名前を付けます。

線形写像 T: V → W の核 ker T は 0 に移る入力全体、像 im T は実際に得られる出力全体です。核は V の、像は W の部分空間です。核の次元を退化次数、像の次元を階数（rank）と呼びます。

核と像が部分空間である理由

T(0) = 0 なので核は 0 を含みます。u、v が核に入り、a、b が実数なら T(au + bv) = aT(u) + bT(v) = 0 なので、核は和と実数倍で閉じています。

像も T(0) = 0 を含みます。像の要素 y₁ = T(x₁)、y₂ = T(x₂) に対して、ay₁ + by₂ = T(ax₁ + bx₂) は再び像に入るため、像も和と実数倍で閉じています。

例題4：残る二方向と、消える一方向を実際に選ぶ

T(x,y,z)=(x+y,z)とします。核を求めるには出力の両方を0にして、x+y=0、z=0を解きます。従って核はt(1,−1,0)全体です。この一本は非零なので独立で、核の基底です。一方、出力(p,q)は入力(p,0,q)から得られるので、像はℝ²全体です。

直前の例の基底k=(1,−1,0)、e₁、e₃を入力に使うと、T(k)=0、T(e₁)=(1,0)、T(e₃)=(0,1)。入力(x,y,z)=−yk+(x+y)e₁+ze₃の最初の項だけが消え、出力の座標は(x+y,z)として残ります。ここで「3=1+2」は、成分を何となく足した式ではなく、この基底の消える一本と残る二本を数えています。

例えば出力(4,−2)を持つ入力は、x+y=4、z=−2を満たすので、(t,4−t,−2)（t∈ℝ）。特定の解(4,0,−2)を基準にすると、全入力は(4,0,−2)+s(1,−1,0)です。どれを代入しても(4,−2)になり、違いは核の方向だけです。この直線自体は原点を含まないので部分空間ではありませんが、二点の差は核へ戻ります。

次元定理

有限次元の実ベクトル空間の間の任意の線形写像 T: V → W について、次が成り立ちます。

dimV=dim(kerT)+dim(imT)

核の基底から出発する証明

前節によって核に基底 k₁, …, kᵣ を選び、それを V の基底 k₁, …, kᵣ, v₁, …, vₛ へ拡張できます。任意の入力をこの基底で表して T を作用させると、k の項は消えます。したがって T(v₁), …, T(vₛ) は像を生成します。

これらの像の線形結合が 0 なら、同じ係数で作った v の結合は核に入るので、k の結合でも表せます。両者を引くと V の基底の従属関係になり、全係数は 0 です。よって T(v₁), …, T(vₛ) は独立で、像の基底です。核の次元は r、像の次元は s、V の次元は r + s なので結論が出ます。

例えば T(x, y, z) = (x + y, z) では、核は (t, −t, 0) 全体で、基底は (1, −1, 0) の一本です。任意の出力 (a, b) は入力 (a, 0, b) から得られるため、像は ℝ²。階数 2 と退化次数 1 の和は、入力空間の次元 3 です。

定理を使う順序にも注意します。「核が一本らしいから像は二次元だろう」と図だけで決めず、核の全体を求め、その基底を確かめれば、像を数える別の方法として次元定理を使えます。反対に像の全体が先に分かれば、核の次元を逆算できます。ただし、次元だけでは核の向きや、ある特定の出力が像に入るかまでは分かりません。

Tₐ(x,y,z)=(x+y,az)：入力3成分・出力2成分を固定し、a=0の境界で自由度を比較する
条件核とその次元像とその次元
a≠0x+y=0、z=0。基底(1,−1,0)、1次元。(p,q)には(p,0,q/a)を入れる。ℝ²全体、2次元。
a=0x+y=0、zは任意。基底(1,−1,0),(0,0,1)、2次元。(p,0)のみ。基底(1,0)、1次元。

表では同じ実数の空間ℝ³→ℝ²を比べ、長さや座標の縮尺は使いません。a=0のときだけ縦の出力が消え、核が一本増えて像が一本減ります。aがとても小さくても0でなければ、実数の厳密な計算では階数は2です。aで割る前に場合分けすること、数値の大小と厳密な独立性を区別することを読み取ってください。二行はaの全場合を尽くし、有限個の試算から推測した判定ではありません。

同じ出力を持つ二つの入力の差は核に入ります。出力に対応する入力 x₀ が一つあれば、その出力を持つ入力全体は x₀ + ker T です。「失われる情報」は、ここでは区別できなくなる入力の方向を意味します。像の次元は、出力欄の数や情報量のビット数とは別物です。基底を変えて座標を書き直しても、空間・核・像の次元は変わりません。次の行列式の章では、平面がつぶれるかどうかを面積から調べます。

寄り道［応用］：三つの色成分を、一つの明るさへ写すと何が消えるか

Web の読みやすさを扱う W3C の WCAG は、sRGB の色から相対輝度を L = 0.2126R + 0.7152G + 0.0722B と計算します。ただし R、G、B は、画面の sRGB 値をそのまま入れるのでなく、仕様の非線形な式で先に線形化した値です。この準備の後で、三つの成分を一つの量へまとめています。

この式を実数ベクトル空間 ℝ³ 全体の写像へ延長して見ると、像は1次元で、次元定理から核は2次元です。例えば変化 (0.7152, −0.2126, 0) は L を変えません。同じ相対輝度でも異なる色があり、一個の数だけから三つの色成分へは戻せないのです。実際の色の範囲 [0, 1]³ 自体は、負の実数倍などで外へ出るためベクトル空間ではありません。数学の空間へ広げて失う方向を調べ、現物の範囲へ戻して解釈しています。

出典：W3C WCAG 2.2：relative luminance の定義。

演習：基底・核・像

1–3は生成・座標・核と像の基本、4–7は基底の選択と条件変更、8–10は分かる情報の限界と逆向きの設計です。空間を必ず指定し、単に本数を数える前に生成性と独立性の根拠を書いてください。

1．三本の矢印の座標は一意か

平面の列 (1, 0), (0, 1), (1, 1) は生成列ですか。基底ですか。(1, 1) の表し方を二通り示してください。

ヒント1：最初の二本

任意の (x, y) を、最初の二本の実数倍で作れます。

ヒント2：三本目を使う

三本目は、最初の二本を足したものです。

解答

生成列ですが、(1, 0) + (0, 1) − (1, 1) = 0 という非自明な関係があるため独立でなく、基底ではありません。(1, 1) の係数は (1, 1, 0) と (0, 0, 1) の二通りに選べます。生成性だけでは座標の一意性が足りません。

2．斜めの基底で読む

b₁ = (1, 1)、b₂ = (1, −1) が ℝ² の基底であることを示し、(3, 1) の座標を求めてください。

ヒント1：係数と成分

係数を x、y とすれば、xb₁ + yb₂ = (x + y, x − y) です。

ヒント2：任意の出力から解く

任意の出力を (p, q) と書き、x + y = p、x − y = q を足す場合と引く場合を考えます。

解答

任意の (p, q) に対し x = (p + q)/2、y = (p − q)/2 が唯一の解です。よって前の同値条件から基底です。(3, 1) の座標は (2, 1)。通常の座標とは違いますが、基底の本数と次元は 2 のままです。

3．二つの出力欄は、二次元か

S(x, y, z) = (x + y, 2x + 2y) の核と像の基底を求め、次元定理を確かめてください。

ヒント1：0 になる条件

x + y = 0 だけで両成分が 0 になります。z には制限がありません。

ヒント2：像の形

a = x + y と置くと、出力は (a, 2a) です。

解答

核は (t, −t, z) 全体なので、基底は (1, −1, 0), (0, 0, 1)。像は (a, 2a) 全体で、任意の a は入力 (a, 0, 0) から得られ、基底は (1, 2) です。退化次数 2、階数 1 で、3 = 2 + 1。出力が二成分でも、像は直線で一次元です。

4．四本から基底を取り出す

v₁=(1,0,1)、v₂=(0,1,1)、v₃=(1,1,2)、v₄=(0,0,0)が張る空間の基底を、元の列から選んでください。その空間の条件式と、(3,−1,2)の選んだ基底での座標を求めてください。

ヒント1

v₃とv₄は新しい方向を加えていますか。

ヒント2

sv₁+tv₂=(s,t,s+t)を読みます。

解答

v₃=v₁+v₂、v₄=0なのでv₁,v₂で全体を生成します。sv₁+tv₂=0なら第一・第二成分からs=t=0なので独立、従ってこの二本が基底です。張る空間はz=x+yを満たす平面。任意の該当点はxv₁+yv₂と書けるので全体を尽くします。(3,−1,2)の座標は(3,−1)で、3v₁−v₂=(3,−1,2)。零ベクトルを含む列は、それだけで独立ではありません。

5．独立なら十分という答案を直す

「(1,0,0),(0,1,0)は独立だからℝ³の基底だ」という答案を診断し、最小本数の追加で基底にしてください。追加するベクトルの条件をすべて求めてください。

ヒント1

独立性のほかに、生成性を確認します。

ヒント2

追加ベクトルを(a,b,c)とし、第三成分を作れる条件を考えます。

解答

最初の二本の結合は(x,y,0)だけで(0,0,1)を作れず、生成性が不足しています。一本(a,b,c)を追加し、c≠0なら任意の(x,y,z)に係数z/cをその一本へ掛け、残りの第一・第二成分を最初の二本で補えます。零になる結合も第三成分から追加係数0、続いて他の二係数0なので独立です。c=0なら第三成分を作れず不可能。最小追加本数は1、条件はc≠0です。

6．係数が変わると基底はいつ失われるか

実数aについてb₁=(1,1)、b₂=(1,a)がℝ²の基底になる条件を求めてください。基底になる場合は任意の(p,q)の座標を、ならない場合は張る空間を求めてください。

ヒント1

c+d=p、c+ad=qを引きます。a−1で割る前に場合を分けます。

ヒント2

(a−1)d=q−pです。a=1では二本は同じです。

解答

a≠1ならd=(q−p)/(a−1)、c=(ap−q)/(a−1)が任意の(p,q)に一意に定まるので基底です。元の二式への代入でp,qに戻ることを確認できます。a=1なら二本は同じ(1,1)で、像は(p,p)の形の直線。例えば(1,0)は作れず、(1,1)には係数(1,0),(0,1)が使えるため生成性と独立性の両方を失います。二本あること自体では基底を保証できません。

7．出力から全入力を逆算する

T(x,y,z)=(x+y,z)について、出力(3,4)を持つ全入力を求め、二つの異なる入力の差が核に入ることを式で示してください。全入力の集合は部分空間でしょうか。

ヒント1

x+y=3、z=4とします。一つの自由な実数を選びます。

ヒント2

全解は(t,3−t,4)。二つのパラメータの解を引きます。

解答

全入力は(t,3−t,4)、t∈ℝです。差は(t−s,−(t−s),0)=(t−s)(1,−1,0)で核に入ります。各解をTへ入れると(3,4)であり、x+y=3、z=4以外の条件はないので全体を尽くします。この集合は零を含まないため部分空間ではありません。特定解(3,0,4)に核を足した集合として表せますが、その集合の点と核の方向は別のものです。

8．次元の情報だけでできる判断

線形写像T:ℝ⁴→ℝ³の像の次元が2と分かっています。核の次元を求め、入力を出力から一意に復元できるか、任意のℝ³の出力を作れるかを判断してください。また、これだけで特定のb=(1,0,0)に届くか分かりますか。

ヒント1

次元定理は入力次元＝核次元＋像次元です。

ヒント2

核が非零なら違う入力が重なり、像が出力空間より小さければ全出力へは届きません。

解答

核の次元は4−2=2。非零の核ベクトルkがあるので、入力xとx+kは同じ出力になり一意に復元できません。像は2次元でℝ³全体ではないため、任意の出力を作ることもできません。ただし特定のbに届くかは像の向きが必要です。像がspan{(1,0,0),(0,1,0)}なら届き、span{(0,1,0),(0,0,1)}なら届きません。どちらも階数2であり、次元だけでは特定の所属を決められません。

9．微分で失う一つの自由度

P₂の基底(1,t,t²)を使い、D:P₂→P₁の核と像の基底を求めて次元定理を確かめてください。D(p)=5を満たす全pと、そのうちp(0)=2も満たすpを求めてください。

ヒント1

D(a+bt+ct²)=b+2ctです。係数ごとに条件を比べます。

ヒント2

核は定数全体。任意のu+vtはut+(v/2)t²を微分して得られます。

解答

微分が0ならb=c=0なので、核は定数全体で基底は(1)という一本、次元1です。任意のu+vtが得られるので像はP₁で基底(1,t)、次元2。入力P₂は3次元なので3=1+2です。D(p)=5ならb=5,c=0、従ってp=a+5t。p(0)=2を加えればa=2で一意です。微分とt=0への代入で両条件を検算できます。

10．指定した核と像を持つ写像を設計する

T:ℝ³→ℝ²で、核をspan{(1,−1,0)}、像をℝ²全体にしたいとします。T(1,0,0)=(1,1)、T(0,0,1)=(1,−1)も指定して、Tの式を作り、核と像が指定どおりか確かめてください。

ヒント1

(x,y,z)=−y(1,−1,0)+(x+y)(1,0,0)+z(0,0,1)を使います。

ヒント2

核の方向の像は0です。残る二項の像を足します。

解答

T(x,y,z)=(x+y)(1,1)+z(1,−1)=(x+y+z,x+y−z)と定まります。0になる条件は二式の和からx+y=0、差からz=0。従って核は指定した一本の方向です。任意の(p,q)にはx=(p+q)/2、y=0、z=(p−q)/2を入れれば届くので、像はℝ²。指定した二入力の像も式から一致し、次元定理でも3=1+2となります。核の条件だけなら多くの写像が作れますが、残り二本の行き先を追加して一つに定まりました。
