連続確率変数と確率密度

0 から 1 の間の位置を一つ選ぶモデルで、全ての点へ同じ正の確率を置くことはできません。もし各点の確率が c > 0 なら、十分多くの異なる点を取るだけで確率の和が 1 を超えます。一点ずつの確率の一覧に代わり、区間の確率を面積で表す道具を作ります。

この章では積分と微積分の基本定理を使います。確率の合計は 1 のままですが、足す相手が高さだけでなく、高さと幅の積になります。

学習の目安は演習込み110–160分です。まず「高さと幅を掛ける理由」から密度とCDFへ進み、次に係数と境界を逆算し、最後に単位と待ち時間のモデルを点検します。演習1–3は基本、4–8は誤りの診断と読み替え、9–10は逆算と設計です。

確率密度関数と区間確率

まず0から1の区間で高さ1、その外で高さ0の関数を考えます。幅1/2の区間なら面積は1×1/2=1/2、区間全体なら1×1=1です。この面積を確率にする考えを、一定でない高さにも広げます。高さが負でないことは確率の非負性、総面積が1であることは全体の重みが1という約束に対応します。

本章では、f が実数上で非負、各有限区間で区分的に連続で、全体の通常または広義積分が 1 になる場合を扱います。区分的に連続とは、各有限区間を有限個に分ければ各内部で連続で、区切りの片側極限も有限になることです。区間の確率を次の式で与える f を、X の確率密度関数と呼びます。

f(x)≥0,∫−∞∞f(x)dx=1,P(a≤X≤b)=∫abf(x)dx

a ≤ b とします。広義積分は、有限の端を遠くへ動かした極限です。非負性により面積が負にならず、積分の区間加法性により隣り合う区間の確率が足せます。ただし、これらの条件から一般の事象全体の確率モデルを構成する定理は、本冊では未証明の枠組みとして使います。

分布が密度を持つことは追加の条件です。離散分布はこの意味の密度を持ちません。また CDF が連続である分布を全て、この区分的に連続な密度の枠で表せるとも主張しません。本章の「連続型」は、ここで指定した密度を持つモデルの範囲です。

密度の形を選び、全体の面積で係数を決める

高さの式が与えられたら、まずそのまま確率に使えるかを確かめます。確認するのは全域で非負か、全体の積分が1かの二つです。積分が1でも途中で負になる関数は使えません。また、値を取り得る範囲の外は0と明記します。これは外側の確率を勝手に増やさないためです。

例題1：右ほど重くなる、区間内の自作モデル

0≤x≤1でf(x)=c(1+x)、外で0とし、密度になるcと、左半分の区間確率を求めます。傾きは決めても全体の量はまだ決めていないので、先に総面積を1へそろえます。∫₀¹c(1+x)dx=c[x+x²/2]₀¹=3c/2。従ってc=2/3です。この係数なら1+x≥1なので非負性も満たします。

左半分の確率は∫₀¹ᐟ²(2/3)(1+x)dx=(2/3)(1/2+1/8)=5/12。右半分は1−5/12=7/12です。直接∫₁ᐟ₂¹f(x)dxを計算しても(2/3)(3/2−5/8)=7/12になり、二つの区間確率の和が1になります。

境界x=1/2での高さはf(1/2)=1ですが、左の面積は1/2ではありません。端の高さ1に幅1/2を掛けると、傾いた上辺を長方形に取り替えてしまいます。実際の左区間の平均の高さは5/6なので、(5/6)(1/2)=5/12です。高さを確率と読む誤りと、一定でない高さを一定として面積を求める誤りは、別々に点検します。

積分した式を区間の右端tで止めれば、どこまでの確率かを一つの関数で記録できます。それが次のCDFです。密度と同じ横軸でも、縦軸の意味は変わります。

累積分布関数と密度

密度 f を持つときも、CDF の意味は前章と同じ F(t) = P(X ≤ t) です。左から t までを積分して求めます。従って F(b) − F(a) が a と b の間の確率になり、f が連続な点では微積分の基本定理により F′(t) = f(t) です。

F(t)=∫−∞tf(x)dx,P(a<X≤b)=F(b)−F(a)

一点の確率と、CDF の連続性

一点 t の近くで f はある有限な M で上から抑えられます。従って、十分小さな h について |F(t + h) − F(t)| ≤ M|h| なので F は t で連続です。また P(X = t) は幅 0 の区間の積分なので 0。区間の端の一点を含むかどうかで確率は変わりません。密度に飛びがある点では、F′ = f という微分の結論を無条件には使えません。

可算加法性の「可算」は、結果を1番、2番、…と並べられることでした。実数の区間の点すべては、この形では並べ切れません。このような個数を非可算と呼びます。一点を無限に足すという言い方でも、番号を付けた級数とは区別が必要です。

例えば Ω = [0, 1]、X(ω) = ω とする一様なモデルでは、結果 1/2 は標本空間に含まれますが P(X = 1/2) = 0 です。確率 0 と空集合は違います。また各点の確率が 0 でも、区間 [0, 1] の確率は 1。可算加法性は可算個の和に関する規則なので、非可算個の一点を普通の級数のように足すことはできません。

CDFは内側の式と外側の値をつなぐ

例題1の続き：全実数でCDFを書く

前のf(x)=(2/3)(1+x)を積分すると、0≤t≤1ではF(t)=(2t+t²)/3です。しかし、この多項式をtの全ての値で使うことはできません。例えばt=2で8/3となり、確率の上限を超えます。t<0ならまだ密度のある範囲へ入っていないので0、t>1なら全体を含んでいるので1です。

従ってF(t)は「t<0で0、0≤t≤1で(2t+t²)/3、t>1で1」と分けます。境界はF(0)=0、F(1)=1で外側とつながり、区間内ではF′(t)=(2+2t)/3=f(t)>0なので減少しません。総面積だけでなく、CDFの値域とつながりも検算に使えます。

例えばP(1/4<X≤3/4)=F(3/4)−F(1/4)=11/16−3/16=1/2。直接の積分でも同じになります。端点の一点に確率がないので、このモデルでは二つの端を含めるかどうかで答えは変わりません。前章の離散分布で端点に質量があった場合と比較してください。

密度を微分で取り出す向きと、密度を積分してCDFを作る向きで、条件も区別します。fが連続な区間内の点なら微積分の基本定理を使えます。例えばこの密度はx=1で外の0へ飛び、Fは左の傾き4/3と右の傾き0が異なるため微分できません。CDF自体はそこで連続です。

一様分布の密度と一点の確率

a < b とします。[a, b] 上で f(x) = 1/(b − a)、その外で 0 とするのが一様分布です。全体の面積は {1/(b − a)}(b − a) = 1。CDF は t < a で 0、a ≤ t ≤ b で (t − a)/(b − a)、t > b で 1 です。区間内の等しい長さには等しい確率が対応します。

[0, 1/4] 上の一様分布なら密度は 4 です。それでも、例えば [0, 1/8] の確率は 4 · (1/8) = 1/2。1 以下でなければならないのは確率であり、密度の高さではありません。X の単位が秒なら、密度の単位は「1/秒」です。幅を掛けて初めて、単位のない確率になります。

逆に、f(x) = 1 を実数全体に置くと積分が発散してしまい、密度になりません。非負であるだけでも、高さが全て 1 以下であるだけでも、正規化の条件は満たせません。

密度と累積分布関数の比較

0 ≤ x ≤ 1 で f(x) = 2x、外側では 0 とします。全体の積分は [x²]₀¹ = 1 なので密度です。0 ≤ b ≤ 1 では f(b) = 2b ですが、P(X ≤ b) = F(b) = b²。左からの面積と境界の高さは、違う量です。

f の一点だけの値を別の非負な有限値に変えても、積分は変わりません。密度の一点の値から、その点の確率を読み取れない理由がここにも現れています。

例題2：左右へ確率を半分ずつ分ける

P(X≤b)=1/2となるbを求めます。幅を半分にするb=1/2では、表の通り左は1/4しかありません。大きい値へ重みが偏るので、境界を右へ動かす必要があります。

0≤b≤1でF(b)=b²だから、b²=1/2を解きます。負の平方根は値域の外なので、b=1/√2≈0.7071です。F(b)=1/2、右側も1−F(b)=1/2で検算できます。f(b)=√2は高さであって、求めた半分という確率ではありません。

別解は面積の比です。底辺b、高さ2bの三角形の面積はb²なので、全体の三角形の面積1の半分を要求してもb²=1/2です。ただし三角形でない密度へ、この図形の式は使えません。この分布ではFが[0,1]で厳密に増えるため解は一つですが、密度が0の区間があるモデルでは、同じ累積値を持つ境界が複数になることがあります。

表では横の位置を図形として比較していません。bは元の量、密度はその逆単位、累積は単位のない確率です。有限個の照合値だけから一般の関数の形を決定したわけではなく、F(b)=b²という積分の結果を確認しています。

指数分布と広義積分

λ > 0 に対し、x ≥ 0 で f(x) = λ exp(−λx)、x < 0 で 0 とする指数分布を考えます。exp(u) は e の u 乗を表します。

f(x)=λe−λx(x≥0),F(t)=1−e−λt(t≥0)

有限の端まで積分し、端を遠ざける

R > 0 について ∫₀ᴿ λe^(−λx) dx = [−e^(−λx)]₀ᴿ = 1 − e^(−λR)。λ > 0 なので R → ∞ で最後の項は 0 になり、全体の積分は 1 です。同じ積分を t で止めれば、上の CDF が得られます。t < 0 では F(t) = 0 です。λ = 0 なら関数は全て 0、λ < 0 なら x ≥ 0 で負になるため、条件を外すと密度になりません。

t ≥ 0 で P(X > t) = e^(−λt) です。このように、ある値より先に残る部分の確率を尾の確率（裾の確率）と呼びます。待ち時間の単位が分なら λ は 1/分の単位を持ち、指数 −λt は単位を持ちません。幾何分布が試行番号を数えたのに対し、このモデルは実数の待ち時間を扱います。

尾の確率から、待ち時間の率を逆算する

例題3：四分を超える確率で率を決める

待ち時間Xを指数分布で表すと仮定し、P(X>4)=1/4になるλを設計します。時間の単位は分です。高さf(4)を1/4と置くのではなく、尾の面積e^(−4λ)=1/4を使います。自然対数を取ると−4λ=−log4、従ってλ=(log4)/4=(log2)/2です。単位は1/分で、正であるため密度の条件を満たします。

代入するとP(X>2)=e^(−log2)=1/2、P(X>4)=e^(−2log2)=1/4です。四分以内の確率は3/4になります。既に二分待った後にさらに四分を超えて待つ確率は、P(X>6|X>2)=e^(−6λ)/e^(−2λ)=e^(−4λ)=1/4。分母1/2が正であることを確認して条件付き確率を使いました。

この計算は「指数分布」という形を仮定して初めて成り立ちます。四分を超える確率1/4という一点の情報だけでは、一般の待ち時間分布は決まりません。例えば0と5分を確率3/4と1/4で取る離散モデルも同じ尾確率ですが、指数密度を持ちません。率を逆算できたことと、仮定した形が現実に適することは別に検討します。

また分を秒へ変えるとXの数値は60倍、密度の高さは1/60倍になります。幅が60倍になる分だけ高さを減らして面積を保つためです。単位を変えたときに何が一定なのかは、演習7で区間確率から確かめます。

寄り道［応用］：待った時間を「覚えない」モデル

NIST は、指数分布を故障率が一定の寿命モデルとして紹介しています。これは全ての機械の寿命が指数分布だという意味ではなく、モデルの条件です。

本章の式なら、s、t ≥ 0 に対して P(X > s + t | X > s) = e^(−λ(s + t))/e^(−λs) = e^(−λt) です。s だけ待ったという条件を付けても、さらに t 待つ確率は初めと同じ。例えば λ = 0.5 /分なら、既に何分待っていても、さらに 2 分を超えて待つ条件付き確率は e⁻¹ です。摩耗で故障しやすくなる状況へ、条件を確かめず流用はできません。

出典：NIST/SEMATECH：Exponential。λ と待ち時間の数値は本章の仮想値で、条件付き確率は本文の式から計算しました。

演習：密度と確率

1．密度になる係数

0 ≤ x ≤ 2 で f(x) = cx、外で 0 とします。密度にする c と、P(1 ≤ X ≤ 2) を求めてください。

ヒント1：総面積を 1 にする

∫₀² cx dx = 2c です。

ヒント2：求める区間だけ積分する

c が決まったら、1 から 2 までの積分を取ります。

解答

2c = 1 なので c = 1/2。この値なら全域で非負です。P(1 ≤ X ≤ 2) = ∫₁² x/2 dx = [x²/4]₁² = 3/4。端の一点を含めなくても同じ確率です。

2．高さ 4 の正体

[0, 1/4] 上の一様分布で、P(0 ≤ X ≤ 1/8)、P(X = 1/8)、f(1/8) をそれぞれ求め、区別してください。

ヒント1：密度は一定

幅 1/4 で総面積 1 なので、高さは 4 です。

ヒント2：一点には幅がない

区間の確率には幅を掛け、一点の確率は 0 です。

解答

区間の確率は 4 · (1/8) = 1/2、一点の確率は 0、密度の値は 4 です。三つの量はそれぞれ面積、幅 0 の面積、高さを表します。密度の値が 4 でも、確率が 1 を超えたわけではありません。

3．待った後の確率

λ = 0.5 の指数分布で、P(X > 4) と P(X > 6 | X > 2) を求めてください。時間の単位は分とします。

ヒント1：CDF の補集合を使う

P(X > t) = e^(−0.5t) です。

ヒント2：条件の分母は正

{X > 6} は {X > 2} に含まれるので、条件付き確率は二つの尾確率の比です。

解答

P(X > 4) = e⁻²。P(X > 6 | X > 2) = e⁻³/e⁻¹ = e⁻² です。いずれも約 0.1353。条件を付けた後の追加の 4 分と、最初からの 4 分を比べた結果です。

4．総積分1だけでは足りない

0≤x≤1でf(x)=4x−1、外で0とします。∫f=1なので密度だという説明を診断し、問題が数値として現れる区間を一つ示してください。

ヒント1

確率は全ての区間で非負でなければなりません。

ヒント2

0≤x<1/4ではf(x)<0です。

解答

全積分は[2x²−x]₀¹=1ですが、fは0≤x<1/4で負なので密度ではありません。実際∫₀¹ᐟ⁴f(x)dx=1/8−1/4=−1/8となり、区間確率が負になります。正規化と非負性は独立に確認する必要があります。

5．CDFから密度と区間確率へ

F(t)はt<0で0、0≤t≤2でt²/4、t>2で1です。0<x<2で密度を求め、P(1/2<X≤3/2)とP(X=1)を計算してください。

ヒント1

区間内でFを微分します。

ヒント2

区間確率はF(3/2)−F(1/2)です。

解答

内側の密度はf(x)=x/2、外側は0とできます。端点での有限な非負値の選び方は積分に影響しません。∫₀²x/2 dx=1で検算できます。区間確率は9/16−1/16=1/2、一点の確率は0です。Fは0と2で連続ですが、2での微分を無条件には主張しません。

6．区間の右端を逆算する

Xは[2,b]の一様分布でb>2です。P(X≤5)=3/5になるbを求め、b≤5の場合も点検してください。

ヒント1

もしb≤5なら確率は既に1です。

ヒント2

b>5なら区間の長さの比は(5−2)/(b−2)です。

解答

b≤5ならP(X≤5)=1となり目標を満たしません。b>5で3/(b−2)=3/5を解くとb=7です。密度は1/5、左の長さ3に掛けて3/5、残りの長さ2から右の確率2/5も確認できます。

7．秒に変えた密度の高さ

Xは[0,2]分の一様分布です。秒で記録するY=60Xの密度とP(Y≤30)を求め、「密度の高さは確率だから1/2のまま」という説明を診断してください。

ヒント1

Yの区間は[0,120]秒です。

ヒント2

同じ事象は{Y≤30}={X≤1/2}です。

解答

密度は0≤y≤120で1/120、外で0です。全体の面積は(1/120)120=1、P(Y≤30)=30/120=1/4で、X側でも(1/2)(1/2)=1/4です。元の密度1/2は1/分、新しい密度1/120は1/秒。幅を60倍にしたので高さを60分の1にして、確率を保ちます。

8．一点だけ高さを変えたら

0≤x≤1でf(x)=2xのうち、x=1/2での値だけ100へ変更した関数をgとします。密度とCDFはどうなりますか。CDFの1/2での導関数は100ですか。

ヒント1

一点の有限値は積分を変えません。

ヒント2

CDFは0≤t≤1でt²のままです。

解答

gは非負で総積分1なので、同じ分布の密度として使えます。CDFは全く変わらず、1/2での微分は2(1/2)=1です。g(1/2)=100とは一致しません。gはそこで連続でないため、「密度が連続な点でF′=g」という定理の条件から外れます。一点の確率も0のままです。

9．尾確率から期限を決める

指数分布の待ち時間XでP(X>2)=1/4です。時間は分で測ります。λを求め、P(X≤t)≥15/16となる最小の実数t≥0を求めてください。有限のtで確率1にできますか。

ヒント1

e^(−2λ)=1/4を解きます。

ヒント2

必要な尾確率は1/16以下です。

解答

λ=(log4)/2=log2（1/分）です。e^(−λt)≤1/16からt≥(log16)/(log2)=4分。従って最小は4分で、その時の累積確率は15/16です。指数の尾はtとともに厳密に減るので最小性も保証されます。どの有限tでも尾e^(−λt)>0だから、確率1の期限はありません。

10．密度の傾きを設計する

0≤x≤1でf(x)=1+θ(2x−1)、外で0という自作モデルを考えます。密度になる実数θを全て求め、P(X≤1/2)=1/3を実現してください。同じ形で1/10を実現できるかも調べてください。

ヒント1

全積分はθによらず1です。非負性は両端の値で調べられます。

ヒント2

左半分の確率は1/2−θ/4です。

解答

直線の両端は1−θ、1+θなので、非負性は−1≤θ≤1と同値です。∫₀¹f=1+θ[x²−x]₀¹=1。左半分は1/2+θ(1/4−1/2)=1/2−θ/4だから、1/3にするにはθ=2/3で、許容範囲内です。1/10ならθ=8/5となり範囲外。許される左半分の確率は1/4以上3/4以下なので、1/10は実現できません。

自分の言葉で

  1. 密度の値には上限 1 が不要なのに、区間の確率は 1 以下になるのはなぜですか。
  2. 一点の確率 0 と、その結果が標本空間に存在しないことは、どう違いますか。
  3. CDF から密度を微分で読み取るとき、どんな点での条件を確認しますか。
