多変数の極限と経路依存性

二つの入力 x、y から一つの値を出す関数では、原点へ近づく道が増えます。横からも縦からも値が 0 へ近づくなら、斜めからでも同じでしょうか。曲がりながら近づく場合はどうでしょうか。一変数の関数の極限を平面へ広げるとき、「すべての近づき方」を一つの条件で扱う必要があります。

この章では、点どうしの距離を使って条件を定義します。経路を比べると極限がないことを示せます。一方、極限があることを示すには、近くの全点をまとめて押さえる評価が役立ちます。

演習込みの目安は120–170分です。まず距離と定義、次に経路で否定する方法と距離で保証する方法、最後に演習へ進みます。演習1–3は基本、4–6は評価の組立て、7–10は条件の変更と保証の設計です。

ユークリッド距離とノルムによる距離

点 p = (a, b)、q = (x, y) の差を v = q − p = (h, k) と書きます。ベクトルの長さをユークリッドノルムと呼び、‖v‖ = √(h² + k²) と定義します。点の距離は ‖q − p‖ です。以下では r = ‖v‖ と略します。

距離 r を使う目的は、横のずれ h と縦のずれ k を一つの条件で小さくすることです。例えば r < 0.1 なら、どちらの座標のずれも0.1未満になります。次の不等式でこの関係を確かめ、後で「どの道を通っても出力の誤差が小さい」と示すために使います。

二乗の和から r ≥ 0 で、r = 0 と h = k = 0 は同値です。また実数 t に対して ‖tv‖ = |t|‖v‖。定義の中から t² をくくれば分かります。

座標のずれと、長さの比較

|h|,|k|≤r≤|h|+|k|≤2r,|hk|≤r22

非負の平方から得る

h²、k² はそれぞれ r² 以下なので、|h|、|k| ≤ r です。また r² ≤ (|h| + |k|)² なので r ≤ |h| + |k|。さらに (|h| − |k|)² ≥ 0 を展開すると 2|hk| ≤ h² + k² = r²。従って (|h| + |k|)² = r² + 2|hk| ≤ 2r² です。比較する量は非負なので、平方根を取れます。

三角不等式

平面のベクトル u、v に対して、‖u + v‖ ≤ ‖u‖ + ‖v‖ です。

二成分の計算で確かめる

u = (u₁, u₂)、v = (v₁, v₂) とすると、(‖u‖‖v‖)² − (u₁v₁ + u₂v₂)² = (u₁v₂ − u₂v₁)² ≥ 0。よって u₁v₁ + u₂v₂ ≤ |u₁v₁ + u₂v₂| ≤ ‖u‖‖v‖ です。‖u + v‖² を展開すると ‖u‖² + 2(u₁v₁ + u₂v₂) + ‖v‖² ≤ (‖u‖ + ‖v‖)²。再び非負な量の平方根を取れば結論です。

ここまでの評価は、座標を別々に測る方法と距離で測る方法を行き来する道具です。一般の内積の定理を前提にせず、二成分の計算から得ました。

ほかの「距離」では、近さの範囲が変わる

同じずれ v=(h,k) に、L¹ノルム ‖v‖₁=|h|+|k|、L∞ノルム ‖v‖∞=max(|h|,|k|) を使うこともできます。これまでのユークリッドノルムを ‖v‖₂ と書き分け、それぞれ dᵢ(p,q)=‖q−p‖ᵢ を距離とします。

縦横だけを戻らずに進む模型なら、図の q までの移動量は 3+2=5 という L¹ の値です。二つの座標のずれを両方とも ε 以下に抑えたい条件は、L∞≤ε と一つに書けます。何を測りたいかによって、便利な尺度が変わります。

以下でいう半径1の「球」は、それぞれの距離が1以下になる点全体です。平面では三次元の立体という意味ではありません。これを B₁={v：‖v‖₁≤1}、B₂={v：‖v‖₂≤1}、B∞={v：‖v‖∞≤1} と書きます。境界も含む閉じた範囲を、同じ点で比べます。なお max(|h|,|k|) は二つの値の大きい方です。

同じ点を測ると、値の大小と半径1への入り方が対応する

どれも非負で、距離0は同じ点の場合だけ、点を入れ替えても距離は同じです。L¹の三角不等式は各成分の |uᵢ+vᵢ|≤|uᵢ|+|vᵢ| を足せば得られます。L∞では各成分の |uᵢ+vᵢ|≤‖u‖∞+‖v‖∞ の最大を取ればよいので、こちらも距離の条件を満たします。

値は ‖v‖∞≤‖v‖₂≤‖v‖₁、半径1の範囲は反対向きに B₁⊆B₂⊆B∞ です。また ‖v‖₂≤√2‖v‖∞、‖v‖₁≤√2‖v‖₂ なので、一つの尺度で0に近づけば他の尺度でも0に近づきます。距離の値や近さの図形は変わっても、この平面の極限でいう「点へ近づく」は同じです。

例題：座標ごとの精度と半径を取り違えない

二つの入力誤差をともに0.1未満にしたいとします。r<0.1なら |h|≤r、|k|≤r なので確実です。逆に |h|<0.1、|k|<0.1 だけでは r<0.1 はいえません。h=k=0.08 なら二つの条件は満たすのに、r=0.08√2≈0.1131 です。

座標から半径を保証するには、両方を0.1/√2未満に抑えれば r²=h²+k²<2(0.1/√2)²=0.01。一般に両座標が δ/√2 未満なら r<δ です。「どちらか一方が小さい」と「両方が小さい」も区別します。h=0でもk=10なら原点の近くではありません。入力が完全に0なら、rも0です。

多変数関数の極限と連続性の定義

p からの距離が δ 未満の点全体を、中心 p、正の半径 δ の開円板と呼びます。集合 D の各点のまわりに、D に丸ごと入る正の半径の開円板を取れるとき、D は開集合です。ある点のまわりの正の半径の開円板が D に入るなら、その点は D の内点です。

極限を考える点 p は D に含まれなくても構いません。ただし、どんな正の半径の円板にも p 以外の D の点があることを要求します。これを D の集積点と呼びます。近づく点がない場合に条件だけが空振りすることを防ぎます。

二変数の極限と連続性の定義

f : D ⊂ ℝ² → ℝ と D の集積点 p に対し、次を満たす実数 L を、q → p のときの f の極限と呼びます。どんな ε > 0 に対しても δ > 0 があり、D のすべての点 q について、次の含意が成立することです。

0<‖q−p‖<δ⇒|f(q)−L|<ε

一般に p ∈ D での連続性は、どんな ε > 0 に対しても δ > 0 があり、q ∈ D、‖q − p‖ < δ なら |f(q) − f(p)| < ε となることです。p が集積点でもあれば、これは極限が f(p) に等しいという条件です。

極限の定義では q = p を除きます。そのため f(p) を定義していなくても極限を問えますし、f(p) だけを変更しても極限は変わりません。連続性は、その極限と実際の関数値を結び付けています。

極限値は一つに決まる

異なる L、M が極限だと仮定し、ε = |L − M|/3 を使います。二つの δ の小さい方の円板内に、集積点の条件により q ≠ p を取れます。すると |L − M| ≤ |L − f(q)| + |f(q) − M| < 2|L − M|/3 となり矛盾です。一変数と同じく、誤差を両側から狭めれば唯一性が出ます。

例題：εから逆算して、円板を一つ選ぶ

Q(x,y)=x²+2y を p=(1,0) の近くで調べ、極限が1であることを示します。まず「出力の誤差」を書くと、x=1+h、y=k に対して Q(1+h,k)−1=2h+h²+2k です。候補の値1を直接代入で予想しても、それだけでは全点に通じる保証にはなりません。

r=√(h²+k²) と置けば、|2h+h²+2k|≤2|h|+h²+2|k|≤4r+r²。r²をrの定数倍へ直すため、先に r<1 と制限します。すると誤差は5r以下です。ここで初めて、与えられた ε>0 に対して δ=min(1,ε/5) と選びます。0<r<δ なら r<1 と5r<εが同時に成り立ち、誤差はε未満。δは経路ごとに選び直していません。

例えばε=0.05ならδ=0.01です。h=0.006、k=−0.006 は r=0.006√2<0.01。直接計算では Q=1+0.000036 なので誤差0.000036、粗い評価でも5r≈0.04243<0.05です。評価が実際より大きくても、許容誤差を覆えば目的を果たします。h=k=0では差は0で、連続性も確認できます。

定義の順序は「εを受け取る→δを一つ選ぶ→その円板内のすべての定義域の点で確認する」です。qを見てからδを変えると、同じ近さで全点を扱う保証が失われます。

経路による極限の不存在の判定

原点以外では F(x, y) = xy/(x² + y²)、原点では F(0, 0) = 0 と定めます。横軸上でも縦軸上でも F は 0 です。しかし斜めの直線 y = x では、t ≠ 0 に対して次の値になります。

F(t,t)=t22t2=12

極限があれば、経路にも同じ制約がかかる

f(q) → L なら、D の p 以外の点を通って p へ近づくどの経路でも、関数値は L へ近づきます。特に qₙ ∈ D、qₙ ≠ p、‖qₙ − p‖ → 0 という点列でも f(qₙ) → L です。

同じ δ に入るだけ

ε に応じた円板を一つ選びます。経路上の点が p へ近づけば、やがて距離は δ 未満になります。点列なら、十分大きい n で同じことが起こります。その後の出力はすべて L から ε 未満です。経路の形そのものについての追加定理は使っていません。

従って F の極限があるなら軸上の値から 0 のはずですが、対角線上の値から 1/2 のはずでもあり、両立しません。原点での極限は存在せず、F はそこで不連続です。F(0, 0) をどんな数に変更しても、この不一致は残ります。

経路の不一致は極限の不存在を示せます。一致する有限個の図だけでは、全点を要求する極限の存在を証明できません。実験の発展例 H は、下の任意の寄り道で計算します。

例題：不一致を、具体的な誤差の失敗へ戻す

Fの極限候補を0とした場合、ε=1/4に固定します。どんなδ>0を提案されても、t=δ/(2√2) として q=(t,t) を取れば、t≠0、‖q‖=δ/2<δ です。それでも |F(q)−0|=1/2>1/4。原点にいくら近い円板を選んでも、この誤差を避けられません。

0以外の候補Lも、横軸の値が0なので極限にはなれません。例えばε=|L|/2、q=(δ/2,0)とすれば |F(q)−L|=|L|。こうして「軸では0、斜めでは1/2」という観察を、全候補を排除する論証へ結べます。

距離を用いた極限の評価

少し式を変え、原点以外では G(x, y) = x²y/(x² + y²)、原点では G(0, 0) = 0 とします。一つ増えた x が、結果を変えます。

円板内の全点に通じる評価

|G(x,y)|=x2|y|x2+y2≤|y|≤x2+y2

任意の ε > 0 に対して δ = ε と選びます。0 < ‖(x, y)‖ < δ なら |G(x, y) − 0| < ε。よって極限は 0 で、原点の定義値にも等しいため連続です。q = p の場合も誤差は 0 です。

ここでは直線も曲線も列挙していません。距離が小さいという一つの条件から、どの点でも出力が小さいと示しました。次章では、この連続な G でも、縦横の変化率をさらに調べる必要があることが分かります。

別の見方：半径の変化と、向きの変化を分ける

原点以外では x=r cosθ、y=r sinθ と書けます。r>0は距離、θは向きの角度で、ここでは一意である必要はありません。すると F=cosθ sinθ、G=r cos²θ sinθ です。Fには半径rが残らず、向きの違いが消えません。Gにはrが一つ残り、|cos²θ sinθ|≤1なので |G|≤r と全方向を同じ評価で覆えます。

θを固定して各方向で極限0を得るだけでは不十分です。この計算を保証に変えているのは、θがrとともに変わっても崩れない上限1です。三角関数を使わない先の評価の方が短く、極座標を使う場合にもこの点を省けません。

寄り道［意外な例］：すべての直線を調べても、まだ足りない

原点以外で H(x, y) = x²y/(x⁴ + y²)、H(0, 0) = 0 とします。今度は有限本どころか、原点を通るすべての直線で値が 0 へ近づきます。それでも原点で極限はありません。

縦軸では x = 0 なので H = 0。ほかの直線は (x, y) = (t, mt) と書けます。m = 0 ならやはり 0。m ≠ 0、t ≠ 0 なら H(t, mt) = mt/(t² + m²) です。固定した m に対して分母は m² へ、分子は 0 へ近づくため、極限は 0 になります。

ところが放物線 y = x² に沿えば、t ≠ 0 で H(t, t²) = t⁴/(2t⁴) = 1/2。原点への距離 √(t² + t⁴) は 0 へ近づくのに、出力は 0 へ戻りません。「直線を全部」は「近くの点を全部」ではなかったのです。この反例は、経路を追加し続ける方法から、円板内の評価へ進む理由も教えてくれます。

多変数の極限と経路の反例の演習

1．座標を距離に換算する

r = √(h² + k²) として、|hk| ≤ r²/2 と |h| + |k| ≤ √2r を示してください。

ヒント1：非負の平方を作る

|h| と |k| の差を二乗すると、積の項が現れます。

ヒント2：和も二乗して比べる

(|h| + |k|)² = r² + 2|hk| です。

解答

(|h| − |k|)² = h² + k² − 2|hk| ≥ 0 より 2|hk| ≤ r²。これが第一の式です。従って (|h| + |k|)² = r² + 2|hk| ≤ 2r²。両辺の平方根を取ると第二の式が出ます。r = 0 のときも、すべて 0 で成立します。

2．原点の値を変えれば直るか

F(x, y) = xy/(x² + y²)（原点以外）の原点での極限を判定してください。原点の定義値を変えた場合も説明してください。

ヒント1：軸で候補を絞る

t ≠ 0 で F(t, 0) はいくつですか。

ヒント2：対角線を代入する

F(t, t) を t ≠ 0 で約分します。

解答

横軸では F(t, 0) = 0 なので、極限が存在するなら 0 です。一方、F(t, t) = 1/2 であり、この点も ‖(t, t)‖ = √2|t| → 0 により原点へ近づきます。従って同じ極限にはならず、極限は存在しません。極限の定義は原点そのものを除くので、F(0, 0) を変更しても結論は同じです。

3．G の連続性を ε–δ で保証する

G(x, y) = x²y/(x² + y²)（原点以外）、G(0, 0) = 0 が、原点で連続であることを示してください。

ヒント1：分母の方が大きい

0 ≤ x²/(x² + y²) ≤ 1 を使えます。

ヒント2：出力を距離で抑える

|G(x, y)| ≤ |y| ≤ ‖(x, y)‖ とした後で δ を選びます。

解答

原点以外では |G(x, y)| = x²|y|/(x² + y²) ≤ |y| ≤ r。任意の ε > 0 に δ = ε を選べば、0 < r < δ で |G(x, y) − G(0, 0)| ≤ r < ε です。r = 0 では左辺も 0 です。よって連続性の定義を満たします。

以下の4–10では、どの量を距離で抑えるか、どの点が定義域に入るかを先に決めてください。

4．長方形の精度を円板へ換算する

|h|<0.02、|k|<0.03 から r<0.03 と結論した説明を点検してください。反例を一つ作り、r<0.03を保証する同じ座標精度 |h|,|k|<η を一つ選んでください。

ヒント1

二つの二乗を足します。片方ずつの上限をrの上限と同一視しないでください。

ヒント2

h=0.019、k=0.029 を試します。保証にはη=0.03/√2を使えます。

解答

反例の r²=0.000361+0.000841=0.001202>0.0009 なので r≈0.03467>0.03。一方、η=0.03/√2 とすれば r²<2η²=0.0009 より r<0.03です。両座標を同時に制限する必要があり、片方だけの条件では他方が大きいまま残ります。零増分もこの保証を満たします。

5．一次項と二次項をまとめて押さえる

S(x,y)=3x−2y+xy の原点での極限を、経路を列挙せず示してください。ε=0.02のとき使えるδも明記してください。

ヒント1

原点の値は0。|xy|≤r²/2 を使います。

ヒント2

r<1なら 3|x|+2|y|+|xy|≤(11/2)r です。

解答

誤差は |S|≤5r+r²/2。δ=min(1,2ε/11) とすれば、0<r<δで |S|≤(11/2)r<ε です。ε=0.02ならδ=0.04/11≈0.003636。例えば(x,y)=(0.001,−0.002)ではr≈0.002236<δ、S=0.006998<0.02。原点では誤差0なので、Sはそこで連続でもあります。

6．一つの係数で極限が変わるか

原点以外で A_c(x,y)=(x²+cxy+y²)/(x²+y²) とします。原点で極限が存在する実数cをすべて求め、その場合に連続にする原点の値を決めてください。

ヒント1

横軸ではいつも1です。候補を決めてから斜めを調べます。

ヒント2

A_c=1+cF と書けます。

解答

横軸では1、対角線では1+c/2です。極限があるなら一致する必要があり c=0。c=0なら原点以外のすべての点でA_c=1なので、極限は確かに1です。原点の値を1にすれば連続、ほかの値なら不連続です。c≠0の場合は原点の値をどう決めても極限は作れません。例えばc=2では軸の1と対角線の2が一致しません。

7．全部の直線という検査を診断する

原点以外の H=x²y/(x⁴+y²)、H(0,0)=0 について、「y=mx上で0へ近づくから極限0」という説明の欠けた点を述べてください。y=cx²上の値をcで表し、c=0,1,−1を比べてください。

ヒント1

直線の傾きmを固定することは、すべての近い点を同時に扱うことではありません。

ヒント2

(x,y)=(t,ct²)では分子がct⁴、分母が(1+c²)t⁴になります。

解答

t≠0で H(t,ct²)=c/(1+c²)。c=0で0、c=1で1/2、c=−1で−1/2です。これらの点は距離 √(t²+c²t⁴)→0 により原点へ近づくので、極限はありません。直線での計算は固定したmごとには正しくても、曲がって近づく点を除外しています。t=0で約分した式を使ってH(0,0)を変更してはいけません。

8．定義域を変えて連続にする

F=xy/(x²+y²)、F(0,0)=0 を D={(x,y)：|y|≤x²} だけに制限します。Dに属する点からの原点の極限を求めてください。Dが原点を内点に持たなくても極限を問える理由も説明してください。

ヒント1

Dの原点以外の点ではx≠0です。x=0なら条件からy=0だからです。

ヒント2

分母をx²以上として |F|≤|y|/|x| とします。

解答

Dの原点以外では |F|≤|y|/|x|≤|x|≤r。従ってδ=εで極限0、定義値も0なのでD上で原点において連続です。原点はDの集積点で、例えば(t,0)が近づけます。極限の定義はD内の点だけを要求するため、円板全体がDへ入る必要はありません。t=0では割り算を使わずF(0,0)=0を確認します。全平面での不存在とは、許す点が違うので矛盾しません。

9．尺度を替えた保証へ翻訳する

ある関数について ‖q−p‖₂<δ₂ なら出力誤差がε未満と分かっています。‖q−p‖∞<δ∞ と ‖q−p‖₁<δ₁ の条件へ、それぞれ安全に翻訳する半径を選んでください。

ヒント1

同じ数値の半径をどの尺度にもそのまま使えるとは限りません。

ヒント2

‖v‖₂≤√2‖v‖∞、‖v‖₂≤‖v‖₁ を使います。

解答

δ∞=δ₂/√2 とすれば ‖v‖₂≤√2‖v‖∞<δ₂。δ₁=δ₂ とすれば ‖v‖₂≤‖v‖₁<δ₂ です。例えばδ₂=0.1ならδ∞=0.1/√2、δ₁=0.1が安全です。∞ノルムでも半径0.1のままにするとv=(0.08,0.08)を許し、‖v‖₂≈0.1131で元の保証の外になります。これは翻訳の失敗であり、関数の出力が実際に失敗するという結論までは出ません。

10．許容誤差から入力精度を設計する

T(x,y)=2x−y+xy をp=(1,2)の近くで計算します。誤差 |T(q)−T(p)| を0.01未満にしたいとき、距離の許容半径δ=0.001とδ=0.003を点検してください。前者を保証し、後者には実際に失敗する点を作ってください。

ヒント1

T(p)=2、T(1+h,2+k)−2=4h+hk です。

ヒント2

|4h+hk|≤4r+r²/2。後者の反例はk=0で作れます。

解答

r<0.001なら誤差≤4r+r²/2<0.0040005<0.01なので前者は安全です。δ=0.003のとき、h=0.0029、k=0を取ると距離0.0029<δですが、T(1.0029,2)=2.0116で誤差0.0116>0.01。上限評価が0.01を超えるだけでは保証不能という結論にとどまりますが、この具体点で実際の失敗も示せました。原点という語はこの問題では基準点pと区別します。
