円環領域とローラン展開

1/z は、0の近くから0そのものを除いたところでは正則ですが、0では定義されません。非負のべきだけのTaylor級数なら中心に値が入ってしまうので、この振る舞いを表せません。負のべきも許すと、穴へ近づくときの情報を読み分けられます。それがLaurent級数です。

学習の目安は演習込み120–180分です。二つの核と係数、収束円環の選択、特異点の分類と設計の三回に分けられます。

前提はTaylor展開とべき級数の正則性、円周積分とML評価です。導出ではCauchyの定理の有限円孔への拡張を、そこで明示した条件で借ります。可除特異点の定理を先に使うことはせず、展開を作った後に「穴を埋められる」を判定します。

円環領域の積分公式

中心 a からの距離が二つの半径の間にある点の集まりが円環です。中心 a は含めません。例えば中心0、内側の半径1、外側の半径2なら 1<|z|<2 で、両方の円周も除きます。外側の円から内点を見ると非負のべき、内側の円から外を見ると負のべきが現れます。二本の円を使うのは、Taylor展開では表せなかった中心側の穴の情報も残すためです。

f が円環 A = {z : r < |z − a| < R} で正則とします。0 ≤ r < R で、R = ∞ も許しますが、積分には有限半径だけを使います。点 z に対して r < r′ < |z − a| < R′ < R を選びます。半径 R′ の外円 Cout と半径 r′ の内円 Cin は、式の中では両方とも反時計回りです。

f(z)=12πi(∮Coutf(ζ)ζ−zdζ−∮Cinf(ζ)ζ−zdζ)

点 z の小円を、もう一つの穴にする

z を中心とする十分小さい閉円板を、内側の閉円板と交わらず外円の内部に入るように除きます。f(ζ)/(ζ − z) は残った閉領域と全境界を含む開近傍で正則です。借用した境界定理の条件が満たされ、外周積分は、内円の反時計回り積分と z の小円の反時計回り積分の和になります。

小円上では f(ζ) = f(z) + [f(ζ) − f(z)] と分けます。定数部分の積分は 2πif(z)。誤差の絶対値は、小円の半径を ε とすると ML評価で 2π max|ζ−z|=ε|f(ζ) − f(z)| 以下です。連続性により0へ行くので、上の外円−内円の式が得られます。これは前々章のCauchy公式と同じ小円の議論です。

正負のべきの展開と係数公式

w = z − a、η = ζ − a と略記します。外円では |w/η| < 1 なので 1/(η − w) = ∑ₙ₌₀∞ wⁿ/ηⁿ⁺¹。内円では |η/w| < 1 なので 1/(η − w) = −∑ₙ₌₀∞ ηⁿ/wⁿ⁺¹。内円側のマイナスが、積分公式のマイナスと打ち消し合います。

円環上のLaurent展開

f が r < |z − a| < R で正則なら、次のように展開できます。負の部分と非負の部分はそれぞれ収束し、任意の閉部分円環 r < α ≤ |z − a| ≤ β < R で一様収束します。

f(z)=∑n=0∞cn(z−a)n+∑m=1∞c−m(z−a)−mck=12πi∮|ζ−a|=sf(ζ)(ζ−a)k+1dζ,k∈ℤ,r<s<R

二つの残りを、別々に0へ送る

閉部分円環に対して r < r′ < α ≤ β < R′ < R を選び、外円・内円での |f| の最大を Mout、Min とします。外側の幾何和を n = 0,…,N で止めた積分誤差は、前章と同じ ML評価で [MoutR′/(R′ − β)](β/R′)ᴺ⁺¹ 以下。内側の幾何和を同じ n で止めた誤差は [Minr′/(α − r′)](r′/α)ᴺ⁺¹ 以下です。

二つの比がともに1未満なので、誤差は全点で同時に0へ行きます。各有限項を積分すると、外側から cₙwⁿ、内側から c₋ₙ₋₁w⁻ⁿ⁻¹ が得られます。これで無限和と積分を無条件に交換せずに、展開と一様収束が得られました。

係数に用いる半径 s は、同じ円環内ならどれでも構いません。実際、f(ζ)/(ζ − a)ᵏ⁺¹ は二つの同心円の間を含む開近傍で正則なので、有限円孔への境界定理から両円の積分が一致します。これが係数の半径不変性です。

一意性も積分で分かります。同じ性質で収束する別の展開があれば、円 |ζ − a| = s 上で (ζ − a)⁻ᵏ⁻¹ を掛けて積分します。ML評価によって一様な残りの積分は0へ行き、べきの円周積分から k 番の係数だけが残ります。どちらの係数も上の積分に等しいので、展開は一意です。

収束円環とローラン係数

f(z) = 1/[z(z − 1)] を中心0で展開します。部分分数は −1/z + 1/(z − 1)。0 < |z| < 1 では、後半に比 z の幾何級数を使い、f(z) = −z⁻¹ − ∑ₙ₌₀∞ zⁿ です。一方 |z| > 1 では f(z) = z⁻²/(1 − z⁻¹) = ∑ₙ₌₀∞ z⁻ⁿ⁻² となります。

この例の図で使う「極」は、その点を中心とするLaurent展開に負のべきが有限個だけ現れ、その少なくとも一つの係数が0でない場合を指します。例えば z=1 の近くでは、(z−1)f(z)=1/z が中心で1になるので、負1乗から始まる極です。一般の分類は、可除特異点・極・真性特異点の節で確認します。

「中心を決めれば展開は一つ」と覚えると、この例で間違えます。中心と、どの円環で関数を表すかの両方を指定したとき、一意性が働きます。

例題1：特異点の距離で、三つの円環を分ける

f(z)=1/[(z−1)(z−3)]を中心0で展開します。0自体でfは正則ですが、中心から距離1と3に極があります。従って、途中に極を含まない円環を選ぶなら、0<|z|<1、1<|z|<3、3<|z|に分けるのが自然です。最初の展開は0にも延長できます。

部分分数 f=−1/[2(z−1)]+1/[2(z−3)] を共通の出発点にします。因子1/(z−b)は、|z|<|b|なら −∑ₙ₌₀∞ zⁿ/bⁿ⁺¹、|z|>|b|なら ∑ₙ₌₀∞ bⁿz⁻ⁿ⁻¹です。どちらも幾何級数で、比はそれぞれz/b、b/zです。

内・中・外で、比を選び直す

内側：|z|<1なら両因子で非負のべきを使えます。f=∑ₙ₌₀∞ [(1−3⁻ⁿ⁻¹)/2]zⁿ=1/3+(4/9)z+…です。f(0)=1/3と一致します。

中間：1<|z|<3では、1を基準にする項だけを負のべきへ切り替えます。f=−(1/2)∑ₙ₌₀∞z⁻ⁿ⁻¹−(1/2)∑ₙ₌₀∞zⁿ/3ⁿ⁺¹。この円環では正負両方の無限和があり、c₋₁=−1/2です。

外側：|z|>3では両因子とも負のべきです。f=(1/2)∑ₙ₌₀∞(3ⁿ−1)z⁻ⁿ⁻¹。n=0の係数は0なので、最初はz⁻²+4z⁻³+13z⁻⁴+…、c₋₁=0です。元の関数が大きいzでz⁻²程度になることとも合います。

表の「比」を見て、正のべき・負のべきの選択が、中心の好みではなく距離の大小で決まることを確かめてください。

同じ関数・同じ中心でも、極のある半径を越えると係数は変わる
円環二つの幾何比べきの種類c₋₁
0<|z|<1z、z/3両方とも非負。0へ延長できる。0
1<|z|<31/z、z/3負の部分と非負の部分。−1/2

外側の展開には負の非零係数が無限個ありますが、これを見て「0は真性特異点」と判定してはいけません。0へ近づく穴あき円板で使える展開ではないからです。実際、元のfは0で正則です。孤立特異点を分類するときは、その点へいくらでも近づける円環の展開を選びます。

半径1と3の円周上にはそれぞれ極があるので、それらを横切る半径不変性は使えません。これらの幾何級数では境界の項も0へ行かず、境界上へ和を延ばすこともできません。有限個の展開例から一般の最大収束円環の定理を結論したのではなく、二つの比から各範囲を直接確かめました。

可除特異点・極・真性特異点

ここからは中心のすぐ近くまで来られる、穴あき円板 0 < |z − a| < R で f が正則とします。このとき a を孤立特異点と呼びます。Laurent展開のうち負のべきの部分を主要部と呼び、その形によって三つに分類します。一般の円環での展開と、孤立特異点の分類を区別してください。

穴を埋められるか、有限のべきで抑えられるか
種類主要部例：a = 0
可除負の係数はすべて0。中心へ正則に延長できる。sin z / z。0での値を1とする。
m位の極負の項が有限個で、最も負の指数が −m。c₋ₘ ≠ 0。z⁻³ + 2z⁻¹ は3位の極。
真性負の非零係数が無限個。可除でも有限位の極でもない。e¹ᐟᶻ。

負1乗 (z−a)⁻¹ の係数 c₋₁ には留数という名前を付けます。次章で、この係数だけが円周積分に残る理由を使います。いまは、最も負のべきが決める極の位数と、負1乗の係数を別々に読みます。

極の位数は最も負の非零の項で決まり、留数は負一乗の係数で決まるので別の情報です。例 z⁻³+2z⁻¹ は三位の極でも留数は2です。e¹ᐟᶻ が真性である理由は、eʷ の級数に全ての次数の非零項があり、有限個では終わらないことです。

係数の分類と、関数の振る舞いを結ぶ

主要部が0なら、残りは非負のべき級数です。前章の補題から中心を含む円板で正則になり、f(a) = c₀ と埋められます。逆に正則に埋められるならTaylor展開を持ち、Laurentの一意性から負の係数は0。従ってこれは可除の必要十分条件です。

さらに、穴の近くで |f| ≤ M と有界なら、m ≥ 1 に対し係数の円周積分を半径 s で評価して |c₋ₘ| ≤ Msᵐ。s → 0 とすれば c₋ₘ = 0 なので可除です。逆に正則な延長は中心近くの閉円板で連続・有界です。これで「有界なら穴を埋められる」ことも証明できました。

最も負の項が c₋ₘ(z − a)⁻ᵐ なら、(z − a)ᵐf(z) は正則に延長でき、中心での値は c₋ₘ ≠ 0。逆にこの性質があれば、その正則な関数をTaylor展開して (z − a)ᵐ で割ると、主要部はちょうどこの形です。特に |f(z)| は a に近づくと∞へ行きます。有限個でも0個でもない残りの場合が真性です。

sin z / z の可除性は sin z = z − z³/3! + … から分かります。e¹ᐟᶻ は前章の指数関数の展開へ 1/z を代入すると 1 + z⁻¹ + z⁻²/2! + … となり、負の非零係数が無限個なので真性です。実軸の正側では∞へ、負側では0へ近づき、極のように絶対値が一律に∞へ行くわけでもありません。真性特異点についてのさらに強い値域の定理は、ここでは使いません。

例題2：引く項を選んで、極の位数を変える

複素定数A、Bに対し、FA,B(z)=[exp(z)−A−Bz]/z³をz=0の近くで調べます。分母が三乗だから必ず三位の極、とは限りません。分子の最初の非零項を探すのが方針です。

係数を順に消す

exp(z)=1+z+z²/2+z³/6+…なので、FA,B=(1−A)z⁻³+(1−B)z⁻²+(1/2)z⁻¹+1/6+z/24+…。A≠1なら最も負の非零指数は−3で三位の極です。A=1、B≠1なら−2から始まり二位の極。A=B=1なら−1から始まり一位の極です。

どの場合も留数はc₋₁=1/2のままです。位数を変える操作と、留数を変える操作は同じではありません。AとBだけではz⁻¹の係数を消せないので、この二つの定数だけで可除にすることは不可能です。

可除にしたければ、分子からz²/2も引く必要があります。[exp(z)−1−z−z²/2]/z³=1/6+z/24+…となり、延長値は1/6です。元の分子の零点の位数が分母の位数以上なら穴が埋まり、足りなければその差が極の位数になります。この比較は、分子が中心の近くで恒等的に0でない場合の、Taylorの最初の非零項から従います。

例題3：実軸での極限だけでは分類できない

G(z)=exp(−1/z²)を考えます。実数x≠0ではG(x)=exp(−1/x²)→0なので、「0と埋めれば可除」と考えたくなります。しかし複素極限では、虚軸からの接近も調べる必要があります。

二方向の極限と、無限の主要部

z=iy（yは0でない実数）ならz²=−y²なのでG(iy)=exp(1/y²)→∞です。実軸では|G(1/2)|=e⁻⁴、|G(1/4)|=e⁻¹⁶と小さくなり、虚軸では|G(i/2)|=e⁴、|G(i/4)|=e¹⁶と大きくなります。従って複素平面の穴の近くで有界ではなく、可除ではありません。また実軸で0へ行くため、絶対値が全方向で∞へ行く極でもありません。

分類は級数でも直接できます。指数関数の全平面で収束する級数に−1/z²を代入すると、G(z)=∑ₙ₌₀∞(−1)ⁿz⁻²ⁿ/n!=1−z⁻²+z⁻⁴/2−z⁻⁶/6+…です。任意の閉部分円環0<α≤|z|≤βで、各項の絶対値はα⁻²ⁿ/n!以下、その数値級数が収束するため一様収束も確認できます。負の非零係数は無限個なので、0は真性特異点です。

ただしz⁻¹の項は一つもなく、留数は0。留数が0という事実だけでは、可除か、極か、真性かは決まりません。この例で全ての複素方向を描いたわけではなく、二方向の比較と全Laurent係数により分類しました。

寄り道［数学の見方］：穴へ近づくことを、無限遠へ行くことに変える

w = 1/(z − a) と置くと、z が a に近づくことは |w| が大きくなることです。有限の主要部 c₋₁/(z − a) + … + c₋ₘ/(z − a)ᵐ は、w について c₋₁w + … + c₋ₘwᵐ という多項式になります。一方 e¹ᐟ⁽ᶻ⁻ᵃ⁾ は eʷ に変わり、有限次数の多項式では終わりません。

これは逆数写像と級数を組み合わせた見方です。「負のべき」は不自然な追加ではなく、中心への接近を反転して見る座標だと考えられます。ただし一般のLaurent展開には非負の部分もあり、反転後の全関数がいつも多項式になるという意味ではありません。

出典：本章の主要部の定義を逆数変換で読み直した自作の比較。

演習：ローラン展開と孤立特異点

1．半径2の内側と外側

f(z) = 1/[z(z − 2)] を、0 < |z| < 2 と |z| > 2 のそれぞれで中心0のLaurent級数にし、c₋₁ を求めてください。

ヒント1：内側では部分分数

f = −1/(2z) + 1/[2(z − 2)] と分けます。

ヒント2：外側では z⁻² をくくる

f = z⁻²/(1 − 2/z) と書けます。

解答

内側は −1/(2z) − ∑ₙ₌₀∞ zⁿ/2ⁿ⁺² で c₋₁ = −1/2。外側は ∑ₙ₌₀∞ 2ⁿz⁻ⁿ⁻² で c₋₁ = 0 です。二円環の間に極2があるので、係数の半径不変性で両者を結ぶことはできません。

2．打ち消した後の主要部

(eᶻ − 1)/z と (eᶻ − 1 − z)/z³ の、0における特異点を分類し、可除なら延長値、極なら位数を求めてください。

ヒント1：最初の非零項を書く

eᶻ − 1 = z + z²/2 + …、eᶻ − 1 − z = z²/2 + z³/6 + …。

ヒント2：割り算後に負の項があるか

二つ目の最初の項は 1/(2z) です。

解答

最初は 1 + z/2 + … で主要部がなく可除、延長値は1。二つ目は 1/(2z) + 1/6 + z/24 + … で1位の極です。元の分子が0であるだけでは可除とは限らず、分母のべきとの比較が必要です。

3．有界性から係数を消す

0 < |z − a| < R で正則な f が |f(z)| ≤ 7 を満たすとします。c₋₂ が0になることを、任意の小半径 s での積分評価から示してください。

ヒント1：係数公式の指数

c₋₂ = (1/2πi)∮ f(ζ)(ζ − a)dζ です。

ヒント2：円の長さと被積分関数の上界

長さは 2πs、絶対値の上界は 7s です。

解答

ML評価から |c₋₂| ≤ (1/2π)(2πs)(7s) = 7s²。係数は s に依存しないので、s → 0 として c₋₂ = 0。同じ議論をすべての m ≥ 1 に適用すると主要部がすべて消え、f は可除です。

4．同じ係数公式でも、円環が違う

f(z)=1/[(z−1)(z−3)]について、中心0のc₋₂を1<|z|<3と|z|>3でそれぞれ求めてください。半径2と4の反時計回りの円で∮ζf(ζ)dζも求め、係数の違いを確認してください。

ヒント1

中間の負の部分は−(1/2)∑z⁻ⁿ⁻¹、外側の先頭はz⁻²です。

ヒント2

c₋₂=(1/(2πi))∮ζf(ζ)dζです。

解答

中間のc₋₂=−1/2、外側はc₋₂=1なので、半径2の積分は−πi、半径4では2πiです。部分分数にζを掛けて各Cauchy公式を使っても、半径2では−(1/2)·1、半径4では−(1/2)·1+(1/2)·3=1が取り出されます。二円の間に極3があるため、半径不変性を両者へ同時に適用できません。

5．主要部を指定して分子を設計する

H(z)=[exp(z)−A−Bz−Cz²]/z³の0における主要部が、ちょうど2z⁻²だけとなるA,B,Cを求めてください。極の位数、留数、定数項も答えてください。

ヒント1

z⁻³、z⁻²、z⁻¹の係数をそれぞれ0、2、0へ合わせます。

ヒント2

これらは1−A、1−B、1/2−Cです。

解答

A=1、B=−1、C=1/2です。H=2z⁻²+1/6+z/24+…なので二位の極、留数0、定数項1/6。三位の極を消すだけでは留数は消えないため、z²の係数も独立に調整しました。分子の先頭は2zで、z³で割ると2z⁻²になることでも位数を検算できます。

6．そもそも孤立しているか

f(z)=1/sin(π/z)について、0を可除・極・真性のいずれかに分類してよいでしょうか。正の実点1/nを使って、穴あき円板での正則性の条件を点検してください。

ヒント1

sin(π/(1/n))=sin(nπ)=0です。

ヒント2

どの小半径R>0にも、0<1/n<Rとなるnがあります。

解答

どの穴あき円板0<|z|<Rにも1/nが入り、その点で分母は0です。従ってfは穴あき円板の全点で正則ではなく、0は孤立特異点として扱えません。本章の三分類の前提が欠けています。「定義されないから真性」という判定は誤りです。中心へ集まる別の特異点がある場合を、中心一つのLaurent主要部の分類へ押し込みません。

7．成長上界から消える係数を探す

fは0<|z|<1で正則で、|f(z)|≤M|z|⁻³ᐟ²を満たします（Mは固定の正定数）。c₋ₘがすべての整数m≥2で0になることを示し、0で可能な特異点を絞ってください。真性は可能でしょうか。

ヒント1

半径sでの係数公式に、関数値の上界Ms⁻³ᐟ²を使います。

ヒント2

|c₋ₘ|≤Msᵐ⁻³ᐟ²です。m≥2なら指数は正です。

解答

係数はsに依存しないのでs→0としてc₋ₘ=0（m≥2）。残れる負の項はc₋₁z⁻¹だけで、c₋₁=0なら可除、非零なら一位の極です。真性は不可能です。上界の指数3/2をそのまま「1.5位の極」と呼ぶことはできません。Laurentの指数と極の位数は整数です。

8．留数0の三つの分類を設計する

0における留数がすべて0で、可除・極・真性に一つずつ当てはまる関数を自分で作ってください。極の例では位数も、真性の例では負の非零係数が無限個であることも示してください。

ヒント1

負1乗だけを避け、負2乗などを使えます。

ヒント2

1、z⁻²、exp(1/z²)が候補です。

解答

穴あき円板に制限した1は主要部0で可除、延長値1。z⁻²は二位の極でc₋₁=0。exp(1/z²)=1+z⁻²+z⁻⁴/2!+…は負の偶数べきが無限にあり真性、しかもc₋₁=0です。三つとも同じ留数でも主要部全体が違います。

9．値と傾きの上界を穴へ引き継ぐ

fは0<|z|<1で正則で、|f(z)−2|≤3|z|を満たします。0へ正則に延長できること、延長値が2であること、延長後の|f′(0)|≤3を示してください。この傾きの上界を達成する関数も一つ挙げてください。

ヒント1

|f|≤5なので可除です。次にg(z)=(f(z)−2)/zを調べます。

ヒント2

gは穴あき円板で正則かつ|g|≤3なので、gも可除です。

解答

有界性からfは正則に延長でき、与えられた不等式のz→0で延長値は2です。gも可除なのでg(0)が定まり、差商の極限から延長後のf′(0)=g(0)。連続性で|g(0)|≤3となります。f(z)=2+3zは|f(z)−2|=3|z|、f′(0)=3を満たして上界を達成します。

10．有限個の補正で真性を消せるか

P(w)を任意の有限次数の多項式とします。exp(1/z)−P(1/z)を0で可除にしたり、有限位の極にしたりできるでしょうか。一方で留数だけを0にするPは選べるでしょうか。

ヒント1

Pが消せる負のべきは有限個です。

ヒント2

exp(1/z)=∑ₙ₌₀∞z⁻ⁿ/n!には、どれだけ先にも非零の項があります。

解答

どの有限次数のPでも、その次数を超える負のべきの係数1/n!は無限個残るので、真性のままです。可除にも有限位の極にもできません。一方、P(w)=wならz⁻¹の係数だけを消せ、留数は0になります。有限個の係数を調整することと、無限の主要部を全て消すことを区別します。
