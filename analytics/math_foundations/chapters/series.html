級数と部分和の極限

1 + 1/2 + 1/4 + 1/8 + … は 2 になる、と聞いたことがあるかもしれません。有限回足した値はいつも 2 より小さいのに、どうして等号で結べるのでしょう。無限個を一度に足す操作を仮定するのでなく、有限の計算を並べ、その極限として意味を与えます。前提は数列の極限と、帰納法です。

項 a₁、a₂、… に対して Sₙ = a₁ + … + aₙ を部分和と呼びます。部分和の数列 Sₙ が有限の実数 S に近づくとき、級数 ∑aₙ は収束し、その和を S と定めます。部分和がどこまでも増える場合も、振動して落ち着かない場合も、ここでは発散です。

この章では「収束するか」だけでなく、「有限回の計算でどこまで確かめられるか」を問いにします。まず等比級数で必要な項数を決め、項が小さくても合計が増え続ける反例を調べ、最後に符号の打消しを使える条件を比べます。学習の目安は演習込み100–150分です。演習1–3は基本、4–7は誤差の見積り、8–10は判定の根拠と条件の設計です。

等比級数と収束条件

等比級数は幾何級数とも呼ばれます。まず 1、r、r²、… の N 項の和を、一般の部分和 Sₙ と区別して GN と書きます。添字を 0 から始めるので、最後の項は rᴺ⁻¹ です。GN を r 倍して元の和から引くと、中間の項が消えます。

例えば4項なら G₄=1+r+r²+r³、その r 倍は rG₄=r+r²+r³+r⁴ です。二つの式を同じ次数でそろえて引くと、r,r²,r³がそれぞれ消え、最初の1と最後の −r⁴ だけが残ります。項数 N が増えても、途中が消える仕組みは同じです。

GN=∑n=0N−1rn,(1−r)GN=1−rN

幾何級数の収束

|r| < 1 なら、∑ₙ₌₀∞ rⁿ = 1/(1 − r)。N 項で打ち切った誤差の絶対値は |r|ᴺ/|1 − r| です。

極限へ渡す部分を明確にする

r ≠ 1 のとき、有限の恒等式を割って GN = (1 − rᴺ)/(1 − r)。幾何べきの極限により、|r| < 1 なら |r|ᴺ → 0、したがって rᴺ → 0 なので極限は 1/(1 − r) です。和から部分和を引けば rᴺ/(1 − r) となり、絶対値を取ると誤差の式が得られます。出発点は有限の等式であり、無限の和を先に引き算したのではありません。

r = 1 では各項が 1 なので GN = N。r = −1 では 1、0、1、0、… と振動します。|r| > 1 でも項の大きさが増え、有限の和へ収束しません。式 1/(1 − r) が計算できるだけでは、それが級数の和であるとは言えません。

部分和の誤差と必要な項数

和 S が存在するとき、RN=S−GN を、N項の後に残る尾部と呼びます。収束は RN→0 という主張ですが、計算には「|RN|≤ε となる N」を知りたいのです。ε は許す誤差の大きさで、正の実数です。項の大きさと尾部を分けるのが、次の例の方針です。

例題1：正の比と負の比で打切りを設計する

まず 1+1/2+1/4+… の和を誤差 1/100 以下で求めます。第N項は 21−N、最初に省く項は 2−N です。省いた項もさらに続くので、最初に省く一項だけを誤差としてはいけません。幾何級数の尾部は RN=21−N です。N=7なら1/64>1/100、N=8なら1/128<1/100。尾部は N とともに減るので、最小は8項です。

部分和 G₈=2−1/128=255/128=1.9921875。和2との差は0.0078125で、確かに指定以内です。「8項」という答えは、7項では失敗することまで調べて初めて最小といえます。

次は 1−1/2+1/4−… を同じ精度にします。符号を残した尾部は RN=(−1/2)N/(1+1/2) なので、|RN|=(2/3)2−N。N=6では1/96>1/100、N=7では1/192<1/100なので、今度は7項で足ります。G₇=43/64、和2/3との差は1/192です。Nが奇数のとき尾部は負で、部分和は真の和より上にあります。

絶対値を取ってから足す評価なら、どちらにも尾部の上界 21−N が使えますが、負の比では打消しの情報を捨てています。保証として誤りではなく、安全側に余分な項を要求する評価です。精密な式を使うか、簡単な上界を使うかを目的に合わせて選びます。

等比級数の部分和の実験

比 r と項数 N を動かし、有限の和 GN の変化を見てください。r が負なら、部分和は極限を挟んで行き来することがあります。|r| が 1 に近いと、収束する場合でも30項では近づき方がゆっくりです。表示される有限個の値が落ち着いて見えることと、収束の証明は分けて考えます。

N 項の計算結果はどの r に対しても定まります。無限級数の収束条件を外れた領域でも、有限和が「未定義」になるわけではありません。r = 1 の有限和には、割り算を含む公式の代わりに N を使います。

級数収束の必要条件と調和級数

級数が収束して Sₙ → S なら、aₙ = Sₙ − Sₙ₋₁ → S − S = 0。したがって、項が 0 に近づかない級数はただちに発散と分かります。これは収束の必要条件であって、十分条件ではありません。

調和級数は発散する

1 + 1/2 + 1/3 + … の各項は 0 に近づきますが、部分和はどんな実数も超えます。

倍々のまとまりで下から評価する

1/2 を一つの組、1/3 + 1/4 を次の組、1/5 + … + 1/8 を次の組とします。一般に分母が 2ᵏ + 1 から 2ᵏ⁺¹ までの組には 2ᵏ 項があり、各項は少なくとも 1/2ᵏ⁺¹。よって一組の和は少なくとも 1/2 です。

2ᵐ までの部分和は 1 + m/2 以上です。m を増やせばどんな数より大きくなるので、部分和は有限値に収束しません。「項が小さくなる速さ」が重要だと、この反例が教えています。

望遠和と比較判定

等比級数でないときは、無理に比を探す前に「足すと消える形」を探します。有限の式を作ってから極限に渡せば、何を無限に続けてよいかを見失いません。

例題2：差に分けて部分和と尾部を同時に求める

∑n=1∞1/[n(n+1)] を考えます。分母が隣り合う整数の積なので、1/n−1/(n+1) を通分すると分子が (n+1)−n=1 になります。この形なら隣の項と打ち消せそうです。

SN=(1−1/2)+(1/2−1/3)+…+(1/N−1/(N+1))=1−1/(N+1)。途中の項が消えるこの形を望遠和と呼びます。N=1なら1/2、N=2なら2/3で元の和とも合います。1/(N+1)→0 なので和は1、尾部は厳密に1/(N+1)です。誤差を1/100以下にする最小項数は N=99 です。

各項はおおよそ1/n²ですが、この例の尾部はおおよそ1/Nです。一項の大きさだけを残り全部と取り違えると、必要項数を大きく見誤ります。幾何級数では尾部も幾何的に減ったのに対し、こちらは項数を10倍ほどにして誤差を10分の1ほどにする減り方です。

非負項の比較判定

全てのnで0≤aₙ≤bₙ、かつ∑bₙが収束するなら∑aₙも収束します。有限個の初めの項を除いてこの条件が成り立つ場合も同じです。

単調性と上界を別々に確認する

aₙ≥0なので AN=a₁+…+aN は単調増加です。一方 AN≤BN≤∑bₙ なので上に有界です。有界単調列の収束定理から AN は収束します。初めの有限項を取り除いても、部分和に固定した有限数を足すだけなので収束性は変わりません。

例えば n≥2 なら 1/n²≤1/[n(n−1)]=1/(n−1)−1/n。右辺のn=2からNまでの和は1−1/Nです。従って∑1/n²は収束します。さらに N≥1で、n=N+1から後ろを同じように比較すれば、尾部は1/N以下です。和の正確な値を知らなくても、収束と誤差の保証は得られます。この章では∑1/n²の和そのものを求める定理は使いません。

比較の向きに注意しましょう。発散する調和級数より小さい、というだけでは結論は出ません。1/n²も1/(2n)も1/n以下ですが、一方は収束し、もう一方は発散します。収束を上から押さえるのか、発散を下から押さえるのかが方針の分かれ目です。

絶対収束と比較による評価

∑|aₙ| が収束するとき、元の級数を絶対収束と呼びます。このとき ∑aₙ も収束します。理由は、後ろの項の和の絶対値が、同じ範囲の |aₙ| の和以下だからです。絶対値の和の「残り」が小さければ、元の部分和どうしの差も小さくなります。

ここでは「項が十分後ろなら部分和どうしの差をどんな精度でも小さくできる数列は収束する」というCauchyの収束判定法を使います。これは実数の最小上界性から、極限の章で導いた定理です。単なる上界の存在だけから、符号の混じる部分和の収束を結論しているのではありません。

級数は収束するが、絶対値を付けると発散する場合を条件収束と呼びます。代表例は 1 − 1/2 + 1/3 − 1/4 + … です。二項を一組で追加すると、偶数部分和の差は S₂ₘ₊₂−S₂ₘ=1/(2m+1)−1/(2m+2)>0。一方、奇数部分和の差は S₂ₘ₊₃−S₂ₘ₊₁=−1/(2m+2)+1/(2m+3)<0 です。小さい正の量ずつ加わる偶数番目は増え、小さい量ずつ失う奇数番目は減ります。

どの偶数部分和もどの奇数部分和以下なので、両者は有界です。最小上界性から示した有界単調列の収束定理で、それぞれに極限があります。隣り合う奇数番目と偶数番目の部分和の差は 1/(2m + 1) → 0 なので、二つの極限は等しくなります。一方、絶対値の級数は調和級数なので発散です。

有限和では順序を変えても答えは同じですが、無限和は「どの順で部分和を作るか」も含む定義です。絶対収束なら並べ替えても和は保たれますが、その一般的な証明は先へ譲ります。条件収束では並べ替えで値が変わることがあります。ここではその深い一般定理を証明せず、有限和の交換法則を無条件に移さない、という注意にとどめます。

交代級数の収束と打切り誤差

調和級数と交代調和級数の違いを、一般の条件にします。bₙ≥0 が単調に減少して0へ近付くとき、SN=b₁−b₂+…+(−1)N−1bN を考えます。必要なのは、符号の交代に加えて大きさの単調減少と0への収束です。

例題3：交代調和級数を区間で挟む

偶数部分和は S2m+2−S2m=b2m+1−b2m+2≥0、奇数部分和は S2m+3−S2m+1=−b2m+2+b2m+3≤0 です。また S2m+1−S2m=b2m+1≥0。偶数側が下から増え、奇数側が上から減り、二つは逆転しません。

有界単調列の収束定理により両側に極限があり、その差 b2m+1 が0になるので同じ値Sへ収束します。Sは隣接する部分和の間にあり、区間の長さは次に足す bN+1 です。従って |S−SN|≤bN+1。この条件の下で初めて「最初に省く一項で誤差を抑える」が使えます。

bₙ=1/nなら |S−SN|≤1/(N+1)。誤差1/20以下をこの評価で保証する最小項数は19です。S₁₉の次は負の項なので S≤S₁₉、かつ S₁₉−1/20≤S。和の名前や正確な値を知らなくても、幅1/20の区間で囲めました。これは評価を満たす最小項数であり、実際の誤差が19項未満では必ず大きい、と主張したのではありません。

対照として bₙ=1 なら偶数部分和0、奇数部分和1の間の隙間は閉じません。大きさが0へ行く条件を除くと、符号が交互でも収束しないことが分かります。

絶対収束の議論も尾部の言葉で言い直せます。AN=∑n=1N|aₙ| が収束すれば、M>Nのとき |SM−SN|≤AM−AN をどんな精度でも小さくできます。Cauchyの判定法がSNの収束を与えます。さらに極限を取ると |S−SN|≤∑n=N+1∞|aₙ|。符号の規則を知らなくても使える点が利点です。

交代調和級数は符号の規則を使って収束し、絶対値を付けると発散します。従って条件収束です。絶対収束は収束より強い性質であり、収束する全ての級数が絶対収束するわけではありません。判定に使った条件を結果と一緒に残しましょう。

寄り道［応用］：リンクをたどる寄与にも、幾何級数が現れる

ネットワークの重要度を計算するライブラリ NetworkX には、Web ページの順位づけから生まれた PageRank が実装されています。通常のモデルには、確率 α でリンクをたどり、確率 1 − α で別の出発点へ移る仕組みがあります。延々と同じ場所を巡る動きに、再出発を混ぜるのです。

0 < α < 1 とし、再出発後、次の再出発までにちょうど k 回リンクをたどる確率は (1 − α)αᵏ。この重みを k = 0 から全部足すと、幾何級数より 1 になります。N 回までで切れば、残りの重みは αᴺ⁺¹ です。これは単純化した確率モデルでの計算ですが、無限の寄与に有限の合計と打切り誤差を与える役割が見えます。実装では行き先のないページの処理や停止基準も別に必要で、級数の一式だけで全体の正しさを示したわけではありません。

級数の収束条件と残差の演習

1．何項なら誤差を抑えられるか

1 + 1/2 + 1/4 + … を N 項で打ち切り、和との差を 1/16 以下にしたいとします。最小の N はいくつですか。

ヒント1：初項の添字

N 項の最後は (1/2)ᴺ⁻¹ です。

ヒント2：残りの公式

誤差は (1/2)ᴺ/(1 − 1/2) = 2¹⁻ᴺ です。

解答

2¹⁻ᴺ ≤ 2⁻⁴ には N ≥ 5 が必要なので最小は5項。部分和は 1 + 1/2 + 1/4 + 1/8 + 1/16 = 31/16、和 2 との差は 1/16 です。4項では差が 1/8 になります。

2．必要条件の向き

「aₙ → 0 なら ∑aₙ は収束する」と「∑aₙ が収束するなら aₙ → 0」のどちらが正しいか、証明または反例を示してください。

ヒント1：正しい向きは差を見る

aₙ を連続する二つの部分和の差で表します。

ヒント2：逆向きには調和級数

aₙ = 1/n を使えます。

解答

後者が正しく、Sₙ → S なら aₙ = Sₙ − Sₙ₋₁ → 0。前者は誤りで、1/n → 0 でも調和級数は倍々の組分けによって発散します。必要条件を満たした段階では、収束の判定はまだ終わっていません。

3．負の比と境界

∑ₙ₌₀∞ (−1/2)ⁿ と ∑ₙ₌₀∞ (−1)ⁿ について、収束するか、収束するなら絶対収束かを判定してください。

ヒント1：比の絶対値

最初の級数では、絶対値を付けても比 1/2 の幾何級数です。

ヒント2：二番目は部分和を書く

1項、2項、3項の和を並べます。

解答

最初は絶対収束し、和は 1/(1 + 1/2) = 2/3。絶対値の和は 2 です。二番目は部分和が 1、0、1、0、… で発散し、条件収束でもありません。符号が交互というだけでは十分でなく、項が 0 へ近づく必要があります。

4．一項の誤差を使う推論を直す

∑ₙ₌₀∞(1/2)ⁿをN項で打ち切るとき、「次の項が1/100以下なら誤差も1/100以下」とする推論を、N=7で点検してください。正しい最小項数も求めてください。

ヒント1：方針

最初に省く項と尾部全体を別々に計算します。

ヒント2：計算の足場

N=7で、最初に省く項は1/128、尾部は2/128です。

解答

1/128<1/100でも尾部1/64>1/100なので推論は誤りです。全て正なので残り一項だけでは足りません。尾部2¹⁻ᴺ≤1/100を調べ、N=7で失敗、N=8で1/128≤1/100なので最小8項です。

5．同じ精度を負の比で保証する

∑ₙ₌₀∞(−1/2)ⁿを誤差1/100以下で近似する最小項数を、正確な尾部の式で求めてください。その部分和は和より上ですか、下ですか。

ヒント1：方針

尾部は(−1/2)ᴺ/(1+1/2)です。

ヒント2：計算の足場

N=6と7を調べます。

解答

尾部の絶対値は(2/3)2⁻ᴺ。6項では1/96>1/100、7項では1/192<1/100なので最小7項。N=7の尾部は負なので部分和は上です。実際43/64−2/3=1/192です。絶対値の級数だけで評価すると8項を要求するため、符号の情報が1項分の差を生みます。

6．望遠和の誤差から逆算する

∑ₙ₌₁∞1/[n(n+1)]について、和とN項の部分和を求め、誤差1/200以下にする最小Nを求めてください。

ヒント1：方針

1/[n(n+1)]=1/n−1/(n+1)です。

ヒント2：計算の足場

有限和で消える項を書き、最後に残る項を見ます。

解答

SN=1−1/(N+1)なので和は1、尾部は1/(N+1)。1/(N+1)≤1/200はN≥199と同値です。N=199の誤差は1/200、N=198では1/199と大きいので最小199項。各項は約1/n²ですが尾部は約1/Nである点も確かめられます。

7．和を知らずに収束を証明する

∑ₙ₌₁∞1/n²が収束することを、n≥2で1/n²≤1/[n(n−1)]として示してください。またN項後の尾部を1/N以下で抑えてください。

ヒント1：方針

非負項なので部分和は増加します。上界は比較先の望遠和から作ります。

ヒント2：計算の足場

n=2からMまで、1/[n(n−1)]=1/(n−1)−1/nを足します。

解答

部分和は1+(1−1/M)≤2で上に有界かつ単調増加なので収束します。N+1からMまでの比較先の和は1/N−1/M。M→∞とすると尾部≤1/Nです。正確な和を求めたのではなく、収束と保証された上界を得ました。

8．比較判定の向きを診断する

「0≤aₙ≤1/nなので∑aₙは収束する」という主張に、収束する例と発散する例を一つずつ与え、欠けている根拠を説明してください。

ヒント1：方針

上から押さえる相手が発散するときは、その上界だけでは決まりません。

ヒント2：計算の足場

aₙ=1/n²とaₙ=1/(2n)を比べます。

解答

どちらも0≤aₙ≤1/nです。前者は演習7で収束、後者の部分和は調和級数の半分なので発散します。したがって与えられた条件だけでは両方起こります。収束を示す比較では、収束すると分かっている非負級数を上界に選ぶ必要があります。

9．交代和を区間で保証する

交代調和級数の和をSとします。S₄=1−1/2+1/3−1/4を計算し、S₄とS₅からSを挟んでください。さらに本文の評価で誤差1/100以下を保証する項数を求めてください。

ヒント1：方針

偶数部分和は下、奇数部分和は上です。

ヒント2：計算の足場

S₅=S₄+1/5、誤差上界は1/(N+1)です。

解答

S₄=7/12、S₅=47/60なので7/12≤S≤47/60です。区間幅は1/5。誤差1/100の保証には1/(N+1)≤1/100、すなわちN≥99を選べば足ります。この評価で保証する最小Nは99ですが、実際の誤差についての最小項数とは区別します。絶対値の級数は発散するので、この保証は符号の交代と大きさの単調減少を使っています。

10．係数が変わっても使える保証を設計する

各n≥1で|aₙ|≤3·2⁻ⁿだけが分かり、符号は不明とします。∑aₙの収束を証明し、N項で誤差1/100以下を一律に保証する最小Nを求めてください。

ヒント1：方針

絶対値の和を、初項3/2の幾何級数で上から押さえます。

ヒント2：計算の足場

N+1からの上界の和は3·2⁻ᴺです。

解答

∑|aₙ|≤∑3·2⁻ⁿ=3なので絶対収束します。尾部の絶対値は3·2⁻ᴺ以下。N=8では3/256>1/100、N=9では3/512<1/100なのでN=9で保証できます。全てaₙ=3·2⁻ⁿとする許された列では誤差が上界と一致するため、8項では一律に保証できず、最小9項です。
