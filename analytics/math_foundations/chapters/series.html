級数と部分和の極限

1 + 1/2 + 1/4 + 1/8 + … は 2 になる、と聞いたことがあるかもしれません。有限回足した値はいつも 2 より小さいのに、どうして等号で結べるのでしょう。無限個を一度に足す操作を仮定するのでなく、有限の計算を並べ、その極限として意味を与えます。前提は数列の極限と、帰納法です。

項 a₁、a₂、… に対して Sₙ = a₁ + … + aₙ を部分和と呼びます。部分和の数列 Sₙ が有限の実数 S に近づくとき、級数 ∑aₙ は収束し、その和を S と定めます。部分和がどこまでも増える場合も、振動して落ち着かない場合も、ここでは発散です。

等比級数と収束条件

まず 1、r、r²、… の N 項の和を、一般の部分和 Sₙ と区別して GN と書きます。添字を 0 から始めるので、最後の項は rᴺ⁻¹ です。GN を r 倍して元の和から引くと、中間の項が消えます。

GN=∑n=0N−1rn,(1−r)GN=1−rN

幾何級数の収束

|r| < 1 なら、∑ₙ₌₀∞ rⁿ = 1/(1 − r)。N 項で打ち切った誤差の絶対値は |r|ᴺ/|1 − r| です。

極限へ渡す部分を明確にする

r ≠ 1 のとき、有限の恒等式を割って GN = (1 − rᴺ)/(1 − r)。幾何べきの極限により、|r| < 1 なら |r|ᴺ → 0、したがって rᴺ → 0 なので極限は 1/(1 − r) です。和から部分和を引けば rᴺ/(1 − r) となり、絶対値を取ると誤差の式が得られます。出発点は有限の等式であり、無限の和を先に引き算したのではありません。

r = 1 では各項が 1 なので GN = N。r = −1 では 1、0、1、0、… と振動します。|r| > 1 でも項の大きさが増え、有限の和へ収束しません。式 1/(1 − r) が計算できるだけでは、それが級数の和であるとは言えません。

等比級数の部分和の実験

比 r と項数 N を動かし、有限の和 GN の変化を見てください。r が負なら、部分和は極限を挟んで行き来することがあります。|r| が 1 に近いと、収束する場合でも30項では近づき方がゆっくりです。表示される有限個の値が落ち着いて見えることと、収束の証明は分けて考えます。

N 項の計算結果はどの r に対しても定まります。無限級数の収束条件を外れた領域でも、有限和が「未定義」になるわけではありません。r = 1 の有限和には、割り算を含む公式の代わりに N を使います。

級数収束の必要条件と調和級数

級数が収束して Sₙ → S なら、aₙ = Sₙ − Sₙ₋₁ → S − S = 0。したがって、項が 0 に近づかない級数はただちに発散と分かります。これは収束の必要条件であって、十分条件ではありません。

調和級数は発散する

1 + 1/2 + 1/3 + … の各項は 0 に近づきますが、部分和はどんな上限も超えます。

倍々のまとまりで下から評価する

1/2 を一つの組、1/3 + 1/4 を次の組、1/5 + … + 1/8 を次の組とします。一般に分母が 2ᵏ + 1 から 2ᵏ⁺¹ までの組には 2ᵏ 項があり、各項は少なくとも 1/2ᵏ⁺¹。よって一組の和は少なくとも 1/2 です。

2ᵐ までの部分和は 1 + m/2 以上です。m を増やせばどんな数より大きくなるので、部分和は有限値に収束しません。「項が小さくなる速さ」が重要だと、この反例が教えています。

絶対収束と比較による評価

∑|aₙ| が収束するとき、元の級数を絶対収束と呼びます。このとき ∑aₙ も収束します。理由は、後ろの項の和の絶対値が、同じ範囲の |aₙ| の和以下だからです。絶対値の和の「残り」が小さければ、元の部分和どうしの差も小さくなります。

ここでは「項が十分後ろなら部分和どうしの差をどんな精度でも小さくできる数列は収束する」というCauchyの収束判定法を使います。これは実数の最小上界性から、極限の章で導いた定理です。単なる上界の存在だけから、符号の混じる部分和の収束を結論しているのではありません。

級数は収束するが、絶対値を付けると発散する場合を条件収束と呼びます。代表例は 1 − 1/2 + 1/3 − 1/4 + …。偶数番目の部分和は増加し、奇数番目の部分和は減少します。どの偶数部分和もどの奇数部分和以下なので、両者は有界です。最小上界性から示した有界単調列の収束定理で、それぞれに極限があります。隣り合う奇数番目と偶数番目の部分和の差は 1/(2m + 1) → 0 なので、二つの極限は等しくなります。一方、絶対値の級数は調和級数なので発散です。

有限和では順序を変えても答えは同じですが、無限和は「どの順で部分和を作るか」も含む定義です。絶対収束なら並べ替えても和は保たれますが、その一般的な証明は先へ譲ります。条件収束では並べ替えで値が変わることがあります。ここではその深い一般定理を証明せず、有限和の交換法則を無条件に移さない、という注意にとどめます。

寄り道［応用］：リンクをたどる寄与にも、幾何級数が現れる

ネットワークの重要度を計算するライブラリ NetworkX には、Web ページの順位づけから生まれた PageRank が実装されています。通常のモデルには、確率 α でリンクをたどり、確率 1 − α で別の出発点へ移る仕組みがあります。延々と同じ場所を巡る動きに、再出発を混ぜるのです。

0 < α < 1 とし、再出発後、次の再出発までにちょうど k 回リンクをたどる確率は (1 − α)αᵏ。この重みを k = 0 から全部足すと、幾何級数より 1 になります。N 回までで切れば、残りの重みは αᴺ⁺¹ です。これは単純化した確率モデルでの計算ですが、無限の寄与に有限の合計と打切り誤差を与える役割が見えます。実装では行き先のないページの処理や停止基準も別に必要で、級数の一式だけで全体の正しさを示したわけではありません。

級数の収束条件と残差の演習

1．何項なら誤差を抑えられるか

1 + 1/2 + 1/4 + … を N 項で打ち切り、和との差を 1/16 以下にしたいとします。最小の N はいくつですか。

ヒント1：初項の添字

N 項の最後は (1/2)ᴺ⁻¹ です。

ヒント2：残りの公式

誤差は (1/2)ᴺ/(1 − 1/2) = 2¹⁻ᴺ です。

解答

2¹⁻ᴺ ≤ 2⁻⁴ には N ≥ 5 が必要なので最小は5項。部分和は 1 + 1/2 + 1/4 + 1/8 + 1/16 = 31/16、和 2 との差は 1/16 です。4項では差が 1/8 になります。

2．必要条件の向き

「aₙ → 0 なら ∑aₙ は収束する」と「∑aₙ が収束するなら aₙ → 0」のどちらが正しいか、証明または反例を示してください。

ヒント1：正しい向きは差を見る

aₙ を連続する二つの部分和の差で表します。

ヒント2：逆向きには調和級数

aₙ = 1/n を使えます。

解答

後者が正しく、Sₙ → S なら aₙ = Sₙ − Sₙ₋₁ → 0。前者は誤りで、1/n → 0 でも調和級数は倍々の組分けによって発散します。必要条件を満たした段階では、収束の判定はまだ終わっていません。

3．負の比と境界

∑ₙ₌₀∞ (−1/2)ⁿ と ∑ₙ₌₀∞ (−1)ⁿ について、収束するか、収束するなら絶対収束かを判定してください。

ヒント1：比の絶対値

最初の級数では、絶対値を付けても比 1/2 の幾何級数です。

ヒント2：二番目は部分和を書く

1項、2項、3項の和を並べます。

解答

最初は絶対収束し、和は 1/(1 + 1/2) = 2/3。絶対値の和は 2 です。二番目は部分和が 1、0、1、0、… で発散し、条件収束でもありません。符号が交互というだけでは十分でなく、項が 0 へ近づく必要があります。
