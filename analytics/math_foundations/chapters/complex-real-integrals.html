留数定理による実積分

∫₋∞∞ dx/(1 + x⁴) は、実数の原始関数だけで計算しようとすると分解が長くなります。複素平面で半円の寄り道を足すと、閉じた経路になり、留数定理が使えます。ただし足した円弧の寄与が最後に0になることと、元の実広義積分が存在することは、自分で確かめる必要があります。

この章では実軸上に極がない有理関数を、二次分母から複数の極・高位の極へと広げて扱います。前提は実積分の評価、ML評価、留数定理です。振動因子のための特別な補題や、主値という別の積分の定義は使いません。

まず分母が二次の 1/(x²+a²)（a>0）で、極の配置・円弧の評価・左右の広義積分を一つずつ確認します。その後、同じ手順を四次の分母へ使い、冒頭の積分へ戻ります。

学習時間の目安は演習を含みます。本文と例題、条件を変える考察、演習の三回に分けて読み進めても構いません。

半円積分路と誤差の評価

R > 0 とし、実軸上を −R から R へ進み、上半円 AR を z = Reⁱᶿ、0 ≤ θ ≤ π で R から −R へ戻ります。内部を左に見るので、合わせた輪郭 ΓR は正向きです。実区間の積分と円弧の積分の和が、留数で求まります。

∫−RRf(x)dx+∫ARf(z)dz=2πi∑a は内部の極Res(f,a)

目標は R → ∞ としたとき、円弧の積分が0に行くことです。一方、通常の実広義積分 ∫₋∞∞ f(x)dx は、例えば0で分けた左側・右側の広義積分がそれぞれ有限に収束するとき、その和と定めます。対称な区間 [−R, R] だけの極限が存在しても、この定義を満たすとは限りません。ここでは絶対値の左右の尾を評価して、両方の収束を先に保証します。

ここで「右側の尾」は R より右に残った積分、「左側の尾」は −R より左に残った積分です。左右それぞれの広義積分で、被積分関数の絶対値を積分しても有限に収まることを絶対収束と呼びます。複素平面で足した円弧の積分と、実軸上にまだ残る二つの尾は、別々に評価します。

二次分母の実積分と単純極

a > 0 とし、f(z) = 1/(z² + a²) を考えます。極は ±ia。R > a とすれば、輪郭上に極はなく、上半円の内部には ia だけがあります。分母の微分は 2z なので、Res(f, ia) = 1/(2ia)。留数定理から輪郭積分は 2πi/(2ia) = π/a です。

円弧の上で分母がどれだけ0から離れるかには、逆三角不等式 |u+v|≥||u|−|v|| を使います。例えば |z|=R なら |z²|=R² なので、|z²+a²|≥R²−a² という共通の下界が得られます。

足した円弧を、具体的な下界で消す

|z| = R では逆三角不等式から |z² + a²| ≥ R² − a² > 0。上半円の長さは πR なので、ML評価により円弧積分の絶対値は πR/(R² − a²) 以下です。分子は R、分母は R² の程度なので、この上界は0へ行きます。

実軸上では分母が正で、関数は全実数で連続です。|x| ≥ 1 で 0 ≤ 1/(x² + a²) ≤ 1/x²。R ≥ 1 に対し、左右それぞれの絶対値の尾は ∫R∞ x⁻² dx = 1/R 以下です。従って通常の広義積分が左右別々に存在し、その和は対称区間の積分の極限にも等しくなります。

∫−∞∞1x2+a2dx=πa,a>0

留数で求めた輪郭積分から円弧の積分を引き、R → ∞ としたのがこの結論です。a > 0 は極の配置を決める条件でもあります。a = 0 では実軸上の0に極ができ、1/x² の実積分も0の近くで発散するため、この証明は使えません。

四次分母の実積分と複数の極

次は f(z) = 1/(1 + z⁴) です。z⁴ = −1 の四つの解は偏角 π/4、3π/4、5π/4、7π/4 の単位円上の点です。上半平面の二つを ζ₁ = (1 + i)/√2、ζ₂ = (−1 + i)/√2 と書きます。R > 1 の上半円の内部にはこの二つだけが入り、どちらも単純極です。

分母の微分は 4z³ なので、留数は 1/(4ζⱼ³) です。ζⱼ⁴ = −1 より 1/ζⱼ³ = −ζⱼ と直せるので、二つの和は簡単になります。

Res(f,ζ1)+Res(f,ζ2)=−ζ1+ζ24=−i22∮ΓR11+z4dz=2πi(−i22)=π2

円弧と実軸の尾を、もう一度別々に確認する

円弧上では |1 + z⁴| ≥ R⁴ − 1 > 0。ML評価により円弧積分の絶対値は πR/(R⁴ − 1) 以下で、0へ行きます。実軸上の被積分関数は連続で非負、|x| ≥ 1 では 1/(1 + x⁴) ≤ 1/x⁴。左右それぞれの尾は ∫R∞ x⁻⁴ dx = 1/(3R³) 以下なので、通常の広義積分として絶対収束します。

従って輪郭積分から円弧を除いて極限を取れます。結論は ∫₋∞∞ dx/(1 + x⁴) = π/√2。四つの留数を全部足すのでなく、選んだ上半円の内部の二つだけを足した点に注意します。

極の種類と輪郭の選択を変える

最初の二次分母では、極が一つ、留数も一つでした。次は「極が増えた」「極が重なった」「中心が動いた」という違いを一つずつ変えます。いずれも、①実軸上の収束、②輪郭と極、③留数、④円弧を消す評価、の四点を省略しません。

例題1：二つの極を足し、実の分解でも確かめる

I=∫₋∞∞ dx/[(x²+1)(x²+4)] を求めます。実軸上に零点はなく、|x|≥1では被積分関数はx⁻⁴以下です。従って左右それぞれの尾は1/(3R³)以下（R≥1）で、通常の広義積分が存在します。

複素関数 f(z)=1/[(z²+1)(z²+4)] を用い、R>2の上半円を選びます。内部の極はiと2iです。因子ごとに単純極の公式を使うと、Res(f,i)=1/[2i·(−1+4)]=1/(6i)、Res(f,2i)=1/[(−4+1)·4i]=−1/(12i)。和は1/(12i)なので閉路積分はπ/6です。

円弧上では |z²+1|≥R²−1、|z²+4|≥R²−4。よって円弧の積分の絶対値は πR/[(R²−1)(R²−4)] 以下で0へ行き、I=π/6を得ます。複素数の係数を途中で実数に直す必要はなく、最後の2πiで純虚数が実数になります。

別解は部分分数です。1/[(x²+1)(x²+4)]=(1/3){1/(x²+1)−1/(x²+4)}。右辺の分子は{(x²+4)−(x²+1)}/3=1なので恒等式を確認できます。既に示した二次分母の積分から (1/3)(π−π/2)=π/6。各広義積分が存在するため、差を取る操作も正当です。

例題2：二重極なら正則部分を一回微分する

J=∫₋∞∞ dx/(x²+1)² を考えます。被積分関数は連続で、|x|≥1でx⁻⁴以下なので絶対収束します。上半円の内部にはiだけがありますが、今回は二重極です。分母の全体を一度微分して割る単純極の公式は使えません。

f(z)=(z−i)⁻²φ(z)、φ(z)=(z+i)⁻² と置きます。φはiの近くで正則で、留数は φ′(i)=−2(2i)⁻³。ここで(2i)³=−8iなので、留数は1/(4i)=−i/4です。従って輪郭積分は2πi/(4i)=π/2。

R>1の円弧上では |(z²+1)²|=|z²+1|²≥(R²−1)² より、円弧の絶対値はπR/(R²−1)²以下で0へ行きます。よってJ=π/2です。実の検算として x=tan θ（−π/2<θ<π/2）と置けば、dx/(1+x²)²=cos²θ dθ。端へ極限を取った積分は [θ/2+sin(2θ)/4] の差π/2となります。

分母を二乗する前の積分πより小さいのも確認できます。全てのxで1/(1+x²)²≤1/(1+x²)で、例えば1<x<2では不等号が厳密です。正の関数の積分としてJ<πとなり、符号や倍率の検算になります。

例題3：平行移動には輪郭の中心も合わせる

a>0、b∈ℝとして K=∫₋∞∞ dx/[(x−b)²+a²] を求めます。w=z−bで見ると極はw=±iaです。原点中心に固執せず、実区間を[b−R,b+R]、円弧をz=b+Reⁱᶿ（0≤θ≤π、R>a）と選ぶと、内部の極b+ia、留数1/(2ia)、円弧上界πR/(R²−a²)が二次分母と全く同じになります。

実軸の右側x≥b+Rではu=x−b≥R、左側x≤b−Rではu=b−x≥Rなので、左右の尾はそれぞれ ∫R∞u⁻²du=1/R 以下です。したがって各片側が別々に収束し、切る中心をbにしても同じ通常の広義積分になります。結論はK=π/aで、bには依存しません。

実の置換u=x−bでも二次分母の結果へ戻れます。例えばa=2,b=3ならK=π/2、極は3±2iです。幅aを二倍にすると面積は半分になりますが、中心bを動かしても面積は変わりません。幅と平行移動は違う役割を持ちます。

円弧積分と広義積分の収束条件

表の O(1/Rᵖ) は、十分大きい R で、値の絶対値が C/Rᵖ 以下になる一つの定数 C を取れるという意味です。C は R によりません。同じ O(1/Rᵖ) でも、円弧と尾の値や上界が等しいという意味ではありません。

同じ半径Rでも、消すべき円弧と片側の尾は別の誤差
関数と半径円弧積分の絶対値の上界片側の尾の絶対値の上界何を保証するか
1/(z²+1)、R=22π/(4−1)=2π/3。1/2。円弧の評価と実軸の尾の評価は別。
同じ関数、R=44π/(16−1)=4π/15。1/4。どちらも一般にはO(1/R)で0へ。
1/(1+z⁴)、R=22π/(16−1)=2π/15。1/(3·2³)=1/24。四次の減衰は両方の上界を小さくする。
同じ関数、R=44π/(256−1)=4π/255。1/(3·4³)=1/192。両方O(1/R³)だが、同じ値ではない。

上段の二次分母はa=1の具体例です。一般の a>0 では円弧上界はπR/(R²−a²)、R>aを使います。円弧を0へ送ることは寄り道を消すため、左右それぞれの尾を抑えることは広義積分の存在のためです。表のR=2,4だけで極限を証明せず、本文の一般の上界が0へ向かうことを使います。対称に切った主値と両片側の収束を混同しないでください。

一般の有理関数でも、分母の次数が分子より2以上大きければ、十分大きい |z| で |f(z)| ≤ C/|z|² と評価できます。理由は、分母の最高次項をくくると括弧が非零の定数へ一様に近づき、分子は定数倍の最高次数で抑えられるからです。このとき大円弧は長さ πR と掛けても0へ行きます。ただし実軸上の極がないことと、輪郭の内部の極の確認は別に必要です。

対照的に 1/z の上半円の積分は、z = Reⁱᶿ を代入すると ∫0π i dθ = iπ で、R によらず残ります。単に f(z) → 0 というだけでは、長くなる円弧の積分を0にはできません。さらに0が実軸上の極なので、実積分の条件も破れます。二次分母と四次分母で得た評価を、別の関数へ無条件に使ってはいけません。

これまでの流れは、平面の幾何から正則性、境界の打ち消し、境界からの値の復元、級数と留数へ進み、最後に実数の計算へ戻るものでした。複素数を使う利点は、答えの形だけでなく、どの情報だけを残せばよいかが見えることにもあります。

円弧を消せることが分かった後は、有限のRでどこまで誤差を抑えられるかも計算できます。例題1の積分π/6を使い、円弧と二つの尾について得た上界を比較します。表を読むときは、どの近似にどの誤差が対応するかを先に決めてください。

全実軸の積分Iと有限区間IRの差を保証するには、二つの尾の和の列を使えます。一方、輪郭の恒等式 IR+∫A_Rf dz=π/6 の円弧を落とす議論には円弧の列を使います。この例では既にI=π/6なので、両者は同じ差を別の方法で抑えています。二列を足す必要はありません。表の数値は実測の誤差ではなく、本文で証明した上界の丸め値です。厳密な許容値の判定には分数の式を使います。

寄り道［接続］：回転・微分方程式・振動・確率の入口

実変数 t と複素定数 λ = α + iβ に対し、y(t) = eλty₀ と置きます。指数関数の微分と実変数の合成関数の微分から y′(t) = λeλty₀ = λy(t)、y(0) = y₀ です。これは y′ = λy の解を実際に確認したもので、一般の微分方程式の理論を前提にしていません。

(u′v′)=(α−ββα)(uv),y=u+iv

eλt = eᵅᵗ(cos βt + i sin βt) なので、時刻 t の写像は倍率 eᵅᵗ の拡大縮小と角度 βt の回転です。実部・虚部に分けた上の2×2行列も、複素数の掛け算そのものです。α = 0 なら大きさを保つ振動 eⁱᵝᵗ になり、振動を組み合わせるFourierの見方へ進めます。この一式だけで一般のFourier展開や積分の交換を正当化したわけではありません。

また a = 1 の実積分から、p(x) = 1/[π(1 + x²)] は非負で全実軸上の積分が1です。従って確率密度の条件を満たす一つのモデルにもなります。平均などが存在するかは別に絶対値の積分を調べる必要があり、正規化だけからすべての統計量が求まるわけではありません。

線形代数・微分方程式・Fourier・統計の既存教材への入口を使えば、それぞれの方向へ進めます。これらの本を先に修了することは、本章の前提ではありません。

演習：実積分と誤差の評価

1．極の高さを変える

∫₋∞∞ dx/(x² + 4) を求め、R > 2 の上半円で円弧積分の絶対値を抑えてください。

ヒント1：a = 2

上半平面の極は 2i で、留数は 1/(4i) です。

ヒント2：円弧上の分母

|z² + 4| ≥ R² − 4 です。

解答

輪郭積分は 2πi/(4i) = π/2。円弧の絶対値は πR/(R² − 4) 以下で0へ行き、左右の実軸の尾もそれぞれ1/R以下なので、通常の広義積分は π/2 です。極が輪郭上に来る R = 2 は選びません。

2．半分の実軸だけを求める

∫₀∞ dx/(1 + x⁴) を求め、上側の二つの留数を足した値との関係を説明してください。

ヒント1：実関数は偶関数

f(−x) = f(x) で、左右の広義積分は絶対収束しています。

ヒント2：輪郭積分が表す区間

上半円輪郭の実軸部分は −R から R で、0からRではありません。

解答

全実軸の積分は π/√2 で、偶関数の左右の積分が等しいので求める値は π/(2√2)。留数の和 −i/(2√2) に 2πi を掛けたものは全実軸の積分です。そこから偶対称性で2で割ります。

3．減衰だけでは足りない

「1/z は大円上で0に近づくので、上半円の積分も0になる」という説明を訂正し、∫₋∞∞ dx/x にこの章の手順を使えない理由も挙げてください。

ヒント1：円弧の長さも増える

MLの上界は (1/R)πR = π で、0ではありません。

ヒント2：パラメータを代入する

(1/z)dz = i dθ なので、上半円の積分を直接計算できます。

解答

円弧の積分は iπ で、R → ∞ でも消えません。また0に実軸上の極があり、実積分は0付近でも無限遠でも左右別々には収束しません。対称な打ち消しを持ち出しても、この章の通常の広義積分の存在は示せません。主値などを論じるには別の定義が必要です。

4．下半円を選んでも同じ実積分になるか

1/(z²+1)について、実軸を−RからRへ進み、下半円でRから−Rへ戻る輪郭（R>1）を選びます。向き・内部の留数・円弧の極限を確認し、実積分を求めてください。

ヒント1

内部は進行方向の右側なので、輪郭は時計回りです。

ヒント2

下の極−iの留数は−1/(2i)。留数定理には−2πiを掛けます。

解答

内部の極は−iだけ。輪郭積分は(−2πi){−1/(2i)}=πです。円弧上の評価πR/(R²−1)は上半円と同じで0へ行きます。左右の実軸の尾は各1/R以下だから、実積分はπです。向きの負号と下側の留数の負号の両方が必要です。

5．正規化と高さから幅を設計する

p(x)=C/[(x−b)²+a²]（a>0,C>0）を自作の線密度モデルとします。全積分を1、最大になる位置をx=3、最大値を1/(2π)にするa,b,Cを求めてください。

ヒント1

最大は分母が最小になるx=bで、値はC/a²です。

ヒント2

全積分Cπ/a=1と最大値C/a²=1/(2π)を連立します。

解答

b=3、正規化からC=a/π。最大値は1/(πa)なのでa=2、C=2/πです。実際p(3)=(2/π)/4=1/(2π)、積分は(2/π)(π/2)=1です。pは非負で実軸上に極もなく、モデルの条件を満たします。

6．実軸に極がなくても失敗する例

f(z)=z/(z²+1) は実軸上で連続で、無限遠で0に近づきます。それでも通常の∫₋∞∞f(x)dxが存在しないことを示し、上半円の円弧積分の極限も求めてください。

ヒント1

実の原始関数は(1/2)log(1+x²)。対称区間の打ち消しと片側の収束は別です。

ヒント2

f(z)=1/z−1/[z(z²+1)]。上半円で第二項の積分の絶対値はπ/(R²−1)以下です。

解答

右片側の積分は(1/2)log(1+R²)→∞、左片側は−∞なので通常の広義積分は存在しません。対称区間では奇関数のため0ですが、それだけでは足りません。円弧では1/zの積分iπが残り、残りの上界π/(R²−1)は0へ行くので極限iπです。実軸上の極の不在もf→0も、それぞれ単独では十分ではありません。

7．二つの許容誤差から半径を選ぶ

例題1の積型分母について、Rを3,5,10から選びます。円弧の上界が0.01未満、かつ左右の尾の和の上界が0.001未満になる候補を全て挙げてください。必要なら3<π<4を使って厳密に判定します。

ヒント1

半径別の表では丸めた値より、分数式を比べます。

ヒント2

R=10の円弧は5π/4752<20/4752、尾は1/1500です。

解答

R=10だけです。20/4752<1/100かつ1/1500<1/1000なので両条件を保証します。R=5では円弧5π/504>15/504>0.01、尾2/375>0.001。R=3も円弧3π/40>9/40>0.01、尾2/81>0.001です。これは示した上界による選択であり、実際の円弧の値が条件を満たすための必要条件を求めたわけではありません。

8．係数を積分から逆算する

実数αに対し qₐ(x)=(αx²+1)/(x²+1)² とします。積分をαの式で求め、全積分がπになるαを決めてください。また全積分0となるαでqₐは非負でしょうか。

ヒント1

x²/(1+x²)²=1/(1+x²)−1/(1+x²)² を使えます。

ヒント2

二つの既知の積分はπとπ/2です。各αで絶対収束も確認します。

解答

|qₐ(x)|≤(|α|+1)/x²（|x|≥1）なので絶対収束します。積分はα(π−π/2)+π/2=π(α+1)/2。πにするにはα=1で、実際q₁=1/(1+x²)です。全積分0はα=−1ですが、q₋₁=(1−x²)/(1+x²)²は|x|>1で負、|x|<1で正です。積分0は関数が0という意味ではなく、非負密度にもなりません。

9．下界として使えない半径を診断する

f(z)=1/[(z²+1)(z²+4)] について「R=3/2なら円弧の上界はπR/[(R²−1)(R²−4)]」という計算を診断してください。その半径の上半円輪郭の積分自体はいくつですか。

ヒント1

R²−4は負です。逆三角不等式から負の数が出ても、逆数の上界には使えません。

ヒント2

R=3/2の内部にはiだけがあり、2iは外部です。

解答

R²−4=−7/4なので、提示された式は負となり絶対値の上界ではありません。|z²+4|≥4−R²=7/4、|z²+1|≥R²−1=5/4 と直すと、この半径での円弧の絶対値は(3π/2)/(35/16)=24π/35以下です。輪郭上には極がなく、内部の留数は1/(6i)だけなので閉路積分はπ/3。R>2のときの閉路積分π/6と区別します。
