留数定理による実積分

∫₋∞∞ dx/(1 + x⁴) は、実数の原始関数だけで計算しようとすると分解が長くなります。複素平面で半円の寄り道を足すと、閉じた経路になり、留数定理が使えます。ただし足した円弧の寄与が最後に0になることと、元の実広義積分が存在することは、自分で確かめる必要があります。

この章では実軸上に極がない二つの有理関数を扱います。前提は実積分の評価、ML評価、留数定理です。振動因子のための特別な補題や、主値という別の積分の定義は使いません。

半円積分路と誤差の評価

R > 0 とし、実軸上を −R から R へ進み、上半円 AR を z = Reⁱᶿ、0 ≤ θ ≤ π で R から −R へ戻ります。内部を左に見るので、合わせた輪郭 ΓR は正向きです。実区間の積分と円弧の積分の和が、留数で求まります。

∫−RRf(x)dx+∫ARf(z)dz=2πi∑a は内部の極Res(f,a)

目標は R → ∞ としたとき、円弧の積分が0に行くことです。一方、通常の実広義積分 ∫₋∞∞ f(x)dx は、例えば0で分けた左側・右側の広義積分がそれぞれ有限に収束するとき、その和と定めます。対称な区間 [−R, R] だけの極限が存在しても、この定義を満たすとは限りません。ここでは絶対値の左右の尾を評価して、両方の収束を先に保証します。

二次分母の実積分と単純極

a > 0 とし、f(z) = 1/(z² + a²) を考えます。極は ±ia。R > a とすれば、輪郭上に極はなく、上半円の内部には ia だけがあります。分母の微分は 2z なので、Res(f, ia) = 1/(2ia)。留数定理から輪郭積分は 2πi/(2ia) = π/a です。

足した円弧を、具体的な下界で消す

|z| = R では逆三角不等式から |z² + a²| ≥ R² − a² > 0。上半円の長さは πR なので、ML評価により円弧積分の絶対値は πR/(R² − a²) 以下です。分子は R、分母は R² の程度なので、この上界は0へ行きます。

実軸上では分母が正で、関数は全実数で連続です。|x| ≥ 1 で 0 ≤ 1/(x² + a²) ≤ 1/x²。R ≥ 1 に対し、左右それぞれの絶対値の尾は ∫R∞ x⁻² dx = 1/R 以下です。従って通常の広義積分が左右別々に存在し、その和は対称区間の積分の極限にも等しくなります。

∫−∞∞1x2+a2dx=πa,a>0

留数で求めた輪郭積分から円弧の積分を引き、R → ∞ としたのがこの結論です。a > 0 は極の配置を決める条件でもあります。a = 0 では実軸上の0に極ができ、1/x² の実積分も0の近くで発散するため、この証明は使えません。

四次分母の実積分と複数の極

次は f(z) = 1/(1 + z⁴) です。z⁴ = −1 の四つの解は偏角 π/4、3π/4、5π/4、7π/4 の単位円上の点です。上半平面の二つを ζ₁ = (1 + i)/√2、ζ₂ = (−1 + i)/√2 と書きます。R > 1 の上半円の内部にはこの二つだけが入り、どちらも単純極です。

分母の微分は 4z³ なので、留数は 1/(4ζⱼ³) です。ζⱼ⁴ = −1 より 1/ζⱼ³ = −ζⱼ と直せるので、二つの和は簡単になります。

円弧と実軸の尾を、もう一度別々に確認する

円弧上では |1 + z⁴| ≥ R⁴ − 1 > 0。ML評価により円弧積分の絶対値は πR/(R⁴ − 1) 以下で、0へ行きます。実軸上の被積分関数は連続で非負、|x| ≥ 1 では 1/(1 + x⁴) ≤ 1/x⁴。左右それぞれの尾は ∫R∞ x⁻⁴ dx = 1/(3R³) 以下なので、通常の広義積分として絶対収束します。

従って輪郭積分から円弧を除いて極限を取れます。結論は ∫₋∞∞ dx/(1 + x⁴) = π/√2。四つの留数を全部足すのでなく、選んだ上半円の内部の二つだけを足した点に注意します。

同じ半径Rでも、消すべき円弧と片側の尾は別の誤差

同じ関数、R=44π/(16−1)=4π/15。1/4。どちらも一般にはO(1/R)で0へ。

同じ関数、R=44π/(256−1)=4π/255。1/(3·4³)=1/192。両方O(1/R³)だが、同じ値ではない。

上段の二次分母はa=1の具体例です。一般の a>0 では円弧上界はπR/(R²−a²)、R>aを使います。円弧を0へ送ることは寄り道を消すため、左右それぞれの尾を抑えることは広義積分の存在のためです。表のR=2,4だけで極限を証明せず、本文の一般の上界が0へ向かうことを使います。対称に切った主値と両片側の収束を混同しないでください。

一般の有理関数でも、分母の次数が分子より2以上大きければ、十分大きい |z| で |f(z)| ≤ C/|z|² と評価できます。理由は、分母の最高次項をくくると括弧が非零の定数へ一様に近づき、分子は定数倍の最高次数で抑えられるからです。このとき大円弧は長さ πR と掛けても0へ行きます。ただし実軸上の極がないことと、輪郭の内部の極の確認は別に必要です。

対照的に 1/z の上半円の積分は、z = Reⁱᶿ を代入すると ∫0π i dθ = iπ で、R によらず残ります。単に f(z) → 0 というだけでは、長くなる円弧の積分を0にはできません。さらに0が実軸上の極なので、実積分の条件も破れます。ここで扱った二例の評価を、別の関数へ無条件に使ってはいけません。

これまでの流れは、平面の幾何から正則性、境界の打ち消し、境界からの値の復元、級数と留数へ進み、最後に実数の計算へ戻るものでした。複素数を使う利点は、答えの形だけでなく、どの情報だけを残せばよいかが見えることにもあります。

寄り道［接続］：回転・微分方程式・振動・確率の入口

実変数 t と複素定数 λ = α + iβ に対し、y(t) = eλty₀ と置きます。指数関数の微分と実変数の合成関数の微分から y′(t) = λeλty₀ = λy(t)、y(0) = y₀ です。これは y′ = λy の解を実際に確認したもので、一般の微分方程式の理論を前提にしていません。

(u′v′)=(α−ββα)(uv),y=u+iv

eλt = eᵅᵗ(cos βt + i sin βt) なので、時刻 t の写像は倍率 eᵅᵗ の拡大縮小と角度 βt の回転です。実部・虚部に分けた上の2×2行列も、複素数の掛け算そのものです。α = 0 なら大きさを保つ振動 eⁱᵝᵗ になり、振動を組み合わせるFourierの見方へ進めます。この一式だけで一般のFourier展開や積分の交換を正当化したわけではありません。

また a = 1 の実積分から、p(x) = 1/[π(1 + x²)] は非負で全実軸上の積分が1です。従って確率密度の条件を満たす一つのモデルにもなります。平均などが存在するかは別に絶対値の積分を調べる必要があり、正規化だけからすべての統計量が求まるわけではありません。

線形代数・微分方程式・Fourier・統計の既存教材への入口を使えば、それぞれの方向へ進めます。これらの本を先に修了することは、本章の前提ではありません。

出典：本章の正規化積分と、複素指数を直接微分した自作の接続例。

演習：実積分と誤差の評価

1．極の高さを変える

∫₋∞∞ dx/(x² + 4) を求め、R > 2 の上半円で円弧積分の絶対値を抑えてください。

ヒント1：a = 2

上半平面の極は 2i で、留数は 1/(4i) です。

ヒント2：円弧上の分母

|z² + 4| ≥ R² − 4 です。

解答

輪郭積分は 2πi/(4i) = π/2。円弧の絶対値は πR/(R² − 4) 以下で0へ行き、左右の実軸の尾もそれぞれ1/R以下なので、通常の広義積分は π/2 です。極が輪郭上に来る R = 2 は選びません。

2．半分の実軸だけを求める

∫₀∞ dx/(1 + x⁴) を求め、上側の二つの留数を足した値との関係を説明してください。

ヒント1：実関数は偶関数

f(−x) = f(x) で、左右の広義積分は絶対収束しています。

ヒント2：輪郭積分が表す区間

上半円輪郭の実軸部分は −R から R で、0からRではありません。

解答

全実軸の積分は π/√2 で、偶関数の左右の積分が等しいので求める値は π/(2√2)。留数の和 −i/(2√2) に 2πi を掛けたものは全実軸の積分です。そこから偶対称性で2で割ります。

3．減衰だけでは足りない

「1/z は大円上で0に近づくので、上半円の積分も0になる」という説明を訂正し、∫₋∞∞ dx/x にこの章の手順を使えない理由も挙げてください。

ヒント1：円弧の長さも増える

MLの上界は (1/R)πR = π で、0ではありません。

ヒント2：パラメータを代入する

(1/z)dz = i dθ なので、上半円の積分を直接計算できます。

解答

円弧の積分は iπ で、R → ∞ でも消えません。また0に実軸上の極があり、実積分は0付近でも無限遠でも左右別々には収束しません。対称な打ち消しを持ち出しても、この章の通常の広義積分の存在は示せません。主値などを論じるには別の定義が必要です。
