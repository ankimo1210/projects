ベクトル場の基本概念

温度のように各点へ一つの数を置く代わりに、向きと大きさを持つ矢印を置くと、流れや力を表す数学のモデルになります。しかし、地図上の矢印、粒子の位置、粒子が描く道は同じものではありません。この違いを保ちながら、三次元で矢印を測る道具を整えます。

復習はベクトルの和と定数倍、行列式と面積、二変数の勾配です。線形代数や常微分方程式の既存教材を先に修了する必要はありません。発展先は学習経路に残しています。

三次元ベクトルの内積と外積

三次元ベクトル a = (a₁, a₂, a₃)、b = (b₁, b₂, b₃) の内積を a·b = a₁b₁ + a₂b₂ + a₃b₃、長さを ‖a‖ = √(a·a) と定めます。a ≠ 0 なら、b の a 方向の符号付き成分は b·a/‖a‖。内積0は直交を表し、向きが逆なら内積は負になります。

面積に向きも持たせたいときは、外積を使います。座標軸 e₁、e₂、e₃ は右手系とし、e₁ × e₂ = e₃ となる向きを採用します。右手の指を a から b へ曲げたときの親指の向きが a × b の向きです。平行な場合の外積は0で、向きは定まりません。

a×b=(a2b3−a3b2,a3b1−a1b3,a1b2−a2b1)

成分式が、垂直と面積を同時に保証する

a·(a × b) を展開すると、a₁a₂b₃ と −a₂a₁b₃ のように六項が二つずつ消えて0になります。b との内積も同様です。また三成分の二乗を足して整理すると、‖a × b‖² = ‖a‖²‖b‖² − (a·b)²。a ≠ 0 のとき、b から a 方向の成分を引いた高さベクトル b⊥ = b − {(a·b)/‖a‖²}a は a と直交し、‖a‖²‖b⊥‖² が同じ右辺です。従って ‖a × b‖ は底辺 ‖a‖ と高さ ‖b⊥‖ の積、つまり平行四辺形の面積です。a = 0 でも両方0です。

スカラー場とベクトル場

領域 U ⊂ ℝ³ の各点 p にベクトル F(p) を対応させる写像 F : U → ℝ³ をベクトル場と呼びます。F(x, y, z) = (P, Q, R) と書き、成分が連続なら連続な場、成分の偏微分が連続なら C¹ の場です。平面の場は二成分で同様に定義し、必要なら第三成分を0にして眺めます。

例えば F(x, y) = (−y, x) の矢印は、各点で原点からの半径に直交します。F(1, 0) = (0, 1) は場所 (1, 0) に立てる矢印であり、その点の位置ベクトル (1, 0) とは別物です。速度場と解釈するモデルでは、粒子の位置 r(t) は r′(t) = F(r(t)) を満たす曲線として別に求めます。この式を満たす道は場に沿う流線にもなりますが、一本の流線から場全体は分かりません。時間に依存する場の粒子軌道と各時刻の流線は、さらに区別が必要です。

勾配場の計算例

開集合 U 上の C¹ 関数 φ(x, y, z) に対し、勾配を ∇φ = (φₓ, φᵧ, φ_z) と定めます。二変数の勾配へ第三成分を加えたものです。全微分と連鎖律により、単位ベクトル u に沿う方向微分は Dᵤφ = ∇φ·u。Cauchy–Schwarz の不等式から |Dᵤφ| ≤ ‖∇φ‖ であり、∇φ ≠ 0 ならその向きで最も速く増えます。

例えば φ = x² + y² + z² なら ∇φ = (2x, 2y, 2z)。半径方向の場になります。しかし、どんな場も勾配とは限りません。回転する場 (−y, x, 0) が勾配でないことは、道に沿う仕事と一周の積分で確かめます。なお、内積0は二つのベクトルが平行という意味ではありません。a = (1, 0, 0)、b = (0, 1, 0) は内積0ですが外積は e₃ です。

寄り道［数学の見方］：地図を一枚足しても、粒子はまだ動かない

同じ場 F(x, y) = (−y, x) に、初期位置 (1, 0) と (2, 0) を入れるモデルを考えます。曲線 (cos t, sin t) と (2cos t, 2sin t) はどちらも r′ = F(r) を満たします。地図は一つでも、初期位置の選び方で道が変わります。

「各点で何が起こるか」という規則と、「どこから始めてどう動くか」という解を分けると、微分方程式への入口が見えます。存在や一意性の一般定理はここでは使っていません。

演習：ベクトル演算と場の区別

1．垂直と面積を同じ計算で

a = (1, 2, 0)、b = (0, 1, 3) の内積と外積を求め、外積の直交性と面積恒等式を確認してください。

ヒント1：外積の順序を保つ

第一成分は 2·3 − 0·1、第二成分は 0·0 − 1·3 です。

ヒント2：二乗長さを比べる

‖a‖² = 5、‖b‖² = 10。外積の二乗長さは成分の二乗の和です。

解答

a·b = 2、a × b = (6, −3, 1)。a との内積は 6 − 6 = 0、b とは −3 + 3 = 0。二乗長さは 36 + 9 + 1 = 46 で、5·10 − 2² = 46 と一致します。平行四辺形の面積は √46 です。

2．場の値と位置の違い

F(x, y, z) = (−y, x, 0)、r(t) = (2cos t, 2sin t, 3) について、r′(t) = F(r(t)) を確認し、t = 0 の位置と場の値を答えてください。

ヒント1：成分ごとに微分する

第三成分の3は定数です。

ヒント2：場に代入する

x と y をそれぞれ 2cos t と 2sin t に替えます。

解答

r′(t) = (−2sin t, 2cos t, 0) = F(r(t))。t = 0 の位置は (2, 0, 3)、場の値は (0, 2, 0) です。位置は点を指定し、場の値はその点からの速度を指定します。

3．三次元の方向微分

φ = xy + z²、p = (1, 2, 1)、u = (1, 0, 1)/√2 とします。勾配と Dᵤφ(p)、最大の方向微分を求めてください。

ヒント1：三つの偏微分

∇φ = (y, x, 2z) です。

ヒント2：u は単位長さ

方向微分は内積、最大値は勾配の長さです。

解答

∇φ(p) = (2, 1, 2)、Dᵤφ(p) = (2 + 2)/√2 = 2√2。‖∇φ(p)‖ = 3 なので最大の方向微分は3、向きは (2, 1, 2)/3 です。φ は多項式で C¹ のため、全微分と方向微分の内積公式を使えます。
