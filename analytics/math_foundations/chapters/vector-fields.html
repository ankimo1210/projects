ベクトル場の基本概念

温度のように各点へ一つの数を置く代わりに、向きと大きさを持つ矢印を置くと、流れや力を表す数学のモデルになります。しかし、地図上の矢印、粒子の位置、粒子が描く道は同じものではありません。この違いを保ちながら、三次元で矢印を測る道具を整えます。

復習はベクトルの和と定数倍、行列式と面積、二変数の勾配です。線形代数や常微分方程式の既存教材を先に修了する必要はありません。発展先は学習経路に残しています。

この章では、矢印を「一つの方向の成分」「面に垂直な成分」「各点での速度」として使い分けます。成分を求める前に、入力が場所なのか時刻なのか、出力に長さや向きをどこまで含めるのかを確かめます。法線の設計、回転の速さ、勾配の単位方向を例題で順に計算します。

学習時間の目安は演習を含みます。本文と例題、条件を変える考察、演習の三回に分けて読み進めても構いません。

三次元ベクトルの内積と外積

三次元ベクトル a = (a₁, a₂, a₃)、b = (b₁, b₂, b₃) の内積を a·b = a₁b₁ + a₂b₂ + a₃b₃、長さを ‖a‖ = √(a·a) と定めます。a ≠ 0 なら、b の a 方向の符号付き成分は b·a/‖a‖。内積0は直交を表し、向きが逆なら内積は負になります。

e₁=(1,0,0)、e₂=(0,1,0)、e₃=(0,0,1) を、それぞれ x,y,z 軸の正方向を向く単位ベクトルとします。「右手系」は、この三方向の向きの約束です。次の外積では、二本の順序も結果の向きに関わります。

面積に向きも持たせたいときは、外積を使います。座標軸 e₁、e₂、e₃ は右手系とし、e₁ × e₂ = e₃ となる向きを採用します。右手の指を a から b へ曲げたときの親指の向きが a × b の向きです。平行な場合の外積は0で、向きは定まりません。

a×b=(a2b3−a3b2,a3b1−a1b3,a1b2−a2b1)

成分式が、垂直と面積を同時に保証する

a·(a × b) を展開すると、a₁a₂b₃ と −a₂a₁b₃ のように六項が二つずつ消えて0になります。b との内積も同様です。また三成分の二乗を足して整理すると、‖a × b‖² = ‖a‖²‖b‖² − (a·b)²。a ≠ 0 のとき、b から a 方向の成分を引いた高さベクトル b⊥ = b − {(a·b)/‖a‖²}a は a と直交し、‖a‖²‖b⊥‖² が同じ右辺です。従って ‖a × b‖ は底辺 ‖a‖ と高さ ‖b⊥‖ の積、つまり平行四辺形の面積です。a = 0 でも両方0です。

外積で面の向きと面積を決める

二本の辺から法線を作るときは、外積の成分式を使う前に辺の順序を決めます。また、外積そのものは面積を含むベクトルであり、単位法線とは長さが違います。

例題1：面積と単位法線を同じ外積から作る

点p=(1,0,0)から出る二辺 a=(1,0,1)、b=(0,2,1) が張る平行四辺形を考えます。位置pは図形を置く場所、a,bは辺の変位です。法線と面積は変位から求めるので、pを外積へ入れません。

a×b=(0·1−1·2, 1·0−1·1, 1·2−0·0)=(−2,−1,2)。長さは√(4+1+4)=3なので面積は3です。aとの内積−2+2=0、bとの内積−2+2=0も確認できます。第三成分が正となる向きを選んだ単位法線は n=(−2,−1,2)/3。三角形の面積なら、この半分の3/2です。

この場所の力をF(p)=(3,1,4)とした自作モデルでは、法線方向の符号付き成分はF(p)·n=(−6−1+8)/3=1/3です。一方、F(p)·(a×b)=1は面積3を含む量です。単位法線で射影を測る場面と、面積を含む向き付き量を測る場面を区別します。

辺の順序をb,aにすれば法線は−n、符号付き成分は−1/3に反転しますが、平行四辺形の面積3は変わりません。法線方向への射影ベクトル (F·n)n も、二つの負号が消えるため同じです。向きを持つ数と、幾何的な成分ベクトルは違う情報を残します。

スカラー場とベクトル場

場所 p に実数を一つ対応させる関数をスカラー場と呼びます。例えば、各点での温度や高さを一つの数として表すモデルです。向きと大きさも出力に含めたいときは、数の代わりにベクトルを対応させます。

領域 U ⊂ ℝ³ の各点 p にベクトル F(p) を対応させる写像 F : U → ℝ³ をベクトル場と呼びます。F(x, y, z) = (P, Q, R) と書き、成分が連続なら連続な場、成分の偏微分が連続なら C¹ の場です。平面の場は二成分で同様に定義し、必要なら第三成分を0にして眺めます。

例えば F(x, y) = (−y, x) の矢印は、各点で原点からの半径に直交します。F(1, 0) = (0, 1) は場所 (1, 0) に立てる矢印であり、その点の位置ベクトル (1, 0) とは別物です。速度場と解釈するモデルでは、粒子の位置 r(t) は r′(t) = F(r(t)) を満たす曲線として別に求めます。この式を満たす道は場に沿う流線にもなりますが、一本の流線から場全体は分かりません。時間に依存する場の粒子軌道と各時刻の流線は、さらに区別が必要です。

速度場と軌道を計算で区別する

例題2：同じ円を描いても、速度場は違う

実数ωを固定し、全平面の場 Fω(x,y)=(−ωy,ωx) を考えます。半径2の曲線 rω(t)=(2cos(ωt),2sin(ωt)) を直接微分すると r′ω=(−2ωsin(ωt),2ωcos(ωt))=Fω(rω(t)) です。全てのtで等式が成立するので、この曲線は初期位置(2,0)からの軌道の一つです。ここでは一般の微分方程式の存在・一意性定理を借りず、候補を代入して確認しています。

速さは2|ω|。ω≠0なら一周に要する最小の正の時間は2π/|ω|です。ω>0なら反時計回り、ω<0なら時計回り。ω=0では位置は(2,0)のままで、円を一周する時間はありません。式の分母に0を入れるのでなく、この場合を別に扱います。

なぜ半径が保たれるのでしょう。任意の微分可能な解r=(x,y)に沿い、d(x²+y²)/dt=2xx′+2yy′=2x(−ωy)+2y(ωx)=0です。従って初期半径から離れないことは、候補を見付ける前にも分かります。ただしこの保存則だけでは一周の速さや向きは決まらず、場の大きさを使う必要があります。

ω=1と3の二行は円という像が同じでも、同じ時刻の位置や速さが違う例です。時刻は共通の単位で、位置と速度は数式の同じ座標尺度を使います。この有限の比較と、本文の全tに対する代入確認を区別して読んでください。

例題3：一本の軌道から場全体を復元できるか

r(t)=(2cos t,2sin t) が観測されたとします。この円上では F(x,y)=(−y,x) が速度と合います。しかし別の場 H(x,y)=(−y,x)+(x²+y²−4)(x,y) も同じ軌道を生みます。円上では x²+y²−4=0 なので、全tで H(r(t))=F(r(t))=r′(t) だからです。

両方とも全平面でC¹ですが、点(1,0)ではF(1,0)=(0,1)、H(1,0)=(−3,1)で違います。原点でも両方0という一致はありますが、場全体の一致にはなりません。一点の検算、一つの円全体での一致、領域全体での一致は、要求する範囲が違います。

この例は軌道が一つ与えられたときの逆問題の限界です。円から離れた場所で何が起きるかは観測していないため、円上で消える項を加える自由度が残ります。一方、特定の場と初期位置から軌道が一意に決まるかという問いは別であり、本章ではその一般定理を証明していません。

勾配場の計算例

開集合 U 上の C¹ 関数 φ(x, y, z) に対し、勾配を ∇φ = (φₓ, φᵧ, φ_z) と定めます。二変数の勾配へ第三成分を加えたものです。全微分と連鎖律により、単位ベクトル u に沿う方向微分は Dᵤφ = ∇φ·u。Cauchy–Schwarz の不等式から |Dᵤφ| ≤ ‖∇φ‖ であり、∇φ ≠ 0 ならその向きで最も速く増えます。

例えば φ = x² + y² + z² なら ∇φ = (2x, 2y, 2z)。半径方向の場になります。しかし、どんな場も勾配とは限りません。回転する場 (−y, x, 0) が勾配でないことは、道に沿う仕事と一周の積分で確かめます。なお、内積0は二つのベクトルが平行という意味ではありません。a = (1, 0, 0)、b = (0, 1, 0) は内積0ですが外積は e₃ です。

勾配による方向の選択と検算

例題4：最も速く増える方向は単位長さで比べる

全空間で φ(x,y,z)=x²+2y²+z² とし、p=(1,1,1)での増え方を比べます。∇φ=(2x,4y,2z)なので∇φ(p)=(2,4,2)、長さは2√6です。単位方向uに対しDᵤφ(p)=(2,4,2)·uであり、最大値2√6は u=(1,2,1)/√6 で達成されます。Cauchy–Schwarzの等号条件からも同じ方向です。

x軸方向e₁ではDₑ₁φ=2。v=(2,−1,0)では∇φ(p)·v=4−4=0なので、単位方向v/√5に沿う一次変化は0です。実際、直線p+hvに代入すると φ(1+2h,1−h,1)=4+6h²。hの一次の項がないことを、偏微分を使わず検算できます。ただしh≠0では値は変わるので、一次変化0はその直線上で一定という意味ではありません。

v=(1,2,1)を長さの調整なしに用い、時刻hでp+hvへ動くと、dφ(p+hv)/dh|h=0=12です。この12は最大方向微分2√6より大きくても矛盾しません。vの速さが√6だからです。単位距離当たりに直すと12/√6=2√6となります。

寄り道［数学の見方］：地図を一枚足しても、粒子はまだ動かない

同じ場 F(x, y) = (−y, x) に、初期位置 (1, 0) と (2, 0) を入れるモデルを考えます。曲線 (cos t, sin t) と (2cos t, 2sin t) はどちらも r′ = F(r) を満たします。地図は一つでも、初期位置の選び方で道が変わります。

「各点で何が起こるか」という規則と、「どこから始めてどう動くか」という解を分けると、微分方程式への入口が見えます。存在や一意性の一般定理はここでは使っていません。

演習：ベクトル演算と場の区別

1．垂直と面積を同じ計算で

a = (1, 2, 0)、b = (0, 1, 3) の内積と外積を求め、外積の直交性と面積恒等式を確認してください。

ヒント1：外積の順序を保つ

第一成分は 2·3 − 0·1、第二成分は 0·0 − 1·3 です。

ヒント2：二乗長さを比べる

‖a‖² = 5、‖b‖² = 10。外積の二乗長さは成分の二乗の和です。

解答

a·b = 2、a × b = (6, −3, 1)。a との内積は 6 − 6 = 0、b とは −3 + 3 = 0。二乗長さは 36 + 9 + 1 = 46 で、5·10 − 2² = 46 と一致します。平行四辺形の面積は √46 です。

2．場の値と位置の違い

F(x, y, z) = (−y, x, 0)、r(t) = (2cos t, 2sin t, 3) について、r′(t) = F(r(t)) を確認し、t = 0 の位置と場の値を答えてください。

ヒント1：成分ごとに微分する

第三成分の3は定数です。

ヒント2：場に代入する

x と y をそれぞれ 2cos t と 2sin t に替えます。

解答

r′(t) = (−2sin t, 2cos t, 0) = F(r(t))。t = 0 の位置は (2, 0, 3)、場の値は (0, 2, 0) です。位置は点を指定し、場の値はその点からの速度を指定します。

3．三次元の方向微分

φ = xy + z²、p = (1, 2, 1)、u = (1, 0, 1)/√2 とします。勾配と Dᵤφ(p)、最大の方向微分を求めてください。

ヒント1：三つの偏微分

∇φ = (y, x, 2z) です。

ヒント2：u は単位長さ

方向微分は内積、最大値は勾配の長さです。

解答

∇φ(p) = (2, 1, 2)、Dᵤφ(p) = (2 + 2)/√2 = 2√2。‖∇φ(p)‖ = 3 なので最大の方向微分は3、向きは (2, 1, 2)/3 です。φ は多項式で C¹ のため、全微分と方向微分の内積公式を使えます。

4．面積を変えない辺の変更

例題1のa=(1,0,1)、b=(0,2,1)について、bをb+λa（λ∈ℝ）に替えます。外積、面積、正のz成分を持つ単位法線はλでどう変わりますか。

ヒント1

外積の成分式から分配則を使い、a×aを調べます。

ヒント2

a×(b+λa)=a×b+λ(a×a)です。

解答

a×a=0なので外積は全てのλで(−2,−1,2)。従って面積3、単位法線(−2,−1,2)/3も変わりません。高さを保ったまま辺の平行成分だけを動かす変更です。λがどんな実数でも外積は非零なので、二辺が平行になる例外はありません。

5．成分条件から一定の場を設計する

全空間で一定の場V=(A,B,C)が、V·e₁=2、V·e₂=−1、V·n=0（n=(1,1,1)/√3）を満たすようにA,B,Cを求めてください。三つの条件にどの演算を使うかも説明してください。

ヒント1

内積は指定した方向の符号付き成分を選びます。

ヒント2

最初の二式からA,Bを決め、三式目A+B+C=0を使います。

解答

A=2、B=−1、C=−1なのでV=(2,−1,−1)です。nは長さ1で、V·n=(2−1−1)/√3=0。nとの直交条件は、法線nを持つ平面にVが沿うことを意味します。外積を使って成分を測る必要はありません。三つの独立な一次条件で一つに決まります。

6．縮みながら回る場を設計する

F(x,y)=(αx−βy,βx+αy)とします。任意の軌道で d(x²+y²)/dt=−2(x²+y²) となり、点(1,0)で速度のy成分が2となるα,βを選んでください。候補r(t)=e⁻ᵗ(cos2t,sin2t)も検算します。

ヒント1

2xx′+2yy′ではβの項が相殺します。

ヒント2

二乗半径の導関数は2α(x²+y²)、(1,0)でのy速度はβです。

解答

α=−1、β=2です。r′=e⁻ᵗ(−cos2t−2sin2t,2cos2t−sin2t)で、F(r)=同じ二成分となります。二乗半径はe⁻²ᵗなので導関数も−2e⁻²ᵗ。αは半径の増減、βは回転を担うことが成分の相殺から分かります。

7．一致する範囲から逆問題を診断する

F=(−y,x)とH=(−y,x)+(x²+y²−4)(x,y)を区別する観測点を、半径1の円から一つ選んでください。また円x²+y²=4上の観測をいくつ増やしても両者を区別できない理由を説明してください。

ヒント1

差H−F=(x²+y²−4)(x,y)を先に計算します。

ヒント2

半径1なら差は−3(x,y)で、円上の点は零ベクトルではありません。

解答

例えば(1,0)でF=(0,1)、H=(−3,1)なので区別できます。実は半径1のどの点でも差は非零です。半径2の円では差が恒等的に0なので、有限点を増やすだけでなく円全体を観測しても二つの場を区別できません。領域全体の復元には別の情報が必要です。

8．場を生むスカラー関数を逆算する

全空間の場G=(2x+y,x+4y,2z)が∇φとなるような多項式φを一つ探し、φ(0,0,0)=5も満たすようにしてください。

ヒント1

φₓをxで積分するとx²+xyに、xに依存しない項を足せます。

ヒント2

yの偏微分がx+4yになるには2y²、zの偏微分にはz²が必要です。

解答

φ=x²+xy+2y²+z²+5です。三つの偏微分を順に取ると(2x+y,x+4y,2z)で、原点の値も5となります。今回は候補を構成し直接確認したので、一般の場が勾配となる条件や一般の積分定理を借りていません。定数項は勾配に現れませんが、指定値で決まります。

9．方向微分の最大値を誤診断しない

あるC¹関数の点pで∇φ(p)=(3,4,0)です。「v=(6,8,0)なら内積50だから、方向微分の最大値は少なくとも50」という説明を訂正し、最大・最小の単位方向と値を求めてください。

ヒント1

vの長さは10です。単位方向の比較か、時間当たりの比較かを分けます。

ヒント2

勾配の長さは5、正負の勾配方向が等号を与えます。

解答

vとの内積50は速さ10で進むp+tvに沿う時刻当たりの変化です。単位方向v/10=(3/5,4/5,0)では50/10=5で、これが最大。逆方向(−3/5,−4/5,0)では−5で最小です。全ての単位uで|∇φ·u|≤5だから、他に大きな値はありません。
