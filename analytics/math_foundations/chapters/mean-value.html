平均変化率と微分係数

微分で分かるのは、一点の近くでの変化率でした。では、区間のどの点でも傾きが正なら、右へ進むほど値が増えると証明できるでしょうか。図では当然に見えても、「各点のごく近く」という情報を「離れた二点の比較」へつなぐ橋が必要です。

その橋が平均値の定理です。区間の両端から計算した平均の変化率が、途中のどこかの微分係数に一致すると述べます。

連続関数の最大値・最小値

証明の土台として、次の補題を使います。上限があることと、その上限の値を取る点があることは別です。例えば開区間 (0, 1) 上の f(x) = x は 1 以下ですが、最大値を取る点はありません。

閉区間上の最大値・最小値定理

a < b とし、実数の閉区間 [a, b] 全体で f が連続なら、f は有界で、最大値と最小値を取る点が [a, b] に存在します。

区間の点列を絞り、極値を得る

まず、閉区間内の任意の点列は、その区間内の点へ収束する部分列を持ちます（Bolzano–Weierstrass の定理）。部分列は、項の順番を保って抜き出した列です。証明には区間を二分し、点列の項が無限個入る半分を繰り返し残します。入れ子区間の定理で共通点 c があり、各区間から添字を増やしながら一項ずつ選べます。選んだ点と c の距離は区間幅以下なので 0 へ近づきます。こうして最小上界性から得た性質を、区間のコンパクト性と呼びます。

もし f が有界でなければ、|f(xₙ)| > n となる点を選べます。収束する部分列 xₙₖ → c を取ると、点列に対する連続性から f(xₙₖ) → f(c) となり、値が無限に大きくなることと矛盾します。したがって有界です。値の最小の上界を M とし、M − 1/n < f(xₙ) ≤ M となる点を選びます。同じ性質で収束部分列を取れば、その極限 c で f(c) = M。最小値は −f に同じ議論を使って得られます。

閉区間という条件は、極限の点が領域の外へ逃げることを防ぎます。連続性という条件は、その点の値へ近くの値を引き継ぎます。どちらも飾りではありません。例えば [0, 1] 上で f(x) = x（x < 1）、f(1) = 0 とすると、定義域は閉区間でも最大値を取りません。

最大値を取るために、どの条件が働くか
定義域と関数閉区間／連続最大値
0 < x < 1、f(x) = x閉区間でない／連続なし。上限1へ近づくだけ
0 ≤ x ≤ 1、f(x) = x閉区間／連続1。x = 1 で達成
0 ≤ x ≤ 1、f(x) = x（x < 1）、f(1) = 0閉区間／1で不連続なし。上限1に届かない

Rolleの定理

Rolle の定理

f が [a, b] で連続、(a, b) で微分可能で、f(a) = f(b) なら、ある c ∈ (a, b) で f′(c) = 0 となります。ここでは a < b です。

極値で左右から傾きを比べる

まず内点 c で最大値を取るとします。十分小さい正の h では f(c + h) − f(c) ≤ 0 なので差の商は 0 以下です。負の h では割る数の符号が変わり、商は 0 以上です。左右から同じ有限の微分係数へ収束するなら、その値は 0 以下かつ 0 以上、つまり 0。最小値の場合も符号を逆にして同じ結論を得ます。

f が定数なら、すべての内点で微分係数は 0 です。定数でなければ、両端の共通の値より大きい値か小さい値を取ります。最大値・最小値定理により、その側の極値は存在し、両端では取れないため内点で取れます。その点に先ほどの議論を使えば証明が終わります。

極値で微分可能なら導関数は 0 ですが、逆は成り立ちません。f(x) = x³ は f′(0) = 0 でも、0 の左では負、右では正で、その点は最大でも最小でもありません。「必要な条件」を「十分な条件」へ入れ替えないようにします。

平均値の定理

平均値の定理

f が [a, b] で連続、(a, b) で微分可能なら、ある c ∈ (a, b) で次の等式が成り立ちます。a < b を仮定します。

f′(c)=f(b)−f(a)b−a

傾いた直線との差を作る

割線の傾きを m = {f(b) − f(a)}/(b − a) とし、g(x) = f(x) − m(x − a) と置きます。g(a) = f(a)、g(b) = f(b) − {f(b) − f(a)} = f(a) なので、両端の値は等しくなります。g は必要な連続性と微分可能性を引き継ぐため、Rolle の定理から g′(c) = f′(c) − m = 0 となる内点が存在します。

例えば f(x) = x² を [0, 2] で考えると、平均の変化率は (4 − 0)/(2 − 0) = 2 です。f′(c) = 2c = 2 となる c = 1 が、実際に区間の内側にあります。ただし定理は一般には点の位置も個数も教えません。「どこかに少なくとも一つ」という存在の主張です。

二枚は横の縮尺が同じですが、g の谷を見やすくするため、縦の縮尺は異なります。高さや傾きの値は各図の目盛りと式で確かめてください。

導関数の符号と関数の増減

区間 I 上で f が連続で、内部で微分可能とします。任意の x < y を I から取ると、[x, y] 全体が I に入るので平均値の定理を使えます。途中の点 c について f(y) − f(x) = f′(c)(y − x)。よって内部で f′ ≥ 0 なら f は単調非減少、f′ > 0 なら厳密に増加します。f′ ≤ 0、f′ < 0 の場合はそれぞれ非増加、厳密な減少です。

特に、内部のすべての点で f′ = 0 なら、任意の二点で値が同じになり、f は定数です。また |f′| ≤ M なら、|f(y) − f(x)| ≤ M|y − x| という変化の上限が得られます。局所的な傾きの上限が、区間全体の誤差保証へ変わりました。

ここで区間という条件を忘れてはいけません。定義域 D = (−2, −1) ∪ (1, 2) 上で、左の部分に f = 0、右の部分に f = 1 を割り当てると、D の全点で微分係数は 0 です。それでも D 全体では定数でありません。左の点から右の点までの閉区間は D に入らず、平均値の定理を使えないからです。

端の連続性も必要です。[0, 1] 上で f(0) = 1、それ以外で f(x) = x とすると、両端の値はともに 1 ですが、内部の導関数はずっと 1 です。Rolle の結論は出ません。また |x| を [−1, 1] で考えると連続性は満たしますが、途中の 0 で微分可能性が欠けます。

寄り道［応用］：二台のカメラから、途中の速度が分かる理由

英国の道路管理機関 National Highways は、離れた入口・出口のカメラで同じ車を記録し、既知の区間距離を所要時間で割って平均速度を計算する仕組みを説明しています。一地点だけの測定と違い、区間全体の移動を使う実例です。

走った道に沿う累積距離を s(t) とし、区間で連続、内部で微分可能なモデルを考えれば、平均値の定理によって、途中のどこかで s′(t) はその平均速度と一致します。例えば平均が時速80 kmなら、そのモデルの途中に時速80 kmの瞬間が必要です。ただし定理は時刻を特定せず、カメラも瞬間の速度を直接撮っているわけではありません。測定の仕組みと、滑らかな運動モデルから数学が付け足す結論を分けると、平均値の意味がはっきりします。

出典：National Highways：Average speed enforcement cameras。

平均値の定理の条件と応用の演習

1．平均の傾きと一致する点

f(x) = x² の区間 [1, 3] で、平均値の定理の点 c を求めてください。

ヒント1：両端の差を取る

平均の変化率は (9 − 1)/(3 − 1) です。

ヒント2：導関数と等しくする

2c が平均の変化率に等しくなる点を探します。

解答

平均の変化率は 4、f′(c) = 2c なので c = 2 です。これは (1, 3) に入ります。多項式は閉区間で連続、内側で微分可能なので、定理の仮定も満たしています。

2．厳密に増えても、導関数は正とは限らない

x³ が実数全体で厳密に増加することを代数で示し、f′ > 0 が厳密な増加の必要条件でないことを説明してください。

ヒント1：二点の差を因数分解する

y³ − x³ = (y − x)(y² + xy + x²) です。

ヒント2：二つ目の因子を平方で書く

y² + xy + x² = (y + x/2)² + 3x²/4 です。

解答

x < y なら y − x > 0。二つ目の因子は 0 以上で、0 になるのは x = y = 0 の場合だけなので、今は正です。よって y³ > x³ で厳密に増加します。一方 f′(0) = 0 です。全点で f′ > 0 なら厳密に増加しますが、厳密な増加から全点での正の導関数は導けません。

3．傾きの上限から値の誤差へ

f が [2, 2.1] で連続、内部で微分可能で、|f′| ≤ 5 とします。|f(2.1) − f(2)| の上限を保証してください。

ヒント1：平均値の定理を書く

差は、ある内点の導関数と区間の幅の積です。

ヒント2：幅の単位を揃える

2.1 − 2 = 0.1 です。

解答

平均値の定理から、ある c ∈ (2, 2.1) で f(2.1) − f(2) = 0.1f′(c)。絶対値を取ると |f(2.1) − f(2)| ≤ 0.1 · 5 = 0.5 です。値そのものは求めていませんが、変化の大きさは保証できました。
