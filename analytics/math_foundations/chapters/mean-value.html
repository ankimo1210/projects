平均変化率と微分係数

微分で分かるのは、一点の近くでの変化率でした。では、区間のどの点でも傾きが正なら、右へ進むほど値が増えると証明できるでしょうか。図では当然に見えても、「各点のごく近く」という情報を「離れた二点の比較」へつなぐ橋が必要です。

その橋が平均値の定理です。区間の両端から計算した平均の変化率が、途中のどこかの微分係数に一致すると述べます。

証明では、まず両端を結ぶ直線の分を引き、両端の高さが等しい関数を作ります。その途中に水平な接線があることを示すため、先に最大・最小を取る点の存在を確かめます。遠回りに見える極値の話が、平均の傾きと途中の傾きをつなぐ土台になります。

学習の目安は演習込み140–200分です。極値とRolle、平均値の定理、誤差と根の保証の三段階に分けても読めます。演習1–3は基本、4–7は適用条件と保証の限界、8–10は関数比較・区間の分割・根の個数の設計です。

連続関数の最大値・最小値

証明の土台として、次の補題を使います。上限があることと、その上限の値を取る点があることは別です。例えば開区間 (0, 1) 上の f(x) = x は 1 以下ですが、最大値を取る点はありません。

証明で使う部分列は、元の数列から、添字 n₁<n₂<… の順に無限個の項を抜き出した数列です。元の順序は変えません。値を上限へ近づける点を次々に選び、その中から閉区間内の一点へ近づく部分列を取り出すと、「値が上限へ近い」から「その値を取る点がある」へ進めます。

閉区間上の最大値・最小値定理

a < b とし、実数の閉区間 [a, b] 全体で f が連続なら、f は有界で、最大値と最小値を取る点が [a, b] に存在します。

区間の点列を絞り、極値を得る

まず、閉区間内の任意の点列は、その区間内の点へ収束する部分列を持ちます（Bolzano–Weierstrass の定理）。部分列は、項の順番を保って抜き出した列です。証明には区間を二分し、点列の項が無限個入る半分を繰り返し残します。入れ子区間の定理で共通点 c があり、各区間から添字を増やしながら一項ずつ選べます。選んだ点と c の距離は区間幅以下なので 0 へ近づきます。こうして最小上界性から得た性質を、区間のコンパクト性と呼びます。

もし f が有界でなければ、|f(xₙ)| > n となる点を選べます。収束する部分列 xₙₖ → c を取ると、点列に対する連続性から f(xₙₖ) → f(c) となり、値が無限に大きくなることと矛盾します。したがって有界です。値の最小の上界を M とし、M − 1/n < f(xₙ) ≤ M となる点を選びます。同じ性質で収束部分列を取れば、その極限 c で f(c) = M。最小値は −f に同じ議論を使って得られます。

閉区間という条件は、極限の点が領域の外へ逃げることを防ぎます。連続性という条件は、その点の値へ近くの値を引き継ぎます。どちらも飾りではありません。例えば [0, 1] 上で f(x) = x（x < 1）、f(1) = 0 とすると、定義域は閉区間でも最大値を取りません。

Rolleの定理

点の十分近くで、その点の値が周囲のどの値以上でもあるとき局所最大、以下なら局所最小と呼び、合わせて極値といいます。例えば f(x)=x² は0の近くで f(x)≥f(0)=0 なので、0で局所最小です。区間全体で最大・最小でなくてもかまいません。微分可能な内点の極値では、左右から見た変化率の符号が両立するため傾きが0になります。

Rolle の定理

f が [a, b] で連続、(a, b) で微分可能で、f(a) = f(b) なら、ある c ∈ (a, b) で f′(c) = 0 となります。ここでは a < b です。

極値で左右から傾きを比べる

まず内点 c で最大値を取るとします。十分小さい正の h では f(c + h) − f(c) ≤ 0 なので差の商は 0 以下です。負の h では割る数の符号が変わり、商は 0 以上です。左右から同じ有限の微分係数へ収束するなら、その値は 0 以下かつ 0 以上、つまり 0。最小値の場合も符号を逆にして同じ結論を得ます。

f が定数なら、すべての内点で微分係数は 0 です。定数でなければ、両端の共通の値より大きい値か小さい値を取ります。最大値・最小値定理により、その側の極値は存在し、両端では取れないため内点で取れます。その点に先ほどの議論を使えば証明が終わります。

極値で微分可能なら導関数は 0 ですが、逆は成り立ちません。f(x) = x³ は f′(0) = 0 でも、0 の左では負、右では正で、その点は最大でも最小でもありません。「必要な条件」を「十分な条件」へ入れ替えないようにします。

平均値の定理

平均値の定理

f が [a, b] で連続、(a, b) で微分可能なら、ある c ∈ (a, b) で次の等式が成り立ちます。a < b を仮定します。

f′(c)=f(b)−f(a)b−a

傾いた直線との差を作る

割線の傾きを m = {f(b) − f(a)}/(b − a) とし、g(x) = f(x) − m(x − a) と置きます。g(a) = f(a)、g(b) = f(b) − {f(b) − f(a)} = f(a) なので、両端の値は等しくなります。g は必要な連続性と微分可能性を引き継ぐため、Rolle の定理から g′(c) = f′(c) − m = 0 となる内点が存在します。

例えば f(x) = x² を [0, 2] で考えると、平均の変化率は (4 − 0)/(2 − 0) = 2 です。f′(c) = 2c = 2 となる c = 1 が、実際に区間の内側にあります。ただし定理は一般には点の位置も個数も教えません。「どこかに少なくとも一つ」という存在の主張です。

二枚は横の縮尺が同じですが、g の谷を見やすくするため、縦の縮尺は異なります。高さや傾きの値は各図の目盛りと式で確かめてください。

割線の傾きと複数の中間点

平均値の定理は「区間の中点で平均の傾きになる」とは言っていません。また、該当する点が一つとは限りません。f(x)=x³を[−1,1]で調べ、割線を引き去る証明の方針も具体的に追ってみましょう。多項式なので閉区間で連続、内部で微分可能です。

例題：補助関数を作り、元の傾きへ戻す

両端の値は−1と1なので、割線の傾きはm=(1−(−1))/(1−(−1))=1です。導関数f′(x)=3x²と等しくする方程式は3c²=1、従ってc=±1/√3。どちらも−1と1の間にあります。中点0ではf′(0)=0なので、平均の傾きにはなりません。

証明の手順ではg(x)=f(x)−m(x−a)=x³−(x+1)を作ると、g(−1)=g(1)=−1となります。定数を足しても導関数は変わらないので、同じ目的にg̃(x)=x³−xを使うこともできます。こちらは両端で0です。どちらもg′(x)=3x²−1となり、Rolleの点±1/√3からf′(c)=1へ戻れます。

なぜ割線の傾きを引くのでしょう。fの両端には高さの差があるため、そのままではRolleの条件f(a)=f(b)がありません。傾き1の直線の分を引くと、両端の差がちょうど消えます。元の関数に水平な接線を探すのでなく、傾き1に対する残りの水平な接線を探したのです。

同じfを[0,1]へ制限すると、平均の傾きは同じ1ですが、内部に入る候補は1/√3だけです。どの点が使えるかは区間にも依存します。一般の証明は少なくとも一点の存在を保証し、具体的な式を解ける場合にだけ、その位置や個数をさらに知ることができます。

導関数の符号と関数の増減

ここでは、x < y なら f(x) ≤ f(y) となることを単調非減少、常に f(x) < f(y) となることを厳密な増加と呼び分けます。非減少は平らな部分を許します。例えば [0,1] 上の f(x)=2 は非減少ですが、異なる入力でも値が等しいため厳密な増加ではありません。導関数の符号を、離れた二点でのこの比較へつなぎましょう。

区間 I 上で f が連続で、内部で微分可能とします。任意の x < y を I から取ると、[x, y] 全体が I に入るので平均値の定理を使えます。途中の点 c について f(y) − f(x) = f′(c)(y − x)。よって内部で f′ ≥ 0 なら f は単調非減少、f′ > 0 なら厳密に増加します。f′ ≤ 0、f′ < 0 の場合はそれぞれ非増加、厳密な減少です。

特に、内部のすべての点で f′ = 0 なら、任意の二点で値が同じになり、f は定数です。また |f′| ≤ M なら、|f(y) − f(x)| ≤ M|y − x| という変化の上限が得られます。局所的な傾きの上限が、区間全体の誤差保証へ変わりました。

ここで区間という条件を忘れてはいけません。定義域 D = (−2, −1) ∪ (1, 2) 上で、左の部分に f = 0、右の部分に f = 1 を割り当てると、D の全点で微分係数は 0 です。それでも D 全体では定数でありません。左の点から右の点までの閉区間は D に入らず、平均値の定理を使えないからです。

端の連続性も必要です。[0, 1] 上で f(0) = 1、それ以外で f(x) = x とすると、両端の値はともに 1 ですが、内部の導関数はずっと 1 です。Rolle の結論は出ません。また |x| を [−1, 1] で考えると連続性は満たしますが、途中の 0 で微分可能性が欠けます。

導関数の区間上界と一次近似の誤差

ある一点の導関数を知ることと、区間全体の変化を数値で保証することは異なります。f′(0)=0という一点の情報だけでは、f(x)=x³が0から1へ変わる量を0に抑えられません。平均値の定理を誤差へ使うには、途中のどのcが選ばれても使える区間上の上界を用意します。

例題：√4.04の変化と一次近似を保証する

f(x)=√xを[4,4.04]で考えます。正の範囲で連続かつ微分可能で、逆関数の微分からf′(x)=1/(2√x)です。区間内では√x≥2なので、0<f′(x)≤1/4。平均値の定理で√4.04−2=0.04f′(c)となるcがあり、0<√4.04−2≤0.01です。従って2<√4.04≤2.01を保証できます。

さらに点4での一次近似2+0.04/4=2.01が、どれくらい正確かを調べます。一般のh>0について4+h≤4.04なら、R(h)=√(4+h)−2−h/4=h(f′(c)−f′(4))です。ここでcは4と4+hの間の点であり、hに応じて変わって構いません。

導関数の差を評価すると、4≤u≤4.04で|f′(u)−f′(4)|=|2−√u|/(4√u)=|u−4|/(4√u(√u+2))≤|u−4|/32です。従って|R(h)|≤h|c−4|/32≤h²/32。h=0.04では|R|≤0.00005で、一次近似2.01はこの誤差以内です。f′(c)≤f′(4)なのでR≤0とも分かり、結局2.00995≤√4.04≤2.01という、単なる変化幅より細かい囲みが得られます。

最初の上界1/4は「元の値2からどれだけ動くか」を保証し、次の導関数の変化の評価は「接線の値2.01からどれだけずれるか」を保証しました。比べる基準が違います。平均値の定理は未知のcを具体的に求めなくても、区間全体で成り立つ評価をそのcに使えることが強みです。

導関数の正の下界と根の位置誤差

関数値が0に近いことを、根の位置が近いことへ変えられるでしょうか。上から傾きを抑えるだけでは逆向きには使えません。関数がほとんど平らなら、大きく離れた点でも関数値が小さくなるからです。ここでは傾きが0から離れているという下からの保証を使います。

例題：関数値の残りから根までの距離を求める

連続性の章で調べたf(x)=x³+x−1は[0,1]に唯一の根cを持ちます。f′(x)=3x²+1≥1なので、近似値m∈[0,1]とcの間に平均値の定理を使うと、f(m)−f(c)=f′(ξ)(m−c)です。m=cなら距離0で自明、それ以外ならξは両点の間の内点です。f(c)=0とf′(ξ)≥1から|m−c|=|f(m)|/f′(ξ)≤|f(m)|が得られます。

例えばm=0.682ならf(m)=0.317214568+0.682−1=−0.000785432なので、位置誤差は0.000785432以下です。厳密な増加も分かっているので、負の値であることからm<cという向きも分かります。

二分法によってc∈[0.5,0.75]まで分かり、mもその中にあるなら、ξも同じ区間に入ります。ここではf′(ξ)≥1+3(0.5)²=7/4なので、|m−c|≤(4/7)|f(m)|と、さらに改善できます。単に根がありそうなことと、根を囲む区間が保証されていることの差が、誤差評価の強さにも現れます。

寄り道［応用］：二台のカメラから、途中の速度が分かる理由

英国の道路管理機関 National Highways は、離れた入口・出口のカメラで同じ車を記録し、既知の区間距離を所要時間で割って平均速度を計算する仕組みを説明しています。一地点だけの測定と違い、区間全体の移動を使う実例です。

走った道に沿う累積距離を s(t) とし、区間で連続、内部で微分可能なモデルを考えれば、平均値の定理によって、途中のどこかで s′(t) はその平均速度と一致します。例えば平均が時速80 kmなら、そのモデルの途中に時速80 kmの瞬間が必要です。ただし定理は時刻を特定せず、カメラも瞬間の速度を直接撮っているわけではありません。測定の仕組みと、滑らかな運動モデルから数学が付け足す結論を分けると、平均値の意味がはっきりします。

出典：National Highways：Average speed enforcement cameras。

平均値の定理の条件と応用の演習

1．平均の傾きと一致する点

f(x) = x² の区間 [1, 3] で、平均値の定理の点 c を求めてください。

ヒント1：両端の差を取る

平均の変化率は (9 − 1)/(3 − 1) です。

ヒント2：導関数と等しくする

2c が平均の変化率に等しくなる点を探します。

解答

平均の変化率は 4、f′(c) = 2c なので c = 2 です。これは (1, 3) に入ります。多項式は閉区間で連続、内側で微分可能なので、定理の仮定も満たしています。

2．厳密に増えても、導関数は正とは限らない

x³ が実数全体で厳密に増加することを代数で示し、f′ > 0 が厳密な増加の必要条件でないことを説明してください。

ヒント1：二点の差を因数分解する

y³ − x³ = (y − x)(y² + xy + x²) です。

ヒント2：二つ目の因子を平方で書く

y² + xy + x² = (y + x/2)² + 3x²/4 です。

解答

x < y なら y − x > 0。二つ目の因子は 0 以上で、0 になるのは x = y = 0 の場合だけなので、今は正です。よって y³ > x³ で厳密に増加します。一方 f′(0) = 0 です。全点で f′ > 0 なら厳密に増加しますが、厳密な増加から全点での正の導関数は導けません。

3．傾きの上限から値の誤差へ

f が [2, 2.1] で連続、内部で微分可能で、|f′| ≤ 5 とします。|f(2.1) − f(2)| の上限を保証してください。

ヒント1：平均値の定理を書く

差は、ある内点の導関数と区間の幅の積です。

ヒント2：幅の単位を揃える

2.1 − 2 = 0.1 です。

解答

平均値の定理から、ある c ∈ (2, 2.1) で f(2.1) − f(2) = 0.1f′(c)。絶対値を取ると |f(2.1) − f(2)| ≤ 0.1 · 5 = 0.5 です。値そのものは求めていませんが、変化の大きさは保証できました。

4．Rolleの点を端点と区別する

f(x)=(x²−1)²を[−1,1]で考えます。Rolleの定理の条件を確認し、f′(c)=0となる内点をすべて求めてください。導関数の方程式で端点が出た場合、定理の点として数えてよいでしょうか。

ヒント1

両端の値は0です。積または連鎖律からf′(x)=4x(x²−1)です。

ヒント2

方程式の解は−1、0、1ですが、条件はc∈(−1,1)です。

解答

多項式なので[−1,1]で連続、(−1,1)で微分可能で、両端はともに0です。f′(c)=4c(c²−1)=0から候補は−1、0、1。内点はc=0だけです。端点も多項式として導関数は0になりますが、Rolleの結論の点には数えません。f(0)=1は区間の最大値で、両端の高さ0から離れた内側の極値に対応します。

5．端点の微分は定理の条件か

①√xを[0,1]、②|x|を[−1,1]、③f(0)=0、0<x≤1でf(x)=1を[0,1]で考えます。平均値の定理の条件をそれぞれ判定し、条件を満たすものは点cを求めてください。満たさないものでは結論も実際に失敗するか確認してください。

ヒント1

必要なのは閉区間での連続性と、開区間での微分可能性です。端点での微分は要求されません。

ヒント2

①平均の傾きは1で、1/(2√c)=1を解きます。②平均は0、③平均は1ですが、それらを取る内点の導関数はありますか。

解答

①は0で片側の差の商が有限でなくても、閉区間で連続、内部で微分可能なので適用できます。c=1/4でf′(c)=1です。②は0で微分できず適用不可。0以外の導関数は±1なので平均の傾き0になる内点はなく、結論も失敗します。③は0で不連続なので適用不可。内部の導関数はすべて0、平均の傾きは1なので結論も失敗します。条件が欠ける場合に常に結論が偽とは限りませんが、この二例では偽だと具体的に確かめました。

6．端点の情報から傾きの上界を逆算する

fが[0,2]で連続、内部で微分可能で、f(0)=1、f(2)=8とします。「全内部点でf′≤3」という条件と両立できますか。全点共通の上界Mを課すなら必要な最小値は何か、実現する関数も一つ作ってください。

ヒント1

平均の傾きは7/2です。定理はこの値を取る内点の存在を保証します。

ヒント2

M≥7/2が必要です。一定の傾きで両端を結ぶ直線なら境界を実現できます。

解答

平均値の定理より、ある内点cでf′(c)=(8−1)/2=7/2です。従ってf′≤3とは両立しません。共通の上界MにはM≥7/2が必要で、f(x)=1+(7/2)xなら全点でf′=7/2、両端の値も指定どおりです。従って実現可能な最小の上界は7/2です。定理を使うと、細かな曲線を知らなくても、許されない変化率の条件を排除できます。

7．関数を小さくすれば根へ近づくか

εは正の実数とし、fε(x)=ε(x−1)を[0,2]で考えます。近似値m=2での関数値の残りと、根cからの位置誤差を求めてください。導関数の下界を用いる誤差保証も計算し、εを小さくするだけで近似位置が改善するか述べてください。

ヒント1

根はc=1、導関数はεです。

ヒント2

誤差の保証は残りを導関数の正の下界で割ります。両方が同じ倍率で変わります。

解答

fε(2)=ε、位置誤差|2−1|=1です。区間全体でfε′=ε>0なので下界ℓ=εを使うと、|m−c|≤|fε(m)|/ℓ=ε/ε=1で、実際の誤差と一致します。εをどれだけ小さくしても根もmも動かないので位置は改善しません。小さい関数値を同じ数の小さい位置誤差と読めない理由を、関数の尺度と導関数の下界が示しています。

8．導関数が近い二つの関数

f、gが[a,b]で連続、内部で微分可能とし、|f′−g′|≤η、|f(a)−g(a)|≤ρを仮定します（η、ρ≥0）。すべてのx∈[a,b]で|f(x)−g(x)|≤ρ+η(x−a)を証明してください。η=ρ=0の場合の意味も述べてください。

ヒント1

二つの関数を別々に評価せず、差F=f−gへ平均値の定理を使います。

ヒント2

|F(x)−F(a)|≤η(x−a)を得たら、三角不等式を使います。

解答

x=aでは仮定そのものです。x>aならF=f−gは[a,x]で連続、内部で微分可能で、|F′|≤η。平均値の定理から|F(x)−F(a)|≤η(x−a)です。従って|F(x)|≤|F(a)|+|F(x)−F(a)|≤ρ+η(x−a)。η=ρ=0ならF(x)=0が全区間で成り立ち、f=gです。例えばf=x²+0.01x+0.02、g=x²を[0,2]で考えるとη=0.01、ρ=0.02で、x=2の差0.04は上界にちょうど達します。

9．微分できない一点で区間を分ける

fは[−1,1]で連続、(−1,0)と(0,1)で微分可能で、それらの点ではf′≥0とします。0で微分できるとは仮定しません。それでも[−1,1]で単調非減少になることを、平均値の定理を使う区間を自分で選んで証明してください。

ヒント1

0をまたぐ二点x<0<yでは、[x,y]全体へ直接は使えません。

ヒント2

[x,0]と[0,y]では、微分できない0はそれぞれ端点です。

解答

同じ側の二点では、その間の閉区間に平均値の定理を使い、f′≥0から値の非減少を得ます。x<0<yなら[x,0]と[0,y]にそれぞれ定理を使えます。端点0で必要な連続性は仮定され、各開区間では微分可能だからです。従ってf(x)≤f(0)≤f(y)。片方が0の場合も同様で、任意の二点を覆います。例えば左でf(x)=x、右でf(x)=2xとする関数は0で角を持ちますが、この条件で単調です。全体へ一度に適用できなくても、分割して結論をつなげられます。

10．定数項から根の個数を設計する

f_q(x)=x³−3x+qの異なる実根の個数を、実数qに応じて分類してください。導関数の符号で区間を分け、各区間の単調性と中間値の定理を組み合わせます。境界q=±2で同じ根を二度数えないようにしてください。

ヒント1

f_q′(x)=3(x²−1)なので、分ける点は−1と1です。

ヒント2

f_q(−1)=q+2、f_q(1)=q−2です。また十分大きいMではf_q(−M)<0<f_q(M)となります。

解答

導関数はx<−1とx>1で正、−1<x<1で負なので、各区間でそれぞれ厳密に増加・減少・増加します。M>|q|+3と取ればM³−3M≥Mで、f_q(−M)<0<f_q(M)も保証できます。

|q|<2ならq+2>0、q−2<0なので、中間値の定理から(−M,−1)、(−1,1)、(1,M)に一つずつ根があり、各区間での単調性からほかにはなく、計3個です。q=2ではf_q=(x−1)²(x+2)で、異なる根は−2と1の2個。q=−2ではf_q=(x+1)²(x−2)で、−1と2の2個です。q>2なら両極値の値が正なので左側の増加区間だけに1個、q<−2なら両極値の値が負なので右側だけに1個。従って|q|>2では1個です。重なった根を異なる二つとして数えず、存在と高々一つの証明を分けています。
