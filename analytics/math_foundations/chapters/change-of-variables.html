変数変換と面積要素

円板の積分を、半径と角度で書けたら便利そうです。しかし x、y を式の中で置き換えるだけでは、面積の数え方が抜け落ちます。角度の同じ一歩でも、中心から遠いほど長い弧を進むからです。

Jacobian 行列は局所的な座標の伸び方を、行列式は面積倍率を表しました。その二つを二重積分につなぎます。一般の変数変換定理は未証明で借りる範囲を明示し、極座標で使う際の原点と継ぎ目も確かめます。

演習を含む学習の目安は120–170分です。線形変換で「領域・密度・面積」を分け、次に極座標の正則な部分、最後に原点・継ぎ目・重複の検査へ進みます。

線形変換と行列式による面積倍率

座標領域 E = [0, 1] × [0, 1] から、T(u, v) = (2u + v, 3v) により平行四辺形 D へ移るとします。Jacobian 行列の二行は (2, 1)、(0, 3)、行列式は 6。u 方向の辺 (2Δu, 0)、v 方向の辺 (Δv, 3Δv) が作るセル面積は、正確に 6ΔuΔv です。

従って変換後の合計の一項は、f(T(u, v)) と 6ΔuΔv の積になります。点の値を替える操作と、面積を替える操作の両方が必要です。この例の倍率は有限のセルにも正確で、非線形写像の局所近似とは違います。

この平行四辺形の公式は、一変数の置換でも確認できる

D は 0 ≤ y ≤ 3、y/3 ≤ x ≤ 2 + y/3 と表せます。連続な f について、単純領域の公式により積分を y 外側で書き、内側に x = 2u + y/3、外側に y = 3v を代入します。一変数の置換積分から、dx = 2du、dy = 3dv の係数が出て、∬Df dA = ∫₀¹∫₀¹6f(2u + v, 3v)du dv です。ここでは三角形の格子や一般の曲線セルの極限について、新たな定理を仮定していません。

f = 1 なら面積は 6。f = x + 2y なら合成した値は 2u + 7v、面積の係数を含めて 6(2u + 7v) を単位正方形で積分し、答えは 27 になります。

二重積分の変数変換定理

有界な領域 E の指示関数（E 内で 1、外で 0）が、囲む矩形上で Riemann 積分可能なとき、E をJordan 可測といいます。面積はその積分です。連続グラフの境界に挟まれた閉領域は、その条件を既に確かめました。

ここで集合 E が閉であるとは、E 内の点列が平面内で収束したとき、その極限も E に入るという意味です。例えば閉矩形はこの性質を持ちます。演算の結果が集合を出ないという前の「演算で閉じている」とは、別の条件です。

未証明で借りる：二重積分の変数変換定理

U ⊂ ℝ² は開集合、T : U → ℝ² は C¹ で単射、すべての q ∈ U で det DT(q) ≠ 0 とします。E ⊂ U は閉かつ有界な Jordan 可測領域、f は T(E) 上で連続とします。このとき T(E) も Jordan 可測で、以下の両辺が積分可能かつ等しいとします。像の可測性と積分可能性も、この借用定理に含めます。

∬T(E)f(x,y)dxdy=∬Ef(T(u,v))|detDT(u,v)|dudv

局所的には T(q + h) ≈ T(q) + DT(q)h なので、行列式の絶対値が微小面積の倍率になる、と理解できます。しかし、この説明だけでは、曲がったセルの面積誤差を全体で抑えること、境界、重なり、像の積分可能性を証明できていません。上の一般定理の完全証明は本章の範囲外です。

絶対値は面積と向きを分けます。例えば T(u, v) = (−u, v) は向きを反転し det DT = −1 ですが、面積を負にはしません。f が負なら積分に負の寄与が出ますが、それは密度の符号であって面積倍率の符号ではありません。

例題：斜めの境界を、座標の辺にする

D={0≤x+y≤2、0≤x−y≤2}上で積分します。斜めの四辺をxやyだけで切ると区間分けが必要ですが、境界に繰り返し現れるx+yとx−yを新しい座標にすれば、二つの範囲を独立に書けそうです。そこでu=x+y、v=x−yと置きます。変数を選ぶ理由は、領域の不等式を単純にすることです。

積分へ代入するのは、新座標から元の座標への写像

uとvを足し引きすると x=(u+v)/2、y=(u−v)/2。従ってT(u,v)=((u+v)/2,(u−v)/2)、座標領域はE=[0,2]×[0,2]です。DT=[[1/2,1/2],[1/2,−1/2]]なのでdet DT=−1/4−1/4=−1/2、面積倍率は1/2です。

逆向きのS(x,y)=(x+y,x−y)の行列式は−2です。これはxy面積をuv面積にする倍率で、今必要なuv面積をxy面積へ戻す倍率とは逆数です。Tは全平面でC¹かつ単射、行列式も非零なので、閉矩形Eに借用定理を使えます。

面積は(1/2)·面積(E)=2。頂点を写すと(0,0)、(1,1)、(2,0)、(1,−1)となり、対角線の長さ2と2を持つ菱形の面積2とも一致します。負の行列式は向きを反転する情報で、面積が負という意味ではありません。

密度の式と面積倍率を、別々に置き換える

f=x+yならf(T(u,v))=uで、∬D(x+y)dA=∫₀²∫₀²u/2 du dv=∫₀²1dv=2。密度の平均は2/面積2=1で、0≤x+y≤2という範囲にも収まります。

f=x²+y²なら合成後は{(u+v)²+(u−v)²}/4=(u²+v²)/2。面積倍率も含めると(u²+v²)/4なので、積分は(1/4){(8/3)·2+2·(8/3)}=8/3です。合成だけして倍率を落とすと16/3、逆向きの倍率2を掛けると32/3となり、正解の2倍、4倍にずれます。

u=v=1なら像は(1,0)、元の密度x²+y²も新しい式(u²+v²)/2も1。点での値の検算と、領域全体の面積の検算を分けると、合成とJacobianのどちらを誤ったか見付けやすくなります。

表の左列で、どちら向きの変換を使っているかを読んでください。行列式の数値を覚えるより、入力側の面積に何を掛ければ出力側の面積になるかを確かめます。

数値はこの線形変換での厳密な倍率です。非線形変換では、各点のDTによる局所倍率を使い、全体の等式は定理に依存します。

例題：向きの反転と、密度の負号を混ぜない

E=[0,2]×[0,1]からT(u,v)=(2−u,v)で移ると、像Dも[0,2]×[0,1]ですが、横方向の並びが反転します。det DT=−1、面積倍率は1です。f=x−2ならD上でf≤0なので、積分も非正になるはずです。

合成はf(T(u,v))=−u。従って∬D(x−2)dA=∫₀¹∫₀²(−u)·1 du dv=−2です。直接にも∫₀¹∫₀²(x−2)dx dy=[x²/2−2x]₀²=−2で一致します。絶対値を外したdet DT=−1を掛けると+2になり、非正の密度なのに正の総量を作ってしまいます。

一変数の置換では、反転した上下端を交換すると別の負号が出ました。ここで借りる二重積分の公式は、領域の面積を非負で数える形です。向きの情報は|det DT|で取り除き、密度fの正負はそのまま残します。これは面積に関する積分の話で、向きを付けた別の積分へ無条件に拡張はしません。

極座標とヤコビアン

極座標は、点を原点からの距離 r と向きの角度 θ の組で表す方法です。r≥0とし、写像Tでその組を普段の座標 (x,y) へ直します。同じ点でも、入力側の二つの数は横と縦の長さではありません。

T(r, θ) = (r cos θ, r sin θ) とします。θ はラジアンで、x の正方向から反時計回りに測ります。DTは入力の小さいずれを二成分の出力のずれへ直す行列、det DTはその行列から計算する一つの数です。面積に掛ける係数は、行列そのものでなく、この行列式の絶対値になります。r、θ による偏微分を列に並べると次の行列です。

DT=[cosθ−rsinθsinθrcosθ],detDT=r(cosθ)2+r(sinθ)2=r

r > 0、角度の幅が 2π 未満の開区間なら T は単射です。同じ像から r = √(x² + y²) が決まり、同じ sin、cos を持つ二つの角度の差は 2π の整数倍なので、この幅では一致します。r > 0 では行列式も非零で、閉じた環状扇形の座標矩形を含む少し大きい開集合に定理を適用できます。

その範囲では dA に対応する係数は r dr dθ です。例えば a ≤ r ≤ b、α ≤ θ ≤ β、0 < a < b、0 < β − α < 2π の環状扇形の面積は、∫αβ∫abr dr dθ = (b² − a²)(β − α)/2 です。

r = 0 では全角度が原点に集まり、行列式は 0。θ と θ + 2π も同じ点です。従って [0, R] × [0, 2π] 全体へ、上の定理をそのまま適用したことにはできません。

例題：円環の四分の一で、範囲と倍率を組み立てる

D={x≥0、y≥0、1≤x²+y²≤4}では、境界が二つの円と二つの半直線です。極座標なら「距離が1から2」「角度が0からπ/2」に分かれ、E=[1,2]×[0,π/2]という矩形になります。x²+y²の上端4を、そのままrの上端4としないことに注意します。

定理の仮定を満たす範囲から計算する

Eを含むU=(1/2,5/2)×(−π/4,3π/4)を取れば、r>0、角度の幅π<2πです。このU上で極座標写像はC¹かつ単射、det DT=r≠0。Eの角度の端0やπ/2もUの内側にあり、原点や一周の継ぎ目の問題はありません。

面積は∫₀^π/2∫₁²r dr dθ=(π/2)[r²/2]₁²=3π/4。密度f=x²+y²なら合成がr²で、倍率rと合わせてr³です。∬Df dA=(π/2)[r⁴/4]₁²=15π/8。平均は(15π/8)/(3π/4)=5/2で、密度の範囲1≤f≤4の間にあります。

さらにf=xなら合成はr cosθで、積分は (∫₀^π/2cosθ dθ)(∫₁²r²dr)=1·7/3=7/3です。θの積分の端点ではsin(π/2)−sin0=1、rでは(8−1)/3。変換後の積分で何を先に積分しても、密度と倍率の両方が入っていることを確認します。

同じ計算で半径0から始めたり角度を一周させたりすると、上のUをそのまま使うことはできません。値を計算できそうな式が出ることと、定理の仮定を満たすことを区別し、次節で除外誤差を扱います。

極座標の原点・継ぎ目と除外誤差

半径 R > 0 の閉円板 B = {x² + y² ≤ R²} と、B 上で連続な f を考えます。B は −R ≤ x ≤ R、−√(R² − x²) ≤ y ≤ √(R² − x²) と書けるので、前章の単純領域の証明により Jordan 可測で f は積分可能です。円の面積の値を先に使ったのではありません。|f| ≤ M となる有限の M も取れます。

二つの細い除外部分を、矩形で覆う

0 < r₀ < R、0 < ε < π/2 とし、E₀ = [r₀, R] × [ε, 2π − ε] を取ります。これを含む開集合 U = (r₀/2, R + 1) × (ε/2, 2π − ε/2) では T は単射、行列式は非零なので、借用定理を正当に適用できます。S₀ = T(E₀) 上では ∬S₀f dA = ∫ε2π−ε∫r₀Rf(r cos θ, r sin θ)r dr dθ です。

円板の原点以外の点は、半径 r > 0 と θ ∈ [0, 2π) で表せます（単位円を一周することの確認）。従って、円板から取り除いた中心部分は正方形 [−r₀, r₀]² に入り、その面積は 4r₀²。正の x 軸付近の継ぎ目は、|θ| ≤ ε と見れば 0 ≤ x ≤ R、|y| ≤ R sin ε ≤ Rε に入るので、面積 2R²ε の矩形で覆えます。sin ε ≤ ε は sin ε = ∫₀ᵋcos t dt ≤ ε からも従います。従って除外部分での積分の絶対値は M(4r₀² + 2R²ε) 以下で、r₀、ε → 0 で消えます。

この比較は、B 上と S₀ 上の f をそれぞれ 0 拡張した、積分可能な二関数の差に対するものです。その差は B から S₀ を除いた部分でのみ非零であり、絶対値を M と被覆矩形の指示関数で抑え、単調性を使います。ここで円の面積 πr₀² を誤差評価の前提にしてはいません。

右辺についても F(r, θ) = f(r cos θ, r sin θ)r は [0, R] × [0, 2π] で連続です。除外した座標領域の積分は、|F| ≤ Mr により、中心の r ∈ [0, r₀] と角度の二つの帯で上から抑えられます。その値は Mπr₀² + Mε(R² − r₀²) ≤ M(πr₀² + εR²) で、やはり 0 へ近づきます。ここに現れた πr₀² は一変数の ∫r dr を計算した結果です。

左右の除外誤差がともに消えるため、円板全体で次の公式を得ます。

∬BfdA=∫02π(∫0Rf(rcosθ,rsinθ)rdr)dθ

f = 1 を入れると面積は ∫02πR²/2 dθ = πR²。f = x² + y² なら合成後は r² ですが、面積係数も掛けて r³ を積分し、∬B(x² + y²)dA = πR⁴/2 です。単位円板の面積平均は (π/2)/π = 1/2 になります。

例題：楕円を円板へ戻し、既に得た公式を組み合わせる

D={x²/9+y²/4≤1}の面積と、f=x²/9+y²/4の積分を求めます。境界に現れるx/3、y/2を座標にすれば単位円板になります。まずx=3u、y=2vという線形写像Sを使い、次に(u,v)の円板で極座標を使います。

一つの公式を無理に適用せず、二段階の根拠をそろえる

S(u,v)=(3u,2v)は全平面で単射、det DS=6です。単位円板Bは前節でJordan可測を確かめてあるので、一般定理をSとBに使えます。楕円の面積は6∬B1du dv=6π。目的関数を合成するとu²+v²なので、積分は6∬B(u²+v²)du dv=6·π/2=3πです。

円板で使った極座標公式は、原点と継ぎ目を除外してから誤差を0に戻す前節の証明に基づきます。「x=3r cosθ、y=2r sinθの行列式が6rだから、閉座標矩形へ直ちに一般定理を使える」と済ませたのではありません。

合成写像の行列式も、直接計算すれば (3cosθ)(2r cosθ)−(−3r sinθ)(2sinθ)=6rです。例えばr=1/2、θ=0なら(x,y)=(3/2,0)、密度は(3/2)²/9=1/4=r²。面積係数は6r=3で、密度1/4とは別の量です。

平均密度は3π/(6π)=1/2。D上の密度の範囲0≤f≤1とも整合します。さらに面積は半径2の円板の4π以上、半径3の円板の9π以下で、6πはその間にあります。包含による粗い見積もりは、変換の倍率を取り違えたときの検算に役立ちます。

極座標の有限セルと面積の実験

r₀ ≤ r ≤ r₀ + Δr、θ₀ ≤ θ ≤ θ₀ + Δθ の座標矩形の積は ΔrΔθ。一方、xy 平面の正確な面積は {(r₀ + Δr)² − r₀²}Δθ/2 = (r₀ + Δr/2)ΔrΔθ です。比は中点半径 r₀ + Δr/2 で、角度を回すだけでは変わりません。r₀ = 0 の扇形も、円板の節と同じ中心除外の極限で公式を得られます。

ここでの扇形面積は近似ではなく、積分から得た厳密な式です。図の描画と数値表示には浮動小数点の丸めがあります。ΔrΔθ は xy 面積そのものではありません。

単射性を欠く変換の多重被覆

この変数変換の議論では det DT=0 となる点を特異点と呼びます。極座標の原点では、この条件が問題になりました。次はそのような点を全て除いても、別々の入力が同じ出力へ重なり得ることを確かめます。

E = ([-1, −1/2] ∪ [1/2, 1]) × [0, 1] 上の T(u, v) = (u², v) を考えます。|det DT| = 2|u| ≥ 1 なので特異点はありません。しかし T(u, v) = T(−u, v) で、単射ではありません。像は [1/4, 1] × [0, 1]、面積は 3/4 なのに、∬E2|u|du dv = 3/2 です。

二つの枝が同じ像を一回ずつ覆い、二重に数えたためです。各枝だけに定理を使えば正しく面積 3/4 となりますが、像が重なるのに両方を足すと二倍です。「行列式が消えない」は局所的な条件で、「一つの像を一回だけ数える」単射性の代わりにはなりません。

寄り道［応用］：円形の画像を、半径と角度の長方形へほどく

OpenCV の warpPolar は画像を極座標や半対数の座標へ再配置します。公式資料では、中心からの距離を出力の横座標へ、角度を縦座標へ尺度変換する式を示しています。また幾何変換全体の説明では、出力画素が参照する入力座標を求め、補間して画素値を得る仕組みを説明しています。

ここからは本章の連続モデルによる比較です。同じ Δr と Δθ の二つのセルを半径 1 と 2 の近くに取れば、面積の一次近似 rΔrΔθ は約二倍違います。極座標画像上の同じ大きさの画素を、元の xy 平面の等面積の画素と読み替えることはできません。

画素値を別の場所で標本化する操作と、面積密度の総量を保存して積分する操作は別です。明るさを再標本化する warpPolar が、全画素の総和へ Jacobian の r を自動的に掛けて保存する、とこの定理から結論はできません。画像の値の意味、補間、画素の面積を決めた上で必要な重みを考えます。

出典：OpenCV：Geometric Image Transformations（Detailed Description・warpPolar）。半径 1、2 のセル比較は本章の自作モデルです。

変数変換と面積倍率の演習

1–3で基本の合成・原点・多重被覆を確認します。4–7では境界に合わせて変数を選び、符号と尺度を検算します。8–10では等面積の変数を設計し、境界の重複・正の面積の重複・特異線の除外を区別してください。

1．平行四辺形へ移る

T(u, v) = (2u + v, 3v)、0 ≤ u, v ≤ 1 の像 D の面積と、∬D(x + 2y)dA を求めてください。

ヒント1：合成した式を求める

x + 2y = 2u + v + 6v = 2u + 7v です。

ヒント2：面積倍率も掛ける

det DT = 2·3 − 1·0 = 6。単位正方形での u、v の積分はどちらも 1/2 です。

解答

DT の行列式は 6 で非零、T は逆写像 v = y/3、u = (x − y/3)/2 を持つので単射です。面積は ∬E6du dv = 6。目的の積分は ∫₀¹∫₀¹6(2u + 7v)du dv = 6(2·1/2 + 7·1/2) = 27 です。係数 6 を落とすと 9/2 となり、面積の違いを数えていない計算になります。

2．単位円板で半径の二乗を集める

単位円板 B 上の x² + y² の積分を極座標で計算し、原点と継ぎ目に定理を直接使わない理由を説明してください。

ヒント1：密度と面積は別の係数

x² + y² = r²、面積係数は r です。

ヒント2：除外してから戻す

まず r ≥ r₀ > 0、ε ≤ θ ≤ 2π − ε の範囲に定理を適用します。

解答

前節の中心・継ぎ目の誤差評価から、円板全体の公式を使えます。∬B(x² + y²)dA = ∫02π∫₀¹r³dr dθ = ∫02π1/4 dθ = π/2。原点では det DT = 0 で全角度が同じ像に集まり、角度 0 と 2π も同じ像なので、閉じた全座標矩形には定理の非零行列式・単射の仮定が成立しません。除外部分の xy 側と座標側の積分誤差を両方 0 へ縮めることで補いました。

3．原点を除いても二重計数は起こる

E = ([-1, −1/2] ∪ [1/2, 1]) × [0, 1]、T(u, v) = (u², v) とします。像の面積と、E 上の |det DT| の積分を比べ、変数変換定理を全体へ適用できない理由を述べてください。

ヒント1：u² の範囲を見る

正負の枝は、どちらも [1/4, 1] に移ります。

ヒント2：枝ごとに積分する

正の枝では ∫1/212u du = 3/4、負の枝も同じです。

解答

像は [1/4, 1] × [0, 1] なので面積 3/4。|det DT| = 2|u| を積分すると、v の幅は 1、正の枝の寄与は [u²]1/21 = 3/4、負の枝の寄与も 3/4、合計 3/2 です。|det DT| ≥ 1 なので原点の特異性は関係しませんが、T(u, v) = T(−u, v) のため単射性を欠きます。各像の点を二回数えており、定理の仮定が満たされません。

4．斜めの境界から変数を選ぶ

D={0≤x+y≤2、0≤x−y≤2}で、面積、∬(x+y)dA、∬(x²+y²)dAを求めてください。逆向きのJacobianを使わないよう、写像の向きを明記してください。

ヒント1

u=x+y、v=x−yとすればE=[0,2]²です。

ヒント2

元の座標へ戻すTはx=(u+v)/2、y=(u−v)/2で、|det DT|=1/2です。

解答

T：uv→xyを使うので面積倍率は1/2です。面積は4·1/2=2。x+y=uなので積分は(1/2)(∫₀²u du)(∫₀²dv)=2です。x²+y²=(u²+v²)/2なので積分は(1/4){(8/3)·2+2·(8/3)}=8/3です。

逆向きS：xy→uvの|det DS|=2を使うと倍率が逆になります。頂点は(0,0),(1,1),(2,0),(1,−1)、面積2とも整合します。

5．負号の出所を診断する

T(u,v)=(2−u,v)、E=[0,2]×[0,1]を使い、像Dでのf=x−2の積分を求めてください。det DTを絶対値なしで掛けた解答が+2になりました。何が誤りですか。

ヒント1

像は同じ矩形ですが、横の向きが反転します。

ヒント2

f(T)=-uは非正です。面積倍率は1です。

解答

det DT=−1、|det DT|=1で、∬Df=∫₀¹∫₀²(−u)du dv=−2。直接にも∫₀²(x−2)dx=−2です。

誤答は面積の向きの負号で密度の負号まで反転させています。D上でf≤0なのに積分が正になる点でも誤りを発見できます。面積は非負で数え、fの符号を保ちます。

6．円環の領域を読み替える

x≥0、y≥0、1≤x²+y²≤4で囲まれたDの面積と∬(x²+y²)dAを極座標で求め、平均値も答えてください。定理を使える開集合も一つ示してください。

ヒント1

rの範囲は1から2、θは0からπ/2です。

ヒント2

r²に面積係数rを掛け、r³を積分します。

解答

U=(1/2,5/2)×(−π/4,3π/4)ならr>0、角度幅π<2πで単射、行列式非零です。面積は(π/2)[r²/2]₁²=3π/4、目的積分は(π/2)[r⁴/4]₁²=15π/8。

平均は5/2で、元の密度の範囲1から4に入ります。r上端を4とするのは、x²+y²=r²という関係を落とした誤りです。

7．楕円へ二段階で移す

D={x²/9+y²/4≤1}で、面積と∬(x²/9+y²/4)dAを求めてください。円板の公式と線形変換の公式を組み合わせ、原点の条件の扱いも説明してください。

ヒント1

x=3u、y=2vで単位円板へ戻ります。

ヒント2

線形変換の面積倍率は6。円板で∬(u²+v²)=π/2でした。

解答

線形写像Sは全平面でC¹・単射・非零行列式6なので、閉円板に一般定理を使えます。面積6π、目的積分6·π/2=3π、平均1/2です。

円板の極座標公式は、本文の原点・継ぎ目の除外誤差を0に戻す証明で得ています。合成写像の行列式6rがr=0で消える事実を無視した直接適用ではありません。r=1/2、θ=0の像で密度1/4も確認できます。

8．等しい座標面積を、等しい実面積にする

円環の四分の一1≤r≤2、0≤θ≤π/2で、半径の代わりにs=r²/2を使います。T(s,θ)=(√(2s)cosθ,√(2s)sinθ)の行列式と座標領域を求め、面積を計算してください。

ヒント1

dr/ds=1/rです。r dr=dsになるようにsを選びました。

ヒント2

二つの列は((cosθ)/r,(sinθ)/r)と(−r sinθ,r cosθ)です。

解答

sの範囲は1/2≤s≤2、角度は0≤θ≤π/2です。行列式はcos²θ+sin²θ=1なので、面積は座標矩形の面積(2−1/2)(π/2)=3π/4です。

s=1/2はr=1、s=2はr=2へ戻り、極座標の∫r drとも一致します。s>0で滑らか・単射な開近傍を取れるため定理の条件も満たします。r=0を含めた滑らかさまでこの計算は保証しません。

9．境界の重複と、領域全体の二重被覆

1≤r≤2について、θを0から2πまで、また0から4πまで動かす二つの座標領域を比較してください。それぞれ∫∫r dr dθと像の面積を求め、角度の端だけの重複と二周の重複の違いを説明してください。

ヒント1

像はどちらも同じ円環です。

ヒント2

円環面積は半径2と1の円板の差から求められます。

解答

像はどちらも面積4π−π=3πの円環です。一周の座標積分は(2π)[r²/2]₁²=3π、二周では(4π)·3/2=6πです。二周ではほとんどすべての像の点を二回数えます。

一周でもθ=0と2πの端が重なるので、借用定理の単射性を閉矩形全体で満たすわけではありません。しかしその継ぎ目を細い角度帯へ閉じ込めて誤差を0にできます。二周の重複は正の面積の領域全体に残り、帯を細くしても消えません。単に「重複は境界だから無視」とは言えません。

10．行列式0の点を除外して戻す

T(u,v)=(u³,v)、E=[−1,1]×[0,1]では、単射なのにdet DTが0になる点があります。像の面積と∬E|det DT|を計算し、定理を直接適用できないことと、除外誤差でこの例の等式を確かめられることを区別してください。

ヒント1

det DT=3u²で、u=0の直線上は0です。

ヒント2

|u|<εを除くと、像からは|x|<ε³の帯を除きます。

解答

像は[−1,1]×[0,1]で面積2。座標積分は∫₀¹∫₋₁¹3u²du dv=[u³]₋₁¹=2です。しかしEを含む全開近傍で行列式非零という定理の仮定は満たしません。

0<ε<1としてu≤−εとu≥εの二矩形へは、各々0を避ける開集合上で定理を使えます。除いた像の帯の面積は2ε³、除いた座標側の積分も∫₋ε^ε3u²du=2ε³で、ともに0へ消えます。等式がこの例で成立することと、仮定を満たさない定理を直接使ってよいことは別です。
