## 本書を貫く 3 原則

1. **確率は長期頻度で定義する** — だから信頼区間は「真値が入る確率」ではない(07 章)
2. **すべての主張はシミュレーションで検算する** — 被覆確率も第 1 種の誤り率も実測する(07・08 章)
3. **モデルは仮定の束であり、診断せずに使わない**(09・10 章)
