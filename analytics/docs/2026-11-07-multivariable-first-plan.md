## 数学の依存と、共通して使う例

点を p = (a, b)、増分を v = (h, k)、r = ‖v‖ = √(h² + k²) と書く。開集合は「各点のまわりに十分小さい円板が丸ごと入る集合」とこの3章内で定義する。微分の定理では点が定義域の内点であることを明記する。

- F(x, y) = xy/(x² + y²)（原点以外）、F(0, 0) = 0。軸では0、y = xでは1/2。偏微分はあるが連続でない。
- G(x, y) = x²y/(x² + y²)（原点以外）、G(0, 0) = 0。|G| ≤ |y| ≤ r で連続。原点の偏微分は両方0だが、全微分はできない。
- P(x, y) = x² + xy + y²。一次式からの正確な余りは h² + hk + k²、絶対値は3r²/2以下。線形近似実験はこの一例に絞る。
- 任意コラムと経路実験の発展例 H(x, y) = x²y/(x⁴ + y²)（原点以外）、H(0, 0) = 0。どの原点を通る直線でも極限0だが、y = x²では1/2。直線だけを全部調べても十分でないことを、式で確かめる。

F→G→Pを再利用し、前の章の結論を次の問いへ使う。関数Gの連続性と、Gの偏導関数の連続性を同じ言葉で済ませない。

## 第1章：距離と、多変数の極限

**問い:** 縦横から同じ値に近づけば、二つの入力を同時に動かしても同じ値になるか。

**節の骨格:** `question` → `distance` → `definition` → `paths` → `estimate` → `exercises` → `reflection`。IDは `multivariable-limits-` を接頭辞とする。

1. 数直線の |x − a| を点どうしの距離 ‖q − p‖へ広げる。‖v‖ = 0 と v = 0 の同値、非負性、伸縮の法則を定義から確認する。
2. 必読部で |h|, |k| ≤ r ≤ |h| + |k| ≤ √2r と |hk| ≤ r²/2 を示す。後二つは (|h| − |k|)² ≥ 0 から得る。三角不等式は (‖u‖‖v‖)² − (u₁v₁ + u₂v₂)² = (u₁v₂ − u₂v₁)² ≥ 0 を展開し、‖u + v‖² ≤ (‖u‖ + ‖v‖)²として証明する。一般の内積理論はまだ使わない。
3. Dの集積点pで lim f(q) = L を「任意の ε &gt; 0 に対し δ &gt; 0 があり、q ∈ D、0 &lt; ‖q − p‖ &lt; δ なら |f(q) − L| &lt; ε」と定義する。集積点とは、任意の正の半径の円板内にp以外のDの点があること。f(p)の定義は極限に不要。連続性ではp ∈ Dとf(p) = Lを要求する。
4. 極限があるなら、pへ近づく各経路・点列でも同じ極限になることを、δ条件の代入から示す。逆向きの「有限本が一致すれば十分」は主張しない。Fの軸と対角線を比較して不存在を証明する。
5. 成功例Gでは |G| ≤ |y| ≤ r なので δ = ε を選べる。経路を列挙せず、円板内の全点を一度に制御することが証明である。

**コラム案:** Hの直線y = mxでは、m ≠ 0なら H(t, mt) = mt/(t² + m²) → 0、m = 0と縦軸でも0。放物線ではH(t, t²) = 1/2。この自己完結した計算を任意の寄り道とし、歴史・現実モデルの事実は追加しない。

|---|---|---|---|
| 1. ∣hk∣ ≤ (h² + k²)/2 と ∣h∣ + ∣k∣ ≤ √2r を示す | 非負の平方を一つ作る | (∣h∣ − ∣k∣)²を展開し、二乗後に比較する | 平方から2∣hk∣ ≤ h² + k²。従って (∣h∣ + ∣k∣)² = r² + 2∣hk∣ ≤ 2r²。両辺非負なので平方根を取る |

## 第2章：偏微分と、全体の連続性

**問い:** 一つずつ入力を動かして得る変化率は、二つを同時に動かしたときの性質まで保証するか。

**節の骨格:** `question` → `definition` → `polynomial` → `counterexample` → `partial-continuity` → `exercises` → `reflection`。IDは `partial-derivatives-` を接頭辞とする。

1. 開集合内の点(a, b)で fₓ(a, b) = limₕ→₀ {f(a + h, b) − f(a, b)}/h、fᵧはもう一方を固定した同様の式と定義する。h = 0の商は未定義で、固定する変数と動かす変数を明記する。
2. Pを定義から展開し、差の商はx側が2a + b + h、y側がa + 2b + k。従ってPₓ = 2x + y、Pᵧ = x + 2y。既知の一変数微分規則でも照合する。
3. Fの軸上の差の商は両方0なので、原点で二つの偏微分は存在する。しかし第1章の経路反例により不連続。軸の制御から円板全体の制御へは移れない。
4. Gは連続で原点の偏微分も0だが、原点以外では Gₓ = 2xy³/(x² + y²)²、Gᵧ = x²(x² − y²)/(x² + y²)²。例えばy = 0、x ≠ 0ではGᵧ = 1なので、Gᵧは原点で連続でない。関数の連続性と偏導関数の連続性を分ける。

**短証明の核:** 偏微分の存在は各座標軸に制限した関数の微分可能性である。Fでは二つの差の商を計算して存在を示し、別経路の値で連続性を否定する。「偏微分可能なら連続」という誤った逆向きの推論を具体的に退ける。

**コラム候補（実例）:** 画像のSobelフィルタで、横と縦の濃淡変化を別々に取り出す例。小さい画素格子と二つの出力を示し、切り口によって見える変化が違うことを本文へ接続する。フィルタの係数・座標の向き・実際の用途は、実装時に公式文書などの一次資料で確認して出典を付ける。今回は調査しない。離散的な差分処理と、極限で定義した偏微分を同一視しない。

## 第3章：全微分・C¹十分条件・連鎖律

**問い:** 二つの入力の変化を、一つの線形写像でまとめて予測できるのはいつか。

**節の骨格:** `question` → `definition` → `necessary` → `c1` → `linear-map-bound` → `chain` → `exercises` → `reflection`。IDは `total-derivative-` を接頭辞とする。

1. 開集合内のpで、線形写像L : R² → Rと余りR(v)があり、f(p + v) = f(p) + L(v) + R(v)、|R(v)|/‖v‖ → 0なら全微分可能と定義する。v = 0では比を定義しない。LをDf(p)と書き、グラフ上の一次式が接平面であることを説明する。
2. 座標軸v = (h, 0)、(0, k)へ代入し、全微分可能なら偏微分がありL(h, k) = fₓ(p)h + fᵧ(p)kと示す。これでLの一意性も分かる。|L(v)| ≤ (|fₓ(p)| + |fᵧ(p)|)‖v‖と余りの条件から、全微分可能なら連続と示す。
3. Gは連続で偏微分も0なので、全微分があるならL = 0。しかしG(t, t) = t/2だから |G(t, t)|/‖(t, t)‖ = 1/(2√2)で、0へ近づかない。従って全微分不可。「連続＋偏微分が存在」でも足りない。
4. **C¹十分条件:** pの開近傍で偏微分が存在し連続なら、fはpで全微分可能。C¹は「一階偏導関数が存在し連続」の略と定義する。必要条件とは主張しない。
5. 証明は増分を横・縦に分解する。f(a + h, b + k) − f(a, b)を、同じ高さb + kでの横の差と、x = aでの縦の差に分け、一変数の平均値の定理を各差へ適用する。係数とfₓ(p)、fᵧ(p)の差は、連続性から共通にη未満。余りはη(|h| + |k|) ≤ √2ηrなので、η = ε/√2で定義を満たす。h = 0またはk = 0の項は0として扱い、退化した区間に平均値の定理を使わない。線分はpを含む十分小さい円板内に収める。
6. ベクトル値写像Φ : U ⊂ R² → R²では、二つの成分の余りをノルムでまとめて同じ定義を使う。DΦは偏微分を並べた2×2行列。行列Aについて ‖Av‖ ≤ C‖v‖はC = 成分の絶対値の総和で直接示せる。作用素ノルムの一般定理は借りない。
7. **連鎖律:** Φがpで全微分可能、g : V ⊂ R² → Rがq = Φ(p)で全微分可能、U・Vは開、Φはp近傍をVへ写すと仮定する。Φ(p + v) = q + Av + r(v)、g(q + w) = g(q) + Bw + s(w)を代入する。線形写像の評価から ‖w‖ ≤ C‖v‖、|Br(v)|/‖v‖ → 0、|s(w)|/‖v‖ → 0となりD(g ∘ Φ)(p) = BAを得る。s(0) = 0と置き、w = 0の場合を割り算から除外せず評価で扱う。行列の積は線形写像の合成として既存章へ戻す。

**コラム候補（実例）:** カメラのレンズ歪み補正で、局所Jacobianが小さい画素格子の変形を表す例。候補モデルはT(x, y) = (x(1 + κr²), y(1 + κr²))、r² = x² + y²とし、κ = 0.1、点(1, 0)ではDT = [[1.3, 0], [0, 1.1]]を自力計算できる。遠くまで同じ行列で補正できるとは主張しない。採用するモデルと実際の用途は、実装時にカメラ校正の公式文書などの一次資料へ照合して出典を付ける。今回は調査せず、実機の校正精度や性能は扱わない。

## 純粋関数APIの決定

新UMDはCommonJSでは `module.exports`、ブラウザでは `globalThis.MathMultivariable` に、次の3関数だけを `Object.freeze` して公開する。DOM・乱数・時刻・可変のモジュール状態を使わず、入力オブジェクトも変更しない。

```text
norm2(point: {x: number, y: number}) -> number

pathState(example: 'axis-trap' | 'curved-trap',
          path: 'x-axis' | 'y-axis' | 'line' | 'parabola',
          t: number, coefficient: number = 1)
 -> {example, path, t, coefficient,
     point: {x, y}, distance: number, value: number, atOrigin: boolean}

quadraticLinearState(base: {x: number, y: number}, delta: {x: number, y: number})
 -> {base, delta, point: {x, y}, baseValue: number,
     coefficients: {x: number, y: number}, linearValue: number, value: number,
     remainder: number, distance: number,
     normalizedError: number | null, errorBound: number}
```

`axis-trap`はF、`curved-trap`はH。経路は順に(t, 0)、(0, t)、(t, ct)、(t, ct²)。原点での値0はこの二つの関数の**定義値**であり、極限値という返り値は作らない。`atOrigin` は点が(0, 0)であるかだけを表す。経路から推測した `limitExists`、全微分可能性を表す真偽値は返さない。

Pの一次式の係数は(2a + b, a + 2b)。`remainder`は表示値二つの減算から求めず、h² + hk + k²を直接計算する。`errorBound`は3‖delta‖²/2、`normalizedError`は距離が正なら |remainder|/distance、距離0では `null`。小さな増分で桁落ちを「誤差が厳密に0」と表示することを避ける。

**エラー契約:** 型違い、欠損座標、NaN、Infinityは `TypeError`。未知のexample/path、有限入力からの数値オーバーフロー、数学的に非零の二乗・経路成分が0へ丸められるアンダーフローは `RangeError`。有限な入力でも全域の機械計算を保証しない。Pの二次量は、非零の平方・値・誤差上限が最小正規化数2^-1022未満の場合もRangeErrorにする。非正規化二次量の桁落ちによる大きな相対精度損失を避けるためで、一般のnormやFの正規化評価にはこの制約を広げない。返り値は浮動小数点近似で、理論上の不等式が機械値の比較では数ulp程度逆転することがある。厳密な上向き丸めの保証は行わない。UI範囲はこれらの極端値を避ける。負の0は出力時に0へ正規化する。

`norm2`は `Math.hypot` を使う。Fの評価はs = max(|x|, |y|)で座標を割ってから uv/(u² + v²) を計算し、原点は別扱いする。Hは(u, v) = (x², y)に同じ比の評価を使うが、非零xの二乗のオーバーフロー/アンダーフローを先に検出する。放物線のct²などが非零入力から0へ丸められる場合も、その場でエラーにする。関数値を0へ置き換えて処理を続けない。

## APIの既知値と境界テスト

浮動小数点値の比較は通常 `|actual − expected| ≤ 10⁻¹² max(1, |expected|)`。0、null、真偽値、列挙値、例外型は厳密に比較する。理論式の代入を同じ実装式で再計算するだけにせず、下記の有理数既知値と照合する。

| テスト名の狙い | 入力 | 期待値 |
|---|---|---|
| normと座標 | (3, 4)、(0, 0)、(10³⁰⁰, 0) | 5、0、10³⁰⁰。単純な二乗和でオーバーフローさせない |
| Fの軸/直線 | x-axis,t = ±1；line,c = 1,t = ±0.5；line,c = −1,t = 0.5 | 0；1/2；−1/2 |
| Hの直線/曲線 | line,c = 1,t = 0.5；parabola,c = 1,t = ±0.5；parabola,c = 2,t = 0.5 | 2/5；1/2；2/5。放物線c = 2の点は(1/2, 1/2) |
| 原点と経路の退化 | 全pathでt = 0；line/parabolaでc = 0 | 原点ではpoint = (0, 0)、value = 0、distance = 0、atOrigin = true。c = 0はx軸になり、t ≠ 0ならatOrigin = false |
| Fの小さい入力 | line,c = 1,t = 10⁻²⁰⁰ | value = 1/2、距離は正。分母の二乗のアンダーフローで誤判定しない |
| Pの具体値 | base = (1, 1)、delta = (0.1, −0.2) | baseValue = 3、coefficients = (3, 3)、linearValue = 2.7、value = 2.73、remainder = 0.03、distance = √0.05、errorBound = 0.075 |
| Pの収束率 | 同じbaseとdeltaをρ = 1, 1/2, 1/4倍 | 余りは0.03, 0.0075, 0.001875。正規化誤差はρ倍、上限はρ²倍 |
| Pの零増分 | 任意の許容base、delta = (0, 0) | value = linearValue = baseValue、remainder = errorBound = 0、normalizedError = null |
| 不正入力 | null、座標欠損、'1'、NaN、Infinity；未知列挙値 | TypeError；未知列挙値はRangeError |
| 数値の表現範囲 | Hのparabolaでt = 10⁻²⁰⁰；Pでdelta = (10⁻²⁰⁰, 0)；Pでbase = (10³⁰⁸, 10³⁰⁸) | RangeError。非零の二乗の消失とオーバーフローを隠さない |
| 入力保全と共存 | freezeしたbase/delta；同一VMで既存3数学JSと新JSを読む | 入力変更なし。既存APIの参照・キー・既知値を維持し、新グローバルだけ追加 |

Pの評価上限は、例えばh, k ∈ {−1, −1/2, 0, 1/2, 1}の格子で0 ≤ remainder ≤ errorBoundと、非零時のnormalizedError ≤ 3distance/2を確認する。極限の証明は格子テストではなく本文の不等式で行う。

## 実験2：線形近似

- ホストは第3章の `<div data-lab="multivariable-linear"></div>` 一つ。関数はPに固定する。基準点a,bは[−1,1]（刻み0.1）、基本増分h,kは[−1,1]（刻み0.05）、拡大率ρは[0,1]（刻み0.01）。実際に評価する増分はρ(h,k)。初期値は(a,b) = (1,1)、(h,k) = (0.1,−0.2)、ρ = 1。

- ρ = 0またはh = k = 0では、現在のnormalizedErrorは「ずれ0のため比は未定義」と表示する。h = k = 0なら第二図には比の曲線を描かず、増分を選ぶ説明を出す。誤差0という分子と、0/0という比を混同しない。
- 数値欄には基準点、実際の増分、一次式の係数、正確値、一次予測、余り、距離、正規化誤差、理論上限を表示する。非零の小さい値を小数点4桁で0に丸めず、|数値| &lt; 10⁻⁴では指数表示に切り替える。
