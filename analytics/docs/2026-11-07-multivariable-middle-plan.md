## 第4章：方向微分と勾配

**動機・問い:** 横と縦の傾きが分かったとして、斜めへ一歩進むとどれだけ増えるか。最も急に増える向きを選べるか。

**節:** `question` → `directional` → `inner-product` → `steepest` → `level-tangent` → `counterexample` → `exercises` → `reflection`。

### 定義と証明の骨格

1. 開集合Uのpと単位ベクトルuについて、両側極限 `Dᵤf(p) = lim(t→0)[f(p+tu)−f(p)]/t` を方向微分と定義する。tは符号付き距離。非単位vでも同様の商は定義できるが、それはパラメータ当たりの変化率であり、単位距離当たりと区別する。境界で片側しか動けない問題はこの定義の定理に含めない。
2. **全微分可能なら**、既存の余り `f(p+tu)=f(p)+tDf(p)u+R(tu)` に代入し、`|R(tu)/t| = |R(tu)|/‖tu‖ → 0` から `Dᵤf(p)=fₓ(p)u₁+fᵧ(p)u₂`。ここで初めて `∇f=(fₓ,fᵧ)` と定義し、内積 `a·b=a₁b₁+a₂b₂` で書き直す。内積という記号だけから公式を仮定しない。
3. `multivariable-limits.html#multivariable-limits-distance` の既証明恒等式 `‖a‖²‖b‖²−(a·b)²=(a₁b₂−a₂b₁)²` を再利用し、`|a·b|≤‖a‖‖b‖` をCauchy–Schwarzと命名する。非零aと単位uなら等号は平行の場合で、内積が正/負になる向きを分ける。
4. ∇f(p)≠0なら、単位uに対して `−‖∇f‖ ≤ Dᵤf ≤ ‖∇f‖`。最大は `u=∇f/‖∇f‖`、最小はその負。∇f=0なら全方向の一次変化率は0で、最急方向は一意に定まらない。極値かどうかはこの章の結論では決めない。
5. 曲線γがt₀の両側で微分可能、γ(t₀)=p、fがpで全微分可能なら `(f∘γ)'(t₀)=∇f(p)·γ'(t₀)`。既存第3章の連鎖律はℝ²→ℝ²→ℝなので、ℝ→ℝ²の場合を無言で済ませず、`γ(t₀+s)=p+sγ'(t₀)+o(|s|)` を余りへ代入して同じ評価を短く示す。γ'=0も割り算せず評価で含める。
6. f∘γが一定なら内積は0。γ'≠0、∇f≠0のとき「等高線の接線と勾配は直交する」。一般の等高線が曲線になる存在定理はまだ主張しない。与えた明示曲線に限って示す。

### 条件と反例

既存の `G(x,y)=x²y/(x²+y²)`（原点0）を再利用する。非零v=(a,b)について `G(tv)/t=a²b/(a²+b²)` なので、全ての方向微分が存在する。それでも座標方向の値0から決まる線形写像と斜めの値は一致せず、原点で全微分できない。単位uでは `DᵤG(0)=u₁²u₂`。これは「全方向の極限をそれぞれ取れる」と「全方向を一つの線形近似で制御できる」の差である。

## 第5章：二階微分、Hessianと極値

**動機・問い:** 接平面が水平でも、谷・山・峠はあり得る。一次の情報が消えたとき、次に何を見るか。

**節:** `question` → `c2` → `mixed-partials` → `taylor` → `stationary` → `classification` → `degenerate` → `exercises` → `reflection`。

### 定義、混合偏微分と二変数Taylor

1. `fₓᵧ=(fₓ)ᵧ`、`fᵧₓ=(fᵧ)ₓ` と順序を明記する。C²は開近傍で一階・二階の偏導関数が存在し連続であること。Hessianは `Hf=[[fₓₓ,fₓᵧ],[fᵧₓ,fᵧᵧ]]` と置く。対称性は定義にせず次で証明する。
2. **C²での混合偏微分交換:** p=(a,b)の周囲の小矩形を開集合内へ収める。矩形差 `Δ=f(a+h,b+k)−f(a+h,b)−f(a,b+k)+f(a,b)` をh,k≠0で割る。補助関数A(x)=f(x,b+k)−f(x,b)の端点差へ平均値の定理を使い、次にfₓのyの差へ同定理を使うと `Δ/(hk)=fₓᵧ(a+θh,b+ηk)`。順序を逆にすると `fᵧₓ(a+θ'h,b+η'k)`。二階偏導関数のpでの連続性から、h,k→0で両方が同じ差商の極限になり等しい。h,kの符号は区間の向きを戻して扱う。片方0の矩形は証明用の差商に使わない。
3. **交換条件が必要な例:** `K=xy(x²−y²)/(x²+y²)`（原点0）。軸上から `Kₓ(0,y)=−y`、`Kᵧ(x,0)=x` なので原点で `Kₓᵧ=−1`、`Kᵧₓ=1`。両者の存在だけで交換できない。原点以外の滑らかさだけでは原点を含むC²の条件にならない。
4. **線分へ一変数Taylorを適用:** pを含む小円板内の増分vを取り `φ(t)=f(p+tv)`。第4章の曲線連鎖律と、C¹なfₓ,fᵧへの同じ規則から `φ'(t)=∇f(p+tv)·v`、`φ''(t)=vᵀHf(p+tv)v`。線分[0,1]の少し外側も定義域に入ることを小円板の選択で保証する。
5. 既存 `taylor.html#taylor-remainder` の **n=1** をφに使うと、ある0<θ<1で `f(p+v)=f(p)+∇f(p)·v+(1/2)vᵀHf(p+θv)v`。n=2を使ってC³を要求しない。v=0は別途等式として処理する。
6. Hの全成分のpでの連続性を使い、各差をη以下にそろえると `|vᵀ(Hf(p+θv)−Hf(p))v| ≤ η(|h|+|k|)² ≤ 2η‖v‖²`。従って `f(p+v)=f(p)+∇f(p)·v+(1/2)vᵀHf(p)v+o(‖v‖²)`。θがvによって変わっても‖θv‖≤‖v‖なので、全方向で同じδが使える。この評価まで示し、各固定方向だけの展開で済ませない。

### 極値の必要条件と十分条件

- 局所最小/最大と厳密な局所最小/最大を近傍内の不等式で定義する。停留点は∇f=0。内点の局所極値では、座標方向の一変数Fermatの議論（左右差商の符号）から∇f=0。境界の極値には適用しない。
- C²の局所最小では、任意vに対して線上の二次展開を用い、`vᵀHv≥0` が必要。最大では≤0。半正定値だけで極値を保証しない。
- Hを `[[A,B],[B,C]]`、D=AC−B²と書く。停留点でD>0かつA>0なら厳密局所最小、D>0かつA<0なら厳密局所最大、D<0なら鞍点。D=0はこの判定では結論しない。鞍点は任意の近傍にf(p)より高い点と低い点があること。
- 正定値の保証を固有値の借用で済ませず、`vᵀHv=A(h+(B/A)k)²+(D/A)k²` と平方完成する。s=h+(B/A)kなら `h²+k²≤2s²+(1+2B²/A²)k²`。従ってA>0,D>0で `vᵀHv≥m‖v‖²`、`m=min(A/2,(D/A)/(1+2B²/A²))>0`。Taylorの余りをm‖v‖²/4以下に取り、主項1/2との比較で厳密最小を証明する。最大は−fで同じ。
- D<0では二次形式が正負を取る方向を示す。A≠0なら(1,0)でA、(−B/A,1)でD/Aとなり異符号。A=0ならB≠0で、(1,t)の値2Bt+Ct²は小さい正負tで異符号。各固定方向で二次主項が余りを支配するため、実際の関数も上下に分かれる。
- 退化例 `x⁴+y⁴`、`−x⁴−y⁴`、`x⁴−y⁴` は全て原点の勾配・Hessianが0だが、順に厳密最小・厳密最大・鞍点。水平という情報やHessian=0を「平坦で値一定」と読まない。

|---|---|---|---|
| 1. f=x²+xy+y²+x³の原点で二次近似と正確な余りを求め、厳密局所最小を保証する半径を一つ示す | 勾配とHessianを求める | 二次項をr²/2以上、三次の絶対値をr³以下にする | ∇f(0)=0、H=[[2,1],[1,2]]、近似h²+hk+k²、余りh³。∣hk∣≤r²/2よりf≥r²/2−r³>0（0<r<1/2）。半径1/2の開円板で厳密最小 |

## 第6章：制約とLagrangeの乗数

**動機・問い:** 平面全体ではなく、円周などの決められた道だけを動けるとき、最適点の勾配はどちらを向くか。

**節:** `question` → `regular-curve` → `tangent-necessary` → `multiplier` → `level-set-borrow` → `candidates` → `failures` → `exercises` → `reflection`。

### まず明示的な正則曲線で証明する

1. 開区間I上のC¹曲線 `γ:I→ℝ²`、t₀∈I、γ(t₀)=p、γ'(t₀)≠0を、その点での正則なパラメータ曲線と定義する。円周 `γ(t)=(cos t,sin t)` はγ'=(-sin t,cos t)で常に長さ1。始点・終点だけの片側極値をこの必要条件へ混ぜない。
2. fがpで全微分可能で、pがγ上で局所最大/最小なら、合成の一変数局所極値から `(f∘γ)'(t₀)=∇f(p)·γ'(t₀)=0`。第4章で示した曲線連鎖律を使う。これは最初に本文内で証明する必要条件。
3. さらにgがpで全微分可能、曲線上でg∘γ=c、`n=∇g(p)≠0` と仮定する。同じ連鎖律でn·γ'=0。二成分の代数からnに直交する非零ベクトルは `α(−n₂,n₁)`（α≠0）なので、γ'に直交する∇fはnの実数倍。従って `∇f(p)=λ∇g(p)`。例えば `λ=(∇f·n)/‖n‖²`。∇f=0でもλ=0として成立し、∇fで割らない。
4. この段階では「与えた正則曲線に沿う必要条件を証明済み」と表示する。∇g≠0という値だけから、未証明のまま曲線の存在を導かない。

### 一般の正則レベル集合で使うときの借用

**未証明で借りる定理はこれ一つ:** gがp近傍でC¹、g(p)=c、gᵧ(p)≠0なら、p近傍のレベル集合g=cはC¹関数y=ψ(x)のグラフとして表せる（陰関数定理の二変数・一方程式の場合）。そのグラフの曲線γ(x)=(x,ψ(x))は正則。gₓ(p)≠0ならx,yを交換する。陰関数定理の存在・一意性・C¹性の完全証明は本章では行わないと明記する。

この借用と上の証明を合わせれば、f,gが近傍でC¹、pがg=c上の局所極値、∇g(p)≠0ならLagrangeの必要条件が成立する。陰関数定理によって一般レベル集合へ拡張した部分と、明示曲線に沿って直接証明した部分を別の囲みにする。円周の主例・全演習は明示表示や直接不等式で検算でき、借用を使わなくても読める。

### 候補から最大・最小へ進むときの条件

- 主例は `f=x+2y`、`g=x²+y²=1`。方程式 `(1,2)=λ(2x,2y)` と制約からλ≠0、p=±(1,2)/√5、λ=±√5/2。候補の値は±√5。
- これが全体の最大・最小である保証は、別に `|x+2y|≤√5√(x²+y²)=√5` と等号成立から与える。方程式を解いただけで保証したことにしない。一般のコンパクト集合上の最大最小定理を新たに借りなくても、この例では達成点を直接示せる。
- **正則性を落とす反例:** 制約x²+y²=0は原点だけ。f=xは制約上で最大かつ最小だが∇f=(1,0)、∇g=0で乗数方程式は成立しない。パラメータ曲線の速度も非零にはできない。
- **必要条件は十分でない反例:** 円周上のf=x³は(0,±1)で∇f=0、λ=0で方程式を満たす。しかし近くに正負のxがあり、x³も正負を取るので極値でない。円周が正則でも候補が全て極値とは限らない。
- **存在を保証しない例:** g=y=0上のf=xは、正則な無限直線でも上にも下にも無界で最大・最小を持たない。不等式制約や曲線の端点は別の候補検査が必要で、本章の定理だけで処理しない。

| 演習（完全な出題） | ヒント1 | ヒント2 | 検算済み解答の核 |
|---|---|---|---|
| 1. 円周x²+y²=1上でx+2yの乗数方程式を解き、全体の最大・最小を別に保証する | ∇gは円周上で非零 | x=1/(2λ)、y=1/λを制約に戻す | λ²=5/4。p=±(1,2)/√5、値±√5、λ=±√5/2。Cauchy–Schwarzにより全円周の値がこの間に入り、両端を達成する |
| 2. 同じ円周上でxyの全候補、λ、最大・最小を求める | (y,x)=2λ(x,y)を両式で使う | 候補の比較に加えて2∣xy∣≤x²+y²を使う | 軸上では方程式が矛盾。4λ²=1。λ=1/2でx=y=±1/√2、値1/2。λ=−1/2でx=−y=±1/√2、値−1/2。∣xy∣≤1/2が全体保証 |
| 3. 制約x²+y²=0、目的f=xに乗数法を使えるか説明する | 制約集合を先に決める | 原点で二つの勾配を比較する | 実行可能点は原点だけなので最大値=最小値=0。∇g=0で正則性を欠き、(1,0)=λ(0,0)を満たすλはない。極値の不存在を意味せず定理の仮定が不足 |

**振り返り3問:** ①制約の上の極値で勾配同士が平行になるのは、どの接線との直交からか。②明示曲線で証明した部分と陰関数定理から借りた部分はどこか。③候補を見つけた後、最大・最小だと保証するには何を別に確かめるか。

**実例コラム候補:** 有限の発電機へ総需要を配分する経済負荷配分で、等式制約下の内部最適点の限界費用が等しくなる例。仮想の2台 `C₁(p₁)=p₁²`、`C₂(p₂)=2p₂²`、`p₁+p₂=3` では2p₁=4p₂、(p₁,p₂)=(2,1)、総費用6。代入すると `C₁(3−p₂)+C₂(p₂)=6+3(p₂−1)²` で最小も直接保証できる。採用時は系統運用機関等の一次資料で「限界費用均等」の利用条件を確認し、出典を付ける。今回はweb調査しない。現実の容量上下限・損失・起動費等はこの単純モデルに含めないと明記する。

## 3実験の純粋API

新しい `assets/multivariable-middle.js` はCommonJSの `module.exports` とブラウザの `globalThis.MathMultivariableMiddle` に、次の3関数だけを `Object.freeze` して公開する。DOM・時刻・乱数・可変のモジュール状態は使わず、入力を変更しない。P=x²+xy+y²を再利用するが、既存APIの内部実装に結合しない。

```text
gradientCompassState(base: {x:number,y:number}, angleRad:number)
 -> {base:{x,y}, angleRad, direction:{x,y}, gradient:{x,y},
     slope:number, maxSlope:number, minSlope:number,
     steepest:{x,y}|null}

curvatureState(example:'bowl'|'saddle'|'flat-min'|'flat-saddle',
               angleRad:number, t:number)
 -> {example, angleRad, t, direction:{x,y}, point:{x,y},
     value:number, quadraticValue:number, remainder:number,
     directionalSecond:number,
     hessian:{xx:number,xy:number,yy:number},
     hessianVerdict:'strict-min'|'saddle'|'inconclusive'}

circleConstraintState(angleRad:number)
 -> {angleRad, point:{x,y}, tangent:{x,y}, value:number,
     tangentRate:number, objectiveGradient:{x,y},
     constraintGradient:{x,y}, lambdaProjection:number,
     normalResidual:{x,y}}
```

### 数式と入力契約

- 3関数ともangleRad∈[−π,π]、`u=(cos angleRad,sin angleRad)`。端点は同じ向きだが、渡された角度は保存する。内部単位はrad、UI表示・入力は度（整数[−180,180]）で、呼び出し前にπ/180を掛ける。未知の型、欠損、NaN/InfinityはTypeError、未知の列挙文字列や範囲外の有限値はRangeError。
- compassのbaseは各成分[−1,1]、UI刻み0.1。gradient=(2a+b,a+2b)、slope=gradient·u、maxSlope=‖gradient‖、minSlope=−maxSlope。gradient=(0,0)ならsteepest=null、slope=0。非零ならgradient/maxSlope。全微分可能性はこの固定多項式について本文で保証済みであり、任意関数に対する判定APIは作らない。
- curvatureはt∈[−1,1]、UI刻み0.01。基準点は原点に固定する。bowl=P、saddle=x²−y²、flat-min=x⁴+y⁴、flat-saddle=x⁴−y⁴。Hは順に(2,1,2)、(2,0,−2)、(0,0,0)、(0,0,0)。directionalSecond=uᵀHu、quadraticValue=(1/2)t² directionalSecond。bowl/saddleのremainderは恒等的0を返す。quarticのquadraticValue=0、remainder=value。hessianVerdictは順にstrict-min/saddle/inconclusive/inconclusiveであり、高次項から分かる実際の形とは分ける。
- constraintは目的f=x+2y、制約g=x²+y²=1に固定。point=(cosθ,sinθ)、tangent=(−sinθ,cosθ)は弧長当たりの単位接線。value=x+2y、tangentRate=−y+2x。objectiveGradient=(1,2)、constraintGradient=(2x,2y)。`lambdaProjection=(∇f·∇g)/‖∇g‖²`、`normalResidual=∇f−lambdaProjection∇g`。任意角度での射影係数を、最適点を意味する「解のλ」と呼ばない。circleではnormalResidual=tangentRate*tangentとなり、極値で0になることを数値と本文で確認する。
- 負の0は返り値で0にそろえる。sin/cosの丸めで理論上0の値が微小になることは、テストで絶対誤差10⁻¹²を許す。APIはゼロ近傍を一律0に切り詰めない。表示側のみ∣値∣≤10⁻¹²を「約0」とし、数学的な等号や極値判定を生成しない。
- 上記の有限範囲とUI刻みを実験のサポート範囲とする。端点の隣の範囲外は拒否する。サブノーマル数や巨大入力を受け入れるための特殊な再スケール・アンダーフロー分岐は追加しない。UI範囲内の通常浮動小数点計算の近似であり、任意の極小値の相対精度は保証しない。
