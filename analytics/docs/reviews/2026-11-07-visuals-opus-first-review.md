## 数学的な欠陥
**重要：表の見出し（th）で数式の記号が大文字に変わる**
- 症状：
  - `…\chapters\observation.html:20` の表で、a(n) = n² が **A(N) = N²**、b(n) が B(N)、「規則 / n」が「規則 / N」と表示されます。
  - `…\chapters\invariants.html:113` の表で、「組 (a, b)」が **組 (A, B)** になります。
  - 本文の定義（observation L9、invariants L104）は小文字なので、表と本文が食い違って見えます。
- 原因：
  - ビルドで全ページに埋め込まれる report 既定の CSS に、`th{font-family:var(--mono);text-transform:uppercase;letter-spacing:.04em}`、`caption{font-family:var(--mono)}`、`th,td{white-space:nowrap}` があります。
  - `…\assets\style.css:40–43` の `.concept-table` は、これらを打ち消していません。
- 確認方法：現在の原稿をスクラッチにビルドし、Linux の画面で確認しました。
- 修正案（root が持つ CSS）：
  - `.concept-table th,.concept-table caption{font-family:inherit;text-transform:none;letter-spacing:normal;font-size:inherit}`
  - `.concept-table th,.concept-table td{white-space:normal}`

**軽微：`…\chapters\determinants.html:43` の「像は線分」**
- 像（im）は次元の章で「写像の出力全体」と定義されており、この行列の像は横軸全体（直線）です。
- 修正案：「**単位正方形の**像は線分」。
