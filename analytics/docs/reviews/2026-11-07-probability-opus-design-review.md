### 重要

1. **弱大数を「証明」とする範囲が広すぎる**（L26、L28）
   - この教科書の道具だけで完全に証明できるのは、有限個の値を取る iid です（n 回の試行を有限の積モデルとして作れるため）。
   - 「有限分散」の一般形では、2つ以上の変数の期待値の線形性と、独立な変数の和の分散が必要になります。連続の場合はさらに同時密度が要りますが、第9章は有限の同時表しか扱いません。
   - 修正案：定理の仮定を「有限個の値を取る iid」として証明する。一般形は「借用した性質の上で同じ議論」と明記する。第9章に n 個の変数の独立を入れ、和の分散には「どの2つも無相関」で足りることも示す。

2. **可算・連続の場合に借りる事実が書かれていない**（L17、L22、L23、L28）
   - **可算：** 幾何分布（第5章）や無限個の値の期待値（第7章）では、無限和が足す順序によらないことを使います。ところが既存の級数の章は、この証明を先送りしています（`\\wsl.localhost\Ubuntu\home\kazumasa\projects\analytics\math_foundations\chapters\series.html:36`「その一般的な証明は先へ譲ります」）。項がすべて非負なら「有限個の和の上限」として示せるので、その証明を入れるか、借用と明記してください。
   - **連続：** E[g(X)] = ∫g(x)f(x)dx を定義とするのか、借りてくる定理とするのかを決めてください。Y = g(X) の密度から計算した値と一致することは、一般には証明しない範囲です。
   - **前提：**
     - 「第1〜5章は微積不要」は不正確です。第1章の可算加法と第5章の幾何分布で、極限と級数を使います。
     - 二項分布の確率の合計が1になることには二項定理が要ります。既存の本では証明されておらず、`\\wsl.localhost\Ubuntu\home\kazumasa\projects\analytics\math_foundations\chapters\elementary-functions.html:26` が使っているだけです。第2章で数え上げにより証明すると、計画に書いてください。

3. **弱大数の実験が、固定した1本の経路だけを主役にしている**（L46）

   - 修正案：
     - 主な図を、ずれる確率の厳密値（exactTail）と Chebyshev の上界を n = 1〜200 で並べたものにする。どちらもすでに API にある確定値です。
     - 経路は「1本の例」と明記し、seed を切り替えられるようにするか、数本を重ねて描く。
     - 厳密値は値の刻みの影響で n について単調に減らないことも、一言添える。
