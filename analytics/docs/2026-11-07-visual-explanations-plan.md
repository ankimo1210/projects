## 設計

現状は全41章・19実験に対し、原本の静的SVGは2件、tableは1件のみ。実験を操作しないと図に出会えない章が多い。定義を読む位置に図を分散し、全41章へ少なくとも1つの新しい概念図/比較表を配置する。重点の節は複数パネルや表を組み合わせる。監査の推奨を基に約60〜70の図表グループを目安とするが、数だけの水増しはしない。

- 図は同じ節の文章・式を指し、入力・出力、軸、範囲、向き、単位やモデルの条件を明示。
- 比較は同じ縮尺、または縮尺の違いを明示。描いた一例や有限点の観察を一般的証明としない。
- 図を加えるだけで文章を二重化しない。数値や分類の列挙は表へ移せるが、数学の定義・仮定・証明・反例は保持。
- 順序・閉点/開点、等号の範囲、面積と確率、定義域と終域の取り違えを避ける。
- rasterや生成画像で数式/数学的形状を描かず、正確なSVGを使う。
- 別ページのギャラリーではなく本文内に配置。各章のコラム1、演習3/ヒント6/解答3/振り返り3を維持。

## 共通の実装契約

rootが assets/style.css の概念図/表の共通styleを所有。他担当はCSSやbuild/catalog/JS/testsを編集しない。
- 単図: figure class="concept-figure" id="slug-visual-name" data-visual="slug-name"、svg class="concept-svg" viewBox="0 0 360 280" (高さは可変) role="img" aria-labelledby="slug-...-title slug-...-desc"。固有title/descとfigcaptionを必須。svgの閉包内で使うidも章/図prefix。
- 比較: div class="concept-grid" に2〜3のfigureを入れる。各SVGは1パネル。狭幅で縦積みし、1枚の横長SVGを無理に縮めない。
- 全色は既存var token (--ink/--ink-2/--ink-3/--surface/--surface-2/--series-1/--series-2/--grid/--ruleなど)。--paperは存在しない。
- SVG文字は基本22px以上。長い式/凡例は図外HTML。軸と曲線は線種/記号でも区別し、色だけに依存しない。線や枠は不必要に塗りで隠さない。
- 表: div class="concept-table-wrap" にtable class="concept-table" data-visual="slug-name"、caption、thead/tbody、scope="col"/"row"。表の最小幅を一律に固定せず、短い数式/見出しはtable-mathで一まとまりとして保つ。長い日本語の文全体は囲まない。表題は表示枠に合わせ、横スクロール中も読めるようにする。横に長い表は枠内スクロール、bodyは横にはみ出さない。情報を詰めすぎず320pxで本文と同等に読める文字サイズ。
- 静的図表はNoJSで全て残る。新たなJSを必要としない。図の隣の文章から図の見方が分かるようにする。

### ユーザー例の具体化
- 集合: 点の所属と集合の包含を区別し、全体U、空集合、和/共通部分/補集合、写像の入力/出力を視覚化。面積の大小に要素数の意味を持たせない。
- 距離: h,kとEuclidean距離rの直角三角形。L1=|h|+|k|、L∞=max(|h|,|k|)を短く定義し、距離の条件を確認。等半径の閉球は菱形/円/正方形でB1⊆B2⊆B∞、距離値はd∞≤d2≤d1。同じずれ(3,2)の値L∞=3、L2=√13、L1=5と、近づく概念が等しい理由も比較。
- 水平接平面: x²+y²、−x²−y²、x²−y²を同じ原点/縮尺/投影で示す。z=0面を補助で示し、x/y方向の断面も添える。単なる透視図の印象だけで極値を判定しない。零Hessianの四次例は別表で比較。

## Review Focus

1. 集合の補集合はどのU/集合に対するものか。∅を一要素のように描かない。写像は各入力から矢印1本。
2. 閉点/開点、有限例と一般保証、切り口と全方向を混同しない。
3. 距離値の大小と球の包含の向き、曲面の山谷の符号・同縮尺。
4. 確率の面積図は値に比例するのか模式図なのか、分母と再重みを明示。
5. 320px/明暗/NoJSで文字・矢印・線・表が読め、はみ出しやラベル衝突がない。
