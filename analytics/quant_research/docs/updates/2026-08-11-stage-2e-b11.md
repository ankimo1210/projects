# 2026-08-11 — Stage 2E / B11 Treasury forecast-to-decision教材

## 結論

B11の座学範囲（Week 41–44、6 Notebook）を実装した。対象は、取得・意味・利用条件を確認できた
U.S. Treasury daily par-yield snapshotを中心にする。JGB intraday、約定可能なquote、cash PnLは
対象外であり、FINRA Treasury Daily AggregateはAPI access/terms gate通過まで条件付き未承認とする。

## 実装した章

| Notebook | 内容 | データ境界 |
|---|---|---|
| 60 | B11 overview、evidence chain | Treasury実データ、FINRAはconditional |
| 61 | formation lag、signal diagnostics、multiple testing、falsification | forecast evidenceのみ |
| 62 | FINRA aggregate schema、trade-level spread identity、scenario cost | 現在fixture-only |
| 63 | par/zero/discount/forward、finite-horizon control | zero/forwardは数学fixture |
| 64 | Treasury yield-change covariance、shrinkage、turnover sensitivity | weightはyield exposure |
| 65 | Forecast-to-Decision specification、claim audit | no-model-selectedを保持 |

Week 42は、認証なしのWeb画面取得を行わない。FINRA API access、利用規約の確認、snapshot hash、
列schema、欠損・再配布条件が揃った場合だけ別gateで昇格する。未通過時はtrade-level fixtureの
identity検算だけを許し、aggregate volumeからspreadやimpactを逆算しない。

## 再現性と検証

- builderは `tools/b11_chapters.py` と `build_nb60.py`〜`build_nb65.py` に分離した。
- `build_notebooks.py --check 60 61 62 63 64 65` は6冊すべてでvalid Python、必須section、Plotly、
  deterministic JSONを通過した。
- clean kernelで6冊を上から実行し、execution errorは0件だった。
- Treasury snapshotのsource/hashは共通loaderが保存し、Notebookは実行時の外部downloadへ依存しない。
- 既存の量的ライブラリと全テストはB11追加後も回帰検証する。

## 主張の境界

- Treasury par yieldは公式のpar curve観測であり、zero-coupon curveやtransaction priceではない。
- FINRA aggregateのtrade count、par volume、channel、on/off-the-run、一部VWAPは、個別quote、queue、
  bid–ask、Kyle lambda、implementation shortfallを識別しない。
- Week 44のweightsはpar-yield change exposureであり、security holdings、duration hedge、realized PnLではない。
- B11 Projectはmodel winnerやproduction strategyを選ばず、仕様・検証・不足データをfreezeする。
