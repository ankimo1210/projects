# 2026-08-10 — Stage 2A / B5–B6実装ノート

## 結論

Stage 2前半を、取得不能なJGB価格や中央銀行イベントの擬似系列ではなく、公式の
**U.S. Treasury Daily Par Yield Curve Rates**を使うB5–B6として実装した。
2015–2025年の固定snapshot、取得manifest、時点整合した翌公表日target、単純baseline、
locked chronological testを全章で共有する。

実データでの主要結果は、複雑なmodelを採用する根拠が得られず、
**no model selected**である。これは失敗ではなく、locked instructional gateに従った教材上の結論である。
固定snapshotは実装時に観察済みなので、このgateを歴史的なpre-registrationとは呼ばない。

## Data feasibilityと品質監査

### Datasetとgrain

| Item | Fixed contract |
|---|---|
| Source | U.S. Treasury Daily Par Yield Curve Rates / official XML feed |
| Snapshot | 2015-01-02–2025-12-31 |
| Grain | Treasury公表日 × 1行 |
| Tenors | 3m, 2y, 5y, 10y, 30y |
| Unit | percent per annum |
| Quote | par yield、bond-equivalent、semiannual coupon basis |
| Retrieval | 2026-08-10 04:52:19 UTC |
| Snapshot SHA-256 | `6ddef9605abbf02c6a4526a51f098135b41da1a437915623af672b1c7bcbd295` |

この系列はindicative bid-side quotationsから推定したconstant-maturity par yieldである。
transaction、executable quote、zero-coupon rate、出来高、intraday liquidityを表さない。
通常は各公表日の18:00 America/New_Yorkまでに利用可能だが、system delayがあり得るため、
same-day trading claimには使わない。

値域は3mが0.00–5.63%、2yが0.09–5.19%、5yが0.19–4.95%、10yが0.52–4.98%、

monotone convexへ変更されたため、break前1,733行、break後1,017行を別regimeとして保持する。
旧方式の最終公表日から新方式の初日へまたがる1-step targetは、通常の金利変化と同一視せず除外した。

### 影響する分析と制約

- Targetは「day-$t$公表後に予測する、次のTreasury公表日の10年par yield変化（bp）」である。
- final testは2023-10-23–2025-12-30のprediction originで、全期間がmethodology break後である。
- training、validation、testは時系列順とし、1-step targetをsplit境界でpurgeする。
- sourceに実際のavailability timestampはないため、公式の通常公表時刻を契約として使い、
  intraday・same-dayの主張を禁止する。
- 価格、position、bid/ask、costがないので、PnL、turnover、transaction cost、net utilityを評価しない。

## B5 — Statistical Learning I

Notebook 24–29で、実データ契約、baseline、regularization、classification/calibration、
temporal validation、総合projectを実装した。

- Featuresはday-$t$ curve、lagged changes、rolling volatility、day-of-weekで、17列。
- Trainは2015-02-02–2021-08-11、validationは2021-08-13–2023-10-19、
  locked testは2023-10-23–2025-12-30。
- testのzero-change RMSEは5.5996 bp、MAEは4.3956 bp。
- validationで選んだlassoのtest RMSEは5.5994 bpだが、改善は0.003%にすぎずMAEも悪化した。
- 採用gateはzero RMSEを1%以上改善し、MAEも悪化しないこと。これは教材用停止規則であり、
  経済的materialityではない。このためB5の結論はno model selectedとする。

## B6 — Statistical Learning II & Model Evaluation

Notebook 30–35で、tree/boosting、kernel ridge/GP、descriptive clustering、shift/conformal、
model tournamentを実装した。B5と同じsnapshot、target、outer testを再利用し、modelごとの
fit rowsとsearch budgetを明示した。

- Week 22のGP gridはvalidation RMSEでlength scale 0.5、noise variance 40 bp²を選び、
  selection期間の90% model-based interval coverageは約91.4%だった。selectionと同じ期間なので
  final coverage保証とは扱わない。
- Week 24のsplit-conformalはproper training、calibration、outer testを分離した。outer testの
  empirical coverageは約96.0%（前半93.0%、後半98.9%）だが、時系列exchangeabilityは未検証である。
- cluster labelはconditional error sliceであり、真のmarket regimeや因果状態とは呼ばない。
- tournamentはRMSE、MAE、rank correlation、runtime、drift、intervalを別々に監査した。
- どのCore candidateも採用gateを通らず、B6もno model selectedとした。
