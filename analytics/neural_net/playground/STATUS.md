# ニューラルネット実験室

更新: 2026-11-03

## 目的と完了条件

ニューラルネットの学習・評価と、PCで回せる異なる規模の精度・計算コストを、自己完結HTMLで比較する。
三日月のブラウザ実験でモデル・学習・推論の仕組みを追い、Fashion-MNISTの実測比較で規模とコストを確認する。
追加の本番依存なし。既存の教材とポータルは維持する。

## 実装方針

- 合成600点、クラス別に学習360・検証120・テスト120へ固定分割。標準化は学習データのみ。
- 2入力 → 隠れ層8×2 → sigmoid。tanh/ReLU、Adam、安定なBCE、任意のL2。
- 線形ロジスティック回帰を学習データだけで学習し、検証時の比較基準にする。
- 学習・検証の損失と正解率を毎epoch計測。最終テストを開くとその実行の学習は終了。
- 乱数seedと設定を固定して再現。学習・評価はブラウザ内で実行する。
- 配色・書体は `docs/templates/claude-report/tokens.css` を全文埋め込み。
- `engine.js` が数値計算、`app.js` が操作と描画、`page.html` / `styles.css` が画面。
  `build.py` が単体 `index.html` を生成する。
- 出力HTMLは約0.32MB、GPU比較snapshotは約0.86MB。学習状態・最新の更新・地図・履歴はRAMに保持し、
  中間配列・学習済みモデルは追加保存しない。

## 規模比較の計画（2026-11-03）

- 実機: RTX 5080 / VRAM 16,303MiB、Core Ultra 9 285K（WSLで20 CPU）、WSLメモリ47GiB。
  PyTorch 2.11.0+cu128、CUDA動作を確認。CPU計測は4スレッドに固定する。
- 題材: 保存済みFashion-MNISTをdownload=Falseで読む。画像28×28、10分類。
  公式学習60,000点から固定・層化分割で学習50,000/検証10,000、公式テスト10,000は最後のみ。
  正規化の平均・標準偏差も学習分だけで求める。
- 比較: 線形、16×1、128×2、512×3、2048×4のMLP（約8千〜1,400万パラメータ）。
  初期化seed11/22/33、同じデータ分割・batch512・8 epoch・Adam lr=0.001・L2=0.0001。
  精度優先のfloat32（TF32なし）。検証loss最小の重みをRAMに保持し、各実行の最後にテストを一度評価する。
- 精度はGPUで学習。CPU/GPUの速度比較は別の同形モデル・同じbatchで、warmup後の更新時間を測定する。
  CUDA同期を含め、3回の計測の最小値を表示。学習全体の時間は評価込みで別に記録する。
- 追加: `src/nn_textbook/scale_experiment.py` とテスト。結果JSONを単体HTMLに埋め込む。
  比較UIは専用 `comparison.html` / `comparison.js`、既存のブラウザ実験とタブで切り替える。
- 実行前の見積り: 入力・モデル・Adam・checkpoint・評価を含めRAM<2GiB、追加VRAM<2GiB程度を想定。
  最大モデルは約14.2M×16byte=217MiB（重み・勾配・Adam状態）に入力約210MiBと活性値・CUDA領域を加える。
  中間重みは保存せず、出力は最終JSONとHTMLのみ（各2MB未満、合計10MB未満）。
  パイロット1 epochで時間・ピークメモリを確認し、その結果で本実行を調整する。
- パイロット実測: 最大14,217,226パラメータ、seed11、1 epochの学習・検証2.926秒、
  学習と最終評価を含むPyTorch割当ピーク547.7MiB。保存JSONは小さく、予定の5規模×3seed×8 epochを実行する。
- 作業データの出力先は `_data/analytics/neural_net/scale-comparison/latest.json` の一つ。
  最終結果の小さなsnapshotだけをplaygroundに取り込み、ハッシュ・設定・実測値を残す。

## モデル・学習・推論の可視化計画（2026-11-03）

- 入力 → 隠れ層 → 出力を同じ横向きの図に置き、各ニューロンを反応地図付きの選択ボタンにする。
  全ての地図は出力の決定境界と同じ座標範囲・向きで、実際の順伝播から描く。
- 1点を固定し、層ごとに順伝播を再生/1段階ずつ進める。再生時は学習を停止し、入力/重みの変更時は再生を解除する。
- ニューロンを選ぶと `sum(a_i * w_i) + b` と活性化の実値、全入力の寄与を表示する。
- 直前の学習360点による平均勾配（L2込み）とAdam更新前後の重みを保持し、選んだ接続の変化を表示。
  1点の推論と、学習集合全体によるパラメータ更新をラベルで区別する。
- マップ・選択点・線を連動。マウス/タッチで点を固定でき、キーボードでも選べるようにする。
  線は符号/太さで重みを表し、選んだニューロンへの接続を強調する。
- 初期タブを仕組みの観察に変更。既存のGPU比較snapshotと数値結果はそのまま使う。
- 編集箇所: `engine.js` と数値テスト、`inspector.js`（新設）、画面/レイアウト/操作、単体HTML生成。
  外部依存・GPU再実験・中間配列の保存は不要。地図は最大20×20×各層の活性値だけをRAMに保持する。
- 手順: 数値整合性の失敗テスト → 数値API → 連動図と操作 → Node/Python検証 → 実ブラウザで推論/学習/テーマ/狭幅確認。
