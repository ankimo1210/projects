# HSK 3級・最初の単元（開発版）

## ねらい

日本語話者が「時間・場所の語順」を練習し、選んだ答えの説明を読み、期限が来たら復習する最小コースです。既存の全級語彙・練習・読解に追加します。画面の「先行体験」はこの開発版を指し、App Store での配信を意味しません。

教材は新規作成した20問の初稿です。中国語・日本語・ピンインの人による監修は未実施で、HSKの出題形式や大綱との対応も未確定です。正式な模試、診断、合格予測、監修済み商品として扱いません。時間語10問・場所表現10問で、後半には時間と場所を組み合わせた文があります。

## 学習の仕様

- 「今日」の画面から目安3分または10分を選択。1問あたり約1分として、期限の来た復習を優先し、残りを未学習の問題で埋めます。
- 時間は解答と解説にかかる目安です。タイマーによる強制終了はありません。対象が少なければ問題数も減ります。
- 復習は期限を過ぎたものだけです。期限前の問題や別級の問題で問題数を埋めません。
- 回答を保存した後に、正誤、選んだ選択肢の説明、基本ルール、例文・ピンイン・和訳を表示します。中国語は既存の端末読み上げ機能を使います。
- 正解は既存 `ReviewScheduler` の1日→3日→7日→14日→30日→90日、誤答は10分後の復習予定です。「正解した」は「習得した」「合格できる」とは異なります。
- 戻る操作やアプリの終了後も、保存済みの問題順・回答・解説を再開します。まだ確定していない選択は保存対象ではありません。
- 保存に失敗した場合、次へ進まず再試行できます。学習メニューから従来のホームと機能にも進めます。

## 教材と履歴の保存

教材は `My Tianjin/Resources/Content/hsk3-first-lesson.json` に同梱します。配列の順序とIDを安定させ、教材版を `2026-09-15-draft1` としています。監修で意味・正答を変更するときは教材版を更新し、保存済みの学習履歴をどう扱うか決めてから配布してください。

新コースの履歴は、既存の SwiftData モデル `StudySessionRecord` の専用キー `course::hsk3-first-lesson` に、一つの版付きJSONとして保存します。新しい SwiftData モデルや破壊的移行は追加しません。既存語彙のIDや学習履歴はそのままです。新コースの成績を従来の自己採点の統計に混ぜません。

専用 `ModelContext` で候補状態を保存し、成功後に画面へ反映します。失敗した場合はそのコンテキストだけをロールバックします。同じ回答の再試行で復習回数を二重加算しない設計です。破損・未対応版のデータは自動で初期化せず、読み込みエラーにします。教材更新時の履歴移行とバックアップUIは後続です。

## 自動検証

プロジェクトのディレクトリで実行します。Node.js以外の追加依存はありません。

```bash
node Tools/validate_content_packs.mjs
node Tools/validate_content_packs.mjs --self-test
node Tools/validate_first_lesson.mjs
node --test Tools/validate_first_lesson.test.mjs
```

新コースの検証は必須テキスト、IDの一意性、正解参照、選択肢、例文、試作の確認状態を確認します。意味の正しさや複数正解の有無は自動検証では保証できません。

Swiftのテストは `CourseEngineTests`・`CourseStoreTests`・`CourseContentTests` にあります。Windows / WSL には Swift と Xcode がなく、ここでは実行できません。Macでプロジェクトを開いてビルドし、利用できるiOS Simulatorを指定して実行してください。

```bash
xcodebuild -list -project "My Tianjin.xcodeproj"
xcodebuild -showdestinations -project "My Tianjin.xcodeproj" -scheme "My Tianjin"
# 上の出力にあるSimulatorのIDへ置き換える
xcodebuild test -project "My Tianjin.xcodeproj" -scheme "My Tianjin" \
  -destination 'platform=iOS Simulator,id=SIMULATOR_ID'
```
