# 汐凪市 午前2時

豪雨で停電した港町を歩く、PCブラウザ用の短編3Dサバイバルホラー。主人公は市営渡船ターミナルの夜勤設備員。防災無線が告げる避難先は、第二水門の向こうにある汐凪警察署。初見の想定は5〜8分です。

## 起動

WSL の Ubuntu シェルで実行します。Node.js 22.18 以降、npm、WebGL 2 対応のデスクトップブラウザを使用します。

```bash
cd /home/kazumasa/projects/shionagi
npm ci
npm run dev -- --host 127.0.0.1 --port 4178
```

[ゲームを開く](http://127.0.0.1:4178/)

読み込みが終わると待合通路から歩き出せます。最初のキー入力またはクリックで音が始まります。画面をクリックするとマウスで周囲を見回せます。

## 市内の道順

- **渡船ターミナル**　曇った窓の外を確かめ、床の誘導帯と非常灯をたどって裏口へ。携帯無線も調べられます。
- **潮見商店街**　冠水した大通りと東側の裏路地が、数本の横道でつながっています。商店街で拾える拳銃には5発入っています。静かに迂回して持たずに進むこともできます。
- **第二水門**　操作盤を使うと8秒で歩道橋が下ります。ポンプ室やコンテナの陰に入ると視線を切れます。走る足音、銃声、橋の作動音は敵を引き寄せます。
- **汐凪警察署**　橋を渡ったら前庭の正面にある誘導灯へ。玄関に手が届く場所で E を押すと暗転してクリアです。死亡時はターミナルからリトライできます。

## 構成と検証

Three.js、TypeScript、Vite で構成しています。人物、港湾設備、商店街、水門、警察署は本作用の3Dモデルです。港の遠景と館内ポスターは本作用に生成し、環境音は Web Audio で合成しています。日本語の市内放送と携帯無線は音声ファイルを同梱しています。[素材の制作記録](docs/ART.md)

```bash
npm test
npm run build
npm run preview -- --host 127.0.0.1
```

通常ルート、無発砲ルート、死亡と再開の確認条件・実測値を [進捗と検証結果](docs/STATUS.md) に記載しています。
