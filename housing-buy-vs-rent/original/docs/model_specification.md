# モデル仕様

## 比較対象

同等の住居を利用する3ケースを比較します。

1. 通常賃貸
2. 借上社宅
3. 購入

比較の原則は **同じ初期資金・同じ月次予算** です。住居費の少ない側は差額を金融資産として運用します。

## 購入側の最終純資産

概念的には:

```math
W_{buy}(T)
= V_T - C_{sell,T} - Tax_{sell,T} - B_T + F_{buy,T}
```

- `V_T`: T年後の住宅売却価格
- `C_sell,T`: 売却費用
- `Tax_sell,T`: 売却関連税
- `B_T`: T年後のローン残高
- `F_buy,T`: 購入側に残った金融資産

## 賃貸側の最終純資産

```math
W_{rent}(T)=F_{rent,T}
```

通常賃貸側は、購入に使わなかった頭金・購入諸費用相当の初期資金、および月次差額を運用します。

## 借上社宅側

ユーザー説明の制度を基準に、年間家賃相当額を給与原資から控除し、控除後給与に所得税等が課されるケースとして計算します。

```math
Salary_{taxable}=Salary_{gross}-Rent_{annual}
```

社宅メリットは、概念的には通常賃貸に比べた税・社会保険負担の減少として金融資産側へ反映します。

## 損益分岐住宅価格上昇率

レポートの主指標 `g*` は次式を満たす住宅価格上昇率です。

通常賃貸との比較:

```math
W_{buy}(g^*) = W_{rent}
```

借上社宅との比較:

```math
W_{buy}(g^*) = W_{corp}
```

`g*` が高いほど、購入側が賃貸側を上回るために必要な住宅価格上昇が大きいことを意味します。

## 基準ケースの代表値

- vs 通常賃貸: `g* ≈ +0.14%/年`
- vs 借上社宅: `g* ≈ +2.46%/年`

## 解釈上の注意

- 元本返済は費用として消えるわけではなく、住宅Equityへ振り替わる一方、金融資産として運用できない機会費用があります。
- 住宅価格変化率は、同じ住戸が経年した後の売却価格を直接表現します。別途「建物減価」を二重計上しません。
- 運用利回りは保証リターンではありません。
- 税務・社保・会社社宅制度は実際の規程や給与処理に合わせて更新してください。
