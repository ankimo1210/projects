# 住宅購入・賃貸・借上社宅の比較

住宅購入・通常賃貸・借上社宅を同じ初期資金と月次予算で比較し、購入に必要な住宅価格上昇率を求める単一HTMLのシミュレーターです。

正式配置先: `/home/kazumasa/projects/housing-buy-vs-rent`。更新日: 2026-09-17。

## 開く

[修正版シミュレーター v2.1](current/report/housing_rent_corporate_buy_report_v2.html) をブラウザで開きます。サーバー・依存パッケージの追加は不要です。ファイル名の `v2` は既存の形式を維持していますが、画面と中身はv2.1です。

基準の損益分岐は通常賃貸 **年0.1406%**、借上社宅 **年2.4576%**。代表感応度6ケースも原本の数値を維持しています。

## 修正内容

- 社宅0年・終了後の家賃を入力チェックに使わないよう修正。UIと感応度の検証を共通化。
- 月次CSVの仮売却税率を売却年1月1日の保有期間で判定。
- 非業務用建物の税務上の経過年数を6か月単位で切捨て・切上げ。
- Node.jsで抽出スクリプトを読み込む際のブラウザ依存エラーを解消。
- 入力連動の説明と、運用利回りの名目年率表記を更新。

税率判定では2026年9月17日取得・各月17日売却を仮定します。長期税率は64か月、10年超軽減は要件を満たす設定で124か月からです。取得日を自由に指定する機能は含みません。

`invest=3%` は税後の名目年率で、月利は `3%/12`、実効年率は約3.0416%です。
会社規程に依存する家賃の税前振替・本人負担・現物課税、3,000万円控除などの適用資格は自動判定しません。

## 開発と検証

プロジェクトのルートから実行します。Node.jsの標準機能のみを使用します。

```sh
node scripts/build-report.cjs
node tests/audit.cjs
```

現行版は **36項目PASS・終了コード0**。基準計算26項目と回帰検証10項目を含みます。月次税額の検証は180か月分を確認します。
[現行の検証結果](docs/audit-results.json)、[修正内容と確認範囲](docs/STATUS.md) を参照してください。

元の不具合を再現する場合:

```sh
node tests/audit.cjs original
```

このコマンドは原本の不具合を検出するため終了コード1になります。
[初回レビュー](docs/logic-review.md) と [初回の検証記録](docs/audit-results-original.json) は原本を対象とする記録です。

## 構成と編集箇所

- `original/`: 受領した10ファイルを無変更で保存。編集しません。
- `current/source/extracted_scripts.js`: 現行計算・検証・UIの編集元。Node.jsでは `HousingSensitivity` をエクスポートします。
- `current/source/full_source.html`: 本文・画面の編集元。スクリプトと表示用コード抜粋はビルドで同期します。
- `current/source/extracted_styles.css`: 原本からのCSS参照コピー。現行レイアウトは維持しています。
- `current/report/`: 生成した自己完結HTML。直接編集せず、上記の編集元から生成します。
- `scripts/build-report.cjs`: スクリプト・本文中のコード抜粋・配布HTMLの同期。
- `tests/audit.cjs`: 基準値の独立検算と回帰検証。引数なしで現行版を検証します。
- `docs/`: レビュー、進捗、検証結果、原本のSHA-256照合記録。

原本の内容と個人条件を含むため、共有先と公開範囲はリポジトリの設定に従って管理してください。
