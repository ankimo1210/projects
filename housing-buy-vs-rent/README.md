# 住宅購入・賃貸・借上社宅の比較

住宅購入・通常賃貸・借上社宅を同じ初期資金と月次予算で比較し、購入に必要な住宅価格上昇率を求める、自己完結型HTMLのシミュレーターです。計算はブラウザー内で完結します。

## 開く・入力する

[シミュレーター v2.2](current/report/housing_rent_corporate_buy_report_v2.html) をブラウザーで開きます。ファイル名の `v2` は既存のリンクを維持するためです。サーバーや追加パッケージは不要です。

基本画面で確認する数値は購入価格、同等住戸の月額家賃、比較年数、住宅ローン金利、税後の運用利回り、社宅利用年数、社宅前の年収、LTVの8項目です。社宅を「利用しない」「比較期間中ずっと」と指定した場合、年数の数値入力は不要です。住戸価格の予想上昇率と税・契約・修繕等の条件は詳細設定で変更できます。パラメータ表から従来の33項目すべてを編集できます。

初期設定では次の値を概算・連動します。

| 項目 | 初期設定 | 手入力との関係 |
|---|---|---|
| 通常時の本人負担社会保険料 | 年収から概算 | 詳細設定で年額を入力可能 |
| 社宅時の本人負担社会保険料 | 税前振替後の年収から概算 | 年額入力、または通常時と同額を選択可能 |
| 年額の保有費用 | 購入価格の1% | 管理費・修繕積立・税・保険等の実額で上書き可能 |
| 社宅年数 | 初期値10年 | 利用なし・全期間・年数指定から選択 |
| 保有費用の増加率 | 初期値0% | 家賃増加率への連動を選択可能 |

概算の社会保険料は**2026年度の東京・協会けんぽ、40歳未満、月給を12か月均等、賞与なし**の例示です。40〜64歳は介護保険料込みに切り替えられます。厚生年金・健康保険の標準報酬上限と雇用保険料率は反映しますが、標準報酬の等級、改定時差、賞与、社宅の現物給与評価、加入保険者による差は省略します。初年度に求めた年額を比較期間中に固定するため、家賃が毎年増える設定でも社会保険料は年ごとに更新しません。対象外の年齢・条件では給与明細の実額を手入力してください。保有費用の1%も市場データではなく便宜的な仮定です。

子の値を直接編集すると、その項目だけ手入力モードに変わり、親の変更に追随しなくなります。連動を再開するには計算方法の選択欄で明示的に戻します。価格と家賃、予想価格上昇率は独立した入力です。概算・連動の状態と採用値は画面および設定JSONに保存されます。旧v2.1形式のJSONは全項目を手入力として読み込み、旧条件の計算結果を維持します。

現在の概算初期値では、通常賃貸との損益分岐は **年+0.1406%**、借上社宅との損益分岐は **年+2.4608%** です。前版の社会保険料を両方150万円とする全手入力条件なら **年+0.1406% / +2.4576%** のままです。折りたたみ式の「初期ケース解説」は、その前版条件を保存した資料であり、現在の入力には連動しません。

## 計算範囲と資料

税額は年収に単一税率を掛けず、給与所得控除、その他控除、社会保険料を反映した前後の税額差で計算します。税制は2026年確認の固定ルールで、将来の法改正を自動取得しません。会社制度の税前振替・本人負担・現物課税や、売却時の3,000万円控除等の適用資格は自動判定しません。投資利回り3%は税後の名目年率で、月利は3%/12です。

社会保険料の概算に使用した資料は[協会けんぽ東京の2026年度保険料率](https://www.kyoukaikenpo.or.jp/shibu/tokyo/public_relations/e-mail_magazine/473.html)、[日本年金機構の標準報酬と保険料](https://www.nenkin.go.jp/service/kounen/hokenryo/hoshu/20150515-01.html)、[厚生労働省の雇用保険料率](https://www.mhlw.go.jp/stf/newpage_71570.html)です。その他の制度根拠と確認条件はHTML末尾の出典と[調査記録](docs/input-simplification-research.md)を参照してください。

## 開発と検証

プロジェクトのルートから実行します。Node.jsの標準機能のみを使用します。

```sh
node scripts/build-report.cjs
node --test tests/input-state.test.cjs
node tests/audit.cjs
```

入力・連動の11テストと、従来条件の36監査項目を確認します。原本を対象としたレビューは[初回レビュー](docs/logic-review.md)に残しています。

`original/` は受領した10ファイルの無変更コピーです。編集元は `current/source/extracted_scripts.js` と `current/source/full_source.html`、生成物は `current/report/housing_rent_corporate_buy_report_v2.html` です。`scripts/build-report.cjs` が5個のスクリプトと本文中のコード抜粋を同期します。詳細な検証範囲は [修正状況](docs/STATUS.md) を参照してください。

原本と設定JSON・CSVには個人条件が含まれます。共有先と公開範囲はリポジトリの設定に従って管理してください。
