# JGB タームプレミアム分解の追試（2026-10）

日銀レビューは、2024年夏からの10年金利の上昇に、期待金利（今後10年の短期金利の見通しの平均）と
タームプレミアム（10年金利から期待金利を引いた残り。長期債を持つリスクの見返りとして上乗せされる分）が
「ほぼ同じ程度」寄与したと分解した。この研究は、無料データと4つのモデル（ACM、そのバイアス補正版、DNS-VAR、
シャドーレート）で同じ分解をやり直し、その結論がどこまで頑健かを調べたもの。以下、日銀のこの記述をほぼ半々と呼ぶ。

- 設計書（判定基準・ゲート・固定設定の正本）:
  [`docs/superpowers/specs/2026-10-17-jgb-term-premium-design.md`](../../../docs/superpowers/specs/2026-10-17-jgb-term-premium-design.md)
- 設定の凍結: `config.json` の SHA-256 は
  `06bd237dbf16717dd5c6154306a0d2160600cecc62f825ba50d1924c2e112460`、
  コードの commit は `ad8721fe4ec4679f33944828dcaf26fb9829fd26`、
  ゲートを実行した commit は `6384a686a571db5c4afe3e598dcaed4c23589039`。
- 日本の推定は凍結した設定で1回だけ実行した（`results.json`）。結果を見たあとで固定設定は変えていない。

表記: 割合 $s$ と 90%区間は小数2桁。$s$ の誤差（推定値 − 真の値）は小数3桁。利回りの変化と誤差は
bp（1 pt = 100 bp）。相関は小数2桁（G2 の 0.9999 だけ4桁）。表の数値はすべて

## 問い

日銀レビュー 2026-E-10（2026年8月、金融市場局・企画局）は、図3（2024年8月からの累積変化。データは2026年6月末まで）
の10年金利の上昇について、本文で次のように述べている（設計書 §1.1 に、本文を読んで確認した記述を記録してある）。

> both factors have contributed to roughly the same degree

2つの要因を詳しく書く。

- **期待金利**: 今後10年間に、日銀が決める短期金利（1か月物）がどう動くかを市場が織り込んだ平均値。
  政策金利が上がる見通しが強まると上がる。
- **タームプレミアム**: 10年金利から期待金利を引いた残り。長く債券を持つリスクの見返りとして上乗せされる分で、
  需給・財政・金融政策の不確実性・海外金利などを反映する。この研究ではモデルの当てはめ誤差と凸性の項（金利が動くときの債券価格の非線形な動きの補正）も、
  この残りに入る。

10年金利の上昇のうち期待金利が説明する割合を **$s$** と書く。

$$
s = \frac{E_{t_1} - E_{t_0}}{Y_{t_1} - Y_{t_0}}
$$

$Y$ は10年ゼロクーポン金利（利払いのない債券の利回り）、$E$ は期待金利。$s = 0$ なら上昇はすべてタームプレミアム、$s = 1$ ならすべて期待金利で、
$s = 0.5$ がほぼ半々にあたる。期待金利の上昇が 10年金利の上昇より大きい（タームプレミアムが下がった）ときは
$s$ が 1 を超え、期待金利が下がったときは 0 を下回る。

- $t_0$ = 2024-07-31（2024年7月の最終データ日）、$t_1$ = 2026-06-30（日銀レビューのデータの最終時点）。
  この間に10年ゼロクーポン金利は 166 bp（1.66 pt）上がった（`results.json` の `delta_yield_pct`）。
- 推定期間は 1986年8月〜2026年6月の月末 479 か月。
- 比較できるのはほぼ半々という記述だけ。日銀の分解の数値は公表されていない（図のみ）。

使った4つのモデルは、どれも月末のゼロクーポン金利のカーブから期待金利を取り出す。

| モデル | 中身 |
|---|---|
| ACM | Adrian-Crump-Moench (2013)。カーブから作った5つの因子で金利を予測し、長期債のリスクへの見返り（リスクの価格）を回帰で推定する。小標本の偏りの補正はしない |
| ACM-BC | ACM の予測部分だけを、小標本の偏りを取り除く Kilian (1998) の補正で直したもの |
| DNS-VAR | Diebold-Li (2006)。カーブを3つの因子で表し、その因子の動きを VAR（過去の値から将来の値を予測する回帰）で予測する。裁定（リスク無しで確実に儲かる取引）が無いことは仮定しない基準線 |
| シャドーレート | Wu-Xia (2016)。政策金利が下限（本研究は −0.10%）で止まる効果を入れたモデル |

モデルを日本に使ってよいかは、日本の結果を見る前に4つの**ゲート**（G1〜G4）で確かめた。ゲートに落ちたモデルは判定から外す。

## 判定

**`term_premium_dominant`**: 頑健ではない（タームプレミアムが主因）。事前に決めた規則で、ゲートを通った3モデル
（ACM・ACM-BC・DNS）の $s$ がいずれも 0.35 を下回ったので、ほぼ半々は頑健ではないと判定する。

判定の規則（設計書 §2.3、計算の前に固定）:

| 結果 | 条件（ゲートを通ったモデルの点推定） |
|---|---|
| 半々は頑健 | すべて $0.35 \le s \le 0.65$ |
| 頑健ではない（期待金利が主因） | すべて $s > 0.65$ |
| 頑健ではない（タームプレミアムが主因） | すべて $s < 0.35$ |
| 頑健ではない（モデル依存） | 上のどれでもない |
| 判定不能 | ゲートを通ったモデルが3つ未満 |

今回の結果は、ゲートを通った3モデルが 0.11・0.16・0.07。シャドーレートはゲートに落ちたので判定に入らない。

この判定を読むときの留保は次の4つ。いずれもラベルを変える根拠にはしない（規則は先に固定してある）。

1. **ACM と DNS の点推定は、小さい $s$ の側に偏っている可能性がある。** 判定は事前に決めた点推定で行い、補正はしていない。
   小標本の調査（後述）では、補正なしの ACM と DNS の $s$ が平均して 0.2 ほど（−0.200、−0.169）小さく出た。
   バイアス補正をした ACM-BC は同じ調査でほぼ偏りが無く（平均 0.009）、日本では 0.16 で、やはり 0.35 を下回った。
   つまり偏りの小さい推定も同じ方向を指す。ただし ACM-BC は散らばりが大きい（標準偏差 0.305）。
2. **ACM-BC の区間は 0.5 を含む。** 区間の上端は 0.503 で、0.5 をわずかに越える。ACM と DNS の区間は 0.5 を含まない。
3. **補足の結果は大きく振れる。** 推定期間を2009年開始にすると $s$ が 1 を超える。この窓では ACM の P の VAR
   （実際の確率の下での金利の動きを表す式）が発散的（最大固有値 1.019）で、$s > 1$ はその下での値である。$t_1$ を最新日
   （2026-10-15）にすると ACM-BC は 0.49 になる。2026-10-15 は月末ではないため、VAR は 2026-09-30 → 2026-10-15 を
   1か月の遷移として扱っており、この 0.49 もその扱いの下での値である。$K = 3$ の ACM では約 0 になる（後述）。
4. **ゲートに落ちたシャドーレートを入れると、同じ規則を当てた参考ラベルは変わる。** 点推定は 0.66 で、4モデルに同じ規則を当てると
   モデル依存になる。これは参考で、判定は規則どおり3モデルで行った。

## 主表

10年金利、$t_0$ = 2024-07-31、$t_1$ = 2026-06-30、推定期間 1986-08〜2026-06。
10年ゼロクーポン金利の変化は 166 bp。

| モデル | $s$ | 90%区間 | 0.5 を含む | 期待金利の変化 | ゲート | 判定に使う |
|---|---|---|---|---|---|---|
| ACM | 0.11 | −0.16 〜 0.35 | いいえ | 18 bp | 合格 | はい |
| ACM-BC | 0.16 | −0.43 〜 0.50 | はい | 27 bp | 合格 | はい |
| DNS-VAR | 0.07 | −0.20 〜 0.30 | いいえ | 11 bp | 合格 | はい |
| シャドーレート | 0.66 | −0.04 〜 1.71 | はい | 109 bp | 不合格（G1・G3） | いいえ（参考） |

- 90%区間は、ACM・ACM-BC・DNS では VAR の残差を取り替えながら金利の経路を作り直して推定をやり直す方法
  （ブートストラップ）を 1,000 回行い、その 5〜95 パーセンタイルを取った。ACM-BC は各回で Kilian の補正もやり直している。
  区間に入るのは、リスクの価格を固定したうえでの、金利の予測側の推定誤差だけ。モデルそのものの誤りは入らない。
- ACM-BC と DNS の区間は互いに独立ではない。`run_japan.py` は ACM-BC の外側のブートストラップに `seeds["acm_bc"] + 1`
  （= 20261019）を使い、これは `seeds["dns"]` と同じ値である。2つのブートストラップが同じシードの乱数列から始まる。
  それぞれの区間は単独では有効だが、両方を合わせて読むときは独立な2つの根拠として数えない。再実行はしていない。
- シャドーレートの区間は、最尤推定のヘッセ行列から500回パラメーターを抽出して求めた。
  500回のうち 259 回は尤度が罰則値になって棄却され、区間は残りの 241 本から作ってある。
  抽出に使うヘッセ行列（尤度の曲率）には、曲率が極端に小さい方向が 6 つあり、その固有値は下限に置き換えた。
  区間は −0.04 から 1.71 まで広い。
- ACM-BC の Kilian 補正は、主表では縮める必要がなく全量が適用された（`acm_bc_shrink` = 1.0）。
- 判定は点推定で行い、区間は判定に使っていない。

## 目安

判定に使わない2つの目安（設計書 §4.5）。

| 目安 | 意味 | $s$ |
|---|---|---|
| タームプレミアム一定 | 期待金利の変化が 10年金利の変化のすべて | 1.00 |
| 据え置き予想 | 市場が今の短期金利がずっと続くと見ていた場合 | 0.54 |

据え置き予想の 0.54 はほぼ半々の帯（0.35〜0.65）に入る。ゲートを通った3モデルの $s$（0.07〜0.16）は
それよりかなり小さく、期待金利の変化は 11〜27 bp にとどまる。この差の原因は調べていない。

### G1 合成データでの再現

各モデル自身の生成過程から 20,000 か月の合成データを10本作り、同じ設定で推定する。各本で、
経路の中で10年金利の上昇が最大の23か月の区間の $\hat s - s_{\text{真}}$ と、10年タームプレミアムの
系列の RMSE（推定値と真の値のずれの二乗平均平方根）を測る。合格は、10本の $\hat s - s_{\text{真}}$ の平均の絶対値が 0.05 以下、
RMSE の中央値が 15 bp 以下。

| モデル | $\hat s - s_{\text{真}}$ の平均 | RMSE の中央値 | 結果 |
|---|---|---|---|
| ACM | −0.004 | 8.0 bp | 合格 |
| ACM-BC | 0.004 | 8.1 bp | 合格 |
| DNS-VAR | 0.012 | 5.5 bp | 合格 |
| シャドーレート | −0.072 | 6.5 bp | **不合格** |
| 負の対照: 据え置き予想（ACM・ACM-BC 共通） | 0.546 | 86.7 bp | 落ちた |
| 負の対照: 据え置き予想（DNS の生成過程） | 0.449 | 107.0 bp | 落ちた |
| 負の対照: 据え置き予想（シャドーレートの生成過程） | 0.771 | 68.2 bp | 落ちた |

- シャドーレートは RMSE の条件は満たしたが、10本すべてで $\hat s$ が真の値より小さく、平均の誤差が −0.072 で許容 0.05 を超えた。
  ずれの原因について、設計書 §9 は別シードの事前調査にもとづき、P の推移行列の推定から来ると書き、
  下限があるとさらに約 −0.06 が加わるとしている。本番の `gates.json` は原因を切り分けていない。
- G1 のシャドーレートの生成過程は下限 0% で作ってある（日本の推定は −0.10%）。1本あたりの推定は 322〜447 秒かかった。

## 小標本バイアス

判定とは別に、日本の推定値をどこまで割り引くかの目安として測った（設計書 §5.1）。G2 で推定した米国の ACM
のパラメーターを生成過程にして、479か月の合成データを500本作り（シード 20261117）、各本で $\hat s - s_{\text{真}}$ を測った。
日本の推定値は使っていない。シャドーレートは計算量のため除いた。

| モデル | 誤差の平均 | 標準偏差 | 5% 点 | 中央値 | 95% 点 |
|---|---|---|---|---|---|
| ACM | −0.200 | 0.207 | −0.529 | −0.208 | 0.109 |
| ACM-BC | 0.009 | 0.305 | −0.460 | −0.006 | 0.498 |
| DNS-VAR | −0.169 | 0.215 | −0.525 | −0.169 | 0.152 |

- 補正なしの ACM と DNS は、$s$ を平均して 0.2 ほど（−0.200、−0.169）小さく見積もる。
  日本の判定で使った ACM と DNS の点推定は補正をしていない版で、この調査は、それらが小さい $s$ の
  側に偏っている可能性を示す。
- ACM-BC は偏りがほぼ無い（0.009）。日本の ACM-BC の 0.16 は、この偏りの影響を受けにくく、ACM・DNS と同じ方向を指す。
  ただし散らばりが大きい（標準偏差 0.305。ACM は 0.207）。日本の ACM-BC でも同様に、90%区間が 0.5 に届いている
  （上端 0.503）。シミュレーションの標準偏差と日本のブートストラップ区間は別の測定である。
- これは参考で、日本の判定を補正するものではない。判定ラベルは事前登録の点推定のまま変えていない。

この調査と日本の推定では条件が違う。

- 生成過程は米国の ACM（因子5つ）で、日本のデータで推定したものではない。
- 生成過程には金利の下限が無い。日本は1995年以降の大半が下限近くにあった。
- 生成過程の評価区間は、合成した経路ごとに10年金利の上昇が最大の23か月をデータから選んだ。
  日本の区間（2024-07-31〜2026-06-30）は事前に固定した。区間の選び方が偏りに与える影響は、分けて測っていない。

## 補足

判定に使わない設定違いの結果（`results.json` の `supplementary`）。設計書は、これらの設定を判定に使わないと定めている
（$t_0$・$t_1$ の別定義は §2.2、5年と20年・30年は §2.3 と §4.5、推定期間の違いは §3.4 と §4.5、$K = 3$ は §4.5）。
右端の列は、各設定の3モデル（ACM・ACM-BC・DNS）の値に判定と同じ規則を機械的に当てはめたもので、判定ではない。
ゲートは主設定でのみ実施しており、この列のラベルにゲートの裏づけは無い。

| 設定 | ACM | ACM-BC | DNS-VAR | シャドーレート | 参考（判定ではない。ゲートは主設定でのみ実施） |
|---|---|---|---|---|---|
| 主表（10年、$t_0$ = 2024-07-31、$t_1$ = 2026-06-30） | 0.11 | 0.16 | 0.07 | 0.66 | タームプレミアムが主因（= 判定） |
| 5年 | 0.24 | 0.30 | 0.22 | 0.86 | タームプレミアムが主因 |
| $t_0$ = 2024-08-30 | 0.05 | 0.07 | 0.05 | 0.63 | タームプレミアムが主因 |
| $t_1$ = 2026-10-15 | 0.33 | 0.49 | 0.30 | 0.78 | モデル依存 |
| 推定期間 2004-01〜 | 0.35 | 0.35 | 0.33 | 0.01 | モデル依存 |
| 推定期間 2009-01〜 | 1.25 | 1.25 | 1.42 | 0.27 | 期待金利が主因 |

- ゲートを通った3モデルの $s$ は、設定によって 0.05（$t_0$ = 2024-08-30）から 1.42（2009年開始の DNS）まで動く。
  ACM だけの設定である $K = 3$ の −0.01 を加えると、範囲は −0.01〜1.42 になる。2009年開始では3モデルとも 1 を超え、
  この設定の参考ラベルは期待金利が主因で、主設定の判定とは異なる。この窓では ACM の P の VAR が発散的（最大固有値 1.019）で、
  DNS の VAR も発散的（1.013）であり、$s > 1$ はその下での値である（下の診断）。
  判定は固定した設定の1回の結果であり、設定を変えれば $s$ は大きく動く。

### 2004・2009年開始の窓で ACM と ACM-BC が一致した理由

**結果の後の診断（設定・結果は変えていない）。** 日本の結果を見たあとに、現在のコードで主表・2004・2009年開始の各窓の
ACM を推定し直し、P の VAR の最大固有値（絶対値）と Kilian の補正量（`shrink`。1 = 補正を全量かける、0 = 補正なし）を測った。
読み取りだけのスクリプトで測っており、`results.json` にはこの値は保存されていない。主表の窓で補正量が 1.0 になることは、
`results.json` の `acm_bc_shrink` と一致した。

| 窓 | ACM の P の VAR の最大固有値 | 補正量 | 起きたこと |
|---|---|---|---|
| 主表（1986-08〜） | 0.98443 | 1.0 | 補正が全量かかる。ACM（0.11）と ACM-BC（0.16）は別の値になる |
| 2004-01〜 | 0.9999993 | 0 | 補正を 0.01 刻みで少しでもかけると非定常になるため、補正量は 0 になる。補正後の $\Phi$ は補正前と同じで、変わるのは定数項 $\mu$ だけ。$\mu$ は期待金利を毎期同じ量だけずらすので、期待金利の変化は変わらず、ACM-BC は ACM と丸め誤差の範囲で一致する |
| 2009-01〜 | 1.01875（発散的） | 0 | 推定値そのものが非定常なので、`kilian_correct` は補正せずにそのまま返す（`acm.py` の非定常のガード）。ACM と ACM-BC は同一になる |

DNS-VAR の最大固有値は、主表の窓で 0.98544、2009年開始の窓で 1.0126（発散的）。

2009年開始の窓の $s > 1$（ACM 1.25、DNS 1.42）は、VAR が発散的なモデルの下での値である。診断は、この窓で VAR が発散的であることと、
ACM と ACM-BC が一致する仕組みを示す。$s > 1$ の原因がそれだと確かめたものではない。

## 限界

### 設計書 §8 の4点

1. **日本の金利は下限近くにあり、ガウスのモデルが合わないかもしれない。** 日本は1995年以降の大半が下限近くで、
   2016〜2024年は10年金利が YCC（イールドカーブ・コントロール）で固定されていた。判定に使った ACM・ACM-BC・DNS は
   下限を扱わないガウスのモデル（金利の変動が正規分布に従う線形のモデル）で、この期間の動学（金利が時間とともにどう動くか）
   を誤る可能性がある。下限を扱うシャドーレートはゲートに落ちて
   判定に入っていないため、**判定は下限を扱わないモデルだけに基づく**。
2. **シャドーレートの準最尤法は局所解に落ちやすいと、設計書は懸念した。** 20通りの初期値で対処し、尤度の上位の解の間の $s$ も記録した。
   上の表のとおり、上位3つの $s$ は 0.66・0.86・0.33（負の対数尤度は1位より 45 と 310 大きい）で、このモデルの $s$ は
   初期値によって大きく異なる。散らばりが局所解によるのか、反復回数の上限までの収束不足によるのかは切り分けていない。
3. **$t_0$ = 2024-07-31 は日銀の利上げ（0.25%）の当日。** $t_0$ の値に当日の反応が入っている。$t_0$ を 2024-08-30
   にしても、ゲートを通った3モデルの $s$ は 0.05〜0.07 で、ラベルは変わらない（補足の表）。
4. **日銀の分解の数値は公表されていない。** 比較できるのはほぼ半々という記述だけで、数値どうしの比較はできない。

### 実際に出た問題

- **G1 の判定方法を、ゲートの本番実行の前に変えた（ユーザー承認済み）。** 当初は1本の合成データで判定する設計だったが、
  本番とは別のシードで試すと、正しい実装でも1本判定では落ちることが多かった（ACM は30本中13本が合格）。
  20,000 か月でも、持続性 0.99 の因子の平均と持続性の推定誤差が $s$ を ±0.05 ほど動かすためで、実装の誤りではなく
  推定の誤差だった。そこで10本の平均で系統的なずれだけを見る方式に変えた。$s$ の許容 0.05 は変えず、RMSE は
  10本の中央値で 15 bp 以下とした。このとき、新しい基準ではシャドーレートが落ちる見込みも設計書 §9 に書いてあった。
- **シャドーレートが G1 と G3 に落ちた。** G1 は平均誤差 −0.072（許容 0.05）、G3 は Wu-Xia との相関 0.82（要 0.9）。
  判定からは外れ、ゲートを通ったモデルは3つ（規則の最低数ちょうど）になった。
- **シャドーレートの推定自体が不安定だった。** 負の対数尤度の散らばり、罰則値で終わった初期値2通り、棄却された抽出 259/500、
  置き換えた固有値 6 個、$s$ の初期値依存（前節）。
- **小標本バイアス。** 補正なしの ACM と DNS の $s$ は平均して 0.2 ほど小さく出る（前節）。判定はこの補正をしていない点推定で行った。
  ACM-BC は偏りがほぼ無く、0.16 で同じ方向を指す。
- **補足の不安定。** 設定を変えると3モデルの $s$ は 0.05〜1.42 に動き（ACM の $K = 3$ では −0.01）、参考ラベルが主設定と
  異なる設定もある（前節。設計書は、これらの設定を判定に使わないと定めている）。2009年開始の窓では ACM の P の VAR が
  発散的（最大固有値 1.019）で、$s > 1$ はその下での値である。
- **ACM と ACM-BC の一致。** 推定期間 2004-01〜 では丸め誤差の範囲で一致し、2009-01〜 では同一。結果の後の診断
  （設定・結果は変えていない）では、2004年開始の窓は P の VAR の最大固有値が 0.9999993 で補正量が 0 になり、
  2009年開始の窓は最大固有値 1.01875 で `kilian_correct` が補正せずに返していた（前節）。
- **小標本の調査の条件が日本と違う。** 生成過程に下限が無いこと、評価区間をデータから選んだこと、日本の区間は固定したこと（前節）。
- **$t_1$ の別定義は月末ではない。** 設計書 §3.1 の月末値の定義（その月で行がある最後の日）に従い、
  月の途中の最新のデータ日（2026-10-15）で計算した。VAR は 2026-09-30 → 2026-10-15 を1か月の遷移として扱う。
  設計書 §2.2 の「最新の月末」と §3.1 の定義は食い違っていた。
- **ACM-BC と DNS の区間が同じシードから始まる。** `seeds["acm_bc"] + 1` と `seeds["dns"]` がともに 20261019 で、
  2つの区間は独立ではない（主表の注）。
- **結果とデータの結びつき。** `config.json` の SHA-256 が縛るのはコードとゲート結果で、データは縛らない（再現手順の末尾）。

### この結果が示さないこと

- **日銀のレビューが誤りだとは示さない。** 日銀は Imakubo and Nakajima (2015) のシャドーレートモデルを名目と実質のカーブ、
  Consensus Forecasts（サーベイ）と組み合わせている。この追試は無料のデータだけで、サーベイも物価連動債も使っていない。
  日銀の数値は公表されていないので、日銀の分解を再現したものでも、数値を比べたものでもない。比べたのはほぼ半々という記述だけ。
- **「タームプレミアムが主因」が真だとも示さない。** 判定に使った3モデルはどれも下限と YCC を扱わず、
  そのうち ACM と DNS の点推定は小標本で小さい側へ偏る傾向があり、設定を変えると $s$ は大きく動く
  （2009年開始の窓では P の VAR が発散的で、$s$ は 1 を超える）。
  示せたのは、固定した設定の下で、ゲートを通った3モデルがほぼ半々より小さい $s$ を出した、ということまで。
- 日銀の図4（買い入れ減額の効果、約10〜25bp）の回帰は追試していない（範囲外）。
- 将来の予測ではない。
