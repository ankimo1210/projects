## Fixed and committed this session

- **Defect 8** — `HSCAL` is negative, so the altitude count must be too.
  Turned flight 17's runaway (2496 km) into flight 18's normal braking
  (15.2 km → 1.2 km at −28 m/s).
- Pulse cap 16384 → 32768; the old cap silently truncated the
  altitude→velocity transition (~19 000 pulses).
- **`ALTSCBIT` declared** (FLGWRD12 bit 9 = 0o400, ECADR 0o110),
  read-modify-write in the pad-load choreography. Nothing in the rope
  ever writes it — it is external state the LR supplies.
- **Velocity data-good gated** on each beam's own asymmetric counter
  window (X's quantum is negative).
- `bin/agc_state` prints `FAILREG`, so ledger item 2's P65 alarm code can
  be read passively. **Never RSET** — it clears the register.

Neither of the last two is the TIG+360 s bug. Both are correct and stay.

## Operating notes worth keeping in front of you

- A flight is ~20 minutes. **Write the purpose and the decision rule into
  the scenario before flying**, not after — three of this session's four
  conclusions came from rules fixed in advance.
- The core dump is the instrument of first resort for "what does the AGC
  believe" (`bin/agc_state`). yaAGC dumps every 10 s by default, so
  passive observation is free. **Do not pass `--dump-time=1`** — the
  synchronous 18 KB write killed flight 12 before ignition.
- `EAGLE_TELEM_OUT` needs an **absolute** path (cwd is `runtime/`).
- `vendor/` is READ-ONLY.
- The working tree can end up on another session's branch; push with
  `git push origin HEAD:main`.
