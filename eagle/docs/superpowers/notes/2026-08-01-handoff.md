P65 altitude-state divergence. At truth 494.9 m the AGC displayed 347.5 m;
at truth 239.0 m it displayed 16.8 m. It then continued through negative
computed altitude while maintaining a real hover above 200 m.

Three low-altitude repair flights have now been used:

1. Run 29: radial altitude → correct H-beam slant range;
2. Run 30: fixed high range scale, which fixed the early range but failed
   below the 2,500 ft boundary;
3. Run 31: automatic high/low scale, whose transition worked but left the
   low-altitude state bias.

Do not make another speculative fix. The next investigation must first
measure, in the same timestamps, the presented LR range/count/scale, the
rope's accepted `RNRAD`/range update, and the before/after navigation state.
The unresolved boundary is now between correctly presented LR observations
and Luminary's state update, not in the socket transport or beam geometry.
