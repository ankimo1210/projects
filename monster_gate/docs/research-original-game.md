# モンスターゲート（コナミ, 2001）調査メモ

「モンスターゲート風のゲーム」を作るための元ネタ調査。実装計画の前提資料。
調査日: 2026-08-29。一次資料は当時の GAME Watch 記事（2001-12〜2002-02）が最も詳しい。

## 1. 概要

- コナミのメダルゲーム。業界初のダンジョン探索型 RPG メダル機。2001-07 先行稼働、2001-10 製品版。
- 一言で言うと「トルネコ/シレン（不思議のダンジョン）をメダルゲーム化したもの」。
  ただし **空腹なし・罠なし・持ち物は使い切りカード10枚のみ** と大胆に削ぎ落としてある。
- エントリーカード（磁気カード, 300円, 最終プレイから30日で失効, 購入店舗のみ有効）にキャラを保存。
- 系譜: MG(2001) → II(2002, 性別/色選択, 見習い・魔人追加) → III(2003, スラッガー追加) →
  Online(2004, セイント追加) → Online II(2005) → エターナルナイツ(2007, e-AMUSEMENT, 協力要素) →
  エルドラクラウン(現行, 2023-11 に「悠久のラビリンス」, コナステ版は PC/iOS/Android で無料配信)。
  GBA 版 2 本（2002, 2003「大いなるダンジョン」= ストーリー付き）、TCG(2002)。

## 2. コアループ（探検ゲーム = 1人用）

1. **ダンジョン選択と BET**: 難易度 ★1〜★7 の 10 ダンジョン。BET 3〜30 枚、WIN 3〜700 枚。
2. **持ち込みカード決定**: 倉庫（最大 100 枚）から最大 10 枚（城によって 6 枠などの制限あり）。
3. **探索（ターン制）**: 階段を探して下へ。敵を倒すと成長。落ちているカード・WIN（メダル）を拾う。
4. **最下層の祭壇で「クリアの証」（宝石）取得 = クリア**。WIN がクレジットに加算。
   ダブルアップカードを取っていると WIN が倍（複数枚で倍々。ブログ例: 1600→3200 枚の判断）。
   ギャンブラーは宝石とダブルアップの位置がミニマップに見える。
5. **死亡** = 獲得 WIN の 50% だけ返還（=半損）。途中で「エスケープ」カードで脱出も可。
6. **経済**: 「カードを使うたびにメダルを BET する」のが肝。簡単な城は黒字化しにくく、難しい城は
   配当が大きい → 「簡単な城でカードを溜める → 強いカードを持って難しい城で稼ぐ」というサイクルが成立。
   ゲームの「利率」は運営側で調整され（稼ぎすぎると WIN 変動/難易度上昇）、後期はこの改悪で客が離れたという証言あり。

## 3. ダンジョン/戦闘ルール（RogueBasin + GAME Watch）

- **フロア構造**: 矩形の部屋がグリッド状に並び、短い通路で接続（外周を回る通路も少数）。
  視界は通路で隣接 1 マス、明るい部屋では 5 マス（ほぼ部屋全体）。
- **敵**: 部屋内で停止(stasis)していて入室すると起動。滞在ターンが長いと追加湧き（ジェネレーター）。
  視認すると最短経路で接近（斜め移動あり、近づかない移動はしない）。見失うと最終確認位置へ、
  その後は部屋をランダム巡回。飛び道具持ちは縦横斜めの直線上にいると撃つ（距離でダメージ減）。
- **プレイヤー**: 8方向移動・攻撃・空振り（その場でターン消費）。通路と部屋の境界で 1 対 1 を作るのが基本。
  高速移動あり。「2 フロア移動して戻ると敵配置がリセット」される。
- **成長**: 明示的レベルなし。敵を倒すと攻撃/防御/HP が上昇（敵の強さに依存、雑魚は無益）。
  敵種ごとに成長上限（戦士: プーニャ 53, キラービー 63）。毎回 Lv1 相当から開始する設計。
  新しい部屋に入ると HP +5。
- **ボス**: 一部フロアで階段を守る。HP 高、攻撃確率 50%、レアカード or メダルをドロップ。
- **敵 HP 表**: プーニャ 9/10, キラービー 11, スケルトン 14, ケムンパ 17, ゴブリン 21, 魔道士 26,
  キラービー群 32, グランシャーク 39, ターミネーター 49, ドラゴン 67, 死神 74, マッドブル 91,
  エビルアイ 111, デーモン 137, キングドラゴン 190, シャドウ 300。
- **城の特殊ルール例**: 会心率 up / 敵も会心 / 酸の床(1歩1ダメ) / 氷で滑る / 通路が明るい /
  後戻り禁止 / 持ち込み枠減 / 持ち込み禁止 / 眠るドラゴン / 全階同一敵(SMOKY) / マップ非表示(DARK)
  / 毎歩 HP 減(CRUEL) / 敵発生率異常(WEARY) / ショップ→カジノ(ROYAL)。
- **ダンジョン内施設**: ショップ（購入・売却、レア装備がまれに並ぶ）、カジノ（スロット）。

## 6. 対戦ゲーム（陣取り, 初代「ふつう」クリアで解放）

- ワールドに **40 城**（★1〜7）。城は「登る」（BET 一律 10 枚）。クリアの証で占領。
- 自分の城に **隣接** する城のみ攻撃可能（スタート両脇は常時可）。ギャンブラーは例外。
- **城主収入（防衛費）**: 挑戦者が消費したメダルの一部と、倒されたガーディアン費用が城主に入る。
  城が多いほど放置収入が増える。
- **ガーディアン**: 城主がモンスターカードを配置。HP 極高、補助無効、飛び道具なし。倒すと WIN/モンスターカード/レアカードを必ずドロップ。
  ★4 以上の城は全モンスター配置可 → 入ってすぐキングドラゴンもあり得る。
- オフラインバトル（城主不在時に自動防衛）。
- 別軸で「ワールドバトル」「スピードバトル」（2〜4 人）も存在。
- 城名は形容詞（POOR, SMOKY, SWEET, DARK, TIGHT, CRUEL, ROYAL, GREAT…）で特性を表す。

## 7. 続編で足されたもの（設計の伸びしろ）

- GBA: メダル→ **MP**。新部屋探索で回復、カードを捨てると MP 回収。ストーリー、ギルドのサブクエスト
  （同時 1 件、断ると二度と来ない）、スロット部屋でカード大量入手。「ゴリ押し不能」になり戦略性が上がったと好評。
- エターナルナイツ: カード合成、プレイヤー間トレード、窮地で他人にカード援助を求める「サポートリクエスト」、
  同店舗で王国を育てる「ドリームオデッセイ」、王国対王国のオンライン戦。
- エルドラクラウン: ストーリーモード、**クリエイトモード**（自作ダンジョンを公開）、キングダム大戦、スマホ無料版。

## 8. 「面白さの芯」と作るときの論点

- 芯は **(a) 使い切りカード 10 枚のデッキ構築 + (b) 使うたびにコストが掛かる経済 + (c) 先行投資→配当のリスク管理**。
  「ローグライクの中でシステム上最も美しい」と評される理由はこの 3 つの噛み合い。
- ダンジョン自体はシンプル（空腹/罠なし、成長は自動）。詰め将棋的な位置取りが戦闘の面白さ。
- 継続要素は「カード資産の蓄積」と「城の占領による放置収入」。
- 実装時に決めるべきこと:
  1. メダルの代替（GBA の MP 方式か、ゲーム内通貨か、両方か）。
  2. 死亡ペナルティ（50% 返還）と WIN 変動の方式。運営調整可能なパラメータとして設計する。
  3. 対戦（非同期の城防衛）をやるか。やるなら自動防衛 AI とガーディアン配置が必要。
  4. ギャンブラーのように「情報が見える」職の扱い（自作ゲームではバランス調整の要）。
