# 産地アトラスの実装・検証メモ

2026-09-15。承認された「旅する図鑑風」の方向を、既存のフランス10産地へ実装。

## 変更した体験

- 起動時の「探索」で地図・写真一覧を切り替える。産地を選ぶと写真と概要が切り替わり、詳細へ進める。
- 産地詳細で気候・品種・スタイルを切り替え、土壌・栽培・醸造などの既存解説、2産地比較、10/20問演習へつなぐ。
- 解答を表示した後だけ関連産地への地図リンクを出す。地図から戻った際、解答・入力・採点状態を初期化しない。
- 紙色・緑・ワイン色を用い、明暗テーマ、文字拡大、VoiceOver向けラベル、44ptのマーカー、写真欠落時の代替表示を用意する。
- 近接したマーカーはまとめ、メニューから各産地を選べる。丸い点は代表位置で、産地の法的境界を示さない。

問題の改訂内容、問題ID、学習履歴の保存形式、無料範囲、StoreKitの仕組みは今回変更していない。新しい本番依存や通信必須の画像読み込みは追加していない。

## 素材と生成

背景地図はNatural Earthの国土・河川データから再現可能なSVGを生成する。経緯度の範囲とピンには共通の変換を使い、ライト・ダークの地形を一致させる。取得元、固定コミット、原データのハッシュは `ReferenceSources/RegionMaps/france_geography.json` に保存。

写真の正本と権利情報は `ReferenceSources/AtlasMedia/` に保存。作者、原典、利用条件、加工内容、確認日、代替テキストをアプリ内で閲覧できる。写真とJSONはオフラインで利用できる。

```sh
python3 scripts/build_france_basemap.py
python3 scripts/build_region_map_pack.py
python3 scripts/build_atlas_media.py
python3 scripts/build_content_review_packet.py
make verify
```

## Macで残る確認

Windows/WSLにはSwift・Xcodeがないため、Swiftのコンパイル、iOSビルド、実画面のレンダリング・UIテストは実行していない。静的レビューと素材画像の確認は、実機動作の確認を代替しない。

Xcodeで `WSET.xcodeproj` を開き、iOS 17以降の利用可能なSimulatorを指定する。

```sh
make test-unit DESTINATION='platform=iOS Simulator,name=iPhone 16'
make test-ui DESTINATION='platform=iOS Simulator,name=iPhone 16'
```

特に確認する経路:

1. 探索 → 集合マーカー → ブルゴーニュ → 写真概要 → 詳細 → 演習。
2. 四択を解答 → 産地の地図 → 戻る → 解答状態を維持 → 次問。
3. Proの記述式 `SAQ-LO2-001`（ボルドー）または `SAQ-LO3-001`（シャンパーニュ）で入力・解答表示・採点選択 → 地図 → 戻る → 入力、採点、保存後の履歴を確認。
4. 無料状態での産地閲覧、写真クレジット、地図／写真データが読み込めない状態。
5. 小画面、最大文字サイズ、VoiceOver、明暗テーマ、視差効果を減らす設定、機内モード。

地図・写真の対象はフランスの既存10産地。世界全域への拡張や公開・配布は今回の変更に含まない。
