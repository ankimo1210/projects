# CruNote 産地アトラス — 承認済み設計

2026-09-15。ユーザー承認：旅する図鑑風の3画面案を基に、まずフランス10産地へ実装する。

## 体験

- 起動直後の「探索」でフランスの地図または写真付き産地一覧を選ぶ。
- 産地マーカーから写真・気候・品種・スタイルを読める産地詳細へ進む。
- 既存の産地比較と10問・20問演習へ接続する。
- 解答後の解説と問題詳細から、その問題の関連産地を地図で確認する。
- 既存の学習、問題・辞書、テイスティング、進捗は引き続き利用できる。

## 表現と制約

- iOS 17以上、SwiftUI / SwiftData。追加の本番依存、外部API、通信必須機能は導入しない。
- 日本語、紙色・深緑・ワイン色、実在する産地の写真、地理データ由来のオフライン背景地図。
- 表示可能な地図は既存のフランス10産地。未収録国を利用可能と見せない。
- 写真ごとに原典URL、作者、ライセンスURL、加工内容、確認日、代替テキストを保持しアプリ内で表示する。
- 地図はNatural Earthのパブリックドメイン地理データから作成し、産地ピンは代表位置と明記する。法的境界を示さない。
- 問題ID、SwiftDataモデル、学習履歴、無料範囲、StoreKit、既存正本の問題文を変更しない。
- Dynamic Type、VoiceOver、ライト／ダーク、Reduce Motion、画像欠落時の代替表示に対応する。
- デザイン案の生成画像は教材写真として使用しない。

## 検証

- 写真10件と産地IDの一対一対応、出典・ライセンス、ファイルサイズとハッシュ、生成物の一致を自動検証。
- 地図の地理データ・座標・代表位置の投影とビルダーの再現性を検証。
- 既存61件のPythonテストと生成チェックを維持し、必要なデータテストとiOS UIテストを追加。
- このWindows/WSL環境ではSwift/Xcode未導入。SwiftUIのビルド・実機UI検証ができない点は明示し、静的確認とプレビュー用の画像確認で代替できる範囲を区別する。

## 実装分担

写真取得は独立した素材調査として分担し、アプリコードとデータ生成・統合は既存形式に合わせて進める。現行ファイルを複製した作業用worktreeで実装し、最後にベースラインのハッシュを確認して今回の差分だけを元プロジェクトへ反映する。コミット・push・公開は実施しない。
