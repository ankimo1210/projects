## 採点器の限界 — 点数は手動補正していません

- レポートの章確認は英語キーワード検索です。Astraには「要旨」「手法」「データ品質」「感度分析」「制約とモデルリスク」等の日本語見出しがありますが、2/9概念しか認識されず、レポート点は1.889/5です。
- 「他モデルの出力参照」の警告は、Astraの30件すべてが自分の `results/astra` を指しています。OpusのREADMEの1件、Fableのサマリーの1件もそれぞれ自身のパスです。これらの警告は他モデル成果物の閲覧を示す証拠にはなりません。
- AstraとOpusのモデル比較ファイルは `model_selected` を使っていますが、採点器は `selected_model` を要求します。内容の存在と特定キーの合致を区別すべき項目です。
- Fableの感度分析は `checks` に格納されていますが、採点器はトップレベルが3キー以上かを検査するため、感度分析チェックが不合格です。
- 元のテスト実行はunittest探索で、Astra・Sol・Fableでは各7件のみ実行されました。別途pytest全体を実行し、45／20／204／60件がすべて合格しました。
- 1回ずつの実行です。微差の順位、費用対効果、一般的な能力を断定する用途には追加の反復実験と採点器の見直しが必要です。
