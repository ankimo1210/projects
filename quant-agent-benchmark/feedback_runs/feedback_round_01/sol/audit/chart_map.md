# Chart contract and QA map

- Delivery: benchmark-required self-contained local HTML plus static PNG files generated by the CLI.
- Palette: blue baseline, orange advanced/candidate, charcoal reference; line style and labels provide non-color distinction.
- `curve.png`: question—how do baseline and advanced zero curves differ by maturity? Family—multi-series line; expected 721 ordered maturity points; unit percent; full-width report evidence.
- `forward_rate.png`: question—does the selected zero shape imply stable instantaneous forwards? Family—multi-series line; expected 721 ordered points; unit percent; zero reference line.
- `repricing.png`: question—where are native-unit repricing errors concentrated? Family—two scatter panels split by rate instruments and bonds; grain instrument; symlog axes declared.
- `model_comparison.png`: question—how do train and fixed-block holdout normalized RMSE compare? Family—grouped bar; two categories; exact metric scale and labels required.
- Final QA surface: generated HTML and the four PNG files; inspect raster dimensions, clipping, titles, axes, units, legends, and embedded-image presence.
