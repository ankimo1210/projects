# feedback_response.md — fable / feedback_round_01

原本: `results/fable`（読み取り専用、ハッシュ不変を確認）。改善版: `feedback_runs/feedback_round_01/fable/submission`。
実験の一覧は `experiments.csv`（E01–E28）、コマンドと出力は `logs/`。数値の尺度は S1（人工真値 bp）、
S2（公開データ再価格付け bp）、S3（価格付け・規約差 bp）、S4（形式・整合性 pass/fail）を混ぜずに記す。

## 共通フィードバック 1: 完了・テスト・内部整合 ≠ 良いカーブ

- **コード上の事実**: 初回はテスト 60/60、内部整合（DV01 FD vs 解析 1.3e-6）は良好だったが、真値との比較は
  1 形状（NS 風）のテスト 1 本のみだった。
- **実験**: 5 形状（flat / steep_up / inverted / humped / neg_front）× 5 条件（clean / missing20 / illiquid /
  outliers / missing20_outliers）の人工市場を、フィッタと同じ支払規約で生成し、真値ゼロ・フォワードと比較（E15, E21）。
- **結果**: advanced は 25 ケース × 3 年限帯すべてで baseline と同等以上（advanced が 0.1bp 超悪化した帯なし）。
  ただし humped + missing20 で **advanced が短期帯 RMSE 7.9bp / 最大 23bp** という弱点が出た（E18）。
  内部整合・テスト・公開データの残差では見えなかった弱点であり、フィードバックの指摘は**支持**。
- **残る不確実性**: 形状は 5 種、雑音は正規、欠損は一様ランダム。実データの構造（マイクロストラクチャ、
  ステール、系統的な規約差）は再現していない。

## 共通フィードバック 2: 弱点は年限で異なる

- **実験**: 公開データの grouped 5-fold holdout を `short T<=2 / mid 2<T<15 / long T>=15` で集計する診断を
  `model_comparison.json` に追加（E24。分割・誤差定義は初回と同一、値は初回と同一）。
- **結果 (S2, bp)**: baseline 5.21 / 2.73 / 3.31、advanced 4.82 / 2.11 / 1.56（n = 28 / 51 / 31）。
  短期帯が両モデルで最も弱く、内訳は非流動債 INS0106（−24bp、precision 最小）と 1.25Y/1.5Y OIS（±2–3bp）。
  人工データでも短期帯が最悪帯（advanced 最大 RMSE 1.05bp、修正前は 7.92bp）。**支持**。
- **未検証**: 短期帯の 1.25Y/1.5Y 誤差のうち規約由来と推定誤差由来の分離は、真値規約が不明なため不可。

## 共通フィードバック 3: baseline/advanced の採用自体は成功ではない

- 人工データで両方を真値と比較した（E15, E21）。advanced 採用は 25 ケース中 24 で S1 が改善、1 ケース（flat2/clean）
  は同等で baseline 選択。選択基準（holdout precision-weighted RMSE）は変更していない。**支持（採用根拠を真値で追認）**。

## 共通フィードバック 4: 公開規約とベンチマーク側規約の不一致（端数年限の支払日・元本日・クーポン）

- **コード上の事実**: `schedule_times` は `forward`（`n=round(T·f)`、支払日 `1/f,…,(n−1)/f, T`、accrual は一律 `1/f`）
  を既定にしていた。非既定の `ceil` は**短いスタブにも accrual 1/f を付けていた**（実装上の欠陥、E09）。
  元本は `100·D(T)`（満期日）、クーポンは `100·c/f` 一定で公開仕様どおり。
- **実験（価格付け単体、E03–E12）**: 既知 `D(T)`（6 曲線、負金利含む）に対し、schedule 関数を共有しない独立
  プライサーで比較。整数年限は全規則で一致（最大差 2.8e-14）、DV01 1.7e-10、単位往復 0、負金利で DF>0。
  端数年限は読み方で **OIS 1.25Y 267bp / 1.5Y 104bp / 3.25Y 59bp、債券 1.6Y 65bp**（yield-equivalent）の幅。
  公開データの最終カーブ上で 1.25Y/1.5Y OIS を 4 通りに再価格付けすると、level-accrual 読み（A `forward`, D `round`）
  は −1.4/+0.8bp、actual-accrual 読み（B `forward_actual`, C `ceil`）は +51/−52bp と**符号が反転**（E10, E11）。
  債券は `ceil` で 44 本中 18 本にクーポンが 1 枚増え平均 +7.5bp/最大 84bp（E12）。
- **判定**: 「level accrual の round 系読みがデータ生成と整合」は**支持**。ただし公開仕様が無言である以上、
  規約は**未確定**のまま（コード・README・MODEL_RISKS に「暫定的な解釈」と明記し、`--stub-rule forward_actual`
  を追加、`ceil` の accrual を修正して `sensitivity.json` で差を計測: E13, E14）。
  初回の「ceil は 50bp ずれ」という記述は accrual 欠陥込みの数字だったので、修正後の値（in-sample RMSE 21 → 13.2bp）に
  差し替えた。**評価側が actual-accrual で価格付けする場合、1.25Y/1.5Y 近傍に約 50bp/quote の規約リスクが残る**（未検証・解消不能）。

## 共通フィードバック 5: フォワード誤差（f = z + T z'）

- **事実**: advanced はフォワードを B-spline で直接表現し、`log D` はその厳密積分。baseline は区間線形ゼロの `z + T z'`。
- **実験 (E26)**: 公開最終カーブで解析フォワードと `−Δlog D/Δt` の差は 0.103 → 0.026 → 0.0065bp（格子 1/24 → 1/48 → 1/96、
  2 次収束）。人工データのフォワード RMSE は advanced 平均 1.3bp / 最大 6.3bp（humped+missing20 短期帯、修正後）。
  baseline は平均 7.8bp / 最大 23.7bp。フォワードの弱点が年限帯（短期）と形状（hump）に依存する点は**支持**。

## 共通フィードバック 6: 形式と数値品質の分離（S4）

- `sensitivity.json` を名前付きトップレベルキー（12 件、各 `condition` / `results` / `interpretation`）に変更。
- `model_comparison.json` に `units` と年限帯別 holdout を追加。HTML 見出しに英語ラベルを併記、`<meta charset>` を追加。
- これらは数値改善ではない（既定パスの `curve.csv` / `cleaning.csv` / `repricing.csv` / `risk.csv` は原本と**バイト一致**）。

## Fable 固有項目

1. **大規模な書き換えを前提にしない** — 既定パスの数値出力は不変。変更は価格付け診断・非既定規則の修正・
   ロバスト層の 2 ガード・形式のみ。
2. **支払規約の価格付け単体確認** — 上記 4 のとおり。整数年限は独立プライサーと一致、端数年限は幅を計測し「未確定」。
3. **ロバスト処理と年限依存ペナルティの安定性** — 25 ケースで advanced が baseline を下回る帯はなし。ただし
   (a) 疎な holdout fold で `type_scales` が `KeyError` を出す欠陥（E16、修正 V3）、
   (b) humped + 20% 欠損で単独クォートの前端 3 本が LOO スクリーン→Tukey の連鎖で棄却され 23bp 誤差（E18）を発見。
   単因子で V4a（端クラスタを LOO 除外対象から外す: 単独では効果なし E19）、V4b（単独クラスタは Tukey ではなく Huber:
   短期 7.92 → 0.70bp、改善率 0.91、E20）。他 24 ケースは変化 0.00bp（E21）、単独 +15bp 外れ値は LOO で従来どおり除外（E22）、
   公開データ出力は不変（E23）。ペナルティの λ は CV が上限 1e4 に張り付くケースが 4/25（flat・欠損）あり、
   格子上限が緩い平滑化を打ち切っている点は**未修正**（真値が平坦なケースのみで害は測定範囲では小）。
4. **感度分析 JSON の構造** — 名前付きキー化。`stub_rule_forward_actual` を追加（12 件）。
5. **実質的改善の有無** — 公開データに対する数値改善は**なし**（設計上、出力不変）。改善は「未知条件での頑健性」
   （クラッシュ 1 件、前端棄却 1 件）と「価格付け診断の正しさ」に限られる。

## 未検証のまま残る事項

- 隠し holdout・真値規約に対する効果（意図的に不参照）。
- 単独クラスタ Huber ガードが「単独の正当クォート vs 単独の小さな外れ値（LOO 閾値未満、3bp < dev < 6σ）」で
  どちらに転ぶかは、直接の実験なし。
- HTML はローカル HTTP 経由でブラウザ描画を確認した（見出し併記・スタイル・図の表示）。この確認で `{CSS}` が生文字列のまま出る退行（09:07 の head 追加時に f-string 接頭辞が落ちた）を検出し修正、回帰テストを追加した。
