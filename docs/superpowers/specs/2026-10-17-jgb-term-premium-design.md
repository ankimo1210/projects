## 1. 目的

日銀レビュー 2026-E-10「Impact of the Bank of Japan's Reductions in JGB Purchases on the
JGB Markets」（2026年8月、金融市場局・企画局）は、**2024年夏から2026年6月末までの10年金利の上昇に、
期待短期金利とタームプレミアムが「ほぼ同じ程度」寄与した**と述べている（同レビュー図3）。
分解は Imakubo and Nakajima (2015) のシャドーレートモデル（名目と実質のカーブ、Consensus Forecasts を使用）による。

この結論が**別の推定方法でも成り立つか**を、無料データだけで確かめる。
成り立たない場合、「どのモデルでも期待金利が主因」「どのモデルでもタームプレミアムが主因」「モデル依存」のどれかを示す。

範囲外: 物価連動債（実質カーブ・インフレリスクプレミアム）、サーベイ予測、日銀レビューの買い入れ減額の回帰（約10〜25bp）の追試、
日次の指標化、予測。

### 1.1 日銀レビューから確認した事実（2026-10-17 に本文を読んで確認）

- 図3: 2024年8月からの累積変化、データは2026年6月末まで。分解は Imakubo and Nakajima (2015)。
- 本文: "both factors have contributed to roughly the same degree"。期待金利の上昇は政策金利のピークの見通しの上方修正、
  タームプレミアムの拡大は需給・財政と金融政策の不確実性・海外金利などによる、と説明している。
- 図4: 10年タームプレミアムを日銀の保有比率の見通しなどに回帰（2009年1月〜2026年6月）。
  減額のストック効果は約10bp、フロー効果を含めて約25bp。
- 分解の数値そのものは公表されていない（図のみ）。追試の比較対象は「ほぼ半々」という記述になる。

## 2. 問いと判定基準（計算の前に固定する）

### 2.1 測る量

各モデルについて、10年ゼロクーポン金利 $Y_t$ を次のように分ける。

$$
E_t = \frac{1}{120}\sum_{h=0}^{119} \mathbb{E}_t\left[r_{t+h}\right], \qquad TP_t = Y_t - E_t
$$

$r_t$ は1か月物金利。$Y_t$ は**当てはめたカーブから読む観測値**で、全モデル共通（モデルの当てはめ誤差は $TP$ に入る）。
凸性の項も $TP$ に含める。期待金利が説明する割合を

$$
s = \frac{E_{t_1} - E_{t_0}}{Y_{t_1} - Y_{t_0}}
$$

とする。

### 2.2 期間

- $t_0$ = 2024年7月の最終データ日（2024-07-31。日銀が減額計画を決めた日）
- $t_1$ = 2026年6月の最終データ日（日銀レビューのデータの最終時点）
- 参考（判定に使わない）: $t_0$ を2024年8月末にした場合、$t_1$ を最新の月末にした場合（推定期間もその月まで延ばす）。

### 2.3 判定

判定に使うのは4モデル: ACM（補正なし）、ACM（バイアス補正）、シャドーレート、DNS-VAR（§4）。

| 結果 | 条件 |
|---|---|
| 半々は頑健 | 4つの点推定がすべて $0.35 \le s \le 0.65$ |
| 頑健ではない（期待金利が主因） | すべて $s > 0.65$ |
| 頑健ではない（タームプレミアムが主因） | すべて $s < 0.35$ |
| 頑健ではない（モデル依存） | 上のどれでもない |
| 判定不能 | §5 のゲートを通ったモデルが3つ未満 |

- ゲートに落ちたモデルは判定から外し、残りのモデルで同じ表を使う。
- 各モデルの90%区間（ブートストラップまたは抽出の5〜95パーセンタイル）と、区間が 0.5 を含むかも報告するが、判定は点推定で行う。
- 主対象は10年。5年（全モデル）と20年・30年（超長期用の ACM のみ、§4.5）は補足。

### 2.4 手順の縛り

1. §5 のゲート G1〜G4 をすべて実行する。日本の推定結果（$E$・$TP$・$s$）はゲートが終わるまで出力しない。
   G4 で日本のカーブ（金利そのもの）を見るのは構わない。
2. ゲートが終わったら、`config.json`（§6）に設定とコードの commit を書いて SHA-256 を記録し、日本の推定を1回だけ実行する。
3. 日本の結果を見た後で §3〜§4 の固定設定を変えない。変える必要が出たら、別の研究として新しい設計書を書く。
4. ゲートの前に固定設定を変える場合は、§9 の変更履歴に理由を書く。

## 3. データ

### 3.1 JGB カーブ

- 出所: 財務省「国債金利情報」（`jgbcm_all.csv` と `jgbcm.csv`、既存の `sources/mof_jgb.py`）。
  年限1〜40年、半年複利。財務省は各年限に固定利付国債を割り当て、その実勢利回りを3次スプラインでつないで算出している。
- 本研究ではこれを**半年利払いのパー利回り**として扱う。
- 2026-08-17 以降の分は `macrokit rates` で追加取得する（約15分。`insert_rates` が遅いのは known-limitations に記載済みで、今回は直さない）。
- 月末値: その月で `market_rates` に行がある最後の日（macrokit の営業日の規約どおり）。

### 3.2 短期金利

- 出所: 日銀「時系列統計データ検索サイト」の API `https://www.stat-search.boj.or.jp/api/v1/getDataCode`
  （認証不要、`format=json`）。無担保コール翌日物の日次 `FM01/STRDCLUCON`（1998-01-05〜）と
  月平均 `FM02/STRACLUCON`（1985年7月〜）。2026-10-17 に実際に取得して確認した。
- `market_rates` に、日次は `curve="jp_call_on"`、月平均は `curve="jp_call_on_mavg"`（`obs_date` は月初）、
  どちらも `tenor_y=1/365` として入れる。
- 用途はカーブの最短点だけ（財務省のデータは1年未満を含まない）。月末のカーブには、その月の月末以前で最後の日次値を使う。
  日次が無い1998年より前は、その月の月平均を使う。

### 3.3 ゼロクーポン金利の作り方

- 各月末に Svensson 曲線（$\beta_0,\dots,\beta_3,\tau_1,\tau_2$、$\tau_i>0$）を当てはめる。
  観測は、その日にあるパー利回り（1〜40年のうちデータのある年限）と、コール翌日物（期間 1/365 年の連続複利ゼロ金利として扱う。
  同じ日の値が無ければ、その日以前で最後の値）。
- 目的関数: 年限ごとのパー利回り誤差の二乗和（等ウェイト）。モデルのパー利回りは割引関数から閉形式で計算する
  （半年利払い: $c = 2(1-P(T))/\sum_i P(t_i)$）。
- 初期値: 前月の解と、固定した初期値格子（`curve.py` に定数で置く）の両方から解き、目的関数が最小のものを採る。決定的に動く。
- 出力: 連続複利のゼロ金利（年率 %）を、期間1〜120か月（月刻み）と補足用に121〜360か月で出す。

### 3.4 推定期間（判定用に固定）

- 1986年8月〜2026年6月（約479か月）。10年金利がそろう最初の月から始め、使える最長を取る。期間を選ぶ余地を残さないため。
- 補足（判定に使わない）: 2004年1月〜、2009年1月〜（日銀レビューの回帰と同じ）。
- 30年・40年は1999年以前に無いが、120か月までのモデルには影響しない。

### 3.5 検証用の米国データ

- FRB の Gürkaynak-Sack-Wright（GSW）ゼロカーブ（`feds200628.csv`、Svensson パラメーター、日次）。月末値を使い、
  パラメーターから期間1〜120か月のゼロ金利を計算する。
- NY 連銀の ACM タームプレミアム公表値（月末値）。NY 連銀は GSW と CRSP の非公開データで推定しているので、完全一致は求めない（§5 G2）。
- Wu-Xia の米国シャドーレート公表系列（入手できれば）。
- 2026-10-17 に取得して確認した形式:
  - GSW: `https://www.federalreserve.gov/data/yield-curve-tables/feds200628.csv`。説明文のあとに `Date,BETA0,...` の見出し行。
    欠測は `NA`、Nelson-Siegel の日は `BETA3=0`・`TAU2=-999.99`。1961-06-14〜。
  - NY 連銀 ACM: `https://www.newyorkfed.org/medialibrary/media/research/data_indicators/ACMTermPremium.xls`（旧形式の .xls、`xlrd` が必要）。
    シート `ACM Monthly`、`DATE` は `30-Jun-1961` 形式の文字列、列 `ACMY01..10`・`ACMTP01..10`・`ACMRNY01..10`。
  - Wu-Xia: アトランタ連銀 `WuXiaShadowRate.xlsx`（`openpyxl` が必要）。シート `Data`、A列が月初の日付、C列がシャドーレート。
    更新は2022年2月で停止している（ゼロ金利期間の比較には足りる）。

### 3.6 保存

- 取得データはすべて macrokit の snapshot（`data/raw` と `manifest.jsonl`）を通す。米国データは DuckDB に入れない。
- 合計は数十 MB 以内の見込み（GSW の CSV が最大）。中間配列（ブートストラップの各回の値など）は保存しない。

## 4. モデル

全モデル共通の入力: 月末のゼロ金利 $y_t^{(n)}$（連続複利、$n$ か月）。1か月物金利 $r_t = y_t^{(1)}$。

### 4.1 ACM（補正なし）

Adrian, Crump and Moench (2013) の回帰3段階。

- 因子 $X_t$: 期間 3, 6, …, 120 か月（3か月刻み、40年限）のゼロ金利の、平均を引いた共分散行列の主成分5つ（$K=5$）。
- 超過収益: $rx_{t+1}^{(n-1)} = \ln P_{t+1}^{(n-1)} - \ln P_t^{(n)} - r_t$、$n \in \{6, 12, 24, 36, 48, 60, 72, 84, 96, 108, 120\}$（11年限）。
- 手順: ① $X_{t+1} = \mu + \Phi X_t + v_{t+1}$ を OLS。② $rx_{t+1} = a + \beta' v_{t+1} + c X_t + e_{t+1}$ を OLS。
  ③ $\lambda_1 = (\beta\beta')^{-1}\beta c'$、$\lambda_0 = (\beta\beta')^{-1}\beta(a + \tfrac12(B^* \mathrm{vec}\,\Sigma + \sigma^2\iota))$。
  ④ $r_t = \delta_0 + \delta_1' X_t$ を OLS。⑤ 価格の再帰式で $A_n, B_n$ を出す。
- 期待金利: $\mathbb{E}_t[r_{t+h}] = \delta_0 + \delta_1'\,\mathbb{E}_t[X_{t+h}]$（物理測度の VAR を反復）。§2.1 の $E_t$ を作る。
- 90%区間: VAR 残差の iid ブートストラップ1,000回で $X$ の経路を作り直し、$(\mu,\Phi)$ を再推定して、実際の $X$ の履歴で $E$ を計算し直す。
  区間は物理測度の推定誤差だけを反映する（リスク中立側は固定）。

### 4.2 ACM（バイアス補正）

- 4.1 と同じ推定のあと、物理測度の $\Phi$ だけを Kilian (1998) のブートストラップ（1,000回）で小標本バイアス補正する。
  補正後の最大固有値の絶対値が1以上なら、補正量を 0.01 刻みで縮めて定常にする。$\mu$ は標本平均を保つよう $\tilde\mu = (I-\tilde\Phi)\bar X$ とする。
- リスク中立の動学（$\mu^Q = \mu - \lambda_0$、$\Phi^Q = \Phi - \lambda_1$）は 4.1 の値に固定する。当てはめた金利は変わらず、期待金利だけが変わる。
- 90%区間: 4.1 の外側のブートストラップ1,000回の各回で、内側の補正（1,000回）をやり直す。

### 4.3 シャドーレート

Wu and Xia (2016) の3因子モデル。

- 短期金利 $r_t = \max(r_L, s_t)$、シャドーレート $s_t = \delta_0 + \delta_1' X_t$。$X_t$ は物理測度・リスク中立測度とも Gaussian VAR(1)。
  識別の正規化は Wu and Xia (2016) に従う。
- 観測: 期間 3, 6, 12, 24, 60, 84, 120 か月の1か月物フォワード金利（ゼロ金利から計算）。誤差は iid。
  フォワードの近似式 $f \approx r_L + \sigma^Q_n\, g\!\left(\frac{a_n + b_n'X_t - r_L}{\sigma^Q_n}\right)$、$g(z) = z\Phi(z) + \phi(z)$。
- 推定: 拡張カルマンフィルタによる準最尤法。初期値は固定した20通り（`shadow.py` に定数で置く）から解き、尤度が最大のものを採る。
  尤度は複数のパラメーターを1回でまとめて計算し（勾配の差分も1回で出す）、初期値ごとに別プロセスで解く。
  予測と更新のたびに状態の共分散を対称化する（試作では、しないと70期ほどで数値的に壊れた）。
- 下限 $r_L = -0.10\%$（日銀の政策金利の最低値）に固定。米国の検証では Wu-Xia と同じ 0.25%。
- 期待金利: フィルタ後の状態 $X_{t|t}$ から、$s_{t+h}$ の条件付き平均 $m_h$ と分散 $v_h$（物理測度の動学のみ）を出し、
  $\mathbb{E}_t[\max(r_L, s_{t+h})] = r_L + (m_h - r_L)\Phi(d) + \sqrt{v_h}\,\phi(d)$、$d = (m_h - r_L)/\sqrt{v_h}$。
- 90%区間: 最尤推定のヘッセ行列から求めた共分散でパラメーターを500回抽出し、$E$ を計算し直す。

### 4.4 DNS-VAR

Diebold and Li (2006)。無裁定ではないので基準線として使う。

- 毎月、期間 3, 6, …, 120 か月のゼロ金利に Nelson-Siegel の3因子を OLS で当てはめる。減衰 $\lambda = 0.0609$（月あたり、Diebold-Li の値）。
- 3因子に VAR(1) を当て、$r_t$ は NS 曲線の期間1か月の値として予測する。
- 90%区間: VAR 残差の iid ブートストラップ1,000回（4.1 と同じ考え方）。

### 4.5 目安と補足（判定に使わない）

- 目安1（タームプレミアム一定）: $s = 1$。
- 目安2（据え置き予想）: $\mathbb{E}_t[r_{t+h}] = r_t$、つまり $\Delta E = \Delta r_t$。
- 因子3つの ACM（$K=3$）。
- 超長期用の ACM: 1999年9月〜2026年6月、因子は期間 3〜360 か月（3か月刻み）の主成分5つ、超過収益は 4.1 の11年限に 180, 240, 300, 360 か月を加える。
  20年・30年の補足だけに使う。
- 2004年1月〜、2009年1月〜の推定期間（4モデルとも）。

### 4.6 乱数

すべてのブートストラップと抽出は固定シード（`config.json` に記録）で決定的に動く。

## 7. テスト
