# 競馬の単勝で市場に勝てるかの反証（keiba_lab）設計書

- 日付：2026-10-27。状態：会話で部分ごとに確認した内容をまとめた初版。設計書としてはユーザーの承認前。
- 発端：ユーザー「過去データから勝つ馬を予想できるんじゃないか」（2026-10-25）。
- 目的の決定（ユーザー、2026-10-26）：的中率ではなく、オッズ（市場の予想）より上手く買えて回収率が100%を超えるかを確かめる。今回は過去データで判定を出すところまで。実際にお金を賭けるかは、判定を見てから決める。
- データの許可（ユーザー、2026-10-27）：netkeiba（スクレイピング）・JRA-VAN データラボ・JRDB の3つとも許可を取得済み。規約の範囲を超える使い方と、公開リポジトリにデータを置くことも含む。

## 1. 目的

中央競馬（JRA）の平地競走の単勝について、過去データから作った「能力モデル」の勝率を、市場の勝率（単勝オッズから逆算したもの）と合成する。そのうえで次の2つを判定する。

- A（情報）：合成したモデルは、市場だけのモデルより勝ち馬をよく当てるか。つまり、市場が織り込んでいない情報を持っているか。
- B（利益）：その情報で控除率（単勝20%）を越えられるか。つまり、締切前に分かるオッズで買う馬を決め、確定オッズで払い戻されたときに、回収率が100%を超えるか。

的中率は目的にしない。A は通るが B は通らない（情報はあるが控除率に食われる）という結果も、それ自体が答えになる。

### 1.1 やらないこと

- 実際の馬券の購入、レース直前のオッズの取り込み、毎週の予想。B が通ったときの次の段階（§12）で扱う。
- 単勝以外の券種、地方競馬（NAR）、障害競走。
- 賭け金の最適化（Kelly など）。判定は定額で出し、Kelly は診断として報告するだけにする。

### 1.2 失敗とみなすこと

- 締切後にしか分からない、そのレースの確定オッズを、買うかどうかの判断や合成の推定に使うこと。
- 特徴量に、そのレースの時点では分からない情報が入ること。
- 本番の期間を見てから、モデル・期間・買い方を変えること。
- 大穴が数本当たっただけの「回収率100%超え」を「儲かる」と判定すること。

## 2. 先行研究と既知の事実（2026-10-27 に確認）

- Benter, W. (1994). "Computer Based Horse Race Handicapping and Wagering Systems: A Report." In D. B. Hausch, V. S. Y. Lo, W. T. Ziemba (eds.), *Efficiency of Racetrack Betting Markets*, 183–198。原文の PDF で確認した。
  - データは香港の全レース（1986-09〜1993-06、3,198レース・32,877頭）。能力モデルは Bolton–Chapman の多項ロジット。
  - 能力モデルの勝率 $f$ と市場の勝率 $\pi$ を、別の標本で $c_i \propto \exp(\alpha \log f_i + \beta \log \pi_i)$ と合成する（式1）。$f$ には out-of-sample の値を使う。
  - 精度の尺度は Bolton–Chapman の擬似 $R^2 = 1 - L(\text{model})/L(1/N)$（$L$ は対数尤度）。結果は、市場 .1218、能力モデル単独 .1245、合成 .1396。能力モデル単独の精度は市場と同程度だが、市場と食い違う向きに偏っていて（表3・4）、そのままでは賭けに使えない。合成すると偏りが消える。
  - 9要因の簡単なモデル（2,313レース）は、単独では .1016 と市場（.1237）を下回るが、合成すると .1327 になる。予想家48人の印を集計したもの（単独 .1014）は、合成しても .1239 で、市場にほとんど何も足さない。価値の尺度は単独の精度ではなく、合成で増えた分 $\Delta R^2 = R^2_C - R^2_P$ である（.0178 と .0090 は、利益が出る大きさだったと書いている）。
  - 賭け方：期待値 = 合成の勝率 × 配当が1を超えるものに、分割 Kelly で賭ける。控除率は平均約19%。5シーズン中4シーズンで純益。
  - 確定オッズについて：確定オッズを正確に見積もれることが不可欠だと書いている。売上の少ない競馬場では発走数分前のオッズを使うしかなく、その不正確さがモデルの効果を下げる。
  - 自分の賭けで配当が下がるため、現実的な期待利益の上限は1レースの売上の0.25〜0.5%程度だと書いている。
- Bolton, R. N., Chapman, R. G. (1986). "Searching for Positive Returns at the Track: A Multinomial Logit Model for Handicapping Horse Races." *Management Science* 32(8), 1040–1059。
- 本命・大穴バイアス：人気薄ほど買われすぎていて、回収率が低い（Ali 1977, *JPE* 85, 803–815 ほか）。
- JRA の払戻率（2014-06-07 以降）：単勝・複勝 80%、馬連・ワイド 77.5%、3連単 72.5%（JRA と兵庫県競馬組合の告知で確認）。
- JRA プレミアム：年度ごとに指定したレースと券種で、払戻金を上乗せする。JRA スーパープレミアムは、指定した券種の払戻率を80%にする。対象のレースは単勝の払戻率が通常と違いうる。
- JRA のレース数は年に約3,450（障害を含む）。

## 3. 問いと判定（計算の前に固定する）

### 3.1 賭け方

- 券種は単勝。賭け金は1頭につき定額（1単位）。
- 判断の時点 τ：締切前オッズの時刻。レースごとに決まる。
  - JRA-VAN の時系列オッズを使うとき：発売の締切（発走の2分前。S0 でデータから確かめる）より前に記録された、最後のスナップショットの時刻。
  - JRDB の直前情報（TYB）を使うとき：TYB のオッズ取得時刻。TYB の単勝オッズは1頭に1つだけで、各レースの発走15分前ごろに作られる（JRDB の仕様書による）。
- 買う条件：$EV_i = p^{C}_i \cdot o_{\tau,i} \ge k$ の馬をすべて買う（1レースで複数頭買うこともある）。$p^{C}$ は合成の勝率（§6.3）、$o_\tau$ は τ のオッズ。$k$ は開発期間だけで、6つ以下の候補から選ぶ（§6.4）。
- 払戻：JRA の確定払戻金のデータをそのまま使う（同着・特払い・JRA プレミアムを含む）。τ のあとに取消・除外になった馬への賭けは返還（賭け金が戻る）。
- τ のオッズがそろわないレースは判定から除き、その数と理由を報告する。
- 自分の賭けがオッズを動かす影響は無視する（§13）。

### 3.2 期間

年は S0（§4.2）のあとで PREREG に書く。

| 名前 | 期間 | 使い方 |
|---|---|---|
| 履歴 | 1986〜 | 過去成績の特徴量を作るためだけに使う |
| 能力モデルの学習 | 履歴の始め〜各年の前年末 | 毎年1月に学習し直す（ウォークフォワード） |
| 開発 | 締切前オッズがある最初の年（第1段の学習に数年分の履歴がたまってから）〜本番の前年（2年以上） | 市場モデルの補正、合成の推定、能力モデルの選択、$k$ の選択 |
| 本番 | 締切前オッズがある最後の5暦年（2021〜2025）。締切前オッズが10年分に満たないときは最後の3暦年 | 判定。1回だけ回す |
| 追試 | 2026-01〜取得した時点 | 判定のあとに1回だけ回して報告する。検出力が低いので判定には使わない |

締切前オッズが5年分（開発2年＋本番3年）に満たないときは、§4.2 の分岐3（B は保留）になる。

### 3.3 指標と検定

- A：本番の期間で、1レースあたりの対数尤度の差 $\Delta LL = \frac{1}{R}\sum_r \left[\log p^{C}_{w(r)} - \log p^{M0}_{w(r)}\right]$ を出す（$w(r)$ はレース $r$ の勝ち馬、$M0$ は市場モデル §6.1）。開催日（日付）単位のブロック・ブートストラップ（1万回、乱数の種は固定）で片側検定する。$H_0: \Delta LL \le 0$。Benter と比べるため、擬似 $R^2$ と $\Delta R^2$ も出す。
- B：本番の期間の回収率 $\rho = \sum \text{払戻} / \sum \text{賭け金}$ を出し、同じブートストラップで片側検定する。$H_0: \rho \le 1$。あわせて、賭けた数・的中数・平均オッズ・年ごとの回収率・最大ドローダウンを出す。
- 本番で検定するモデルは1本だけ（§6.4 の規則で開発期間に選ぶ）なので、多重検定の補正はしない。

### 3.4 判定

| 判定 | 条件 |
|---|---|
| `profitable` | ① A と B がどちらも5%で有意。② 本番の年ごとの回収率の点推定が、過半の年で1を超える（数本の大穴に頼った結果を除くため）。③ $k$ を候補の隣の値にしても、本番の回収率の点推定が1を超える |
| `informative_only` | `profitable` ではなく、A が5%で有意 |
| `no_edge` | A が有意でない |
| `informative_b_deferred` | 分岐3（締切前オッズが足りない）のときだけ使う。市場を確定オッズにして A を判定し、有意ならこれ、有意でなければ `no_edge` |

- ② は、真の優位が+5%のとき、本番5年なら約97%、3年なら約93%の確率で満たす（1年の回収率の標準誤差を約5%として計算）。正しい優位を落としにくい大きさにしてある。
- `profitable` か `informative_b_deferred` のときだけ、段階 S3（§12）を設計する。

## 6. モデル

### 6.1 市場モデル M0（比べる相手）

- $q_i = (1/o_{\tau,i}) / \sum_j (1/o_{\tau,j})$ とし、本命・大穴バイアスを補正した $p^{M0}_i \propto q_i^{\gamma}$ を基準にする。$\gamma$ は開発期間で、条件付きロジットの最尤法で推定する。
- 補正なしの $q$（Benter の「市場」に当たる）の成績も報告する。

### 6.2 能力モデル（第1段）

- 形：1レースの中で $P(i \text{ が勝つ}) = e^{s_i}/\sum_j e^{s_j}$（条件付きロジット）。
- M1：線形 $s_i = w^\top x_i$。L2 正則化つきの最尤法で推定する。
- M2：scikit-learn の HistGradientBoosting（勝ち・負けの2値）の log-odds を $s_i$ とし、レースの中でソフトマックスにする。新しい依存（LightGBM など）が必要になったら、ユーザーに聞く。
- M3（市場を織り込んで学ぶモデル）：$s_i = \beta \log q_i + w^\top x_i$ を条件付きロジットで推定する。特徴量の重み $w$ は「市場が見落としている分」だけを学ぶ。学習に使うオッズは、τ のオッズがある年はそれ、ない年は確定オッズ（どちらも、そのレースの年より前のレースだけ）。
  - 加えた理由：レビューの合成データの実験（1レース14頭、学習4万・開発2万・本番1万レース、市場だけが知る情報と能力の特徴量の誤差がそれぞれ市場の対数勝率の分散の15〜30%）で、W1 と同じ大きさの埋め込み（オラクルで約4標準誤差）を、2段構え（M1）は20回中5〜7回しか検出できなかった。能力モデルの「市場と食い違う部分」の大半が、市場だけが知る情報を再現しきれない誤差で、合成の係数 $\alpha$ が1つだけなので、埋め込んだ情報もその誤差と一緒に薄められるため。同じ世界で M3 は20回中20回検出した（2026-10-27）。
- 特徴量の候補（開発期間で増減してよい）：
  - スピード指数（走破タイムを、コース・距離ごとの基準タイムとその日の馬場差で補正したもの）：前走、近3走の最高と平均
  - 近走の着順と着差、クラス、前走からの日数、距離の変化
  - 距離・芝ダート・コースの適性（似た条件での過去成績）、上がり3ハロンの順位
  - 斤量とその変化、馬体重とその増減、枠・馬番（コースごと）、年齢、性別、頭数
  - 騎手・調教師の成績（as-of の移動集計）、種牡馬の芝ダート別・距離別の成績
  - 調教タイム（坂路など。データがある期間だけ）
- 過去走がない馬（新馬戦や他地区からの転入など）には欠損の印を持たせる。合成では市場に寄ることになる。

### 6.3 合成（第2段）

- $p^{C}_i \propto \exp(\alpha \log \hat f_i + \beta \log q_i)$。$\hat f$ は第1段の out-of-sample の勝率（そのレースの年より前のデータで学習したもの）。開発期間で、条件付きロジットの最尤法で推定する。M3 のときは $\hat f$ を M3 の勝率にする（M3 は市場を含むので、ここでは τ のオッズへの合わせ直しになる）。
- $\alpha$ と $\beta$ を信頼区間つきで報告する。$\alpha = 0$ なら、能力モデルは市場に何も足していない。

### 6.4 能力モデルの選び方と買い方

- M1・M2・M3 のうち、開発期間の $\Delta LL$（合成 対 M0）が最も大きいものだけを本番に送る。
- $k$ は候補 {1.00, 1.05, 1.10, 1.20, 1.30, 1.50}（PREREG で確定する）から、開発期間の回収率で選ぶ。開発期間で賭けた数が2,000未満になる候補は選ばない。

## 7. 判定のあとの診断（判定には使わない）

- A'：市場を確定オッズにした A。市場の情報が最も多い時点と比べるので、A より厳しい。
- 合成と M0 の較正：予測した勝率の帯ごとの実際の勝率（Benter の表1〜7 に当たるもの）。
- 回収率を、オッズの帯・頭数・芝ダート・年ごとに分けたもの。
- 買った馬の $o_{\text{final}}/o_\tau$ の分布。締切直前に入るお金が、買った馬に不利な向きに動くかを見る。
- 分割 Kelly（1/2・1/3）で賭けた場合の資産の推移。
- 特徴量のグループを1つずつ外したときの $\Delta LL$ の減り方。市場にない情報をどこが持っているかを見る。
- 追試（2026-01〜）の A と B。
- τ をひとつ前のスナップショットにした B（JRA-VAN の時系列オッズを使うときだけ）。

## 13. 既知のリスク

- JRA の単勝は売上が大きく、市場は効率的とみられる。一番ありそうな結果は `informative_only` か `no_edge`。
- 締切前オッズが何年分遡れるかは分かっていない。短ければ B は保留になる。
- τ のあとに入るお金（締切直前の大口）で、買った馬のオッズが下がりうる。払戻は確定オッズなので、本番の回収率にはこの影響が入る。
- B の検出力：平均オッズ10倍の馬を1レース1頭買うとして計算した。本番5年（約1.7万レース）なら回収率の標準誤差は約2.3%で、真の優位が+5%なら約70%、+10%ならほぼ確実に検出できる。本番3年（約1万レース）なら標準誤差は約3%で、+10%なら約95%だが、+5%は約半分しか検出できない。
- TYB を使うときは、τ が発走の15分前ごろになる。締切までの十数分に入るお金の影響が大きくなり、その分 B は不利になる（現実に15分前に買う人の成績としては正しい）。
- 自分の賭けがオッズを動かす影響を無視している。賭け金を大きくすると回収率は下がる（Benter は、現実的な期待利益の上限を1レースの売上の0.25〜0.5%程度としている）。
- JV-Data の解析の誤りや、成績の訂正がありうる。G0 で netkeiba と突き合わせる。
- 時代による変化（2019年のクラス名の変更、無観客開催の期間など）。特徴量では、クラスを名前ではなく数値の段階で持つ。
- JRA プレミアムの対象レースは払戻率が違う。払戻金のデータをそのまま使い、G0 で別に確かめる。
