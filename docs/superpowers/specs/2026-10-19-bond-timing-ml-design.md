## 1. 目的

米国債 ETF（TLT・IEF）を、月末ごとに「持つか、現金か」で切り替える売買シグナルを作る。そのシグナルが、時点の規則を守り費用を引いたあとでも、ずっと持ち続けることと単純なルールに勝つかを判定する。機械学習（ML）は、単純なルールと線形モデルに費用込みで勝つときだけ採用する。

日本（2561、JGB）は同じ仕組みで次の段階 S2 として行う（§12）。

## 2. 原論文と既知の問題（2026-10-19 に確認）

- 原論文：Bianchi, Büchner, Tamoni, "Bond Risk Premiums with Machine Learning", RFS 34(2), 1046–1089（2021、doi:10.1093/rfs/hhaa062）。
  - データ：Liu–Wu のゼロ金利（1971:08〜2018:12）、FRED-MD の128系列（McCracken–Ng）。
  - 予測：1990:01 から、毎月の拡張窓で再推定する。学習と検証は 85% と 15% に分け、検証は学習の直後の期間（連続）。NN の初期値は固定した100通りで、予測を平均する。計算は2,300コアのクラスター。
  - 訂正前の原稿の値（WRAP の受理稿）：フォワードレートだけの NN（1層3ノード）で R²oos は 2年 12.7%〜10年 26.4%、満期均等のポートフォリオで 23.0%。マクロを加えた NN のグループ・アンサンブルで 20.0%〜36.3%。
- 訂正論文：Bianchi, Büchner, Hoogteijling, Tamoni, "Corrigendum: Bond Risk Premiums with Machine Learning", RFS 34(2), 1090–1103（doi:10.1093/rfs/hhaa098）。「予測の時点で入手できない情報を使っていた」ことを直した。out-of-sample の R² は下がったが、NN の予測力は統計的にも経済的にも有意なまま、と要旨にある。訂正後の数値と、何を直したかの中身は有料で、確認できていない。
- 関係する先行研究：
  - Ghysels, Horan, Moench (2018, RFS 31(2) 678–714)：改定前（実時間）のマクロデータを使うと、マクロ変数の予測力が大きく下がる。
  - Bauer, Hamilton (2018, RFS 31(2) 399–448)：持続性の高い説明変数と重なった収益のもとでは、小標本のゆがみで「利回り以外も効く」と見えやすい。spanning の帰無仮説のもとでのブートストラップを提案した。
- この研究で特に疑う点：
  1. 1年保有の超過収益を毎月とると、目的変数が11か月重なる。学習の最後の11か月の目的変数は、予測の時点でまだ確定していない。これを学習や検証に入れると先読みになる（訂正の中身はこれかもしれないが、確かめていない）。
  2. 確定値のマクロデータは、当時は入手できなかった改定を含む。
  3. 窓の重なりは、学習なしでも高い見かけの精度を作る（候補4で、重なりのない目的変数では AUC が 0.5 前後に落ちた）。

## 3. 問いと判定（計算の前に固定する）

### 3.1 売買の形

- 判断は月末 t の終値の時点。翌月（t→t+1）の配分を、対象の債券 ETF 100% か現金 100% かで決める（主）。比率を 0〜100% で決める型は副とし、判定に使わない。空売りはしない。
- 対象：TLT 型（主、判定に使う）と IEF 型（副）。
- 費用：切り替え1回で2本を売買する（債券 ETF と短期国債 ETF）。1本あたり片道1bp、切り替え1回で2bp を、切り替えた月のリターンから引く。感度は4bp。
- 税と為替は扱わない。米ドル建てで評価し、切り替えの回数を報告する。

### 3.2 期間

| 名前 | 期間 | 使い方 |
|---|---|---|
| 開発 | 1971-08〜1999-12（TLT 型は 1982-08〜） | 形の確認と、最良の単純ルールを選ぶことだけ |
| 本番 A | 2000-01〜2018-12（228か月） | 主の判定。実時間のマクロがある期間 |
| 本番 B | 2019-01〜最新 | 論文の公表後。最後に1回だけ回す |

### 3.3 指標と検定

- 戦略の月次の超過リターン（現金に対する、費用控除後）$r_t$ から、確実性等価 $\mathrm{CER}=12\,(\bar r-\tfrac{\gamma}{2}\,\mathrm{var}(r))$（$\gamma=5$、年率）とシャープレシオを出す。
- 比べる量は、同じ月の2つの戦略の差。重ならない月次の系列なので、窓の重なりは判定に入らない。
- 検定：差の系列に定常ブートストラップ（Politis–Romano、平均ブロック長12か月、1万回、乱数の種は固定）をかけた片側検定。CER の差とシャープの差の両方を出し、判定には CER の差を使う。
- 予測の精度として R²oos（Campbell–Thompson、過去平均に対して）も出すが、判定には使わない。

### 3.4 主な戦略と多重検定

主な戦略は5本に限る。

| 記号 | 階段 | 中身 |
|---|---|---|
| P1 | L1 | 開発期間の費用控除後 CER で、3つの単純ルール（傾き・trend・CP）から1つ選んで固定する |
| P2 | L2 | 利回りの主成分3つの回帰 |
| P3 | L2 | 主成分3つ＋実時間のマクロ因子8つの回帰 |
| P4 | L3 | NN（フォワード＋マクロ、初期値20通りの平均） |
| P5 | L3 | Extra Trees（フォワード＋マクロ） |

- 仮説 $H_A(k)$：本番 A で、戦略 k の CER がずっと保有（L0）を上回る（k=P1〜P5、Holm で5本を補正）。
- 仮説 $H_B(k)$：本番 A で、ML の戦略 k の CER が P1 を上回る（k=P4・P5、Holm で2本を補正）。
- 有意水準は5%（片側、補正後）。

### 3.5 判定

| 判定 | 条件 |
|---|---|
| `ml_signal_usable` | P4 か P5 のどちらかが、次をすべて満たす。① $H_A$ と $H_B$ が補正後に有意。② 本番 B で、L0 と P1 に対する CER の差がどちらも正。③ 費用4bp と、5営業日遅れの執行（§5 の R5）のどちらでも、本番 A の2つの差の符号が変わらない。④ マクロを使うので、§8 の G3（Bauer–Hamilton 型）の p 値が 0.05 未満 |
| `simple_rule_usable` | `ml_signal_usable` でなく、P1〜P3 のどれかが、$H_A$ で補正後に有意、本番 B の L0 に対する差が正、③と同じ頑健性を満たす |
| `no_usable_signal` | 上のどちらでもない |

- 判定は TLT 型だけで出す。IEF 型と実際の ETF のリターンでの結果は、補足として報告する。
- `ml_signal_usable` か `simple_rule_usable` になったときだけ、段階 S3（毎月のシグナル配信）を設計する。

### 3.6 手順の縛り

- §3 の判定・§6 のモデルと候補の値・§7 の分解・§8 の確認の手順を、本番 A を回す前に `bond_timing_lab/PREREG.md` に書いて commit する。PREREG の commit を結果に記録する。
- §8 の確認（G0〜G2）を、本番 A の結果を見る前にすべて通す。
- 本番 B は、本番 A の判定と頑健性の確認を終えて記録してから、1回だけ回す。回したあとにモデルや期間を変えたら、その旨と理由を結果に書き、判定は最初の1回で出す。

## 4. データ

### 4.1 米国の金利

- GSW（FRB `feds200628.csv`）：Svensson のパラメーター（日次、1961-06〜）。macrokit の snapshot（`macrokit us-term`、`macrokit/data/raw/us_term/gsw/`）を読む。macrokit の `parse_gsw`・`month_end_days`・`gsw_zero` を使う。
  - GSW は年限ごとに公表の範囲が違う：1〜7年は1961-06、10年は1971-08、15年は1971-11、20年は1981-07、25〜30年は1985-11 から。範囲の外の年限は、パラメーターから計算できても使わない（日ごとに、公表されている最長の年限で打ち切る）。
- Liu–Wu（Cynthia Wu のページ、月次、1961〜2025）：§7 の論文に近い設定と、GSW との比較に使う。実際の配信（S3）には使わない（更新が遅いため）。

### 4.2 現金

- FRED の DTB3（3か月物 T-bill、日次）を、キーなしの CSV（`fredgraph.csv?id=DTB3`）で取る。月末 t の値を、翌月の現金の利回りとする（年率を12で割る）。
- 予備として TB3MS（月平均、1934〜）も取り、DTB3 の欠けを埋めない（欠けた月は一覧にする）。

### 4.3 債券のリターン

- 合成：満期 n 年のゼロクーポン債を月末 t に買い、t+1 に満期 n−1/12 年として売る対数リターン $r_{t+1}(n)=n\,y_t(n)-(n-\tfrac{1}{12})\,y_{t+1}(n-\tfrac{1}{12})$（$y$ は連続複利の小数）。
  - TLT 型：n=17年（TLT の実効デュレーションに近い）。GSW の20年が公表される1981-07 から作れる。
  - IEF 型：n=7.5年。1971-08 から。
  - 1年保有の超過収益（論文と同じ定義）：$rx_{t+12}(n)=n\,y_t(n)-(n-1)\,y_{t+12}(n-1)-y_t(1)$、n=2〜10年（§7 の分解と、目的変数の副に使う）。
- 実際の ETF：TLT・IEF・BIL の日次の配当込み価格（yfinance、2002-07〜。BIL は 2007-05〜）。合成のリターンとの一致を G0 で確かめる。
- 5営業日遅れの執行には、GSW の日次パラメーターから作る日次の合成リターンを使う。

### 4.4 マクロ（FRED-MD のビンテージ）

- St. Louis Fed の FRED-MD ページから取る。
  - 1999-08〜2014-12 の zip（45 MB）、2015-01〜2025-12 の zip（35 MB）、2026年の月次 CSV（`monthly/YYYY-MM-md.csv`。2026-08 だけ `2026-rev-08-md.csv`）。
- 各ビンテージの2行目にある変換コード（tcode）で、そのビンテージの中だけで変換する。系列の構成はビンテージごとに変わるので、ビンテージの中にある系列だけを使う。
- 公開日がページに書かれていないので、月末 t の判断には、ビンテージ t−1 を使う（確実に出ている）。ビンテージ t を使う場合は感度として報告し、判定に使わない。
- 論文に近い設定（§7 の V0）には、ビンテージ 2019-02 を「確定値」として使う（論文の標本の終わり 2018-12 を含む最初の時期のもの）。

### 4.5 保存

- 生データは Git 管理外の `/home/kazumasa/projects/_data/bond_timing_lab/raw/` に置き、macrokit の `save_snapshot` で manifest（SHA-256・URL・取得時刻）を残す。合計は約150 MB の見込み。
- Git に残すのは、コード、PREREG、結果の要約 JSON、README の表。中間の配列（各ブートストラップの値、各学習の予測など）は保存せず、固定した種から作り直す。

## 5. 時点のルール

| 番号 | ルール | 検査 |
|---|---|---|
| R1 | 月末 t の判断には、t までに観測できたデータだけを使う。金利は t の終値、マクロはビンテージ t−1 | 特徴量の各列に「観測できた時点」を持たせ、t より後のものがあれば例外にする |
| R2 | 学習には、目的変数が t までに確定した組 $(x_s, y_{s\to s+h})$、$s+h\le t$ だけを使う（h=1 か 12か月） | 学習の組を作る関数が、最後の目的変数の終わりと t を比べて例外にする |
| R3 | 候補の値の選択は、学習期間の後ろ15%を検証に使い、学習と検証の目的変数の間に h か月の空白を置く | 空白の長さを検査する |
| R4 | 標準化・主成分・欠損の補完は、毎回その時点の学習データだけで作る | 学習の窓の外のデータを渡すと例外にする |
| R5 | 執行は月末の終値（主）。感度として、翌月の5営業日目の終値で入れ替える | 2つの執行の結果を並べる |

## 6. モデル

### 6.1 特徴量

| 記号 | 中身 |
|---|---|
| F | 1年金利と、1年ごとのフォワード $f_t(n)=n\,y_t(n)-(n-1)\,y_t(n-1)$、n=2〜10（10本） |
| P | 1〜10年金利の主成分3つ（学習の窓の中で作る） |
| CP | Cochrane–Piazzesi 因子（学習の窓の中で、満期平均の超過収益を F に回帰した予測値） |
| M | FRED-MD の変換後の系列（標準化。窓の中で欠損が多い系列は外す）。線形モデルには主成分8つ |
| X | 対象の債券の過去12か月の超過リターン、過去12か月の実現ボラティリティ、10年−3か月の傾き |

### 6.2 階段

- L0：ずっと保有、ずっと現金。
- L1：単純なルール3つ。どれも候補の値を持たない。
  - 傾き：GSW の10年ゼロ金利 − DTB3 が正なら保有。
  - trend：対象（TLT 型か IEF 型）の過去12か月の累積超過リターンが正なら保有。
  - CP：CP 因子による満期平均の超過収益の予測が正なら保有（CP の回帰は R2 を守って毎年1月に推定し直す）。
  - P1 には、開発期間の TLT 型の費用控除後 CER が最も高いものを選ぶ。比べるのは、3つのルールがそろっている月だけ。
- L2：P の OLS。P＋マクロ因子8つの OLS。
- L3：
  - Elastic Net（F＋M、l1_ratio ∈ {0.1, 0.5, 0.9}、α は対数で等間隔の20点）。
  - Extra Trees（F＋M、木500本、最大の深さ ∈ {2, 4, 6}、葉の最小の数 ∈ {5, 20}、max_features ∈ {0.3, 1.0}）。
  - 勾配ブースティング（scikit-learn の HistGradientBoosting、学習率 ∈ {0.03, 0.1}、深さ ∈ {2, 3}、回数 ∈ {100, 300}、L2 ∈ {0, 1}）。
  - NN-F（F だけ、1層3ノード。論文で金利だけのときに最もよかった形）と NN-FM（F＋M、2層 32・16ノード、L2 の重み ∈ {1e-4, 1e-3, 1e-2}）。scikit-learn の MLPRegressor（adam、500回）。初期値は固定した20通りで、予測を平均する。

### 6.3 目的変数と再推定

- 目的変数の主は、論文と同じ1年保有の超過収益のうち、10年ゼロのもの $rx_{t+12}(10)$。1971-08 から作れるので、TLT 型（1981-07〜）より学習の期間が長い。シグナルは「翌12か月の超過収益の予測が正なら保有」とし、TLT 型と IEF 型の両方に同じシグナルを使う。副の目的変数は、10年ゼロの翌月の超過リターン。
- 再推定は毎年1月。金利だけのモデルは1990年から、マクロを使うモデルは2000年から（ビンテージがある期間）。予測は毎月、その月末の特徴量で出す。
- 学習の組（R2 を満たすもの）が60未満のときは予測せず、その月の戦略は現金とする。
- 候補の値は R3 の検証の平均二乗誤差で選び、選んだ値で学習データ全体（R2 を満たす組）に学習し直す。

## 7. 見かけの予測力の分解（判定とは別に報告）

1990-01〜2018-12 の out-of-sample で、論文に近い設定から始めて、時点のルールを1つずつ足す。目的変数は1年保有の超過収益（n=2〜10年と満期平均）、指標は R²oos。モデルは EN・ET・NN-FM と P の OLS。

| 設定 | 中身 |
|---|---|
| V0 | 論文に近い設定。マクロは確定値（ビンテージ 2019-02、公表の遅れを無視）、学習に未確定の目的変数を含める（$s\le t-1$）、検証に空白なし、標準化と主成分は全期間で作る。金利は Liu–Wu と GSW の両方 |
| V1 | V0 ＋ R2（確定した目的変数だけ） |
| V2 | V1 ＋ R3・R4（空白と、窓の中での変換） |
| V3 | V2 ＋ R1（実時間のマクロ）。ビンテージがある 2000-01〜2018-12 で V2 と比べる |

- 訂正の中身は確認できていないので、V0 は考えられる先読みの組み合わせを再現したものであり、論文の訂正前の計算そのものではない。

## 8. 道具の確認（判定の前にすべて通す）

| 番号 | 確認 | 合格の条件 |
|---|---|---|
| G0 データ | 合成の TLT 型・IEF 型と、実際の TLT・IEF の月次リターン（2002-08〜） | 相関 0.95 以上。下回った型は、判定に実際の ETF のリターン（2002-08〜）を使い、本番 A をその分短くする。GSW と Liu–Wu の金利の差も一覧にする |
| G1 合成データ | W0：目的変数と対象のリターンを、実際の値のブロック・ブートストラップ（ブロック12か月）に置き換え、特徴量との関係を壊す。W2：実時間のマクロの第1主成分に比例する成分を、目的変数と対象のリターンに埋め込む。比例の係数は、その成分の符号で持つ戦略の CER が、本番 A で L0 より年4%以上よくなる最小の値にする | 各20回。W0 で P1〜P5 の $H_A$ が有意になるのは、どの戦略も20回中2回以下。W2 で P3 と P4 が $H_A$ で有意になるのは、それぞれ20回中18回以上 |

| G3 Bauer–Hamilton 型 | 利回りの主成分3つの VAR(1) と、マクロ因子の独立な VAR(1) から、マクロが効かない世界を200回作り直す。各回で本番 A の「P4 の CER − P2 の CER」と「P5 の CER − P2 の CER」を計算する。対象のリターンは、作り直した金利から §4.3 の式で作る | 判定 §3.5 の④で使う（p 値 =（1＋実データ以上の回数）/201）。計算を軽くするため、初期値は5通り、候補の値は本番 A の実データで選んだものに固定する |

## 10. テスト

- `returns.py`：平らなカーブでは超過収益が0になる。既知のパラメーターでの手計算と一致する。
- `pit.py`：R1〜R4 の例外（G2）。学習の組の最後の目的変数の終わりが t 以下になる。空白の長さ。
- `fredmd.py`：小さなビンテージの例で、tcode の各変換（差分・対数差分・二階差分）が手計算と一致する。系列の構成が変わるビンテージを扱える。
- `evaluate.py`：CER の式。ブートストラップの再現性（同じ種で同じ値）。Holm の補正の既知の例。判定の表（§3.5）の各分岐。
- `backtest.py`：費用が切り替えの月だけに引かれる。ずっと保有の戦略の結果が、対象のリターンそのものと一致する。
- 合成データでの G1 は、実行時間が長いので `make test` には入れず、CLI で回して結果を記録する。

## 11. 計算量

- 実データの1回（本番 A・B、2つの目的変数）：再推定37回 × 全モデル。手元の20コアで、再推定ごとに並列にして1時間程度の見込み。
- G1（各20回）と G3（200回）は、モデルを減らした設定で各1〜2時間の見込み。GPU は使わない。

## 12. 次の段階の概略

- S2 JGB：対象は 2561（実際の価格は上場以来。yfinance の 2561.T は 2020-02-21 からで、2026-10-19 に確認）と、財務省カーブから作る合成（デュレーション約9.5年）。金利は macrokit の Svensson ゼロ金利（`termstructure/curve.py`）、現金は無担保コール翌日物（macrokit `callrate`）。日本のマクロにはビンテージがほとんどないので、市場のデータ（JGB のフォワード、米国の因子、trend）だけを使う。ゼロ金利政策・QQE・YCC（2016-09〜2024-03）の期間を分けて報告する。判定は S1 と同じ形で、別に出す。
- S3 毎月のシグナル配信：S1 か S2 で使えると判定されたときだけ設計する。

## 13. 既知のリスク

- 2000〜2018年は債券の上昇相場で、ずっと保有に勝つのは難しい。勝てないこと自体が結果になりうる。
- 本番 B は約90か月で、検出力が低い。判定では符号だけを求める。
- 合成の TLT 型は、実際の TLT（クーポン・凸性・経費）と違う。G0 で確かめ、判定は合成で出す。
- FRED-MD は、ビンテージごとに系列の構成と変換コードが変わる。ビンテージの中だけで扱う。
- yfinance の価格には誤りや欠けがありうる。日次の値を GSW の合成リターンと見比べ、大きく外れた日を一覧にする（除外しない）。
- 訂正論文の中身が分からないので、論文の訂正後の数値とは比べられない。
