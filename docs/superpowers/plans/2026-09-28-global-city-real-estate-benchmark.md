## 2. 比較を三つの層に分ける

| 層 | 資産・指標 | 比較条件 | 主な限界 |
|---|---|---|---|
| A 土地 | 現地通貨/土地㎡、円/土地㎡、土地取得額/許容延床㎡、地価指数 | 用途、建築可能容積、権利、評価/実売、都市内立地 | 海外の地価は欠落が多い。住宅価格から建物分を引く推計は別系列 |
| B 区分住宅 | 売買価格/専有㎡、月額家賃/専有㎡、条件を合わせた表面利回り | 中古共同住宅、面積、築年、駅距離、階・設備、所有権、契約種別 | 売買と賃貸は通常別標本。条件を揃えても同一物件の実績ではない |
| C 賃貸一棟 | NOI利回り、費用率、空室、CapEx後CF、10年IRR | 住宅用途、規模、築年、構造、安定稼働/改修案件、地域 | 一棟取引・実績費用は入手難。調査利回りとモデル値を明示する |

福岡の楽待等の一棟物件はCに置く。Bの海外コンドミニアム利回りを、福岡の一棟利回りへ直接比較しない。JREI国際指数の高級住宅はBの独立した「prime」区分に置き、一般住宅と別タブにする。

### 標準物件条件

- Bの第一比較群: 中古共同住宅、専有40〜60㎡、築10〜30年、住宅用途、完成済み。可能な都市では鉄道駅徒歩圏を別集計する。海外の徒歩分数を直線距離から捏造しない。
- Bの第二比較群: 60〜90㎡の世帯向け住宅。第一群と混ぜて都市平均を作らない。都市の主要ストックに合わない場合は対象比率も示す。
- C: 安定稼働の賃貸共同住宅を優先。JREI・CBRE等に依存する比較では、各調査の標準物件条件を原文のまま記録し、条件が共通する部分だけ比較する。
- 価格の安い個票を削除する前に、築古・借地・家賃規制・一括売買・面積誤りを判別する。外れ値処理前後の件数と結論の変化を保存する。
- 条件を緩める順序は、面積帯→築年帯→都市内範囲。各段階を別コホートIDにし、緩和前後の差を表示する。築年不明を自動的に同じ群へ入れない。

### 地理の扱い

`city_core`（行政中心市）、`metro`（都市圏）、`submarket`（区・地区）を別IDにする。地理台帳に元の境界名、行政コード、境界年、FUAとの対応を保存する。都市圏しかない指標は都市圏として掲載し、中心市の住宅データと同じ観測値にはしない。

東京23区と東京都、ニューヨーク市とNY都市圏、City of LondonとGreater London、福岡市と福岡都市圏を区別する。香港・シンガポールは都市相当の市場だが、他都市の中心部だけとの比較を避け、必要なら地区別に分ける。

## 5. 指標と計算定義

### 5.1 価格・成長率

- 土地㎡と建物専有㎡の単価を別の指標IDにする。総床面積から専有面積への一律換算はしない。
- 土地の許容延床単価は `土地価格総額 /（土地面積 × 採用容積率）`。指定容積率と実際に使える容積率は区別し、道路・高さ等の制約が未確認なら「指定容積率ベース」と表示する。
- 現地名目価格と現地CPIで実質化した価格、円換算名目価格を並べる。為替による安さを現地の収益性改善と混同しない。BIS等の実質化済み系列は再度CPIで割らない。購買力平価は所得・生活費の補助比較に限定し、投資CFの換算に使わない。
- 成長率は同一仕様の指数、継続地点、リピートセール、条件調整モデルを優先する。各年の標本平均は構成変化を含むため、別系列にする。
- `CAGR = (V_end / V_start)^(1/経過年数) - 1`。指数の基準年を100に揃えても、都市間の絶対価格水準は比較できない。
- 借地・リースホールドは残存年数別にする。土地の所有権相当価値への換算を行うなら、その割引率・更新条件をモデル仮定として別途表示する。

### 5.2 「期待利回り」を三つに区別

| 表示名 | 定義 | 使い方 |
|---|---|---|
| 調査上の要求利回り | 投資家・鑑定士等がその時点で求める利回り | JREI・CBRE等。調査条件・費用控除定義を併記 |
| 現在の収益利回り | 実績または安定化NOI / 同時点の価格 | 実績NOI、満室想定、鑑定NOIを識別。分母も取引・売出・鑑定を識別 |
| シナリオIRR | 将来CFと売却を置いた内部収益率 | 仮定に条件付けられた将来収益率。確率を置かない初版では「期待値」と呼ばない |

市況レポートの `yield` は定義を読んで上記へ対応付ける。用語だけでNOIと認定しない。NOIの原定義が確認できないものは `yield_definition_unverified` としてNOIランキングから除外する。

### 5.3 収益と費用

\[
G = \text{年間満室想定賃料等},\quad
EGI = G - \text{空室・未回収損失} + \text{その他収入}
\]

\[
NOI = EGI - \text{固定資産関連税・保険・管理・通常修繕・所有者負担費用}
\]

\[
y_{gross}=G/P,\quad y_{NOI}=NOI/P,\quad
y_{allin}=NOI/(P+C_{buy}+C_{initial})
\]

\[
y_{cash}=(NOI-CapEx_{reserve})/(P+C_{buy}+C_{initial})
\]

`P` は物件価格、`C_buy` は取得費、`C_initial` は初期工事、`CapEx_reserve` は将来大規模更新の平準化額。最後の指標は「修繕積立控除後利回り」と呼び、市場のcap rateと混ぜない。DCFでは実際の年別工事を使い、同じ工事の積立と支出を二重控除しない。

NOIは借入利息・元本返済・所得税・減価償却・資本的支出を控除する前とする。ただしソースが別定義なら原定義も保持する。共益費の通過項目、入替広告費、賃借人負担税などもマッピングする。実収入には既に空室影響があるため、同じ期間の稼働率を再度掛けない。

香港等の公表利回りや `12 × 都市平均家賃 / 都市平均価格` は、定義・標本が合わない限り「参考比率」。異なる面積基準・物件群では、その参考比率も表示しない。区分住宅と賃貸一棟のNOIを同じ順位にしない。

### 5.4 金利・為替・所得

- NOIスプレッドは `同時点のNOI利回り − 同一通貨の10年国債利回り`。土地リスク、流動性、成長、期間、税を完全に調整した超過収益率ではない。
- 国債は投資機会費用の一指標。実際の借入条件、為替ヘッジコスト、投資家の調達通貨は別に入力する。
- OECDの対象外・欠損は現地政府/中央銀行の系列を確認する。香港HKMA、シンガポールMAS等のソースを別紙X08に記載した。発行プログラム変更、通貨、指標利回りと実取引の違いを残し、廃止系列を現在まで延長しない。
- 所得比は同じ地理範囲の世帯所得を使用し、中央値/平均、総額/可処分、世帯/一人を混ぜない。標準住戸の価格所得比と家賃所得比を作り、揃わない都市は非表示とする。
- 円ベースCFは各時点の `現地CF × 円/現地通貨`。現地通貨建て借入も同じ時点で円換算する。年平均と期末為替は家賃フロー・評価額に応じて使い分ける。

## 6. 分析モデル：単純な比較から段階的に進める

### M0 データ被覆と記述比較 — 必須

都市×指標×年の取得状況、観測方法、資産群、標本数を先に可視化する。価格・家賃・NOI・成長・国債差の中央値と分布を、比較可能な組ごとに出す。初版では独自100点スコアを作らない。高い点数がデータ不足を隠すことを避ける。

都市の並び替えは指標ごとに行い、対象数を表示する。データ不足を最下位として扱わない。任意の重みで将来ランキングを作る場合も、順位の重み感応度を必須とする。

### M1 条件を合わせた価格・賃料比較 — 必須

地理・面積帯・築年帯・物件種別・取引種別・時点を揃えたコホートを作る。価格と家賃の標本数を別々に示す。同一住戸に対応しない場合は「条件を合わせた別標本」と明記する。

価格と家賃の観測期間が90日超ずれる場合は、原則その組の利回りを比較対象から外す。年次調査同士は同一対象年でも調査期間を確認し、四半期の実測利回りとは別表にする。調整して揃えるなら使用指数と補正幅を保存し、無調整値も残す。

採用セルは価格・家賃それぞれ独立物件数30件以上を目安とする。20〜29件は参考、20件未満は細かい順位付けを避ける。これは公的統計の公表値を否定する閾値ではなく、自作推計の暫定的な表示基準。件数が多くても偏った標本なら不適切と判定する。投資家調査の回答数を物件件数に置き換えない。

分布の信頼区間は建物単位の再標本化で評価する。多数の広告再掲を独立標本に数えない。売出価格を成約価格へ一律何％割り引く処理はしない。

### M2 条件調整モデル — 個票が足りる都市だけ

都市内の `log(価格/㎡)` と `log(家賃/㎡)` を別に推定する。候補変数は面積、築年、立地、建物種別、階、権利、契約期。賃料規制や所有権など主要変数が欠ける都市では精密な調整値を出さない。

原則100件以上・説明変数あたり十分な独立物件数を確保し、単純なコホート中央値を基準に、時系列を分けた検証で誤差が改善する場合に採用する。都市ダミーだけで国際的な品質差を解決したと扱わない。小標本のため改善を確認できなければM1に留める。

### M3 パフォーマンスと原因の調査 — 必須だが因果を断定しない

2015年〜共通最新期、直近5年、直近10年の現地実質成長率を比較する。比較可能な8都市以上が揃う組では上下四分位と中位を用い、それ未満は数値のみ示す。「高パフォーマンス」は指標・期間ごとに定義し、地価上昇と保有総収益を分ける。

| 検証する要因 | 指標 | 調べる順序・反証 |
|---|---|---|
| 実需・所得 | 世帯、純移動、雇用、実質所得、大学等 | 人口だけでなく世帯数・借家需要を見る。需要増でも家賃が増えていないなら価格説明として弱い |
| 供給 | 住宅ストック、完成戸数、許可、空室、新規供給/既存戸数 | 再開発の利便性向上と住宅供給増を同時に見る。許可を竣工と扱わない |
| 金利・信用 | 国債、実際の貸出条件、信用供給 | 価格だけ上昇し賃料が横ばいなら利回り圧縮を疑う。金利低下だけで全都市の差を説明しない |
| 土地利用 | 容積、交通、供給可能地、規制 | 事業化時・工事・開業を分け、既に価格に反映済みかを調べる |
| 税・制度 | 取得資格、賃料規制、取得/保有/売却費用 | 制度変更前後の需要層・物件群を分ける。別都市全体を安易な対照群にしない |

同じ資産・定義なら `P = NOI / cap rate` から `Δlog P = Δlog NOI − Δlog cap rate` と分解できる。別ソースの不一致が大きい場合はこの恒等式を強制しない。区分の家賃/価格比を使う場合はNOI分解と別表示にする。

原因メモは各都市につき「観測された変化→一次資料→説明仮説→反証・未確認事項」の順に記す。20都市の小さな横断回帰だけで因果や将来成長を確定しない。因果推論は、政策時点・適切な対照群・並行トレンド等が揃う個別テーマで別設計とする。

### M4 国内物件の買値と海外比較を接続 — 福岡への適用

海外の水準から日本の適正価格を直接決めない。まず国内の現在家賃、運営費、修繕、融資から物件の成立価格を求める。そのうえで海外比較は、要求利回り・賃料成長・出口利回りに置いた幅が妥当かの参考にする。

対象は福岡の既存固定スナップショットとし、収集日・件数・物件ID集合を固定する。博多、赤坂・大濠、箱崎・貝塚、高宮・大橋等を地域別に分け、各物件に `現在の売出価格 / 収支から求めた価格上限 / 必要な賃料成長 / 出口利回り耐性` を付ける。データ確認前に全件数や既存通過数を固定値として引用しない。

以前の個人所得との損益通算による `equity_irr_with_loss_offset` は、個人条件に依存する別シナリオとして維持する。国際比較や物件の共通採点へ混ぜず、既存の通算効果なし判定も変更しない。

## 7. 10年シナリオ分析

### 7.1 共通の資産CF

保有期間は基準10年、感応度5年・15年。年次の期末CFとし、取得時をt=0に置く。

\[
CF_0=-(P+C_{buy}+C_{initial})
\]

\[
CF_t=NOI_t-CapEx_t,\quad
Sale_H=\frac{NOI_{H+1}}{cap_{exit}}(1-c_{sell})-C_{exit}
\]

最終CFへ `Sale_H` を加える。`C_exit` は未控除の売却時費用、借入なしの段階では残債を含まない。次年度NOIを出口価格に使うことを表示する。借地残存年数と更新条件にこの方法が合わない場合は売却価格を別入力し、一般の永久所有モデルを適用しない。

投資家借入後CFでは、取得時借入を加え、各年の利息・元本返済、出口の残債を控除する。元本返済をNOIの費用にはしない。年間DSCRと最低CFを併記し、IRRだけで資金繰りを判定しない。

IRRが存在しない、符号変化が複数あって一意でない場合は、その状態を返し、NPV・総CFも示す。任意の一根を「期待利回り」と表示しない。

### 7.2 仮定の置き方

| 変数 | 基準 | 感応度・ストレス例 |
|---|---|---|
| 現行家賃 | 確認できた現行契約/安定化賃料 | 初年度家賃−10%、回復は別指定 |
| 将来家賃 | 当初は実質横ばいの共通参照ケース。名目化に使うインフレ仮定を明示 | 実質成長±1%/年、別途都市固有の根拠付きケース |
| 空室・未回収 | 現行実績または同じ市場区分の指標 | +5ポイント。新規供給が多い市場は別途期間を設定 |
| 運営費 | 費目別実績。未確認部分は出所付き範囲 | +20%、保険・管理費の別感応度 |
| 大規模修繕 | 建物調査の年別工程 | 見積額+30%、時期前倒し。根拠なしの工事額を実績扱いしない |
| 出口利回り | 入り口と同水準の参照ケース。築年増・市場の標準条件も検討 | +50/+100/+200bp、下方感応度−50bp。0以下を許さない |
| 借入 | 無借入を共通比較の基準にする | LTV50%/70%、実際に可能な返済期間、金利+100/+200bp |
| 為替 | 取得時レート一定の参照ケース | 現地通貨が円に対し−10%/−20%、+10%。推移経路も指定 |
| 取得・売却費用 | 主体・国籍・居住地・権利を指定した見積り | 追加取得税や売却費の変化。空欄を0と扱わない |

これは予想値ではなく比較用の仮定。インフレ・金利・賃料成長を独立に大きく動かした場合の整合性も注記する。基準、家賃・稼働悪化、金利・出口悪化、複合悪化の4ケースを作り、単変量感応度と分ける。仮定する確率の根拠がないため、初版では加重平均の「期待IRR」や成功確率を計算しない。

複合悪化の共通参照ケースは、家賃−10%、空室+5ポイント、運営費+20%、出口+100bp、借入金利+100bp、現地通貨の円換算価値−20%を用いる。ただし発生確率は付けず、二重計上や契約固定期間との不一致を確認する。都市固有のケースは別列にする。

### 7.3 税と実行可能性

現地の追加取得税、年次資産課税、譲渡費用は適用条件を確認して取得・運営・売却の段階に配置する。日本の所得税・損益通算・譲渡税ロジックを海外へそのまま流用しない。

海外の個人所得税、源泉税、日本側課税、租税条約、外国税額控除、法人利用まで含む税引後比較は、適用主体と税務仕様を確定した拡張工程とする。初版は税引前の共通結果と、確認できた取引・保有費用まで。税引前結果を「最終手取り」と表示しない。

韓国の保証金・チョンセは返還負債として扱う。機会費用で月額相当へ換算する場合は換算金利を明記した補助指標に留める。保証金の流入だけをCFに加えて高IRRを出すことは禁止する。

## 8. 品質・検証の条件

| 検証 | 合格条件または表示上の扱い |
|---|---|
| 出所と単位 | 掲載値100%にsource_id、定義、対象期、取得日、単位、資産区分、地理、観測方法を持つ |
| 原本突合 | 各採用系列の初期・中期・最新の少なくとも3観測を原本と照合。桁、通貨、年率化、暫定値を確認 |
| 物件重複 | 再掲・複数仲介・多行の同一売買を識別。DVFの売買総額を物件行ごとに加算しない |
| 利回り | 生の収入と価格から再計算可能。サンプル・面積・期間の不一致を検知して除外または参考へ移す |
| 改定・欠損 | 取得漏れと公表なしを区別。方法変更を注記し、断絶を機械的に接続しない |
| 成長・リスク | 期間と頻度を一致。10年CAGRは実際に10年以上離れた両端値が必要。10年の四半期変動率には41時点・40変化分を要し、欠損は補間して埋めない。鑑定平滑化を注記 |
| 将来予測 | 学習・検証期間を分離。同一建物の広告を学習と検証に分散しない。公表日以後の情報のみ使用 |
| 再現性 | 同じ原本・設定・コード版から同じ指標。乱数シードと除外件数を保存 |
| レポート | 欠損は0にならず、単位・期間・観測/調査/モデルが図にも表示される。原典へ遡れる |

「今の標準地だけで長期を遡る」生存地点分析と、「各年の市場」を表す指数は別表示にする。利用可能な履歴だけで良い都市を選ぶ生存偏りも、全候補都市との被覆比較で点検する。

外部提供指数の過去公表版を確保できない場合、現在の改定済み系列による分析を「当時実行可能な投資成績」と主張しない。2026年の選定都市・物件だけを使った結果も同様とする。

## 11. 実行タスクと受入条件

分析は各タスクの成果物を確認して順に進める。通常のデータ整理は都度の追加承認を必要としない。有料契約・新規依存・公開API変更・外部公開が必要な作業のみ、既存の承認範囲を確認する。

### Task 1 — 指標・都市・ソース台帳を固定する

**作成:** `sources.json`、`cities.json`、`schema.py`、`tests/test_schema.py`。**更新:** ソース調査票の取得状態と権利欄。

- [ ] 20都市の元地理コードと中心市/都市圏の区分を記録する。
- [ ] 採用系列に単位・資産・価格/家賃/面積定義・期間・観測方法・利用条件を記録する。
- [ ] 定義不足、重複series_id、土地/建物面積の混在を拒否する台帳検証を作る。
- [ ] 「BIS国別指数を福岡市へ割当」「primeを一般住宅へ割当」を拒否する固定入力を検証する。
- [ ] 初版で取得する系列と保留系列を一覧出力する。

**受入:** 全採用系列に出所と定義がある。unknownの権利・定義は有効な比較値へ進めない。対象都市の増減が文書と台帳で一致する。

### Task 2 — 6都市の原本と履歴を収集する

**作成:** `collect.py`、先行4都市群のアダプタ、`macro.py`、`tests/test_collection.py`、原本・マニフェスト。

- [ ] 香港RVDの既確認CSVを保存し、先頭・末尾・暫定符号を原本照合する。
- [ ] 香港価格/家賃/公表yield、英国HPI/PIPR、米国住宅系列、国内既存系列を個別に取得する。
- [ ] FX、CPI、国債の対応系列を取得する。利用可能な公表日・改定版を記録する。
- [ ] タイムアウト、HTMLを返すCSV URL、ゼロ件、ページ欠落、同名改定ファイルのケースを検証する。
- [ ] 取得ログ・期待期間との差分・ハッシュを出し、再実行して原本が破壊されないことを確かめる。

**受入:** 各都市に価格・家賃の少なくとも一つの履歴または、取得できなかった具体的理由がある。取得できた系列は開始・終端・欠損年を説明できる。全6都市の価格・家賃が揃わなければ、その欠損を解消するまで「6都市比較完成」と呼ばない。

### Task 3 — 標準化・比較可能性・M0を作る

**作成:** `normalize.py`、`tests/test_normalize.py`、`observations.parquet`、`coverage.csv`。

- [ ] 原本を定義付きlong形式へ変換する。無変換の値も追跡可能にする。
- [ ] 週額×52、月額×12、現地通貨→JPY、sqft→㎡の単位変換を検証する。
- [ ] 専有/総床の不一致、地理の不一致、時点差90日超を検知する。
- [ ] チョンセ保証金、英国床面積欠損、台湾駐車場込み面積、DVF多行売買を、原本採用前に既知の制約として登録する。
- [ ] 都市×指標×年の被覆表を出し、層A/B/Cごとの比較可能な組を確定する。

**受入:** 不一致は勝手に補正されず、除外理由が出る。日付・単位の変換が原本と3点以上一致する。広域データに中心市のラベルが付かない。

### Task 4 — M1と利回り・費用比較を作る

**作成:** `metrics.py`、`tests/test_metrics.py`、指標表と費用マッピング。

- [ ] 価格・賃料の別標本を定義したコホートへ分け、独立件数と分布を出す。
- [ ] CAGR、表面/NOI/取得総額/修繕控除後利回り、国債との差を算出する。
- [ ] 実収入の空室二重控除、取得費の欠損0化、保証金の賃料化、NOI定義未確認を拒否する。
- [ ] JREI・CBRE等は原定義と標準物件条件を人が照合し、調査値専用の表へ置く。
- [ ] 次の手計算ケースを検証する。価格100、年間想定賃料6、稼働95%、運営費1.5ならNOI4.2、NOI利回り4.2%。取得費5なら取得総額ベース4.0%。修繕積立0.6なら修繕控除後約3.4286%。

**受入:** すべての利回りを入力から再計算できる。経費率仮定による値はモデルと表示される。足りない都市のNOIを全国一律の経費率で埋めない。

### Task 5 — M4とシナリオDCFを作る

**作成:** `scenarios.py`、`tests/test_scenarios.py`、`scenarios.parquet`。

- [ ] 10年・無借入・税引前CFを先に実装し、取得費・年別CapEx・翌年NOIでの売却を含める。
- [ ] 借入後CF、残債、DSCR、金利・期間の感応度を追加する。
- [ ] 各年の円換算と、為替一定/段階変化の経路を適用する。
- [ ] 基準と3つの悪化ケース、買値上限の逆算を出す。買値上限は要求NPV=0または指定IRRを満たす価格として条件を併記する。
- [ ] 価格100、費用なし、年NOI5、出口5%、10年ならIRR5%になることを検証する。
- [ ] 同じケースで出口6%なら売却額83.3333…、最終CF88.3333…、IRRは5%未満になることを検証する。
- [ ] 借入有無、最後の残債、CFごとのFX、複数符号変化、金利0、売却費100%などの入力を検証する。
- [ ] 福岡の固定物件群を読み取り、データ不足を残したまま現在家賃での買値と出口感応度を作る。

**受入:** 修繕の二重控除がない。海外へ国内税制を適用しない。税・取得費等の未確定入力は「試算条件」と表示し、最終手取りと誤認させない。既存スクリーニングの出力・保存データは変更されない。

### Task 6 — 20都市候補へ拡張し、成長・原因を調べる

**作成:** 採用決定したソースのアダプタと入力検証、原因調査メモ。**更新:** 都市・ソース台帳、被覆表。

- [ ] 個票が足りる都市だけM2を実行し、コホート中央値との予測誤差を比較する。
- [ ] 期間別・指標別に成長を分類し、同じ都市でも地価と家賃の分類が違う場合を示す。
- [ ] 世帯・雇用・供給・金利・制度の一次資料から、観測事実と説明仮説を分けた原因メモを作る。
- [ ] 学習/検証に同じ建物が漏れないこと、公表日時より前に値が使われないことを検証する。
- [ ] 日本の各都市について近い比較相手を、規模・産業・人口・供給・住宅種別から2〜3都市選ぶ。事後の価格上昇率だけで似た都市を選ばない。

**受入:** 全候補都市の採用・欠損理由が説明される。20都市すべてが全指標で比較可能と偽らない。原因の断定と将来予測の裏付けが別々に示される。

この表は全体版のデータ定義調査と検証を含む計画値で、納期確約ではない。直近は先行収集プランAの1〜2人日を目安に2市場の成果物を作る。本書Task 1〜4の6都市比較はその後の段階とする。無料データで不足する項目は、狭い比較群のまま出す選択と、有料データで補う選択を具体的な欠損表で判断する。

全体版の必須完了条件は次のとおり。§0の初回2市場版は、先行収集プランTask 1〜3の完了条件で判定する。

- [ ] 6都市の価格・家賃の履歴と原典が揃い、期間・定義・欠損を説明できる。
- [ ] 日本の土地比較と、海外で取得可能な土地の比較範囲が明確になっている。
- [ ] 少なくとも一組の国内外比較で、同条件の収益指標または定義を揃えた調査利回りを示せる。成立しなければ国際利回り比較は未完了と明示する。
- [ ] 20都市候補の被覆と採用/保留理由が一覧になっている。
- [ ] 福岡の現行家賃・買値・修繕を起点にした試算と、海外比較から分かること/分からないことが分かれている。

分析後の自動更新は、原本の更新確認を月次、比較レポートを四半期、制度と投資家調査を公表ごとに更新する案とする。利用規約・更新頻度・費用を確定してからジョブ化する。この計画作成では収集ジョブの追加やスケジュール登録は行っていない。
