# 0003. 知識を開発リポジトリ内に保持する

- Status: Accepted
- Date: 2026-09-16
- Supersedes: [ADR 0001](0001-workspace-docs-and-knowledge-layers.md) の独立 wiki への保存方針のみ

## Context

独立した `~/wiki` と開発リポジトリに保存先が分かれていた。
ユーザーは独立 wiki の新規運用を終了し、知識を
`/home/kazumasa/projects` にまとめることを選んだ。
作業対象のコードと知識を同じリポジトリで見つけ、保守できるようにする。

## Decision

- プロジェクト固有の知識は、そのプロジェクトの README または `docs/` に置く。
- 共通の環境設定・再利用できる手順・トラブル解決記録は、ルートの `docs/knowledge/` に置く。
- ワークスペース全体の重要な判断理由は、引き続き `docs/decisions/` に置く。
- ノートは依頼されたときに作成し、会話全文ではなく再利用に必要な事実、手順、検証結果、制約を残す。
- 秘密情報や勤務先・顧客の機密は保存しない。
- 旧 `/home/kazumasa/wiki` は既存資料として保持し、新規保存先にはしない。
  この決定は旧 wiki の削除・変更・一括移行・コミット・push を許可するものではない。
  必要な既存ノートは個別に確認して取り込む。

## Consequences

- Codex と Claude の共通指示は同じ保存方針を参照する。
- 新規に wiki の分類体系や同期処理を導入せず、通常の Markdown と既存の docs 構成を使う。
- 旧 wiki の内容は自動的には移行されない。今回の WSL 圧縮ノートはコピーし、原本を保持した。
