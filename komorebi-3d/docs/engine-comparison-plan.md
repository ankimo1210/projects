# ORBIT: Three.js と Babylon.js の比較

目的: 同じBlender作品とReact画面を別の描画エンジンで表示し、利用者が違いを操作して確認する。

## 範囲と比較条件

- 既存の `/` はThree.js版、`/babylon` は同じUIのBabylon.js版、`/compare` は比較ページ。
- 共通GLB、視野角43度、モデル正規化、透明背景を使う。
- 比較ページでは生成可能な共通スタジオHDR、環境光のみ、露出1.2、ACES、DPR 1、同じ角度を使用。装飾ノードを除き作品だけを比較する。
- 同じHDRでもBRDF、環境光の前処理、トーンマッピング実装は異なる。ピクセルの一致やエンジン全体の優劣を結論にしない。
- 3D制作は引き続きBlender。今回変えるのはWeb描画エンジンであり、Spline等のGUI制作体験は今回の対象外。

## 実装順序

1. 計測のウォームアップ除外・欠測と、比較画面の動作を検証するテストを先に用意。
2. 共通のレンダラー入力とHDRを追加。Babylon.js 9.25.0 / loadersだけを必要な依存関係として追加。
3. Babylon版に同一GLB、正規化、回転、ワイヤーフレーム、ノード、統計、失敗時プレビューを実装。
4. 比較画面に2つのビュー、同期回転、作品切り替え、順次計測を実装。
5. 型・lint・実ブラウザで確認し、デスクトップ／モバイルの画像と観測結果を残す。

## 計測

- ランタイム・アセットの初回ダウンロードは計測対象外。ウォームアップ後の描画間隔を測定。
- 各エンジンを単独で描画。1秒のウォームアップ後、4秒以上の描画間隔からFPSとp95を計算。
- CSS寸法・描画バッファ寸法、サンプル数、作品のメッシュ／三角形、ブラウザのGPU識別を記録。
- 非表示タブやリサイズは中断。測定途中の値を完成した結果として表示しない。
- この環境の自動確認はChromium + SwiftShader。実機GPU／iPhoneの性能とは区別する。

## 完了条件

同じ作品を両エンジンで実際に表示し、同期操作・単独計測・作品切り替え・モバイル表示・既存サイトが動く。コードとローカルプレビューまで。公開やpushは別途依頼後。
