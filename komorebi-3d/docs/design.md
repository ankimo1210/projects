# Komorebi 3D の設計

目的は既存の喫茶店を継続編集できる3Dプロジェクトにし、Unreal Engineで試す
入口を用意すること。Blenderで確認済みの成果と、UE未検証の処理を区別する。

- 制作元: BlenderのPythonと`.blend`。GLBに部品の形状、材質、配置を含める。
- UE: C++モジュールを持たない5.8向けプロジェクト。組み込みPythonとInterchangeを利用。
- 初回処理: 自己完結GLBを新規マップへインポートし、UE用の照明を追加する。
- 保存先: このリポジトリを原本にし、Unrealを動かすWindows機へ新規作業コピーを作る。
- 再実行: 既存の作業コピーとマップを上書きしない。新規コピーで反復する。
- 検証: データの存在・GLB構造・コピー保護・構文を確認。UE未導入ならUE描画は未検証とする。

最初の範囲はエディタ上のシーン鑑賞。ゲーム化、キャラクター操作、開閉アニメーション、
アセット最適化、公開配布は含まない。
