  中立も分母に含める。219政策段落を15会合に集計し、政府・経済物価の段落を除く。
  全期間を同じモデルrevisionにそろえ、部分的な原文補正は混ぜていない。
- 下段は各会合の決定文に記された無担保コール翌日物の誘導目標。決定日の位置で
  階段状に表示する。実勢金利や適用開始日の系列とは区別する。
- 初期表示ではセンチメントを「主な意見の公表日」に置く。会合日へ戻す表示は
  公表後の文章による事後比較で、当日の金利予測の成績を意味しない。
- [金利manifest](data/boj_policy_rates_2025_2026.json)は日銀決定文15件のURL、金利、

## 2025年の試作と原文補正

[2025年の保存HTML](data/validation/boj_sentiment_2025_2026-11-10.html)と
[非公開ページ](https://chatgpt.com/space/page_7e254e581e9481918c5cf9a5d0ff6290)は試作の記録。
2025年８会合の固定結果を参照できる。

2025年9月・10月・12月の金融政策運営に関する全47段落について、BERTの出力に
Codexによる原文の読解と根拠を添えた。26件は一致し、11件は判定を変更し、10件は保留した。
原文判定では、引締めの支持をタカ派、当面の据え置きや利上げを待つ主張をハト派とした。
金融環境の水準を説明する段落は中立とし、政策金利の方向を決めにくい段落や資産処分の意見は保留した。

- 9月の「現時点での利上げは避けるべき」は、BERTではタカ派（出力97.7%）、原文判定ではハト派。
- 12月の利上げ後も実質金利が大幅なマイナスだと説明する段落は、BERTではハト派（出力99.6%）、原文判定では中立。
- 前回会合との比較は、同じ論点を扱う匿名の意見6組を抜粋。9月と10月の一例では「なお」だけが加わり、10月と12月の一例では見通し実現を条件とする記述から、実現の確度が高まったとして今回の利上げを支持する記述へ進んだ。

原文判定は読解の試案で、独立した正解ラベルは未作成。保存済みのBERT出力に原文判定を添える形で補正した。
レポートの「補正した段落を見る」で11件に絞れる。各根拠と比較の抜粋は[読解データ](data/boj_sentiment_readings_2025.json)に記録した。

## 2025年試作の結果と読み方

- 原文274段落：金融政策116、経済・物価116、政府意見42。前二者232段落を分類し、政府意見は未分類の参考表示。
- 主な集計は金融政策運営の116段落だけ。タカ派41、ハト派20、中立55。上位2クラスの出力差が20ポイント未満の段落は5件で、「中立」とは別に拮抗と表示する。
- モデル出力は正解確率・利上げ確率ではない。段落数は委員の人数や票数でもない。
- 文単位の分類器を段落単位へ適用しているため、段落内の混在も未検証。前後の表示は読者向けで、推論は段落ごとに独立。
- BERTの中立には方向性なしの文のほか、周辺文脈なしでは方向を決められない文も含まれる。

## 採用モデルと判断

[`Woochachino/cbsent`](https://huggingface.co/Woochachino/cbsent) の
ModernBERT（BERT系）を使用。revisionは
`21c60231755d79fe9566bb8f0bfd08bd78233ce5` に固定。
Fed・カナダの文書とFOMC等のラベルで学習された英語モデルであり、入力は日銀の公式英訳。
今回の追加学習はない。モデルカードのFOMCテスト496文・3 seed平均weighted F1 0.658を、
日銀の性能や特定revision単体の正解率に読み替えない。重みはCC BY-NC 4.0で、配布物には含めない。

初期候補 `LorenzoAleCon29/finbert-tone-ecb-hawkish-dovish` は、
単純な利上げ支持を中立とし、CPU/GPUで同じラベルを再現したため採用を見送った。
ModernBERTは点検用5例のうち4例で期待と一致するが、
`It is premature to raise interest rates given weak demand.` をタカ派と誤分類する。
この少数例の一致を性能評価には使わず、結果と限界をHTMLに埋め込んでいる。

## 再実行（WSL、リポジトリルートから）

共有 `.venv`、本番依存宣言、lockfileは変更しない。
推論時のみ `uv run --no-sync --with` の一時環境を使う。
今回使用した既存PyTorchは `2.11.0+cu128`、Transformersは `4.57.6`、
最終推論はCPU・FP32・batch 8・4スレッド。
PyTorchをまだ利用できない環境では、同じ一時環境の `--with torch==2.11.0` で指定できる。

```bash
cd /home/kazumasa/projects

# 保存HTMLを閲覧（このファイル1本だけをlocalhostに配信する）
uv run --no-sync python market-research/scripts/analysis/boj_sentiment_report.py serve --year 2026 --port 8772

# 以下は別のターミナルで必要な場合にだけ実行
# 原本を再取得すると現在の公表版に置き換わる。通常の閲覧には不要。
uv run --no-sync python market-research/scripts/analysis/boj_sentiment_report.py fetch --year 2026 --as-of 2026-11-11
uv run --no-sync --with transformers==4.57.6 python market-research/scripts/analysis/boj_sentiment_report.py score --year 2026 --device cpu
uv run --no-sync python market-research/scripts/analysis/boj_sentiment_report.py render --year 2026 \
  --readings market-research/docs/data/boj_sentiment_readings_2026.json

# 原本・モデルなしでも、保存HTML内の結果から通信なしで再生成できる
uv run --no-sync python market-research/scripts/analysis/boj_sentiment_report.py render --year 2026 \
  --from-html market-research/docs/data/validation/boj_sentiment_2026.html \
  --output _data/market-research/boj-sentiment-2026/rebuilt.html
```

PC上の閲覧URLは <http://localhost:8772/#reading-review>。スマホでは冒頭の非公開ページを開く。
原文判定は保存HTMLに埋め込むため、`--from-html` で再生成するときは読解データの指定も不要。
サーバーは起動時点のHTMLを配信するため、
HTMLを再生成したら `Ctrl+C` で止めて起動し直す。
保存HTMLはサーバーなしでもブラウザで開ける。Google Fontsが利用できない場合はローカルフォントにフォールバックする。

上流がTransformers 5形式で保存した `tokenizer.json` を、4.xの
`PreTrainedTokenizerFast` で読み、同梱の特殊トークン・入力名を明示している。
モデル重みはsafetensorsのみを使い、remote codeを実行しない。
2025年の原本から再計算する場合は、各コマンドで `--year 2025` を指定する。
